資格取得の支援を調べるときは、学習や受験の時間をどう確保するかと、費用を誰が負担するかを分けます。公務員なら資格の勉強に全国一律の特別休暇が使える、という制度ではありません。業務研修、職専免、年次休暇、自己啓発等休業、費用助成はそれぞれ条件を確認します。

本記事は2026年11月時点の公開情報にもとづきます。国の制度と横浜市の公式案内を例に、申込み前の確認手順を整理します。本人の任用や職種に適用される制度、助成額、返還義務等の判断は、所属の要綱・規程と担当への照会で行ってください。

## 時間と費用を別々に確認する

受験料の助成があることは、講座を受ける時間が勤務になることや、試験日に特別休暇を取得できることを意味しません。制度の案内を見つけたら、本人が利用したい支援が何かを分けて確認します。

| 支援の区分 | 確認する内容 |
| --- | --- |
| 業務としての研修 | 受講命令、対象時間、修了報告、勤務記録 |
| 職務専念義務の免除 | 根拠、対象、承認期間、給与の扱い |
| 年次休暇 | 残数、試験・通学の予定、取得単位と承認 |
| 自己啓発等休業 | 対象課程、任用・在職要件、期間、無給の取扱い |
| 費用の助成 | 対象資格、対象者、経費、申請時期、取消・返還 |

例えば、業務に関係する試験の受験料を助成する制度があっても、本人が受講する民間の講座代や交通費まで対象とは限りません。資格の取得前に申請する制度か、合格してから申請する制度かも重要です。

資格の登録料、更新料、年会費、教材、実務講習、試験の再受験等も分けます。支援対象の「受験料」という言葉から、取得・維持にかかる全経費まで公費と考えないようにします。

## 研修命令と職専免で参加する場合を区別する

地方公務員法第35条は、勤務時間と職務上の注意力を職責の遂行に用いる職務専念義務を定めています。学びたい内容が仕事に関係していても、本人が勤務時間中の受講を独断で決めることはできません。

横浜市職員研修規程第10条は、選定された職員へ日常業務を離れて研修を受けるよう命じる仕組みと、自己啓発を主目的と認める研修を職免によって行う取扱いを区別しています。この規程は同市長が任命権者として行う研修の例です。他の任命権者や自治体にもそのまま同じ条件を当てはめるものではありません。

資格講座の名称が研修であっても、どの取扱いで参加するかを担当へ確認します。職専免の場合も、承認が必要な範囲や給与等の扱いを確認し、単に勤務を休める制度と読み替えないようにします。

オンライン受講や録画の視聴でも同じ確認が必要です。職場で視聴すれば必ず勤務、自宅で学べば必ず私的、という区分ではありません。詳しい整理は[研修の時間と勤務の扱い](./seido-kyuka-kenshu-jikan.html)を参照してください。

## 年休で試験や学習の時間を確保する場合

業務研修等に当たらない学習や受験の予定では、本人の年次休暇の残数と取得手続を確認します。国の勤務時間法第17条第3項には、取得時期の承認と、公務の運営に支障がある場合を除き承認しなければならない旨の定めがあります。地方は本人の条例・規則等で確認してください。

試験の日、事前の講習、会場への移動、合格後の手続をカレンダーに分けます。試験日だけでなく何に勤務しない時間が必要かを整理し、日・時間等の取得単位に沿って請求します。

仕事で必要な資格を取得する予定であっても、休暇の承認と研修・費用支援の認定は別です。年休を使ったから助成対象外、又は助成対象だから特別休暇が認められると、本人の推測で結び付けないようにします。

短時間勤務や非常勤の場合は、本人の付与日と残数、勤務する日を基に予定を考えます。勤務しない日を年休として数えたり、試験日に予定される休憩まで休暇時間へ含めたりしないでください。

:::insight
資格取得の計画では、「取りたい資格」と「利用できる支援」を先に一致させようとしないことが大切です。本人が何を学び、現在又は将来のどの仕事で使いたいかを整理し、そのうえで時間と費用の制度を調べるほうが判断しやすくなります。私たちは、助成があるという理由だけで受験を勧めたり、支援がないから学ぶ意味がないと決めたりしません。試験だけでなく講習や登録、継続の負担も見通し、本人が無理なく続けられる計画を考えてください。現職の業務に知識を活かしながら働き続ける選択も尊重します。資格を取ることを転職の意思表示にせず、必要な学習と制度の確認をそれぞれ進めることができます。
:::

## 自己啓発等休業は資格勉強全般の休暇ではない

国の自己啓発等休業法第2条は、対象となる職員と、大学等における修学・国際貢献活動を定義しています。任意の資格試験の独学や、あらゆる民間講座の受講を対象にする制度ではありません。

同法第3条は、職員としての在職期間2年以上、公務の運営への支障、勤務成績や修学等の内容を踏まえた承認を定めています。大学等での修学は原則2年、一定の場合3年の範囲などの期間があります。人事院のQ&Aでも対象課程や除外される職員、請求手続等を確認できます。

同法第5条による休業中は、身分を保有しますが職務に従事せず、給与は支給されません。学費を公費で支払ってもらう仕組みや、有給の試験休暇と同じではありません。生活の見通しに関わる共済掛金、退職手当等も別に確認します。

地方公務員法第26条の5も、条例による自己啓発等休業の承認、対象、身分、無給等を定めています。任期付き・非常勤等の除外や対象課程、期間は本人に適用される制度で確認します。国の在職要件や期間を全自治体へそのまま一般化しないようにしてください。

本人は、入学・受講を決める前に、学校や課程の名称、在学期間、学ぶ内容、業務能力との関係、希望する休業期間を示して相談します。合格・入学してから休業を申請すれば必ず認められると見込まないことが大切です。

## 横浜市の費用支援例は対象資格の案内から読む

横浜市の職員採用公式サイトは、法令により取得・受講が義務付けられる資格や、知識・技術を人材育成に活用できる資格の取得時に、受験料等を助成すると案内しています。対象資格の例にはITパスポート試験、社会福祉士、技術士、一級建築士、介護職員初任者研修、防災士等があります。

同ページは、受験、合格、申請、助成という流れを示しています。資格名が例示されていることから、同市の全職員があらゆる関連費用を無条件で受け取れると判断することはできません。本人の職種、任用、適用される要綱、対象経費、申請に必要な資料を担当へ確認します。

この案内を他自治体の支援内容として使うこともできません。所属に似た制度がある場合でも、助成対象資格の範囲、年度の予算、申請順序、他の補助との併用はそれぞれ確かめます。

公開ページに記載されていない支給額や返還期間を、他の制度から補って説明しないことが必要です。採用向けの概要と、本人の申請を判断する要綱・承認通知を分けて読みます。

## 申込み前に本人条件と返還等の規定を確認する

所属の支援制度が見つかったら、まず現行の年度と対象者を確認します。常勤・非常勤、任期、職種、在職期間、取得前後の勤務条件等が定められているかを見ます。受講時に対象でも、申請日や支給日に条件を満たす必要があるかは別の確認です。

| 確認する資料 | 見るポイント |
| --- | --- |
| 現行の要綱・募集案内 | 対象者、資格、経費、予算等の条件 |
| 申請書・承認通知 | 事前申請の要否、承認対象、条件 |
| 支払証明・合格証等 | 必要な原本・写し、本人名義、提出期限 |
| 取消・返還の条項 | 不正、重複、未修了、退職等の扱い |
| 変更・辞退の手続 | 延期、受講中止、異動・任用変更時の届出 |

返還については、すべての支援が退職時返還になるとも、資格を取得すれば必ず返還不要とも説明できません。補助、修学資金の貸付、業務研修では根拠と契約が違います。本人に適用される条項と、どの事由でいくら返すかを担当へ尋ねてください。

判断に迷う条項がある場合は、支援を受ける前に説明を求めます。後から届いた請求への対応や個別契約の適法性は、記事で判定せず、担当や必要な専門窓口へ相談します。

## 学習経験と実務経験を別に言葉にする

資格の勉強で学んだ知識、試験に合格したこと、実務でその知識を使った経験は別です。現職での担当業務とどう関係するかを整理すると、次に学ぶ内容や実務上の課題を見つけやすくなります。

転職を検討する場合も、資格名だけで採用や希望の配置が保証されるわけではありません。求人の応募要件、担当する業務、必要な実務経験、資格の登録・更新等を確認します。受講しただけの内容を実務実績として書いたり、内部教材をそのまま応募資料へ持ち出したりしないようにしてください。

支援制度を利用したことを理由に、転職活動を急ぐ必要もありません。今の仕事で知識を深める、異動先の業務に備える、学ぶテーマを絞るなど、本人の目的に合わせて計画できます。

:::insight
資格と進路を考えるときは、合格後にどの業務を担当したいかを具体化することが役立ちます。資格名が求人に載っていても、実務経験や担当範囲の条件は会社によって異なります。私たちは、支援が受けられることを転職の成功と結びつけず、現在の経験と学んだ内容を分けて整理する姿勢を大切にします。所属の制度で時間や費用の見通しを立て、現職で学びを活かして働き続ける判断も尊重します。別の仕事を見る場合も、必要な知識、勤務時間、通学や家庭の予定との両立を確認できます。今は学習制度を調べるだけという段階でも構いません。本人の希望と継続できる負担を起点に、受験や進路の時期を考えてください。
:::

学んだ内容と仕事の条件を比べたい場合は、[公務員経験を活かせる仕事](../?gov=1)を任意の情報収集に利用できます。現職の制度確認を先に進めても構いません。

## よくある質問

### 公務員には資格試験用の特別休暇がありますか

全国一律の資格試験用特別休暇として説明できるものではありません。本人の所属で研修、職専免、年休等のどの制度が使えるかを確認します。費用助成の有無とも別です。

### 自己啓発等休業はどんな資格の勉強にも使えますか

国では大学等課程の履修や国際貢献活動等の対象が定められています。資格の独学や任意講座がすべて対象になるわけではありません。任用・在職要件と学習内容を担当に示して確認してください。

### 費用の助成を受けたら退職時に返す必要がありますか

本人の要綱や契約の条件によります。助成と貸付、業務研修を区別し、取消・返還の事由と手続を確認してください。返還義務の有無を一律には断定できません。
