**応募先を調べる過程で、口コミの記載を目にすることがあります。**

**判断の材料にしてよいのか、迷うところ**です。

この記事では、**読み分け方**と、**自分が書く側になるときの注意**を扱います。

## 先に——自分が書く側の注意

**地方公務員法第34条第1項**です。

> **職員は、職務上知り得た秘密を漏らしてはならない。****その職を退いた後も、また、同様とする。**

**「その職を退いた後も」**と書かれています。

**退職しても、義務は続きます。**

**同条第2項**は、**法令による証人、鑑定人等となる場合**について、**任命権者の許可**を要するとしています。

**つまり、例外は手続きを経たものに限られる**構造です。

**匿名であっても、職務上知り得た秘密にあたる内容を書くことはできません。**

| 内容 | 扱い |
|---|---|
| 職務上知り得た秘密 | **書けません**（退職後も同様） |
| 特定の個人が分かる内容 | 避けてください |
| 進行中の案件 | 避けてください |
| 一般に公表されている事項 | 公表の範囲で |

**判断に迷う内容は、書かないでください。**

**匿名の投稿でも、内容から所属や時期が特定されることがあります。**

## 読む側——何が分かり、何が分からないか

| 分かること | 分からないこと |
|---|---|
| 投稿した人が感じたこと | **書いた人の立場・部署・時期** |
| 具体的な出来事の記述 | それが今も続いているか |
| 複数に共通する記載 | 全体の傾向かどうか |
| 制度の有無の記載 | 実際の運用 |

**右の列が重要**です。

**部署が違えば、同じ会社でも状況が異なります。**

**役所でも、課によって忙しさや進め方が違ったはず**です。

**同じことが、民間でも起きています。**

## 偏りの構造

| 要因 | 内容 |
|---|---|
| 書く動機 | **不満があるときのほうが書かれやすい** |
| 退職者の比率 | 在職者より書きやすい立場です |
| 時期のずれ | 数年前の記載が残ります |
| 部署の偏り | 特定の部署の話に寄ることがあります |
| 件数の少なさ | 規模の小さい会社では数が限られます |

**1行目と3行目**です。

**満足している人は、わざわざ書きません。**

**そして、記載には日付があります。**

**古い記載が上位に出ることがあります。**

**投稿の時期を確認**してください。

## 読み分けの方法

| 区分 | 例 | 扱い |
|---|---|---|
| ① 事実の記載 | 「◯◯の制度がある」「拠点は◯か所」 | **確認できます** |
| ② 出来事の記述 | 「◯◯という対応があった」 | 個別の事例 |
| ③ 評価の記載 | 「働きやすい」「合わなかった」 | 書いた人の感想 |

**①を拾ってください。**

**事実の記載は、求人票や会社の資料と突き合わせられます。**

**合っていれば、記載の信頼性が上がります。**

**合っていなければ、面接で確認する項目になります。**

**③は、そのまま受け取らないでください。**

**「働きやすい」の中身は、人によって違います。**

## 使い方——質問に変える

| 口コミの記載 | 面接での聞き方 |
|---|---|
| 残業が多い | 「繁忙の時期と、その際の対応を伺えますか」 |
| 制度が使いにくい | 「◯◯制度の取得の実績を伺えますか」 |
| 部署によって違う | 「配属予定の部署の体制を伺えますか」 |
| 離職が多い | 「この職種の在籍の年数の傾向を伺えますか」 |

**記載をそのままぶつけないでください。**

**「口コミで見たのですが」と切り出すと、確認ではなく指摘になります。**

**確認したい事項だけを、自分の言葉で聞いてください。**

:::insight
口コミについて、**面談でお伝えしているのが「見た後に、何を確認するかを決めてください」**という点です。多くの方が、**読んで不安になったところで止まってしまいます。**ところが、**不安の中身を言葉にすると、たいてい確認できる事項に変わります。**「残業が多いらしい」→**繁忙の時期はいつか、その際の勤務時間はどうか。**「人が定着しないらしい」→**この職種の在籍の年数はどのくらいか。**この形にすれば、**面接で聞けます。**そして、**聞いたときの答え方も情報になります。**具体的に答えるか、言葉を濁すか。**これは、口コミより確かな材料**です。役所でも、**事業者を判断するときに、書面の記載より説明の仕方で分かることがあったはず**です。同じことです。**読んで止まるのではなく、読んで質問を作ってください。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 行政が相手の会社の場合

| 確認できること | 資料 |
|---|---|
| 担っている事業 | **自治体の公表資料** |
| 指定・受託の期間 | 議会の議案、契約の公表 |
| 事業の評価 | 指定管理者の事業報告書 |
| 選定の理由 | プロポーザルの結果 |

**口コミより、こちらのほうが確かな材料**です。

**役所で扱ってきた種類の資料**でもあります。

**扱いは**[応募前の企業調査で見るべき資料](senko-sagasu-kigyochosa.html)**に整理しています。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 見るときの手順

| 順 | やること |
|---|---|
| 1 | 投稿の時期を確認する |
| 2 | 事実の記載だけを拾う |
| 3 | 求人票・会社の資料と突き合わせる |
| 4 | 合わない点を質問にする |
| 5 | **評価の記載は参考にとどめる** |
| 6 | 時間を区切る |

**6です。**

**読み続けると、判断が偏ります。**

**1社あたり10分から15分**を目安にしてください。

## 在職中の投稿について

| 場面 | 注意 |
|---|---|
| 現職について書く | **守秘義務があります** |
| 前職について書く | 退職後も同様です |
| 応募先について書く | 選考の過程は書かないでください |
| 特定できる記述 | 避けてください |

**3行目です。**

**選考の過程で知った情報**には、**公表されていないものが含まれます。**

**書かないでください。**

**なお、これは口コミサイトに限りません。**

**会員制の交流の場でも同じ**です。

## 突き合わせの例

**事実の記載は、他の資料で確認できます。**

| 口コミの記載 | 突き合わせる先 |
|---|---|
| 「拠点が増えている」 | 会社のウェブサイト、設備の状況 |
| 「◯◯の事業が中心」 | セグメントの情報、発表 |
| 「在宅勤務の制度がある」 | 求人票、採用のページ |
| 「官公庁の案件が多い」 | **自治体の公表資料、事業等のリスク** |
| 「人が増えている」 | 従業員数の推移 |

**4行目です。**

**行政が相手の事業が中心かどうかは、自治体の側の資料で確認できます。**

**指定管理者の指定、入札の結果、契約の公表。**

**口コミの記載が裏づけられれば、その部分は信頼できます。**

**一方、突き合わせて合わない記載があれば、その項目は面接で確認**してください。

**この作業をすると、口コミが「確認の出発点」に変わります。**

**読んで終わりにしないための手順**です。

## よくある失敗

**1. 評価の記載をそのまま受け取る**

**書いた人の感想**です。

**2. 投稿の時期を見ない**

**数年前の記載が残ります。**

**3. 読み続ける**

**時間を区切ってください。**

**4. 記載を面接でそのままぶつける**

**確認ではなく指摘になります。**

**5. 事実の記載を突き合わせない**

**確認できる部分を使ってください。**

**6. 自治体の公表資料を見ない**

**より確かな材料があります。**

**7. 自分が書く側の注意を忘れる**

**退職後も義務は続きます。**

:::insight
ここまで読み方の話をしておいて逆のことを言いますが、**口コミを見ないという選択もあります。**面談で拝見していると、**読んだことで迷いが増え、応募できなくなる方**がいらっしゃいます。**判断の材料が増えたのではなく、不安が増えただけ**という状態です。そもそも、**中途採用で確認すべきことは、求人票と面接でおおむね揃います。**業務の内容、勤務の条件、配属先、募集の背景。**これらは、確認すれば答えが返ってきます。**一方、口コミで得られるのは、**書いた人の立場も時期も分からない情報**です。**確認できない情報で判断しないでください。**ですから、**見るとしても、質問を作るためだけに使う。****作れなければ、見なくて差し支えありません。**そして、**迷ったら、面接で直接聞いてください。**答え方そのものが材料になります。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方公務員法第34条第1項**は、**職務上知り得た秘密を漏らしてはならない**とし、**その職を退いた後も同様**と定めています。**匿名でも、書けない内容があります**
- 読む側では、**書いた人の立場・部署・時期が分からない**点を前提にしてください
- **不満があるときのほうが書かれやすい**という偏りがあります
- **事実の記載を拾い、求人票や会社の資料と突き合わせて**ください
- **評価の記載は、参考にとどめて**ください
- **読んだ後に、質問を作って**ください。記載をそのままぶつけないでください
- **行政が相手の会社は、自治体の公表資料のほうが確かな材料**です

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 悪い記載が多い会社は、応募を避けるべきですか

**記載の数だけで判断しないでください。**投稿の数は、**会社の規模と、在籍した人の数**にも左右されます。**規模が大きいほど、記載の数も増えます。**見るべきは、**同じ内容が複数の時期にわたって繰り返されているかどうか**です。特定の時期に集中している場合、**その時期に何かがあった**という読み方になります。**組織の変更や事業の見直しがあった時期**かもしれません。会社の発表や有価証券報告書の記載と突き合わせると、**背景が分かる**ことがあります。読み方は[有価証券報告書の読み方｜転職者が見るべき箇所](senko-sagasu-yuho.html)に整理しています。**気になる点は、面接で確認**してください。

### 現職の口コミを書いてもよいですか

**職務上知り得た秘密にあたる内容は、書けません。****地方公務員法第34条第1項**は、**在職中も、退職した後も、この義務が続く**と定めています。**匿名であっても同じ**です。また、**内容から所属や時期が特定される**ことがあります。加えて、**特定の個人が分かる記述**は、別の問題を生じさせます。**判断に迷う内容は、書かないでください。**なお、**書かないことで不利益が生じるものではありません。**転職の活動に、口コミの投稿は必要ありません。**読む側として使うにとどめて**ください。

### 選考の過程で知ったことを、書いてもよいですか

**書かないでください。**選考の過程では、**公表されていない情報に触れる**ことがあります。組織の体制、事業の計画、募集の背景、選考の内容。**これらは、公開を前提としたものではありません。**また、**守秘に関する取り決め**を求められる場合があります。その場合は、**取り決めの範囲に従ってください。**取り決めがない場合でも、**公表されていない情報を書くことは避けて**ください。なお、**面接で聞いた内容を、他の応募先の面接で話すこと**も同様です。**選考の過程で得た情報は、自分の判断のために使う**という位置づけにしてください。
