在職中の転職活動は、**制度上、認められています。**

**職業選択の自由**は、憲法第22条第1項に定められています。**転職を検討すること自体に、問題はありません。**

ただし、**在職している以上、守るべき線があります。**

この記事では、**その3つの線**を扱います。連絡の実務は[連絡手段と、職場に知られないための注意](senko-mensetsu-renraku.html)にあります。

## 線を越えた場合の帰結

**まず、守るべき理由を確認します。**

**地方公務員法第29条第1項**です。

> 職員が次の各号のいずれかに該当する場合には、当該職員に対し、**懲戒処分として戒告、減給、停職又は免職の処分をすることができる。**
>
> 一 この法律（中略）又はこれらに基づく条例、地方公共団体の規則若しくは地方公共団体の機関の定める規程に**違反した場合**
>
> 二 **職務上の義務に違反し、又は職務を怠つた場合**

**法令や規程に違反した場合、職務上の義務に違反した場合。**

**転職活動そのものは、これに当たりません。**

**問題になり得るのは、活動の方法**です。勤務時間中に行う、職場の資源を使う、情報を持ち出す。**これらは、別の問題**です。

## 守るべき3つの線

| 線 | 根拠 | 具体 |
|---|---|---|
| ① 勤務時間 | **地方公務員法第35条**（職務に専念する義務） | 勤務時間中に活動しない |
| ② 職場の資源 | 服務、情報セキュリティの方針 | 端末、メール、印刷を使わない |
| ③ 情報の取扱い | **地方公務員法第34条**（守秘義務） | 職務上の情報を持ち出さない |

**3つとも、転職活動に特有の話ではありません。**

**在職中、常に守るべきこと**です。

## ①——勤務時間

**地方公務員法第35条**は、**勤務時間と注意力のすべてを職責の遂行に用いる**ことを求めています。

| ✕ | ○ |
|---|---|
| 勤務時間中に求人を見る | **勤務時間外に見る** |
| 勤務時間中に応募先と連絡 | 昼休みか、勤務時間の後 |
| 勤務時間中に書類を作る | 自宅で作る |
| 勤務時間中に面接を受ける | **休暇を取得する** |

**4つ目について補足します。**

**平日の日中に面接を受ける場合、年次休暇を取得してください。**

**休暇は、理由を問わず取得できるのが原則**です。「私用」で足ります。

**組み方は**[平日日中の面接をどう調整するか](senko-mensetsu-jikan.html)**にあります。**

## ②——職場の資源

| 資源 | 理由 |
|---|---|
| 業務用の端末 | **業務のために貸与されています** |
| 職場のメール | 同上。**記録が残る仕組みがあります** |
| 印刷の設備 | 業務用の消耗品です |
| 業務用の電話 | 同上 |
| 執務室 | 画面越しの面接に使わない |

**5つとも、私的な用途に使うことは、服務の観点で問題になり得ます。**

**加えて、情報セキュリティの方針で、閲覧や通信の記録が管理されている**ことがあります。

**業務用の端末で求人サイトを見ることは、避けてください。**

## ③——情報の取扱い

**地方公務員法第34条第1項**は、**職務上知り得た秘密を漏らしてはならない**とし、**その職を退いた後も同様**としています。

| 場面 | 注意 |
|---|---|
| 職務経歴書 | 個別の案件が特定できる記述をしない |
| 面接 | 内部の検討の経緯を話さない |
| 画面越しの面接 | 背景や画面の共有に、職務の情報が映らないように |
| 資料 | **職務の資料を私物の端末に置かない** |
| 退職後 | **義務は続きます** |

**4つ目が、実務上いちばん起こりやすい**です。

**自宅で書類を作るときに、職場の資料を持ち帰ってはいけません。**

**書けるのは、公表されている数字と、自分が使った方法**です。

:::insight
在職中の活動で、**面談でお伝えしているのは「3つの線を守っていれば、それ以上の心配は要らない」**ということです。面談で伺っていると、**「調べているところを見られたのでは」「同僚に気づかれたのでは」と気にして、活動そのものが止まってしまう方**がいらっしゃいます。ところが、**転職を検討している職員は、どの職場にも一定数います。**珍しいことではありません。そして、**仮に知られたとしても、それ自体が服務上の問題になるわけではありません。**憲法第22条第1項のとおり、**職業選択の自由**があります。心配すべきなのは、**知られることではなく、線を越えること**です。勤務時間中に活動していないか。職場の端末を使っていないか。職務の情報を持ち出していないか。**この3つだけを確認してください。**過度に隠すことに神経を使うより、**線を守るほうがはるかに重要**です。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 職務経歴書を作るときの線

**書類を作る作業で、いちばん線に触れやすい**です。

| ✕ 書かない | ○ 書ける |
|---|---|
| 特定の事業者名、施設名 | 業種と規模 |
| 個人が特定できる事案 | 事案の類型と件数 |
| 未公表の内部の数値 | **公表されている統計や決算の数字** |
| 内部の検討の経緯 | 自分が使った方法と、決めた範囲 |

**判断の目安は、「どこで」ではなく「どうやって」で書くこと**です。

**方法と、自分の判断の範囲**は、守秘の対象ではありません。

## 副業・兼業との違い

**転職活動と、副業や兼業は別の話**です。

**地方公務員法第38条第1項**は、**任命権者の許可を受けなければ、営利企業の役員を兼ねたり、報酬を得て事業や事務に従事したりしてはならない**としています。

| 行為 | 扱い |
|---|---|
| 求人を見る、応募する | **許可は不要** |
| 面接を受ける | 許可は不要 |
| 内定を受諾する | 許可は不要 |
| **退職日の前に就業する** | **許可が必要な場合があります** |
| 報酬を受け取る | 同上 |

**4つ目と5つ目に注意してください。**

**入社日を退職日の翌日以降にしていれば、この問題は生じません。**

**研修や説明会への参加を、退職日の前に求められた場合**は、**報酬の有無と、所属の規程を確認**してください。

**判断に迷う場合は、人事の担当に相談**するか、**応募先に時期の調整を相談**してください。

## 応募先に伝えてよいこと

| 内容 | 可否 |
|---|---|
| 担当してきた業務の内容 | **可**（一般的な範囲で） |
| 制度の仕組み | **可**（公表されている範囲） |
| 扱った件数の概数 | 可 |
| 個別の案件の詳細 | **不可** |
| 内部の方針や検討の経緯 | **不可** |

**面接で詳しく聞かれた場合も、この線は変わりません。**

**「その件は、職務上の守秘に関わりますので、一般的な範囲でお答えします」**と述べて差し支えありません。

**この線を守れること自体が、評価の対象**になります。

[経験の言い換えから相談する](../apply.html)こともできます。

**なお、入社前の課題や事前学習を求められることがあります。**報酬を伴わない自習であれば、通常は問題になりませんが、**勤務時間中に行わないでください。**

## よくある失敗

**1. 勤務時間中に応募先と連絡する**

**職務に専念する義務**があります。

**2. 職場の端末で求人を見る**

**記録が残る仕組み**があります。

**3. 職務の資料を自宅に持ち帰る**

**守秘の義務**に関わります。

**4. 画面越しの面接を職場から受ける**

**背景と音声**で線を越える可能性があります。

**5. 個別の案件を面接で話す**

**一般的な範囲**にとどめてください。

**6. 知られることを過度に心配する**

**線を守るほうが重要**です。

:::insight
ここまで線の話をしておいて逆のことを言いますが、**この線は、転職活動のためだけのものではありません。**勤務時間中に私的なことをしない、職場の資源を私的に使わない、職務の情報を持ち出さない。**3つとも、在職中は常に求められていること**です。つまり、**転職活動だからといって、新しく何かを守る必要はありません。**普段どおりにしていれば足ります。そして、**この3つを守っていた事実は、次の職場でも意味を持ちます。**とくに、**自治体を顧客とする会社や、個人情報を扱う事業をしている会社**では、**情報の扱いに慣れている人**が求められます。**在職中の活動で線を守れた人は、入社後も守れる**と受け取られます。面接で「守秘の扱い」について聞かれたときに、**自分の実践として答えられる**ことにもなります。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方公務員法第29条第1項**は、**法令等への違反**や**職務上の義務違反**を懲戒の事由としています。**転職活動そのものは、これに当たりません**
- 守るべき線は、**①勤務時間 ②職場の資源 ③情報の取扱い**の3つです
- **平日の面接は、年次休暇を取得**してください。理由は「私用」で足ります
- **業務用の端末、メール、印刷の設備は使わない**でください
- **職務の資料を私物の端末に置かない。**書けるのは、公表されている数字と自分が使った方法です
- **知られることを過度に心配するより、線を守るほうが重要**です

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 昼休みに応募先と連絡するのは問題ありますか

**休憩の時間であれば、私的な用事に使えるのが原則**です。ただし、**場所には注意してください。**執務室での通話は、**周囲に内容が聞こえます。**外に出るか、人のいない場所を選んでください。また、**業務用の電話や端末は使わないでください。**私物の端末を使う場合も、**職場の通信の設備に接続しない**ようにしてください。なお、**昼休みに来る連絡に出られないことは、応募先に伝えておけば調整されます。**「平日の日中は出られないことがあります」と先に伝えてください。

### 上司に活動を知られた場合、どうなりますか

**それ自体が服務上の問題になるわけではありません。**職業選択の自由があり、**転職の検討は職員の権利の範囲内**です。ただし、**業務への影響を心配されることはあります。**その場合、**業務は通常どおり担っていることを示す**のがいちばんの答えです。なお、**知られた時点で、意思が固まっているなら、改めて正式に伝える**ほうが整理がつきます。中途半端な状態が続くと、**周囲も扱いに困ります。**伝え方は[退職を切り出すタイミングと相手](senko-taishoku-kirisashi.html)にあります。

### 応募先から、現在の業務について詳しく聞かれました

**一般的な範囲で答えてください。**業務の内容、担当してきた機能、扱った件数の概数。**これらは答えられます。**一方、**個別の案件の内容、内部の検討の経緯、未公表の数値は答えられません。**聞かれた場合は、**「職務上の守秘に関わるため、一般的な範囲でお答えします」**と述べれば足ります。**この対応で、選考が不利になることはありません。**むしろ、**線を守れる人として受け取られます。**なお、**しつこく個別の情報を求められる場合は、応募先の姿勢として気に留めておいてください。**
