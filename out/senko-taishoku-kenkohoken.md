退職すると、**共済組合の資格を失います。**

**次の勤務先に空白なく入る場合、その勤務先の健康保険に加入する**のが通常です。

**空白が生じる場合は、自分で選んで手続きする必要があります。**

この記事では、**選択肢と比較の手順**を扱います。

**⚠ 制度の詳細と保険料は、共済組合や市区町村によって異なります。****この記事は一般的な整理にとどめます。必ず窓口で確認してください。**

## 住所があれば、被保険者になります

**まず、国民健康保険の仕組みを確認します。**

**国民健康保険法第5条**です。

> **都道府県の区域内に住所を有する者**は、当該都道府県が当該都道府県内の市町村とともに行う国民健康保険の**被保険者とする。**

**住所を有する者は、被保険者**です。

**ただし、同法第6条**により、**他の医療保険の被保険者や被扶養者である場合などは、適用除外**とされています。

**つまり、他の保険に入っていなければ、国民健康保険の被保険者になる**という構造です。

**「どこにも入らない」という状態は、制度上は想定されていません。**

## 3つの選択肢

| 選択肢 | 概要 | 手続きの先 |
|---|---|---|
| ① 共済組合の任意継続 | 一定の期間、継続して加入できる制度 | **共済組合** |
| ② 国民健康保険 | 市町村と都道府県が運営 | **市区町村の窓口** |
| ③ 家族の被扶養者になる | 要件を満たす場合 | 家族の勤務先 |

**空白なく次の勤務先に入る場合は、④として「次の勤務先の健康保険」**があります。

**この場合、入社の手続きで処理されます。**

## ①——任意継続

| 項目 | 一般的な内容 |
|---|---|
| 制度 | 共済組合に継続して加入する仕組み |
| 期間 | **一定の期間に限られます**（共済組合による） |
| 申出の期限 | **退職後、短い期間内**に申し出る必要があります |
| 保険料 | **全額が自己負担**になるのが通常 |
| 扶養 | 家族を扶養に入れられる場合があります |

**3つ目に注意してください。**

**申出の期限を過ぎると、選択できなくなることがあります。**

**退職の前に、期限と手続きの方法を確認してください。**

**4つ目について補足します。**在職中は、**保険料の一部を所属が負担している**のが通常です。

**任意継続では、その負担がなくなるため、金額が変わります。**

## ②——国民健康保険

| 項目 | 一般的な内容 |
|---|---|
| 加入 | 住所のある市区町村で手続き |
| 期限 | **退職後すみやかに**（14日以内とされることがあります） |
| 保険料 | **前年の所得**などにもとづいて算定されるのが通常 |
| 扶養の考え方 | **世帯単位**で算定される仕組み |

**3つ目が、①との大きな違い**です。

**前年の所得にもとづくため、在職中の所得が反映されます。**

**退職して収入が減っていても、保険料は前年の水準で算定される**ことがあります。

## ③——家族の被扶養者

| 項目 | 内容 |
|---|---|
| 要件 | 家族の勤務先の健康保険の基準による |
| 収入の基準 | 定められた範囲内であること |
| 手続き | **家族の勤務先を通じて** |
| 保険料 | 被扶養者としての保険料の負担がない仕組み |

**要件を満たす場合、負担がいちばん小さい選択肢**になることがあります。

**ただし、収入の基準があります。**

**退職手当の扱いを含めて、家族の勤務先に確認してください。**

:::insight
選択で、**面談でお伝えしているのは「金額を両方から取り寄せてから決めてください」**という点です。**任意継続の保険料は共済組合、国民健康保険の保険料は市区町村**が算定します。**どちらが有利かは、前年の所得、扶養の人数、市区町村の算定の方法によって変わります。**一般論では決まりません。手順としては、**①共済組合に任意継続の保険料を問い合わせる ②市区町村に国民健康保険の保険料を試算してもらう ③比較する**という順です。**②の試算には、前年の所得が分かる資料が必要**になることがあります。**源泉徴収票や課税証明を用意してください。**そして、**この作業には時間がかかります。**窓口の対応時間は平日の日中です。在職中は、**休暇を取るか、電話で確認する**ことになります。**退職の1か月前には着手してください。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 比較の手順

| 順 | やること |
|---|---|
| 1 | **共済組合**に、任意継続の保険料と期限を確認 |
| 2 | **市区町村**に、国民健康保険の保険料を試算してもらう |
| 3 | 家族の被扶養者になれるかを確認（該当する場合） |
| 4 | 金額と要件を比較して決める |
| 5 | 期限内に手続き |

**1と2は、同時に進められます。**

**必要な資料（源泉徴収票、課税証明など）を先に確認してください。**

## 空白が短い場合

**退職日と入社日の間が数日の場合も、手続きが必要になることがあります。**

| 状況 | 一般的な扱い |
|---|---|
| 空白なし（翌日入社） | 次の勤務先で加入 |
| 数日の空白 | **その期間の扱いを確認**（国民健康保険など） |
| 1か月以上 | ①〜③から選択 |

**2つ目の扱いは、市区町村と次の勤務先に確認してください。**

**短い期間でも、制度上は加入が必要とされることがあります。**

## 保険料以外に見る点

**金額だけで決められない場合もあります。**

| 観点 | 内容 |
|---|---|
| 期間の制限 | 任意継続は**一定の期間**に限られます |
| 途中での切替え | 任意継続から国民健康保険への変更の可否 |
| 付加的な給付 | 共済組合が独自に行う給付の有無 |
| 健診の扱い | 加入する保険によって、受けられる健診が変わることがあります |
| 家族の扱い | 扶養に入れられるか、世帯単位か |

**1つ目に注意してください。**

**任意継続は、期限が来ると終わります。**その時点で、**国民健康保険などへの切替えが必要**になります。

**転職までの期間が長くなる見込みがある場合、この点を考えてください。**

**3つ目と4つ目は、共済組合によって異なります。**加入している共済組合に確認してください。

## 手続きを忘れた場合

| 状況 | 一般的な扱い |
|---|---|
| 国民健康保険の手続きが遅れた | **さかのぼって加入**となり、保険料も遡って生じるのが通常 |
| その間に受診した | 全額を支払い、後から請求する形になることがあります |
| 任意継続の期限を過ぎた | **選択できなくなる**ことがあります |

**1つ目について補足します。**

**手続きが遅れても、加入していなかったことにはなりません。**

**資格は退職日の翌日から生じており、保険料もその時点から計算される**のが通常です。

**遅らせても負担は減りません。**期限内に手続きしてください。

## 手続きに必要なもの

**一般的な項目**です。**市区町村や共済組合によって異なります。**

| 手続き | 必要になることがあるもの |
|---|---|
| 国民健康保険の加入 | 資格喪失に関する証明、本人確認の書類、マイナンバーが分かるもの |
| 任意継続の申出 | 共済組合が定める申出の書類 |
| 被扶養者の認定 | 収入に関する証明、続柄が分かる書類 |

**1つ目の「資格喪失に関する証明」は、共済組合または所属から交付されます。**

**受け取る時期を、退職の手続きのときに確認してください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## よくある失敗

**1. 任意継続の期限を過ぎる**

**選択できなくなる**ことがあります。

**2. 片方の金額だけで決める**

**両方から取り寄せて**比較してください。

**3. 前年の所得の影響を見込まない**

**国民健康保険は前年の所得にもとづく**のが通常です。

**4. 短い空白でも手続きが要ることを知らない**

**数日でも確認**してください。

**5. 資格喪失の証明の受け取りを確認しない**

**加入の手続きに必要**になることがあります。

**6. 一般的な説明だけで判断する**

**個別性が高い**ため、窓口で確認してください。

:::insight
ここまで比較の話をしておいて逆のことを言いますが、**空白を作らなければ、この検討は不要になります。**退職日の翌日に入社すれば、**次の勤務先の健康保険に加入する手続きだけ**で済みます。面談でお伝えしているのは、**「手続きを減らしたいなら、空白を作らない」**という点です。3月31日退職、4月1日入社。**この形であれば、健康保険も年金も、次の勤務先で処理されます。**一方、**療養や、転居の準備で期間が必要な場合**は、空白が生じます。その場合は、**比較して選ぶことになります。**どちらが良いかは、事情によります。**ただ、「なんとなく空けた」結果として手続きが増えるのは避けたいところ**です。**空白を作るかどうかは、意図して決めてください。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **国民健康保険法第5条**は、**住所を有する者**を被保険者としています。**第6条により、他の医療保険に加入している場合は適用除外**です
- 選択肢は、**①任意継続 ②国民健康保険 ③家族の被扶養者**。空白がなければ**次の勤務先の健康保険**です
- **任意継続には申出の期限**があります。退職の前に確認してください
- **国民健康保険の保険料は、前年の所得にもとづく**のが通常です
- **両方の金額を取り寄せてから比較**してください。一般論では決まりません
- **空白を作らなければ、この検討は不要**になります

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 在職中に、任意継続の保険料を聞けますか

**聞けます。**共済組合に、**「退職した場合の任意継続の保険料を知りたい」**と問い合わせれば、**一般的な説明と、試算が得られる**ことがあります。**退職を決めたことを伝える必要はありません。**制度の照会として聞けば足ります。なお、**共済組合への問い合わせが、所属の庶務を経由する場合**があります。**経由の方法を先に確認**してください。直接問い合わせられる場合は、そのほうが確実です。**在職中の早い段階で確認しておく**と、判断が楽になります。

### 扶養している家族がいます

**扶養の扱いは、選択肢によって異なります。**任意継続では、**家族を扶養に入れられる場合**があります。国民健康保険では、**世帯単位で算定される仕組み**のため、考え方が違います。**家族の人数によって、有利な選択肢が変わる**ことがあります。比較するときは、**世帯全体の負担**で見てください。なお、**配偶者が勤務先の健康保険に加入している場合、そちらの被扶養者になれるか**も確認してください。**要件を満たせば、負担がいちばん小さくなる**ことがあります。

### 退職後に病院にかかる予定があります

**保険の切れ目を作らないでください。**手続きが完了する前に受診すると、**いったん全額を支払い、後から請求する**形になることがあります。**任意継続も国民健康保険も、資格は退職日の翌日から生じる**のが通常ですが、**保険証が手元に届くまでに時間がかかります。**その間の受診については、**窓口で相談**してください。**資格があることを証明する書類**を発行してもらえる場合があります。**受診の予定がある場合は、手続きを最優先**にしてください。
