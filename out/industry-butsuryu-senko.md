物流の選考について、**公務員の方が戸惑う点**があります。

**「応募したら、その日のうちに面接の日程が来ました」**

**「資格が無いと応募できないと言われました」**

**どちらも、この業界では起こること**です。**そして、どちらにも理由があります。**

**選考が速いのは、人が足りていないから**です。**資格が要る職種があるのは、法令で選任が義務づけられているから**です。

この記事では、**選考の流れと、面接で見られている観点**を扱います。業界の構造は[未経験から物流に入るには](industry-butsuryu-mikeiken.html)、志望動機の組み立ては[物流の志望動機](industry-butsuryu-shiboudoki.html)にあります。

## 運行管理者は、選任しなければなりません

**「資格が要る」と言われる職種の、根拠になる条文**です。

**貨物自動車運送事業法第16条第1項**です。

> **一般貨物自動車運送事業者は、第三条の許可を受けた後、速やかに、事業用自動車の運行の安全の確保に関する業務を行わせるため、国土交通省令で定めるところにより、運行管理者資格者証の交付を受けている者のうちから、運行管理者を選任しなければならない。**

**「選任しなければならない」**です。**そして、選任できるのは「運行管理者資格者証の交付を受けている者」に限られます。**

**同条第3項**は、**選任したときに、遅滞なくその氏名を国土交通大臣に届け出る**ことを求めています。

そして、**同法第17条第1項**です。

> **国土交通大臣は、次の各号のいずれかに該当する者に対し、運行管理者資格者証を交付する。**
>
> 一　**運行管理者試験に合格した者**
>
> 二　事業用自動車の運行の安全の確保に関する業務について**国土交通省令で定める一定の実務の経験その他の要件を備える者**

**資格者証の取り方が、2つ書かれています。**

**⚠ 試験の内容、実務の経験の要件、実施の時期については、所管する国土交通省や試験を実施する機関の公表を確認してください。**当社が確認していない内容は、この記事には載せていません。

## これが、採用にどう効くか

**この仕組みから、2つのことが起こります。**

| 起こること | 理由 |
|---|---|
| **有資格者の求人は、急ぎで出る** | 選任が義務なので、欠員が出ると困る |
| **無資格でも「補助」で募集が出る** | **第17条第1項第2号の実務経験の道があるため** |

**2つ目を見落とさないでください。**

**資格が無い状態で、運行管理の補助の立場から入る道**があります。**求人票の職種名が「運行管理補助」「運行管理アシスタント」になっていることがあります。**

**⚠ ただし、資格者証の交付の要件を満たせるかどうかは、個別の事情によります。**この記事では判断できません。**応募先と、所管の公表で確認してください。**

**そして、管理部門の他の職種——総務・人事・経理・安全——には、この資格は関係ありません。**

## 選考の流れは、職種で分かれます

| 職種 | 流れの型 | 回数の目安 |
|---|---|---|
| 運行管理・運行管理補助 | 書類 → 拠点の責任者 → 役員 | **1〜2回。速い** |
| 倉庫の運営管理 | 書類 → 拠点の責任者 → **現場の確認** | 2回前後 |
| 安全・コンプライアンス | 書類 → 部門長 → 役員 | 2〜3回 |
| 総務・人事 | 書類 → 人事 → 役員 | 2〜3回 |
| 経理 | 書類 → 部門長 → 役員 | 2〜3回 |
| 荷主側の物流部門 | 書類 → 部門長 → 役員 | **3回前後** |

**上の2つは、選考が速い**です。**応募から内定まで2週間ということも珍しくありません。**

**これは、応募する側にとって利点でもあり、注意点でもあります。**

**利点は、決まる人と直接話せること。**注意点は、**条件の確認が追いつかないまま進みやすいこと**です。

**⚠ 速く進むときほど、確認する項目を先に決めておいてください。**

**荷主側の物流部門は、選考が長め**です。**荷主企業の採用の手順に乗る**ためです。

**役所の採用試験と違う点は、筆記試験が無いか軽いこと**です。**書類と面接で判断されます。**

## 拠点の見学は、申し出て構いません

**選考の途中で、拠点の見学が入ることがあります。**入らない場合も、**こちらから申し出て構いません。**

**理由は2つ**あります。

**1つは、通勤の確認**です。[物流の年収と働き方](industry-butsuryu-nenshu.html)で触れたとおり、**物流の拠点は公共交通機関からたどり着きにくい場所**にあることが多く、**実際に行ってみないと分かりません。**

**もう1つは、現場の状態の確認**です。

| 見る点 | 分かること |
|---|---|
| 通路と荷物の置き方 | **整理の状態が保たれているか** |
| 掲示物が更新されているか | 記録と周知が回っているか |
| 点呼の場所と様子 | **手順が形だけになっていないか** |
| 保護具の着用 | 安全の管理の実態 |
| 働いている方の年齢層 | 人員の構成 |

**役所で立入検査をしてきた方なら、見慣れた観点**のはずです。**その目で、遠慮なく見てください。**

**整っていない拠点に入るなら、最初の仕事はそこを整えることになります。**それを承知で入るのと、知らずに入るのとでは、心構えが違います。

## 面接で見られている観点は、5つです

| 観点 | 具体的に確かめられること |
|---|---|
| ① 記録の管理 | **規程にもとづいて記録を残せるか** |
| ② 現場との距離の取り方 | **指導する目線で来ないか** |
| ③ 突発への対応 | 計画が崩れたときに何を優先するか |
| ④ 勤務の前提 | **早朝・夜間・通勤の手段** |
| ⑤ 定着の見込み | **すぐ辞めないか** |

**①が、公務員の強い持ち札**です。

**答え方は、具体的に。**「超過勤務の命令と実績の管理を、係◯人分について月次で処理していました。記録の様式を整理して、確認の漏れが出ないようにしました」。

**②は、この業界で最も警戒される点**です。[物流の志望動機](industry-butsuryu-shiboudoki.html)でも触れましたが、**「法令にもとづいて適切に指導します」という答え方は、評価を落とします。**

**「まず、点呼や作業に立ち会わせてください」**が、この業界で評価される答え方です。

**⑤は、この業界では特に見られます。**人の入れ替わりが課題になっている会社が多く、**「なぜ公務員を辞めてまで、うちに来るのか」**を確かめられます。

**答え方は、[物流の志望動機](industry-butsuryu-shiboudoki.html)の③の型を使ってください。**

:::insight
選考に同席させていただいていて、**この業界で公務員の方が損をする場面**があります。**選考が速く進むので、条件の確認が後回しになる**ことです。面接が1回で終わり、その場で「いつから来られますか」と聞かれる。**勢いで答えてしまい、あとで勤務の時間帯や拠点の場所が想定と違うと分かる。**これが、実際に起こります。対処は単純で、**応募する前に、確認する項目を紙に3つ書いておくこと**です。勤務の時間帯、拠点の所在地と通勤の手段、給与の体系が現場と管理で違うかどうか。**この3つを聞くまでは、入社の時期を答えない**と決めておいてください。そして、**この確認をすること自体が、選考の材料になります。**条件を確認せずに「やる気があります」とだけ言う応募者と、**確認したうえで意思を示す応募者**では、後者のほうが**入ったあとに続く**と判断されます。会社の側も、**早期に辞められるのがいちばん困ります。**ですから、確認は歓迎されます。⚠ **速い選考は、判断の材料が少ないまま決めさせる仕組みではありません。**速いぶん、**こちらが確認の時間を取ってください。**
:::

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 場面 | 効く理由 |
|---|---|
| 記録・規程についての質問 | **要綱にもとづいて処理してきた** |
| 勤務時間の管理の経験 | **運行管理の中核と重なる** |
| 監査・検査への対応 | 検査する側にいた |
| 契約・委託の管理 | 条件を読んで詰める動作が同じ |
| 前提条件の確認 | 確認する習慣がある |

**効きにくい場所**

| 場面 | 効きにくい理由 |
|---|---|
| 成果を数字で語る | **役所では個人の成果として記録されない** |
| 自己紹介を短く話す | 説明が経緯から始まりがち |
| 現場の作業についての質問 | 経験が無い |
| 即断を求められる場面 | **前例を確認してから答える習慣** |

**2つ目は、事前の練習で直ります。****結論から先に言ってください。**

**4つ目について。**この業界の面接では、**「いつから来られますか」「この条件で大丈夫ですか」**と、その場で判断を求められることがあります。**即答する必要はありません。****「持ち帰って確認させてください」で構いません。**

## 準備の手順

| 順 | やること | 目安 |
|---|---|---|
| 1 | **記録・規程・労務**の経験を書き出す | 1時間 |
| 2 | **「変えた話」を3つ**書き出す | 1時間 |
| 3 | 応募先の**拠点の所在地**を地図で確認する | 30分 |
| 4 | **通勤の手段**を具体的に検討する | 30分 |
| 5 | **確認する項目を3つ**決める | 20分 |
| 6 | 結論から話す練習を、**声に出して**行う | 30分 |

**5つ目を必ずやってください。**選考が速いので、**その場で思い出すのでは間に合いません。**

## 内定から入社まで

**労働基準法第15条第1項**により、**労働契約の締結に際して、賃金・労働時間その他の労働条件の明示**が求められます。**書面で条件を確認してください。**

**⚠ 選考が速い会社ほど、書面の交付が後回しになることがあります。**口頭で聞いた条件と、書面の内容が一致しているかを確認してください。

**食い違いがあれば、その場で確認して構いません。**「面接では◯◯と伺いましたが、書面では△△となっています」。**確認は、当然の行為です。**

:::insight
ここまで対策の話をしてきましたが、**この業界を見るときの当社の見解**を申し上げます。**選考が速いことを、良い兆候とも悪い兆候とも決めつけないでください。**速い理由は、**人が足りていること**が大半です。これは事実であって、**その会社の質を直接には示しません。**見るべきなのは、**速いなかでも、こちらの質問に具体的に答えるかどうか**です。勤務の時間帯を実例で答えてくれるか、前任者の離職の経緯を説明してくれるか、書面をきちんと出してくれるか。**この3つが揃う会社は、速くても信頼できます。**逆に、**「入ってみないと分からない」「まずは来てください」で押し切ろうとする会社**は、**入ったあとの進め方も同じ**である可能性があります。そして、**合わないと判断して辞退することは、失礼ではありません。**確かめた結果、**いまの職に残るという結論**も、同じ資格で成り立ちます。**急いで決めさせようとする空気に、合わせる必要はありません。**当社が、いまの職を辞めることをお勧めすることはありません。
:::

## まとめ

- **選考が速いのは、人が足りていることが大半**です。**会社の質を直接には示しません**
- **貨物自動車運送事業法第16条第1項**は、**運行管理者資格者証の交付を受けている者のうちから、運行管理者を選任しなければならない**と定めています。**選任した氏名は国土交通大臣に届け出ます**
- **同法第17条第1項**は、資格者証の交付を、**運行管理者試験に合格した者**と、**国土交通省令で定める一定の実務の経験その他の要件を備える者**に対して行うと定めています
- ⚠ **試験や実務経験の要件は、所管と実施機関の公表を確認してください**
- **資格が無くても、補助の立場から入る募集があります。****総務・人事・経理・安全の職種には、この資格は関係ありません**
- **拠点の見学は、申し出て構いません。****通勤の確認**と**現場の状態の確認**の2つの意味があります
- 見られている観点は、**①記録の管理 ②現場との距離の取り方 ③突発への対応 ④勤務の前提 ⑤定着の見込み**の5つです
- ⚠ **応募する前に、確認する項目を3つ決めておいてください。**選考が速いので、**その場では間に合いません**
- ⚠ **口頭の条件と書面の内容が一致しているか**を確認してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 在職中です。選考の速さに、こちらが追いつけるでしょうか

**追いつけます。**そして、**追いつけない速さで進めようとする会社は、見送って構いません。**伝え方は、**「現職の引き継ぎに◯か月必要です」**と、**最初の面接で先に言っておくこと**です。これを言っておくと、**会社の側も入社の時期を前提に組めます。**なお、**選考の日程の調整**は、**一次面接をオンラインで行い、拠点の見学を土日に設定する**といった対応をしてもらえることがあります。ただし、**稼働していない日に見ても実際の環境は分かりません。**可能であれば、**平日に半日の休暇を取って行く**ほうが、見る価値があります。**急かされていると感じたら、そのことをそのまま伝えて構いません。**

### 運行管理者の資格は、入る前に取るべきですか

**この記事では判断できません。**資格者証の交付の要件は**貨物自動車運送事業法第17条第1項**に定められていますが、**試験の実施時期、受験の要件、実務経験の扱い**は、**所管する国土交通省や試験を実施する機関の公表を確認してください。**当社が確認していない内容をお伝えすることはできません。一般論として申し上げられるのは、**資格が無い状態で補助の立場から入る募集がある**ということだけです。**学習を始めていること自体は、関心の本気度として伝わります。**面接で「学習を始めています」と言えるだけでも、**無関心な応募者とは区別されます。**なお、**総務・人事・経理・安全の職種**では、この資格は求められません。

### 現場の作業を経験しないと、管理はできないと言われました

**会社によって考え方が違います。**「まず現場を経験してもらう」という方針の会社もあれば、**「管理の経験がある人を管理の職として採る」**という会社もあります。**どちらが正しいという話ではありません。**確認のしかたは、面接で**「入社後、現場の作業を経験する期間はありますか」**と聞くことです。期間が決まっているなら、**その後にどの職に就くのか**もあわせて確認してください。⚠ **「いずれ管理に」という口約束だけで入るのは避けてください。**期間と、その後の職について、**書面か、少なくとも具体的な説明**をもらってください。なお、**一定期間現場を見ること自体は、管理の仕事に確実に効きます。**
