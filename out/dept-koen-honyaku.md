公園緑地課の経験を、職務経歴書にどう書けばよいか。ここでつまずく方が多いのは、**仕事の名前が、そのまま民間にない**からです。

「公園の管理」と書くと、**清掃と草刈りの手配をしていた人**に読まれます。実際には、**数十から数百の施設を、台帳で管理し、点検し、修繕の順番を決め、使う人の間の調整をして、事業者に貸し出す条件を作っていた**わけですが、それが伝わりません。

この記事では、**民間での訳語**と、**中核スキルの分解**を並べます。

## 公園は、公告することで生まれます

まず、この仕事の立ち位置を条文で押さえます。**都市公園法第2条の2**です。

> 都市公園は、次条の規定によりその管理をすることとなる者が、当該都市公園の供用を開始するに当たり都市公園の区域その他政令で定める事項を公告することにより設置されるものとする。

**読み飛ばされやすい条文ですが、ここが出発点**です。

**広場があるから公園なのではありません。****区域を定めて、公告した時点で、公園になります。**

つまり、**公園緑地課がやっているのは、「制度上の資産を、生まれた時点から管理し続けること」**です。土地の取得、区域の決定、公告、開園、供用、点検、修繕、更新——**この一連の流れを持っています。**

しかも、**都市公園法第16条は、公園管理者は、みだりに都市公園の区域の全部又は一部について都市公園を廃止してはならないと定めています。**つまり、**手放すこともできない資産**です。

**生まれた時点から、手放せない資産を、使われ続ける状態で維持する。**

**これは、民間でいえば、施設の運営管理そのものです。**

## 民間での訳語

| 行政での言い方 | 民間での言い方 |
|---|---|
| 都市公園の管理 | 施設の運営管理、ファシリティマネジメント |
| 公園台帳の整備 | 資産台帳の管理、設備の台帳の整備 |
| 遊具の点検 | 設備の定期点検、安全点検の運用 |
| 長寿命化計画 | 中長期の修繕計画、更新計画の策定 |
| 指定管理者の選定と監督 | 委託先の選定、業務委託の管理、契約の履行の確認 |
| 占用の許可 | 施設の利用許可、テナントの区画の管理 |
| 公募設置管理制度 | 施設内の収益事業の誘致、事業者の公募 |
| 都市緑地の保全 | 用地の管理、緑地の資産の管理 |
| 街路樹の維持 | 屋外の資産の保全、植栽の管理 |
| 公園の愛護会との調整 | 地域との協働、利用者団体との調整 |
| 苦情と要望の処理 | 利用者からの問い合わせの一次対応 |
| 供用の開始と廃止の手続 | 施設の開設と閉鎖の手続き |

**この表を職務経歴書にそのまま貼る必要はありません。**ただ、**自分がやっていたことに、民間で通じる名前が付いている**ことは、知っておいてください。

## 中核スキルを5つの工程に分ける

**この経歴の中核は、「使われている資産を、止めずに維持する」ことです。**5つの工程に分けます。

**工程1：資産を把握する**

台帳です。**公園の数、面積、施設の数、遊具の基数、樹木の本数。**これがなければ、点検の計画も、予算の要求も作れません。

**この工程に固有の制約があります。**公園の資産は、**移動しません。**そして、**屋外にあります。**建物であれば図面で分かることが、**公園では現地に行かないと分からない。**台帳が現地と合わなくなる速度が速い、という性質があります。

**工程2：状態を測る**

点検です。**遊具、園路、便所、照明、樹木。**種類ごとに、見る周期も、見るべき点も違います。

**この工程に固有の制約があります。**点検の対象に、**生き物が入っている**ことです。樹木は、点検した時点で健全でも、**翌年には変わります。**しかも、倒れれば人に当たる。**状態が変化し続ける資産を、周期で押さえる**——この形は、設備だけを扱う仕事にはない特徴です。

**工程3：順番を決める**

**傷んでいる箇所は、いつも予算より多い。**そこから、**今年直すものを選びます。**利用者の数、危険の度合い、次の更新までの年数を見て決めます。

**この工程に固有の制約があります。**公園は、**地域ごとに使う人が決まっています。**だから、**どの公園を先にしたかが、地域の間の話になります。**設備の保全であれば、危険度の順で決めれば通りますが、**ここでは「なぜうちの公園は後なのか」に答えられる基準が要ります。**

**工程4：使う人の間を調整する**

**公園は、使い方が競合します。**球技をしたい人、静かに過ごしたい人、犬を連れて来る人、イベントで使いたい団体。**全部を同時には満たせません。**

**この工程に固有の制約があります。**利用者は、**契約している相手ではありません。**誰でも入れる場所なので、**出入りの管理ができない。**それでも、**使い方のルールを作って、掲示して、運用する。**この形の運営は、民間でも商業の施設の共用部などに限られます。

**工程5：民間の力を入れる**

指定管理者の選定、公募設置管理制度、占用の許可。**公園の中で、誰かに事業をしてもらう仕組みを作る工程**です。

**この工程に固有の制約があります。**都市公園法第5条の2は、**飲食店、売店などの公募対象公園施設について、設置又は管理を行う者を公募により決定する指針を定めることができる**とし、**使用料の最低額や、事業者に建設させる園路・広場に関する事項まで指針に定める**ことを求めています。つまり、**事業者に何をさせ、いくら取り、周辺に何を作らせるかを、先に設計する側**にいたということです。**これは、テナントの誘致の条件設計と、ほぼ同じ作業**です。

:::insight
この5つの工程のうち、**職務経歴書でいちばん書かれていないのが、工程5**です。面談で伺うと、**「公募の事務をやっていました」**という言い方をされます。ところが、中身を聞くと、**どの区画を貸すか、いくらを最低額にするか、事業者に何を作らせるか、何年で回収させるかを決めていた**という話が出てきます。**これは、事業の条件を設計する仕事**です。民間でいえば、**商業施設の区画の企画、事業者の誘致の条件づくり、収益の設計**に当たります。しかも、**相手は民間の事業者**なので、**採算が合わなければ応募が来ません。****「公告したのに応募が来なかった」という失敗が起こり得る仕事**をしていたわけです。書くなら、**「公募対象公園施設について、募集の区画、使用料の最低額、事業者に建設させる施設の条件を設計し、公募から認定までを担当」**という形です。**この一行があると、施設の運営を扱う会社での読まれ方が、一段変わります。**
:::

## 民間の施設の運営管理と、どこが同じでどこが違うか

**同じ点は3つあります。**

- **台帳を持ち、点検の周期を決め、修繕の順番を決めている**こと
- **限られた予算の中で、優先順位を説明できる形で決めている**こと
- **委託先を選び、仕様を書き、履行を確認している**こと

**違う点は4つあります。**

| 違い | 行政（公園緑地課） | 民間（施設の運営管理） |
|---|---|---|
| 入る人 | 誰でも入れる。出入りの管理ができない | 契約者、来館者。管理ができる |
| 収益 | 基本は無料。収益は付随的 | 収益が前提。稼働率と単価で測る |
| 手放せるか | みだりに廃止できない | 採算が合わなければ閉鎖もある |
| 資産の性質 | 樹木など、状態が変化し続ける資産を含む | 主に設備。経年で劣化するが変化はしない |

**この4つのうち、移った後にいちばん効くのは、2番目**です。**数字で測られる形に変わります。**ただし、**測られる項目が増えるだけで、やることの骨は変わりません。**

**もう一つ、見落とされやすい違いがあります。**3番目の「手放せるか」です。民間の施設は、**採算が合わなければ閉じるという選択肢**を持っています。だから、**運営の議論が「続けるかどうか」から始まる**ことがある。ところが、公園は**都市公園法第16条によって、みだりに廃止できません。**つまり、**この経歴の方は、「続けることが前提の資産を、限られた予算で回す」訓練を、何年も受けてきた**ことになります。**閉じられない施設をどう持たせるか**——これは、**民間でも、基幹の設備や、地域に根を張った拠点で、そのまま問われる論点**です。

## 評価が高くなりやすい4つの方向

**1. 施設の運営管理を受託する会社**

**指定管理者の側**です。**発注する側にいた経験は、そのまま提案の材料になります。**

**2. 造園・緑化の会社**

**発注者が何を見るかを知っている**ことが効きます。仕様書の読み方、検査の視点。

**3. 商業施設・複合施設の運営**

**共用部の運営、テナントの区画の管理、催事の調整。**公園の運営と、構図が重なります。

**4. 自治体を顧客とする企業**

**台帳の整備、点検の支援、長寿命化計画の策定支援。**発注の側の事情が読めることが、そのまま強みになります。

## つまずきやすい点

**1. 「公園の維持管理」で丸める**

**台帳／点検／順番／調整／民間の導入**の5つに分けてください。

**2. 公募や指定管理の経験を、事務として書く**

**事業の条件を設計する仕事**です。**使用料の最低額まで決めていたなら、そう書いてください。**

**3. 遊具の安全の経験を書かない**

**人が怪我をしうる設備を、周期で点検し、記録していた。****安全の管理の経験**として読まれます。

**4. 数字を入れない**

**公園の数、面積、遊具の基数、年間の修繕の件数と金額。**桁だけでも入れてください。

**5. 苦情の対応を、苦労話にする**

**使い方が競合する場所で、ルールを作って運用していた**と書いてください。

:::insight
この経歴の方に、**最初に確かめていただきたい数字が4つ**あります。**管理していた公園の数、合計の面積、遊具などの施設の基数、年間の修繕の件数と金額**です。この4つが並ぶと、**書類の読まれ方が変わります。**「公園の管理」と書かれた1行と、**「街区公園から総合公園まで◯か所、計約◯ヘクタール、遊具約◯基を管理。年間約◯件、約◯万円の修繕を発注」**という1行では、**読む側が想定する規模が違うから**です。面談で伺うと、**「数えたことがなかった」とおっしゃる方が多い**のですが、**台帳にある数字**です。異動すると取りにくくなるので、**在職中に控えておいてください。**そのうえで、**自分が作った基準を1つ**——点検の区分でも、修繕の優先順位の付け方でも——**書き出しておくと、実績欄の芯ができます。**在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 都市公園法第2条の2は、**都市公園は、区域その他の事項を公告することにより設置される**と定めています
- つまり、**公園緑地課は「制度上の資産を、生まれた時点から手放せないまま維持する」仕事**をしています
- 民間での訳語は、**施設の運営管理、資産台帳の管理、委託先の管理、事業者の誘致**です
- 中核スキルは、**①把握する ②測る ③順番を決める ④使う人の間を調整する ⑤民間の力を入れる**の5工程に分けられます
- 民間との違いは、**入る人、収益、手放せるか、資産の性質**の4点です
- 先に、**公園の数・面積・施設の基数・修繕の件数と金額**の4つを控えてください

## よくある質問

### 技術職ではなく、事務で公園を担当していました

**それでも書けます。**公園緑地課の事務は、**台帳の管理、指定管理者の選定と協定、占用の許可、予算の要求と執行、苦情と要望の受付、愛護会との調整**など、**技術以外の部分が広くあります。**とくに、**指定管理者の選定と監督**は、**施設の運営を受託する会社への転職でそのまま効く経験**です。書くなら、**「公園◯か所について、指定管理者の選定、協定の締結、業務の履行の確認を担当。設計と積算は技術職が担当」**と、**自分の範囲を明示してください。**線を引いた応募は、読まれます。

### 街路樹や緑地の担当が中心でした。公園とは違いますか

**違いますが、書き方の骨は同じ**です。**屋外にあって、状態が変化し続ける資産を、周期で管理していた**という点は共通しています。街路樹の場合は、**倒木や枝の落下に関わる点検、剪定の委託、沿道からの要望の処理**が中心になります。**この経験は、造園の会社、インフラの管理を受託する会社、鉄道や電力の沿線・線下の管理でそのまま効きます。**とくに、**「人に当たりうるものを、周期で見て、記録を残していた」**という書き方は、**安全の管理の経験として読まれます。**

### 公募設置管理制度や指定管理の経験がなくても大丈夫ですか

**大丈夫です。**その場合は、**工程1から工程4**で書いてください。**台帳、点検、修繕の順番、利用者の調整。**この4つだけでも、**施設の運営管理の中核**です。むしろ、**現場に近い経験が長い方は、受託の側の会社で即戦力として読まれやすい**傾向があります。**公募や指定管理は、発注の側の設計の経験**なので、**そこを持っている方は、自治体を顧客とする企業やコンサルティングの側**に寄せやすくなる、という違いです。**どちらが有利ということではなく、行き先が変わります。**行き先の分け方は[公園緑地課から転職しやすい業界と職種](dept-koen-tenshokusaki.html)に整理しています。
