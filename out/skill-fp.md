**「取る意味はあるか」**というご相談を伺います。

**評価される場面と、されにくい場面があります。**

この記事では、**その分かれ目**を扱います。

**⚠ 試験の内容・等級・実施の方法は、所管するところの公表を確認してください。****この記事では、個別の内容には触れません。**

## 技能検定の合格者の名称が、法律に定められています

**職業能力開発促進法第50条第1項**です。

> **技能検定に合格した者は、技能士と称することができる。**

**同条第2項**は、**技能士と称するときは、その合格した技能検定に係る職種等を明示する**ことを定めています。

**つまり、国が行う技能検定の枠組みの中にある**ということです。

**⚠ どの職種が技能検定に含まれるかは、所管の公表を確認**してください。

**この点は、民間の団体が実施する資格とは位置づけが異なります。**

**扱いは**[MOS｜取るべき人と、取らなくてよい人](skill-mos.html)**に整理しています。**

## 評価される場面

| 場面 | 理由 |
|---|---|
| ① 応募条件に記載がある | **満たす材料になる** |
| ② 金融・保険の分野 | 業務の内容と重なります |
| ③ 相談の業務 | 相談の型を学べます |
| ④ 分野を変える | 学習していることを示せる |
| ⑤ 体系的に学びたい | 範囲が決まっています |

**②と③が中心**です。

**③について。**

**相談の業務では、相手の状況を聞き取り、選択肢を整理して示す**という動作があります。

**この型を学べる点は、実務に効きます。**

## 評価されにくい場面

| 場面 | 理由 |
|---|---|
| ① 応募条件に記載がない | 判断の中心にならない |
| ② 実務の経験がある | **経験のほうが具体** |
| ③ 分野が離れている | 業務と結び付きません |
| ④ 応募の時期が近い | 書類の作成が優先 |
| ⑤ 目的が曖昧 | 「何か取っておきたい」だけ |

**②が、公務員からの転職では多い**です。

**税、保険、年金、福祉の担当であれば、実務の経験のほうが具体**です。

**制度を運用し、住民に説明してきた経験**が、材料になります。

## 行政の実務との重なり

| 行政での経験 | 重なる部分 |
|---|---|
| ① 税の賦課・相談 | **税に関する制度の説明** |
| ② 保険・年金の事務 | 制度の仕組み |
| ③ 福祉の相談 | 生活の状況の把握 |
| ④ 住宅に関する事務 | 住まいに関する制度 |
| ⑤ 債権の管理 | 支払の相談 |
| ⑥ 住民への説明 | 専門でない相手への説明 |

**⑥が中心**です。

**制度を、専門でない相手に説明してきた経験**は、**相談の業務でそのまま使えます。**

**扱いは**[市区町村職員から民間へ](senko-tachiba-shichoson.html)**に整理しています。**

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 金融・保険 | **顧客への説明、相談** |
| ② 相談の窓口の事業 | 生活に関する相談 |
| ③ 住宅・不動産 | 資金に関する説明 |
| ④ 自治体が相手の事業 | 制度の理解 |
| ⑤ 福祉・介護の事業 | 制度の説明 |

**②と④が、行政の経験と重なります。**

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

:::insight
この資格について、**面談でお伝えしているのが「実務の経験と重ねて書いてください」**という点です。**資格だけを書くと、「関心がある」という程度に読まれます。**ところが、**税や保険、年金の事務を担当してきた方**であれば、**制度を運用し、住民に説明してきた経験**があります。**この経験と重ねると、意味が変わります。**「◯◯税の賦課に関する事務を担当し、年約◯件の照会に対応。制度の内容を、専門でない相手に説明してきた」。**そのうえで資格を併記すると、「実務があり、体系的にも学んでいる人」として読まれます。**逆に、**実務と離れた分野で資格だけを書くと、結び付きが見えません。**ですから、**自分の実務のどこと重なるかを、先に整理してください。**重なりが見つからない場合は、**優先順位を下げて差し支えありません。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 書き方の例

**悪い例**

> 資格を取得しました。

**良い例**

> ◯◯課において、**◯◯に関する制度の事務を担当。**年間約◯件の相談に対応し、**制度の要件と手続を、専門でない相手に分かる言葉で説明。**支払が困難な事案について、**状況を確認のうえ、分割の相談に対応。****（資格の欄）◯年に取得**

**資格の欄と、職務の欄が分かれています。**

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 取る前に考えること

| 確認すること | 内容 |
|---|---|
| ① 応募したい求人の条件 | **記載があるか** |
| ② 実務との重なり | どこと結び付くか |
| ③ 目的 | 学ぶためか、条件を満たすためか |
| ④ 期限 | 応募の時期に間に合うか |
| ⑤ 他の優先順位 | 書類、条件の整理 |

**②を先に確認してください。**

**重なりが見つからない場合、書類での効きが弱くなります。**

**なお、取れば転職できる、という関係にはありません。**

**何を説明し、どう対応したか**が、評価の対象です。

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 実務の整理 | **担当した制度、相談の件数** |
| 重なりの確認 | どの分野と結び付くか |
| 求人を読む | 週に30分 |
| 要件の確認 | 所管の公表を確認 |

**1行目を先にしてください。**

**年度の報告や統計から、件数を確認**できます。

**根拠のない数は書かないでください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 取得の理由 | **1つの理由で短く** |
| 実務との関係 | どこと重なるか |
| 相談への対応 | 難しかった場面 |
| 説明の工夫 | 伝え方 |
| できる範囲 | **正確に、限定して** |

**1行目です。**

**「何となく」では、目的が伝わりません。**

**実務の場面と結び付けて説明**してください。

## 説明の工夫という材料

**住民への説明で工夫してきた点は、そのまま書けます。**

| 工夫 | 内容 |
|---|---|
| ① 言葉の言い換え | **専門用語を避ける** |
| ② 順序 | 結論、理由、手続の順 |
| ③ 資料 | 記入例、図、チェックの表 |
| ④ 確認 | 理解の状況を確かめる |
| ⑤ 記録 | 説明した内容を残す |

**③と④が、相談の業務で効きます。**

**③について。**

**記入例やチェックの表を作った経験**があれば、**作ったもの**として書いてください。

**④について。**

**説明した後に、相手が理解できたかを確かめる**という動作です。

**一方的に説明して終えない**という点は、相談の職務で見られます。

## よくある失敗

**1. 資格だけを書く**

**実務と重ねて**書いてください。

**2. 実務との重なりを確認しない**

**書類での効きが弱くなります。**

**3. 取得の理由を用意しない**

**面接で聞かれます。**

**4. 相談の件数を書かない**

**経験の厚み**が伝わりません。

**5. 説明の工夫を書かない**

**相談の業務**で見られます。

**6. 応募の時期が近いのに受験を優先する**

**書類の作成が先**です。

**7. できる範囲を広く書く**

**入社後に困ります。**

**8. 取れば転職できると考える**

**何を説明し対応したか**が評価の対象です。

:::insight
ここまで「実務と重ねて」という話をしておいて逆のことを言いますが、**自分の生活のために学ぶ、という目的も否定されません。**面談で拝見していると、**転職の材料になるかどうかだけで判断される方**がいらっしゃいます。ところが、**転職を考える時期は、生活の見通しを立てる時期**でもあります。収入が変わる、保険が変わる、住まいを考える。**これらを自分で整理できることには、実際の価値があります。**扱いは[住宅ローンがある状態での転職](senko-taishoku-loan.html)や[配偶者も公務員の場合の考え方](senko-tachiba-haigusha.html)にも触れています。**制度の知識があると、確認すべき先が分かります。**ですから、**「書類に効くか」だけで判断しないでください。**そのうえで、**書類に書くかどうかは、実務との重なりで決める。****目的と、書き方は別に考えて差し支えありません。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **職業能力開発促進法第50条**は、**技能検定に合格した者は技能士と称することができる**とし、**職種等の明示**を求めています
- **どの職種が技能検定に含まれるかは、所管の公表を確認**してください
- 評価されるのは、**応募条件に記載がある、金融・保険の分野、相談の業務、分野を変える、体系的に学びたい**場合です
- 評価されにくいのは、**記載がない、実務の経験がある、分野が離れている**場合です
- **制度を、専門でない相手に説明してきた経験**が中心の材料です
- **資格だけを書かず、実務と重ねて**ください
- **自分の生活のために学ぶという目的も、否定されません**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 税や保険の担当ではありませんでした

**重なりを探してから判断してください。**住民への説明を伴う業務であれば、**説明の経験**として重なります。また、**債権の管理や、支払の相談**に関わっていれば、生活の状況を踏まえた対応の経験になります。**重なりが見つからない場合は、優先順位を下げて差し支えありません。**なお、**分野を変える転職**では、**学習していること自体が材料**になる場面があります。扱いは[ITパスポート｜情報政策課以外でも意味があるか](skill-itpassport.html)に整理した考え方と同じです。**目的を1つに絞ってください。**

### 等級はどこまで目指せばよいですか

**応募したい求人の記載を基準にしてください。**求人票に具体の記載があれば、それが目安です。**記載がない場合、等級を自分で決める必要はありません。**なお、**⚠ 等級の構成や要件は、所管の公表を確認**してください。**この記事では触れません。**また、**上位を目指すかどうかは、目的によります。**相談を職務とするのか、知識として持つのか。**目的が決まると、必要な範囲が決まります。**読み方は[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。

### 相談の仕事に就きたいのですが

**求人票の仕事内容を確認してください。**「相談」と書かれていても、**相手と内容が違います。**個人の生活に関する相談、事業者の相談、制度の案内、苦情の対応。**求められる知識も、勤務の形も変わります。**なお、**行政での相談の経験**は、**相手を選べない状況での対応**として評価されます。書き方は、**「年間約◯件の相談に対応し、制度の要件と手続を説明」**という形です。扱いは[社会福祉士・ケアマネジャー｜福祉職の転職で](skill-fukushi.html)にも整理しています。**相談の相手と内容を、先に確認してください。**
