休憩時間は、勤務時間の途中にある空き時間というだけではありません。長さ、置き方、自由に利用できることを、本人の制度で確認します。昼当番等を指示されている場合は、予定表に「休憩」と書かれていることだけで実際の勤務の扱いまで決めないようにします。

本記事は2026年11月時点の公開情報にもとづきます。国の一般職の規定を中心に、地方・民間との違いを整理します。個別の時間外手当や勤務時間の認定は、実際の指示と記録を基に勤務管理・給与担当へ確認してください。職場の実態を推測して断定するものではありません。

## 国の休憩は勤務時間とは別に置く

国の勤務時間法第5条は、通常の週の勤務時間を休憩時間を除き38時間45分としています。同法第9条は、勤務時間を割り振る場合に規則に基づいて休憩を置くことを定めています。始業から終業までの在庁時間と、休憩を除いた勤務時間は分けて考えます。

人事院規則15-14第7条は、通常の1日7時間45分の勤務の割振りについて60分、各省各庁の長が業務の運営と健康・福祉を考慮して必要と認める場合は45分とする基準等を定めています。それ以外の勤務については30分以上とする規定等があります。

この数字だけで、どの職員も昼の同じ時刻から1時間休むと決めることはできません。同条には休憩を置く位置、特別の勤務形態、申告を考慮する場合などの定めもあります。本人の勤務区分と通知された休憩の開始・終了を確認してください。

| 区分 | 確認すること |
| --- | --- |
| 通常の勤務 | 適用される休憩の長さと時刻 |
| 交替勤務等 | 特別の形態に応じた配置と基準 |
| フレックス | 申告した休憩と実際に割り振られた休憩 |
| 短時間勤務・非常勤 | 本人に適用される勤務と休憩の定め |
| 当番等がある日 | 勤務する時間帯と別の休憩の確保 |

例えば、始業8時30分、終業17時15分、休憩1時間という仮の勤務では、間の8時間45分のうち勤務は7時間45分です。休憩が45分なら始業・終業との対応も別に確認します。この仮の時刻を、全国共通の勤務時間と考えないでください。

## 自由利用と職場の情報管理は分けて考える

規則15-14第7条第6項は、職員が休憩時間を自由に利用できると定めています。単に食事をしてよい時間という意味だけではなく、勤務の時間との区別が必要です。

一方、休憩中なら職場の端末や住民情報を私的に利用してよいという意味ではありません。外出の際の施設管理上の手続、職場の機器・アカウント、守秘等に関する本人の規程は別に確認します。「自由利用」を、すべての服務や情報管理の取扱いがなくなることと混同しないようにします。

私的な連絡や学習を考える場合も、使用する端末や資料、場所の扱いを確かめてください。仕事のために待機や対応が求められる時間と、本人が自由に使う時間が混ざっていないかも確認します。

外出の時刻や戻る時刻を調整したい場合に、本人の判断で休憩を短くして早く退庁することは避けます。休憩の変更、勤務時間の割振り変更、年休の時間申請はそれぞれの手続です。

## 昼当番は実際の指示と対応を記録する

厚生労働省の労働基準法に関するQ&Aでは、昼休みの電話や来客対応は業務であり、勤務時間に含まれると説明しています。労働から離れることが保障されているかが重要で、休憩という名称だけでは判断されません。

国の職員についても、規則上の自由利用と、指示される業務の時間を分けて所属へ確認します。厚労省の民間向けQ&Aだけを根拠に、本人の超過勤務手当の額まで計算することはできません。勤務の割振り、業務命令、休憩の再配置、正規の勤務時間以外の勤務の扱い等を担当に確かめます。

例えば、昼休みに窓口対応をするよう指示されたという仮のケースなら、指示された時間、対応が必要な状態、実際に行った業務、別に休憩を取る案内があったかを整理します。「電話が鳴らなかったから必ず休憩」「少し対応したから昼全体が必ず時間外」という本人の推測だけで処理しないでください。

| 確認用のメモ | 内容 |
| --- | --- |
| 当初の休憩 | 通知された開始・終了時刻 |
| 指示 | 誰から、どの時間帯に、何の対応を求められたか |
| 実際の対応 | 対応した業務と時間、待機の条件 |
| 別の休憩 | いつ、どれだけ確保されたか |
| 勤怠処理 | 勤務と休憩の修正先、必要な申請 |

記録には住民や相談者の個人情報まで私的に書き写す必要はありません。時刻と指示・業務の概要等、確認に必要な範囲で整理し、組織の正式な経路で照会します。

:::insight
休憩の確認では、本人が休めたという感覚と、勤務の区分を一緒にしないことが大切です。食事を取りながら電話を待つ時間は、予定表の名称だけでは整理できません。私たちは、まず通知された休憩、指示された対応、実際に確保された別の休憩を並べ、担当へ確認する方法を勧めます。誰かの職場の例をそのまま本人の処理へ当てはめるより、具体的な日と時間を示すほうが照会しやすくなります。記録を整える目的は、職場への不信を強めたり退職へ向かったりすることではありません。現職で勤務と休養を適切に分け、本人が日々の予定を立てられるようにするための確認として扱いたいところです。
:::

## 休息時間や育児関係の時間は別の制度

国の規則15-14第8条には、特別の形態で勤務する一定の職員についての休息時間の規定があります。この休息時間は正規の勤務時間に含まれ、与えられなくても繰り越されないとされています。勤務時間から除く休憩とは扱いが違います。

すべての職員に一律で15分の休息が追加される、使わなかった休息分をまとめて早退に使える、といった理解は避けます。対象者、置く位置、回数等を本人の勤務区分で確認してください。

育児のための保育時間や育児時間、短時間勤務等も別の制度です。子の世話のために勤務しない時間と、通常の休憩を同じものとして相殺しないようにします。名称が似ていても、承認、対象年齢、給与、取得単位などの確認が必要です。

また、勤務終了後から次の勤務開始までの休養に関する取扱いは、勤務途中に置く休憩とは別の話です。一つの「休む時間」という言葉で、複数の制度の計算を混ぜないことが重要です。

## 地方と民間の一斉休憩の例外を区別する

地方公務員は、地方公務員法第24条第5項に基づく条例等で勤務条件を確認します。労働基準法の適用と読替えもあり、国の規則だけで全自治体の休憩を説明することはできません。

労働基準法第34条は、6時間を超える労働で45分以上、8時間を超える労働で1時間以上の休憩を途中に置く原則、一斉付与、自由利用を定めています。民間で一斉付与をしない場合の労使協定の規定等と、業種等に関する特例の扱いは別に確認します。

地方公務員法第58条第4項には、労基法第34条第2項ただし書の労使協定に関する部分を、条例に特別の定めがある場合へ読み替える規定があります。地方職員に「民間と同じ労使協定を必ず結ぶ」と説明しないようにします。

一斉に取らない制度があっても、休憩をなくしてよいことにはなりません。交替して確保する時間、勤務の割振り、本人へ通知する方法を確認してください。民間へ転職する場合も、就業規則、実際の勤務と当番、休憩の交替方法を尋ねます。

## 勤務・休憩・時間外の記録を照合する

国では勤務時間法第13条に正規の勤務時間以外の勤務に関する規定があります。休憩中に対応した時間をどう扱うかは、勤務の命令と割振り、別の休憩、給与の規定等を照合する必要があります。

本人は勤務管理担当へ「この日は当番を指示され、予定された休憩がこのように変わった」と具体的に伝えます。給与の計算が関係する場合は、勤務記録が修正されるか、給与担当にも確認が必要かを尋ねてください。

実際の記録と表示が違うと感じても、次の日の出退勤を短くして埋め合わせたり、年次休暇で帳尻を合わせたりしないようにします。正式な記録と申請の方法を確認します。担当の説明に疑問が残る場合は、本人に適用される相談窓口や監督機関の担当を所属等へ確かめます。

## 働き方の比較は休憩を含む時間帯で考える

勤務時間だけでなく、始業・終業、休憩の長さ、食事や外出の予定、通勤を並べると、一日の見通しを立てやすくなります。求人票等に8時間と書かれているときも、それが休憩を除いた所定時間か、始業から終業の幅かを確認してください。

フレックスや短時間勤務を比較する場合は、休憩がどこに置かれ、本人が変更を申し出られる範囲があるかも尋ねます。個々の職場での利用実態を、制度があるという事実だけから推測しないことが大切です。

:::insight
休憩の取り方を仕事選びの条件にするなら、制度上の分数と、その日の勤務をどのように組むかを分けて比べたいところです。休憩が長いほど必ず生活に合うとも、短ければ働きやすいとも限りません。私たちは、本人が休養や食事を確保できることを前提に、通勤、家庭の予定、勤務の開始と終了を含めて確認することが大切だと考えます。今の職場で当番や交替の扱いを確かめ、勤務条件を理解して働き続ける判断も尊重します。ほかの仕事を見る場合も、職場の忙しさを想像で評価せず、求人の条件と正式な説明を集め、本人の希望する一日の過ごし方に照らして検討してください。情報収集だけにとどめる選択もできます。
:::

仕事の条件を調べたい場合は、[公務員経験を活かせる仕事](../?gov=1)を任意の情報収集に利用できます。現職での確認を先に進めても構いません。

## よくある質問

### 国の公務員の休憩は全員60分ですか

通常の割振りに関する60分と一定の場合の45分等の規定があり、勤務形態による基準もあります。本人の勤務区分と正式な休憩時間を確認してください。

### 昼当番があっても休憩と記録されていれば勤務ではありませんか

名称だけでは判断できません。指示と実際の対応、別の休憩の有無を整理し、勤務管理担当へ確認します。個別の時間外手当まで、記事だけで判定することはできません。

### 休憩を短くしてその分早く帰れますか

本人が独断で変更するものではありません。勤務の割振りや休憩の変更、年休等の手続を確認します。休息時間や育児関係の時間も別制度として扱います。
