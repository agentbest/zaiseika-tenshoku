**「何社くらい受けるものですか」**というご相談を伺います。

**役所の採用は、1つの試験を受ける形**でした。

**民間の中途採用は、仕組みが違います。**

この記事では、**数の決め方**を扱います。

## 複数に応募することは、制限されていません

**民法第521条**です。

> **何人も、法令に特別の定めがある場合を除き、契約をするかどうかを自由に決定することができる。**
>
> ２ 契約の当事者は、法令の制限内において、**契約の内容を自由に決定することができる。**

**契約をするかどうかを自由に決められる**、という原則です。

**応募は、労働契約を結ぶための過程**にあたります。

**複数に応募すること、選考の途中で辞退すること、内定を断ること。**

**いずれも、原則として制限されていません。**

**「1社に絞るべきではないか」という心配は、ここで解消します。**

**ただし、辞退の連絡は必要**です。原則が自由であることと、**連絡をしないでよいことは別**です。

## 数ではなく、条件で決まります

**「何社」という問いの立て方を変えてください。**

| 問い | 答えの出し方 |
|---|---|
| 何社受けるか | 決まりません |
| **条件に合う求人が何件あるか** | **探せば分かります** |
| 同時に何件進められるか | **在職中の時間で決まります** |

**2行目と3行目**です。

**条件に合う求人の数は、条件の絞り方で決まります。**

**同時に進められる数は、時間で決まります。**

**この2つの掛け算**が、実際の数になります。

## 在職中に同時に進められる数

| 段階 | 必要な時間 |
|---|---|
| 求人を読む | 1件あたり10分から20分 |
| 書類を整える | 1社目に時間がかかります |
| 応募 | 短時間 |
| 面接 | **1回あたり、移動を含めて半日** |
| 条件の確認 | 内定の段階で |

**4行目が制約**です。

**面接は、複数回行われることが一般的**です。

**在職中は、平日の日中に時間を取りにくい**という制約があります。

**面談で伺う範囲では、同時に選考が進んでいる会社が3社を超えると、日程の調整が難しくなる**という声が多くあります。

**これは決まりではなく、時間の制約から生じる目安**です。

## 段階を分けて考える

| 段階 | 数の考え方 |
|---|---|
| ① 求人を読む | **多くて構いません** |
| ② 候補に残す | 条件で絞ります |
| ③ 応募する | 同時に進める数を決めます |
| ④ 面接 | ③から進んだもの |
| ⑤ 内定 | 比べられる数があるとよい |

**①と③を分けてください。**

**読む数を絞る必要はありません。**

**読むことで、条件の相場が分かります。**

**絞るのは、③の段階**です。

**⑤について。**

**1社だけで判断すると、比べる相手がありません。**

**条件が妥当かどうかは、複数を並べて初めて分かります。**

:::insight
数について、**面談でお伝えしているのが「1社だけで進めないでください」**という点です。**条件の合う求人が1件見つかると、そこに集中される方**がいらっしゃいます。気持ちは分かりますが、**比べる相手がない状態で条件を判断することになります。**提示された条件が妥当かどうかは、**他の求人の条件と並べて初めて分かる**ためです。一方で、**数を増やしすぎると、在職中は対応しきれません。**書類の準備、面接の日程、連絡の管理。**すべてが増えます。**ですから、**同時に進めるのは、日程を管理できる範囲**にとどめてください。そして、**候補として読む数は絞らないでください。**読む作業には時間の制約が小さく、**相場をつかむ効果があります。****読むのは広く、応募は管理できる範囲で。**この分け方が現実的です。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 数が少なくなる場合

| 原因 | 対処 |
|---|---|
| 条件を絞りすぎている | 職種を広げる |
| 勤務地を絞りすぎている | 範囲を1段広げる |
| 職種名で探している | **仕事内容の言葉で探す** |
| 領域を1つに絞っている | 隣接する領域を見る |
| 時期が合っていない | 条件を登録して待つ |

**3つ目です。**

**職種名で絞ると、同じ仕事が検索から漏れます。**

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

**5つ目について。**

**行政が相手の事業では、募集が出る時期が事業の周期に左右されます。**

**待つ期間があること自体は、珍しいことではありません。**

## 辞退について

| 場面 | 対応 |
|---|---|
| 書類の段階 | 連絡を入れてください |
| 面接の前 | **日程が押さえられています。早めに** |
| 面接の後 | 連絡を入れてください |
| 内定の後 | 期限内に回答してください |

**2行目です。**

**面接の日程は、相手の予定も押さえられています。**

**辞退が決まったら、早めに連絡**してください。

**連絡は、メールで構いません。**

**理由を詳しく説明する必要はありません。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 進め方の組み立て

| 順 | やること |
|---|---|
| 1 | 条件を書き出す |
| 2 | 求人を広く読む |
| 3 | 条件に合うものを候補に残す |
| 4 | **同時に進める数を決める** |
| 5 | 応募する |
| 6 | 進行を記録する |
| 7 | 結果が出たら、次を足す |

**7が要**です。

**一度に全部出すのではなく、進行に合わせて足していく**形です。

**1社の選考が終わったら、次を1社足す。**

**この進め方なら、同時に進む数が一定に保てます。**

## 進行の記録

| 記録する項目 | 内容 |
|---|---|
| 会社名 | 一覧にします |
| 応募の経路 | 直接か、紹介か |
| 応募の日 | いつ出したか |
| 現在の段階 | 書類／一次／二次／内定 |
| 次の予定 | 日時と場所（または方法） |
| 期限 | 返事の期限 |

**同時に3社が進むと、記録がないと把握できなくなります。**

**紙でも、表計算でも構いません。**

**2つ目を必ず残してください。**

**経路が分からなくなると、同じ会社に重複して応募する原因になります。**

**扱いは**[直接応募とエージェント経由の違い](senko-sagasu-direct.html)**に整理しています。**

## 期間の見込み

| 段階 | 一般的な目安 |
|---|---|
| 書類の結果 | 数日から2週間程度 |
| 面接の日程の調整 | 在職中は時間がかかります |
| 選考の全体 | 1社あたり1か月前後のことがあります |
| 内定から入社まで | 退職の手続きの期間によります |

**これらは会社によって異なります。**

**3行目について。**

**同時に3社を進めても、結果が出る時期はそろいません。**

**先に結果が出た先の回答の期限と、他社の進行がずれる**ことがあります。

**この場合、期限の調整を確認**してください。**確約はできませんが、伝えておくこと自体に意味があります。**

## よくある失敗

**1. 1社だけで進める**

**比べる相手がありません。**

**2. 一度に多数出す**

**在職中は対応しきれません。**

**3. 読む数まで絞る**

**相場が分かりません。**

**4. 辞退の連絡をしない**

**日程が押さえられています。**

**5. 数を目標にする**

**条件に合うかが先**です。

**6. 結果を待ってから次を探す**

**期間が延びます。**

**7. 進行を記録しない**

**どこまで進んだか分からなくなります。**

:::insight
ここまで数の話をしておいて逆のことを言いますが、**数を増やせば決まるというものではありません。**面談で拝見していると、**応募の数を増やして、書類が定型になってしまう方**がいらっしゃいます。ところが、**中途採用で見られているのは、その求人の条件に合っているかどうか**です。**同じ書類を多数に出すと、どの求人にも合わない書き方になります。**役所の経験は、**求人ごとに違う言葉で説明したほうが伝わります。**用地の折衝を、不動産の会社には「権利関係の調査と合意形成」、自治体向けのシステムの会社には「事業の進行の管理と関係課との調整」と書く。**同じ経験でも、置く言葉が変わります。**ですから、**数を増やすより、条件の近いものに絞って、1件ずつ合わせる**ほうが進みます。在職中は時間も限られています。**数で補おうとしないでください。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **民法第521条**は、**契約をするかどうかを自由に決定できる**と定めています。**複数への応募、辞退、内定の断りは、原則として制限されていません**
- ただし、**辞退の連絡は必要**です
- **「何社」ではなく、「条件に合う求人が何件あるか」と「同時に何件進められるか」**で考えてください
- **読む数は絞らず、応募は管理できる範囲**にとどめてください
- **1社だけで進めない**でください。条件が妥当かどうかは比べて分かります
- **一度に全部出さず、結果が出たら次を足す**形にしてください
- **数を増やして書類が定型になると、かえって伝わりません**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 複数の内定が出た場合、どう選べばよいですか

**条件を項目に分けて並べてください。**業務の内容、勤務地、勤務時間、休日、賃金の構成、転勤の可能性、制度。**この7項目を表にして、社ごとに埋めます。**そのうえで、**自分が重く見る項目に順位を付けてください。**すべてを満たす先はまれです。**何を優先するかを決めると、選べます。**なお、**回答の期限は会社によって異なります。**期限が近い先がある場合、**他社の選考の状況を伝えて、待てるかを確認**して差し支えありません。**確約はできませんが、確認はできます。**期限を過ぎてから相談すると、調整の余地がなくなります。

### 在職中で、面接の時間が取れません

**先に伝えてください。**「在職中のため、平日の日中は調整が難しい」という事情は、**伝えれば調整の対象**になります。オンラインでの実施、始業前や終業後の時間帯、土日。**対応できる範囲は会社によって異なります**が、**聞かずに諦めないでください。**なお、**紹介を通す場合、日程の調整を任せられます。**在職中の事情を伝えておけば、**調整が可能な先を優先して示す**こともできます。扱いは[転職エージェントの使い方](senko-sagasu-agent.html)に整理しています。**休暇を取って対応する場合は、取得の理由を詳しく説明する必要はありません。**

### 書類で通らない場合、数を増やすべきですか

**数の前に、書類の中身を見直してください。**通らない原因は、**条件が合っていない**か、**経験が伝わっていない**かのどちらかであることが多いです。1つ目なら、**応募する求人を変えます。**2つ目なら、**書き方を変えます。**見分け方は、**応募条件の欄と自分の経歴を並べること**です。条件に書かれている経験が自分にあるのに通らない場合、**書き方の問題**である可能性があります。役所の職名や制度の名前だけで書いていると、**中身が伝わりません。**書き方は[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)に整理しています。
