面談で、**「家族に反対されています」**と伺うことがあります。

**反対の中身は、人によって違います。**

この記事では、**伝え方の順序**と、**反対されたときの整理の仕方**を扱います。

**⚠ 家族の事情は個別性が高い**ため、**この記事は一般的な整理にとどめます。**

## 家族は、無関係な第三者ではありません

**民法第752条**です。

> **夫婦は同居し、互いに協力し扶助しなければならない。**

**「協力」と「扶助」**が、条文の言葉として置かれています。

**生活を一緒に成り立たせる関係**が前提になっている、ということです。

**転職は、この生活の条件を変える出来事**です。

**勤務地、勤務時間、休日、収入、通勤の時間、家事や育児の分担。**

**変わる範囲が、自分だけで完結しません。**

**ですから、家族への説明は「報告」ではなく「条件の擦り合わせ」**になります。

**この点を踏まえると、伝え方の順序が決まります。**

## 結論——「決めた」より前に、「考えている」を伝える

| 伝える時期 | 相手の受け取り方 |
|---|---|
| 退職を決めた後 | **相談ではなく通告**として受け取られます |
| 内定が出た後 | 判断の余地が小さく、反発が出やすくなります |
| 検討を始めた段階 | **一緒に考える余地**が残ります |

**3つ目を選んでください。**

**早く伝えるほど、反対の理由を聞く時間が取れます。**

**そして、反対の理由が分かれば、対処できるものと、できないものに分かれます。**

## 伝えるときの順序

| 順 | 伝えること |
|---|---|
| 1 | **いま考えている段階である**こと（決めていない） |
| 2 | **なぜ考えているか**（きっかけ） |
| 3 | **何が変わる可能性があるか**（勤務地・時間・収入・休日） |
| 4 | **何を確認しようとしているか**（求人、条件、制度） |
| 5 | **いつまでに何を判断するか** |

**1を最初に置いてください。**

**「辞めます」から始めると、以降の説明が耳に入りません。**

**5を入れると、相手が見通しを持てます。**

**「いつまでも宙ぶらりんになるのではないか」という不安が、反対の理由になっていることがあります。**

## 2の伝え方——きっかけを具体で言う

**抽象的な理由は、伝わりません。**

| 伝わりにくい | 伝わりやすい |
|---|---|
| やりがいがない | 3年続けた業務が、来年度から別の課に移る |
| 将来が不安 | 担当している制度が、あと数年で形が変わる見込み |
| 環境を変えたい | 異動の希望を3回出したが、通っていない |
| 成長したい | いまの仕事で身につくものが、頭打ちになっている感覚がある |

**右の列のほうが、話が続きます。**

**具体的な事実であれば、相手も「それなら」と考えられます。**

**抽象的な言葉だと、「気の迷いではないか」と受け取られやすい**です。

## 反対されたときの整理

**反対の理由は、だいたい次のどれかに分かれます。**

| 理由 | 性質 |
|---|---|
| ① 生活の見通しが分からない | **情報で解消できます** |
| ② 安定を失うことへの不安 | 情報で一部解消できます |
| ③ 周囲への体裁 | 話し合いの対象 |
| ④ 家族自身の生活が変わる | **条件の調整が必要です** |
| ⑤ 本人の状態への心配 | 理由の説明が必要です |

**①と④が多い**です。

**①は、数字と事実を出せば解消に向かいます。**

**④は、調整の問題です。**勤務地が変われば通勤や保育の段取りが変わります。

**⑤は、見落とされやすい**です。

**「疲れているのではないか」「追い詰められているのではないか」**という心配が、反対の形で出ていることがあります。

## ①への対処——見通しを数字で示す

| 出すもの | 中身 |
|---|---|
| 収入の見込み | **提示された条件**（内定前なら求人票の範囲） |
| 支出の変化 | 通勤、保育、住居に関する手当の有無 |
| 時期 | 退職の時期と、入社の時期 |
| 退職手当の扱い | 支給の時期と、使途の予定 |
| 空白の期間 | あるのか、ないのか |

**5つ目を明示してください。**

**空白があるかどうかで、相手の受け取り方が変わります。**

**退職手当の支給の時期については**[退職手当はいつ振り込まれるか](senko-taishoku-shikyubi.html)**に整理しています。**

**借入がある場合は**[住宅ローンがある状態での転職](senko-taishoku-loan.html)**も併せて確認してください。**

:::insight
反対されたときに、**面談でお聞きしているのが「反対の理由を、相手の言葉で聞けていますか」**という点です。多くの場合、**「反対された」という事実だけが残っていて、理由が確認されていません。**ところが、**理由が分かると、対処が変わります。**生活の見通しが分からないという理由なら、**数字を出せば進みます。**一方、**家族自身の生活が変わることへの懸念**なら、**条件の調整**が必要です。**この2つは、対処がまったく違います。**そして、**理由を聞く場面で、説得しようとしないでください。**説得を始めると、相手は理由を言わなくなります。**「何が心配か」を聞いて、その場では答えない。**持ち帰って、次に会うときに情報を持ってくる。**この進め方のほうが、結果として早い**です。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## ④への対処——変わる範囲を具体にする

| 項目 | 確認すること |
|---|---|
| 勤務地 | 通勤の時間、送迎の可否 |
| 勤務時間 | 保育園・学童の時間に間に合うか |
| 休日 | 土日か、シフトか |
| 出張 | 頻度と泊まりの有無 |
| 転勤 | 可能性の有無 |

**5つ目を、求人の段階で確認**してください。

**転勤の可能性がある求人は、家族の事情によっては候補から外れます。**

**後で分かるより、先に絞るほうが確実**です。

[経験の言い換えから相談する](../apply.html)こともできます。

## ⑤への対処——状態の説明を先にする

**「追い詰められているのではないか」という心配には、状態の説明が効きます。**

| 伝えること | 例 |
|---|---|
| 現状の評価 | いまの仕事に不満はある／ないの区別 |
| 体調 | 問題があるか、ないか |
| 判断の根拠 | 感情ではなく、条件で考えていること |
| 期限 | 焦って決める予定がないこと |

**4つ目が効きます。**

**「今月中に決める」ではなく、「半年かけて見る」と伝えると、心配が薄れます。**

## 伝える場面の作り方

| 項目 | 目安 |
|---|---|
| 時間 | まとまった時間が取れるとき |
| 場所 | 落ち着いて話せる場所 |
| 回数 | **1回で終わらせない** |
| 資料 | 求人票、条件の一覧 |

**3つ目です。**

**1回で結論を出そうとすると、対立になります。**

**1回目は伝えるだけ、2回目に質問に答える、3回目に判断する**という分け方が現実的です。

## 反対が続く場合

**次の3つを確認してください。**

**1. 理由が変わっていないか**

**最初の理由が解消したのに、別の理由が出てくる場合、根にあるのは別のもの**であることがあります。

**2. 情報が足りているか**

**具体的な求人や条件が出ていない段階では、判断の材料がありません。**

**3. 時期の問題ではないか**

**家族の事情（受験、介護、出産など）と重なっている**場合、**時期をずらすという選択**があります。

**3つ目は、検討に値します。**

**転職の時期は、自分だけで決めるものではありません。**

## よくある失敗

**1. 決めてから伝える**

**通告として受け取られます。**

**2. 反対の理由を聞かない**

**対処が決まりません。**

**3. 抽象的な理由で説明する**

**気の迷いと受け取られます。**

**4. 1回で結論を出そうとする**

**対立になります。**

**5. 数字を出さない**

**見通しが立ちません。**

**6. 家族の生活の変化を説明しない**

**自分の話だけになります。**

**7. 反対されたことを理由に、話を打ち切る**

**理由が残ったままになります。**

:::insight
ここまで伝え方の話をしておいて逆のことを言いますが、**家族が反対していること自体は、悪いことではありません。**面談で拝見していると、**反対されたことで検討が止まった方**と、**反対をきっかけに条件を詰め直した方**がいらっしゃいます。後者のほうが、**結果として納得のいく選択になっている**ことが多いです。理由は、**反対の理由に答えようとすると、自分でも曖昧だった部分が詰まるから**です。収入の見込み、時期、空白の期間。**これらを説明できる状態にすることは、面接の準備そのもの**でもあります。ですから、**反対を「乗り越える障害」と考えないでください。****確認の機会**です。そして、**いまの職場に残るという判断も、同じ材料から出てきます。**条件を並べた結果、**いまのほうが条件がよいと分かる**こともあります。それは、検討が無駄だったという意味ではありません。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **民法第752条**は、**夫婦の同居・協力・扶助**を定めています。**転職は生活の条件を変えるため、報告ではなく擦り合わせ**になります
- **決めた後ではなく、考えている段階で伝えて**ください
- 伝える順序は、**①段階 ②きっかけ ③変わること ④確認すること ⑤時期**
- **反対の理由を、相手の言葉で聞いて**ください。**見通しの問題か、生活の調整の問題か**で対処が変わります
- **説得を先にしない。**理由を聞いて、情報を持ち帰ってください
- **1回で結論を出さない。**3回に分ける進め方が現実的です
- 家族の事情と時期が重なっているなら、**時期をずらすという選択**もあります

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 伝えたら、強く反対されて話ができなくなりました

**いったん間を置いてください。**その場で議論を続けても、**理由が出てきません。**次に話すときは、**「何が心配か、教えてほしい」という聞き方**に変えてみてください。**反対の内容ではなく、心配の中身を聞く形**です。そのうえで、**その場で答えないでください。**「調べて、また話す」と伝えて持ち帰る。**情報を持って戻ると、話が進むことがあります。**なお、**強い反対の背景に、自分では気づいていない事情がある**こともあります。家族自身の仕事や健康の状況が変わっている、といった場合です。**まず聞くことを優先**してください。

### 親には伝えるべきですか

**生活を共にしていない場合、伝える義務はありません。**ただし、**後から知って反発が出る**ことはあります。判断の目安は、**その人の生活に影響があるかどうか**です。同居している、介護の分担がある、経済的なやり取りがある。**影響があるなら、早めに伝えるほうが摩擦が少ない**です。一方、**影響がない場合、伝える時期は自分で決めて差し支えありません。**なお、**「公務員を辞めること」そのものへの反発**が出ることがあります。その場合は、**辞める話ではなく、何をしに行くかの話**として伝えるほうが、受け取られやすいです。

### 反対されたまま、進めてよいものでしょうか

**判断はご本人のものです。**ただし、**反対の理由が生活の調整に関わるもの（保育、介護、通勤）である場合、調整しないまま進めると、入社後に問題が出ます。**この場合は、**進める前に調整**してください。一方、**理由が体裁や漠然とした不安である場合、時間をかけて説明を重ねる**ほうが現実的です。なお、**理由が解消しないまま期限が来る**こともあります。その場合、**応募を見送って、次の機会に回す**という選択もあります。**求人は、その1件だけではありません。**時期をずらして、条件の合う求人を探し直すこともできます。
