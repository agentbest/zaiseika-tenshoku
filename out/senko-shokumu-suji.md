職務経歴書の相談で、いちばん多く伺うのがこれです。

**「売上も利益もないので、書ける数字がありません」**

**窓口、相談、許認可、内部の管理。**成果が、**件数にも金額にも見えない仕事**です。

ただ、**数字が無いのではありません。****数えていないだけ**であることが、ほとんどです。役所の仕事は、**数えられるものに囲まれています。**対象の数、処理した数、かかった日数、関わった人の数。**どれも、探せば出てきます。**

この記事では、**その探し方を3つ**に分けます。書類全体の型は[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)にあります。

## 結論：数字の出どころは3つしかない

| 方法 | どこから取るか | 使いやすさ |
|---|---|---|
| ① 公表資料から拾う | 決算の資料、事務事業の評価、統計、白書 | **出典が付くので、いちばん強い** |
| ② 自分で数える | 手元の記録、引継ぎの資料、年間の予定表 | 手間はかかるが確実 |
| ③ 変化で出す | 前と後を比べる（日数、枚数、回数） | **少ない手間で効く** |

**①から順に当たってください。**①で足りれば、②の手間は要りません。

## 「主要な施策の成果を説明する書類」が、毎年作られています

①がいちばん強い理由は、**役所が毎年、成果を数字で説明する書類を作っているから**です。

**地方自治法第233条第5項**です。

> 普通地方公共団体の長は、第三項の規定により決算を議会の認定に付するに当たつては、当該決算に係る会計年度における主要な施策の成果を説明する書類その他政令で定める書類を併せて提出しなければならない。

**「主要な施策の成果を説明する書類」**。自治体によって、**主要施策の成果報告書、決算成果説明書**などと呼ばれています。

さらに、**同条第6項**は、**議会の認定に付した決算の要領を住民に公表しなければならない**と定めています。

つまり、**自分が担当した事業の実施の件数や実績は、すでに公表されている**ことが多い、ということです。**探す先は、自分の記憶ではなく、自治体のサイト**です。

事務事業の評価をしている自治体なら、**評価シートに事業ごとの指標と実績値**が載っています。**そこに自分の担当事業があれば、そのまま出典付きで使えます。**

**公表されている数字を使う利点は、2つ**あります。**出典が書けること。**そして、**守秘の線を越えないこと**です。

## 数えられるものの棚卸し

②に進むときは、**次の6種類を上から見てください。**

| 種類 | 例 |
|---|---|
| 対象の数 | 管内人口、対象の世帯数、施設数、事業者数、担当した部局の数 |
| 処理の数 | 年間の申請件数、決定件数、相談件数、審査件数、発注件数 |
| 時間 | 処理にかかる日数、待ち時間、会議の回数、繁忙期の期間 |
| 人 | 係の人数、指導した新任の人数、研修の受講者数、関係機関の数 |
| 文書 | 様式の数、マニュアルの頁数、通知の発出件数、答弁の作成件数 |
| 金額 | 予算の規模、契約の金額、交付した補助金の件数 |

**このうち3つ埋まれば、書類は変わります。**全部を埋める必要はありません。

**「対象の数」と「処理の数」は、ほぼ全員が書けます。**窓口でも、相談でも、内部の管理でも、**相手にしていた母数と、処理した量**は必ずあります。

## 「減らした」を書く——変化の出し方

③は、**数字が無い仕事でいちばん効く方法**です。**前と後を比べるだけ**で、指標そのものは自分で選べます。

| 変化の指標 | 書き方の例 |
|---|---|
| 日数 | 申請から決定までの標準の日数を、◯日から◯日に短縮 |
| 枚数 | 申請に必要な添付書類を◯種類から◯種類に削減 |
| 回数 | 月◯回の定例の会議を、資料の事前の共有により月◯回に集約 |
| 手戻り | 記載の不備による再来庁を、記入例の様式化により減少 |
| 範囲 | 手作業だった集計を表計算で自動化し、担当者◯人の作業を不要に |

**元の数字が記録に残っていないときは、「◯日程度かかっていたものを、◯日程度に」と幅で書いて構いません。**

**盛らないでください。**面接で、**「その◯日は、何を数えた日数ですか」**と聞かれます。**答えられる範囲の数字だけを書く。**これが唯一の条件です。

:::insight
面談で「数字がない」とおっしゃる方に、**必ず伺っている質問が1つ**あります。**「その仕事、引き継ぐとしたら、後任に何を説明しますか」**です。ここで出てくる説明は、**ほぼ全部が数字**です。「年間だいたい◯件来る」「繁忙期は◯月から◯月」「◯種類の様式がある」「◯課と◯課に回す」。**引継ぎのために覚えている情報が、そのまま職務経歴書の数字になります。**公表されている数字と違って、**引継ぎで使う数字は「肌感」で持っている**ので、**探す手間がかかりません。**もう1つ、**この経歴でいちばん多い失敗**を挙げると、**担当した事業の予算額を、自分の成果のように書いてしまう**ことです。「◯億円の事業を担当」と書くと、面接で**「そのうち、あなたが決めた部分はどこですか」**と必ず聞かれます。予算の規模は**組織の規模の話**なので、**自分の判断の範囲とは別に書いてください。**規模は規模、判断は判断。分けて並べたほうが、**両方とも信用されます。**
:::

## 使ってよい数字、使わないほうがよい数字

| ○ 使える | ✕ 避ける |
|---|---|
| 決算資料・事務事業の評価など、**公表されている数字** | 未公表の内部の集計値 |
| 自分が処理した件数（概数・「約」でよい） | 個人や事業者が特定できる事案の数 |
| 組織の規模（人口、職員数、予算の規模） | 他の自治体との比較で優劣を示す数字 |
| 自分が変えた前後の比較 | 出どころを説明できない数字 |

**判断に迷ったら、「この数字の出どころを、面接で1行で説明できるか」**で決めてください。説明できないものは、**外してもほとんど損をしません。**

自分の経歴からどの数字を拾えるかは、一度話しながら整理したほうが早いことが多いです。[どの経験に値が付くのかから相談できます](../apply.html)。

## 応募先によって、効く数字が違います

**同じ経歴でも、出す数字を選び直すだけで読まれ方が変わります。**

| 応募先の方向 | 前に出す数字 |
|---|---|
| 自治体向けのSaaS・システム | 対象の部局数、扱っていた業務の種類、紙の様式の数、関係する職員の数 |
| 建設コンサルタント・インフラ | 施設の数、工事の件数、予算の規模、点検の対象の数 |
| 金融・債権の管理 | 対象の件数、時効の管理をしていた債権の種類、折衝の件数 |
| 医療・福祉・介護の事業者 | 担当の世帯数、連携した機関の数、支援の計画の件数 |
| 人材・研修・コンサルティング | 研修の回数と受講者数、作った資料の数、説明会の回数 |

**上の表の数字は、どれも「②自分で数える」で出せるもの**です。応募先が変わるたびに数え直す必要はありません。**6種類の棚卸しを一度やっておけば、あとは並べ替えるだけ**で足ります。

## よくある失敗

**1. 全部の行に数字をつける**

**数字が並びすぎると、どれも読まれません。**要約欄に1〜2個、実績欄に3〜4個。**それで十分**です。

**2. 予算額を自分の成果として書く**

**規模の話と、判断の話を分けてください。**混ぜると、両方の信用が落ちます。

**3. 桁を丸めすぎる**

「多数の申請を処理」「多くの住民対応」。**「多数」は、数字ではありません。**

**4. 内部の未公表の数値を出す**

**公表されている範囲に置き換えてください。**同じことは、たいてい公表資料でも言えます。

**5. 変化の原因を、全部自分の手柄にする**

「収納率が◯％向上しました」と書くと、**制度の改正や景気の影響を確認されます。****「自分が担当した部分」を明示**してください。

**6. 数字が出ないことを理由に、応募を止める**

**②と③は、誰でも1時間あれば作れます。**止まる理由にはなりません。

:::insight
ここまで書いておいて逆のことを言いますが、**数字が無くても読まれる欄が1つ**あります。**「やり方を変えた話」**です。数字の有無にかかわらず、**「去年と同じやり方でしたか」に答えられる人**は、採用の側から見ると分かりやすい。様式を1枚減らした、確認の順番を入れ替えた、説明の資料を作り直した。**その変更は、効果を測っていなくても、判断として読まれます。**逆に、**測っていない効果を数字にして書くほうが、面接で崩れます。**「◯％削減」と書いて、根拠を聞かれて答えられないと、**その1行だけでなく、書類全体の数字が疑われます。**数字は、**出せるところだけに出してください。**出せない部分は、**方法の説明で埋められます。**在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 数字の出どころは、**①公表資料から拾う ②自分で数える ③変化で出す**の3つ。**①から当たる**のが早道です
- **地方自治法第233条第5項**により、決算には**主要な施策の成果を説明する書類**が添えられます。**同条第6項で決算の要領は住民に公表されます**
- **自分が担当した事業の実績は、すでに公表されていることが多い。**探す先は、記憶ではなく自治体のサイトです
- 自分で数えるときは、**対象の数・処理の数・時間・人・文書・金額**の6種類。**3つ埋まれば十分**です
- 変化は、**日数・枚数・回数・手戻り・範囲**で出せます。**幅で書いて構いません**
- 使ってよいのは、**出どころを1行で説明できる数字**だけです

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 担当した事業が、決算の成果の書類に載っていません

**小さな事業は、個別に載らないことがあります。**その場合は、**上位の事業の枠で探してください。**事務事業の評価をしている自治体なら、**評価シートのほうが細かい単位**で作られていることが多いです。それでも見つからないときは、**②の自分で数える方法に切り替えてください。**年間の予定表、月例の報告、引継ぎの資料。**この3つに、件数と時期はたいてい残っています。**なお、公表資料に載っていない数字を使うこと自体は問題ありません。**自分が処理した件数の概数は、自分の職務の内容**です。気をつけるのは、**個別の案件が特定できる形にしないこと**だけです。

### 「約」や「程度」を付けると、弱く見えませんか

**弱く見えません。**むしろ、**「約」が付いているほうが、確認を取ったうえで書いていると読まれます。**精密な数字を出すと、**その根拠を面接で詰められます。**「年間1,247件」と書けば、**どの期間の、何の件数かを説明できなければなりません。**「年間約1,200件」であれば、**桁と規模が伝わり、説明も1行で済みます。**職務経歴書で求められているのは、**正確さの証明ではなく、規模の把握**です。ただし、**「約」を付ければ何を書いてもよい、ということではありません。**説明できる範囲で丸める、という意味です。

### 民間では通用する数字ではない気がして、書くのをためらいます

**比べる必要はありません。**採用の担当者が見ているのは、**数字の大きさではなく、その人が自分の仕事の規模を把握しているかどうか**です。「年間約200件の申請を審査し、うち約30件は追加の資料の確認が必要だった」と書いてあれば、**仕事の構造を理解している人として読まれます。**件数が1万件でも、**構造が書かれていなければ同じ評価にはなりません。**むしろ、**規模を把握していない書類のほうが心配されます。**数えた数字は、**そのまま出してください。**自分の経験がどう読まれるかは、[経験の言い換えから相談する](../apply.html)こともできます。
