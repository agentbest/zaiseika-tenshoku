**「会社のことを、どう調べればよいか分からない」**というご相談を伺います。

**役所では、事業者を調べる作業は担当の業務の中で行うもの**でした。

**転職の場面では、自分のために調べることになります。**

この記事では、**見られる資料**と、**見るところ**を扱います。

## 財務の情報は、公告されています

**会社法第440条第1項**です。

> **株式会社は**、法務省令で定めるところにより、**定時株主総会の終結後遅滞なく、貸借対照表**（**大会社にあっては、貸借対照表及び損益計算書**）**を公告しなければならない。**

**同条第2項**は、**官報または日刊新聞紙で公告する会社**について、**要旨の公告で足りる**としています。

**同条第3項**は、**電磁的方法による措置**を定めています。

> （略）**定時株主総会の終結後遅滞なく**、第一項に規定する貸借対照表の内容である情報を、**定時株主総会の終結の日後五年を経過する日までの間、継続して電磁的方法により不特定多数の者が提供を受けることができる状態に置く措置**をとることができる。

**会社のウェブサイトで「決算公告」として掲載されているもの**が、これにあたります。

**同条第4項**は、**有価証券報告書を提出しなければならない株式会社**について、**前3項の規定を適用しない**としています。

**上場している会社などは、有価証券報告書のほうで情報が公開されている**ためです。

**つまり、株式会社であれば、どちらかの形で財務の情報が公開されている**ということです。

## 見られる資料

| 資料 | どこで見るか |
|---|---|
| ① 決算公告 | 会社のウェブサイト、官報 |
| ② 有価証券報告書 | 提出している会社の場合 |
| ③ 会社のウェブサイト | 事業の内容、沿革、拠点 |
| ④ 採用のページ | 職種、制度、体制 |
| ⑤ 発表・お知らせ | 受注、事業の開始 |
| ⑥ 商業登記の情報 | 登記所で取得できます |

**③と⑤を先に見てください。**

**事業の内容と、直近で何が起きているか**が分かります。

**⑤について。**

**「◯◯市の指定管理者に選定されました」「◯◯県の業務を受託しました」**といった発表があれば、**行政が相手の事業を担っている**ということです。

## 行政が相手の会社を調べる方法

**ここは、役所で働いてきた人に向いている作業**です。

| 調べるもの | どこで見るか |
|---|---|
| ① 指定管理者の指定 | **議会の議案、議決の結果** |
| ② 入札・契約の結果 | 自治体の公表 |
| ③ プロポーザルの結果 | 自治体の公表 |
| ④ 委託の状況 | 予算の説明資料、事業の概要 |
| ⑤ 事業の評価 | 指定管理者の評価、事業報告 |

**①について。**

**指定管理者の指定は、議会の議決を経て行われます。**

**議案と議決の結果は、公表されています。**

**どの団体が、どの施設を、どの期間担っているかが分かります。**

**⑤について。**

**指定管理者は、事業報告書を提出する仕組み**になっています。

**公表されている場合、事業の状況を確認できます。**

**これらの資料の読み方は、役所で身につけたもの**です。

## 決算公告の見るところ

| 項目 | 見ること |
|---|---|
| 純資産の部 | 累積の状況 |
| 資産と負債 | 構成 |
| 損益（大会社の場合） | 当期の状況 |
| 公告の継続性 | **毎年行われているか** |

**4つ目です。**

**継続して公告されているかどうかは、確認できる点**です。

**なお、決算公告だけで会社の状況を判断しきることはできません。**

**1期の数字で評価せず、他の資料と併せて見てください。**

**数字の読み方に自信がない場合、無理に判断しなくて差し支えありません。**

**見るべきは、事業の内容と、自分の経験が使えるか**です。

:::insight
企業を調べるときに、**面談でお伝えしているのが「自治体の公表資料を使ってください」**という点です。行政が相手の事業を担う会社については、**相手の側の公表資料から確認できることが多くあります。**指定管理者の指定の議案、入札の結果、プロポーザルの選定の理由、事業報告書。**これらは、役所で日常的に扱ってきた種類の資料**です。**読み方を知っている**という点で、**公務員から転職する方には有利な調べ方**になります。たとえば、**プロポーザルの選定の理由**には、**その会社が何を強みとして提案したか**が書かれていることがあります。**面接で話す材料になります。**また、**指定の期間**が分かれば、**事業の継続の見通し**も見えます。会社のウェブサイトだけを見て「よく分からない」と止まるより、**相手の側から調べる**ほうが、具体が出てきます。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 採用のページから分かること

| 見るところ | 分かること |
|---|---|
| 募集している職種の数 | 体制の状況 |
| 同じ職種の継続した募集 | 増員か、他の理由か |
| 制度の記載 | 休暇、在宅勤務、研修 |
| 社員の紹介 | **どんな経歴の人がいるか** |
| 拠点の一覧 | 勤務地の候補 |

**4つ目です。**

**行政の出身者が在籍しているかどうか**が分かることがあります。

**いれば、経験の使いどころが想像しやすくなります。**

**5つ目について。**

**拠点の一覧は、将来の勤務地の候補**でもあります。

**転勤の範囲を考えるときの材料になります。**扱いは[転職にともなう転居と単身赴任](senko-taishoku-tenkyo.html)に整理しています。

[経験の言い換えから相談する](../apply.html)こともできます。

## 調べる順序

| 順 | やること |
|---|---|
| 1 | 会社のウェブサイトで事業の内容を見る |
| 2 | 発表・お知らせで直近の動きを見る |
| 3 | **自治体の公表資料で、担っている事業を確認** |
| 4 | 決算公告または有価証券報告書を見る |
| 5 | 採用のページで体制と制度を見る |
| 6 | 求人票と突き合わせる |

**6が要**です。

**調べた内容と求人票の記載が合っているか**を確認してください。

**合っていれば、面接で聞く内容が具体になります。**

**合わない点があれば、それが質問になります。**

## 調べすぎないこと

| 項目 | 目安 |
|---|---|
| 1社あたりの時間 | **30分から1時間** |
| 調べる会社の数 | 応募を検討する先 |
| 深さ | 事業の内容と直近の動きが分かれば足ります |

**1行目です。**

**応募の前に、すべてを把握する必要はありません。**

**面接は、確認する場でもあります。**

**分からない点は、質問として持っていって差し支えありません。**

**調べきれないこと自体は、応募を止める理由になりません。**

## よくある失敗

**1. 会社のウェブサイトだけを見る**

**自治体の公表資料**も使えます。

**2. 決算の数字だけで判断する**

**1期の数字で評価しないでください。**

**3. 発表・お知らせを見ない**

**直近の動きが分かります。**

**4. 求人票と突き合わせない**

**質問が作れません。**

**5. 調べるのに時間をかけすぎる**

**面接で確認できます。**

**6. 採用のページを読まない**

**体制と制度が分かります。**

**7. 調べた内容を面接で使わない**

**質問の材料になります。**

:::insight
ここまで調べる話をしておいて逆のことを言いますが、**調べた内容を、知識として披露しないでください。**面談で拝見していると、**調べたことを面接で話そうとして、確認の質問が後回しになる方**がいらっしゃいます。ところが、**面接で聞かれているのは、その会社で何ができるか**です。**調べた内容は、質問の材料として使うほうが効きます。**たとえば、「◯◯市の指定管理者に選定されたという発表を拝見しました。今回の募集は、その事業に関わるものでしょうか」という聞き方です。**調べたことが伝わり、同時に確認もできます。**一方、調べた事実を並べるだけでは、**自分が何をする人かが伝わりません。**ですから、**調べる目的は「質問を作ること」**だと考えてください。**質問が3つ用意できれば、調査としては足りています。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **会社法第440条**は、**株式会社に貸借対照表（大会社は損益計算書も）の公告**を義務づけています。**電磁的方法による措置**をとる会社もあります
- **有価証券報告書を提出する会社には、同条の適用がありません。**そちらで情報が公開されています
- 見る資料は、**会社のウェブサイト、発表・お知らせ、決算公告、採用のページ**です
- **行政が相手の会社は、自治体の公表資料から調べられます。**指定管理者の議案、入札・プロポーザルの結果、事業報告書
- **これらの資料の読み方は、役所で身につけたもの**です
- **決算の数字だけで判断しないでください**
- **調べる目的は、質問を作ること**です。3つ用意できれば足ります

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 決算公告が見つかりません

**公告の方法が複数あります。**会社のウェブサイトに掲載している場合、**「決算公告」「電子公告」といった項目**を探してください。**会社の概要のページの下部**にあることがあります。ウェブサイトにない場合、**官報で公告されている**ことがあります。なお、**見つからない場合もあります。**この場合、**他の資料で確認**してください。事業の内容、直近の発表、自治体の公表資料。**判断の材料は、財務の情報だけではありません。**また、**有価証券報告書を提出している会社には、会社法第440条の適用がありません。**その場合は、有価証券報告書のほうを確認してください。読み方は別の記事で整理します。

### 自治体の公表資料は、どこを見ればよいですか

**その自治体のウェブサイトです。**探す項目は、**「指定管理者」「入札」「契約」「プロポーザル」「公募」**です。議会の議案と議決の結果は、**議会のページ**にあります。指定管理者の評価や事業報告書は、**施設を所管する課のページ**に掲載されていることがあります。**自分の団体以外の自治体でも、同じ構成であることが多い**です。なお、**公表の範囲は団体によって異なります。**見つからない項目があっても、**その会社に問題があることを意味しません。**あくまで、**確認できる範囲で見る**という位置づけです。

### 調べた内容は、書類に書くべきですか

**志望の動機と結びつく範囲で書いてください。**調べた事実を列挙するだけでは、**志望の動機になりません。**「◯◯の事業を担っていることを知り、自分の経験が使えると考えた」という形で、**自分の経験とつなげて**ください。たとえば、**指定管理の事業を担っている会社**であれば、**施設の管理や利用者の対応に関わった経験**とつなげられます。**発注者支援**であれば、**工事の監督や積算の経験**です。**事実と経験の接続**が、志望の動機の中身になります。組み立て方は[業界の選び方と、志望動機への落とし方](senko-shibo-gyokaierabi.html)に整理しています。
