夏季休暇は、年次休暇とは別に、夏季の諸行事や心身の健康維持、家庭生活の充実等に対応する休暇です。ただし、全公務員が同じ日数を同じ時期に取得する制度ではありません。国と自治体、本人の任用、勤務日の割振りを分けて確認します。

本記事は2026年11月時点の公開情報にもとづきます。国の一般職の例と横浜市の具体例を区分します。本人の取得可能日数、分割、給与と承認は所属の人事・服務担当へ確認してください。

## 国の原則は7月から9月の3日以内

人事院規則15-14第22条第1項第15号は、夏季の盆等の行事、心身の健康の維持・増進、家庭生活の充実等のため勤務しないことが相当な場合について、夏季休暇を定めています。

原則の対象は一の年の7月から9月までです。業務の繁忙期等の事情で、その期間に全部又は一部を使うことが困難と認められる職員については、6月から10月までの期間としています。単に本人が希望すれば全員が10月まで使える、という説明ではありません。

| 国の制度の項目 | 確認する内容 |
| --- | --- |
| 原則の対象期間 | 7月から9月 |
| 業務事情による対象期間 | 要件を満たすと認められる場合は6月から10月 |
| 上限 | 原則として連続する3日の範囲内 |
| 日数に含めない日 | 条文に掲げる週休日、休日等 |
| 分割 | 運用通知の条件を確認 |

この3日は、年次休暇を3日使うという意味ではありません。申請上の休暇区分と、年次休暇の残日数を分けて把握します。年次休暇を前後につなげる場合も、夏季休暇そのものの日数が増えるわけではありません。

## 週休日等を除く連続を勤務表で確認する

国の条文は、週休日、勤務時間を割り振らない日、一定の超勤代休時間が指定された日、休日、代休日を除くと定めています。結婚や忌引の連続暦日と、同じ数え方にしないことが必要です。

例えば、仮に月曜から金曜まで勤務し土日が週休日の人なら、金曜・翌月曜・火曜という取り方も、除外する週休日を挟んだ連続の考え方として確認します。これは日数計算を示す例であり、個別の承認やすべての勤務形態を保証するものではありません。

交替制勤務や短時間勤務では、土日がそのまま本人の週休日とは限りません。希望する休暇日、勤務が割り振られた日、休日等を一枚に並べ、休暇として数える日を担当と照合してください。

申請の開始日と終了日だけを見て、間にあるすべての日を同じ休暇日数へ入れることは避けます。反対に、休日という言葉だけで自動的に除外するのではなく、本人の勤務上の区分を確認します。

## 分割は条件付きで確認する

人事院の運用通知第14は、原則として連続する3日の扱いについて、特に必要と認められる場合は1暦日ごとに分割できるとしています。いつでも自由に三つの別の日を選べるというものではなく、本人の希望と必要性を所属へ確認します。

希望がある場合には、一括取得の予定と分割したい予定を示して相談します。家族の予定や勤務上の調整があるなら、確認に必要な範囲で事情を伝えます。口頭の相談だけで分割の承認まで済んだとは判断しないでください。

夏季休暇の期間変更と、年次休暇の時季の変更も別に扱います。承認済みの日程を変更する場合には、残りの日数、取得期間内に収まるか、申請の変更方法を再確認します。

特別休暇全体の区分は[特別休暇の種類](seido-kyuka-tokubetsu-shurui.html)でも説明しています。夏季休暇の取扱いを、同じ特別休暇という理由だけで結婚・忌引等へ当てはめないことが大切です。

:::insight
夏季休暇の予定を作るときは、休みの日数より先に、本人の勤務表と対象期間をそろえることを勧めます。週休日等を除く連続なのか、暦日を続けて数えるのかで、同じ三日という説明でも日程が変わるためです。本人用の表には、希望する休み、勤務日、週休日、年次休暇を別の欄に置きます。分割したい場合や業務事情による対象期間の確認が必要なら、担当への質問も分けて残します。制度があることだけで旅行等の日程を確定せず、承認の条件を確認してから調整します。現職で働き続ける場合にも、外の勤務条件を調べる場合にも、名前だけでなく実際の使い方を比較する姿勢が役立つと考えます。
:::

外の仕事も調べたい場合は、[公務員向けの求人情報](../?gov=1)を材料にできます。休暇の確認だけで応募を決める必要はありません。

## 非常勤の夏季休暇も勤務条件を確認する

国家公務員の非常勤については、人事院規則15-15第4条第1項第8号に有給の夏季休暇があります。ただし対象となる非常勤職員の条件や、勤務時間が定められていない日の扱いを、運用通知と本人の任用で確認します。

同規則も原則7月から9月、業務事情で困難と認められる場合の6月から10月という対象期間を定めています。運用通知は勤務時間が定められていない日を除外し、特に必要と認められる場合の分割を示しています。

常勤と名称や上限が似ていても、任用期間、勤務日数、勤務の割振りを省いて判断しません。非常勤だからすべて対象外、又は常勤とすべて同じ、のどちらにもまとめないでください。

地方の会計年度任用職員等には、国の非常勤の規則がそのまま適用されるものではありません。任用通知と所属の休暇規程を示し、本人の対象と日数を人事担当へ確認します。

## 自治体例は対象期間・日数とも国と区別する

地方公務員法第24条第5項に基づく休暇の条件は、本人の自治体の条例等で確認します。横浜市の一般職職員の例では、条例第4条に夏季休暇があり、規則第4条は6月1日から9月30日までの5日の範囲内としています。

さらに、短時間勤務職員等の日数計算や、6月1日以後の新規採用・復職等には別の定めがあります。国の「3日」を「5日」に置き換えるだけで、自分の取得可能日数が分かるわけではありません。

同市の規則第6条も、休暇期間に勤務を要しない日や休日を算入する一般の取扱いから夏季休暇を除外しています。具体的な連続・分割や時間の扱いは、勤務形態と運用に沿って確認します。

自治体の例規を検索するときは、名称だけでなく、現行の条例、規則、適用対象を確認します。前年度の庁内案内や別の自治体の経験を、今年の本人の条件として使わないことが必要です。

## 年度途中の採用・退職は残日数だけで決めない

採用や復職が対象期間の途中にある場合には、その任用や復職の条件を確認します。自治体の例のように、特定日時点の勤務や在職状況で日数を区分する場合もあります。年次休暇と同じ在職月数の割合を、根拠なく夏季休暇へ使わないでください。

退職を予定する場合は、正式な退職日と、夏季休暇の取得可能期間を別に整理します。退職後に休暇を使うことはできず、転職先へ未使用分が当然に引き継がれるものでもありません。

転職先の民間会社に「夏季休暇あり」と書かれていても、一斉の休日、本人が取得する特別休暇、年次有給休暇を利用する制度などを分けて確認します。公務員時代と同じ仕組みという前提にはしません。

未使用分の繰越しや金銭での精算も、本人の規定に根拠があるかを確認します。年次休暇のような残数表示があっても、翌年へ自動的に足せると判断しないでください。対象期間内の取得と、次年度の扱いは別の確認事項です。

## 申請と給与の確認は担当ごとに整理する

人事院規則15-14第25条・第27条には、対象の請求を承認する枠組みと事前の請求等が定められています。希望日を共有したことと正式な承認は別です。本人の手順に従って休暇簿等へ記入し、変更時も連絡します。

有給の休暇でも、実績に応じる手当等の給与計算がすべて同じになるとは限りません。所属が案内する給与の扱いを確認します。横浜市の例では条例第2条が特別休暇を有給としていますが、別任用や別制度はその根拠で確認します。

| 申請前の確認 | 確認する相手 |
| --- | --- |
| 本人の対象と日数 | 人事・服務担当 |
| 週休日等の位置 | 勤務の割振り担当 |
| 分割や対象期間の例外 | 承認担当 |
| 給与・各手当 | 給与担当 |
| 業務の代理・期限 | 上司や担当チーム |

休暇中の連絡先は必要な範囲で共有し、常時の業務対応を約束する前提にしません。引継ぎや資料の所在は組織の方法で整理し、業務情報を私用端末へ持ち出して休みを補う形にはしないでください。

勤務条件全体の整理には[相談フォーム](../apply.html)も利用できます。ご利用は無料です（紹介手数料は採用企業の負担）。休暇の承認や個別の給与は所属へ確認してください。

:::insight
勤務先を比較する際は、夏季休暇が何日あるかだけでなく、年間の休日、年次休暇との関係、取得対象の時期、本人の勤務形態を同じ項目で並べることを勧めます。名称が同じでも、一斉に休む会社と本人が日程を申請する職場では、使い方が異なるためです。現職で予定を調整しながら働き続ける選択にも理があります。転職を検討する場合も、未使用の休暇を使い切ることだけを退職日の基準にせず、仕事の内容や次の勤務開始日、生活の予定を合わせて確認します。休暇の多寡を不安や応募の理由に変えるのではなく、本人に合う働き方を考えるための具体的な条件として扱う姿勢が大切だと考えます。
:::

日数を照会した際は、回答の対象となった年度と勤務条件も控えておきます。勤務日数や任用が変わった場合は、以前の回答がそのまま使えるかを確認してください。旅行等の予定と、承認済みの休暇期間を分けて保管しておくと、日程変更の際に確認する項目が分かります。

## よくある質問

### 国の夏季休暇は土日を含めた3日ですか

条文に掲げる週休日・休日等を除いて、原則連続する3日の範囲内です。本人の勤務表で、休暇として数える日を確認します。

### 夏季休暇は必ず分割できますか

国の運用は、特に必要と認められる場合の1暦日ごとの分割を示しています。本人の希望を所属へ伝え、承認と取得期間を確認してください。

### 自治体も国と同じ日数・期間ですか

同じとは限りません。横浜市の一般職の例は6月から9月の5日を基本とし、採用・勤務形態等の別の条件もあります。本人の規程で確認します。
