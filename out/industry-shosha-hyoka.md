商社を検討される公務員の方から、**遠慮がちにこう伺う**ことがあります。

**「私がやってきたのは、内部の事務です。民間の役に立つでしょうか」**

**立ちます。**しかも、**ご本人がいちばん軽く見ている部分**が評価されます。

**理由は、会社の側が何を義務づけられているかを見れば分かります。**この記事では、**法令上の仕組みから逆算して、どの経験が評価されるか**を扱います。

商社の機能の整理は[未経験から商社に入るには](industry-shosha-mikeiken.html)、選考の進み方は[商社の選考フローと、面接で見られている観点](industry-shosha-senko.html)にあります。

## 重要な決定は、一人に任せられない仕組みになっています

**会社法第362条第4項**です。

> **取締役会は、次に掲げる事項その他の重要な業務執行の決定を取締役に委任することができない。**
>
> **一　重要な財産の処分及び譲受け**
>
> **二　多額の借財**
>
> 三　支配人その他の重要な使用人の選任及び解任
>
> 四　支店その他の重要な組織の設置、変更及び廃止

**「委任することができない」**です。

**重要な財産の処分と取得、多額の借財は、取締役会が決めなければならない。**一人の判断で進めることが、**法律の段階で封じられています。**

**商社にとって、これは日常の話です。**

**商社が扱うのは、財産の売買と、その裏側の資金**です。**商法第552条第1項**のとおり、**問屋は「相手方に対して、自ら権利を取得し、義務を負う」**立場にあります。**自分の名前で義務を負うのですから、その決定は組織として行う必要があります。**

**結果として、商社の中には、決裁のための仕組みが厚く存在します。**

| 会社側の必要 | 社内での形 |
|---|---|
| 重要な財産の処分・譲受けの決定 | **稟議、審議の資料、会議体への付議** |
| 多額の借財の決定 | 資金の計画、与信の管理 |
| 決定の記録 | **議事録、決裁の記録** |
| 決定の前提の確認 | 与信の審査、輸出管理の該当性の確認 |
| 決定後の検証 | 実績の報告、内部監査 |

**右の列を見てください。****役所でやってきたことと、形が同じ**です。

## 評価される経験は、5つに整理できます

| 経験 | 商社での呼ばれ方 | なぜ評価されるか |
|---|---|---|
| ① 決裁・合議の事務 | 稟議、決裁の運用 | **重要な決定を組織で行う仕組みそのもの** |
| ② 審査・該当性の判断 | 与信の審査、輸出管理 | **要件に当てはめる訓練を受けている** |
| ③ 契約・入札の事務 | 契約の審査、購買の管理 | 条件を読んで詰める動作が同じ |
| ④ 記録と報告の整備 | 議事録、内部監査への対応 | **後から検証される前提の書類** |
| ⑤ 予算・出納・決算 | 経理、資金の管理 | 締切と精度が要る仕事 |

**①が、この業界では想像以上に評価されます。**

**役所の決裁の仕組みは、民間から見ると異様に整っています。**誰が、何を根拠に、どの段階で決めるか。**合議先はどこか。**専決の範囲はどこまでか。**これを毎日運用してきた人は、稟議の仕組みを設計・運用できます。**

**そして、商社は会社法上、重要な決定を組織で行わなければなりません。**つまり、**その仕組みが要る側**にいます。

**②も直結します。**[未経験から商社に入るには](industry-shosha-mikeiken.html)で触れた**輸出管理**は、**貨物が規制の区分に該当するかを確認する仕事**です。**許認可の審査と、動作が同じ**です。

**与信の審査も同様**です。**相手方の情報を集め、基準に当てはめ、限度を決める。**滞納整理や、補助金の交付の審査をしてきた方には、**見慣れた構造**です。

## 言い換えの表

**職務経歴書に、役所の言葉のまま書かないでください。**

| 役所での言い方 | 商社に伝わる言い方 |
|---|---|
| 起案・決裁 | **稟議の作成と、関係部署との合議の取りまとめ** |
| 合議 | 関係部門との事前の調整と、論点の整理 |
| 専決規程の運用 | **決裁の権限の区分にもとづく処理** |
| 支出負担行為の確認 | 発注の前の、予算と契約の条件の確認 |
| 許可・認可の審査 | **要件への該当性の判断と、記録の作成** |
| 立入検査 | 相手方の実態の確認と、是正の要求 |
| 滞納整理 | **債権の管理と回収、分割の条件の設定** |
| 入札の執行 | 調達の手続きの運用、業者の選定 |
| 決算統計の作成 | 年度の実績の取りまとめと前年度比較 |
| 監査の指摘への対応 | **内部統制上の指摘への対応と仕組みの改善** |

**右の列は、求人票の応募条件に出てくる言葉に近い**です。

**この置き換えをしないまま出すと、読む側が「何ができる人か」を判断できません。**

## 評価されにくい経験

**正直に書いておきます。**

| 経験 | 評価されにくい理由 |
|---|---|
| 特定の制度の細かい運用の知識 | **その制度を扱わない会社では使えない** |
| 庁内の根回しの経験 | 相手も組織の形も違う |
| 前例の踏襲を徹底した実績 | **前例の無い場面が多い** |
| 在籍年数そのもの | 年数より、何を担ったか |
| 役職の名称 | **対応する段階が会社側に無い** |

**「係長を◯年」という書き方は、この業界では効きません。**

**書くなら、「◯人の係の事務の進行を管理し、年間◯件を処理した」**です。**段階の名前ではなく、担った範囲と件数**で書いてください。

**それから、制度の細かい知識**です。**その制度を扱う会社なら強い材料**になりますが、**扱わない会社には響きません。**応募先によって、**前に出す経験を入れ替えてください。**

:::insight
面談で拝見していて、**商社を受ける方がいちばん取りこぼしているのが「与信」に当たる経験**です。皆さん、**滞納整理や債権の管理を、地味な仕事として職務経歴書の後ろに置かれます。**ところが、商社にとって**与信は事業の根幹**です。商法第552条のとおり、**問屋は自分の名前で義務を負います。**売った相手から代金が回収できなくても、**仕入れ先への支払いは自分が負う。**ですから、**取引先の信用をどう見るか、限度をどこに置くか、焦げ付いたときにどう回収するか**が、会社の損益に直結します。そして、**この仕事を業務として経験している人は、民間にもそう多くありません。**営業の側にいた人は「売る」経験はあっても、**回収できない相手とどう向き合うか**の経験が薄いことがある。一方、**税や保険料の滞納整理を担当した公務員は、そこを毎日やってきています。**相手の状況を聞き取り、資力を確認し、分割の条件を決め、履行されなければ次の手段に移る。**これは与信管理と回収の実務そのものです。**職務経歴書の前のほうに置いてください。**「滞納整理」という言葉ではなく、「債権の管理と回収」**と書けば、意味が通じます。
:::

## 職務経歴書での並べ方

| 位置 | 書くもの |
|---|---|
| 冒頭の要約（3〜4行） | **審査・契約・債権の管理のうち、担った機能** |
| 職歴の1つ目 | 直近の担当。**件数と規模を入れる** |
| 職歴の2つ目以降 | **応募先の分野に近いものを前へ** |
| 実績の欄 | **「変えた話」**（様式を作った、基準を整理した） |
| 資格・研修 | 簿記、法務、貿易に関する学習 |

**冒頭の要約を必ず付けてください。**商社の中途採用では、**配属先の部門長が書類を読みます。**読む時間は限られています。

**実績の欄は、「担当した」ではなく「何が変わったか」**で書いてください。**自分が来る前と、去ったあとで何が違うか。**様式を作った、判断の基準を整理した、前例の無い事案の処理の方針を決めた。

**⚠ 公表されていない内部の数字や、個別の相手方の事情は書かないでください。**守秘の観点に加えて、**それを書く人は、次の職場の情報も外で話す**と見られます。

[経験の言い換えから相談する](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担です）。

## 面接で聞かれやすいこと

| 聞かれること | 何を確かめられているか |
|---|---|
| 判断に迷う事案を、どう処理してきましたか | **判断の作り方** |
| 回収できない相手と、どう向き合いましたか | **与信・回収の実務の経験** |
| 決裁が通らなかったとき、どうしましたか | 組織の中での進め方 |
| 数字の責任について、どう考えていますか | **予算の執行と損益の違いの理解** |
| 会計や法務のソフトは使えますか | 道具への構え |

**2つ目は、滞納整理や債権の管理の経験がある方には、いちばん語れる質問**です。

**3つ目も、良い材料になります。**通らなかった理由を確認し、**論点を整理して出し直した**という話ができれば、**組織の中で物事を進められる人**として読まれます。

**5つ目は、正直に答えて構いません。**役所の財務会計システムは独特なので、**市販のソフトの経験が無い方がほとんど**です。**「仕組みは同じなので、操作は覚えます」**で足ります。

:::insight
ここまで「評価される」話をしてきましたが、**申し上げておきたいことがあります。**評価される経験があることと、**移ったほうがよいことは、別**です。面談で、**「思ったより評価されると分かったので、動かないといけない気がしてきました」**とおっしゃる方がいらっしゃいます。そうではありません。**この経験は、消えません。**審査を担った事実、債権の管理を担った事実、決裁の仕組みを運用した事実。**異動して別の分野に移っても、担った事実は残ります。**ですから、**いま動く理由が他にある場合**——通勤の事情、家族の事情、担いたい役割が変わった——**その理由で判断してください。**「評価されるから」は、**動く理由としては弱い**です。むしろ、**いまの職場で、その経験がさらに厚くなる見込みがあるなら、厚くしてから動くほうが選択肢は広がります。**とくに、**審査や債権の管理は、担当した規模と年数で評価が変わります。**係の担当として回していた方が、**取りまとめの側に立つ**と、書ける内容が一段変わる。**その段階が近いなら、待つ判断にも理があります。**評価されるという事実は、**動くと決めたときに使える材料**であって、**動く理由ではありません。**在職のまま、整理だけのご相談も承っています。
:::

## まとめ

- **評価される経験は、会社が負っている仕組みから逆算できます**
- **会社法第362条第4項**は、**重要な財産の処分及び譲受け**、**多額の借財**などの**重要な業務執行の決定を、取締役に委任することができない**と定めています
- **商法第552条第1項**のとおり、**問屋は相手方に対して自ら権利を取得し、義務を負います。**だから決定を組織で行う仕組みが要ります
- 評価される経験は、**①決裁・合議の事務 ②審査・該当性の判断 ③契約・入札の事務 ④記録と報告の整備 ⑤予算・出納・決算**の5つです
- **①の決裁の仕組みの運用**は、民間から見ると整っています。**稟議の仕組みが要る側に、商社はいます**
- **②は輸出管理・与信の審査に直結**します。許認可の審査と動作が同じです
- ⚠ **滞納整理・債権の管理の経験を、後ろに置かないでください。**商社では**与信は事業の根幹**です
- 職務経歴書は、**役所の言葉のままにしない**でください。**担った範囲と件数、そして「何が変わったか」**で書きます
- **評価されることと、移ったほうがよいことは別**です。動く理由は、別に必要です

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 技術職です。事務の経験がありませんが、評価されますか

**されます。**商社は物を扱うので、**品質の確認、規格への適合、設備や施設の管理**を分かる人が要ります。役所で**工事の発注と監督**をしていた方なら、**仕様書の作成、業者との協議、検査**の経験がそのまま使えます。**環境や廃棄物の許認可**を担当していた方は、**資源やリサイクルの分野**で規制の理解が効きます。探し方は、**会社が扱っている品目から見る**ことです。自分が検査や許認可で見てきた物と重なる会社があれば、**その分野の理解は、入ったあとに効きます。**なお、**技術職の方が会計や契約の経験の無さを気にされることが多い**のですが、**技術の側から入って、あとから覚える形で問題ありません。**

### 窓口や相談の業務しか経験がありません

**③の折衝と、④の記録の面で材料になります。**窓口の業務は、**相手の事情を聞き取り、制度に当てはめ、結論を伝え、記録に残す**という構造です。これは、**取引先とのやり取りと、同じ動作**です。とくに、**苦情や、制度の要件に当てはまらない相談に対応した経験**は、**説明の責任を負う場面の経験**として読まれます。書き方は、**件数と、難しい類型の処理**を入れてください。「年間◯件の相談に対応し、制度の要件に当てはまらない事案について、関係する制度を確認したうえで方針を整理した」。**判断の方針を自分で整理した、という部分が評価されます。**

### 簿記や貿易の資格を、先に取るべきですか

**先に取る必要はありません。**この業界の中途採用では、**実務の経験が先に見られます。**ただし、**学習を始めていること自体は、関心の本気度として伝わります。**とくに、**簿記**は、**予算の会計と企業の会計の違いを説明できるようになる**という点で実益があります。面接で「予算の管理と損益の管理は見る方向が逆だと理解しています」と言えるようになるのは、**この学習の副産物**です。貿易の実務や通関に関する学習も、**貿易の職種を志望するなら接点になります。**⚠ **試験の内容や難度は、実施する団体の公表を確認してください。**当社が確認していない情報は、この記事には載せていません。
