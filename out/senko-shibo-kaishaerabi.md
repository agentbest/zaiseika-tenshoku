求人を探し始めると、**候補が増えすぎて絞れなくなる**ことがあります。

在職中であれば、**同時に進められるのは3〜5社**です。**その枠に、どれを入れるか。**

この記事では、**絞るための4つの基準**を扱います。業界の選び方は[業界の選び方と、志望動機への落とし方](senko-shibo-gyokaierabi.html)にあります。

## 求人票には、条件が明示されます

**絞り込みの材料は、求人票にあります。**

**職業安定法第5条の3第1項**です。

> 公共職業安定所、特定地方公共団体及び職業紹介事業者、労働者の募集を行う者（中略）は、それぞれ、職業紹介、労働者の募集又は労働者供給に当たり、求職者（中略）に対し、**その者が従事すべき業務の内容及び賃金、労働時間その他の労働条件を明示しなければならない。**

**従事すべき業務の内容と、労働条件を明示しなければならない。**

つまり、**求人票に書かれている業務の内容と条件は、明示が義務づけられた情報**です。

**これを読まずに応募するのは、判断の材料を使っていないということ**になります。

**求人票は、絞り込みのために読んでください。**

## 4つの基準

| 順 | 基準 | 判断 |
|---|---|---|
| ① | **必須要件を満たすか** | 満たさなければ、応募しても通りません |
| ② | **仕事内容と経験が対応するか** | 3割以下なら見送る |
| ③ | **志望動機が書けるか** | 書けない求人は、入社後も使えない可能性 |
| ④ | **条件が許容できるか** | 勤務地、転勤、時間 |

**①から順に見てください。**

**①で外れる求人に時間を使わないこと**が、いちばん効率に効きます。

## ①——必須要件

| 記載 | 扱い |
|---|---|
| 「必須」「必要な経験」 | **満たさないと、書類では通りません** |
| 「歓迎」「あれば尚可」 | 無くても応募できます |
| 「◯年以上の経験」 | 実務の期間で数えます |
| 資格の指定 | 取得済みが前提の場合があります |

**判断に迷うのは、「法人営業の経験3年以上」のような書き方**です。

**自治体向けの事業であれば、行政側での折衝の経験が評価されることがあります。**

**迷ったら、人材会社の担当者に確認するか、応募して確かめてください。**

## ②——仕事内容との対応

**求人票の「仕事内容」を1行ずつ読み、自分の経験が対応するかを見ます。**

| 対応の度合い | 判断 |
|---|---|
| 7割以上 | **応募する。**志望動機も書きやすい |
| 半分程度 | 書き方次第。**関係する経験を前に出す** |
| 3割以下 | **見送る。**書類の段階で通りにくい |

**3割以下の求人に10社応募するより、7割の求人を3社探すほうが、結果が早く出ます。**

## ③——志望動機が書けるか

**これが、この記事の主題です。**

**応募する前に、志望動機の②（経験との接点）を3行書いてみてください。**

| 結果 | 判断 |
|---|---|
| すらすら書ける | **応募する価値がある** |
| 書けるが、抽象的になる | 求人票をもう一度読む |
| 何も浮かばない | **見送る** |

**3行が書けない求人は、入社後に自分の経験が使えない可能性が高い**です。

**この確認に、5分もかかりません。**

**そして、書けた3行は、そのまま志望動機の材料**になります。**無駄になりません。**

## ④——条件

| 項目 | 確認する場所 |
|---|---|
| 勤務地 | 求人票の勤務地の欄 |
| 転勤 | 「転勤の有無」「就業の場所の変更の範囲」 |
| 勤務の時間 | 所定の時間、時間外の扱い |
| 処遇 | 想定される範囲の記載 |
| 雇用の形態 | 期間の定めの有無 |

**条件で外れる求人は、応募の前に除いてください。**

**選考が最終まで進んでから条件が合わないと分かるのが、いちばん時間を失います。**

:::insight
応募先を絞るときに、**面談でお伝えしている基準が「3行テスト」**です。応募を検討している求人について、**志望動機の②を3行書いてみる。**書けたら応募、書けなければ見送る。**この基準の良いところは、5分で判断できること**です。在職中で時間が限られている方ほど、**応募の前の5分**が効きます。そして、**書けなかった求人を無理に応募しない**ことで、**準備の質が保てます。**面談で拝見していると、**応募の数を増やそうとして、1社あたりの準備が薄くなっている**方がいらっしゃいます。結果として、**どれも通らない**という状態になります。**3行書ける求人だけに絞れば、応募の数は減りますが、1社あたりの準備は厚くなります。**通過する割合は、そちらのほうが高くなります。**絞ることは、機会を減らすことではありません。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 求人票で見落としやすい欄

| 欄 | 見るべき理由 |
|---|---|
| 募集の背景 | **増員か後任か。**事業の状況が分かる |
| 配属先 | 部署の名前と人数。**組織の中の位置** |
| 選考の流れ | **画面越しの面接があるか。**在職中は重要 |
| 就業の場所の変更の範囲 | 入社後に変わり得る範囲 |
| 試用の期間 | 期間と、その間の条件 |

**3つ目は、在職中の方にとって実務的な情報**です。

**選考がすべて対面であれば、休暇が複数回必要になります。**

**画面越しの面接が含まれていれば、負担が大きく変わります。**

## 応募しない求人の扱い

**見送った求人も、記録に残しておいてください。**

| 記録すること | 後でどう使うか |
|---|---|
| 会社名と職種 | **再募集のときに、判断をやり直せる** |
| 見送った理由 | 自分の基準が一貫しているか確認できる |
| 日付 | 募集の時期の傾向が分かる |

**2つ目が、意外に効きます。**見送った理由を並べると、**自分が何を重く見ているか**が見えてきます。

「勤務地で見送った」が続くなら、**条件の絞り方が生活と合っていない**のかもしれません。「志望動機が書けなくて見送った」が続くなら、**探している業界が自分の機能と合っていない**可能性があります。

**見送りの記録は、探し方を見直す材料**になります。

**また、同じ会社が別のポジションで募集することがあります。**そのときに、**前回の判断を思い出せる**と、検討が早く済みます。

## 絞った後にやること

| 順 | やること |
|---|---|
| 1 | 求人票を印刷するか、保存する |
| 2 | **志望動機の①と③**を足して、300〜400字にする |
| 3 | 職務経歴書の**要約欄と順番**を、その求人に合わせる |
| 4 | 応募する |

**3つ目は、15分から30分**で済みます。

**書類を全文書き直す必要はありません。**

[経験の言い換えから相談する](../apply.html)こともできます。

**この記録は、表計算の数行で足ります。**会社名、職種、日付、判断、理由。**応募した求人と同じ表に、見送りの行として残しておくと管理が楽になります。**

## よくある失敗

**1. 必須要件を確認せずに応募する**

**書き方では通りません。**

**2. 対応の度合いが低い求人に応募し続ける**

**3割以下なら見送る**ほうが早いです。

**3. 志望動機を書かずに応募する**

**5分の確認**で判断できます。

**4. 条件を後回しにする**

**最終まで進んでから外れる**のが、いちばん時間を失います。

**5. 応募の数を増やして、準備を薄くする**

**通過する割合が下がります。**

**6. 選考の流れを確認しない**

**在職中は、休暇の回数が変わります。**

:::insight
ここまで絞り方の話をしておいて逆のことを言いますが、**基準を厳しくしすぎて、候補がゼロになるのも困ります。**面談で拝見していると、**7割の対応、条件も完全に合致、志望動機もすらすら書ける**という求人を探し続けて、**半年動けていない**という方がいらっしゃいます。**すべてが揃う求人は、多くありません。**現実的な線としては、**①の必須要件を満たし、③の3行が書ける**なら、**②が半分程度でも応募してよい**と考えています。②は、**書き方で補える部分**があるからです。逆に、**①と③が満たせない求人は、書き方では補えません。**優先順位をつけるなら、**①と③が必須、②と④は調整の余地あり**という見方になります。**完璧な求人を待つより、条件を満たす求人に確実に応募する**ほうが、結果は早く出ます。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **職業安定法第5条の3第1項**は、**従事すべき業務の内容と労働条件の明示**を求めています。**求人票は、絞り込みの材料**です
- 基準は、**①必須要件 ②仕事内容との対応 ③志望動機が書けるか ④条件**の4つ。**①から見て**ください
- **②が3割以下なら見送る。**10社応募するより、7割の求人を3社探すほうが早いです
- **③は「3行テスト」。**志望動機の②を3行書いてみて、書けなければ見送ります
- **書けた3行は、そのまま志望動機の材料**になります。無駄になりません
- **①と③は必須、②と④は調整の余地あり**。完璧な求人を待たないでください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 求人票の情報が少なく、判断できません

**記載が少ない求人もあります。**その場合、**公式サイトで事業の内容を確認**してください。それでも分からなければ、**人材会社の担当者に確認**できます。担当者は、**求人票に書かれていない情報（配属先の雰囲気、前任者の状況、選考の進め方）を持っていることがあります。**直接応募の場合は、**応募の前に問い合わせても差し支えありません。**「配属予定の部署の体制について伺えますか」という形です。**問い合わせたこと自体が不利になることは、ほとんどありません。**

### 3行テストで書けたのに、書類で落ちました

**③が満たせても、①と②で外れている可能性があります。**もう一度、**必須要件と仕事内容との対応**を確認してください。とくに、**「◯年以上の経験」の年数**を満たしているか。**志望動機が書けることと、経験が要件に合うことは別**です。また、**同じ求人に、より近い経験の応募者がいた**という場合もあります。この場合は、こちらで対処できません。**3社から5社の傾向**を見て判断してください。切り分けの手順は[書類選考で落ちるときに見直す点](senko-mensetsu-shorui.html)に整理しています。

### 同時に何社まで応募してよいですか

**在職中であれば、3〜5社**が現実的です。理由は、**面接の日程の調整と、応募先ごとの準備**が追いつかなくなるためです。とくに、**志望動機の①と③は応募先ごとに変わる**ため、社数が増えるほど準備の時間が必要になります。ただし、**1社ずつ結果を待つ必要はありません。**並行して進めるのが通常です。**選考の段階がばらけると、面接の準備も分散します。**目安としては、**1社が最終に進んだら、新規の応募を一時的に止める**という進め方もあります。日程の組み方は[平日日中の面接をどう調整するか](senko-mensetsu-jikan.html)にあります。
