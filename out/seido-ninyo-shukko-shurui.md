「出向」と説明されても、それだけでは本人の身分、給与、復帰の条件は分かりません。公務の派遣や人事交流、研修、転任と、民間企業の在籍出向・転籍は、根拠の異なる制度です。

まず辞令や説明資料にある正式な制度名と根拠を確認します。「元の職場へ戻る予定がある」という説明だけで、在籍が続くのか、退職を伴うのかを決めないことが大切です。本記事は2026年11月時点の公開情報にもとづきます。

## 出向の通称より根拠制度と通知を確認する

日常の呼び名が同じでも、本人に適用される取扱いは異なります。最初に次の違いを整理します。

| 制度・呼び名 | 確認の出発点 |
| --- | --- |
| 民間の在籍出向 | 元の企業との雇用関係を残し、別企業で働く条件 |
| 民間の転籍・移籍出向 | 元の雇用関係の終了と、新しい企業との契約 |
| 国の官民人事交流の交流派遣 | 官民人事交流法に基づく身分保持と企業での雇用 |
| 地方の公益的法人等への職員派遣 | 派遣法、条例、派遣先との取決め |
| 地方公共団体間の職員派遣 | 地方自治法などの根拠と双方の身分・費用負担 |
| 研修派遣、併任、転任等 | 研修命令や任用通知に示された根拠と職務 |

派遣先が民間企業だから必ず転籍、他の自治体だから必ず在籍のまま、といった判断はできません。地方公務員法第15条の2の転任の定義と、別の法人で働く派遣制度の要件も区別します。

国と地方の交流、自治体間の交流なども、名称から一つの仕組みに決めず、退職・採用、併任、派遣等のどれを使うかを通知で確認してください。一般的な制度一覧だけでは、本人の手続きは確定しません。

## 民間の在籍出向と転籍は雇用関係が異なる

民間の在籍出向は、元の企業との雇用関係を維持しながら、出向先でも雇用関係の下で業務に従事する仕組みです。賃金の支払方法、勤務時間、休暇、出向期間、復帰などの条件を確認します。

厚生労働省の労働契約ポータルサイトでは、在籍出向について、本人の個別同意又は労働者の利益に配慮して整備された就業規則等の根拠を説明しています。毎回必ず個別の同意が必要と一律に説明するものではありません。労働契約法第14条は、出向を命じることができる場合でも、権利を濫用した命令は無効とする規定です。

転籍は、元の企業との雇用関係を終了し、新しい企業との雇用関係へ移るものです。同省の説明では、本人の合意が必要とされています。「グループ会社だから元の会社へいつでも戻れる」とは考えず、契約と合意の内容を確認します。

ただし、労働契約法第21条は国家公務員・地方公務員を適用除外としています。ここでの民間労働契約の説明を、そのまま公務員の任用や派遣の同意要件へ流用することはできません。公務では、利用する法律・条例等に同意や明示の定めがあるかを確認します。

## 国の官民人事交流では身分を保持して企業で働く

国の官民人事交流の交流派遣は、国家公務員の身分を保持しつつ、派遣先企業の従業員として働く制度です。官民人事交流法第7条では、本人の同意、人事院による計画の認定、任命権者と企業との取決めなどを定めています。同法第9条に基づき、本人は取決めに沿って企業と労働契約を結びます。

期間は同法第8条により原則三年以内で、所定の同意・承認等を経た延長は、派遣開始から引き続き五年を超えない範囲です。満了時の職務復帰は同法第13条に定められています。元の担当や席へ必ず戻るという意味とは分けて確認します。

給与は派遣先企業から支給され、府省等からは支給されません。公務の職務と企業の業務を同時に自由に行う制度でもありません。派遣前の機関に対する業務や影響力の利用など、特有の制限もあります。

医療保険と年金等の取扱いも一括して判断しないでください。同法第14条には共済の短期給付等に関する特例があり、人事院のFAQでも派遣先の制度が適用される範囲と年金等を区別しています。「国家公務員の身分があるから医療もすべて従前どおり」とは言えません。本人と家族の手続きは、共済組合と派遣先の担当に確認します。

## 地方の公益的法人派遣と退職派遣は別の仕組み

公益的法人等への一般職の地方公務員の派遣等に関する法律第2条は、条例で定める団体への職員派遣を規定しています。任命権者は、派遣先との取決めの内容を本人に明示し、同意を得る必要があります。取決めには報酬、勤務条件、業務、期間、復帰などを定めます。

同法第3条では原則三年以内、必要な同意等を経た延長は通算して五年以内です。同法第5条には職務復帰の定めがあります。給与は同法第6条で原則不支給ですが、一定の業務について条例に基づき支給できる例外があります。派遣先で働く地方公務員は全員自治体から給与が出る、又は全員出ないとは説明できません。

同法第7条には、引き続き元の共済組合の組合員とする特例があります。国の官民交流の取扱いを、そのまま地方のこの派遣へ当てはめないことが重要です。

一方、同法第10条には、自治体が出資する特定法人で働くため、要請に応じて退職し、その後の採用につながる「退職派遣者」の仕組みもあります。こちらは、職員として在籍したままの派遣と同じではありません。法律、条例、取決めにある要件を確認し、「退職という文字があるが実質は同じ」と自己判断しないでください。

:::insight
出向の説明を受けたときは、行き先の知名度や仕事内容より先に、本人の法的な位置付けを確認することを勧めます。在籍が続くか、誰と契約を結ぶか、どの制度から給与が出るかが違えば、必要な手続きも変わります。復帰の予定があることと、元の身分を保持することも同じではありません。制度名、根拠、通知日、期間、復帰条件を一枚の確認表に整理すると、説明のどこが未確認かが見えます。分からない点を口頭の印象で補わず、担当に資料を示して尋ねることが大切です。他の職員が経験した出向が似ていても、同じ法律や取決めによるものかは別です。本人の条件を確かめる手順から始めれば、勤務先の変化を落ち着いて検討できます。
:::

## 自治体間派遣と研修も通知の根拠を読む

地方自治法第252条の17の職員派遣では、派遣先の普通地方公共団体の職員の身分も併せて持ちます。給料・手当・旅費などと、退職手当等の費用負担について、それぞれ定めがあります。これは同条に基づく派遣の説明で、国との交流やすべての公的機関への派遣に共通する説明ではありません。

研修の場合は、地方公務員法第39条の研修制度や、所属の研修計画・命令を確認します。別の機関で実務を経験していても、研修としての勤務なのか、その機関の職員にも任命されるのかは、場所だけでは分かりません。勤務時間、服務、費用、事故時の対応、報告先をそれぞれ確認します。

併任という説明を受けた場合も、兼ねる職、元の職、指揮命令、期間を確認してください。通称として出向と呼ばれていることだけを根拠に、別の制度の手続きを省くことはできません。

## 給与・退職手当・年金は確認先を分ける

派遣期間が退職手当の勤続期間や年金記録にどう反映されるかは、制度と本人の条件によります。「すべて全期間通算される」「すべて途切れる」のどちらにも一律には言えません。

| 確認事項 | 主な相談先と資料 |
| --- | --- |
| 身分、任命、復帰 | 元の人事担当、辞令、派遣根拠、取決め |
| 給与、賞与、費用負担 | 双方の給与担当、労働条件、条例等 |
| 勤務時間、休暇、服務 | 派遣制度の担当、派遣先の規程と取決め |
| 医療保険、家族資格、掛金 | 共済組合、派遣先の保険担当 |
| 年金記録、退職等年金給付 | 共済組合など本人の実施機関 |
| 退職手当、勤続期間、精算 | 本人の退職手当を扱う担当 |

例えば給与の説明を受けても、それだけで医療保険の切替や退職手当の扱いまで確認できたことにはなりません。未確認事項を区分し、開始前と終了時の届出、貸付・団体契約などへの影響も必要に応じて確認します。

:::insight
現職の制度を使って別の組織を経験することと、自ら退職して転職することでは、期間や復帰、身分の条件が異なります。どちらが本人に合うかは、経験したい仕事と必要な条件を整理して比べる必要があります。公務内の異動や研修で希望する経験を積めるなら、その制度を先に確かめる判断にも理があります。外部の求人を見る場合も、出向先と転職先を同じ条件だと想定せず、雇用する主体、期間、役割、復帰の有無を確認してください。制度の説明を受けただけで退職を決める必要はありません。現職を続ける、制度利用を相談する、外部の条件を情報収集するという選択肢を、本人が確認できた事実と希望に沿って考えることが大切です。
:::

外部の仕事も調べたい場合は[公務員経験の整理に関する案内](../?gov=1)を参照できます。派遣や研修を優先して検討しても構いません。

## よくある質問

### 出向と言われたら元の職員の身分は残りますか？

通称だけでは決まりません。在籍のままの派遣か、退職・採用を伴う制度か、併任や転任かを正式な通知と根拠で確認します。復帰の条件も別に確認してください。

### 本人の同意がなければ公務の出向はできませんか？

制度ごとに確認します。国の官民交流派遣や地方の公益的法人派遣には同意の規定がありますが、これをすべての任用に一般化できません。民間労働契約の説明も公務へそのまま適用しないでください。

### 元の共済や退職手当の扱いは変わりませんか？

制度によって異なります。身分を保持する場合でも医療保険と年金等の扱いが同一とは限りません。取決めと根拠を示し、共済組合・給与・退職手当担当へ個別に確認します。

## 制度名と本人の条件を確認してから判断する

辞令、派遣の根拠、勤務条件、復帰条件を確認し、分からない項目は双方の担当へ照会します。業務情報や内部資料は組織のルールに沿って引き継ぎ、私的に持ち出さないでください。
