**福祉の分野で働いてきた方から、「資格をどう使えばよいか」**というご相談を伺います。

**相談援助を業とする資格は、扱いに特徴があります。**

この記事では、**その特徴**と、**経験の示し方**を扱います。

**⚠ 登録・資格の要件と手続は、所管するところの公表を確認してください。****この記事では個別の要件には触れません。**

## 相談援助が、定義に書かれています

**社会福祉士及び介護福祉士法第2条第1項**です。

> **この法律において「社会福祉士」とは、第二十八条の登録を受け、社会福祉士の名称を用いて、専門的知識及び技術をもつて、身体上若しくは精神上の障害があること又は環境上の理由により日常生活を営むのに支障がある者の福祉に関する相談に応じ、助言、指導、福祉サービスを提供する者又は医師その他の保健医療サービスを提供する者その他の関係者**（略）**との連絡及び調整その他の援助を行うこと**（略）**を業とする者をいう。**

**「相談に応じ、助言、指導」**に加えて、**「関係者との連絡及び調整」**が定義に含まれています。

**つまり、相談を受けるだけでなく、関係する機関をつなぐことまでが業の内容**です。

**行政の福祉の担当がしてきた動作と、そのまま重なります。**

**なお、介護支援専門員（ケアマネジャー）については、介護保険の制度に基づく資格**です。

**要件と手続は、所管するところの公表を確認**してください。

## 資格の扱いを3つに分ける

| 扱い | 内容 |
|---|---|
| ① 資格が必須 | **配置が求められる職** |
| ② 資格が評価される | 必須ではないが、経験として読まれる |
| ③ 資格の知識が活きる | 資格は問われないが、理解が役立つ |

**①だけを探すと、候補が限られます。**

**②と③にも広げてください。**

**③について。**

**制度を支える側の仕事**——システム、教材、調査、自治体を相手とする事業——では、**資格は問われなくても、制度の理解が前提**になります。

## 行政での経験の特徴

| 特徴 | 内容 |
|---|---|
| ① 制度の運用 | **要件の確認、決定、通知** |
| ② 複数の制度をまたぐ | 生活、障害、高齢、児童 |
| ③ 関係機関との連携 | 医療、福祉、教育、警察 |
| ④ 困難な事案の調整 | 関係者が多い事案 |
| ⑤ 記録と根拠 | 判断の経緯を残す |
| ⑥ 計画・統計 | 事業の計画、実績の集計 |

**②が、民間から見て希少**です。

**1つの分野の事業者では、他の制度の仕組みまでは見えません。**

**行政の担当は、制度をまたいで対象者を見る立場**にあります。

**④について。**

**関係者が多く、調整が必要な事案**を扱った経験は、**相談の職務で直接評価されます。**

## 使える領域

| 領域 | 扱い |
|---|---|
| ① 相談の窓口の事業 | **①②** |
| ② 介護・障害の事業所 | ①② |
| ③ 医療機関の相談の部門 | ①② |
| ④ 地域包括に関する事業 | ①② |
| ⑤ 自治体が相手の事業 | **③制度の理解** |
| ⑥ 福祉に関するシステム・教材 | ③ |

**⑤と⑥が見落とされやすい**です。

**自治体の福祉の事務を受託する会社、システムを提供する会社**があります。

**制度の運用を知っている人**が、そこで必要とされます。

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 書き方の例

**悪い例**

> 福祉の部署で、相談業務を担当しました。

**良い例**

> **資格：社会福祉士（登録◯年）**
> ◯◯課において、**◯◯に関する相談を年間約◯件担当。**要件の確認から決定、通知までを実施。**関係機関（医療機関、事業所、学校等◯者）との会議を運営し、支援の方針を整理。****困難な事案◯件について、経緯を記録し、対応の方針を作成。**制度改正に伴い、**要綱と説明の資料を改正。**

**「件数」「工程」「連携」「記録」「制度の事務」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

:::insight
福祉の分野のご相談で、**面談でお伝えしているのが「決定する側にいた経験を書いてください」**という点です。民間の事業所では、**サービスを提供する立場**が中心になります。一方、**行政の担当は、要件を確認し、可否を決定する立場**です。**この違いが、そのまま価値になります。**受託や、自治体を相手とする事業では、**「行政がどの基準で判断するか」を知っている人**が必要とされます。どの資料を求められるか、どこで差し戻されるか、どういう記録が残るか。**これは、決定する側にいないと分かりません。**さらに、**制度をまたいで見てきた経験**も希少です。1つの制度の事業者からは、他の制度の仕組みが見えにくい。**書類には、「要件の確認から決定、通知まで」と工程を明記してください。**「相談業務」では、この立場が伝わりません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 取る前・使う前に考えること

| 確認すること | 内容 |
|---|---|
| ① 登録の状況 | **有効かどうか、氏名の変更** |
| ② 応募したい求人の条件 | 必須か、歓迎か |
| ③ 働き方の条件 | 時間、日数、夜間、訪問 |
| ④ 分野 | 高齢、障害、児童、生活 |
| ⑤ 期限 | 応募の時期までに間に合うか |

**③を先に決めてください。**

**相談の職務でも、訪問を伴うもの**と、**窓口や電話が中心のもの**があります。

**勤務の形が大きく変わります。**

**④について。**

**同じ資格でも、分野によって求められる知識が違います。**

**担当してきた分野に近い求人から見る**ほうが、説明がしやすくなります。

**そのうえで、隣接する分野に広げてください。**

**なお、資格を取れば転職できる、という関係にはありません。**

**どの制度を、どの立場で運用してきたか**が、評価の対象です。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 担当した制度と件数 | **分野、年間の件数** |
| 決定に関わった範囲 | 要件の確認、起案 |
| 連携の経験 | 相手と、進め方 |
| 困難な事案 | 3件、経緯と結論 |
| 記録の残し方 | 何を、どう残したか |

**4行目です。**

**なお、特定の対象者が分かる説明は避けてください。**

**守秘の義務は、資格を離れた後も続きます。**

[経験の言い換えから相談する](../apply.html)こともできます。

## よくある失敗

**1. 「相談業務」とだけ書く**

**決定する側にいた**ことを書いてください。

**2. 件数を書かない**

**規模**が伝わりません。

**3. 連携した機関の数を書かない**

**範囲**が伝わりません。

**4. 制度の事務を書かない**

**要綱、様式、説明の資料**は成果物です。

**5. 複数の制度をまたいだ経験を書かない**

**民間から見て希少**です。

**6. ①の領域だけを探す**

**②③にも広げて**ください。

**7. 働き方の条件を決めない**

**訪問の有無**で大きく変わります。

**8. 資格を取れば進めると考える**

**どの立場で運用したか**が評価の対象です。

:::insight
ここまで資格の話をしておいて逆のことを言いますが、**この分野では、勤務の条件を先に確認してください。**面談で拝見していると、**業務の内容だけで判断して、条件を後回しにする方**がいらっしゃいます。ところが、**相談の職務は、事業所によって勤務の形が大きく違います。**訪問が中心か、窓口が中心か。夜間や休日の対応があるか。担当する件数はどの程度か。移動の範囲はどこまでか。**同じ「相談員」という職種名でも、実態がまったく違います。**そして、**条件が合わないと、内容が合っていても続きません。**ですから、**求人票の勤務時間、休日、勤務地の欄を先に読んで**ください。そのうえで、**面接で「一日の流れ」と「担当する件数の目安」を確認**してください。**具体が分かれば、判断ができます。**業務への関心と、続けられる条件は、分けて考えてください。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **社会福祉士及び介護福祉士法第2条第1項**は、**登録を受け、名称を用いて、相談に応じ、助言、指導、関係者との連絡及び調整その他の援助を行うことを業とする者**と定義しています
- **関係者との連絡及び調整までが、業の内容**に含まれています
- **介護支援専門員は、介護保険の制度に基づく資格**です。要件は所管の公表を確認してください
- 資格の扱いは、**①必須 ②評価される ③知識が活きる**の3つです。**①だけを探さないでください**
- 行政での経験で希少なのは、**制度をまたいで見てきたこと**と、**決定する側にいたこと**です
- **「相談業務」ではなく、「要件の確認から決定、通知まで」**と工程を書いてください
- **勤務の条件を先に確認**してください。同じ職種名でも実態が違います

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 資格を持っていませんが、福祉の分野に移れますか

**求人の条件によります。**配置が求められる職では、**資格が必須**となります。一方、**相談の補助、事務、制度の運用の支援、自治体を相手とする事業**では、**資格が問われないことがあります。**この場合、**制度の運用の経験が評価される**ことがあります。判断の目安は、**求人票の「必須」の欄**です。なお、**在職中に資格の取得を目指す**という選択もあります。**受験の要件は、実務の経験の年数と内容で定められていることがある**ため、**所管するところの公表を確認**してください。

### 事業所の経験がないと、現場では通じませんか

**制度を運用してきた経験は、現場でも使えます。**要件の確認、記録の作成、関係機関との連携、家族への説明。**これらは、立場が変わっても同じ動作**です。違うのは、**サービスを提供する側になる**という点です。日々の支援の実務は、入社後に覚える部分があります。**面接では、この区別を示してください。**「制度の運用と連携の経験がある。日々の支援の実務は、入社後に身につけたい」。**分かっている部分と、これから覚える部分を整理できていると、準備ができている人として読まれます。**

### 行政の福祉と、民間の福祉では何が違いますか

**立場と、扱う範囲が違います。**行政は、**要件を確認し、可否を決定する立場**です。民間の事業所は、**決定を受けてサービスを提供する立場**が中心になります。また、**行政は制度をまたいで対象者を見る**のに対し、**事業所は担当する制度の範囲が中心**になります。この違いは、**弱みではなく、視点の違い**です。**受託や、自治体を相手とする事業では、行政の側の視点が求められます。**扱いは[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)に整理しています。**どちらの立場で働きたいかを、先に決めてください。**
