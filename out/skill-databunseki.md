**統計や指標を扱ってきた方から、「データ分析の職種に移れるか」**というご相談を伺います。

**すでに身についている部分と、足すべき部分を分けて**ください。

この記事では、**その線引き**を扱います。

## 公的統計には、基本理念が定められています

**統計法第3条**です。

> **公的統計は、行政機関等における相互の協力及び適切な役割分担の下に、体系的に整備されなければならない。**
>
> ２ **公的統計は、適切かつ合理的な方法により、かつ、中立性及び信頼性が確保されるように作成されなければならない。**
>
> ３ **公的統計は、広く国民が容易に入手し、効果的に利用できるものとして提供されなければならない。**
>
> ４ **公的統計の作成に用いられた個人又は法人その他の団体に関する秘密は、保護されなければならない。**

**方法の合理性、中立性と信頼性、利用しやすさ、秘密の保護。**

**この4つが、条文として置かれています。**

**行政で数字を扱ってきた方は、この規律を前提にしてきた**ということです。

**そして、この前提は、民間でも必要とされます。**

**都合のよい切り取りをしない、出典を示す、個人が特定される形で出さない。**

**これらは、分析の技術より前の部分**です。

## すでに身についていること

| 要素 | 内容 |
|---|---|
| ① 出典の確認 | **どの統計の、いつの数字か** |
| ② 定義の確認 | 何を数えたものか |
| ③ 経年の比較 | 前年、5年前との比較 |
| ④ 他団体との比較 | 同規模の団体との比較 |
| ⑤ 秘密の保護 | 個人が特定される形で出さない |
| ⑥ 説明の作法 | 数字の意味を言葉で説明する |

**②が、実務では最も重要**です。

**同じ「世帯数」でも、定義が違えば比べられません。**

**この確認の習慣は、民間の分析でも必要とされます。**

**集計の対象が違うまま比べて、誤った結論を出す。**

**この事故は、どの組織でも起きています。**

## 足すべき範囲

| 要素 | 内容 |
|---|---|
| ① 仮説を立てる | **何を確かめたいのか** |
| ② 加工する | 集計、結合、整形 |
| ③ 可視化する | 見て分かる形にする |
| ④ 基本的な統計の考え方 | 平均と中央値、ばらつき、相関 |
| ⑤ ツール | 表計算、データベース、分析の環境 |
| ⑥ 伝える | 意思決定につなげる |

**①が起点**です。

**行政の統計は、「現状を正確に示す」ことが中心**になります。

**分析の職種では、「何を確かめ、何を決めるか」から入ります。**

**この順序の違いを理解しておいてください。**

**④について。**

**平均だけで語らない、ばらつきを見る、相関と因果を分ける。**

**この3点を押さえるだけでも、読み方が変わります。**

## どこまで学ぶか

| 目的 | 必要な範囲 |
|---|---|
| 会社を見る・数字を読む | **①〜④の考え方で足ります** |
| 業務で集計を担う | ⑤のツールが必要 |
| 分析を職種とする | ①〜⑥を体系的に |

**2行目と3行目を分けてください。**

**「データ分析」という言葉が指す範囲は、求人によって大きく違います。**

**集計と報告が中心の求人**と、**仮説の設計から担う求人**では、求められるものが違います。

**求人票の仕事内容の欄で確認**してください。

**読み方は**[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)**に整理しています。**

## 書き方の例

**悪い例**

> 統計の作成と、データの分析を担当しました。

**良い例**

> ◯◯に関する統計の作成を担当。**年間約◯件のデータについて、定義を確認のうえ集計し、経年と他団体との比較を実施。****◯◯の傾向を把握し、翌年度の事業の対象の設定に反映。**公表にあたり、**個人が特定されない形に整理したうえで、数値の意味を説明する資料を作成。**

**「件数」「確認」「比較」「反映」「公表の配慮」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

:::insight
データの扱いについて、**面談でお伝えしているのが「定義を確認する習慣を書いてください」**という点です。**「分析の経験」と書かれても、どの水準か分かりません。**一方、**「集計の定義を確認したうえで比較した」**と書かれていると、**実務が分かっている人**として読まれます。そして、**この習慣は、民間でも不足していることがあります。**別の部署が作った数字を、定義を確かめずに比べる。集計の期間がずれたまま推移を見る。**その結果、誤った結論で施策を決めてしまう。**行政では、**統計法の規律や、公表に伴う説明責任があるため、この確認が習慣になっています。**書類には、**「定義と対象の範囲を確認したうえで比較」**と書いてください。**技術の水準より、扱い方の確かさが先に見られる**場面があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| どの数字を扱ったか | **統計の種類、件数** |
| 定義の確認の仕方 | 何を確かめたか |
| 比較の方法 | 経年、他団体 |
| 施策への反映 | 数字から何を決めたか |
| 使えるツール | 表計算、データベース |

**4行目です。**

**「数字を見て、何を決めたか」**を用意しておいてください。

**集計しただけでは、分析の経験として読まれにくい**ことがあります。

**なお、特定の対象者が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

## 学ぶ前に考えること

| 確認すること | 内容 |
|---|---|
| ① すでにある経験 | **統計の作成、比較、公表** |
| ② 目的 | 読むためか、業務で担うためか |
| ③ 応募したい求人の範囲 | 集計中心か、設計から担うか |
| ④ 期限 | 応募の時期までに間に合うか |

**②で必要な範囲が変わります。**

**なお、資格や講座を取れば転職できる、という関係にはありません。**

## よくある失敗

**1. 「分析の経験」とだけ書く**

**どの水準か**が伝わりません。

**2. 定義の確認を書かない**

**実務が分かっている証明**になります。

**3. 何を決めたかを書かない**

**集計だけでは読まれにくい**です。

**4. 求人の範囲を確認しない**

**集計中心か、設計からか**で違います。

**5. 平均だけで語る**

**ばらつき**も見てください。

**6. 相関と因果を混ぜる**

**分けて説明**してください。

**7. 公表の配慮に触れない**

**秘密の保護**は条文に置かれています。

**8. 講座を受ければ進めると考える**

**どう扱い何を決めたか**が評価の対象です。

:::insight
ここまで技術の話をしておいて逆のことを言いますが、**行政の数字の扱いには、民間にない強みがあります。それは「出せない数字が分かること」です。**面談で拝見していると、**この点を当たり前だと思っている方**がいらっしゃいます。ところが、**統計法第3条第4項は、作成に用いられた個人や法人の秘密の保護を定めています。**そして、行政では、**公表の可否、集計の単位、対象が特定される危険**を日常的に判断してきたはずです。**「この区分で出すと、対象が1件になるので出せない」**という判断です。**民間でも、同じ問題が起きます。**顧客の情報、取引先の情報、従業員の情報。**扱いを誤ると、信用に直結します。**ですから、書類には、**「公表にあたり、対象が特定されない形に整理」**と書いてください。**出せる数字を作る技術と、出せない数字を見分ける判断は、両方が必要**です。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **統計法第3条**は、**体系的な整備、適切かつ合理的な方法と中立性・信頼性、容易な入手と効果的な利用、秘密の保護**を基本理念としています
- 行政で身についているのは、**出典の確認、定義の確認、経年と他団体の比較、秘密の保護、説明の作法**です
- 足すのは、**仮説、加工、可視化、基本的な統計の考え方、ツール、伝えること**です
- **「データ分析」が指す範囲は求人によって違います。**仕事内容の欄で確認してください
- **定義を確認する習慣**を書いてください。実務が分かっている証明になります
- **数字を見て何を決めたか**を書いてください
- **出せない数字を見分ける判断**は、民間でも必要とされます

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 表計算しか使ったことがありません

**求人の範囲によります。**集計と報告が中心の業務であれば、**表計算の実務で足りる**ことがあります。一方、**大量のデータを扱う業務**では、データベースや分析の環境の操作が要件になることがあります。判断の目安は、**求人票の応募条件**です。「表計算の実務経験」と書かれていれば該当します。なお、**使えるツールは、正確に書いて**ください。**できないことを書くと、入社後に困ります。**「表計算で、関数と集計の機能を用いた集計・分析の経験あり」という形で、**範囲を明示**してください。

### 統計の専門的な知識がありません

**求められる水準は、職種によって違います。**専門的な分析を担う職種では、**統計の知識が要件**になります。一方、**集計、報告、資料の作成**が中心の職種では、**正確さと定義の確認のほうが重視される**ことがあります。なお、**平均と中央値の違い、ばらつきの見方、相関と因果の区別**の3点は、**どの職種でも押さえておくと読み方が変わります。**体系的に学ぶかどうかは、**②の目的**で判断してください。**応募の時期が近い場合は、優先順位を下げて**差し支えありません。

### 公的統計を使う仕事には、どんなものがありますか

**自治体を顧客とする事業が中心です。**計画の策定の支援、調査、施策の効果の測定、立地や需要の分析。**これらでは、公的統計が基礎の資料**になります。どの統計に何が載っているか、定義や公表の時期がどうなっているか。**この理解は、外から入った人には時間がかかります。**書類には、**「◯◯の統計を用いて、◯◯の分析を実施」**と、**使った統計の名称**を書いてください。**具体が伝わります。**なお、統計の分類や基準の仕組みは[業界の選び方と、志望動機への落とし方](senko-shibo-gyokaierabi.html)にも触れています。
