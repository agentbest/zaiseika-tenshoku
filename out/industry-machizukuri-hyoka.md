まちづくり・都市開発を検討される方から、**こう伺うことがあります。**

**「役所の中でしか意味を持たない経験なのではないでしょうか」**

**そうではありません。**むしろ、**この業界は、行政の仕組みを内側から知っている人を必要としています。**

**理由は、法律が民間に与えている権限を見れば分かります。**この記事では、**そこから逆算して、どの経験が評価されるか**を扱います。

業界の構造は[未経験からまちづくり・都市開発に入るには](industry-machizukuri-mikeiken.html)、選考の進み方は[まちづくり・都市開発の選考フローと、面接で見られている観点](industry-machizukuri-senko.html)にあります。

## 民間から、都市計画の決定を提案できます

**都市計画法第21条の2第1項**です。

> **（都市計画の決定等の提案）第二十一条の二　都市計画区域又は準都市計画区域のうち、一体として整備し、開発し、又は保全すべき土地の区域としてふさわしい政令で定める規模以上の一団の土地の区域について、当該土地の所有権又は建物の所有を目的とする対抗要件を備えた地上権若しくは賃借権**（中略）**を有する者**（中略）**は、一人で、又は数人共同して、都道府県又は市町村に対し、都市計画**（中略）**の決定又は変更をすることを提案することができる。**

**「提案することができる」**です。

**都市計画は、行政が一方的に決めるものだけではありません。****土地の所有者等が、決定や変更を提案できる**制度があります。

**では、その提案書は、誰が作るのでしょうか。**

**土地の所有者が、自分で都市計画の案を書けるでしょうか。**

**書けません。**区域の設定、用途の考え方、基盤の整備の計画、行政の上位の計画との整合。**専門の知識が要ります。**

**そして、この提案書は、行政の側が読んで判断します。**

**つまり——行政が何を見るかを知っている人が、いちばん通る提案書を書けます。**

## 組合の設立も、同じ構造です

**[未経験からまちづくり・都市開発に入るには](industry-machizukuri-mikeiken.html)で扱った都市再開発法第11条第1項**です。

> **第一種市街地再開発事業の施行区域内の宅地について所有権又は借地権を有する者は、五人以上共同して、定款及び事業計画を定め、国土交通省令で定めるところにより、都道府県知事の認可を受けて組合を設立することができる。**

**「定款及び事業計画を定め」「認可を受けて」**です。

| 民間がやること | 行政が見ること |
|---|---|
| 提案書・事業計画を作る | **要件を満たしているか** |
| 定款を定める | 法令に適合しているか |
| 権利者の合意を取る | **同意の要件を満たしているか** |
| 収支の見通しを立てる | 事業として成立するか |
| 上位の計画との整合を示す | **既存の計画と矛盾しないか** |

**右の列を知っている人が、左の列を作る。**

**これが、この業界が公務員を採る理由**です。

## 評価される経験は、5つに整理できます

| 経験 | この業界での使われ方 | なぜ評価されるか |
|---|---|---|
| ① 計画の策定 | 提案書・事業計画の作成 | **行政が何を見るかを知っている** |
| ② 用地・補償の折衝 | 権利者との個別の協議 | **年単位の合意形成の経験** |
| ③ 行政との協議の段取り | **関係課との協議の設計** | **外から作れない知識** |
| ④ 補助の制度の運用 | 事業への補助の活用 | **交付する側にいた** |
| ⑤ 審議会・委員会の事務 | 組合の総会・理事会の運営 | 会議体を回せる |

**③が、この業界でいちばん値段が付く経験**です。

**[まちづくり・都市開発の選考フローと、面接で見られている観点](industry-machizukuri-senko.html)でも触れましたが、「どの課と、どの順で話すか」**は、**役所に何年もいて、協議で戻された経験がある人だけが持っている知識**です。

**そして、この業界では時間が金銭に直結します。**協議の順番を間違えて計画を組み直すことになれば、**その分の人件費が会社の負担**になります。

**②も、直接の戦力**です。**用地の取得を担当した方は、権利者の方が何を心配するかを知っています。**補償の考え方、代替地の話、税の扱い、仮住まいの不安。

## 言い換えの表

**職務経歴書に、役所の言葉のまま書かないでください。**

| 役所での言い方 | この業界に伝わる言い方 |
|---|---|
| 都市計画の決定の事務 | **計画の案の作成と、関係課・審議会との協議** |
| 地区計画の担当 | 区域の設定、地区整備計画の内容の検討 |
| 用地の取得・補償 | **権利者◯名との折衝、権利関係の調査、補償の算定** |
| 住民説明会の運営 | 説明会の設計、意見の整理、計画への反映 |
| 開発行為の許可の審査 | **申請の内容の審査と、基準への適合の確認** |
| 補助金の交付の事務 | **補助の制度の適用の判断と、実績の確認** |
| 審議会の庶務 | 会議体の招集・議事・記録の運営 |
| 関係課との合議 | **協議の相手と順番の設計、論点の整理** |

**⚠ いちばん下の行を、必ず入れてください。**これが、この業界での差になります。

**書き方は、具体的に。**「地区計画の案件では、道路・建築・公園・消防と協議が要り、消防は建物の計画が固まってからでないと実質的な話ができないため、順番を設計して進めました」。

## 評価されにくい経験

**正直に書いておきます。**

| 経験 | 評価されにくい理由 |
|---|---|
| 制度の条文の知識だけ | **運用を知らないと使えない** |
| 庁内の根回しの経験 | 相手も組織の形も違う |
| 決裁を通した実績 | **決める側の話であって、作る側の話ではない** |
| 在籍年数そのもの | 年数より、何を担ったか |
| 役職の名称 | **対応する段階が会社側に無い** |

**3つ目について補足します。**

**役所では、決裁を通すことが仕事の完了**でした。**この業界では、決裁を通す相手は行政**です。**自分が作る側に回ります。**

**「決裁を通してきた」ではなく、「通る案を作ってきた」**と書けるかどうかが、分かれ目です。

:::insight
面談で拝見していて、**この業界を受ける方がいちばん取りこぼしているのが「協議で戻された経験」**です。皆さん、**うまく通した案件**を書かれます。ところが、**この業界で価値があるのは、戻された経験のほう**です。理由は単純で、**戻される理由を知っている人だけが、戻されない案を作れるから**です。どういう書き方をすると、どの課から何を言われるか。上位の計画との整合をどう示せば納得されるか。数字の根拠をどこまで詰めておく必要があるか。**これは、実際に戻された人しか知りません。**そして、**民間の側にいる人は、戻された理由を推測するしかありません。**行政が「この部分の説明が不十分です」と言ったとき、**本当は何を確認したいのか**が読めない。ここで何往復もして、時間が溶けていきます。**その通訳ができる人**が、この業界では重宝されます。ですから、職務経歴書にも面接にも、**「戻された経験と、そこから学んだこと」**を入れてください。「当初の案では上位の計画との関係の整理が足りず、差し戻しを受けました。以後、案を作る段階で整合の説明を先に用意するようにしました」。**失敗談ではなく、実務の知識として語ってください。**
:::

## 職務経歴書での並べ方

| 位置 | 書くもの |
|---|---|
| 冒頭の要約（3〜4行） | **計画・折衝・協議のうち、担った機能** |
| 職歴の1つ目 | 直近の担当。**地区の規模と件数を入れる** |
| 職歴の2つ目以降 | **応募先の実績に近い分野のものを前へ** |
| 実績の欄 | **協議の相手と順番／戻された経験と対処** |
| 資格・研修 | 関連する資格の取得・学習の状況 |

**冒頭の要約を必ず付けてください。**この業界の中途採用では、**部門長が書類を読みます。**読む時間は限られています。

**⚠ 公表されていない内部の事情や、特定の権利者に関する情報は書かないでください。**守秘の観点に加えて、**それを書く人は、次の職場の情報も外で話す**と見られます。**事業の名称や規模は、公表されている範囲で書けます。**

[経験の言い換えから相談する](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担です）。

## 面接で聞かれやすいこと

| 聞かれること | 何を確かめられているか |
|---|---|
| 行政のどの部署と、どうやり取りしていましたか | **③の関係の地図** |
| 協議で戻された経験はありますか | **実務の深さ** |
| 権利者と直接話した経験はありますか | ②の経験 |
| まとまらなかった案件は、どう扱いましたか | **止まった状態への耐性** |
| 採算について、どう考えていますか | 予算の執行との違いの理解 |

**1つ目に、所属と所掌事務を答えないでください。****関係の地図**を答えてください。

**5つ目は、構造の理解で答えます。****「予算は使い切ってよい上限として管理されますが、事業の収支は費用が少ないほうがよい。方向が逆だと理解しています」**と言えると、**覚悟の表明より説得力があります。**

:::insight
ここまで「評価される」話をしてきましたが、**申し上げておきたいことが2つ**あります。**1つ目は、評価される経験があることと、移ったほうがよいことは別**だということです。この経験は消えません。計画を作った事実、折衝した事実、協議を設計した事実。**異動しても残ります。**ですから、**動く理由は別に必要**です。「評価されるから」は、動く理由としては弱い。**2つ目は、この業界に限っては、確認の順番があるということ**です。⚠ **前の職場と取引のある会社に移る場合、在職中の職務との関係が問題になることがあります。**まちづくりの事業では、**自治体と民間が委託や協議の関係にある**ことが多く、**自分が担当していた事業の相手方に移る**形になりやすい。**再就職に関する規制は、国家公務員と地方公務員で異なり、地方公務員については自治体ごとに定めがあります。**離職前の職務との関係で、**一定期間、特定の行為が制限される**場合があります。⚠ **この記事では、個別の事情について判断できません。所属の人事担当部署と、適用される条例・規程を必ず確認してください。**そして、**この確認は、職務経歴書を書くより先**にやってください。確認の結果で、**応募先の選び方そのものが変わります。**当社が、いまの職を辞めることをお勧めすることはありません。
:::

## まとめ

- **評価される経験は、法律が民間に与えている権限から逆算できます**
- **都市計画法第21条の2第1項**は、一定規模以上の一団の土地の区域について、**土地所有者等が、一人で、又は数人共同して、都道府県又は市町村に対し、都市計画の決定又は変更を提案することができる**と定めています
- **その提案書は、行政の側が読んで判断します。**つまり、**行政が何を見るかを知っている人が、いちばん通る提案書を書けます**
- **都市再開発法第11条**の**定款及び事業計画**も同じ構造です。**民間が作り、行政が認可します**
- 評価される経験は、**①計画の策定 ②用地・補償の折衝 ③行政との協議の段取り ④補助の制度の運用 ⑤審議会・委員会の事務**の5つです
- **③がいちばん値段が付きます。****この業界では時間が金銭に直結する**ためです
- ⚠ **「協議で戻された経験」を書いてください。****戻される理由を知っている人だけが、戻されない案を作れます**
- ⚠ **「決裁を通してきた」ではなく「通る案を作ってきた」**と書けるかどうかが分かれ目です
- ⚠ **職務経歴書を書くより先に、再就職に関する規程の確認を済ませてください**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 都市計画の部署にいたことがありません

**②④⑤で組み立ててください。****用地の取得、補助金の交付、審議会の事務**は、都市計画の部署以外でも担当します。とくに、**用地や補償の折衝**は、道路・河川・公園・学校・下水道など、**事業を持つ部署のどこでも発生します。**この経験は、**この業界の中核と直接重なります。**また、**商工・観光・文化の部署**であれば、**まちづくり会社やエリアマネジメントの分野**が候補になります。こちらは、**施設の運営、公共空間の活用、地域の事業者との調整**が中心で、**都市計画の知識より、地域の関係者と動いた経験**が効きます。**分野で候補を狭めないでください。**

### 技術職ですが、計画より設計の経験が中心です

**建設コンサルタントの分野**が、いちばん近い候補です。基盤の設計、インフラの計画、事業の実施の支援。**設計の経験がそのまま使えます。**加えて、**まちづくり・都市開発の会社でも、基盤の計画を担う技術者を求めている**ことがあります。⚠ **職種によっては資格が必須要件になっている**ので、求人票で確認してください。なお、**発注者側で設計を発注し、検査してきた経験**は、**発注者支援の分野**でも評価されます。「設計した経験」だけでなく、**「発注し、成果品を検査した経験」**も書いてください。**受注する側から見ると、発注者が何を見るかを知っている人**は、価値があります。

### 在籍が短く、担当した案件も少ないです

**件数より、関与の深さ**を書いてください。1件でも、**構想から事業の認可まで通して担当した**なら、それは強い材料です。逆に、**多数の案件に浅く関わった**場合は、**共通してやっていた動作**を抽出してください。「◯件の案件について、いずれも関係課との協議の日程と論点の整理を担当」という書き方です。また、**在籍が短い場合、なぜ動くのかを必ず聞かれます。**答え方は、**「この分野を続けたいが、行政では異動で離れることになる」**という形が自然です。⚠ **前の職場の不満から説明しないでください。**続けたいという方向で語ってください。
