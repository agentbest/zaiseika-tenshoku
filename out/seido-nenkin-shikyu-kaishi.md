公務員期間の年金をいつから受け取れるかは、給付の名前を分けることから確認します。老齢厚生年金、経過的職域加算額、年金払い退職給付は、同じ開始条件の給付ではありません。退職したという事実だけで、その全部を直ちに受け取れるわけでもありません。

本記事は2026年11月時点の公開情報にもとづきます。老齢・退職の給付を中心に一般的な整理を行い、地方公務員については各共済の案内と法令を基に説明します。本人の年金と請求時期は、所属していた共済組合・年金事務所等で確認してください。

## 一元化前後の勤務期間と給付名を分ける

2015年10月の被用者年金一元化後、公務員も厚生年金の仕組みで給付を受けます。一方、それまでの職域部分に関係する経過措置と、一元化後の期間を対象とする年金払い退職給付は、別に確認します。

| 給付の区分 | 主に確認する対象と条件 |
| --- | --- |
| 老齢基礎年金 | 公的年金全体の資格期間等、原則65歳 |
| 公務員期間の老齢厚生年金 | 共済が関係する厚生年金期間、年齢・資格期間 |
| 経過的職域加算額等 | 2015年9月までの共済期間と経過措置 |
| 年金払い退職給付の退職年金 | 2015年10月以後の対象期間、継続期間・年齢・退職 |
| 退職手当 | 所属の別制度で支払条件を確認 |

「共済年金」という呼び方だけでは、現在どの給付について質問しているか分からない場合があります。古い年金証書と最近の通知で名称が違うなら、名称、対象期間、発行した組合をそのまま控えて照会します。

一元化前に既に受給権があった人と、その後に受給権が発生する人でも扱いは分かれます。単に2015年より前に採用されたという理由で、古い制度の受給要件がすべて本人に適用されるとは考えません。

## 老齢厚生年金は65歳と受給資格を基本に確認する

厚生年金保険法第42条は、被保険者期間を持つ人について、65歳以上と資格期間等の要件を定めています。若い時期に公務員を退職しても、確認するのは本人の加入記録と将来の資格であり、退職日から老齢厚生年金が始まるわけではありません。

公務員になる前後の民間勤務や国民年金の期間がある場合は、それらを受給資格の判定にどう使うかを確認します。資格のために期間を合算することと、すべての年金を一つの支給主体から受け取ることは別です。

65歳になっても民間会社で働く場合、老齢厚生年金には在職による支給調整があります。年金を受け取るために必ず全ての仕事を辞めなければならない、と決めるものではありません。共済固有の給付の退職要件とは区別します。

機構の案内では、特別支給の老齢厚生年金について生年月日等の対象条件があります。共済組合等から支給される部分の開始年齢は、女性も男性と同じ扱いです。民間期間がある女性は、その期間の年金と開始年齢が異なる場合があるため、それぞれ確認してください。

特定警察職員等の経過措置や、長期加入等の特例が関係する人は、一般の開始年齢だけで結論を出さず担当へ照会します。対象外の人へ、昔の同僚が受けた特別支給をそのまま当てはめないことが必要です。

## 経過的職域加算額は古い勤務期間の条件を確認する

地方職員共済組合は、一元化前の職域部分が廃止された後も、対象の組合員期間等に応じて経過的職域加算額が支給される仕組みを説明しています。2015年9月までの期間が対象となるため、以後に初めて加入した人の年金払い退職給付とは別です。

東京都職員共済組合の案内は、65歳以後の本来支給について、年齢、公的年金加入期間等、2015年9月以前の公務員共済期間を確認項目としています。また、一元化前の期間が一年未満でも、それに引き続く公務員厚生年金期間との合算による取扱いを示しています。

したがって、「一元化前に一年ないから必ず対象外」「一年以上なら年齢を問わず受け取れる」といった一項目だけの判定は避けます。採用、共済間異動、退職の履歴を示し、本人の経過措置を組合へ確認してください。

旧職域の給付には、組合員である間の支給停止も案内されています。老齢厚生年金の在職調整と同じ計算を、そのまま旧職域へ使うわけではありません。給付名別に、いつ権利が生じ、いつ実際に支給されるかを聞くことが大切です。

:::insight
給付の開始時期を確認するときは、年金を一つの総額として尋ねる前に、本人に関係する給付名を並べることを勧めます。同じ共済から案内されても、厚生年金、旧職域、年金払い退職給付では、見る期間や退職の条件が違うためです。本人用の表に、制度名、対象期間、開始条件、照会先を一行ずつ置けば、回答の範囲を確かめやすくなります。まだ分からない給付は未確認として残し、他の給付の回答で埋めないことも大切です。現職に残る人にも、民間へ移る人にも、この整理は将来の準備として役立ちます。受給条件の確認を退職の勧めへ結び付けず、本人が判断するための情報を整える形がよいと考えます。
:::

仕事内容も比較したい場合は、[公務員向けの求人情報](../?gov=1)を見ることもできます。制度の確認と転職の決断を同時に進める必要はありません。

## 年金払い退職給付の退職年金には退職の条件がある

地方公務員等共済組合法第76条は、退職年金、公務障害年金、公務遺族年金を退職等年金給付の種類として定めています。ここでは、そのうち老齢・退職の計画に関係する退職年金を扱います。

同法第88条は、一年以上の引き続く組合員期間を持つ人が退職後に65歳に達する場合や、65歳到達後に退職する場合等を定めています。65歳になった時点で組合員である場合の除外もあり、老齢厚生年金と同じ条件で一律に始まるわけではありません。

また、第87条は終身退職年金と有期退職年金を定めています。有期部分を年金又は一時金等で受け取る選択は、受給条件と別に確認します。選択の詳細は[年金払い退職給付の受け取り方](seido-nenkin-kyufu-sankan.html)も参照できます。

例えば、仮に65歳になる前に公務員を退職して民間会社へ移った人なら、共済に残る対象期間と、65歳時点の受給条件を確認します。民間会社を辞めることまで、共済の退職条件と同じ意味で求められるとは決めません。逆に公務員の組合員として再び勤務する場合は、同法第95条の支給停止等も関係します。

任意継続の医療掛金を払うことと、在職者としてこの給付の対象期間を積み上げることも別です。再任用等については名称だけで判断せず、本人がどの資格を得るかを共済へ確認します。

## 繰上げ・繰下げも制度ごとに選択条件が違う

地方職員共済組合は、退職年金について、条件を満たす退職者の繰上げ・繰下げを案内しています。終身と有期は同時に扱う一方、老齢基礎・厚生年金を必ず同時に繰り上げ又は繰り下げる必要はないと説明しています。

公的な老齢基礎・厚生年金の繰上げには、原則同時請求等の別の条件があります。退職年金の説明をすべての給付へ当てはめると、請求の組合せを誤るおそれがあります。どの給付の受取時期を変えたいか、名称を示して質問してください。

共済の給付算定基礎額は、第77条の付与額や利子等による計算を確認します。通知にある基礎額は、老齢厚生年金の年額や、そのまま受け取る現金額ではありません。適用する利率等も時点で異なるため、古い資料の数値で現在の給付額を断定しないようにします。

受給の開始条件と、どの時期を選ぶかの判断は別です。将来の年金額だけでなく、税、医療保険料、家族の条件、当面の生活費も合わせて確認します。すべての人に同じ受取年齢を勧めることはできません。

## 請求の準備は給付名と担当窓口をそろえる

厚生年金保険法第33条の裁定請求と、共済の退職年金等の請求を分けて準備します。地方職員共済組合の請求案内では、老齢厚生年金の支給開始年齢に達した時の手続きや、65歳到達時の別の請求が説明されています。

| 確認しておく項目 | 本人用メモの内容 |
| --- | --- |
| 生年月日と加入履歴 | 共済名、民間期間、取得・喪失の時期 |
| 一元化前後 | 2015年9月までと10月以後の対象期間 |
| 給付の開始 | 各給付の年齢・資格期間・退職条件 |
| 請求 | 書類、提出可能日、添付、受付先 |
| 退職後の連絡 | 住所等の変更、通知未着時の窓口 |
| 支払 | 対象月、停止の有無、決定後の通知 |

厚生年金保険法第36条、地方公務員等共済組合法第78条は、支給事由が生じた月の翌月分からの支給等を定めています。実際の初回振込は裁定や支払処理を経るため、対象月と入金日を混同しないでください。

退職前に資料を保管するときは、本人に交付された通知を使います。業務用の人事記録や他職員の情報を持ち出す方法は取りません。通知が見つからない場合は、本人確認と再交付の方法を担当へ問い合わせます。

職務や希望条件の整理には[相談フォーム](../apply.html)を利用できます。ご利用は無料です（紹介手数料は採用企業の負担）。個人の給付決定や年金請求の受付は、共済・年金事務所等へ確認してください。

:::insight
受給時期の一覧を作った後は、確定した資格と将来の仮定を分けて見直すことが大切です。いままでの勤務記録が確認できても、いつまで働くかや、どの時期に年金を請求するかまで決まるわけではありません。資料には、回答の基準日と本人の予定を別の欄に置き、再就職や住所変更があれば確認し直します。現職を続ける場合の条件を整理することにも意味があります。外の仕事を調べる場合も、年金だけで結論を出さず、仕事の内容や生活時間、家族の予定を合わせて考えてください。受取開始の制度は本人が選ぶための材料であり、退職や応募を急ぐ理由にせず、未確認の点を残したままでも情報収集を続けられる形を勧めます。
:::

## よくある質問

### 公務員の年金は全部65歳からですか

65歳が基本となる給付はありますが、特別支給や繰上げ等、給付ごとの条件を確認します。退職年金には退職の条件もあるため、同じ年齢だけで一括して判断しません。

### 2015年より前に採用されていれば旧職域分を必ず受け取れますか

加入期間や一元化前後の経過措置等を確認します。一元化前の期間が一年未満でも、その後の公務員期間と合わせる取扱いが関係する場合があります。本人の履歴を共済へ示してください。

### 老齢厚生年金の請求だけですべての共済給付も済みますか

一律に完了とはいえません。経過的職域加算額や年金払い退職給付など、本人の給付名ごとに必要な請求と受付先を確認します。

情報収集の相談には[LINE](https://line.me/R/ti/p/@697nxhbt)も利用できます。受給時期を確認しながら、現職を続けることも含めて本人の希望に沿って考えられます。
