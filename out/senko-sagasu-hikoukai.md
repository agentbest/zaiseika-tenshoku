**「非公開求人」という言葉を目にした、というご相談を伺います。**

**特別なものに見えますが、仕組みの違いから生じているもの**です。

この記事では、**なぜ存在するのか**と、**どう扱えばよいか**を扱います。

## 2つの仕組みがあります

**職業安定法第4条第1項**です。

> この法律において**「職業紹介」**とは、**求人及び求職の申込みを受け、求人者と求職者との間における雇用関係の成立をあつせんすること**をいう。

**「申込みを受けて、あっせんする」**という定義です。

**掲載することは、定義に含まれていません。**

**同条第6項**は、**別の行為を定義**しています。

> この法律において**「募集情報等提供」**とは、次に掲げる行為をいう。
>
> 一 労働者の募集を行う者等（略）の依頼を受け、**労働者の募集に関する情報を労働者になろうとする者**（略）**に提供すること。**

**こちらは、「情報を提供すること」**です。

| | 職業紹介 | 募集情報等提供 |
|---|---|---|
| 中身 | **雇用関係の成立をあっせんする** | 募集の情報を提供する |
| 掲載 | **前提としない** | 情報の提供が中心 |
| 例 | 人材の紹介 | 求人の検索サイト |

**この違いが、非公開求人が存在する理由**です。

**あっせんを通じて進める場合、募集の情報を広く掲載する必要がありません。**

**掲載していない求人が「非公開求人」と呼ばれているもの**です。

## 非公開にする理由

| 理由 | 内容 |
|---|---|
| ① 応募の数を絞りたい | 選考の手間を抑えるため |
| ② 組織の変更を公表したくない | 新しい部署、体制の変更 |
| ③ 後任の募集であることを知られたくない | 在職者がいる段階 |
| ④ 事業の内容を公表したくない | 受託の交渉中、開発中 |
| ⑤ 対外的な印象 | 募集が続いていることを出したくない |

**①と③が多い**です。

**③について。**

**担当者が在職している段階で後任を探す場合、掲載すると社内外に伝わります。**

**この場合、あっせんを通じて進める形が選ばれます。**

**行政が相手の事業では、④もあります。**

**受託が決まる前に体制の準備を進める場合**です。

## 非公開であることの意味

| 誤解 | 実際 |
|---|---|
| 条件がよい | **条件とは関係がありません** |
| 数が少ない | 会社によります |
| 選考が緩い | 変わりません |
| 誰でも紹介される | **条件が合う場合に紹介されます** |

**1行目を確認してください。**

**非公開であることは、掲載していないという意味**です。

**条件の良し悪しを表すものではありません。**

**条件は、求人票の内容で判断**してください。読み方は[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。

## どう届くか

| 順 | 流れ |
|---|---|
| 1 | 求職の申込みをする（登録・面談） |
| 2 | 経験と希望の条件を伝える |
| 3 | 条件に合う求人が紹介される |
| 4 | 求人票の内容を確認する |
| 5 | 応募するかを決める |

**2が要**です。

**条件を伝えていなければ、合う求人を選べません。**

**勤務地、勤務時間、業務の内容、時期。**

**この4つを伝えておいてください。**

**5について。**

**紹介を受けても、応募しない選択ができます。**

**内容を確認してから決めて差し支えありません。**

:::insight
非公開の求人について、**面談でお伝えしているのが「数を期待しないでください」**という点です。**「非公開求人が多数あります」という説明を受けて、登録すればたくさん紹介されると期待される方**がいらっしゃいます。ところが、**紹介されるのは条件に合うものだけ**です。**条件を絞るほど、紹介される数は減ります。**そして、**それが正しい状態**です。条件に合わない求人を大量に紹介されても、**確認の手間が増えるだけ**です。ですから、**見るべきは数ではなく、条件の合い方**です。行政が相手の事業では、**募集の数そのものが多くありません。**指定管理や受託の時期に応じて生じるためです。**そのぶん、条件を登録しておいて、出たときに知らせを受ける**という使い方が向いています。**待つ期間があること自体は、珍しいことではありません。**在職中であれば、待つ間も不利になりません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 紹介を受けたときに確認すること

| 確認すること | 理由 |
|---|---|
| 募集の背景 | 増員か、後任か、立ち上げか |
| 配属先の所在地 | 通勤の時間 |
| 選考の流れ | 回数と期間 |
| 応募の期限 | 判断の時間 |
| 他に紹介される可能性 | 比べる相手があるか |

**4つ目を確認してください。**

**期限が示されていれば、その中で判断できます。**

**期限が分からないまま急がされる状況は、避けてください。**

**5つ目について。**

**1件だけで判断すると、比べる相手がありません。**

**複数の求人を並べてから決める**ほうが、納得しやすくなります。

[経験の言い換えから相談する](../apply.html)こともできます。

## 在職中の使い方

| 項目 | 内容 |
|---|---|
| 登録の時期 | **応募を決める前で構いません** |
| 伝えること | 在職中であること、時期の見込み |
| 連絡の方法 | 連絡可能な時間帯を伝える |
| 進め方 | 情報を受け取るだけの段階もあります |

**1つ目です。**

**登録した時点で、応募が始まるわけではありません。**

**条件を伝えて、合うものが出たときに知らせを受ける**という段階があります。

**2つ目について。**

**在職中であることを伝えておくと、日程の調整に配慮されます。**

**面接の時間帯、連絡の方法、選考の期間。**

**これらは、伝えておけば調整の対象になります。**

## 公開の求人との使い分け

| 用途 | 向いているもの |
|---|---|
| 相場を知る | **公開の求人**（数が多く、自分で読めます） |
| 条件の傾向をつかむ | 公開の求人 |
| 応募条件の言葉を拾う | 公開の求人 |
| 条件に合うものを待つ | **紹介** |
| 条件の確認を任せる | 紹介 |
| 日程の調整を任せる | 紹介 |

**上の3つを先にしてください。**

**公開されている求人を読むことで、その領域で何が求められているかが分かります。**

**この理解があると、紹介を受けたときの判断が速くなります。**

**逆に、相場を知らないまま紹介だけを受けると、比べる基準がありません。**

## 紹介の手数料について

**求職者が手数料を負担する仕組みにはなっていません。**

| 項目 | 内容 |
|---|---|
| 負担する側 | **採用する企業** |
| 求職者の負担 | 原則としてありません |
| 根拠 | 職業安定法に定めがあります |

**この点は**[転職エージェントの使い方](senko-sagasu-agent.html)**で扱います。**

**費用の心配で登録をためらう必要はありません。**

**なお、手数料の扱いは、紹介を行う事業者に確認して差し支えありません。**

## よくある失敗

**1. 非公開であることを、条件のよさと受け取る**

**掲載していないという意味**です。

**2. 数を期待する**

**条件に合うものだけが紹介されます。**

**3. 条件を伝えない**

**合う求人を選べません。**

**4. 紹介されたら応募しなければならないと考える**

**確認してから決めて差し支えありません。**

**5. 1件だけで判断する**

**比べる相手を持ってください。**

**6. 期限を確認しない**

**判断の時間が分かりません。**

**7. 在職中であることを伝えない**

**日程の調整ができません。**

:::insight
ここまで非公開の話をしておいて逆のことを言いますが、**公開されている求人を軽く見ないでください。**面談で拝見していると、**「非公開のほうがよい求人がある」と考えて、掲載されている求人を見なくなる方**がいらっしゃいます。ところが、**掲載する理由にも合理性があります。**広く知ってもらいたい、応募の数を確保したい、事業を公表している。**掲載されていること自体は、条件の良し悪しと関係がありません。**そして、**掲載されている求人は、自分のペースで読めます。**在職中は時間が限られるため、**自分で読める求人があることには意味があります。**現実的なのは、**両方を使うこと**です。掲載されている求人で相場と傾向をつかみ、**条件を登録して、合うものが出たら知らせを受ける。****この2つは競合しません。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **職業安定法第4条第1項**は、**職業紹介を「求人及び求職の申込みを受け、雇用関係の成立をあっせんすること」**と定義しています。**掲載は定義に含まれていません**
- **同条第6項**の**募集情報等提供**は、**募集に関する情報を提供する行為**です。求人の検索サイトがこれにあたります
- **この仕組みの違いから、掲載していない求人が生じます。**それが非公開求人です
- **非公開であることは、条件の良し悪しを表しません**
- **紹介される数は、条件を絞るほど減ります。**それが正しい状態です
- **期限を確認し、複数を並べて判断**してください
- **公開の求人と非公開の求人は競合しません。**両方を使ってください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 登録すると、勤務先に知られませんか

**在職中であることを伝えておいてください。**求職の申込みの内容は、**本人の同意なく提供されるものではありません。**当社では、**推薦する前に、応募先を確認**しています。**在職中の勤務先に関係する会社がある場合、その旨を伝えておくと、紹介の対象から外すことができます。**連絡の方法についても、**勤務時間中の電話を避ける、メールのみにする**といった希望を伝えて差し支えありません。**書類の提出の時期も調整できます。**在職中の転職は珍しいことではありません。**配慮の仕方は、伝えれば決まります。**

### 紹介された求人を断ると、次が来なくなりますか

**そのようなことはありません。**断る理由が分かるほうが、**次の紹介の精度が上がります。**「勤務地が遠い」「業務の内容が想定と違う」「時期が合わない」。**理由を伝えてください。**条件の理解が更新されます。なお、**断る理由がうまく言えない場合もあります。**その場合は、「なんとなく合わない気がする」でも構いません。**どこが引っかかったかを一緒に整理する**ことができます。**断ること自体が、条件を詰める作業**になります。**無理に応募しないでください。**

### 複数のところに登録してもよいですか

**差し支えありません。**ただし、**同じ求人に重複して応募しないよう注意**してください。**同じ会社に複数の経路から応募が届くと、選考が進めにくくなる**ことがあります。応募の前に、**どこから応募するかを決めておいてください。**また、**やり取りの数が増えると、在職中は対応が負担になります。**数を増やすより、**条件を正確に伝えられるところを絞る**ほうが進みます。なお、**当社を通す場合、企業へ推薦する形で選考が進みます。**条件の確認や日程の調整をお任せいただけます。**在職中で時間が取りにくい場合、この手間が省けます。**
