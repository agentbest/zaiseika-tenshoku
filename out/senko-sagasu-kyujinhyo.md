**求人票を読み慣れていない、というご相談を伺います。**

**役所では、求人票を読む機会がほとんどありません。**

この記事では、**読む順序**と、**それぞれの欄から分かること**を扱います。

## 求人票は、書くべきことが定められた書類です

**職業安定法第5条の3第1項**です。

> 公共職業安定所、特定地方公共団体及び職業紹介事業者、労働者の募集を行う者及び募集受託者並びに労働者供給事業者は、それぞれ、職業紹介、労働者の募集又は労働者供給に当たり、**求職者**（略）に対し、**その者が従事すべき業務の内容及び賃金、労働時間その他の労働条件を明示しなければならない。**

**同条第2項**は、**求人者の側の義務**を定めています。

> **求人者**は求人の申込みに当たり公共職業安定所、特定地方公共団体又は職業紹介事業者に対し（略）**従事すべき業務の内容及び賃金、労働時間その他の労働条件を明示しなければならない。**

**同条第3項**は、**契約を結ぶ段階で条件を変更する場合**について定めています。

> （略）**第一項の規定により明示された従事すべき業務の内容及び賃金、労働時間その他の労働条件**（略）**を変更する場合**その他厚生労働省令で定める場合は、当該契約の相手方となろうとする者に対し、**当該変更する従事すべき業務の内容等**（略）**を明示しなければならない。**

**つまり、求人票は「書くべきことが決まっている書類」であり、「変わったら知らせる」仕組みも置かれている**ということです。

**ですから、読むべき欄は決まっています。**

**そして、条件が変わった場合は、その明示を受けられます。**

## 読む順序

| 順 | 欄 | 分かること |
|---|---|---|
| 1 | **仕事内容** | 日々の業務。情報量が最も多い |
| 2 | **応募条件（必須・歓迎）** | 求められている経験 |
| 3 | 雇用形態・契約の期間 | 期間の定めの有無 |
| 4 | 勤務地 | 配属先、転勤の範囲 |
| 5 | 勤務時間 | 始業・終業、残業の扱い |
| 6 | 休日 | 週休の形、年間の日数 |
| 7 | 賃金の構成 | 基本給と手当の内訳 |
| 8 | 募集の背景 | 増員か、後任か |
| 9 | 選考の流れ | 回数、期間 |

**1と2を先に読んでください。**

**この2つが合わなければ、他の欄を読む意味が薄くなります。**

## 1——仕事内容の欄

| 見るところ | 読み取れること |
|---|---|
| 動詞 | **何をする仕事か**（作る／管理する／折衝する／確認する） |
| 相手 | 誰を顧客にするか（行政／企業／消費者） |
| 範囲 | 担当の広さ |
| 裁量 | 判断が含まれるか、手順に沿うか |
| 記載の量 | **短いほど、確認すべきことが多い** |

**5つ目です。**

**仕事内容が2〜3行しか書かれていない求人は、面接で確認する項目が増えます。**

**書かれていないこと自体は問題ではありません。**

**ただし、応募の前に確認する必要がある、ということです。**

## 2——応募条件の欄

| 区分 | 読み方 |
|---|---|
| 必須 | **満たしていないと、選考が難しい** |
| 歓迎 | 満たしていれば有利。必須ではない |
| 求める人物像 | 抽象的な記載。判断の材料にしにくい |

**「必須」に書かれている経験を、自分の言葉で説明できるか**を確認してください。

**業界の経験が必須なら、その業界の経験が要ります。**

**一方、「折衝の経験」「制度の理解」「進行の管理」であれば、業界が違っても該当します。**

**行政での実務経験が挙げられている場合、経験がそのまま条件に重なります。**

## 4——勤務地の欄

| 記載 | 確認すること |
|---|---|
| 「本社」とだけ書かれている | **配属先の所在地** |
| 「全国各地」 | 具体的な候補地 |
| 「転勤なし」 | 範囲の定めがあるか |
| 「顧客先」 | 常駐先の場所 |

**4つ目は、行政が相手の事業で見かけます。**

**庁舎内に常駐する形の職場**があるためです。

**通勤の時間が変わるため、所在地を確認**してください。

**扱いは**[転職にともなう転居と単身赴任](senko-taishoku-tenkyo.html)**に整理しています。**

## 7——賃金の構成

| 確認すること | 内容 |
|---|---|
| 基本給と手当の区分 | どこまでが固定か |
| 固定残業代の有無 | **含まれている場合、何時間分か** |
| 賞与 | 制度の有無、支給の実績 |
| 昇給 | 制度の有無 |
| 手当の内訳 | 住居、通勤、扶養、資格 |

**2つ目を確認してください。**

**一定時間分の残業代があらかじめ含まれている場合があります。**

**その場合、何時間分が含まれているか**が書かれています。

**記載を読み飛ばすと、想定していた働き方と違うことになります。**

:::insight
求人票で、**面談でお聞きしているのが「募集の背景の欄を見ましたか」**という点です。この欄は、**書かれていれば情報量が多い**にもかかわらず、読み飛ばされやすいところです。「事業の拡大にともなう増員」「前任者の退職にともなう後任」「新規の受託にともなう体制の整備」。**この3つで、入社後の状況が変わります。**増員なら、**既にいる人と同じ仕事**をします。後任なら、**引継ぎがあり、前任者のやり方が残っています。**新規の受託なら、**立ち上げから関わる**ことになります。行政が相手の事業では、**3つ目が多い**です。指定管理や業務の受託が決まった後に、担う人を集めるためです。**この場合、業務の手順が固まっていないことがあります。**それを負担と見るか、関われる範囲が広いと見るかは、人によります。**書かれていない場合は、面接で聞いて差し支えありません。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 書かれていない欄の読み方

| 書かれていない項目 | 確認の方法 |
|---|---|
| 配属先の所在地 | 面接、または紹介を通じて確認 |
| 残業の実態 | 面接で「繁忙の時期」を聞く |
| 募集の背景 | 面接で聞く |
| 離職の状況 | 直接は聞きにくい。募集の頻度から推測 |
| 制度の利用の実績 | 面接で「取得の実績」を聞く |

**4つ目です。**

**同じ求人が繰り返し掲載されている場合、募集が続いている**ということです。

**事業の拡大による場合もあれば、別の理由の場合もあります。**

**推測で判断せず、面接で確認**してください。

[経験の言い換えから相談する](../apply.html)こともできます。

## 5件並べて読む

**1件だけ読むと、何が標準か分かりません。**

| 比べる項目 | 見えること |
|---|---|
| 応募条件 | その領域で共通して求められる経験 |
| 仕事内容 | 業務の範囲の広さの違い |
| 勤務の条件 | 働き方の幅 |
| 賃金の構成 | 手当の構成の違い |

**1つ目が要**です。

**繰り返し出てくる言葉が、その領域の共通の要件**です。

**その言葉を、職務経歴書に使ってください。**

**探し方そのものは**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 条件が変わった場合

**職業安定法第5条の3第3項**により、**契約を結ぶ段階で条件を変更する場合、変更の明示を受けられます。**

| 場面 | 対応 |
|---|---|
| 内定の条件が求人票と違う | **変更の内容の明示を求める** |
| 配属先が違う | 同上 |
| 賃金の構成が違う | 同上 |

**行き違いである場合もあります。**

**まず、書面で確認**してください。

## よくある失敗

**1. 賃金の欄から読む**

**仕事内容と応募条件が先**です。

**2. 「歓迎」を必須と読む**

**満たしていなくても応募できます。**

**3. 固定残業代の記載を読み飛ばす**

**働き方の想定が変わります。**

**4. 勤務地を「本社」のまま受け取る**

**配属先を確認**してください。

**5. 募集の背景を見ない**

**入社後の状況が変わります。**

**6. 1件だけ読んで判断する**

**5件並べると基準ができます。**

**7. 変わった条件を口頭で受け取る**

**書面で確認**してください。

:::insight
ここまで読み方の話をしておいて逆のことを言いますが、**求人票だけで判断しきる必要はありません。**面談で拝見していると、**求人票を読み込んで、書かれていない点が気になって応募に進めない方**がいらっしゃいます。ところが、**求人票に書ける分量には限りがあります。**明示すべき事項は定められていますが、**職場の雰囲気や、業務の進め方の細部までは書ききれません。**これらは、**面接で確認する前提**になっています。ですから、**求人票で見るのは「条件が外れていないか」まで**で足ります。仕事内容、応募条件、勤務地、勤務時間。**この4つが外れていなければ、残りは面接で聞く**という進め方が現実的です。**面接は、相手が自分を見る場であると同時に、自分が相手を見る場**でもあります。**聞くことを前提に、求人票の段階では絞り込みすぎないでください。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **職業安定法第5条の3**は、**業務の内容・賃金・労働時間その他の労働条件の明示**を定めています。**求人票は、書くべきことが決まっている書類**です
- **同条第3項**により、**契約を結ぶ段階で条件を変更する場合、変更の明示**を受けられます
- 読む順序は、**①仕事内容 ②応募条件**が先です
- **勤務地の「本社」は、配属先とは限りません**
- **固定残業代の記載**を読み飛ばさないでください
- **募集の背景**は、入社後の状況を左右します
- **5件並べて読む**と、その領域の共通の要件が見えます

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 応募条件を満たしていません。応募してよいものですか

**「必須」と「歓迎」で分けて考えてください。**必須の条件を満たしていない場合、**選考が進みにくい**のは事実です。ただし、**必須の書き方には幅があります。**「◯◯の経験3年以上」のように数値で書かれているものは、**満たしているかが明確**です。一方、「顧客折衝の経験」「制度の理解」のように書かれているものは、**自分の経験が該当するかを説明できれば足ります。**役所での経験は、**民間の言葉に置き換えると該当する**ことがあります。判断に迷う場合、**応募の前に確認**できます。紹介を通す場合、**企業に照会してもらう**ことができます。

### 仕事内容の記載が短い求人は、避けたほうがよいですか

**避ける理由にはなりません。**記載が短い理由は複数あります。**募集の様式が決まっている、業務の範囲が広くて書ききれない、公表を控えている部分がある**など、**会社側の事情**です。ただし、**確認すべき項目が増えるのは事実**です。応募の前に、**①日々の業務の流れ ②担当の範囲 ③顧客が誰か**の3点を確認してください。**面接で聞いて差し支えありません。**なお、**同じ会社の他の求人票を見る**と、書き方の傾向が分かることがあります。**会社全体で記載が簡素なのか、この求人だけなのか**で見方が変わります。

### 内定の条件が、求人票と違っていました

**まず、変更の内容を書面で確認**してください。**職業安定法第5条の3第3項**は、**契約を結ぶ段階で条件を変更する場合、変更する内容を明示しなければならない**と定めています。**明示を求めて差し支えありません。**そのうえで、**違いの理由を確認**してください。**選考の過程で、配属先や役割が変わることはあります。**その場合、**変更後の条件で判断**することになります。**条件が合わなければ、辞退することもできます。**なお、**口頭でのやり取りだけで進めないでください。**後から確認できません。**書面で受け取る習慣を持ってください。**
