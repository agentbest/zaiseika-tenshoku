**係長級は、実務と運営の両方を担う立場**です。

**ところが、職務経歴書では書きにくい**という相談を伺います。

この記事では、**判断の範囲の示し方**と、**求人の選び方**を扱います。

## 自分が何を決めていたかは、規程で確認できます

**地方自治法第153条第1項**です。

> **普通地方公共団体の長は、その権限に属する事務の一部をその補助機関である職員に委任し、又はこれに臨時に代理させることができる。**

**事務の一部を職員に委任できる**という仕組みです。

**多くの団体では、これを踏まえた事務の専決に関する規程が置かれています。**

**職位ごとに、どの事項を決裁できるかが定められている**わけです。

**つまり、自分が何を決めていたかは、文書で確認できる**ということです。

**規程を確認して、自分の職位で専決できた事項を書き出してください。**

**これが、判断の範囲の説明になります。**

## 係長級で担っていること

| 項目 | 内容 |
|---|---|
| ① 係の事務の進行の管理 | 人数、業務の量、期限 |
| ② 困難な事案の処理 | 例外、前例のない事案 |
| ③ 決裁 | **専決できた事項** |
| ④ 他課・他団体との調整 | 相手と、内容 |
| ⑤ 後進の指導 | 人数、作った資料 |
| ⑥ 上位への説明 | 課長、部長、議会 |

**①と③が、中途採用で読まれる中心**です。

**②について。**

**標準の手順で処理できない事案は、係長級に集まります。**

**この処理の経験が、専門性の証明になります。**

## 書き方の例

**悪い例**

> ◯◯課で係長として、係の業務を担当しました。

**良い例**

> ◯◯課の係長として、**職員◯人の係の事務の進行を管理。**年間約◯件の申請の処理について進捗を確認し、**遅れの見込まれる案件を事業課と調整。****制度の要件に当てはまらない事案について、類似の事例と関係法令を確認したうえで判断の方針を整理し、◯件を処理。**新任の担当者◯人に対し、確認の手順書と記入例を作成して指導。

**「人数」「件数」「判断」「指導」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 言い換えの対応

| 役所の言葉 | 民間での読まれ方 |
|---|---|
| 係の事務の進行の管理 | **チームの進行の管理** |
| 専決 | 一定の範囲での決裁の権限 |
| 困難事案の処理 | エスカレーションの対応 |
| 他課との調整 | 部門間の調整 |
| 要綱・様式の整備 | 業務の手順の設計 |
| 課長への説明 | 上位への報告、資料の作成 |

**3行目です。**

**求人票では、「エスカレーション対応」「難易度の高い案件の担当」「専門相談の窓口」**と書かれていることがあります。

**自分の経験と重なるかを見てください。**

## 求人の選び方

| 種類 | 内容 |
|---|---|
| ① 実務の中核 | 経験のある分野での担当 |
| ② チームの運営 | 少人数の進行の管理を含む |
| ③ 行政が相手の事業 | 発注者支援、制度の支援、施設の運営 |
| ④ 立ち上げ | 新規の受託にともなう体制の整備 |

**②が、係長級の経験と重なりやすい**です。

**数人の進行を管理しながら、自分も実務を持つ。**

**この形は、民間でも一般的**です。

**「プレイングマネージャー」という言い方がされることがあります。**

**求人票の仕事内容に、実務と管理の両方が書かれていれば該当します。**

:::insight
係長級のご相談で、**面談でお聞きしているのが「専決の規程を確認しましたか」**という点です。多くの方が、**「自分は決裁の権限がないので、判断はしていない」**とおっしゃいます。ところが、**専決に関する規程を見ると、係長の職位で決裁できる事項が定められている**ことが少なくありません。軽微な支出、定型の許可、照会への回答。**これらは、自分の判断で処理していたはず**です。加えて、**課長決裁の案件でも、方針を整理して起案したのは自分**という場合があります。**起案は、判断の一部**です。どの根拠を用い、どう整理し、どう結論づけたか。**この過程を担ったこと自体が、説明の材料になります。**ですから、書き方は「決裁の権限がありました」ではなく、**「◯◯について専決し、年間◯件を処理。課長決裁の案件については、根拠の整理と方針の起案を担当」**です。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 準備の順序

| 順 | やること |
|---|---|
| 1 | **専決に関する規程を確認する** |
| 2 | 係の人数、業務の量、件数を確認する |
| 3 | 困難な事案の処理を書き出す |
| 4 | 指導した人数と、作った資料を書き出す |
| 5 | 民間の言葉に置き換える |
| 6 | 求人を読む |

**1と3が、この立場ならではの作業**です。

**3について。**

**「特に難しかった案件」を3件思い出してください。**

**何が難しく、どう整理し、どう結論づけたか。**

**これが、面接で話す材料になります。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 在職中の進め方

| 項目 | 内容 |
|---|---|
| 記録 | 月に1回、担当した件数と新しく扱ったこと |
| 資料の確認 | 専決の規程、係の分掌 |
| 求人を読む | 週に30分 |
| 日程の確保 | **議会・予算の時期を避ける** |

**4行目です。**

**係長級は、議会対応や予算の編成に関わることがあります。**

**選考の開始を、繁忙期と重ならないように選んでください。**

**扱いは**[選考スケジュールの組み方](senko-sagasu-schedule.html)**に整理しています。**

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| どこまで自分で決めたか | **専決できた事項と、起案した案件** |
| 困難な案件の対応 | 3件、経緯と結論 |
| 人をどう動かしたか | 指導の方法、作った資料 |
| 対立をどう扱ったか | 調整した相手と、落としどころ |
| なぜ変わるのか | 続けたい部分と、続けにくい部分 |

**1行目です。**

**「上司の決裁でした」で止めないでください。**

**起案の段階で何を整理したかを述べる**と、判断の過程が伝わります。

**4行目について。**

**利害が対立した案件は、面接で話しやすい材料**です。

**相手、争点、提案した方法、結果。**

**この4つで整理しておいてください。**

**なお、特定の事案が分かる説明は避けてください。**

**経緯は、一般的な形に置き換えて話して差し支えありません。**

**守秘の義務は、退職した後も続きます。****扱いは**[口コミサイトとの付き合い方](senko-sagasu-kuchikomi.html)**にも整理しています。**

## よくある失敗

**1. 専決の規程を確認しない**

**判断の範囲が文書で確認できます。**

**2. 「権限がない」と考える**

**起案も判断の一部**です。

**3. 係の人数を書かない**

**範囲が伝わりません。**

**4. 困難な事案を書かない**

**専門性の証明**になります。

**5. 指導を「指導しました」で済ませる**

**人数と作った資料**を書いてください。

**6. 管理の職種だけを探す**

**実務と管理の両方**の求人があります。

**7. 議会・予算の時期に選考を始める**

**途中で止まります。**

**8. 上位への説明の経験を書かない**

**対外の説明として読まれます。**

:::insight
ここまで書き方の話をしておいて逆のことを言いますが、**係長級で身につくもののうち、最も持ち運びやすいのは「調整」です。**面談で拝見していると、**調整を「雑務」と見ている方**がいらっしゃいます。ところが、**利害の異なる相手の間に立って、期限までに結論を作る**という仕事は、民間で常に必要とされています。事業課と財政課、本庁と出先、団体と事業者、住民と事業者。**役所の係長級は、この立場に日常的に置かれています。**そして、**調整には型があります。**関係者を洗い出す、それぞれの前提を確認する、譲れない点を見分ける、落としどころを設計する、記録に残す。**これを手順としてできる人は、多くありません。**ですから、書類には**「◯◯と◯◯の間で条件が対立した案件について、双方の前提を確認したうえで◯◯の方法を提案し、◯か月で合意」**と書いてください。**調整は、成果として書けます。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方自治法第153条第1項**は、**長が権限に属する事務の一部を補助機関である職員に委任できる**と定めています。**これを踏まえた専決の規程で、職位ごとの決裁の範囲が定められています**
- **自分が何を決めていたかは、規程で確認できます**
- 書くのは、**人数・件数・判断・指導**です
- **課長決裁の案件でも、根拠の整理と方針の起案を担ったこと**は書けます
- **困難な事案の処理**が、専門性の証明になります
- **実務と管理の両方**を含む求人が、経験と重なりやすいです
- **調整は、成果として書けます**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 係長になって間がなく、書ける実績がありません

**期間の長さより、何をしたかを書いてください。**係の事務の進行の管理、困難な事案の処理、他課との調整、新任の指導。**これらは、期間が短くても始まっています。**書き方は、**「係◯人の事務の進行を管理し、年間約◯件の処理について進捗を確認」**という形です。**数を入れると、範囲が伝わります。**また、**係長になる前の実務の経験**も併せて書いてください。**担当として処理してきた内容と、係長として運営した内容を分けて書く**と、段階が伝わります。扱いは[30代の公務員が転職するとき](senko-tachiba-30dai.html)にも整理しています。

### 部下の人数が少なく、管理の経験として弱い気がします

**人数の多さだけで判断されるものではありません。**見られているのは、**進行をどう管理したか、困難な案件にどう対応したか**です。少人数でも、**期限の管理、業務の配分、引継ぎの整理**は担っています。また、**受託した事業者への指示や確認**を担当している場合、それも人を動かした経験です。「受託事業者◯社に対し、仕様に基づく履行の確認と指示を実施」という形で書けます。なお、**少人数の進行の管理を求める求人**は多くあります。**人数の規模ではなく、担った役割の中身**で書いてください。

### 転職後、また係長のような立場になれますか

**求人の条件によります。**入社時の役割は、**求人票に書かれた内容**によって決まります。**実務が中心の募集**と、**チームの運営を含む募集**では、入社時の役割が異なります。なお、**入社直後から運営を任される求人は、多くありません。**業務を覚える期間が必要なためです。**中長期の見通しについては、面接で確認**して差し支えありません。「この役割から、どのような展開が想定されますか」という聞き方です。**確約は得られません**が、**その会社の考え方が分かります。**まずは、**求人票の仕事内容で、入社時の役割を確認**してください。
