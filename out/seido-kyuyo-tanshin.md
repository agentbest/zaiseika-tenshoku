都道府県の職員や、広い範囲に出先機関を持つ自治体の職員にとって、遠くの事務所への異動は珍しくありません。配偶者の仕事や子どもの学校の事情で、家族を残して単身で赴任することになったときに支給されるのが**単身赴任手当**です。

この記事では、**単身赴任手当の根拠、支給される要件、月額と距離による加算、届出と支給の始まり方、配偶者も公務員の場合の調整、転職したときの扱い**を整理します。

地方公務員の単身赴任手当は、各自治体が条例と規則で定めます。この記事で示す額や距離は国の条文にもとづくもので、自治体の額や基準とは限りません。自分の扱いは、所属の給与条例・規則と人事担当課で確かめてください。本記事は2026年11月時点の公開情報にもとづきます。

## 単身赴任手当の根拠——地方自治法第204条と給与条例

地方自治法第204条第2項は、条例で支給できる手当の1つとして**単身赴任手当**を挙げています。同条第3項で、手当の額と支給方法は条例で定めることとされています。

地方公務員法第25条第1項は、給与は条例にもとづいて支給しなければならないとしています。同条第3項第5号で、地方自治法第204条第2項の手当を支給する場合は、その手当に関する事項を給与条例に定めるとされています。単身赴任手当を置くかどうか、どんな条件で支給するかは、自治体の条例と規則で決まります。

ここからは、比べる物差しとして国の条文で仕組みを確かめます。

## 支給の要件——給与法第12条の2第1項

給与法第12条の2第1項は、単身赴任手当を支給する職員を定めています。要件を分けると次のとおりです。

| 要件 | 条文の内容 |
|---|---|
| きっかけ | 官署を異にする異動、または在勤する官署の移転にともなって住居を移転したこと |
| 別居の理由 | 父母の疾病その他の人事院規則で定めるやむを得ない事情により、同居していた配偶者と別居することになったこと |
| 通勤の困難 | 異動の直前の住居から、異動後の官署に通勤することが、人事院規則の基準に照らして困難であること |
| 生活の状況 | 単身で生活することを常況としていること |

ただし書で、**配偶者の住居から在勤する官署に通勤することが困難と認められない場合は支給しない**とされています。家族の住む家から通えるなら、手当は付きません。

## やむを得ない事情と通勤困難の基準——人事院規則9-89

**やむを得ない事情（第2条）**　次の事情が挙げられています。

- 配偶者が、介護を必要とする職員や配偶者の父母、同居の親族を介護すること
- 配偶者が、学校その他の教育施設に在学している同居の子を養育すること
- 配偶者が引き続き就業すること
- 配偶者が、職員や配偶者の所有する住宅を管理するため、引き続きその住宅に住むこと
- 配偶者が職員と同居できないと認められる、これらに類する事情

配偶者には、届出をしていないが事実上婚姻関係と同様の事情にある者を含むとされています。

**通勤困難の基準（第3条）**　次のどちらかに当たることとされています。

- 人事院の定めるところにより算定した通勤距離が**60キロメートル以上**であること
- 60キロメートル未満でも、通勤方法、通勤時間、交通機関の状況などから、それに相当する程度に通勤が困難と認められること

## 月額と距離による加算——第12条の2第2項・規則第4条

単身赴任手当の月額は、給与法第12条の2第2項で**3万円**とされています。職員の住居と配偶者の住居との間の交通距離が人事院規則で定める距離以上のときは、**7万円を超えない範囲**で距離の区分に応じた額を加算するとされています。

人事院規則9-89第4条は、加算が付く距離を**100キロメートル**とし、区分ごとの加算額を定めています。

| 交通距離 | 加算額 |
|---|---|
| 100km以上300km未満 | 8千円 |
| 300km以上500km未満 | 1万6千円 |
| 500km以上700km未満 | 2万4千円 |
| 700km以上900km未満 | 3万2千円 |
| 900km以上1,100km未満 | 4万円 |
| 1,100km以上1,300km未満 | 4万6千円 |
| 1,300km以上1,500km未満 | 5万2千円 |
| 1,500km以上2,000km未満 | 5万8千円 |
| 2,000km以上2,500km未満 | 6万4千円 |
| 2,500km以上 | 7万円 |

交通距離は、最も経済的かつ合理的と認められる通常の交通の経路と方法による、職員の住居から配偶者の住居までの経路の長さで算定するとされています（第4条第1項）。自治体の加算の区分は、国と同じとは限りません。

## 配偶者も公務員のとき——支給の調整（規則第6条）

人事院規則9-89第6条は、**職員の配偶者が単身赴任手当、または国や地方公共団体などのこれに相当する手当を受けている場合**は、その間、職員には単身赴任手当を支給しないとしています。夫婦がともに公務員で、それぞれが別の場所に赴任している場合は、二重に受けられない作りです。

## 届出と支給の始まり方——規則第7条・第9条

単身赴任手当は、職員が自分で届け出る手当です。

- **届出（第7条）**　要件を満たした職員は、証明する書類を添えて単身赴任届を出さなければならないとされています。住居、同居者、配偶者の住居などに変更があったときも同様です
- **支給の始まり（第9条第1項）**　要件を満たした日の属する月の翌月から支給が始まり、要件を欠いた日の属する月で終わります。ただし、**届出が事実の生じた日から15日を経過した後にされたときは、届出を受理した日の属する月の翌月から**の支給になります

国の条文では、届出が遅れると、さかのぼって支給されない月が出ることになります。自治体の届出の期限も、所属の規則で確かめてください。住居手当や通勤手当も、異動のときに届出が必要になることが多い手当です。[住居手当の記事](seido-kyuyo-jukyo.html)と[通勤手当の記事](seido-kyuyo-tsukin.html)にまとめています。

## 転職するとどうなるか

**1. 民間の単身赴任手当は会社の規程で決まる**

民間企業には、給与法第12条の2にあたる法律上の定めはありません。単身赴任手当を置くか、いくら払うか、帰省の交通費を出すかは、会社の賃金規程や転勤に関する規程で決まります。

**2. 転勤の範囲は労働条件として明示される**

労働基準法施行規則第5条第1項第1号の3は、使用者が明示しなければならない労働条件として、就業の場所と従事すべき業務に関する事項を挙げ、**就業の場所と従事すべき業務の変更の範囲を含む**としています。転勤のある会社かどうかは、労働条件通知書の「就業場所（変更の範囲）」で確かめられます。

**3. 単身赴任を避けたい人は、転勤の有無を条件にできる**

いま単身赴任をしていて、それを終えたいことが転職を考える理由の1つになっている人もいます。その場合は、手当の有無より先に、**勤務地が限定されているか、転勤があるならどの範囲か**を確かめてください。

自分の経歴がどう言い換えられるかは、一度話しながら整理したほうが早いことが多いです。[相談の申込みはこちら](../apply.html)

:::insight
単身赴任中の方が民間の求人を見るとき、「地元の勤務地」で絞り込むと、行政が相手の求人は思ったより少なく見えることがあります。自治体向けのシステムやコンサルの会社は、本社を大都市に置き、地方の顧客には出張や常駐で対応する形をとることがあるためです。ここで見落とされやすいのが、**勤務地とは別に「担当エリア」「出張の頻度」「リモートの可否」が求人票に書かれている**点です。勤務地が遠くても、在宅中心で月に数回の出張という条件なら、家族と暮らしながら働ける場合があります。逆に、勤務地は近くても全国の自治体を回る営業職なら、家を空ける日数は今より増えることもあります。勤務地の欄だけでなく、移動の条件まで読んで比べてください。
:::

## 誤解されやすい点

**「離れた場所に異動すれば必ず支給される」と思い込む**

国の条文では、配偶者と別居することになった理由が人事院規則で定めるやむを得ない事情に当たること、通勤が困難であること、単身で生活していることが要件です（給与法第12条の2第1項、規則第2条・第3条）。配偶者の住居から通勤できるなら支給されません。

**「手当は異動の月からさかのぼって出る」と思い込む**

国では、届出が事実の生じた日から15日を経過した後にされると、届出を受理した月の翌月からの支給になります（規則第9条第1項ただし書）。

**「夫婦とも公務員ならそれぞれ受けられる」と思い込む**

配偶者が単身赴任手当や国・地方公共団体のこれに相当する手当を受けている間は、職員には支給されません（規則第6条）。

:::insight
単身赴任が続くと、家族のために転職を、と考えるのは自然なことです。ただ、**この条件なら、いま動かない選択にも理があります。**自治体の異動には周期があり、次の異動で通える範囲に戻れる見込みがあるなら、そちらを待ったほうが、仕事の連続性も家族の生活も保ちやすい場合があります。人事の希望調書で家庭の事情を伝えられる仕組みがあるなら、まずそれを使ってから考えても選択肢は減りません。一方で、単身赴任が繰り返される見込みが高い職種なら、民間で勤務地が限定された職を探す意味はあります。比べるなら、次の異動の見込みと、転勤のない求人の範囲を並べてください。在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担）。
:::

## まとめ

- 単身赴任手当は、地方自治法第204条第2項にもとづき**条例で支給できる手当**の1つ。要件と額は自治体の条例・規則で決まる
- 国では、異動にともなって住居を移し、**やむを得ない事情で配偶者と別居**し、**通勤が困難**で、単身で生活している職員に支給する（給与法第12条の2第1項）
- やむを得ない事情は、介護、子の養育、配偶者の就業、持ち家の管理など。通勤困難の基準は通勤距離60km以上など（規則第2条・第3条）
- 国の月額は**3万円**。交通距離100km以上で、距離に応じて8千円から7万円までの加算（第12条の2第2項、規則第4条）
- **届出が15日を過ぎると、支給の始まりが遅れる**（規則第9条）。転職先では、手当の有無より先に転勤の範囲を確かめる

## よくある質問

### 配偶者がいない場合、子どもと離れて赴任しても単身赴任手当は出ますか

**国の給与法第12条の2第1項は、同居していた配偶者と別居することを要件にしています。**配偶者のいない職員の扱いについて人事院規則に別の定めがあるかどうかは、この記事では確かめていません。自治体の扱いは条例と規則で決まるので、人事担当課で確かめてください。

### 単身赴任手当は税金の対象になりますか

**一般的には、単身赴任手当も給与の一部として、所得税の源泉徴収の対象になります。**職務上の出張の際の帰宅など、旅費の扱いが関わる場面は個別性が高いので、所属の給与担当と税務署の案内で確かめてください。共済の掛金の計算にどう入るかは、所属の共済組合の案内で確認するのが確実です。

### 新しく採用されたときに単身になる場合も支給されますか

**国の条文では、新たに俸給表の適用を受ける職員となったことにともなって住居を移し、配偶者と別居することになった職員のうち、人事院規則で定める職員にも、異動の場合に準じて支給するとされています**（給与法第12条の2第3項）。対象の範囲は人事院規則9-89第5条に定められています。自治体の扱いは条例と規則で確かめてください。
