まちづくりの志望動機で、**いちばん多く見かける書き出し**があります。

**「地域を良くする仕事に、引き続き関わりたいと考えました」**

**気持ちは伝わりますが、選考では効きません。**

理由は2つあります。**1つは、その一文が、どの会社にも当てはまること。**もう1つは、**「引き続き」と書いた時点で、役所でもできることになってしまう**ことです。

**相手が知りたいのは、「なぜ役所の側ではないのか」**です。

**その答えは、手続きの仕組みを見ると、はっきりします。**この記事では、**そこから志望動機を組み立てる手順**を扱います。業界の構造は[未経験からまちづくり・都市開発に入るには](industry-machizukuri-mikeiken.html)、条件の確かめ方は[まちづくり・都市開発の年収と働き方](industry-machizukuri-nenshu.html)にあります。

## 行政の側の関わり方は、手続きで決まっています

**都市計画法第16条第1項**です。

> **（公聴会の開催等）第十六条　都道府県又は市町村は、次項の規定による場合を除くほか、都市計画の案を作成しようとする場合において必要があると認めるときは、公聴会の開催等住民の意見を反映させるために必要な措置を講ずるものとする。**

そして、**同法第17条第1項**です。

> **（都市計画の案の縦覧等）第十七条　都道府県又は市町村は、都市計画を決定しようとするときは、あらかじめ、国土交通省令で定めるところにより、その旨を公告し、当該都市計画の案を、当該都市計画を決定しようとする理由を記載した書面を添えて、当該公告の日から二週間公衆の縦覧に供しなければならない。**

**同条第2項**は、**公告があったときは、関係市町村の住民及び利害関係人が、縦覧期間満了の日までに意見書を提出できる**という構造です。

**この2つの条文が示しているのは、行政の側の住民との接し方が、手続きとして定まっている**ということです。

**公聴会を開く。案を縦覧に供する。意見書を受け付ける。**

**⚠ これは、行政が住民と関わらないという意味ではありません。****関わり方が、制度として枠づけられている**ということです。

## 民間の側は、枠の外でも関わります

**[未経験からまちづくり・都市開発に入るには](industry-machizukuri-mikeiken.html)で扱った都市再開発法第11条第1項**を、もう一度見てください。

> **第一種市街地再開発事業の施行区域内の宅地について所有権又は借地権を有する者は、五人以上共同して、定款及び事業計画を定め、**（中略）**都道府県知事の認可を受けて組合を設立することができる。**

**「五人以上共同して」**——この合意は、**縦覧や意見書では作れません。**

**個別に伺い、何度も話し、条件を詰める。**この工程が、**組合の設立の前に必要です。**

| | 行政の側 | 民間の側 |
|---|---|---|
| 住民との接点 | **公聴会、縦覧、意見書** | **個別の訪問、勉強会、何度もの協議** |
| 期間 | 手続きの期間が定まっている | **年単位で続く** |
| 相手 | 住民・利害関係人 | **一人ひとりの権利者** |
| 到達点 | 計画の決定 | **合意の形成** |

**右の列が、この業界の仕事**です。

**志望動機は、ここに接続させてください。**「地域を良くしたい」ではなく、**「手続きの枠の外で、合意を作る側に回りたい」**です。

## 3つの層に分けます

| 層 | 問い | 材料の出どころ |
|---|---|---|
| ① 機能 | **なぜ、合意を作る仕事なのか** | 役所での担当の経験 |
| ② 会社 | **なぜ、この会社なのか** | 実績のページ、求人票 |
| ③ 立場 | **なぜ、行政ではなく事業者の側なのか** | 自分の考えの変化 |

## ① 合意を作った経験は、役所にあります

| 役所での担当 | 接続する場面 |
|---|---|
| 用地の取得・補償の折衝 | **権利者との個別の協議** |
| 住民説明会の運営 | 勉強会、説明会の設計 |
| 計画の策定（意見の取りまとめ） | **意見の整理と、計画への反映** |
| 審議会・委員会の事務 | 組合の総会・理事会の運営 |
| 苦情・相談の対応 | 反対されている方への対応 |
| 関係課との調整 | **行政の各課との協議** |

**書き方は、「調整しました」で止めないでください。****何を背負ったか**を書きます。

> 道路の事業に係る用地の取得を担当し、権利者◯名との折衝を行いました。事業の工期という動かせない期限と、個別の事情の間に立って、順序と条件を組み立てる仕事でした。全員の合意までに◯年を要した案件もあります。

**「年単位で向き合った」という事実**が、この業界では材料になります。

## ② 会社は、実績のページから取ります

**この業界は、実績が公表されていることが多い**です。

| 資料 | 志望動機に使える材料 |
|---|---|
| 実績のページ | **どの地域で、どういう規模の事業を扱ってきたか** |
| 事業の紹介 | 再開発か、区画整理か、計画の策定か |
| 求人票の仕事内容 | **その職種の日々の中身** |
| 求人票の募集の背景 | 増員か後任か |
| 会社の沿革 | 何から始まって、どこへ広げたか |

**使い方は、「読みました」ではなく「読んで、自分の経験とどこが重なったか」**です。

> 実績を拝見し、地方都市の中心市街地での事業を継続して扱われていることが分かりました。私が担当していたのも、同じ規模の自治体の中心部です。権利者に高齢の方や、店舗を営まれている方が多い地区での進め方は、想像がつきます。

**⚠ ただし、前の職場で知り得た内部の事情や、特定の権利者に関する情報は書かないでください。**守秘の観点に加えて、**それを書く人は、次の職場の情報も外で話す**と見られます。

## ③ 行政ではなく、事業者の側である理由

**必ず問われます。**相手が確かめたいのは2つです。

| 相手の懸念 | 確かめたいこと |
|---|---|
| **指導する目線のまま来ないか** | 事業者の側に立てるか |
| **止まった案件に耐えられるか** | 異動で離れられないことを分かっているか |

**答え方の型は、「決めるところまでではなく、動き出すところまで」**です。

> 都市計画の決定に関わる仕事をしてきました。決定までは制度の手続きで進みますが、実際に事業が動き出すには、権利者の合意という別の工程が要ります。決定までで手が離れる立場ではなく、動き出すところまで関わる立場に移りたいと考えました。

**もう一つの型は、「最後まで見たい」**です。

> 担当した地区の計画が完成形になるのは、自分が異動したずっと後です。途中で引き継ぐ形でしか関われないことに、物足りなさがありました。同じ案件に長く関わる働き方を選びたいと考えました。

**⚠ 避けてください——役所の批判から入る書き方**です。「行政は動きが遅い」「制度が硬直している」。**読む側から見ると、次は当社の悪いところを外で言う人に見えます。**

:::insight
面接に同席させていただいていて、**この業界で評価が分かれる瞬間**があります。**「まとまらなかった案件は、どう扱いましたか」**という質問への答え方です。多くの方が、**最終的にまとまった話**に持っていこうとされます。ところが、この質問で確かめられているのは、**まとまらない状態に、どれだけ居続けられるか**です。この仕事では、**反対されている権利者の方と、何年も向き合い続ける**ことがあります。説得できないまま、それでも関係を切らずに通い続ける。**役所であれば、異動で担当が変わりました。**この業界では、変わりません。ですから、評価される答えは、**「まとまりませんでした」で終わってよい**のです。「◯年かけましたが、最終的にご同意はいただけませんでした。ただ、反対の理由は最後まで伺い続けて、記録に残しました。次の担当が同じ説明を一からしなくて済むようにしました」。**この答えには、続ける力と、引き継ぐ配慮の両方が入っています。**うまくいった話だけを並べる方より、**こちらのほうが信用されます。**用地の折衝や、苦情の対応を長く担当した方は、**こういう経験を必ず持っておられます。**思い出して、書き出しておいてください。
:::

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 経験 | 志望動機での使い方 |
|---|---|
| 用地の取得・補償の折衝 | **権利者との個別の協議に直結** |
| 住民説明会の運営 | 勉強会・説明会の設計 |
| 計画の策定 | **策定の手順を知っている** |
| 行政との協議の段取り | **どの課と、どの順で話すかが分かる** |
| 補助の制度の活用 | 交付する側にいた |
| 審議会・委員会の事務 | 組合の運営の支援 |

**効きにくい場所**

| 経験の不足 | 面接での扱い方 |
|---|---|
| 受注の提案 | **売り込む工程が役所に無い** |
| 事業の採算の判断 | 構造の理解を示す |
| 不動産の相場の感覚 | 入ってから覚える領域 |
| 建物の設計・施工の知識 | 分野による |

**2つ目について。****予算の執行と、事業の採算は、見る方向が逆**です。

**「予算は使い切ってよい上限として管理されますが、事業の収支は費用が少ないほうがよい。方向が逆だと理解しています」**と言えると、**覚悟の表明より説得力があります。**

## 材料を集める順番

| 順 | やること | 目安 |
|---|---|---|
| 1 | **年単位で向き合った経験**を3つ書き出す | 1時間 |
| 2 | そのうち、**まとまらなかったもの**に印を付ける | 20分 |
| 3 | 応募先の**実績のページ**を読む | 1時間 |
| 4 | 自分が関わった地域・規模と**重なるもの**を探す | 30分 |
| 5 | ③の型（動き出すところまで／最後まで見たい）を決める | 20分 |
| 6 | ①②③を**つなげて300字**にまとめる | 40分 |

**2つ目を飛ばさないでください。**この業界では、**まとまらなかった経験のほうが材料になります。**

## 面接で聞かれやすいこと

| 聞かれること | 何を確かめられているか |
|---|---|
| なぜ行政ではないのですか | **③の中身** |
| 権利者と直接話した経験はありますか | 合意形成の経験 |
| まとまらなかった案件は、どう扱いましたか | **止まった状態への耐性** |
| 案件が10年続くことに抵抗はありますか | 時間の感覚 |
| 行政との協議で、どちらの立場に立ちますか | **元の所属に引きずられないか** |

**5つ目は、必ず聞かれます。****「事業者の側に立ちます。ただし、行政の側の制約も分かるので、通らない計画を持ち込まないで済みます」**が自然です。

**⚠ 「元の所属に配慮します」と答えないでください。**

:::insight
ここまで組み立て方の話をしてきましたが、**この業界を志望される方には、先に確認していただきたいことがあります。****前の職場と取引のある会社に移る場合、在職中の職務との関係が問題になることがある**という点です。まちづくりの事業では、**自治体と民間の会社が委託や協議の関係にある**ことが多く、**自分が担当していた事業の相手方に移る**という形になりやすい。⚠ **再就職に関する規制は、国家公務員と地方公務員で異なり、地方公務員については自治体ごとに定めがあります。**離職前の職務との関係で、**一定期間、特定の行為が制限される**場合があります。**⚠ この記事では、個別の事情について判断できません。必ず、所属の人事担当部署と、適用される条例・規程を確認してください。**志望動機を書き始める前に確認しておくと、**応募先の選び方そのものが定まります。**確認した結果、候補から外れる会社が出てくることもありますが、**それは早い段階で分かったほうが良い**ことです。選考が進んでから問題になるより、**最初に確認しておくほうが、双方にとって負担が軽くて済みます。**当社が、いまの職を辞めることをお勧めすることはありません。**確認した結果、残るという結論も正しい結論です。**
:::

## まとめ

- **「地域を良くしたい」は、志望動機になりません。**役所でもできることになってしまいます
- **都市計画法第16条第1項**は、**公聴会の開催等、住民の意見を反映させるために必要な措置**を定めています
- **同法第17条第1項**は、**都市計画の案を公告の日から二週間公衆の縦覧に供する**ことを義務づけ、**第2項**で**住民及び利害関係人の意見書の提出**を定めています
- **行政の側の住民との接し方は、手続きとして枠づけられています。**民間の側は、**その枠の外で、個別に合意を作ります**
- 志望動機は、**①機能（なぜ合意を作る仕事か） ②会社 ③行政ではない理由**の3層に分けます
- ①の材料は、**用地の折衝、住民説明会、計画の策定、審議会の事務、苦情の対応**にあります
- ⚠ **まとまらなかった経験を、必ず1つ用意してください。**この業界では**止まった状態に居続けられるか**が見られます
- ③は、**「動き出すところまで」**または**「最後まで見たい」**の型で書きます。**役所の批判から入らない**でください
- ⚠ **前の職場と取引のある会社に移る場合、再就職に関する規程の確認が要ります。**所属の人事担当部署に確認してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 用地や都市計画の経験がありません。志望動機が書けません

**①の層を、別の経験で組み立ててください。**この業界で効くのは、**制度の名前ではなく動作**です。**利害の対立する相手と、年単位で向き合った経験**があれば、分野は問いません。滞納の整理、福祉の相談、事業者の指導、苦情の対応。**どれも、相手の事情を聞き、こちらの制約を説明し、落とし所を探す仕事**です。書き方は、**「都市計画の経験はありませんが、◯件について、相手の事情を個別に確認しながら◯年かけて処理しました」**という形です。そのうえで、**まちづくり会社やエリアマネジメントの分野**であれば、商工・観光・文化・生涯学習の経験も直接効きます。**分野で候補を狭めないでください。**

### 「まちづくりが好き」という動機では弱いですか

**それだけでは弱いです。**ただし、**捨てる必要はありません。**問題は、**好きであることが、仕事ができることの説明になっていない**という点です。使い方としては、**①②③を組み立てたうえで、最後に一言添える**形にしてください。先に持ってくると、**他の応募者と区別がつかなくなります。**また、**「好き」の中身を具体化する**と強くなります。どの地区の、どういう変化を見て、何を面白いと思ったのか。**自分が担当した地区でも、住んでいる町でも構いません。**具体的な場所と出来事に紐づいていれば、**関心が本物であることが伝わります。**抽象的な「まちづくりが好き」は、**誰でも書けます。**

### 志望動機は、何社ぶん書き分ける必要がありますか

**①は共通で構いません。②と③は、会社ごとに書き直してください。**①は「なぜ合意を作る仕事か」なので、**同じ経験が材料になります。**②はその会社の実績から取った材料なので、**使い回すと読んでいないことが分かります。**③も、**会社の性格で説得力のある型が変わります。**大規模な事業を扱う会社なら「動き出すところまで」、地域に根ざした会社なら「最後まで見たい」。**同じ言葉でも、置く場所で意味が変わります。**なお、⚠ **応募先を選ぶ前に、再就職に関する規程の確認を済ませておいてください。**書き分けの作業をしたあとで候補から外れると、時間が無駄になります。
