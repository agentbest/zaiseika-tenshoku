**契約の事務を担当してきた方が、民間の契約書を読むと違和感を覚えます。**

**前提が違う**ためです。

この記事では、**違いの中身**と、**読み方**を扱います。

## 自治体の契約には、方法と確定の要件が定められています

**地方自治法第234条第1項**です。

> **売買、貸借、請負その他の契約は、一般競争入札、指名競争入札、随意契約又はせり売りの方法により締結するものとする。**

**同条第2項**です。

> **前項の指名競争入札、随意契約又はせり売りは、政令で定める場合に該当するときに限り、これによることができる。**

**同条第5項**は、**契約の確定**について定めています。

> 普通地方公共団体が契約につき契約書又は契約内容を記録した電磁的記録を作成する場合においては、当該普通地方公共団体の長又はその委任を受けた者が契約の相手方とともに、**契約書に記名押印し**（略）**なければ、当該契約は、確定しないものとする。**

**つまり、自治体の契約は、方法が法定され、確定の要件も定められている**ということです。

**民間の契約は、この枠組みの外**にあります。

**ここが、最初に押さえる違い**です。

## 違いの整理

| 項目 | 自治体の契約 | 民間の契約 |
|---|---|---|
| 方法 | **法令で定められた方法** | 当事者が決める |
| 相手方の選定 | 競争入札が原則 | 交渉・選定は自由 |
| 条項 | **標準の様式・約款が多い** | 案件ごとに異なる |
| 交渉の余地 | 小さい | **大きい** |
| 確定の要件 | 条文に定めがある | 契約の内容による |
| 変更 | 変更の契約の手続 | 合意による |

**4行目が、最も大きな違い**です。

**自治体では、条項がほぼ決まっており、交渉する場面が限られます。**

**民間では、条項そのものが交渉の対象**になります。

**したがって、「読む」だけでなく、「どこを直すべきか」を考える必要があります。**

## 民間の契約書で見るところ

| 条項 | 見るところ |
|---|---|
| ① 業務の範囲 | **どこまでが約束の内容か** |
| ② 対価と支払 | 金額、時期、条件 |
| ③ 期間・更新 | 自動で更新されるか |
| ④ 解除 | **どういう場合に解除できるか** |
| ⑤ 損害賠償 | 上限の定めがあるか |
| ⑥ 秘密の保持 | 範囲と期間 |
| ⑦ 知的財産 | 成果物の権利の帰属 |
| ⑧ 再委託 | 可否と条件 |

**①と④が中心**です。

**①について。**

**「業務の範囲」が曖昧だと、後から追加の作業を求められます。**

**自治体の仕様書では、範囲が細かく書かれる**ことが多いものです。

**民間では、簡潔に書かれることがあります。**

**この違いに注意してください。**

**⑦について。**

**自治体の契約では、成果物の権利の扱いが約款で定められている**ことがあります。

**民間では、案件ごとに異なります。**

## 自治体の契約実務で身についていること

| 経験 | 民間での読まれ方 |
|---|---|
| 仕様書の作成 | **業務の範囲の設計** |
| 予定価格の積算 | 原価の見積り |
| 入札・選定の手続 | 調達の手続 |
| 履行の確認・検査 | 検収、品質の確認 |
| 変更の契約 | 変更の管理 |
| 債権の管理 | 支払の管理 |

**1行目です。**

**仕様書を書いた経験は、「業務の範囲を言葉にする力」**として読まれます。

**民間の契約書で最も争いになるのが、この範囲**です。

**書き方は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

:::insight
契約について、**面談でお伝えしているのが「発注する側にいた経験を書いてください」**という点です。自治体の契約の事務を担当してきた方は、**発注者として仕様を作り、選定し、履行を確認してきました。**一方、民間で契約書を扱う多くの場面は、**受注する側**です。**この違いが、そのまま価値になります。**受託する会社では、**「発注者は何を見ているか」「仕様のどこを重く見るか」「検査で何を確認されるか」**を知っている人が必要とされます。とくに、**行政が相手の事業では、提案書と仕様の読み合わせが仕事の中心**になります。**発注した側の視点は、そこで直接使えます。**書類には、**「発注者として、仕様書の作成から履行の確認までを担当」**と明記してください。**「契約事務の経験」ではなく、「発注する側の経験」**と書くだけで、読まれ方が変わります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 読む順序

| 順 | 見るところ |
|---|---|
| 1 | **業務の範囲**（別紙・仕様を含む） |
| 2 | 対価と支払の条件 |
| 3 | 期間と更新 |
| 4 | 解除と損害賠償 |
| 5 | 秘密の保持、知的財産 |
| 6 | 変更の手続 |

**1を最初に読んでください。**

**別紙や仕様書に本体があることが多い**ためです。

**本文だけを読むと、範囲が分かりません。**

**6について。**

**変更の手続が定められていないと、後から追加の作業が生じたときに扱いが決まりません。**

## 学ぶ前に考えること

| 確認すること | 内容 |
|---|---|
| ① すでにある経験 | **仕様、選定、検査** |
| ② 応募したい求人の条件 | 契約の知識が要件か |
| ③ 目的 | 法務に進むのか、調達か、受託の管理か |
| ④ 期限 | 応募の時期までに間に合うか |

**①を先に整理してください。**

**契約の実務を経験しているなら、その整理が学習より先**です。

**なお、資格を取れば転職できる、という関係にはありません。**

**どの立場で、何を判断してきたか**が、評価の対象です。

[経験の言い換えから相談する](../apply.html)こともできます。

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 行政が相手の事業 | **発注者の視点** |
| ② 調達・購買 | 選定、条件の確認 |
| ③ 契約・法務の部門 | 条項の確認 |
| ④ 受託の管理 | 履行、変更、検収 |
| ⑤ 営業の事務 | 条件の整理 |

**①と④が、経験と最も重なります。**

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 何を担当したか | **件数、金額の規模、契約の種類** |
| どこまで自分で決めたか | 専決できた事項 |
| 難しい局面の対応 | 3件、経緯と結論 |
| 仕様の作り方 | 範囲をどう決めたか |
| 検査で見たところ | 確認の項目 |

**4行目です。**

**仕様の範囲をどう決めたかは、民間でも同じ論点**になります。

**「過去の実績と、必要な体制から作業の量を見積もり、範囲を定めた」**という形で説明できます。

**なお、特定の事業者が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

## よくある失敗

**1. 本文だけを読む**

**別紙と仕様**に本体があります。

**2. 業務の範囲を確認しない**

**後から追加の作業**が生じます。

**3. 変更の手続を見ない**

**扱いが決まりません。**

**4. 「契約事務の経験」とだけ書く**

**発注する側の経験**と書いてください。

**5. 仕様書の作成を書かない**

**範囲を言葉にする力**として読まれます。

**6. 検査の経験を書かない**

**検収・品質の確認**にあたります。

**7. 交渉の余地がない前提で読む**

**民間では条項が交渉の対象**です。

**8. 資格を取れば進めると考える**

**何を判断してきたか**が評価の対象です。

:::insight
ここまで違いの話をしておいて逆のことを言いますが、**自治体の契約実務で身につく「疑う読み方」は、そのまま使えます。**面談で拝見していると、**「決まった様式しか扱っていないので、応用が利かない」と考える方**がいらっしゃいます。ところが、**契約の事務では、書かれていない事態を想定する習慣**が身につきます。履行が遅れたらどうするか、数量が変わったらどうするか、瑕疵があったらどうするか。**これらは、様式が決まっていても、案件ごとに確認してきたはずです。**そして、**民間の契約書を読むときに必要なのも、同じ想定**です。「この条項だと、こういう場合に困る」と気づけるかどうか。**この感覚は、条文の知識より実務で身につきます。**ですから、**「様式が決まっていた」ことを弱みとして語らないでください。**決まった様式の中で、**何を確認してきたか**を書いてください。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方自治法第234条第1項**は、契約の方法を**一般競争入札・指名競争入札・随意契約・せり売り**とし、**同条第2項**で後三者を政令で定める場合に限っています
- **同条第5項**は、**記名押印等がなければ契約は確定しない**としています
- **民間の契約は、この枠組みの外**にあります。**条項そのものが交渉の対象**です
- 読む順序は、**①業務の範囲 ②対価と支払 ③期間 ④解除と損害賠償**です
- **別紙と仕様に本体があります。**本文だけを読まないでください
- **「契約事務の経験」ではなく「発注する側の経験」**と書いてください
- **書かれていない事態を想定する習慣**は、そのまま使えます

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 随意契約の事務しか経験がありません

**それでも書けます。**随意契約では、**理由の整理と、相手方の選定の妥当性の説明**が求められます。「政令の定めに該当する理由を整理し、決裁の資料を作成」「見積りを◯者から徴し、内容を比較のうえ選定」という形です。**判断の根拠を作った経験**として読まれます。なお、**競争入札の経験がないこと自体は、問題になりません。**求人票の応募条件を確認してください。「調達の経験」「契約の事務の経験」と書かれていれば、**該当します。**読み方は[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。

### 民間の契約書を、どう勉強すればよいですか

**実物を読むのが近道です。**公表されている契約書の様式や、業界団体が示す約款を読むと、**条項の並び方が分かります。**そのうえで、**自分が扱ってきた自治体の契約書と比べて**ください。**どの条項が増えているか、どの条項が簡潔になっているか。**比べると、違いが具体に見えます。なお、**体系的に学ぶ手段として、資格や検定を使うこともできます。**ただし、**応募の時期が近い場合は優先順位を下げて**ください。**職務経歴書の作成と、求人を読む作業**のほうが、時期に直接効きます。

### 法務の部門に移りたいのですが、応募できますか

**応募条件によります。**法務の部門では、**企業の法務の経験や、法学の専門的な知識**が要件とされることがあります。一方、**契約の管理、調達、受託の管理**の職種では、**自治体の契約実務が直接使えます。**まずは、**求人票の「必須」の欄**を読んでください。なお、**行政が相手の事業を行う会社**では、**契約の相手方が自治体**であるため、**自治体の契約の仕組みを知っている人**が必要とされます。**法務という職種名で絞らず、仕事内容の欄で探して**ください。扱いは[職種を変える転職と、変えない転職](senko-tachiba-shokushutenkan.html)に整理しています。
