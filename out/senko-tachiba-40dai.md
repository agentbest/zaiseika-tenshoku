**係長、課長補佐、課長。**

**段階が上がり、担う範囲が変わった段階**です。

この記事では、**管理の経験の書き方**と、**求人の選び方**を扱います。

## 段階ごとに、求められる能力が定められています

**地方公務員法第15条の2第1項**です。

> 二 **昇任** 職員をその職員が現に任命されている職より**上位の職制上の段階に属する職員の職に任命する**ことをいう。
>
> 五 **標準職務遂行能力** **職制上の段階の標準的な職の職務を遂行する上で発揮することが求められる能力**として任命権者が定めるものをいう。

**同条第2項**です。

> 前項第五号の標準的な職は、**職制上の段階及び職務の種類に応じ、任命権者が定める。**

**段階ごとに、求められる能力が別に定義されている**ということです。

**多くの団体が、この標準職務遂行能力を定めて公表しています。**

**自分の団体のものを読むと、段階ごとに何が求められていたかが、そのまま言葉になっています。**

**職務経歴書の材料として使えます。**

## 何が見られているか

| 項目 | 内容 |
|---|---|
| ① 管理の範囲 | **人数、予算、事業の数** |
| ② 判断の範囲 | どこまで自分で決めたか |
| ③ 組織の運営 | 進行の管理、配分、調整 |
| ④ 人の育成 | 指導した人数、方法 |
| ⑤ 対外の折衝 | 相手と、難易度 |
| ⑥ 制度の設計 | 要綱、手順、仕組みを作った経験 |

**①と②が中心**です。

**「課長補佐を務めました」だけでは、範囲が伝わりません。**

**人数、扱った予算の規模、担当した事業の数。**

**これらを数で書いてください。**

## 書き方の例

**悪い例**

> ◯◯課で課長補佐として、課の運営に従事しました。

**良い例**

> ◯◯課で課長補佐として、**係◯つ・職員◯人の事務を統括。**年間約◯億円の事業予算の執行の管理を担当し、**議会への説明資料の作成と答弁の調整**を担った。**制度改正に伴い要綱と様式を改正し、対象者約◯件への周知と、窓口の説明の手順を整備。**

**「人数」「金額」「作ったもの」が入っています。**

**これが、民間で読まれる形**です。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 管理の経験の言い換え

| 役所の言葉 | 民間での読まれ方 |
|---|---|
| 課の運営 | **組織の運営、進行の管理** |
| 予算の執行の管理 | 予算の管理、原価の管理 |
| 議会への説明 | 対外の説明、経営層への報告 |
| 要綱の改正 | 制度の設計、規程の整備 |
| 監査への対応 | 内部統制、是正の対応 |
| 係間の調整 | 部門間の調整 |

**3行目です。**

**議会への説明は、民間では「経営層や社外への説明」に近い**位置づけになります。

**資料を作り、想定される問いに備え、期限までに整える。**

**この動作は、業界を問わず必要とされます。**

## 求人の選び方

| 種類 | 内容 |
|---|---|
| ① 管理の職種での募集 | 部門の責任者、管理部門 |
| ② 専門の職種での募集 | **経験のある分野での実務** |
| ③ 行政が相手の事業 | 発注者支援、制度の支援、施設の運営 |
| ④ 立ち上げの役割 | 新規の受託にともなう体制の整備 |

**②を候補から外さないでください。**

**管理の職種に限ると、求人の数が限られます。**

**専門の分野での実務であれば、候補が広がります。**

**④について。**

**指定管理や業務の受託が決まった後、体制を整える役割**があります。

**手順を作る経験が、そのまま使えます。**

:::insight
40代のご相談で、**面談でお伝えしているのが「管理の経験を、役職名で伝えないでください」**という点です。**「課長補佐でした」「課長でした」という説明は、役所の中では通じます。**ところが、**民間では、同じ名称でも範囲が違います。**課長が数人を見る会社もあれば、数十人を見る会社もあります。**ですから、名称ではなく数で伝えてください。**職員が何人、係がいくつ、予算がいくら、事業がいくつ。**この4つの数字があれば、範囲が伝わります。**そして、**もう1つ加えていただきたいのが「何を決めていたか」**です。予算の配分、人の配置、事業の優先順位、外部への説明の内容。**決めた範囲が、そのまま責任の範囲**です。役所では、**決裁の区分として明文化されている**はずです。**自分の職位で専決できた事項を確認してください。**それが、判断の範囲の説明になります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 条件の整理

| 項目 | 考えること |
|---|---|
| 役割 | 管理か、実務か、両方か |
| 勤務地 | 転勤の可否 |
| 処遇の構成 | 基本給と手当の内訳 |
| 制度 | 休暇、在宅勤務 |
| 期間の見通し | いつまで働きたいか |

**5行目です。**

**40代では、残る期間を意識した選択になります。**

**定年までの期間、その後の働き方。**

**この見通しがあると、求める条件が決まります。**

**なお、処遇の条件は会社の制度によって決まります。**

**応募の段階で、構成を確認**してください。読み方は[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。

[経験の言い換えから相談する](../apply.html)こともできます。

## 準備の順序

| 順 | やること |
|---|---|
| 1 | **自分の団体の標準職務遂行能力を読む** |
| 2 | 段階ごとに担った役割を書き出す |
| 3 | 人数・金額・事業の数を確認する |
| 4 | 専決できた事項を確認する |
| 5 | 民間の言葉に置き換える |
| 6 | 求人を読む |

**1と4が、この年代ならではの作業**です。

**どちらも、公表されている資料や規程で確認できます。**

## 在職中の進め方

| 項目 | 内容 |
|---|---|
| 資料の確認 | 標準職務遂行能力、決裁の区分 |
| 数の確認 | 職員数、予算、事業の数 |
| 求人を読む | 週に30分 |
| 日程の確保 | 議会・予算の時期を避ける |

**4行目です。**

**この年代は、議会対応や予算の編成で時間が取りにくい時期があります。**

**選考の開始を、繁忙期と重ならないように選んでください。**

**扱いは**[選考スケジュールの組み方](senko-sagasu-schedule.html)**に整理しています。**

**なお、資料の確認と数の確認は、繁忙期でもできます。**

**動けない時期に材料を揃えておくと、動ける時期に一気に進められます。**

## よくある失敗

**1. 役職名で伝える**

**数で伝えて**ください。

**2. 判断した範囲を書かない**

**専決の区分**を確認してください。

**3. 管理の職種だけを探す**

**専門の分野での実務**も候補です。

**4. 議会対応を書かない**

**対外の説明の経験**として読まれます。

**5. 標準職務遂行能力を読まない**

**段階ごとの言葉がそのまま使えます。**

**6. 制度を作った経験を書かない**

**要綱、手順、様式**は成果物です。

**7. 期間の見通しを持たない**

**求める条件が決まりません。**

**8. 処遇の構成を確認しない**

**基本給と手当の内訳**を見てください。

:::insight
ここまで書き方の話をしておいて逆のことを言いますが、**40代で求められるのは、管理ができることだけではありません。**面談で拝見していると、**「管理職として採用されなければ意味がない」と考える方**がいらっしゃいます。ところが、**中途採用で実際に評価されているのは、「判断できること」**です。**前例のない事案に、根拠を組み立てて結論を出す。**役所で長く働いた方は、この経験を積んでいます。制度の要件に当てはまらない申請、他団体に例のない事案、災害時の対応。**これらは、年数がないとできません。**そして、**この能力は、管理の職位でなくても使えます。**専門の分野の担当として入り、**難しい案件を任される**という形もあります。ですから、**職位にこだわらず、判断が求められる役割を探してください。**求人票の「応募条件」に、**「判断」「調整」「折衝」**という言葉があれば、該当します。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方公務員法第15条の2**は、**昇任を「上位の職制上の段階に属する職への任命」**、**標準職務遂行能力を「職制上の段階の標準的な職の職務の遂行に求められる能力」**と定義しています
- **段階ごとに求められる能力が定められている**ため、**公表されている標準職務遂行能力が書類の材料**になります
- 管理の経験は、**役職名ではなく数**で伝えてください。**人数・予算・事業の数**です
- **何を決めていたか**を書いてください。**専決の区分**で確認できます
- **議会への説明**は、対外の説明の経験として読まれます
- **管理の職種だけに絞らない**でください。専門の分野での実務も候補です
- **判断が求められる役割**を探してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 管理職の求人は少ないと聞きました

**募集の形が分かれています。**管理の職位での募集は、**数が限られる**のが一般的です。一方、**専門の分野での実務の募集**では、**経験の長い人が求められる**ことがあります。また、**新規の受託にともなう体制の整備**では、**立ち上げから関われる人**が必要になります。判断の目安は、**求人票の応募条件**です。「マネジメントの経験」が必須なら管理の職位、「◯◯分野での実務経験」なら専門の職種です。**どちらも見てください。**行政が相手の事業では、**制度の理解と判断の経験が要件**になっていることがあります。探し方は[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)に整理しています。

### 部下を持った経験がありません

**書ける内容はあります。**新任の担当者への指導、他課との調整、事業の進行の管理、外部の事業者への指示。**これらは、部下を持たなくても経験している**ことがあります。書き方は、**「新任の担当者◯人に対し、確認の手順書と記入例を作成して指導」「受託事業者◯社に対し、仕様に基づく履行の確認と指示を実施」**という形です。**人を動かした事実**が伝わります。また、**専門の分野での実務を中心に組み立てる**という選択もあります。**管理の経験がないことを理由に、応募を狭めないでください。**求人票の必須の欄を読んで判断してください。

### 処遇の条件は、どう確認すればよいですか

**求人票の賃金の欄と、内定時の提示の両方を確認**してください。求人票では、**基本給と手当の区分、固定残業代の有無と時間数、賞与と昇給の制度**を見ます。内定の段階では、**書面で提示を受けてください。**口頭のやり取りだけでは、後から確認できません。なお、**求人票の記載と内定の条件が異なる場合、変更の明示を受けられます。**職業安定法第5条の3第3項に定めがあります。扱いは[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。**確認は、応募の前からできます。**
