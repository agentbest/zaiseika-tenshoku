住宅課の経験を、職務経歴書にどう書けばよいか。ここでつまずく方が多いのは、**仕事の名前が、そのまま民間にない**からです。

「公営住宅の管理」と書くと、**団地の窓口にいた人**に読まれます。実際には、**数百から数千戸の賃貸の住宅について、入居者を選び、家賃を決め、収納を管理し、修繕を回し、出ていただく場面まで扱っていた**わけですが、それが伝わりません。

この記事では、**民間での訳語**と、**中核スキルの分解**を並べます。

## 「必要があると認めるとき」は、供給しなければなりません

まず、この仕事の立ち位置を条文で押さえます。**公営住宅法第3条**です。

> 地方公共団体は、常にその区域内の住宅事情に留意し、低額所得者の住宅不足を緩和するため必要があると認めるときは、公営住宅の供給を行わなければならない。

**短い条文ですが、この仕事の性格が全部入っています。**

**「常に住宅事情に留意し」**——**市場を見続けることが、前提に置かれています。**

**「必要があると認めるときは、供給を行わなければならない」**——**採算で決めるのではなく、必要の有無で決めます。**

つまり、**住宅課がやっているのは、「市場を読んで、足りない部分を自分たちで埋める」仕事**です。**民間の賃貸の事業者が、収益の見込める場所に建てるのとは、判断の入口が違います。**

**ただし、建てた後にやることは、ほとんど同じです。**募集、審査、家賃の設定、収納、修繕、退去。**賃貸住宅の管理そのもの**です。

## 民間での訳語

| 行政での言い方 | 民間での言い方 |
|---|---|
| 公営住宅の管理 | 賃貸住宅の管理、プロパティマネジメント |
| 入居者の募集 | 募集、リーシング、空室の対策 |
| 入居の資格の審査 | 入居審査、与信の確認 |
| 家賃の決定 | 賃料の設定、料金の設計 |
| 家賃の収納 | 債権の管理、入金の消込み |
| 滞納の整理 | 未収金の回収、督促の実務 |
| 明渡しの請求 | 契約の解除、法的手続きの実務 |
| 住宅の修繕 | 建物の維持管理、原状回復の管理 |
| 長寿命化計画・建替え | 中長期の修繕計画、建替えの事業 |
| 住生活基本計画 | 市場の分析、事業の計画 |
| 空き家の対策 | 遊休不動産の活用 |
| 住宅セーフティネットの登録 | 物件の登録、貸主との折衝 |

**この表を職務経歴書にそのまま貼る必要はありません。**ただ、**自分がやっていたことに、民間で通じる名前が付いている**ことは、知っておいてください。

## 中核スキルを5つの工程に分ける

**この経歴の中核は、「住まいを、必要な人に、続けられる条件で渡す」ことです。**5つの工程に分けます。

**工程1：住宅事情を読む**

**区域の中で、どんな世帯が、どれだけ住まいに困っているか。**家賃の相場、空き家の数、高齢の単身の世帯の増え方。**この読みが、供給の判断の入口になります。**

**この工程に固有の制約があります。**読む対象が、**払える人ではなく、払えない人**だということです。**民間の市場の分析は、需要のある層を探します。****行政の分析は、市場から外れた層を探します。**同じ統計を見ていても、**目が向く先が逆**になります。

**工程2：入れる人を決める**

入居の資格の審査と、選考です。**収入の基準、住宅に困っている度合い、世帯の状況。**応募が枠を超えれば、**選ばなければなりません。**

**この工程に固有の制約があります。**選考の理由を、**落ちた人にも説明できる形にしておく必要がある**ことです。民間の入居審査は、**断る理由を細かく説明しません。**行政では、**基準を公表し、その基準で選び、問われれば答えます。****この「説明できる選び方」の設計は、そのまま民間でも使えます。**

**工程3：家賃を決める**

公営住宅の家賃は、**入居者の収入と、住宅の便益を組み合わせて決まります。**同じ間取りでも、**世帯によって家賃が違います。**

**この工程に固有の制約があります。**家賃が、**毎年動く**ということです。収入の申告を受けて、**世帯ごとに計算し直します。**数百から数千の世帯について、これを毎年やる。**民間の賃貸で、入居者ごとに毎年賃料を計算し直す運用は、まずありません。****この事務の量と精度を回していた経験は、そのまま説明の材料になります。**

**工程4：住み続けられる状態を保つ**

修繕、設備の更新、共用部の管理、自治会との調整。**そして、滞納の整理**です。

**この工程に固有の制約があります。**滞納に対して、**すぐに出ていただく選択が取りにくい**ことです。**払えない事情が、生活の事情と直結している**からです。だから、**福祉の部署や、生活の支援の窓口につなぐ**動きが入ります。**回収と支援を、同時に扱う。**この組み合わせは、民間の管理の会社にはあまりありません。

**工程5：出るときを扱う**

退去、原状回復、収入が基準を超えた世帯への対応、建替えに伴う移転。**そして、明渡しの請求**です。

**この工程に固有の制約があります。**建替えに伴う移転は、**相手が高齢であることが多い**という点です。**何十年も住んでいた部屋から、別の住戸に移っていただく。****法的な手続きの前に、納得していただく工程が要ります。**この経験は、**民間の建替えの事業でそのまま求められます。**

:::insight
この5つの工程のうち、**職務経歴書でいちばん書かれていないのが、工程3の家賃の決定**です。面談で伺うと、**「家賃の算定の事務をしていました」**という一行で終わってしまいます。ところが、中身を聞くと、**毎年の収入の申告を数百から数千世帯分受け付け、世帯ごとに家賃を計算し、通知し、問い合わせに答え、変更があれば訂正する**という話が出てきます。**これは、料金の設計と、大量の個別の計算の運用**です。民間でいえば、**料金体系の運用、請求の管理、顧客ごとの条件の管理**に当たります。しかも、**間違えれば、生活に直結します。**書くなら、**「入居世帯約◯世帯について、毎年の収入の申告の受付から家賃の決定、通知、変更の処理までを担当」**という形です。**この一行があると、事務の精度と量を扱える人として読まれます。**不動産の管理でも、料金を扱う事業でも、**同じ性質の仕事があります。**
:::

## 民間の賃貸住宅の管理と、どこが同じでどこが違うか

**同じ点は3つあります。**

- **募集、審査、契約、家賃の収納、修繕、退去**という一連の工程を持っていること
- **滞納に対して、督促から法的な手続きまでの段取りを持っている**こと
- **建物の修繕を、計画と予算の中で回している**こと

**違う点は4つあります。**

| 違い | 行政（住宅課） | 民間（賃貸住宅の管理） |
|---|---|---|
| 入居者を選ぶ基準 | 困っている度合い。基準を公表する | 支払える見込み。基準は公表しない |
| 家賃の決め方 | 収入と便益で、世帯ごとに毎年決まる | 市場の相場で、契約ごとに決まる |
| 滞納への対応 | 支援につなぐ工程が入る | 回収と契約の解除が中心 |
| 空室の扱い | 応募がある限り埋まる。募集の工夫は別の目的 | 空室は収益の損失。埋めることが目的 |

**この4つのうち、移った後にいちばん効くのは、4番目**です。**空室が損失になる、という感覚**は、**行政の側では持ちにくい**からです。**ただし、埋めるための工程そのものは、同じ**です。

**もう1つ、見落とされやすい違いがあります。**1番目の「選ぶ基準」です。行政では、**基準を公表して、その基準で選び、問われれば答えます。**民間では、**断る理由を細かく説明しない**のが通例です。**ここだけ見ると、行政の側の手間が多いように見えます。**ところが、**説明できる基準を作って運用してきた経験は、民間でも求められる場面が増えています。**入居を断る理由が差別に当たらないか、審査の基準が説明できるか。**この点を問われる場面が、賃貸の業界では増えているから**です。**基準を作って公表し、そのとおりに運用してきた経験は、そこで直接に効きます。**

## 評価が高くなりやすい4つの方向

**1. 賃貸住宅の管理の会社**

**プロパティマネジメント**です。**戸数を扱った経験と、滞納の実務が、そのまま効きます。**

**2. 不動産の開発・建替えの事業**

**移転の調整の経験**が効きます。**住んでいる人がいる建物を建て替える仕事**は、民間にもあります。

**3. 住宅のセーフティネットに関わる事業者**

**高齢者や、住まいに困っている方の入居を扱う会社**です。**福祉と住宅の両方が分かる人は多くありません。**

**4. 自治体を顧客とする企業**

**公営住宅の管理の受託、長寿命化の計画の策定支援、住宅の政策の調査。**発注の側の事情が読めることが強みになります。

**なお、この4方向は、求める経験が違います。**1番と3番は、**入居者と直接やり取りしてきた経験**を見ます。2番は、**移転と建替えの調整**を見ます。4番は、**計画と制度の経験**を見ます。**同じ住宅課の経歴でも、担当していた範囲によって、通りやすい方向が変わる**ということです。**自分がどの工程を長くやってきたかを、先に整理しておいてください。**

## つまずきやすい点

**1. 「公営住宅の管理」で丸める**

**読む／選ぶ／決める／保つ／出る**の5つに分けてください。

**2. 戸数を書かない**

**管理していた戸数、団地の数、年間の募集の戸数。**桁だけでも入れてください。

**3. 家賃の決定を、事務として書く**

**料金の設計と、大量の個別の計算の運用**です。

**4. 滞納の整理を、苦労話にする**

**督促の段階を設計し、支援につなぐ判断をしていた**と書いてください。

**5. 住宅の政策の経験を書き落とす**

**住生活基本計画、空き家の対策、耐震の補助。****計画と補助金の実務は、別に評価されます。**

:::insight
この経歴の方に、**最初に確かめていただきたい数字が4つ**あります。**管理していた戸数、団地や住棟の数、年間の募集と入居の戸数、滞納の整理で扱った件数**です。この4つが並ぶと、**書類の読まれ方が変わります。**「公営住宅の管理」と書かれた1行と、**「市営住宅◯団地、約◯戸について、募集、入居の審査、家賃の決定、滞納の整理、退去までを担当。年間の募集は約◯戸」**という1行では、**読む側が想定する規模が違うから**です。面談で伺うと、**「戸数は分かりますが、滞納の件数は数えたことがない」とおっしゃる方が多い。****そこが、いちばん差が付く部分**です。民間の管理の会社では、**滞納への対応ができる人が、常に足りていません。**督促の段階を設計し、法的な手続きの直前まで扱い、同時に支援につなぐ判断もしてきた。**この経験を持つ人は、そう多くありません。**在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 公営住宅法第3条は、**常に住宅事情に留意し、必要があると認めるときは公営住宅の供給を行わなければならない**と定めています
- つまり、**住宅課は「市場を読んで、足りない部分を自分たちで埋める」仕事**をしています
- 民間での訳語は、**賃貸住宅の管理、入居審査、賃料の設定、債権の管理、建替えの事業**です
- 中核スキルは、**①読む ②選ぶ ③決める ④保つ ⑤出る**の5工程に分けられます
- 民間との違いは、**選ぶ基準、家賃の決め方、滞納への対応、空室の扱い**の4点です
- 先に、**戸数・団地の数・年間の募集の戸数・滞納の件数**の4つを控えてください

## よくある質問

### 技術職で、住宅の建替えや修繕が中心でした

**それは、書きやすい形です。**民間では、**建物の維持管理と、建替えの事業**が、そのまま対応します。書くべきは、**①管理していた住棟の数と戸数 ②長寿命化計画の策定や改定に関わったか ③建替えに伴う移転の調整をしたか ④修繕の年間の件数と金額**の4つです。とくに、**③の移転の調整**は、**民間の建替えの事業でいちばん人が足りない部分**です。**住んでいる方がいる建物を、住んでいるまま動かす。**この経験は、**技術と交渉の両方ができる人として読まれます。**

### 滞納の整理が長く、正直あまり良い記憶がありません

**そこが、民間でいちばん評価される経験です。**理由は、**この工程を最後まで扱える人が少ない**からです。督促の段階を決め、分割の相談に応じ、法的な手続きの準備をし、同時に生活の支援につなぐ。**回収と支援を、同じ人が扱っていた**わけです。民間の管理の会社では、**回収は外部に出していることも多く、中の事情が分かる人が重宝されます。**書くなら、**「滞納の整理について、督促の段階の基準を運用。分割の相談、法的手続きの準備、福祉部門への連携までを担当」**という形です。**件数を添えると、さらに具体になります。**

### 住宅の政策の担当で、公営住宅の管理はしていません

**その場合は、別の方向で書けます。**住生活基本計画、空き家の対策、耐震の改修の補助、住宅セーフティネットの登録。**これらは、計画の策定と、補助金の実務と、民間の事業者との折衝**です。民間でいえば、**市場の分析、補助金を使った提案、物件のオーナーへの営業の支援**に当たります。とくに、**空き家と住宅セーフティネットの経験**は、**不動産の会社や、住まいの支援を手がける事業者で直接に効きます。**行き先の分け方は[住宅課から転職しやすい業界と職種](dept-jutaku-tenshokusaki.html)に整理しています。
