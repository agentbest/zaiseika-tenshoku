公務員宿舎に住んでいる人が退職する場合は、仕事の引継ぎと並行して住まいの明渡しを確認します。引越し業者へ荷物の搬出を頼むことと、宿舎の点検・原状回復・鍵の返却まで終えることは別です。

本記事は2026年11月時点の公開情報にもとづき、国家公務員宿舎法が適用される国の宿舎を中心に説明します。自治体の職員住宅、大学等の法人独自の宿舎、民間借上住宅は、本人の規程や契約を別に確認してください。退去期限と具体的な手続きは、所属の宿舎担当と維持管理機関へ照会します。

## 入居時の書類で適用制度と担当を特定する

建物の呼び名が官舎や公務員住宅でも、適用される根拠が同じとは限りません。入居時の貸与承認書や契約書から、誰が貸しているか、国の宿舎法に基づく貸与か、管理を担当する機関はどこかを確認します。

同じ国家公務員でも、住まいが民間の賃貸住宅なら、本人の賃貸借契約の解約条件等を読みます。反対に、現場の管理を民間会社等が受託していても、そのことだけで国の宿舎が一般の民間賃貸借になるわけではありません。

| 手元で確かめる資料 | 確認したい内容 |
| --- | --- |
| 貸与承認書等 | 宿舎名、戸番、貸与主体、使用条件 |
| 入居時の案内 | 管理窓口、連絡方法、退去手順 |
| 点検・補修の記録 | 入居前からの状態、入居後の変更 |
| 駐車場の承認書 | 宿舎と別に廃止届が必要か |
| 今回の退職関係書類 | 居住資格を失う時点と日程 |

合同宿舎では、所属する官署と宿舎の管理側の両方に連絡する手順があります。「管理人へ話したから人事や宿舎担当も承知している」と推測せず、誰に何を届け出るかを確認してください。

## 国の宿舎の明渡しは20日以内という原則がある

国家公務員宿舎法第18条第1項は、職員でなくなった場合等に、その該当することとなった日から20日以内の明渡しを定めています。退職だけでなく、転任等により居住資格を失った場合や、法に基づく明渡請求など、別の事由もあります。

本人が退職した後も、同居家族が公務員ではないまま生活を続けるから期限と無関係になる、という制度ではありません。誰の資格で貸与を受けているかを見て、家族の転居も含めた予定を組みます。配偶者に別の貸与資格があると考える場合も、新しい取扱いを正式に確認してください。

「退職予定日」「職員でなくなることに該当する日」「明渡期限」を担当に照合し、暦日で示された日付を記録します。最終登庁日を起算日にしたり、引越し予定日から逆算して法定期限を変えたりしないようにします。

明渡しに必要な状態も確認します。荷物が一部残っている、原状回復の確認が終わっていない、鍵をまだ返していないといった場合に、本人だけで完了と判断しないことが大切です。

## 最長の猶予期間まで自動的に住めるわけではない

同条第1項ただし書は、相当の事由がある場合に、維持管理機関の承認を受けて指定された期間だけ使用を続けられることを定めています。その範囲は、公邸・無料宿舎が該当日から2月、有料宿舎が6月です。原則の20日にその期間を自由に足せる制度ではありません。

財務省の退職等に伴う明渡しの通達は、具体的な明渡計画を求めて審査し、真にやむを得ない事情があるものに相当の期間だけ承認する取扱いを示しています。住み続けたいという希望や、窓口へ相談したという事実と、正式な承認は分けます。

| 猶予を照会する際の項目 | 整理すること |
| --- | --- |
| 猶予が必要な理由 | 事情と、それを示す資料 |
| 明渡計画 | 次の住居、転居予定、準備の進行状況 |
| 希望する期間 | 具体的な日付と必要な理由 |
| 提出と決定 | 申請先、必要書類、承認の通知方法 |
| 承認後の管理 | 指定期限、使用料、状況変更時の連絡 |

次の住まいが決まらない場合は、期限を過ぎてから相談するのではなく、未確定であることを担当へ伝えます。申請中なら当然に期限が止まるとは考えず、審査中の取扱いも確認してください。

:::insight
住まいの予定を立てるときは、退職日、明渡期限、次の住居に入れる日、引越し日を一つずつ分けることを勧めます。四つが近いから同じ日でよいとは限りません。原状回復の作業や点検が必要なら、荷物を運び出してから返却完了までの時間も確保します。猶予の可能性があっても、未承認の期間を使える前提で契約を決めないことが大切です。現職継続と転職の比較では、宿舎使用料だけでなく、転居に必要な初期費用や生活の動線を並べます。住まいを失うという不安だけで仕事の判断を急ぐより、本人に適用される期限と確認先を具体的にしておくことで、現在の仕事に残る案も含めた比較がしやすくなります。
:::

勤務先を変える場合の仕事内容は、[行政経験に関連する求人](../?gov=1)でも比較できます。宿舎の手続きと応募先の条件は、それぞれ確認してください。

## 退去届と点検の日程を先に組む

財務省の貸与関係様式に示された条件では、原則として明け渡す日の5日前までに管理人へ届け出ます。合同宿舎では所属官署の長にも届け出る取扱いです。これは明渡期限とは別の手続き上の期限なので、「20日以内だからその最終日に連絡すればよい」という意味ではありません。

現在の様式、部数、提出方法は、本人の宿舎担当に確認します。公開の宿舎退去届・自動車保管場所使用廃止届には、転居先と連絡先等の欄もあります。退去後に確認や精算の連絡を受けられるよう、情報を更新してください。

合同宿舎管理人の業務指導は、退去者立会いで宿舎と設備を点検し、補修等が必要な場合の対応を指示することを定めています。引越し日だけ先に予約するのではなく、事前点検、補修、完了確認、鍵の返却の順序を担当とすり合わせます。

管理人の勤務日や、点検を実施できる時間も確認します。期限の最終日が都合のよい日とは限りません。相手の休みや業者の予約が取れないことを理由に、自動的に明渡期限が延びるとは扱わないようにします。

## 原状回復と軽微修繕は原因と範囲を確認する

宿舎法第16条は、本人の責任による損傷等の原状回復または損害賠償を定めています。第17条には、本人の責任によらない修繕についての国の負担と、軽微なものの例外があります。民間賃貸の一般的な敷金精算の説明だけでは、今回の負担範囲は決まりません。

財務省の原状回復等の通達は、専用部分について、本人の責任や住まい方、管理の不十分さによる損傷等を対象として示しています。原因を問わず全部新品にするという読み方も、古くなった部分なら全部無関係という読み方も避けます。

同通達は、必要最小限の範囲で、維持管理機関が負担等を勘案して実施方法を指示する仕組みです。損傷のない部分を色や模様を合わせるためだけに更新することのないよう求める記載もあります。疑問がある場合は、箇所、原因、指示の根拠、施工範囲を確認してください。

| 点検前にまとめるもの | 使い道 |
| --- | --- |
| 入居時の写真・確認記録 | 入居以前の状態を照合する |
| 故障や修理の連絡記録 | 原因、時期、対応済み事項を示す |
| 自分で設置・変更した物の一覧 | 撤去・原状回復等の取扱いを確認する |
| 指示事項と見積り | 補修範囲、方法、日程を比較する |

自己負担で設置した設備も、勝手に残せば次の入居者が使えるとは限りません。撤去、原状回復、寄附等のどの扱いになるかを確認します。担当の指示と工事内容が食い違わないよう、発注前に必要な仕様を照合してください。

仕事と生活条件を分けて整理したい場合は、[応募前の相談](../apply.html)も利用できます。ご利用は無料です（紹介手数料は採用企業の負担）。退去の承認や補修負担の判断は、宿舎の担当窓口で確認します。

## 使用料・駐車場・退去後の連絡まで確認する

宿舎使用料、駐車場、共用部分の費用、個別の光熱費、補修費はそれぞれ確認します。退職により給与からの徴収が終わる場合も、最後の精算や納付方法まで自動的に決まったとは考えません。どの日までの費用か、請求時期と支払先を照合します。

明渡期限に反して使用を続けた場合には、宿舎法第18条第3項と施行令第16条の損害賠償金が関係します。施行令は原則として該当期間の使用料相当額の3倍とし、所定の軽減対象には別の定めを置いています。従来の使用料を払えばそのまま住み続けられる、という制度ではありません。

退去後に郵便や請求が届くことも考え、所属と管理側へ転居先・連絡先を届けます。郵便の転送、住民登録、保険資格等の変更は、宿舎の退去届とは別の生活上の手続きです。一つを提出しただけで全部済んだと扱わないようにします。

国と自治体等を横断した確認事項は、[官舎・職員住宅の退去](seido-tetsuzuki-kansha.html)でも整理しています。別制度の住宅には、国の20日や猶予期間をそのまま広げず、貸主と今回の契約・規程へ戻って確認します。

:::insight
転職後の住居費を比べるときは、毎月の家賃だけでなく、一度に必要な支出と、仕事を始めるまでの予定を別に置きます。初期費用、引越し、補修の精算が同じ時期に重なる場合は、支払時期も比較の材料になります。まだ仕事の希望が固まっていないなら、住まいの制度確認だけ先に進めても構いません。現職で希望する業務や働き方を実現できる場合には、残る判断にも理があります。転職する案でも、未承認の猶予や未確認の会社の住宅支援を確定条件にしないことが大切です。仕事の条件、次の住居、現在の宿舎の返却をそれぞれ確認し、本人が説明できる予定にそろえることが、判断を急がずに選択肢を比較するための準備になります。
:::

## よくある質問

### 有料宿舎なら退職後も六か月は住めますか

自動的には住めません。法第18条ただし書による相当の事由と維持管理機関の承認が必要で、指定された期間に限ります。6月は範囲の上限であり、原則の20日に自由に加算するものでもありません。

### 荷物を出した日が明渡し完了日ですか

本人だけでは判断せず、原状回復の確認や鍵返却等を含め、何をもって完了と扱うか担当へ確認します。点検可能日も含めて予定を組んでください。

### 自治体の職員住宅にも国の期限が適用されますか

一律には当てはまりません。自治体の規則、使用許可条件、契約等を確認します。法人独自の宿舎や借上住宅も別です。

宿舎の退去は、制度、期限、承認、届出、返却の順に確認します。仕事の希望を整理する段階なら、[LINEで短く聞く](https://line.me/R/ti/p/@697nxhbt)こともできます。
