**工事の担当をしてきた方から、「発注者の経験はどう書くか」**というご相談を伺います。

**発注者の事務は、法律に列挙されています。**

この記事では、**その一覧**と、**資格の組み合わせ方**を扱います。

**⚠ 受験の要件・区分・手続は、所管するところの公表を確認してください。****この記事では、個別の要件には触れません。**

## 発注関係事務が、条文に書かれています

**公共工事の品質確保の促進に関する法律第7条第1項**です。

> **発注者は、基本理念にのっとり、現在及び将来の公共工事の品質が確保されるよう、公共工事の品質確保の担い手の中長期的な育成及び確保に配慮しつつ、公共工事等の仕様書及び設計書の作成、予定価格の作成、入札及び契約の方法の選択、契約の相手方の決定、工事等の監督及び検査並びに工事等の実施中及び完了時の施工状況又は調査等の状況**（略）**の確認及び評価その他の事務**（以下「**発注関係事務**」という。）**を、次に定めるところにより、適切に実施しなければならない。**

**「発注関係事務」として、次のものが列挙されています。**

| 条文に挙げられた事務 | 経験として書けること |
|---|---|
| 仕様書及び設計書の作成 | **求める内容の記述** |
| 予定価格の作成 | 積算、原価の見積り |
| 入札及び契約の方法の選択 | 調達の方法の判断 |
| 契約の相手方の決定 | 選定、評価 |
| 工事等の監督及び検査 | 工程、品質、出来形の確認 |
| 施工状況等の確認及び評価 | 実施中と完了時の確認 |

**これが、発注者側の経験の内訳**です。

**書類を書くときは、この順で並べてください。**

**条文に沿っているため、抜けが生じません。**

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 発注者支援 | **発注関係事務の補助** |
| ② 建設コンサルタント | 調査、設計、監理 |
| ③ 施工の管理 | 現場の管理 |
| ④ 維持管理・点検 | 保全の計画 |
| ⑤ 指定管理・受託の会社 | 施設の維持 |

**①が、最も直接に重なります。**

**発注関係事務は、外部に支援を委ねる場面があります。**

**この支援を担う会社では、発注者の側を経験した人**が必要とされます。

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 書き方の例

**悪い例**

> 道路の工事の監督をしていました。

**良い例**

> ◯◯の事業において、**発注者として、土木の工事◯件（工事費約◯千万円〜◯億円）を担当。****仕様書及び設計書の作成、予定価格の作成、入札の方法の選択、契約の相手方の決定までの一連を実施。**施工中は、**工程・品質・出来形の確認を現場で実施し、変更が生じた案件◯件について協議のうえ変更の契約を締結。**完了時に**検査を実施し、是正の確認までを管理。**

**「立場」「件数」「規模」「一連の事務」「変更」「検査」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

:::insight
発注者の経験について、**面談でお伝えしているのが「条文の順に並べてください」**という点です。**「工事の監督をしていた」と書かれることが多い**のですが、**発注者の事務は、監督だけではありません。**公共工事の品質確保の促進に関する法律第7条には、**仕様書及び設計書の作成、予定価格の作成、入札及び契約の方法の選択、契約の相手方の決定、監督及び検査、施工状況等の確認及び評価**が挙げられています。**このうち、いくつを担当したか。**書類にこの順で並べると、**担った範囲が一目で伝わります。**そして、**発注者支援の会社では、この事務を支援することが業務**です。つまり、**条文の言葉が、そのまま業務の説明**になっています。**求人票の仕事内容と、書類の言葉が揃う**わけです。**「監督」だけを書くと、範囲が狭く読まれます。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 資格の組み合わせ方

| 状況 | 扱い |
|---|---|
| ① 応募条件に記載がある | **満たす材料になる** |
| ② 現場に配置される | 資格が前提になることがあります |
| ③ 発注者支援 | **経験と併せて評価されます** |
| ④ 入社後の取得 | 支援の制度がある会社も |
| ⑤ 目的が曖昧 | 優先順位を下げてください |

**③について。**

**資格だけでも、経験だけでもなく、両方が揃うと候補が広がります。**

**なお、取れば転職できる、という関係にはありません。**

**どの事務を、どの規模で担ったか**が、評価の対象です。

## 確認の観点という材料

| 観点 | 内容 |
|---|---|
| ① 工程 | **予定との差、遅れへの対応** |
| ② 品質 | 材料、施工の方法、記録 |
| ③ 出来形 | 寸法、数量 |
| ④ 安全 | 体制、周知 |
| ⑤ 書類 | 提出の期限、内容 |

**⑤について。**

**提出の書類が揃っているかを確認してきた経験**は、**受注する側で「何を出せばよいか」を知っていることになります。**

**扱いは**[建築施工管理技士｜取得の順序と転職時期](skill-kenchikusekou.html)**にも整理しています。**

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 実績の整理 | **工種、件数、工事費、延長** |
| 担当した事務の整理 | 条文の順に並べる |
| 要件の確認 | 所管の公表を確認 |
| 証明の書類の準備 | 所属での手続 |

**4行目を早めに**してください。

**在職中のほうが、手続が簡単**です。

**根拠のない数は書かないでください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 担当した工事 | **工種、規模、件数** |
| 担当した事務の範囲 | **条文の順で** |
| 変更への対応 | 3件、経緯と処置 |
| 検査の観点 | 何を見たか |
| 立場 | 発注者か、受注者か |

**2行目です。**

**「設計書の作成から検査まで」**のように、**範囲を示して**ください。

**なお、特定の工事や事業者が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

## 発注者支援で求められること

| 求められること | 行政での対応する経験 |
|---|---|
| ① 監督の補助 | **現場での確認** |
| ② 工程の確認 | 予定との差の把握 |
| ③ 書類の確認 | 提出物の点検 |
| ④ 協議の支援 | 変更、近隣、関係機関 |
| ⑤ 記録の作成 | 経緯を残す |

**③と⑤が、事務の比重が高い部分**です。

**書類の点検と記録の作成は、技術の実務がなくても担えます。**

**行政での経験が、そのまま業務になります。**

**なお、現場へ出る頻度は求人によって異なります。**

**勤務の形を、応募の段階で確認**してください。

## よくある失敗

**1. 「監督」だけを書く**

**範囲が狭く読まれます。**

**2. 条文の順に並べない**

**抜けが生じます。**

**3. 規模を書かない**

**工事費、延長、件数**を書いてください。

**4. 変更への対応を書かない**

**変更の管理**として読まれます。

**5. 書類の確認の経験を書かない**

**受注する側でも使える視点**です。

**6. 証明の書類の準備を後回しにする**

**在職中のほうが簡単**です。

**7. 要件を人づてで判断する**

**所管の公表**を確認してください。

**8. 取れば転職できると考える**

**どの事務をどの規模で担ったか**が評価の対象です。

:::insight
ここまで発注者の事務の話をしておいて逆のことを言いますが、**現場の経験がないことを、弱みとして語らないでください。**面談で拝見していると、**「施工をしていないので、現場では務まらないのでは」と話す方**がいらっしゃいます。ところが、**発注者支援の業務は、施工そのものではありません。**監督の補助、工程の確認、書類の確認、協議の支援。**発注者の側で担ってきた動作が、そのまま業務の中身**です。そして、**この領域では、施工の経験より、発注関係事務の理解が求められます。**面接では、**「施工の経験はないが、発注者として設計書の作成から検査までを担当してきた」**と、**担った範囲を述べてください。**そのうえで、**現場で覚える部分は入社後に身につけたいと伝える。**弁解ではなく、**範囲の説明**として話すことが要点です。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **公共工事の品質確保の促進に関する法律第7条**は、**仕様書及び設計書の作成、予定価格の作成、入札及び契約の方法の選択、契約の相手方の決定、監督及び検査、施工状況等の確認及び評価**を**発注関係事務**としています
- **これが、発注者側の経験の内訳**です。**書類は、この順で並べて**ください
- 効くのは、**発注者支援、建設コンサルタント、施工の管理、維持管理・点検、指定管理・受託の会社**です
- **「監督」だけを書くと、範囲が狭く読まれます**
- **資格と経験の両方が揃うと、候補が広がります**
- **証明の書類の準備は、在職中に**済ませてください
- **現場の経験がないことを、弱みとして語らないでください。**範囲の説明として話してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 設計や積算は担当していません

**担当した事務だけを書いてください。**発注関係事務のうち、**どこを担ったかを明示する**のが正確です。「契約の手続と、施工中の確認、検査を担当。設計と積算は担当課が実施」という形です。**担っていない部分を書かないほうが、入社後に困りません。**なお、**担当していない事務でも、内容を確認してきた**場合は、その旨を書けます。「設計書の内容を確認のうえ、契約の手続を実施」。**確認の経験も、材料になります。**扱いは[契約書の読み方｜自治体の契約実務との差](skill-keiyakusho.html)に整理しています。

### 受験の要件に、行政の実務は算入されますか

**所管するところの公表を確認してください。**要件は、**実務の経験の年数と内容**で定められていることがあります。どの職務が該当するかは、**公表されている案内で確認**するのが確実です。**人づての情報や、以前の記憶で判断しないでください。**なお、**証明の書類が必要になる場合、所属での手続が要る**ことがあります。**在職中に確認し、必要なら書類を整えておいてください。**退職した後では、依頼に手間がかかります。扱いは[建築施工管理技士｜取得の順序と転職時期](skill-kenchikusekou.html)にも整理しています。

### 維持管理の担当でしたが、書けますか

**書けます。**点検の発注、補修の工事の監督、保全の計画の作成。**これらは、発注関係事務と同じ構造**です。書き方は、**「道路の維持管理において、点検の業務◯件と補修の工事◯件を発注者として担当。点検の結果を踏まえ、◯か年の補修の計画を作成し、年度ごとの予算に反映」**という形です。**計画の作成は、保全の計画の業務と重なります。**扱いは[電気主任技術者｜公営企業・インフラ運営での評価](skill-denkishunin.html)にも整理しています。**新設の工事に限らず、維持管理の経験も材料です。**
