**「庁内調整ばかりで、外に出せる経験がない」**というご相談を伺います。

**その調整こそが、持ち運べる経験**です。

この記事では、**理由**と、**言語化の仕方**を扱います。

## 所掌が分かれていることが、調整を生みます

**地方自治法第138条の3第1項**です。

> **普通地方公共団体の執行機関の組織は、普通地方公共団体の長の所轄の下に、それぞれ明確な範囲の所掌事務と権限を有する執行機関によつて、系統的にこれを構成しなければならない。**

**同条第2項**です。

> **普通地方公共団体の執行機関は、普通地方公共団体の長の所轄の下に、執行機関相互の連絡を図り、すべて、一体として、行政機能を発揮するようにしなければならない。**

**同条第3項**です。

> 普通地方公共団体の長は、当該普通地方公共団体の**執行機関相互の間にその権限につき疑義が生じたときは、これを調整するように努めなければならない。**

**所掌事務と権限が明確に分かれ、そのうえで一体として機能することが求められる。**

**この構造が、調整を必要とします。**

**そして、条文自体が「調整」という言葉を使っています。**

**つまり、調整は、制度が予定している働き**です。

**付随的な雑務ではありません。**

## 調整の型

**調整には、繰り返される手順があります。**

| 順 | やること |
|---|---|
| 1 | **関係者を洗い出す** |
| 2 | それぞれの前提を確認する |
| 3 | 譲れない点を見分ける |
| 4 | 落としどころを設計する |
| 5 | 順序を決めて当たる |
| 6 | 合意の内容を記録に残す |

**2と3が中心**です。

**相手が反対している理由は、多くの場合、立場に基づく前提**です。

**所掌の範囲、予算の制約、過去の経緯、上位の方針。**

**この前提を確認せずに説得しても、動きません。**

**5について。**

**誰から当たるかで、結果が変わる**ことがあります。

**この順序の設計は、経験によって身につくもの**です。

## 交渉との違い

| 項目 | 交渉 | 調整 |
|---|---|---|
| 相手 | 利害が対立する外部 | **同じ組織の中** |
| 目的 | 条件を決める | **全体として動く形を作る** |
| 関係 | 一時的なこともある | 続く |
| 勝敗 | 生じることがある | **生じさせない** |
| 記録 | 契約書 | 決裁、議事の記録 |

**4行目です。**

**調整では、勝ち負けを作らない**ことが要点になります。

**相手が後から協力しなくなると、次の案件で困る**ためです。

**この感覚は、民間の部門間の調整でも同じ**です。

## 書き方の例

**悪い例**

> 関係課との調整を担当しました。

**良い例**

> ◯◯の事業の実施にあたり、**関係する◯課との調整を担当。**各課の所掌と制約を確認したうえで、**費用の負担と事務の分担について◯案を作成し、順序を決めて協議。****◯か月で合意に至り、内容を決裁の文書と要綱に反映。**

**「相手の数」「確認」「案の作成」「順序」「期間」「記録」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 言い換えの対応

| 行政の言葉 | 民間での読まれ方 |
|---|---|
| 庁内調整 | **部門間の調整** |
| 関係課との協議 | 関係部署との合意の形成 |
| 合議 | 承認の取り付け |
| 根回し | **事前の合意の形成** |
| 決裁の取得 | 承認の手続 |
| 他団体との協議 | 社外との調整 |
| 事務の分担の整理 | 役割の定義 |

**4行目です。**

**「根回し」は、民間では「事前の合意の形成」**として読まれます。

**否定的な言葉として使わないでください。**

**会議の前に論点を詰めておく**という動作は、どの組織でも必要とされます。

:::insight
調整の経験について、**面談でお伝えしているのが「相手の数と、期間を書いてください」**という点です。「関係課と調整しました」とだけ書かれると、**規模が分かりません。**3課の調整と、10課の調整では、難易度がまったく違います。同様に、**1か月で合意した案件と、1年かかった案件**では、扱った内容が違います。ですから、**「関係する◯課と、◯か月にわたり協議」**と書いてください。そして、**何が争点だったかを1行足してください。**費用の負担、事務の分担、時期、責任の所在。**この争点の類型は、民間の部門間の調整とほぼ同じ**です。予算をどちらが持つか、誰が実務を担うか、いつまでに終えるか。**やっていることは同じ**です。ですから、**「庁内調整」という言葉で止めず、中身を開いて書いてください。**そこに、持ち運べる経験があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 行政が相手の事業 | **庁内の動き方が分かる** |
| ② 事業の推進・企画 | 部門間の調整 |
| ③ 受託の管理 | 発注者との協議 |
| ④ 導入の支援 | 顧客の社内の合意の形成 |
| ⑤ 管理部門 | 全社の調整 |

**④について。**

**システムやサービスの導入では、顧客の社内で合意を作る必要**があります。

**誰の承認が要るか、誰が反対しそうか、どの順で当たるか。**

**この設計ができる人は、導入の支援で重宝されます。**

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 難しかった調整 | **3件、争点と結論** |
| 相手の数 | 関係した課・団体の数 |
| 期間 | どれだけかかったか |
| 反対された場合の進め方 | 前提の確認の仕方 |
| 記録の残し方 | 合意をどう固定したか |

**4行目です。**

**反対された案件をどう進めたか**は、必ず用意しておいてください。

**説得したのではなく、前提を確認して案を作り直した**という説明のほうが、実務に近く読まれます。

**なお、特定の事案が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 学ぶ前に考えること

| 確認すること | 内容 |
|---|---|
| ① すでにある経験 | **調整した案件を3件** |
| ② 争点の類型 | 費用、分担、時期、責任 |
| ③ 応募したい求人の条件 | 調整の経験が挙がっているか |
| ④ 期限 | 応募の時期までに間に合うか |

**①を先に整理してください。**

**研修や資格より、実際の案件の整理が効きます。**

**なお、講座を受ければ転職できる、という関係にはありません。**

**何を争点とし、どう合意を作ったか**が、評価の対象です。

## よくある失敗

**1. 「庁内調整」で止める**

**中身を開いて**書いてください。

**2. 相手の数を書かない**

**規模**が伝わりません。

**3. 期間を書かない**

**難易度**が伝わりません。

**4. 争点を書かない**

**民間と共通する部分**です。

**5. 「根回し」を否定的に語る**

**事前の合意の形成**として読まれます。

**6. 説得したと書く**

**前提を確認して案を作り直した**ほうが実務に近いです。

**7. 記録の残し方に触れない**

**合意の固定**は重要な工程です。

**8. 講座を受ければ進めると考える**

**どう合意を作ったか**が評価の対象です。

:::insight
ここまで調整の話をしておいて逆のことを言いますが、**民間では、調整の前に「決める人」がはっきりしていることがあります。**面談で拝見していると、**行政と同じ進め方をしようとして、時間をかけすぎてしまう方**がいらっしゃいます。行政では、**所掌が分かれているため、関係する部署すべての合意が必要**になります。一方、民間では、**責任者が決めれば進む**場面があります。**全員の合意を待つと、遅いと見られる**ことがあります。ですから、入社後にまず確認すべきは、**「この件は、誰が決めるのか」**です。そのうえで、**決める人に必要な材料を揃える**という進め方に切り替える。**調整の型は同じでも、当たる順序と範囲が変わります。**面接では、**「関係者を洗い出して合意を作る進め方に慣れている。決裁の構造は組織によって違うため、入社後に確認したい」**と話してください。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方自治法第138条の3**は、**明確な範囲の所掌事務と権限を有する執行機関による系統的な構成**、**相互の連絡を図り一体として行政機能を発揮すること**、**長による権限の疑義の調整**を定めています
- **所掌が分かれている構造が、調整を必要とします。**調整は、制度が予定している働きです
- 調整の型は、**①洗い出し ②前提の確認 ③譲れない点 ④落としどころ ⑤順序 ⑥記録**です
- **相手の数と、期間、争点**を書いてください
- **「根回し」は、事前の合意の形成**として読まれます
- **説得したのではなく、前提を確認して案を作り直した**という説明のほうが実務に近いです
- 民間では、**決める人がはっきりしている**ことがあります。当たる順序と範囲が変わります

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 調整の相手が課内だけでも、書けますか

**書けます。**係と係の間、担当と上司の間でも、**前提を確認し、案を作り、合意を得る**という動作は同じです。書き方は、**「係間で事務の分担に差が生じていた◯◯の業務について、処理の状況を整理したうえで分担の案を作成し、係長の承認を得て運用を変更」**という形です。**規模より、手順が伝わるか**が重要です。なお、**外部との協議の経験があれば、併せて書いて**ください。事業者、他団体、関係機関。**相手の種類が増えるほど、範囲の広さが伝わります。**

### 反対されて進まなかった案件は、書けますか

**書けます。**進まなかった理由を説明できるなら、**判断の経験**になります。「◯◯の案について、◯課と協議したが、制度上の制約により実現が難しいと整理。代替として◯◯の方法を提案し、一部を実施」という形です。**全部が実現しなくても、整理した過程が残ります。**なお、**「反対されたので諦めた」で止めないでください。**何を確認し、何が分かり、次にどうしたか。**この3点があれば、成果として読まれます。**面接でも、**うまくいかなかった案件は聞かれます。**用意しておいてください。

### 民間では、調整の経験をどう評価されますか

**職種によって扱いが変わります。**事業の推進、導入の支援、受託の管理、管理部門では、**調整が業務の中心**になります。この場合、**直接の経験として読まれます。**一方、個人で完結する業務が中心の職種では、**評価の比重が下がる**ことがあります。判断の目安は、**求人票の応募条件**です。「関係部署との調整」「社内外の折衝」「プロジェクトの推進」といった言葉があれば、**調整の経験が要件**になっています。読み方は[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。
