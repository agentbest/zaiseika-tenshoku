未経験から警備・BPOを検討するときは、業界が初めてなのか、応募する仕事の工程を経験していないのかを分けます。公務で記録や連絡、期限の確認をしていた経験は説明の材料になりますが、警備の実務、事務センターの管理、企業との折衝をすべて経験したことにはなりません。求人の必須条件と、自分が行った作業を一つずつ照合しましょう。

本記事は2026年11月時点の公開情報にもとづきます。確認日は2026年11月25日です。ALSOKの公式中途募集と、トランスコスモスの事務センター求人を一例にします。未経験なら誰でも応募・採用されるという説明ではありません。募集継続と本人の応募資格は、採用窓口へ確認してください。

## 警備とBPOで、仕事の入口を分ける

ALSOKの中途募集には、機械警備、警備輸送、技術、営業、ガードセンター、資金という総合職の区分があります。警備という領域の中でも、現場の対応、運転、技術、営業などは担当が異なります。募集法人とグループ各社の区別、新卒と中途の区別も保ち、他社の常駐警備の条件をそのまま用いません。

BPOを調べるときも、事務処理、顧客との調整、センターの運用、コールセンター、技術サポートを一括しないことが大切です。今回のトランスコスモスの仕事番号1315447は、東京・京橋の事務センターの管理業務です。進捗、シフト、日報、提出物の管理と、クライアントからの問い合わせや業務調整などを掲げています。

同求人が説明するチームの仕事は、書類の開封・仕分け、点検、不備に関する書類の送付、入力、受渡し、発送等です。電話対応は取次ぎや簡単な受答え程度の記載がありますが、それを専門の電話相談業務と同じにはしません。受託する業務と本人が担う管理の範囲を分けて読みます。

職種がまだ決まっていない人は、働きたい場所や時間だけでなく、どの工程を担当したいかをメモにします。警備の現場対応を希望するのか、事務処理を希望するのか、チームの進捗を管理したいのかで、確認すべき経験や勤務は変わります。

## 警備の応募条件は、経験の有無と別に確認する

ALSOKの公式中途募集は、正社員と嘱託員の区分を示し、正社員について年齢と高卒以上の条件を掲げています。普通自動車運転免許を入社までに取得できることに加え、入社後すぐに運転を伴う業務に従事する前提も記載しています。免許の保有と、実際に運転する勤務を引き受けられることは別に確認する事項です。

同ページは正社員の試用期間を6か月、労働条件の変更なしとしています。嘱託員には正社員登用の途があると説明していますが、本人が必ず登用されるという意味ではありません。募集区分、本人に適用する条件、契約の扱いを窓口で確認してください。公務の勤続年数だけから、同社での経験区分や待遇を決めません。

警備業法第14条には、18歳未満の者や同条が参照する事由に該当する者を警備員としてはならないという制限があります。経験がなくても働けるかという検討と、法令上の条件を満たすかは別です。個別の該当や必要な確認については、採用窓口の案内に従って確認してください。

また、同法第15条は、警備業務について同法から特別な権限を与えられるものではないこと等を定めています。警備を行政や警察の権限を引き継ぐ仕事と考えず、担当範囲、教育、報告先を確かめます。公務で人へ説明した経験があっても、私人に対して行政上の権限を使えるような説明はしません。

## 事務BPOの未経験歓迎と、PC・対応の条件を分ける

今回の事務センター求人は未経験者歓迎の記載がある一方、応募条件としてコミュニケーション、PC基本操作、電話対応への抵抗がないことを挙げています。一般事務や事務センターの経験は歓迎として示されています。他業界のマネジメント経験についても歓迎の記載がありますが、本人の経験が該当するかを確認します。

「未経験」という語があるからといって、入力や資料作成、チームとの連携の準備まで不要ではありません。現在の操作歴を、実務で使ったもの、学習で操作したもの、未経験に分けましょう。管理職の肩書があっても、本人が進捗やシフトの何を担当したかを説明する必要があります。

| 求人の項目 | 本人が照合すること | 混同しないこと |
| --- | --- | --- |
| PC基本操作 | 入力、文書や表の扱いなど本人の操作歴 | 学習予定を経験済みとする |
| 連絡・コミュニケーション | 確認した事項と引継ぎ先 | 相手の心理や満足を作る |
| 管理業務 | 進捗、提出物、シフトの担当経験 | 上司の承認や組織成果を加える |
| 顧客との調整 | 何を確認し、どこまで判断したか | 行政の窓口対応を契約交渉へ広げる |

[公務員経験を整理しながら求人を比較する](../?gov=1)際は、必須と歓迎を分け、条件を満たすか不明な欄を要確認として残してください。

## 公務員経験の接点は、記録と引継ぎから考える

公務での経験には、申出の内容を記録する、不足している資料を確認する、期限を整理する、判断が必要な点を担当へつなぐといった工程があります。応募書類では、その対象、本人の作業、確認先まで具体化します。「責任感」「調整力」という言葉だけでまとめず、何をどう行ったかを示しましょう。

ただし、住民への案内は警備の現場対応や、契約にもとづく企業の顧客対応と同じではありません。規定や手順を確認して説明した経験と、現場で判断する責任を区別します。未知の事態にも一人で対応できると広げず、経験のない業務と教わる必要のある範囲を明記してください。

事務センターの管理でも、庁内で日程を集めた経験と、スタッフのシフトを決める経験は別です。本人が情報を収集したのか、案を作ったのか、最終決定したのかを区分します。委託先が構築した仕組みや、上司の判断、所属全体の成果を本人の実績に含めません。

:::insight
未経験の仕事を調べるときは、今ある経験を無理に新しい職種名へ置き換えないことを勧めます。公務での記録や照会には説明できる工程がありますが、警備の現場対応や受託センターの運用と同じ責任ではありません。本人がしたこと、他者が判断したことを分ければ、接点と学ぶ必要のある範囲が見えてきます。求人の未経験歓迎という記載も、PCや運転、法令上の条件を省略するものではありません。応募条件に対応する事実を確かめ、不明点は窓口へ質問してください。学習の意欲と現在の経験を別に述べることで、入職後の役割や確認を受ける体制について具体的に話す準備になります。
:::

## 独立した架空例：担当工程と未経験の範囲

次は説明用に作成した架空例です。実在の職員の相談や採用結果ではありません。本人の応募に使う場合は事実に置き換え、実施していない工程を削除してください。

| 項目 | 架空の記入例 |
| --- | --- |
| 本人の仕事 | 自治体の庶務で、各担当から提出される資料の受付を担当 |
| 実施した工程 | 提出状況を表に記録し、不足項目を担当者へ確認 |
| 引継ぎ | 判断が必要な内容を区分して上司へ報告 |
| PC操作 | 実務で入力、並べ替え、表の更新を担当 |
| 他者の担当 | 最終判断、担当割当、勤務シフトは上司が決定 |
| 未経験 | 警備の実務、現場での運転、企業のセンター運用 |
| 確認する事項 | 応募条件への該当、最初の担当、研修、報告先、勤務 |

この例なら「提出状況を記録し、不足項目を確認して、判断が必要な内容は上司へ報告しました」と説明できます。「事務センターを統括しました」と書くと、実際には担当していない権限や管理を加えることになります。警備を検討する場合も、この事務経験を警備の実務経験と呼びません。

説明に成果の数字が必要だと考えて、計測していない効率化率や処理件数を作らないでください。本人が実際に記録し、適切に外部へ示せる事実があるときだけ、その範囲で使用します。数値がなくても、確認の順序や引継ぎ時の状態は具体的に説明できます。

また、学習用に表を作った場合は、実務で導入したものと分けます。内部の原票や住民情報を使わず、独立した架空データで練習してください。作例の目的と本人の制作範囲を示し、他者が作った資料を自分の成果にしないことが基本です。

[担当業務と希望職種を相談用にまとめる](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担）。経験や希望条件によって、面談や求人紹介を案内できない場合があります。

## 研修、契約、勤務を一緒に確認する

事務センターの今回の求人には研修とOJTの案内があります。ただし、教育があることは、本人がすべての作業を短期間で単独実施できる保証ではありません。入職直後に担当する作業、確認を受ける人、判断に迷ったときの報告先を聞きます。管理業務の開始や手当の条件も、本人への説明を確認してください。

雇用形態は契約社員・アルバイト、勤務期間は1年以上の長期と記載されています。長期と無期雇用は別です。有期契約の更新に関する基準と、通算期間・更新回数の上限設定なしの案内があっても、本人の更新が決まったとは扱いません。初回の期間、更新、試用、勤務日数を確認します。

警備では現業のシフトと営業等の勤務を区別します。ALSOKの公式募集は現業に日勤・夜勤の例を示し、営業等には原則の日中勤務を掲げています。本人の配属と勤務は別に確認し、夜勤後の非番と休日を一括しません。運転が必要な仕事は、通勤とは別に業務での運転を検討します。

事務センターの例は顧客企業内での勤務です。BPOだから在宅と推測せず、通勤、出社、業務や就業場所の変更を聞きます。顧客先に勤務しても、顧客に直接雇用されるわけではありません。雇用主と、日々の指示・確認の体制を区別して理解しましょう。

## 応募前に決めつけず、確認する順序を作る

最初に法人と職種を決め、次に応募条件を照合し、本人の担当工程を整理します。その後、未経験の作業、研修、勤務、契約の不明点を確認します。求人にあるモデルや他者の経験談を、自分に適用される条件として扱わないことが大切です。

必要な情報がまだそろわない場合は、応募や退職の判断を保留できます。現在の仕事を続けながら操作を学び、別の職種を調べることも選択肢です。条件を満たして応募できることと、その仕事を引き受けたいことは別々に判断してください。

応募資料に現職の内部記録、職員名簿、個別の住民・顧客情報を持ち出さないでください。匿名化だけで外部利用が認められるとは限りません。個人端末や外部の生成AIへ内部情報を入力せず、公開情報と説明できる工程で整理します。職務上の連絡先や行政上の便宜を応募先への利点に使わないことも基本です。

:::insight
入口が広いという印象だけで、本人の働き方まで決まったと考えないことを勧めます。未経験を対象にする求人でも、運転、シフト、PC操作、顧客先への通勤、契約の更新など、確認する条件があります。研修は重要な情報ですが、役割や習得の結果を保証するものではありません。現在できる作業と、確認を受けながら学ぶ必要のある作業を分けて伝えてください。条件が合わなければ、別の職種を比較したり、現職を続けたりできます。内定前の退職を前提にせず、不明な欄を一つずつ埋める進め方を勧めます。本人の経験を増やして見せるより、引き受ける仕事と生活上の条件を理解することが、判断の土台になります。
:::

## まとめ：未経験の範囲と、応募条件を分ける

警備・BPOへの転職は、法人と職種を決め、実務、免許、PC、法令上の条件を照合するところから始めます。公務での連絡や記録は担当工程として説明し、警備やセンター管理の経験へ自動的に変えないことが基本です。研修、報告先、勤務、契約を確認し、現職を続ける選択も残して比較しましょう。

[LINEで相談の進め方を確認する](https://line.me/R/ti/p/@697nxhbt)際は、外部へ示せる担当と希望、未確認の条件を分けて伝えてください。

## よくある質問

### 未経験歓迎なら、特別な条件なく応募できますか？

求人ごとの条件を確認します。経験が不問でも、免許、PC、勤務、法令上の要件などは別にあります。必須と歓迎を分け、本人の応募資格を採用窓口へ確認してください。

### 公務の窓口経験は、警備やBPO経験になりますか？

同じ職務の経験にはなりません。申出の確認、記録、引継ぎなど本人の工程を示し、現場対応や企業との契約にもとづく実務との違いを保ちます。

### 研修があれば、管理業務も最初から一人でできますか？

研修は習得結果や単独実施の保証ではありません。最初に担当する作業、確認を受ける人、判断に迷ったときの報告先を、応募先へ具体的に確認してください。
