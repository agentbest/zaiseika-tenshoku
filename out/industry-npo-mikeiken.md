**「この分野に移れるか」**というご相談を伺います。

**未経験という言葉の中身を、先に分けてください。**

この記事では、**業界の構造**と、**経験の使い方**を扱います。

## 法人の仕組みが、法律で定められています

**特定非営利活動促進法第2条第1項**です。

> **この法律において「特定非営利活動」とは、別表に掲げる活動に該当する活動であって、不特定かつ多数のものの利益の増進に寄与することを目的とするものをいう。**

**同条第2項**は、**法人の要件**を定めています。

> 一 次のいずれにも該当する団体であって、**営利を目的としないもの**であること。
>
> イ **社員の資格の得喪に関して、不当な条件を付さないこと。**
>
> ロ **役員のうち報酬を受ける者の数が、役員総数の三分の一以下であること。**

**公益社団法人及び公益財団法人については、別の法律**があります。

**公益社団法人及び公益財団法人の認定等に関する法律第4条**です。

> **公益目的事業を行う一般社団法人又は一般財団法人は、行政庁の認定を受けることができる。**

**つまり、この分野の法人は、法律に基づく仕組みの中にある**ということです。

**設立、認定、報告。**

**手続と規律が、制度として置かれています。**

## 業界の構造

| 区分 | 内容 |
|---|---|
| ① 特定非営利活動法人 | **別表に掲げる活動を行う** |
| ② 公益社団法人・公益財団法人 | 行政庁の認定を受けたもの |
| ③ 一般社団法人・一般財団法人 | 認定を受けていないもの |
| ④ 社会福祉法人・学校法人等 | 別の法律に基づく |
| ⑤ 任意の団体 | 法人格を持たない |

**この区分によって、扱いが変わります。**

**⚠ 各法人の要件・手続は、所管するところの公表を確認**してください。

## 収入の構成という前提

**この分野を理解するうえで、収入の構成が要点**になります。

| 収入の種類 | 内容 |
|---|---|
| ① 会費 | 会員からの拠出 |
| ② 寄付 | 個人・法人からの拠出 |
| ③ 補助金・助成金 | **行政や財団からの交付** |
| ④ 委託の収入 | **行政等からの受託** |
| ⑤ 事業の収入 | 自らの事業による |

**③と④が、公務員経験と直接つながる部分**です。

**補助金の申請、実績の報告、委託の履行、検査への対応。**

**これらは、行政の側で扱ってきた手続**です。

**立場が逆になるだけ**で、動作は共通します。

## 「未経験」の中身を分ける

**この分野への転職で、「未経験」という言葉は、複数の意味を含みます。**

| 何が未経験か | 実際の扱い |
|---|---|
| ① 法人での勤務 | **未経験になります** |
| ② 分野（福祉、環境、教育等） | 担当していれば経験あり |
| ③ 補助金・委託の手続 | **行政の側で経験あり** |
| ④ 会計・報告 | 行政の側で経験あり |
| ⑤ 相談・支援の実務 | 分野による |

**③と④は、未経験ではありません。**

**ここを分けずに「未経験です」と書くと、持っているものが伝わりません。**

## 公務員経験が効く場所

| 場面 | 効く理由 |
|---|---|
| ① 補助金・助成金の申請 | **要綱の読み方、要件の確認** |
| ② 実績の報告 | 様式、期限、根拠の整理 |
| ③ 行政との協議 | 手続と時期が分かる |
| ④ 委託の履行 | 仕様の読み方、検査の観点 |
| ⑤ 制度の説明 | 専門でない相手への説明 |
| ⑥ 記録の整備 | 経緯を残す習慣 |

**①と②が、最も直接に効きます。**

**多くの法人で、この事務を担える人が不足しています。**

**申請の要件を読み違える、報告の期限に遅れる、根拠の資料が揃わない。**

**これらは、実際に起きています。**

**扱いは**[中小企業診断士｜公務員が取るときの現実的な道筋](skill-shindanshi.html)**にも触れています。**

## 公務員経験が効きにくい場所

| 場面 | 理由 |
|---|---|
| ① 寄付を集める | **行政に同じ動作がありません** |
| ② 会員を増やす | 同上 |
| ③ 現場の支援の実務 | 分野と経験による |
| ④ 少人数での運営 | 役割が分かれていません |
| ⑤ 収入の見通しの管理 | 予算が保証されない前提 |

**①と⑤が、最も大きい違い**です。

**⑤について。**

**行政では、予算が議決されていることが前提**です。

**一方、この分野では、収入の確保そのものが業務**になります。

**この違いを理解しているかどうかは、面接で見られます。**

:::insight
この分野への転職で、**面談でお伝えしているのが「行政の側でやってきた手続を、そのまま書いてください」**という点です。**「未経験です」と書き出す方が多い**のですが、**補助金の交付の決定、実績報告書の審査、委託の仕様の作成、検査**を担当してきた方は、**この分野の法人が日々向き合っている手続を、反対側から見てきた**ことになります。**どの要件でつまずくか、どの資料が求められるか、どの時期に何が必要か。****これは、受ける側からは見えにくい部分**です。そして、**多くの法人で、この事務を担える人が足りていません。**書類には、**「補助金の制度◯件を担当し、年間約◯件の申請の審査と実績報告の確認を実施」**と書いてください。**「未経験」で始めると、この材料が埋もれます。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

| 職種 | 内容 |
|---|---|
| ① 管理部門・事務局 | **会計、総務、報告、労務** |
| ② 補助金・助成の担当 | 申請、実績の報告 |
| ③ 事業の担当 | 分野の実務 |
| ④ 広報・渉外 | 発信、関係づくり |
| ⑤ 相談・支援の現場 | 資格が要る場合があります |

**①と②が、未経験から入りやすい入口**です。

**③⑤は、分野の経験や資格が要件となることがあります。**

**求人票の応募条件を確認**してください。

**読み方は**[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)**に整理しています。**

## 応募の前に確認すること

| 項目 | 確認すること |
|---|---|
| ① 法人の区分 | **どの法律に基づくか** |
| ② 収入の構成 | 委託か、補助か、寄付か |
| ③ 事業の内容 | 公表されている資料で |
| ④ 体制 | 職員の数、役割の分かれ方 |
| ⑤ 勤務の条件 | 時間、休日、雇用の形 |

**②が要**です。

**行政からの委託が中心の法人では、行政の手続の理解が直接使えます。**

**一方、寄付や会費が中心の法人では、別の力が求められます。**

**扱いは**[応募前の企業調査で見るべき資料](senko-sagasu-kigyochosa.html)**に整理しています。**

## 調べ方

| 資料 | 分かること |
|---|---|
| ① 法人の公表資料 | 事業の内容、収支 |
| ② 所管の公表 | **認定や届出の状況** |
| ③ 自治体の公表 | 委託・補助の実績 |
| ④ 事業の報告 | 活動の規模 |
| ⑤ 採用のページ | 体制、職種 |

**③が、行政の経験を活かせる調べ方**です。

**委託の契約や補助の交付の実績は、自治体の側で公表されている**ことがあります。

**どの法人が、どの事業を担っているかが分かります。**

**この調べ方は、役所で使ってきたもの**です。

## 書き方の例

**悪い例**

> NPOの経験はありませんが、関心があります。

**良い例**

> ◯◯課において、**◯◯に関する補助の制度◯件を担当。**年間約◯件の申請について、**要件の確認、交付の決定、実績報告の確認**を実施。**委託事業◯件について、仕様の作成から履行の確認までを担当。**活動を行う団体◯者と**協議し、事業の内容と報告の様式について調整。**

**「制度の数」「件数」「工程」「団体との協議」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 行政の側と、法人の側の対応

**同じ手続を、立場を変えて扱うことになります。**

| 手続 | 行政の側 | 法人の側 |
|---|---|---|
| 補助金 | **要件を確認し、交付を決定** | **要件を読み、申請する** |
| 実績の報告 | 報告を審査する | 報告を作成する |
| 委託 | 仕様を作り、検査する | 仕様を読み、履行する |
| 協議 | 制度の説明をする | 事業の内容を説明する |
| 記録 | 決裁の文書に残す | 事業の記録に残す |

**左の列を経験していれば、右の列で何が求められるかが分かります。**

**とくに、実績の報告**です。

**どの資料を揃えれば通るのか、どの記載で差し戻されるのか。**

**審査する側にいた人は、この見通しが立ちます。**

**書類には、「実績報告の確認を年約◯件実施」**と書いてください。

## 入る前に整理しておくこと

| 項目 | 内容 |
|---|---|
| ① 担った手続 | **補助、委託、協議、検査** |
| ② 関わった分野 | 福祉、環境、教育、地域 |
| ③ 団体との接点 | 協議、説明会、審査 |
| ④ 会計の経験 | 予算、執行、決算 |
| ⑤ 記録の作成 | 作ったもの |

**③が見落とされやすい**です。

**活動を行う団体と協議した経験**があれば、**相手の事情を知っている**ことになります。

**どういう体制で、どう動いているか。**

**この理解は、入った後の立ち上がりに効きます。**

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| なぜこの分野か | **関心ではなく、接点で** |
| 何ができるか | 手続、会計、報告 |
| 収入の前提の理解 | **予算が保証されない点** |
| 少人数の運営への考え | 役割の広さ |
| 勤務の条件 | 時間、雇用の形 |

**3行目です。**

**「行政では予算が議決されていることが前提でしたが、こちらでは収入の確保自体が業務だと理解しています」**と示せると、**前提の理解が伝わります。**

**なお、特定の団体が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

## よくある失敗

**1. 「未経験です」から書き出す**

**行政の側での手続**を先に書いてください。

**2. 関心だけを志望の理由にする**

**接点**で説明してください。

**3. 補助金・委託の経験を書かない**

**最も直接に効く部分**です。

**4. 収入の構成を確認しない**

**求められる力が変わります。**

**5. 法人の区分を確認しない**

**根拠となる法律が違います。**

**6. 自治体の公表資料を使わない**

**委託・補助の実績**が分かります。

**7. 勤務の条件を後回しにする**

**雇用の形が求人によって違います。**

**8. 収入の前提の違いに触れない**

**面接で見られます。**

:::insight
ここまで「効く場所」の話をしておいて逆のことを言いますが、**この分野では、勤務の条件を必ず先に確認してください。**面談で拝見していると、**事業の内容への関心が強く、条件を後回しにする方**がいらっしゃいます。ところが、**法人によって、雇用の形や勤務の条件は大きく異なります。**期間の定めの有無、勤務の時間、休日、事業の期間に連動する雇用。**とくに、補助や委託を財源とする事業では、事業の期間と雇用の期間が結び付いている**ことがあります。**求人票の雇用の形と期間の欄を、先に読んでください。**そのうえで、**面接で「事業の期間と雇用の関係」を確認**してください。**聞きにくい質問ではありません。**採用する側も、**前提を理解している人**を求めています。**条件を確認したうえで選ぶほうが、結果として続きます。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **特定非営利活動促進法第2条**は、**不特定かつ多数のものの利益の増進に寄与することを目的とする活動**と、**営利を目的としないこと**などの法人の要件を定めています
- **公益社団法人及び公益財団法人の認定等に関する法律第4条**は、**公益目的事業を行う一般社団法人又は一般財団法人が、行政庁の認定を受けることができる**としています
- **法人の区分によって、根拠となる法律が違います**
- **「未経験」の中身を分けて**ください。**補助金・委託の手続と会計・報告は、行政の側で経験しています**
- 効くのは、**申請、実績の報告、行政との協議、委託の履行、制度の説明、記録の整備**です
- 効きにくいのは、**寄付を集める、会員を増やす、収入の見通しの管理**です
- **入りやすいのは、管理部門・事務局と、補助金・助成の担当**です
- **勤務の条件と、事業の期間との関係を先に確認**してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 関心のある分野の経験がありません

**分野より、手続の経験で入る方法があります。**管理部門や事務局の職種では、**会計、総務、報告、労務**が業務の中心です。**分野の実務の経験がなくても、これらは担えます。**書き方は、**「補助金の制度の運用と、実績報告の確認を担当」**という形です。なお、**分野の実務を担う職種**では、**資格や経験が要件**となることがあります。**求人票の応募条件を確認**してください。**入口を1つに絞らないでください。**

### 処遇や雇用の形が不安です

**求人票で先に確認してください。**期間の定めの有無、勤務の時間、休日、賃金の構成。**これらは、法人と職種によって大きく異なります。**とくに、**補助や委託を財源とする事業**では、**事業の期間と雇用の期間が結び付いている**ことがあります。面接では、**「事業の期間と雇用の関係」**を確認して差し支えありません。**前提を理解している人**として読まれます。扱いは[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。

### 行政との関係が近い法人を探すには

**自治体の公表資料から探せます。**委託の契約の公表、補助金の交付の実績、指定管理者の指定。**これらは、自治体の側で公表されている**ことがあります。**どの法人が、どの事業を担っているかが分かります。**そのうえで、**法人の公表資料で事業の内容と収支を確認**してください。**この調べ方は、役所で使ってきたもの**です。扱いは[応募前の企業調査で見るべき資料](senko-sagasu-kigyochosa.html)に整理しています。**外から探すより、相手の側の資料から探すほうが確実です。**
