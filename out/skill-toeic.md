**「何点あれば有利になるのか」**というご相談を伺います。

**基準は、求人によって決まります。**

この記事では、**基準の調べ方**と、**意味が出る場面**を扱います。

**⚠ 試験の内容・実施の方法・基準は、実施する団体と各社の公表を確認してください。****この記事では、具体の点数には触れません。**

## 能力の開発は、入社後にも続きます

**職業能力開発促進法第8条**です。

> **事業主は、その雇用する労働者が多様な職業訓練を受けること等により職業能力の開発及び向上を図ることができるように、その機会の確保について、次条から第十条の四までに定める措置を通じて、配慮するものとする。**

**事業主の側にも、能力の開発の機会の確保について配慮する立場がある**と定められています。

**つまり、入社の時点ですべてを備えている必要はない**という前提が、法律の側にも置かれています。

**資格や試験は、入口の材料の1つ**です。

**そのうえで、どの場面で材料になるのかを見ていきます。**

## 基準は、求人票に書かれています

**「何点から意味が出るか」という問いの答えは、求人票にあります。**

| 記載 | 意味 |
|---|---|
| 具体の基準が「必須」に記載 | **その基準を満たす必要があります** |
| 具体の基準が「歓迎」に記載 | 満たしていなくても応募できます |
| 語学に関する記載がない | **判断の中心にはなりません** |
| 技能の指定がある | 読む・書く・聞く・話すのどれか |

**3行目が、公務員からの転職では多い**です。

**行政が相手の事業では、語学が条件に挙がることは多くありません。**

**相手が日本の行政機関だからです。**

**扱いは**[英語｜必要になる職種と、不要な職種](skill-eigo.html)**に整理しています。**

## 意味が出る場面

| 場面 | 理由 |
|---|---|
| ① 応募条件に基準がある | **満たす材料になる** |
| ② 海外との取引がある事業 | 実務で使う |
| ③ 技術の分野（仕様・規格） | 読む技能が要る |
| ④ 実務での使用経験がない | **到達を示すものが他にない** |
| ⑤ 社内の制度で求められる | 入社後に必要になる場合 |

**④について。**

**業務で英語を使った場面がない場合、水準を示すものが他にありません。**

**この場合、試験の結果が材料になります。**

**一方、使った場面があるなら、そちらのほうが具体**です。

## 意味が出にくい場面

| 場面 | 理由 |
|---|---|
| ① 応募条件に記載がない | 判断の中心にならない |
| ② 行政が相手の事業 | **相手は日本の行政機関** |
| ③ 実務での使用経験がある | 経験のほうが具体 |
| ④ 応募の時期が近い | **短期間では大きく変わらない** |
| ⑤ 他に足りないものがある | 書類、条件の整理 |

**④が要**です。

**語学の力は、短期間で大きく変わりません。**

**応募の時期が決まっているなら、いま持っている力で応募できる求人を探す**ほうが現実的です。

## 書くときの注意

| 注意 | 内容 |
|---|---|
| ① 受験の年を書く | **いつの結果か** |
| ② 記載するかを選ぶ | 応募先に関係するか |
| ③ 実務の経験と併記 | 使った場面があれば |
| ④ 技能の別 | 求人が指定している場合 |
| ⑤ 誇張しない | 会話の可否などを盛らない |

**①が抜けやすい**です。

**受験から年数が経っている場合、現在の水準とは別のもの**として読まれることがあります。

**⑤について。**

**「日常会話程度」といった表現は、受け取り方に幅があります。**

**使った場面を具体に書く**ほうが、誤解が生じません。

:::insight
語学の試験について、**面談でお聞きしているのが「応募したい求人を5件読みましたか」**という点です。**「何点あればよいか」という問いは、求人を読む前に出てくることが多い**です。ところが、**基準は求人ごとに違います。**そして、**公務員からの転職で多い領域——行政が相手の事業、自治体向けのシステム、受託や指定管理——では、語学が応募条件に挙がることが多くありません。**つまり、**読んでみると、そもそも要件でなかったということが起こります。**逆に、**要件がある求人では、基準が具体に書かれています。**「◯◯以上」「英文の資料を読める方」。**求人票を見れば、答えが載っている**わけです。ですから、**先にすべきは、勉強でも受験でもなく、求人票を読むこと**です。**読んだうえで必要なら受ける。**この順序にしてください。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 受ける前に考えること

| 確認すること | 内容 |
|---|---|
| ① 応募したい求人の条件 | **5件読んで確認** |
| ② 必須か、歓迎か | 扱いが違います |
| ③ 技能の指定 | 読む・書く・聞く・話す |
| ④ 期限 | 応募の時期に間に合うか |
| ⑤ 他の優先順位 | 書類、条件の整理 |

**①を最初に置いてください。**

**なお、受ければ転職できる、という関係にはありません。**

**要件として挙げられている場合に、条件を満たす材料になる**というものです。

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 求人を読む | **週に30分** |
| 使った場面の書き出し | 窓口、資料、会議 |
| 学習の継続 | 長く続ける前提で |
| 受験の時期の検討 | 結果が出る時期を確認 |

**2行目です。**

**外国籍の住民への対応、英文の資料の確認、海外からの視察の受入れ。**

**業務で使った場面があれば、書類に書けます。**

**扱いは**[英語｜必要になる職種と、不要な職種](skill-eigo.html)**に整理しています。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 使った場面 | **業務での具体例** |
| 技能の別 | どの技能が使えるか |
| 学習の状況 | 継続しているか |
| 受験の理由 | なぜ受けたか |
| できる範囲 | **正確に、限定して** |

**5行目です。**

**できないことを書かないでください。**

**「英文の資料を読み、内容を要約した経験があります」**という形で、範囲を明示してください。

## 使った場面の書き方

| 場面 | 書き方の例 |
|---|---|
| 窓口の対応 | 外国籍の住民への対応を年◯件担当 |
| 資料の確認 | 英文の規格を確認し、仕様に反映 |
| 案内の作成 | 多言語の案内の作成に関与 |
| 受入れ | 海外からの視察の受入れに対応 |
| 研修 | 語学の研修を受講（◯年） |

**2行目が、技術の分野では効きます。**

**規格や仕様の原文が英語であることがあり、読む技能が実務に直結**します。

**この場合、「読む」技能の経験として書いてください。**

**なお、業務で使った場面がない場合、無理に書かないでください。**

**その場合は、学習の状況を書けば足ります。**

## よくある失敗

**1. 求人票を読まずに受験する**

**要件でないもの**を目指すことになります。

**2. 受験の年を書かない**

**いつの結果か**が分かりません。

**3. 実務で使った場面を書かない**

**経験のほうが具体**です。

**4. 技能の別に触れない**

**求人が指定している**ことがあります。

**5. 会話の可否を盛る**

**受け取り方に幅**があります。

**6. 応募の時期が近いのに学習を始める**

**書類の作成が優先**です。

**7. 行政が相手の事業でも必要だと考える**

**相手は日本の行政機関**です。

**8. 受ければ転職できると考える**

**要件を満たす材料の1つ**です。

:::insight
ここまで「まず求人票を」という話をしておいて逆のことを言いますが、**受験そのものに意味がない、という話ではありません。**面談で拝見していると、**「転職に必要ないなら、やめておこう」と判断される方**がいらっしゃいます。ところが、**入社後に使う場面はあり得ます。**海外の事例を調べる、規格や技術の資料を読む、外国籍の方への対応を含む業務を担う。**そして、職業能力開発促進法第8条のとおり、事業主の側にも能力の開発の機会の確保について配慮する立場があります。****入社後に学ぶ枠組みは、会社の側にもある**ということです。ですから、**転職の準備としては優先順位を下げ、長く続ける前提で学ぶ**という位置づけにしてください。**応募の時期に間に合わせようとしない。**これが要点です。**学習を続けていること自体は、面接で話せる材料になります。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **職業能力開発促進法第8条**は、**事業主が、労働者の職業能力の開発及び向上の機会の確保について配慮する**としています。**入社の時点ですべてを備えている必要はありません**
- **「何点から意味が出るか」の答えは、求人票に書かれています**
- **必須・歓迎・記載なし**で、扱いが違います
- **行政が相手の事業では、語学が条件に挙がることが多くありません**
- **実務で使った場面があるなら、そちらのほうが具体**です
- **受験の年を書いて**ください。**会話の可否を盛らないでください**
- **先にすべきは、勉強でも受験でもなく、求人票を5件読むこと**です

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 求人票に基準が書かれていました

**その求人では、要件です。**「必須」であれば、**基準を満たす必要があります。**「歓迎」であれば、**満たしていなくても応募できます。**なお、**基準の数値は、会社と職種によって異なります。**他社の記載を当てはめないでください。また、**基準を満たしていても、実務で使えるかは別**に確認されることがあります。面接で、**「業務ではどの場面で使いますか」**と聞いておくと、入社後の想像がつきます。読み方は[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。

### 古い結果しか持っていません

**受験の年を明記したうえで、記載して差し支えありません。**ただし、**現在の水準とは別のもの**として読まれることがあります。気になる場合は、**実務で使った場面を併せて書いて**ください。「英文の資料を確認し、内容を要約して庁内に共有」という形です。**直近の使用の事実があると、年数の古さが補われます。**なお、**応募条件に基準がある求人で、古い結果しかない場合**は、**受け直すかどうかを期限と照らして判断**してください。扱いは[選考スケジュールの組み方](senko-sagasu-schedule.html)に整理しています。

### 受験の結果が出るまで、応募を待つべきですか

**待たないでください。**結果が出るまでの期間に、**条件の合う求人が掲載を終える**ことがあります。とくに、**行政が相手の事業では、募集が事業の周期に応じて生じる**ため、時期を逃すと次がいつになるか読めません。**語学が要件でない求人には、いま応募できます。**そのうえで、**結果が出たら、必要な求人に追加で応募する**という進め方で差し支えありません。**「準備が整ってから」と考えて時期を逃すほうが、機会を失います。**扱いは[何社くらい受けるべきか](senko-sagasu-fukusu.html)に整理しています。
