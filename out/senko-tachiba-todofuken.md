**都道府県の仕事は、住民から見えにくい**と言われます。

**ところが、民間から見ると接点が多い**という特徴があります。

この記事では、**経験の特徴**と、**示し方**を扱います。

## 都道府県の事務は、法律で性質が定められています

**地方自治法第2条第5項**です。

> **都道府県は、市町村を包括する広域の地方公共団体として、第二項の事務で、広域にわたるもの、市町村に関する連絡調整に関するもの及びその規模又は性質において一般の市町村が処理することが適当でないと認められるものを処理する**ものとする。

**3つの性質**が挙げられています。

| 性質 | 内容 |
|---|---|
| ① 広域にわたるもの | 複数の市町村に及ぶ事務 |
| ② 市町村に関する連絡調整 | **市町村への支援、調整** |
| ③ 規模・性質において一般の市町村が処理することが適当でないもの | **専門性の高い事務** |

**この3つが、そのまま経験の特徴**になります。

**なお、同条第3項**は、**市町村を基礎的な地方公共団体**と位置づけています。

**住民に最も近い事務は市町村、広域と専門は都道府県**という整理です。

## 経験の特徴

| 特徴 | 具体の例 |
|---|---|
| ① 許認可・監督 | 事業者への許可、立入検査、指導 |
| ② 市町村への支援 | 助言、研修、調整、財政の支援 |
| ③ 広域の計画 | 総合計画、分野別の計画、区域の設定 |
| ④ 専門の機関 | 保健所、土木事務所、農林事務所、試験研究機関 |
| ⑤ 国との連絡 | 通知の受け、照会、事務の実施 |
| ⑥ 大規模な事業 | 道路、河川、港湾、病院、学校 |

**①が、民間で最も直接に使えます。**

**規制を受ける側の会社では、許認可の対応を担う人が必要とされる**ためです。

**②も特徴的**です。

**市町村という、組織を相手に支援や調整をした経験**は、**法人を顧客とする仕事に近い**位置づけになります。

## 書き方の例

**悪い例**

> ◯◯県◯◯課で、事業者の指導を担当しました。

**良い例**

> ◯◯に関する許可の事務を担当。**年間約◯件の許可の審査と、◯件の立入検査を実施。**基準に適合しない事案について、**是正の指導と改善の計画の確認**を担当。**管内◯市町村の担当者向けに、事務の手引を作成し、研修を◯回実施。**

**「件数」「相手」「作ったもの」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 言い換えの対応

| 役所の言葉 | 民間での読まれ方 |
|---|---|
| 許可・認可の審査 | **基準に照らした審査、与信に近い判断** |
| 立入検査 | 監査、品質の確認 |
| 是正の指導 | 改善の要求、是正の管理 |
| 市町村への助言 | **顧客への支援、導入の支援** |
| 研修の実施 | 教育、マニュアルの整備 |
| 広域の計画の策定 | 事業の計画、中期の計画 |

**4行目です。**

**市町村への助言は、「組織を相手にした支援」**です。

**自治体向けのシステムやサービスの会社では、この動作がそのまま業務になります。**

## 民間での使いどころ

| 領域 | 使える経験 |
|---|---|
| ① 自治体向けの事業 | **市町村の事情を理解している** |
| ② 規制を受ける側の会社 | 許認可、検査、是正の対応 |
| ③ 建設コンサルタント・発注者支援 | 大規模な事業の経験 |
| ④ 医療・福祉・環境 | 専門の機関での経験 |
| ⑤ 調査・コンサルティング | 計画の策定、分析 |

**①が、都道府県職員の強み**です。

**市町村の規模の違い、体制の違い、事務の進め方の違い。**

**これらを知っている人は、自治体向けの事業で重宝されます。**

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 何を担当したか | **件数、相手、範囲** |
| どこまで自分で決めたか | 専決できた事項 |
| 難しい局面の対応 | 3件、経緯と結論 |
| 相手との関係の作り方 | 指導と支援の使い分け |
| 異動の幅 | 経験した分野 |

**4行目です。**

**都道府県の仕事は、指導する立場と支援する立場の両方**を経験します。

**この使い分けができる点は、説明の材料**になります。

**なお、特定の事業者が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

:::insight
都道府県職員の方のご相談で、**面談でお伝えしているのが「市町村を相手にした経験を、前面に出してください」**という点です。多くの方が、**許認可や検査の経験を中心に書かれます。**それも重要ですが、**民間から見て希少なのは、市町村を相手にした経験**のほうです。自治体向けの事業を行う会社では、**「市町村がどう動くか」が分からない**という課題を抱えています。予算の時期、議会の日程、決裁に要する期間、担当者の異動の周期、規模による体制の違い。**これらは、外から見ても分かりません。**そして、**都道府県の職員は、複数の市町村を同時に相手にしてきた**経験があります。**十数から数十の団体の事情を知っている**わけです。これは、**自治体向けの営業、導入の支援、制度の支援のいずれでも使えます。**書類には、**「管内◯市町村の担当者を対象に」**と数を書いてください。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 準備の順序

| 順 | やること |
|---|---|
| 1 | 担当した事務を、①〜⑥の性質で分類する |
| 2 | 件数、相手、範囲を確認する |
| 3 | **市町村を相手にした経験を抜き出す** |
| 4 | 民間の言葉に置き換える |
| 5 | 求人を読む |
| 6 | 職務経歴書を作る |

**3が要**です。

**研修、会議、照会への回答、計画の調整。**

**市町村と関わった場面を、すべて書き出してください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 在職中の進め方

| 項目 | 内容 |
|---|---|
| 記録 | 担当した件数、関わった市町村の数 |
| 資料の確認 | 分掌、決裁の区分 |
| 求人を読む | 週に30分 |
| 日程の確保 | **議会・予算・検査の時期を避ける** |

**4行目です。**

**出先の機関では、検査や許認可の繁忙期が分野ごとに異なります。**

**自分の繁忙期を書き出してから、選考の時期を決めてください。**

**扱いは**[選考スケジュールの組み方](senko-sagasu-schedule.html)**に整理しています。**

## よくある失敗

**1. 市町村を相手にした経験を書かない**

**民間から見て希少**です。

**2. 許認可を「担当しました」で済ませる**

**件数と基準**を書いてください。

**3. 立入検査を書かない**

**監査・品質の確認**として読まれます。

**4. 専門の機関での経験を書かない**

**分野の経験**が要件になることがあります。

**5. 研修の実施を書かない**

**教育・マニュアルの整備**に対応します。

**6. 異動の幅を弱みと考える**

**分野をまたいだ経験**として書けます。

**7. 繁忙期に選考を始める**

**分野ごとに時期が違います。**

**8. 特定の事業者が分かる説明をする**

**守秘の義務は退職後も続きます。**

:::insight
ここまで書き方の話をしておいて逆のことを言いますが、**都道府県の職員は、異動の幅を弱みと受け取りがちです。**面談で拝見していると、**「保健所、土木事務所、本庁の総務と、バラバラで専門がない」**とおっしゃる方がいらっしゃいます。ところが、**この幅は、見方を変えると強みになります。**理由は2つあります。1つは、**どの分野でも、同じ動作を繰り返している**こと。基準に照らした判断、相手への説明、記録の作成、関係先との調整。**分野が変わっても、動作は共通**しています。もう1つは、**分野をまたいだ経験を持つ人が、組織の中では重宝される**こと。新しい領域に入っても、**立ち上がりが速い**ためです。ですから、書類には**機能でまとめ直したうえで、経験した分野を一覧として添える**という構成にしてください。**「幅がある」ことが伝わります。**整理の仕方は[異動が多い公務員の職務経歴書の並べ方](senko-shokumu-ido.html)に整理しています。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方自治法第2条第5項**は、都道府県の事務を、**広域にわたるもの、市町村に関する連絡調整に関するもの、規模・性質において一般の市町村が処理することが適当でないもの**としています
- **この3つが、そのまま経験の特徴**になります
- **許認可・監督の経験**は、規制を受ける側の会社で直接使えます
- **市町村を相手にした経験**は、民間から見て希少です。前面に出してください
- **専門の機関での経験**は、分野の要件になることがあります
- **異動の幅は、機能でまとめ直せば強み**になります
- 書くのは、**件数・相手・範囲・作ったもの**です

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 本庁と出先で、書き方を変えるべきですか

**分けて書くほうが伝わります。**本庁では、**制度の運用の設計、予算、市町村との調整、議会への対応**が中心になります。出先では、**許認可の審査、検査、指導、現場の管理**が中心です。**役割が違うため、まとめて書くと中身がぼやけます。**書き方は、**在籍の一覧を時系列で置き、その後に機能でまとめる**という構成です。「制度の運用の設計」「基準に照らした審査」「事業者への指導」「市町村への支援」のように、**動作の軸でまとめ直して**ください。読む側は、**役職や所属ではなく、何ができるか**を見ています。

### 保健所や試験研究機関の経験は、使えますか

**分野によっては、そのまま要件になります。**食品、環境、薬事、動物の愛護に関する分野など、**規制を受ける側の会社で、対応を担う人が求められる**ことがあります。また、**検査や分析の実務**は、民間の検査機関や品質の管理の部署で使えます。書き方は、**「◯◯に関する検査を年間約◯件実施」「◯◯法に基づく監視を担当し、◯件の指導を実施」**という形です。**根拠の法令と件数**を書いてください。**分野の名称は、正式な法令の名称で記載**してください。なお、**資格が要件となる求人**もあります。保有する資格は、**取得の年と併せて記載**してください。

### 転居をともなう異動が多く、民間でも転勤が心配です

**求人の段階で確認できます。**転勤の可能性と範囲は、**内定の前に確認**してください。求人票に「転勤なし」と書かれていても、**範囲の定めを確認**することをお勧めします。なお、**行政が相手の事業では、各地に拠点がある会社が多い**一方、**勤務地が特定の案件に紐づく**こともあります。**配属予定の案件と、その勤務の場所**を確認してください。扱いは[転職にともなう転居と単身赴任](senko-taishoku-tenkyo.html)に整理しています。**転居が難しい事情があるなら、応募の段階で伝えて**差し支えありません。
