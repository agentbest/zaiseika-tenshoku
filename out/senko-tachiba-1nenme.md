**採用された年に、続けられるか不安になる方がいらっしゃいます。**

**慣れない環境で、判断が難しい時期**です。

この記事では、**整理の仕方**と、**相談先**を扱います。

**⚠ 体調に関わることは、先に対処してください。****この記事は、制度と進め方の整理にとどめます。**

## 制度の上でも、最初の期間は特別に扱われています

**地方公務員法第22条**です。

> **職員の採用は、全て条件付のものとし、当該職員がその職において六月の期間を勤務し、その間その職務を良好な成績で遂行したときに、正式のものとなる**ものとする。この場合において、人事委員会等は（略）**条件付採用の期間を一年を超えない範囲内で延長することができる。**

**採用から一定の期間は、条件付**という仕組みです。

**つまり、制度の側も、最初の期間を「見極めの期間」として扱っている**ということです。

**この時期に、仕事が身についていないと感じること自体は、想定の範囲**です。

**慣れていないことと、合わないことは別**です。

**まず、この2つを分けてください。**

## 何が起きているかを分ける

| 要素 | 内容 |
|---|---|
| ① 業務の量 | 処理が追いつかない |
| ② 業務の内容 | 扱う対象が合わない |
| ③ 人との関わり | 指導の受け方、職場の関係 |
| ④ 環境 | 通勤、勤務時間、場所 |
| ⑤ 体調 | 睡眠、食事、気分の変化 |
| ⑥ 見通し | この先が想像できない |

**⑤があてはまる場合、先に対処してください。**

**産業医、共済組合の相談の窓口、医療機関。**

**相談の窓口は、団体ごとに置かれています。**

**人事担当に、窓口の場所を確認して差し支えありません。**

**①と⑥は、時間の経過で変わる**ことがあります。

**②と③は、配置の変更で変わる**ことがあります。

## 1年目にできること

| やること | 相手 |
|---|---|
| 業務の量の相談 | 係長、上司 |
| 指導の受け方の相談 | 同上 |
| 体調の相談 | **産業医、共済組合の窓口** |
| 異動の希望 | 人事の制度による |
| 休暇の取得 | 制度の範囲で |

**1行目です。**

**処理が追いつかないことを、そのまま伝えて差し支えありません。**

**1年目で処理が追いつかないのは、珍しいことではありません。**

**伝えなければ、配分は変わりません。**

**4行目について。**

**多くの団体で、異動の希望を出す仕組みがあります。**

**時期と方法を、人事担当に確認**してください。

## 準備の順序

| 順 | やること |
|---|---|
| 1 | **体調の確認**（必要なら相談） |
| 2 | 起きていることを①〜⑥で分ける |
| 3 | 時間で変わるもの、配置で変わるものを見分ける |
| 4 | 相談できる先に相談する |
| 5 | それでも変わらない場合、選択肢を調べる |
| 6 | 判断する |

**5を6の前に置いてください。**

**調べることと、決めることは別**です。

**どんな仕事があるか、どんな条件があるかを知ってから、判断して差し支えありません。**

## 転職を検討する場合の前提

| 項目 | 内容 |
|---|---|
| 職務経歴 | **短いため、書ける内容が限られます** |
| 説明 | 変わる理由の説明が求められます |
| 選べる求人 | 未経験を前提とする募集が中心になります |
| 時期 | 急ぐ必要はありません |

**1行目です。**

**1年目でも、担当した業務は書けます。**

**扱った件数、対象、使ったシステム、作成した資料。**

**ただし、量は限られます。**

**2行目について。**

**「なぜ変わるのか」は、確認されることがあります。**

**責められているのではなく、次も同じ理由にならないかを確認されている**という位置づけです。

**この説明のためにも、①〜⑥の整理が必要**です。

:::insight
1年目のご相談で、**面談でお伝えしているのが「辞めるかどうかを、いま決めなくてよい」**という点です。採用の年は、**判断の材料が最も少ない時期**です。配属された1つの課しか知らず、担当した業務も限られています。**この状態で「公務員が合わない」と結論を出すのは、材料が足りません。**役所は、**課によって仕事の性質がまったく違います。**窓口が中心の課、制度の設計が中心の課、現場の監督が中心の課。**数年で配置が変わる仕組み**になっているのは、そのためでもあります。ですから、**「いまの課が合わない」と「公務員が合わない」を分けてください。**前者であれば、**異動の希望という手段**があります。一方、**体調に影響が出ている場合は別**です。**その場合は、我慢する期間を設けないでください。**相談の窓口は、制度として置かれています。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 在職中の進め方

| 項目 | 内容 |
|---|---|
| 業務の記録 | 月に1回、数行 |
| 求人を読む | 週に30分 |
| 制度の確認 | 異動の希望、休暇、相談の窓口 |
| 書類の下書き | 時間の取れるときに |

**1行目です。**

**担当した件数と、その月に新しく扱ったこと。**

**この2つを残しておくと、後で材料になります。**

**転職しない場合も、人事評価の資料として使えます。**

**2行目について。**

**求人を読む作業は、応募の意思がなくてもできます。**

**「外にどんな仕事があるか」を知るだけでも、見通しが変わります。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 相談できる先

| 相談先 | 内容 |
|---|---|
| 上司・係長 | 業務の量、進め方 |
| 人事担当 | 制度、異動の希望、窓口の場所 |
| 産業医 | 体調 |
| 共済組合の窓口 | 健康、生活 |
| 家族・知人 | 状況の共有 |
| 外部の相談 | 仕事の選択肢 |

**1行目を飛ばさないでください。**

**「相談したら評価が下がる」と考える方がいらっしゃいますが、業務の量の相談は、通常の報告の一部**です。

**処理が滞るほうが、結果として問題になります。**

## 1年目に身についているもの

**「まだ何もできない」と感じる時期ですが、次の点は身についています。**

| 項目 | 内容 |
|---|---|
| 行政の仕組み | 予算の年度、議会の時期、決裁の流れ |
| 規程に沿う処理 | 根拠を確認してから進める習慣 |
| 記録の作法 | 経緯を残す、様式に沿って書く |
| 対外の対応 | 住民・事業者への説明 |
| 期限の管理 | 締切から逆算して動く |

**1行目です。**

**行政の仕組みは、外から入った人には見えにくい**ものです。

**1年でも、内側で経験した理解は残ります。**

**行政が相手の事業を担う会社では、この理解が要件になる**ことがあります。

**2行目について。**

**根拠を確認してから進める習慣は、民間でも評価されます。**

**これらは、いま担当している業務の中で積み上がっています。****記録に残しておいてください。**

## よくある失敗

**1. 体調の変化を後回しにする**

**先に対処**してください。

**2. 慣れていないことと、合わないことを分けない**

**時間で変わるものがあります。**

**3. 業務の量を相談しない**

**伝えなければ配分は変わりません。**

**4. 異動の希望の仕組みを確認しない**

**配置で変わることがあります。**

**5. いまの課と、公務員全体を同じに考える**

**課によって性質が違います。**

**6. 調べる前に決める**

**調べることと決めることは別**です。

**7. 記録を残さない**

**後で材料になります。**

**8. 1人で抱える**

**相談の窓口は制度として置かれています。**

:::insight
ここまで慎重な話をしておいて逆のことを言いますが、**「石の上にも三年」を理由に、体調を崩すまで続ける必要はありません。**面談で拝見していると、**年数の目安を気にして、限界まで続けてしまう方**がいらっしゃいます。**年数の目安に、制度上の根拠はありません。**判断の基準は、**続けられる状態かどうか**です。そして、**続けられない状態が体調に現れている場合、それは判断の材料**です。この場合、**まず休むことと、相談することが先**になります。転職の検討は、**その後で構いません。**一方、**体調に問題がなく、業務に慣れていないだけであれば、時間が解決する部分があります。**この2つは、対処がまったく違います。**自分がどちらかを、正直に見てください。**分からない場合は、**産業医や相談の窓口で話してみてください。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方公務員法第22条**は、**採用を条件付のものとし、6月の期間の勤務と良好な成績で正式のものとなる**と定めています。**制度の側も、最初の期間を見極めの期間として扱っています**
- **慣れていないことと、合わないことを分けて**ください
- 起きていることを、**①量 ②内容 ③人 ④環境 ⑤体調 ⑥見通し**で分けてください
- **⑤があてはまる場合、先に対処**してください。相談の窓口は制度として置かれています
- **業務の量は、相談して差し支えありません**
- **「いまの課が合わない」と「公務員が合わない」は別**です
- **調べることと、決めることは別**です。調べてから判断してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 1年目で辞めると、次の就職に影響しますか

**説明が求められることはあります。**在職の期間が短い場合、**「なぜ変わるのか」を確認される**ことがあります。ここで用意しておきたいのが、**①〜⑥の整理**です。「業務の量が想定と違った」「扱う内容が自分の関心と離れていた」。**具体に説明できれば、次の条件の話につながります。**一方、「合わなかった」だけでは、**次も同じではないかという疑問が残ります。**なお、**未経験を前提とする募集**では、在職の期間の短さより、**基礎的な事務の経験と、学ぶ姿勢**が見られることがあります。求人票の「必須」の欄を読んで判断してください。

### 異動の希望を出しても、通らない気がします

**仕組みと時期を確認してください。**多くの団体で、**異動の希望を出す仕組み**が置かれています。**時期、方法、書き方**を人事担当に確認してください。**通る保証はありません**が、**出していなければ、検討の対象にもなりません。**また、**書き方によって伝わり方が変わります。**「いまの課が嫌だ」ではなく、**「◯◯の分野に関心があり、そこで経験を積みたい」**という形にすると、配置の検討の材料になります。なお、**希望が通るまでに時間がかかる**こともあります。その間の進め方は、上司に相談してください。

### 相談できる人がいません

**制度として置かれた窓口があります。**産業医、共済組合の相談の窓口、団体が設けている相談の窓口。**これらは、上司を通さずに利用できる**ことがあります。**人事担当に、窓口の場所と利用の方法を確認**してください。「制度について知りたい」という照会で足ります。また、**外部の相談**も使えます。当社でも、**仕事の選択肢について話を伺うことができます。**転職を決めていなくても構いません。**何が起きているかを言葉にする作業**から始めて差し支えありません。**1人で抱える状態を続けないでください。**
