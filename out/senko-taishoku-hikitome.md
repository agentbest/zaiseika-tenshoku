退職を伝えると、**引き止められることがあります。**

**「もう少し考えてみないか」**
**「次の異動で希望の部署に行けるようにする」**
**「来年度は昇任の見込みがある」**

**引き止めがあること自体は、珍しくありません。**人が抜ければ、**業務の割り振りをやり直す必要があるから**です。

この記事では、**提示される条件の性質と、検討するかどうかの判断**を扱います。伝え方は[退職を切り出すタイミングと相手](senko-taishoku-kirisashi.html)にあります。

## 人事の権限は、任命権者にあります

**提示された条件を検討するとき、確認すべき点があります。**

**地方公務員法第17条第1項**です。

> 職員の職に欠員を生じた場合においては、**任命権者は、採用、昇任、降任又は転任のいずれかの方法により、職員を任命することができる。**

**任命は、任命権者が行います。**

つまり、**直属の上司や課長が「異動させる」と述べても、それは任命の決定ではありません。**

**意向を伝えることはできても、決めるのは任命権者**です。

**引き止めの場で提示される条件は、多くの場合、確約ではなく見込み**です。

**この点を理解したうえで、検討してください。**

## 提示されやすい条件

| 条件 | 性質 |
|---|---|
| 異動の希望を通す | **任命権者の判断。**確約ではない |
| 昇任の見込み | 同上。**選考や評価の結果による** |
| 業務の負担の軽減 | 所属の判断で調整できることがある |
| 働き方の運用 | **所属の運用で変えられる場合がある** |
| 処遇 | **条例に基づくため、個別の調整は困難** |

**3つ目と4つ目は、所属の判断で実現しやすい部分**です。

**1つ目と2つ目は、見込みにとどまります。**

**5つ目は、制度上、個別の調整ができません。**地方自治法第204条の2により、**給与その他の給付は条例に基づいて支給されます。**

## 検討するかどうかの判断

| 問い | 判断 |
|---|---|
| 提示された条件で、**辞める理由が解消するか** | 解消しないなら、検討の余地は小さい |
| その条件は、**確約か見込みか** | 見込みなら、実現しない可能性がある |
| 実現する**時期はいつか** | 次年度以降なら、それまで待てるか |
| **応募先への影響**はどうか | 受諾後であれば、辞退の影響が生じる |

**1つ目が出発点です。**

**辞める理由が「担当する分野を選べない」であれば、異動の希望が通ることで解消する可能性があります。**

**一方、「制度を運用する側ではなく、作る側で働きたい」であれば、庁内の異動では解消しません。**

**自分の理由が、どちらの型かを先に確かめてください。**

## 受諾の前か後かで、重さが違う

| 段階 | 扱い |
|---|---|
| 内定の受諾前 | **検討して差し支えありません** |
| 受諾した後 | **辞退の影響**が生じます |
| 入社の直前 | **避けてください** |

**受諾した後に残る判断をすると、応募先は採用の計画をやり直すことになります。**

**だから、迷いがあるうちは受諾しない。**これが基本です。

**扱いは**[内定辞退の伝え方](senko-mensetsu-jitai.html)**にあります。**

## 断るときの伝え方

**検討したうえで、意思が変わらない場合の伝え方**です。

> ご配慮いただき、ありがとうございます。検討いたしましたが、退職の意思は変わりません。◯月◯日での退職について、引き続きご相談させていただければと思います。

**3文で足ります。**

| ✕ | ○ |
|---|---|
| 曖昧にして先延ばしにする | **意思が変わらないことを明確に** |
| 条件を比較して説明する | 比較の中身を述べる必要はありません |
| 感謝を述べない | **配慮への謝意は添える** |

**1つ目を避けてください。**

**曖昧にすると、引き止めが続きます。**結果として、**引継ぎの調整が進みません。**

:::insight
引き止めで、**面談でお伝えしているのが「条件が変わるなら残る、という判断にも理がある」**という点です。面談で伺った例では、**異動の希望が通ることが確認できて、残る判断をされた方**がいらっしゃいます。**それは、失敗ではありません。**比べたうえで選んだ結果です。ただし、**2つ確認してください。**1つは、**その条件が確約か見込みか。**地方公務員法第17条のとおり、**任命は任命権者が行います。**課長の言葉が、そのまま実現するとは限りません。**書面や、人事の担当を通じた確認**ができるかどうかを見てください。もう1つは、**辞める理由が本当に解消するか。**処遇が理由であれば、条例に基づく以上、**個別の調整は困難**です。**解消しない理由で残ると、同じ状況が1年後に繰り返されます。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 引き止めが長引く場合

| 状況 | 対応 |
|---|---|
| 何度も面談が設定される | **意思を明確に伝え、日程の相談に移す** |
| 書面を受け取ってもらえない | **人事の担当に相談** |
| 退職日の変更を求められる | 引継ぎの都合なら調整、それ以外は理由を確認 |
| 周囲から説得される | **個別に応じる必要はありません** |

**2つ目について補足します。**

**退職の意思表示の経路は、所属の規程で定められています。**

**上司が受け取らない場合でも、規程に従った提出の方法があります。**人事の担当に相談してください。

## 見込みを、確度の高い形にする方法

**残ることを検討する場合、提示された条件の確度を上げられるかを確認してください。**

| 方法 | 内容 |
|---|---|
| 時期を特定する | 「次の異動で」ではなく、**いつの内示か** |
| 範囲を特定する | 「希望を考慮する」ではなく、**どの部署か** |
| 経路を確認する | **人事の担当にも共有されているか** |
| 記録を残す | 面談の内容を自分で書き留める |

**3つ目が、いちばん実務的**です。

**所属の長が人事の担当に意向を伝えているかどうかで、実現の確度が変わります。**

**確認の仕方は、「人事にもお伝えいただけますか」と述べるだけ**で足ります。

**なお、確度を上げられない場合でも、それは相手の誠実さの問題とは限りません。**任命は任命権者が行うため、**現場の管理職に確約する権限がない**というだけです。

**その前提で、待てるかどうかを判断してください。**

## 引き止めを受けないために

**事前にできることもあります。**

| 準備 | 効果 |
|---|---|
| 入社日を確定させてから伝える | **日程が動かないことが伝わる** |
| 引継ぎの計画を用意する | 業務の心配が減る |
| 意思を明確に述べる | **相談の余地があると受け取られない** |

**3つとも、伝える場面での工夫**です。

**「考えている段階です」と述べると、説得の対象になります。**

[経験の言い換えから相談する](../apply.html)こともできます。

**判断に要する時間は、長くても数日**です。応募先への回答の期限もあるため、**1週間以上かけないほうが確実**です。

## よくある失敗

**1. 曖昧に返事をする**

**引き止めが続きます。**

**2. 提示された条件を、確約だと受け取る**

**任命は任命権者が行います。**

**3. 受諾した後に残る判断をする**

**応募先の計画に影響**します。

**4. 辞める理由が解消するかを確かめない**

**1年後に同じ状況**になります。

**5. 感謝を述べない**

**配慮への謝意**は添えてください。

**6. 「考えている段階」と伝える**

**説得の対象**になります。

:::insight
ここまで対応の話をしておいて逆のことを言いますが、**引き止められること自体は、悪いことではありません。**面談で伺っていると、**引き止めを「迷惑をかけている証拠」と受け取って、罪悪感を強める方**がいらっしゃいます。ところが、**引き止めは、その人の仕事が評価されていたことの表れ**でもあります。**必要とされていない人は、引き止められません。**ですから、**謝意は述べたうえで、判断は自分でしてください。**そして、**引き止めを断ったことで関係が壊れることは、実際には多くありません。**丁寧に伝え、最後まで業務を担い、引継ぎを整える。**この3つを守れば、関係は保てます。**面談で伺った例では、**退職後も元の職場と自然な関係が続いている方**が大半です。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方公務員法第17条第1項**は、**任命権者が採用・昇任・降任・転任のいずれかの方法により任命する**としています。**上司の言葉は、任命の決定ではありません**
- 提示される条件のうち、**異動と昇任は見込み**、**業務の負担と働き方の運用は所属の判断で調整できる**ことがあります
- **処遇は条例に基づくため、個別の調整は困難**です
- 判断の出発点は、**その条件で辞める理由が解消するか**です
- **受諾の前か後かで重さが違います。**迷いがあるうちは受諾しないでください
- **曖昧に返事をしない。**引き止めが続き、引継ぎの調整が進みません

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 「あと1年待てば昇任できる」と言われました

**確約かどうかを確認してください。**昇任は、**選考や人事評価の結果にもとづいて行われる**のが通常です。**地方公務員法第21条の3**は、昇任を**能力の実証にもとづき、適性を有すると認められる者の中から行う**としています。したがって、**「来年は昇任する」という言葉が、そのまま実現するとは限りません。**確認するなら、**選考の要件を満たしているか、いつ結果が出るか**を聞いてください。そのうえで、**1年待てるかを自分で判断**してください。なお、**応募先が1年待てることは、まずありません。**

### 引き止めの条件を、応募先に伝えるべきですか

**伝える必要はありません。**応募先にとって、**現職の条件は判断の材料になりません。**ただし、**受諾の前に迷いが生じた場合は、回答の期限を相談**してください。「もう少し検討させていただきたい」と伝えれば足ります。**理由を詳しく述べる必要はありません。**なお、**引き止めの条件を持ち出して、応募先に条件の上積みを求めるのは避けてください。**交渉の材料として使うと、**入社後の関係に影響します。**条件の相談は、[条件交渉はどこまでできるか](senko-mensetsu-joken.html)の考え方に沿って行ってください。

### 残ることにした場合、周囲との関係はどうなりますか

**多くの場合、日常に戻ります。**役所では、**退職を検討して残る職員は珍しくありません。**ただし、**伝えた範囲で情報が広がっている場合、しばらくは話題になることがあります。**対処としては、**残る判断をした旨を、伝えた相手に自分から伝える**ことです。「ご配慮いただいた条件を踏まえて、引き続き勤務させていただきます」という形です。曖昧にすると、**周囲が扱いに困ります。**なお、**残る判断をした場合も、整理した内容は無駄になりません。**自分が何を重く見ているかは、**次の判断のときにも使えます。**
