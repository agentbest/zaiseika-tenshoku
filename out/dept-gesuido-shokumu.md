下水道課の職務経歴書で、いちばん多い失敗はこれです。

**「下水道事業に関する業務」**

**この1行で終わってしまいます。**

読む側は、ここから**「役所の下水道の担当だった人」**という像しか作れません。実際には、**処理場を運転し、管の中をカメラで調べ、他人の排水設備を審査し、工場の排水を規制し、使用料を賦課し、大雨のときはポンプ場を動かし、数十年先の更新の計画を組んでいた**わけですが、それが書かれていません。

この記事では、**職務要約・担当業務・実績**の3つに分けて、悪い例と良い例を並べます。

言い換えは[下水道課の経験は民間で何と呼ばれるか](dept-gesuido-honyaku.html)、行き先は[下水道課から転職しやすい業界と職種](dept-gesuido-tenshokusaki.html)に書いています。

## 他人の土地に立ち入って、検査できることになっています

書き方に入る前に、この仕事の性格を条文で押さえます。**書類の芯になる部分**です。

**下水道法第13条**です。

> 公共下水道管理者は、公共下水道若しくは流域下水道の機能及び構造を保全し、又は公共下水道からの放流水若しくは流域下水道からの放流水の水質を第八条の技術上の基準に適合させるために必要な限度において、その職員をして排水区域内の他人の土地又は建築物に立ち入り、排水設備、特定施設、除害施設その他の物件を検査させることができる。

**ここが、書類の芯です。**

**自分の設備を守るために、他人の設備を検査できる。**

なぜ、こういう権限が法律に書かれているのか。**下水道は、入口を選べないからです。**区域の全戸から、何が流れてくるかを、こちらで決められない。だから、**入口の側を検査する権限が、法律の側に置かれている。**

しかも、**第12条の2**は、特定の施設を持つ工場や事業場について、**「政令で定める基準に適合しない下水を排除してはならない」**と定めています。**受け入れる側が、入口の基準を持っている**ということです。

民間で人を採る側から見ると、これは**「受け入れる側の品質の管理をしてきた人」**です。**原料の受入れの検査、取引先の監査、他社が自社の設備に接続するときの審査**——**同じ構造の仕事が、いくつもの業界にあります。**

職務経歴書には、**この「入口を守る」範囲が見えるように書いてください。**

## 職務要約

### 悪い例

> 下水道課において、下水道事業に関する業務に従事。施設の維持管理、水質管理、使用料業務等を担当。

**これでは、規模も、判断の範囲も読めません。**

### 良い例（処理場と管路が長い方）

> 処理区域内人口約◯万人、日量約◯万立方メートルの処理場◯か所、管きょ延長約◯キロメートルの下水道事業において、処理場の運転管理を担当。流入の水質と水量に応じた運転の調整、放流水質の測定と記録、汚泥の脱水と処分の管理を実施。管きょのカメラ調査を年間約◯キロメートル発注し、更生の優先順位を設定。

### 良い例（計画と経営が長い方）

> 下水道事業のストックマネジメント計画および経営の戦略の策定を担当。管きょ約◯キロメートルについて、布設の年度と調査の結果から更新の優先順位を設定し、年間約◯キロメートル、約◯億円の改築の計画を策定。公営企業会計による決算の調製、使用料の改定の試算、処理場の統合の検討にも従事。

**太字にしなくても、数字が入っているだけで読み方が変わります。**処理区域内の人口、処理場の能力、管きょの延長、施設の数。**この4つのうち、分かるものから埋めてください。**

:::insight
この経歴の職務経歴書で、**書けるのに書かれていないことの筆頭が「除害施設の指導と立入検査」**です。面談で伺うと、**「事業所の排水の指導をしていました」**という言い方をされます。ところが、中身は、**工場や事業場に立ち入って、排水の水質を測り、基準に合わなければ除害施設の設置や改善を求め、それでも直らなければ次の段階に進む**という仕事です。**相手は、こちらの設備に水を流してくる事業者**です。**自分の組織の中の仕事ではないので、実績だと思われていない。****ところが、民間でいえば、これは「取引先の監査」と「受入れの検査」**です。製造でも、食品でも、化学でも、**同じ場面があります。**書くなら、**「特定事業場約◯か所を対象に、排水の水質の検査と除害施設の指導を年間約◯件実施。基準の説明、改善の計画の確認、再検査までの段階を運用」**という形です。**件数が入ると、扱っていた量が伝わります。**この一行があると、**扱える範囲が一段広く読まれます。**
:::

## 担当業務

**「下水道事業」で丸めず、6つに分けてください。**

| 機能 | 書き方の例 |
|---|---|
| 処理場と水質 | 処理場◯か所の運転管理、流入に応じた運転の調整、放流水質の測定と記録、汚泥の処理 |
| 管きょと施設 | 管きょ延長約◯キロメートルの点検、カメラ調査の発注、更生と改築の発注、台帳の整備 |
| 排水設備と水質の規制 | 排水設備の確認と検査、指定工事店の指定と監督、特定事業場の立入検査と除害施設の指導 |
| 使用料と接続 | 約◯万件の使用料の賦課、受益者負担金の賦課と徴収、未接続の世帯への水洗化の促進 |
| 計画と経営 | ストックマネジメント計画、全体計画、経営の戦略、使用料の試算、公営企業会計 |
| 雨水と危機の対応 | 雨水ポンプ場の運転、大雨時の体制、浸水の対応、災害時の相互の応援 |

**この6つのうち、自分がやっていないものは書かなくて構いません。**むしろ、**やっていない機能を空欄にしたほうが、やった機能の密度が読まれます。**

**とくに、4番目の「使用料と接続」**は、**行政の中でめずらしい部分**です。**未接続の世帯に戸別に働きかけて、接続してもらう。**これは、民間でいえば**加入の促進**で、**数字が動く仕事**です。やっていたなら、**戸数を添えて書いてください。**

**もう1つ、6番目の「雨水と危機の対応」も書き落とされやすい部分**です。大雨が来れば、**その時間から、街のどこかで水が上がり始めます。**ポンプをいつ動かすか、ゲートをいつ操作するか、操作する人をいつ引き揚げるか。**この段取りは、事前に決めておかないと動きません。**書くなら、**「大雨時の雨水ポンプ場の運転と、操作の従事者の安全の確保について、体制と手順を整備。年◯回の訓練を実施」**という形です。**民間でも、止められない設備を持つ事業では、同じ体制を持っています。**

## 実績

**ここが書きにくい部分です。**成果が、**川がきれいなままで、街が浸水しなかったこと**として現れるからです。

### 悪い例

> 適正な処理と安定した運転に努め、事故のない運営に貢献した。

**これは、姿勢の話であって、実績ではありません。**

### 良い例——3つの型

**型1：基準と手順を作った**

> 雨天時の流入の増加に対する処理場の運転の切り替えの基準を、水位と流量の区分で整理し、夜間と休日の連絡の経路を含めて文書化。当番が単独で判断しない形に変更。

**型2：損失を減らした**

> 雨天時に管きょへ入り込む水の調査について、区域ごとの流量の比較から範囲を絞り込む方法を導入し、年間約◯キロメートルの調査で侵入の箇所◯件を特定。処理する水量の抑制につなげた。

**型3：更新を動かした**

> 管きょの布設の年度とカメラ調査の結果を台帳で整理し、改築の優先順位の基準を作成。年間約◯キロメートル、約◯億円の更生を計画に位置づけ、資金の残高を踏まえて年次に配分。

**3つとも、「維持した」ではなく、「自分が設計した」で書かれています。**

**このうち、型2はとくに数字にしやすい実績**です。本来入らないはずの水が、雨のたびに管に入ってくる。**その分だけ、処理の費用が増えます。**調査した延長と、見つけた箇所は残ります。民間の設備の保全でも、**「損失をどれだけ減らしたか」は、いちばん伝わる形**です。ただし、**処理の費用の内訳そのものは、公表されている範囲で書いてください。****「調査の方法を変えて、特定の件数が増えた」という書き方で十分**に伝わります。

### 数字の出し方

| 数えるもの | 書き方の例 | 注意 |
|---|---|---|
| 事業の規模 | 処理区域内人口約◯万人、水洗化率約◯パーセント | 公表されている数字を使う |
| 処理場の能力 | 日量約◯万立方メートル、処理場◯か所 | 処理の方式を添えると強い |
| 管きょの延長 | 管きょ延長約◯キロメートル | 汚水・雨水・合流の別があれば添える |
| 使用料の件数 | 約◯万件の賦課 | 収納率は公表値を使う |
| 除害施設の指導 | 特定事業場約◯か所、年間約◯件 | 数えていないことが多い部分 |
| 更新の実績 | 年間約◯キロメートル、約◯億円 | 個別の工事名は書かない |

**「約」を付けて構いません。**正確な数字が出せないことよりも、**桁が分かることのほうが大事**です。

### 応募先で並べ替える

| 応募先の方向 | 上に置く機能 |
|---|---|
| 処理場の運転を受託する会社 | 処理場と水質／委託の仕様と履行の確認／雨水と危機の対応 |
| 管路の調査・更生・工事の会社 | 管きょと施設／工事の発注と検査／道路と交通の調整 |
| プラント・機械のメーカー | 処理場と水質／設備の更新の検討／運転の実務 |
| コンサルタント・計画の支援 | 計画と経営／台帳／使用料の試算 |
| 工場の排水処理・環境の分析 | 排水設備と水質の規制／放流水質の測定／汚泥の処理 |

**同じ経歴でも、順番を変えるだけで読まれ方が変わります。**中身を作り直す必要はありません。

:::insight
書き方の話をしておいて逆のことを言いますが、**書類を完成させてから動く必要はありません。**この経歴の方に多いのは、**「決まった手順どおりに運転していただけ」**と考えて、実績欄を薄く書いてしまうことです。ところが、**下水道の運転に、同じ日は二日とありません。**流入の量も質も、天気と時間で変わる。**微生物の状態を見て、送る空気と返す汚泥を毎日変えている。**それは、運転であって、作業ではありません。**そして、下水道法第13条は、他人の設備に立ち入って検査する権限を、その職員に与えています。****つまり、法律が「あなたは検査する人だ」と言っている**わけです。**先に、4つの数字だけ確かめてください。**処理区域内の人口、処理場の能力、管きょの延長、除害施設の指導の件数。**このうち4つ目は、数えていないことが多い**ので、**直近の1年分だけでも数えてみてください。**この4つが揃った時点で、**書類の読まれ方が変わります。**在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 書いてはいけないこと

| ✕ 書かない | ○ こう書く |
|---|---|
| 処理場やポンプ場の警備、立入りの管理の詳細 | 施設の数と、担当していた運転の範囲 |
| 管きょの弱い箇所や、陥没のおそれのある場所 | 改築の優先順位を、どういう基準で決めたか |
| 特定の事業場の名前と、排水の違反の経緯 | 立入検査と指導の段階を運用し、扱った件数 |
| 使用者の個別の事情や、滞納の経緯 | 滞納への対応の段階と、扱った件数 |
| 入札や契約の予定価格に関わる情報 | 発注の件数と、検査で見ていた項目 |

**1行目と3行目は、とくに注意してください。**下水道は、**生活の基盤の設備**であり、**規制の相手は、名前の分かる事業者**です。**施設の守りに関わる情報と、相手の名前が分かる記述は、書類にも面接にも出さない。**この線を守ることは、**それ自体が評価の対象**になります。**迷ったら、公表されている資料に載っている範囲にとどめてください。**

## つまずきやすい点

**1. 「下水道事業」で丸める**

**処理場と水質／管きょと施設／排水設備と水質の規制／使用料と接続／計画と経営／雨水と危機の対応**の6つに分けてください。

**2. 除害施設の指導の件数を書かない**

**こちらの設備に水を流してくる事業者を検査していた量**です。**差が付く部分です。**

**3. 水洗化の促進を、事務として書く**

**戸別に働きかけて、接続の数字を動かした仕事**です。**戸数を添えてください。**

**4. 大雨の対応を、苦労話にする**

**基準を決めて、体制を組んで、運用していた**と書いてください。

**5. 事業者の名前が分かることを書いてしまう**

**件数と段階だけにとどめてください。**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## まとめ

- 下水道法第13条は、**下水道の機能と構造を保全し、放流水質を基準に適合させるために、他人の土地や建築物に立ち入って排水設備や除害施設を検査できる**と定めています
- つまり、**下水道課は「入口を選べない設備の、入口を守る」仕事**をしています。**受け入れる側の品質の管理**です
- 職務要約には、**処理区域内の人口・処理場の能力・管きょの延長・施設の数**を入れてください
- 実績は、**①基準と手順を作った ②損失を減らした ③更新を動かした**の3つの型で書けます
- 書いてはいけないのは、**施設の守りに関わる情報、事業者の名前が分かる記述、個別の事案**です
- **除害施設の指導の件数**は、**数えていないことが多い**ので、**直近の1年分だけでも数えてください**

## よくある質問

### 事務職で、処理場に入ったこともありません

**それでも書けます。**下水道課の事務は、**使用料と受益者負担金の賦課と徴収、水洗化の促進、指定工事店の指定、契約と入札、公営企業会計の決算、経営の戦略**など、**技術以外の部分が広くあります。**書くなら、**「約◯万件の使用料の賦課、受益者負担金の賦課と徴収、未接続の世帯約◯戸への水洗化の促進、公営企業会計による決算の調製を担当。技術上の検査は技術職が実施」**と、**自分の範囲を明示してください。**とくに、**水洗化の促進**は、**数字を動かした経験として、技術の有無に関わらず読まれる部分**です。線を引いた応募は、読まれます。

### 小規模な町で、農業集落排水や浄化槽も一緒に担当しています

**規模の大小は、それほど問題になりません。**むしろ、**小規模な自治体ほど、一人が見る範囲が広い**ことがあります。**処理場も、管路も、使用料も、計画も、数人で回している。**しかも、**公共下水道、農業集落排水、浄化槽という、方式の違う3つを同じ担当で見ている。****その場合は、「範囲の広さ」と「方式の幅」を前に出してください。**書くなら、**「処理区域内人口約◯千人の下水道事業について、公共下水道、農業集落排水、合併処理浄化槽の3方式の維持管理と使用料を少人数で担当」**という形です。**「少人数で」「3方式を」という一語**が、**幅の証明になります。**とくに受託の会社では、**一人で複数の役割を回せる人が求められます。**

### 上水道の担当が長く、下水道は最近です

**それは、そのまま書けます。**上水道と下水道は、**求人票では「上下水道」とまとめられている**ことが多く、**受託の会社もコンサルティングも、両方を手がけているところが大半**です。**両方の経験がある人は、むしろ読まれやすい。**書くときは、**年数で区切って、上水と下水を明示してください。**「上水道の管路の維持管理◯年、その後、下水道の処理場の運転管理◯年」という形です。**曖昧にすると、どちらの求人でも読みにくい書類になります。**下水道の側で先に出すべきなのは、**生き物を扱う処理場の運転と、雨水の対応**です。**上水道にはない材料**なので、そこを先に置いてください。面接で聞かれることは[下水道課出身者が面接で必ず聞かれること](dept-gesuido-mensetsu.html)に整理しています。
