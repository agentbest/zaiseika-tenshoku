退職が近づくと、「自分が作った資料を持っていきたい」「転職先で役立つデータを控えておきたい」という気持ちが出てきます。財政課なら、予算の査定の資料、決算統計の作業ファイル、起債の協議の様式、自分で組んだ集計の表。**どれも自分の仕事の成果で、持っていけそうに思えます。**

結論から書くと、**職務上作成した資料とデータは自治体の文書で、持ち出しは原則としてできません。**中に職務上の秘密や個人情報が含まれていれば、**地方公務員法第34条と個人情報保護法の罰則の対象**になり得ます。持っていけるのは、**頭の中にある経験と、公表されている情報**です。

この記事では、**何が持ち出せず、何が持っていけるか、そして退職時に何を確かめるか**を、条文で整理します。文書の管理の規則は自治体ごとに違うので、**自分の自治体の文書管理の規則と情報セキュリティの規程は、担当課で確かめてください。**守秘義務の全体は[守秘義務は退職後も続くのか](seido-fukumu-himitsu.html)に書いています。

## 持ち出しに関わる3つの規定

| 規定 | 対象 | 罰則 |
|---|---|---|
| **地方公務員法第34条**（秘密を守る義務） | 職務上知り得た秘密を漏らすこと。**退職後も同様** | 1年以下の拘禁刑又は50万円以下の罰金（第60条第2号） |
| **個人情報保護法第67条**（従事者の義務） | 個人情報の取扱いに従事する行政機関等の職員**または職員であった者**が、業務に関して知り得た個人情報の内容を**みだりに他人に知らせ、または不当な目的に利用**すること | 第176条・第180条 |
| **個人情報保護法第176条** | 行政機関等の職員または職員であった者が、正当な理由なく、**個人の秘密に属する事項が記録された個人情報ファイル（複製・加工したものを含む）を提供**したとき | **2年以下の拘禁刑又は100万円以下の罰金** |
| **個人情報保護法第180条** | 業務に関して知り得た保有個人情報を、**自己または第三者の不正な利益を図る目的で提供し、または盗用**したとき | **1年以下の拘禁刑又は50万円以下の罰金** |

個人情報保護法第2条により、地方公共団体の機関は「行政機関等」に含まれ、**第67条・第176条・第180条は「職員であった者」を明示的に対象にしています。**退職後に、在職中に持ち出した個人情報を使うことは、これらの罰則の対象です。

これらに加えて、**自治体の文書管理の規則と情報セキュリティの規程**が、文書の持ち出しと、データの複製・外部への送信を制限しています。罰則がなくても、在職中の違反は懲戒の対象で、退職後に発覚した場合は自治体からの責任追及の対象になり得ます。

## 何が持ち出せないか

| 分類 | 例 | 根拠 |
|---|---|---|
| **個人情報を含むもの** | 住民の情報、職員の名簿、事業者の担当者の情報、給与・税・福祉の個別のデータ | 個人情報保護法第67条・第176条・第180条 |
| **職務上の秘密を含むもの** | 未公表の予算・計画・検討資料、入札・契約の非公開情報、内部の協議の記録、監査・調査の資料 | 地方公務員法第34条 |
| **自治体の文書そのもの** | 公表済みの内容でも、自治体の管理する形の文書・データ（決裁文書、作業ファイル、様式、システムのデータ） | 文書管理の規則、情報セキュリティの規程 |
| **自分が作成した資料** | 査定の資料、集計表、マニュアル、様式——**自分が作っても自治体の文書** | 同上 |

**「自分が作った」は、持ち出してよい理由にはなりません。**職務上作成した文書は自治体のもので、著作権も原則として自治体に帰属します。作った人の頭の中にある「作り方」は、その人のものです。

## 何を持っていけるか

| 分類 | 例 | 注意 |
|---|---|---|
| **頭の中の経験** | 仕事の進め方、判断の基準、制度の運用の理解、失敗と改善の記憶 | 個別の事案の中身を伴わない形で |
| **公表されている情報** | 公表済みの予算書、決算書、計画、統計、条例・規則、議会の議事録 | **自治体のサイトなど公開の経路から改めて入手する。**自治体の管理する形の文書をそのまま持ち出さない |
| **自分の資格・研修の記録** | 取得した資格の証明、受講した研修の修了証 | 自分に交付されたもの |
| **自分の人事の記録** | 辞令、給与明細、源泉徴収票、退職手当の通知 | 自分に交付されたもの。転職先や税務署で使う |
| **一般的な知識** | 地方財政制度、地方自治法・地方財政法の理解、会計の知識 | 自治体の秘密ではない |

**転職先で使うのは、経験と知識です。**「起債の協議の資料をどう組んだか」は経験で、「その資料そのもの」は自治体の文書です。前者を言葉で説明できれば、後者は要りません。

## よくある持ち出しの形と、その扱い

| 形 | 扱い |
|---|---|
| **私用のメールに転送する** | 情報セキュリティの規程に反する。個人情報・秘密を含めば第34条・個人情報保護法の対象 |
| **USBメモリにコピーする** | 同上。多くの自治体で私物のUSBの使用自体が禁止 |
| **私用の端末で画面を撮影する** | 同上。「コピーではない」は言い訳にならない |
| **紙の資料を自宅に持ち帰る** | 文書管理の規則に反する。退職時に返却しなければ持ち出し |
| **クラウドの個人アカウントに保存する** | 同上。在職中の利便のために保存していたものも、退職前に消す |
| **自分のメモ・手帳に書いた内容** | 個別の事案の中身、個人情報、秘密が含まれていれば、第34条・個人情報保護法の対象。仕事の進め方のメモは問題ない |

**「在職中に自宅で仕事をするために」私用の端末やクラウドに保存していたデータは、退職前に消してください。**退職後に残っていれば、持ち出しと同じです。

## 退職時に確かめること

| 順序 | 確かめること |
|---|---|
| 退職前 | 私用のメール、端末、クラウド、USBに、職務上のデータが残っていないか。**残っていれば消す** |
| 退職前 | 自宅に持ち帰っている紙の資料がないか。あれば返却 |
| 退職前 | 貸与された端末、記録媒体、鍵、カードを返却する準備 |
| 退職時 | 自治体の情報セキュリティの規程で定められた誓約書（退職時の秘密保持の誓約）に署名する場合、内容を読んで理解する |
| 退職時 | 自分に交付された書類（辞令、源泉徴収票、退職手当の通知、資格の証明）を受け取る |

**退職時の誓約書は、多くの自治体で提出を求められます。**内容は、職務上知り得た秘密と個人情報を退職後も漏らさない、自治体の情報を持ち出していない、というものです。署名する前に、上の手順で私用の環境を確かめておくと、誓約と実態が一致します。

:::insight
面談で伺うと、**「自分で作ったマニュアルと集計表を、転職先で使うために持っていった」という方**がいます。作った本人の成果物という意識で、悪意はありません。ただ、集計表に事業者の担当者の情報や、未公表の数字が含まれていれば、第34条と個人情報保護法の対象で、自治体の文書を持ち出したことは文書管理の規則に反します。逆に、**在職中の最後の月に、自分の仕事の進め方を「事案の中身を抜いて」ノートに書き出した**という方は、転職先でそのノートを見ながら、同じ仕組みをゼロから作り直しています。ここで1つ提案があります。**退職の前に、「作り方」を自分の言葉で書き出してください。**査定の手順、集計の組み方、協議の段取り。数字も名前も入れず、手順と判断の基準だけ。**それが、持っていける経験の全部で、転職先で使えるのもそれだけです。**資料そのものは、転職先では形式が違って使えないことが多く、持ち出す価値も実はありません。
:::

## 転職するとどうなるか

転職を考えている方にとって、情報の持ち出しで効いてくる点は3つです。

**1. 資料とデータは持ち出せない。経験と知識は持っていける**

**「作り方」を自分の言葉で書き出す**のが、持っていける経験の正しい形です。

**2. 私用の環境に残っているデータは、退職前に消す**

**在職中の利便のために保存したものも、退職後に残っていれば持ち出し**です。

**3. 退職後に使えば、罰則の対象になり得る**

**第34条と個人情報保護法は「職員であった者」を対象**にしています。転職先で使った時点で問題になります。

## 手続きと期限

| 順序 | 手続き | 時期 |
|---|---|---|
| 退職を決めたら | 自治体の文書管理の規則と情報セキュリティの規程で、持ち出しの禁止の範囲を確かめる | 早めに |
| 退職前 | 仕事の進め方を、事案の中身を抜いて自分の言葉で書き出す | 退職前 |
| 退職前 | 私用のメール・端末・クラウド・USBの職務上のデータを消す。紙の資料を返却する | 退職前 |
| 退職時 | 貸与品を返却し、誓約書の内容を理解して署名する | 退職日 |
| 退職時 | 自分に交付された書類を受け取り、保管する | 退職日 |
| 退職後 | 公表されている情報は、公開の経路から改めて入手する | 必要なとき |

## 誤解されやすい点

**「自分が作った資料は自分のもの」と思い込む**

**職務上作成した文書は自治体の文書**です。持っていけるのは作り方の経験です。

**「公表されている内容なら持ち出してよい」と思い込む**

**内容が公表されていても、自治体の管理する形の文書の持ち出しは文書管理の規則に反します。**公開の経路から改めて入手してください。

**「個人情報を含まなければ問題ない」と思い込む**

**職務上の秘密（第34条）と、文書管理の規則の問題は別に残ります。**

**「退職すれば罰則は関係ない」と思い込む**

**第34条も個人情報保護法第67条・第176条・第180条も「職員であった者」を対象**にしています。

:::insight
ここまで持ち出しの話を書いておいて逆のことを言いますが、**持ち出せないことは、転職の不利にはなりません。**転職先が求めているのは、前職の資料ではなく、資料を作れる人です。それでも1本の記事にしたのは、**善意で資料を持ち出して、後から問題になる方を面談で見る**からです。罰則は「職員であった者」に及び、転職先で使った時点で問題になります。**作り方を書き出して、資料は置いていく。**それで、経験は全部持っていけます。そのうえで、**自分の経験に値を付けてくれる業界の見込みと、同じ紙に並べてください。**片方だけでは比較になりません。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 職務上作成した資料とデータは**自治体の文書で、持ち出しは原則としてできません。**「自分が作った」は理由になりません
- 個人情報を含むものは**個人情報保護法第67条・第176条・第180条**、職務上の秘密を含むものは**地方公務員法第34条**の対象で、いずれも**「職員であった者」を明示的に対象**にしています
- **第176条は2年以下の拘禁刑又は100万円以下の罰金、第180条は1年以下の拘禁刑又は50万円以下の罰金、第34条違反は1年以下の拘禁刑又は50万円以下の罰金**です
- 持っていけるのは、**頭の中の経験、公表されている情報（公開の経路から改めて入手）、自分に交付された書類、一般的な知識**です
- **仕事の進め方を、事案の中身を抜いて自分の言葉で書き出す**のが、経験を持っていく正しい形です
- 退職前に、**私用のメール・端末・クラウド・USBの職務上のデータを消し、紙の資料を返却し、誓約書の内容を理解して署名**します

## よくある質問

### 自分で作ったExcelの集計表を、転職先で同じものを作るために持っていきたいです。だめですか

**持ち出しはできません。作り方を書き出して、転職先で作り直してください。**集計表は職務上作成した自治体の文書で、自分が作ったものでも自治体のものです。中に事業者の名前、担当者の情報、未公表の数字が含まれていれば、個人情報保護法第67条と地方公務員法第34条の対象で、退職後に転職先で使えば「職員であった者」として罰則の対象になり得ます。数字を消しても、自治体の管理する形のファイルの持ち出しは、文書管理の規則と情報セキュリティの規程に反します。**持っていけるのは、「どの項目を、どういう順序で、どういう計算式で組んだか」という作り方**で、これは頭の中にあります。退職前に、その作り方を、数字も名前も入れずに自分の言葉で書き出してください。転職先では、データの形式も項目も違うので、前職のファイルをそのまま使えることはほとんどなく、作り直すほうが結果として早いことが多いです。作り直せることが、あなたの経験の証明です。

### 在職中に自宅で仕事をするため、私用のクラウドに資料を保存していました。どうすればよいですか

**退職前に、すべて消してください。**在職中に自宅で仕事をするための保存が、自治体の情報セキュリティの規程で認められていたかどうかにかかわらず、退職後に残っていれば持ち出しと同じです。中に個人情報や職務上の秘密が含まれていれば、退職後の保有と利用は個人情報保護法第67条と地方公務員法第34条の問題になります。消す対象は、クラウドの保存、私用のメールへの転送、私用の端末のダウンロードフォルダ、スマートフォンの写真、USBメモリなど、職務上のデータが残り得るすべての場所です。ゴミ箱やバックアップにも残ることがあるので、完全に削除してください。**消したことを、退職時の誓約書の前提にする**と、誓約と実態が一致します。退職後に「消し忘れた」ものが見つかった場合は、使わずに消し、扱いに迷う場合は前職の担当課に相談してください。

### 公表されている予算書や統計を、転職先の分析に使ってよいですか

**使えます。ただし、公開の経路から改めて入手してください。**公表済みの予算書、決算書、地方財政状況調査の結果、統計、計画、条例・規則は、誰でも入手できる情報で、地方公務員法第34条の「秘密」ではありません。転職先の分析や提案に使うことは自由です。注意するのは、**自治体の管理する形の文書（作業用のファイル、内部の様式、公表前の版）をそのまま持ち出さないこと**で、同じ内容でも、自治体のサイトや統計のデータベースから改めて入手した公表版を使います。公表版と内部の作業ファイルの違いは、公表版には個人情報や内部の検討の跡がないことで、ここが線です。また、**公表されている情報に、在職中に知った非公開の背景（なぜその数字になったか、内部でどう議論されたか）を加えて説明することは、第34条の対象**になり得ます。公表されている情報の範囲で分析し、背景は一般論として語る形が、転職先での安全な使い方です。
