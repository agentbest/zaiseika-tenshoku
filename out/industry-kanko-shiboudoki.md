観光・地域振興の志望動機で、**いちばん多く見かける書き出し**があります。

**「この地域が好きで、力になりたいと考えました」**

**気持ちは伝わります。**ただし、**これだけでは選考で効きません。**

理由は2つあります。**1つは、その地域に住んでいる人なら誰でも書けること。**もう1つは、**「力になりたい」が、役所にいてもできることだから**です。

**相手が知りたいのは、「なぜ行政の側ではないのか」**です。

**その答えの手がかりは、法律が行政と事業者の役割をどう書き分けているかを見ると、はっきりします。**この記事では、**そこから志望動機を組み立てる手順**を扱います。業界の構造は[未経験から観光・地域振興に入るには](industry-kanko-mikeiken.html)、条件の確かめ方は[観光・地域振興の年収と働き方](industry-kanko-nenshu.html)にあります。

## 法律は、行政と事業者を書き分けています

**観光立国推進基本法第4条第1項**です。

> **（地方公共団体の責務）第四条　地方公共団体は、基本理念にのっとり、観光立国の実現に関し、国との適切な役割分担を踏まえて、自主的かつ主体的に、その地方公共団体の区域の特性を生かした施策を策定し、及び実施する責務を有する。**

**地方公共団体は、「施策を策定し、及び実施する責務」**です。

そして、**同法第6条**です。

> **（観光事業者の努力）第六条　観光に関する事業**（第十六条において「観光事業」という。）**を営む者**（以下「観光事業者」という。）**は、その事業活動を行うに際しては、住民の福祉に配慮するとともに、観光立国の実現に主体的に取り組むよう努めるものとする。**

**観光事業者は、「その事業活動を行うに際して」**です。

**この2つの条文の違いを見てください。**

| | 地方公共団体（第4条） | 観光事業者（第6条） |
|---|---|---|
| 何をするか | **施策を策定し、実施する** | **事業活動を行う** |
| 書かれ方 | **責務を有する** | 努めるものとする |
| 立ち位置 | 区域の特性を生かす | **住民の福祉に配慮する** |

**行政は施策を作る。事業者は事業を行う。**

**⚠ どちらが上ということではありません。****役割が違う**ということです。

**そして、この業界の仕事は、右の列**です。

## 志望動機は、ここに接続させてください

**「地域を良くしたい」は、第4条の側でもできます。**

**言うべきなのは、「施策を作る側ではなく、事業として回す側に移りたい」**です。

**この違いは、具体的な場面で説明できます。**

| 行政の側 | 事業の側 |
|---|---|
| 補助金を交付して、事業者の取組を支援する | **自分たちで事業を組み立て、原資を確保する** |
| 計画を作り、目標を示す | **目標に向けて、実際に人を集める** |
| 実績の報告を受け、検証する | **実績を作り、報告する** |
| 公平に配分する | **選んで、集中して投じる** |
| 単年度で区切る | **続けるか、やめるかを自分で決める** |

**右の列が、この業界の仕事**です。

**役所にいて、左の列に物足りなさを感じた場面**があるなら、それが志望動機の材料になります。

## 3つの層に分けます

| 層 | 問い | 材料の出どころ |
|---|---|---|
| ① 機能 | **なぜ、事業を回す側なのか** | 役所での担当の経験 |
| ② 組織 | **なぜ、この組織・この地域なのか** | 公表資料と求人票 |
| ③ 立場 | **なぜ、行政ではなく事業者の側なのか** | 自分の考えの変化 |

## ① 事業を回す経験は、役所にもあります

| 役所での担当 | 接続する場面 |
|---|---|
| 補助金の交付と実績の確認 | **申請する側、事業を実施する側** |
| イベント・行事の実施 | 集客の企画と運営 |
| 観光・物産の計画の策定 | **事業の設計** |
| 地域の事業者との調整 | 会員・関係者との関係づくり |
| 広報・情報の発信 | 発信の企画 |
| 施設の管理・指定管理の所管 | **施設の運営** |

**書き方は、「担当しました」で止めないでください。****何を自分で決めたか**を書きます。

> 市の物産展の実施を担当し、出展する事業者の選定、会場の構成、告知の手順を組み立てました。前年度の来場の状況から、時間帯ごとの人の流れに合わせて配置を変え、滞在の時間を延ばすことを狙いました。

**「自分で決めて、結果を見た」という形**になっています。**これが、事業を回す側の経験**です。

## ② 組織と地域は、公表資料から取ります

| 資料 | 志望動機に使える材料 |
|---|---|
| 組織の事業の計画・報告 | **どの事業に力を入れているか** |
| 自治体の観光の計画 | **その地域が何を目指しているか** |
| 決算・収支の資料 | **財源の構成** |
| 求人票の仕事内容 | その職の日々の中身 |
| 施設や催事の情報 | 実際に何をやっているか |

**⚠ 自治体の観光の計画は、公表されています。**これを読んでから面接に行くと、**話が具体的になります。**

**使い方は、「読みました」ではなく「読んで、どこに反応したか」**です。

> 市の観光の計画を拝見し、通過型から滞在型への転換が課題として挙げられていることを確認しました。私が担当していた自治体でも同じ課題がありましたが、宿泊の受け皿を増やす話と、夜の過ごし方を作る話は、別の取組が要ると感じていました。

**この書き方は、計画を読んでいないとできません。**

## ③ 行政ではなく、事業者の側である理由

**必ず問われます。**相手が確かめたいのは2つです。

| 相手の懸念 | 確かめたいこと |
|---|---|
| **行政の目線のまま来ないか** | 事業者の側に立てるか |
| **条件を分かっているか** | 土日の勤務、収入を作る仕事 |

**答え方の型は、「配分する側から、実施する側へ」**です。

> 補助金を交付する側として、地域の事業者の取組を支援してきました。交付する側は、公平に配分し、実績を確認するところまでが役割です。実際に人を集め、続けるかどうかを判断しているのは、事業者の側です。そちらに移りたいと考えました。

**もう一つの型は、「単年度で区切らずに続けたい」**です。

> 単年度の事業として実施し、翌年度に継続するかは予算の査定で決まる、という進め方をしてきました。育てるには時間がかかる取組が、年度で切れてしまう場面を見てきました。続けるかどうかを、現場で判断できる立場に移りたいと考えました。

**⚠ 避けてください——役所の批判から入る書き方**です。「行政は単年度主義で」「縦割りで動けない」。**読む側から見ると、次は当社の悪いところを外で言う人に見えます。**

**⚠ そして、「地域が好き」を最初に持ってこないでください。**①②③を組み立てたうえで、**最後に一言添える**なら効きます。

:::insight
面接に同席させていただいていて、**この分野で評価が分かれる瞬間**があります。**「土日の勤務や、収入を作る仕事について、どうお考えですか」**という質問への答え方です。よくあるのは、**「覚悟しています」**という答えです。これは、**あまり効きません。**覚悟の表明は、**誰でもできるから**です。評価される答え方は、**具体的に確認してきたことを示す**形です。「土日の勤務については、家族と話して、月に◯回程度であれば対応できると確認してきました」「収入を作る経験はありませんが、補助金の申請と実績の管理はできるので、まずそこから担いたいと考えています」。**ここには、2つのことが入っています。****条件を自分で確認してきたこと**と、**できる範囲を正直に示していること**です。採る側から見ると、**覚悟を語る人より、確認してきた人のほうが、入ったあとに続きます。**とくに、職員が数名という組織では、**一人辞めることの影響が大きい**ので、**「この人は入ったあとに揉めなさそうか」**を見ています。⚠ 志望動機の熱量より、**確認の丁寧さ**のほうが、この分野では効きます。
:::

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 経験 | 志望動機での使い方 |
|---|---|
| 補助金の交付と実績の確認 | **申請する側に回れる** |
| 計画の策定 | **事業の設計に直結** |
| 地域の事業者との調整 | 会員・関係者との関係づくり |
| イベント・行事の実施 | **集客の企画と運営** |
| 会議体の運営 | 理事会・総会の運営 |
| 統計・調査の取りまとめ | 事業の検証 |

**効きにくい場所**

| 経験の不足 | 面接での扱い方 |
|---|---|
| 売上を作る | **できる範囲を具体的に示す** |
| 価格の設定 | 構造の理解を示す |
| 土日・連休の勤務 | **確認してきたことを示す** |
| 少人数での兼務 | 分掌の外を拾った経験を出す |

## 材料を集める順番

| 順 | やること | 目安 |
|---|---|---|
| 1 | **自分で決めて結果を見た経験**を3つ書き出す | 1時間 |
| 2 | 応募先の**自治体の観光の計画**を読む | 1時間 |
| 3 | 組織の**事業の計画・報告**を読む | 1時間 |
| 4 | **財源の構成**を確認する | 30分 |
| 5 | ③の型（配分する側から／単年度で区切らずに）を決める | 20分 |
| 6 | **土日の勤務について、家族と話す** | — |
| 7 | ①②③を**つなげて300字**にまとめる | 40分 |

**6つ目を飛ばさないでください。**面接で聞かれてから考え始めると、**その場で答えられません。**

## 面接で聞かれやすいこと

| 聞かれること | 何を確かめられているか |
|---|---|
| なぜ行政ではないのですか | **③の中身** |
| 土日の勤務について、どうお考えですか | **確認してきたか** |
| 収入を作ることについて、どうお考えですか | できる範囲を示せるか |
| 地域の事業者と話した経験はありますか | 調整の経験 |
| 行政との協議で、どちらの立場に立ちますか | **元の所属に引きずられないか** |

**5つ目は、必ず聞かれます。****「事業者の側に立ちます。ただし、行政の側の制約も分かるので、通らない要望を出さないで済みます」**が自然です。

**⚠ 「元の所属に配慮します」と答えないでください。**

:::insight
ここまで組み立て方の話をしてきましたが、**この分野を志望される方に、必ず申し上げていることがあります。****地域に関わる方法は、転職だけではありません。**面談でお会いする方の中には、**「この地域に関わりたい」という気持ちを、職を変えることでしか実現できない**と考えておられる方がいらっしゃいます。実際には、**在職のまま関わる道**もあります。⚠ ただし、**職員の兼業・副業については、所属の規程で扱いが定められています。**何ができるかは、**所属の人事担当部署に確認してください。**この記事では判断できません。そして、⚠ **観光協会や地域の法人に移る場合、再就職に関する規程の確認も要ります。**これらの法人は、**自治体から補助や委託を受けている**ことが多く、**自分が担当していた相手方に移る形**になりやすい。**離職前の職務との関係で、一定期間、特定の行為が制限される場合があります。**⚠ **必ず、所属の人事担当部署と、適用される条例・規程を確認してください。**この確認は、**志望動機を書くより先**にやっておくと、応募先の選び方が定まります。当社が、いまの職を辞めることをお勧めすることはありません。**確認した結果、残るという結論も正しい結論です。**
:::

## まとめ

- **「この地域が好き」は、志望動機になりません。**住んでいる人なら誰でも書けますし、**役所にいてもできること**です
- **観光立国推進基本法第4条第1項**は、**地方公共団体が「施策を策定し、及び実施する責務を有する」**と定めています
- **同法第6条**は、**観光事業者が「その事業活動を行うに際しては、住民の福祉に配慮するとともに、観光立国の実現に主体的に取り組むよう努める」**と定めています
- **行政は施策を作る。事業者は事業を行う。**⚠ **どちらが上ということではなく、役割が違います**
- 志望動機は、**①機能（なぜ事業を回す側か） ②組織・地域 ③行政ではない理由**の3層に分けます
- ①の材料は、**補助金の交付、行事の実施、計画の策定、事業者との調整**にあります。**「自分で決めて、結果を見た」経験**を書いてください
- ②は、**自治体の観光の計画**を読んでから書いてください。**公表されています**
- ③は、**「配分する側から、実施する側へ」**または**「単年度で区切らずに続けたい」**の型で書きます
- ⚠ **志望動機の熱量より、確認の丁寧さ**のほうが、この分野では効きます
- ⚠ **兼業・副業の規程と、再就職に関する規程**を、所属の人事担当部署に確認してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 出身地ではない地域でも、志望動機は書けますか

**書けます。**むしろ、**出身であることを理由の中心に置かないほうが強い**ことがあります。採る側から見ると、**「出身だから」は、続ける理由としては弱い**からです。書くべきなのは、**その地域の課題と、自分の経験の重なり**です。「通過型から滞在型への転換が課題として挙げられている地域で、私は◯◯の取組に関わってきました」。これは、**出身かどうかと関係なく成り立ちます。**なお、**縁が無い地域の場合、なぜその地域かは必ず聞かれます。**答えは、**課題の性質と、自分の経験が合うから**で構いません。⚠ そのうえで、**移住を伴う場合、住まい・通勤・家族の見通し**を確認してきたことを示してください。

### 観光の仕事は初めてです。志望動機が弱くなりませんか

**弱くなりません。**この分野で効くのは、**観光の知識より、補助の制度・計画の策定・地域の調整の経験**です。商工、農林、文化、生涯学習、企画の部署にいた方は、材料を持っています。とくに、**補助金の交付事務**は、部署を問わず評価されます。書き方は、**「観光の実務は初めてですが、補助の申請の審査と、地域の事業者との調整を◯年担ってきました」**という形です。そのうえで、**その地域の観光の計画を読んでおく**と、話が通じます。⚠ **知らないことを知っているように書かないでください。**入ったあとに差が出ますし、面接で突っ込まれたときに答えられません。

### 志望動機は、何組織ぶん書き分ける必要がありますか

**①は共通で構いません。②と③は、組織ごとに書き直してください。**①は「なぜ事業を回す側か」なので、**同じ経験が材料になります。**②はその地域の計画と組織の資料から取った材料なので、**使い回すと読んでいないことが分かります。**③も、**組織の性格で説得力のある型が変わります。**受託が中心の法人なら「配分する側から実施する側へ」、自主事業を伸ばしている組織なら「単年度で区切らずに続けたい」。**同じ言葉でも、置く場所で意味が変わります。**なお、⚠ **応募先を決める前に、再就職に関する規程の確認を済ませておいてください。**
