定年が65歳に向けて引き上げられる中で、「60歳から定年まで、フルタイムで働き続けるのは体力的に難しい」「時間を減らして続けたい」という方のために設けられたのが、**定年前再任用短時間勤務**です。

この制度は、**条例で定める年齢（国の例で60歳）以上で退職した職員を、本人の希望に基づき、定年退職日相当日まで短時間勤務の職に採用する**仕組みです。「いったん退職して、短時間の職員として戻る」形なので、退職手当の受取りの時期、共済、身分の扱いが、フルタイムで続ける場合と変わります。60歳以降の選択肢の1つとして、転職と並べて考える価値があります。

この記事では、**定年前再任用短時間勤務の条文、仕組み、身分と給与、共済と退職手当、転職との比較、選考の注意**を整理します。**年齢、勤務時間、給与は条例による**ので、人事の担当課で確かめてください。定年の引上げは[定年引上げの仕組み](seido-ninyo-teinen.html)に書いています。

## 条文——第22条の4

| 項 | 内容 |
|---|---|
| **第1項** | 任命権者は、**条例年齢以上退職者**（条例で定める年齢に達した日以後に退職した者。臨時的任用・任期付・非常勤の職員の退職を除く）を、条例で定めるところにより、**従前の勤務実績その他の情報に基づく選考**により、**短時間勤務の職**（1週間の通常の勤務時間が、同種の常時勤務を要する職より短い職）に採用することができる。ただし、その短時間勤務の職に係る**定年退職日相当日を経過した者は除く** |
| **第2項** | 条例で定める年齢は、**国家公務員法第60条の2第1項に規定する年齢（60歳）を基準**として定める |
| **第3項** | 採用された職員（定年前再任用短時間勤務職員）の任期は、**採用の日から定年退職日相当日まで** |
| **第4項** | 定年退職日相当日を経過した者を短時間勤務の職に採用・昇任・降任・転任することはできない |

**「条例年齢以上退職者」＝60歳以上で退職した者、「定年退職日相当日」＝その短時間勤務の職に対応するフルタイムの職の定年退職日**です。60歳以降に退職し、選考を経て短時間勤務の職に採用され、定年退職日相当日まで働く、という流れです。

## 仕組み——退職と再任用

| 段階 | 内容 |
|---|---|
| **60歳以降に退職** | 条例で定める年齢（国の例で60歳）に達した日以後に退職する。**退職手当はこの時点で支給**（60歳以降の退職は退職事由を定年退職として算定する経過措置が国にあり、自治体も準じる） |
| **選考** | 従前の勤務実績その他の情報に基づく選考。**本人の希望が前提**（国の制度では本人の希望により採用） |
| **採用** | 短時間勤務の職に採用。**身分は短時間勤務の職員**（常時勤務を要する職ではない） |
| **任期** | 採用の日から定年退職日相当日まで |
| **勤務時間** | 国の例では週15時間30分から31時間までの範囲（内閣人事局の説明）。自治体は条例で定める |
| **給与** | 短時間勤務の職の給与（勤務時間に応じた額。60歳以降の7割水準の措置が基礎） |
| **終了** | 定年退職日相当日に任期が満了 |

**いったん退職するので、退職手当はその時点で受け取り、再任用後の期間は退職手当の対象になりません。**フルタイムで定年まで続ける場合と、退職手当の受取りの時期と額の計算が変わります。

## 身分・共済・年金——フルタイムで続ける場合との違い

| 項目 | フルタイムで定年まで | 定年前再任用短時間勤務 |
|---|---|---|
| **身分** | 常時勤務を要する職の職員 | 短時間勤務の職の職員 |
| **退職手当** | 定年退職の時点で支給。60歳以降の期間も在職期間に算入 | **60歳以降の退職の時点で支給。**再任用の期間は対象外 |
| **共済（短期給付）** | 組合員 | 勤務時間により、組合員となる場合と健康保険となる場合がある（条例・共済の定め） |
| **共済（長期給付）** | 組合員 | 勤務時間により厚生年金の被保険者となる形が一般的 |
| **給与** | 60歳以降は7割水準（国の例） | 短時間勤務の職の給与（勤務時間に応じた額） |
| **働き方** | フルタイム | 週の勤務時間を減らす |

**共済の扱いは、短時間勤務の職の勤務時間によって変わる**ので、共済組合と人事の担当課で確かめてください。年金の記録は、共済または厚生年金として続くので、空白は生じません。

## 転職との比較

| 項目 | 定年前再任用短時間勤務 | 民間への転職（60歳以降） |
|---|---|---|
| **働く時間** | 短時間（週の勤務時間を減らす） | 転職先による（フルタイムが多い） |
| **給与** | 短時間勤務の職の給与 | 転職先の給与。60歳以降の処遇は企業により幅がある |
| **退職手当** | 60歳以降の退職の時点で受取り | 同上（退職して転職するので同じ時点で受取り） |
| **期間** | 定年退職日相当日まで | 転職先の定年・継続雇用の条件による |
| **仕事の中身** | 自治体の業務（管理職ではない職） | 転職先の業務。財政・会計の経験を生かす形 |
| **向いている** | 時間を減らして自治体で続けたい | 経験を外で生かしたい、フルタイムで働きたい |

**どちらも「60歳以降に退職して退職手当を受け取る」点は同じ**で、その後を自治体の短時間の職で過ごすか、民間で過ごすかの違いです。60歳以降の退職手当の扱いが定年退職と同様になる経過措置があるので、退職手当の面では両者に差はなく、**その後の働き方と収入で比べる**ことになります。

## 選考の注意

| 点 | 内容 |
|---|---|
| **本人の希望が前提** | 希望しなければ採用されない。希望の申出の時期は自治体の定めによる（60歳に達する前年度の意思確認など） |
| **選考** | 従前の勤務実績その他の情報に基づく。**勤務成績が著しく不良な場合などは採用されないことがある** |
| **職の設定** | 短時間勤務の職は自治体が設ける。希望する職があるとは限らない |
| **一度退職すると戻れない** | 再任用が決まる前に退職を確定させない。**選考の結果を確かめてから退職の手続きを進める**のが安全 |

:::insight
面談で伺うと、**60歳で「もう体力的にフルタイムは無理だから辞める」と決めた方が、定年前再任用短時間勤務の制度を知らなかった**というケースがあります。制度があれば、時間を減らして自治体で続ける道と、転職する道の両方を並べられました。逆に、**制度を使うつもりで退職したのに、短時間勤務の職の設定が希望と違い、結局転職した**という方もいます。ここで1つ提案があります。**60歳の前年度に、人事の担当課で「定年前再任用短時間勤務の職の種類、勤務時間、給与、選考の時期」を確かめ、同時に転職先の60歳以降の条件を調べてください。**退職手当の扱いは両者で差がないので、比べるのは、その後の働き方と収入です。**時間を減らして続ける道と、経験を外で生かす道を、同じ紙に並べてから決める**のが、後悔の少ない形です。
:::

## 転職するとどうなるか

60歳前後で転職を考えている方にとって、定年前再任用短時間勤務で効いてくる点は3つです。

**1. 60歳以降の退職手当の扱いは、再任用でも転職でも同じ**

**退職事由を定年退職として算定する経過措置**（国の例）が、どちらにも及びます。

**2. 比べるのは、その後の働き方と収入**

**短時間で自治体に残るか、フルタイムで民間に移るか。**給与、勤務時間、仕事の中身で比べてください。

**3. 選考の結果を確かめてから退職を確定させる**

**一度退職すると、選考に通らなければ戻れません。**転職の内定と同じで、確定してから退職の手続きを進めてください。

## 手続きと期限

| 順序 | 手続き | 時期 | 場所 |
|---|---|---|---|
| 60歳の前年度 | 自治体の情報提供と意思確認。定年前再任用短時間勤務の職、勤務時間、給与、選考の時期を確かめる | 59歳 | 人事の担当課 |
| 同時に | 転職先の60歳以降の条件を調べ、並べる | 59歳 | 転職支援 |
| 希望する場合 | 定年前再任用短時間勤務の希望を申し出る | 自治体の定める時期 | 任命権者 |
| 選考 | 勤務実績などに基づく選考 | 自治体の定める時期 | 任命権者 |
| 選考の結果の後 | 退職の手続き。退職手当の受取り | 60歳以降 | 人事の担当課 |
| 採用 | 短時間勤務の職に採用。共済または健康保険・厚生年金の切替え | 採用の日 | 人事の担当課、共済組合 |
| 定年退職日相当日 | 任期の満了 | ── | ── |

## 誤解されやすい点

**「定年前再任用短時間勤務は定年後の再任用」と思い込む**

**定年の前に、60歳以降で退職した者を短時間勤務の職に採用する制度**です（第22条の4）。定年退職日相当日で任期が満了します。

**「身分はそのまま」と思い込む**

**いったん退職し、短時間勤務の職の職員として採用されます。**退職手当はその時点で受け取ります。

**「希望すれば必ず採用される」と思い込む**

**選考があり、短時間勤務の職の設定も自治体による**ので、希望どおりになるとは限りません。

**「再任用のほうが転職より退職手当で有利」と思い込む**

**60歳以降の退職手当の扱いは、再任用でも転職でも同じ**です。比べるのはその後の働き方と収入です。

:::insight
ここまで定年前再任用短時間勤務の話を書いておいて逆のことを言いますが、**この制度を使うかどうかは、転職の判断と対立するものではありません。**どちらも60歳以降に退職して退職手当を受け取り、その後をどこで過ごすかの違いです。それでも1本の記事にしたのは、**制度を知らずに「フルタイムか辞めるか」の二択で決める方を面談で見る**からです。短時間で残る道を知ったうえで転職を選ぶなら、その判断は確かです。そのうえで、**自分の経験に値を付けてくれる業界の見込みと、同じ紙に並べてください。**片方だけでは比較になりません。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 定年前再任用短時間勤務は、地方公務員法第22条の4により、**条例で定める年齢（国の例で60歳）以上で退職した職員を、選考により、定年退職日相当日まで短時間勤務の職に採用する制度**です
- **いったん退職するので、退職手当はその時点で支給され、再任用の期間は対象外**です。60歳以降の退職は退職事由を定年退職として算定する経過措置が国にあります
- 身分は**短時間勤務の職の職員**で、共済の扱いは勤務時間により変わります。年金の記録に空白は生じません
- **転職との違いは、退職手当ではなく、その後の働き方と収入**です。短時間で自治体に残るか、フルタイムで民間に移るかを、給与、勤務時間、仕事の中身で比べてください
- **選考があり、職の設定も自治体による**ので、希望どおりになるとは限りません。選考の結果を確かめてから退職を確定させてください
- 60歳の前年度に、**制度の中身と転職先の条件を同じ紙に並べる**のが、後悔の少ない形です

## よくある質問

### 定年前再任用短時間勤務の給与は、どのくらいになりますか

**短時間勤務の職の給与で、勤務時間に応じた額です。具体的な額は条例によるので、人事の担当課で見込みを聞いてください。**定年前再任用短時間勤務職員の給与は、自治体の給与条例で定められ、多くの自治体で、同種のフルタイムの職の給料月額を勤務時間に応じて按分した額を基礎にしています。フルタイムの職の給料月額は60歳以降の7割水準の措置（国の例）が適用されるので、その7割水準をさらに勤務時間で按分した額が目安になります。期末手当・勤勉手当の支給の有無と割合、通勤手当などの手当も条例で定められます。国の例では、勤務時間は週15時間30分から31時間までの範囲（内閣人事局の説明）で、自治体も条例で範囲を定めています。転職先の60歳以降の給与と比べる場合は、勤務時間当たりの額と、年間の額の両方で並べると、働く時間の違いを踏まえた比較になります。**人事の担当課に「週○時間の短時間勤務の職に採用された場合の給与と手当の見込額」を照会してください。**

### 定年前再任用短時間勤務の期間中に、民間に転職することはできますか

**できます。任期の途中で退職することを禁じる規定はありません。**定年前再任用短時間勤務職員は、任期が定年退職日相当日までと定められていますが、任期の途中で本人が退職を申し出ることは、他の職員と同じように可能です。短時間勤務の職員として働きながら、民間の転職先を探し、内定が出たら退職して転職する形は、制度上は問題ありません。退職手当は60歳以降の退職の時点ですでに受け取っているので、再任用の期間の途中で退職しても退職手当の追加はなく、減額もありません。注意するのは、短時間勤務の職員としての在職中も、地方公務員法の服務（職務専念義務、守秘義務、営利企業への従事等の制限）が及ぶこと、退職後は再就職者の働きかけの規制（第38条の2）が及ぶことです。「まず短時間で自治体に残り、その間に転職先を探す」という形は、時間に余裕があり、転職先を落ち着いて選べるので、60歳以降の転職の進め方として合理的です。転職先の60歳以降の処遇を確かめ、短時間勤務の給与と並べてから決めてください。

### 60歳で退職して転職するか、定年前再任用短時間勤務にするか、どう決めればよいですか

**退職手当の扱いは同じなので、その後の働き方と収入、仕事の中身で比べてください。**どちらも60歳以降に退職して退職手当を受け取る点は同じで、国の経過措置により退職事由は定年退職として算定されます（自治体も準じる）。違いは、その後を自治体の短時間勤務の職で過ごすか、民間のフルタイムの職で過ごすかです。定年前再任用短時間勤務は、週の勤務時間を減らして、自治体の業務（管理職ではない職）を定年退職日相当日まで続ける形で、給与は勤務時間に応じた額です。民間への転職は、財政・会計の経験を生かして、転職先の業務にフルタイムで従事する形で、給与は転職先の60歳以降の処遇によります。民間の事業主には、高年齢者雇用安定法により65歳までの雇用確保の義務があり、70歳までの就業確保の努力義務がありますが、60歳以降の給与の水準は企業により幅があります。**人事の担当課で短時間勤務の給与の見込みを、転職先で60歳以降の条件を、それぞれ確かめて、年間の収入、勤務時間、仕事の中身、健康の見込みを同じ紙に並べて**ください。どちらも合理的な選択で、正解は本人の優先順位で決まります。
