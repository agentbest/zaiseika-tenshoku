**結論から書きます。定年前再任用短時間勤務とは、60歳（条例で定める年齢）以降に定年より前に退職した職員を、本人の希望と選考により、定年退職日相当日まで「短時間勤務の職」に採用する制度です**（地方公務員法第22条の4）。定年が65歳へ段階的に引き上げられるのに合わせて設けられました。

押さえる点は4つです。

| 点 | 中身 |
|---|---|
| 身分 | **いったん退職し、短時間勤務の職員として新たに採用される**。フルタイムの職員が勤務時間を減らす制度ではない |
| 任期 | **採用の日から定年退職日相当日まで**（第22条の4第3項） |
| 勤務時間 | 国家公務員の例では**週15時間30分から31時間**の範囲（人事院）。自治体は条例で定める |
| 退職手当 | **退職した時点で支給**され、短時間勤務の期間は対象にならない |

勤務時間、給与、希望の出し方は自治体の条例と運用によるので、**自分の場合は人事担当課で確かめてください。**

## 条文——地方公務員法第22条の4

| 項 | 内容 |
|---|---|
| 第1項 | 任命権者は、**条例年齢以上退職者**（条例で定める年齢に達した日以後に退職した者。臨時的任用・任期付・非常勤の職員の退職を除く）を、**従前の勤務実績その他の情報に基づく選考**により、**短時間勤務の職**に採用することができる。ただし定年退職日相当日を経過した者は除く |
| 第2項 | 条例で定める年齢は、**国家公務員法第60条の2第1項の年齢（60歳）を基準**として定める |
| 第3項 | 任期は、**採用の日から定年退職日相当日まで** |
| 第4項 | 定年退職日相当日を経過した者は、短時間勤務の職に採用等できない |

「短時間勤務の職」とは、1週間の通常の勤務時間が、同種のフルタイムの職より短い職のことです。「定年退職日相当日」は、その短時間勤務の職をフルタイムで占めていたとした場合の定年退職日にあたる日です。

## 流れ——退職して、選考を経て、短時間の職員になる

1. **60歳の前年度**：任命権者から60歳以降の任用・給与・退職手当についての情報提供と、勤務の意思の確認が行われる（国の制度の例。自治体も同様の仕組みを設けている）
2. **希望の申出と選考**：従前の勤務実績などに基づく選考。**希望すれば必ず採用されるわけではない**
3. **退職**：60歳以降に退職し、**退職手当を受け取る**
4. **採用**：短時間勤務の職に採用。勤務時間に応じた給与になる
5. **任期満了**：定年退職日相当日で終わる

**一度退職すると、選考に通らなければ元に戻れません。**選考の結果を確かめてから退職を確定させる順序が安全です。

## 給与・退職手当・共済はどう変わるか

| 項目 | フルタイムで定年まで続ける | 定年前再任用短時間勤務 |
|---|---|---|
| 給与 | 60歳以降は給料月額が7割水準になる措置（国の例） | 短時間勤務の職の給与。級ごとの基準額×勤務時間の割合（国の例） |
| 退職手当 | 定年退職時に支給。60歳以降の期間も在職期間に入る | **60歳以降に退職した時点で支給**。短時間勤務の期間は対象外 |
| 共済・年金 | 組合員 | 勤務時間によって扱いが変わり得る。年金の記録は共済または厚生年金として続き、空白は生じない |
| 働き方 | フルタイム | 週の勤務時間を減らす |

国の制度では、60歳に達した日以後に、非違によることなく定年前に退職した人の退職手当は、当分の間、退職理由を「定年」として算定されます（人事院・内閣人事局「国家公務員の60歳以降の働き方について」）。地方公務員についても同じ趣旨の措置を条例で講じるよう求められており、自分の自治体の条例で確かめてください。給与の具体的な額、期末・勤勉手当の扱い、共済の扱いは条例と共済組合の定めによるので、**人事担当課と共済組合で「週○時間の場合の給与と共済の扱い」を照会してください。**

## 国家公務員の例で見る具体的な条件

自治体の条件を聞くときの物差しとして、人事院が示している国家公務員の定年前再任用短時間勤務の条件を挙げます。

| 項目 | 国家公務員の例（人事院） |
|---|---|
| 勤務時間 | 週15時間30分〜31時間、1日7時間45分以内。週休日は土日が基本だが、平日に設定することもできる |
| 俸給 | 職務の級ごとの基準俸給月額 ×（週の勤務時間 ÷ 38時間45分） |
| 手当 | 地域手当、住居手当、通勤手当、超過勤務手当、期末・勤勉手当などが支給される。**退職手当は支給されない** |
| 年次休暇 | 20日を超えない範囲で、勤務日数・勤務時間に応じて決まる。退職前の残日数は引き継がれない |
| 兼業 | 一定の要件を満たせば、許可を得て兼業できる |
| 社会保険 | 勤務時間などの条件で加入先が変わる。週の勤務時間がフルタイムの4分の3以上なら共済組合・厚生年金に加入 |

**年次休暇の残日数が引き継がれない**ことと、**兼業が許可制で認められ得る**ことは、退職前の予定を立てるときに効きます。自治体の条件はこれと違うことがあるので、同じ項目を人事担当課に聞いてください。表をそのまま質問票として使うと、聞き漏れが減ります。

:::insight
面談で伺うと、60歳で「**体力的にフルタイムは無理だから辞める**」と決めた方が、定年前再任用短時間勤務の制度を知らなかったという話があります。知っていれば、時間を減らして自治体で続ける道と、転職する道を並べられました。逆に、制度を使うつもりで退職したのに、用意された短時間勤務の職が希望と違い、結局転職した方もいます。**60歳の前年度の情報提供の機会に、職の種類・勤務時間・給与・選考の時期を聞き、同時に転職先の60歳以降の条件も調べてください。**退職手当の扱いは、短時間で残っても転職しても大きくは変わらないので、比べるのはその後の働き方と収入です。
:::

## 転職と比べると

| 項目 | 定年前再任用短時間勤務 | 60歳以降に民間へ転職 |
|---|---|---|
| 退職手当 | 60歳以降の退職時に受け取る | 同じ（退職して転職する時点で受け取る） |
| 働く時間 | 短時間 | 転職先による（フルタイムが多い） |
| 給与 | 勤務時間に応じた短時間勤務の職の給与 | 転職先の処遇。企業により幅がある |
| 期間 | 定年退職日相当日まで | 転職先の定年・継続雇用の条件による。民間には高年齢者雇用安定法による65歳までの雇用確保措置の義務がある |
| 仕事の中身 | 自治体の業務 | 財政・会計などの経験を生かす業務 |

どちらも「60歳以降に退職して退職手当を受け取る」点は同じで、**その後を自治体の短時間の職で過ごすか、民間で過ごすか**の違いです。定年の引上げ全体の仕組みは[定年引上げの仕組み](seido-ninyo-teinen.html)、60歳以降の選び方は[再任用か民間転職か](seido-ninyo-sainiyo.html)に書いています。

## 誤解されやすい点

- **「定年後の再任用のこと」**——定年より**前**に、60歳以降で退職した人を採用する制度です。定年退職後の暫定再任用とは別です
- **「身分はそのままで時間だけ減る」**——いったん退職し、短時間勤務の職員として採用されます
- **「希望すれば必ず採用される」**——選考があり、職の設定も自治体によります
- **「残ったほうが退職手当で有利」**——60歳以降の退職手当の扱いは、残っても転職しても大きな差はありません

:::insight
定年前再任用短時間勤務の話を書いてきましたが、**この制度を使うかどうかは、転職の判断と対立するものではありません。**どちらも60歳以降に退職し、その後をどこで過ごすかの違いです。それでも1本の記事にしたのは、制度を知らずに「フルタイムか辞めるか」の二択で決める方を面談で見るからです。短時間で残る道を知ったうえで転職を選ぶなら、その判断は確かです。そのうえで、**自分の経験に値を付けてくれる業界があるかを同じ紙に並べてください。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 定年前再任用短時間勤務は、**60歳（条例年齢）以降に退職した職員を、選考により定年退職日相当日まで短時間勤務の職に採用する制度**（地方公務員法第22条の4）
- **いったん退職**するので、退職手当は退職時に支給され、短時間勤務の期間は対象外
- 勤務時間は国の例で**週15時間30分〜31時間**。自治体は条例で定める
- 給与は**勤務時間に応じた額**。具体額は条例によるので人事担当課で照会する
- **選考がある**ので、結果を確かめてから退職を確定させる

## よくある質問

### 定年前再任用短時間勤務の給与は、どのくらいになりますか

**短時間勤務の職の給与で、勤務時間に応じた額になります。具体額は条例によるので、人事担当課に見込みを照会してください。**国家公務員の例では、職務の級ごとに定められた基準俸給月額に、週の勤務時間をフルタイム（週38時間45分）で割った割合を掛けて俸給月額を出します（人事院）。自治体も条例で同様の仕組みを置いていることが多いですが、額は自治体ごとです。期末手当・勤勉手当、通勤手当などの扱いも条例で定められます。転職先の60歳以降の給与と比べるときは、年間の額と、勤務時間あたりの額の両方で並べると、働く時間の違いを踏まえた比較になります。

### 短時間勤務の期間中に、民間に転職することはできますか

**できます。任期の途中で退職することを禁じる規定はありません。**退職手当は最初に退職した時点で受け取っているので、途中で辞めても追加や減額はありません。在職中は地方公務員法の服務（職務専念義務、守秘義務、営利企業への従事等の制限）が及び、退職後は再就職者の働きかけの規制（第38条の2）が及びます。「まず短時間で残り、その間に転職先を落ち着いて探す」という進め方は、時間に余裕を持てる点で合理的です。

### 定年前再任用短時間勤務と、定年後の再任用（暫定再任用）は何が違いますか

**採用される時期と任期が違います。**定年前再任用短時間勤務は、**定年より前**に60歳以降で退職した人を、**定年退職日相当日まで**の任期で短時間勤務の職に採用する制度です。暫定再任用は、定年の段階的な引上げの経過期間に設けられたもので、**定年退職等をした人**を、65歳までの間、1年以内の任期で採用する制度です（人事院の説明）。どちらが使えるかは、生年月日と自治体の定年の引上げのスケジュールで変わるので、60歳の前年度の情報提供の際に確かめてください。
