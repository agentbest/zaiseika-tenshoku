公園緑地課の職務経歴書で、いちばん多い失敗はこれです。

**「公園の維持管理に関する業務」**

**この1行で終わってしまいます。**

読む側は、ここから**「草刈りと清掃の手配をしていた人」**という像しか作れません。実際には、**数十から数百の施設を台帳で持ち、点検の周期を決め、直す順番を決め、他人が公園に施設を作りたいと言ってきたときに許可の可否を判断していた**わけですが、それが書かれていません。

この記事では、**職務要約・担当業務・実績**の3つに分けて、悪い例と良い例を並べます。

言い換えは[公園緑地課の経験は民間で何と呼ばれるか](dept-koen-honyaku.html)、行き先は[公園緑地課から転職しやすい業界と職種](dept-koen-tenshokusaki.html)に書いています。

## 「自分でやるのが困難か」で判断していました

書き方に入る前に、この仕事の性格を条文で押さえます。**書類の芯になる部分**です。

**都市公園法第5条**は、公園管理者以外の者が公園施設を設け、又は管理しようとするときは許可を受けなければならないとしたうえで、**許可できる場合をこう限定しています。**

> 一 当該公園管理者が自ら設け、又は管理することが不適当又は困難であると認められるもの
> 二 当該公園管理者以外の者が設け、又は管理することが当該都市公園の機能の増進に資すると認められるもの

**ここが、書類の芯です。**

**「他人にやらせてよいか」を、2つの物差しで判断していた**ということです。**自分でやるのが困難か。****任せたほうが良くなるか。**

そして、**同条第3項は、その期間を10年を超えることができないと定めています。**つまり、**期限を切って任せ、更新のたびに見直す仕組み**です。

**民間で人を採る側から見ると、これは「自前でやるか、外に出すかを判断し、期限を切って管理する仕事」**です。**委託の判断そのもの**と言い換えられます。

職務経歴書には、**この判断をしていたことが見えるように書いてください。**

## 職務要約

### 悪い例

> 公園緑地課において、公園の維持管理及び整備に関する業務に従事。指定管理者との調整、苦情対応等を担当。

**これでは、規模も、判断の範囲も読めません。**

### 良い例（維持管理が長い方）

> 市が管理する都市公園◯か所、計約◯ヘクタールの維持管理を担当。遊具約◯基、便所約◯か所について点検の周期と区分を定め、年間約◯件、約◯万円の修繕を発注。街路樹約◯本の剪定と危険木の判断を担当し、倒木に至る前の伐採の基準を整備。

### 良い例（計画と制度が長い方）

> 緑の基本計画の改定および公園施設長寿命化計画の策定を担当。公園◯か所の台帳を整備し、更新の時期と概算の費用を年次に配分。指定管理者制度の導入を担当し、公募の要求水準、選定の基準、モニタリングの項目を設計。公園管理者以外の者による公園施設の設置の許可についても審査を担当。

**太字にしなくても、数字と制度の名前が入っているだけで読み方が変わります。**公園の数、面積、施設の基数、計画の名前。**この4つのうち、分かるものから埋めてください。**

:::insight
この経歴の職務経歴書で、**書けるのに書かれていないことの筆頭が「許可の審査」**です。都市公園法第5条の許可、占用の許可、行為の許可。**どれも、自分が発注した仕事ではありません。**だから、**「自分の実績」とは思われていない。**ところが、**中身は、申請の内容の確認、条件の設定、期間の設定、履行の確認**——**発注した工事とほぼ同じことをしています。**しかも、**相手は自社ではなく、外部の事業者や団体です。**面談で伺うと、**「イベントの申請は毎週来ていました」とおっしゃる方が多い。****その件数を数えてください。**書くなら、**「都市公園法に基づく公園施設の設置の許可および占用の許可を年間約◯件審査。条件の設定から履行の確認までを担当」**という形です。**民間でいえば、これは「自社の場所を他社に使わせるときの条件づくりと管理」**です。**商業施設でも、駅でも、工場の敷地でも、同じ場面があります。****この一行があると、扱える範囲が一段広く読まれます。**
:::

## 担当業務

**「維持管理及び整備」で丸めず、6つに分けてください。**

| 機能 | 書き方の例 |
|---|---|
| 維持管理 | 都市公園◯か所、計約◯ヘクタールの点検、修繕、清掃と草刈りの委託の管理 |
| 台帳と計画 | 公園台帳の整備、公園施設長寿命化計画の策定、緑の基本計画の改定 |
| 許可と占用 | 公園施設の設置の許可、占用の許可、行為の許可の審査、条件の設定 |
| 委託と指定管理 | 指定管理者の公募、要求水準の作成、選定、協定の締結、モニタリング |
| 整備と用地 | 公園の新設と再整備、区域の決定と公告、用地の取得に係る事務 |
| 利用者と地域 | 公園愛護会との調整、要望と苦情の処理、催しの受入れと調整 |

**この6つのうち、自分がやっていないものは書かなくて構いません。**むしろ、**やっていない機能を空欄にしたほうが、やった機能の密度が読まれます。**

**とくに、3番目と4番目は、民間で直接に読み替えられる機能**です。**場所を貸す条件を作る仕事**と、**委託先を選んで管理する仕事**だからです。

## 実績

**ここが書きにくい部分です。**成果が、**使われ続けていること**として現れるからです。

### 悪い例

> 公園の適切な維持管理に努めた。利用者からの要望に丁寧に対応した。

**これは、姿勢の話であって、実績ではありません。**

### 良い例——3つの型

**型1：基準を作った**

> 遊具および園路の点検の結果を4段階に区分し、修繕の優先順位の基準を作成。それまで要望の順に対応していた修繕を、危険度と利用者数で並べ替え、年度末への集中を解消。

**型2：使われ方を変えた**

> 利用の競合が続いていた公園について、時間帯と区域を分ける使い方のルールを作成し、掲示と周知を実施。要望の件数が前年より減少。

**型3：委託の質を上げた**

> 指定管理者のモニタリングについて、回数の確認が中心だった項目を、利用の時間帯と作業の時間帯の突き合わせに改め、要求水準書を改定。次期の公募から適用。

**3つとも、「やったこと」ではなく、「自分が変えたこと」で書かれています。**

### 数字の出し方

| 数えるもの | 書き方の例 | 注意 |
|---|---|---|
| 公園の数と面積 | 都市公園◯か所、計約◯ヘクタール | 台帳の数字を使う。種別ごとに分けると強い |
| 施設の基数 | 遊具約◯基、便所約◯か所、照明約◯基 | 点検の対象の数で構わない |
| 樹木の本数 | 街路樹約◯本、公園の高木約◯本 | 概数で構わない |
| 修繕の件数と額 | 年間約◯件、約◯万円 | 発注の実績。個別の案件は書かない |
| 許可の件数 | 設置・占用・行為の許可 年間約◯件 | 数えていないことが多い部分 |
| 委託の規模 | 指定管理料 年約◯万円、委託◯件 | 公表されている数字を使う |

**「約」を付けて構いません。**正確な数字が出せないことよりも、**桁が分かることのほうが大事**です。

### 応募先で並べ替える

| 応募先の方向 | 上に置く機能 |
|---|---|
| 指定管理・施設運営の会社 | 委託と指定管理／維持管理／利用者と地域 |
| 造園・緑化の会社 | 維持管理／樹木の判断／工事の発注と検査 |
| 開発・デベロッパー | 許可と占用／整備と用地／台帳と計画 |
| 商業施設・複合施設の運営 | 利用者と地域／許可と占用／委託の管理 |
| 自治体を顧客とする企業 | 台帳と計画／長寿命化／許可の運用 |

**同じ経歴でも、順番を変えるだけで読まれ方が変わります。**中身を作り直す必要はありません。

:::insight
書き方の話をしておいて逆のことを言いますが、**書類を完成させてから動く必要はありません。**この経歴の方に多いのは、**「決まった予算で、決まった公園を回していただけ」**と考えて、実績欄を薄く書いてしまうことです。ところが、**この仕事の中心は、配分の判断です。**傷んでいる箇所は、いつも予算より多い。**そこから、どれを今年直すかを選んでいます。**しかも、**公園は地域ごとに使う人が決まっている**ので、**「なぜうちの公園が後なのか」に答えられる基準が要ります。**つまり、**限られた資源の配分を、地域に説明できる形で決めてきた**——**これは、民間の施設の運営でそのまま求められる技術**です。**先に、4つの数字だけ確かめてください。**公園の数と面積、施設の基数、修繕の件数と金額、許可の件数。**このうち4つ目は、数えていないことが多い**ので、**1か月分だけでも数えてみてください。**この4つが揃った時点で、**書類の読まれ方が変わります。**在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 書いてはいけないこと

| ✕ 書かない | ○ こう書く |
|---|---|
| 特定の公園で起きた事故の詳細 | 点検の区分と、そこで運用していた記録の手順 |
| 苦情を言ってきた人や団体のこと | 利用が競合する場面の類型と、作ったルール |
| 指定管理者の会社名と、その評価 | 要求水準とモニタリングの項目を、どう設計したか |
| 公表されていない選定の過程 | 公表されている公募の要件と、自分が担当した範囲 |
| 「うちの市は公園が多すぎる」 | 「◯か所を◯人体制で管理し、点検の周期を種別ごとに設定した」 |

**1行目は、とくに注意してください。**遊具の事故は、**関わった方にとっては大きな出来事**ですが、**書類に詳細を書くと、特定につながります。**書くのは、**その後に何を変えたか**です。

## つまずきやすい点

**1. 「維持管理及び整備」で丸める**

**維持管理／台帳と計画／許可と占用／委託と指定管理／整備と用地／利用者と地域**の6つに分けてください。

**2. 許可の件数を書かない**

**他人が公園を使うことを審査した量**です。**書かれていない部分なので、差が付きます。**

**3. 優先順位の基準を書かない**

**限られた予算の配分を、地域に説明できる形で決めてきた**——**この仕事の中心です。**

**4. 苦情の対応を、苦労話にする**

**ルールを作って、掲示して、運用していた**と書いてください。

**5. 計画の名前を書き落とす**

**緑の基本計画、長寿命化計画。****改定に関わっただけでも書けます。**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## まとめ

- 都市公園法第5条は、**公園管理者以外の者が公園施設を設けるときの許可を、「自ら設け、又は管理することが不適当又は困難」「機能の増進に資する」という2つの物差しで判断する**と定めています
- つまり、**公園緑地課は「自前でやるか、外に出すかを判断し、期限を切って管理する」仕事**をしています
- 職務要約には、**公園の数と面積・施設の基数・修繕の件数と金額・計画の名前**を入れてください
- 実績は、**①基準を作った ②使われ方を変えた ③委託の質を上げた**の3つの型で書けます
- **許可の件数**は、**数えていないことが多い**ので、**1か月分だけでも数えてください**
- 事故や苦情は、**詳細ではなく、その後に変えたこと**を書いてください

## よくある質問

### 技術職で、計画や制度には関わっていません

**それは、むしろ書きやすい形です。**造園や維持管理の受託の会社では、**現場の判断の経験が直接効きます。**書くべきは、**①管理していた公園の数と面積 ②点検で見ていた項目 ③樹木や遊具の危険の判断の基準 ④検査で差し戻していた理由**の4つです。とくに、**④の「何で不合格にしていたか」**は、**受注する側に回ったときに、そのまま「どこを押さえれば通るか」の知識になります。**書くなら、**「植栽の活着の確認、清掃の時間帯と利用の時間帯の整合、点検の記録の写真の有無を検査の項目として運用」**という形です。**これは、提案の質に直結する情報**として読まれます。

### 公園の数が少ない市で、規模が小さいのですが

**数の多少は、それほど問題になりません。**むしろ、**小規模な自治体ほど、一人が見る範囲が広い**ことがあります。**維持も、許可も、指定管理も、街路樹も、用地も、全部を数人で回している。****その場合は、「範囲の広さ」を前に出してください。**書くなら、**「都市公園◯か所について、点検、修繕の発注、許可の審査、指定管理者の監督、愛護会との調整までを少人数で担当」**という形です。**「単独で」「少人数で」という一語**が、**幅の証明になります。**

### 指定管理者制度の導入そのものには関わっていません

**運用の側の経験で書けます。**導入の設計に関わっていなくても、**協定に基づくモニタリング、業務の報告の確認、不備があったときの指示、更新の際の条件の見直し**は、担当していたはずです。**受託の会社から見ると、ここがいちばん知りたい部分**です。「発注者は、何を見て、どこで指摘してくるのか」。書くなら、**「指定管理者◯者について、月次の報告の確認と現地の確認を実施。要求水準に対する不足を◯件指摘し、改善の報告までを確認」**という形です。面接で聞かれることは[公園緑地課出身者が面接で必ず聞かれること](dept-koen-mensetsu.html)に整理しています。
