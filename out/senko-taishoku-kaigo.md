**家族の介護が始まったことをきっかけに、働き方を見直す方がいらっしゃいます。**

**介護は、期間の見通しが立ちにくい**という特徴があります。

この記事では、**制度の確認先**と、**勤務の条件の絞り方**を扱います。

**⚠ 介護に関する制度は、条例・規程・就業規則によって異なります。****この記事は一般的な整理にとどめます。**

## 転職先では、申出でできる制度があります

**育児休業、介護休業等育児又は家族介護を行う労働者の福祉に関する法律第11条第1項**です。

> **労働者は、その事業主に申し出ることにより、介護休業をすることができる。**

**「申し出ることにより」**と書かれています。

**事業主の承認を条件とする書き方にはなっていません。**

**同条第2項**は、**回数と日数の上限**を定めています。

> 一 当該対象家族について**三回**の介護休業をした場合
>
> 二 当該対象家族について介護休業をした日数（略）が**九十三日**に達している場合

**対象家族1人について、3回まで、通算93日まで**という構造です。

**この制度は、転職先が民間の事業所であれば適用されます。**

**いまの職場での扱いは、条例と規程によります。**

**所属の人事担当に確認**してください。

## 確認の順序

| 順 | 確認すること | 確認先 |
|---|---|---|
| 1 | **介護の状況と見通し** | 地域包括支援センター・ケアマネジャー |
| 2 | いまの職場の制度 | 所属の人事担当 |
| 3 | 転職先の制度 | 求人票・就業規則 |
| 4 | 給付の扱い | 転職先・関係機関 |
| 5 | 勤務の条件 | 求人票 |

**1を最初に置いてください。**

**介護の体制が定まらないうちに勤務の条件を決めると、後で合わなくなります。**

**要介護の認定、サービスの利用、家族の分担。**

**これらが見えてから、勤務の条件を絞るほうが確実**です。

## 2——いまの職場で使える制度

| 制度 | 確認すること |
|---|---|
| 介護休暇 | 条例上の日数と要件 |
| 介護休業 | 期間と要件 |
| 部分休業・時間休 | 取得の単位 |
| 勤務時間の変更 | 制度の有無 |
| 在宅勤務 | 制度の有無と運用 |

**まず、いまの職場で対応できるかを確認**してください。

**制度を使うことで続けられる場合があります。**

**転職を前提にせず、制度の照会として聞くことができます。**

**この確認をしないまま辞めると、選択肢を1つ捨てることになります。**

## 3——転職先の制度

| 確認すること | 内容 |
|---|---|
| 介護休業・介護休暇 | 就業規則の定め |
| 対象となる要件 | **勤続の年数などの要件**がある場合があります |
| 短時間勤務・時差出勤 | 有無と要件 |
| 在宅勤務 | 有無と頻度 |
| 実際の運用 | 取得の実績 |

**2つ目に注意してください。**

**法律上の制度であっても、労使協定により対象から除かれる場合があります。**

**入社してすぐに使えるとは限りません。**

**応募の段階で、就業規則の内容を確認**してください。

## 5——勤務の条件で絞る

**介護と両立する場合、条件で求人を絞るほうが確実です。**

| 条件 | 見るところ |
|---|---|
| 勤務地 | 通勤の時間、自宅からの距離 |
| 勤務時間 | 始業・終業、残業の見込み |
| 休日 | 土日か、シフトか |
| 急な休みへの対応 | **時間単位の休暇の有無** |
| 出張・転勤 | 頻度と可能性 |
| 在宅勤務 | 可否と頻度 |

**4つ目が効きます。**

**介護は、急な対応が生じます。**

**半日や1日単位でしか休めない制度だと、対応が難しくなります。**

**時間単位で休める制度があるかを確認**してください。

**5つ目について。**

**転勤の可能性がある求人は、介護の事情によっては候補から外れます。**

**後で分かるより、先に絞るほうが確実**です。

:::insight
介護のご相談で、**面談でお伝えしているのが「いまの職場の制度を先に確認してください」**という点です。介護が始まった直後は、**目の前の対応に追われて、制度を調べる時間が取れません。**その状態で「続けられない」と判断されることがあります。ところが、**確認してみると、条例上の制度で対応できる範囲があった**という例が少なくありません。**在宅勤務や時差出勤の運用がある場合もあります。**そして、**転職して環境を変えたほうがよい場合も、判断の材料が揃います。**いまの職場で使える制度を把握していれば、**転職先の制度と比べられる**からです。比べる基準がないまま動くと、**いまより条件の悪い先を選ぶ**ことがあります。ですから、**順序は「いまの制度を確認する → 転職先の制度と比べる」**です。どちらも、**制度の照会として聞いて差し支えありません。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 面接で伝える範囲

**介護の事情を詳しく説明する義務はありません。**

**ただし、勤務の条件に関わる範囲は、整理しておくほうが後の齟齬が減ります。**

| 伝える範囲 | 例 |
|---|---|
| 勤務できる時間 | 始業・終業の希望 |
| 急な対応の可能性 | あること、その頻度の見込み |
| 出張・転勤 | 対応の可否 |
| 必要な制度 | 休暇の取り方 |

**2つ目を伝えておくと、入社後の調整がしやすくなります。**

**伝えずに入社して、後から調整できないほうが問題になります。**

**なお、介護の詳細や家族の状況を説明する必要はありません。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 時期の組み立て

| 時期 | できること |
|---|---|
| 介護が始まった直後 | **体制を整える。転職の判断はしない** |
| 体制が定まった後 | いまの制度を確認する |
| その後 | 求人を見る、条件を絞る |
| 条件が合う求人が出たとき | 応募 |

**1行目です。**

**介護が始まった直後は、判断の材料が揃いません。**

**この時期に結論を出す必要はありません。**

**体制が定まってから、改めて考えて差し支えありません。**

## 退職を決める前に確認すること

| 項目 | 確認先 |
|---|---|
| 退職手当の扱い | 所属の給与担当 |
| 保険の切替え | 共済組合・転職先 |
| 年金の手続き | 年金事務所 |
| 住民税の扱い | 市区町村 |
| 介護に関する費用の負担 | 市区町村の担当窓口 |

**5つ目です。**

**介護に関する費用の負担は、世帯の状況によって扱いが変わることがあります。**

**収入の構成が変わる場合、影響の有無を市区町村の担当窓口に確認**してください。

**なお、確認は在職中にできます。**

**「収入が変わった場合の取扱い」を一般的な照会として聞く形**です。

## 在職中にできること

| 項目 | 内容 |
|---|---|
| ケアマネジャーとの相談 | 体制の見直し |
| いまの制度の確認 | 人事担当へ |
| 職務経歴書の下書き | 時間の取れるときに |
| 求人の条件の整理 | 勤務地・時間・休暇 |

**4つ目を先にしておくと、求人が出たときに判断が速くなります。**

**条件を紙に書き出しておくだけで構いません。**

## よくある失敗

**1. いまの職場の制度を確認せずに辞める**

**選択肢を1つ捨てることになります。**

**2. 介護が始まった直後に結論を出す**

**材料が揃いません。**

**3. 転職先の制度の要件を確認しない**

**入社直後は対象外となる場合**があります。

**4. 時間単位の休暇の有無を見ない**

**急な対応ができません。**

**5. 転勤の可能性を確認しない**

**後で条件が変わります。**

**6. 勤務の条件を伝えない**

**入社後に調整できません。**

**7. 介護の詳細を説明しようとする**

**勤務の条件に関わる範囲で足ります。**

:::insight
ここまで条件の話をしておいて逆のことを言いますが、**介護の事情があることは、選考で不利になるとは限りません。**面談で伺っていると、**「条件を付けると、採用されないのではないか」と考えて、条件を伏せる方**がいらっしゃいます。ところが、**条件を伏せて入社すると、続かなくなります。**採用する側にとっても、**短期間で離職されるほうが負担**です。そして、**介護をしながら働いている人は、珍しくありません。**制度を整えている事業所もあります。**条件を先に出すことで、合う求人だけが残ります。**残る数は減りますが、**残ったものは合っている**ということです。求人を数で見ると不安になりますが、**必要なのは条件の合う1件**です。そして、**行政が相手の事業を担う会社には、公共の制度を理解している人を求めている先があります。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **育児・介護休業法第11条**は、**労働者は事業主に申し出ることにより介護休業をすることができる**と定めています。**対象家族1人につき3回、通算93日**が上限です
- **いまの職場の制度を先に確認**してください。**制度で対応できる範囲があることがあります**
- **転職先の制度は、勤続の年数などの要件**がある場合があります。**就業規則を確認**してください
- 勤務の条件では、**時間単位の休暇の有無**と**転勤の可能性**を確認してください
- **介護が始まった直後に結論を出さない。**体制が定まってからで足ります
- 面接で伝えるのは、**勤務の条件に関わる範囲**です。詳細の説明は不要です

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 介護がいつまで続くか分かりません。どう説明すればよいですか

**見通しが立たないことを、そのまま伝えて差し支えありません。**採用する側も、**介護の期間が読めないことは理解しています。**伝えるのは、**期間ではなく勤務の条件**です。「週に1回、通院の付き添いで午前中に休みが必要になる見込みです」「急な対応が月に数回生じる可能性があります」という形です。**条件であれば、相手も判断できます。**一方、「いつまで続くか分かりません」だけでは、**相手が何を検討すればよいか分かりません。**なお、**状況は変わります。**入社後に変化した場合、その時点で相談する形で差し支えありません。

### 介護休業の給付は、転職後すぐに受けられますか

**要件があります。**介護休業に関する給付は、**加入の期間などの要件を満たす場合に支給される**仕組みです。**転職の直後は、要件を満たさないことがあります。**具体的な要件と金額は、**転職先の担当部署か、関係する機関に確認**してください。なお、**公務員として在職している間は雇用保険の適用がない**ため、**転職前の期間がそのまま通算されるとは限りません。**この点は[公務員に失業給付が出ない理由と、代わりの備え](senko-taishoku-shitsugyo.html)に整理しています。**制度の前提が変わるため、確認しておいてください。**

### 介護のために勤務地を変えたいのですが、求人が見つかりません

**探す軸を変えてみてください。**1つは、**職種を広げること。**同じ地域でも、職種を絞りすぎると候補が減ります。もう1つは、**在宅勤務が可能な求人を見ること**です。**勤務地の制約が小さくなります。**さらに、**行政が相手の事業は、その地域に拠点がある**ことがあります。指定管理者、業務の受託、発注者支援など、**地域に根ざした事業**です。**公務員としての経験が使える先でもあります。**なお、**条件を満たす求人が出る時期は読めません。**在職中であれば、**条件を登録しておいて、出たときに知らせを受ける**という進め方もできます。
