商社の選考について、**公務員の方から繰り返し伺う思い込み**が2つあります。

**「新卒で入る会社で、中途では入れないのでは」**

**「年齢で切られるのでは」**

**どちらも、そのままでは正しくありません。**

正確に言うと、**入り口が「商社」ではなく「職種」になっている**というだけです。そして、**年齢の扱いには、法律上の定めがあります。**

この記事では、**選考の流れと、面接で実際に見られている観点**を扱います。機能の整理は[未経験から商社に入るには](industry-shosha-mikeiken.html)、志望動機の組み立ては[商社の志望動機](industry-shosha-shiboudoki.html)にあります。

## 求人票の記載は、正確でなければなりません

**選考の前提として、知っておいていただきたい条文があります。**

**職業安定法第5条の4第1項**です。

> **（求人等に関する情報の的確な表示）**公共職業安定所、特定地方公共団体及び職業紹介事業者、労働者の募集を行う者及び募集受託者、募集情報等提供事業を行う者並びに労働者供給事業者は、この法律に基づく業務に関して（中略）広告等により求人若しくは労働者の募集に関する情報（中略）を提供するときは、**当該情報について虚偽の表示又は誤解を生じさせる表示をしてはならない。**

そして、**同条第2項**です。

> （中略）広告等により求人等に関する情報を提供するときは、**正確かつ最新の内容に保たなければならない。**

**「虚偽の表示又は誤解を生じさせる表示をしてはならない」「正確かつ最新の内容に保たなければならない」**です。

**求人票の記載と、面接で聞いた話が食い違ったとき、確認するのは当然の行為**だということです。

**遠慮する必要はありません。**「求人票では△△と拝見しましたが、実際の運用はいかがでしょうか」。**この確認は、法の建て付けに沿っています。**

## 年齢については、均等な機会の定めがあります

**労働施策の総合的な推進並びに労働者の雇用の安定及び職業生活の充実等に関する法律第9条**です。

> **（募集及び採用における年齢にかかわりない均等な機会の確保）第九条　事業主は、労働者がその有する能力を有効に発揮するために必要であると認められるときとして厚生労働省令で定めるときは、労働者の募集及び採用について、厚生労働省令で定めるところにより、その年齢にかかわりなく均等な機会を与えなければならない。**

**「年齢にかかわりなく均等な機会を与えなければならない」**と定められています。**厚生労働省令で定める例外はありますが、原則は均等な機会**です。

**ですから、求人票に年齢の条件が書かれていない募集**については、**年齢を理由に応募をためらう必要はありません。**

**実務として見ていただきたいのは、年齢そのものではなく、求められている経験の年数**です。**「◯年以上の実務経験」と書かれていれば、その年数が要件**であって、年齢が要件ではありません。

## 選考の流れは、職種で分かれます

| 職種 | 流れの型 | 回数の目安 |
|---|---|---|
| 経理・財務 | 書類 → 部門の責任者 → 役員 | **3回前後** |
| 法務・輸出管理 | 書類 → 実務の担当 → 部門長 → 役員 | 3〜4回 |
| 与信・審査 | 書類 → 部門の責任者 → 役員 | 3回前後 |
| 貿易の実務 | 書類 → 実務の担当 → 部門長 | **2〜3回** |
| 営業・調達 | 書類 → 部門長 → 役員 → 場合により現場 | 3〜4回 |
| 事業投資の管理 | 書類 → 複数回の面接 → 役員 | **4回以上のことも** |

**役所の採用試験と、いちばん違うのは、人事が主役ではないこと**です。

**配属される部門の責任者が、選考の中心**にいます。**「一緒に働く人」が面接に出てくる**ため、質問が実務に寄ります。

**もうひとつ違うのは、筆記試験が無いか、軽いこと**です。**教養試験・専門試験で選抜する仕組みではありません。**書類と面接で判断されます。

**⚠ そのぶん、職務経歴書の比重が大きくなります。**役所の受験申込書とは、求められているものが別物です。

## 上位のポジションは、決裁の段階が増えます

**部長級・管理職として採用される場合、選考の回数が増えます。**

**理由は、会社の意思決定の仕組みにあります。**一定の職位以上の採用は、**役員の決裁や、会議体での確認を経る**ことがあります。

**結果として、次のことが起こります。**

| 起こること | 理由 |
|---|---|
| 面接と面接の間隔が空く | **会議体の日程を待つ** |
| 同じことを複数回聞かれる | 面接官が別の階層の人だから |
| 最終の連絡までに時間がかかる | **決裁の段階が複数ある** |

**「手応えがあったのに連絡が来ない」**のは、**落選の合図とは限りません。**

**期日の確認は、してください。**「◯月中に結論をいただけると、こちらの検討も進めやすいのですが、見通しはいかがでしょうか」。**この聞き方なら、急かしている印象になりません。**

## 面接で見られている観点は、5つです

| 観点 | 具体的に確かめられること |
|---|---|
| ① 機能の説明 | **自分が何を担えるかを、職種の言葉で言えるか** |
| ② 数字への理解 | **予算の執行と損益の違いを分かっているか** |
| ③ 間に立てるか | 利害の違う相手の間で条件をまとめた経験 |
| ④ 前提の確認 | **勤務地・出張・時間帯を確認しているか** |
| ⑤ 立ち上がりの速さ | 最初の3か月で何をするか |

**①が、いちばん落ちる原因になります。**

**「幅広く対応してきました」という答えは、評価されません。**

**職種の言葉に置き換えてください。**契約の審査、支出の負担行為の確認、許可の該当性の判断、実績報告の検査。**これらは、商社の中の仕事と対応します。**

**⑤も、用意しておいてください。**

> 最初の3か月は、取り扱っている品目と取引の流れを把握することに充てます。並行して、過去の案件の記録を読んで、判断が必要になる場面のパターンを整理します。手を入れるのは、その次だと考えています。

**いきなり改善案を語る答えは、評価が割れます。**中を知らないまま提案していると受け取られるためです。

:::insight
選考に同席させていただいていて、**公務員の方がいちばん損をしている場面**があります。**「現職では、どのような成果を出されましたか」**という質問への答え方です。多くの方が、**担当した事務の内容**を説明されます。「◯◯の申請の審査を担当していました」。**これは経歴の説明であって、成果の説明ではありません。**商社の面接官が聞いているのは、**「その人が関わったことで、何が変わったか」**です。答え方を変えるだけで、印象が変わります。「審査の担当でしたが、判断が分かれる類型について、過去の事例を整理して基準の表を作りました。以後、新任の担当でも同じ判断ができるようになり、照会の件数が減りました」。**やったことは同じでも、後者は「変えた話」になっています。**役所の仕事は、**成果が個人に紐づかない書き方で記録される**ため、この転換が要ります。探し方のこつは、**「自分が来る前と、去ったあとで、何が違うか」**を考えることです。様式を作った、手順を整理した、前例の無い事案の処理の方針を決めた。**どれも、立派な成果です。**ご本人が当たり前だと思っている部分に、たいてい答えがあります。
:::

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 場面 | 効く理由 |
|---|---|
| 書類の作り込み | **記録を残す訓練を受けている** |
| 制度・規制についての質問 | **許認可の側にいた** |
| 官公庁が相手の案件の話 | 相手の意思決定の流れが読める |
| 契約の条件についての質問 | 契約事務の経験 |
| 前提条件の確認 | **確認する習慣がある** |

**効きにくい場所**

| 場面 | 効きにくい理由 |
|---|---|
| 成果を数字で語る | **役所では個人の成果として記録されない** |
| 自己紹介を短く話す | 説明が丁寧になりすぎる |
| 想定外の質問への即答 | **前例を確認してから答える習慣** |
| 志望動機を機能で語る | 業種で考えてしまう |

**2つ目は、事前の練習で直ります。**

**役所の説明は、経緯から順に話す形**になりがちです。**面接では、結論から先に言ってください。**「担ってきたのは、契約の審査です。年間◯件、◯億円規模の案件を扱っていました」。**この順序に変えるだけで、伝わり方が変わります。**

## 準備の手順

| 順 | やること | 目安 |
|---|---|---|
| 1 | 職務経歴書を、**職種の言葉**に置き換える | 2時間 |
| 2 | **「変えた話」を3つ**書き出す | 1時間 |
| 3 | 応募先の**事業の分野**を確認する | 1時間 |
| 4 | **最初の3か月**の答えを作る | 30分 |
| 5 | **確認する項目を3つ**決める（勤務地・出張・時間） | 20分 |
| 6 | 結論から話す練習を、**声に出して**行う | 30分 |

**5つ目を、必ずやってください。**[商社の年収と働き方](industry-shosha-nenshu.html)で触れたとおり、**勤務地と業務の範囲は、この業界では特に確認が要ります。**

[経験の言い換えから相談する](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担です）。

| 質問 | 何が分かるか |
|---|---|
| この職種の方は、どういう異動をされていますか | **勤務地の前提** |
| 前任の方は、どういう経緯で離れましたか | 定着の状況 |
| 採用の決定は、どういう手順で行われますか | **選考の見通し** |
| 入って最初に任せたいことは何ですか | 期待されている役割 |
| 中途で入られた方は、どの職種に多いですか | **受け入れの実績** |

**1つ目は、必ず聞いてください。**この業界では、**勤務地が変わる異動がある**ためです。

:::insight
ここまで対策の話をしてきましたが、**こちらからも見るべき点**があります。**面接で、こちらの質問にどう答えるか**です。とくに、**勤務地と出張の質問への答え方**を見ておいてください。具体的な実例を挙げて答えてくれる会社と、**「人によりますね」で終わる会社**では、入ったあとの見通しの立てやすさが違います。**求人票の記載は正確でなければならない**という職業安定法第5条の4の建て付けからしても、**確認に対して曖昧な答えしか返らないのは、こちらの判断材料**になります。それから、**選考の進め方そのもの**も見てください。次の面接の日程を示してくれるか、結論の時期を伝えてくれるか。**この2つが揃わない会社は、入ったあとの進め方も同じ**である可能性があります。選考は、**採点されるだけの場ではありません。**そして、**合わないと判断して辞退することは、失礼ではありません。**受けてみて確かめた結果、**いまの職に残るという結論**になることもあります。それも、**情報が増えたうえでの判断**です。当社が、いまの職を辞めることをお勧めすることはありません。
:::

## まとめ

- **入り口は「商社」ではなく「職種」**です。**新卒でしか入れないわけではありません**
- **職業安定法第5条の4第1項**は、求人等に関する情報について**虚偽の表示又は誤解を生じさせる表示をしてはならない**と定め、**同条第2項**は**正確かつ最新の内容に保たなければならない**と定めています。**記載との食い違いを確認するのは、当然の行為**です
- **労働施策総合推進法第9条**は、**年齢にかかわりなく均等な機会を与えなければならない**と定めています。**見るべきは年齢ではなく、求められている経験の年数**です
- 選考は**書類と面接**で、**筆記試験は無いか軽い**です。**そのぶん職務経歴書の比重が大きくなります**
- **上位のポジションほど、決裁の段階が増えて期間が延びます。**連絡が来ないのは落選の合図とは限りません
- 見られている観点は、**①機能の説明 ②数字への理解 ③間に立てるか ④前提の確認 ⑤立ち上がりの速さ**の5つです
- **「担当していました」ではなく「何が変わったか」**で答えてください。**自分が来る前と去ったあとの違い**を探します
- **面接は、こちらが会社を見る場**でもあります。勤務地の質問への答え方を見てください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 在職中です。面接の日程は調整してもらえますか

**調整してもらえることが多いです。**中途採用では、**在職中の応募が前提**になっているためです。一次面接をオンラインで行う、平日の夜や土曜に設定する、といった対応も一般的です。**申し出るときは、希望の時間帯を先に示すほうが早く決まります。**「平日の18時以降、または土曜であれば伺えます」という形です。なお、**役員が出てくる面接は、役員の都合に左右されます。**候補の日を複数もらったら、**早めに返すほうが調整が楽**です。日程の詰め方も、**調整の手際として見られています。**あわせて、**現職の繁忙期は先に伝えておいてください。**予算や決算の時期に集中して面接が入ると、どちらも中途半端になります。

### 職務経歴書に、扱った金額を書いてよいですか

**公表されている範囲であれば書けます。**予算書・決算書は公表されているので、**自分が担当した事業の規模は、公表資料の範囲で示せます。**契約の金額も、**入札の結果が公表されているもの**であれば同様です。**⚠ 公表されていない内部の数字や、個別の相手方の事情は書かないでください。**守秘の観点に加えて、**それを書く人は、次の職場の情報も外で話す**と見られます。判断に迷うときは、**規模を丸めて書く**方法があります。「◯億円規模の案件」「年間◯件程度」。**精度より、規模感が伝わることのほうが重要**です。

### 複数の商社を並行して受けても問題ありませんか

**問題ありません。**中途採用では一般的です。むしろ、**1社に絞ると、志望動機の③（なぜ行政ではないか）を言葉にする機会が減ります。**進め方のこつは、**日程を少しずらすこと**です。同じ週に最終面接が重なると、条件を比べる時間が取れません。**いちばん行きたい会社を、意図的に後ろに置く**という組み方もあります。なお、**選考が進んでいる会社があることは、聞かれたら正直に伝えて構いません。**隠す必要はなく、**結論の時期の調整を相談できる**という利点のほうが大きいです。伝え方は、**会社名を出さずに「他社の選考も進んでいます」**で足ります。
