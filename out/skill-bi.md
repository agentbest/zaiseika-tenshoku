**統計や財政の数字を扱ってきた方から、「可視化の仕事に移れるか」**というご相談を伺います。

**数字を伝わる形にする経験は、すでに積んでいます。**

この記事では、**接続の仕方**と、**足すべき技術**を扱います。

## 財政の状況は、住民に公表するものです

**地方自治法第243条の3第1項**です。

> **普通地方公共団体の長は、条例の定めるところにより、毎年二回以上歳入歳出予算の執行状況並びに財産、地方債及び一時借入金の現在高その他財政に関する事項を住民に公表しなければならない。**

**「毎年二回以上」「住民に公表しなければならない」**と定められています。

**公表の相手は、専門家ではなく住民**です。

**つまり、専門的な数字を、専門でない相手に伝わる形にする**ことが求められます。

**これが、可視化の目的そのもの**です。

**行政で公表の資料を作ってきた方は、この作業を経験しています。**

## 可視化で行うこと

| 工程 | 内容 |
|---|---|
| ① 目的を決める | **誰に、何を分かってほしいか** |
| ② データを集める | 出所、定義、期間 |
| ③ 整える | 集計、結合、欠損の扱い |
| ④ 図を選ぶ | 推移、構成、比較、分布 |
| ⑤ 見せ方を決める | 並び、色、注記 |
| ⑥ 更新の仕組み | 定期の更新をどうするか |

**①と④が中心**です。

**④について。**

**推移は折れ線、構成は帯や円、比較は棒、分布は別の形。**

**目的に応じて図の種類が決まります。**

**行政の公表資料でも、この選択をしてきたはず**です。

## 行政で身についていること

| 経験 | 可視化での使いどころ |
|---|---|
| ① データの出所の確認 | **どの統計、どの年度か** |
| ② 定義の確認 | 何を数えたものか |
| ③ 経年と他団体との比較 | 推移と比較の設計 |
| ④ 専門でない相手への説明 | **伝わる形にする** |
| ⑤ 公表の配慮 | 個人が特定されない形に |
| ⑥ 定期の更新 | 毎年・毎四半期の作業 |

**④が、最も価値がある部分**です。

**財政の指標を、住民向けの広報紙に載せる。**

**この作業は、専門的な数字を翻訳する仕事**です。

**民間でも、同じことが求められます。**

## 足すべき技術

| 技術 | 内容 |
|---|---|
| ① ツールの操作 | **表計算の外に出る** |
| ② データの整形 | 縦横の変換、結合 |
| ③ 更新の自動化 | 手作業を減らす |
| ④ 見る人に合わせる | 経営層、現場、顧客 |
| ⑤ 指標の設計 | 何を見れば判断できるか |
| ⑥ 共有の仕組み | 誰がいつ見るか |

**③が、民間との違いが出る部分**です。

**行政では、年に数回の公表のために、その都度作る**ことがあります。

**民間では、毎日や毎週見るため、更新の自動化が前提**になります。

**⑤について。**

**「何を見れば判断できるか」を決めるのが、指標の設計**です。

**財政の指標を扱ってきた方は、この考え方を持っています。**

## 書き方の例

**悪い例**

> 統計データの集計と、グラフの作成を担当しました。

**良い例**

> ◯◯に関する財政の状況について、**年◯回の公表資料を作成。**歳入歳出の執行の状況と、**過去◯年の推移、類似する団体との比較**を図に整理。**専門的な用語を用いずに説明する注記を付し、広報紙とウェブで公表。**集計の手順を**表計算の様式として整備し、担当が交代しても同じ形で作成できるように運用。**

**「回数」「比較の設計」「伝え方」「再現できる仕組み」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

:::insight
可視化について、**面談でお伝えしているのが「翻訳した経験を書いてください」**という点です。**「グラフを作成」と書かれても、水準が分かりません。**ところが、**「専門的な指標を、住民に分かる言葉と図に置き換えて公表した」**と書かれていると、**目的が伝わります。**そして、**この翻訳の作業は、民間でも必要とされています。**経営層は細かい数字を見る時間がない、現場は自分の担当の範囲しか見ない、顧客は専門用語を知らない。**相手に応じて、見せ方を変える必要があります。**行政では、**住民という最も幅の広い相手に向けて公表する義務**があるため、この訓練を受けています。書類には、**「専門的な用語を用いずに説明する注記を付した」「図の種類を目的に応じて選んだ」**と書いてください。**ツールの名前より、この判断のほうが評価されます。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## どこまで学ぶか

| 目的 | 必要な範囲 |
|---|---|
| 会社の資料を読む | **図の読み方で足ります** |
| 業務で集計と図を作る | ツールの操作 |
| 可視化を職種とする | ①〜⑥を体系的に |

**求人によって、求められる範囲が違います。**

**「データの可視化」と書かれていても、集計が中心の業務**と、**指標の設計から担う業務**では、必要なものが違います。

**求人票の仕事内容の欄で確認**してください。

**読み方は**[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)**に整理しています。**

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 自治体向けの事業 | **公的なデータの扱いが分かる** |
| ② 調査・分析 | 図の設計 |
| ③ 事業の企画 | 指標の設計 |
| ④ 管理部門 | 定期の報告 |
| ⑤ 広報 | 対外の発信 |

**①について。**

**自治体を顧客とする事業では、公表されているデータを使う場面**があります。

**どの資料に何が載っているか、定義や公表の時期がどうなっているか。**

**この理解は、外から入った人には時間がかかります。**

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 作った資料と相手 | **誰に向けたものか** |
| 図の選び方 | 目的と図の対応 |
| 定義の確認 | 何を確かめたか |
| 更新の仕組み | 再現できる形か |
| 使えるツール | **正確に、範囲を明示して** |

**5行目です。**

**できないことを書くと、入社後に困ります。**

**「表計算で、関数と集計の機能を用いた集計・作図の経験あり」**という形で、範囲を明示してください。

## 学ぶ前に考えること

| 確認すること | 内容 |
|---|---|
| ① すでにある経験 | **公表資料、統計、財政の資料** |
| ② 目的 | 読むためか、業務で担うためか |
| ③ 応募したい求人の範囲 | 集計中心か、設計からか |
| ④ 期限 | 応募の時期までに間に合うか |

**なお、ツールを覚えれば転職できる、という関係にはありません。**

**誰に向けて、何を、どう伝えてきたか**が、評価の対象です。

## よくある失敗

**1. 「グラフを作成」とだけ書く**

**目的と相手**を書いてください。

**2. 翻訳した経験に触れない**

**最も価値がある部分**です。

**3. 図の選び方を書かない**

**目的と図の対応**が判断です。

**4. 定義の確認に触れない**

**数字の扱いの確かさ**が伝わります。

**5. 更新の仕組みを書かない**

**再現できる形か**が見られます。

**6. 使えるツールを広く書く**

**範囲を明示**してください。

**7. 求人の範囲を確認しない**

**集計中心か設計からか**で違います。

**8. ツールを覚えれば進めると考える**

**誰に何を伝えたか**が評価の対象です。

:::insight
ここまで技術の話をしておいて逆のことを言いますが、**可視化で最も避けたいのは、誤解を招く図です。**面談で拝見していると、**見栄えを優先して、軸の起点を動かす、単位を揃えない、期間を切り取る**といった図を作ってしまう例があります。行政では、**公表する資料であるため、この操作は許されません。**軸を動かせば差が大きく見え、期間を切り取れば傾向が変わる。**受け取る側の判断を誤らせます。**そして、**民間でも、これは信用の問題です。**社内の報告で誤った印象を与えれば、判断が狂う。顧客への資料で誇張すれば、後から問題になる。**行政で身につけた「正確に見せる」感覚は、そのまま価値になります。**書類には、**「比較の条件を揃えたうえで作図」**と書いてください。**見栄えより、正確さを優先してきた**ことは、強みとして書けます。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方自治法第243条の3第1項**は、**毎年二回以上、歳入歳出予算の執行状況、財産、地方債及び一時借入金の現在高その他財政に関する事項を住民に公表しなければならない**としています
- **公表の相手は住民**です。**専門的な数字を、専門でない相手に伝わる形にする**経験を積んでいます
- 可視化の工程は、**①目的 ②収集 ③整形 ④図の選択 ⑤見せ方 ⑥更新**です
- 行政で身につくのは、**出所と定義の確認、経年と他団体の比較、翻訳、公表の配慮**です
- 足すのは、**ツール、整形、更新の自動化、相手に合わせること、指標の設計**です
- **翻訳した経験**を書いてください。ツールの名前より評価されます
- **誤解を招く図を作らない**という感覚は、そのまま価値になります

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 専用のツールを使ったことがありません

**表計算の経験から書いてください。**集計、関数、作図、様式の整備。**これらは、業務としては同じ作業**です。求人票の応募条件で、**特定のツールが必須とされているか**を確認してください。「必須」であれば、その経験が要ります。「歓迎」であれば、**表計算の経験で応募できる**ことがあります。なお、**ツールは考え方が共通している**部分があります。「表計算で、集計の手順を様式として整備した経験があります」と書けば、**判断の材料になります。**できないことは書かないでください。

### 財政の数字を扱っていませんでした

**扱った数字で書いてください。**申請や届出の件数、利用者の数、事業の実績、検査の件数。**どの分野でも、数字を集計し、公表や報告に使っている**はずです。書き方は、**「◯◯の実績について、年◯回の集計を担当し、推移を図に整理して報告に使用」**という形です。**財政に限りません。**なお、**公表された資料に載った数字**であれば、**作成に関わった事実を書ける**ことがあります。判断に迷う場合は、**内容に触れず、作業の説明にとどめて**ください。

### 指標の設計とは、何をするのですか

**「何を見れば判断できるか」を決める作業**です。たとえば、窓口の業務であれば、**処理の件数だけでなく、待ち時間、再来の割合、不備の率**を見ることで、状況が分かります。**どれを見るかを決めるのが、設計**です。行政でも、**事業の評価の指標を設定した経験**があれば、同じ作業です。「事業の評価にあたり、◯◯を指標として設定し、年度ごとに測定」という形で書けます。**数字を並べるのではなく、判断に使える数字を選ぶ。****この考え方が、民間でも求められます。**
