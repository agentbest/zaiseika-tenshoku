総務課から転職しようとすると、最初にこう思う方が多くいます。

**「自分は何の専門家でもない」**

文書、例規、情報公開、不服審査、選挙、庁内の取りまとめ。**どれも自治体特有の仕事に見えて、民間に対応する職種が思い浮かびません。**

ただ、これは言葉の問題です。**総務課の仕事は、民間でいう法務・コンプライアンス・内部統制・総務の領域にきれいに対応します。**言い換えができていないだけです。

この記事では、総務課の仕事を分解して、それぞれが求人票でどう書かれているかを並べます。

## 記録は「あとから説明する」ためにあります

先に、この部署の中心にある考え方を条文で押さえます。

公文書等の管理に関する法律第1条は、この法律が、国及び独立行政法人等の諸活動や歴史的事実の記録である公文書等が、**健全な民主主義の根幹を支える国民共有の知的資源**として、主権者である国民が主体的に利用し得るものであることにかんがみ、公文書等の管理に関する基本的事項を定めること等により、行政文書等の適正な管理、歴史公文書等の適切な保存及び利用等を図り、もって行政が適正かつ効率的に運営されるようにするとともに、**国及び独立行政法人等の有するその諸活動を現在及び将来の国民に説明する責務が全うされるようにする**ことを目的とすると定めています。

**記録は、あとから説明するためにある。**

これが、文書管理の根っこにある考え方です。整理のためでも、保管のためでもありません。**説明を求められたときに、出せる状態にしておくためです。**

なお、この法律の直接の対象は国と独立行政法人等です。地方公共団体については、第34条が**この法律の趣旨にのっとり、その保有する文書の適正な管理に関して必要な施策を策定し、及びこれを実施するよう努めなければならない**としています。**努力義務ですが、趣旨は共通です。**

だから多くの自治体が、文書管理規程と保存年限を定め、廃棄の手続を置いています。**総務課は、その仕組みを作って回している部署です。**

## 総務課が実際にやっていること

自治体によって所管の範囲はかなり違いますが、おおむね次の仕事が入ります。

- 文書の収受・配布・発送、公印の管理
- 文書管理規程の整備、保存年限の設定、廃棄の手続
- 例規の整備（条例・規則の審査、法制執務、例規集の管理）
- 議案の取りまとめ、議会との連絡
- 情報公開請求への対応、個人情報の開示請求への対応
- 審査請求（行政不服審査）の手続、審理員・審査会との調整
- 訴訟の対応、顧問弁護士との連絡
- 行政区域や住居表示に関する事務
- 選挙管理委員会事務局の事務（自治体による）
- 庁内の照会・取りまとめ、全庁的な事務連絡
- 表彰、儀式、慶弔

**共通しているのは、どれも「手続そのもの」を扱う仕事**だということです。事業をするのではなく、**事業が正しい形で行われるようにする**部署です。

この性格は、民間の管理部門と同じです。ただ、**自治体の総務課はこれらを1つの課で抱えている**ぶん、範囲が広くなります。企業では、法務と総務と記録管理が別のチームに分かれていることが普通です。

## 庁内の言葉と、求人票の言葉の対応

| 庁内での言い方 | 求人票での言い方 |
|---|---|
| 文書の収受・発送、公印の管理 | 総務、文書管理、押印・契約書の管理 |
| 文書管理規程の整備、保存年限 | 文書管理、記録管理、規程整備 |
| 文書の廃棄の手続 | 記録の保存期間管理、廃棄の統制 |
| 例規の審査、法制執務 | 法務、規程整備、契約審査 |
| 条例・規則の改正 | 社内規程の改定、ルールメイキング |
| 議案の取りまとめ | 取締役会・株主総会の事務局 |
| 情報公開請求への対応 | 開示対応、情報開示、広報法務 |
| 個人情報の開示請求 | 個人情報保護、データガバナンス |
| 審査請求の手続 | 係争対応、苦情対応、コンプライアンス |
| 訴訟の対応 | 法務、係争対応 |
| 顧問弁護士との連絡 | 法務、外部専門家の管理 |
| 庁内の照会・取りまとめ | 全社横断の調整、事務局機能 |
| 選挙の管理執行 | 大規模イベントの運営、オペレーション管理 |

並べると、**法務・コンプライアンス・記録管理・事務局機能の4領域にまたがっている**ことが分かります。

:::insight
総務課の方の書類で、いちばんもったいないのが**「庶務」「事務全般」と書いてしまうこと**です。この言葉は、民間では**指示された作業をこなす役割**として読まれます。実際にやっていたのは、**規程を作り、手続を設計し、外部からの請求に応え、争いになったときに対応する**仕事です。**求人票の言葉でいえば「法務」「コンプライアンス」「規程整備」「記録管理」にあたります。**とくに**例規の審査を担当していた方は、法務の求人を見ていないことが多い**です。条例の条文を書き、他の例規との整合を確認し、上位法に反していないかを見る。これは民間の契約審査や規程整備と、やっていることが同じです。検索する語を変えるだけで、出てくる求人の層が変わります。
:::

## 民間の法務・総務と、どこが同じでどこが違うか

**同じところ**

- 規程を作り、改定し、周知する
- 外部からの請求や問い合わせに、期限内に応える
- 記録を残し、保存期間を決め、期限が来たら廃棄する
- 争いになったときに、事実関係を整理して外部の専門家と対応する
- 全部署に照会をかけ、回答を取りまとめる

**違うところ**

- **開示請求に応じる義務が法令で定められている**（民間は原則として応じる義務がない）
- **不服申立ての手続が制度として用意されている**（行政不服審査の仕組み）
- **規程の改正に議会の議決が要るものがある**（条例）
- **文書の保存年限と廃棄の手続が規程で厳格に決まっている**
- **選挙という、期日が動かない大規模な事務を抱えることがある**

この5つのうち、面接でいちばん効くのは**1つ目**です。**「請求されたら応える」が前提の環境で仕事をしてきた**人は多くありません。

**「出す前提で記録を残してきた」**という説明は、開示や監査への対応が重い企業には強く響きます。

## この経験がとくに高く評価される場所

### 1. 事業会社の法務・コンプライアンス

例規の審査、条例の改正、訴訟の対応を担当していた方の接続先です。

企業側では、法務、規程整備、コンプライアンスといった職種になります。**条文を読み、書き、整合を確認する**という作業は、契約審査や社内規程の改定とそのまま重なります。

**資格がなくても入れる求人がある領域**でもあります。法務の実務経験として読まれるからです。

### 2. 内部統制・記録管理

文書管理規程の整備、保存年限の設定、廃棄の手続を担当していた方の接続先です。

企業側では、内部統制、記録管理、監査対応といった職種になります。**「あとから説明できる状態にしておく」という考え方を制度として運用してきた経験**は、監査や開示が重い業種で直接使えます。

### 3. 事務局機能・総務

議案の取りまとめや庁内の照会を担当していた方の接続先です。

企業側では、総務、株主総会・取締役会の事務局、社内の横断的な調整といった職種になります。**全部署に照会をかけて期限内に取りまとめる**という仕事は、どの企業にもあります。

[財政・会計の経験が効く求人を見てみる](../?fin=1)

### 4. 自治体を顧客にする企業

文書管理システム、例規システム、選挙の支援を行う会社です。

**文書の流れ、決裁の段数、保存年限の実際、例規の改正の手順**を知っていることが値になります。外から見ただけでは分かりません。

## 「例規の審査」を、もう少し分解しておきます

総務課の経験のなかで、いちばん値が付きやすいのに説明されていないのが例規です。分解しておきます。

**1. 上位法との整合を確認する**

条例が法律に反していないか。規則が条例の委任の範囲を超えていないか。**民間でいえば、社内規程が法令や上位の規程に反していないかを確認する作業です。**

**2. 庁内の他の例規との整合を確認する**

同じ言葉が別の例規で違う意味で使われていないか。改正すると他の例規の引用がずれないか。**規程が数百本ある組織では、これが常に問題になります。**

**3. 条文を書く**

要件と効果を分けて書く。「ものとする」と「しなければならない」を使い分ける。ただし書きの位置を決める。**この作業ができる人は、企業の法務でも限られます。**

**4. 改正の手続を通す**

条例なら議会の議決、規則なら長の決裁。**施行日を決め、経過措置を置き、関係する例規を同時に改正する。**この段取りは、企業の規程改定とほぼ同じです。

**5. 施行後の照会に答える**

現場から「この場合はどう扱うのか」と聞かれ、条文の解釈を示します。**書いた人が答えられなければ、その規程は運用されません。**

書類には、**この5つのうちどこを担当したか**を書いてください。「例規を担当」ではなく、「条例◯件の改正を、条文の作成から議会の議決まで担当した」と書けると、法務の実務経験として読まれます。

## 職務経歴書でつまずきやすい点

**1. 「庶務」「事務全般」と書く**

**領域の名前に置き換えてください。**法務、規程整備、記録管理、事務局。

**2. 規模を書かない**

**扱った文書の件数、例規の改正件数、開示請求の件数、審査請求の件数、照会の対象部署数。**規模が伝わる数字を必ず入れてください。

**3. 例規の仕事を落とす**

いちばんもったいない部分です。**条文を書いた経験は、法務の実務経験として読まれます。**

**4. 選挙の経験を書かない**

**期日が動かない大規模な事務**を回した経験です。投票所の数、従事者の人数、期日前投票の期間。**オペレーション管理の実績として書けます。**

**5. 個別の請求や争訟の中身を書く**

これは避けてください。**手続と判断の構造で書きます。**請求者や相手方が特定できる書き方はしないでください。

自分の経歴がどう言い換えられるかは、一度話しながら整理したほうが早いことが多いです。[どの経験に値が付くのかから相談できます](../apply.html)。

:::insight
ここまで書いておいて逆のことを言いますが、**総務課にいるうちに動かないほうがよい場合もあります。**とくに、**例規の審査をまだ通しで担当していない段階**です。条例の改正を、起案から議会の議決まで通すと、書けることが大きく変わります。**「例規の管理を担当」と「条例の改正を◯件通した」では、読まれ方が違います。**もう一つ、**選挙を一度も経験していないなら、それも待つ価値があります。**期日が動かない大規模な事務は、民間でも代わりのいない経験です。異動の希望が出せる時期なら、そちらを先に確かめるのも十分に理のある判断です。
:::

## まとめ

- 公文書管理法第1条は、公文書を**「諸活動を現在及び将来の国民に説明する責務」**を全うするためのものと位置づけています。**記録は、あとから説明するためにあります**
- 地方公共団体については第34条が**この法律の趣旨にのっとった施策の策定と実施を努力義務**としています
- 総務課の仕事は、**法務・コンプライアンス・記録管理・事務局機能**の4領域にまたがっています
- 庁内の「庶務」は、求人票では**「法務」「規程整備」「記録管理」「内部統制」**と書かれています。**検索する言葉を変えるところから始めてください**
- 民間との最大の違いは、**開示請求に応じる義務が法令で定められていること**です。**「出す前提で記録を残してきた」**という説明が強く効きます
- **例規の仕事と選挙の経験を落とさないでください。**どちらも代わりのいない材料です

在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。

## よくある質問

### 法学部卒でなくても、法務の求人に応募できますか

できます。**法務の求人で見られるのは、条文を読んで整合を確認できるかどうか**です。例規の審査を担当していたなら、その作業を日常的にやってきたことになります。ただし、**民法や会社法の知識は別に要ります。**入ってから学ぶ前提で応募することになるので、**面接では「行政法の実務は経験したが、民事の領域は学び直しが要る」と正確に言ってください。**

### 選挙の経験は、民間で評価されますか

**評価されます。**期日が1日も動かない、従事者が数百人規模になる、やり直しが利かない。**この条件で大規模な事務を回した経験は、民間でも代わりがいません。**書くときは、投票所の数、従事者の人数、期日前投票の期間、開票の所要時間といった**規模と時間の数字**を必ず添えてください。「選挙事務を担当」だけでは伝わりません。

### 総務課は範囲が広すぎて、専門性がないと言われませんか

**書き方で変わります。**「事務全般」と書けばそう見えますが、**担当した領域を選んで書けば専門性は説明できます。**例規、記録管理、開示対応、争訟対応、選挙。どれも民間に対応する職種があります。**応募先の領域を先に決めて、その領域の経験を先頭に置いてください。**範囲の広さは、最後に1行で添えると効きます。
