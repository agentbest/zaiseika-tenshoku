NPO・公益法人の選考で、**落ちた理由が志望動機だった**というご相談を、繰り返し伺います。

**「社会に貢献したいと申し上げたのですが、それでは弱いと言われました」**

**弱いのは、気持ちではありません。****接続の仕方**です。

**「社会に貢献したい」は、その法人でなくても成り立ちます。**同じ文章が、**別の法人にも、いまの役所にも当てはまる。**選考する側は、そこを見ています。

この記事では、**志望動機を3つの層に分けて、それぞれの材料をどこから取るか**を扱います。未経験から入る道筋は[NPO・公益法人に未経験から入るには](industry-npo-mikeiken.html)、条件の確かめ方は[NPO・公益法人の年収と働き方](industry-npo-nenshu.html)にあります。

## 法人の側は、事業の範囲を自分で決められません

**志望動機を組み立てる前に、相手の制約を知っておいてください。**

**特定非営利活動促進法第3条**です。

> **（原則）第三条　特定非営利活動法人は、特定の個人又は法人その他の団体の利益を目的として、その事業を行ってはならない。**
>
> **２　特定非営利活動法人は、これを特定の政党のために利用してはならない。**

**短い条文ですが、この法人格の性格を決めています。**

**特定の誰かのために事業を行ってはならない。**つまり、**「誰の利益のために動くか」が、法律の段階で縛られている**ということです。

そして、**同法第2条第1項**は、**特定非営利活動を「別表に掲げる活動に該当する活動であって、不特定かつ多数のものの利益の増進に寄与することを目的とするもの」**と定義しています。**別表**に活動の分野が列挙されていて、**定款に書いた分野の事業を行う**という建て付けです。

**公益法人も同じ構造**です。**公益認定法第5条第1号**は、**「公益目的事業を行うことを主たる目的とするものであること」**を認定の基準に挙げています。

**この2つが意味するのは、法人の側には「何でもやります」という選択肢が無い**ということです。

**ですから、志望動機も「何でもやります」では噛み合いません。****定款に書かれた事業の、どれに関わりたいのか**が問われます。

## 志望動機は、3つの層に分けます

| 層 | 問い | 材料の出どころ |
|---|---|---|
| ① 分野 | **なぜ、この分野なのか** | 自分の担当した業務の経験 |
| ② 法人 | **なぜ、この法人なのか** | 定款・事業報告書・事業計画書 |
| ③ 立場 | **なぜ、行政ではなくこの法人なのか** | **自分の考えの変化** |

**多くの方が①だけを書いて出されます。**①は必要ですが、**①だけだと、同じ分野の他の法人にもそのまま出せる文章**になります。

**そして、いちばん問われるのは③**です。

## ① 分野を選んだ理由は、経験から取ります

**ここは、役所での担当がそのまま材料になります。**

| 担当してきたこと | 接続できる分野 |
|---|---|
| 生活保護、生活困窮者の相談 | 福祉、就労の支援、子どもの居場所 |
| 児童福祉、保育の認可・指導 | 子育て、子どもの貧困、里親の支援 |
| 環境、廃棄物、公害 | 環境の保全、資源の循環、自然の保護 |
| 商工、観光、農林 | まちづくり、地域の産業、観光の振興 |
| 国際交流、多文化共生 | 国際協力、外国人住民の支援 |
| 防災、危機管理 | 災害の支援、被災地の復興 |
| 文化、スポーツ、生涯学習 | 文化・芸術の振興、スポーツの振興 |

**書き方は、「関心があります」ではなく「何を見たか」**です。

> 生活困窮者自立支援の窓口を担当し、相談に来られた方のうち、制度の要件に当てはまらない方が一定数いることを実務として把握していました。制度の外側を受け止める機能が地域に要ると考えるようになり、その機能を担っている法人を探していました。

**「見たことがある」は、強い材料です。**役所の窓口は、**その分野で何が起きているかを、いちばん近くで見る場所**です。

## ② 法人を選んだ理由は、公表資料から取ります

**ここで差が付きます。**

**法人の資料は、外から読めます。**[年収と働き方の記事](industry-npo-nenshu.html)でも触れましたが、**定款、事業報告書、事業計画書、計算書類**は、備置きと閲覧の定めがあり、**多くの法人は公式サイトに置いています。**

| 資料 | 志望動機に使える材料 |
|---|---|
| 定款 | **事業の範囲。**どこまでを自分たちの仕事と定義しているか |
| 事業報告書 | **前年度に実際にやったこと。**計画との差 |
| 事業計画書 | **これから増やそうとしていること** |
| 計算書類 | 収入の構成。どの事業に力を入れているか |
| 理事の名簿 | どういう分野の人で運営されているか |

**使い方は、「読みました」ではなく「読んで、どこに反応したか」**です。

> 事業報告書を拝見し、相談の件数が前年度から増える一方で、継続して関わる件数の割合が下がっていると記載されている点が気になりました。窓口で同じ課題を見ていたので、入口を広げたあとに継続の体制が追いつかない状況は想像がつきます。その部分の仕組みを整える仕事であれば、自分の経験が使えると考えました。

**この書き方は、相手の資料を読んでいないと書けません。**そこが伝わります。

**なお、批判的な読み方にならないよう気をつけてください。**「課題がある」と指摘する形ではなく、**「同じ課題を自分も見てきた」**という並びに置くと、**外から採点する立場になりません。**

## ③ 行政ではなく、この法人である理由

**公務員から応募する場合、必ず聞かれます。**

**聞かれている中身は2つ**です。

| 相手の懸念 | 確認したいこと |
|---|---|
| **行政に戻りたくなるのではないか** | 一時的な感情で動いていないか |
| **行政の目線のまま来るのではないか** | 法人の側に立てるか |

**答え方には、使える型があります。**

**「制度の側でできることと、できないことの線を見た」**という形です。

> 制度は、要件を定めて公平に配分する仕組みです。要件を定めるからこそ公平が保てる一方で、要件の外側に残る方がいます。窓口にいた◯年間、そこを見てきました。制度の設計を担う側にいた経験は、制度の外側を受け止める側でも使えると考えています。行政を否定するつもりはなく、役割が違うという整理です。

**この型の良いところは、行政を否定していない**ことです。

**⚠ 役所の批判から入る志望動機は、避けてください。**「役所では動きが遅いので」「縦割りで何もできないので」という書き出しは、**相手の側から見ると、次は法人の悪いところを外で言う人に見えます。**

**もうひとつの型は、「関わる段階を変えたい」**です。

> 補助金を交付する側として、年度末の実績報告で結果を見ていました。見ていたのは結果だけで、その間に何があったかは書類からしか分かりません。交付の仕組みを知っている立場で、実施する側に回りたいと考えました。

**どちらの型も、共通しているのは「行政の経験を使う前提で書いている」**ことです。**捨てて来る話にしないでください。**

:::insight
面接に同席させていただいていて、**③で評価が分かれる瞬間**があります。分かれ目は、**「行政の側の事情を、どこまで言えるか」**です。よくあるのは、**行政の側を悪く言わないように気をつけるあまり、当たり障りのない説明で終わってしまう**形です。これは安全ですが、**印象に残りません。**一方で評価される方は、**行政の側の制約を、制度として説明されます。**「予算は年度で区切られるので、年度をまたぐ支援は仕組みとして組みにくい」「公平性を担保するために要件を定めるので、要件の外は制度として拾えない」。**事実として説明しているだけで、批判になっていません。**そして、この説明ができる方は、**法人に入ったあとに行政と協議する場面で、そのまま戦力になります。**相手が何を根拠に断っているのかが分かるからです。法人の側は、**行政に要望を出しても通らない経験を重ねています。**「なぜ通らないのかを説明できる人」は、**その時点で欲しい人材**です。志望動機は、**入ったあとの働きぶりの予告**として聞かれています。
:::

## 公務員の経験が効く場所・効きにくい場所

**志望動機に書ける形で、整理しておきます。**

**効く場所**

| 経験 | 志望動機での書き方 |
|---|---|
| 補助金の交付事務 | **申請する側に回っても、審査の観点が分かる** |
| 委託の発注と検査 | 受託する側での報告の作り方が読める |
| 要綱・規程の作成 | **法人の内部の規程を整える仕事につながる** |
| 審議会・委員会の事務 | 理事会・評議員会の運営に重なる |
| 窓口での相談 | **その分野で何が起きているかを見てきた** |
| 議会への説明 | 会員・寄附者・行政への説明に形が近い |

**効きにくい場所**

| 経験の不足 | 面接での扱い方 |
|---|---|
| 寄附を集めた経験 | **無いことを認めたうえで、覚える前提で話す** |
| 会員を増やした経験 | 継続的な関係作りは、入ってから学ぶ領域 |
| 収支の責任を負った経験 | 予算の執行と、収入を作ることは別 |
| 少人数で兼務した経験 | 分掌の外を拾う働き方への構え |

**効きにくい場所は、隠さないほうが通ります。****「できます」と言って入ったあとに差が出るより、最初に整理しておくほうが双方にとって良い**からです。

## 材料を集める順番

**3〜4時間でできます。**

| 順 | やること |
|---|---|
| 1 | 自分の担当した業務を書き出し、**分野を2つに絞る** |
| 2 | その分野の法人を、公式サイトで**5法人**見る |
| 3 | 候補の法人の**定款と事業報告書**を読む |
| 4 | **反応した記述を、1法人につき2つ**書き出す |
| 5 | ③の型（線を見た／段階を変えたい）の**どちらで書くか**を決める |
| 6 | ①②③を**つなげて300字**にまとめる |

**4つ目が、いちばん効きます。**読んで何も反応しなかった法人は、**志望動機を書くのが苦しくなります。**それは、**相性の情報**として受け取ってください。

**なお、法人の数は多くありません。**同じ分野で5法人を比べると、**やり方の違いがはっきり見えます。**「直接の支援が中心か、中間支援か」「行政からの委託が中心か、自主事業が中心か」。**その違いに、自分がどう反応するか**が、②の材料になります。

[経験の言い換えから相談する](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担です）。

## 面接で聞かれやすいこと

| 聞かれること | 何を確かめられているか |
|---|---|
| なぜ、いま動くのですか | **一時的な感情で動いていないか** |
| 行政に戻る可能性はありますか | 定着の見込み |
| うちの事業のどれに関わりたいですか | **定款・事業報告書を読んできたか** |
| 行政との協議で、どちらの立場に立ちますか | 法人の側に立てるか |
| 前の職場の、どこが合わなかったのですか | **人の話をどう扱う人か** |

**5つ目は、答え方に気をつけてください。**特定の人物の話にせず、**仕組みの話に置き換える**のが安全です。

**「合わなかった」ではなく「担える役割が変わってきた」**という整理のほうが、話が前に進みます。

:::insight
ここまで組み立て方の話をしてきましたが、**逆のことも申し上げておきます。**志望動機を整えきってから応募しようとして、**動き出しが止まってしまう方**が、少なからずいらっしゃいます。実際には、**①と②の材料を集めた段階で、一度応募して構いません。**理由は、**③が、選考の過程で固まるから**です。面接で「なぜ行政ではないのか」を問われて、**答えながら自分の考えが整理される**ということが、よく起こります。1社目で言葉にできなかったことが、**3社目では言える**ようになる。これは珍しくありません。ですから、**いちばん行きたい法人を1社目にしない**というのが、実務上のこつです。同じ分野で、**関心はあるが第一志望ではない法人**から受けてください。そして、**いま動くかどうかを決めきらないまま、資料を読むところまでやっておく**のも、十分に意味があります。定款と事業報告書の読み方は、**その法人を受けるかどうかと関係なく身に付きます。**在職のまま、材料集めだけのご相談も承っています。
:::

## まとめ

- **「社会に貢献したい」は、その法人でなくても成り立ちます。**接続の仕方を変えてください
- **特定非営利活動促進法第3条**は、**特定の個人・団体の利益を目的として事業を行ってはならない**、**特定の政党のために利用してはならない**と定めています
- **同法第2条第1項**は、特定非営利活動を**「不特定かつ多数のものの利益の増進に寄与することを目的とするもの」**と定義しています。**公益認定法第5条第1号**も、**公益目的事業を主たる目的とすること**を基準に挙げています
- **法人の側に「何でもやります」という選択肢が無い**ので、志望動機も**定款に書かれた事業のどれに関わるか**で書きます
- 志望動機は、**①分野 ②法人 ③行政ではない理由**の3層に分けます。**③がいちばん問われます**
- ②の材料は、**定款・事業報告書・事業計画書・計算書類**から取ります。**読んでどこに反応したか**を書いてください
- ③は、**「制度の線を見た」か「関わる段階を変えたい」**の型で書きます。**役所の批判から入らない**でください
- **効きにくい経験は、隠さずに、覚える前提で話す**ほうが通ります

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### その分野の活動経験がありません。志望動機として弱くなりますか

**弱くはなりません。**ただし、**「関心があります」だけで止めない**でください。**業務として何を見たかに置き換えてください。**窓口で相談を受けた、許認可で現場を見た、補助金を交付して実績報告を読んだ。**どれも、その分野に業務として関わった経験です。**活動の経験が無いことは、**面接で正直に言って構いません。**そのうえで、**「見てきた側から、実施する側に回りたい」**という並びにすると、経験の無さが欠点ではなく**視点の違い**として扱われます。なお、**ボランティアとして関わってみる**のも一つですが、**それをしないと応募できないわけではありません。**在職中に時間を取れない方は、資料を読むところから始めてください。

### 定款を読んでも、何を書けばよいか分かりません

**定款で見るのは、2か所だけで足ります。**1つ目は、**目的の条項。**その法人が何を実現しようとしているかが、**一文で書かれています。**2つ目は、**事業の条項。**そこに列挙された事業のうち、**自分の経験が重なるものがどれか**を見てください。**それ以上は読み込まなくて構いません。**むしろ、**志望動機の材料として濃いのは、事業報告書のほう**です。定款は「建前としてできること」の範囲で、**事業報告書は「実際にやったこと」**だからです。**計画と実績の差**が書かれていることもあり、そこは**面接で聞く材料**にもなります。

### 複数の法人に応募する場合、志望動機は使い回せますか

**①の層は使い回せます。②と③は、法人ごとに書き直してください。**①は「なぜこの分野か」なので、**同じ分野の法人なら同じ経験が材料になります。**一方、②は**その法人の資料から取った材料**なので、使い回すと**読んでいないことがすぐ分かります。**③も、**法人の性格によって説得力のある型が変わります。**行政からの委託が中心の法人なら「制度を知っている立場で実施する側に回る」、自主事業が中心の法人なら「制度の外側を受け止める機能」。**同じ言葉でも、置く場所で意味が変わります。**なお、**応募する法人の数を絞りすぎない**ほうが、③を言葉にする機会が増えます。
