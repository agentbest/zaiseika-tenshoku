まちづくりに関わりたい、というご相談は、**公務員の方からいちばん多く伺う**ものの一つです。

**「都市計画の仕事をしていました。民間でも同じことができますか」**

**できます。**ただし、**「同じこと」の中身が変わります。**

**役所は、計画を決め、許可し、認可する側**にいました。**民間は、その枠組みの中で、実際に事業を動かす側**です。

**そして、その枠組みは法律に書かれています。**この記事では、**法令の枠組みから業界の構造を整理し、未経験から入る道筋**を扱います。

## 再開発の事業は、民間が組合を作って行えます

**都市再開発法第11条第1項**です。

> **（認可）第十一条　第一種市街地再開発事業の施行区域内の宅地について所有権又は借地権を有する者は、五人以上共同して、定款及び事業計画を定め、国土交通省令で定めるところにより、都道府県知事の認可を受けて組合を設立することができる。**

**読み解いていただきたいのは、主語**です。

**「宅地について所有権又は借地権を有する者」**が、**「五人以上共同して」**、**「都道府県知事の認可を受けて」**組合を設立する。

**つまり、事業を起こすのは民間の側**です。**行政は認可する側**にいます。

**そして、土地区画整理法第3条第1項**も、同じ構造です。

> **（土地区画整理事業の施行）第三条　宅地について所有権若しくは借地権を有する者又は宅地について所有権若しくは借地権を有する者の同意を得た者は、一人で、又は数人共同して、当該権利の目的である宅地について、**（中略）**土地区画整理事業を施行することができる。**

**「一人で、又は数人共同して」**です。

**この2つの条文が示しているのは、まちづくりの事業には、行政の側と、事業を実際に動かす側がある**ということです。

**そして、動かす側には、専門の仕事があります。**

## 業界は、5つに分かれます

| 区分 | 何をするか | 公務員からの入りやすさ |
|---|---|---|
| **再開発コンサルタント** | 組合の設立支援、事業計画、権利者との調整 | **経験が直結する** |
| 都市計画コンサルタント | 計画の策定の支援、調査、住民参加の設計 | **経験が直結する** |
| デベロッパー | 用地の取得、事業の企画、建物の開発 | 分野による |
| 建設コンサルタント | 基盤の設計、インフラの計画 | **技術職は直結** |
| まちづくり会社・エリアマネジメント | 地域の運営、公共空間の活用、施設の運営 | **入りやすい** |

**上の2つが、公務員からいちばん自然に移れる領域**です。

**理由は、仕事の相手が行政と権利者だから**です。**役所の側で、計画の策定や事業の認可を扱ってきた方**は、**手続きの流れと、どこで時間がかかるかを知っています。**

## 再開発コンサルタントという仕事

**この職種は、公務員の方にあまり知られていません。**

**第11条の条文を、もう一度見てください。****「五人以上共同して、定款及び事業計画を定め」**とあります。

**この定款と事業計画を、権利者だけで作れるでしょうか。**

**作れません。**権利の調査、従前の資産の評価、事業の収支、施設の計画、行政との協議。**専門の知識が要ります。**

**それを支援するのが、再開発コンサルタント**です。

| 仕事の中身 | 役所での対応する経験 |
|---|---|
| 権利者の意向の把握 | **住民説明会、個別の相談** |
| 権利の調査 | 用地の取得、登記の確認 |
| 事業計画の作成 | **計画の策定、収支の見通し** |
| 行政との協議 | **どの課と、どの順で話すかを知っている** |
| 組合の運営の支援 | 審議会・委員会の事務 |
| 合意形成 | **利害の対立する相手との調整** |

**右の列が、そのまま左の列に対応します。**

**⚠ ただし、資格が要る場面があります。**技術的な業務については、**関係する資格が求められる**ことがあります。**求人票の応募条件を確認してください。**

## 認可する側から、申請する側へ

**この移り方は、実務として自然です。**

| 役所の側 | 事業者の側 |
|---|---|
| 認可の申請を審査する | **申請の書類を作り、提出する** |
| 計画が要件を満たすか確認する | 要件を満たす計画を作る |
| 権利者からの相談を受ける | **権利者の意向をまとめる** |
| 関係課と調整する | **行政の関係課と協議する** |
| 事業の進捗を確認する | 進捗を管理し、報告する |

**左の列をやってきた方は、右の列で何が求められるかが分かります。**

**とくに、「どの課と、どの順で話すか」**です。**これは、外から学ぶのが難しい知識**です。都市計画、建築、道路、公園、上下水道、消防、教育。**一つの事業に、いくつもの課が関わります。**

**その順番と、それぞれが何を気にするかを知っている人**は、**協議の段取りを組めます。**

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 場面 | 効く理由 |
|---|---|
| 行政との協議 | **相手の意思決定の流れと時期が読める** |
| 計画の策定 | **策定の手順を知っている** |
| 住民説明・合意形成 | 説明会と個別対応の経験 |
| 権利の調査 | **用地の取得、登記の確認の経験** |
| 補助の制度の活用 | **交付する側にいた** |
| 審議会・委員会の運営 | 組合の総会・理事会の運営に重なる |
| 議会・住民への説明 | 説明の責任を負う場面 |

**効きにくい場所**

| 場面 | 効きにくい理由 |
|---|---|
| 事業の採算の判断 | **予算の執行とは見る方向が違う** |
| 受注の営業 | 売り込む仕事は役所に少ない |
| 不動産の相場の感覚 | 市況の読みは経験で付く |
| 建物の設計・施工の知識 | 分野による |
| 長期にわたる案件の資金の管理 | **入金までの期間が長い** |

**最後の1つは、この業界の特徴**です。

**再開発の事業は、構想から完了まで長い年月がかかります。**その間、**会社は費用を先に出しています。****役所の単年度の予算とは、お金の動き方がまったく違います。**

:::insight
面談で拝見していて、**この業界を志望される公務員の方が、いちばん誤解しておられるのが「時間の感覚」**です。役所の都市計画の部署にいると、**担当する期間は3年程度**です。その間に、計画の一部が進む。**異動して、次の担当が引き継ぐ。**ところが、**民間の再開発コンサルタントは、同じ案件に10年以上関わり続ける**ことがあります。構想、権利者の合意、組合の設立、事業計画の認可、権利変換、工事、完了。**この全部を、同じ担当者が見る。**これは、役所では経験できないことです。移った方が口を揃えておっしゃるのが、**「最後まで見られるのが、こんなに違うとは思わなかった」**という言葉です。一方で、**裏返しもあります。**案件が止まったとき、**異動で離れることができません。**権利者の一部が反対して動かない状態が、**何年も続く**こともある。**そこに居続ける覚悟が要ります。**ですから、面接で確認していただきたいのは、**「いま担当されている案件は、着手から何年目ですか」**です。この1問で、その会社が扱う案件の時間の長さが分かります。**そして、自分がその時間に耐えられるかを、考えてみてください。**
:::

## 入り方の手順

| 順 | やること | 目安 |
|---|---|---|
| 1 | 自分が関わった**事業の種類**を書き出す（再開発、区画整理、計画策定など） | 30分 |
| 2 | **職種名で求人を検索する**（再開発、都市計画、まちづくり） | 1時間 |
| 3 | 出てきた会社の**実績のページ**を読む | 1時間 |
| 4 | 自分が関わった事業と**重なるものを探す** | 30分 |
| 5 | 求人票の**応募条件を5件読み比べる** | 1時間 |
| 6 | **資格の要件**があるか確認する | 20分 |

**3つ目が、この業界では効きます。**

**再開発や区画整理の実績は、公表されている**ことが多く、**どの地域で、どういう規模の事業を扱ってきたか**が読めます。**自分が知っている地域の事業があれば、それは強い材料**です。

**⚠ ただし、前の職場で知り得た内部の事情を書いたり話したりしないでください。**守秘の観点に加えて、**この人は情報を外で話すと受け取られます。**

## 面接で聞かれやすいこと

| 聞かれること | 何を見られているか |
|---|---|
| どの事業に、どの立場で関わりましたか | **経験の具体性** |
| 権利者と直接話した経験はありますか | **合意形成の経験** |
| 案件が長期にわたることに抵抗はありますか | **時間の感覚** |
| 行政との協議で、どちらの立場に立ちますか | **元の所属に引きずられないか** |
| 受注の場面で、どう関わりますか | 営業への構え |

**2つ目は、用地の取得や、住民説明会を担当した方には、語れる質問**です。

**答え方は、まとめた話だけでなく、まとまらなかった話**も入れてください。「全員の合意は得られませんでしたが、反対されている方の理由を個別に確認し、どこまでなら受け入れられるかを整理しました」。**この業界では、まとまらない状況への向き合い方が見られます。**

**4つ目は、必ず聞かれます。****「事業者の側に立ちます。ただし、行政の側の制約も分かるので、通らない計画を持ち込まないで済みます」**が自然です。

:::insight
ここまで入り方の話をしてきましたが、**この業界を検討するときに、見ておいていただきたい点**があります。**会社の規模と、扱う案件の性格**です。この業界には、**全国の大規模な事業を扱う会社**と、**特定の地域に根ざして小規模な事業を積み重ねる会社**があります。どちらが良いという話ではなく、**働き方がまったく違います。**前者は、**転勤や長期の出張がある**ことが多い。後者は、**地域が固定されるかわりに、案件の数を同時に持つ**ことがあります。そして、**公務員から移る方にとっては、後者のほうが経験が効きやすい**場合があります。理由は、**自分が知っている地域の制度と、行政の担当課の動き方が分かるから**です。⚠ ただし、**前の職場と直接取引のある会社に移る場合、在職中の職務との関係が問題になることがあります。**再就職に関する規制は、国家公務員と地方公務員、また自治体ごとに定めが異なります。**⚠ 所属の人事担当部署と、適用される規程を必ず確認してください。**この記事では、個別の事情について判断できません。確認を怠ったまま進めると、**ご本人にも、移った先にも負担がかかります。**先に確認してください。
:::

## まとめ

- **役所は計画を決め、許可し、認可する側。民間は、その枠組みの中で事業を動かす側**です
- **都市再開発法第11条第1項**は、**施行区域内の宅地について所有権又は借地権を有する者が、五人以上共同して、定款及び事業計画を定め、都道府県知事の認可を受けて組合を設立できる**と定めています
- **土地区画整理法第3条第1項**も、**宅地について所有権若しくは借地権を有する者等が、一人で、又は数人共同して施行できる**と定めています。**事業を起こすのは民間の側**です
- 業界は、**再開発コンサルタント・都市計画コンサルタント・デベロッパー・建設コンサルタント・まちづくり会社**の5つに分かれます
- **上の2つが、公務員からいちばん自然に移れる領域**です。**仕事の相手が行政と権利者**だからです
- **「どの課と、どの順で話すか」は、外から学ぶのが難しい知識**です。そのまま価値になります
- ⚠ **時間の感覚が変わります。**同じ案件に**10年以上**関わることがあります。**止まった案件から異動で離れることはできません**
- ⚠ **前の職場と取引のある会社に移る場合、再就職に関する規程の確認が要ります。**所属の人事担当部署に確認してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 事務職です。技術の知識がありませんが、応募できますか

**応募できます。**この業界の仕事は、**技術の部分と、調整・手続きの部分**に分かれます。**権利者の意向の把握、事業計画の作成、行政との協議、組合の運営の支援**は、**技術の知識より、制度の理解と調整の経験**が要る領域です。**用地の取得、住民説明会、計画の策定**を担当していた方なら、材料は十分にあります。⚠ ただし、**技術的な業務については、関係する資格が求められる**ことがあります。**求人票の応募条件を確認してください。**なお、**まちづくり会社やエリアマネジメントの分野**では、**施設の運営、イベントの企画、地域の事業者との調整**が中心になるため、**事務職の経験がそのまま使えます。**

### 都市計画に関わったことがありません。別の部署からでも移れますか

**移れる場合があります。**この業界で効くのは、**都市計画の知識そのものより、行政の手続きと合意形成の経験**です。**用地の取得、補助金の交付、住民説明会の運営、審議会の事務**を担当していた方は、**別の分野であっても材料になります。**とくに、**利害が対立する相手との調整の経験**は、この業界の中核と重なります。書き方は、**「都市計画の経験はありませんが、◯件の用地の折衝を担当し、権利関係の調査と合意形成を行ってきました」**という形です。**制度の名前ではなく、動作で書いてください。**なお、**まちづくり会社の分野**は、商工、観光、文化、生涯学習の経験も生きます。

### 年齢が高めです。未経験の業界に移れますか

**この業界では、年数が不利になりにくい**面があります。理由は、**扱う案件が長期にわたり、制度の理解と調整の経験が求められるから**です。**行政の中で計画や用地、補助の制度を長く担当してきた方**は、**その年数がそのまま経験として読まれます。**ただし、**役職の名称は、そのままでは評価に結びつきません。**「課長補佐を◯年」ではなく、**「◯件の用地の折衝と、◯地区の計画の策定を担当」**という形で、**担った範囲と件数**で書いてください。なお、**案件の時間の長さ**は、あらかじめ考えておいてください。**着手から完了まで10年という案件**に、どこから関わるかで、見える景色が変わります。
