**調査や統計を担当してきた方から、「検定を受けるべきか」**というご相談を伺います。

**裏づけになる場面と、ならない場面があります。**

この記事では、**その分かれ目**を扱います。

**⚠ 試験の内容・区分・実施の方法は、実施する団体の公表を確認してください。****この記事では、個別の内容には触れません。**

## 自治体の統計調査には、手続があります

**統計法第24条第1項**です。

> **地方公共団体**（地方公共団体の規模を勘案して政令で定めるものに限る。以下「指定地方公共団体」という。）**の長その他の執行機関は、統計調査を行おうとするときは、あらかじめ、政令で定めるところにより、次に掲げる事項を総務大臣に届け出なければならない。**これを変更しようとするときも、同様とする。
>
> 一 **調査の名称及び目的**

**調査を行うにあたり、名称と目的を含む事項を届け出る**という仕組みです。

**つまり、自治体の調査にも、制度上の手続と規律がある**ということです。

**思いついた項目を集めるだけの作業ではありません。**

**調査を設計し、実施した経験には、この前提が含まれています。**

**この点が、書類に書ける材料**です。

## 検定が裏づけになる場面

| 場面 | 理由 |
|---|---|
| ① 応募条件に記載がある | **満たす材料になる** |
| ② 実務の経験が少ない | 到達を示すものが他にない |
| ③ 分析を職種とする求人 | 水準の目安になることがある |
| ④ 分野を変える | 学習していることを示せる |
| ⑤ 体系的に学びたい | 範囲が決まっている |

**②について。**

**集計の実務が中心だった場合、分析の水準を示すものが他にありません。**

**この場合、検定が材料になります。**

**⑤について。**

**独学では触れない範囲を知る手段**としては、有効です。

## 裏づけになりにくい場面

| 場面 | 理由 |
|---|---|
| ① 応募条件に記載がない | 判断の中心にならない |
| ② 実務の経験がある | **経験のほうが具体** |
| ③ 集計・報告が中心の求人 | 正確さが重視されます |
| ④ 応募の時期が近い | 書類の作成が優先 |
| ⑤ 目的が曖昧 | 「何か取っておきたい」だけ |

**②が、公務員からの転職では多い**です。

**年間の統計の作成、調査の設計、経年と他団体との比較。**

**これらの経験のほうが、具体に書けます。**

**扱いは**[データ分析｜EBPMの延長で身につける範囲](skill-databunseki.html)**に整理しています。**

## 実務で書ける材料

| 材料 | 書き方の例 |
|---|---|
| 調査の設計 | 目的、対象、項目、方法を整理 |
| 対象の規模 | 対象者約◯名、回収◯件 |
| 集計と分析 | 定義を確認のうえ、経年と比較 |
| 公表 | 個人が特定されない形に整理 |
| 施策への反映 | **数字から何を決めたか** |

**5行目が要**です。

**集計しただけでは、分析の経験として読まれにくい**ことがあります。

**「傾向を把握し、翌年度の事業の対象の設定に反映」**という形で、**判断につながった**ことを書いてください。

## 書くときの注意

| 注意 | 内容 |
|---|---|
| ① 取得の年を書く | いつ取ったか |
| ② 区分を正確に | **段階がある場合** |
| ③ 実務と併記 | 経験があれば併せて |
| ④ 誇張しない | できる範囲を限定して |
| ⑤ 関係するものを選ぶ | 応募先に関係するか |

**④について。**

**「分析ができます」と書くと、範囲が広く受け取られます。**

**「定義を確認したうえでの集計と、経年・他団体との比較の経験あり」**という形で、**範囲を明示**してください。

:::insight
検定について、**面談でお伝えしているのが「調査を設計した経験のほうが強い」**という点です。**「統計の知識を示したい」というご相談**を受けますが、**民間で不足しているのは、知識より設計の経験**です。何のために調べるのか、誰を対象にするのか、どの項目を聞くのか、どう集計するのか、結果をどう使うのか。**この一巡を回した人は、多くありません。**そして、**自治体の調査には、統計法第24条のとおり届出の手続があり、名称と目的を明確にする必要があります。****目的が曖昧な調査は、そもそも進みません。**この規律の中で設計してきた経験は、**民間の調査や分析でもそのまま使えます。**書類には、**「目的、対象、項目、方法を整理して調査を設計」**と書いてください。**検定の区分より、この一文のほうが伝わります。**そのうえで、応募条件に記載があるなら取得を検討してください。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 受ける前に考えること

| 確認すること | 内容 |
|---|---|
| ① 応募したい求人の条件 | **記載があるか** |
| ② 実務で書ける材料 | 調査、集計、分析 |
| ③ 目的 | 読むためか、職務とするためか |
| ④ 期限 | 応募の時期に間に合うか |
| ⑤ 他の優先順位 | 書類、条件の整理 |

**②を先に並べてください。**

**書ける材料があるなら、受験より書類の作成が先**です。

**なお、受ければ転職できる、という関係にはありません。**

**何を調べ、どう確かめ、何に使ったか**が、評価の対象です。

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 担当した調査の整理 | **目的、対象、件数** |
| 集計の手順の書き出し | 定義、方法 |
| 公表資料の確認 | 作成に関わったもの |
| 求人を読む | 週に30分 |

**1行目です。**

**年度の報告や統計の資料から、対象の数と回収の件数を確認**してください。

**根拠のない数は書かないでください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 担当した調査 | **目的、対象、規模** |
| 定義の確認 | 何を確かめたか |
| 集計の方法 | どの単位で |
| 施策への反映 | 何を決めたか |
| できる範囲 | **正確に、限定して** |

**4行目です。**

**なお、特定の対象者が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 自治体が相手の事業 | **公的統計と調査の手続が分かる** |
| ② 調査・コンサルティング | 設計、集計、報告 |
| ③ 事業の企画 | 効果の測定 |
| ④ 集計・報告の部門 | 定義の確認、正確さ |
| ⑤ 公共分野の分析 | 制度の理解 |

**①について。**

**自治体を顧客とする事業では、調査を受託する場面**があります。

**発注する側で、仕様を書き、履行を確認してきた経験**は、そこで直接使えます。

**どの項目を聞けば目的に答えられるか、回収をどう確保するか、公表でどこに配慮するか。**

**これらは、発注した側にいないと分かりません。**

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## よくある失敗

**1. 実務の材料を並べずに受験を考える**

**経験のほうが具体**です。

**2. 施策への反映を書かない**

**集計だけでは読まれにくい**です。

**3. 「分析ができます」と書く**

**範囲を明示**してください。

**4. 取得の年・区分を書かない**

**水準が分かりません。**

**5. 調査の設計の経験を書かない**

**一巡を回した人は多くありません。**

**6. 根拠のない数字を書く**

**記録から確認**してください。

**7. 応募の時期が近いのに受験を優先する**

**書類の作成が先**です。

**8. 受ければ転職できると考える**

**要件を満たす材料の1つ**です。

:::insight
ここまで「実務が先」という話をしておいて逆のことを言いますが、**学ぶこと自体は、読み方を変えます。**面談で拝見していると、**数字を扱ってきたのに、平均だけで説明してしまう方**がいらっしゃいます。ばらつきを見ない、相関と因果を分けない、母数の違う数字を並べる。**これらは、実務の経験だけでは気づきにくい部分**です。そして、**気づかないまま資料を作ると、受け取る側の判断を誤らせます。**体系的に学ぶと、**この危うさが見えるようになります。**ですから、**応募の準備としては優先順位を下げつつ、長く続ける前提で学ぶ**という位置づけにしてください。**入社後にも使えます。**そして、**学んだ結果を実務に使った**なら、そこまで書いてください。「ばらつきを併せて示す形に、報告の様式を見直した」。**学習と成果がつながっていると、伝わります。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **統計法第24条第1項**は、**指定地方公共団体が統計調査を行おうとするときは、調査の名称及び目的を含む事項を総務大臣に届け出なければならない**としています
- **自治体の調査にも、制度上の手続と規律があります。**設計の経験には、この前提が含まれます
- 検定が**裏づけになる**のは、**応募条件に記載がある、実務の経験が少ない、分析を職種とする**場合です
- **なりにくい**のは、**記載がない、実務の経験がある、集計・報告が中心の求人**の場合です
- **調査を設計した経験のほうが強い**です。目的・対象・項目・方法を整理したと書いてください
- **施策への反映**を書いてください。集計だけでは読まれにくいです
- **「分析ができます」ではなく、範囲を明示**してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 調査を設計した経験がありません

**集計と報告の経験で書いてください。**「◯◯に関する実績について、定義を確認のうえ年◯回集計し、推移を図に整理して報告に使用」という形です。**定義の確認**に触れると、実務が分かっていることが伝わります。なお、**既存の調査の実施を担当した**場合も、**配布と回収、督促、集計、公表の工程**を書けます。「対象者約◯名への配布と、回収◯件の管理を担当」。**設計に関わっていなくても、工程は担っています。**扱いは[データ分析｜EBPMの延長で身につける範囲](skill-databunseki.html)に整理しています。

### どの区分を目指せばよいですか

**応募したい求人の記載を基準にしてください。**求人票に具体の記載があれば、それが目安です。**記載がない場合、区分を自分で決める必要はありません。**なお、**目的で分けて**ください。**会社の資料を読むためであれば、基本的な考え方で足ります。**一方、**分析を職務とするのであれば、体系的な範囲が必要**になります。**⚠ 区分の構成や出題の範囲は、実施する団体の公表を確認**してください。**この記事では触れません。**読み方は[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。

### 公表資料に名前が載っていませんが、書けますか

**担当した事実を書いて差し支えありません。**公表資料に作成者の名が載らないのは一般的です。書き方は、**「◯◯に関する年報の作成を担当。集計、図表の作成、注記の整理を実施」**という形です。**作業の内容で書けば足ります。**なお、**公表されていない内容には触れないでください。**集計の途中の数字、検討の経緯、未公表の資料。**これらは書かないでください。**公表された範囲で、**自分が担った作業**を書いてください。守秘の義務は、退職した後も続きます。
