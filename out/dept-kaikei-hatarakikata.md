会計課・出納室の働き方について、先に言っておきたいことがあります。

**この部署は、責任の重さが法律で書き分けられています。**

感覚の話ではありません。条文に、ほかの職員とは違う基準が書いてあります。ここを知っておくと、自分の仕事をどう説明すればよいかが決まりますし、民間に移ったときに何が変わるかも見通せます。

この記事では、その条文を確認したうえで、一年の波と評価のされ方、そして移ったあとに変わることを扱います。

言い換えは[会計課・出納室の経験は民間で何と呼ばれるか](dept-kaikei-honyaku.html)、行き先は[会計課・出納室からの転職先](dept-kaikei-tenshokusaki.html)、書類と面接は[職務経歴書](dept-kaikei-shokumu.html)と[面接](dept-kaikei-mensetsu.html)に分けています。

## 会計職員だけ、基準が一段重い

地方自治法第243条の2の8第1項は、こう定めています。

**会計管理者若しくは会計管理者の事務を補助する職員、資金前渡を受けた職員、占有動産を保管している職員又は物品を使用している職員が、故意又は重大な過失（現金については、故意又は過失）により、その保管に係る現金、有価証券、物品若しくは占有動産又はその使用に係る物品を亡失し、又は損傷したときは、これによって生じた損害を賠償しなければならない。**

括弧の中を読んでください。

**「現金については、故意又は過失」。**

ほかは「故意又は重大な過失」です。現金だけ、**重大でない過失でも賠償責任の対象になります。**

同項の後段では、次の行為をする権限を持つ職員や、その事務を直接補助する職員で規則で指定された者が、故意又は重大な過失により法令に違反して行為をしたり怠ったりして損害を与えたときも同様とされています。

1. 支出負担行為
2. 支出命令（第232条の4第1項）と、支出前の確認（同条第2項）
3. 支出又は支払
4. 契約の監督又は検査（第234条の2第1項）

**支出に関わる工程が、ひとつずつ名指しで挙げられています。**

これが、会計課の働き方の土台にあります。慎重なのは性格ではなく、**制度がそう組まれているから**です。

## 一年の形――年度末が2回来ます

会計課の繁忙の形も、条文で決まっています。

地方自治法第235条の5は、**普通地方公共団体の出納は、翌年度の5月31日をもって閉鎖する**と定めています。

会計年度は3月31日に終わりますが、出納は5月31日まで開いています。3月末までに債務が確定した支出を、4月と5月に処理できるということです。

そして第233条第1項は、**会計管理者は、毎会計年度、決算を調製し、出納の閉鎖後3か月以内に、証書類その他の書類と併せて長に提出しなければならない**としています。第2項で長は監査委員の審査に付し、第3項で監査委員の意見を付けて**次の通常予算を議する会議までに議会の認定に付す**、と続きます。

まとめると、会計課の一年はこうなります。

| 時期 | 主な仕事 |
|---|---|
| 4〜5月 | **出納整理期間（最大の山）**。前年度分と当年度分を並行処理 |
| 6〜8月 | 決算の調製、証書類の整理、長への提出 |
| 8〜10月 | 監査委員の審査への対応、議会の認定 |
| 10〜12月 | 公会計の財務書類の作成、通常の支出審査 |
| 1〜3月 | **年度末（第2の山）**。支出の集中、繰越の処理 |
| 毎月 | 例月出納検査への対応、定例の支払 |

**年度末が2回来る**というのは、この形を指しています。3月末で一度締まり、5月末でもう一度締まります。

加えて、**毎月の例月出納検査**があります。月次でも外部の目が入るので、締めが完全に緩む時期がありません。

## 転職活動の時期を、この波から逆算する

面接は平日日中に入ることが多く、1社で複数回あります。**4月から5月の出納整理期間と、1月から3月の年度末は避けたほうが無難**です。

比較的まとまった時間を作りやすいのは、**決算が議会の認定を通ったあとから、年末までの間**です。時期でいうと、おおむね秋から初冬にかけてです。

現実的な組み立てはこうなります。

1. 決算の調製が終わったあたりで書類を作る
2. 議会の認定が終わってから2社ほど受けて、説明の詰まる場所を直す
3. 年明けから3月は活動を止めるか、進んでいる1社だけに絞る
4. 出納整理期間が明けてから再開する

**山を無視して始めると、中途半端に止まって最初からやり直しになります。**

## 会計課の評価は、なぜ分かりにくいのか

会計課の成果は、**「間違って払わなかったこと」**と**「検査で指摘を受けなかったこと」**です。どちらも、起きなかったことです。

事業課の成果は目に見えます。会計課の成果は、**何も起きなかった状態**として現れます。

加えて、審査は担当課と利害が正面から向き合います。差し戻せば相手の作業が増えます。**感謝される場面が多い部署ではありません。**

ここで大事なのは、この構造を**不満として語らないこと**です。転職の面接でこれを不満の形で出すと、次の職場でも同じことを言うと思われます。

**構造として説明してください。**「発見される仕組みの中で、指摘を受けない状態を保ってきた」と言えれば、それはそのまま内部統制の適性として読まれます。

## 庁内の言葉と、求人票の言葉

働き方に関わる部分を置き換えると、次のようになります。

| 庁内での言い方 | 求人票での言い方 |
|---|---|
| 出納整理期間の並行処理 | 期をまたぐ決算処理、月次・年次決算 |
| 例月出納検査への対応 | 内部監査対応、統制の運用評価 |
| 決算の調製と監査委員の審査 | 決算業務、監査法人対応 |
| 支出審査の日々の運用 | 支払審査、購買統制、経費精算の承認 |
| 賠償責任を前提とした取扱い | 現金・有価証券の管理、内部統制の運用 |
| 指定金融機関との定例協議 | 銀行対応、決済インフラの運用 |

このうち、働き方として直接伝わるのは**「期をまたぐ決算処理」**と**「毎月の監査対応」**です。民間でも決算や監査は動かせない期限なので、そこを回してきた経験として説明すると通りやすくなります。

:::insight
会計課の方が民間に移って最初に戸惑うのは、仕事の難しさではなく**「止める根拠が法律から社内規程に変わること」**です。会計課では、地方自治法第232条の4第2項が確認しないままの支出を禁じているので、止める理由を自分で作る必要がありません。条文を示せば済みます。民間の内部統制部門では、根拠が社内規程になります。**規程は改正できるので、「では規程を変えればいい」という反論が来ます。**ここで押し切られると統制が形だけになります。逆に言えば、**法律を後ろ盾に止めてきた経験がある人は、根拠の示し方を知っている**ということでもあります。面接では「規程がどの段階で、誰が改正できるのか」を確認しておいてください。
:::

## 民間に移ると、何が変わるか

**1. 止める根拠が変わる**

上に書いたとおりです。法律から社内規程に変わります。**規程を作る側に回れるかどうか**が、働きやすさを分けます。

**2. 賠償責任の枠組みが変わる**

地方自治法第243条の2の8のような、職員個人の賠償責任を定めた規定は、民間には同じ形ではありません。会社の損害賠償は就業規則や一般法の枠組みで扱われます。**責任が軽くなるという話ではなく、拠り所が変わる**という意味です。現金や有価証券を扱う職場では、社内規程で厳しく定められていることもあります。

**3. 締めの回数が増える**

自治体は年1回の決算に、出納整理期間が付く形です。事業会社の多くは**月次で締めます。**同じ1年でも、締めの回数が大きく増えます。1回あたりの負荷は下がりますが、**常に何かの締めが動いている**状態になります。

**4. 外部の目が入る周期が変わる**

例月出納検査は毎月ですが、民間の内部監査や会計監査は年に数回であることが多くなります。**見られる頻度は下がりますが、1回の深さは増します。**

## 責任の重さを、書類と面接でどう扱うか

ここは扱い方を間違えやすいので、分けて書きます。

**書くときは、事実として置く**

職務経歴書では、制度として一段重い基準が課される立場だったことを、事実として1行入れてください。「現金の亡失については、重大な過失でなくても賠償責任の対象となる立場で、年間◯件の出納を扱った」のような形です。

**面接でも、事実として置く**

「責任が重くて大変でした」と続けると、リスクを避けたい人に見えます。**制度の説明として置いて、その中でどう運用してきたかに話を進めてください。**

- 現金の取扱いをどういう手順にしていたか
- 二人以上で確認する工程をどこに置いていたか
- 差異が出たときにどの順で調べていたか

**この3つを答えられると、内部統制の理解がある人として読まれます。**

第243条の2の8第2項は、損害が2人以上の職員の行為によるときは、**それぞれの職分に応じ、かつ、当該行為が損害の発生の原因となった程度に応じて賠償の責めに任ずる**としています。つまり、**誰がどの工程を持っていたかが後から問われる**構造です。だから工程の分け方を説明できることに意味があります。

## つまずきやすい点

**1. 繁忙期に活動を始めて中断する**

いちばん多い形です。年度末や出納整理期間に書類を作り始めて、面接の日程が組めずに止まる。**山の谷間から始めてください。**

**2. 忙しさを転職理由にする**

管理部門は民間でも繁忙期があります。**理由は、やってきたことの延長で組んでください。**

**3. 評価されにくさを不満の形で出す**

構造として説明すれば強みになり、不満として出すと弱みになります。**同じ事実でも、置き方で逆になります。**

**4. 異動の可能性を検討しないまま動く**

会計課は、契約検査課、税務課、財政課、監査委員事務局といった部署と接続します。**庁内で移る選択肢を一度も検討していないなら、先にそちらを確かめたほうが選択肢は減りません。**

**5. 退職時期の制度面を確認しないまま決める**

退職手当や共済の扱いは在職期間で変わる部分があります。**手続きの前に、必ず所属の人事担当課と共済組合で確認してください。**

自分の場合にどの時期が動きやすいかは、一度話しながら整理したほうが早いことが多いです。[どの経験に値が付くのかから相談できます](../apply.html)。

:::insight
ここまで時期の話をしておいて逆のことを言いますが、**「落ち着いたら動く」と考えていると、動かないまま数年たちます。**会計課には谷間はありますが、毎月の検査がある以上、完全に手が空く時期はありません。実際に動いた方に共通しているのは、**谷間に「書類を作る」「2社受ける」といった小さい単位で区切って進めた**ことです。全部を一気にやろうとすると、山に飲まれて止まります。逆に、いま出納整理期間の真ん中にいるなら、無理に始める必要はありません。**書類の下書きだけ作って、決算が片付いてから出す**という進め方で十分間に合います。在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 地方自治法第243条の2の8は、会計職員の賠償責任を**「故意又は重大な過失（現金については、故意又は過失）」**と書き分けています。**現金だけ、基準が一段重い**構造です
- 同条は、支出負担行為・支出命令と確認・支出又は支払・契約の監督又は検査という**支出の工程をひとつずつ名指し**しています
- 第235条の5により**出納は翌年度5月31日に閉鎖**するので、**年度末が2回**来ます。山は4〜5月と1〜3月の2回で、加えて毎月の例月出納検査があります
- 活動しやすいのは、**決算が議会の認定を通ったあとから年末までの間**です
- 評価は「間違って払わなかったこと」「指摘を受けなかったこと」で、**起きなかったことが成果**です。**不満ではなく構造として説明してください**
- 民間に移って最初に戸惑うのは、**止める根拠が法律から社内規程に変わること**です。面接で規程の段階を確認してください

## よくある質問

### 会計課は残業が多いと聞きますが、実際どうですか

自治体ごとの実態は公表されていないので、個別の水準をここで断定することはできません。**制度から言えるのは、出納の閉鎖が翌年度5月31日と決まっており、決算の提出期限も定められているため、4〜5月と年度末に業務が集中する構造になっている**ということです。応募先に自分の状況を説明するときは、時間数ではなく**「年度末が2回来て、加えて毎月の検査がある部署でした」**と構造で伝えるほうが正確に伝わります。

### 賠償責任の話は、面接で言わないほうがいいですか

言い方によります。**「現金の亡失については、重大な過失でなくても賠償責任の対象になる立場で仕事をしていました」**と事実として述べるのは、内部統制や経理の面接では有効です。責任の重い立場を理解して働いてきたことが伝わります。一方、**それを理由に「怖かった」「負担だった」と続けると、リスクを避けたい人に見えます。**制度の説明として置いて、その中でどう運用してきたかに話を進めてください。

### 出納整理期間の経験は、民間で通じますか

そのままの言葉では通じません。**「決算の締めが2段階になっていて、4月と5月は前年度分と当年度分を並行して処理していた」**と言い換えてください。民間でいえば、期をまたいだ処理を2か月間並行させる形に近く、経理・財務の面接では具体的な業務経験として読まれます。
