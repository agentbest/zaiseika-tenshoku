石川県庁の給与データを他県と並べると、ひとつ目を引く数字があります。**諸手当月額107,266円**。地域手当の支給割合は約2.13%にすぎないのに、諸手当の総額は首都圏の県に迫る水準です。

同じ北陸の福井県は61,422円。**同じ地域で、45,000円以上の差がついています。**

この構造を理解しておくことは、転職を考えるうえで実務的な意味を持ちます。この記事では、まず数字を正しく読み解き、そのうえで県庁の経験が民間のどの言葉に置き換わるのかを整理します。

## 石川県庁の給与水準を、数字で確認する

総務省の調査によると、石川県の一般行政職は次のとおりです（令和6年4月1日現在）。

| 項目 | 石川県 |
|---|---|
| ラスパイレス指数 | 99.5 |
| 平均年齢 | 42.3歳 |
| 平均給料月額 | 323,000円 |
| 諸手当月額 | 107,266円 |
| 平均給与月額 | 430,266円 |
| 平均給与月額（国ベース） | 356,309円 |
| 地域手当（国の指定基準） | 約2.13% |
| 地域手当（実際の支給割合） | 約2.13% |

### 諸手当107,266円という数字の読み方

近隣・他県と並べると、この数字の特異さが分かります。

| 県 | 諸手当月額 | 地域手当（実支給） |
|---|---|---|
| **石川県** | **107,266円** | **約2.13%** |
| 神奈川県 | 112,415円 | 約14.24% |
| 新潟県 | 80,019円 | 約1.51% |
| 富山県 | 73,969円 | 約2.09% |
| 福井県 | 61,422円 | 約1.95% |

神奈川県と近い水準ですが、**神奈川の地域手当が約14.24%あるのに対し、石川は約2.13%**です。つまり石川県の諸手当107,266円は、**地域手当ではない手当の積み上がり**だということになります。

:::insight
この構造は、転職を考えるときに注意が要ります。**手当の中身によっては、業務の状況が変われば額も変わる**からです。時間外勤務手当や特殊勤務手当のように、担当する業務の内容と量に連動する手当は、配属や年度が変われば同じようには付きません。**いま受け取っている額面を「自分の標準」だと思って民間の提示額と比べると、判断を誤る可能性があります。**比べるなら、複数年の源泉徴収票を並べて、どの程度ぶれているかを見てください。ぶれ幅が大きいなら、その部分は固定の水準として数えないほうが安全です。同じ論点は[福島県](pref-fukushima.html)にもあります。
:::

なお、地域手当は国の指定基準どおりで上乗せはありません。ラスパイレス指数99.5は、学歴や経験年数の差を補正した指数です。**平均給料月額（補正なし）とラスパイレス指数（補正済み）は意味が違うので、混ぜて読まないでください。**

上の平均は自分の給与ではありません。民間の求人票と比べるときは、**自分の源泉徴収票の支払金額**を使ってください。

## 県庁の経験は、民間で何と呼ばれるか

| 県庁での仕事 | 求人票での言い方 |
|---|---|
| 予算の要求・査定、財政計画 | 予実管理、投資判断、経営企画 |
| 災害対応・復旧事業の進行管理 | プロジェクトマネジメント、BCP、リスク管理 |
| 住民説明・合意形成 | 渉外、パブリックリレーションズ |
| 企業誘致・立地支援 | 事業開発、用地開発、アライアンス |
| 観光の誘客・受入環境整備 | 観光事業企画、地域ブランディング |
| 伝統産業・地場産業の支援 | 事業開発、ブランド戦略 |
| 県土整備の設計・積算・監督 | 発注者支援、施工管理 |
| 市町村への助言・支援 | パートナー支援、カスタマーサクセス |
| 内部管理（人事・財政・総務・会計） | コーポレート、管理部門 |
| 議会対応、条例・規則の改正 | 渉外、法務、規程整備 |

部署ごとの詳しい対応は[自治体の部署別 仕事ガイド](../zukan.html)にまとめています。財政課であれば[財政課の経験は民間で何と呼ばれるか](dept-zaisei-honyaku.html)で、さらに細かく分解しています。

## 石川で積んだ経験の、外での値段

**1. 前例のない事業を組み立てた経験**

制度が先にあって当てはめる仕事ではなく、**制度そのものを作りながら進める仕事**を経験している方が、石川県庁には多くいます。国、市町、事業者、住民という立場の違う相手と、決まっていないルールの中で合意を作ってきた。

民間でこれに相当するのは、新規事業の立ち上げです。**前例がない、判断基準がない、関係者が多い、それでも期限がある。**構造が同じです。書き方さえ変えれば、そのまま新規事業開発の経験として読まれます。

書くときのこつは、**事業名ではなく規模と密度で書く**ことです。同時に動いていた事業の数、関係した市町や事業者の数、当初計画からの変更をどう処理したか。通常の年度サイクルでは起きない密度の意思決定を回してきたはずです。

**2. 期限と資源の制約下でのオペレーション**

限られた人員で、条件の悪い環境の広域を回す。優先順位を付けて資源を配分する。**これはBCPやオペレーション設計そのものです。**

民間側では、インフラ運営、物流、製造業の生産管理といった領域で、この能力が求められています。**「限られた条件で回した経験」として書けば、業界を問わず読まれます。**

**3. 観光と伝統産業のブランド戦略**

観光地と伝統工芸を抱える県として、県庁には誘客と地場産業支援の実務があります。**行政の立場で座組みを作った経験**は、観光関連の事業者、地域商社、ブランド事業を持つ企業から見て希少です。

**4. 市町村を相手にしてきた経験**

規模も体制もばらばらな市町を相手に、温度差をどう埋めたか。「連絡調整」ではなく、**複数顧客を持つアカウント業務の経験**として書けば、そのまま職務能力になります。小規模な自治体を相手にしてきた経験はとくに値がつきます。担当が1人で何役も兼ねている、専任の技術職がいない。**こうした事情は、売る側からはほとんど見えません。**

## 職務経歴書に、県庁の仕事をどう落とすか

**制度名ではなく、判断したことを書く**

「○○推進事業を担当」では読み手に何も残りません。事業名は庁内でしか意味を持たない固有名詞です。**何件を、どういう基準で審査し、どこで判断が割れて、どう決着させたか。**

**「従事」で終わらせない**

災害対応や復旧の業務を「従事」の一行で済ませてしまう方が多くいます。これでは何をしてきた人なのかが伝わりません。**動員した人員や事業者の数、判断が割れた場面の決着のさせ方、計画変更の処理。**ここまで書いて初めて、職務能力として読まれます。

**本庁と出先機関を書き分ける**

本庁は制度の設計と全県調整、出先は現場対応と個別案件の処理と、職務の性質がまったく違います。**どちらをどれだけ経験したかを書き分ける**と、読み手が配属をイメージできます。

**異動歴を「立ち上げの回数」に変える**

異なる制度領域を短期間で立ち上げてきた経験は、民間では**キャッチアップの速さ**として読まれます。編年式で並べ、それぞれの配属で最初の数か月に何を習得したかを1行添えてください。

## 技術職の場合は、探し方が変わる

**発注者側の経験そのものが職種になる**

「発注者支援」という職種が、建設コンサルタント業界には確立しています。設計の審査、積算の確認、工事の監督、住民説明。県庁でやってきたことが、そのまま職務内容として書かれた求人です。

**資格が入口で効く**

技術士、施工管理技士、測量士、電気主任技術者。**実務経験の年数が受験要件になっているものは、在職中でなければ積めません。**取れるものがあるなら、動く前に取っておいてください。

**復旧・復興の実務は特殊な資産になる**

被害の調査、応急の対応、本復旧の設計と発注、住民への説明。この一連を通した技術者は多くありません。**同じ条件を持つ地域の事業で、直接求められる経験です。**

## 面接で必ず詰められる2つのこと

**「意思決定のスピードに耐えられるか」**

行政は手続きの段数が多く、決裁を経て動きます。民間は月次で数字を締め、その場で方針を変えます。稟議の段数を弁解せず、**自分の判断で動かした範囲を具体的に答えてください。**通常より速い意思決定を求められた場面を持っているなら、それが最も分かりやすい材料になります。

**「数字への意識があるか」**

「利益を意識したことはありますか」という形で聞かれます。「行政なので利益はありません」と答えると、そこで話が終わります。事業の優先順位を付けた、単価の根拠を詰めた、複数案を比べた。**同じ思考をしていたことを、民間の言葉で説明できるか**が見られています。

## 在職中に進めるときの注意点

**顔が知られている前提で動く**

県内の企業の多くは、県庁と何らかの接点を持っています。取引先、許認可の相手方、補助事業の対象。**在職中の活動が伝わりやすい環境**だという前提で進めてください。応募先が現在の担当業務の相手方である場合は、とくに慎重に扱う必要があります。

**服務上の扱いを先に確かめる**

在職中に得た情報を持ち出すことは避けなければなりませんし、退職後の営業活動についても扱いを確認しておいたほうが安全です。**判断に迷う場合は、応募の前に人事担当課に制度上の取扱いを確認してください。**

**面接の日程は、議会日程から逆算する**

地方自治法第211条は、長が毎会計年度予算を調製し、年度開始前に議会の議決を経なければならないと定めています。都道府県は年度開始前30日までに予算を議会へ提出するようにしなければならない、とも書かれています。決算は、出納閉鎖後3か月以内の長への提出、監査委員の審査、議会の認定という順です（第233条）。**予算編成の山と定例会の会期中は、平日日中の面接を入れるのが難しくなります。**

**在職中に決める**

公務員には雇用保険が適用されないため、辞めてから探すと収入のない期間がそのまま持ち出しになります（[公務員に雇用保険がない理由](seido-shitsugyo-nashi.html)）。

:::insight
石川県庁の方の相談で、しばしば出てくる言葉があります。「いま抜けるわけにはいかない」。これは重い話で、外から軽く扱うべきではありません。ただ、判断材料として2つだけ添えます。ひとつは、**自分の経験が外でどう呼ばれるかを知ることと、いま辞めることは別だ**ということ。知っておくだけなら、いつでもできます。もうひとつは、**担当している案件を通しで一巡させてから動くほうが、書けることは確実に厚くなる**ということです。途中で抜けると、着手したところまでしか書けません。残る判断にも、動く判断にも、それぞれ理があります。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

- 災害対応や復旧の業務は**「従事」で終わらせない。**動員した人員と事業者の数、判断の決着、計画変更の処理で書いてください

## よくある質問

### 諸手当が高いのは、恵まれているということですか

**そう単純には言えません。**地域手当は約2.13%と低く、諸手当107,266円は地域手当以外の手当の積み上がりです。時間外勤務手当のように業務量に連動する手当が含まれる場合、**配属や年度が変われば同じようには付きません。**転職の判断に使うなら、複数年の源泉徴収票を並べて、ぶれ幅の大きい部分を除いた水準で考えたほうが安全です。

### 災害対応の経験は、時間が経つと価値が下がりますか

**事業の新しさより、そこで何を回したかが残ります。**同時並行の案件をどう捌いたか、計画変更をどう処理したか、立場の違う相手の合意をどう作ったか。これらは年数が経っても職務能力として読まれます。逆に、事業名や年度だけを書いていると、時間の経過とともに何も伝わらなくなります。**固有名詞に依存しない書き方に直しておくこと**が、そのまま対策になります。

### 県外に出たほうが選択肢は広いですか

**職種によります。**インフラ、観光、自治体向け事業といった分野では、県外に本社を置く企業が県内に担当を配置しているケースがあり、**県内勤務のまま本社基準の給与体系になる**組み合わせもあります。この種の求人は勤務地から検索すると視界に入りません。県外を考える前に、まず職種で探してみてください。北陸新幹線で首都圏とつながっているため、月に数回の出社であれば現実的な選択肢になります。
