市川市の地域手当は、**国の指定基準が12%、実際の支給割合が10%です。**

**国の基準より2ポイント低く支給しています。**

これまでの回で、地域手当を**「その地域の民間賃金の水準をもとに国が定めた割合」**と書いてきました。**この言い方は足りませんでした。**この回で、そこを直します。

## 市川市の給与水準を、数字で確認する

総務省の調査によると、市川市の一般行政職は次のとおりです（令和6年4月1日現在）。

| 項目 | 市川市 |
|---|---|
| ラスパイレス指数 | 101.1 |
| 平均年齢 | 42.8歳 |
| 平均給料月額 | 324,200円 |
| 諸手当月額 | 115,462円 |
| 平均給与月額 | 439,662円 |
| 平均給与月額（国ベース） | 396,151円 |
| 地域手当（国の指定基準） | **12%** |
| 地域手当（実際の支給割合） | **10%** |

諸手当は総額の**26.3%**を占めます。

## 国が示すのは基準で、支給率を決めるのは団体です

総務省の同じ調査には、全国1,721団体の地域手当が、**「国の指定基準」と「実際の支給割合」の2列**で載っています。

**この2つが違う団体が、88あります。**

そして**上に外れる団体も、下に外れる団体もあります。**

国の指定基準が12%の団体は、全国に24あります。実際の支給割合を並べると、こうなります。

| 実際の支給割合 | 団体の数 |
|---|---|
| 6% | 1 |
| **10%** | **1（市川市）** |
| 12%（基準どおり） | 18 |
| 15% | 3 |
| 16% | 1 |

**国が同じ12%と示した24団体で、実際の支給率は6%から16%まで分かれます。**

**市川市は、この24団体のなかで実支給10%の唯一の団体です。**

つまり、正しい言い方はこうなります。**国は地域ごとに支給率の基準を示す。実際に何%支給するかは、団体が条例で決める。**基準どおりの団体が多数ですが、**上回る団体も下回る団体もあります。**

### 船橋市と並べる

同じ千葉県で、国の指定基準も同じ12%。**違うのは実際の支給割合です。**

| 項目 | 市川市 | 船橋市 |
|---|---|---|
| 地域手当（国の指定基準） | 12% | 12% |
| 地域手当（実際の支給割合） | **10%** | **12%** |
| ラスパイレス指数 | 101.1 | 99.6 |
| 平均年齢 | 42.8歳 | 40.2歳 |
| 平均給料月額 | **324,200円** | 307,200円 |
| 地域手当（概算） | 32,420円 | **36,864円** |
| 地域手当以外（概算） | **83,042円** | 73,776円 |

**市川市は国の基準より2ポイント低く支給しているのに、総額では船橋市より21,822円多くなります。**

内訳は、給料月額で市川市が17,000円多く、地域手当で船橋市が4,444円多く、地域手当以外で市川市が9,266円多い、という形です。

:::insight
**これまでの回で、地域手当を「団体が決めた割合ではなく、国が定めた割合」と書いてきました。**富士市と茨木市の回です。**この言い方は不正確でした。**正しくは、**国が地域ごとに支給率の基準を示し、実際に何%支給するかは団体が条例で決めます。**全国1,721団体のうち88団体で、基準と実際の支給率が違います。**市川市は国基準12%に対して実支給10%。**国の基準どおりなら、給料月額324,200円の12%でおよそ38,904円ですが、実際は10%でおよそ32,420円。**月あたり6,484円の差になります。**ここから言えることは2つあります。**1つめ。地域手当の割合は、団体の判断が入る余地のある数字です。**だから「国が決めた割合だから団体の給与の決め方とは関係ない」とは言い切れません。**2つめ。それでも、団体の総額を比べる意味がないという結論は変わりません。**市川市は基準より2ポイント低く支給していて、それでも船橋市より総額で21,822円多い。**地域手当を下げても、給料月額と他の手当で順序は変わります。**結局、**どの数字をどう組み合わせても、団体の平均からあなたの実額は出てきません。**市川市の諸手当115,462円のうち、地域手当10%ぶんは32,420円ほど。**残る83,042円（総額の18.9%）が、時間外の量、担当する業務、役職、住んでいる場所で人ごとに違う部分です。**求人票の想定年収と比べる前に、複数年ぶんの源泉徴収票の支払金額を並べてください。

## 市は、どういう団体か

市川市は、中核市でも施行時特例市でもない市です。**開発許可や建築確認をどこまで市が処理するかは、市によって扱いが異なります。**保健所は設置しないので、食品衛生や感染症対策は都道府県の仕事として残ります。

**ところが、町村との間にははっきりした線が1本あります。**

社会福祉法第14条第1項は、**都道府県及び市（特別区を含む）は、条例で、福祉に関する事務所を設置しなければならない**と定めています。一方、同条第3項では、**町村は、条例で、その区域を所管区域とする福祉に関する事務所を設置することができる**とされています。

**市は必ず置く。町村は置いてもよい。**ここが分かれ目です。

そして同条第6項によれば、市町村の福祉に関する事務所は、**生活保護法、児童福祉法、母子及び父子並びに寡婦福祉法、老人福祉法、身体障害者福祉法、知的障害者福祉法**に定める援護、育成、更生の措置に関する事務のうち、市町村が処理することとされているものをつかさどります。

**6つの法律にまたがる給付と措置を、1つの事務所で扱う。**これが、市になった団体に必ずある仕事です。

職務経歴書に書くときは、**「市役所の仕事」ではなく、担当した事務の名前で書いてください。**市の人口と処理件数を添えると、読まれ方が変わります。

## 「あとから直せない記録」を扱う実務

市川市役所の方に、いちばん強く伝えたいのがこの点です。

戸籍法第1条は、**戸籍に関する事務は、この法律に別段の定めがあるものを除き、市町村長がこれを管掌する**と定めています。そして同条では、**市町村長が処理することとされている事務は、地方自治法第2条第9項第1号に規定する第1号法定受託事務とする**とも書かれています。

**国の事務を、市町村長が処理する形になっています。**

そして第6条は、**戸籍は、市町村の区域内に本籍を定める一の夫婦及びこれと氏を同じくする子ごとに編製する**と定めています。

**個人ごとでも、世帯ごとでもありません。**

住民基本台帳が「いまどこに住んでいるか」を追う記録だとすれば、**戸籍は「生まれてから死ぬまでの身分関係」を、世代をまたいで積み上げていく記録です。**

**違いは、時間の長さです。**

実務は、次のような形になります。

- 届出を受けて、そのとおりに記載してよいかを法律にあてる
- **受理するかどうかの判断は、その場で求められる**
- 記載した内容は、何十年も残る
- **誤りは、相続や国籍の手続きで、ずっとあとに見つかる**
- 直すには、家庭裁判所の許可が必要になることがある

**「あとから気軽に直せない記録を、その場の判断で確定させる」仕事です。**

**企業でも、同じ構造の場面が増えています。**

契約書の原本、登記、知的財産の出願、資格や研修の記録、監査証跡。**「あとで直せばいい」が通らない記録は、どの会社にもあります。**

そして**多くの企業で、こうなります。**その場の判断は担当者に任され、**判断の根拠が残りません。****数年後に問題が出たとき、なぜそう処理したのかを誰も説明できません。**担当者はすでに異動しています。

求人票では、記録管理、法務、コンプライアンス、内部統制、監査対応といった名前で書かれています。

書くときのこつは、**個人の情報にあたることを一切書かないこと**です。**受理するかどうかをその場でどう判断したか、判断に迷ったときどこに確かめたか、判断の根拠をどう残したか、そして誤りが後から見つかったときどう直したか。**この形にすると、そのまま職務能力として読まれます。

## 市川で、どの経験が値になるか

**1. その場で確定させる判断をした経験**

**持ち帰れない判断**を日常的にしてきたことは、それ自体が職務能力です。

**2. 判断の根拠を残した経験**

**数年後に説明できるかどうか。**この感覚を持っている人は、企業にほとんどいません。

**3. 長く残る記録を扱った経験**

**何十年も残る前提で仕事をした経験**は、記録管理と監査対応でそのまま使われます。

**4. 法律の条文にあてて可否を決めた経験**

**「この届出は受理できるか」を条文で判断する。**法務の実務と同じ構造です。

## 県内・県外の求人を見るときに

市川市は東京に隣接し、**都内を担当エリアとする求人が、通勤の範囲に入ります。**

**まず職種で絞り、そのあとに勤務形態と担当エリアを確認する。**勤務地から検索を始めると、リモート可や週数日出社の求人が最初から視界に入りません。

自分の経歴がどう言い換えられるかは、一度話しながら整理したほうが早いことが多いです。[どの経験に値が付くのかから相談できます](../apply.html)。

## 職務経歴書に、市役所の仕事をどう落とすか

**制度名ではなく、判断したことを書く**

「戸籍の窓口を担当」では読み手に何も残りません。**受理の可否をその場でどう判断し、根拠をどう残したか。**

**迷った場面を書く**

**条文にあてても割り切れない届出は必ず出ます。**そのとき何をしたかを書けると、実務があったことが伝わります。

**規模を必ず書く**

市の人口、年間の届出件数、繁忙期の1日あたり件数、照会の件数。**数字を添えないと規模が伝わりません。**

## 技術職の場合は、探し方が変わる

**発注者側の経験そのものが職種になる**

「発注者支援」という職種が、建設コンサルタント業界には確立しています。設計の審査、積算の確認、工事の監督、住民説明。市役所でやってきたことが、そのまま職務内容として書かれた求人です。

**資格が入口で効く**

技術士、施工管理技士、測量士、電気主任技術者、建築基準適合判定資格者、建築士。**実務経験の年数が受験要件になっているものは、在職中でなければ積めません。**取れるものがあるなら、動く前に取っておいてください。

## 面接で必ず詰められる2つのこと

**「意思決定のスピードに耐えられるか」**

行政は手続きの段数が多く、決裁を経て動きます。民間は月次で数字を締め、その場で方針を変えます。稟議の段数を弁解せず、**自分の判断で動かした範囲を具体的に答えてください。**戸籍の受理判断のように、**その場で確定させてきた仕事があるなら、それは強い材料になります。**

**「数字への意識があるか」**

「利益を意識したことはありますか」という形で聞かれます。窓口や許認可に関わったなら、**年間の件数、繁忙期の処理量、待ち時間の変化、予算の執行率**で答えてください。「行政なので利益はありません」と答える必要はありません。

## 在職中に進めるときの注意点

**顔が知られている前提で動く**

市内の企業の多くは、市役所と何らかの接点を持っています。取引先、許認可の相手方、補助事業の対象。**在職中の活動が伝わりやすい環境**だという前提で進めてください。応募先が現在の担当業務の相手方である場合は、とくに慎重に扱う必要があります。

**服務上の扱いを先に確かめる**

在職中に得た情報を持ち出すことは避けなければなりませんし、退職後の営業活動についても扱いを確認しておいたほうが安全です。**判断に迷う場合は、応募の前に人事担当課に制度上の取扱いを確認してください。**

**面接の日程は、議会日程から逆算する**

地方自治法第211条は、長が毎会計年度予算を調製し、年度開始前に議会の議決を経なければならないと定めています。市町村は年度開始前20日までに予算を議会へ提出するようにしなければならない、とも書かれています。決算は、出納閉鎖後3か月以内の長への提出、監査委員の審査、議会の認定という順です（第233条）。**予算編成の山と定例会の会期中は、平日日中の面接を入れるのが難しくなります。**

**在職中に決める**

公務員には雇用保険が適用されないため、辞めてから探すと収入のない期間がそのまま持ち出しになります（[公務員に雇用保険がない理由](seido-shitsugyo-nashi.html)）。

## よくある質問

### 地域手当は、国が決めるのではないのですか

**国が示すのは、地域ごとの支給率の基準です。**実際に何%支給するかは、団体が条例で決めます。**全国1,721団体のうち88団体で、基準と実際の支給率が違います。**市川市は基準12%に対して実支給10%。逆に、基準を上回って支給している団体もあります。

### 基準より低く支給しているのに、総額が船橋市より多いのはなぜですか

**給料月額と、地域手当以外の手当です。**給料月額で市川市が17,000円多く、地域手当以外でも9,266円多い。地域手当では船橋市が4,444円多いのですが、**差し引きで市川市が21,822円上回ります。**地域手当だけを見ても、総額の上下は決まりません。

### 諸手当26.3%のうち、自分に関係するのはどこですか

**地域手当10%ぶんのおよそ32,420円を除いた、83,042円の部分です。**総額に占める割合でいうと18.9%。**時間外の量、担当する業務、役職、住んでいる場所で人ごとに違います。**求人票の想定年収と比べるときは、ここがどれだけ自分に付いているかが効きます。
