**「プロジェクト管理の経験がない」**とおっしゃる方がいらっしゃいます。

**計画を立て、実行し、報告してきた経験は、その型に当てはまります。**

この記事では、**対応**と、**足すべき範囲**を扱います。

## 計画から評価までが、制度として一巡します

**地方自治法第233条第1項**です。

> **会計管理者は、毎会計年度、政令で定めるところにより、決算を調製し、出納の閉鎖後三箇月以内に、**証書類その他政令で定める書類と併せて、**普通地方公共団体の長に提出しなければならない。**

**同条第2項・第3項**です。

> ２ 普通地方公共団体の長は、決算及び前項の書類を**監査委員の審査に付さなければならない。**
>
> ３ 普通地方公共団体の長は（略）**監査委員の意見を付けて次の通常予算を議する会議までに議会の認定に付さなければならない。**

**同条第5項**です。

> 普通地方公共団体の長は（略）当該決算に係る会計年度における**主要な施策の成果を説明する書類**その他政令で定める書類を併せて提出しなければならない。

**同条第6項**は、**決算の要領の公表**を義務づけています。

**予算で計画し、執行し、決算で結果を示し、審査を受け、公表する。**

**この一巡が、制度として定められている**ということです。

**行政の事業は、この型の中で進みます。**

## プロジェクト管理の型との対応

| プロジェクト管理 | 行政での経験 |
|---|---|
| ① 目的と範囲の設定 | 事業の目的、対象、実施の内容 |
| ② 計画 | **予算、工程、体制** |
| ③ 実行 | 執行、契約、事業の実施 |
| ④ 進捗の管理 | 執行の見込み、工程の確認 |
| ⑤ 課題の管理 | 遅れ、変更、苦情への対応 |
| ⑥ 報告 | **議会への説明、決算、成果の説明** |
| ⑦ 記録・振り返り | 決算の資料、翌年度への反映 |

**②と⑥が、行政ならではの厚み**があります。

**⑥について。**

**結果を、外部（議会・住民）に説明する義務がある**という点は、民間の多くの案件より厳しい条件です。

**説明できる形で記録を残す**という習慣が身につきます。

## 足すべき範囲

| 要素 | 内容 |
|---|---|
| ① 範囲の管理 | **やらないことを決める** |
| ② 変更の管理 | 変更の手続と、影響の評価 |
| ③ 危険の予測 | 起こり得る事態と、備え |
| ④ 課題の一覧 | 期限と担当を付けて追う |
| ⑤ 関係者の管理 | 誰の承認が要るか |
| ⑥ 見積りの精度 | 工数と期間 |

**①が、行政と最も違う部分**です。

**行政の事業では、対象を広く取ることが求められる場面**があります。

**民間の案件では、「今回はやらないこと」を明示して合意する**ことが重要になります。

**③と④について。**

**課題を一覧にして、期限と担当を付けて追う**という運用は、**形式が決まっています。**

**行政でも同じことをしていますが、呼び方が違う**だけです。

## 書き方の例

**悪い例**

> ◯◯事業を担当し、計画の策定から実施まで行いました。

**良い例**

> ◯◯事業（**年間予算約◯億円、関係課◯課、委託事業者◯者**）を担当。**◯か年の計画の策定を担い、現状の分析、関係課との調整、審議会への説明、意見の募集への対応を実施。**実施の段階では、**工程を月次で確認し、遅れの見込まれる案件について事業者と工程を調整。****決算にあたり、成果を説明する資料を作成し、議会での説明に対応。**

**「規模」「関係者の数」「工程の管理」「報告」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 言い換えの対応

| 行政の言葉 | 民間での読まれ方 |
|---|---|
| 計画の策定 | **計画の立案、要件の整理** |
| 予算の要求・執行 | 予算の策定・管理 |
| 工程の管理 | 進捗の管理 |
| 関係課との調整 | 関係部署との調整 |
| 委託先の管理 | 委託先・協力会社の管理 |
| 議会への報告 | 経営層への報告 |
| 決算・成果の説明 | **成果の報告、振り返り** |
| 監査への対応 | 内部統制、是正の対応 |

**7行目です。**

**成果を説明する書類を作った経験**は、**振り返りの資料の作成**として読まれます。

:::insight
プロジェクト管理について、**面談でお伝えしているのが「規模を数で書いてください」**という点です。「事業を担当しました」とだけ書かれていると、**どの程度の案件か分かりません。**プロジェクト管理の経験は、**規模で見られます。**予算の額、関係した課や団体の数、委託事業者の数、期間、対象の件数。**この5つのうち、書けるものを並べてください。**そして、**行政の事業は、規模の割に関係者が多い**という特徴があります。庁内の関係課、事業者、住民、議会、国や都道府県。**これだけの関係者を巻き込みながら期限内に進めた経験**は、民間でも通じます。**「関係課◯課、委託事業者◯者と調整のうえ、◯か年で完了」**と書くだけで、**難易度が伝わります。**規模を書かないまま「担当しました」で終えると、**小さい案件だったと読まれかねません。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 行政が相手の事業 | **年度と手続の前提が分かる** |
| ② 導入の支援 | 工程の管理、関係者の調整 |
| ③ 事業の推進・企画 | 計画から実行まで |
| ④ 建設・施設の分野 | 工程、予算、検査 |
| ⑤ 受託の管理 | 履行、変更、報告 |

**①について。**

**行政を相手とする案件は、年度で区切られ、議会の日程に影響されます。**

**この前提を織り込んで工程を引ける人**は、外から入った人には多くありません。

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 規模 | **予算、関係者の数、期間** |
| 遅れへの対応 | 3件、原因と処置 |
| 変更の扱い | 手続と、影響の評価 |
| 関係者の巻き込み方 | 誰に、どの順で |
| 振り返り | 次に何を変えたか |

**2行目です。**

**計画どおりに進まなかった案件**は、必ず聞かれると考えて用意してください。

**なお、特定の事案が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 学ぶ前に考えること

| 確認すること | 内容 |
|---|---|
| ① すでにある経験 | **担当した事業と規模** |
| ② 足りない部分 | 範囲の管理、変更の管理 |
| ③ 応募したい求人の条件 | 資格の指定があるか |
| ④ 期限 | 応募の時期までに間に合うか |

**③について。**

**求人によっては、資格が応募条件として挙げられている**ことがあります。

**記載がない場合、判断の中心にはなりません。**

**なお、資格を取れば転職できる、という関係にはありません。**

**どの規模の案件を、どう進めたか**が、評価の対象です。

## よくある失敗

**1. 規模を書かない**

**予算、関係者の数、期間**を書いてください。

**2. 「計画の策定」で止める**

**実行と報告**まで書いてください。

**3. 遅れへの対応を用意しない**

**必ず聞かれます。**

**4. 範囲の管理に触れない**

**やらないことを決める**が民間の要点です。

**5. 議会への報告を書かない**

**経営層への報告**として読まれます。

**6. 委託先の管理を書かない**

**協力会社の管理**にあたります。

**7. 課題の一覧の運用を書かない**

**期限と担当を付けて追う**形式です。

**8. 資格を取れば進めると考える**

**どう進めたか**が評価の対象です。

:::insight
ここまで型の話をしておいて逆のことを言いますが、**行政の事業と民間の案件では、失敗の扱いが違います。**面談で拝見していると、**「計画どおりに終えた」ことだけを書く方**がいらっしゃいます。行政では、**予算どおりに執行し、計画どおりに完了すること**が評価されます。一方、民間の案件では、**途中で状況が変わったときに、どう判断したか**が問われます。範囲を絞る、期限を延ばす、費用を追加する、中止する。**どれも、判断として正当**です。ですから、面接では、**「変更が生じたときに、何を基準に決めたか」**を話せるようにしてください。「対象の範囲を絞り、当初の目的のうち◯◯を優先した」という形です。**行政でも、補正や変更の契約を経験しているはず**です。**その判断の過程を、失敗としてではなく、管理の一部として書いてください。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方自治法第233条**は、**決算の調製、監査委員の審査、議会の認定、主要な施策の成果を説明する書類の提出、決算の要領の公表**を定めています
- **計画・実行・報告・公表の一巡が、制度として定められています**
- プロジェクト管理の型は、**①目的と範囲 ②計画 ③実行 ④進捗 ⑤課題 ⑥報告 ⑦振り返り**です
- 足すのは、**範囲の管理、変更の管理、危険の予測、課題の一覧、関係者の管理、見積りの精度**です
- **規模を数で書いて**ください。予算、関係者の数、期間です
- **行政の事業は、規模の割に関係者が多い**という特徴があります
- **変更が生じたときの判断**を、管理の一部として書いてください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 大規模な事業を担当したことがありません

**規模より、型が一巡しているかを書いてください。**小さな事業でも、**目的の設定、計画、実行、進捗の確認、報告**は同じです。書き方は、**「◯◯事業（予算約◯百万円、関係課◯課）を担当し、計画の作成から実施、決算の資料の作成までを一貫して担当」**という形です。**一貫して担った**という点は、規模の大きい組織では得にくい経験です。なお、**複数の事業を同時に担当していた**場合、その数も書いてください。**並行して進める力**として読まれます。

### 資格は取ったほうがよいですか

**応募条件に記載がある場合に、満たす材料になります。**記載がない場合、**判断の中心にはなりません。**なお、体系的に学ぶ手段としては有効です。**用語と型を覚えると、経験の言い換えがしやすくなる**という効果があります。「工程の管理」を「進捗の管理」、「課題の整理」を「課題の一覧の運用」と言い換えられるようになります。ただし、**応募の時期が近い場合は優先順位を下げて**ください。**職務経歴書の作成と、求人を読む作業**のほうが、時期に直接効きます。扱いは[選考スケジュールの組み方](senko-sagasu-schedule.html)に整理しています。

### 委託事業者に任せていた部分は、書けますか

**管理した側として書いてください。**「委託事業者◯者に対し、仕様に基づく履行の確認と工程の調整を実施。遅れの見込まれる工程について、代替の手順を協議のうえ決定」という形です。**自分が手を動かしていなくても、判断と調整は担っています。**これは、**民間のプロジェクト管理でも同じ構造**です。なお、**発注する側の経験**であることを明記してください。扱いは[契約書の読み方｜自治体の契約実務との差](skill-keiyakusho.html)にも整理しています。**「任せていた」ではなく「管理していた」**と書いてください。
