**育児休業の期間に、今後のことを考える方がいらっしゃいます。**

**時間の使い方が変わり、働き方を見直す機会になるため**です。

この記事では、**制度上の位置づけ**と、**確認すべき点**を扱います。

**⚠ 手当金・保険・税の扱いは、制度と規程によって異なります。****この記事は一般的な整理にとどめます。金額や要件は、必ず共済組合と所属に確認してください。**

## 育児休業は、在職中の状態です

**地方公務員の育児休業等に関する法律第2条第1項**です。

> 職員（略）は、**任命権者の承認を受けて**、当該職員の子（略）を**養育するため**、当該子が**三歳に達する日**（略）まで、**育児休業をすることができる。**

**「職員」が「承認を受けて」休業する**、という構造です。

**つまり、育児休業中も職員の身分は続いています。**

**同法第5条第1項**は、**承認が効力を失う場合**を定めています。

> 育児休業の承認は、当該育児休業をしている職員が**産前の休業を始め、若しくは出産した場合**、当該職員が**休職若しくは停職の処分を受けた場合**又は当該育児休業に係る子が**死亡し、若しくは当該職員の子でなくなった場合**には、その効力を失う。

**この条文が前提としているのも、職員であること**です。

**職員でなくなれば、育児休業という状態も続きません。**

**したがって、育児休業中の転職は「休業からそのまま転職する」のではなく、「退職して、次の勤務先に入る」という手順**になります。

## 何を確認するか

| 順 | 確認すること | 確認先 |
|---|---|---|
| 1 | **手当金の扱い**（退職した場合にどうなるか） | **共済組合** |
| 2 | 保険の切替え | 共済組合・転職先 |
| 3 | 退職手当の扱い | 所属の給与担当 |
| 4 | 復職を前提とした制度の扱い | 所属 |
| 5 | 転職先での育児に関する制度 | **転職先の人事** |

**1を最初に確認してください。**

**育児休業の期間に支給されるものは、育児休業をしていることを前提としています。**

**退職すると前提が変わるため、扱いを確認する必要があります。**

**金額と要件は制度によって異なる**ため、**共済組合に直接お尋ねください。**

## 5——転職先の制度を、応募の段階で確認する

**ここが見落とされやすい**です。

| 確認すること | 内容 |
|---|---|
| 育児に関する休業・休暇の制度 | 就業規則にどう定められているか |
| 勤続の要件 | **入社直後は対象外となる場合**があります |
| 短時間勤務の制度 | 有無と要件 |
| 子の看護に関する休暇 | 有無と要件 |
| 実際の運用 | 取得の実績があるか |

**2つ目に注意してください。**

**育児に関する制度には、勤続の年数など、対象となる要件が定められていることがあります。**

**入社してすぐに利用できるとは限りません。**

**応募の段階で、求人票と就業規則の内容を確認**してください。

**5つ目も確認に値します。**制度があることと、使われていることは別です。

## 産前産後休業中の場合

| 項目 | 一般的な整理 |
|---|---|
| 身分 | **職員のまま**です |
| 出産に関する給付 | 共済組合の制度によります |
| 転職活動 | 体調が優先です |
| 手続きの時期 | 出産の前後は手続きが重なります |

**3つ目です。**

**産前産後の期間は、体調の変化が大きい時期**です。

**この期間に無理に進める必要はありません。**

**育児休業に入ってから検討を始めても、時間は取れます。**

:::insight
育児休業中のご相談で、**面談でお伝えしているのが「復職するかどうかを、先に決めなくてよい」**という点です。多くの方が、**「復職しないなら、早く決めなければ」**と考えて急がれます。ところが、**育児休業の期間は、制度上の上限まで取れる**ものです。**その間に情報を集めること自体は、復職の判断と両立します。**面談で伺った例では、**求人を見たうえで復職を選ばれた方**も、**復職してから改めて動かれた方**もいらっしゃいます。**どちらも、情報を集めたことが判断の材料になっています。**そして、**復職してから動く場合、手当金や保険の扱いを気にせずに済む**という面もあります。**復職せずに退職する場合と、復職してから退職する場合では、確認すべきことが変わります。****この違いを先に知っておくと、判断がしやすくなります。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 面接で聞かれることへの備え

**育児の事情は、話す義務のあるものではありません。**

**ただし、勤務の条件に関わる範囲は、伝えておくほうが後の齟齬が減ります。**

| 伝える範囲 | 例 |
|---|---|
| 勤務できる時間 | 始業・終業の時間の希望 |
| 勤務できる日 | 土日の可否 |
| 出張・転勤 | 対応の可否 |
| 保育の段取り | 見込みが立っているか |

**4つ目は、聞かれることがあります。**

**「保育園が決まっているか」という趣旨**です。

**決まっていない場合、その旨と見込みを伝えて差し支えありません。**

**なお、採用の可否は勤務の条件で判断されるもの**です。

**家庭の事情そのものを詳しく説明する必要はありません。**

## 時期の組み立て

| 時期 | できること |
|---|---|
| 育児休業の前半 | 情報を集める、制度を確認する |
| 中盤 | 求人を見る、条件を絞る |
| 後半 | 応募、面接 |
| 復職の前 | 判断 |

**この順で組むと、無理がありません。**

**ただし、保育の段取りが先に決まる場合、時期は前後します。**

**保育の確保と、入社の時期を合わせる必要がある**ためです。

[経験の言い換えから相談する](../apply.html)こともできます。

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 職務経歴書の下書き | 時間の取れるときに |
| 共済組合への照会 | 制度の照会として |
| 転職先の制度の確認 | 求人票の段階で |
| 面談 | オンラインで短時間から |

**2つ目は、退職の意思を伝えずにできます。**

**「退職した場合の取扱い」を制度の照会として聞く形**です。

## 退職の意思を伝える時期

**育児休業中でも、意思を伝える手順は在職中と同じ**です。

| 項目 | 内容 |
|---|---|
| 伝える相手 | 所属長（所属の定めによります） |
| 時期 | **次の職の見込みが立ってから** |
| 方法 | 所属の定めによります |
| 引継ぎ | 休業中のため、担当の業務がない場合があります |

**2つ目です。**

**休業中であっても、次の職が決まる前に退職の意思を伝える必要はありません。**

**4つ目は、在職中の方と異なる点**です。

**休業に入る際に引継ぎを済ませている場合、退職時の引継ぎは書類の手続きが中心**になります。

**ただし、復職を前提に人員の配置が組まれていることがあります。**

**早めに伝えるほうが、所属の調整がしやすい**という面はあります。

**この点は、次の職の見込みとの兼ね合いで判断してください。**

## よくある失敗

**1. 手当金の扱いを確認せずに退職の時期を決める**

**共済組合に確認**してください。

**2. 転職先の育児に関する制度を確認しない**

**入社直後は対象外となる場合**があります。

**3. 保育の段取りと入社の時期がずれる**

**先に確認**してください。

**4. 産後すぐに進めようとする**

**体調が優先**です。

**5. 復職するかどうかを先に決めようとする**

**情報を集めてからで構いません。**

**6. 家庭の事情を詳しく説明しようとする**

**勤務の条件に関わる範囲で足ります。**

:::insight
ここまで確認の話をしておいて逆のことを言いますが、**育児休業中であることは、選考で不利に働くとは限りません。**面談で伺っていると、**「休んでいる間に応募するのは印象が悪いのではないか」と心配される方**がいらっしゃいます。ところが、**採用する側が見ているのは、入社後に何ができるか**です。**休業中であること自体が判断の対象になる場面は多くありません。**むしろ、**在職中の方より時間が取れるため、面接の日程が組みやすい**という面もあります。そして、**育児休業を取得していること自体が、制度を使いながら働いてきた実績**でもあります。**復職後の働き方を具体的に考えている**という点は、説明すれば伝わります。心配なのは印象ではなく、**制度と段取りの確認が済んでいるかどうか**です。そこが整っていれば、時期の問題は小さくなります。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方公務員の育児休業等に関する法律第2条**は、**任命権者の承認を受けて、子が3歳に達する日まで育児休業をすることができる**と定めています。**育児休業中も職員の身分は続いています**
- 同法**第5条**は承認が効力を失う場合を定めており、**いずれも職員であることが前提**です
- **手当金の扱いは、退職した場合に変わることがあります。**金額と要件は**共済組合**に確認してください
- **転職先の育児に関する制度は、応募の段階で確認**してください。**勤続の要件がある場合があります**
- **産前産後の期間は、体調が優先**です。育児休業に入ってからでも時間は取れます
- **復職するかどうかを先に決める必要はありません。**情報を集めることと両立します

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 育児休業中に応募して、いつから働けるかを聞かれました

**保育の段取りと合わせて答えてください。**「保育の確保ができ次第」という答え方では、**採用する側が予定を立てられません。**目安の時期を示したうえで、**確定していない旨を添える**形が現実的です。たとえば、「◯月の入園を申し込んでおり、結果は◯月に出ます。決まれば◯月から勤務できます」という伝え方です。**不確定であること自体は、珍しいことではありません。**伝えずに進めて、後から時期が合わないほうが問題になります。なお、**入社の時期を調整できる求人もあります。**応募の段階で、**時期の相談が可能かを確認**してください。

### 復職せずに退職すると、手当金を返すことになりますか

**制度と規程によって異なります。****一般的な整理としては、支給の要件を満たしていた期間について支給されるもの**ですが、**取扱いは制度によって違います。**この点は、**共済組合に直接確認**してください。「復職せずに退職した場合の取扱いを知りたい」という照会で、**一般的な説明が得られます。**なお、**確認は在職中にできます。**退職の意思を伝える前に、**制度の照会として聞いて差し支えありません。**金額に関わる部分なので、**人づての情報ではなく、制度を所管するところに確認**してください。

### 復職してから転職するほうがよいのでしょうか

**どちらにも理由があります。**復職してから動く場合、**手当金や保険の扱いを気にせずに進められる**という面があります。また、**復職後の働き方を実際に経験したうえで判断できます。**一方、**育児休業中に動く場合、時間が取れる**という面があります。**面接の日程も組みやすい**です。判断の材料は、**保育の段取り、体調、家族との調整、制度の扱い**の4つです。**この4つを並べて、無理のないほうを選んでください。**なお、**復職してから改めて検討する**という進め方も、**検討をやめたことにはなりません。**時期をずらす判断です。
