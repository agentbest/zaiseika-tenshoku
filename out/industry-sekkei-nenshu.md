設計事務所へ移る場合の報酬と働き方は、会社名や専門職の印象だけでは判断できません。応募する法人と職務、給与の対象、契約期間、勤務地、勤務制度をそろえて確認します。現在の公務員としての本人条件と、同じ項目で比較することが出発点です。

本記事は2026年11月時点の公開情報にもとづきます。確認日は2026年11月25日です。日本設計と日建設計の公式募集を例に整理します。給与額を転職の訴求に使わず、未確認の平均や別職務の条件から本人の待遇を推計しません。

## 専門職と事務・営業、法人を分けて比較する

総合設計事務所の仕事は、建築の意匠だけでなく、都市、構造、設備、監理、コスト等の領域へ分かれます。日本設計の公式紹介にも、複数の専門領域が協働する説明があります。会社全体が関わる工程と、一人の担当する責任を区別します。

日建設計のキャリア要項にも技術系の複数分野と、事務、営業、広報等の区分があります。同じ会社の中でも、設計、社内管理、受注営業では対象の実務が違います。別職務の給与例を、自分の条件として取り出さないようにします。

日本設計と日建設計は別の法人です。日建設計のグループ各社の応募先も、別途確認する案内があります。似た名称やグループのブランドを一つにせず、正式な雇用主と職名を記録してください。別法人の勤務制度や待遇を、本人の募集へ移しません。

行政側の発注や許認可に関わった経験と、自ら設計・計画や受注提案を行った経験も別です。本人が担った工程を確認し、専門経験があることを前提とする職務へ該当するかを照合します。待遇の希望と応募条件の充足を同じ判断にしないことが必要です。

[財政・会計の経験に接点がある掲載求人を見る](../?fin=1)ときも、法人名と正式な職務を対にして確認できます。設計事務所や希望領域の募集が常に掲載されるとは限りません。

## 公開された給与説明と、本人への提示を分ける

日本設計の確認した建築設計、都市計画、企画推進の募集では、給与は経験と能力を考慮し、会社の規定によるとされています。通勤手当と賞与の回数の案内もありますが、この説明だけで本人の基本給や賞与額、初年度の支給を算出することはできません。

経験を考慮することは、公務員の勤務年数が一定の額へ自動で換算される保証ではありません。本人が何を担当したかを整理し、正式な提示の内訳を確認します。年齢や在籍期間だけから期待額を決めないでください。

日建設計のキャリア要項にはモデル年収の紹介がありますが、モデルであって確約ではなく、業績や勤務成績で変動するとの注意が付いています。モデルの年齢と本人の年齢が一致しても、同じ額になるとは考えません。本記事では額を使って転職を勧めません。

持株会社や別のグループ企業の平均、他職務のモデルも本人の保証額ではありません。対象の法人、職務、期間、含む項目が異なる数値を一つにせず、本人への正式提示と別の資料として扱います。

## 固定、変動、初年度の対象を確認する

本人に条件が提示されたら、基本給、手当、時間外の扱い、賞与等を分けます。これは比較に必要な確認項目であり、すべての職務に同じ支給制度があるという説明ではありません。記載されていない制度を他社の情報で補わないようにします。

年間の見込みが示された場合は、何を含むかを確認します。固定して支給される部分と、評価や業績等で変わる部分があるなら別の欄にします。変動する支給を、毎月確定する基本給へ足して比べないでください。

初年度と通常年度も区別します。入職の時期や評価対象期間、支給条件が分からないものを、過去の実績やモデルから補いません。支給回数が分かっても、本人の支給額が決まるわけではありません。

現職の条件は、自分の明細や制度で確認します。ある月の支給額と応募先の年間見込みを直接比べず、同じ期間と内訳にそろえます。他の職員の給与情報や特定自治体の内部事情を持ち出す必要はありません。

## 有期契約と更新、社員登用を分けて読む

日本設計の確認した建築設計、都市計画、企画推進の欄には、契約期間1年の有期契約と記載されています。勤務成績や健康状態、会社の業務都合等で更新を判断し、通算契約期間の上限は3年、試用は2か月という説明があります。

社員登用の実績も記載されていますが、本人の更新や登用を保証するものではありません。公開された実績の割合を、本人の採用や登用の確率として使わないようにします。初年度の契約と将来の可能性は別に記録します。

別職務に違う期間や更新上限の条件がある場合も、一つの会社の標準としてまとめません。上限がないという表記を見つけても、継続が保証される意味にはなりません。本人が応募する欄と、正式な提示を照合してください。

試用中の条件、その後の扱い、更新の確認方法等は本人への説明で確かめます。日建設計の一般の要項と、日本設計の有期契約の説明も混ぜないでください。雇用区分や期間が一般ページだけで読み切れなければ、個別職務の案内と窓口で確認します。

:::insight
モデル年収と社員登用の実績は、本人への条件提示とは別に読むことを勧めます。同じ年齢の例があっても、専門実務や担当する責任が同じとは限りません。また、登用実績の紹介を、本人が必ず期間の定めのない働き方へ移る保証にはできません。給与の内訳、契約期間、更新、試用を別の欄にして確認します。現在の条件も同じ期間と項目にそろえれば、何が変わり何が未確認かが分かれます。これは待遇の高低を予想する方法ではなく、正式な法人と職務を単位に判断材料をそろえる方法です。勤務地や担当業務も含め、報酬の一項目だけで進路を決めずに比較できます。
:::

## フレックスや在宅制度と、担当業務の予定を分ける

日本設計の確認した職務には、フレキシブルタイムの範囲と、1か月の清算期間における総労働時間を示すフレックスの説明があります。時間外労働ありとも記載されています。制度の時間帯の幅を、一人が連続して働く時間や平均残業時間と同じにはしません。

日建設計の一般要項には標準の時間帯とフレックス、在宅勤務制度の紹介があります。これだけで、本人が毎日好きな場所と時間で働けるとは考えません。担当顧客との打合せ、チームの連携、現場での予定等を個別に確認します。

所定の制度と実際の担当業務で生じる時間外の扱いも別です。設計事務所は必ず長時間勤務になる、どの職務も残業がないといった未公開の実態を推測しないでください。本人が初期に何を担い、どの工程上の予定があるかを質問できます。

休日や休暇も、制度があることと本人が希望する日に利用できることを分けます。業務との調整方法や本人の適用を確認し、別職務の例で補わないようにします。現職との比較でも、片方だけを理想的な条件にしないことが必要です。

## 勤務地と専門条件を、希望とは別に照合する

日本設計の確認した募集は本社を初期の勤務地として示し、国内外の事業所・現場等を変更範囲としています。現在の場所の記載だけで、将来ずっとそこへ固定されるとは読めません。

日建設計の一般の応募資格には、国内外で勤務可能であることが含まれます。勤務地の一覧と本人の希望を分け、配属、変更範囲、出張や現場対応を個別に確認してください。希望を面談で話したことと、会社が正式に条件として提示したことは別です。

専門の応募条件も照合します。日本設計の建築設計は必要実務と一級建築士、都市計画は関連実務と指定資格のいずれかを求め、企画推進は資格不要でも関連する企画・営業実務を求めています。公務の発注や調整を、自らの設計や受注営業へ変えません。

日建設計の一般要項には募集職の実務3年以上があり、資格や語学は歓迎とされています。他社の必須と混ぜず、個別求人の最新の条件も確認します。給与条件に関心があることと、応募資格がそろっていることは別です。

## 独立した架空例で、条件確認表を作る

以下はこの記事だけの架空例です。会社が提示した待遇や実在の職員の条件ではありません。本人の事実へ置き換え、未実施の作業を削除します。架空の給与額や回答も設定していません。

| 比較項目 | 架空の本人による記入 |
|---|---|
| 希望する工程 | 都市や施設の検討を資料整理と連携から支える仕事 |
| 本人の実務 | 発注側で要求条件の担当箇所を確認し、関係課への質問をまとめた |
| 他者の役割 | 専門設計は受注者、方針と契約の決裁は上司 |
| 未経験 | 自らの建築設計、受注営業 |
| 現職の確認 | 自分の給与明細と勤務制度を確認 |
| 応募先の報酬 | 公開説明を読了。本人への額の提示は受けていない |
| 契約の確認 | 有期の期間、更新、試用、登用の本人適用を質問する |
| 場所の確認 | 初任地と国内外への変更範囲、出張等を別に確認する |
| 時間の確認 | 制度と担当業務上の予定、在宅の適用を確認する |
| 未確認 | 実務・資格の対象、初期役割、正式な雇用条件 |

この表では、発注側の経験があるだけで専門職の条件を満たすとは認定していません。モデルや登用実績を、本人への保証にもしていません。正式な説明を受けた項目へ、確認日と対象職務を添えて更新できます。

[仕事内容と条件の比較を相談する](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担）。経験や希望によっては、面談・求人紹介を提供できない場合があります。

## 情報を守り、現職継続も同じ項目で比べる

住民や事業者の情報、非公開の計画・調達・許認可・契約内容を持ち出したり、私用AIへ入力したりしません。委託先の図面や専門計算を本人の制作実績にせず、公開・利用できる範囲と担当を確認します。行政上の便宜や内部人脈を、受注の強みとして提供する約束もしないでください。

募集の確認日と職名を残し、更新があれば以前の条件と分けて読みます。一般の制度紹介と本人の予定業務への説明を区別し、質問を用意したこと、送ったこと、回答を受けたことを別に記録します。正式な条件が未確認のまま、住居や退職の予定を確定しないようにします。

本人が必須とする条件と調整できる希望も分けられます。特定の場所で働く必要があることと、将来専門性を深めたいことは別です。在職中に仕事内容や要件を調べる進め方もあり、応募を始めたことだけで退職を先に決める必要はありません。

本人の経験の説明にも、担当した期間と分担を残します。引継ぎ後に資料を更新したことを、構想全体を自分で設計した経験へ広げないでください。待遇の希望を伝えるために、他者の設計や上司の決裁を加える必要はありません。公開募集と受けた説明が違うように見えるときは、対象職務と適用時点を添えて質問し、自分の解釈だけで一方の条件を選ばないようにします。

現職で公共施設や都市の条件整理を深める選択もあります。自ら専門設計や提案を担いたいのか、発注側の確認・調整を続けたいのかを分け、現職と応募先を同じ項目で比較します。

[行政に接点のある掲載求人を比較する](../?gov=1)際も、望む工程と働く条件を並べられます。

:::insight
報酬に関心があっても、本人が担いたい責任と勤務条件が合うかは別に確かめることを勧めます。発注側の条件整理を深めたい人と、自ら設計や受注提案を行いたい人では選ぶ役割が変わります。現職で希望する工程を続けられるなら、残る判断も比較対象です。会社の作品やモデルの印象を、本人の配属と契約が合う根拠にしないようにします。期間、勤務地、時間の本人適用を確認し、未確認は質問に残せます。公開制度と正式な提示を分け、応募や面接を終えたことだけで退職を決めず、仕事と生活の情報がそろった時点で進路を考えられます。空欄を予想で埋めず、必要な判断材料を明確にして残せます。
:::

## まとめとよくある質問

設計事務所の待遇は、正式な法人と職務を単位に確認します。モデルと本人提示、有期契約と登用、勤務制度と本人適用を分けて比較してください。

### モデル年収と同じ年齢なら同額になりますか

その保証はありません。紹介した案内もモデルの変動や非確約を示しています。本人の経験と正式な提示を確認し、未確認の額を推計しないようにします。

### 社員登用実績があれば将来は無期ですか

本人への保証ではありません。初年度の契約、更新、登用の扱いを別に確認します。公開実績を本人の確率として使いません。

### フレックスや在宅制度があれば自由に働けますか

制度と実際の職務の適用は別です。顧客対応、現場、チームの連携等の予定を確認し、本人への正式な説明と照合してください。
