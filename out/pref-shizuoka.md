静岡県庁の給与データには、他県と比べて際立った特徴があります。**ラスパイレス指数102.2。**国家公務員の水準を100としたときに、2.2ポイント上回っています。

この記事で扱ってきた都道府県のなかで、**最も高い水準**です。東京都と山梨県が100.5、神奈川県が100.0ですから、静岡県はそれらを明確に超えています。

「地方の県庁だから、民間に移れば給与は上がるはずだ」という前提で動くと、判断を誤る可能性があります。まず数字を正しく読み解いてください。

## 静岡県庁の給与水準を、数字で確認する

総務省の調査によると、静岡県の一般行政職は次のとおりです（令和6年4月1日現在）。

| 項目 | 静岡県 |
|---|---|
| ラスパイレス指数 | 102.2 |
| 平均年齢 | 42.7歳 |
| 平均給料月額 | 333,500円 |
| 諸手当月額 | 100,147円 |
| 平均給与月額 | 433,647円 |
| 平均給与月額（国ベース） | 371,183円 |
| 地域手当（国の指定基準） | 3.7% |
| 地域手当（実際の支給割合） | 約4.68% |

### ラスパイレス指数102.2が意味すること

この指数は、**学歴や経験年数の差を補正して**計算されるため、団体間の給与水準を直接比べられます。並べると、静岡県の位置がはっきりします。

| 都県 | ラスパイレス指数 | 地域手当（実支給） |
|---|---|---|
| **静岡県** | **102.2** | **約4.68%** |
| 東京都 | 100.5 | 約18.72% |
| 山梨県 | 100.5 | 約3.63% |
| 神奈川県 | 100.0 | 約14.24% |
| 岐阜県 | 99.3 | 約3.86% |

**静岡県は、東京都より高い指数を、はるかに低い地域手当で実現しています。**上乗せ手当ではなく、**給料表そのものの水準が高い**ということです。

加えて諸手当100,147円も、地域手当が約4.68%であることを考えると、**地域手当以外の手当の積み上がりが大きい**構造だと分かります。

:::insight
この数字は、転職の判断に直接効きます。相談の場で「地方の県庁だから、民間に移れば上がるはずだ」と考えている方に会うことがありますが、**静岡県の場合、その前提は成り立ちにくい**と考えたほうがよいでしょう。だからといって動けないという意味ではありません。**確かめる方法は簡単です。自分の源泉徴収票の支払金額を出して、求人票の想定年収と並べる。**団体の平均でも指数でもなく、自分の実額です。ここを飛ばして印象で判断すると、条件の良い求人を外したり、逆に安い条件を受けたりします。なお、諸手当のうち業務量に連動する部分は配属や年度で変わり得るので、**複数年の源泉徴収票を並べてぶれ幅を見る**とさらに正確になります。
:::

なお、上の平均は自分の給与ではありません。**平均給料月額（年齢構成の影響を受ける）とラスパイレス指数（補正済み）は意味が違うので、混ぜて読まないでください。**

| 予算の要求・査定、財政計画 | 予実管理、投資判断、経営企画 |
| 防災計画の策定と訓練の運営 | BCP、リスク管理、危機管理 |
| 企業誘致・立地支援 | 事業開発、用地開発、アライアンス |
| 産業支援・技術支援の施策 | 産学連携、技術企画、事業開発 |
| 港湾・物流の計画と調整 | インフラ企画、物流ネットワーク設計 |
| 農林水産の産地形成・輸出支援 | 事業開発、産地開発、海外展開 |
| 観光の誘客・受入環境整備 | 観光事業企画、地域ブランディング |

| 市町への助言・支援 | パートナー支援、カスタマーサクセス |

部署ごとの詳しい対応は[自治体の部署別 仕事ガイド](../zukan.html)にまとめています。財政課であれば[財政課の経験は民間で何と呼ばれるか](dept-zaisei-honyaku.html)で、さらに細かく分解しています。

## 静岡で、どの経験が値になるか

**1. 防災の実務は、全国で最も厚い部類**

静岡県は、大規模地震への備えを長年にわたって積み重ねてきた県です。県庁には**計画の策定、訓練の設計と運営、関係機関との調整、備蓄と輸送の設計、住民への周知**という一連の実務があります。

民間側では、BCPの策定、リスク管理、安全管理といった職務がこれに当たります。近年はどの業界でも事業継続の体制整備が求められており、**実際に計画を作り、訓練で動かした経験**を持つ人は多くありません。

書くときのこつは、**計画名を並べないこと**です。何者を動員し、どの想定でどう動かし、訓練の結果から何を変えたか。**設計と改善のサイクルを回した経験として書けば、業界を問わず読まれます。**

**2. 輸送用機器を中心としたものづくりと企業支援**

自動車、二輪、楽器、製紙、食品、医薬・医療機器。静岡県は製造業の集積が厚い県で、県庁には企業支援と誘致の実務があります。**補助制度の設計、人材確保の支援、用地とインフラの手当て、取引先とのマッチング。**

とくに医薬品・医療機器は規制産業です。**許認可や監視指導を担当していた方は、企業側の薬事管理・品質保証・規制対応の職務にそのまま接続します。**企業が知りたいのは条文の解釈ではなく、実際にどこを見られるかという運用のほうです。

**3. 東西に長い県土で、複数の経済圏を扱ってきた経験**

伊豆、東部、中部、西部。静岡県は経済圏が複数に分かれており、産業の構成も課題も地域ごとに違います。**同じ制度を、条件の違う地域に当てはめる。**この経験は、全国展開する企業がいちばん苦労するところです。

**4. 港湾と物流**

港湾を抱える県として、物流と立地に関わる実務があります。**用地、環境影響、地元調整、他の管理者との協議。**物流施設の開発が全国で進むなか、立地に伴う行政手続きを知っている人は事業者側にほとんどいません。

**5. 市町を相手にしてきた経験**

政令市から小規模な町まで、規模の幅が大きい県です。**同じ制度でも、相手の体制によって進め方をまったく変えなければならない。**この経験は、自治体を顧客にする企業から見ると、そのまま実務能力です。

## 首都圏・名古屋圏の求人も、視野に入れてよい

静岡県は新幹線で首都圏とも名古屋圏ともつながっており、**転居せずに両方の求人に応募できる**位置にあります。

ここで多いのが、通勤時間だけで線引きしてしまう判断です。近年はリモート可、週数日出社といった勤務形態の求人が増えています。とくに自治体を顧客にする企業は、担当エリアに出向くことが仕事なので、本社への出社頻度が低い場合があります。

**まず職種で絞り、そのあとに勤務形態を確認する。**勤務地から検索すると、県内では出会えない職種が最初から視界に入りません。

## 職務経歴書に、県庁の仕事をどう落とすか

**制度名ではなく、判断したことを書く**

「○○推進事業を担当」では読み手に何も残りません。事業名は庁内でしか意味を持たない固有名詞です。**何件を、どういう基準で審査し、どこで判断が割れて、どう決着させたか。**

**防災の仕事は「担当」で終わらせない**

計画を作った、訓練をやった、では何ができる人なのか伝わりません。**動員した機関と人員の数、想定の置き方、訓練で見つかった問題と、その後どう直したか。**ここまで書いて初めて、設計と改善の経験として読まれます。

**異動歴を「立ち上げの回数」に変える**

異なる制度領域を短期間で立ち上げてきた経験は、民間では**キャッチアップの速さ**として読まれます。編年式で並べ、それぞれの配属で最初の数か月に何を習得したかを1行添えてください。

## 技術職の場合は、探し方が変わる

**発注者側の経験そのものが職種になる**

「発注者支援」という職種が、建設コンサルタント業界には確立しています。設計の審査、積算の確認、工事の監督、住民説明。県庁でやってきたことが、そのまま職務内容として書かれた求人です。

**資格が入口で効く**

技術士、施工管理技士、測量士、電気主任技術者。**実務経験の年数が受験要件になっているものは、在職中でなければ積めません。**取れるものがあるなら、動く前に取っておいてください。

**耐震・津波対策の実務は特殊な資産になる**

構造物の耐震化、海岸保全、避難施設の整備。この領域を発注者側で扱った技術者は限られており、**同じ課題を抱える地域の事業では強く求められます。**

## 面接で必ず詰められる2つのこと

**「意思決定のスピードに耐えられるか」**

行政は手続きの段数が多く、決裁を経て動きます。民間は月次で数字を締め、その場で方針を変えます。稟議の段数を弁解せず、**自分の判断で動かした範囲を具体的に答えてください。**災害対応や訓練で即断した経験があるなら、それが最も分かりやすい材料になります。

**「数字への意識があるか」**

「利益を意識したことはありますか」という形で聞かれます。「行政なので利益はありません」と答えると、そこで話が終わります。事業の優先順位を付けた、単価の根拠を詰めた、複数案を比べた。**同じ思考をしていたことを、民間の言葉で説明できるか**が見られています。

## 在職中に進めるときの注意点

**顔が知られている前提で動く**

県内の企業の多くは、県庁と何らかの接点を持っています。取引先、許認可の相手方、補助事業の対象。**在職中の活動が伝わりやすい環境**だという前提で進めてください。応募先が現在の担当業務の相手方である場合は、とくに慎重に扱う必要があります。

**服務上の扱いを先に確かめる**

在職中に得た情報を持ち出すことは避けなければなりませんし、退職後の営業活動についても扱いを確認しておいたほうが安全です。**判断に迷う場合は、応募の前に人事担当課に制度上の取扱いを確認してください。**

**面接の日程は、議会日程から逆算する**

地方自治法第211条は、長が毎会計年度予算を調製し、年度開始前に議会の議決を経なければならないと定めています。都道府県は年度開始前30日までに予算を議会へ提出するようにしなければならない、とも書かれています。決算は、出納閉鎖後3か月以内の長への提出、監査委員の審査、議会の認定という順です（第233条）。**予算編成の山と定例会の会期中は、平日日中の面接を入れるのが難しくなります。**

**在職中に決める**

公務員には雇用保険が適用されないため、辞めてから探すと収入のない期間がそのまま持ち出しになります（[公務員に雇用保険がない理由](seido-shitsugyo-nashi.html)）。

:::insight
ここまで転職の話を書いてきましたが、**残る判断にも理があります。**とくに静岡県の場合、ラスパイレス指数102.2という水準を考えると、**「水準を上げるための転職」は成立しにくい**かもしれません。それでも動く理由があるとすれば、水準ではなく**仕事の中身のほう**です。制度を運用する側から、事業を作る側へ。判断の材料としては、こちらを軸に考えたほうが噛み合います。いま担当している領域で通しの経験が積み切れていないなら、それを終えてから動くほうが、書けることは確実に厚くなります。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 静岡県の一般行政職は**ラスパイレス指数102.2、平均給与月額433,647円**（令和6年4月1日現在・総務省調査）
- **指数はここまで見てきた都道府県で最も高い水準**です。しかも地域手当は約4.68%で、**給料表そのものの水準が高い**構造です
- 「地方だから民間に移れば上がる」という前提は成り立ちにくい。**自分の源泉徴収票の支払金額と、求人票の想定年収を並べてください**
- 経験が効く方向は、**防災の実務／ものづくりと企業支援／複数の経済圏を扱った経験／港湾と物流／市町支援**の5つです
- 防災の仕事は「担当」で終わらせない。**動員した機関の数、想定の置き方、訓練で見つけた問題とその後の改善**まで書いてください
- 動く理由は水準ではなく**仕事の中身**を軸にしたほうが噛み合います

## よくある質問

### ラスパイレス指数が高いということは、転職すると下がりますか

**職種と応募先によります。**指数が高いのは事実ですが、それは国家公務員と比べた給料月額の話です。民間では職種と等級で決まるため、行政を顧客にする事業や、専門性がそのまま値付けされる職種では下がらないこともあります。**まず「自分の経験がどこで希少になるか」を決めてから、水準の話をしてください。**先に水準から入ると、選択肢が不必要に狭まります。

### 防災の経験は、どんな企業で評価されますか

**製造業、インフラ、物流、金融、そして規制の厳しい業界全般**です。近年はどの業界でも事業継続の体制整備が求められており、BCPの策定と訓練の運営は独立した職務になっています。**実際に計画を作り、訓練で動かし、その結果から計画を直した経験**を持つ人は多くありません。書くときは計画名ではなく、動員した機関の数と改善の中身で書いてください。

### 県庁と静岡市・浜松市では、転職のしやすさが違いますか

**経験の翻訳という点では、大きな違いはありません。**どちらも制度を回す側の経験です。強いて言えば、県は広域と市町の調整の仕事が多く、政令市は住民と事業者を直接相手にする仕事が多いため、**「誰を相手にしてきたか」の説明の仕方が変わります。**自治体向けの事業を持つ企業では県の経験が、住民接点のあるサービス業では市の経験が噛み合いやすい傾向があります。
