広告・PR会社で働いたことがなくても、募集職務と自分の担当経験を照合することはできます。ただし、自治体で広報や調整に関わったことを、商業PRの全工程を経験したことへ置き換えません。業界の在籍経験と、実際に行った作業、これから担う専門的な責任を分けて調べます。

本記事は2026年11月時点の公開情報にもとづきます。確認日は2026年11月25日です。公式の中途募集を使った確認方法を示すもので、未経験者の採用率や内定保証、非公開の面接質問・評価理由を示すものではありません。

## まず希望する仕事を、担当工程に分ける

広告・PR会社の仕事には、顧客の課題整理、戦略の立案、施策の提案・実行、制作、広告運用、効果の確認などがあります。会社が提供する範囲と、個人が担当する範囲を分けます。広報原稿の作成が好きだからといって、すべての募集が原稿制作中心の仕事とは限りません。

プラップジャパンのキャリア採用ページには、PRコンサルタントとPRプランナーという別の職務があります。PRコンサルタントは顧客の課題に対して企画から実行等へ関わる仕事、PRプランナーは戦略の立案に特化した仕事として説明されています。職務の名称だけで、どちらが未経験者向きかを決めないでください。

ベクトルの公式業務説明では、PRコンサルタントがコミュニケーション施策の企画・実行を担い、ホームページ制作や広告運用などの実務では子会社と連携するとされています。プロジェクトを進めることと、本人が専門制作を行うことは別です。どの工程を自分で行い、誰と連携するかを確認します。

正式な法人と応募職務も記録します。グループのブランド、採用窓口、配属先、契約上の雇用主を混ぜないようにします。ベクトルの中途募集にはPR事業会社3社のいずれかへの配属が示されていますが、在籍や出向等の形態まで、その記載だけから補わず正式に確認します。

[行政に接点のある掲載求人を見る](../?gov=1)ときも、業界名の次に、顧客と担当工程を読むことから始められます。広告・PR会社や希望する職務が常に掲載されるとは限りません。

## 必須条件の選択肢と、同時に必要な条件を読む

プラップジャパンのPRコンサルタント募集では、大卒以上と、列挙条件のいずれかに対応する方という案内があります。コミュニケーション関連の業界経験には年数の目安があり、ほかにも折衝、企画提案、論理的思考、調査分析、デジタル等に関する項目が挙げられています。

この列挙をすべて同時に満たす専門経験へ読み替えたり、業界経験の項目だけを取り出してほかの選択肢を消したりしないようにします。一方、公務員として調整したことがあるだけで、能力要件を満たすとも認定しません。本人が説明できる事実を整理し、どの範囲が対象か不明なら採用窓口へ確認します。

英語の使用経験、PR関連の得意分野、リーダー経験等の尚可要件も、必須条件とは別です。歓迎される項目に一つ接点があるから、学歴や必須の条件を確認しなくてよいという意味にはなりません。本人の学歴や職歴は事実に沿って記載し、募集に合わせて補完しないでください。

PRプランナーの募集は、専門実務の選択肢を示しています。コピーライターやデザイナー等の経験、コミュニケーション戦略やPR戦略の立案、事業会社でのPR等の企画・ディレクションなどがあり、2〜3年以上の目安が記載されています。一般的な文書作成経験を、そのまま専門職の経験に変えないことが必要です。

| 読む項目 | 本人が整理すること | 避ける読み替え |
|---|---|---|
| 学歴等の条件 | 本人の確認できる情報 | 任用や職位から学歴を推定する |
| 経験・能力の選択肢 | 対応する実務と説明できる範囲 | 列挙条件を無断で全部必須にする |
| 専門経験の目安 | 職務内容と担当期間 | 在籍期間を専門経験年数にする |
| 尚可要件 | 追加で説明できる事実 | 必須条件の代わりにする |
| 勤務条件 | 希望と正式提示を分ける | 応募可能なら条件も合うと決める |

## 公務員経験は、作業と判断と成果を分けて使う

行政で広報、説明、会議運営、資料の確認等を担当した場合、本人が実施した工程を整理できます。誰に何を伝える目的だったか、どの根拠を確認し、何を作り、誰に判断を求めたかを書きます。部署名や「コミュニケーション力」だけで終わらせないことが大切です。

たとえば制度案内の担当原稿を作成したなら、対象者と手続き条件の照合、関係課への確認、原稿の作成、公開前の確認のうち、自分の工程を示します。上司の方針決定、委託先のデザインや撮影、別担当のメディア対応は分けて記載します。

商業PRで顧客へ提案する立場には、別の役割があります。顧客の課題を整理し、施策を企画して説明し、合意した範囲で実行する仕事を経験していなければ、未経験として残します。行政の住民対応を、有償の顧客提案へそのまま置き換える必要はありません。

結果の説明も、測定した範囲に限定します。原稿を公開したことは説明できても、閲覧率や問い合わせ削減を測っていなければ数字を加えません。組織の施策が公表された場合でも、本人の担当部分と全体の成果を区別します。未経験を隠すために成果を広げないようにします。

:::insight
業界の在籍経験がないことと、関連する作業を何もしていないことは別です。案内の根拠を確認し、関係課の情報をそろえ、読み手に必要な順序へ原稿を整理したなら、その工程を本人の事実として残せます。一方で、商業PRの戦略や広告運用まで行ったことにはできません。既に経験した工程、近いが役割の違う工程、未実施の工程に分けることを勧めます。求人の経験条件へ当てはまるかは別に確認し、表現を大きくして埋めないようにします。これは採用側の評価を予想する方法ではなく、経験と今後の学習対象を分けて説明する方法です。本人の範囲を保つことで、初期に担う役割についての質問も作れます。
:::

## 独立した架空例で、応募準備を具体化する

以下はこの記事だけの架空例で、実在の応募者や採用成功例ではありません。本人の事実に置き換え、実施していない作業を削除します。企業からの回答、配属先、選考結果は設定していません。

架空の本人は、自治体の事業案内の担当部分を作成し、関係課に条件を確認した経験があるとします。希望する役割は、発信の目的整理と企画を支える仕事です。商業PRの有償提案と広告運用は未経験という設定です。

| 項目 | 架空の本人による記入 |
|---|---|
| 自分が担当したこと | 事業の対象者と申請条件を関係課へ確認し、担当原稿を作成した |
| 本人の工夫 | 対象者の条件と手続きの順序を分け、確認事項を一覧にした |
| 他者の役割 | 発信方針と最終承認は上司、デザインは委託先 |
| 関連しそうな工程 | 情報の照合、説明事項の整理、関係者への確認 |
| 未経験 | 外部顧客への有償PR提案、広告運用、施策の効果測定 |
| 応募条件 | 本人の学歴・職歴を確認してから、個別募集の条件と照合する |
| 質問したいこと | 自分の担当実務が対象に含まれるか、初期の担当工程と他部署との分担 |
| 勤務条件 | 雇用主、配属の形態、場所の変更範囲は未確認 |
| 現在の準備 | 担当期間と工程のメモを作成。応募書類の送信は未実施 |

この例では、学歴や能力要件の充足を架空設定で結論付けていません。本人の担当事実がそろったら、募集原文と照合して不明点を質問します。確認した日付と職名を残し、問い合わせを送った段階と回答を受けた段階を分けます。

[広報や調整の経験と応募要件の対応を相談する](../apply.html)場合も、内部資料ではなく自分の言葉で整理した工程を使えます。ご利用は無料です（紹介手数料は採用企業の負担）。経験や希望によっては、面談・求人紹介を提供できない場合があります。

## 書類と選考は、本人の中途募集に沿って進める

ベクトルの中途PRコンサルタント募集では、履歴書と職務経歴書の案内があり、履歴書には前職の転職理由と志望動機を記載するとされています。選考は書類と複数回の面接、リファレンスチェックの実施が示されています。これは当該募集の案内で、全社共通や業界共通のフローとして広げません。

プラップジャパンを調べる場合も、中途の応募ページと、新卒の説明会や早期・春の選考案内を区別します。新卒の日程を、在職中の本人の中途選考へそのまま当てはめないでください。必要書類、提出先、日程は、応募する正式職務の案内で確認します。

面接へ向けては、本人の課題、行動、分担、確認できた結果を説明できるようにします。特定の質問が必ず出る、面接官は公務員にこう感じる、といった予想を準備の前提にしません。公開募集との接点と未経験を整理し、どの役割を今後学ぶ必要があるかを質問できます。

自主的に制作例を用意する場合も、企業が求める提出物と区別します。架空の課題で作成した案は、その旨を示し、実際の採用案件や仕事の成果としません。提出を求められていないものを大量に送ることが有利だと考えず、必要な形式と範囲を確認してください。

## 情報管理と、現在の立場の境界を守る

経験を説明するために、未発表の事業計画、住民や事業者の個人情報、内部の契約・調達情報を持ち出さないでください。私用端末への保存や私用AIへの入力も避けます。名前だけ消しても案件を特定できる場合があるため、公開情報と本人の工程で説明します。

委託先の制作物を提出する場合も、本人が作ったものと混同せず、利用できる範囲を確認します。組織の資料を本人のポートフォリオとして自由に使えるとは決めません。提示できない資料があれば、その範囲を守って自分の作業を言葉で説明する進め方ができます。

行政上の便宜を提供できることや、現職の連絡先を営業先へ利用できることを強みにしないようにします。募集職務との接点は、制度を調べた工程や説明・調整の経験です。権限や内部情報を転職先に渡す話へ変えません。

学習計画も、応募する職務に合わせて考えます。PRの企画を学びたいのか、制作の技術を身に付けたいのか、顧客の課題整理を担いたいのかによって対象は変わります。講座を受けたことを実務経験として数えず、自主学習と仕事で行ったことを分けて記載します。

## 働く条件と現職継続を、同じ項目で比べる

応募できる職務が見つかったことと、本人に合う働き方であることは別です。担当する顧客、企画と実行の範囲、勤務地、出向や配属、時間の制度を確認します。会社全体の幅広い仕事を、自分の希望する案件に関われる保証へ変えないでください。

現職で広報や説明業務を深める選択もあります。外部顧客を支援したいのか、現在の行政サービスの情報発信を続けたいのかを分けると、調べる職務が明確になります。応募準備を始めたことだけを理由に、退職を先に決める必要はありません。

[行政に接点のある掲載求人を比較する](../?gov=1)際も、現職を含めて希望する工程と勤務条件を並べられます。

:::insight
未経験から調べる段階では、会社の知名度より、どの相手に何を提供する仕事を望むかを確認することを勧めます。原稿の作成を深めたいのか、顧客の課題整理から施策の実行まで担いたいのかで、選ぶ役割は変わります。現職で希望する工程を続けられるなら、残る判断も同じように比較できます。応募条件に接点があっても、配属や働く場所が本人の必須条件と合うかは別の質問です。経験を募集の言葉へ大きく置き換えるより、実施した工程と未経験を分けて伝えます。必要な確認がそろうまで判断を残し、学ぶ対象と担当責任を明らかにしてから進路を考えられます。
:::

## まとめとよくある質問

未経験から広告・PR会社を調べる場合は、個別の募集職務と条件を確認します。公務員経験を工程として残し、商業PRの未経験、専門要件、働く条件を別々に照合してください。

### 自治体広報を担当したなら業界経験者ですか

同じものとは扱いません。担当した対象、目的、確認や作成の工程を記載し、商業PRとの接点と未経験部分を分けます。募集でどの経験に含まれるか不明なら窓口へ確認します。

### 文書を作る仕事をしていればPRプランナーへ応募できますか

文書作成だけで専門経験を満たすとは判断できません。紹介した募集には戦略立案や専門制作等の選択肢と年数の目安があります。本人の担当工程と期間を原文へ照合してください。

### 制作例がなければ内部の広報資料を提出すべきですか

自由に持ち出して提出するものではありません。公開範囲や利用できる権限、本人と他者の担当を確認します。秘密や個人情報を含めず、求められる提出物を確認して、自分の工程を説明してください。
