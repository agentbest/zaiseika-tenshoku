交通局や公営企業の職務経歴書で、いちばん多い失敗はこれです。

**「交通局において公営企業の経営に関する業務に従事」**

**この1行で終わってしまいます。**

読む側は、ここから**「役所の交通の担当だった人」**という像しか作れません。実際には、**数百台の車両を毎日決まった時刻に出し、法定の周期で検査し、路線ごとの収支を出し、税で持つ部分と料金で回す部分を切り分けて説明し、事故が起きれば止めて、再開の判断までしていた**わけですが、それが書かれていません。

この記事では、**職務要約・担当業務・実績**の3つに分けて、悪い例と良い例を並べます。

言い換えは[交通・公営企業の経験は民間で何と呼ばれるか](dept-kotsu-honyaku.html)、行き先は[交通・公営企業から転職しやすい業界と職種](dept-kotsu-tenshokusaki.html)に書いています。

## 「収入をもつて充てなければならない」と、その例外が書かれています

書き方に入る前に、この仕事の性格を条文で押さえます。**書類の芯になる部分**です。

**地方公営企業法第17条の2**です。

> 次に掲げる地方公営企業の経費で政令で定めるものは、地方公共団体の一般会計又は他の特別会計において、出資、長期の貸付け、負担金の支出その他の方法により負担するものとする。
> 一 その性質上当該地方公営企業の経営に伴う収入をもつて充てることが適当でない経費
> 二 当該地方公営企業の性質上能率的な経営を行なつてもなおその経営に伴う収入のみをもつて充てることが客観的に困難であると認められる経費
> 2 地方公営企業の特別会計においては、その経費は、前項の規定により地方公共団体の一般会計又は他の特別会計において負担するものを除き、当該地方公営企業の経営に伴う収入をもつて充てなければならない。

**ここが、書類の芯です。**

**原則は、収入で経費をまかなう。**独立採算です。**ただし、性質上それが適当でない経費と、能率的に経営してもなお困難な経費は、一般会計が負担する。**

つまり、**この仕事は「税で持つ部分と、料金で回す部分を、切り分けて説明する」仕事**です。どの路線の、どの経費が、どちらに当たるか。**その線を毎年引いて、根拠を示し、繰入れの額を協議する。**

民間で人を採る側から見ると、これは**「親会社の補助と自力の採算を切り分けて、事業の損益を説明できる人」**です。**グループの子会社、補助を受ける事業、公共性のある事業**——**同じ構造の説明が求められる場面は、民間にいくつもあります。**

職務経歴書には、**この「切り分けて説明した」範囲が見えるように書いてください。**

## 職務要約

### 悪い例

> 交通局において、公営企業の経営に関する業務に従事。運行管理、車両管理、経理等を担当。

**これでは、規模も、判断の範囲も読めません。**

### 良い例（運行と現場が長い方）

> ◯路線、車両約◯台、乗務員約◯人、年間輸送人員約◯万人のバス事業において、営業所の運行管理を担当。ダイヤの編成、乗務員の配置、車両の割り当て、運行の異常時の対応を実施。安全管理規程に基づく点呼と指導、事故の再発の防止の手順の整備を担当。

### 良い例（経営と企画が長い方）

> 年間輸送人員約◯万人、経常収益約◯億円のバス事業において、経営の企画を担当。路線別の収支の分析、一般会計からの繰入れの根拠の整理と協議、運賃の改定の試算と認可の申請、公営企業会計による決算の調製を実施。◯路線の再編の案を策定し、沿線の説明会と議会への説明を担当。

**太字にしなくても、数字が入っているだけで読み方が変わります。**路線数、車両数、乗務員の数、年間の輸送人員、経常収益。**この5つのうち、分かるものから埋めてください。**

:::insight
この経歴の職務経歴書で、**書けるのに書かれていないことの筆頭が「一般会計との負担の協議」**です。面談で伺うと、**「繰入金の事務を担当していました」**という言い方をされます。ところが、中身は、**どの経費が「収入で充てることが適当でない」に当たり、どの経費が「能率的に経営してもなお困難」に当たるかを、路線ごと、費目ごとに整理し、根拠を付けて財政の部署と協議し、額を確定させる**という仕事です。**これは、親会社との資金の調整そのもの**です。民間でいえば、**グループ内の負担の区分の設計、補助の申請と根拠の整理、事業の損益の説明**に当たります。**「繰入金」という言葉は、求人票には出てきません。**同じ仕事は、**「事業採算の説明」「資金計画」「ステークホルダーとの調整」**と書かれています。書くなら、**「一般会計からの繰入れについて、路線と費目ごとに負担の区分の根拠を整理し、年間約◯億円の繰入れを財政の部署と協議して確定」**という形です。**この一行があると、事業の損益を説明できる人として読まれます。**
:::

## 担当業務

**「公営企業の経営」で丸めず、6つに分けてください。**

| 機能 | 書き方の例 |
|---|---|
| 運行 | ◯路線のダイヤの編成、乗務員約◯人の配置、車両の割り当て、運行の異常時の対応 |
| 車両と施設 | 車両約◯台の法定の検査と保守、更新の計画、営業所と車庫の施設の保全 |
| 営業 | 運賃と定期券の設計、ICカードの運用、広告と関連事業、乗客からの苦情の対応 |
| 経営と会計 | 路線別の収支の分析、一般会計との負担の協議、運賃の改定と認可、公営企業会計 |
| 安全 | 安全管理規程の運用、点呼と指導、事故の対応と再発の防止、監査への対応 |
| 企画と再編 | 路線の再編、需要の分析、地域の交通の計画への参画、民間との共同の運行 |

**この6つのうち、自分がやっていないものは書かなくて構いません。**むしろ、**やっていない機能を空欄にしたほうが、やった機能の密度が読まれます。**

**とくに、4番目の「経営と会計」**は、**一般会計しか知らない行政の経歴とは、明確に違う部分**です。**損益と資金を見ていたなら、必ず書いてください。**

**もう1つ、5番目の「安全」も書き落とされやすい部分**です。点呼、指導、事故の対応。**毎日やっていることなので、実績だと思われていない。**ところが、**民間の交通と物流では、安全の管理体制を回した経験が、そのまま求人票の条件になっています。**書くなら、**「安全管理規程に基づく点呼と指導を営業所で運用。事故の報告の様式と再発の防止の手順を整備し、年◯回の安全の会議を主催」**という形です。**民間でも、同じ法律のもとで同じ体制を持っています。**

## 実績

**ここが書きにくい部分です。**成果が、**毎日ちゃんと走っていること**として現れるからです。

### 悪い例

> 安全運行の確保と経営の健全化に努め、市民の足を守った。

**これは、姿勢の話であって、実績ではありません。**

### 良い例——3つの型

**型1：基準と手順を作った**

> 運行の異常時の連絡と判断の手順を、事象の区分ごとに整理し、夜間と休日の連絡の経路を含めて文書化。営業所の当番が単独で判断しない形に変更。

**型2：収支を動かした**

> ◯路線について、路線別の収支と輸送人員を分析し、減便と経路の変更を組み合わせた再編の案を策定。年間約◯円の収支の改善を見込み、沿線の説明会◯回と議会への説明を経て実施。

**型3：体制を作った**

> 車両の更新の計画を、走行の距離と年式から優先順位を設定する形に整理。年間約◯台、約◯億円の更新を計画に位置づけ、予備の車両の台数を運行と保全の両方から決定。

**3つとも、「維持した」ではなく、「自分が設計した」で書かれています。**

**このうち、型2はとくに数字にしやすい実績**です。路線の再編は、**前後の収支と輸送人員が残ります。**民間の事業の再編でも、**「どれだけ改善したか」は、いちばん伝わる形**です。ただし、**個別の路線名や、住民の反対の中身は書かなくて構いません。****「収支と輸送人員を分析して案を作り、説明を経て実施した」という骨で十分**に伝わります。

### 数字の出し方

| 数えるもの | 書き方の例 | 注意 |
|---|---|---|
| 事業の規模 | ◯路線、車両約◯台、乗務員約◯人 | 決算の資料の数字を使う |
| 輸送人員 | 年間約◯万人 | 路線別があれば添える |
| 収支 | 経常収益約◯億円、経常収支 | 公表値を使う |
| 繰入れ | 年間約◯億円 | 根拠の区分を添えると強い |
| 再編の実績 | ◯路線、年間約◯円の改善 | 路線名は書かなくてよい |
| 安全 | 点呼の運用、会議の回数、訓練の回数 | 事故の個別の内容は書かない |

**「約」を付けて構いません。**正確な数字が出せないことよりも、**桁が分かることのほうが大事**です。

### 応募先で並べ替える

| 応募先の方向 | 上に置く機能 |
|---|---|
| 民間の鉄道・バス・タクシー | 運行／安全／車両と施設 |
| 物流・運送 | 運行／安全／乗務員の労務 |
| 交通の計画のコンサルタント | 企画と再編／経営と会計／住民と議会への説明 |
| 施設の運営・公益の事業 | 営業／経営と会計／公共性の説明 |
| 車両・設備のメーカーと整備 | 車両と施設／更新の計画／発注の仕様 |

**同じ経歴でも、順番を変えるだけで読まれ方が変わります。**中身を作り直す必要はありません。

:::insight
書き方の話をしておいて逆のことを言いますが、**書類を完成させてから動く必要はありません。**この経歴の方に多いのは、**「決まったダイヤを毎日回していただけ」**と考えて、実績欄を薄く書いてしまうことです。ところが、**乗務員が1人欠けたとき、車両が1台故障したとき、雪が降ったとき、その日のダイヤを誰がどう組み替えたか。**それは、運用であって、作業ではありません。**そして、地方公営企業法第17条の2は、経費を収入で充てることを原則とし、例外を一般会計が負担すると定めています。****つまり、法律が「あなたは採算を説明する人だ」と言っている**わけです。**先に、5つの数字だけ確かめてください。**路線数、車両数、年間の輸送人員、経常収益、繰入れの額。**このうち「繰入れの額」は、決算の資料に載っていても、自分の実績だと思っていないことが多い**ので、**根拠の区分と一緒に控えておいてください。**この5つが揃った時点で、**書類の読まれ方が変わります。**在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 書いてはいけないこと

| ✕ 書かない | ○ こう書く |
|---|---|
| 事故の個別の内容と、当事者に関わる情報 | 事故の報告の様式と、再発の防止の手順を整備したこと |
| 車庫や施設の警備、立入りの管理の詳細 | 施設の数と、担当していた保全の範囲 |
| 労使の協議の内部の経緯 | 乗務員の配置と労務の管理を、どういう基準で運用したか |
| 入札や契約の予定価格に関わる情報 | 発注の件数と、仕様で見ていた項目 |
| 未公表の路線別の収支の数値 | 公表されている範囲の数字と、分析の方法 |

**1行目と3行目は、とくに注意してください。**交通の事業は、**人を乗せる仕事であり、乗務員という多くの職員を抱える組織**です。**事故の当事者と、労使の内部の経緯は、書類にも面接にも出さない。**この線を守ることは、**それ自体が評価の対象**になります。**迷ったら、公表されている資料に載っている範囲にとどめてください。**

## つまずきやすい点

**1. 「公営企業の経営」で丸める**

**運行／車両と施設／営業／経営と会計／安全／企画と再編**の6つに分けてください。

**2. 繰入れの協議を、事務として書く**

**親会社との資金の調整**です。**根拠の区分を設計したことが伝わる形にしてください。**

**3. 安全の管理体制を書き落とす**

**民間の交通と物流では、求人票の条件そのもの**です。

**4. 異常時の運用を、苦労話にする**

**手順を決めて、体制を組んで、運用していた**と書いてください。

**5. 事故の内容や労使の経緯を書いてしまう**

**公表されている範囲と、整備した手順にとどめてください。**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## まとめ

- 地方公営企業法第17条の2は、**経費は経営に伴う収入で充てることを原則とし、性質上適当でない経費と能率的に経営してもなお困難な経費は一般会計が負担する**と定めています
- つまり、**交通・公営企業は「税で持つ部分と、料金で回す部分を、切り分けて説明する」仕事**をしています
- 職務要約には、**路線数・車両数・乗務員の数・年間の輸送人員・経常収益**を入れてください
- 実績は、**①基準と手順を作った ②収支を動かした ③体制を作った**の3つの型で書けます
- 書いてはいけないのは、**事故の個別の内容、労使の内部の経緯、施設の守りに関わる情報**です
- **繰入れの額と根拠の区分**は、**自分の実績だと思われていないことが多い**ので、**控えておいてください**

## よくある質問

### 事務職で、運行や車両の判断はしていません

**それでも書けます。**交通局の事務は、**運賃の改定と認可の申請、路線別の収支の分析、一般会計との負担の協議、公営企業会計の決算、契約と入札、広告と関連事業、苦情の対応**など、**技術以外の部分が広くあります。**書くなら、**「路線別の収支の分析、一般会計からの繰入れの協議、運賃の改定の試算と認可の申請、公営企業会計による決算を担当。運行と車両の技術上の判断は技術職が実施」**と、**自分の範囲を明示してください。**とくに、**公営企業会計と、繰入れの根拠の設計**は、**外部から採りにくい経験**です。線を引いた応募は、読まれます。

### 小規模な事業で、路線も車両も少ないのですが

**規模の大小は、それほど問題になりません。**むしろ、**小規模な事業体ほど、一人が見る範囲が広い**ことがあります。**運行も、車両も、料金も、会計も、全部を数人で回している。****その場合は、「範囲の広さ」を前に出してください。**書くなら、**「◯路線、車両◯台の事業について、運行の管理、車両の保守の発注、運賃の運用、公営企業会計による決算までを少人数で担当」**という形です。**「少人数で」という一語**が、**幅の証明になります。**とくに民間の交通の会社の営業所や、物流の拠点では、**一人で複数の役割を回せる人が求められます。**

### 病院や電気・ガスの公営企業で、交通ではありません

**書き方の骨は同じ**です。**収入で充てる部分と、一般会計が負担する部分を切り分ける。公営企業会計で損益と資金を見る。料金を原価で説明する。**この構造は、どの公営企業でも共通です。違うのは、**6つの機能の中身**です。病院なら「診療」「施設と設備」「医事と請求」「経営と会計」「安全と感染の対策」「企画と再編」、電気やガスなら「供給」「設備」「営業と料金」「経営と会計」「保安」「計画」。**自分の事業に合わせて置き換えてください。**行き先も、**病院なら民間の医療法人と医療系の企業、電気・ガスなら民間の公益事業**と、**同じ構造の民間側がそのまま並びます。**面接で聞かれることは[交通・公営企業出身者が面接で必ず聞かれること](dept-kotsu-mensetsu.html)に整理しています。
