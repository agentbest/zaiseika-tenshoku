**営繕や工事の担当をしてきた方から、「いつ取るべきか」**というご相談を伺います。

**検定が段階に分かれているため、順序と時期を組み立てられます。**

この記事では、**その考え方**を扱います。

**⚠ 受験の要件・区分・手続は、所管するところの公表を確認してください。****この記事では、個別の要件には触れません。**

## 技術検定は、段階に分けて行われます

**建設業法第27条第1項**です。

> **国土交通大臣は、施工技術の向上を図るため、建設業者の施工する建設工事に従事し又はしようとする者について、政令の定めるところにより、技術検定を行うことができる。**

**同条第2項**です。

> **前項の検定は、これを分けて第一次検定及び第二次検定とする。**

**検定が、段階に分けて行われる**と定められています。

**つまり、一度に全部を満たす必要はなく、順に進められる**ということです。

**この構造があるため、在職中と転職後で、段階を分けて計画できます。**

**⚠ 各段階の要件と、実務の経験の扱いは、所管の公表を確認**してください。

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 施工の管理 | **現場の管理** |
| ② 発注者支援 | 監督の補助、工程の確認 |
| ③ 建設コンサルタント | 施工の監理 |
| ④ 施設の管理・営繕 | 改修、保全の計画 |
| ⑤ 指定管理・受託の会社 | 施設の維持 |

**②と④が、行政の経験と重なります。**

**②について。**

**発注する側で監督や検査をしてきた経験**は、支援の業務でそのまま使えます。

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 行政での経験との接続

| 経験 | 民間での読まれ方 |
|---|---|
| ① 設計・積算の確認 | **見積りの妥当性の確認** |
| ② 工事の監督 | 工程、品質、安全の確認 |
| ③ 検査 | 検収、完成の確認 |
| ④ 変更の協議 | 変更の管理 |
| ⑤ 近隣への対応 | 苦情、説明 |
| ⑥ 保全の計画 | 中長期の計画、予算 |

**②と⑥が中心**です。

**⑥について。**

**施設の改修を、予算の年度と合わせて計画した経験**は、**保全の計画の業務と重なります。**

**扱いは**[電気主任技術者｜公営企業・インフラ運営での評価](skill-denkishunin.html)**にも整理しています。**

## 取得と転職の時期の組み方

| 順 | 考えること |
|---|---|
| 1 | **受験の要件を確認する**（所管の公表） |
| 2 | 在職中に満たせる段階を確認する |
| 3 | 応募したい求人の条件を確認する |
| 4 | 必須か、入社後でよいかを見る |
| 5 | 時期を組む |

**4が要**です。

**入社後の取得を前提とする求人**もあります。

**この場合、応募の時点で保有していなくても選考が進みます。**

**求人票の「必須」の欄を確認**してください。

**読み方は**[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)**に整理しています。**

:::insight
取得の時期について、**面談でお伝えしているのが「在職中に満たせる部分を先に済ませてください」**という点です。**受験の要件には、実務の経験が関わることがあります。**そして、**行政での実務が要件にどう扱われるかは、所管の公表で確認する必要**があります。ここで重要なのは、**証明の書類が必要になる場合、所属での手続が要る**という点です。**退職した後に、前の職場へ書類を依頼するのは、手間がかかります。**在職中であれば、**同じ手続がはるかに簡単**です。ですから、**転職を検討し始めた段階で、まず要件を確認し、必要な書類の準備を済ませておいてください。**受験するかどうかは、**その後で決めて差し支えありません。**書類だけ整えておけば、**判断の余地が残ります。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 書き方の例

**悪い例**

> 営繕課で、工事の監督をしていました。

**良い例**

> ◯◯課において、**発注者として、建築の工事◯件（工事費約◯千万円〜◯億円）の監督を担当。**設計と積算の内容を確認のうえ、**工程、品質、安全の確認を現場で実施。****変更が生じた案件◯件について、内容を協議し、変更の契約の手続を管理。**近隣への説明を担当し、**苦情◯件に対応。**完成にあたり、**検査を実施し、是正の確認までを管理。**

**「立場」「件数」「規模」「変更」「検査」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 確認の観点という材料

**監督や検査で見てきた項目は、そのまま書ける材料になります。**

| 観点 | 内容 |
|---|---|
| ① 工程 | **予定との差、遅れへの対応** |
| ② 品質 | 材料、施工の方法、記録 |
| ③ 安全 | 体制、周知、事故の防止 |
| ④ 出来形 | 寸法、数量 |
| ⑤ 書類 | 提出の期限、内容 |

**①と⑤が、発注する側の視点**です。

**⑤について。**

**提出の書類が揃っているかを確認してきた経験**は、**受注する側で「何を出せばよいか」を知っていることになります。**

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 要件の確認 | **所管の公表を確認** |
| 証明の書類の準備 | 所属での手続 |
| 実績の整理 | 件数、工事費、工種 |
| 求人を読む | 週に30分 |

**2行目を早めに**してください。

**在職中のほうが、手続が簡単**です。

[経験の言い換えから相談する](../apply.html)こともできます。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 担当した工事 | **工種、規模、件数** |
| 監督の観点 | 何を見たか |
| 変更への対応 | 3件、経緯と処置 |
| 近隣への対応 | 進め方 |
| 立場 | **発注者か、受注者か** |

**5行目です。**

**なお、特定の工事や事業者が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

## 取得の順序の考え方

**段階が分かれているため、次の順で整理できます。**

| 順 | 内容 |
|---|---|
| 1 | **いま満たしている要件を確認する** |
| 2 | 次の段階に必要な期間を確認する |
| 3 | 在職中に進められる範囲を決める |
| 4 | 応募の時期と重ねる |
| 5 | 入社後に続ける部分を決める |

**3と5を分けてください。**

**在職中に全部を終える必要はありません。**

**途中まで進めた状態でも、書類には書けます。**

**「◯年に第一次検定に合格、第二次検定は◯年の受験を予定」**という書き方です。

**進行中であることが伝われば、学ぶ意思として読まれます。**

**⚠ ただし、合格していない段階を保有と書かないでください。****事実と異なる記載になります。**

## よくある失敗

**1. 要件の確認を後回しにする**

**在職中のほうが手続が簡単**です。

**2. 立場を書かない**

**発注者か受注者か**を明記してください。

**3. 工事費や件数を書かない**

**規模**が伝わりません。

**4. 変更への対応を書かない**

**変更の管理**として読まれます。

**5. 検査の観点を書かない**

**受注する側でも使える視点**です。

**6. 入社後の取得の可否を確認しない**

**必須でない求人**があります。

**7. 要件を人づてで判断する**

**所管の公表**を確認してください。

**8. 取れば転職できると考える**

**何を監督しどう判断したか**が評価の対象です。

:::insight
ここまで順序の話をしておいて逆のことを言いますが、**発注者としての経験は、それ自体が希少です。**面談で拝見していると、**「施工の経験がないので、現場の求人は無理だ」と考える方**がいらっしゃいます。ところが、**発注者支援や建設コンサルタントでは、発注する側の視点が求められます。**仕様をどう組み立てるか、積算の根拠をどう確認するか、工程の遅れをどう扱うか、検査で何を見るか。**これらは、施工の経験からは身につきません。**そして、**役所の外には、発注する側の立場が存在しません。**ですから、**資格の取得を待つより、発注者としての経験で応募できる求人を先に探してください。**扱いは[技術職の転職｜事務職と何が違うか](senko-tachiba-gijutsu.html)に整理しています。**資格は、その後で足しても間に合います。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **建設業法第27条**は、**技術検定を行うことができる**とし、**第一次検定及び第二次検定に分ける**としています
- **段階に分かれているため、在職中と転職後で計画を分けられます**
- 効くのは、**施工の管理、発注者支援、建設コンサルタント、施設の管理・営繕、指定管理・受託の会社**です
- 接続するのは、**設計・積算の確認、工事の監督、検査、変更の協議、近隣への対応、保全の計画**です
- **在職中に、要件の確認と証明の書類の準備を済ませて**ください。退職後は手間がかかります
- **入社後の取得を前提とする求人**もあります。必須かどうかを確認してください
- **発注者としての経験は、それ自体が希少**です

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 事務職ですが、営繕の担当でした

**書けます。**技術職でなくても、**工事の発注の手続、契約の管理、支払の処理、近隣への対応**に関わっていれば、材料になります。書き方は、**「建築の工事◯件について、発注の手続から契約、支払までの管理を担当」**という形です。**技術的な判断を担っていない場合は、そう書いてください。**「技術的な確認は担当課が実施し、契約と進行の管理を担当」。**できる範囲を正確に書く**ほうが、入社後に困りません。扱いは[契約書の読み方｜自治体の契約実務との差](skill-keiyakusho.html)に整理しています。

### 受験の要件に、行政の実務は算入されますか

**所管するところの公表を確認してください。**要件は、**実務の経験の年数と内容**で定められていることがあります。どの職務が該当するかは、**公表されている案内で確認**するのが確実です。**人づての情報や、以前の記憶で判断しないでください。**要件は改められることがあります。なお、**証明の書類が必要になる場合、所属での手続が要る**ことがあります。**在職中に確認し、必要なら書類を整えておいてください。**退職した後では、依頼に手間がかかります。

### 転職の時期と、受験の時期が重なります

**優先順位を決めてください。**応募の時期が決まっているなら、**職務経歴書の作成と求人を読む作業が先**です。受験は、**入社後でも続けられます。**なお、**入社後の取得を支援する制度**がある会社もあります。求人票や採用のページで確認してください。一方、**選任や配置が前提の職**では、**入社時点での保有が要件**となることがあります。この場合は、**取得の時期から逆算**してください。扱いは[選考スケジュールの組み方](senko-sagasu-schedule.html)に整理しています。
