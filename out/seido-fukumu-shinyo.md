**結論から書きます。信用失墜行為とは、地方公務員法第33条が禁じている「その職の信用を傷つけ、又は職員の職全体の不名誉となるような行為」のことです。**

- **勤務時間の内外を問わず、私生活の行為にも及びます**
- **罰則はなく**、違反すると**懲戒処分（第29条：戒告・減給・停職・免職）**の対象になります
- 何が当たるかは条文に列挙されておらず、**個別の事案ごとに任命権者が判断**します。判断の目安として、国家公務員には人事院の「懲戒処分の指針」があり、自治体も独自に懲戒処分の指針を定めて公表していることがあります
- **転職活動そのものは信用失墜行為に当たりません。**転職を考える人が気をつけるのは、SNSでの発信と、退職前の言動です

## 条文と、その読み方

「第三十三条 職員は、その職の信用を傷つけ、又は職員の職全体の不名誉となるような行為をしてはならない。」

| 要素 | 意味 |
|---|---|
| 「その職の信用を傷つけ」 | 自分の職（その自治体の職員としての職）の信用を損なう行為 |
| 「職員の職全体の不名誉」 | 公務員全体の信用を損なう行為 |
| 勤務時間 | 条文に限定がない。**勤務時間外の行為も対象** |
| 職務との関連 | 条文に限定がない。職務と無関係の私生活の行為も、公務員の信用を損なえば対象 |

職務専念義務（第35条）が勤務時間についての義務であるのに対し、第33条は時間の限定がないのが特徴です。第60条以下の罰則に第33条は含まれていないので、刑罰ではなく懲戒の問題として扱われます。

## どんな行為が懲戒の対象として挙げられているか

人事院の「懲戒処分の指針」は、国家公務員の標準的な懲戒処分の例を分野別に示しています。自治体の指針は自治体ごとに中身が違うので、ここでは人事院の指針の分野と主な項目を示します。

| 分野 | 主な項目 |
|---|---|
| 一般服務関係 | 欠勤、遅刻・早退、**休暇の虚偽申請**、勤務態度不良、**秘密漏えい**、兼業の承認等を得る手続のけ怠、公文書の不適正な取扱い、セクシュアル・ハラスメント、パワー・ハラスメント など |
| 公金官物取扱い関係 | 横領、窃取、詐取、紛失、諸給与の違法支払・不適正受給、コンピュータの不適正使用 など |
| 公務外非行関係 | 暴行・けんか、窃盗、詐欺、賭博、麻薬等の所持等、酩酊による粗野な言動等、痴漢行為、盗撮行為 など |
| 飲酒運転・交通事故・交通法規違反関係 | 飲酒運転、人身事故を伴う交通事故 など |
| 監督責任関係 | 指導監督不適正、非行の隠ぺい・黙認 |

**「公務外非行」が一つの分野になっていること**が、勤務時間外の私生活も対象になることをよく表しています。なお、この指針に**転職活動に当たる項目はありません。**SNSに特化した項目もありませんが、投稿の内容によっては秘密漏えいやハラスメントなどの項目に当たり得ます。

## 懲戒処分になると何が起きるか

第29条は、この法律や条例に違反した場合、職務上の義務に違反し又は職務を怠った場合、全体の奉仕者たるにふさわしくない非行のあった場合に、懲戒処分ができると定めています。信用失墜行為は第33条違反として1号に当たります。懲戒処分は、軽いほうから**戒告・減給・停職・免職**の4種類です。どれになるかは、指針の標準例を目安に、行為の動機・態様・結果、故意か過失か、職責、過去の非違行為の有無などを総合的に考えて任命権者が決めます（人事院の指針も、標準例に載っていない行為でも懲戒の対象になり得るとしています）。

転職との関係で効いてくるのは次の点です。

- **懲戒免職**になると、退職手当の全部又は一部が支給されないことがある。国家公務員退職手当法第12条が「懲戒免職等処分を受けた場合等の退職手当の支給制限」を定めており、自治体の退職手当条例にも同様の規定が置かれているのが一般的
- 懲戒処分を受けた事実は、転職先の面接で前職の退職理由や経歴を聞かれたときに、説明を求められ得る
- 処分を公表する基準を定めている自治体もある

「もうすぐ辞めるから」は、慎重になる理由のほうです。

## 転職を考える人にとっての線引き

| 場面 | 第33条との関係 |
|---|---|
| 転職活動をする、転職支援サービスに登録する | **対象外**。職員の自由 |
| 面接で前職の仕事を説明する | 対象外。ただし**職務上の秘密を話せば第34条**、特定の人や自治体を不当に貶める発言は第33条に触れ得る |
| SNSで転職活動について書く | 発信自体は対象外。自治体・上司・同僚・住民を特定できる形での批判や侮辱、職務上の情報を含む内容は対象になり得る |
| 匿名アカウントで内部を批判する | **匿名でも、特定されれば対象になり得る**。匿名であることは免責にならない |
| 退職を申し出た後の勤務態度 | 主に職務専念義務（第35条）の問題。著しく不誠実な態度は第33条にも触れ得る |
| 面接のために休暇を取る | **病気休暇や特別休暇を偽って取れば「休暇の虚偽申請」**。年次休暇の取得に理由の説明は通常要らないので、偽る必要がない |

線があるのは「転職活動」ではなく、**発信と言動**です。転職を考える時期は職場への不満が高まりやすく、それを公開の場で口にすることが、第33条に触れる典型的な場面になります。

## SNSで気をつけること

匿名のアカウントでも、投稿の内容、時期、写真、つながりから特定されることがあります。転職を考え始めたら、投稿の前に「**自治体の名前が出ても困らない内容か**」を確かめ、過去の投稿も見直してください。転職先の採用担当が応募者のSNSを見ることもあり、前職を批判する投稿は、転職先の評価にも響きます。

:::insight
面談で伺った中に、**転職先も退職日も決まった後、SNSに自治体への不満を投稿して特定され、注意を受けた**という方がいました。「もう関係ない」と思っていたそうですが、第33条は退職日まで及び、懲戒処分を受ければ退職手当や転職先への説明に影響し得ます。反対に、転職活動を職場に伏せて進め、申出の後も最後まで丁寧に勤務し、SNSには転職後に「お世話になりました」とだけ書いた方は、前職の同僚との関係が続き、業界の情報が入り続けています。**転職を考え始めたら、不満は公開の場ではなく、面談の場で言ってください。**そこで口にすれば、次の職場を選ぶ材料に変わります。
:::

## 退職前に確認しておくこと

| 場面 | すること | 根拠 |
|---|---|---|
| 転職を考え始めたら | SNSの投稿内容を絞り、過去の投稿を見直す | 第33条・第34条 |
| 面接のとき | 職務上の秘密を話さない。前職の課題は一般化して述べる | 第34条・第33条 |
| 休暇の申請 | 理由を偽らない | 第33条（休暇の虚偽申請） |
| 退職の申出の後 | 引継ぎを含めて丁寧に勤務する。職場で不満を口にしない | 第35条・第33条 |
| 退職後 | 守秘義務は退職後も続く。第33条は職員でなくなれば及ばない | 第34条 |

:::insight
信用失墜行為の話を書いてきましたが、**第33条は転職するかどうかの判断を左右するものではありません。**転職活動は対象外で、線があるのは発信と言動だけです。それでも1本の記事にしたのは、転職を決めた解放感から、退職前に不満を公開の場で口にして、最後に信用を落とす方を見るからです。第33条を守ることは、公務員としての義務であると同時に、転職先での信用を守ることでもあります。そのうえで、**自分の経験に値を付けてくれる業界があるかを同じ紙に並べてください。**応募先が決まっていない段階のほうが整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 信用失墜行為は、地方公務員法第33条が禁じる**職の信用を傷つけ、職員の職全体の不名誉となる行為**
- **勤務時間外・私生活にも及ぶ**。罰則はなく、**懲戒処分（第29条）**の対象
- 何が当たるかは任命権者が個別に判断する。目安は人事院の「懲戒処分の指針」や自治体の指針（**公務外非行**も一つの分野）
- **転職活動は当たらない**。気をつけるのは、SNSでの発信、面接での前職の話し方、休暇の申請、退職前の言動
- 第33条は退職日まで及び、守秘義務（第34条）は退職後も続く

## よくある質問

### 勤務時間外のプライベートな行為でも、信用失墜行為になるのはなぜですか

**第33条に勤務時間や職務との関連の限定がないためです。**条文は「その職の信用を傷つけ、又は職員の職全体の不名誉となるような行為」とだけ定めており、私生活の行為でも、公務員の信用を損なうものであれば対象になります。人事院の「懲戒処分の指針」が「公務外非行関係」という分野を設け、暴行、窃盗、痴漢行為、盗撮行為などを挙げているのもこのためです。飲酒運転も独立した分野として挙げられています。どの程度の処分になるかは、行為の態様や結果、職責などを総合的に考慮して任命権者が判断します。

### 匿名のSNSで、自治体の働き方への不満を書いています。問題になりますか

**内容次第で、匿名でも問題になり得ます。**公務員の働き方についての一般的な意見で、職務上の秘密を含まず、特定の人や自治体を侮辱するものでなければ、通常は問題になりません。一方、自治体や上司・同僚を特定できる形での批判や侮辱、職務上知り得た個別の情報を含む投稿、事実に反する内容で自治体を貶める投稿は、特定されれば第33条（内容によっては第34条）の問題になり得ます。投稿の前に「自治体の名前が出ても困らない内容か」を確かめてください。

### 面接で前職の不満を聞かれました。正直に答えると信用失墜行為になりますか

**事実に基づき、特定の人や事案を貶めない形で答えれば、問題にはなりません。**転職理由として前職の課題を述べること自体は転職活動の一部です。避けるのは、上司や同僚を特定できる形で悪く言うこと、職務上知り得た個別の事案を持ち出すこと、事実に反する内容で自治体を貶めることです。「予算の査定に携わる中で、制度の枠内でできることの限界を感じ、自治体を支援する側に立ちたいと考えた」のように、**自分の判断と志向を軸に、前職の課題は一般化して述べる**形が、法律の面でも面接の評価の面でも適切です。転職理由の組み立ては[退職理由の伝え方](senko-mensetsu-taishokuriyu.html)に書いています。
