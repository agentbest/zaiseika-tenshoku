農業・食品の志望動機で、**いちばん多く見かける書き出し**があります。

**「食の安全に関わる仕事がしたいと考えました」**

**気持ちは伝わります。**ただし、**選考では効きません。**

理由は2つあります。**1つは、その一文が、どの会社にも当てはまること。**もう1つは、**保健所や食品の監視の部署にいれば、すでに関わっていること**です。

**相手が知りたいのは、「なぜ、監視する側ではないのか」**です。

**その答えの手がかりは、法律が事業者に何を求めているかを見ると、はっきりします。**この記事では、**そこから志望動機を組み立てる手順**を扱います。業界の構造は[未経験から農業・食品に入るには](industry-shokuhin-mikeiken.html)、条件の確かめ方は[農業・食品の年収と働き方](industry-shokuhin-nenshu.html)にあります。

## 事業者は、選ばれるための情報を出す側にいます

**食品表示法第4条第1項**です。

> **（食品表示基準の策定等）第四条　内閣総理大臣は、内閣府令で、食品及び食品関連事業者等の区分ごとに、次に掲げる事項のうち当該食品を消費者が安全に摂取し、及び自主的かつ合理的に選択するために必要と認められる事項を内容とする販売の用に供する食品に関する表示の基準を定めなければならない。**

**「消費者が安全に摂取し、及び自主的かつ合理的に選択するために必要と認められる事項」**です。

**2つのことが並んでいます。****安全に摂取すること**と、**自主的かつ合理的に選択すること。**

**この2つ目が、志望動機の入り口**になります。

**監視する側の仕事は、安全の側**に重心があります。**基準を満たしているか、危害が生じていないか。**

**事業者の側の仕事には、選ばれる側の仕事**があります。**何を作り、どう伝え、誰に届けるか。**

**そして、[未経験から農業・食品に入るには](industry-shokuhin-mikeiken.html)で扱った食品衛生法第55条第1項**のとおり、**営業には許可が要ります。**許可を得たうえで、**事業として成り立たせる**必要がある。

| 行政の側 | 事業者の側 |
|---|---|
| 基準を満たしているか確認する | **基準を満たす仕組みを日常的に回す** |
| 危害が生じていないか見る | **危害を生じさせない手順を作る** |
| 表示が適正か確認する | **表示を作る** |
| — | **選ばれるものを作り、届ける** |

**いちばん下の行が、行政には無い仕事**です。

**志望動機は、ここに接続させてください。**

## 3つの層に分けます

| 層 | 問い | 材料の出どころ |
|---|---|---|
| ① 機能 | **なぜ、事業者の側なのか** | 役所での担当の経験 |
| ② 会社 | **なぜ、この会社・この品目なのか** | 公表資料と求人票 |
| ③ 立場 | **なぜ、監視する側ではないのか** | 自分の考えの変化 |

## ① 事業者の側で使える経験は、役所にあります

| 役所での担当 | 接続する場面 |
|---|---|
| 食品営業の許可・監視 | **品質保証、施設の基準への適合** |
| 食中毒・有症苦情の調査 | **事故への対応、原因の究明** |
| 表示に関する指導 | **表示の管理** |
| 農地・農政の事務 | 産地との関係、制度の対応 |
| 補助金の交付と実績の確認 | **補助の申請と実績の報告** |
| 環境・排水・廃棄物の許認可 | 工場の環境の管理 |
| 契約・入札の事務 | 購買・調達 |

**書き方は、「担当しました」で止めないでください。****何を見ていたか**を書きます。

> 食品営業施設の監視指導を担当していました。同じ指摘が繰り返される施設と、一度で改善される施設の違いは、手順が文書になっているかどうかでした。記録の様式が作業の流れに合っていない施設では、記録が後回しになり、結果として確認ができない状態になります。

**「どこで崩れるかを知っている」**という形になっています。**これが、事業者側にとって欲しい知識**です。

## ② 会社と品目は、公表資料から取ります

| 資料 | 志望動機に使える材料 |
|---|---|
| 公式サイトの製品の紹介 | **何を作っているか、どこに工場があるか** |
| 品質や安全に関する方針 | **どの仕組みを入れているか** |
| 会社の沿革 | 何から始まって、どこへ広げたか |
| 求人票の仕事内容 | **その職種の日々の中身** |
| 採用のページ | 中途で入った人がどこにいるか |

**使い方は、「読みました」ではなく「読んで、自分の経験とどこが重なったか」**です。

> 貴社が複数の産地から原料を受け入れていることを拝見しました。受入れの段階での確認の記録は、事故が起きたときに原因を絞り込める唯一の手がかりになります。監視する側として、その記録が揃っていない施設を何度も見てきました。その部分を整える仕事であれば、経験が使えると考えています。

**⚠ ただし、前の職場で知り得た内部の事情や、特定の事業者に関する情報は書かないでください。**守秘の観点に加えて、**それを書く人は、次の職場の情報も外で話す**と見られます。**一般的な運用の話に留めてください。**

## ③ 監視する側ではない理由

**必ず問われます。**相手が確かめたいのは2つです。

| 相手の懸念 | 確かめたいこと |
|---|---|
| **指導する目線のまま来ないか** | 会社の側に立てるか |
| **現場と話ができるか** | 作業する方との距離の取り方 |

**1つ目が、この分野では特に警戒されます。**

**理由は、工場の側が監視を受ける立場にあるから**です。**「元保健所の人が来て、社内で指導を始める」**という状態は、**会社にとって歓迎できるものではありません。**

**答え方の型は、「起きてから確認する側から、起きないようにする側へ」**です。

> 監視や調査は、起きたことを確認する仕事です。起きないようにする仕組みを日常的に回しているのは、事業者の側です。指摘をする側ではなく、指摘を受けない状態を作る側で経験を使いたいと考えました。

**もう一つの型は、「作って届けるところまで関わりたい」**です。

> 表示の指導をしていましたが、その表示が何を伝えようとしているかは、作る側にいないと分かりません。基準を満たすことと、消費者に伝わることは、別の作業です。両方に関わる立場に移りたいと考えました。

**⚠ 避けてください——役所の批判から入る書き方**です。「規制が形式的だった」「現場を見ていなかった」。**読む側から見ると、次は当社の悪いところを外で言う人に見えます。**

:::insight
面接に同席させていただいていて、**この分野で評価が分かれる瞬間**があります。**「現場の作業をされている方と、どう関わりますか」**という質問への答え方です。よくあるのは、**「法令にもとづいて、適切に指導します」**という答えです。これは、**この分野ではいちばん警戒される答え方**です。食品の工場で、**記録が後回しになるのは、作業者の怠慢ではないことが多い**からです。記録の様式が作業の流れに合っていない、記入する場所が作業台から離れている、書く時間が工程に組み込まれていない。**これは、様式と工程の設計の問題**です。監視する側にいた方なら、**同じ指摘が繰り返される施設を見てきているはず**です。そこで、**「なぜ直らないのか」を現場の側から考えたことがあるかどうか**が、この質問で問われています。評価される答え方は、**「まず、記録を書いている場面を見せてください」**という形です。⚠ そして、**この視点を持っている方は、「本社が言ってきた」と受け取られずに済みます。**役所で、本庁と出先や、事業者と現場の間を調整してきた方は、**この距離の取り方をすでに知っています。**面接では、その経験を具体的に出してください。
:::

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 経験 | 志望動機での使い方 |
|---|---|
| 食品営業の許可・監視 | **どこで指摘を受けるかが分かる** |
| 事故・苦情の調査 | **起きたときの手順を知っている** |
| 表示に関する指導 | 表示の管理に直結 |
| 補助金の交付・実績の確認 | 申請する側に回れる |
| 記録の整備 | **検査に耐える書類の作り方** |
| 本庁と出先の調整 | **管理と現場の距離の取り方** |

**効きにくい場所**

| 経験の不足 | 面接での扱い方 |
|---|---|
| 原価と歩留まりの管理 | **構造の理解を示す** |
| 販路の開拓 | 売り込む工程が役所に無い |
| 価格の交渉 | 入ってから学ぶ領域 |
| 現場の作業の経験 | **無いことを認めて、見る姿勢を示す** |

**最後の1つは、隠さないでください。****「作業の経験はありません。ですから、まず見せていただきます」**という言い方で足ります。

## 材料を集める順番

| 順 | やること | 目安 |
|---|---|---|
| 1 | 自分が扱った**法令の名前**を書き出す | 30分 |
| 2 | **「どこで崩れるか」を見てきた例**を3つ書き出す | 1時間 |
| 3 | 応募先の**製品と工場の場所**を確認する | 1時間 |
| 4 | **品質や安全に関する方針**を読む | 30分 |
| 5 | ③の型（起きないようにする側へ／作って届けるところまで）を決める | 20分 |
| 6 | ①②③を**つなげて300字**にまとめる | 40分 |

**2つ目が、この分野では効きます。****監視する側から見た「崩れる場面」**は、**工場側では手に入りにくい知識**です。

## 面接で聞かれやすいこと

| 聞かれること | 何を確かめられているか |
|---|---|
| なぜ監視する側ではないのですか | **③の中身** |
| 現場の作業をされている方と、どう関わりますか | **立ち位置の理解** |
| 事故が起きたときの対応の経験はありますか | 実務の深さ |
| 行政の検査で、どちらの立場に立ちますか | **元の所属に引きずられないか** |
| 勤務地が工場や産地でも構いませんか | 前提の確認 |

**4つ目は、必ず聞かれます。****「会社の側に立ちます。ただし、行政の側の見方も分かるので、指摘を受けにくい整え方ができます」**が自然です。

**⚠ 「元の所属に配慮します」と答えないでください。**

:::insight
ここまで組み立て方の話をしてきましたが、**逆のことも申し上げます。**この分野を志望される方の中には、**保健所や食品の監視の部署で、事業者の側の苦労を見てきた方**が多くいらっしゃいます。**その経験があるからこそ、事業者の側に移りたいと考える。**これは、自然な動機です。ただ、**その動機のまま入ると、最初に落胆することがあります。**理由は、**中に入ると、改善が進まない理由が「分かっていない」ことではなく「手が足りない」ことだと分かるから**です。品質保証の担当者は、**記録の確認、監査の準備、苦情の処理、教育の実施**を、少人数で回しています。**やるべきことは分かっているが、時間が無い。**外から見ていたときに「なぜやらないのか」と思ったことの多くが、**優先順位の問題**だった、と気づきます。ですから、**入ってすぐに改善案を出すより、まず手を動かして負担を減らすほうが、結果として早く変わります。**面接でも、**「何をしたいか」より「何を引き受けられるか」**を言えると、評価が変わります。そして、**確かめた結果、いまの職に残る判断**も、同じ資格で成り立ちます。当社が、いまの職を辞めることをお勧めすることはありません。
:::

## まとめ

- **「食の安全に関わりたい」は、志望動機になりません。**監視する部署にいれば、すでに関わっています
- **食品表示法第4条第1項**は、**消費者が「安全に摂取し、及び自主的かつ合理的に選択する」ために必要な事項を内容とする表示の基準**を定めることとしています
- **安全に摂取すること**と**自主的かつ合理的に選択すること**——**2つ目に、行政には無い仕事があります**
- 志望動機は、**①機能（なぜ事業者の側か） ②会社・品目 ③監視する側ではない理由**の3層に分けます
- ①の材料は、**許可・監視、事故の調査、表示の指導、補助の交付、環境の許認可**にあります
- ⚠ **「どこで崩れるかを見てきた」という形**で書いてください。**工場側では手に入りにくい知識**です
- ③は、**「起きてから確認する側から、起きないようにする側へ」**または**「作って届けるところまで」**の型で書きます
- ⚠ **「適切に指導します」と答えないでください。****「まず、記録を書いている場面を見せてください」**が評価される答え方です
- ⚠ **記録が後回しになるのは、作業者の怠慢ではなく、様式と工程の設計の問題**であることが多いです

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 食品や農業に関わる部署にいたことがありません

**①の層を、別の経験で組み立ててください。**総務・人事・経理・法務の職種であれば、**行政での対応する経験が、そのまま材料になります。**また、**環境部局で排水や廃棄物の許認可**を扱っていた方は、**食品の工場の環境の管理**に直接つながります。**契約・入札の事務**があれば、**購買・調達**が候補です。そのうえで、**この分野ならではの部分を押さえておく**と話が通じます。**衛生の管理の手順がある、表示の確認が要る、季節で原料の入りが変わる。**調べてきたことが伝われば、差が付きます。⚠ **知らないことを知っているように書かないでください。**入ったあとに差が出ます。

### 志望する会社が、過去に事故を起こしています。触れるべきですか

**自分から持ち出さないでください。**志望動機で触れると、**採点する立場に立っている**ように読まれます。**聞かれた場合のみ、事実として確認したことを述べてください。**答え方は、**「公表されている内容は拝見しました。再発を防ぐ仕組みを作る側で関わることに、意味があると考えています」**という形です。**批判にも、擁護にもならない位置**に置くのがこつです。⚠ **公表されていない事情を、前職で知り得た立場から話すことは避けてください。**守秘の観点に加えて、**この人は情報を外で話すと受け取られます。**判断に迷うときは、**触れないほうが安全**です。

### 志望動機は、何社ぶん書き分ける必要がありますか

**①は共通で構いません。②と③は、会社ごとに書き直してください。**①は「なぜ事業者の側か」なので、**同じ経験が材料になります。**②はその会社の資料から取った材料なので、**使い回すと読んでいないことが分かります。**③も、**会社の性格で説得力のある型が変わります。**製造が中心の会社なら「起きないようにする側へ」、商品の開発や販路に力を入れている会社なら「作って届けるところまで」。**同じ言葉でも、置く場所で意味が変わります。**なお、⚠ **産地の法人や、自治体から補助・委託を受けている法人に応募する場合は、再就職に関する規程の確認を先に済ませてください。**
