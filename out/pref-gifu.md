岐阜県庁で働いてきた方の転職は、条件のうえで有利な点がひとつあります。**名古屋圏に隣接している**ため、転居せずに大都市圏の求人に応募できることです。

その一方で、多くの方が**通勤時間だけで線引きしてしまい、職種の選択肢を狭めています。**県内か名古屋か、という二択で考えると、実際にはもっと広い選択肢が視界から消えます。

この記事では、まず公表されている数字で自分の位置を確認し、そのうえで県庁の経験が民間のどの言葉に置き換わるのかを整理します。

## 岐阜県庁の給与水準を、数字で確認する

総務省の調査によると、岐阜県の一般行政職は次のとおりです（令和6年4月1日現在）。

| 項目 | 岐阜県 |
|---|---|
| ラスパイレス指数 | 99.3 |
| 平均年齢 | 42.9歳 |
| 平均給料月額 | 327,700円 |
| 諸手当月額 | 79,840円 |
| 平均給与月額 | 407,540円 |
| 平均給与月額（国ベース） | 362,291円 |
| 地域手当（国の指定基準） | 約2.45% |
| 地域手当（実際の支給割合） | 約3.86% |

### 地域手当の上乗せ幅が、比率で見ると大きい

読みどころはここです。**国が指定する基準は約2.45%なのに、実際の支給割合は約3.86%。**差は約1.4ポイントですが、**比率で見ると5割以上の上乗せ**になります。

他県と並べると、この特徴が分かります。

| 県 | 国の指定基準 | 実際の支給割合 | 差 |
|---|---|---|---|
| **岐阜県** | **約2.45%** | **約3.86%** | **＋約1.4** |
| 茨城県 | 6.0% | 約7.46% | ＋約1.5 |
| 山梨県 | 2.75% | 約3.63% | ＋約0.9 |
| 栃木県 | 3.5% | 約4.40% | ＋約0.9 |
| 富山県 | 約2.09% | 約2.09% | 差なし |

地域手当は民間賃金の高い地域に支給される手当で、国の指定基準は市町村単位で決まっていますが、**都道府県が独自の判断で支給割合を設定する余地があります。**岐阜県は、基準に対する上乗せの比率が大きいほうに位置します。

:::insight
この表を「地域手当が高い県ほど得だ」と読まないでください。**地域手当は民間企業にはない概念です。**求人票が提示するのは基本給と諸手当を含んだ年収であって、「地域手当◯%」という内訳では書かれていません。相談でよく起きるのが、地域手当を含んだ現在の額面を基準に「これより下は受けられない」と判断し、**実際には条件の良い求人を最初から外している**ケースです。比べるときは、源泉徴収票の支払金額と、求人票の想定年収を突き合わせてください。手当の名目ごとに比べようとすると、必ず噛み合いません。
:::

なお、上の平均は自分の給与ではありません。全年齢の平均です。**平均給料月額（年齢構成の影響を受ける）とラスパイレス指数（補正済み）は意味が違うので、混ぜて読まないでください。**

| 予算の要求・査定、財政計画 | 予実管理、投資判断、経営企画 |
| 企業誘致・立地支援 | 事業開発、用地開発、アライアンス |
| 産業支援・技術支援の施策 | 産学連携、技術企画、事業開発 |
| 地場産業の支援・販路開拓 | 事業開発、ブランド戦略、海外展開 |
| 観光の誘客・受入環境整備 | 観光事業企画、地域ブランディング |
| 森林・林業政策 | サステナビリティ、資源調達 |
| 中山間地域の振興・交通の確保 | モビリティ事業企画、地域事業 |

| 市町村への助言・支援 | パートナー支援、カスタマーサクセス |

## 岐阜で、どの経験が値になるか

**1. 条件のまったく違う2つの地域を、同時に扱ってきた経験**

岐阜県は、平野部と山間部で条件がまったく違う県です。人口が集中し産業が集積する地域と、人口減少と移動条件の制約が課題になる地域が、同じ県内にあります。

**同じ制度を、条件の違う地域に当てはめる。**この経験は、全国展開する企業がいちばん苦労するところです。都市部でうまくいった型が地方では噛み合わない、その理由を**実務として理解している**人材は多くありません。

**2. 特色ある地場産業の支援と販路開拓**

刃物、陶磁器、木材。全国的に知られた産地を持つ県として、県庁には支援と販路開拓の実務があります。**行政の立場でブランドの座組みを作った経験**は、地域商社、ブランド事業を持つ企業、そして海外展開を進める企業から見て希少です。

とくに輸出は許認可と補助金の塊なので、**制度を知っていること自体が実務能力**にあたります。

**3. 高度なものづくりと企業支援**

航空宇宙、自動車部品、機械。高い技術を持つ企業の集積があり、県庁には企業支援と誘致の実務があります。**補助制度の設計、人材確保の支援、取引先とのマッチング、用地とインフラの手当て。**企業側が自力ではたどり着けない情報を、行政の立場で扱ってきたことになります。

**4. 中山間地域の交通と生活基盤**

移動条件の厳しい地域で、交通をどう確保するか。施設をどう維持するか。**「減らす計画」を住民の合意を取りながら通した経験**は、全国の自治体でこれから必要になるのに、実際に通した人はまだ多くありません。

**5. 市町村を相手にしてきた経験**

規模も体制もばらばらな市町村を相手に、温度差をどう埋めたか。「連絡調整」ではなく、**複数顧客を持つアカウント業務の経験**として書けば、そのまま職務能力になります。

## 名古屋圏の求人を、勤務地で切らない

岐阜県は名古屋圏に隣接し、**転居せずに大都市圏の求人に応募できます。**判断の誤りは、通勤時間だけで線引きしてしまうことです。

近年はリモート可、週数日出社といった勤務形態の求人が増えています。とくに自治体を顧客にする企業は、担当エリアに出向くことが仕事なので、本社への出社頻度が低い場合があります。

**まず職種で絞り、そのあとに勤務形態を確認する。**勤務地から検索すると、県内では出会えない職種が最初から視界に入りません。名古屋圏に本社を置く企業が、中部一円を担当する形で人を配置しているケースもあります。

## 職務経歴書に、県庁の仕事をどう落とすか

**制度名ではなく、判断したことを書く**

「○○推進事業を担当」では読み手に何も残りません。事業名は庁内でしか意味を持たない固有名詞です。**何件を、どういう基準で審査し、どこで判断が割れて、どう決着させたか。**

**地域差の扱いを実績として書く**

岐阜県庁の方がいちばん書き落とすのがここです。同じ制度を条件の違う地域に当てはめる際、**何を変え、何を変えなかったか。**この判断の中身を書けば、全国展開を考える企業にとって直接読める経験になります。

**異動歴を「立ち上げの回数」に変える**

異なる制度領域を短期間で立ち上げてきた経験は、民間では**キャッチアップの速さ**として読まれます。編年式で並べ、それぞれの配属で最初の数か月に何を習得したかを1行添えてください。

## 技術職の場合は、探し方が変わる

**発注者側の経験そのものが職種になる**

「発注者支援」という職種が、建設コンサルタント業界には確立しています。設計の審査、積算の確認、工事の監督、住民説明。県庁でやってきたことが、そのまま職務内容として書かれた求人です。

**資格が入口で効く**

技術士、施工管理技士、測量士、電気主任技術者。**実務経験の年数が受験要件になっているものは、在職中でなければ積めません。**取れるものがあるなら、動く前に取っておいてください。

**山地・河川と防災の実務は特殊な資産になる**

急峻な地形での道路、砂防、河川管理。この条件下での設計と維持管理を経験した技術者は、同じ条件を持つ地域の事業では強く求められます。**管理延長ではなく、限られた予算でどう優先順位を付けたか**を書いてください。

## 面接で必ず詰められる2つのこと

**「意思決定のスピードに耐えられるか」**

行政は手続きの段数が多く、決裁を経て動きます。民間は月次で数字を締め、その場で方針を変えます。稟議の段数を弁解せず、**自分の判断で動かした範囲を具体的に答えてください。**

**「数字への意識があるか」**

「利益を意識したことはありますか」という形で聞かれます。「行政なので利益はありません」と答えると、そこで話が終わります。事業の優先順位を付けた、単価の根拠を詰めた、複数案を比べた。**同じ思考をしていたことを、民間の言葉で説明できるか**が見られています。

## 在職中に進めるときの注意点

**顔が知られている前提で動く**

県内の企業の多くは、県庁と何らかの接点を持っています。取引先、許認可の相手方、補助事業の対象。**在職中の活動が伝わりやすい環境**だという前提で進めてください。応募先が現在の担当業務の相手方である場合は、とくに慎重に扱う必要があります。

**服務上の扱いを先に確かめる**

在職中に得た情報を持ち出すことは避けなければなりませんし、退職後の営業活動についても扱いを確認しておいたほうが安全です。**判断に迷う場合は、応募の前に人事担当課に制度上の取扱いを確認してください。**

**面接の日程は、議会日程から逆算する**

地方自治法第211条は、長が毎会計年度予算を調製し、年度開始前に議会の議決を経なければならないと定めています。都道府県は年度開始前30日までに予算を議会へ提出するようにしなければならない、とも書かれています。決算は、出納閉鎖後3か月以内の長への提出、監査委員の審査、議会の認定という順です（第233条）。**予算編成の山と定例会の会期中は、平日日中の面接を入れるのが難しくなります。**

**在職中に決める**

公務員には雇用保険が適用されないため、辞めてから探すと収入のない期間がそのまま持ち出しになります（[公務員に雇用保険がない理由](seido-shitsugyo-nashi.html)）。

:::insight
ここまで転職の話を書いてきましたが、**残る判断にも理があります。**県庁は、県内では数少ない「制度を作る側」の職場です。しかも異動によって複数の領域を横断できる。この積み方は民間企業ではあまりできません。とくに中山間地域の再編のように、着手から完了まで年単位かかる案件を担当している場合、途中で抜けると着手したところまでしか書けません。**通しで一巡させてから動くほうが、書けることは確実に厚くなります。**名古屋圏に近い岐阜県は、地方県庁のように「動くなら転居を伴う」という制約がないぶん、機が熟すまで待っても選択肢はそれほど減りません。ただし、自分の経験が外でどう呼ばれるかを知っておくことには、動かない場合でも意味があります。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 岐阜県の一般行政職は**ラスパイレス指数99.3、平均給与月額407,540円**（令和6年4月1日現在・総務省調査）
- **地域手当は国の指定基準約2.45%に対し、実際の支給割合は約3.86%。**差は約1.4ポイントですが、比率では5割以上の上乗せです
- **地域手当は民間にない概念です。**源泉徴収票の支払金額と、求人票の想定年収で比べてください
- 経験が効く方向は、**条件の違う2地域を同時に扱った経験／地場産業の支援／高度なものづくり／中山間地域の交通と生活基盤／市町村支援**の5つです
- 地域差の扱いは**何を変え、何を変えなかったか**まで書いてください。全国展開を考える企業に直接読まれます
- **勤務地から検索しない。**職種で絞ってから勤務形態を確認する順序に変えてください

## よくある質問

### 名古屋の企業に転職すると、通勤が現実的ではないのですが

**毎日通う前提で考えないでください。**リモート可、週数日出社の求人が増えています。とくに自治体を顧客にする企業は、担当エリアに出向くことが仕事なので、本社への出社頻度が低い場合があります。**募集要項の勤務形態の記載まで確認してから判断してください。**通えないと判断するのは、その後で十分です。

### 地域手当がなくなると、実質的に給与が下がりませんか

**下がる場合はあります。**ただし民間企業の給与体系には地域手当という区分がなく、勤務地の物価や相場は基本給や各種手当に織り込まれています。したがって「地域手当の分だけ減る」という比べ方自体が成り立ちません。**現在の源泉徴収票の支払金額**を基準にして、求人票の想定年収と比べてください。

### 中山間地域の担当でしたが、経験として弱くないですか

**弱くありません。**むしろ、条件の厳しい地域で制度を回した経験は、県外でも求められます。人口減少と移動条件の制約は全国共通の課題ですが、**実際に再編や統合を通した人はまだ多くありません。**自治体向けコンサルティング会社や、インフラ運営を受託する企業が探しているのは、この経験です。書くときは地域名ではなく、合意をどう作ったかで書いてください。
