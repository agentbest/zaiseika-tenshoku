製造業の管理部門を検討される方から、**同じ2つの質問**をいただきます。

**「給与は上がりますか」**

**「工場勤務になると、生活はどう変わりますか」**

**1つ目に、当社が数字でお答えすることはできません。**会社ごとに事情が違いますし、**裏を取っていない数字を並べるのは、この記事の趣旨に反します。**

**2つ目のほうが、実は影響が大きい**です。そして、こちらは**制度の仕組みから説明できます。**

この記事では、**何が根拠になっているか**と、**製造業に固有の働き方の仕組み**を扱います。職種の整理は[未経験から製造業の管理部門に入るには](industry-seizo-mikeiken.html)にあります。

## 給与の根拠が、条例から就業規則に変わります

**いま、給与の根拠になっているのは条例です。**

**地方公務員法第24条第1項**です。

> **職員の給与は、その職務と責任に応ずるものでなければならない。**

**同条第2項**は、**「生計費並びに国及び他の地方公共団体の職員並びに民間事業の従事者の給与その他の事情を考慮して定められなければならない」**と定めています。**考慮すべきものが、法律に書かれています。**

**民間企業では、この構造がありません。**

**労働基準法第89条**は、**常時10人以上の労働者を使用する使用者に、就業規則の作成と行政官庁への届出**を義務づけており、**記載事項として「賃金の決定、計算及び支払の方法、賃金の締切り及び支払の時期並びに昇給に関する事項」**が挙げられています。

| | 役所 | 製造業の会社 |
|---|---|---|
| 根拠 | **条例** | **就業規則・給与規程** |
| 決め方 | 法律の考慮事項にもとづく | 会社が定める |
| 見られるか | **公表されている** | 在職者は見られる。応募時は要確認 |
| 事業所ごとの差 | 基本的に無い | **工場ごとに手当が違うことがある** |

**最後の行が、製造業の特徴**です。**本社と工場、工場と工場で、勤務の条件や手当が違う**ことがあります。**どの事業所に配属されるかで、条件が変わる**ということです。

## 1年単位の変形労働時間制という仕組みがあります

**製造業で、いちばん知っておいていただきたい条文**です。

**労働基準法第32条の4第1項**です。

> **使用者は、当該事業場に、労働者の過半数で組織する労働組合がある場合においてはその労働組合、労働者の過半数で組織する労働組合がない場合においては労働者の過半数を代表する者との書面による協定により、次に掲げる事項を定めたときは、第三十二条の規定にかかわらず、**その協定で第二号の対象期間として定められた期間を平均し**一週間当たりの労働時間が四十時間を超えない範囲内において**、（中略）**労働させることができる。**

**第2号**の**対象期間**は、**「その期間を平均し一週間当たりの労働時間が四十時間を超えない範囲内において労働させる期間をいい、一箇月を超え一年以内の期間に限る」**と定義されています。

**平たく言えば、一定の期間を平均して週40時間に収まればよい**という仕組みです。

**製造業でこの制度が使われる理由**は、**生産の繁閑があるから**です。

| 時期 | 働き方 |
|---|---|
| 生産が多い時期 | **1日の所定の労働時間が長くなる** |
| 生産が少ない時期 | 所定の労働時間が短くなる／休日が増える |
| 長期の休暇 | **会社の暦で、まとまって設定される** |

**⚠ ここが、役所と最も違う点**です。

**役所では、休暇は自分で取ります。**製造業では、**工場の稼働の計画に沿って、休日が会社の暦で決まる**ことがあります。**お盆や年末年始に、まとまった休みが設定される**一方で、**自分の都合で休む日を選びにくい時期**もあります。

**この仕組みが適用されるかどうかは、事業場と職種によります。**本社の管理部門では通常の時間管理、**工場の管理部門では工場の暦に合わせる**、という形もあります。**面接で確認してください。**

## 時間外労働と割増賃金の仕組みは、共通です

**労働基準法第37条**により、**時間外・休日・深夜の労働には割増賃金**が必要です。**役所の時間外勤務手当と、考え方は同じ**です。

**⚠ ただし、変形労働時間制のもとでは、時間外労働の数え方が変わります。**

**所定の労働時間が日によって違う**ため、**「8時間を超えたら時間外」という単純な数え方にならない**場合があります。

**確認のしかたは、面接で直接聞くことです。**「変形労働時間制が適用される職種でしょうか」「その場合、時間外の扱いはどうなりますか」。**聞いて構いませんし、説明できる会社であるかどうかも判断材料になります。**

## 働き方は、本社か工場かで分かれます

| | 本社の管理部門 | 工場の管理部門 |
|---|---|---|
| 時間の管理 | 通常の時間管理が多い | **工場の暦に沿うことがある** |
| 繁忙の波 | 決算、株主総会の時期 | **生産の計画と、監査・検査の時期** |
| 相手 | 他部門、外部の専門家 | **現場、行政、検査機関** |
| 出張 | 工場への出張 | 本社への出張 |
| 通勤 | 都市部が多い | **工場の所在地** |
| 住まい | 選択肢が多い | **社宅や寮があることも** |

**環境・安全の担当は、工場に置かれることが多い**です。[未経験から製造業の管理部門に入るには](industry-seizo-mikeiken.html)で触れたとおり、**届出や立入検査への対応は、現地でなければできない**ためです。

**経理・人事・法務は、本社と工場の両方に置かれる**ことがあります。**求人票の勤務地を必ず確認してください。**

:::insight
面談で伺っていて、**製造業に移った方が最初に戸惑うのが「休みが先に決まっている」**という点です。役所では、**年次有給休暇を自分の都合で取る**のが基本でした。工場の暦がある職場では、**大型連休の時期が会社側で決まっている**ことがあります。これを不自由と感じる方と、**楽だと感じる方**に、はっきり分かれます。楽だと感じる方の理由は、**「取る理由を考えなくてよい」**というものです。役所では、休むときに**周りへの気兼ねと、繁忙期を外す配慮**が要りました。会社の暦で決まっていれば、**その配慮が要りません。**一方、**お子さんの学校行事や、家族の予定に合わせたい方**にとっては、制約になります。ですから、確認していただきたいのは、**「暦で決まっている部分と、自分で取れる部分の割合」**です。面接で聞けます。「年間の休日のうち、会社の暦で決まっているのはどのくらいでしょうか」。**この1問で、生活の組み立て方がかなり分かります。**そして、**年次有給休暇の仕組みそのものは、役所も民間も同じ枠組み**です。違うのは、**所定の休日の決まり方**のほうだけです。
:::

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 場面 | 効く理由 |
|---|---|
| 締切が決まっている業務を回す | **予算・決算・議会の日程で動いてきた** |
| 記録を残して説明する | 監査を受ける前提の書類の作り方 |
| 規程や手順を整える | **要綱を条文の形で書いてきた** |
| 検査・監査への対応 | **検査する側にいた** |
| 現場の部署との調整 | 本庁と出先の関係に構造が似ている |

**効きにくい場所**

| 場面 | 効きにくい理由 |
|---|---|
| 生産の計画に合わせて動く | **自分の暦で組み立ててきた** |
| 原価の管理 | 予算の執行とは見る方向が違う |
| 製品や工程の知識 | 入ってから覚える領域 |
| 交替制の職場の労務管理 | 役所に対応する形が少ない |

**4つ目は、人事・労務の職種を志望する場合に効いてきます。**

**交替制の勤務がある職場の労務管理**は、**役所ではほとんど経験しません。**面接で聞かれたら、**「経験はありませんが、勤務時間の管理と、規程にもとづく運用は担ってきました」**という並べ方が自然です。

## 入る前に確認しておくこと

**労働基準法第15条第1項**は、**使用者が労働契約の締結に際し、賃金、労働時間その他の労働条件を明示しなければならない**と定めています。**明示すべき事項は、労働基準法施行規則第5条**に具体的に並んでいます。

**条件を示してもらうことは、権利として認められています。**

| 確認すること | どこで確認するか |
|---|---|
| 賃金の決定・計算・支払の方法、昇給 | **給与規程・労働条件通知書** |
| 就業の場所と、従事すべき業務 | **労働条件通知書**（配属される事業所を含む） |
| 始業・終業の時刻、休憩、休日 | 就業規則 |
| **変形労働時間制の適用の有無** | **面接で確認する** |
| 年間の休日のうち、会社の暦で決まる割合 | **面接で確認する** |
| 事業所ごとの手当の違い | 給与規程 |
| 転居を伴う異動の範囲 | **面接で確認する** |

**4つ目と5つ目は、この業界では必ず確認してください。**生活の組み立て方に直結します。

| 聞かれること | 何を見られているか |
|---|---|
| 勤務地が工場でも構いませんか | **前提の確認** |
| 転居を伴う異動は可能ですか | 事実の確認 |
| 繁忙期に、どう対処してきましたか | 段取りの作り方 |
| 現場の方と話をした経験はありますか | **工場での立ち位置** |
| 条件面で、譲れない点はありますか | **後から食い違わないか** |

**1つ目と2つ目は、正直に答えてください。**

**難しい事情があるなら、その場で言っておくほうが良い**です。入ってから困るより、**選考の段階で職種や配属先を調整してもらえる**ことがあります。

**5つ目に「特にありません」と答えないでください。**入ったあとに食い違う可能性を残します。

:::insight
ここまで確認の話をしてきましたが、**当社の見解を申し上げます。**製造業の管理部門を検討される方の中には、**「工場勤務は避けたい」**と最初から決めておられる方がいらっしゃいます。**ここは、一度ほどいて考えてみてください。**理由は2つあります。1つは、**環境・安全のように、公務員の経験がいちばん直結する職種が、工場に置かれていることが多い**からです。**工場を外すと、自分の強い持ち札が使える求人が候補から消えます。**もう1つは、**生活の条件が、都市部の勤務より良くなることがある**という点です。工場の所在地では、**通勤の時間が短く、住居の費用も抑えられる**ことがあります。社宅がある会社もあります。**役所からの転職で、通勤が楽になった**という例も伺っています。もちろん、**お子さんの学校や、ご家族の仕事の事情で動けない方**もいらっしゃいます。**その場合は、本社の職種に絞るのが正しい判断**です。申し上げたいのは、**「工場だから不便」という前提で候補を外す前に、具体的な場所と条件を見てください**ということだけです。そして、**確認した結果、いまの職に残るという結論**も、同じ資格で成り立ちます。当社が、いまの職を辞めることをお勧めすることはありません。
:::

## まとめ

- **給与の根拠が、条例から就業規則・給与規程に変わります**
- **地方公務員法第24条**は、給与が**職務と責任に応ずるもの**であること、**生計費・国や他団体の職員・民間事業の従事者の給与その他の事情を考慮して定められること**を定めています
- **労働基準法第89条**は、**常時10人以上の労働者を使用する使用者に就業規則の作成と届出**を義務づけています
- **労働基準法第32条の4**は、**一箇月を超え一年以内の対象期間を平均して、一週間当たりの労働時間が40時間を超えない範囲**で労働させることができる仕組みを定めています。**製造業では生産の繁閑に合わせて使われます**
- ⚠ **この仕組みのもとでは、休日が会社の暦で決まることがあります。**役所のように自分の都合だけで取る形とは違います
- ⚠ **変形労働時間制では、時間外労働の数え方が変わります。**面接で確認してください
- 働き方は、**本社か工場か**で分かれます。**環境・安全は工場に置かれることが多い**です
- **労働基準法第15条**と**施行規則第5条**により、**条件の明示は権利**です。**就業の場所と、異動の範囲を必ず確認**してください
- **「工場だから不便」という前提で候補を外す前に、具体的な場所と条件を見てください**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 交替制の勤務になることはありますか

**管理部門では、通常はありません。**交替制は、**生産の現場の勤務の形**です。ただし、**工場の管理部門では、現場の勤務の時間帯に合わせた対応が必要になる**ことがあります。たとえば、**朝の始業前に安全の朝礼がある、夜間の作業がある日に立ち会う、休日の点検に対応する**といった場面です。**頻度は会社と職種によります。**確認のしかたは、面接で**「現場の勤務の時間帯に合わせて出勤する場面は、どのくらいありますか」**と聞くことです。なお、**人事・労務の職種では、交替制の勤務の労務管理そのものが業務**になります。経験が無いことは正直に伝えて構いません。**規程にもとづく運用の経験**があれば、材料になります。

### 社宅や寮がある会社は、条件として有利ですか

**総額だけでは判断できません。**確認していただきたいのは、**自己負担の額と、利用できる期間、退去の条件**です。**入居できる期間が限られている**ことがあり、その後に住居の費用が自己負担になる場合があります。また、**社宅の有無によって、住居に関する手当の扱いが変わる**こともあります。**給与規程と社宅の規程の両方を確認してください。**役所でも同様の仕組みがある自治体がありますが、**条件は会社ごとに違います。**なお、**転居を伴う異動があるかどうかと、社宅の有無はつながっています。**異動の範囲を確認するときに、あわせて聞いておくと整理しやすいです。

### 退職の時期は、いつにするのが良いですか

**この記事では判断できません。**退職手当の算定、共済の扱い、年次有給休暇の残りなど、**個別の事情で変わります。**所属の人事担当部署と、**共済組合の窓口で確認**してください。一般論として申し上げられるのは、**内定が出てから退職の意思を伝えるほうが、選択肢が残る**ということだけです。あわせて、**製造業では入社の時期を生産の計画に合わせて相談される**ことがあります。**急かされることもあれば、待ってもらえることもあります。**現職の引き継ぎに必要な期間は、**選考の段階で伝えておいてください。**なお、**当社が、いまの職を辞めることをお勧めすることはありません。**確認した結果、残るという結論も正しい結論です。
