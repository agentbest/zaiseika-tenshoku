まちづくり・都市開発を検討される方から、**こう伺うことがあります。**

**「役所と同じような仕事なら、働き方も似ているのでしょうか」**

**似ている部分と、まったく違う部分があります。**

**似ているのは、制度の枠組みの中で動くこと。**違うのは、**時間の単位**です。

**役所の仕事は、年度で区切られます。**この業界の仕事は、**事業の段階で区切られます。**そして、**その段階は法律に書かれています。**

この記事では、**何が根拠になっているか**と、**働き方がどう変わるか**を扱います。業界の構造は[未経験からまちづくり・都市開発に入るには](industry-machizukuri-mikeiken.html)にあります。

**⚠ なお、給与の水準について、当社が数字でお答えすることはできません。**会社ごとに事情が違いますし、**裏を取っていない数字を並べるのは、この記事の趣旨に反します。**

## 仕事の区切りは、事業の段階です

**都市再開発法第72条第1項**です。

> **（権利変換計画の決定及び認可）第七十二条　施行者は、前条の規定による手続に必要な期間の経過後、遅滞なく、施行地区ごとに権利変換計画を定めなければならない。**この場合においては、国土交通省令で定めるところにより、**都道府県**（中略）**又は**（中略）**の認可を受けなければならない。**

**「前条の規定による手続に必要な期間の経過後、遅滞なく」**です。

**前の手続きが終わってから、次に進む。**この積み重ねで事業が進みます。

**そして、[未経験からまちづくり・都市開発に入るには](industry-machizukuri-mikeiken.html)で扱った第11条**が、**組合の設立の認可**を定めています。

**事業の段階を並べると、こうなります。**

| 段階 | 何が起きるか | 仕事の性格 |
|---|---|---|
| 構想・準備 | 権利者の意向の把握、勉強会 | **地道な個別対応が続く** |
| 組合の設立 | **第11条の認可**（定款・事業計画） | 書類の作成が集中する |
| 事業計画の認可 | 計画の確定 | 行政との協議が集中する |
| 権利変換 | **第72条の権利変換計画の認可** | **いちばん神経を使う段階** |
| 工事 | 施工、仮住まいの対応 | 現場対応が増える |
| 完了 | 清算、管理への移行 | 書類の整理が集中する |

**この段階ごとに、忙しさの質が変わります。**

**⚠ そして、年度とは無関係**です。**3月に忙しいとは限りません。**

## 給与の根拠は、条例から就業規則に変わります

**いま、給与の根拠になっているのは条例です。**

**地方公務員法第24条第1項**は、**「職員の給与は、その職務と責任に応ずるものでなければならない」**と定め、**同条第2項**は、**生計費・国や他の地方公共団体の職員・民間事業の従事者の給与その他の事情を考慮して定められなければならない**としています。

**労働基準法第89条**は、**常時10人以上の労働者を使用する使用者に、就業規則の作成と行政官庁への届出**を義務づけ、**記載事項として「賃金の決定、計算及び支払の方法、賃金の締切り及び支払の時期並びに昇給に関する事項」**を挙げています。

| | 役所 | この業界の会社 |
|---|---|---|
| 根拠 | **条例** | **就業規則・給与規程** |
| 見られるか | **公表されている** | 在職者は見られる。応募時は要確認 |
| 評価の単位 | 年度 | **案件の進捗と受注** |
| 資格の扱い | 手当がある場合がある | **資格手当が設けられていることがある** |

**3行目が、この業界の特徴**です。

**案件が長期にわたるため、「今年度の成果」で評価しにくい**という事情があります。**評価の仕組みがどうなっているかは、会社によって違います。****面接で確認してください。**

## 働き方は、会社の性格で分かれます

| | 全国の大規模な事業を扱う会社 | 地域に根ざした会社 |
|---|---|---|
| 勤務地 | **転勤・長期の出張がある** | 地域が固定されやすい |
| 案件の数 | **1〜2件を深く** | **複数件を同時に** |
| 忙しさの山 | 案件の段階で来る | **複数の案件の山が重なる** |
| 相手 | 大規模な権利者、行政、施工者 | **地元の権利者、市町村** |
| 効く経験 | 制度の理解、大規模な調整 | **地域の制度と担当課の動き方** |

**公務員から移る方には、右の列のほうが経験が効きやすい**ことがあります。**自分が知っている地域の制度と、行政の担当課の動き方が分かる**からです。

**ただし、複数の案件を同時に持つ**ため、**段取りの組み方が問われます。**

## 役所と違う点を、4つに整理します

| 違い | 内容 |
|---|---|
| ① 時間の単位 | **年度ではなく、事業の段階**で区切られる |
| ② 担当の期間 | **異動が無い。**同じ案件に10年関わることがある |
| ③ 相手 | **権利者との個別の対応が中心**になる |
| ④ 受注 | **仕事を取ってくる工程**がある |

**②が、いちばん大きい**です。

**[未経験からまちづくり・都市開発に入るには](industry-machizukuri-mikeiken.html)でも触れましたが、最後まで見られるのが、この仕事の魅力**です。一方で、**案件が止まったとき、異動で離れることができません。**

**③も、覚悟が要る部分**です。**権利者の方にとっては、住まいや商売の場所が変わる話**です。**説明会で全体に話すだけでなく、個別に何度も伺う**ことになります。

**役所で用地の取得や住民説明を担当していた方**は、**この性質を知っています。**知らずに入ると、**想定より消耗します。**

**④は、役所には無い工程**です。**提案書を作り、他社と競って選ばれる。**この場面にどう関わるかは、職位と会社によります。

:::insight
面談で伺っていて、**この業界に移った方が最初に驚くのが「入金までの期間」**です。再開発の事業は、**構想から完了まで長い年月がかかります。**その間、**会社は人件費を先に出し続けています。**契約の形にもよりますが、**業務の完了や事業の段階の到達をもって精算される**ことがあり、**着手から入金までに年単位の間が空く**場合があります。これが、働く側にどう効くかというと、**会社の資金の余裕が、働き方に直結する**ということです。余裕のある会社は、**案件が止まっても担当者を責めません。**余裕の無い会社では、**進捗の圧力が個人にかかります。**ですから、面接で確認していただきたいのは、**「いま動いている案件は何件ありますか」「そのうち、着手から5年以上経っているものはありますか」**です。⚠ **この2問は、会社の経営状態を直接聞くものではありません。**案件の構成を聞いているだけなので、**失礼にはなりません。**そして、**答えられない会社、答えたがらない会社**は、その反応自体が情報です。役所にいると、**事業が止まっても給与は変わりません。**この前提が変わることを、先に理解しておいてください。
:::

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 場面 | 効く理由 |
|---|---|
| 行政との協議 | **相手の意思決定の流れと時期が読める** |
| 権利者への個別の対応 | **用地の取得、住民説明の経験** |
| 計画・書類の作成 | 策定の手順を知っている |
| 組合の総会・理事会の運営 | 審議会・委員会の事務と同じ構造 |
| 補助の制度の活用 | **交付する側にいた** |
| 長期の案件を管理する | 計画の進行管理の経験 |

**効きにくい場所**

| 場面 | 効きにくい理由 |
|---|---|
| 受注の提案 | **売り込む工程が役所に無い** |
| 事業の採算の判断 | 予算の執行とは見る方向が違う |
| 案件が止まった状態への耐性 | **異動で離れられない** |
| 不動産の相場の感覚 | 市況の読みは経験で付く |

**3つ目について、正直に考えてみてください。**

**役所では、困難な案件も3年で引き継ぎました。**この業界では、**引き継げません。****同じ相手と、何年も向き合い続ける**ことになります。

**これを「最後まで見られる」と取るか、「逃げられない」と取るか**で、この転職の評価は分かれます。

## 入る前に確認しておくこと

**労働基準法第15条第1項**は、**労働契約の締結に際して、賃金・労働時間その他の労働条件を明示しなければならない**と定めています。**条件を示してもらうことは、権利として認められています。**

| 確認すること | どこで確認するか |
|---|---|
| 賃金の決定・計算・支払の方法、昇給 | **給与規程・労働条件通知書** |
| 就業の場所と、従事すべき業務 | **労働条件通知書** |
| **転勤・長期の出張の範囲** | **面接で確認する** |
| **評価の仕組み**（案件が長期の場合） | **面接で確認する** |
| 資格手当の有無 | 給与規程 |
| 動いている案件の数と、経過年数 | **面接で確認する** |
| 権利者対応で、夜間・休日の対応があるか | **面接で確認する** |

**最後の項目を忘れないでください。**

**権利者の方には、お勤めの方もいます。**説明や協議が、**平日の夜や休日**になることがあります。**頻度は会社と案件によります。**

:::insight
ここまで確認の話をしてきましたが、**この業界を検討される公務員の方に、必ず申し上げていること**があります。**前の職場と取引のある会社に移る場合、在職中の職務との関係が問題になることがあります。**再開発や区画整理の事業では、**自治体と民間の会社が委託や協議の関係にある**ことが多く、**自分が担当していた事業の相手方に移る**という形になりやすい。⚠ **再就職に関する規制は、国家公務員と地方公務員で異なり、地方公務員については自治体ごとに定めがあります。**離職前の職務との関係で、**一定期間、特定の行為が制限される**場合があります。**⚠ この記事では、個別の事情について判断できません。必ず、所属の人事担当部署と、適用される条例・規程を確認してください。**確認を怠ったまま進めると、**ご本人にも、移った先にも負担がかかります。**そして、**確認した結果、候補から外れる会社が出てくることもあります。**それは、**早い段階で分かったほうが良い**ことです。選考が進んでから問題になるより、**最初に確認しておくほうが、双方にとって負担が軽くて済みます。**当社が、いまの職を辞めることをお勧めすることはありません。**確認した結果、残るという結論も正しい結論です。**

## まとめ

- **仕事の区切りが、年度から事業の段階に変わります。****3月に忙しいとは限りません**
- **都市再開発法第72条第1項**は、**施行者が前条の手続に必要な期間の経過後、遅滞なく、施行地区ごとに権利変換計画を定め、認可を受けなければならない**と定めています
- **同法第11条**の**組合の設立の認可**から、権利変換、工事、完了まで、**段階ごとに忙しさの質が変わります**
- **給与の根拠が、条例から就業規則・給与規程に変わります。**⚠ **案件が長期のため、評価の仕組みを確認**してください
- 働き方は、**全国の大規模な事業を扱う会社**と**地域に根ざした会社**で分かれます。**公務員には後者のほうが経験が効きやすい**ことがあります
- 役所と違うのは、**①時間の単位 ②担当の期間（異動が無い） ③権利者との個別の対応 ④受注の工程**の4つです
- ⚠ **案件が止まっても、異動で離れられません。****「最後まで見られる」と取るか「逃げられない」と取るか**で評価が分かれます
- ⚠ **権利者対応が、平日の夜や休日になることがあります。**頻度を確認してください
- ⚠ **前の職場と取引のある会社に移る場合、再就職に関する規程の確認が要ります。**所属の人事担当部署に確認してください

## よくある質問

### 案件が止まったら、給与はどうなりますか

**通常、給与そのものが案件の進捗に直結することはありません。**労働契約にもとづいて支払われるためです。ただし、**賞与や評価に影響する仕組みを設けている会社**はあります。確認のしかたは、面接で**「評価は、どういう単位で行われますか」**と聞くことです。案件が長期にわたる業界なので、**年度ごとの成果では測りにくい**という事情があり、**会社によって工夫が違います。**プロセスを評価する仕組み、複数年で見る仕組み、受注への貢献を見る仕組み。**どの仕組みかによって、日々の動き方が変わります。**なお、**当社が会社ごとの制度をお伝えすることはできません。**給与規程と、面接での説明で確認してください。

### 資格は、入る前に取るべきですか

**職種によります。**技術的な業務を担う職種では、**関係する資格が応募の条件になっている**ことがあります。一方、**調整や手続きを担う職種**では、**要件になっていない募集もあります。**判断の目安は、**求人票の応募条件**です。⚠ **試験の内容や受験の要件については、実施する団体の公表を確認してください。**当社が確認していない内容はお伝えできません。なお、**資格手当が設けられている会社**もあるため、**給与規程で扱いを確認**しておくと、取る順番を考えやすくなります。**資格を取ってから応募する必要は、必ずしもありません。**実務の経験があるなら、先に応募して構いません。

### 退職の時期は、いつにするのが良いですか

**この記事では判断できません。**退職手当の算定、共済の扱い、年次有給休暇の残りなど、**個別の事情で変わります。**所属の人事担当部署と、**共済組合の窓口で確認**してください。⚠ **とくにこの業界では、再就職に関する規程の確認を先に行ってください。**前の職場と取引のある会社に移る場合、**離職前の職務との関係で制限がかかることがあります。**確認の結果によっては、**応募先の選び方そのものが変わります。**一般論として申し上げられるのは、**内定が出てから退職の意思を伝えるほうが、選択肢が残る**ということだけです。**当社が、いまの職を辞めることをお勧めすることはありません。**
