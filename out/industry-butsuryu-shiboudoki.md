物流の志望動機で、**いちばん多く見かける書き出し**があります。

**「社会を支えるインフラの仕事に関わりたいと考えました」**

**気持ちは伝わりますが、選考では効きません。**

理由は2つあります。**1つは、その一文が、どの物流会社にも当てはまること。**もう1つは、**「支える」だけでは、自分が何をする人なのか分からないこと**です。

**この業界は、いま制度が動いています。**そして、**動いている部分に、公務員の経験が直接刺さります。**

この記事では、**そこから志望動機を組み立てる手順**を扱います。業界の構造は[未経験から物流に入るには](industry-butsuryu-mikeiken.html)、条件の確かめ方は[物流の年収と働き方](industry-butsuryu-nenshu.html)にあります。

## 運送契約には、書面を交付する義務があります

**この業界で、いま何が起きているかを示す条文**です。

**貨物自動車運送事業法第12条**です。

> **（書面の交付）第十二条　真荷主及び一般貨物自動車運送事業者は、運送契約を締結するときは、国土交通省令で定める場合を除き、次に掲げる事項を書面に記載して相互に交付しなければならない。**
>
> 一　**運送の役務の内容及びその対価**
>
> 二　当該運送契約に**運送の役務以外の役務の提供が含まれる場合**にあっては、**運送の役務以外の役務の内容及びその対価**
>
> 三　その他国土交通省令で定める事項

**第2号に注目してください。**

**「運送の役務以外の役務」**です。**運ぶこと以外にやっている作業——荷役、待機、仕分け、検品——について、その内容と対価を書面に記載する**という建て付けになっています。

**これは、契約の内容を明確にする方向の規律**です。

**役所で契約事務をしてきた方なら、この意味がすぐ分かるはずです。****仕様に書かれていない作業が積み重なって、実態と契約が合わなくなる**——これは、公共調達でも起こることです。

そして、**同法第14条**は、一定規模以上の事業者に**安全管理規程を定め、届け出る**ことを義務づけています。

**つまり、この業界は「契約を書面で明確にし、規程にもとづいて運用する」方向へ動いています。**

**そして、この作業を担える人が足りていません。**

## 3つの層に分けます

| 層 | 問い | 材料の出どころ |
|---|---|---|
| ① 機能 | **なぜ、この職種なのか** | 役所での担当の経験 |
| ② 会社 | **なぜ、この会社・この拠点なのか** | 公表資料と求人票 |
| ③ 立場 | **なぜ、行政ではなく事業者の側なのか** | 自分の考えの変化 |

**「社会を支えたい」は、この3つのどこにも入りません。**だから通らないのです。

## ① 職種を選んだ理由は、経験から取ります

| 役所での担当 | 物流での対応する仕事 |
|---|---|
| 契約・入札の事務 | **契約の内容の整理、委託先の管理** |
| 要綱・規程の作成 | **安全管理規程、社内の手順の整備** |
| 勤務時間・休暇の管理 | **運行管理、労務の管理** |
| 監査・検査の対応 | 行政の監査への対応 |
| 許認可の審査 | 手続きの実務、変更の届出 |
| 災害・選挙の事務 | **計画が崩れたときの立て直し** |
| 窓口での苦情の対応 | 近隣・荷主からの申し出への対応 |

**書き方は、「担当しました」で止めないでください。****何を整えたか**を書きます。

> 業務委託の契約事務を担当していました。仕様書に書かれていない作業を受託者が行っている状態が続いていた案件について、実態を確認したうえで仕様を書き直し、次年度の契約で内容と対価を対応させました。

**「実態と契約が合っていない状態を、整理した」**という形になっています。**これが、第12条が目指している方向と重なります。**

## ② 会社と拠点は、求人票と公表資料から取ります

**物流会社の情報は、公式サイトだけでは分かりにくい**ことがあります。**求人票のほうが具体的**です。

| 資料 | 志望動機に使える材料 |
|---|---|
| 公式サイトの事業の紹介 | **運送か倉庫か、両方か** |
| 拠点の一覧 | **どこに拠点があるか、規模はどうか** |
| 求人票の仕事内容 | **その職種の日々の中身** |
| 求人票の募集の背景 | 増員か後任か |
| 採用のページ | 中途で入った人がどこにいるか |

**使い方は、「読みました」ではなく「読んで、自分の経験とどこが重なったか」**です。

> 求人票の仕事内容に、安全管理規程の見直しと、記録の様式の整備が挙げられていました。要綱と様式を改正のたびに作り直してきた経験があるので、この部分は着任後すぐに担えると考えています。

**この書き方は、求人票を読み込んでいないとできません。**

## ③ 行政ではなく、事業者の側である理由

**公務員から応募する場合、必ず問われます。**

**相手が確かめたいのは2つ**です。

| 相手の懸念 | 確かめたいこと |
|---|---|
| **指導する目線のまま来ないか** | 会社の側に立てるか |
| **現場と話ができるか** | 乗務員・作業者との距離の取り方 |

**答え方の型は、「基準を満たす仕組みを、内側から作る側へ」**です。

> 監査や検査は、その時点の状態を確認するものです。基準を満たし続ける仕組みを日常的に回しているのは、事業者の側です。指摘をする側ではなく、指摘を受けない状態を作る側で経験を使いたいと考えました。

**もう一つの型は、「制度が変わる時期に、対応する側で関わりたい」**です。

> 制度の改正のたびに、要綱と様式を作り直す仕事をしてきました。いま物流で進んでいる見直しは、規程と記録の作り直しを伴うものだと理解しています。その作業であれば、経験が使えると考えました。

**⚠ 避けてください——役所の批判から入る書き方**です。「規制が形式的だった」「現場を見ていなかった」。**この書き出しは、読む側から見ると、次は当社の悪いところを外で言う人に見えます。**

:::insight
面接に同席させていただいていて、**この業界で評価が分かれる瞬間**があります。**「乗務員の方や、作業者の方と、どう関わりますか」**という質問への答え方です。よくあるのは、**「法令にもとづいて、適切に指導します」**という答えです。これは、**この業界ではいちばん警戒される答え方**です。理由は、**管理の側と現場の側の関係が、この業界の長年の課題だから**です。管理部門が現場の実態を知らないまま指示を出すと、**記録は形だけ整い、実態は変わらない**という状態になります。評価される答え方は、**「まず、点呼や作業に立ち会わせてください」**という形です。実際に、**朝の点呼に何時に集まるのか、どの順番で確認しているのか、記録を書く時間が確保されているのか。**これを見ないと、**記録の様式を直しても、現場で使われません。**役所の側にいた方なら、**申請の様式が事業者の実務に合っていないと、書類が揃わない**という経験をお持ちのはずです。**同じ構造です。**そして、**本庁と出先の間の調整をしてきた方**は、この距離の取り方をすでに知っています。面接では、**その経験を具体的に出してください。**「現場を見てから決める」と言える人は、この業界では歓迎されます。
:::

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 経験 | 志望動機での使い方 |
|---|---|
| 契約・入札の事務 | **契約の内容と実態を対応させる仕事に直結** |
| 要綱・規程の作成 | 安全管理規程と手順の整備 |
| 勤務時間・休暇の管理 | **運行管理の中核と重なる** |
| 監査・検査の対応 | 受ける側の準備ができる |
| 災害・選挙の事務 | **計画が崩れたときの立て直し** |
| 本庁と出先の調整 | **管理と現場の距離の取り方** |

**効きにくい場所**

| 経験の不足 | 面接での扱い方 |
|---|---|
| 料金の設定と交渉 | **構造の理解を示す** |
| 荷主への提案 | 売り込む仕事は役所に少ない |
| 現場の作業の段取り | **見てから覚える前提で話す** |
| 突発の事態への即応 | 災害・選挙の経験を出す |

**3つ目は、隠さないでください。**

**「作業の経験はありません。ですから、まず立ち会わせていただきます」**という言い方で足ります。**知ったふりをするほうが、この業界では信用を落とします。**

## 材料を集める順番

| 順 | やること | 目安 |
|---|---|---|
| 1 | **契約・規程・労務**のうち、担った機能を書き出す | 30分 |
| 2 | **「実態と書面が合っていない状態を整理した」経験**を探す | 1時間 |
| 3 | 応募先の**事業の種類と拠点の場所**を確認する | 1時間 |

**2つ目が、この業界では効きます。**

## 面接で聞かれやすいこと

| 聞かれること | 何を確かめられているか |
|---|---|
| なぜ物流なのですか | **職種で答えられるか** |
| 乗務員や作業者の方と、どう関わりますか | **立ち位置の理解** |
| 行政の監査で、どちらの立場に立ちますか | **元の所属に引きずられないか** |
| 計画が崩れたときに、どう動きましたか | 突発への対応 |
| 早朝や夜間の勤務は可能ですか | 前提の確認 |

**3つ目は、必ず聞かれます。**

**答え方は、「会社の側に立ちます。ただし、行政の側の見方も分かるので、指摘を受けにくい整え方ができます」**という形が自然です。**「元の所属に配慮します」と答えないでください。**

:::insight
ここまで組み立て方の話をしてきましたが、**逆のことも申し上げます。**志望動機を完成させてから応募しようとして、**動き出しが止まってしまう方**がいらっしゃいます。実際には、**①と②の材料が揃った段階で応募して構いません。**③は、**選考の過程で固まります。**そして、**この業界を見るときには、もう一つやっておいていただきたいこと**があります。**実際に拠点へ行ってみること**です。[物流の年収と働き方](industry-butsuryu-nenshu.html)でも触れましたが、物流の拠点は**公共交通機関からたどり着きにくい場所**にあることが多く、**通勤の前提が変わります。**そして、**行ってみると、志望動機の中身も変わります。**荷物が動いている時間帯、働いている方の年齢層、建物の状態。**資料では分からないことが分かります。**面接のときに行くのでも構いませんが、**その前に一度、外から見ておく**と、質問の質が変わります。そのうえで、**条件が合わずに見送るという結論**になることもあります。**それも正しい結論です。**そして、**いまの職に残る判断**も、同じ資格で成り立ちます。当社が、いまの職を辞めることをお勧めすることはありません。在職のまま、情報だけ取るご相談も承っています。
:::

## まとめ

- **「社会を支えるインフラ」は、志望動機になりません。**どの物流会社にも当てはまるためです
- **貨物自動車運送事業法第12条**は、**真荷主及び一般貨物自動車運送事業者が運送契約を締結するときに、運送の役務の内容及びその対価**、**運送の役務以外の役務が含まれる場合はその内容及び対価**などを、**書面に記載して相互に交付しなければならない**と定めています
- **同法第14条**は、一定規模以上の事業者に**安全管理規程を定め、届け出る**ことを義務づけています
- **この業界は「契約を書面で明確にし、規程にもとづいて運用する」方向へ動いています。**その作業を担える人が足りていません
- 志望動機は、**①機能（なぜこの職種か） ②会社・拠点 ③行政ではない理由**の3層に分けます
- ①の材料は、**契約・入札、要綱の作成、勤務時間の管理、監査の対応、災害・選挙の事務**にあります
- ⚠ **「実態と書面が合っていない状態を整理した」経験**を探してください。**第12条が目指す方向そのもの**です
- ③は、**「内側から作る側へ」**または**「制度が変わる時期に対応する側で」**の型で書きます
- ⚠ **「適切に指導します」と答えないでください。****「まず点呼や作業に立ち会わせてください」**が、この業界で評価される答え方です

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 物流の知識がまったくありません。志望動機が書けません

**知識は、①の材料にはなりません。**①は「なぜこの職種か」なので、**役所で担ってきた機能**が材料です。契約、規程、労務、記録。**これらは、物流の知識がなくても書けます。**そのうえで、**業界の動きを押さえておく**と、②と③に厚みが出ます。押さえるのは、**労働時間の規制、荷役作業の負担の軽減、共同配送、自動化**の4つで足ります。**1〜2週間、業界の報道を追えば、面接で話が通じる程度にはなります。**⚠ ただし、**数字を覚えて話そうとしないでください。**確認していない数字を面接で口にすると、突っ込まれたときに答えられません。**構造を理解していることが伝われば十分**です。

### 前職で、物流事業者を指導する立場でした。有利ですか

**書き方次第です。**手続きや監査の構造を知っていること自体は、**材料になります。**ただし、**「指導していた」という書き方をすると、③の懸念（指導する目線のまま来ないか）を強めます。**書くなら、**「基準の確認をする立場にいたので、どこが見られるかが分かります」**という、**能力の話に留めてください。**⚠ また、**特定の事業者に関する情報や、前職で知り得た内部の事情を書かないでください。**守秘の観点に加えて、**この人は情報を外で話すと受け取られます。**なお、**元の所属との関係を有利さとして示すことも避けてください。**期待されているのは、**制度の理解であって、人脈ではありません。**

### 志望動機は、何社ぶん書き分ける必要がありますか

**①は共通で構いません。②と③は、会社ごとに書き直してください。**①は「なぜこの職種か」なので、**同じ経験が材料になります。**②はその会社の求人票から取った材料なので、**使い回すと読んでいないことが分かります。**③も、**会社の性格で説得力のある型が変わります。**規程の整備が課題の会社なら「内側から作る側へ」、事業の拡大の局面にある会社なら「制度が変わる時期に対応する側で」。**同じ言葉でも、置く場所で意味が変わります。**なお、**応募先を絞りすぎない**ほうが、③を言葉にする機会が増えます。拠点の場所が違えば、**通勤の条件も比べられます。**
