**定年までの期間が見えてくる段階**です。

**その後の働き方を含めて考える方がいらっしゃいます。**

この記事では、**選択肢の整理**と、**経験の示し方**を扱います。

**⚠ 定年や再任用の制度は、条例と規程によって異なります。****必ず所属に確認してください。**

## 民間にも、65歳までの雇用を確保する仕組みがあります

**高年齢者等の雇用の安定等に関する法律第9条第1項**です。

> **定年**（六十五歳未満のものに限る。以下この条において同じ。）**の定めをしている事業主は、その雇用する高年齢者の六十五歳までの安定した雇用を確保するため、次の各号に掲げる措置**（略）**のいずれかを講じなければならない。**
>
> 一 **当該定年の引上げ**
>
> 二 **継続雇用制度**（現に雇用している高年齢者が希望するときは、当該高年齢者をその定年後も引き続いて雇用する制度をいう。以下同じ。）**の導入**
>
> 三 **当該定年の定めの廃止**

**3つのいずれかを講じなければならない**という構造です。

**つまり、転職先にも、65歳までの雇用を確保する仕組みが置かれている**ということです。

**ただし、どの措置がとられているかは会社によって異なります。**

**応募の段階で、定年の定めと、その後の扱いを確認**してください。

## 選択肢の整理

| 選択肢 | 内容 |
|---|---|
| ① いまの団体で続ける | 定年まで、その後は制度による |
| ② 定年前に転職する | 次の勤務先で働く |
| ③ 定年後に働く | 退職後に、改めて勤務する |
| ④ ①と③の組み合わせ | 定年まで勤め、その後に移る |

**④を候補から外さないでください。**

**定年まで勤めたうえで、その後に移る**という進め方があります。

**この場合、退職手当の扱いや、制度の適用が変わります。**

**扱いは所属に確認**してください。

**なお、②と④では、確認すべきことが異なります。**

**先に、どちらを検討しているかを決めてください。**

## 何が見られているか

| 項目 | 内容 |
|---|---|
| ① 専門の深さ | **その分野で何ができるか** |
| ② 判断の経験 | 前例のない事案への対応 |
| ③ 調整の経験 | 相手と、難易度 |
| ④ 育成 | 後進への指導、手順の整備 |
| ⑤ 健康と勤務の条件 | 働ける時間、日数 |
| ⑥ 役割の受け止め方 | **職位にこだわらず働けるか** |

**⑥が確認される**ことがあります。

**前職より職位が下がる形での採用になる場合**があるためです。

**「どのような役割でも、必要とされる仕事をする」という姿勢が伝われば足ります。**

**ただし、無理に迎合する必要はありません。**

**自分が担いたい範囲を、条件として伝えて差し支えありません。**

## 行政が相手の事業との接続

| 事業の形 | 経験の使いどころ |
|---|---|
| 発注者支援 | 工事の監督、積算、工程の管理 |
| 制度の運用の支援 | 審査、要件の確認、相談の対応 |
| 施設の運営 | 管理、利用者の対応、収支 |
| 計画の策定の支援 | 調査、資料の作成、説明 |
| 事業者への指導 | 基準の確認、是正の要求 |

**この領域では、経験の長さがそのまま要件になる**ことがあります。

**制度の仕組み、意思決定の流れ、予算の時期。**

**これらを知っていること自体が価値になります。**

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

:::insight
50代のご相談で、**面談でお伝えしているのが「定年まで勤めるという選択を、先に検討してください」**という点です。**転職を考え始めると、いま動くことが前提になりがち**です。ところが、**定年まで勤めたうえで、その後に働くという選択**があります。この場合、**退職手当や年金の扱いが変わります。**扱いは制度によるため、**所属と共済組合に確認が必要**ですが、**確認してから判断するほうが確実**です。そして、**行政が相手の事業では、定年後に移る方が少なくありません。**制度の理解と実務の経験が、そのまま要件になるためです。**「もう遅い」ということはありません。**一方で、**いま動く理由がある場合**——担いたい役割がある、健康の状態、家族の事情——**それは、待つ理由より優先されることがあります。****どちらを優先するかは、材料を並べてから決めてください。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 確認すること

| 項目 | 確認先 |
|---|---|
| 定年の時期 | 所属の人事担当 |
| 再任用などの制度 | 同上 |
| 退職手当の扱い | 給与担当 |
| 年金の受給の見込み | **年金事務所・共済組合** |
| 健康保険の扱い | 共済組合 |

**3行目と4行目**です。

**退職の時期によって、扱いが変わることがあります。**

**金額と時期は制度によって異なる**ため、**所管するところに直接確認**してください。

**この記事では金額に触れません。**

**扱いは**[退職手当はいつ振り込まれるか](senko-taishoku-shikyubi.html)**も併せて確認してください。**

## 経験の示し方

**悪い例**

> ◯◯課で30年、用地の取得を担当しました。

**良い例**

> 用地の取得を長く担当し、**相続が複数代にわたる土地の権利者の調査**や、**制度の要件に当てはまらない事案の判断の方針の整理**を担当。**新任の担当者への指導と、確認の手順書の作成**を継続的に実施。**他団体からの照会への回答**も担った。

**「例外の処理」「育成」「照会の受け皿」**が入っています。

**この3つは、年数がないとできないこと**です。

**専門性という言葉を使わずに、専門性を示せます。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 勤務の条件

| 項目 | 整理すること |
|---|---|
| 勤務の日数 | 常勤か、短時間か |
| 勤務の時間 | 始業・終業 |
| 通勤 | 距離と時間 |
| 出張・転勤 | 対応の可否 |
| 健康 | 定期の通院などの有無 |

**1行目です。**

**常勤に限らず、短時間の勤務での募集**もあります。

**働き方の幅を先に決めておくと、求人の範囲が変わります。**

**5行目について。**

**定期の通院などがある場合、勤務の日や時間の調整が必要になります。**

**応募の段階で、対応の可否を確認**してください。

**伏せて入社すると、調整ができません。**

**伝える範囲は、勤務に関わる部分で足ります。**

**病名や経緯を詳しく説明する必要はありません。**

## よくある失敗

**1. 定年まで勤める選択を検討しない**

**確認してから判断**してください。

**2. 退職手当・年金の扱いを確認しない**

**退職の時期で変わる**ことがあります。

**3. 年数だけで経験を語る**

**例外の処理、育成、照会の受け皿**を書いてください。

**4. 職位にこだわる**

**役割の中身**で見てください。

**5. 常勤だけを探す**

**短時間の募集**もあります。

**6. 定年の定めを確認しない**

**会社によって措置が異なります。**

**7. 健康の条件を整理しない**

**働ける範囲が決まりません。**

**8. 行政が相手の事業を見ない**

**経験の長さが要件になる**領域です。

:::insight
ここまで選択肢の話をしておいて逆のことを言いますが、**この年代で最も効くのは、人に教えられることです。**面談で拝見していると、**ご自身の経験を「当たり前のこと」として語る方**がいらっしゃいます。ところが、**制度の要件をどう確認するか、例外の事案をどう整理するか、相手にどう説明するか。****これらは、手順として書き出せる形で持っている方が少ない**です。そして、**行政が相手の事業を担う会社では、この手順を必要としています。**新しく入った人が、**制度を理解するまでに時間がかかる**ためです。**手順を整備し、人に教えられる人**は、そこで役に立ちます。ですから、**書類には「作った手順書」「指導した人数」「回答した照会」を書いてください。****実務ができることに加えて、実務を伝えられる**という点が、この年代の強みになります。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **高年齢者等の雇用の安定等に関する法律第9条第1項**は、**65歳までの安定した雇用を確保するため、定年の引上げ・継続雇用制度の導入・定年の定めの廃止のいずれかの措置**を義務づけています
- **どの措置がとられているかは会社によって異なります。**応募の段階で確認してください
- 選択肢は、**①続ける ②定年前に転職 ③定年後に働く ④定年まで勤めてから移る**です
- **④を候補から外さないでください**
- **退職手当・年金の扱い**は、所属・共済組合・年金事務所に確認してください
- 経験は、**年数ではなく「例外の処理」「育成」「照会の受け皿」**で示してください
- **実務を伝えられること**が、この年代の強みになります

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### この年代で、応募できる求人はありますか

**求人の条件によります。****労働施策総合推進法第9条**は、**募集及び採用について、年齢にかかわりなく均等な機会を与えなければならない**と定めています。年齢の記載がある求人では、**その理由が示されている**ことがあります。判断の目安は、**求人票の「必須」の欄**です。求められている経験が自分にあるかを見てください。なお、**行政が相手の事業では、実務の年数と制度の理解が要件**とされていることがあります。**発注者支援、制度の運用の支援、施設の運営**などです。**年代ではなく、経験の中身で判断**してください。数は限られますが、**条件の合う求人は存在します。**

### 定年後に働くほうがよいのでしょうか

**確認してから判断してください。**比べる材料は、**退職手当の扱い、年金の受給の見込み、健康保険の扱い、担いたい役割、健康の状態**です。**制度に関わる部分は、所属・共済組合・年金事務所に確認**してください。**金額と時期が分かれば、比べられます。**なお、**定年まで勤めてから移る場合、その間に準備ができます。**職務経歴書の作成、制度の確認、求人を読む作業。**これらは在職中に進められます。**一方、**いま動く理由がある場合**は、その理由を優先して差し支えありません。**どちらが正解ということはありません。**

### 職位が下がる形での採用に、抵抗があります

**役割の中身で見てください。**民間では、**同じ名称でも範囲が違います。**名称が下がっても、**担う範囲が広い**ことがあります。逆に、名称が同じでも範囲が狭いこともあります。**確認するのは、何を担当し、何を決められるか**です。「この役割では、どこまでを判断していただくことになりますか」という聞き方で確認できます。なお、**抵抗があること自体は、無理に抑える必要はありません。**担いたい範囲があるなら、**それを条件として伝えて差し支えありません。**条件が合う求人に絞るほうが、入社後に続きます。**伏せて入社して、後から合わないほうが負担になります。**
