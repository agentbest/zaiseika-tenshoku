観光・地域振興の選考について、**公務員の方が戸惑う点**が2つあります。

**「募集が、いつの間にか終わっていました」**

**「面接が1回で、その場で条件の話になりました」**

**どちらも、この分野では起こること**です。**組織が小さく、採用の手順が整っていない**ためです。

**これは、応募する側にとって利点でもあり、注意点でもあります。**

この記事では、**選考の流れと、面接で見られている観点**を扱います。業界の構造は[未経験から観光・地域振興に入るには](industry-kanko-mikeiken.html)、志望動機の組み立ては[観光・地域振興の志望動機](industry-kanko-shiboudoki.html)にあります。

## 資格者の選任が要る職があります

**旅行業に関わる職を志望する場合、知っておいていただきたい条文**です。

**旅行業法第11条の2第1項**です。

> **（旅行業務取扱管理者の選任）第十一条の二　旅行業者又は旅行業者代理業者**（以下「旅行業者等」という。）**は、営業所ごとに、一人以上の第六項の規定に適合する旅行業務取扱管理者を選任して、当該営業所における旅行業務に関し、その取引に係る取引条件の明確性、旅行に関するサービスの**（後略）

**「営業所ごとに、一人以上」「選任して」**です。

**[物流の選考フローと、面接で見られている観点](industry-butsuryu-senko.html)で扱った運行管理者**と、**構造が同じ**です。**選任が義務なので、欠員が出ると困ります。**

**結果として、有資格者の募集は急ぎで出ます。**

**⚠ ただし、これは旅行業を営む組織の、旅行業務に関わる職の話**です。

**観光協会や地域の法人でも、旅行の手配を事業として行う場合は登録と選任が要ります。**一方、**企画、調整、補助金の申請、情報の発信が中心の職**では、**この資格は要件になっていない募集が大半**です。

**⚠ 試験や選任の要件については、所管する観光庁や試験を実施する機関の公表を確認してください。**当社が確認していない内容は、この記事には載せていません。

## 選考の流れは、組織の規模で分かれます

| 組織 | 流れの型 | 回数の目安 |
|---|---|---|
| 観光協会・地域の法人（小規模） | 書類 → **代表・事務局長** | **1〜2回。速い** |
| 観光協会（一定の規模） | 書類 → 事務局長 → 理事 | 2〜3回 |
| 地域商社・まちづくり会社 | 書類 → 責任者 → 代表 | 2回前後 |
| 宿泊事業者の管理部門 | 書類 → 部門長 → 役員 | 2〜3回 |
| 観光のコンサルタント | 書類 → 部門長 → **課題** → 役員 | 3回前後 |
| 行政からの受託が中心の法人 | 書類 → 責任者 → 役員 | 2〜3回 |

**上の3つは、選考が速い**です。**決める人が最初から出てきます。**

**利点は、決定権のある人と直接話せること。**注意点は、**条件の確認が追いつかないまま進みやすいこと**です。

**⚠ 速く進むときほど、確認する項目を先に決めておいてください。**

**観光のコンサルタントでは、課題の提出**を求められることがあります。**「この地域について、あなたならどう進めますか」**という形です。

**⚠ ここで、行政の計画の手順で書かないでください。**「現況の調査を行い、課題を整理し」は、**役所の側の手順**です。**求められているのは、「誰と組んで、何から始めるか」**です。

## 募集を見落とさない方法

**この分野でいちばん多い失敗が、募集の見落とし**です。

**[未経験から観光・地域振興に入るには](industry-kanko-mikeiken.html)でも触れましたが、観光協会や地域の法人の募集は、一般の求人サイトに出ないことがあります。**

| 見る場所 | 頻度 |
|---|---|
| 法人の公式サイトの「お知らせ」 | **週に一度** |
| 自治体の公表（関係団体の募集） | 週に一度 |
| 関係する団体の案内 | 月に一度 |
| 一般の求人サイト | 随時 |

**募集の期間が2週間程度ということもあります。**

**⚠ そして、募集が出ていない時期でも、問い合わせから始める方法**があります。「採用の予定があれば教えてほしい」という短い連絡で足ります。**半年後に欠員が出たときに連絡が来た、という例もあります。**

## 面接で見られている観点は、5つです

| 観点 | 具体的に確かめられること |
|---|---|
| ① 条件の確認 | **土日の勤務、期間の定めを確認してきたか** |
| ② 補助・受託の実務 | **申請と実績の報告ができるか** |
| ③ 地域の関係者との距離 | **行政の目線で来ないか** |
| ④ 少人数での兼務 | 分掌の外を拾えるか |
| ⑤ 定着の見込み | **すぐ辞めないか** |

**①が、この分野では特に見られます。**

**[観光・地域振興の志望動機](industry-kanko-shiboudoki.html)でも触れましたが、「覚悟しています」より「確認してきました」のほうが効きます。**

**職員が数名という組織では、一人辞めることの影響が大きい**ためです。

**②は、公務員の強い持ち札**です。

**答え方は、審査の観点**にしてください。「交付する側として、事業の目的と実施の内容が対応しているか、経費の区分が適切か、成果をどう測るかを見ていました。申請する側でも、その観点で組み立てられます」。

**③は、警戒される点**です。**「行政と調整します」という答え方より、「地域の方の話を先に聞きます」**という形にしてください。

:::insight
選考に同席させていただいていて、**この分野で公務員の方が損をする場面**があります。**「うちに来て、何をしたいですか」**という質問への答え方です。多くの方が、**施策の提案**をされます。「この地域は滞在型への転換が課題なので、夜の過ごし方を作る取組が要ると思います」。**内容としては正しいことが多いのですが、この分野ではあまり効きません。**理由は、**その程度のことは、すでに何度も議論されているから**です。小さな組織ほど、**課題は分かっているが、手が足りなくて進んでいない**という状態にあります。ですから、評価される答えは、**「何をしたいか」より「何を引き受けられるか」**です。「補助金の申請と実績の報告は、着任後すぐに引き取れます。まずそこを担って、企画に回せる時間を作りたいと考えています」。**この答えは、相手の負担が減る絵**になっています。⚠ そして、**提案は入ってからいくらでもできます。**面接の段階で提案を出すと、**「中を知らないのに言っている」**と受け取られることがあります。まず引き受ける。**それが、この分野で信用される入り方です。**
:::

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 場面 | 効く理由 |
|---|---|
| 補助・受託についての質問 | **交付する側・発注する側にいた** |
| 行政との協議の段取り | 相手の意思決定の流れが読める |
| 計画についての質問 | **策定の手順を知っている** |
| 会議体の運営 | 審議会・委員会の事務 |
| 書類の作り込み | 記録を残す習慣 |

**効きにくい場所**

| 場面 | 効きにくい理由 |
|---|---|
| 成果を数字で語る | **役所では個人の成果として記録されない** |
| 自己紹介を短く話す | 説明が経緯から始まりがち |
| 課題で実行の手順を書く | **計画の手順で書いてしまう** |
| 即断を求められる場面 | 前例を確認してから答える習慣 |

**4つ目について。**この分野の面接では、**「いつから来られますか」「この条件で大丈夫ですか」**と、その場で判断を求められることがあります。

**即答する必要はありません。****「持ち帰って確認させてください」で構いません。**

## 準備の手順

| 順 | やること | 目安 |
|---|---|---|
| 1 | **補助・受託の実務**の経験を書き出す | 1時間 |
| 2 | **「引き受けられること」を3つ**決める | 30分 |
| 3 | 応募先の**自治体の観光の計画**を読む | 1時間 |
| 4 | 組織の**事業の報告と財源**を確認する | 1時間 |
| 5 | **確認する項目を4つ**決める（土日・期間・財源・休日の取り方） | 20分 |
| 6 | **土日の勤務について、家族と話す** | — |

**2つ目が、この分野では効きます。****「何をしたいか」ではなく「何を引き受けられるか」**です。

**5つ目と6つ目を、必ず済ませてください。**選考が速いので、**その場では間に合いません。**

[経験の言い換えから相談する](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担です）。

## 逆質問で使えるもの

| 質問 | 何が分かるか |
|---|---|
| この職の財源は、補助・受託・自主事業のどれですか | **職の期間** |
| 期間の定めがある場合、満了後に継続された方はいますか | **実績** |
| 年間の休日を、どういう形で取っていますか | **生活の組み立て方** |
| 前任の方は、どういう経緯で離れましたか | 定着の状況 |
| 入って最初に引き受けてほしいことは何ですか | 期待されている役割 |

**1つ目と2つ目は、遠慮せずに聞いてください。**[観光・地域振興の年収と働き方](industry-kanko-nenshu.html)で触れたとおり、**行政からの受託や補助を財源とする職で、期間が定められている**ことがあります。

## 内定から入社まで

**労働基準法第15条第1項**により、**労働契約の締結に際して、賃金・労働時間その他の労働条件の明示**が求められます。**書面で条件を確認してください。**

**⚠ 小規模な組織ほど、書面の交付が後回しになることがあります。**口頭で聞いた条件と、書面の内容が一致しているかを確認してください。

**⚠ とくに、期間の定めの有無**です。**口頭では「更新は問題ない」と言われても、書面で期間が定められているなら、それが契約の内容**です。

:::insight
ここまで対策の話をしてきましたが、**この分野を受ける前に、必ず済ませておいていただきたいこと**があります。**再就職に関する規程の確認**です。観光協会や地域の法人は、**自治体から補助や委託を受けている**ことが多く、**自分が担当していた相手方に応募する**形になりやすい。⚠ **規制は、国家公務員と地方公務員で異なり、地方公務員については自治体ごとに定めがあります。**離職前の職務との関係で、**一定期間、特定の行為が制限される**場合があります。**⚠ この記事では、個別の事情について判断できません。必ず、所属の人事担当部署と、適用される条例・規程を確認してください。**⚠ そして、**選考が速い分野なので、応募してから確認するのでは間に合わないことがあります。**内定が出てから問題が分かると、**ご本人にも、組織にも負担がかかります。**とくに、職員が数名という組織では、**採用のやり直しの負担が大きい。**応募先を選ぶ前に済ませておけば、**候補の絞り方が最初から定まります。**当社が、いまの職を辞めることをお勧めすることはありません。**確認した結果、残るという結論も正しい結論です。**
:::

## まとめ

- **選考が速いのは、組織が小さく、採用の手順が整っていないから**です。**決める人が最初から出てきます**
- **旅行業法第11条の2第1項**は、**旅行業者等が営業所ごとに一人以上の旅行業務取扱管理者を選任する**ことを義務づけています。**選任が義務なので、有資格者の募集は急ぎで出ます**
- ⚠ **これは旅行業務に関わる職の話**です。**企画・調整・補助の申請・情報の発信が中心の職では、要件になっていない募集が大半**です
- ⚠ **募集の見落としが、この分野でいちばん多い失敗**です。**法人の公式サイトと自治体の公表を、週に一度見てください**
- 見られている観点は、**①条件の確認 ②補助・受託の実務 ③地域の関係者との距離 ④少人数での兼務 ⑤定着の見込み**の5つです
- ⚠ **「何をしたいか」より「何を引き受けられるか」**を答えてください。**課題は分かっているが手が足りない**という状態にあります
- ⚠ **提案は入ってからできます。**面接で提案を出すと「中を知らないのに言っている」と受け取られることがあります
- ⚠ **応募する前に、確認する項目を4つ決めておいてください。**選考が速いので、その場では間に合いません
- ⚠ **応募先を選ぶ前に、再就職に関する規程の確認を済ませてください**

## よくある質問

### 在職中です。選考の速さに追いつけますか

**追いつけます。**伝え方は、**「現職の引き継ぎに◯か月必要です」**と、**最初の面接で先に言っておくこと**です。これを言っておくと、**組織の側も入社の時期を前提に組めます。**⚠ **そして、追いつけない速さで進めようとする組織は、見送って構いません。**なお、**面接の日程**については、**オンラインで対応してもらえる**ことが多く、遠方でも進められます。ただし、**現地を一度も見ずに決めないでください。**[観光・地域振興の年収と働き方](industry-kanko-nenshu.html)で触れたとおり、**移住を伴う場合は住まい・通勤・家族の見通しが判断の中心**になります。**現地を訪ねる時間は、確保してください。**

### 資格を取ってから応募すべきですか

**職種によります。****旅行業務に関わる職**では、**選任の要件があるため、資格の扱いが募集ごとに違います。**一方、**企画・調整・補助の申請・情報の発信が中心の職**では、**要件になっていない募集が大半**です。まず、**自分が応募する職に資格が要るかどうか**を、求人票で確認してください。⚠ **試験や選任の要件については、所管する観光庁や実施する機関の公表を確認してください。**当社が確認していない内容はお伝えできません。なお、**学習を始めていること自体は、関心の本気度として伝わります。**ただし、**資格より、補助の申請と実績の報告ができることのほうが、この分野では即戦力として見られます。**

### 複数の組織を並行して受けても問題ありませんか

**問題ありません。**ただし、**この分野は組織の数が限られ、地域内で関係者がつながっている**ことがあります。**隠す必要はありません**が、**それぞれに志望動機を書き分けておく**ことは、より重要になります。とくに、**「なぜこの地域か」が使い回しに見えると、印象が悪くなります。**⚠ また、**応募先を決める前に、再就職に関する規程の確認を済ませておいてください。**複数に応募してから確認して、**その大半が候補から外れる**という事態を避けられます。なお、**募集の時期が重ならない**ことも多いため、**見つけた順に受けていく**という進め方が現実的です。
