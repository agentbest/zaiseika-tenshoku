公務員の服務のうち、転職の場面で意外に効いてくるのが、**第36条の政治的行為の制限**です。政治や選挙に関わる転職先——政党の職員、議員の秘書、政治団体、選挙の支援を業とする企業、政策提言を行う団体——を考える方にとって、**在職中にどこまで関われるか**が問題になります。

結論から書くと、**第36条は「職員は」で始まる在職中の規定で、退職後には及びません。**退職すれば、政治団体の役員になることも、選挙運動をすることも自由です。ただし、**在職中は、転職の準備としての関わり方に線があります。**

この記事では、**第36条の条文を読んで、何が制限され、退職後にどうなるか、政治に関わる転職先へ移る場合の在職中の線引き**を整理します。**第5号の条例で定める政治的行為は自治体ごとに違う**ので、自分の自治体の条例は人事の担当課で確かめてください。

## 条文——第36条の構造

| 項 | 内容 |
|---|---|
| **第1項** | 職員は、**政党その他の政治的団体の結成に関与し、役員となってはならず**、構成員になるように・ならないように**勧誘運動をしてはならない** |
| **第2項** | 職員は、特定の政党・政治的団体・内閣・自治体の執行機関を支持または反対する目的、公の選挙・投票で特定の人・事件を支持または反対する目的で、**次の政治的行為をしてはならない**（ただし書で区域外の例外） |
| 第2項第1号 | 投票をするように・しないように勧誘運動をすること |
| 第2項第2号 | 署名運動を企画・主宰するなど積極的に関与すること |
| 第2項第3号 | 寄附金その他の金品の募集に関与すること |
| 第2項第4号 | 文書・図画を自治体の庁舎・施設に掲示するなど、自治体の庁舎・施設・資材・資金を利用すること |
| 第2項第5号 | **条例で定める政治的行為** |
| **第3項** | 何人も、職員に政治的行為を求め、そそのかし、あおってはならず、代償・報復として地位に関する利益・不利益を与えてはならない |
| **第4項** | 職員は、違法な求めに応じなかったことを理由に不利益な取扱いを受けない |
| **第5項** | 本条は、職員の政治的中立性を保障することにより、自治体の行政の公正な運営を確保し、職員の利益を保護することを目的とする |

**主語は「職員は」**です。退職した後は「職員」ではないので、第36条は及びません。

## 第1項——政治団体の結成と役員は、目的を問わず禁止

第1項は、**目的を問わず**、政党その他の政治的団体の結成への関与、役員への就任、構成員の勧誘運動を禁じています。第2項が「支持または反対する目的をもって」という要件を置いているのに対し、第1項にはその要件がありません。

**転職の準備として、在職中に政治団体の役員に就任することは、第1項に触れます。**政党の職員として採用が決まっても、役員でなければ第1項の対象ではありませんが、採用の前に役員に就く形は避けてください。

## 第2項——目的を持った政治的行為の制限と、区域外の例外

第2項は、**特定の政党・執行機関・候補者などを支持または反対する目的で**、第1号から第5号の行為をすることを禁じます。目的の要件があるので、政治的な目的を持たない行為（たとえば選挙の事務に職務として従事すること）は対象ではありません。

**ただし書の区域外の例外**が、地方公務員に特有の点です。**自分の自治体の区域外では、第1号から第3号と第5号の行為ができます。**都道府県の職員なら都道府県の区域外、市町村の職員なら市町村の区域外です（支庁・地方事務所・指定都市の区に勤務する職員は、その所管区域外）。第4号（自治体の庁舎・施設・資材・資金の利用）は区域を問わず禁止です。

| 行為 | 区域内 | 区域外 |
|---|---|---|
| 投票の勧誘運動 | 禁止 | **可** |
| 署名運動への積極的関与 | 禁止 | **可** |
| 寄附金の募集への関与 | 禁止 | **可** |
| 自治体の庁舎・施設・資材・資金の利用 | 禁止 | **禁止** |
| 条例で定める政治的行為 | 禁止 | **可** |

## 国家公務員との違い——罰則の有無

国家公務員法の政治的行為の制限（第102条、人事院規則14-7）には罰則がありますが、**地方公務員法第36条には罰則がありません。**違反した場合の扱いは、**第29条の懲戒処分**（この法律に違反した場合）です。地方公務員の制限は、国家公務員に比べて範囲が限定され（区域外の例外、目的の要件）、罰則もない点で緩やかです。

**転職を控えた時期の懲戒処分は、退職手当と転職先への説明に影響します。**罰則がないからといって軽く考えないでください。

## 政治に関わる転職先へ移る場合の線引き

| 場面 | 第36条との関係 | どうするか |
|---|---|---|
| **政党の職員、議員の秘書、政治団体の職員に応募する** | 応募・面接・内定は政治的行為ではない。**対象外** | 勤務時間外に、私用の端末で（第35条） |
| **在職中に政治団体の役員に就任する** | **第1項に触れる**（目的を問わず禁止） | 就任は退職日の翌日以降に |
| **在職中に、応募先の政党のために選挙運動を手伝う** | 区域内なら**第2項に触れる**。区域外なら第1号〜第3号は可 | 区域内では行わない。区域外でも、第4号（自治体の資材・資金の利用）は禁止 |
| **在職中に政策提言の団体で無償で活動する** | 団体が「政治的団体」に当たるか、活動が第2項の目的を持つかによる | 人事の担当課に確かめる。政治的目的を持たない研究・提言なら対象外のことが多い |
| **退職後に政治団体の役員になる、選挙運動をする** | **対象外**（退職後は職員ではない） | 自由 |

**転職活動そのものは政治的行為ではありません。**線があるのは、在職中に政治団体の役員に就くことと、区域内で選挙運動などに関与することです。

:::insight
面談で伺うと、**議員の秘書や政党の職員への転職を考えている方が、「公務員は政治に関われないから、転職活動もできない」と思い込んでいる**ことがあります。第36条が制限するのは政治的行為で、応募も面接も内定も政治的行為ではありません。逆に、**内定した政党のために、在職中から地元の選挙を手伝った**という方は、第2項第1号の勧誘運動に当たる可能性があり、懲戒の対象になり得ます。ここで1つ提案があります。**政治に関わる転職先を考える方は、「役員への就任」と「選挙運動への関与」の2つを、退職日の翌日以降に回してください。**それ以外の準備——応募、面接、政策の勉強、無償の研究会——は在職中にできます。**第36条は退職後には及ばないので、退職日を境に、できることが一気に広がります。**在職中に線を守ることが、転職先での信用にもなります。
:::

## 転職するとどうなるか

転職を考えている方にとって、政治的行為の制限で効いてくる点は3つです。

**1. 転職活動は政治的行為ではない**

政党や政治団体への応募、面接、内定は、第36条の対象外です。

**2. 在職中の役員就任と、区域内の選挙運動は、退職後に**

**第1項と第2項のとおり**です。退職日の翌日から自由になります。

**3. 退職後は第36条は及ばない。守秘義務は続く**

退職後の政治活動は自由ですが、**第34条の守秘義務は退職後も続きます。**在職中に知った非公開の情報を政治活動に使わないでください。

## 手続きと期限

| 場面 | すること | 根拠 |
|---|---|---|
| 政治に関わる転職先に応募する | 勤務時間外に、私用の端末で | 第35条 |
| 内定先から在職中の役員就任を求められた場合 | 断り、就任は退職日の翌日以降に | 第36条第1項 |
| 内定先の選挙運動を手伝うよう求められた場合 | 区域内では行わない。区域外でも自治体の資材・資金は使わない | 第36条第2項 |
| 政治的団体に当たるか迷う団体での活動 | 人事の担当課に確かめる。条例で定める政治的行為も確かめる | 第36条第2項第5号 |
| 退職後 | 政治活動は自由。守秘義務は続く | 第34条 |

## 誤解されやすい点

**「公務員は政治に関わる転職先に応募できない」と思い込む**

**応募・面接・内定は政治的行為ではありません。**

**「退職後も政治的行為の制限が続く」と思い込む**

**第36条は「職員は」で始まる在職中の規定**で、退職後には及びません。

**「地方公務員も違反すれば刑事罰」と思い込む**

**地方公務員法第36条に罰則はありません。**懲戒処分の対象です（第29条）。

**「区域外なら何でもできる」と思い込む**

**第4号（自治体の庁舎・施設・資材・資金の利用）は区域を問わず禁止**です。第1項の役員就任も区域を問いません。

:::insight
ここまで政治的行為の制限の話を書いておいて逆のことを言いますが、**第36条は、転職の判断を左右するものではありません。**在職中に役員に就かず、区域内で選挙運動をしないだけで、転職活動は自由に進められます。それでも1本の記事にしたのは、**政治に関わる転職先を考える方が、この条文を理由に応募そのものを諦めている**のを面談で見るからです。制限されるのは政治的行為で、応募は政治的行為ではない。**退職日を境に、できることが広がる制度**です。そのうえで、**自分の経験に値を付けてくれる業界の見込みと、同じ紙に並べてください。**片方だけでは比較になりません。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 地方公務員法第36条は、**「職員は」で始まる在職中の規定**で、退職後には及びません
- **第1項は、目的を問わず、政治的団体の結成への関与・役員への就任・構成員の勧誘運動を禁止**します
- **第2項は、支持・反対の目的をもって、投票の勧誘運動、署名運動への積極的関与、寄附金の募集への関与、自治体の庁舎・施設・資材・資金の利用、条例で定める政治的行為を禁止**します。**自治体の区域外では第4号以外は可**です
- **罰則はなく、違反は第29条の懲戒処分の対象**です。国家公務員の制限とは範囲も罰則も違います
- **政党・政治団体への応募、面接、内定は政治的行為ではありません。**在職中に避けるのは、役員への就任と、区域内の選挙運動などへの関与です
- 退職後の政治活動は自由ですが、**第34条の守秘義務は続きます**

## よくある質問

### 議員の秘書への転職を考えています。在職中にその議員の後援会に入ってよいですか

**後援会が「政治的団体」に当たる場合、構成員になること自体は第36条第1項の対象ではありませんが、役員になることと、他の人を勧誘することは第1項に触れます。**第1項が禁じるのは、政治的団体の結成への関与、役員への就任、構成員になるように・ならないようにする勧誘運動です。単に構成員になることは、条文上は禁じられていません。ただし、**後援会の活動として選挙の際に投票の勧誘運動や寄附金の募集に関与すれば、自分の自治体の区域内では第2項に触れます。**その議員が自分の自治体の区域で活動している場合、後援会の活動の多くが区域内の政治的行為に当たる可能性があるので、**在職中は後援会の活動には関わらず、加入も退職後に回すのが安全**です。応募と面接は政治的行為ではないので、在職中に進められます。転職先の議員の事務所にも、公務員の事情として「在職中は政治的行為の制限があるので、活動は退職後から」と伝えれば理解されます。

### 政策提言を行うシンクタンクへの転職を考えています。在職中に無償で研究会に参加してよいですか

**団体が「政治的団体」に当たらず、活動が特定の政党や候補者を支持・反対する目的を持たなければ、第36条の対象ではありません。**第1項の対象は「政党その他の政治的団体」で、政策の研究や提言を行う団体が直ちにこれに当たるわけではありません。第2項の対象は、特定の政党・執行機関・候補者を支持または反対する目的を持つ行為で、政治的な目的を持たない政策研究は対象外です。**ただし、団体の性格や活動の内容によって判断が分かれる**ので、参加の前に人事の担当課に「この団体の研究会への参加は第36条の対象か」を確かめてください。第36条とは別に、無償であっても勤務時間外に行うこと（第35条）、職務上知り得た秘密を研究に使わないこと（第34条）、報酬を得る場合は第38条の許可が要ることは守ります。政策提言の団体への転職は、財政課の経験が直接生きる転職先の1つなので、在職中に研究会で顔を知られておくことは、選考の面でも有利に働きます。

### 退職後に、自分の自治体の議員選挙に立候補できますか

**退職後なら、第36条の制限はありません。**第36条は在職中の規定で、退職すれば政治的行為の制限は及ばず、立候補も選挙運動も自由です。在職中に立候補することはできず、立候補の届出をした日に退職したものとみなされる仕組みが公職選挙法にあります。立候補と退職の関係は[公職への立候補と失職](seido-fukumu-koushoku.html)に書いています。退職後の立候補で注意するのは、**第34条の守秘義務が退職後も続くこと**です。在職中に知った非公開の情報を選挙運動や議員活動に使うことはできません。公表されている情報と、自分の経験に基づく政策の主張は自由です。また、在職中に選挙の準備として後援会の役員に就いたり、区域内で支持を求める活動をしたりすれば第36条に触れるので、**準備は退職後に**、在職中は政策の勉強と、退職の段取りに絞ってください。
