**「いまの職種を続けるか、変えるか」**というご相談を伺います。

**準備の仕方が、大きく変わります。**

この記事では、**2つの違い**と、**それぞれの進め方**を扱います。

## 任用は、能力の実証に基づいて行われます

**地方公務員法第15条**です。

> **職員の任用は、この法律の定めるところにより、受験成績、人事評価その他の能力の実証に基づいて行わなければならない。**

**「能力の実証」**という言葉が置かれています。

**能力があることを、何らかの形で示すこと**が前提になっている、ということです。

**中途採用も、考え方は同じ**です。

**その仕事ができることを、経験や資格で示す**ことになります。

**ここから、2つの進め方が分かれます。**

| 進め方 | 実証の仕方 |
|---|---|
| **職種を変えない** | 同じ仕事をしてきた事実で示す |
| **職種を変える** | **別の形で示し直す** |

**後者のほうが、準備の量が多くなります。**

## 2つの軸で整理する

**「変える／変えない」は、業界と職種の2つの軸**があります。

| | 業界を変えない | 業界を変える |
|---|---|---|
| **職種を変えない** | ① 最も進めやすい | ② 経験が直接使えます |
| **職種を変える** | ③ 業界の知識が使えます | ④ **準備が最も必要** |

**公務員からの転職では、②が多くなります。**

**行政という「業界」から民間へ移るためです。**

**このとき、職種を変えるかどうかで、①③の考え方が分かれます。**

**④は、同時に2つを変える形**です。

**できないわけではありませんが、説明の組み立てが増えます。**

## 職種を変えない場合

| 項目 | 内容 |
|---|---|
| 探し方 | **同じ業務内容の求人を探す** |
| 書き方 | 担当した業務をそのまま書く |
| 説明 | **なぜ場所を変えるのか** |
| 強み | 即戦力として読まれやすい |
| 注意 | 同じ業務でも進め方が違います |

**3行目です。**

**職種が同じ場合、「なぜいまの職場ではなく、こちらなのか」**が問われます。

**業務の内容ではなく、環境や役割の違いで説明**することになります。

**5行目について。**

**同じ「審査」でも、民間では手順も基準も異なります。**

**面接で、進め方の違いを確認**してください。

## 職種を変える場合

| 項目 | 内容 |
|---|---|
| 探し方 | **未経験を前提とする募集を探す** |
| 書き方 | **持ち込める要素で組み立てる** |
| 説明 | なぜ変えるのか、何を持ち込めるか |
| 強み | 前職の視点が使える場合があります |
| 注意 | 入社後に覚える量が多くなります |

**2行目です。**

**職種が変わっても、持ち込める要素があります。**

| 持ち込める要素 | 例 |
|---|---|
| 基礎的な事務の処理 | 正確さ、期限の管理 |
| 調整 | 利害の異なる相手との合意形成 |
| 説明 | 資料の作成、対外の対応 |
| 制度の理解 | 行政の仕組み、法令の読み方 |
| 判断 | 根拠を確認してから進める習慣 |

**4行目です。**

**行政が相手の事業では、制度の理解が職種を問わず使えます。**

**営業であれ、企画であれ、事務であれ、相手が行政なら前提が共通**します。

**職種を変えるなら、この領域が入りやすい**です。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| なぜ変えるのか | **続けたい部分と、変えたい部分** |
| 何を持ち込めるか | 3つ挙げる |
| 覚える量への向き合い方 | 学んだ経験の具体例 |
| 前職の職種への未練 | 整理がついているか |
| 条件 | 勤務地、時間、役割 |

**2行目です。**

**「持ち込めるもの」を3つ用意**してください。

**1つでは足りず、5つでは散ります。**

**3つを、それぞれ具体例つきで話せる状態にしてください。**

:::insight
職種の話で、**面談でお聞きしているのが「その職種を、やってみたことがありますか」**という点です。職種を変える場合、**「やってみたい」と「向いている」は別**です。面談で伺った例では、**企画の仕事に関心があると話された方が、担当した業務を聞いていくうちに、実は調整の場面で力を発揮していた**ということがありました。**関心と、実際にできることは、必ずしも一致しません。**ですから、**変えたい職種について、近い経験がなかったかを探してください。**役所では、**本来の担当でない業務を任されることが多い**です。広報の資料を作った、システムの更改で要件を整理した、イベントの運営を担当した。**これらは、職種を変える際の材料になります。**「未経験です」と書くより、**「担当外でしたが、◯◯を経験しました」**と書くほうが、実証になります。**過去数年の業務を洗い出してみてください。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 準備の順序

| 順 | やること |
|---|---|
| 1 | 担当した業務を書き出す |
| 2 | **続けたい部分と、変えたい部分を分ける** |
| 3 | 変えるかどうかを決める |
| 4 | 変える場合、持ち込める要素を3つ決める |
| 5 | 近い経験がなかったか探す |
| 6 | 求人を読み、条件を確認する |
| 7 | 職務経歴書を作る |

**2と5が要**です。

**5について。**

**担当外の業務、臨時の担当、研修、兼務。**

**これらの中に、材料があることがあります。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 在職中の進め方

| 項目 | 内容 |
|---|---|
| 記録 | 担当外の業務も書き留める |
| 求人を読む | **両方の職種を見る** |
| 条件の見直し | 月に1回 |
| 異動の希望 | 職種を変えたい場合の手段 |

**2行目です。**

**変える職種と、変えない職種の両方の求人を読んでください。**

**比べると、どちらが自分に合うかが見えてきます。**

**4行目について。**

**役所の中で、職種に近い部署へ異動するという手段**もあります。

**時期と仕組みを、人事担当に確認**してください。

## それぞれの探し方

| | 探し方 |
|---|---|
| 変えない場合 | **仕事内容の欄に、自分の業務と同じ動作があるか** |
| 変える場合 | **応募条件に「未経験可」「業界経験不問」があるか** |
| 共通 | 行政が相手の事業を先に見る |

**3行目です。**

**行政が相手の事業では、職種を問わず制度の理解が前提になります。**

**営業、企画、事務、技術。**

**どの職種でも、相手が行政であれば、経験が接続します。**

**職種を変える場合も、変えない場合も、この領域から見てください。**

**そのうえで、条件が合わなければ範囲を広げる**という順序が現実的です。

**最初から広げると、比べる基準がありません。**

## よくある失敗

**1. 変えるかどうかを決めずに応募する**

**書き方が定まりません。**

**2. 持ち込める要素を挙げられない**

**3つ用意**してください。

**3. 近い経験を探さない**

**担当外の業務**に材料があります。

**4. 「未経験です」とだけ書く**

**経験した部分**を書いてください。

**5. 同じ職種なら同じ進め方だと考える**

**民間では手順も基準も違います。**

**6. 業界と職種を同時に変える負担を見ない**

**説明の量が増えます。**

**7. 片方の職種の求人しか見ない**

**比べると見えてきます。**

**8. 異動という手段を考えない**

**役所の中でも職種は変えられます。**

:::insight
ここまで整理の話をしておいて逆のことを言いますが、**職種という区切りに、こだわりすぎないでください。**面談で拝見していると、**「営業はできない」「企画がしたい」と、職種の名前で候補を絞る方**がいらっしゃいます。ところが、**同じ職種名でも、会社によって業務の中身がまったく違います。**行政が相手の営業は、**提案書を作り、仕様を読み解き、議会の時期に合わせて動く**仕事です。消費者が相手の営業とは、必要な力が違います。同様に、**企画という名称の職種でも、調査が中心の会社と、調整が中心の会社があります。**ですから、**見るべきは職種名ではなく、求人票の仕事内容の欄**です。そこに書かれた業務が、自分の経験と重なるか。**この見方であれば、職種を変えるかどうかという問い自体が、小さくなります。**探し方は、[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)に整理しています。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方公務員法第15条**は、**任用を受験成績、人事評価その他の能力の実証に基づいて行う**と定めています。**中途採用も、できることを示す点は同じ**です
- **職種を変えない場合は事実で示し、変える場合は別の形で示し直す**ことになります
- **業界と職種の2つの軸**で整理してください。公務員からの転職は、**業界を変える形**が中心です
- 変える場合は、**持ち込める要素を3つ**用意してください
- **担当外の業務・臨時の担当・兼務**に、材料があることがあります
- **「未経験です」とだけ書かない**でください
- **職種名ではなく、求人票の仕事内容**で判断してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 職種を変えないほうが、決まりやすいですか

**一般に、準備の量は少なくなります。**同じ業務をしてきた事実が、そのまま実証になるためです。ただし、**公務員の場合、「同じ職種」が民間に存在するとは限りません。**たとえば、**税の賦課の事務**と同じ仕事は、民間にはありません。**近いのは、基準に照らした判断と、その記録**です。この場合、**職種を変えないつもりでも、言い換えが必要**になります。判断の目安は、**求人票の仕事内容が、自分の業務とどれだけ重なるか**です。**重なりが大きいものから見てください。**言い換えは[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)に整理しています。

### 何を持ち込めるか、思いつきません

**業務を動作に分けてください。**「誰を相手に、何を確認し、何を決めていたか」です。窓口の業務なら、**相手は住民、確認するのは要件、決めるのは可否**です。これを抽象化すると、**顧客対応、基準に照らした確認、判断**になります。**この3つは、多くの職種で必要とされます。**また、**期限の管理、記録の作法、根拠を確認してから進める習慣**も持ち込めます。これらは、**役所で当たり前に身につくもの**ですが、**民間で評価される**ことがあります。**当たり前だと思っている部分にこそ、材料があります。**書き出してみてください。

### 未経験の職種は、年齢によって難しくなりますか

**求人の条件によります。****労働施策総合推進法第9条**は、**募集及び採用について、年齢にかかわりなく均等な機会を与えなければならない**と定めています。年齢の記載がある求人では、**その理由が示されている**ことがあります。なお、**職種を変える場合、入社後に覚える量が多くなる**のは事実です。このため、**基礎的な処理の力や、学んだ経験**が見られることがあります。対処は、**近い経験を示すこと**です。担当外で扱った業務、研修で学んだこと、独学で取得した資格。**実証の材料を増やす**ほうが、年齢の議論より効きます。
