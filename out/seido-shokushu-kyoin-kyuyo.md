公立学校の教員の給与を比べる際は、給料表の額と教職調整額、その他の手当を分けて確認します。教職調整額は2025年の法改正により段階的な引上げの仕組みが設けられましたが、本則の数字をそのまま2026年の支給率として読まないことが大切です。

本記事は2026年11月時点の公開情報にもとづき、公立の義務教育諸学校等に関する制度を中心に整理します。本人の校種、職名、任用区分、給与条例と経過措置は、教育委員会や給与担当に確認してください。国立・私立の学校や大学へ同じ説明を当てはめるものではありません。

## 教職調整額は給与全体の一項目として確認する

教員の給与には、職務や経験等に応じて給料表等で定める給料と、対象条件に応じる手当等があります。教職調整額は、公立の義務教育諸学校等の教育職員の給与等に関する特別措置法、いわゆる給特法と、自治体の条例に基づく制度です。

文部科学省は、教師の職務と勤務態様の特殊性を踏まえ、勤務時間の内外を包括的に評価し、本給相当として支給する仕組みと説明しています。本人が働いた時間外の時間数に単価を掛ける一般の時間外勤務手当とは、計算と制度の考え方が異なります。

給特法第3条は、教職調整額の支給と、対象教育職員に時間外勤務手当・休日勤務手当を支給しない取扱いを定めています。だからといって、何時間でも自由に勤務を命じられる制度だと読むことはできません。勤務を命ずる条件や、業務量・健康管理は別に確認します。

| 給与で比べる欄 | 確認する内容 |
| --- | --- |
| 給料 | 適用する給料表、級・号給、職歴認定 |
| 教職調整額 | 対象者、基準の率、条例と経過措置 |
| その他の手当 | 地域、扶養、通勤等の対象条件 |
| 特別な勤務等 | 個別手当の根拠、要件、申請方法 |
| 賞与等の算定 | 教職調整額の反映と在職期間等の条件 |

「調整額が増える」という説明だけでは、本人の手取りや年間の支給額は確定しません。給与の構成と社会保険料等の控除も分け、現在の給与明細と適用条例を照合します。

## 2026年は本則10％と経過措置5％を読み分ける

改正後の給特法第3条第1項の本則は、原則として給料月額の10％を基準とする規定です。ただし、同法附則第2項には段階的な読替えがあり、2026年1月1日から12月31日までは5％です。現在の率を調べるときは本則と附則を合わせて読みます。

| 適用期間 | 幼稚園以外の対象教育職員についての国法上の基準 |
| --- | --- |
| 2026年1月～12月 | 5％。本記事の確認時点に適用される経過措置 |
| 2027年1月～12月 | 6％となる予定の段階 |
| 2028年1月～12月 | 7％となる予定の段階 |
| 2029年1月～12月 | 8％となる予定の段階 |
| 2030年1月～12月 | 9％となる予定の段階 |
| 2031年1月以後 | 本則の10％となる予定 |

この表は、現在成立している法令に基づく段階を整理したものです。将来の率を既に支給されている条件として説明せず、本人への具体的な支給は、その時点の条例等で確認します。

幼稚園の対象教育職員は、本則で4％という別の取扱いです。また、2025年改正には給与関係と学校運営等で施行時期の異なる部分があります。すべて2026年4月から同時に変わった、という読み方はしません。

自治体側の対応例として、仙台市の2026年1月公報に掲載された改正条例にも、2026年5％から2030年9％までの読替表があります。これは同市の改正内容の例です。他自治体の本人の給与を確定する場合は、その教育職員に適用される条例と附則を確認してください。

## 校種と職名だけでなく任用区分まで確かめる

給特法第2条の対象となる義務教育諸学校等には、公立の小学校、中学校、義務教育学校、高等学校、中等教育学校、特別支援学校、幼稚園があります。「義務教育」と略されていても、高校等を含む法定の範囲です。

同条の教育職員には、教諭のほか、養護教諭、栄養教諭、実習助手、寄宿舎指導員等も列挙されています。一方、学校で働く事務職員等を、全員この定義の教員として扱うことはできません。

教育職員に含まれることと、第3条の教職調整額の支給対象になることも別です。第3条には校長、副校長、教頭、指導改善研修被認定者の除外があります。管理職の処遇は、調整額を支給する一般の教員と同じ比較にしないようにします。

講師についても、第2条は常時勤務の者や所定の短時間勤務の職等を限定して定めています。時間講師など、勤務の呼び方だけで対象を決めず、任用通知と勤務時間、適用される給与の規定を確認します。指導改善研修関係には改正時の経過措置もあるため、本人への適用を一律に判断しません。

:::insight
教員の給与を比較するときは、調整額の率より先に、校種、職名、任用区分、適用する給与条例を書き出すことを勧めます。同じ学校で働いていても、管理職、教諭、講師、事務職員では条件が違います。将来の制度改正を含む説明を読んだ場合は、現在の条件と今後の予定を別の欄に置きます。転職を考える際も、公立学校での給料に似た名称の手当が応募先にあるかどうかだけで比べる必要はありません。担当する仕事、勤務の割振り、評価、時間外勤務の扱いを同じ項目で確認します。数字の一部だけを大きく見せるより、本人に適用される給与の構成と仕事の条件をそろえることが、現職継続を含めて落ち着いて比較するための準備になります。
:::

学校以外の公共分野の仕事を調べる段階なら、[行政経験に関連する求人](../?gov=1)を見ることもできます。教員の給与制度と、各求人の労働条件は別に確認してください。

## 時間外勤務を命じる条件と時間管理を混同しない

給特法第6条は、対象教育職員を正規の勤務時間を超えて勤務させる場合を、政令の基準に従って条例で定める場合に限るとしています。その基準を定める政令は、原則として時間外勤務を命じないことを出発点にしています。

例外は、生徒の実習、学校行事、職員会議、非常災害や生徒指導上の緊急措置等に関する所定の業務で、臨時または緊急のやむを得ない必要がある場合です。いわゆる超勤4項目に関係するからといって、日常の業務を無制限に追加できるという意味ではありません。

他方、勤務時間の管理で用いる「在校等時間」は、命令された超勤4項目の時間だけを数える概念ではありません。文部科学省の2026年4月適用の指針Q&Aは、校内の時間や校外での業務の時間を外形的に把握し、休憩や業務外の時間を除く考え方を説明しています。

教職調整額を受けているから時間の記録が不要になるわけではありません。勤務命令、実際の業務、在校等時間、健康確保の相談は、それぞれの制度の目的に沿って確認します。本人の具体的な勤務の扱いは、学校管理職と教育委員会へ照会してください。

## 地方の条例と給与明細を一緒に確認する

法律は教職調整額を条例で定めるところにより支給する枠組みです。本人は、給与条例、教育職員の特別措置に関する条例、関係規則、改正附則を合わせて確認します。条例名が異なる場合も、給与担当に適用される資料を尋ねます。

| 給与担当へ確認すること | 手元で準備する資料 |
| --- | --- |
| 対象職員に該当するか | 任用通知、職名、勤務時間 |
| 今月の基準と適用時期 | 給与明細、条例と附則 |
| 他手当等への反映 | 計算に使う給料と調整額の区分 |
| 休職や勤務形態変更 | 変更の発令日、適用期間 |
| 退職時の計算 | 退職日、退職理由、支給通知等 |

給特法第3条第3項には、地域手当、期末・勤勉手当、退職手当等について給料を算定基礎とする場合に、教職調整額を加える内容を条例で定める仕組みがあります。ただし、すべての手当へ同じ割合で単純に加算するという説明ではありません。項目ごとの根拠を確認します。

民間へ移るときは、公立学校の調整額の制度がそのまま引き継がれるわけではありません。給与の総額だけでなく、基本給、固定の手当、時間外勤務手当、所定労働時間、賞与の条件を正式な労働条件で比較します。

教育経験と希望する職務を整理したい場合は、[応募前の相談](../apply.html)も利用できます。ご利用は無料です（紹介手数料は採用企業の負担）。本人の給与や給付の確定は、教育委員会等の担当へ確認します。

## 給与の改善と勤務環境の確認を並行する

教職調整額の改正は処遇に関する制度です。それだけで、本人の業務量や勤務時間が変わると断定することはできません。勤務の負担を変えたい場合は、担当業務、校務分掌、支援体制、健康上の配慮を具体的に確認します。

国立学校や私立学校、大学等に応募する場合は、設置者や雇用主と給与規則、就業規則を調べます。公立学校の給特法の率を使って、応募先でも同じ手当があると推定しないでください。非常勤として働く案も、職務と勤務日数、契約期間を分けて比較します。

:::insight
働き方を変えたいと考えるときは、給与の構成と負担の原因を別の表に置くことを勧めます。調整額の引上げ予定があっても、本人が変えたいのは授業以外の分担や勤務地かもしれません。校内での役割調整や支援の利用により希望に近づけるなら、現職に残る判断にも理があります。外の仕事を見る場合も、教える経験という一語だけでなく、企画、教材作成、関係者調整、記録や改善等に分けて説明できます。これは経験の整理例で、特定職への採用を保証するものではありません。制度の変更だけに判断を預けず、今と次の仕事の役割、勤務時間、正式な条件をそろえ、自分が何を優先したいかを確かめます。
:::

## よくある質問

### 2026年の教職調整額は全員10％ですか

本則の10％に対し、幼稚園以外の対象教育職員は附則の経過措置で2026年は5％です。幼稚園や支給対象外の職員区分もあり、本人の条例・任用区分を確認します。

### 教職調整額は何時間分の残業代ですか

勤務時間の内外を包括的に評価する仕組みとして説明されており、本人の時間外の時間数に単価を掛ける制度ではありません。一般の固定残業代と同じものとして扱わず、勤務を命ずる条件と時間管理も別に確認してください。

### 学校の事務職員や非常勤講師にも同じ制度ですか

学校で働く人全員が同じ対象ではありません。給特法の教育職員の定義、教職調整額の対象、勤務形態、条例等を確認します。公立と私立・国立も分けてください。

教員の給与は、対象区分、現在の経過措置、条例、勤務条件を順に確かめます。仕事の希望を整理する段階なら、[LINEで短く聞く](https://line.me/R/ti/p/@697nxhbt)こともできます。
