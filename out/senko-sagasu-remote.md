**「リモート可」と書かれた求人を見かけます。**

**記載だけでは、実態が分かりません。**

この記事では、**確認する項目**と、**探し方**を扱います。

## 働き方の条件は、就業規則に定められます

**労働基準法第89条**です。

> **常時十人以上の労働者を使用する使用者は、次に掲げる事項について就業規則を作成し、行政官庁に届け出なければならない。**次に掲げる事項を変更した場合においても、同様とする。
>
> 一 **始業及び終業の時刻、休憩時間、休日、休暇**並びに労働者を二組以上に分けて交替に就業させる場合においては就業時転換に関する事項
>
> （略）
>
> 十 前各号に掲げるもののほか、**当該事業場の労働者のすべてに適用される定めをする場合においては、これに関する事項**

**1号に、始業及び終業の時刻が挙げられています。**

**10号は、事業場の労働者すべてに適用される定めを対象としています。**

**在宅勤務の扱いも、就業規則または別に定める規程で整理されているのが通常**です。

**つまり、「リモート可」の中身は、規程として定められている**ということです。

**求人票の一言ではなく、規程の内容を確認**してください。

## 「リモート可」の幅

| 記載 | 実際にあり得る内容 |
|---|---|
| リモート可 | **週に1日から、全日まで幅があります** |
| 在宅勤務あり | 制度はあるが、利用の要件がある場合 |
| ハイブリッド | 出社と在宅の組み合わせ |
| フルリモート | 出社を前提としない |
| リモート相談可 | **個別の相談による** |

**1行目と5行目**です。

**同じ記載でも、実際の頻度は会社によって異なります。**

**確認しないまま応募すると、想定と違うことになります。**

## 確認する項目

| 項目 | 確認すること |
|---|---|
| ① 頻度 | **週に何日か。月に何日か** |
| ② 対象 | 職種、勤続の年数などの要件 |
| ③ 開始の時期 | **入社直後から可能か** |
| ④ 出社が必要な場面 | 会議、研修、顧客の対応 |
| ⑤ 勤務時間の扱い | 始業・終業の管理の方法 |
| ⑥ 費用 | 通信費、機器、光熱費の扱い |
| ⑦ 場所 | 自宅のみか、他の場所も可か |

**③が見落とされやすい**です。

**入社後の一定の期間は出社、という運用がある**ことがあります。

**「入社直後から利用できますか」**と確認してください。

**⑥について。**

**通信費や機器の扱いは、規程で定められていることがあります。**

**支給、貸与、実費の精算。**

**扱いは会社によって異なります。**

## 行政が相手の事業での注意

| 事業の形 | リモートの可否 |
|---|---|
| 庁舎内での常駐 | **出社（常駐先への出勤）が前提**です |
| 窓口の運営 | 同上 |
| 施設の管理 | 現地での勤務が中心 |
| 計画・制度の支援 | 一部リモートが可能な場合があります |
| 情報システムの開発 | リモートの運用がある場合があります |

**1行目です。**

**行政が相手の事業には、常駐を前提とするもの**があります。

**契約の内容として、勤務の場所が定められている**場合です。

**求人票に「リモート可」とあっても、配属先の案件によって異なる**ことがあります。

**配属予定の案件と、その勤務の形を確認**してください。

**確認の仕方は、「配属予定の案件では、在宅勤務の運用はどのようになっていますか」です。**

## 探し方

| 方法 | 内容 |
|---|---|
| 絞り込みの条件 | **「リモート可」の項目で絞る** |
| 検索の語 | 在宅勤務、テレワーク、リモート |
| 仕事内容の欄 | 勤務の場所の記載 |
| 勤務地の欄 | 「在宅」「本社または在宅」などの記載 |
| 会社の採用ページ | 制度の説明が詳しいことがあります |

**5行目です。**

**求人票より、採用のページのほうが制度の説明が詳しい**ことがあります。

**利用の実績が書かれている**場合もあります。

:::insight
リモートの求人で、**面談でお伝えしているのが「頻度より、出社が必要な場面を聞いてください」**という点です。**「週に何日リモートですか」**という質問には、**制度上の答え**が返ってきます。ところが、実際に負担になるのは、**出社が必要になる場面がいつ生じるか**のほうです。会議、研修、顧客への訪問、案件の立ち上げ。**これらが月に何回あるか**で、生活の組み立てが変わります。とくに、**通勤に時間がかかる場所に住む予定なら、この頻度が判断を左右します。**そして、**行政が相手の事業では、相手方の庁舎に出向く場面**があります。打合せ、報告、納品。**これは相手の都合で決まる**ため、こちらの希望だけでは調整できません。ですから、聞き方は**「出社が必要になるのは、どのような場面ですか。頻度の目安はありますか」**です。**制度ではなく、実際の動き方を聞いてください。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 公務員としての経験との接続

| 経験 | 民間での言い換え |
|---|---|
| 在宅勤務の運用 | 制度の整備、運用の手順の作成 |
| オンラインでの会議の運営 | 進行の管理、資料の共有 |
| 電子決裁の運用 | 業務の手順の整理 |
| 情報の管理 | 情報の取扱いの規律の理解 |

**4行目です。**

**在宅で業務を行う場合、情報の取扱いが課題になります。**

**役所で情報の管理の規律に沿って業務をしてきた経験**は、**説明の材料になります。**

**書き方は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 応募の前に整理しておくこと

| 項目 | 内容 |
|---|---|
| 希望する頻度 | 週に何日を希望するか |
| 譲れない条件か | **これが満たされないと難しいか** |
| 理由 | 介護、育児、通勤の距離など |
| 出社できる範囲 | 月に何回なら可能か |

**2行目です。**

**リモートが譲れない条件なのか、あれば望ましい条件なのか**を分けてください。

**譲れない条件であれば、求人を絞る軸になります。**

**望ましい条件であれば、他の条件と併せて判断できます。**

**この区別があると、紹介を受けるときにも伝えやすくなります。**

**4行目について。**

**「出社は月に◯回までなら可能」という形で示せると、相手も調整を検討できます。**

**可否だけで答えるより、範囲を示すほうが話が進みます。****この整理は、応募の前にしておいてください。**

**条件が固まっていれば、求人を見る速さも変わります。**

## よくある失敗

**1. 「リモート可」の記載だけで判断する**

**頻度と要件を確認**してください。

**2. 入社直後から使えると考える**

**一定の期間は出社という運用**があります。

**3. 出社が必要な場面を聞かない**

**生活の組み立てに影響します。**

**4. 配属予定の案件を確認しない**

**案件によって異なる**ことがあります。

**5. 費用の扱いを確認しない**

**規程で定められています。**

**6. 譲れない条件かどうかを分けない**

**求人の絞り方が決まりません。**

**7. 採用のページを見ない**

**制度の説明が詳しいことがあります。**

:::insight
ここまで確認の話をしておいて逆のことを言いますが、**リモートを条件に入れると、候補が減ります。**面談で拝見していると、**リモート可で絞った結果、求人が数件しか残らない方**がいらっしゃいます。ここで考えていただきたいのは、**リモートが目的なのか、その先にある事情が目的なのか**です。通勤の時間を減らしたいのであれば、**勤務地が近い求人**でも解決します。育児や介護の都合であれば、**時差出勤や時間単位の休暇**で対応できる場合があります。**手段を1つに絞ると、候補が減ります。**ですから、**「なぜリモートが必要か」を先に言葉にしてください。**そのうえで、**その事情を満たす手段を複数持つ**ほうが、候補は広がります。**リモートは手段の1つ**です。他の手段で足りるなら、**求人の範囲はずっと広くなります。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **労働基準法第89条**は、**始業及び終業の時刻**をはじめとする事項について、**就業規則の作成と届出**を義務づけています。**在宅勤務の扱いも規程で整理されるのが通常**です
- **「リモート可」の記載には幅があります。**週1日から全日まであり得ます
- 確認するのは、**頻度、対象の要件、開始の時期、出社が必要な場面、勤務時間の扱い、費用、場所**です
- **入社直後から利用できるか**を確認してください
- **行政が相手の事業には、常駐を前提とするもの**があります。配属予定の案件を確認してください
- **制度ではなく、出社が必要になる場面と頻度**を聞いてください
- **リモートは手段の1つ**です。目的を言葉にすると、候補が広がります

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 面接で、リモートの希望を伝えてよいですか

**条件の確認として伝えて差し支えありません。**ただし、**伝え方に順序があります。**先に「リモートでないと困ります」と切り出すと、**条件の交渉として受け取られます。**まず、**制度としてどうなっているかを聞いてください。**「在宅勤務の運用について伺えますか」という形です。そのうえで、**自分の事情を伝えます。**「通勤に時間がかかるため、週に◯日程度の在宅を希望しています」という伝え方です。**事情と希望をセットで伝える**と、**調整の余地があるかどうかが分かります。**なお、**譲れない条件であれば、応募の段階で伝えておく**ほうが、双方の時間が無駄になりません。

### 公務員の経験で、リモートの仕事はできますか

**業務の内容によります。**制度の運用の支援、資料の作成、調査、審査の事務、相談の対応。**これらは、在宅での実施が可能な場合があります。**一方、**施設の管理、窓口の運営、現場の監督**は、現地での勤務が中心です。判断の目安は、**その業務に「場所が必要か」**です。なお、**役所で在宅勤務や電子決裁を運用した経験があれば、それ自体が説明の材料**になります。「在宅で業務を進める際の情報の取扱いについて、規律に沿って運用した経験があります」という形です。**経験の言い換えは、業務の動作で考えてください。**

### フルリモートの求人は、どう探せばよいですか

**絞り込みの条件と検索の語を併用**してください。求人サイトの「リモート可」の項目で絞ったうえで、**「フルリモート」「完全在宅」「出社なし」**などの語で検索します。ただし、**記載の仕方は会社によって異なります。**絞り込みだけでは漏れることがあります。また、**勤務地の欄に「在宅」と書かれている求人**もあります。なお、**フルリモートで絞ると候補が大きく減ります。**「出社が月に数回まで」という範囲に広げると、**候補が増える**ことがあります。**条件を段階で設定してみてください。**まず広く見て、そこから絞るほうが、見落としが減ります。
