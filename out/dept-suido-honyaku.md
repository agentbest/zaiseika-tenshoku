水道局の経験を、職務経歴書にどう書けばよいか。ここでつまずく方が多いのは、**「公営企業」という言葉が、民間に伝わらない**からです。

「水道事業に従事」と書くと、**役所の水道の窓口にいた人**に読まれます。実際には、**24時間止められない設備を運転し、数百キロメートルの管路を保全し、水質を測り続け、料金を請求して回収し、数十年先の更新の計画を立てていた**わけですが、それが伝わりません。

この記事では、**民間での訳語**と、**中核スキルの分解**を並べます。

## 「常時水を供給しなければならない」と書かれています

まず、この仕事の立ち位置を条文で押さえます。**水道法第15条**です。

> 水道事業者は、事業計画に定める給水区域内の需要者から給水契約の申込みを受けたときは、正当の理由がなければ、これを拒んではならない。
> 2 水道事業者は、当該水道により給水を受ける者に対し、常時水を供給しなければならない。

**この2つが、仕事の性格を決めています。**

**申込みは、正当の理由がなければ拒めません。****そして、常時、供給しなければなりません。**

つまり、**この経歴の方は、「断れない、止められない」という条件のもとで、設備と料金を回してきた**ことになります。しかも、**同条第3項は、料金を支払わないときは、供給規程の定めるところにより給水を停止することができる**とも定めています。**止める判断も、制度の中に置かれている**ということです。

民間で人を採る側から見ると、これは**「止められないインフラを、独立採算で運営してきた人」**です。**電力、ガス、通信、鉄道、プラント**——**同じ条件の事業は、民間にいくつもあります。**

## 民間での訳語

| 行政での言い方 | 民間での言い方 |
|---|---|
| 水道事業の運営 | 公益事業の運営、インフラ事業の運営 |
| 浄水場の運転管理 | プラントの運転管理、設備の保全 |
| 配水管の維持管理 | 管路の保全、インフラの維持管理 |
| 漏水の調査 | 損失の低減、設備の異常の検知 |
| 水質の検査 | 品質管理、分析、検査の実務 |
| 給水装置工事の審査と検査 | 施工の審査、技術基準の適合の確認 |
| 指定給水装置工事事業者の指定 | 協力会社の認定と管理 |
| 料金の調定と収納 | 請求の管理、債権の管理 |
| 給水の停止 | 供給の停止、契約の停止の実務 |
| 管路の更新計画 | 設備の投資の計画、資産の管理 |
| 公営企業会計・経営戦略 | 独立採算の事業の運営、損益と資金の管理 |
| 災害時の応急給水 | 事業の継続、危機の対応 |

**この表を職務経歴書にそのまま貼る必要はありません。**ただ、**自分がやっていたことに、民間で通じる名前が付いている**ことは、知っておいてください。

## 中核スキルを5つの工程に分ける

**この経歴の中核は、「止められないものを、採算の中で回す」ことです。**5つの工程に分けます。

**工程1：作る**

水源の管理、取水、浄水場の運転。**薬品の注入、ろ過、消毒。****24時間、動いています。**

**この工程に固有の制約があります。****在庫が持てない**ということです。作った水を、**大量に貯めておくことはできません。**需要に合わせて、**作りながら送る。**民間の製造業であれば、**需要の変動を在庫で吸収します。****水道は、それができません。**この条件で運転してきた経験は、**同じ性質を持つ事業**——**電力、ガス、熱供給**——**で、そのまま通じます。**

**工程2：送る**

配水池、ポンプ、配水管。**数百キロメートルの管路**を通して、**各戸まで届けます。**

**この工程に固有の制約があります。****設備の大半が、地下にある**ということです。目で見て点検できません。**漏水は、地表に出るまで分からないことがある。**だから、**音を聞き、水圧を見て、夜間の最小の流量を測って、当たりを付ける。****見えない設備の異常を、間接の情報から推定する技術**です。これは、**設備の保全を扱う会社で、直接に評価される部分**です。

**工程3：測る**

水質の検査、水量の把握、水圧の管理。**基準に適合しているかを、常に確かめ続けます。**

**この工程に固有の制約があります。****基準を外れたときの影響が、口に入るものである**という点です。だから、**測って終わりではなく、外れたときに誰が何をするかまで、手順にしてあります。**この形の品質の管理は、**食品、医薬品、化学の分野と共通**しています。

**工程4：課金する**

検針、調定、請求、収納、そして滞納への対応。**数万から数十万の需要家について、周期で回します。**

**この工程に固有の制約があります。****止める判断が、生活に直結する**ということです。水道法第15条第3項は給水の停止を認めていますが、**実際の運用では、停止の前に連絡と相談の段階を置きます。****回収と、生活への配慮を、同じ担当が扱う。**この組み合わせは、**電気やガスの事業者でも、同じ課題になっています。**

**工程5：更新する**

管路の更新の計画、耐震化、浄水場の改良。**数十年の単位で、いつ、どこを、いくらで替えるかを決めます。**

**この工程に固有の制約があります。****料金でまかなうという前提**です。**税ではありません。**更新の費用は、**最終的に料金に跳ね返ります。**だから、**「いくらまでなら上げられるか」という判断が、計画の中に入ってきます。****設備の計画と、料金の設計が、同じ机の上にある。**この経験は、**民間のインフラ事業でそのまま求められます。**

:::insight
この5つの工程のうち、**職務経歴書でいちばん書かれていないのが、工程5**です。面談で伺うと、**「更新計画の策定に関わりました」**という一行で終わってしまいます。ところが、中身を聞くと、**管路の布設の年度と材質から更新の優先順位を組み、年間の更新の延長を決め、必要な費用を積み上げ、料金の水準と資金の残高を見ながら年次に配分した**という話が出てきます。**これは、設備の投資の計画そのもの**です。民間でいえば、**資産の管理、設備投資の計画、長期の収支の計画**に当たります。しかも、**独立採算**です。**税で埋める前提ではない。**書くなら、**「管路約◯キロメートルについて、布設の年度と材質から更新の優先順位を設定。年間約◯キロメートル、約◯億円の更新の計画を策定し、資金の残高と料金の水準を踏まえて年次に配分」**という形です。**この一行があると、経営の側の仕事ができる人として読まれます。**インフラを持つ民間の会社では、**この設計ができる人が足りていません。**
:::

## 民間のプラント・インフラの保全と、どこが同じでどこが違うか

**同じ点は3つあります。**

- **24時間動く設備を、計画と点検で保全している**こと
- **基準に対する適合を、測定と記録で証明している**こと
- **更新の投資を、長期の計画として積み上げている**こと

**違う点は4つあります。**

| 違い | 行政（水道局） | 民間（プラント・インフラ） |
|---|---|---|
| 相手を選べるか | 区域内の申込みは、正当の理由がなければ拒めない | 契約の相手を選べる |
| 止められるか | 常時の供給が義務。停止は例外的な場面に限られる | 計画停止も、事業の判断で行える |
| 料金の決め方 | 条例で定める。改定には手続きと説明が要る | 市場と原価で決める |
| 利益の扱い | 独立採算だが、利益の最大化は目的ではない | 利益が事業の目的に含まれる |

**この4つのうち、移った後にいちばん効くのは、2番目**です。**止められない設備を回してきた経験**は、**民間でも希少**です。**計画停止ができる環境に移ると、むしろ楽に感じる**方が多い部分です。

**もう1つ、効き方が大きいのは4番目**です。公営企業は、**独立採算ではあるものの、利益を増やすことが目的ではありません。**料金は、**かかる費用をまかなう水準**で設計されます。**移った後は、ここに「利益」という項目が足される。**ただし、**足されるだけ**です。**費用を積み上げて、収入と突き合わせて、資金の残高を見る**という作業そのものは、**公営企業会計でやってきたことと同じ**です。**まったく新しい考え方を学び直すわけではない**——ここは、先に知っておくと構えずに済む部分です。

## 評価が高くなりやすい4つの方向

**1. 水道の事業を受託する会社・プラントのメーカー**

**浄水場の運転の受託、管路の工事、設備の更新。**発注の側にいた経験が、そのまま効きます。

**2. 電力・ガス・熱供給などの公益の事業**

**止められない設備と、需要家への課金。****構造が、ほぼ同じ**です。

**3. 建設コンサルタント・インフラの計画の支援**

**管路の更新の計画、耐震化、経営の戦略の策定支援。**計画の側の経験がある方に向きます。

**4. 設備の保全・施設の管理の会社**

**点検の周期、異常の検知、記録の管理。****プラントでも、ビルの設備でも、同じ骨の仕事です。**

**なお、この4方向は、求める経験が違います。**1番と4番は、**現場の運転と保全**を見ます。2番は、**需要家への課金と、供給の体制**を見ます。3番は、**計画と経営の数字**を見ます。**同じ水道局の経歴でも、技術職か事務職か、現場か本庁かによって、通りやすい方向が変わる**ということです。**自分がどの工程を長くやってきたかを、先に整理しておいてください。**

## つまずきやすい点

**1. 「水道事業に従事」で丸める**

**作る／送る／測る／課金する／更新する**の5つに分けてください。

**2. 規模の数字を書かない**

**給水人口、給水戸数、管路の延長、施設の能力。**桁だけでも入れてください。

**3. 公営企業会計の経験を書き落とす**

**独立採算の事業の運営**です。**損益と資金を見ていたなら、そう書いてください。**

**4. 料金の実務を、事務として書く**

**数万から数十万の需要家に対する請求と回収**です。**量が伝わる形にしてください。**

**5. 災害時の対応を、苦労話にする**

**応急の給水の体制を設計し、運用していた**と書いてください。

:::insight
この経歴の方に、**最初に確かめていただきたい数字が4つ**あります。**給水人口、給水戸数、管路の延長、年間の有収水量**です。この4つが並ぶと、**書類の読まれ方が変わります。**「水道事業に従事」と書かれた1行と、**「給水人口約◯万人、給水戸数約◯万戸、管路延長約◯キロメートルの水道事業において、浄水場の運転管理と管路の更新の計画を担当」**という1行では、**読む側が想定する事業の規模が違うから**です。**これらは公表されている数字**なので、**在職中に控えておけば足ります。**そのうえで、**自分が関わった更新や改良の、延長か金額を1つ**書き出しておくと、**実績欄の芯ができます。**なお、この分野は、**水道の事業そのものの受託が広がっている**ため、**発注の側にいた人を求める求人が、以前より増えています。**在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 水道法第15条は、**正当の理由がなければ給水契約の申込みを拒めず、常時水を供給しなければならない**と定めています
- つまり、**水道局は「断れない、止められない」条件で、設備と料金を回す仕事**をしています
- 民間での訳語は、**インフラ事業の運営、プラントの運転管理、管路の保全、請求と債権の管理、資産の管理**です
- 中核スキルは、**①作る ②送る ③測る ④課金する ⑤更新する**の5工程に分けられます
- 民間との違いは、**相手を選べるか、止められるか、料金の決め方、利益の扱い**の4点です
- 先に、**給水人口・給水戸数・管路の延長・有収水量**の4つを控えてください

## よくある質問

### 事務職で、浄水場や管路の技術的なことは分かりません

**それでも書けます。**水道局の事務は、**料金の調定と収納、給水装置の申請の受付、指定工事事業者の指定、契約と入札、公営企業会計の決算、経営の戦略の策定**など、**技術以外の部分が広くあります。**とくに、**公営企業会計の経験**は、**一般会計しか知らない行政の職員とは、明確に違う経験**です。**損益計算書と貸借対照表を扱ってきた**なら、**民間の経理や経営の企画に、そのまま接続します。**書くなら、**「公営企業会計による決算の調製、経営の戦略の策定、料金の改定の試算を担当」**と、**自分の範囲を明示してください。**

### 検針と収納が中心で、専門性がないと感じます

**量と、止める判断の経験で書いてください。**「約◯万件の検針と調定、収納の管理を担当。滞納については、連絡、相談、給水の停止の判断までの段階を運用」という形です。**数万件を周期で回す事務**は、**それ自体が経験**です。加えて、**「止める判断」を扱ってきたこと**は、**電気やガス、通信など、同じ課題を持つ事業者で直接に効きます。**止めた後に再開する手順、事情がある世帯の扱い、支払いの相談の受け方。**この運用を知っている人は、外部から採りにくい**からです。

### 水道の事業が広域化や民間の活用に向かっていて、先が不安です

**その動きは、むしろ経験の価値を上げる方向に働いています。**事業の受託や、広域での運営が広がると、**発注の側の事情と、水道の現場の両方が分かる人が必要になります。**受託の会社の側にも、広域の企業団の側にも、**その両方を持っている人は多くありません。**不安の中身が「今の職場が続くか」であれば、**それは別の話として考える必要があります**が、**経験そのものが古くなるという心配は、この分野では当てはまりにくい**と考えています。行き先の分け方は[水道局から転職しやすい業界と職種](dept-suido-tenshokusaki.html)に整理しています。
