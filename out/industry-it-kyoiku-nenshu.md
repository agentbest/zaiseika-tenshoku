IT教育・研修会社の給与や働き方は、講師、法人営業、運営等の職務と、正社員や業務委託の区分を分けて確認します。オンラインで研修をする仕事でも、自宅での勤務が常に認められるとは限りません。公務から移るかどうかを決める前に、年俸に含まれる支給と、本人に適用される勤務の条件を整理できます。

本記事は2026年11月時点の公開情報にもとづきます。確認日は2026年11月25日です。給与額の大小で転職を勧めるものではありません。以下は個別の公式求人の条件例であり、IT教育会社全体や本人の条件が同じという意味ではありません。

## 講師と営業、正社員と業務委託を分ける

トレノケートの公式採用ページは、正社員とパートナー講師の業務委託を別に案内しています。正社員の勤務や福利厚生を、そのまま業務委託の契約へ移すことはできません。今回本人がどの区分で契約するのかを最初に確認します。

今回確認したCisco分野の講師求人は、法人向けの集合やオンライン研修の講義を中心とする正社員の募集です。教材や演習環境の作成や改善、技術の調査、営業の技術支援等は、経験を積んだ後に会社の必要と本人の希望を照合して担当を広げるとしています。

東京の法人営業も正社員の募集ですが、仕事は研修や人材育成の提案です。顧客の課題の把握、計画、提案、受注後の導入支援、効果の確認や改善等が示されています。講師の講義の予定と、営業の顧客への活動を同じ勤務としてまとめません。

公務で研修の運営や発注を担当した場合も、今回の提供側の仕事とは別に読みます。申込や会場の調整は本人の経験として書けますが、講義や研修販売を担当していないなら、その実務を加えません。仕事内容の接点と給与の条件は、それぞれ確認します。

| 比較する項目 | 読む対象 | 混ぜないもの |
| --- | --- | --- |
| 契約 | 正社員か業務委託か | 他区分の休日や待遇 |
| 職務 | 講義、営業、運営等 | 別職種の担当や評価 |
| 給与 | 固定の支給、手当、賞与等 | 合計の全てを基本給とすること |
| 勤務 | 出社、時間、場所、制度の条件 | 本人の希望だけでの確定 |

職務の違いを見比べたい方は、[掲載中の求人を仕事内容から確認できます](../?gov=1)。研修会社という業界名に加えて、今回担当する工程を読むために使えます。

## 年俸に含まれる固定残業と賞与を読む

今回の講師と営業の求人は、想定年収に月三十時間分の固定残業手当と、年二か月分の賞与を含むと説明しています。そのため、合計の全てを基本給と見たり、賞与をさらに同じ分だけ足したりしません。何を合わせた目安かを先に確認します。

同求人は、記載は目安で、最終的には経験、能力、前職年収を考慮して決定するとしています。公務で現在受け取っている支給と、まだ本人に提示されていない条件を、同じ確かさの数字として並べないことが大切です。個別の提示前は未確認の欄を残せます。

賞与は会社の業績によるとされ、インセンティブの制度も案内されています。制度の存在から、本人の将来の支給が決まるわけではありません。想定の年収に含まれる賞与と、実際の支給の条件を分けて確認します。

固定残業の時間が書かれていても、実際の勤務時間がその時間と同じになるとは限りません。本人の仕事の進め方や業務量を、この記載だけで推測しません。超過した場合の扱いや給与の内訳等が不明なら、正式な条件提示で確かめます。

通勤やリモート勤務の手当、入社時の支援等も、本人が対象かと、いつどの条件で支給されるかを確認します。一時的な支援を毎年の固定の収入として計算しないようにします。別の職種の例や会社全体の平均を、本人の条件へ割り当てません。

:::insight
年俸や想定年収を比べるときは、何が含まれるかを先にそろえられます。固定残業手当と賞与を含む目安なら、それぞれを分けて記録し、合計をそのまま基本給とは読みません。賞与が業績によるという記載と、本人の初年度の扱いも別に確認します。固定残業の時間は、本人の残業の実績や将来の仕事量を示す数字ではありません。公務の現在の支給と比較する場合も、固定と変動、一時的な支援を分けることが判断材料になります。給与を増やすために残業や賞与を自分で見込むのではなく、正式な提示の構成と生活上必要な条件を照合するための作業です。
:::

## オンライン研修と自宅勤務を同じにしない

今回の二つの求人は、出社を基本とし、業務の内容や状況に応じてリモート勤務を利用できるとしています。オンラインで講義するから、毎日自宅で勤務できるとは読みません。出社する場所と、利用できる制度の条件を確認します。

勤務地は東京都新宿区の勤務先が示され、出向なしと案内されています。ただし、別の募集や将来の職務へ同じ条件を広げません。本人が希望する通勤範囲と、今回正式に提示される場所や変更の範囲を分けて確認できます。

勤務時間は標準の時間と休憩、コアタイムのあるフレックス制度が示されています。制度があることだけで、講義や顧客の予定を無視して本人が好きな時間だけ勤務できるとは判断しません。具体的な運用は、担当する仕事に合わせて確認します。

講師の求人は、企業向けの研修が平日の日中を基本とし、夜間や休日の研修はほとんどなく、シフトや障害対応による緊急の呼び出しはないと説明しています。この職種の案内を、全てのIT講師や研修会社にも当てはまる特徴とは扱いません。

営業の活動も、講師の講義の予定とは別です。顧客への提案や導入後の支援等を含む仕事内容を読み、本人にどの担当が適用されるかを確認します。公開の仕事紹介にある活動の例を、本人の一日の予定や残業の保証にしないようにします。

## 架空の比較例で公開情報と本人への提示を分ける

以下は独立して作成した架空例です。実在の応募者、企業の回答や面談の記録ではありません。特定の求人の必須条件を満たす例でもありません。使う場合は本人の事実へ置き換え、未実施のことは削除してください。

| 項目 | 架空の記入例 |
| --- | --- |
| 検討対象 | 研修会社の正社員の講師と法人営業を別々に比較している |
| 公務での担当 | 職員研修の申込と会場の連絡を取りまとめた |
| 未経験 | 専門技術の講義、Ciscoの設計構築運用、法人への研修販売 |
| 給与の確認 | 想定年収に固定残業手当と賞与が含まれると読んだ |
| 個別の提示 | 本人の本給、手当、賞与等の正式な提示は受けていない |
| 本人の希望 | 通勤とリモートの併用を希望するが、承認の回答は受けていない |
| 次の確認 | 応募条件、勤務の運用、給与の構成、試用と契約、勤務地の範囲 |

この例では、公開情報を確認した状態と、本人の勤務が確定した状態を分けられます。希望する働き方を記録しても、企業がその希望を承認したことにはなりません。応募する前に、必要な職歴や技術が合うかも別に照合します。

比較表に未確認の欄があっても、推測で埋める必要はありません。何を採用担当へ確かめるかを整理できます。回答を受けたら、今回の法人と職種、確認日を記録し、別の募集の条件へ自動的に広げないようにします。

条件の比較を整理したい方は、[経験と希望する働き方について相談できます](../apply.html)。ご利用は無料です（紹介手数料は採用企業の負担）。経験や希望等により、求人の紹介や面談等をご提供できない場合があります。

## 試用や研修制度は記載の範囲で確認する

今回の二つの求人は、試用期間を六か月とし、給与、総労働時間、固定残業の条件を本採用時と同じと明記しています。具体的に何が同じと書かれているかを読みます。別の雇用区分や会社にも同じ試用の条件があるとは広げません。

同社の求人は、業務上必要な研修を、上長と受講計画を相談した上で勤務時間内に受けられるとし、一部対象外の研修があることも示しています。自分が希望する全ての研修を自由に受けられるという意味にはしません。資格の受験費用の補助も、本人の対象と条件を確認します。

講師の仕事では、技術の調査や検証、資格の学習が業務の一環と説明されています。一方で、技術の習得を本人が進める前提もあります。研修制度があることから、応募時点で必要な技術実務が不要になるとは判断しません。

休日や休暇等の制度も、今回の正社員の条件として読みます。取得の実績や制度の存在が、本人の希望する日に全て取得できるという保証ではありません。勤務する上で必要な希望があれば、担当する業務と合わせて確認します。

## 働き方の希望と応募資格を別々に照合する

Cisco分野の講師は、Cisco製品のネットワークの設計、構築、運用の経験を目安三年以上とし、基礎技術の実務やCCNA相当の知識とスキル等を必須にしています。講師経験は歓迎で未経験も歓迎していますが、技術の実務まで不要とはしていません。

東京の法人営業は、法人営業の経験が三年以上あることを必須にしています。研修業界や人事の領域の経験は応募条件に含めないとしています。公務での研修発注や日程調整を、自動的に営業の実務へ読み替えないようにします。

働き方が希望に近いことと、応募資格を満たすことは別です。本人の職歴でどこを担当したかを整理し、必須の年数や技術を照合します。合わない部分を学ぶ意欲だけで埋めず、別の職務の募集を比較することも可能です。

:::insight
働く時間や場所が希望に近くても、仕事内容と必須条件を別に確認できます。講師未経験を歓迎する募集でも、専門の技術実務が必要な場合があります。営業も、研修を発注した経験と法人へ販売した経験は同じではありません。本人の経験を確定した上で、給与の構成、勤務の運用、契約や研修制度を並べると、関心だけで全ての条件が合うと決めずに済みます。制度があることと本人が利用できること、希望することと採用側が承認することも分けて記録します。まだ条件が合わなければ、現職を続けて比較する判断も同等です。退職を先に決める必要はありません。
:::

## 正式な条件を確認して比較表を更新する

比較の前提として、公開の目安、本人への提示、現在の支給実績の三つを区別できます。現在の実績が分かる項目と、将来の変動する支給がまだ分からない項目を混ぜません。初年度と通常の年度で支給の扱いが変わるかも、今回の案内に沿って確認します。分からない部分を、過去の人の例から推定して確定する必要はありません。

制度の利用について回答を受けた場合は、今回の職種と本人に関する回答として残します。リモート勤務の運用や研修の受講計画を、別の部署や業務委託の講師にも同じと広げないようにします。条件の比較を終えた後でも、担当が変わる案内があれば、その時点の正式な内容で更新できます。

希望する条件が変わったときは、給与の合計だけではなく、通勤する場所、勤務の時間、担当したい職務を合わせて読み直します。

本人への提示を受けたら、雇用主、職務、勤務地や変更の範囲、給与の内訳、試用、勤務時間や休日等を項目ごとに読み直します。求人と差があれば、推測で合わせず、今回の採用担当へ確認します。口頭の説明と書面の内容も分けて記録できます。

公開情報の記載は閲覧時に更新を確かめます。受付が終了した募集は、過去の条件の参考として扱います。応募の送信、受領、選考の連絡、勤務条件の提示は別の段階です。希望の配属や勤務を、回答前から確定として比較表へ記入しないようにします。

在職中に情報を集める場合は、公務の勤務と私用の準備を分けます。職員の名簿や内部の研修評価、システムの設定等を応募のために持ち出しません。面接の候補は所属の休暇等の手続きを確認して調整できます。現職で経験を続ける選択も残せます。

確認事項をまとめたい方は、[LINEで働き方の比較を短く整理することもできます](https://line.me/R/ti/p/@697nxhbt)。情報収集の段階でも利用できます。

## よくある質問

### 年俸の全てを基本給として比較してよいですか

今回の求人は、固定残業手当と賞与を含む目安と説明しています。含まれる支給と本人への提示を分けて確認します。賞与やインセンティブの制度があることだけで、本人の将来の支給が決まるとは判断しません。

### オンライン講師なら自宅で勤務できますか

今回の求人は出社を基本とし、業務の内容や状況に応じてリモート勤務を利用できるとしています。オンラインで研修を実施することと、自宅での勤務が承認されることは別です。今回の担当と制度の条件を確認します。

### 条件が合うか分からない段階でも比較できますか

比較できます。未確認の欄を残して、職務、応募資格、給与の構成、勤務する時間や場所を整理できます。この記事は退職を勧めるものではありません。現職に残る判断も同等に扱い、正式な提示を確認して判断できます。
