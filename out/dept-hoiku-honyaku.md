保育課からの転職で、いちばん取りこぼされているのはこれです。

**この部署は、「施設を審査し、基準で見て、直させる」仕事をしてきた**ということ。

どの類型に当たるかを判定し、基準に適合しているかを審査し、開設を認め、運営を見て、足りなければ改善させる。

**これは、民間でいう多店舗の品質管理と、開設の審査**です。

そして、**扱う施設の数は、数十から百を超える**こともあります。

この記事では、その対応を整理します。訳語の対応表、中核スキルの工程分解、そして**民間の多店舗運営・品質管理の仕事とどこが同じでどこが違うか**まで扱います。

## 定義が、施設の類型を分けています

まず、この部署が扱う「施設」がどう定義されているかを条文で確認します。

児童福祉法第39条第1項は、こう定めています。

**保育所は、保育を必要とする乳児・幼児を日々保護者の下から通わせて保育を行うことを目的とする施設（利用定員が二十人以上であるものに限り、幼保連携型認定こども園を除く。）とする。**

短い条文ですが、**要素が3つ**入っています。

**1. 「日々保護者の下から通わせて」**。**通う施設**であることが定義に入っています。入所して生活する施設とは、別の類型です。

**2. 「利用定員が二十人以上であるものに限り」**。**定員20人が、類型を分ける線**です。19人以下は、別の枠組み（地域型保育）になります。

**3. 「幼保連携型認定こども園を除く」**。**別の法律に基づく施設は、この定義から外れます。**

**つまり、施設の類型は、定義の当てはめで決まります。**

そして、**類型が決まると、適用される基準も、給付の仕組みも、指導の根拠も変わります。**

**この「定義に当てはめて、適用されるルールを決める」という作業**が、保育課の入口にあります。

**民間でいえば、業態の区分を判定して、適用される基準を決める仕事**です。フランチャイズの店舗区分、施設の許認可の類型、サービスの区分。**構造は同じです。**

**面接では、この構造を一度言ってください。**

> 施設の類型は、定員や提供する内容の定義で決まります。**類型が決まると、適用される基準も給付も指導の根拠も変わる**ので、そこを判定するところから仕事が始まります。

## 民間での訳語

履歴書や職務経歴書では、**自治体の中でしか通じない言葉を、募集要項に出てくる言葉に置き換えます。**

| 自治体での呼び方 | 民間での呼ばれ方 |
|---|---|
| 保育所の設置認可・確認 | 施設の開設審査、許認可の審査 |
| 施設の類型の判定 | 業態・区分の判定、適用基準の決定 |
| 運営基準への適合の確認 | 基準適合の監査 |
| 指導監査・改善報告の確認 | 内部監査、是正の追跡 |
| 監査結果の公表 | 監査結果の開示 |
| 公立保育所の運営管理 | 直営拠点の運営管理 |
| 保育士の配置・人員の確認 | 要員配置の管理、人員基準の確認 |
| 処遇改善に関する加算の確認 | 賃金に関わる要件の確認 |
| 保育士の確保対策 | 採用支援、人材確保の施策 |
| 事故・ヒヤリハットの報告と対応 | 事故報告、再発防止の仕組み |
| 給食・保健・アレルギーの管理 | 食品衛生と安全の管理 |
| 施設の整備に対する補助 | 設備投資の補助の審査 |

**「保育の仕事」ではなく、「開設審査」「基準適合の監査」「要員配置の管理」「安全管理」に分けて書く**のが基本です。

## 中核スキルを5つの工程に分ける

この部署の仕事は、**5つの工程**に分解できます。

**① 定義に当てはめる**

**どの類型の施設か**を判定します。定員、対象の年齢、提供する内容、根拠となる法律。

**類型が決まると、適用される基準が決まります。**ここを誤ると、その後の審査も指導も根拠を失います。

**② 認可・確認する**

**設備と運営が、基準に適合しているか**を審査します。

面積、採光、避難の経路、調理の設備、職員の資格と人数、運営の規程、給食の体制。**図面の段階から見ることもあります。**

**そして、この審査の結果が、参入できるかどうかを決めます。**

**③ 運営を見る**

開設した後、**基準どおりに運営されているか**を確認します。

人員が配置されているか、記録が残っているか、健康と安全の管理がされているか、事故の報告が適切か。

**書類だけでなく、実地で見る**のがこの工程の特徴です。

**④ 直す**

基準を満たしていない点が見つかれば、**改善を求め、報告を受け、確認します。**

**そして、結果は公表されます。**指摘の内容と、改善の状況。**外に出る前提で書く**という点が、企業の内部監査と違うところです。

**⑤ 増やす・支える**

整備に対する補助、人材の確保、事業者への情報提供。

**基準を満たす施設を増やさなければ、供給は増えません。**だから、**見る側であると同時に、支える側**でもあります。

## 民間の多店舗運営・品質管理と、どこが同じでどこが違うか

**同じところ**

**1. 基準に適合しているかを、実地で確認する**

**書類と現場が一致しているか。**これは、**チェーンの店舗監査、委託先の監査、工場の監査**とまったく同じ工程です。

**2. 要員の配置を管理する**

**必要な資格を持った人が、必要な人数いるか。**保育に限らず、**人員基準がある業種では共通の課題**です。

**3. 事故と安全の管理がある**

事故の報告、原因の確認、再発の防止。**構造は、どの対人サービスでも同じ**です。

**違うところ**

**1. 審査の結果が、参入の可否を決める**

民間の加盟審査でも、断ることはあります。ただ、**行政の認可は、事業そのものができるかどうかを決めます。**

**この重さの下で審査してきた**という点は、伝える価値があります。

**2. 監査の結果が公表される**

企業の内部監査の結果は、社内の文書です。**自治体の指導監査の結果は、公表されます。**

**外に出る前提で、指摘を書いてきた**——この訓練は、開示を扱う部門で効きます。

**3. 見る側であると同時に、支える側でもある**

**監査だけをしていればよい立場ではありません。**供給が足りなければ、**整備の補助や人材の確保で増やす**必要があります。

**「指摘する相手を、同時に支援する」**という立場は、**民間のパートナー管理や加盟店の支援**と近い構造です。

:::insight
保育課の方が職務経歴書で損をしやすいのは、**扱っていた施設の数を書かないこと**です。書類には「保育施設の指導監査」とだけ書かれていて、**何か所を見ていたのかが分かりません。**民間の採用担当は、**この経歴を多店舗の品質管理として読める**のですが、施設数がないと規模が測れません。**「確認・指導の対象として◯か所（内訳：認可保育所◯、認定こども園◯、地域型保育◯、認可外◯）を所管し、年間◯件の実地の指導を実施」**と書くだけで、読まれ方が変わります。**とくに種類の内訳が効きます。**種類ごとに基準も給付の仕組みも違うので、**複数の類型を横断して見てきたこと**が、**一つの類型しか知らない事業者側の管理者との違い**になります。施設数と、種類の内訳と、指導の件数。**この3つが書かれていれば、事務職ではなく品質管理の経験者として読まれます。**
:::

## 評価が高くなりやすい4つの方向

**1. 保育・教育事業者の本部（運営管理・品質管理・開設）**

**いちばん需要がある方向**です。

**基準、指導で見られる点、加算の要件、開設の手続。**監督する側にいた経験は、**事業者側にとって直接の価値**です。

とくに、**開設の審査を見てきた経験**は、**新しい施設を作る部署**でそのまま使えます。**何が通り、何で止まるかを知っている**ためです。

**書くときは、開設の審査に関わった件数も入れてください。**設計の段階から見た経験があれば、それも書きます。

**2. 人材サービス（保育・教育分野）**

保育士の採用支援、人材の紹介、派遣。

**この分野で難しいのは、人員基準の理解**です。**類型ごとの配置の基準、資格の要件、加算に関わる人員の要件。**これを知らないと、事業者が本当に必要としている人数と資格が分かりません。

**保育士の確保対策を担当していた方**は、**採用の側から見た経験**として、そのまま話せます。

[公務員の経験が活きる求人を見てみる](../?gov=1)

**3. 自治体を顧客にする企業・保育分野のシステム**

施設の管理のシステム、指導監査の支援、保育の記録のサービス、事業者向けの支援。

**発注する側にいた経験**に加えて、**基準と監査の実務を知っていること**が提案の材料になります。

**この方向は経歴の説明に時間がかかりません。**制度側から来る人材を前提に募集を出しているためです。ただし、**顧客が自治体だけとは限らない**ので、**入ってから事業者向けの担当になる**可能性は確認しておいてください。

**4. 保育以外の対人サービスの品質管理**

介護、学習塾、スポーツクラブ、児童の放課後サービス。**多店舗で、人員基準があり、安全の管理が要る業種**です。

**基準適合の監査と、要員配置の管理と、事故の対応。**この3つが揃っている業種であれば、**業界が違っても工程は同じ**です。

:::insight
方向を決めるときに、**残る判断のほうが妥当だと感じる場面**もあります。保育課は、**担当している工程によって、書ける内容がまったく変わる**部署です。公立保育所の庶務だけなのか、**指導監査に出ているのか**、**開設の認可の審査に関わっているのか**、**保育士の確保対策を担当しているのか。**このうち、**民間でいちばん値が付くのが指導監査と、開設の審査**です。とくに**開設の審査は、事業者側の「新規開設の部署」でそのまま使える**経験で、**設計の段階から見た経験があれば、さらに強くなります。**まだ庶務や補助金の事務が中心の段階なら、**指導監査に同行してからのほうが、選べる方向が明確に増えます。**もう一つ、**保育士の確保対策**は、**人材サービスへの転職で直接の材料**になります。いずれも、いまの場所でしか積めません。在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## つまずきやすい点

**1. 「保育の仕事」で丸める**

**開設審査・基準適合の監査・要員配置の管理・安全管理**に分けてください。

**2. 施設の数と種類の内訳を書かない**

**規模が測れません。**これがないと、多店舗の品質管理として読まれません。

**3. 開設の審査を落とす**

**事業者側の新規開設の部署でそのまま使える経験**です。件数を書いてください。

**4. 「公表される」ことを書かない**

**外に出る前提で指摘を書いてきた**という訓練は、開示を扱う部門で効きます。

**5. 個別の事案に触れる**

**施設名、個別の指摘の内容、事故の詳細、園児や職員に関する情報。**すべて書けません。工程と件数で書いてください。

どの経験に値が付くかは、募集の出方で変わります。[どの経験に値が付くのかから相談できます](../apply.html)。

## まとめ

- 児童福祉法第39条は、保育所を**「日々保護者の下から通わせて保育を行う」施設**とし、**利用定員二十人以上**に限るとしています。**定義が類型を分けています**
- **類型が決まると、適用される基準も給付も指導の根拠も変わります。**そこを判定するところから仕事が始まります
- 民間での訳語は、**施設の開設審査／基準適合の監査／是正の追跡／要員配置の管理／安全管理**が中心になります
- 中核スキルは**①定義に当てはめる ②認可・確認する ③運営を見る ④直す ⑤増やす・支える**の5工程です
- 民間の多店舗運営・品質管理と**同じ**なのは、実地で基準適合を確認すること・要員の配置を管理すること・事故と安全の管理があること
- **違う**のは、審査の結果が参入の可否を決めること・監査の結果が公表されること・見る側であると同時に支える側でもあることです

## よくある質問

### 保育士の資格がないと、この分野では働けませんか

**本部や管理の職種では、資格が前提にならないことが多くあります。**求められるのは、**基準の理解、指導で見られる点、開設の手続、人員配置の管理**です。現場の保育とは別の能力として評価されます。面接では、**「保育の実務は経験していないが、基準への適合の確認と施設の監督を担当していた」**と正確に言ってください。**役割の線をはっきりさせるほうが読まれ方がよくなります。**

### 公立保育所の運営を担当していた場合は、どう書けばよいですか

**「直営拠点の運営管理」として書けます。**職員の配置、予算の管理、施設の修繕、給食の管理、保護者への対応、事故への対応。**これは、民間でいう直営店舗の運営管理とほぼ同じ**です。書くときは、**所管していた施設の数、園児数の合計、職員数**を添えてください。そのうえで、**指導監査や認可の審査に担当が広がれば、書ける内容が大きく増えます。**

### 保育士の確保対策は、どう書けばよいですか

**「人材確保の施策」として書けます。**就職の相談会、資格を持ちながら働いていない方への働きかけ、処遇改善に関する周知、修学資金などの支援。**これは、民間でいう採用支援や、人材の確保の施策**と同じ工程です。書くときは、**実施した施策の内容と、参加者数や相談件数**を添えてください。**人材サービスへの転職では、直接の材料**になります。
