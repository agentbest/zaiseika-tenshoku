**教員からの転職では、「授業しかしていない」と感じる方**がいらっしゃいます。

**実際には、複数の役割を同時に担っています。**

この記事では、**経験の分け方**と、**示し方**を扱います。

## 学校は、職ごとに職務が定められた組織です

**学校教育法第37条第1項**です。

> **小学校には、校長、教頭、教諭、養護教諭及び事務職員を置かなければならない。**

**同条第4項**です。

> **校長は、校務をつかさどり、所属職員を監督する。**

**同条**は、**教諭について、次のように定めています。**

> **教諭は、児童の教育をつかさどる。**

**職ごとに、職務が条文で定められている**という構造です。

**つまり、学校は組織であり、その中で職務が分かれている**ということです。

**なお、中学校・高等学校については、それぞれ準用や別の規定が置かれています。**

**自分の校種に応じた規定を確認**してください。

## 「教育をつかさどる」の中身を分ける

| 要素 | 実際にやっていること |
|---|---|
| ① 授業の設計 | 年間の計画、単元の構成、教材の作成 |
| ② 授業の実施 | 進行、説明、個別の対応 |
| ③ 評価 | 到達の確認、記録、説明 |
| ④ 学級の経営 | 集団の運営、行事、個別の面談 |
| ⑤ 保護者への対応 | 説明、相談、苦情 |
| ⑥ 校務の分掌 | 教務、生徒指導、進路、研究 |
| ⑦ 部活動・課外 | 指導、大会の運営 |

**①〜③が、民間では「研修の設計・実施・評価」**にあたります。

**④が「集団の運営」、⑤が「顧客対応」、⑥が「部門の業務」**です。

**「授業しかしていない」のではなく、7つを同時に担っている**ということです。

## 書き方の例

**悪い例**

> ◯◯小学校で、教諭として勤務しました。

**良い例**

> ◯◯において、**児童◯名の学級を担任。**年間の指導の計画を作成し、**単元ごとの教材と評価の基準を設計。****保護者◯世帯への説明会の運営と、個別の面談を年◯回実施。**校務分掌として**◯◯を担当し、◯名の教職員と行事の企画・運営**を担った。**新規に着任した教職員への指導**を担当。

**「人数」「設計したもの」「運営」「指導」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 言い換えの対応

| 学校の言葉 | 民間での読まれ方 |
|---|---|
| 指導の計画の作成 | **研修・カリキュラムの設計** |
| 授業の実施 | 講師、ファシリテーション |
| 評価・所見 | 到達度の測定、フィードバック |
| 学級の経営 | **集団の運営、チームの管理** |
| 保護者への対応 | 顧客対応、苦情の対応 |
| 校務分掌 | 部門の業務、委員会の運営 |
| 教材の作成 | コンテンツの制作 |
| 研究授業・研修 | 社内の勉強会、ノウハウの共有 |

**1行目と4行目が、最も使える**部分です。

**人材の育成を担う部署では、①〜④がそのまま業務**になります。

## 民間での使いどころ

| 領域 | 使える経験 |
|---|---|
| ① 研修・人材の開発 | **設計、実施、評価の一連** |
| ② 教育に関する事業 | 教材、学習のサービス、進路 |
| ③ 自治体・教育委員会が相手の事業 | **学校の実情が分かる** |
| ④ 顧客対応・相談 | 保護者への対応の経験 |
| ⑤ 採用・育成の部門 | 指導と評価の経験 |

**③が見落とされやすい**です。

**学校向けのシステム、教材、施設、給食、ICTの支援。**

**これらの事業では、「学校がどう動くか」を知っている人**が求められます。

**年度の流れ、行事の時期、教職員の体制、教育委員会との関係。**

**外から見ても分かりません。**

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 何を担当したか | **人数、設計したもの、期間** |
| 難しい対応の経験 | 3件、経緯と結論 |
| 大人を相手にできるか | **保護者・同僚との協働の例** |
| 数字への向き合い方 | 評価・集計の経験 |
| 退職の時期 | **年度との関係** |

**3行目です。**

**「子どもが相手の仕事」と見られることがあります。**

**保護者への説明、同僚との分掌の調整、地域との連携。**

**大人を相手にした場面を、具体に用意**してください。

**なお、特定の児童生徒や保護者が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

:::insight
教員の方のご相談で、**面談でお伝えしているのが「設計した側面を書いてください」**という点です。多くの方が、**「授業をしていました」**と書かれます。ところが、**授業は、実施の部分にすぎません。**その前に、**年間の計画を作り、単元を構成し、教材を選び、評価の基準を決めている。**これは、**研修の設計そのもの**です。民間の人材の開発の部署では、**「どんな研修を、誰に、どの順で、どう測るか」**を決める仕事があります。**やっていることは同じ**です。そして、**教員は、設計したものを自分で実施し、結果を評価し、翌年に改善している。****この一巡を毎年回している人**は、民間には多くありません。ですから、書類には**「年間の計画の作成」「単元ごとの教材と評価の基準の設計」**と明記してください。**実施だけを書くと、講師の経験としてしか読まれません。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 準備の順序

| 順 | やること |
|---|---|
| 1 | 担当した学級・教科・人数を書き出す |
| 2 | **設計したものを書き出す**（計画、教材、基準） |
| 3 | 校務分掌と、担った役割を書き出す |
| 4 | 大人を相手にした場面を書き出す |
| 5 | 民間の言葉に置き換える |
| 6 | 求人を読む |

**2と4が要**です。

**4について。**

**保護者への説明、同僚との調整、地域や関係機関との連携。**

**これらは、面接で必ず材料になります。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 在職中の進め方

| 項目 | 内容 |
|---|---|
| 記録 | 担当した人数、作成した教材・資料 |
| 制度の確認 | **退職の手続きと、年度との関係** |
| 求人を読む | 週に30分 |
| 日程の確保 | **学期中と行事の時期を避ける** |

**2行目です。**

**教員の退職は、年度との関係で時期が限られる**ことがあります。

**手続きの時期を、早めに人事担当に確認**してください。

**制度の照会として聞くことができます。**

**後任の確保や引継ぎの関係で、調整に時間がかかることがあります。**

**早く確認するほど、選べる時期が広がります。**

**扱いは**[選考スケジュールの組み方](senko-sagasu-schedule.html)**に整理しています。**

## よくある失敗

**1. 「授業をしていた」とだけ書く**

**設計した側面**を書いてください。

**2. 人数を書かない**

**規模が伝わりません。**

**3. 校務分掌を書かない**

**部門の業務**として読まれます。

**4. 大人を相手にした場面を用意しない**

**面接で聞かれます。**

**5. 評価・集計の経験を書かない**

**数字への向き合い方**が伝わります。

**6. 学校向けの事業を見ない**

**学校の実情が分かる**人が求められます。

**7. 退職の時期を確認しない**

**年度との関係**があります。

**8. 特定の児童生徒が分かる説明をする**

**守秘の義務は退職後も続きます。**

:::insight
ここまで書き方の話をしておいて逆のことを言いますが、**教員の経験で最も希少なのは、「相手を選べない状況で成果を出してきたこと」です。**面談で拝見していると、**この点を当たり前だと思っている方**がいらっしゃいます。ところが、**民間の研修や教育の事業では、受講者が選べる場面や、意欲のある人が集まる場面**が多くあります。**学校は違います。**関心の有無にかかわらず、決められた集団を相手に、**決められた期間で一定の到達に導く。**しかも、**個別の事情を抱えた相手が混ざっている。**この条件で成果を出す方法を、経験として持っている人は多くありません。書類には、**「習熟の差がある集団に対し、個別の課題を把握したうえで指導の方法を分け、◯名全員の到達を確認」**という形で書いてください。**条件の厳しさごと書く**と、伝わります。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **学校教育法第37条**は、**置くべき職員**を定め、**校長は校務をつかさどり所属職員を監督する**、**教諭は児童の教育をつかさどる**としています
- **「教育をつかさどる」の中身は、7つの要素**に分けられます
- **①〜③は、研修の設計・実施・評価**にあたります
- **設計した側面を書いて**ください。実施だけでは講師の経験としてしか読まれません
- **大人を相手にした場面**を、面接用に用意してください
- **学校向けの事業**では、学校の実情を知っていることが要件になります
- **退職の時期は、年度との関係**を早めに確認してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 退職の時期は、年度末でなければなりませんか

**手続きの定めを確認してください。**教員の退職については、**年度の途中の場合、後任の確保や引継ぎの関係で調整が必要**になることがあります。**時期と手続きは、所属の人事担当に確認**してください。**制度の照会として聞くことができます。**なお、**内定から入社までの期間**については、**応募の段階で相手に伝えておいて**ください。「年度の区切りでの退職になる見込み」と先に伝えれば、**企業側も計画を立てられます。**伝えずに進めて、内定後に時期が合わないほうが問題になります。扱いは[選考スケジュールの組み方](senko-sagasu-schedule.html)に整理しています。

### 企業での勤務の経験がなく、応募条件を満たせません

**応募条件の書き方を見てください。**「業界経験」が必須とされている求人は難しくなります。一方、**「研修の企画・運営の経験」「人材の育成の経験」「顧客への説明の経験」**が挙げられている場合、**該当します。**教員の経験は、**これらの言葉に置き換えられます。**また、**学校・教育委員会が相手の事業**では、**学校での勤務経験そのものが要件**になることがあります。探し方は[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)に整理しています。**職種名ではなく、応募条件の言葉で判断**してください。

### 部活動の指導は、書いてよいですか

**運営の側面を書いてください。**「部活動を担当」だけでは、中身が伝わりません。**「◯名の集団の活動を計画し、年間の日程と大会への参加を管理」「保護者への説明と、外部の指導者との調整を担当」**という形にすると、**運営の経験として読まれます。**また、**大会の運営に関わった経験**があれば、**行事の企画・運営**として書けます。参加の人数、関わった団体の数、準備の期間。**数を入れてください。**なお、**指導の成果を強調しすぎない**ほうが読まれやすいです。**担った役割と範囲**を書いてください。
