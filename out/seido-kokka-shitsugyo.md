国家公務員を退職して仕事が決まっていない場合でも、全員に雇用保険の基本手当が出るわけではありません。一方、一般の退職手当等が失業等給付に相当する額に満たない場合などには、国家公務員退職手当法第10条の「失業者の退職手当」を確認する余地があります。

本記事は2026年11月時点の公開情報にもとづきます。国の制度の一般的な取扱いを整理し、基本手当に相当する退職手当を中心に説明します。本人の任用区分、勤続期間、退職理由、支給額と手続きは、退職時の所属と住所・居所を管轄するハローワークに確認してください。

## 雇用保険と同じ給付を二重に受ける制度ではない

雇用保険法第6条は、公的部門で働く人のうち、他の法令等による退職後の給付が求職者給付等の内容を超えると認められる一定の人を適用除外としています。公務員という名称だけで全員の加入状況を決めず、任用資料や所属の説明で確認します。

国家公務員退職手当法第10条は、一般の退職手当等と、雇用保険の規定により計算する給付相当額を比較する仕組みです。厚生労働省も、その差額分を限度としてハローワーク等を通じて支給するものと説明しています。一般の退職手当を受け取った後に、雇用保険相当額をそのまま上乗せする制度ではありません。

同条には、雇用保険の相当する給付の支給を受ける者へ支給してはならない規定もあります。民間勤務時の雇用保険の記録がある場合や、退職後に別の仕事を経て再離職した場合は、経歴を省略せず窓口へ伝えます。自分で有利な制度だけを選んで重ねて請求できるとは考えないでください。

地方公務員は所属の退職手当条例等を確認します。国立大学法人や独立行政法人も、職員区分によって適用制度が異なります。本記事の国の法律を、名前の似たすべての組織へ直接当てはめることはできません。

## 勤続期間と退職理由を組み合わせて確認する

基本手当に相当する退職手当の勤続期間は、第10条第1項・第2項では原則12月以上です。同条の特定退職者は6月以上とされています。特定退職者は、雇用保険の特定受給資格者に相当するものとして内閣官房令で定める区分です。短い任期で退職したことや、仕事が見つからないことだけで該当するわけではありません。

| 退職した人の区分 | 条文上の確認の出発点 |
| --- | --- |
| 基本手当相当の通常の区分 | 原則として勤続12月以上 |
| 同条の特定退職者 | 勤続6月以上という特則の適用を確認 |
| 高年齢求職者給付金相当の区分 | 第4項・第5項に別の6月要件等がある |
| 短期雇用特例被保険者相当の区分 | 第6項・第7項に別の要件がある |

高年齢の区分や季節的な勤務等の区分を、通常の基本手当の日数表へ無条件に入れないようにします。また、一般の退職手当等を受けない場合の規定もありますが、「退職金がない」という事実だけで支給が確定するわけではありません。

所定給付日数の計算に使う「基準勤続期間」と、一般の退職手当の計算上の勤続期間も区別します。過去の職員等の期間には、空白期間や既に退職手当の支給を受けた期間などについて除外条件があります。過去の在職を単純にすべて足した数字で自己判定しないでください。

内閣人事局は、12月未満で退職した場合の在職票と、再び国家公務員に採用された場合の提出について案内しています。前後の勤務が近接している場合でも、任用日、退職日、在職票、支給歴をそろえ、通算できる期間を所属に確認します。

## 退職手当が少額でも差額が一度に支給されるとは限らない

基本手当相当の通常の仕組みでは、既に受けた一般の退職手当等を基本手当の日額で割り、端数を切り捨てた日数が「待期日数」になります。内閣人事局は、退職時の退職手当を基本手当相当額の先渡しとみなし、何日分に当たるか計算するものと説明しています。

この待期日数を超える失業の日について支給するため、差額の計算結果だけで振込日や総額は確定しません。所定給付日数から待期日数を引いた日数が上限となり、支給期間内の失業認定等も必要です。途中で就職した場合などは、最後まで失業し続けた場合と同じ支給にはなりません。

基本手当の日額は、失業者の退職手当支給規則第1条・第2条に従って計算します。退職前の一定の給与を基にする賃金日額と、そこから算定する基本手当の日額は別です。対象給与には除外されるものや、給与が支払われなかった期間等についての特則があります。

内閣人事局の計算例にも適用時点が示されています。古い例の額を現在の自分の給付額に置き換えたり、俸給月額だけで計算を終えたりせず、所属が作成する給与の記録と窓口の算定を照合します。

:::insight
給付を調べるときは、退職時の入金額、追加給付の上限、支給され得る時期を別の欄に置くことを勧めます。同じ「退職後のお金」でも、既に支給されたものと、失業認定等を経て支払われるものでは確かさが違います。特に待期日数の間も生活費は必要なので、差額があるという説明だけで資金の予定を決めないことが大切です。制度上の可能性を確認することと、希望する仕事内容を考えることは並行できます。未確認の給付を確定収入に数えず、現時点の資金と支出予定を先に整理すれば、給付の有無だけに応募先の判断を引っ張られずに済みます。受給の確認は担当窓口へ、仕事の比較は職務や条件の資料へと、質問を分けて進めます。
:::

仕事の選択肢を確認する段階なら、[行政経験に関連する求人](../?gov=1)で職務内容を比較できます。給付の受給資格は、制度の担当窓口へ別に確認してください。

## 待期日数と退職理由による給付制限を分ける

ここでいう待期日数は、雇用保険について説明される一律の短い待期と同じ意味ではありません。既支給の退職手当等と本人の日額に応じて変わる日数です。「退職後しばらく待てば全員支給される」と考えないようにします。

さらに、支給規則第9条は、求職の申込みをした日から起算して、雇用保険法第33条の期間と待期日数に等しい失業の日数を経過した後に支給する仕組みを定めています。正当な理由のない自己都合退職等についての給付制限は、退職手当額から計算する待期日数とは別の確認事項です。

退職の事情、過去の給付、訓練の受講等によっても適用の確認が必要になります。古い案内の制限期間をそのまま使わず、今回の退職日と理由を伝えて、受給資格証等に記載される日付を確かめます。申込みを遅らせれば、支給開始の計算や残る支給期間にも影響し得ます。

## 所属での書類交付とハローワークの手続きをつなぐ

支給規則第3条は、基本手当に相当する退職手当の資格を有する場合に、所属庁等の長が国家公務員退職票を交付することを定めています。一般の退職手当の支給通知や、民間勤務で用いる雇用保険の離職票と混同しないでください。

同規則第5条では、退職後速やかに管轄ハローワークへ出頭し、退職票を提出して求職を申し込むことになっています。その後、受給資格証の交付や失業の認定等につなげます。所属へ連絡しただけ、あるいは求人サイトへ登録しただけで、この手続きが完了するわけではありません。

| 段階 | 主に確認する相手と内容 |
| --- | --- |
| 退職前後 | 所属へ任用区分、退職理由、支給歴、必要書類を確認 |
| 求職申込み | 管轄ハローワークへ退職票等を提出し、資格と日程を確認 |
| 認定・支給 | 指示された認定日に必要な申告を行い、支給の取扱いを確認 |
| 状況変更 | 就職、就労、転居、働けない事情等を担当へ報告 |

行政執行法人の職員は、施行令第10条による支給官署の特例の対象です。支給規則第6条では、ハローワークから返された退職票を所轄官署等へ提出する手順があります。独立行政法人だからすべて同じ窓口という説明も、全手続きをハローワークだけで終えるという説明も避けます。

認定を受ける期間には、短時間の就労、収入のある活動、事業の準備等も正確に伝えます。申告の必要性を自分の呼び方で判断せず、行った日、時間、内容等を記録し、担当の案内に沿って申告してください。

職務経験や希望条件を整理したい場合は、[応募前の相談](../apply.html)も利用できます。ご利用は無料です（紹介手数料は採用企業の負担）。給付の認定と、転職先を検討する相談は役割が異なります。

## 働けない事情が続く場合は支給期間の延長を照会する

基本手当相当の給付は、原則として退職日の翌日から起算する1年の期間内の失業を対象にします。支給期間と、実際に支給する日数は別です。手続きをした日から新たに1年もらえるという意味ではありません。

妊娠、出産、育児、疾病・負傷等で30日以上続けて職業に就けない場合には、法第10条と支給規則の定めに沿って受給期間の延長を確認します。内閣人事局の案内では、確認書類と退職票または受給資格証を添え、ハローワークへ申請する手順が示されています。単に休養したいという希望と、制度上の延長理由は分けます。

退職後の事業開始等については、要件を満たす場合に支給期間の特例があります。事業を始めれば失業給付が続くという意味ではありません。準備への専念や開始の日、実施期間等を伝え、今回の特例と申請期限を確認します。

:::insight
退職前に制度を調べているなら、追加給付があるかどうかだけで辞職日を決める必要はありません。現職での異動や働き方の調整で希望に近づける場合には、残る判断にも理があります。退職後に求職する場合も、健康上働ける状態か、希望する仕事を探す期間をどう確保するか、生活費を何で賄うかを分けて考えます。給付の制度は、その一部を確認する材料です。受給期間の延長ができる可能性と、働けない間にも同じ給付が支払われるという理解は区別してください。担当窓口への照会結果を日付と資料名付きで残し、確認できた条件に沿って予定を組むことが、現職継続を含めた選択肢を落ち着いて比べるための準備になります。
:::

## よくある質問

### 自己都合で辞めた国家公務員は対象になりませんか

自己都合という言葉だけでは決まりません。勤続期間、一般の退職手当等との比較、失業状態、支給期間、給付制限等を組み合わせて確認します。本人の退職理由を所属とハローワークへ伝えてください。

### 勤続6月あれば全員が申請できますか

通常の基本手当相当は原則12月以上です。特定退職者の特則や、高年齢等の別区分に6月の要件がありますが、全員に広げられません。適用される条項と任用区分を確認します。

### 退職票を提出すれば差額全額が振り込まれますか

求職申込み後も、待期日数、給付制限、支給期間内の失業認定等を確認します。差額は無条件の一括給付ではありません。就職や就労等の状況も正確に申告してください。

失業者の退職手当は、資格、金額、期間、書類の順に分けて確かめます。仕事の希望を整理する段階なら、[LINEで短く聞く](https://line.me/R/ti/p/@697nxhbt)こともできます。正式な受給判断は、所属と管轄窓口に確認してください。
