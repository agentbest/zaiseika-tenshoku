親族が亡くなったときの忌引・服喪休暇は、本人との続柄、必要な行事、日数の数え方を確認して申請します。国の制度では続柄に応じた連続日数が定められていますが、自治体や任用が違えば同じ条件とは限りません。まず所属へ事情と勤務を離れる予定を伝え、手続きの方法を確かめます。

本記事は2026年11月時点の公開情報にもとづきます。国の一般職の例と地方の具体例を分けて説明します。本人の対象、取得開始日、移動日、給与、必要資料は所属の人事・服務担当へ確認してください。

## 国の制度は親族の死亡に伴う必要な行事等が対象

人事院規則15-14第22条第1項第13号は、別表第2に掲げる親族が死亡し、葬儀、服喪その他の必要な行事等のため勤務しないことが相当と認められる場合の休暇を定めています。

対象は葬儀への出席だけに限った説明ではありませんが、親族が亡くなれば、いつでも自由に別表の日数を使えるという意味でもありません。運用通知の第14は、社会通念上妥当と認められる範囲の期間に限ること、連続日数を暦日で扱うことを示しています。

死亡日、葬儀の日、必要な準備や移動の予定が離れている場合は、その事情を担当へ伝えます。取得開始日を全国共通で「死亡した翌日」又は「葬儀の日」と固定するのではなく、本人の適用規程と必要な期間を確認してください。

また、後日の法要や追悼に関する休暇は、忌引と同じ枠とは限りません。国の規則には父母の追悼のための別の規定があるため、対象行事と時期を分けて確認します。

## 続柄の別表は注記まで確認する

次の表は、人事院規則15-14別表第2による国の例の一部です。全国の公務員や民間会社に共通する法定日数ではありません。上限の範囲で必要な取得期間を確認します。

| 国の例の親族 | 連続日数の範囲 |
| --- | --- |
| 配偶者、父母 | 7日 |
| 子 | 5日 |
| 祖父母 | 3日。代襲相続と祭具等承継の条件を満たす場合は7日 |
| 孫 | 1日 |
| 兄弟姉妹 | 3日 |
| おじ・おば | 1日。代襲相続と祭具等承継の条件を満たす場合は7日 |
| 父母の配偶者・配偶者の父母 | 3日。生計を一にしていた場合は7日 |
| 子の配偶者・配偶者の子 | 1日。生計を一にしていた場合は5日 |

このほかの姻族等も別表に区分があります。祖父母、配偶者の祖父母、兄弟姉妹、配偶者の兄弟姉妹を同じ日数として扱わないでください。親族関係と別表の欄を対応させて確認します。

同居していることと、生計を一にするという条件も、自己判断で同じものにしません。代襲相続や祭具等の承継が関係する場合も、本人が喪主であるという理由だけで注記を満たすと決めないでください。必要な確認方法を担当に聞きます。

配偶者等の定義、事実上の関係の扱いは、本人の適用制度の定義や別の取扱いを確認します。他の手当や扶養で認定を受けていることが、そのまま休暇の同じ続柄の判定になるとは限りません。

## 国の連続日数は勤務日だけで数えない

国の運用では、忌引の連続する日数を暦日で扱います。週休日や休日を挟む場合も、勤務日だけを選んで日数を後へ延ばせるという計算にはなりません。

例えば、仮に月曜から金曜まで勤務する人が、金曜を初日とした連続3暦日の期間を確認するなら、金曜、土曜、日曜という並びになります。月曜と火曜まで三つの勤務日を自動的に数えられるわけではありません。これは計算の仮例であり、本人の取得開始日を決めるものではありません。

一方、地方の規程では計算方法が異なる場合があります。国の暦日の説明を、別の自治体の同じ「3日」という数字へそのまま当てはめないようにします。交替制勤務や短時間勤務は、本人の勤務表で確認することが必要です。

| 日程の確認 | 本人が担当へ伝えること |
| --- | --- |
| 出来事 | 死亡日、続柄、必要な行事 |
| 希望する期間 | 勤務を離れる初日と末日 |
| 勤務の割振り | 勤務日、週休日、休日 |
| 移動 | 行先、経路、往復に必要な期間 |
| 別の休暇 | 忌引の対象と分けて相談したい期間 |

国の連続期間を、残日数として別の週へ自由に分割できるとは考えません。葬儀日程の変更等がある場合は、もとの承認期間と必要な変更を担当へ伝えてください。

:::insight
忌引の確認では、続柄の表から日数だけを抜き出すより、必要な行事と移動、本人の勤務日を一つの日程表に置く方法を勧めます。暦日と勤務日の違いや、遠隔地の移動を別に見る必要があるためです。事情をすべて整理しきれない場合は、まず分かる範囲を所属へ伝え、後から必要な書類や期間を確認する進め方もできます。職場全体へ詳細な家族情報を説明する必要があると考えず、承認の窓口と業務の代理担当を分けて連絡します。この時期に働き方の結論を出す必要はありません。本人と家族の予定を優先し、制度の確認は必要な手続きを進めるためのものとして扱う姿勢が大切だと考えます。
:::

働き方の情報は、必要になった時に[公務員向け求人情報](../?gov=1)で確認できます。親族の死亡を機に応募や退職を決める必要はありません。

## 遠隔地への移動は基本日数と分けて確認する

国の第22条第1項第13号は、葬儀のため遠隔地へ赴く場合、往復に要する日数を加える規定を置いています。どこでも一律に二日を追加する、距離だけで自動計算するといった制度ではありません。

担当へは、葬儀の場所、予定する交通手段と経路、出発・帰着の予定を伝え、必要な日数と確認資料を聞きます。現地での私的な滞在や別の用事を含む期間まで、すべて往復の日数とすることは避けます。

交通事情や葬儀日程が変わった場合には、承認内容と実際に必要な期間を見直します。海外へ赴く場合も、国の条文の対象、必要な移動、本人の規程を担当へ確認してください。行先だけで休暇の総日数を断定しません。

## 自治体の服忌休暇と非常勤の規定を区分する

地方公務員法第24条第5項に基づく地方の勤務条件は、本人の条例・規則で確認します。横浜市の一般職の例では「服忌休暇」という名称を使い、条例第4条、規則第4条と別表第2で対象や期間を定めています。

同市の規則第6条は、勤務を要しない日や休日を休暇日数に含める一般の規定から服忌休暇を除外しています。育児短時間勤務職員等の計算には別の取扱いもあります。国と続柄表の数字が似ていても、同じ暦日計算とは限らない点に注意します。

国の非常勤については、人事院規則15-15第4条第1項第6号が親族死亡の有給休暇を定め、運用通知で国の別表の親族と休暇の例を参照しています。ただし地方の会計年度任用職員等には、本人の自治体の規程を確認します。

民間会社へ転職した場合は、新勤務先の就業規則等で慶弔休暇の対象、日数、給与を確認します。国の忌引の表を、すべての会社へ共通する日数として請求するものではありません。勤務先が変わる前後に事由が生じた場合も、それぞれの対象期間を確認してください。

## 事前に請求できない場合も連絡と申請を区別する

人事院規則15-14第27条は、原則として事前の休暇簿による請求を定めていますが、やむを得ない事由で事前請求できない場合は、事情を付して事後に承認を求められる仕組みです。突然の出来事では、連絡可能な範囲で所属へ伝え、正式な申請の方法を確認します。

地方も所属の手順に沿います。横浜市の規則には事前承認や前日までの請求の規定と、やむを得ない事由の場合の速やかな請求の扱いがあります。電話で欠勤の事情を伝えたことだけで、所定の承認まで終わったとは考えないようにします。

必要な資料は所属で確認します。続柄や死亡の事実、葬儀等の予定、移動の必要性について何を示すかを聞き、全国一律で戸籍や死亡診断書を提出する義務があるとは決めません。資料の準備がすぐに難しい場合も、その事情を担当へ伝えます。

職場への連絡は、申請を受ける担当と、業務を代わる担当を分けて整理できます。急ぐ案件や資料の所在等は、組織の方法で引き継ぎます。業務データを私用端末へ持ち出し、休暇中も常時対応する約束をする必要はありません。

休暇の分類は[特別休暇の種類](seido-kyuka-tokubetsu-shurui.html)も参照できます。共済や互助会の弔慰・埋葬に関係する給付と休暇は別制度です。休暇の承認が、給付の申請や支給決定まで含むとは考えず、必要な窓口を別に確認してください。

後日、本人が働き方の整理を希望する場合には[相談フォーム](../apply.html)も利用できます。ご利用は無料です（紹介手数料は採用企業の負担）。休暇の承認や家族関係の個別判定は所属の担当へ確認してください。

:::insight
家族の出来事が重なった時に、勤務先を変えるかどうかまで一度に判断する必要はありません。まずは必要な休暇の申請と業務の連絡を整え、落ち着いてから今後の働き方を考える進め方もできます。現職で使える制度や勤務の調整を確認することにも意味があります。後に転職先を比べる場合は、休暇の日数だけでなく、対象者、給与、申請方法、日々の勤務時間を同じ項目で並べるとよいと考えます。ある場面の経験だけで会社や公務全体の制度を決め付けず、本人に適用する条件を確認します。悲しみや手続きの負担を仕事の結論へ結び付けず、現職を続ける選択も含め、本人が考えられる時期と希望を尊重する姿勢を大切にしたいと思います。
:::

## よくある質問

### 忌引は必ず勤務日だけを数えますか

国の運用は連続する暦日です。自治体では休日等の計算が異なる場合があるため、本人の規程と勤務表で確認してください。

### 配偶者の父母も自分の父母と同じ日数ですか

国の別表では区分が異なり、生計を一にしていたか等の注記もあります。続柄と条件を担当へ示して確認します。自治体や会社では別の規程を確認してください。

### 突然のことで事前申請できなければ取得できませんか

国には、やむを得ない事情で事前請求できない場合の事後承認の規定があります。所属へ連絡し、必要な申請と資料を確認してください。自治体も本人の手順に沿います。
