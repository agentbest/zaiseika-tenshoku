「民間は在宅勤務が普通になった。役所は毎日出勤している」——転職を考える理由の中で、この数年で増えたのが、テレワークの有無です。財政課の業務は、庁内のシステムと紙の決裁に依存する部分が多く、在宅で完結しにくいという事情もあります。

自治体のテレワークは、**法律で定められた制度ではなく、各自治体の規程（要綱、規則）で定められています。**そのため、対象の業務、日数の上限、端末の貸与、手当の有無が、自治体ごとに大きく違います。国には**在宅勤務等手当**（給与法第12条の3）が設けられています。

この記事では、**自治体のテレワークの根拠と仕組み、財政課でどこまで使えるか、職務専念義務と守秘義務との関係、転職先の在宅勤務との比較**を整理します。**自分の自治体の制度は、テレワークの規程と人事の担当課で確かめてください。**

## 根拠——法律ではなく、自治体の規程

| 規定 | 内容 |
|---|---|
| **地方公務員法第24条第5項** | 勤務時間その他の勤務条件は条例で定める |
| **自治体のテレワークの規程**（要綱、規則） | 勤務場所を自宅などとする勤務の形態、対象の職員・業務、日数、手続き、端末、情報管理を定める |
| **国の例：給与法第12条の3**（在宅勤務等手当） | 住居などで正規の勤務時間の全部を勤務することを、一定の期間以上について1か月当たり平均10日を超えて命ぜられた職員に、**月額3,000円**の在宅勤務等手当を支給 |

**テレワークは、勤務時間の割振りではなく、勤務場所の指定の問題**なので、条例ではなく、任命権者の規程（要綱）で定めている自治体がほとんどです。制度の有無、対象、日数は自治体ごとで、**「自治体にテレワークがあるか」は一般論では答えられません。**

## 自治体のテレワークの一般的な形

| 項目 | 一般的な内容 | 自治体ごとの違い |
|---|---|---|
| **形態** | 在宅勤務（自宅）、サテライトオフィス勤務、モバイルワーク | 在宅勤務のみの自治体が多い |
| **対象の職員** | 全職員、または育児・介護などの事情がある職員 | 事情を要件にする自治体と、しない自治体 |
| **対象の業務** | 資料の作成、データの分析、調査など、庁外で完結する業務 | 窓口、決裁、システムへの接続の可否で範囲が変わる |
| **日数** | 週1〜2日、月○日までなど上限を設ける | 上限なしから、月数日まで幅がある |
| **端末** | 自治体が貸与する端末で、庁内システムに接続 | 貸与の台数に限りがあり、順番待ちの自治体もある |
| **勤務時間** | 通常の勤務時間と同じ。始業・終業を報告 | フレックスと組み合わせられる自治体もある |
| **手当** | 自治体による。国の在宅勤務等手当に準じた手当を設ける自治体もある | 手当なしの自治体も多い |

## 財政課でどこまで使えるか

| 業務 | テレワークとの相性 | 理由 |
|---|---|---|
| **予算の査定** | 部分的に可 | 要求書の読込みと分析は在宅で可。各課との協議、内示、決裁は庁内 |
| **決算統計・健全化判断比率** | 可 | データの作業が中心。ただし財務会計システムへの接続の可否による |
| **起債の協議の資料** | 可 | 資料の作成は在宅で可。協議そのものは庁内または出張 |
| **議会の対応** | 不可 | 議会の会期中は庁内 |
| **資料の作成・分析** | 可 | 端末とデータの持出しの範囲による |
| **紙の決裁** | 不可 | 電子決裁の導入の程度による |

**財政課は、資料の作成と分析の業務でテレワークが使え、協議・決裁・議会の業務では使えない**という構造です。電子決裁と財務会計システムの庁外からの接続が進んでいる自治体ほど、使える範囲が広がります。**繁忙期（予算編成、議会）はほぼ出勤、閑散期は週1〜2日の在宅**という形が、財政課での現実的な使い方です。

## 職務専念義務と守秘義務——在宅でも同じ

| 規定 | 在宅勤務での意味 |
|---|---|
| **第35条**（職務に専念する義務） | 在宅でも勤務時間中は職務に専念する。**家事、私用、転職活動を勤務時間中に行えば違反** |
| **第34条**（秘密を守る義務） | 在宅で扱う資料・データに含まれる秘密を、家族を含めて漏らさない。**画面を家族に見せない、資料を印刷しない** |
| **個人情報保護法第67条** | 業務で扱う個人情報を、みだりに他人に知らせない。在宅で扱う個人情報の範囲は規程で制限されることが多い |
| **情報セキュリティの規程** | 貸与された端末以外を使わない、私用のクラウドに保存しない、公衆無線LANを使わない |

**在宅勤務中に転職活動をすることは、第35条の職務専念義務の違反**です。勤務時間中は職務に、転職活動は勤務時間外に、という線は、在宅でも出勤でも同じです（[職務専念義務と転職活動](seido-fukumu-sennen.html)）。

## 転職先の在宅勤務との比較

| 項目 | 自治体 | 民間 |
|---|---|---|
| **根拠** | 自治体の規程 | 就業規則、労使の合意 |
| **日数** | 上限を設ける自治体が多い（週1〜2日など） | 企業による。フルリモートから出社が原則まで幅がある |
| **業務の制約** | 庁内システム、紙の決裁、窓口、議会 | 企業のシステムの整備の程度による。クラウドが中心なら制約は小さい |
| **端末・環境** | 貸与の端末。台数に限りがあることも | 貸与が一般的。通信費の補助があることも |
| **手当** | 自治体による | 在宅勤務手当を設ける企業がある |
| **確かめること** | 規程の有無、対象、日数、端末、部署での運用 | **就業規則の定め、配属部署の実態（週何日出社か）、出社の日数の変更の可能性、通信費・手当** |

**転職先の「在宅勤務可」は、配属される部署の実態と、会社の方針の変更の可能性で判断してください。**入社後に出社の日数が増える企業もあります。

:::insight
面談で伺うと、**「役所は在宅ができないから」と転職を考えている方が、自分の自治体にテレワークの規程があり、財政課でも閑散期は使えることを知らなかった**というケースがあります。規程はあっても、課の慣行で誰も使っていないため、制度がないと思い込んでいました。逆に、**転職先の「在宅勤務可」を信じて入社したら、配属部署では週4日出社が慣行で、しかも入社後に会社の方針で出社が原則に戻った**という方もいます。ここで1つ提案があります。**「在宅ができないから」が転職の理由なら、まず自分の自治体の規程と、自分の課での運用を確かめ、次に転職先の配属部署の実態と、方針の変更の可能性を聞いてください。**財政課の業務のうち、資料の作成と分析は在宅で可能で、繁忙期以外なら週1〜2日は現実的です。**それでも足りないなら、転職先の実態を確かめたうえで判断する。**制度の名前ではなく、実際に週何日家で働けるかで比べてください。
:::

## 転職するとどうなるか

転職を考えている方にとって、テレワークで効いてくる点は3つです。

**1. 自治体の規程と、自分の課の運用を確かめる**

**規程があっても課の慣行で使われていないことがあります。**財政課でも閑散期は使えます。

**2. 転職先は、配属部署の実態と方針の変更の可能性で判断**

**「在宅勤務可」の一言では分かりません。**週何日出社か、今後変わる可能性があるかを聞いてください。

**3. 在宅でも職務専念義務と守秘義務は同じ**

**在宅勤務中の転職活動は第35条の違反**です。転職活動は勤務時間外に。

## 手続きと期限

| 順序 | すること | 時期 | 場所 |
|---|---|---|---|
| 働き方に不満を感じたら | 自治体のテレワークの規程の有無、対象、日数、端末を確かめる | 最初に | 人事の担当課、規程 |
| 規程があれば | 自分の課での運用を所属に確かめ、閑散期に申請する | 閑散期 | 所属 |
| 在宅勤務中 | 職務専念義務、守秘義務、情報セキュリティの規程を守る | 継続 | ── |
| 転職を考えたら | 転職先の就業規則の在宅勤務の定め、配属部署の実態、方針の変更の可能性、手当を聞く | 内定の段階 | 転職先 |
| 入社後 | 在宅勤務の日数の実績を自分でも記録する | 継続 | ── |

## 誤解されやすい点

**「自治体にはテレワークの制度がない」と思い込む**

**自治体の規程によります。**規程はあるが課で使われていない、という状態もあります。

**「財政課の業務は在宅でできない」と思い込む**

**資料の作成と分析は在宅で可能**です。協議・決裁・議会は庁内で、繁忙期は出勤が中心になります。

**「在宅勤務中なら少しくらい私用をしてもよい」と思い込む**

**職務専念義務は在宅でも同じ**です（第35条）。

**「転職先の『在宅勤務可』は永続する」と思い込む**

**会社の方針で変わることがあります。**配属部署の実態と変更の可能性を聞いてください。

:::insight
ここまでテレワークの話を書いておいて逆のことを言いますが、**在宅で働けるかどうかは、転職の判断を左右するほどの要素ではないことが多いです。**財政課の繁忙期は出勤が要り、転職先の在宅の日数も方針で変わります。それでも1本の記事にしたのは、**「在宅ができないから」という理由が、自治体の規程の確認も転職先の実態の確認もないまま、転職の理由になっているのを面談で見る**からです。両方を確かめれば、理由が消えるか、根拠のある理由に変わります。そのうえで、**自分の経験に値を付けてくれる業界の見込みと、同じ紙に並べてください。**片方だけでは比較になりません。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 自治体のテレワークは、**法律ではなく各自治体の規程（要綱、規則）で定められ**、対象の職員・業務、日数、端末、手当が自治体ごとに違います
- 国には**在宅勤務等手当（給与法第12条の3、月額3,000円）**があり、1か月当たり平均10日を超えて在宅勤務を命ぜられた職員が対象です。自治体は手当の有無が分かれます
- 財政課では、**資料の作成と分析は在宅で可能、協議・決裁・議会は庁内**という構造で、閑散期に週1〜2日が現実的な使い方です
- **在宅でも職務専念義務（第35条）と守秘義務（第34条）は同じ**で、在宅勤務中の転職活動は職務専念義務の違反です
- 転職先の在宅勤務は、**就業規則の定め、配属部署の実態、方針の変更の可能性、手当**で判断してください
- **「在宅ができないから転職」は、自治体の規程と課の運用、転職先の実態の両方を確かめてから**

## よくある質問

### 私の自治体にテレワークの制度があるか、どう確かめればよいですか

**例規集や庁内の規程で「テレワーク」「在宅勤務」を検索するか、人事の担当課に聞いてください。**テレワークは勤務場所の指定の問題なので、条例ではなく、任命権者の要綱や規則（「テレワーク勤務実施要綱」「在宅勤務に関する規程」など）で定められていることが多く、例規集に載っていない場合もあります。人事の担当課に「テレワークの制度があるか、対象の職員と業務、日数の上限、端末の貸与はどうなっているか」を聞くのが最も確実で、転職の意思を伝える必要はありません。制度があっても、自分の課で運用されているかは別なので、所属にも確かめてください。財政課で誰も使っていない場合、最初に申請する人になることをためらう方が多いですが、規程に基づく申請は正当な手続きで、閑散期の資料の作成の業務なら承認されやすいです。制度がない自治体では、フレックスや時差出勤（[フレックスタイム・時差出勤](seido-kyuka-flex.html)）が、働き方の融通を得る別の道になります。

### 在宅勤務の日に、昼休みに転職先とオンライン面接をしてよいですか

**昼休みは勤務時間外なので、職務専念義務の直接の対象ではありませんが、貸与された端末や自治体のネットワークを使わないこと、勤務時間に食い込まないことが線です。**在宅勤務中も、勤務時間中は第35条の職務専念義務が及び、面接が勤務時間に食い込めば違反です。昼休みは勤務時間外なので、私用の端末で、私用の回線を使い、昼休みの時間内に終える形なら、法律上の問題は生じにくいです。ただし、貸与された端末や自治体のネットワークを転職活動に使うことは、情報セキュリティの規程に反し、公用の機器の私用として問題になります。また、在宅勤務の日に面接を入れることが習慣になると、在宅勤務を転職活動のために使っているとの疑いを招き、在宅勤務の承認や職場の信頼に影響します。面接は年次有給休暇を取って行うのが最も安全で、在宅勤務の日の昼休みに行う場合も、私用の端末と回線で、時間内に、が最低限の線です（[職務専念義務と転職活動](seido-fukumu-sennen.html)）。

### 転職先の在宅勤務の実態は、どう確かめればよいですか

**就業規則の定め、配属される部署の実態（週何日出社か）、会社の方針の変更の可能性、通信費や手当の4つを、内定の段階で聞いてください。**民間の在宅勤務は法律の制度ではなく、就業規則と労使の合意によるので、企業ごとに、フルリモートから出社が原則まで幅があります。求人票の「在宅勤務可」「ハイブリッド勤務」は、会社全体の制度を示しているだけで、配属される部署の実態は別です。「配属予定の部署では、週に何日出社している方が多いですか」「在宅勤務の方針は、この1〜2年で変わりましたか」と聞くのが、条件の確認として自然です。この数年で、在宅勤務の日数を減らして出社を原則に戻した企業が少なくないので、方針の変更の可能性は特に確かめてください。在宅勤務の端末の貸与、通信費の補助、在宅勤務手当の有無も、手取りと環境に効きます。公務員の在宅勤務は貸与の端末と庁内システムへの接続が前提ですが、民間ではクラウドのシステムが中心で、業務の制約は小さいことが多い一方、労働時間の管理を自分で担う場面が増えます。
