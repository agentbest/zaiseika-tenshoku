育児休業中の給与を確認するときは、毎月の給与、期末・勤勉手当、復帰後の号俸の調整を分けます。休業期間の給与が支給されないことから、賞与も必ずゼロ、復帰後も号俸が固定される、と一括りにはできません。

本記事は2026年11月時点の公開情報にもとづきます。主に国の一般職の規定を根拠に、支給対象の判定と計算の順序を整理します。本人の額や日程は給与担当へ、地方と非常勤の扱いは本人に適用する条例・規則等で確認してください。年収の見通しを一律に計算する記事ではありません。

## 毎月の給与と手当金、賞与、号俸は別に確認する

国の育児休業法第5条、地方の同法第4条は、休業中も身分や職を保有しながら職務に従事せず、その期間の給与を支給しない仕組みを定めています。

一方、国の同法第8条は、所定の勤務した期間等がある場合の期末・勤勉手当を定めています。地方の同法第7条も、国の扱いを基準として定める条例により支給できる仕組みです。毎月の給与と同じ結論をそのまま当てはめません。

| 確認する項目 | 切り分けること |
| --- | --- |
| 毎月の給与 | 休業した期間と勤務した期間 |
| 共済等の手当金 | 給与とは別の給付要件と請求 |
| 期末・勤勉手当 | 対象条件、算定期間、除算等 |
| 復帰後の号俸 | 適用する調整制度と調整日 |

月の途中で休業や復帰をする場合も、月全体を無給と決めず、給与担当の計算と対象期間を確認します。共済の手当金の振込があることと、給与の処理が完了したことも別です。

制度の給付面は[育児休業手当金](seido-kyosai-ikuji-teate.html)で整理しています。本記事では、職場が計算する賞与と号俸を中心に確認します。

## 基準日に育休中でも所定の対象条件を確認する

国の給与法第19条の4・第19条の7は、期末・勤勉手当について6月1日と12月1日の基準日を定めています。基準日の在職等の扱いと、育休中の職員の特例を合わせて読む必要があります。

国の育休法第8条は、基準日に育休中でも、基準日以前6か月以内に勤務した期間がある職員等への支給を定めています。ただし、期末手当には規則で定める勤務に相当する期間の扱いがあり、勤勉手当と同じ文言ではありません。

規則19-0第15条は、期末手当について所定の休暇等を勤務に相当する期間として扱う一方、除く期間も定めています。本人が実際に登庁した日だけを数えて、両方の支給対象を判断しないでください。

基準日に在職するから必ず満額、休業中だから必ず不支給、という二つの理解はいずれも適切ではありません。まず対象条件を確認し、その後に額を計算するための在職・勤務期間へ進みます。

例えば、仮に基準日より前に勤務し、その後育休へ入った場合は、勤務した日と休業した期間を給与担当へ示します。この仮例だけで支給割合が決まるものではなく、本人の記録と適用規程で確認します。

## 期末は半分、勤勉は全期間を除く原則と例外を読む

国の規則9-40第5条は、期末手当の在職期間の算定で、所定の例外を除く育休期間の2分の1を除算すると定めています。第11条は、勤勉手当の勤務期間から、同じく所定の例外を除いた育休期間を除算します。

ここで除算するのは、手当の計算に使う期間です。「育休を取ると最終的な賞与額がいつも半額」という意味ではありません。休業の日数、他の在職・勤務期間、適用する割合等を合わせて確認します。

| 国の算定の区分 | 育休期間の原則の扱い |
| --- | --- |
| 期末手当の在職期間 | 育休期間の2分の1を除算 |
| 勤勉手当の勤務期間 | 育休期間を除算 |
| 所定の短期育休 | 期間の条件を満たす場合は上記除算から除く |

勤勉手当には人事評価等の別の要素もあります。期間の除算をしない場合であっても、他の職員と最終額が必ず同じになるという保証ではありません。

## 1か月以下の例外は区分ごとの承認期間を合算する

規則9-40第5条第2項第2号は、除算から除く育休を二つに分けています。一つは承認期間の全部が出生の日から所定の57日間以内にある育休、もう一つはそれ以外の育休です。

それぞれの区分で、承認期間が複数ある場合は合算し、1か月以下かを確認します。一回の申請が短ければ何度取っても除算されない、という読み方はしません。

また、基準日前6か月のうち実際に重なった部分だけを取り出して1か月以下と決めるのではなく、条文が見る承認期間の範囲を担当へ確認してください。通知の初日・末日と分割履歴が必要になります。

出生直後の育休を延長して所定の期間を超える場合も、承認期間全体の条件を照合します。共済の掛金免除の1か月や日数の条件とは、判定する制度が別です。

:::insight
賞与の説明を受けるときは、支給額だけでなく、対象となるかの判定と算定に使う期間を分けて尋ねることを勧めます。期末と勤勉では、勤務に相当する期間や除算の扱いが異なるためです。本人用の表に、基準日、勤務した期間、育休の承認期間、分割と変更の履歴を並べれば、担当の説明を具体的に照合できます。未確認の短期特例を前提に生活費を見込まず、通知と計算根拠を確認してから予定へ反映します。現職の制度を使って育児と仕事を続ける判断にも意味があります。賞与の一部分だけで仕事を変える結論へ進まず、本人が必要とする生活の予定と勤務条件を別々に整える順序がよいと考えます。
:::

外の仕事も調べたい場合は[公務員向け求人情報](../?gov=1)を確認できます。制度の確認と転職の結論を同時に決める必要はありません。

## 定期の昇給と復帰後の号俸調整を同じ処理にしない

国の育休法第9条は、復帰後の号俸について、部内の他の職員との均衡上必要と認められる範囲で調整できると定めています。これは休業中の毎年の昇給を、全員へ同じ号数で保証する条文ではありません。

規則19-0第16条は、育休期間を100分の100以下の換算率で換算して勤務したものとみなし、復帰日、復帰後の最初の昇給日又はその次の昇給日に、昇給に準じて号俸を調整できるとしています。

したがって、休業期間はすべて昇給上失われるとも、同年代と必ず同じ号俸へ一度で戻るとも断定できません。適用俸給表、休業前の号俸、対象期間、調整日、他の異動や制度改正等を給与担当に確認します。

人事院の復職時調整の運用通知にも、計算方法や期間の合算等の定めがあります。休業前後に給与制度の切替え等がある場合は、通知や給与明細の差だけを見て育休の影響と判断しないでください。

昇給と、職務の級等が変わる昇格・昇任も別の話です。号俸調整の規定を、役職や配置が自動的に元と同じになる保証へ広げないことが大切です。

## 地方と非常勤は本人の給与規程を確認する

地方の法律第7条は、国の基準を踏まえた条例による期末・勤勉手当の支給を定めています。国の規則の除算や例外を、そのまま地方の全員の計算式として使わず、所属条例と規則を確認します。

会計年度任用職員等は、対象となる任用、支給の要件、勤務時間・期間、報酬や給料の定め、再度の任用等も本人の通知で確認してください。常勤一般職と同じ昇給・復帰時調整の制度があるとは限りません。

国の非常勤についても、その職員に適用する給与等の定めを確認します。育休を取れることと、常勤向けの賞与・号俸の規則がすべて適用されることは別です。

転職を検討する場合、現在の勤務先での在職期間や号俸の調整が、新勤務先へそのまま移るわけではありません。転職先の給与制度と賞与対象期間を、入社日や任用終了日とは別に確認します。

## 本人用の確認表で計算と入金を照合する

給与担当へ尋ねる際は、休業の初日・末日、出生直後の区分、延長・分割の履歴、復帰日をそろえます。本人へ交付された通知や給与明細を使い、庁内の給与資料を私的に持ち出して集めないでください。

確認項目は、期末と勤勉それぞれの対象条件、算定に使った期間、除算した期間と例外、号俸調整の対象期間と調整日です。理由が分からない差があれば、どの処理によるものかを担当へ照会します。回答を受けた日と、確認した規程名も本人用に残します。

計算が決まる時期と実際の支給時期も分けます。復帰月の明細ですべての調整を直ちに確認できると決めず、反映する給与月や後の精算の有無を聞いてください。

育休の延長や退職を検討する場合も、未確定の賞与や号俸を前提に日程を断定しません。本人の希望する勤務と生活の条件を整理し、必要な制度の回答をそろえて判断します。

働き方の情報整理を希望する場合は[相談フォーム](../apply.html)を利用できます。ご利用は無料です（紹介手数料は採用企業の負担）。給与明細や家族の資料を転職相談へ一式送る必要はありません。

:::insight
給与の比較では、今の月額と将来の見込みを一つの数字へまとめる前に、確定した処理と確認待ちの調整を分けることを勧めます。育休中の無給、賞与の対象期間、復帰後の号俸は、別の規定と日程で動くためです。現職の担当へ根拠を確認しておけば、外の条件を調べる場合も比較項目をそろえられます。転職先の賞与や昇給の説明も、本人の入社日と適用条件で確かめ、同じ名称だから同じ結果になるとは考えません。現職へ復帰して続けることにも、必要な情報がそろうまで判断を保留することにも理があります。育休による一時的な入金の違いを不安の材料にせず、本人が望む働き方を考えるための条件を整える姿勢を大切にします。
:::

## よくある質問

### 育休中は賞与が必ずゼロですか

国では基準日以前の勤務した期間等による支給の規定があります。対象条件と、実際の額の算定を分けて給与担当へ確認します。

### 一回の育休が1か月以内なら除算されませんか

国の例外は所定の区分ごとに複数の承認期間を合算します。一回の長さだけでなく、期間全体と履歴を照合します。

### 復帰すれば育休前の号俸のままですか

国には所定の復帰後の号俸調整があります。適用条件、換算と調整日を確認し、地方や非常勤は本人の規程で確認してください。

情報収集だけの相談には[LINE](https://line.me/R/ti/p/@697nxhbt)も利用できます。現職を続ける判断を含め、本人の希望する範囲で整理できます。
