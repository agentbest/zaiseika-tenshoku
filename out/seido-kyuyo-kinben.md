公務員のいわゆるボーナスは、**期末手当**と**勤勉手当**の2つでできています。期末手当が「基準日に在職していること」を軸に決まるのに対し、勤勉手当は**人事評価の結果と勤務の状況**で額が変わる手当です。同じ職場で同じ級にいても、勤勉手当の額は人によって違うことがあります。

この記事では、**勤勉手当の根拠、国の条文での額の決まり方、期間率と成績率、人事評価との結びつき、転職したときの見方**を整理します。期末手当の基準日・支給日・在職期間の割合は[期末手当の記事](seido-kyuyo-kimatsu.html)にまとめているので、ここでは繰り返しません。

地方公務員の勤勉手当は、各自治体が条例と規則で割合や評価の反映方法を定めます。この記事では特定の自治体の割合を示しません。自分の扱いは、所属の給与条例・規則と人事担当課で確かめてください。本記事は2026年11月時点の公開情報にもとづきます。

## 勤勉手当の根拠——地方自治法と地方公務員法

地方自治法第204条第2項は、条例で支給できる手当の1つとして**勤勉手当**を挙げています。期末手当とは別の手当として並んでおり、同条第3項で額と支給方法は条例で定めることとされています。

人事評価との結びつきは、地方公務員法に書かれています。

| 条文 | 内容 |
|---|---|
| 第23条第2項 | 任命権者は、人事評価を任用、**給与**、分限その他の人事管理の基礎として活用する |
| 第23条の2第1項 | 任命権者は、職員の執務について定期的に人事評価を行う |
| 第23条の2第2項 | 人事評価の基準と方法は任命権者が定める |
| 第23条の3 | 任命権者は、人事評価の結果に応じた措置を講じなければならない |

人事評価の結果を給与にどう反映するかは、法律が細かく決めているわけではありません。勤勉手当や昇給への反映は、各自治体の条例・規則で具体化されます。昇給との関係は[昇給の仕組み](seido-kyuyo-shokyu.html)に書いています。

## 国の勤勉手当——給与法第19条の7

国家公務員の勤勉手当は、給与法第19条の7に定められています。第1項は、勤勉手当を**6月1日と12月1日の基準日に在職する職員**に対し、**基準日以前における直近の人事評価の結果**と**基準日以前6か月以内の期間における勤務の状況**に応じて支給するとしています。

期末手当の条文（第19条の4）と比べると、違いは次のとおりです。

| 項目 | 期末手当 | 勤勉手当 |
|---|---|---|
| 額を左右するもの | 在職期間 | **人事評価の結果**と勤務の状況 |
| 割合の決め方 | 条文で一律に定める | **各庁の長が人事院規則の基準に従って定める** |
| 基礎額に扶養手当 | 含む | **含まない**（第3項） |

第3項は、勤勉手当基礎額を、基準日現在の**俸給と専門スタッフ職調整手当の月額、これらに対する地域手当などの月額の合計**としています。期末手当と違い、扶養手当は基礎額に入りません。役職に応じた加算は、期末手当と同じ仕組みが準用されます（第4項）。

## 額の決まり方——期間率×成績率

第19条の7第2項は、勤勉手当の額を**勤勉手当基礎額×各庁の長が定める割合**としています。その割合は、人事院規則9-40第9条で次の掛け算とされています。

**期間率（勤務期間による割合）× 成績率（勤務成績による割合）**

### 期間率は15日刻み

期間率は、基準日以前6か月以内の勤務期間に応じて別表第二で定められています（第10条）。期末手当の在職期間の割合が4段階なのに対し、勤勉手当は細かく刻まれています。

| 勤務期間 | 期間率 |
|---|---|
| 6か月 | 100分の100 |
| 5か月15日以上6か月未満 | 100分の95 |
| 5か月以上5か月15日未満 | 100分の90 |
| 4か月15日以上5か月未満 | 100分の80 |
| 4か月以上4か月15日未満 | 100分の70 |
| 3か月15日以上4か月未満 | 100分の60 |
| 3か月以上3か月15日未満 | 100分の50 |
| 3か月未満 | 段階的に下がり、15日未満は100分の5 |

### 成績率は人事評価の段階で決まる

成績率は、第13条で、**直近の業績評価の全体評語**に応じた範囲の中で各庁の長が定めるとされています。行政職などの一般の職員（特定管理職員以外）の場合、条文は次のように区分しています。

| 区分 | 成績率 |
|---|---|
| 全体評語が「非常に優秀」以上で、勤務成績が特に優秀 | 100分の125.25以上100分の318.75以下 |
| 全体評語が「優良」以上で、勤務成績が優秀 | 100分の113.75以上100分の125.25未満 |
| 全体評語が「優良」以上で勤務成績が良好、「良好」、評価の結果がない職員 | 100分の102.25 |
| 全体評語が「やや不十分」以下、基準日以前6か月以内に懲戒処分を受けた職員など | 100分の93.75以下 |

特定管理職員には、それぞれ高めの範囲が別に定められています。上位の区分に何人を当てるかの基準となる割合は人事院が定めるとされています（第13条第5項）。また、所属ごとの勤勉手当の総額には上限があり、条文の割合で計算した額の総額を超えてはならないとされています（給与法第19条の7第2項後段）。上位の区分に厚く配れる額にも、所属全体の枠がある作りです。

いまの割合は人事院の勧告を受けた改正で見直されることがあります。数字は条文の現時点の値として読んでください。

## 勤務期間から除かれる期間——第11条

勤勉手当の勤務期間は、期末手当の在職期間より**除かれる範囲が広い**のが特徴です。人事院規則9-40第11条第2項は、たとえば次の期間を除算するとしています。

| 期間 | 扱い |
|---|---|
| 育児休業の期間（短期のものなどを除く） | 除算 |
| 休職の期間（公務上の災害による休職などを除く） | 除算 |
| 病気で勤務しなかった期間（公務上・通勤による負傷や疾病を除く） | 週休日などを除いて30日を超えると、その全期間を除算 |
| 介護休暇で勤務しなかった期間 | 週休日などを除いて30日を超えると、その全期間を除算 |
| 給与を減額された期間 | 除算 |

期末手当では育児休業の期間を2分の1だけ差し引く扱いですが、勤勉手当では除算の対象になります。休んだ後の最初の勤勉手当が期末手当より大きく下がるのは、この違いによるものです。自治体の除算の扱いは条例と規則で確かめてください。

## 転職するとどうなるか

**1. 退職の時期による扱いは期末手当と同じ形**

給与法第19条の7第1項後段は、基準日前1か月以内に退職した職員にも勤勉手当を支給するとしています。基準日と退職日の関係は期末手当と同じ形なので、[期末手当の記事](seido-kyuyo-kimatsu.html)で確かめてください。勤勉手当の場合は、それに加えて期間率と成績率が掛かります。

**2. 民間の賞与も評価で動くが、仕組みは会社ごと**

民間企業の賞与は、会社の賃金規程と業績、個人の評価で決まります。評価の段階と賞与の係数を公開している会社もあれば、業績連動の部分が大きい会社もあります。法律や規則で範囲が決まっている公務員の勤勉手当と違い、**係数の幅は会社によって大きく異なります。**内定の段階で、評価制度と賞与の算定方法を確かめてください。

**3. 人事評価の記録は、職務経歴書の材料になる**

業績評価で目標を立て、期末に振り返る流れは、民間の目標管理（MBO）や評価面談と近い作りです。どんな目標を立て、何を達成したかは、職務経歴書の実績欄にそのまま使えます。

どの経験に値が付くのかから相談できます。[相談の申込みはこちら](../apply.html)

:::insight
勤勉手当の仕組みを説明するとき、**業績評価の全体評語をそのまま面接で伝えようとする**方がいます。「優良でした」と言っても、民間の面接官には評価の基準も分布も分からないので、判断の材料になりません。民間の評価面談で見られているのは、期初に立てた目標が何で、それをどの数字や成果物で測り、どこまで届いたかです。自治体の業績評価でも、多くは期初に目標を書き、期末に自己評価と面談をしているはずです。その**目標シートの中身**のほうが、評語よりずっと伝わります。予算の執行管理なら「当初予算に対する執行率を月次で追い、補正の要否を判断した」のように、民間の言葉で言える形に直しておくと、面接で詰まりにくくなります。
:::

## 誤解されやすい点

**「勤勉手当は全員同じ割合」と思い込む**

国の条文では、成績率は直近の業績評価の全体評語に応じて区分されています（人事院規則9-40第13条）。多くの職員が当たる区分は1つの割合ですが、上位と下位の区分は範囲で定められています。

**「勤勉手当の基礎額にも扶養手当が入る」と思い込む**

国の勤勉手当基礎額は、俸給と地域手当などの合計で、扶養手当は含みません（給与法第19条の7第3項）。期末手当とは基礎額の範囲が違います。

**「育児休業の扱いは期末手当と同じ」と思い込む**

期末手当では育児休業の期間を2分の1差し引きますが、勤勉手当では勤務期間から除算されます（同規則第11条第2項）。短期の育児休業などには例外があります。

**「評価が上がれば手当は青天井」と思い込む**

成績率には上限があり、所属ごとの総額にも上限があります（給与法第19条の7第2項後段）。

:::insight
「公務員のボーナスは年間◯か月分」という言い方をよく見かけますが、**勤勉手当の部分は、成績率と期間率で人によって変わります。**期末手当と勤勉手当をひとまとめにした月数を自分の数字だと思って転職先の賞与と比べると、ずれが出ます。比べるなら、**直近2年分の明細で期末手当と勤勉手当を分けて書き出す**のが確実です。そのうえで、勤勉手当が評価で安定して上位に入っている方は、評価の仕組みが変わる転職で、初年度は標準の扱いに戻る可能性も考えておいてください。在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担）。
:::

## まとめ

- 勤勉手当は、地方自治法第204条第2項にもとづき**条例で支給できる手当**の1つ。期末手当とは別の手当
- 人事評価は給与の基礎として活用するとされている（地方公務員法第23条第2項、第23条の3）
- 国では、**基準日以前の直近の人事評価の結果と、6か月以内の勤務の状況**に応じて支給する（給与法第19条の7第1項）
- 額は**勤勉手当基礎額×期間率×成績率**（同条第2項、人事院規則9-40第9条）。基礎額に扶養手当は入らない
- 期間率は15日刻み（別表第二）。成績率は**業績評価の全体評語の段階**で区分される（第13条）
- 育児休業や30日を超える病気休暇などは、勤務期間から除かれる（第11条）

## よくある質問

### 病気休暇を取ると、勤勉手当は減りますか

**国では、病気で勤務しなかった期間が一定を超えると、期間率が下がります。**人事院規則9-40第11条第2項第9号は、公務上・通勤による負傷や疾病を除き、病気で勤務しなかった期間から週休日などを除いた日が30日を超える場合に、その全期間を勤務期間から除算するとしています。勤務期間が短くなると、別表第二の期間率が下がります。30日以内であれば、この号による除算はありません。自治体の扱いは規則で定められているので、人事担当課で確かめてください。

### 採用1年目で人事評価の結果がまだない場合はどうなりますか

**国では、評価の結果がない職員は、標準の区分の成績率になります。**人事院規則9-40第13条第1項第1号ハは、基準日以前における直近の人事評価の結果がない職員を、全体評語が「良好」の職員と同じ区分とし、成績率を100分の102.25（特定管理職員以外の一般の職員の場合）としています。あわせて、採用からの勤務期間に応じた期間率が掛かります。自治体の扱いは条例と規則で確かめてください。

### 勤勉手当にも税金や共済の掛金はかかりますか

**一般的には、勤勉手当も給与として所得税の源泉徴収の対象になり、共済の掛金もかかります。**期末手当と同じく、賞与として税額を計算するのが一般的な取扱いです。共済組合の掛金も、期末・勤勉手当の額にもとづいて計算されます。具体的な額は扶養の状況や前月の給与で変わるので、明細と所属の共済組合、税務署の案内で確かめてください。転職した年の年末調整は転職先で行うのが一般的で、手続きは[年末調整は誰がやるか](seido-zei-nenmatsu.html)にまとめています。
