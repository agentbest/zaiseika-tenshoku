**広報や広聴を担当してきた方から、「民間のマーケティングとは違うのでは」**というご相談を伺います。

**動作は、重なる部分が多い**です。

この記事では、**接続の仕方**と、**書き方**を扱います。

## 意見を集める仕組みは、法律に置かれています

**行政手続法第39条第1項**です。

> **命令等制定機関は、命令等を定めようとする場合には、当該命令等の案**（略）**及びこれに関連する資料をあらかじめ公示し、意見**（略）**の提出先及び意見の提出のための期間**（略）**を定めて広く一般の意見を求めなければならない。**

**同条第2項**です。

> 前項の規定により公示する命令等の案は、**具体的かつ明確な内容のもの**であって、かつ、当該命令等の題名及び当該命令等を定める根拠となる法令の条項が明示されたものでなければならない。

**同条第3項**です。

> 第一項の規定により定める意見提出期間は、**同項の公示の日から起算して三十日以上**でなければならない。

**案を示し、期間を定めて意見を集め、それを踏まえて決める。**

**この流れが、条文として定められています。**

**自治体でも、同様の手続が条例や要綱で定められている**ことがあります。

**つまり、「相手の声を集めて、設計に反映する」という動作を、制度として経験している**ということです。

## マーケティングの動作との対応

| マーケティングの動作 | 広報広聴での経験 |
|---|---|
| ① 対象を定める | **誰に届けるかを決める** |
| ② 調査する | アンケート、意見の募集、相談の内容 |
| ③ 課題を絞る | 意見の分類、傾向の把握 |
| ④ 伝え方を設計する | 媒体、文面、時期 |
| ⑤ 届ける | 広報紙、ウェブ、説明会、報道 |
| ⑥ 効果を測る | 反応、申請の件数、問い合わせの数 |
| ⑦ 次に反映する | 翌年度の事業への反映 |

**②と⑥が、行政ならではの厚み**があります。

**②について。**

**意見の募集、アンケート、窓口での相談、議会での質問。**

**複数の経路から声が集まる仕組み**があります。

**⑥について。**

**申請の件数や、問い合わせの数は、そのまま反応の指標**になります。

## 書き方の例

**悪い例**

> 広報紙の編集と、ホームページの更新を担当しました。

**良い例**

> ◯◯に関する制度の周知について、**対象を◯◯層に絞り、**広報紙・ウェブ・説明会の**媒体ごとに文面と時期を設計。****意見の募集で寄せられた◯件の意見を分類し、説明の順序と用語を修正。**周知の後、**申請の件数が前年同期比で約◯割増加。**

**「対象」「設計」「反映」「結果」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 言い換えの対応

| 行政の言葉 | 民間での読まれ方 |
|---|---|
| 広報紙の編集 | **コンテンツの企画・制作** |
| 対象者への周知 | ターゲットへの告知 |
| 意見の募集 | 顧客の声の収集 |
| 相談の内容の分析 | 課題の抽出 |
| 説明会の運営 | イベントの企画・運営 |
| 報道への対応 | 広報、対外の発信 |
| 申請の件数の推移 | **効果の測定** |

**7行目です。**

**「何をしたら、件数がどう動いたか」を説明できる**と、効果の測定の経験として読まれます。

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 自治体向けの事業 | **行政の周知の仕組みが分かる** |
| ② 広報・広報の支援 | 媒体の設計、文面 |
| ③ 事業の企画 | 対象の設定、効果の測定 |
| ④ 調査・分析 | 意見の分類、傾向の把握 |
| ⑤ 地域に関する事業 | 住民への届け方 |

**①について。**

**自治体向けの事業では、「どうすれば住民に届くか」を知っている人**が求められます。

**広報紙の配布の仕組み、回覧の流れ、説明会の運び方、報道の扱い。**

**外から入った人には見えにくい**ものです。

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

:::insight
広報広聴の経験について、**面談でお伝えしているのが「届かなかった経験を書いてください」**という点です。多くの方が、**「広報紙を◯回発行」「ウェブを更新」と、実施した事実を書かれます。**ところが、**マーケティングで問われているのは、届いたかどうか**です。そして、**行政の周知では、届かない経験を数多くしているはずです。**対象が高齢の方なのにウェブだけで告知した、申請の期限の直前に出した、用語が専門的で伝わらなかった。**これらを踏まえて、翌年に変えた**という経験があるなら、それが書くべき内容です。**「前年は申請が伸びなかったため、周知の媒体を◯◯に変更し、文面を平易にしたうえで時期を◯か月前倒し。結果、件数が約◯割増加」**という形です。**失敗と、その後の修正**が入っていると、**考え方が伝わります。**実施した回数だけでは、伝わりません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 誰に届けたかったか | **対象の設定の考え方** |
| どう測ったか | 件数、反応、問い合わせ |
| うまくいかなかった例 | 3件、原因と修正 |
| 媒体の選び方 | 対象と媒体の対応 |
| 数字の扱い | 前年比、推移 |

**3行目です。**

**うまくいかなかった例を聞かれる**ことがあります。

**原因と、その後の修正**を用意しておいてください。

**なお、特定の事案が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

## 学ぶ前に考えること

| 確認すること | 内容 |
|---|---|
| ① すでにある経験 | **周知、意見の募集、効果の確認** |
| ② 応募したい求人の条件 | 経験の指定があるか |
| ③ 目的 | 広報に進むのか、事業の企画か |
| ④ 期限 | 応募の時期までに間に合うか |

**①を先に整理してください。**

**広報広聴の経験があるなら、その整理が学習より先**です。

**なお、資格や講座を受ければ転職できる、という関係にはありません。**

**対象を定め、届け、測り、直した経験**が、評価の対象です。

[経験の言い換えから相談する](../apply.html)こともできます。

## 実績が小さい場合

| やること | 内容 |
|---|---|
| 数字を拾う | **申請の件数、閲覧の数、参加の人数** |
| 前年と比べる | 変化の有無 |
| 変えた点を書き出す | 媒体、文面、時期 |
| つなげる | 変えた点と、変化の関係 |

**1行目です。**

**担当した事業の件数は、記録が残っている**ことが多いものです。

**年度の報告や統計の資料から確認**してください。

**根拠のない数は書かないでください。**

## よくある失敗

**1. 実施した回数だけを書く**

**届いたかどうか**が問われます。

**2. 対象の設定に触れない**

**誰に届けたかったか**が中心です。

**3. 効果を測っていない**

**件数の推移**で示せます。

**4. うまくいかなかった例を用意しない**

**面接で聞かれます。**

**5. 媒体の選び方を書かない**

**対象と媒体の対応**が設計です。

**6. 意見の募集の経験を書かない**

**顧客の声の収集**にあたります。

**7. 根拠のない数字を書く**

**記録から確認**してください。

**8. 講座を受ければ進めると考える**

**定め・届け・測り・直した経験**が評価の対象です。

:::insight
ここまで接続の話をしておいて逆のことを言いますが、**行政の広報と民間のマーケティングには、目的の違いがあります。**面談で拝見していると、**この違いを踏まえずに書いて、かみ合わない**ことがあります。行政の周知は、**必要な人に、漏れなく届けること**が目的です。一方、民間のマーケティングは、**買ってもらうこと**が目的になります。**「全員に届ける」と「買う人に届ける」は、設計が違います。**ですから、面接では、**この違いを理解していることを示してください。**「行政では、対象者全員に届けることが求められるため、媒体を複数使い、期限を長く取りました。民間では、反応する層に絞る設計が必要だと理解しています」。**この一言があると、考え方が伝わります。**そして、**漏れなく届ける設計を経験している**ことは、**公共性の高い事業では強み**になります。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **行政手続法第39条**は、**命令等の案を公示し、提出先と期間を定めて広く一般の意見を求める**こと、**期間は公示の日から30日以上**であることを定めています
- **「相手の声を集めて、設計に反映する」動作を、制度として経験しています**
- マーケティングの動作は、**①対象 ②調査 ③課題 ④設計 ⑤届ける ⑥測る ⑦反映**です
- **実施した回数ではなく、届いたかどうか**を書いてください
- **届かなかった経験と、その後の修正**が、考え方を伝えます
- **申請の件数の推移**は、効果の測定として読まれます
- **行政の「漏れなく届ける」と民間の「反応する層に届ける」の違い**を理解していると示してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 広報の担当ではありませんでしたが、書けますか

**書けます。**事業の担当として、**制度の周知、説明会の運営、案内の作成**を行っていれば、該当します。書き方は、**「◯◯制度について、対象者約◯件への案内の作成と発送を担当。窓口での説明の手順を整備し、問い合わせの内容を分類して案内の文面を修正」**という形です。**対象、手段、修正**が入っていれば伝わります。なお、**申請の件数の推移**が分かるなら、併せて書いてください。**「周知の方法を変えた結果、件数がどう動いたか」**は、担当の事業でも説明できます。

### 数字が残っておらず、効果を示せません

**残っている数字から探してください。**申請や届出の件数、説明会の参加の人数、問い合わせの件数、広報紙の発行の部数。**これらは、年度の報告や統計の資料に残っている**ことが多いものです。**担当課に照会して確認**できます。なお、**数字がどうしても確認できない場合は、書かないでください。**代わりに、**設計の考え方**を書いてください。「対象を◯◯層と想定し、媒体を◯つに分けて周知」という形です。**根拠のない数字を書くより、設計の説明のほうが確実**です。

### 民間のマーケティングの知識は、どこから学べばよいですか

**目的で分けてください。**応募先を理解するためであれば、**求人票と採用のページを読む**ところから始めて差し支えありません。「誰に、何を、どう売っている会社か」が分かれば足ります。一方、**業務として担うのであれば、体系的な学習が役立ちます。**ただし、**応募の時期が近い場合は優先順位を下げて**ください。**職務経歴書の作成と、求人を読む作業**のほうが、時期に直接効きます。扱いは[選考スケジュールの組み方](senko-sagasu-schedule.html)に整理しています。**学ぶこと自体は、入社後にも続けられます。**
