企画課の働き方について、先に言えることがあります。

**繁忙の山が、議会の日程で決まります。**

財政課のように法定の期限が直接かかる部署ではありませんが、企画課の成果物は最後に議会を通ります。だから議会の会期が、そのまま仕事の締切になります。

この記事では、その構造を条文から確認したうえで、評価のされ方と、民間に移ったあとに何が変わるかを扱います。

言い換えは[企画課・政策企画の経験は民間で何と呼ばれるか](dept-kikaku-honyaku.html)、行き先は[企画課・政策企画からの転職先](dept-kikaku-tenshokusaki.html)、書類と面接は[職務経歴書](dept-kikaku-shokumu.html)と[面接](dept-kikaku-mensetsu.html)に分けています。

## 議会が議決しなければならないものは、法律で決まっています

地方自治法第96条第1項は、**普通地方公共団体の議会は、次に掲げる事件を議決しなければならない**として、事項を列挙しています。冒頭はこうです。

1. **条例を設け又は改廃すること**
2. **予算を定めること**
3. **決算を認定すること**
4. 法律又はこれに基づく政令に規定するものを除くほか、**地方税の賦課徴収**又は分担金、使用料、加入金若しくは手数料の徴収に関すること
5. その種類及び金額について政令で定める基準に従い**条例で定める契約を締結すること**

以下、財産の処分、不動産の信託、負担付きの寄附の受入れ、権利の放棄、公の施設の長期かつ独占的な利用、訴えの提起や和解などが続きます。

企画課の仕事に引きつけて読むと、こうなります。

**条例の改正が要るものは、必ず議会を通る。**

組織機構の見直しは、部や課の設置を条例で定めている自治体では条例改正になります。使用料や手数料の見直しも議決事件です。そして自治体によっては、**総合計画の基本構想を条例で議決事件にしている**ところがあります。

つまり企画課の成果物の多くは、**「作って終わり」ではなく「議会で議決されて初めて確定する」**という構造を持っています。

## 企画課の一年

自治体によって時期は違いますが、おおむね次の形になります。

| 時期 | 主な仕事 |
|---|---|
| 4〜5月 | 前年度の実績の集計、進捗管理の取りまとめ |
| 6月 | **議会（第1の山）**。報告・議案の対応 |
| 6〜8月 | 行政評価、事務事業の点検、次年度の重点の整理 |
| 8〜9月 | **予算編成方針への反映**。財政課との協議 |
| 9月 | **議会（第2の山）**。決算審査への対応 |
| 10〜12月 | 計画の改定作業、審議会、パブリックコメント |
| 12月 | **議会（第3の山）** |
| 1〜3月 | 計画の確定、組織機構の議案、**議会（最大の山）** |
| 通年 | 庁議の運営、交付金の情報収集、他団体との協議 |

**議会のたびに山が来ます。**そして3月議会がいちばん重くなります。当初予算、条例改正、組織機構の議案が重なるためです。

これに加えて、**計画の改定年度**が数年おきに来ます。改定年度は審議会とパブリックコメントが入るので、通年で負荷が上がります。

**財政課のように締切が法律で固定されているわけではありませんが、議会の会期という動かせない枠に合わせて逆算する点は同じ**です。

## 転職活動の時期を、この波から逆算する

面接は平日日中に入ることが多く、1社で複数回あります。**議会の会期中と、その直前は避けたほうが無難**です。

比較的まとまった時間を作りやすいのは、**6月議会が終わってから8月まで**、または**9月議会が終わってから10月まで**です。

現実的な組み立てはこうなります。

1. 6月議会が終わったあたりで書類を作る
2. 7月から8月に2社ほど受けて、説明の詰まる場所を直す
3. 9月議会の期間は活動を止めるか、進んでいる1社だけに絞る
4. 10月から再開し、12月議会の前に区切りをつける

**計画の改定年度に当たっている場合は、改定が終わるまで待つ判断も十分に理があります。**改定を1回通すと、書ける材料が大きく増えるからです。

## 企画課の評価は、なぜ分かりにくいのか

企画課の成果は、**他の部署が動いた結果**として現れます。

事業課であれば、施設ができた、利用者が増えた、と言えます。企画課は、その事業を計画に位置づけ、予算がつくように整理し、進捗を追っただけです。**成果を出したのは事業課で、企画課はその手前を作っています。**

加えて、**うまくいかなかったときだけ名前が出る**という面もあります。計画が実行されない、指標が動かない、部署間の調整が進まない。こうしたときに企画課が問われます。

ここで大事なのは、この構造を**不満として語らないこと**です。転職の面接でこれを不満の形で出すと、次の職場でも同じことを言うと思われます。

**構造として説明してください。**「成果が他部署の実績として出る前提で、手前を整える仕事をしていた」と言えれば、それはそのまま経営企画の適性として読まれます。

## 庁内の言葉と、求人票の言葉

働き方に関わる部分を置き換えると、次のようになります。

| 庁内での言い方 | 求人票での言い方 |
|---|---|
| 議会日程から逆算した進行管理 | スケジュール管理、プロジェクト推進 |
| 庁議・幹部説明の資料作成 | 経営会議の事務局、役員向け資料の作成 |
| 審議会・パブリックコメントの運営 | ステークホルダー対応、外部委員会の運営 |
| 全庁からの照会と取りまとめ | 全社横断の調整、情報集約 |
| 計画の改定作業 | 中期経営計画の改定、計画管理 |
| 進捗管理と年次報告 | モニタリング、実績報告の作成 |

このうち、働き方として直接伝わるのは**「議会日程から逆算した進行管理」**と**「幹部説明の資料作成」**です。民間でも取締役会や経営会議は動かせない期限なので、そこを回してきた経験として説明すると通りやすくなります。

:::insight
企画課の方が民間に移って最初に戸惑うのは、**「決めてくれる場」が明確でなくなること**です。庁内では、庁議や部長会といった場が決まっていて、そこに諮れば結論が出ました。議会という最終的な決着の場もあります。民間の経営企画では、**会議体はあっても、そこで決まらずに持ち帰りになることが珍しくありません。**誰が決めるのかが案件ごとに違う、ということも起きます。**入る前に「この手の案件はどこで決まるのか」を面接で聞いておいてください。**経営会議で決まるのか、担当役員の判断なのか、事業部が持ち帰るのか。企画課の進め方は、決着の場が決まっている前提で組み立てられているので、ここを確認しておくと最初の数か月が楽になります。
:::

## 民間に移ると、何が変わるか

**1. 決着の場が変わる**

上に書いたとおりです。**どこで決まるのかを案件ごとに見極める**必要が出てきます。

**2. 計画の期間が短くなる**

総合計画は基本構想で10年前後、基本計画で5年程度です。民間の中期経営計画は3年が多く、年度ごとに見直す会社もあります。**長い期間で組み立てる習慣は、そのままでは合わない場面があります。**

**3. 成果の測り方が変わる**

行政評価の指標は、住民の状態や利用実績など、**動くまでに時間がかかるもの**が多くなります。民間では売上や利益といった月次で動く数字が中心です。**指標を設計する力は活きますが、周期が変わります。**

**4. 外部への説明の形が変わる**

パブリックコメントや審議会のような、**制度として組み込まれた外部説明の場**は民間にありません。代わりに、株主や取引先、監査といった相手が出てきます。**説明する相手が変わるだけで、説明の設計そのものは同じです。**

## 「手前を整える仕事」を、どう実績として残すか

評価が見えにくい構造は変えられませんが、**記録の残し方は自分で決められます。**在職中からやっておくと、書類を作るときに困りません。

**1. 会議の設計を記録する**

どの課を集めて、何を議題にして、どういう資料を出したか。**開催の事実ではなく、設計の意図を残してください。**「3課を集めた」ではなく「対象者が重なっている3課を集め、重複範囲を数字で示す資料を出した」という形です。

**2. 計画に載せた施策の、その後を追う**

策定して終わりにせず、**翌年度以降に予算がついたか、実際に始まったか**を記録しておきます。企画課の成果はここにしか現れません。

**3. 落としたものを記録する**

統合した施策、廃止した事業、指標から外した項目。**やめた判断は記録が残りにくい**ので、意識して残してください。書類でいちばん効く材料になります。

**4. 交付金や補助の採択を数える**

計画に要件を落として採択された案件があれば、件数と金額を控えておきます。**「計画で何かを取ってきた」実績は、そのまま説明材料になります。**

この4つは、異動しても手元に残る形で控えておいてください。**年数がたつと、自分が何をしたのか思い出せなくなります。**

## つまずきやすい点

**1. 議会の会期に活動を始めて中断する**

いちばん多い形です。**会期が終わった直後から始めてください。**

**2. 忙しさを転職理由にする**

経営企画は民間でも繁忙期があります。**理由は、やってきたことの延長で組んでください。**

**3. 評価されにくさを不満の形で出す**

構造として説明すれば強みになり、不満として出すと弱みになります。**同じ事実でも、置き方で逆になります。**

**4. 計画の改定年度に無理に動く**

改定を1回通すと書ける材料が大きく増えます。**改定の最中なら、終わるまで待つ判断にも十分な理があります。**

**5. 異動の可能性を検討しないまま動く**

企画課は、財政課、人事課、情報政策、事業課のいずれにも接続します。**庁内で移る選択肢を一度も検討していないなら、先にそちらを確かめたほうが選択肢は減りません。**

**6. 退職時期の制度面を確認しないまま決める**

退職手当や共済の扱いは在職期間で変わる部分があります。**手続きの前に、必ず所属の人事担当課と共済組合で確認してください。**

自分の場合にどの時期が動きやすいかは、一度話しながら整理したほうが早いことが多いです。[どの経験に値が付くのかから相談できます](../apply.html)。

:::insight
ここまで時期の話をしておいて逆のことを言いますが、**「計画が一段落したら動く」と考えていると、動かないまま数年たちます。**企画課には必ず次の計画があり、改定が終われば進捗管理が始まります。完全に区切りがつく瞬間は来ません。実際に動いた方に共通しているのは、**議会と議会のあいだに「書類を作る」「2社受ける」といった小さい単位で区切って進めた**ことです。全部を一気にやろうとすると、議会に飲まれて止まります。逆に、いま改定の真ん中にいるなら、無理に始める必要はありません。**改定を通してから動くほうが、書ける材料は確実に厚くなります。**在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 地方自治法第96条第1項は、**条例の制定改廃、予算、決算、契約の締結**などを議会の議決事件として列挙しています。企画課の成果物の多くは**議会で議決されて初めて確定**します
- だから山は**議会のたび**に来て、3月議会がいちばん重くなります。当初予算、条例改正、組織機構の議案が重なるためです
- 活動しやすいのは、**6月議会が終わってから8月まで**、または**9月議会が終わってから10月まで**です
- 企画課の成果は**他の部署が動いた結果**として現れ、うまくいかなかったときだけ名前が出ます。**不満ではなく構造として説明してください**
- 民間に移って最初に戸惑うのは、**「決めてくれる場」が明確でなくなること**です。面接で「この手の案件はどこで決まるのか」を聞いておいてください
- **計画の改定年度なら、改定を通してから動く判断にも十分な理があります**

## よくある質問

### 企画課は残業が多いと聞きますが、実際どうですか

自治体ごとの実態は公表されていないので、個別の水準をここで断定することはできません。**制度から言えるのは、成果物の多くが議会の議決を経る構造になっているため、会期前に作業が集中する**ということです。応募先に自分の状況を説明するときは、時間数ではなく**「議会のたびに山が来て、3月議会がいちばん重い部署でした」**と構造で伝えるほうが正確に伝わります。

### 計画の策定と改定では、どちらの経験が評価されますか

**改定のほうが厚く読まれます。**策定は白紙から作る作業ですが、改定は**前の計画の結果を評価したうえで組み直す**作業だからです。何が達成され、何が達成されなかったのかを整理し、残すものと落とすものを決める。民間の中期経営計画の見直しと、工程がほぼ同じです。策定しか経験がない場合は、**進捗管理を1回でも通してから動く**と材料が増えます。

### 企画課から異動してしまうと、経験は使えなくなりますか

使えなくなりません。ただし、**制度の細部は年数がたつと目減りします。**交付金の要件や計画の様式は変わっていきます。一方、**全部署から材料を集めて体系に落とす進め方や、権限がないまま合意を作る方法は、時間がたっても残ります。**離れて年数がたっているなら、制度の知識より進め方のほうを前に出してください。
