政令指定都市20団体の給与データには、道府県には見られない特徴があります。**地域手当の「国の指定基準」と「実際の支給割合」が、20団体すべてで一致しています。**差はゼロです。

道府県では、この2つがずれる団体が多くありました。愛知県は基準8.5%に対し実支給約10.85%、大阪府は11.8%に対し約13.80%。

**なぜ政令市では一致するのか。**ここから読み解くと、自分の給与の成り立ちが見えてきます。

## 札幌市の給与水準を、数字で確認する

総務省の調査によると、札幌市の一般行政職は次のとおりです（令和6年4月1日現在）。

| 項目 | 札幌市 |
|---|---|
| ラスパイレス指数 | 99.2 |
| 平均年齢 | 40.3歳 |
| 平均給料月額 | 305,600円 |
| 諸手当月額 | 78,119円 |
| 平均給与月額 | 383,719円 |
| 平均給与月額（国ベース） | 346,832円 |
| 地域手当（国の指定基準） | 3.00% |
| 地域手当（実際の支給割合） | 3.00% |

### 政令市の地域手当が「ぴったり」な理由

地域手当の国の指定基準は、**市町村単位**で決まります。

道府県の場合、県内にはさまざまな指定率の市町村があります。総務省の調査で県として示される率は、それらを合わせた結果です。だから端数が出ますし、県の判断で上乗せをすれば実支給が基準を上回ります。

**政令市は、それ自体がひとつの市です。**だから指定率がそのまま適用され、3.00%、6.00%、10.00%、15.00%、16.00%といったきりのよい数字が並びます。**上乗せの余地が構造的に小さい**ということです。

札幌市は3.00%。政令市20団体のなかでは低いグループにあたります。

### 平均給料月額は政令市で最も低い

札幌市の平均給料月額305,600円は、**政令市20団体のなかで最も低い額**です。

ただし平均年齢40.3歳も、20団体のなかで2番目に若い数字です。**給料表は勤続年数とともに上がる形なので、若い職員の比率が高いほど平均給料月額は低く出ます。**

補正済みのラスパイレス指数は99.2。20団体の分布のなかでは中位より下ですが、**額面の低さがそのまま給料表の水準の低さを意味するわけではありません。**

:::insight
政令市の方の相談で気をつけているのが、**道府県の数字と直接比べてしまうこと**です。たとえば札幌市の平均給与月額383,719円と、北海道の386,694円を並べて「道のほうが高い」と読む方がいます。しかし**平均年齢が札幌市40.3歳、北海道42.5歳と2.2歳違います。**この差だけでも平均給料月額は動きます。**団体どうしの比較は、条件が揃っていない限り判断に使えません。**やることは単純です。**自分の源泉徴収票の支払金額を出して、求人票の想定年収と並べる。**そして札幌市は諸手当78,119円が総額の20.4%と薄めなので、**動く部分が小さく、去年の額面がそのまま物差しとして使えます。**
:::

道府県の地域手当の分布は[愛知県職員の転職](pref-aichi.html)に、諸手当の比率は[大阪府職員の転職](pref-osaka.html)に表で整理しています。

## 政令市の職員は、条文に書かれた事務を担っている

政令市で働く方が職務経歴書を書くときに、いちばん効く条文があります。

地方自治法第252条の19は、**政令で指定する人口50万以上の市（指定都市）**は、都道府県が処理することとされている事務のうち政令で定めるものを処理することができる、と定めています。そして条文に、対象の事務が具体的に列挙されています。

- 児童福祉に関する事務
- 民生委員に関する事務
- 身体障害者の福祉に関する事務
- 生活保護に関する事務
- 社会福祉事業に関する事務
- 知的障害者の福祉に関する事務
- 母子家庭及び父子家庭並びに寡婦の福祉に関する事務
- 老人福祉に関する事務
- 母子保健に関する事務
- 介護保険に関する事務
- 障害者の自立支援に関する事務
- 生活困窮者の自立支援に関する事務
- **食品衛生に関する事務**
- **医療に関する事務**
- 精神保健及び精神障害者の福祉に関する事務
- 結核の予防に関する事務
- 難病の患者に対する医療等に関する事務
- **土地区画整理事業に関する事務**
- **屋外広告物の規制に関する事務**

**このリストは、そのまま職務経歴の棚卸しに使えます。**

道府県の職員向けの記事では、この条文を「指定都市に事務が移っているので、県の担当範囲が他県と違う」という文脈で扱ってきました（[大阪府職員の転職](pref-osaka.html)ほか）。**政令市の職員は、その反対側にいます。移ってきた事務を実際に担っている立場です。**

ここが採用側との認識のずれを生みます。市役所職員と聞いて、**住民窓口や地域行事を思い浮かべる採用担当者は少なくありません。**しかし政令市の職員が担っているのは、**県レベルの権限を伴う事務**です。

書き方の対処は単純です。

- 担当した事務を、**この条文の言葉で書く**（「福祉の仕事」ではなく「生活保護に関する事務」）
- **どの範囲まで自分の市で決められたか**を書く
- 対象の規模（人口、件数、事業所数）を添える

**「市役所だから小さい仕事」と読まれない書き方をしてください。**

| 予算の要求・査定、財政計画 | 予実管理、投資判断、経営企画 |
| 都市計画、土地区画整理 | 用地開発、開発企画、都市開発 |
| 食品衛生・医療の許認可と監視 | 品質保証、薬事管理、規制対応 |
| 生活保護・福祉の現業と査察 | ケースマネジメント、公共系事業企画 |

| 企業誘致・立地支援 | 事業開発、用地開発、アライアンス |
| 上下水道・交通など公営企業 | インフラ運営、アセットマネジメント |
| 観光の誘客・受入環境整備 | 観光事業企画、インバウンド事業 |

部署ごとの詳しい対応は[自治体の部署別 仕事ガイド](../zukan.html)にまとめています。財政課であれば[財政課の経験は民間で何と呼ばれるか](dept-zaisei-honyaku.html)で、さらに細かく分解しています。

## 札幌で、どの経験が値になるか

**1. 大都市の規模で、制度を運用してきた経験**

同じ制度でも、対象が数十万人になると運用の設計が変わります。**窓口の数、処理の順序、例外の扱い、システムとの接続。**この規模で回した経験は、全国展開する企業の業務設計にそのまま対応します。

**2. 積雪寒冷地のインフラを扱った経験**

除排雪、道路の維持、エネルギーの需要。**気象条件が事業コストに直結する地域**での実務は、同じ条件の地域に展開する企業にとって直接読める経験です。

**3. 観光と住民生活の両立**

来訪者が集中する都市です。誘客だけでなく、受入環境の整備や地域との調整まで担当していれば、それは観光事業企画の中核です。**人が集まりすぎたときに何をしたか**まで書けると、いま企業が求めている経験に重なります。

**4. 北海道全体の拠点機能を担ってきた経験**

道内の他自治体や、道外・海外との関係づくり。**自分の市で完結しない調整**をしていたなら、それは広域で事業を組む企業に読める経験です。

**5. 公営企業の運営**

上下水道、交通、病院。**料金、需要予測、施設の更新、人員配置。**独立採算に近い形で運営してきた経験は、民間の事業運営とほぼ同じ言葉で書けます。

## 道内だけで探すと、選択肢を自分で狭めてしまう

札幌市には道内の拠点機能が集まっており、県庁所在地としては求人の選択肢が多いほうです。それでも職種を絞ると件数は限られます。

近年はリモート可、週数日出社といった勤務形態の求人が増えています。とくに自治体を顧客にする企業は、担当エリアに出向くことが仕事なので、本社への出社頻度が低い場合があります。**担当エリアが北海道全域という求人であれば、拠点が札幌にあること自体が条件になっている**ことがあります。

**まず職種で絞り、そのあとに勤務形態と担当エリアを確認する。**勤務地から検索を始めると、この種の求人が最初から視界に入りません。

自分の経歴がどう言い換えられるかは、一度話しながら整理したほうが早いことが多いです。[どの経験に値が付くのかから相談できます](../apply.html)。

## 職務経歴書に、市役所の仕事をどう落とすか

**制度名ではなく、判断したことを書く**

「○○推進事業を担当」では読み手に何も残りません。事業名は庁内でしか意味を持たない固有名詞です。**何件を、どういう基準で審査し、どこで判断が割れて、どう決着させたか。**

**規模を必ず書く**

政令市の仕事は、対象の規模が大きいことが特徴です。**人口、件数、事業所数、予算額。**数字を添えないと、規模が伝わりません。ここを省くと「市役所だから小さい仕事」と読まれます。

**異動歴を「立ち上げの回数」に変える**

異なる制度領域を短期間で立ち上げてきた経験は、民間では**キャッチアップの速さ**として読まれます。編年式で並べ、それぞれの配属で最初の数か月に何を習得したかを1行添えてください。

## 技術職の場合は、探し方が変わる

**発注者側の経験そのものが職種になる**

「発注者支援」という職種が、建設コンサルタント業界には確立しています。設計の審査、積算の確認、工事の監督、住民説明。市役所でやってきたことが、そのまま職務内容として書かれた求人です。

**資格が入口で効く**

技術士、施工管理技士、測量士、建築士、電気主任技術者。**実務経験の年数が受験要件になっているものは、在職中でなければ積めません。**取れるものがあるなら、動く前に取っておいてください。

**都市部の維持管理と更新の経験は、これから増える職務になる**

新設ではなく、既存の施設をどう保たせるか。点検、優先順位付け、予算配分、廃止の判断。**この判断をした経験は、インフラ運営を受託する企業が探しています。**書くときは、対象施設の数と、優先順位をどう決めたかで書いてください。

## 面接で必ず詰められる2つのこと

**「意思決定のスピードに耐えられるか」**

行政は手続きの段数が多く、決裁を経て動きます。民間は月次で数字を締め、その場で方針を変えます。稟議の段数を弁解せず、**自分の判断で動かした範囲を具体的に答えてください。**

**「数字への意識があるか」**

「利益を意識したことはありますか」という形で聞かれます。「行政なので利益はありません」と答えると、そこで話が終わります。事業の優先順位を付けた、単価の根拠を詰めた、複数案を比べた。**同じ思考をしていたことを、民間の言葉で説明できるか**が見られています。

## 在職中に進めるときの注意点

**顔が知られている前提で動く**

市内の企業の多くは、市役所と何らかの接点を持っています。取引先、許認可の相手方、補助事業の対象。**在職中の活動が伝わりやすい環境**だという前提で進めてください。応募先が現在の担当業務の相手方である場合は、とくに慎重に扱う必要があります。

**服務上の扱いを先に確かめる**

在職中に得た情報を持ち出すことは避けなければなりませんし、退職後の営業活動についても扱いを確認しておいたほうが安全です。**判断に迷う場合は、応募の前に人事担当課に制度上の取扱いを確認してください。**

**面接の日程は、議会日程から逆算する**

地方自治法第211条は、長が毎会計年度予算を調製し、年度開始前に議会の議決を経なければならないと定めています。市町村は年度開始前20日までに予算を議会へ提出するようにしなければならない、とも書かれています。決算は、出納閉鎖後3か月以内の長への提出、監査委員の審査、議会の認定という順です（第233条）。**予算編成の山と定例会の会期中は、平日日中の面接を入れるのが難しくなります。**

**在職中に決める**

公務員には雇用保険が適用されないため、辞めてから探すと収入のない期間がそのまま持ち出しになります（[公務員に雇用保険がない理由](seido-shitsugyo-nashi.html)）。

:::insight
政令市の職員の方から、**「市役所というだけで、規模の小さい仕事だと思われる」**という話をよく聞きます。**実際そう読まれています。**採用担当者の多くは、市役所と聞いて住民窓口を思い浮かべるからです。対処は簡単で、**規模を数字で書くこと**に尽きます。対象の人口、年間の処理件数、所管する事業所数、扱った予算。これを1行入れるだけで、読まれ方が変わります。もうひとつ有効なのが、**地方自治法252条の19の言葉をそのまま使う**ことです。「福祉の仕事」ではなく「生活保護に関する事務」、「保健所の仕事」ではなく「食品衛生に関する事務」。条文の言葉は、県レベルの権限を伴う事務であることを示します。なお、残る判断にも理があります。いま担当している領域で通しの経験が積み切れていないなら、それを終えてから動くほうが、書けることは確実に厚くなります。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## よくある質問

### 政令市の地域手当が、道府県のようにずれていないのはなぜですか

**指定率が市町村単位で決まるからです。**道府県として示される率は、県内のさまざまな指定率の市町村を合わせた結果なので端数が出ますし、県の判断で上乗せをすれば実支給が基準を上回ります。**政令市はそれ自体がひとつの市なので、指定率がそのまま適用されます。**3.00%、10.00%、16.00%ときりのよい数字が並ぶのはそのためです。

### 市役所というだけで、小さい仕事だと思われませんか

**そう読まれることは実際にあります。**対処は規模を数字で書くことです。対象の人口、年間の処理件数、所管する事業所数、扱った予算。**あわせて、地方自治法252条の19の言葉をそのまま使ってください。**「福祉の仕事」ではなく「生活保護に関する事務」、「保健所の仕事」ではなく「食品衛生に関する事務」。条文の言葉は、県レベルの権限を伴う事務であることを示します。

### 北海道庁と比べて、給与水準は低いのですか

**そのまま比べられません。**札幌市の平均給与月額383,719円と北海道の386,694円は近い数字ですが、平均年齢が札幌市40.3歳、北海道42.5歳と2.2歳違います。**この差だけでも平均は動きます。**団体どうしの比較は条件が揃っていない限り判断に使えないので、自分の源泉徴収票の支払金額と、求人票の想定年収を並べてください。
