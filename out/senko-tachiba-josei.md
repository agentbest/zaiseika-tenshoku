**「結婚や出産の予定があると、転職は難しいのか」**というご相談を伺います。

**制度の前提を確認したうえで、時期の整理をしてください。**

この記事では、**法律上の定め**と、**実務の進め方**を扱います。

**⚠ 制度の要件は、団体と会社によって異なります。****必ず、所属と転職先に確認してください。**

## 募集及び採用における定めがあります

**雇用の分野における男女の均等な機会及び待遇の確保等に関する法律第5条**です。

> **事業主は、労働者の募集及び採用について、その性別にかかわりなく均等な機会を与えなければならない。**

**同法第9条**です。

> **事業主は、女性労働者が婚姻し、妊娠し、又は出産したことを退職理由として予定する定めをしてはならない。**
>
> ２ 事業主は、**女性労働者が婚姻したことを理由として、解雇してはならない。**
>
> ３ 事業主は、その雇用する女性労働者が**妊娠したこと、出産したこと**（略）**その他の妊娠又は出産に関する事由**（略）**を理由として、当該女性労働者に対して解雇その他不利益な取扱いをしてはならない。**
>
> ４ **妊娠中の女性労働者及び出産後一年を経過しない女性労働者に対してなされた解雇は、無効とする。**ただし、事業主が当該解雇が前項に規定する事由を理由とする解雇でないことを証明したときは、この限りでない。

**募集と採用について、性別にかかわりない均等な機会**が定められています。

**そして、婚姻・妊娠・出産を理由とする不利益な取扱いが禁じられています。**

**つまり、これらの事由を採用の判断材料とすることは、制度が想定していません。**

## 何を伝えるか

| 項目 | 考え方 |
|---|---|
| 家族の計画 | **伝える義務はありません** |
| 勤務できる時間 | **条件として伝えます** |
| 勤務できる日 | 同上 |
| 出張・転勤の可否 | 同上 |
| 必要な制度 | 入社後の利用の見込み |

**1行目と2行目を分けてください。**

**家族の計画そのものは、伝える義務のあるものではありません。**

**一方、勤務の条件に関わる部分は、伝えておくほうが後の齟齬が減ります。**

**「◯時までの勤務を希望」「土日の勤務は難しい」**という形です。

**条件で伝えれば、相手も判断できます。**

## 時期の整理

| 状況 | 考えること |
|---|---|
| 予定が具体にある | **制度の利用の要件**（勤続の年数など） |
| 予定は未定 | 条件を優先して選ぶ |
| すでに育児中 | 勤務の条件、保育の段取り |
| 介護がある | 勤務の条件、急な対応 |

**1行目です。**

**転職先の制度には、勤続の年数などの要件が定められている**ことがあります。

**入社してすぐに利用できるとは限りません。**

**応募の段階で、就業規則の内容を確認**してください。

**扱いは**[育休中・産休中の転職](senko-taishoku-ikukyu.html)**に整理しています。**

**4行目については**[介護と両立しながらの転職](senko-taishoku-kaigo.html)**を併せて確認してください。**

## 確認する項目

| 項目 | 確認すること |
|---|---|
| 育児に関する制度 | 就業規則の定め、要件 |
| 短時間勤務 | 有無と要件 |
| 時間単位の休暇 | **急な対応ができるか** |
| 在宅勤務 | 有無と頻度 |
| 転勤の可能性 | 範囲 |
| 取得の実績 | **制度があることと、使われていることは別** |

**3行目と6行目**です。

**制度の有無だけでなく、実際に利用されているかを確認**してください。

**聞き方は、「◯◯制度の取得の実績を伺えますか」で足ります。**

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 勤務できる時間・日 | **具体の時間で答える** |
| 出張・転勤 | 可否と、その範囲 |
| 急な対応の可能性 | 頻度の見込み |
| 働き続ける見通し | 条件が合えば、という前提で |
| 前職での経験 | 業務の中身 |

**1行目です。**

**「できる範囲」を数で示すと、相手が検討できます。**

**「◯時までなら勤務できます」「月に◯回程度であれば出張も可能です」**という形です。

**可否だけで答えるより、範囲を示すほうが話が進みます。**

:::insight
ライフイベントとの兼ね合いについて、**面談でお伝えしているのが「条件で絞ってください」**という点です。**「いまは時期が悪いのではないか」と考えて、検討そのものを止めてしまう方**がいらっしゃいます。ところが、**時期の良し悪しは、条件が決まって初めて判断できます。**勤務の時間、通勤の距離、休暇の取りやすさ、制度の要件、在宅勤務の可否。**これらを条件として並べ、満たす求人があるかを確認する。**そこで初めて、「いま動けるか」が分かります。**条件を満たす求人が存在するなら、時期の問題は小さくなります。**逆に、**条件に合う求人が見当たらないなら、時期をずらすか、条件を見直すか**という判断になります。**どちらにしても、材料が必要**です。そして、**条件を伏せて入社すると、続きません。**採用する側にとっても、**短期間で離職されるほうが負担**です。**条件は、先に出してください。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 制度の違いを確認する

| 項目 | 確認先 |
|---|---|
| いまの制度 | **所属の人事担当** |
| 転職先の制度 | 求人票、就業規則 |
| 保険・年金の切替え | 共済組合、年金事務所 |
| 給付の扱い | 共済組合、関係機関 |
| 保育の手続き | 市区町村 |

**1行目です。**

**いまの職場で使える制度を先に確認**してください。

**制度を使うことで続けられる場合があります。**

**転職を前提にせず、制度の照会として聞くことができます。**

**比べる基準がないまま動くと、いまより条件の悪い先を選ぶことがあります。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 準備の順序

| 順 | やること |
|---|---|
| 1 | **いまの職場の制度を確認する** |
| 2 | 勤務の条件を書き出す（時間、日、通勤、出張） |
| 3 | 譲れない条件を決める |
| 4 | 求人を読み、条件に合うものがあるか確認する |
| 5 | 制度の要件を確認する |
| 6 | 判断する |

**3が要**です。

**すべてを満たす求人はまれ**です。

**何を優先するかが決まっていれば、選べます。**

## 在職中の進め方

| 項目 | 内容 |
|---|---|
| 制度の確認 | 所属の人事担当へ |
| 求人を読む | 週に30分 |
| 条件の整理 | 月に1回見直す |
| 日程の確保 | オンラインでの面接を確認 |

**4行目です。**

**在職中は、面接の時間が限られます。**

**オンラインでの実施が可能かを、応募の段階で確認**してください。

## よくある失敗

**1. いまの職場の制度を確認しない**

**選択肢が1つ減ります。**

**2. 家族の計画を、条件と混ぜて伝える**

**条件だけで足ります。**

**3. 可否だけで答える**

**範囲を示す**ほうが話が進みます。

**4. 制度の要件を確認しない**

**入社直後は対象外となる**場合があります。

**5. 取得の実績を確認しない**

**制度があることと、使われていることは別**です。

**6. 条件を伏せて入社する**

**入社後に調整できません。**

**7. 時期の良し悪しだけで判断する**

**条件が決まって初めて判断できます。**

**8. 転勤の可能性を確認しない**

**後で条件が変わります。**

:::insight
ここまで条件の話をしておいて逆のことを言いますが、**ライフイベントを前提に、仕事の内容まで狭める必要はありません。**面談で拝見していると、**「両立しやすい仕事」という基準だけで候補を絞り、業務の内容を後回しにする方**がいらっしゃいます。ところが、**両立のしやすさは、業務の内容よりも、勤務の条件と職場の運用で決まる**ことが多いです。同じ職種でも、**時間単位の休暇がある職場とない職場では、続けやすさがまったく違います。**ですから、**業務の内容は自分の経験と関心で選び、両立のしやすさは条件で確認する。****この2つを分けてください。**そして、**行政が相手の事業には、制度を整えている会社があります。**受託や指定管理では、**行政の基準に沿った労務の管理が求められる**ためです。**業務の内容も、経験と重なります。**探し方は[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)に整理しています。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **男女雇用機会均等法第5条**は、**募集及び採用について、性別にかかわりなく均等な機会を与えなければならない**と定めています
- **同法第9条**は、**婚姻・妊娠・出産等を理由とする不利益な取扱いを禁じ**、**妊娠中・出産後1年を経過しない者への解雇を無効**としています（事業主の証明がある場合を除く）
- **家族の計画を伝える義務はありません。**伝えるのは、**勤務の条件**です
- **可否だけでなく、範囲を数で示して**ください
- **制度の要件（勤続の年数など）と、取得の実績**を確認してください
- **いまの職場の制度を先に確認**してください。比べる基準になります
- **業務の内容は経験と関心で、両立のしやすさは条件で**選んでください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 面接で、結婚や出産の予定を聞かれました

**答える義務はありません。****男女雇用機会均等法第5条**は、**募集及び採用について性別にかかわりない均等な機会**を定めています。**同法第9条**は、**婚姻・妊娠・出産等を理由とする不利益な取扱い**を禁じています。**これらの事由を採用の判断材料とすることは、制度が想定していません。**答え方としては、**勤務の条件に置き換えて答える**方法があります。「現時点で具体の予定はありませんが、勤務については◯時まで対応できます」という形です。なお、**この質問が出たこと自体を、判断の材料にして差し支えありません。**紹介を通している場合は、**やり取りの内容を共有**してください。

### 制度が整っているかを、どう見分けますか

**3つ確認してください。**1つ目は、**就業規則の定め**。求人票に記載がなければ、**面接で内容を確認**します。2つ目は、**取得の実績**。「◯◯制度の取得の実績を伺えますか」と聞けば、**運用の状況が分かります。**3つ目は、**時間単位の休暇の有無**。**急な対応が必要な場面で、半日や1日単位でしか休めないと、続けにくくなります。**なお、**採用のページに、制度の説明や社員の紹介が載っている**ことがあります。**求人票より詳しい**場合があるため、併せて確認してください。

### ブランクがありますが、応募できますか

**応募条件によります。**「◯年以上の実務経験」が必須の場合、**期間の要件**を満たす必要があります。一方、期間が明示されていない求人では、**経験の中身で判断**されます。ブランクについては、**期間と、その間にしていたこと**を簡潔に書けば足ります。**詳しい説明は不要**です。なお、**復帰を前提とした募集**や、**短時間の勤務から始められる求人**もあります。**勤務の形を条件として示して**差し支えありません。扱いは[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。**条件を読んでから判断**してください。
