退職を上司に伝えた後、**次に来るのが「誰に、いつ伝えるか」**です。

**自分の判断で広げないでください。**

この記事では、**伝える範囲と順番**を扱います。上司への伝え方は[退職を切り出すタイミングと相手](senko-taishoku-kirisashi.html)にあります。

## 組織は、系統的に構成されています

**情報が流れる順序にも、組織の構造が関わります。**

**地方自治法第138条の3第1項**です。

> 普通地方公共団体の執行機関の組織は、普通地方公共団体の長の所轄の下に、それぞれ明確な範囲の所掌事務と権限を有する執行機関によつて、**系統的にこれを構成しなければならない。**

**系統的に構成する。**

**権限も、責任も、系統に沿って配置されています。**

**退職の情報も、同じ系統に沿って流れるのが自然**です。

**直属の上司 → 所属の長 → 人事 → 同僚 → 関係先。**

**この順を飛ばすと、上の立場の人が後から知ることになります。**

**それは、その後の調整に影響します。**

## 伝える範囲と時期

| 相手 | 時期 | 決める人 |
|---|---|---|
| 直属の上司 | **入社日が確定した直後** | 自分 |
| 所属の長 | 上司の判断 | 上司 |
| 人事の担当 | 書面の提出時 | 規程による |
| 係・課の同僚 | **所属の長の了解を得てから** | 所属の長 |
| 他課の関係者 | 引継ぎの段階 | 上司と相談 |
| 外部の関係先 | 退職の直前 | 上司と相談 |

**4段目以降は、自分では決めません。**

**「いつ、誰に、どこまで伝えてよいか」を、上司に確認してください。**

**この確認を1回しておけば、判断に迷いません。**

## なぜ自分で広げないのか

| 理由 | 内容 |
|---|---|
| 業務の割り振りに影響する | **所属の長が調整する前に広がると、混乱します** |
| 後任の検討に影響する | 人事の作業が動いていることがあります |
| 関係先への説明の順序 | 組織としての連絡の段取りがあります |
| 周囲の受け止め | 経路によって、受け止め方が変わります |

**1つ目が、実務上いちばん影響します。**

**人が抜けることが分かると、業務の割り振りを考え直す必要があります。**

**その検討が済む前に情報が広がると、周囲が落ち着きません。**

## 聞かれたときの答え方

**伝えてよい範囲が決まる前に、同僚から聞かれることがあります。**

| 状況 | 答え方 |
|---|---|
| 「辞めるって本当?」 | 「上司と相談しているところです」 |
| 「どこに行くの?」 | **伝える範囲が決まってから** |
| 「いつまでいるの?」 | 「日程が固まったらお伝えします」 |

**否定する必要はありませんが、詳細を述べる必要もありません。**

**「相談中」という答え方であれば、嘘にもなりません。**

**範囲が決まったら、改めて伝えてください。**

## 同僚に伝えるとき

**了解が得られたら、自分から伝えてください。**

| 項目 | 内容 |
|---|---|
| 時期 | 所属の長が決めた時期 |
| 範囲 | 係の中か、課の中か |
| 内容 | **退職日と、引継ぎの予定** |
| 転職先 | **業種程度で足ります** |
| 理由 | 詳しく述べる必要はありません |

> ◯月◯日をもって退職することになりました。引継ぎについては、◯月中に進める予定です。ご迷惑をおかけしますが、よろしくお願いいたします。

**3文で足ります。**

**理由を聞かれた場合も、詳しく答える必要はありません。**

:::insight
同僚に伝える場面で、**面談でお伝えしているのが「不満を述べない」**という点です。辞める理由を聞かれたときに、**組織や制度への不満を述べてしまう**ことがあります。気持ちとしては自然ですが、**残る人にとっては、その環境で働き続ける話**です。**辞める人が不満を述べると、残る人の立場が難しくなります。**加えて、**その話は伝わります。**役所は狭い組織で、**人は異動します。**数年後に、別の場面で顔を合わせることもあります。**述べるなら、「新しい分野に挑戦することにしました」という程度**で足ります。**現職を否定せずに去る**ことは、自分のためでもあります。とくに、**自治体を顧客とする業界に移る場合、元の職場との関係は仕事の上でも意味を持ちます。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

**この一言は、伝える相手の人数分だけ繰り返すことになります。**短くしておくほど、負担が小さくなります。

## 関係先に伝えるとき

**外部への連絡は、所属の判断に従ってください。**

| 相手 | 伝えること |
|---|---|
| 他課の担当 | **後任の氏名と連絡先** |
| 事業者 | 担当が変わる旨（時期は所属の判断で） |
| 関係機関 | 同上 |
| 住民の相談者 | **所属の判断で。**自分から伝えない |

**4つ目に注意してください。**

**継続して相談を受けている方がいる場合、伝え方は所属の判断**です。

**自分から「辞めます」と伝えると、相手が不安になることがあります。**

**「担当が変わります」という形で、組織として伝えるのが通常**です。

## 範囲を決めるときの相談の仕方

**上司に確認するときは、次の3点を具体的に聞いてください。**

| 聞くこと | なぜ必要か |
|---|---|
| **いつから**伝えてよいか | 業務の割り振りの検討の状況による |
| **どこまで**の範囲か | 係の中か、課の中か、部の中か |
| **誰が**伝えるか | 自分か、上司か、所属の長か |

**3つ目を確認しておくと、重複や行き違いが防げます。**

**所属によっては、朝礼や会議の場で、所属の長から周知される**ことがあります。その場合、**自分から個別に伝える必要はありません。**

**逆に、「自分から伝えてほしい」と言われることもあります。**その場合は、**上司が示した範囲の中で、直接伝えてください。**

**確認に要するのは数分**です。**伝えた直後の相談の中で、あわせて聞いておく**と効率的です。

## 引継ぎの相手には、早めに伝わる

**範囲が限られていても、引継ぎの相手には早い段階で伝わります。**

| 相手 | 理由 |
|---|---|
| 後任 | 引継ぎの計画を立てる必要があります |
| 係の中で業務を分担する職員 | 割り振りの調整が生じます |
| 他課で同じ案件を担当する職員 | 進行中の案件の相手として |

**3つとも、業務の必要から伝わる相手**です。

**この範囲は、所属の長が判断します。**

**自分から先に伝えるのではなく、「引継ぎの相談をしてよいか」を確認**してください。

## 伝えた後の過ごし方

| ✕ | ○ |
|---|---|
| 業務への関与を減らす | **最後まで通常どおり担当する** |
| 引継ぎを後回しにする | 早い段階から資料を作る |
| 転職先の話を広げる | 聞かれた範囲で答える |
| 不満を漏らす | 述べない |

**1つ目が、周囲の受け止めにいちばん影響します。**

**伝えた後も、退職日までは職員です。**

[経験の言い換えから相談する](../apply.html)こともできます。

**なお、伝える範囲が広がるほど、問い合わせも増えます。**同じ説明を何度もすることになるため、**退職日と引継ぎの予定だけを短く伝える形**にしておくと、対応が楽になります。

## よくある失敗

**1. 上司の了解を得ずに同僚に伝える**

**業務の割り振りの検討**に影響します。

**2. 「まだ内緒で」と言って伝える**

**その形で広がります。**

**3. 辞める理由として不満を述べる**

**残る人の立場**が難しくなります。

**4. 転職先を詳しく話す**

**業種程度**で足ります。

**5. 住民の相談者に自分から伝える**

**所属の判断**に従ってください。

**6. 伝えた後に業務への関与を減らす**

**退職日までは職員**です。

:::insight
ここまで順序の話をしておいて逆のことを言いますが、**伝えた後の関係は、多くの場合、思っているより変わりません。**面談で伺っていると、**「気まずくなるのでは」と心配していたが、実際には普段どおりだった**という感想をよく聞きます。理由は、**役所では人の出入りが日常的にあるから**です。異動、育児、介護、定年。**人が抜ける場面に、組織は慣れています。**むしろ、**関係が変わるのは、伝え方や引継ぎの進め方が雑だった場合**です。順序を守り、引継ぎを整え、最後まで業務を担う。**この3つを守れば、関係は保てます。**そして、**退職後も連絡を取れる相手が残ることは、次の仕事でも意味を持ちます。**とくに、**リファレンスの依頼が必要になる場合**には、**その関係が直接に必要**になります。扱いは[リファレンスチェックは公務員でも行われるか](senko-mensetsu-reference.html)に整理しています。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方自治法第138条の3第1項**は、執行機関の組織を**系統的に構成する**としています。**情報も、系統に沿って流れるのが自然**です
- 順番は、**直属の上司 → 所属の長 → 人事 → 同僚 → 関係先**です
- **同僚以降は、自分で決めません。**「いつ、誰に、どこまで」を上司に確認してください
- 範囲が決まる前に聞かれたら、**「上司と相談しているところです」**で足ります
- **辞める理由として不満を述べない。**残る人の立場が難しくなります
- **伝えた後も、退職日までは職員**です。業務への関与を減らさないでください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 同僚に先に相談してしまいました

**上司に伝える時期を早めてください。**同僚から先に伝わると、**上司が最後に知る**ことになります。その状態が続くほど、**関係に影響します。**伝えるときに、経緯を詳しく説明する必要はありませんが、**「先に同僚に相談してしまいました」と一言添える**ほうが、後から判明するより誠実です。なお、**相談した同僚には、範囲が決まるまで伏せてもらうよう依頼**してください。**ただし、依頼しても広がることがあります。**その前提で、早めに正式に伝えることを勧めます。

### 送別の会を開くと言われました

**所属の慣行に従って構いません。**参加するかどうかは、**自分で決められます。**なお、**在職中に転職先の詳細を広く伝える場にはしないでください。**とくに、**その会社が自治体と取引がある場合**、具体的な話をすると誤解を招くことがあります。**「民間の会社に移ります」という程度**にとどめてください。また、**送別の会の費用について、所属の慣行がある場合は確認**してください。なお、**参加を辞退することも可能**です。事情があれば、上司に伝えれば足ります。

### 退職後も連絡を取ってよいですか

**個人的な連絡であれば、問題ありません。**ただし、**業務上の働きかけには制限があります。****地方公務員法第38条の2**により、**離職前5年間の職務に属する契約等の事務について、離職後2年間、元の組織の職員への働きかけが制限されます。**自治体を顧客とする会社に移る場合は、**この線を確認**してください。詳しくは[内定から入社までにやること](senko-mensetsu-junbi.html)にあります。また、**業務の照会に答える場合も、守秘の義務は退職後も続きます。**答えられるのは、**一般的な事柄まで**です。
