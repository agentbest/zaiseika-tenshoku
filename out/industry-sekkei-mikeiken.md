未経験から設計事務所を目指すときは、設計事務所という業界で働いたことがないのか、応募する職務の実務を経験していないのかを分けます。公務で建築、都市計画、公共施設の整備に関わっていても、委託先が行った設計を本人の実務に置き換えることはできません。求人が求める実務、資格、勤務可能な範囲と、自分の担当工程を照合することから始めましょう。

本記事は2026年11月時点の公開情報にもとづきます。確認日は2026年11月25日です。日本設計と日建設計の公式キャリア募集を例として扱い、業界全体に共通する応募資格や採用結果を示すものではありません。最新の募集継続と、本人の経験が応募条件に該当するかは各社に確認してください。

## 設計事務所の職種は、設計だけではない

設計事務所の募集には、意匠、構造、設備、都市計画、監理、コスト、企画推進、管理部門など異なる仕事があります。法人が幅広い領域を扱っていても、一人の応募者がすべての業務を担うわけではありません。「公共施設に関わった」という経験も、計画の作成、発注条件の整理、設計内容の確認、予算管理では担当が異なります。

日本設計の公式募集は建築設計、都市計画、構造設計、環境・設備設計、監理、企画推進などを分けています。日建設計のキャリア募集も、技術系総合職と事務系総合職を掲げ、都市、土木、マネジメント・コンサルティング、事務・営業等を区分しています。社名を先に決めるより、職種ごとの仕事内容と条件を読む必要があります。

また、同じグループでも採用主体は別です。日建設計のページは同社の募集であるとし、グループ各社への応募はそれぞれの募集要項を確認するよう案内しています。グループ全体の事業紹介を、ある会社の応募条件や配属先の保証に使わないでください。

## 「資格不要」と「実務経験不要」を分ける

日本設計の都市計画は、都市・地域計画の調査・計画立案や都市開発事業の事業推進業務の実務経験者を対象としています。必要資格は技術士、一級建築士、再開発プランナーのいずれかです。関連する公務経験があることから、資格条件まで不要だとは読めません。資格を持つことだけで、実務の条件を満たすとも限りません。

同社の企画推進は、建築設計・関連領域の業務企画および受注営業を対象業務とし、建築設計・関連領域における企画および営業業務の実務経験者を対象としています。必要資格はなしと記載されていますが、実務経験まで不問という意味ではありません。自治体で企画書を作った経験が、そのまま建築関連の企画・営業実務に該当するかは確認が必要です。

日建設計のキャリア募集は、募集職における実務経験が3年以上あることと、国内外を問わず勤務可能なことを応募資格に挙げています。一級建築士や技術士等、語学の能力は歓迎として別に記載されています。年数だけを満たしていても、募集職の実務かどうかと、勤務地の条件をそれぞれ確認します。

| 条件の読み方 | 本人側で照合する事項 | 読み替えないこと |
| --- | --- | --- |
| 関連職務の実務経験 | 何を本人が作成・検討・確認したか | 事業への所属だけで実務済みとする |
| 必要資格 | 資格名と保有状態、募集の指定 | 学習中を保有済みとする |
| 資格不要の職種 | 同時に記載された実務条件 | すべて未経験で応募可能とする |
| 勤務可能な範囲 | 国内外、異動、生活上の条件 | 希望地だけで勤務できるとする |

公務経験の接点を探す際は、[担当業務を整理しながら求人を比較する](../?gov=1)方法もあります。資格と実務の条件を一つずつ確認し、満たしていない条件を志望の強さで補ったことにしないようにします。

## 公務の経験を、担当した工程から整理する

都市計画や再開発の担当なら、本人が調査、計画立案、協議の論点整理、事業推進のどこに関わったかを分けます。条例や計画に沿った行政側の確認と、受託者として計画案を作成する仕事は責任の関係が異なります。自分が立案した部分と、委託先の提案を確認した部分を区別して説明してください。

公共施設の整備担当なら、要求条件の整理、関係部署からの意見収集、予算や契約の手続き、工程の連絡などが本人の経験となる場合があります。一方、設計図面の作成、構造計算、設備設計、専門判断を委託先が行ったなら、それを自分の技術実績に含めません。最終決定が上司や会議体にあった場合も、権限の分担を保ちます。

建築職や土木職として実際に専門実務を行った人は、担当した業務、時期、役割、成果物の種類を具体化します。担当名だけで経験を小さく扱う必要も、大きく広げる必要もありません。本人の実務が求人の対象に含まれるか、採用窓口が確認できる形に整理します。

事務系の仕事を検討する場合も同じです。財務、経理、人事、営業等の募集を、設計経験がない人なら誰でも入れる枠とは考えません。必要な実務、知識、勤務条件を別途確認し、公務の会計や契約手続きとの共通点と違いを示します。

:::insight
未経験という言葉を使う前に、何が未経験なのかを分けることを勧めます。設計事務所で働いたことがなくても、募集に関係する実務を公務で担当している場合はあります。一方、施設整備に関わったというだけでは、設計や監理の専門工程を担当したことにはなりません。本人が作ったもの、確認したもの、他者へ判断を依頼したものを区分してください。そのうえで公式の実務と資格の条件を照合すれば、確認すべき点を絞れます。学習の意欲は大切な希望ですが、現在の経験に置き換えるものではありません。条件が合わない場合も、現職を続けながら学ぶことや、別の職務を調べることを選べます。応募の可否と、将来の関心を分けて考えましょう。
:::

## 独立した架空例：応募条件との対応表

以下は説明用に作成した架空例です。実在の相談者や採用結果ではありません。本人の応募書類へ使う場合は事実に置き換え、行っていない工程や保有していない資格は削除してください。

| 項目 | 架空の記入例 |
| --- | --- |
| 本人の担当 | 自治体の施設整備担当として、利用部署の要望を収集 |
| 実際にしたこと | 要望を項目別に整理し、未確認事項を委託先へ照会するための資料を作成 |
| 他者がしたこと | 設計図面と技術検討は委託先、仕様の最終決定は所属の決裁者 |
| 未経験の仕事 | 意匠・構造・設備の設計実務、建築関連の受注営業 |
| 保有資格 | 当該募集が必要とする資格は未保有 |
| 求人との照合 | 調整工程の接点はあるが、設計実務・資格条件を満たすとは判断できない |
| 次に行うこと | 採用窓口で対象実務を確認し、条件に合う職務を改めて調べる |

この例なら「利用部署の要望を整理し、未確認事項の照会用資料を作成しました」と説明できます。「公共施設を設計しました」と書くと、本人と委託先の担当が入れ替わります。また、企画推進が資格不要だからといって、経験のない受注営業を行ったことにはできません。

本人が設計した成果物がある場合も、組織の共同成果と本人の制作範囲を分けます。学習で作った図面やモデルは、学習作例と明記し、実務で使用した成果として出しません。授業や独習でソフトを操作したことから、案件の要件整理や設計判断まで経験したとは書けません。

対応表には「条件を満たす」「未充足」「要確認」を別々に残してください。判断できない部分を都合よく満たしたことにせず、採用窓口へ確認する事項にします。応募を急ぐために、本人の経歴や権限を言い換えて増やす必要はありません。

[公務の担当工程と希望職種を相談用に整理する](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担）。経験や希望条件によって、面談や求人紹介を案内できない場合があります。

## 応募資料に出せるものを確認する

日本設計の募集では、職種に応じて履歴書、職務経歴書、業務実績や作品の資料等が示されています。日建設計もキャリアシートやポートフォリオの案内を掲げています。必要な提出物は当該職種の記載を読み、指定形式、容量、提出方法、本人の担当範囲を照合してください。職種による提出の扱いを一律にしません。

資料の提出を求められていても、現職の内部図面、契約資料、設備の詳細、個人情報を持ち出す許可にはなりません。公開されている成果物でも、著作権、利用条件、組織としての取扱い、本人の制作範囲を確認します。名前を消すだけで外部利用できるとは限りません。

内部資料を個人端末へ移したり、外部の生成AIへ入力したりして作品集を作らないでください。外部へ示せる公開情報と、本人が担当した工程の説明から構成し、示せない資料の代わりに秘密を開示する必要はありません。提出資料の形式については、採用窓口に相談します。

また、公務の担当を離れても行政上の便宜を提供できるような説明はしません。職務上知った連絡先や未公開計画を受注につながる資源として売り込まないことが基本です。応募先に伝えるのは、適切に説明できる経験と、本人の希望です。

## 雇用形態と勤務条件も別に照合する

日本設計の今回取り上げる都市計画や企画推進等の募集は、契約期間1年、更新あり、通算契約期間の上限3年、試用期間2か月と記載しています。社員登用の説明や過去の実績があっても、本人が必ず登用される保証にはしません。別の募集区分には条件の異なるものもあるため、当該職種の欄を確認します。

日建設計の募集には国内外の勤務が可能であることが応募資格として示されています。希望する拠点でずっと働けると考えず、勤務地、業務の変更、勤務制度と本人の生活上の条件を照合してください。フレックスや在宅勤務の制度があっても、個人の利用条件や出社の必要がすべて決まるわけではありません。

選考についても、書類、面接、検査の公開案内と、本人への具体的な日程を区別します。応募してからの期間や採用時期を保証と扱わず、現職の勤務や所属の手続きと調整します。内定前の退職を前提にせず、条件が合わなければ応募を見送ることもできます。

:::insight
専門職への入口を探すときは、学習すれば将来できることと、現在の募集に応募できることを分ける必要があります。公式募集の実務年数や必要資格は、関心だけで省略できません。同時に、公務で本人が行った専門実務を、勤務先の違いだけで小さく扱う必要もありません。担当工程を具体化し、条件への該当を確認してください。契約期間や勤務地が希望と合うかも、専門性とは別の判断です。登用の実績や制度を本人の確定した将来として受け取らず、提示された条件を一つずつ照合しましょう。いま応募することだけが進路ではありません。現職を続けながら対象職務を調べ、必要な学習や資格の条件を確かめる選択にも理があります。
:::

## 確認の返答を受けて、候補を見直す

採用窓口へ経験の該当を確認するときは、担当部署の名前だけで尋ねず、本人が行った工程と、他者が担った専門作業を短く示します。内部資料を送らずに説明できる範囲を用い、どの条件への該当を確かめたいかを明記してください。返答が曖昧な場合も、自分の経験を都合よく言い換えて解決しようとせず、追加で確認する事項として残します。

応募対象ではないと分かった場合は、理由を本人の能力全体の否定に広げる必要はありません。当該募集の条件と現在の経験の関係として整理し、別職種の条件や学習の必要を調べ直せます。現職での担当業務を適切に続けながら、進路の比較に必要な情報を集めることもできます。

## まとめ：未経験の範囲を明確にして、条件を照合する

設計事務所への転職では、業界未経験、職務未経験、資格の有無を分けます。資格不要の職種にも実務条件がある場合があり、専門資格があっても募集職の実務を満たすとは限りません。公務で本人が行った工程と、委託先や決裁者の仕事を区別して説明しましょう。

[LINEで相談の進め方を確認する](https://line.me/R/ti/p/@697nxhbt)際も、希望する職種、現在の担当、未経験の工程、勤務条件を分けて伝えてください。応募を見送ることや現職継続も含めて比較できます。

## よくある質問

### 建築の部署にいれば、設計経験者として応募できますか？

部署名だけでは判断できません。本人が作成・検討・確認した業務と、委託先が行った設計を分け、募集が求める実務に該当するかを応募先に確認してください。

### 資格不要と書かれた職種なら、完全未経験でも応募できますか？

実務条件を別に確認します。日本設計の企画推進は必要資格なしですが、建築設計・関連領域の企画および営業業務の実務経験者が対象です。

### 学習した図面を実績として提出できますか？

提出可能な形式を応募先に確認し、学習作例と実務成果を区別します。他者の制作物や内部資料を本人の成果として出さず、権利や情報の取扱いも確認してください。
