広報広聴課からの転職でいちばん多い誤解は、**「広報紙を作っていた人」と読まれること**です。

編集はたしかに仕事の一部ですが、**中身は「制度を、使う人に届く形に直す」作業**です。そして、届いたかどうかを確かめて次に返すところまでが範囲に入ります。

この記事では、**その仕事が民間で何と呼ばれるか**を整理します。訳語の対応表、中核スキルの工程分解、そして**民間の広報とどこが同じでどこが違うか**まで扱います。

行き先や職務経歴書の書き方は、別の記事に分けて書きます。ここでは、まず言葉の対応と工程を押さえます。

## 「ひとしく受ける権利」を実質化する仕事です

まず、この部署の立ち位置を条文で確認します。

地方自治法第10条第2項は、こう定めています。

**住民は、法律の定めるところにより、その属する普通地方公共団体の役務の提供をひとしく受ける権利を有し、その負担を分任する義務を負う。**

**「ひとしく受ける権利」**という部分が要点です。

制度は、**知られていなければ使われません。**手当があっても、申請できることを知らなければ受け取れません。**知っている人だけが使える状態は、「ひとしく」からずれます。**

つまり、広報の目的は**宣伝ではなく、到達の設計**です。**誰に届いていないかを把握し、そこに届く経路を選ぶ**のが中身になります。

そして、もう一方の「広聴」にも制度上の裏づけがあります。

地方自治法第74条第1項は、**選挙権を有する者は、その総数の五十分の一以上の者の連署をもつて、その代表者から、普通地方公共団体の長に対し、条例の制定又は改廃の請求をすることができる**と定めています。

**住民が、制度そのものを変えるよう求められる**わけです。広聴は、この請求にまで至る前の段階で、**声を集めて政策側に返す経路**として置かれています。

**発信して終わりではなく、返ってきたものを政策に戻す。**この往復が、広報広聴課の仕事の形です。

## 民間での訳語

履歴書や職務経歴書では、**自治体の中でしか通じない言葉を、募集要項に出てくる言葉に置き換えます。**

| 自治体での呼び方 | 民間での呼ばれ方 |
|---|---|
| 広報紙の編集・発行 | オウンドメディアの編集、社内報・会報誌の制作 |
| 報道発表・記者クラブ対応 | プレスリリース配信、メディアリレーション |
| ホームページの運用・改修 | コーポレートサイトの運用、CMS運用 |
| SNSの運用 | ソーシャルメディア運用、アカウント運営 |
| 広聴・市民の声の集約 | VOC（顧客の声）の収集と分析 |
| パブリックコメントの実施 | 意見募集、ステークホルダー調整 |
| シティプロモーション | ブランディング、地域マーケティング |
| 移住定住のプロモーション | 獲得施策、リードの獲得 |
| 情報発信の全体設計 | コミュニケーション設計、広報戦略 |
| 各課からの原稿の取りまとめ | 編集ディレクション、進行管理 |
| 撮影・写真の管理 | クリエイティブ管理、アセット管理 |
| 危機管理時の情報発信 | クライシスコミュニケーション |

**「広報紙」を「オウンドメディア」と言い換えるだけで、読まれ方が変わります。**発行部数、発行回数、ページ数を添えると、規模がそのまま伝わります。

## 中核スキルを5つの工程に分ける

この部署の仕事は、**5つの工程**に分解できます。**企業の広報・マーケティング部門の工程と、ほぼ同じ形**です。

**① 誰に届けるかを決める**

全住民に一律に出すのではなく、**制度ごとに届けたい相手が違います。**児童手当は子育て世帯、介護の制度は高齢者とその家族、創業の支援は事業者。

**対象が決まると、経路が決まります。**ここを飛ばすと、広報紙に全部載せるだけの作業になります。

**② 何を伝えるかを削る**

ここが、この部署のいちばん難しい工程です。

各課から上がってくる原稿は、**制度をそのまま説明した文章**になっています。要件、期限、例外、根拠条文。**正確ですが、そのままでは読まれません。**

そこで、**「対象は誰か」「いつまでに」「どこへ」の3つを先に立て、残りを削る**作業をします。**削ったことで不正確になっていないかを、所管課と突き合わせる**ところまでが工程です。

**③ 経路を選ぶ**

広報紙、ホームページ、SNS、報道発表、回覧、ポスター、窓口での案内。**それぞれ届く相手が違います。**

高齢者に届けたいのに、SNSだけで出しても届きません。**逆に、期限が近い情報を月1回の広報紙に載せても間に合いません。**

**④ 出す**

校正、写真の確認、掲載日の調整、印刷の入稿。**期限が固定されている工程**です。広報紙は発行日が決まっており、**遅れは選択肢になりません。**

**⑤ 届いたかを確かめ、次に返す**

問い合わせの件数、申請の件数、ページの閲覧数、窓口での反応。**「出した」ではなく「使われた」で確かめます。**

そして、広聴で集まった声を所管課に返します。**ここが、民間の広報部門にはあまりない工程**です。

## 民間の広報と、どこが同じでどこが違うか

**同じところ**

**1. 原稿が自分のところに集まってくる構造**

企業の広報も、各事業部から情報を集め、編集して出します。**自分でネタを作るのではなく、集めて整える立場**であることは共通です。

**2. 期限が動かない**

広報紙の発行日と、企業のリリース配信日。**どちらも後ろにずらせません。**

**3. 「正確さ」と「読まれること」が引っ張り合う**

所管課は正確さを求め、読者は短さを求めます。**この調整が仕事の本体である点も同じ**です。

**違うところ**

**1. 目的が「売る」か「届ける」か**

企業の広報は、最終的に**売上や採用や企業価値**につながることを求められます。自治体の広報は、**制度が使われること**が目的です。

この違いは、**指標の置き方に出ます。**企業では、問い合わせ数や採用応募数のような**獲得の数字**が問われます。自治体では、**届いていない層に届いたか**が問われます。

**移った直後に戸惑うのは、ここです。**ただし、**「届いていない層に届ける」という発想は、企業でも弱い部分**なので、持ち込む価値があります。

**2. 出せない情報の性質が違う**

企業では、**未発表の業績や新製品**が出せません。自治体では、**個人が特定される情報と、意思決定前の情報**が出せません。

**どちらも「出せないものを扱う訓練」を受けている**点は同じですが、**線の引き方が違う**ので、移った先で覚え直す必要があります。

**3. 広聴に相当する機能が薄い**

企業にも顧客の声を集める仕組みはありますが、**広報部門が担っているとは限りません。**カスタマーサポートやマーケティングに分かれていることが多くなります。

**だから、広聴の経験は「広報の枠を超えた経験」として説明したほうが伝わります。**

:::insight
広報広聴課の方が職務経歴書で損をしやすいのは、**②の「削る」工程を書かないこと**です。書類に並ぶのは「広報紙の編集」「SNSの運用」「ホームページの改修」という工程名ばかりで、**いちばん手間がかかっている「制度の文章を、使う人の言葉に直す」部分が消えています。**ここは企業でも人が足りない領域です。専門用語で書かれた仕様や制度を、顧客や社員に伝わる形に直せる人は多くありません。書き方としては、**「所管課の原稿を、対象・期限・窓口の3点に整理し直したうえで、削った内容が不正確になっていないかを所管課と突き合わせて確定させた」**のように、**工程として書いてください。**「分かりやすくした」では伝わりません。**何を基準に削り、誰と確認したか**まで書くと、編集の仕事をしていた人だと読まれます。
:::

## 評価が高くなりやすい4つの方向

**1. 企業の広報・コーポレートコミュニケーション**

**報道発表の経験がそのまま効きます。**記者からの問い合わせに答え、事実関係を確認し、出せる範囲を決める。**この判断の型は企業でも同じ**です。

特に、**危機管理時の情報発信を経験している方**は評価されます。災害、事故、不祥事。**事実が固まる前に、何を出し何を出さないかを決めた経験**は、企業の広報でそのまま求められます。

**2. オウンドメディア・コンテンツ編集**

**定期刊行物を、期限どおりに、一定の品質で出し続けた経験**が効きます。企業のメディア運営でも、**続けられるかどうかが最大の課題**です。

**発行回数、部数、ページ数、継続年数**を必ず書いてください。

**3. 自治体を顧客にする企業**

広告代理店、印刷会社、シティプロモーションの支援会社、自治体向けのウェブ制作会社。**発注する側にいた経験が、そのまま提案に使えます。**

**入札・プロポーザルの実際を知っている**ことも大きな材料になります。**どういう提案が通り、どこで落ちるか**を、審査する側から見てきています。

**4. マーケティング・ユーザーコミュニケーション**

**VOCの収集と分析**という形で効きます。広聴で集まった声を分類し、所管課に返してきた経験は、**顧客の声を製品側に返す仕事と同じ構造**です。

[公務員の経験が活きる求人を見てみる](../?gov=1)

:::insight
方向を決めるときに、**残るほうが妥当だと感じる場面**もあります。広報広聴課は、**自治体の中では珍しく、成果が外から見えやすい部署**だからです。広報紙は住民の手元に届き、報道発表は記事になり、SNSの反応は数字で残ります。**この「外に出る仕事」を、自治体の中で続けられる場所は限られています。**そして、シティプロモーションや移住定住のように、**数年かけて結果が出る仕事**に関わっている途中なら、**その一巡を終えてからのほうが、経歴として厚くなります。**企画から実施、効果の測定までを通した経験は、途中で抜けると説明しにくくなるためです。一方で、**広報紙の制作だけが担当範囲で、広聴や報道対応に関わっていない**なら、外に出たほうが幅は広がります。**担当範囲が一巡しているかどうか**が、判断の分かれ目になります。
:::

## つまずきやすい点

**1. 「広報紙を作っていた」で説明を終える**

**編集・報道対応・ウェブ・広聴の4つに分けて**、それぞれ何をどこまでやったかを書いてください。

**2. 「削る」工程を書かない**

**いちばん手間がかかっている部分です。**工程として書いてください。

**3. 数字を持っていない**

発行部数、発行回数、ページ数、報道発表の件数、ホームページの月間閲覧数、SNSのフォロワー数、広聴で受けた件数。**公表されている範囲で控えておいてください。**

**4. 広聴の経験を落とす**

**民間の広報部門にはあまりない工程**です。**VOCの収集と分析**として書けば、価値が伝わります。

**5. 作った現物を手元に残していない**

広報紙や制作物は、**公表されているものであれば、実物が最も強い材料**になります。**在職中に、自分が担当した号を控えておいてください。**未公表のものや、個人が写り込んでいるものは使えません。

どの経験がどの方向で値が付くかは、募集の出方で変わります。[経歴を見ながらの相談もできます](../apply.html)。ご利用は無料です（紹介手数料は採用企業の負担です）。

## まとめ

- 地方自治法第10条第2項は、住民が**役務の提供をひとしく受ける権利**を有すると定めています。**知られていない制度は使われない**ため、広報は**到達の設計**の仕事です
- 第74条の直接請求に至る手前で、**声を集めて政策に返す**のが広聴の位置づけです
- 民間での訳語は、**オウンドメディアの編集／メディアリレーション／VOCの収集と分析／コミュニケーション設計**が中心になります
- 中核スキルは**①誰に届けるかを決める ②何を伝えるかを削る ③経路を選ぶ ④出す ⑤届いたかを確かめ、次に返す**の5工程です
- 民間の広報と**同じ**なのは、原稿が集まる構造・期限が動かないこと・正確さと読みやすさの調整。**違う**のは、目的が「売る」か「届ける」か、出せない情報の性質、広聴機能の有無です
- 評価が高くなりやすいのは、**企業広報／オウンドメディア編集／自治体を顧客にする企業／マーケティング**の4方向です

## よくある質問

### デザインができないのですが、編集の経験として通用しますか

**編集と制作は別の仕事として扱われます。**自治体の広報紙も、レイアウトや印刷は委託していることが多く、**職員は企画・原稿・校正・進行を担っている**のが普通です。募集要項でも、**編集ディレクションと制作は分けて書かれている**ことがほとんどなので、「デザインは委託先が担い、自分は企画と進行と校正を担当した」と正確に書いてください。**できないことを書かないほうが、書類は強くなります。**

### SNSのフォロワー数が少ないのですが、書かないほうがよいですか

**数字の大小より、運用の中身のほうが読まれます。**自治体のアカウントは、母数が人口に制約されるため、企業と単純には比べられません。書くなら、**投稿頻度、運用体制（何人で回していたか）、災害時の運用の切り替え、炎上を避けるための確認手順**のほうが効きます。**災害時に運用を切り替えた経験があれば、それが最も評価される材料**です。

### 報道対応の経験は、どこまで書いてよいですか

**公表済みの案件について、対応の型を書く範囲にとどめてください。**取材の相手方、未公表の案件、個別の記者とのやりとりは書けません。書けるのは、**「年間◯件の報道発表を行い、事実関係の確認手順と、出せる範囲の判断を所管課と整理していた」**といった形です。**判断の構造だけを書く**のが原則になります。
