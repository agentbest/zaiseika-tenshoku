物流を検討される方から、**同じ言葉を伺います。**

**「運んだこともないのに、評価されるものがあるでしょうか」**

**あります。**しかも、**ご本人がいちばん軽く見ている部分**が評価されます。

**理由は、事業者の側が何を義務として負っているかを見れば分かります。**この記事では、**法令上の仕組みから逆算して、どの経験が評価されるか**を扱います。

業界の構造は[未経験から物流に入るには](industry-butsuryu-mikeiken.html)、選考の進み方は[物流の選考フローと、面接で見られている観点](industry-butsuryu-senko.html)にあります。

## 倉庫には、管理を担う者を選任する義務があります

**倉庫業法第11条**です。

> **（倉庫管理主任者）第十一条　倉庫業者は、倉庫ごとに、管理すべき倉庫の規模その他の国土交通省令で定める基準に従つて、倉庫の適切な管理に必要な知識及び能力を有するものとして国土交通省令で定める要件を備える倉庫管理主任者を選任して、**倉庫における管理の業務を行わせなければならない。

**「倉庫ごとに」「選任して」「行わせなければならない」**です。

**[物流の選考フローと、面接で見られている観点](industry-butsuryu-senko.html)で扱った運行管理者**と、**構造が同じ**です。**運ぶ側にも、預かる側にも、管理を担う者を置く義務がある。**

**この業界は、「管理を担う人を置き、記録を残し、行政の確認を受ける」仕組みの上に成り立っています。**

**⚠ 倉庫管理主任者の要件については、所管する国土交通省の公表を確認してください。**当社が確認していない内容は、この記事には載せていません。

## 行政は、報告を求め、立入検査をします

**貨物自動車運送事業法第60条第1項**です。

> **（報告の徴収及び立入検査）第六十条　国土交通大臣は、この法律の施行に必要な限度において、国土交通省令で定めるところにより、貨物自動車運送事業者に対し、その事業に関し報告をさせることができる。**

**同条第2項**は、**立入検査**について定めています。

**つまり、この業界の事業者は、行政から報告を求められ、立入検査を受ける立場**にあります。

**役所で監査や立入検査をしてきた方**は、**その相手側に回る**ことになります。

| 役所の側 | 事業者の側 |
|---|---|
| 報告を求める | **報告を作成して提出する** |
| 立入検査で記録を確認する | **記録を検査に耐える状態で保つ** |
| 不備を指摘する | **指摘を受けないよう日常的に点検する** |
| 是正を求める | 是正の計画を作り、実行する |
| 改善の報告を受ける | **改善したことを記録で示す** |

**右の列をできる人**が、**この業界では足りていません。**

**理由は、現場からの登用で育った担当者が多く、「検査で何を見られるか」を外から知る機会が少ないから**です。

## 評価される経験は、5つに整理できます

| 経験 | 物流での呼ばれ方 | なぜ評価されるか |
|---|---|---|
| ① 勤務時間・休暇の管理 | 運行管理、労務の管理 | **法令に紐づく管理の中核** |
| ② 記録の整備と保存 | 点呼の記録、日報、帳簿の管理 | **立入検査で見られるもの** |
| ③ 監査・立入検査の対応 | 行政の監査への対応 | **検査する側にいた** |
| ④ 契約・委託の管理 | 荷主との契約、協力会社の管理 | **契約と実態を対応させる仕事** |
| ⑤ 要綱・規程の作成 | 安全管理規程、社内の手順 | 条文の形で書くことに慣れている |

**①が、いちばん求められています。**

**役所で、超過勤務の命令と実績の管理、休暇の承認、職員の健康管理の手続き**を担当していた方は、**運行管理の中核と、やることの構造が同じ**です。

**②も直結します。**この業界で**記録は、事業を続けるための条件**です。**点呼の記録、運転日報、車両の点検の記録、倉庫の入出庫の帳簿。**これらが揃っていないと、**検査で指摘を受けます。**

**役所の仕事は、記録を残すことを前提に組まれています。**その習慣が、そのまま価値になります。

**④は、[物流の志望動機](industry-butsuryu-shiboudoki.html)で扱ったとおり、この業界がいま整理している部分**です。

## 言い換えの表

**職務経歴書に、役所の言葉のまま書かないでください。**

| 役所での言い方 | 物流に伝わる言い方 |
|---|---|
| 超過勤務の命令・実績の管理 | **◯人分の勤務時間の管理と、月次の集計** |
| 休暇の承認 | 勤務の割り当てと、要員の調整 |
| 文書の収受・保存 | **記録の保存期間の管理と、検索できる整理** |
| 立入検査 | **現地での運用状況の確認と、是正の要求** |
| 監査の指摘への対応 | 指摘への対応と、再発防止の仕組みの整備 |
| 要綱の制定・改正 | 内部規程・様式の作成と改正 |
| 業務委託の契約事務 | **委託の仕様の作成、履行の確認、精算** |
| 入札の執行 | 調達手続きの運用と、業者の選定 |
| 苦情・相談の対応 | 近隣・荷主からの申し出への対応 |

**⚠ 件数と規模を必ず入れてください。**「勤務時間の管理」ではなく**「係◯人分の勤務時間の管理を月次で」**です。

## 評価されにくい経験

**正直に書いておきます。**

| 経験 | 評価されにくい理由 |
|---|---|
| 特定の制度の細かい運用の知識 | **物流に関わらない制度は使えない** |
| 庁内の根回しの経験 | 相手も組織の形も違う |
| 前例の踏襲を徹底した実績 | **計画が崩れる場面が日常的にある** |
| 在籍年数そのもの | 年数より、何を担ったか |
| 役職の名称 | **対応する段階が会社側に無い** |

**「係長を◯年」という書き方は、この業界では効きません。**

**書くなら、「◯人の係の事務の進行を管理し、年間◯件を処理した」**です。

**3つ目について補足します。**この業界では、**事故、渋滞、天候、設備の故障**で、計画が当日に崩れます。**前例どおりに処理することが正解にならない場面**が定期的にあります。

**ただし、災害対応・選挙の事務・感染症の対応を経験した方**は、**その状況を知っています。**書いてください。

:::insight
面談で拝見していて、**物流を受ける方がいちばん取りこぼしているのが「文書の保存」の経験**です。皆さん、**「文書管理をしていました」と一言で片づけて**しまわれます。ところが、**この業界で記録は、事業の継続に直結します。**点呼の記録、運転日報、車両の点検の記録、倉庫の帳簿。**これらには保存の期間が定められているものがあり、立入検査で確認されます。**そして、現場では**「記録は取っているが、探せない」**という状態が起こりがちです。取った記録が箱に入ったまま、検査の前日に総出で探す。**これは、珍しい話ではありません。**役所の側にいた方は、**文書の分類、保存期間の設定、廃棄の手続き、検索できる状態での保管**を、制度として運用してきています。**この経験は、そのまま持ち込めます。**そして、**入って最初の3か月で成果が出しやすい領域**でもあります。記録の分類を整理し、保存期間の一覧を作り、置き場所を決める。**これだけで、次の検査のときに目に見えて楽になります。**職務経歴書には、**「文書管理」ではなく「保存期間の設定と、分類・検索できる状態での保管の運用」**と書いてください。**何ができる人かが伝わります。**
:::

## 職務経歴書での並べ方

| 位置 | 書くもの |
|---|---|
| 冒頭の要約（3〜4行） | **労務・記録・契約のうち、担った機能** |
| 職歴の1つ目 | 直近の担当。**人数・件数・規模を入れる** |
| 職歴の2つ目以降 | **応募先の職種に近いものを前へ** |
| 実績の欄 | **「変えた話」**（様式を作った、探せるようにした） |
| 資格・研修 | 運行管理、衛生管理、簿記などの学習 |

**冒頭の要約を必ず付けてください。**物流の中途採用では、**拠点の責任者が書類を読みます。**読む時間は限られています。

**実績の欄は、「担当した」ではなく「何が変わったか」**で書いてください。

**⚠ 公表されていない内部の事情や、特定の事業者に関する情報は書かないでください。**守秘の観点に加えて、**それを書く人は、次の職場の情報も外で話す**と見られます。

[経験の言い換えから相談する](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担です）。

## 面接で聞かれやすいこと

| 聞かれること | 何を確かめられているか |
|---|---|
| 記録の管理をした経験はありますか | **この業界の中核** |
| 何人分の勤務時間を管理していましたか | **①の規模** |
| 立入検査では、何を見ていましたか | **受ける側に回れるか** |
| 計画が崩れたときに、どう動きましたか | 突発への対応 |
| 現場の方と話をした経験はありますか | 立ち位置の理解 |

**3つ目は、この業界での強い持ち札**です。

**答え方は、指摘した話ではなく、見ていた観点**にしてください。「記録が揃っているか、日付と担当者が入っているか、実際の運用と記録が一致しているか」。**これは、そのまま事業者側の自主点検の観点になります。**

**5つ目は、正直に答えて構いません。****「現場の作業の経験はありません。ですから、まず立ち会わせていただきます」**で足ります。

:::insight
ここまで「評価される」話をしてきましたが、**申し上げておきたいことがあります。**評価される経験があることと、**移ったほうがよいことは、別**です。面談で、**「思ったより評価されると分かったので、動かないといけない気がしてきました」**とおっしゃる方がいらっしゃいます。そうではありません。**この経験は、消えません。**勤務時間を管理した事実、記録の保存を運用した事実、検査をした事実。**異動して別の分野に移っても、担った事実は残ります。**ですから、**いま動く理由が他にある場合**——通勤の事情、家族の事情、担いたい役割が変わった——**その理由で判断してください。**「評価されるから」は、**動く理由としては弱い**です。とくにこの業界は、**[物流の年収と働き方](industry-butsuryu-nenshu.html)で扱ったとおり、職種によって生活の組み立て方が大きく変わります。**勤務の時間帯、拠点の場所、通勤の手段。**これらが合わないなら、評価される経験があっても、続きません。**確認の順番としては、**「評価されるか」より先に「条件が合うか」**です。条件が合ったうえで、**評価される経験を持っていることが効いてきます。**順番を逆にしないでください。在職のまま、整理だけのご相談も承っています。
:::

## まとめ

- **評価される経験は、事業者が負っている義務から逆算できます**
- **倉庫業法第11条**は、**倉庫業者が倉庫ごとに倉庫管理主任者を選任し、管理の業務を行わせなければならない**と定めています。**運ぶ側にも預かる側にも、管理を担う者を置く義務があります**
- **貨物自動車運送事業法第60条**は、**国土交通大臣が事業者に報告をさせることができる**と定め、**立入検査**についても定めています
- **事業者は、報告を求められ、立入検査を受ける立場**です。**検査する側にいた経験は、受ける側の準備に直結します**
- 評価される経験は、**①勤務時間・休暇の管理 ②記録の整備と保存 ③監査・立入検査の対応 ④契約・委託の管理 ⑤要綱・規程の作成**の5つです
- ⚠ **「文書管理」を一言で片づけないでください。****保存期間の設定と、検索できる状態での保管**は、この業界で**入って3か月で成果が出る領域**です
- 職務経歴書は、**人数・件数・規模**を入れて書いてください。**役職の名称は効きません**
- ⚠ **確認の順番は、「評価されるか」より先に「条件が合うか」**です。勤務の時間帯・拠点の場所・通勤の手段を先に確認してください
- **評価されることと、移ったほうがよいことは別**です

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 労務の経験がありません。他に材料はありますか

**②③④が材料になります。**文書の保存の運用、監査の対応、契約事務。**どれも、この業界の実務に対応するものがあります。**とくに、**業務委託の契約事務**は、物流会社が**協力会社に業務を委託する場面**と重なります。仕様の作成、履行の確認、精算。**やることの構造が同じ**です。また、**窓口で苦情を受けてきた経験**は、**近隣からの申し出や、荷主からの照会への対応**に対応します。書き方は、**件数と、一連の流れを担ったこと**を入れてください。労務の経験が無いことを、応募しない理由にしないでください。**職種を選べば、材料はあります。**

### 技術職です。土木や建築の経験は使えますか

**使えます。**物流の拠点は**建物と設備の集合体**なので、**施設の管理、修繕の計画、設備の更新の発注**を担う職種があります。役所で**工事の発注と監督**をしていた方なら、**仕様書の作成、業者との協議、検査**の経験がそのまま重なります。また、**消防法や建築基準法にもとづく点検・届出**を扱っていた方は、**拠点側の対応する業務に直接つながります。**近年は**自動化された設備を備えた拠点**も増えており、**設備の保全を担う人の需要**があります。探し方は、**「設備管理」「施設管理」「工務」**といった職種名です。**製品や荷物の知識は、入ってから覚える前提**で構いません。

### 資格を先に取るべきですか

**職種によります。****運行管理者や倉庫管理主任者**は、**選任される職に就くために要件がある**ため、応募先の職種によって扱いが変わります。一方、**総務・人事・経理・安全の職種**では、これらの資格は求められません。⚠ **要件や試験については、所管する国土交通省や実施する機関の公表を確認してください。**当社が確認していない内容はお伝えできません。一般論として申し上げられるのは、**資格が無い状態で補助の立場から入る募集がある**ということだけです。**学習を始めていること自体は、関心の本気度として伝わります。**まず、**自分が応募する職種に資格が要るかどうか**を、求人票で確認してください。
