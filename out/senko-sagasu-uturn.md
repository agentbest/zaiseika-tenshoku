**地元に戻ることを考えている、というご相談を伺います。**

**家族の事情、住まい、生活の組み立て。**

**理由はさまざま**です。

この記事では、**使える窓口**と、**遠隔地からの進め方**を扱います。

## 自治体が職業紹介を行える仕組みがあります

**職業安定法第29条第1項**です。

> **地方公共団体は、無料の職業紹介事業を行うことができる。**

**同条第2項**は、**特定地方公共団体が行う場合の厚生労働大臣への通知**を定めています。

**同条第3項**です。

> 特定地方公共団体は、**取扱職種の範囲等**（その職業紹介事業において取り扱う職種の範囲その他業務の範囲をいう。以下同じ。）**を定めることができる。**

**扱う職種の範囲を定められる**という仕組みです。

**つまり、自治体が行う紹介では、扱う分野が限られていることがあります。**

**移住や就職の相談の窓口が置かれている団体があります。**

**自分が戻りたい地域の窓口があるかを、先に確認**してください。

## 使える窓口

| 窓口 | 特徴 |
|---|---|
| ① 自治体の移住・就職の相談 | **地域の事情に詳しい** |
| ② 都市部にある地域の相談の窓口 | 出向かずに相談できることがあります |
| ③ 公共職業安定所 | 全国の求人を扱います |
| ④ 紹介事業者 | 地域を指定して相談できます |
| ⑤ 求人の検索サイト | 地域で絞り込めます |

**①と②を併用**してください。

**②について。**

**都市部に、地方の自治体が相談の窓口を置いていることがあります。**

**戻る前に相談できる**という点で、在職中には使いやすい形です。

**なお、窓口の有無と内容は団体によって異なります。**

## 地元の求人の特徴

| 特徴 | 内容 |
|---|---|
| 数が限られる | **都市部と比べて件数が少ない** |
| 時期が読めない | 募集が出る時期が事業の周期に左右されます |
| 掲載されないことがある | **地元の媒体や会社のページのみ**の場合があります |
| 行政が相手の事業がある | 地域に拠点を置く会社があります |
| 知人の紹介 | 地域によっては一般的です |

**3行目です。**

**全国向けの求人サイトに載らない募集**があります。

**地元の新聞、地域の媒体、会社のウェブサイト。**

**探す先を増やしてください。**

**4行目について。**

**指定管理、業務委託、発注者支援、建設コンサルタント。**

**これらは、地域に根ざして事業を行う会社が担っていることがあります。**

**公務員としての経験が重なる**領域です。

## 遠隔地から進めるときの段取り

| 順 | やること |
|---|---|
| 1 | 戻る時期の目安を決める |
| 2 | 地域の窓口に相談する |
| 3 | 求人を探す（複数の経路で） |
| 4 | **オンラインでの選考が可能か確認** |
| 5 | 帰省の予定に合わせて面接をまとめる |
| 6 | 住まい・学校の手続きを並行 |

**4と5が要**です。

**移動に時間と費用がかかる**ため、**一度の帰省で複数社の面接を組む**ほうが効率的です。

**応募の段階で、日程をまとめられるかを相談**して差し支えありません。

**オンラインでの一次選考が可能な会社もあります。**

**確認の仕方は、「遠方のため、オンラインでの実施は可能でしょうか」で足ります。**

## 費用と時間の見積もり

| 項目 | 内容 |
|---|---|
| 交通費 | **負担の有無を確認**（会社によります） |
| 宿泊 | 面接が複数日にわたる場合 |
| 休暇 | 帰省と面接を兼ねる場合 |
| 移動の時間 | 前後の日程に余裕を |

**1行目です。**

**面接の交通費の扱いは、会社によって異なります。**

**支給される場合、支給の方法と時期を確認**してください。

**支給されない場合もあります。**

**確認しておくと、予定が立てやすくなります。**

:::insight
Uターンのご相談で、**面談でお聞きしているのが「戻る時期が先か、仕事が先か」**という点です。この順序によって、進め方が変わります。**時期が先に決まっている場合**——家族の事情や住まいの都合で、**「◯年◯月には戻る」**と決まっているなら、**その時期から逆算して選考を組みます。**この場合、**求人が出るのを待つ余裕が小さい**ため、**複数の経路を同時に使う**ことになります。一方、**仕事が先の場合**——条件の合う求人が見つかったら戻る、という進め方なら、**待てます。**地域の求人は**数が限られ、時期も読めない**ため、**待てること自体が有利に働きます。**条件を登録しておいて、出たときに動く形です。**この2つを混ぜると、判断が難しくなります。**「いい求人があれば」と言いながら時期も決めている状態だと、**どちらも中途半端になります。****先にどちらかを決めてください。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 家族との調整

| 項目 | 確認すること |
|---|---|
| 学校・保育 | 転校・転園の手続きと時期 |
| 配偶者の仕事 | 続けられるか、変わるか |
| 住まい | 実家、賃貸、持ち家 |
| 介護 | 戻る理由が介護の場合の体制 |
| 生活の変化 | 車の要否、買い物、通院 |

**5行目です。**

**地域によっては、日常の移動に車が必要**になります。

**支出の構成が変わる**ため、**生活の費用を並べて確認**してください。

**伝え方は**[家族への伝え方と、反対されたときの整理](senko-taishoku-kazoku.html)**に整理しています。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 地元の自治体を受ける場合

| 項目 | 内容 |
|---|---|
| 経験者の採用 | 実施の有無は団体によります |
| 募集の時期 | 公表されます |
| 要件 | 職務経験の年数などが定められます |
| 情報の確認 | **その団体の公表を直接確認** |

**4行目です。**

**実施の有無、時期、要件は、団体ごとに異なります。**

**人づての情報ではなく、公表されている募集要項を確認**してください。

**なお、民間への転職と並行して検討して差し支えありません。**

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 地域の窓口への相談 | オンラインや電話で可能な場合があります |
| 求人を読む | 地域を指定して検索 |
| 職務経歴書の準備 | 1通目を仕上げる |
| 帰省の予定の確認 | 面接に充てられる日 |

**4行目を早めに**してください。

**帰省の予定が決まれば、逆算して応募の時期が決まります。**

**年末年始や連休は、面接の日程が組みにくい時期**でもあります。

**前後にずらせるかを、先に確認**してください。

## よくある失敗

**1. 戻る時期と仕事のどちらを先にするか決めない**

**判断が難しくなります。**

**2. 全国向けのサイトだけで探す**

**地元の媒体や会社のページ**も見てください。

**3. 自治体の窓口を使わない**

**地域の事情に詳しい**窓口があります。

**4. 面接を1社ずつ組む**

**移動の負担が増えます。**

**5. 交通費の扱いを確認しない**

**予定が立てにくくなります。**

**6. 生活の費用の変化を見ない**

**支出の構成が変わります。**

**7. 学校・保育の手続きの時期を確認しない**

**入社の時期と合わないことがあります。**

:::insight
ここまで段取りの話をしておいて逆のことを言いますが、**「地元に仕事がない」と決めつけないでください。**面談で拝見していると、**求人サイトで地域を指定して検索し、件数の少なさを見て諦めてしまう方**がいらっしゃいます。ところが、**地域の求人は、掲載される場所が分散しています。**全国向けのサイトに載らず、**地元の媒体、会社のウェブサイト、自治体の窓口**にだけ出ているものがあります。そして、**行政が相手の事業は、その地域に拠点を置く会社が担っています。**指定管理者は、**その施設がある地域で事業を行います。**発注者支援も、**その自治体の区域で業務が行われます。**つまり、**公務員としての経験が使える仕事は、地域に存在します。**探す場所を変えてください。**自治体の公表資料から、地域で事業を担っている会社を逆に探す**という方法もあります。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **職業安定法第29条第1項**は、**地方公共団体が無料の職業紹介事業を行うことができる**と定めています。**取扱職種の範囲等を定められる**ため、扱う分野が限られることがあります
- 窓口は、**自治体の移住・就職の相談、都市部の地域の窓口、公共職業安定所、紹介事業者、求人サイト**です
- 地元の求人は、**掲載される場所が分散**しています。探す先を増やしてください
- **戻る時期が先か、仕事が先か**を決めてください
- **一度の帰省で複数社の面接をまとめる**ほうが負担が小さくなります
- **交通費の扱いと、生活の費用の変化**を確認してください
- **行政が相手の事業は、その地域に拠点を置く会社が担っています**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 地元に、行政が相手の会社があるか分かりません

**自治体の公表資料から探せます。**その自治体のウェブサイトで、**「指定管理者」「入札の結果」「契約の公表」「プロポーザル」**を見てください。**どの会社が、どの事業を担っているか**が分かります。そこから、**会社のウェブサイトで採用の情報を確認**します。**掲載がなくても、問い合わせて差し支えありません。**「採用の予定について伺いたい」という照会です。なお、**建設コンサルタント、施設の運営、窓口の受託、情報システム**などは、地域に拠点を置いていることが多い領域です。調べ方は[応募前の企業調査で見るべき資料](senko-sagasu-kigyochosa.html)に整理しています。

### 面接のために何度も帰省するのは難しいです

**まとめる相談をしてください。**「遠方のため、複数社の面接を同じ週に入れたい」という事情は、**伝えれば調整の対象**になります。また、**オンラインでの実施が可能な会社もあります。**一次選考はオンライン、最終だけ対面、という形もあります。**応募の段階で確認**してください。なお、**紹介を通す場合、日程をまとめる調整を任せられます。**複数社の面接を同じ日程に寄せる相談ができます。扱いは[転職エージェントの使い方](senko-sagasu-agent.html)に整理しています。**移動の負担は、先に伝えておくほうが調整しやすくなります。**

### 地元に戻ると、扱う仕事の幅が狭くなりませんか

**領域は変わりますが、狭くなるとは限りません。**地域に拠点を置く会社では、**1人が担う範囲が広い**ことがあります。都市部の会社で職種が細かく分かれている業務を、**まとめて担当する**形です。**これを負担と見るか、関われる範囲が広いと見るかは、人によります。**判断の目安は、**求人票の仕事内容**です。**担当の範囲がどこまでかを確認**してください。なお、**行政が相手の事業では、複数の自治体を担当する**こともあります。**その場合、地域をまたいで仕事をすることになります。**勤務地と担当の区域は別のものとして確認してください。
