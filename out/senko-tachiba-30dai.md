**複数の部署を経験し、担当の範囲が広がった段階**です。

**後進の指導が始まっている方もいらっしゃいます。**

この記事では、**評価される点**と、**書類の組み立て**を扱います。

## 自分の職務についての記録があります

**地方公務員法第23条第1項**です。

> **職員の人事評価は、公正に行われなければならない。**
>
> ２ 任命権者は、**人事評価を任用、給与、分限その他の人事管理の基礎として活用する**ものとする。

**同法第23条の2第1項**です。

> **職員の執務については、その任命権者は、定期的に人事評価を行わなければならない。**

**定期的に行われる**という仕組みです。

**つまり、自分の職務について、目標と実績を整理した記録が毎年作られている**ということです。

**職務経歴書を書くときの材料は、すでに手元にあります。**

**評価の結果そのものを書類に載せる必要はありません。**

**評価の際に自分で書いた「何を担当し、何を達成したか」の記述が、材料になります。**

**過去数年分を読み返すところから始めてください。**

## 何が見られているか

| 項目 | 内容 |
|---|---|
| ① 担当した範囲 | **1人で完結する範囲の広さ** |
| ② 判断の経験 | 例外や困難な事案の処理 |
| ③ 調整の経験 | 他課、他団体、事業者との折衝 |
| ④ 後進への指導 | 人数、方法、作った資料 |
| ⑤ 制度への対応 | 改正への対応、手順の整備 |
| ⑥ 次に何をしたいか | 条件の明確さ |

**①と②が中心**です。

**20代との違いは、「言われたことをした」から「自分で決めた」へ移っている点**です。

**決めた範囲を書いてください。**

## 書き方の例

**悪い例**

> ◯◯課で、申請の審査を担当しました。

**良い例**

> ◯◯課で、年間約◯件の申請の審査を担当。**制度の要件に当てはまらない事案について、類似の事例と関係法令を確認したうえで判断の方針を整理し、◯件を処理。**新任の担当者◯人に対し、確認の手順書と記入例を作成して指導。

**後者は、「範囲」「判断」「指導」の3つが入っています。**

**これが、30代で求められる書き方**です。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 複数の部署を経験している場合

| 書き方 | 内容 |
|---|---|
| 時系列で並べる | 在籍の一覧として |
| **機能でまとめる** | 審査、調整、契約、説明などの軸で |
| 両方を書く | 一覧＋機能のまとめ |

**2行目です。**

**部署の名前を並べるだけでは、何ができるかが伝わりません。**

**「審査と決定」「契約と調達」「対外の説明」のように、機能でまとめ直して**ください。

**異動が多い場合の整理は**[異動が多い公務員の職務経歴書の並べ方](senko-shokumu-ido.html)**に整理しています。**

## 両立している場合

| 事情 | 整理すること |
|---|---|
| 育児 | 勤務できる時間、急な対応の可能性 |
| 介護 | 同上 |
| 配偶者の勤務 | 転勤の可否、通勤の範囲 |
| 住まい | 転居の可否 |

**勤務の条件に関わる範囲を、先に整理**してください。

**条件が決まっていれば、求人を絞る軸になります。**

**伝え方は**[家族への伝え方と、反対されたときの整理](senko-taishoku-kazoku.html)**に整理しています。**

:::insight
30代のご相談で、**面談でお聞きしているのが「人事評価のときに書いた記述を読み返しましたか」**という点です。多くの方が、**職務経歴書を一から書こうとして、何を書けばよいか分からず止まります。**ところが、**毎年の人事評価で、自分の担当と実績を文章にしているはず**です。目標として掲げたこと、その結果として書いたこと。**これは、そのまま職務経歴書の材料になります。**しかも、**当時の記憶が新しい状態で書かれたもの**です。数年前の件数や対象は、後から思い出そうとしても正確に出てきません。**手元に控えがあれば、読み返してください。**そのうえで、**民間の言葉に置き換える**作業をします。「◯◯条例に基づく審査」を「基準に照らした判断と、その記録」に。**評価の記述をそのまま使うのではなく、下敷きとして使う**という位置づけです。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 求人を選ぶ軸

| 軸 | 内容 |
|---|---|
| 顧客が誰か | 行政、企業、消費者 |
| 担当の範囲 | 広いか、専門に絞るか |
| 判断の範囲 | どこまで自分で決めるか |
| 勤務の条件 | 時間、場所、転勤 |
| 育成の有無 | 人を見る立場になるか |

**3行目です。**

**役所で自分の判断で進めてきた方が、手順に沿うだけの業務に移ると、合わないことがあります。**

**逆に、判断の負担を減らしたい場合もあります。**

**どちらを求めているかを、先に決めてください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 残るという判断

| 場面 | 考えること |
|---|---|
| 昇任の見込み | **段階が変われば、書けることが増えます** |
| 希望する部署への異動 | 可能性と時期 |
| 制度・資格の機会 | 在職中に得られるもの |
| 条件を比べた結果 | いまのほうが合っている場合 |

**1行目です。**

**次の段階に上がる見込みがあるなら、上がってから動くほうが、書けることが増えます。**

**焦って動く理由は、この年代では多くありません。**

**判断は、材料が揃ってからで差し支えありません。**

## 準備の順序

| 順 | やること |
|---|---|
| 1 | **過去数年の人事評価の記述を読み返す** |
| 2 | 担当した業務を、件数・対象・範囲で書き出す |
| 3 | 機能でまとめ直す |
| 4 | 続けたい部分と、負担だった部分を分ける |
| 5 | 求める条件を決める |
| 6 | 求人を読む |
| 7 | 職務経歴書を作る |

**1と4が要**です。

**1は材料の収集、4は条件の決定**にあたります。

**この2つが終わっていれば、書類は1日で形になります。**

**逆に、この2つを飛ばすと、何度書き直しても定まりません。**

## 在職中の進め方

| 項目 | 目安 |
|---|---|
| 記録を取る | 月に1回、数行 |
| 求人を読む | 週に30分 |
| 条件の見直し | 月に1回 |
| 書類の作成 | まとまった時間を1回 |

**1行目です。**

**担当した件数と、その月に新しく扱ったこと。**

**この2つを残しておくと、書類を作るときに使えます。**

**思い出して書くより、記録から書くほうが正確**です。

## よくある失敗

**1. 部署の名前だけを並べる**

**機能でまとめ直して**ください。

**2. 人事評価の記述を読み返さない**

**材料は手元にあります。**

**3. 判断した範囲を書かない**

**30代で中心に見られる部分**です。

**4. 後進への指導を書かない**

**人数と作った資料**を書いてください。

**5. 勤務の条件を整理しない**

**求人を絞る軸になりません。**

**6. 判断の範囲を求人で確認しない**

**入社後に合わないことがあります。**

**7. 昇任の見込みを計算に入れない**

**段階が変われば書けることが増えます。**

**8. 「まだ何者でもない」と考える**

**担当し、決めてきた事実**があります。

:::insight
ここまで書き方の話をしておいて逆のことを言いますが、**30代は、経験の説明より条件の説明のほうが難しい**です。面談で拝見していると、**経歴は整理できているのに、「何をしたいか」が出てこない方**がいらっしゃいます。理由は、**役所では、担当は与えられるもの**だったからです。希望を出す機会はあっても、**自分で選び取る経験は多くありません。**ですから、**「何をしたいか」を問われると、答えが用意されていない。**この場合は、**過去の担当から逆に考えてください。**これまで担当した業務のうち、**続けたいと思えた部分はどれか。****負担が大きかった部分はどれか。**業務の量、扱う内容、判断の責任、対外の対応、人との関わり方。**この5つで分けると、輪郭が出ます。**そして、**続けたい部分が多い求人**を探す。**これが、条件の作り方**です。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方公務員法第23条・第23条の2**により、**人事評価は定期的に行われ、任用・給与・分限その他の人事管理の基礎として活用**されます。**自分の職務についての記録が毎年作られています**
- **人事評価の際に書いた記述が、職務経歴書の下敷き**になります
- 見られているのは、**担当した範囲、判断の経験、調整の経験、後進への指導、制度への対応**です
- **「範囲」「判断」「指導」の3つ**を書いてください
- 複数の部署を経験している場合は、**機能でまとめ直して**ください
- **判断の範囲を、求人で確認**してください
- **昇任の見込みがあるなら、上がってから動く**という選択もあります

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 係長になったばかりで、管理の経験が浅いです

**期間の長さより、何をしたかを書いてください。**係の事務の進行の管理、困難な事案の折衝、新任の指導、他課との調整。**これらは、期間が短くても書けます。**書き方は、**「係◯人の事務の進行を管理し、事業の計画に対する進捗を確認。遅れの見込まれる案件について、事業課と工程を調整」**という形です。**人数と、調整した相手を具体に**してください。なお、**「管理職ではないので書けない」と考えないでください。**中途採用で見られているのは、**役職の名称ではなく、担った役割**です。段階が変わったこと自体が、**求められるものが変わった証**になります。

### 転職を考えていると、いまの仕事に身が入りません

**在職中の業務は、書類の材料になります。**いま担当している業務の件数、扱った事案、作成した資料。**これらは、職務経歴書に書ける内容**です。**この視点で業務を見ると、記録を取る動機が生まれます。**また、**転職しない判断をした場合も、記録は人事評価の資料として使えます。**どちらに転んでも、無駄になりません。なお、**検討に時間がかかること自体は、珍しいことではありません。**求人を読む、条件を整理する、制度を確認する。**これらは、月に数時間で進みます。**日々の業務と並行して差し支えありません。

### 30代の後半になると、応募が難しくなりますか

**求人の条件によります。****労働施策総合推進法第9条**は、**募集及び採用について、年齢にかかわりなく均等な機会を与えなければならない**と定めています。年齢の記載がある求人では、**その理由が示されている**ことがあります。判断の目安は、**求人票の「必須」の欄**です。求められている経験が自分にあるかどうかで見てください。なお、**行政が相手の事業では、実務の年数が長いほうが評価される**ことがあります。制度の理解、折衝の経験、判断の実績。**これらは、年数とともに積み上がるもの**です。年代より、**経験の中身で判断**してください。
