**「人前で話すのは慣れているが、提案は苦手」**というご相談を伺います。

**説明と提案は、目的が違う技術**です。

この記事では、**違い**と、**足すべきもの**を扱います。

## 説明は、制度上の義務として組み込まれています

**地方自治法第121条第1項**です。

> 普通地方公共団体の長（略）並びにその委任又は嘱託を受けた者は、**議会の審議に必要な説明のため議長から出席を求められたときは、議場に出席しなければならない。**

**「審議に必要な説明のため」**と書かれています。

**説明することが、制度の中に義務として置かれている**ということです。

**そして、問われるのは「聞かれたことに正確に答えること」**です。

**提案して、決めてもらうことではありません。**

**行政で身につくのは、この形の技術**です。

## 説明と提案の違い

| 項目 | 説明 | 提案 |
|---|---|---|
| 目的 | **正確に理解してもらう** | **決めてもらう** |
| 起点 | 相手の問い | こちらの目的 |
| 構成 | 経緯、根拠、現状 | **結論、理由、依頼** |
| 網羅性 | 必要 | **絞る** |
| 終わり方 | 答え終える | **次の行動を求める** |
| 想定する反応 | 追加の質問 | 承諾、保留、断り |

**3行目と5行目が、最も大きな違い**です。

**説明では、経緯から順に述べるのが自然**です。

**提案では、結論から述べ、最後に行動を求めます。**

**この順序を入れ替えるだけで、伝わり方が変わります。**

## 行政で身についていること

| 技術 | 内容 |
|---|---|
| ① 根拠の明示 | **どの条文、どの資料によるか** |
| ② 想定問答 | 問われることを先に洗い出す |
| ③ 正確さ | 事実と推測を分ける |
| ④ 簡潔さ | 限られた時間で答える |
| ⑤ 関係者との事前の調整 | 論点を詰めておく |
| ⑥ 記録 | 答えた内容を残す |

**②が、民間でも強く効きます。**

**提案の場でも、質問への備えが結果を左右します。**

**「想定される問いを洗い出し、答えを用意しておく」**という習慣は、そのまま使えます。

## 提案で足すもの

| 足すもの | 内容 |
|---|---|
| ① 結論を先に置く | **最初の30秒で伝える** |
| ② 相手の利得 | 相手にとって何がよいか |
| ③ 選択肢 | 案を複数示し、推奨を述べる |
| ④ 数字の根拠 | 費用、効果、期間 |
| ⑤ 行動の依頼 | **次に何をしてほしいか** |
| ⑥ 想定される反対への備え | 先に触れておく |

**①と⑤が要**です。

**⑤について。**

**説明では、答え終えれば終わりです。**

**提案では、「◯月までにご判断いただきたい」「次回、詳細をお持ちします」**と、**次の動きを示して終わります。**

**この一言がないと、その場で止まります。**

## 資料の作り方の違い

| 項目 | 行政の資料 | 提案の資料 |
|---|---|---|
| 分量 | 網羅する | **絞る** |
| 順序 | 経緯から | 結論から |
| 図表 | 正確さを優先 | **伝わりやすさを優先** |
| 注記 | 詳しく | 必要最小限 |
| 想定する読み方 | 手元で読む | **その場で見る** |

**5行目です。**

**行政の資料は、手元で読まれることを前提に作られます。**

**提案の資料は、その場で見ながら聞かれます。**

**1枚に載せる情報の量が変わります。**

:::insight
プレゼンテーションについて、**面談でお伝えしているのが「想定問答を作れることを書いてください」**という点です。議会の答弁の準備をしてきた方は、**問われることを先に洗い出し、答えを用意する作業**を繰り返しています。**この作業が、民間の提案の場でもそのまま必要**です。提案の内容そのものより、**「その質問が来たときに答えられるか」で結果が決まる**場面があります。費用の根拠、他社との違い、失敗したときの扱い、社内で反対されたときの説明。**これらを事前に洗い出せる人は、多くありません。**書類には、**「議会での答弁に備え、想定される質問◯件を洗い出し、根拠の資料とともに整理」**と書いてください。**答弁そのものではなく、準備の作業**を書くのが要点です。**これは、営業でも、導入の支援でも、社内の提案でも使えます。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 説明した相手と場面 | **議会、住民、事業者、他団体** |
| 準備の仕方 | 想定問答、資料 |
| 難しかった場面 | 3件、状況と対応 |
| 提案の経験 | 庁内での提案でも可 |
| 資料の作り方 | 分量、構成 |

**4行目です。**

**外部への提案の経験がなくても、庁内での提案は経験しているはず**です。

**予算の要求、事業の企画、制度の改正の提案。**

**これらは、決めてもらうための説明**です。

**なお、特定の事案が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

## 書き方の例

**悪い例**

> 議会対応や住民説明会を担当しました。

**良い例**

> ◯◯の事業について、**住民説明会◯回（延べ参加者約◯名）の企画と進行**を担当。**想定される質問◯件を事前に整理し、根拠の資料を準備。**説明の後に寄せられた意見◯件を分類し、**事業の内容と周知の方法に反映。**庁内では、**◯◯の制度の改正について、現状の課題と◯案を比較した資料を作成し、課内会議で提案。**

**「回数」「準備」「反映」「提案」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 学ぶ前に考えること

| 確認すること | 内容 |
|---|---|
| ① すでにある経験 | **説明の場面、準備の作業** |
| ② 何が足りないか | 結論から話す、行動を求める |
| ③ 応募したい求人の条件 | 提案の経験が挙がっているか |
| ④ 期限 | 応募の時期までに間に合うか |

**②で分かれます。**

**話すこと自体に慣れているなら、足すのは構成と終わり方**です。

**講座を受けるより、手元の資料を組み替えて練習するほうが早い**ことがあります。

**なお、講座を受ければ転職できる、という関係にはありません。**

**誰に、何を、どう伝えてきたか**が、評価の対象です。

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 行政が相手の事業 | **根拠を求められる場面が多い** |
| ② 導入の支援 | 顧客の社内での説明 |
| ③ 研修・教育 | 説明の設計 |
| ④ 事業の企画 | 社内の提案 |
| ⑤ 広報・渉外 | 対外の説明 |

**②について。**

**顧客の担当者が、社内で説明するための材料を用意する**という場面があります。

**自分が話すのではなく、相手が話せるようにする。**

**これは、答弁の資料を作ってきた経験と同じ形**です。

**誰が、どこで、何を問われるかを想像して作る**という点が共通します。

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## よくある失敗

**1. 説明と提案を同じものと考える**

**目的が違います。**

**2. 経緯から話し始める**

**提案では結論が先**です。

**3. 行動の依頼で終わらない**

**その場で止まります。**

**4. 想定問答の作成を書かない**

**民間でも必要とされる準備**です。

**5. 網羅しようとする**

**提案では絞ってください。**

**6. 庁内での提案を書かない**

**決めてもらうための説明**です。

**7. 資料の分量を変えない**

**その場で見られる前提**にしてください。

**8. 講座を受ければ進めると考える**

**誰に何を伝えてきたか**が評価の対象です。

:::insight
ここまで違いを強調しておいて逆のことを言いますが、**行政の説明の作法が求められる場面もあります。**面談で拝見していると、**「民間では結論から話すと聞いたので、根拠を省く」方**がいらっしゃいます。ところが、**契約や制度に関わる説明では、根拠の明示が必要**です。とくに、**行政を顧客とする事業**では、**相手が根拠を求めます。**どの制度に基づくのか、どの資料によるのか、前例はあるのか。**ここを曖昧にすると、相手が決裁を取れません。**ですから、**結論から話し、求められたら根拠を出せる状態にしておく**という組み立てが現実的です。資料も、**本体は絞り、参考として根拠の資料を別に用意する。****この二段構えは、行政の答弁の準備と同じ形**です。**捨てる技術ではなく、出す順序を変える技術**だと考えてください。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方自治法第121条第1項**は、**議会の審議に必要な説明のため、議長から求められたときは議場に出席しなければならない**としています。**説明は制度上の義務**です
- **説明は「正確に理解してもらう」、提案は「決めてもらう」**技術です
- **提案では、結論を先に置き、行動の依頼で終わって**ください
- 行政で身につくのは、**根拠の明示、想定問答、正確さ、簡潔さ、事前の調整、記録**です
- **想定問答を作れること**は、民間の提案の場でもそのまま使えます
- 資料は、**その場で見られる前提**で分量を絞ってください
- **根拠は捨てず、出す順序を変えて**ください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 議会での説明は、自分がしたわけではありません

**準備の作業を書いてください。**答弁に立つのが管理職であっても、**想定問答の作成、根拠の資料の準備、関係課との確認**は担当が行うことが一般的です。書き方は、**「議会での答弁に備え、想定される質問◯件を整理し、根拠の資料と答弁の案を作成」**という形です。**準備の作業そのものが、評価の対象**になります。なお、**住民説明会や事業者への説明**を担当した経験があれば、併せて書いてください。**相手と回数、準備の内容**を書くと、範囲が伝わります。

### 人前で話すのが苦手です

**話す技術と、準備の技術は別です。**提案の場で結果を左右するのは、**準備のほう**であることが少なくありません。資料の構成、想定される質問への答え、次の行動の依頼。**これらは、話し方に自信がなくても整えられます。**なお、**求人によって、話す場面の多さが違います。**求人票の仕事内容の欄で、**「提案」「折衝」「説明」**といった語がどの程度出てくるかを確認してください。読み方は[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。**苦手を理由に候補を狭めすぎないでください。**

### 提案の資料は、どう練習すればよいですか

**手元の資料を組み替えるのが早いです。**過去に作った説明の資料を1つ選び、**結論を1枚目に置き、根拠を後ろに回す**形に作り直してみてください。そのうえで、**「この提案で、相手に何をしてほしいか」を最後の1枚に書く。**これだけで、提案の形になります。なお、**分量を減らす練習**も併せて行ってください。**1枚に載せる情報を減らし、その場で見て分かる形にする。**行政の資料は、網羅性を優先するため密になりがちです。**削る作業が、最も練習になります。**
