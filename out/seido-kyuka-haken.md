「一度、役所の外で働いてみたい」——転職を考える公務員の動機の中で、最も多く聞くものの1つです。財政課の仕事は、自治体の内側から見た仕事で、外側から自治体を見る経験がありません。その経験があれば、転職するかどうかの判断も、転職先の選び方も変わります。

地方公務員には、**職員の身分を保ったまま、自治体の外の法人で働く制度**があります。公益的法人等への一般職の地方公務員の派遣等に関する法律に基づく**職員派遣**と**退職派遣**です。自治体が出資する株式会社、一般社団・財団法人、地方独立行政法人などに、一定の期間、役職員として派遣されます。

この記事では、**2つの派遣の仕組み、給与、復帰、そして転職前に「外を経験する」使い方**を整理します。**派遣先の法人と職員の範囲、期間は条例と取決めで定める**ので、自分の自治体で派遣の制度がどう運用されているかは人事の担当課で確かめてください。派遣は本人の申出だけで決まる制度ではなく、自治体の人事の判断によります。

## 2つの派遣を並べる

| 項目 | 職員派遣（第2条） | 退職派遣（第10条） |
|---|---|---|
| **派遣先** | **公益的法人等**：一般社団法人・一般財団法人、一般地方独立行政法人、特別の法律により設立された法人で政令で定めるもの、地方自治法上の連合組織のうち、条例で定めるもの | **特定法人**：自治体が出資している株式会社のうち、公益の増進に寄与し自治体の事務・事業と密接な関連を有するものとして条例で定めるもの |
| **身分** | **職員の身分を保ったまま**派遣される | **いったん退職**して、特定法人の役職員として在職する |
| **給与** | **派遣の期間中、自治体からは支給しない**（第6条第1項）。派遣先から報酬。ただし派遣先の業務が自治体の委託・共同・補完の業務である場合は、条例により自治体が支給できる（第2項） | 特定法人から報酬 |
| **期間** | 取決めと条例で定める（3年以内とする自治体が多い） | **退職の日の翌日から起算して3年を超えない範囲**（第10条） |
| **復帰** | 期間が満了したときは職務に復帰する（第5条第2項）。派遣先の役職員の地位を失った場合などは速やかに復帰させる（第1項） | 期間の満了などの場合、**退職した時就いていた職またはこれに相当する職に採用**する（第10条第1項） |

**職員派遣は「籍を残して出向する」形、退職派遣は「一度辞めて、戻る約束で出資会社に行く」形**です。どちらも、期間が終われば自治体に戻ります。

## 職員派遣——第2条・第5条・第6条

| 要素 | 内容 |
|---|---|
| **要件** | 派遣先の業務の全部または一部が自治体の事務・事業と密接な関連を有し、自治体が施策の推進のために人的援助を行うことが必要であること（条例で定める法人） |
| **取決め** | 任命権者と派遣先の間で、報酬その他の勤務条件、従事すべき業務、派遣の期間、復帰に関する事項などを定める（第2条第3項） |
| **職員の同意** | 派遣は任命権者が行うが、実務上は本人の同意を得て行う運用 |
| **給与** | 原則として自治体からは支給せず、派遣先から報酬。派遣先の業務が自治体の委託・共同・補完の業務なら、条例により自治体が支給できる |
| **復帰** | 期間の満了で職務に復帰。派遣先の役職員の地位を失った場合などは速やかに復帰 |

**共済の組合員資格は、職員の身分が続くので継続します。**退職手当の在職期間の扱い、昇給、共済の掛金の負担（自治体か派遣先か）は、条例と取決めで定められ、人事の担当課で確かめてください。

## 退職派遣——第10条

| 要素 | 内容 |
|---|---|
| **派遣先** | 自治体が出資する株式会社のうち、条例で定める特定法人 |
| **形** | 任命権者の要請に応じて**退職**し、引き続き特定法人の役職員として在職 |
| **期間** | 退職の日の翌日から起算して**3年を超えない範囲**で取決めに定める |
| **再採用** | 期間が満了した場合、役職員の地位を失った場合などに、**退職した時就いていた職またはこれに相当する職に採用**（欠格事由に該当する場合などを除く） |
| **共済** | **長期給付（年金）は共済に残る。**第11条により退職派遣者は地方公務員等共済組合法第140条の公庫等職員とみなされ、継続長期組合員として年金の記録が共済で続く。短期給付（健康保険）は特定法人の健康保険に切り替わる |
| **退職手当** | 第12条により、再採用後の処遇と退職手当は部内の職員との均衡を失しないよう措置される。条例により、再採用後の退職の際に通算する扱いが一般的 |

**退職派遣は、形式上は退職**ですが、第11条により年金（長期給付）は共済の継続長期組合員として続き、健康保険は特定法人の制度に切り替わります。再採用で自治体に戻れば、短期給付も共済に戻ります。**「退職」という言葉に驚く方が多いですが、戻る約束と年金の継続が組み込まれた退職**です。

## 転職前に「外を経験する」使い方

| 点 | 内容 |
|---|---|
| **派遣は自治体の人事の判断** | 本人が「派遣に行きたい」と申し出て決まる制度ではなく、自治体の施策として人的援助が必要な法人に、人事が職員を選んで派遣する。**希望を伝えることはできる** |
| **派遣先で見えること** | 自治体の外から見た自治体、法人の経営と財務、民間に近い意思決定の速さ、自治体の職員が法人からどう見えるか |
| **派遣後の転職** | 派遣を終えて復帰した後に転職することに、法律上の制限はない。**派遣先の法人にそのまま転職することは、派遣の趣旨と第38条の2の働きかけの規制との関係で慎重に** |
| **経歴** | 派遣の期間は「自治体から○○法人に派遣され、○○を担当」として説明できる。自治体の外での実績として転職先に評価されやすい |
| **判断の材料** | 外で働いてみて、「戻りたい」と思うか「外で続けたい」と思うかが、転職の判断の最も確かな材料になる |

**派遣は、転職の予行演習として設計された制度ではありません。**自治体の施策のための人的援助が目的で、その結果として職員が外の経験を得る、という順序です。ただし、**派遣を経験した職員が、その後に転職するかどうかを、自分の実感で判断できる**のは事実で、面談でも、派遣経験のある方は転職の理由が明確です。

## 派遣先への転職——注意

派遣を終えた後、派遣先の法人から「うちに来ないか」と誘われることがあります。

| 点 | 内容 |
|---|---|
| **法律上の制限** | 就職先を制限する規定はない |
| **第38条の2** | 派遣先が自治体と契約や処分の関係を持つ法人であれば、退職後2年間、離職前5年間の組織の役職員に対する契約等事務に関する働きかけは禁止。**派遣先に転職して、自治体との契約について古巣に働きかけることはできない** |
| **派遣の趣旨** | 自治体の施策のために派遣した職員が、派遣先に転職して自治体に戻らない形は、制度の趣旨から見て自治体が歓迎しにくい |
| **職場との関係** | 復帰して一定の期間を置いてから転職するのが、関係を保つ形 |

:::insight
面談で伺うと、**派遣先の法人で2年働いて復帰した方が、「外で働くとはどういうことか」を実感として持っていて、転職の判断が速く、転職先の選び方も具体的**です。逆に、**派遣の経験がないまま転職して、「民間の意思決定の速さについていけない」と入社後に戸惑った**という方もいます。ここで1つ提案があります。**「外で働いてみたい」が転職の動機なら、まず自治体の派遣の制度を確かめ、希望を人事に伝えてください。**派遣は自治体の判断で決まるので、必ず行けるわけではありませんが、希望を伝えた職員が派遣の候補になることはあります。**派遣で外を経験してから転職を考えれば、判断は実感に基づき、経歴には外の実績が加わります。**行けなかった場合も、転職の準備は変わらず進められます。
:::

## 転職するとどうなるか

転職を考えている方にとって、派遣の制度で効いてくる点は3つです。

**1. 職を保ったまま、外で働く制度がある**

**職員派遣は籍を残して、退職派遣は戻る約束で。**どちらも期間が終われば自治体に戻ります。

**2. 派遣は自治体の判断。希望は伝えられる**

**本人の申出だけで決まる制度ではありません**が、希望を伝えた職員が候補になることはあります。

**3. 派遣先への転職は、第38条の2と派遣の趣旨から慎重に**

**復帰して一定の期間を置いてから**というのが、関係を保つ形です。

## 手続きと期限

| 順序 | 手続き | 時期 | 場所 |
|---|---|---|---|
| 外で働く経験を考えたら | 自治体の派遣の条例（対象の法人、職員の範囲、期間）を確かめる | 最初に | 人事の担当課、例規集 |
| 希望を伝える | 人事の面談や自己申告で、派遣の希望を伝える | 人事の異動の時期の前 | 所属、人事の担当課 |
| 派遣が決まったら | 取決めの内容（報酬、業務、期間、復帰）、共済・退職手当の扱いを確かめる | 派遣の前 | 人事の担当課、共済組合 |
| 退職派遣の場合 | 退職の手続き、健康保険の切替え（年金は共済で継続）、退職手当の通算の扱いを確かめる | 派遣の前 | 人事の担当課、共済組合 |
| 派遣中 | 派遣先の業務に従事。取決めの範囲で | 期間中 | 派遣先 |
| 復帰 | 期間の満了で職務に復帰（退職派遣は再採用） | 期間の満了 | 人事の担当課 |
| 転職を考えるなら | 復帰後、一定の期間を置いてから。派遣先への転職は第38条の2と派遣の趣旨から慎重に | ── | ── |

## 誤解されやすい点

**「派遣は希望すれば行ける」と思い込む**

**自治体の施策として人事が判断する制度**です。希望は伝えられますが、決めるのは自治体です。

**「退職派遣は本当に辞めること」と思い込む**

**期間の満了で退職した時の職に採用する約束のある退職**です（第10条第1項）。

**「職員派遣中は自治体から給与が出る」と思い込む**

**原則として自治体からは支給せず、派遣先から報酬**です（第6条第1項）。例外は条例によります。

**「派遣先にそのまま転職するのは自由」と思い込む**

**法律上の制限はありませんが、第38条の2の働きかけの規制と派遣の趣旨から慎重に**。

:::insight
ここまで派遣の話を書いておいて逆のことを言いますが、**派遣は転職の予行演習の制度ではなく、行けるかどうかは自治体が決めます。**それでも1本の記事にしたのは、**「外で働いてみたい」という動機が、転職以外の形でも実現し得ることを知らない方を面談で見る**からです。派遣で外を経験した方の転職の判断は、実感に基づいていて速く、的確です。行けなくても、転職の準備は変わらず進められます。そのうえで、**自分の経験に値を付けてくれる業界の見込みと、同じ紙に並べてください。**片方だけでは比較になりません。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 公益的法人等への派遣は、**職員の身分を保ったまま一般社団・財団法人などで働く職員派遣（第2条）**と、**出資株式会社のためにいったん退職して働き、期間満了で退職した時の職に採用される退職派遣（第10条）**の2つです
- 職員派遣の給与は**原則として自治体からは支給されず、派遣先から報酬**です（第6条）。期間の満了で職務に復帰します（第5条）
- 退職派遣の期間は**退職の日の翌日から3年を超えない範囲**で、**年金は共済の継続長期組合員として続き**（第11条）、健康保険は特定法人の制度に切り替わります。再採用後の処遇と退職手当は部内の職員との均衡を失しないよう措置されます（第12条）
- **派遣は自治体の施策としての人事の判断**で、本人の申出だけで決まる制度ではありませんが、希望は伝えられます
- 派遣で外を経験した後の転職に法律上の制限はありませんが、**派遣先への転職は第38条の2の働きかけの規制と派遣の趣旨から慎重に**。復帰して一定の期間を置いてから
- **「外で働いてみたい」という動機は、転職以外の形でも実現し得ます。**派遣の経験は、転職の判断の最も確かな材料になります

## よくある質問

### 派遣に行きたいと人事に伝えたら、転職を考えていると思われませんか

**派遣の希望は、公務の能力の向上や自治体の施策への貢献の文脈で伝えれば、転職の意思とは受け取られません。**派遣は自治体の施策のために職員を法人に送る制度で、希望する職員がいることは自治体にとっても歓迎される場合が多いです。伝え方は、「自治体の出資法人や関連団体の業務を経験して、財政課の仕事に生かしたい」「法人の側から自治体の財政を見る経験を積みたい」のように、公務に生かす目的で伝えるのが自然です。転職の意図を伝える必要はなく、伝えるべきでもありません。派遣に行けるかどうかは、自治体の施策、派遣先の人的援助の必要、本人の適性と所属の事情で決まるので、希望を伝えても行けないことはあります。派遣の制度がない自治体や、派遣先が限られている自治体では、自己啓発等休業や修学部分休業（[自己啓発等休業](seido-kyuka-jikokeihatsu.html)、[修学部分休業](seido-kyuka-shugaku.html)）が、外の経験を得る別の道になります。

### 退職派遣で出資会社に行くと、共済や退職手当はどうなりますか

**年金は共済の継続長期組合員として続き、健康保険は特定法人の制度に切り替わり、退職手当は条例により再採用後の退職の際に通算する扱いが一般的です。**退職派遣は形式上の退職ですが、第11条により退職派遣者は地方公務員等共済組合法第140条の公庫等職員とみなされ、長期給付（年金）については共済の組合員として扱われるので、年金の記録に空白は生じず、共済の年金として続きます。短期給付（健康保険）は特定法人の健康保険に加入します。退職手当は、退職派遣の時点で支給するのではなく、第12条（退職派遣者の採用時における処遇等）と自治体の条例により、再採用後に退職する際に、派遣前の在職期間を通算して計算する扱いが一般的です。特定法人での在職期間の扱い（通算するか、除くか）は条例と取決めによるので、人事の担当課で確かめてください。再採用の際は、退職した時に就いていた職またはこれに相当する職に採用されます（第10条第1項）。「退職」という言葉に不安を持つ方が多いですが、戻る約束、年金の継続、退職手当の通算が制度に組み込まれているので、身分の面での不利は限定的です。

### 派遣先の法人から、派遣の終了後に「うちに来ないか」と誘われました。受けてよいですか

**法律上、就職先を制限する規定はありませんが、第38条の2の働きかけの規制と、派遣の趣旨の両面で慎重に考えてください。**派遣先が自治体と契約や処分の関係を持つ法人であれば、退職後2年間、離職前5年間に在職した組織の役職員に対して、その契約などに関する働きかけはできません（地方公務員法第38条の2第1項）。派遣先に転職すれば、自治体との関係の業務で古巣に働きかける場面が生じやすく、規制の線を守るために担当を外れる形が要ります。派遣の趣旨の面では、自治体が施策のために派遣した職員が派遣先に転職して戻らない形は、自治体が歓迎しにくく、後に続く職員への派遣の運用にも影響します。誘いを受けるなら、いったん復帰して一定の期間を公務で働き、そのうえで改めて応募する形が、職場との関係を保ち、第38条の2の線も守りやすい形です。派遣で得た外の実績は他の転職先でも評価されます。
