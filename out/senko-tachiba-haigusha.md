**配偶者も公務員という世帯からのご相談**です。

**片方が民間に出ると、世帯の条件が変わります。**

この記事では、**変わる範囲**と、**確認の順序**を扱います。

**⚠ 制度の扱いは、団体と会社によって異なります。****必ず、所属と共済組合に確認してください。**

## 費用は、世帯として分担するものです

**民法第760条**です。

> **夫婦は、その資産、収入その他一切の事情を考慮して、婚姻から生ずる費用を分担する。**

**「その資産、収入その他一切の事情を考慮して」**という書き方です。

**個々の収入ではなく、世帯として費用をまかなう**という前提が置かれています。

**したがって、転職の判断も、世帯の条件として整理する**ことになります。

**片方の収入や勤務の条件だけを見て判断すると、全体が見えません。**

## 両方が公務員である場合の特徴

| 特徴 | 内容 |
|---|---|
| ① 制度が同じか近い | 休暇、勤務時間、共済 |
| ② 年度の周期が同じ | **繁忙期が重なることがある** |
| ③ 異動の時期が同じ | 年度の変わり目 |
| ④ 転勤の範囲が予測できる | 団体の区域が中心 |
| ⑤ 収入の構成が似ている | 給与の仕組みが近い |

**①が、世帯の運営を支えている**場合があります。

**両方が同じ制度を使えるため、休暇や勤務時間の調整がしやすい。**

**片方が民間に出ると、この前提が変わります。**

**②について。**

**年度の変わり目や議会の時期が重なると、世帯としての負担が集中します。**

**片方が民間に移ると、繁忙期がずれる**ことがあります。

**これは、負担の分散として働く面もあります。**

## 変わる範囲

| 項目 | 変わること |
|---|---|
| ① 保険 | **共済から、転職先の制度へ** |
| ② 扶養の扱い | 世帯の構成によって変わります |
| ③ 手当 | 住居、扶養、通勤の扱いが変わります |
| ④ 勤務時間・休日 | 会社の制度による |
| ⑤ 転勤の可能性 | 会社の定めによる |
| ⑥ 休暇の制度 | 要件が異なります |

**①と②を、先に確認**してください。

**扶養の扱いは、世帯の収入の構成によって変わります。**

**扱いは、共済組合と転職先に確認**してください。

**⑤について。**

**公務員どうしの場合、転勤の範囲がおおむね予測できます。**

**民間では、会社の定めによります。**

**転勤の可能性と範囲を、内定の前に確認**してください。扱いは[転職にともなう転居と単身赴任](senko-taishoku-tenkyo.html)に整理しています。

## 確認の順序

| 順 | やること | 確認先 |
|---|---|---|
| 1 | 保険・扶養の扱い | **共済組合** |
| 2 | 手当の変化 | 転職先の求人票・就業規則 |
| 3 | 勤務時間・休日 | 同上 |
| 4 | 転勤の可能性 | 同上 |
| 5 | 世帯の収支の見通し | 家庭内で |
| 6 | 育児・介護の分担 | 同上 |

**1を最初に置いてください。**

**保険と扶養は、世帯の全員に関わります。**

**5について。**

**収入だけでなく、支出の変化も並べてください。**

**通勤の費用、住居に関する手当、保育の費用。**

**これらが変わると、手取りの比較だけでは判断できません。**

## 分担の見直し

| 項目 | 確認すること |
|---|---|
| 送迎・保育 | 勤務時間が変わる場合 |
| 家事 | 帰宅の時間が変わる場合 |
| 介護 | 急な対応の可否 |
| 学校・行事 | 平日の対応 |
| 休暇の取りやすさ | **どちらが取りやすいか** |

**5行目です。**

**公務員の休暇の制度と、転職先の制度は異なります。**

**どちらが急な休みを取りやすいか**が変わる可能性があります。

**この点は、先に話しておいてください。**

**伝え方は**[家族への伝え方と、反対されたときの整理](senko-taishoku-kazoku.html)**に整理しています。**

:::insight
配偶者も公務員という世帯のご相談で、**面談でお伝えしているのが「両方が同時に動かないでください」**という点です。面談で伺った例では、**世帯として働き方を見直そうとして、両方が同時に転職を検討された方**がいらっしゃいます。ところが、**この進め方には無理があります。**理由は2つです。1つは、**収入と保険の前提が同時に変わると、見通しが立たないこと。**もう1つは、**選考の日程が重なると、家庭の運営が回らなくなること**です。面接、書類の準備、条件の確認。**これらが2人分同時に走ると、在職中の時間では収まりません。**ですから、**片方が先に動き、状況が落ち着いてから、もう片方が検討する**という順序が現実的です。**そして、片方が公務員として制度を残すことには、意味があります。**休暇の制度、保険、収入の安定。**世帯としての土台が残ります。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 面接で伝えること

| 項目 | 内容 |
|---|---|
| 勤務できる時間 | 送迎などの制約がある場合 |
| 転勤の可否 | **配偶者の勤務地との関係** |
| 急な対応の可能性 | 頻度の見込み |
| 入社の時期 | 退職の手続きの期間 |

**2行目です。**

**配偶者の勤務地が固定されている場合、転勤の可否は条件**になります。

**「転居をともなう異動は難しい」と、応募の段階で伝えて**差し支えありません。

**伏せて入社すると、後から調整できません。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 在職中の進め方

| 項目 | 内容 |
|---|---|
| 制度の確認 | 共済組合、所属の人事担当 |
| 求人を読む | 週に30分 |
| 世帯の条件の整理 | 月に1回、2人で |
| 日程の確保 | **繁忙期が重ならない時期** |

**4行目です。**

**両方が公務員の場合、繁忙期が重なることがあります。**

**選考の時期を、両方の予定を見て決めてください。**

**扱いは**[選考スケジュールの組み方](senko-sagasu-schedule.html)**に整理しています。**

## 世帯の見通しの作り方

**2人で1枚の表を作ってください。**

| 項目 | いま | 転職後の見込み |
|---|---|---|
| 勤務時間（2人分） | 始業・終業 | 同左 |
| 休日 | 土日、シフト | 同左 |
| 通勤の時間 | 片道 | 同左 |
| 急な休みの取りやすさ | どちらが取れるか | 同左 |
| 転勤の可能性 | 範囲 | 範囲 |
| 支出の変化 | 通勤、保育、住居 | 同左 |

**「いま」の列を先に埋めてください。**

**現状が書き出せていないと、比べられません。**

**そして、この表は、転職しない場合にも使えます。**

**世帯としての働き方を見直す材料**になります。

**埋めてみた結果、いまのほうが条件がよいと分かることもあります。**

**それは、検討が無駄だったという意味ではありません。**

**判断の材料が揃ったということです。**

**表は、年に1回見直せば足ります。****異動の後が、見直しの機会になります。**

## よくある失敗

**1. 両方が同時に動く**

**見通しが立たなくなります。**

**2. 保険・扶養の扱いを確認しない**

**世帯の全員に関わります。**

**3. 手取りだけで比べる**

**支出の変化**も並べてください。

**4. 手当の変化を見ない**

**住居・扶養・通勤**の扱いが変わります。

**5. 転勤の可能性を確認しない**

**配偶者の勤務地との関係**が生じます。

**6. 休暇の取りやすさの変化を話さない**

**分担が変わります。**

**7. 繁忙期が重なる時期に選考を始める**

**家庭の運営が回りません。**

**8. 条件を伏せて入社する**

**後から調整できません。**

:::insight
ここまで慎重な話をしておいて逆のことを言いますが、**両方が公務員であることは、転職を検討するうえで有利な条件です。**面談で拝見していると、**「世帯のリスクを取れない」と考えて、検討を止めてしまう方**がいらっしゃいます。ところが、**片方が制度を残していれば、もう片方は条件で選べます。**収入の安定、保険、休暇の制度。**土台があるからこそ、焦って決めずに済む。**在職中に情報を集め、条件の合う求人が出るまで待てる。**この「待てること」は、大きな利点**です。行政が相手の事業では、**募集が事業の周期に応じて生じる**ため、**待てるかどうかが結果を左右します。**ですから、**世帯としての安定を、検討を止める理由ではなく、じっくり選ぶための条件として使ってください。**そして、**条件が合う求人が出なければ、動かないという判断でも構いません。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **民法第760条**は、**夫婦が、その資産、収入その他一切の事情を考慮して、婚姻から生ずる費用を分担する**と定めています。**世帯として整理**してください
- 変わるのは、**保険、扶養、手当、勤務時間・休日、転勤の可能性、休暇の制度**です
- **保険と扶養の扱いを、最初に共済組合へ確認**してください
- **手取りだけでなく、支出の変化**を並べてください
- **両方が同時に動かない**でください。見通しが立たなくなります
- **片方が制度を残すことには意味があります。**土台が残ります
- **待てること**は、行政が相手の求人では大きな利点です

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 扶養や手当は、どう変わりますか

**世帯の収入の構成と、双方の制度によって決まります。**扶養の扱いは、**共済組合と転職先の制度**の両方に関わります。手当については、**住居、扶養、通勤**の扱いが、会社の制度によって異なります。**求人票の賃金の欄で、基本給と手当の区分を確認**してください。そのうえで、**内定の段階で書面の提示を受けて**ください。**具体の金額と要件は、この記事では扱いません。**共済組合、転職先の担当、市区町村（保育料等に関わる場合）に、**それぞれ確認**してください。扱いは[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。

### 配偶者が転勤のある職の場合、どう考えますか

**転勤の範囲を先に確認してください。**公務員の場合、**団体の区域が中心**となることが多く、範囲が予測できます。そのうえで、**自分の転職先の転勤の可能性**を確認します。**両方に転勤の可能性があると、世帯として調整が難しくなります。**対処は2つです。1つは、**転勤のない求人に絞ること。**もう1つは、**在宅勤務が可能な求人を見ること**です。勤務地の制約が小さくなります。なお、**「転居をともなう異動は難しい」は、条件として伝えて**差し支えありません。**伏せて入社すると、調整ができません。**

### どちらが先に動くべきですか

**判断の材料は3つです。**1つ目は、**条件の合う求人が、どちらの分野に多いか。**2つ目は、**どちらが休暇や勤務時間の制約が少ないか。**3つ目は、**繁忙期がいつか**です。**この3つを並べると、順序が決まります。**なお、**同時に動かないこと**を優先してください。片方が先に移り、**生活の形が落ち着いてから**もう片方が検討する。**この順序であれば、判断の材料も揃います。**先に動いた側の経験が、**もう片方の検討にも使えます。**扱いは[何社くらい受けるべきか](senko-sagasu-fukusu.html)に整理しています。
