教員の退職手当は、教員免許や勤続年数だけで全国一律の額が決まるものではありません。公立学校では、本人に適用される退職手当条例等を確認し、算定基礎の給与、勤続期間、退職理由、調整額を分けて照合します。

本記事は2026年11月時点の公開情報にもとづき、宮城県と大阪府の公式資料を例に確認方法を整理します。例示した条件を全国へ広げず、本人の給付は所属の教育委員会・退職手当担当へ確認してください。国立・私立学校や大学等の退職金規程は別に調べます。

## 公立学校でも適用条例と支給担当を確かめる

地方自治法第204条は、退職手当を含む手当について条例を根拠とする枠組みを定めています。国の国家公務員退職手当法の支給率を、そのまま地方公務員である教員全員に当てはめるものではありません。

例えば大阪府の職員の退職手当に関する条例は、地方公務員法や地方教育行政の法律を根拠として、対象職員と退職手当を定めています。宮城県の教育庁の案内も、職員の退職手当に関する条例に基づく給付として説明しています。

勤務する学校の所在地だけで、本人に適用される条例を決めないことも大切です。県費負担教職員、指定都市の職員、自治体が独自に任用する職員等では、給与負担や人事の制度を区別して確認します。

| 最初に確認するもの | 整理する内容 |
| --- | --- |
| 任用通知と勤務先 | 任命権者、職員区分、任期 |
| 給与と退職手当の根拠 | 適用条例、規則、支給担当 |
| 過去の勤務 | 正規、講師、他自治体等の期間と支給歴 |
| 今回の退職 | 希望日、退職理由、再就職先の予定 |
| 給付の名称 | 一般の退職手当、年金、共済給付等の区分 |

常勤の正規教員と、臨時的任用、短時間勤務、非常勤等の区分も分けます。学校で教えていた期間があることだけで、すべて同じ退職手当の対象になるとは考えないでください。

## 基本額の算定基礎は給与明細の総額と異なる

退職手当の計算は、算定の基礎となる給料月額に、勤続期間や退職理由に応じた率を用いる基本額と、別の仕組みの調整額等を区別して読みます。大阪府の条例も、基本額と退職手当の調整額を分けています。

宮城県の教職員向け計算案内では、退職時の給料月額を、本俸に教職調整額と給料の調整額を加えたものとして説明しています。通勤手当や扶養手当等を含めた給与明細の総支給額を、そのまま計算の基礎にするという意味ではありません。

給特法第3条第3項は、教職調整額を受ける人について、退職手当等の給料を基礎とする計算に調整額を加える内容を条例で定める仕組みを置いています。本人が支給対象であるか、退職時の率と経過措置がどうなるかを、適用条例と合わせて確認します。

2026年の教職調整額の確認では、将来の引上げ予定を現在の支給額として計算しないようにします。校長等の管理職や対象外の区分に、教諭と同じ加算を置くことも避けます。[教員の給与と教職調整額](seido-shokushu-kyoin-kyuyo.html)で、対象と時点を分けて確認できます。

## 三つの調整に関する名称を区別する

給与や退職金の資料には、似た名称が出てきます。教職調整額、給料の調整額、退職手当の調整額を、一つの手当の呼び方の違いとしてまとめないことが大切です。

| 名称 | 確認の出発点 |
| --- | --- |
| 教職調整額 | 給特法と条例による対象・率、給与への反映 |
| 給料の調整額 | 職務等の条件に応じる給与上の調整 |
| 退職手当の調整額 | 在職中の職員区分等に基づく退職手当の計算 |

宮城県の案内では、退職手当の調整額は、対象となる在職月の調整月額を高いものから60月分合計する仕組みです。最後の60月をそのまま取る意味ではありません。勤続期間や自己都合退職等による不支給・減額、除外する月もあるため、最高区分の月額に必ず60を掛ける計算にはしません。

また、同県は、特別支援学校からの異動等で給料の調整額がなくなった場合を、基本額の特例の確認例として示しています。過去の一番高い給与を全期間に使うという単純な説明とは異なります。給与の変更日、変更理由、前後の期間を担当に示してください。

:::insight
退職手当の見込みを読むときは、最終額より先に、計算書のどの欄が何を示すかを書き分けることを勧めます。給料の基礎、支給率、勤続期間、調整額、控除後の入金では意味が違います。教職調整額と退職手当の調整額の名称が似ていても、別の計算なので同じ欄にまとめません。異動や休業の記録も、担当が確認できる形で残しておくと、見込み額に疑問がある際の照会が具体的になります。転職の判断では、未確認の額を生活費の確定収入にしないことが大切です。給付の確認と希望する仕事の比較を分け、現職を続ける案も含めて、本人に適用される条件で予定を作るための材料として扱います。
:::

仕事の選択肢を比べる段階なら、[行政経験に関連する求人](../?gov=1)を見ることもできます。退職手当の算定は、制度の担当窓口へ別に確認してください。

## 勤続期間と退職理由を一緒に照合する

同じ在職年数でも、自己都合、定年、傷病、死亡、認定された早期退職等では適用する区分が異なる場合があります。採用先が決まっていることと、本人が希望する退職理由の区分になることは別です。

宮城県の案内も、勤続期間と退職事由に応じて支給率を決める仕組みを示しています。休職、育児休業等の期間には、計算で除く期間の取扱いがあるため、カレンダー上の採用日から退職日までを単純に年数へ直すだけでは足りません。

講師等の勤務歴がある場合は、任用の種類、勤務時間、任用間の空白、以前に退職手当を受けたかを確認します。雇用保険や年金の加入期間が続いていることだけで、退職手当の勤続期間も同じように通算できるとは判断しません。

人事担当には、任用通知、在職証明、過去の支給通知、休業期間等の資料を示します。職歴の記憶だけで申告せず、必要な期間が記録に反映されているかを確認してください。任期満了と途中の自己都合退職の違いも、今回の事実に沿って照会します。

## 別の自治体へ移っても当然に通算されるわけではない

公務内の転職では、前の所属の退職手当を精算する場合と、所定の条件で在職期間を通算する場合を分けます。退職手当を受け取ることと、その同じ期間を新しい所属で再び通算することを、自由に重ねられるとは考えません。

大阪府の教育庁は、2025年4月以後、国や他の地方公共団体から空白なく採用される場合でも、任命権者間の相互了解の下で行う計画的な人事交流に限り、相互通算を前提に在職期間を通算する扱いを案内しています。府費負担教職員も対象に含む説明です。

これは大阪府の例であり、全国の教員採用が同じ扱いという意味ではありません。宮城県の案内にも、継続した在職、支給歴、相手側の通算規定等の条件があります。教員同士の転職だからという理由だけで手続きを省略せず、双方へ根拠と必要書類を確認してください。

国立・私立学校や民間企業に移る場合は、新しい雇用主の退職金規程も別に確認します。現在の退職手当、将来の年金、応募先の企業年金等を一つの通算の話にまとめないことが大切です。

## 必要書類と振込予定は退職日より前に確認する

退職手当の決定には、所属の手続きと履歴等の確認が関わります。宮城県の提出書類案内には、申出書、口座関係書類、退職所得の受給に関する申告書、履歴や給与の記録等が示されています。傷病等の退職理由や休業歴に応じて、確認資料が変わります。

| 確認の段階 | 担当へ尋ねること |
| --- | --- |
| 退職前 | 提出様式、期限、退職理由、通算の有無 |
| 計算の照合 | 給料の基礎、職歴・休業歴、調整額の区分 |
| 支給決定 | 決定額、計算内訳、控除、振込予定日 |
| 退職後 | 通知の送付先、入金、不一致がある場合の連絡先 |

大阪府の条例は、一般の退職手当等の支払について、原則として退職日から起算して1月以内とし、特別の事情がある場合の例外も定めています。全国一律に同じ日に振り込まれるという案内ではありません。

宮城県は、決定通知書、計算内訳書、退職所得の源泉徴収票の交付と、通知書に記載する振込予定日を案内しています。口座を先に解約・名義変更すると入金が遅れる可能性があるため、指定した口座を入金まで使える状態にします。

経歴と希望する働き方を整理したい場合は、[応募前の相談](../apply.html)も利用できます。ご利用は無料です（紹介手数料は採用企業の負担）。給付と税の正式な判断は、支給担当や税務署等へ確認します。

## 決定額と実際の入金、年金を分けて記録する

退職手当の決定額から、税や共済貸付の未償還金等が控除される場合があります。宮城県の支給案内も控除項目を説明しています。決定額をそのまま入金予定として使わず、計算内訳と控除後の額を照合してください。

退職所得の税の計算と、退職した年の給与に関する税の手続きは別です。退職後の住民税や医療保険料等の支出も、退職手当を受け取るだけでなくなるものではありません。個別の申告や税額は、税務署・市区町村に確認します。

公立学校共済等の年金払い退職給付も、通常の退職手当と別の制度です。退職日にすべて一括で支払うとは限りません。年金の加入記録や受給要件は共済等の窓口へ照会し、通知書を制度ごとに分けて保管します。

:::insight
退職手当がいくらになるかだけで、仕事を変える時期を決める必要はありません。本人が続けたい教育の仕事、変えたい勤務条件、生活上必要な資金を分けて整理します。校内の役割や働き方の調整で希望に近づけるなら、残る判断にも理があります。転職する案では、未確認の通算や支給日を確定した条件にせず、正式な回答を得て予定を組みます。退職手当の額だけを取り上げるより、入金までの期間と、その後の住まい・保険等の支出を合わせて確認するほうが、具体的な準備につながります。給付は進路の結論を代わりに出すものではなく、現職継続を含む選択肢を本人の条件で比べるための材料です。
:::

## よくある質問

### 教職調整額と退職手当の調整額は同じですか

別です。教職調整額は給与上の制度で、退職手当の調整額は在職中の職員区分等に応じる計算です。給料の調整額という別の項目もあり、計算書の欄を分けて確認します。

### 他県の公立学校へ移れば勤続年数は全部引き継がれますか

一律には決まりません。採用経路、勤務の連続、支給歴、双方の通算規定等を確認する必要があります。新しい採用先と現在の担当へ照会してください。

### 退職日に退職手当が振り込まれますか

退職日と振込日は別です。適用条例の支払期限や例外、必要書類、決定通知の予定日を確認します。本人の通知書で口座と振込予定を照合してください。

教員の退職手当は、根拠制度、計算内訳、期間と理由、手続きの順に確かめます。仕事の希望を整理する段階なら、[LINEで短く聞く](https://line.me/R/ti/p/@697nxhbt)こともできます。
