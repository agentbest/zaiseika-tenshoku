企画課から転職しようとした人が最初に止まるのは、たいてい職務経歴書の1行目です。

**「総合計画の策定を担当」**と書いてみる。書いた本人が、これで何が伝わるのか分からない。そこで手が止まります。

理由ははっきりしています。企画課の仕事は、**自分で何かを作ったり売ったりする仕事ではない**からです。作るのは文書で、動かすのは他の部署です。実績を書こうとすると、自分が何をしたのかが急に説明しにくくなります。

この記事では、企画課・政策企画の仕事を分解して、それぞれが民間の求人票でどう書かれているかを並べます。訳語が分かれば、検索する言葉も応募先の選び方も変わります。

## 企画課の仕事は、法律でも「2つ」で書かれています

まず、企画課の仕事の形を条文で確認します。ここを押さえておくと、面接で「企画課とは何をする部署ですか」と聞かれたときに、そのまま答えられます。

まち・ひと・しごと創生法第1条は、少子高齢化の進展に対応し、人口の減少に歯止めをかけるとともに東京圏への人口の過度の集中を是正するといった背景を述べたうえで、この法律が何を定めるかを次のように書いています。

**基本理念、国等の責務、政府が講ずべき施策を総合的かつ計画的に実施するための計画（まち・ひと・しごと創生総合戦略）の作成等について定めるとともに、まち・ひと・しごと創生本部を設置する。**

ここに、2つのことが並んでいます。

**1つは、計画を作ること。**
**もう1つは、推進する体制を作ること。**

計画だけでは動きません。動かす場所を別に用意して、初めて回り始める。**法律自体が、その構造で書かれています。**

企画課の仕事も同じです。総合計画や総合戦略を作る仕事と、それを全庁で回す会議体や進捗管理の仕組みを作る仕事。**この2つがセットになっています。**

そして、後者のほうが説明しにくい。書類で損をしているのは、たいてい後者のほうです。

## 企画課・政策企画が実際にやっていること

自治体によって所管の範囲は違いますが、おおむね次の仕事が入ります。

- 総合計画・総合戦略の策定と改定（審議会、パブリックコメント、議会対応）
- 各部署の個別計画との整合の確認
- 施策の進捗管理、指標の設定と実績の集計
- 行政評価、事務事業の点検
- 国の交付金や補助制度の情報収集と、庁内への展開
- 広域連携、近隣自治体との協議
- 組織機構の見直し、事務分掌の調整
- 統計・人口推計の整理、将来推計の作成
- 市長・副市長への説明と、庁議の運営
- 外部の有識者や住民との会議の設計と運営

並べてみると分かるとおり、**自分の部署だけで完結する仕事がほとんどありません。**要求するのでも執行するのでもなく、**全体の形を作って回す**のが企画課の位置です。

そして、**権限を持っていません。**予算の決定権は財政課にあり、事業の実施権限は各部署にあります。企画課が持っているのは、**計画に書き込む権限と、場を設計する権限**だけです。

この構造は、民間の経営企画とほぼ同じです。

## 計画には階層があり、企画課はその真ん中に立っています

もう一つ、外から見えにくい構造があります。**計画は1本ではありません。**

多くの自治体では、いちばん上に長期の基本構想があり、その下に中期の基本計画、さらに下に単年度または数年の実施計画が置かれます。そしてその横に、福祉・都市計画・環境・教育といった**分野ごとの個別計画**が何十本も並んでいます。

企画課がやっているのは、**この縦と横が食い違わないようにすること**です。

- 個別計画が上位計画の方針から外れていないか
- 同じ対象に対して複数の計画が別々の目標を掲げていないか
- 計画の期間がずれていて、改定の時期が噛み合わなくなっていないか
- 上位計画に書いていない事業が、個別計画にだけ載っていないか

**どれも、誰かが見ていないと静かにずれていきます。**そして、ずれていても当面は誰も困りません。困るのは、予算が足りなくなったときと、住民から「何をやりたいのか分からない」と言われたときです。どちらも、ずれが起きてから数年たったあとに表面化します。

この仕事は、民間でいえば**全社方針と部門計画の整合をとる作業**です。事業部ごとの計画が全社の方針とずれていないか、同じ顧客に対して複数の部門が別々の目標を持っていないか。**構造がそのまま同じです。**

職務経歴書では、ここを書くと差が出ます。「個別計画◯本と総合計画の整合を確認し、目標の重複◯件を整理した」と書けると、**計画を書いた人ではなく、計画群を管理した人**として読まれます。

## 庁内の言葉と、求人票の言葉の対応

ここからが本題です。上の仕事は、求人票では別の言葉で書かれています。

| 庁内での言い方 | 求人票での言い方 |
|---|---|
| 総合計画・総合戦略の策定 | 中期経営計画の策定、経営計画の立案 |
| 個別計画との整合の確認 | 全社方針と部門計画の整合、計画管理 |
| 施策の進捗管理 | 進捗管理、モニタリング、PMO |
| 指標の設定と実績の集計 | KPI設計、指標のモニタリング、データ分析 |
| 行政評価、事務事業の点検 | 事業評価、投資対効果の検証、事業ポートフォリオの見直し |
| 交付金・補助制度の活用 | 資金調達、制度活用、渉外 |
| 広域連携、他団体との協議 | アライアンス、渉外、パートナーシップ |
| 組織機構の見直し | 組織設計、組織開発、業務改革 |
| 統計・人口推計 | 市場分析、需要予測、データ分析 |
| 庁議の運営、幹部への説明 | 経営会議の事務局、経営企画、役員対応 |
| 審議会・住民会議の設計と運営 | ステークホルダー対応、ファシリテーション |
| パブリックコメントの実施 | 広報、ステークホルダー調整 |

並べると、**経営企画・事業企画の領域にほぼそのまま重なっている**ことが分かります。違うのは対象が行政サービスか事業かという点であって、やっていること自体は近い。

:::insight
企画課の方の書類で、いちばんもったいないのが**「計画を作った」で止めてしまうこと**です。求人票に「計画策定」という言葉は出てきますが、それだけでは**文書を書いた人**として読まれます。読み手が知りたいのは、**その計画で何が動いたか**です。まち・ひと・しごと創生法が計画の作成と本部の設置を並べて書いているのと同じで、企画課の仕事も**作ることと回すことの2つ**です。書類には後者を必ず入れてください。「策定後、◯課で構成する推進会議を設置し、四半期ごとに進捗を確認する形にした」の1行があるかどうかで、読まれ方が変わります。検索する語も「企画」ではなく「経営企画」「事業企画」「計画管理」に変えてください。
:::

## この経験がとくに高く評価される場所

同じ企画課出身でも、行き先によって値の付き方が変わります。大きく3つです。

### 1. 事業会社の経営企画・事業企画

いちばん自然な接続先です。中期計画の策定、部門計画との整合、進捗管理、指標の設計。**構造がそのまま重なります。**

ここで効くのは、**権限がないまま全体を動かしてきた経験**です。経営企画は、事業部に対して指示する権限を持たないことが多い部署です。それでも計画どおりに進める必要がある。**企画課が庁内でやってきたことと同じ形です。**

[財政・会計の経験が効く求人を見てみる](../?fin=1)

### 2. 自治体を顧客にしている企業

自治体向けのコンサルティング、シンクタンク、システム、まちづくり関連の企業です。

ここでは**計画の中身と、計画が動く仕組みの両方を知っていること**が値になります。総合計画にどう書かれると予算がつきやすいのか、個別計画と総合計画の関係はどうなっているのか、交付金の要件を計画にどう落とすのか。**外からは見えません。**

提案が通らない会社の多くは、ここを理解しないまま「良い提案」を作っています。

[行政が相手の求人を見てみる](../?gov=1)

### 3. 自治体と組んで動かす事業を持つ企業

地域に拠点を置く事業、観光、エネルギー、農業、交通など、**自治体と一緒に動かす必要がある事業**を持つ企業です。

広域連携や他団体との協議をしてきた経験は、そのまま渉外や事業開発として読まれます。とくに、**利害の違う相手をひとつの合意に持っていった経験**は、社外との連携が必要な事業で直接使えます。

## 職務経歴書でつまずきやすい点

**1. 「計画を策定」で終わる**

いちばん多い失敗です。**策定後に何が動いたかを1行足してください。**

**2. 関わった計画の名前を並べてしまう**

「◯◯総合計画」「◯◯総合戦略」「◯◯ビジョン」が並ぶと、読み手は違いが分かりません。**計画の名前ではなく、自分が担当した工程を書いてください。**現状分析なのか、指標の設計なのか、審議会の運営なのか、庁内調整なのかで、伝わる能力が変わります。

**3. 「調整力」で終わらせる**

庁内調整は確かに大変ですが、その言葉だけでは何ができる人か分かりません。**誰と誰の何が対立していて、どういう材料を出して、どう決着させたか。**そこまで書いて初めて、プロジェクトを進められる人として読まれます。

**4. 指標の話を落としてしまう**

行政評価や総合戦略では、指標を設定して実績を追っています。これは民間でいう指標設計そのものです。**どの指標を、なぜその指標にしたか、そして実績をどう集めたか**を書くと、データを扱える人として読まれます。

**5. 権限がなかったことを弱みとして書く**

**逆です。**権限がないまま動かしてきたことが強みです。「決定権はなかったが、◯課との合意を積み上げて計画に反映させた」と書いてください。

自分の経歴がどう言い換えられるかは、一度話しながら整理したほうが早いことが多いです。[どの経験に値が付くのかから相談できます](../apply.html)。

:::insight
ここまで書いておいて逆のことを言いますが、**企画課にいるうちに動かないほうがよい場合もあります。**とくに、**計画を策定して、その計画で1年でも実績を追った経験がない段階**です。企画課の書類でいちばん効くのは、作った話ではなく**回した話**なので、策定だけで終わっていると書けることが薄くなります。策定の翌年度に進捗管理を1回でも通せば、材料の厚みが変わります。もう一つ、企画課は**庁内のほぼ全部署と接点を持つ部署**です。ここで作った関係は、庁内に残る場合でも外に出る場合でも効きます。異動の希望が通る見込みがあるなら、そちらを先に試すのも十分に理のある判断です。
:::

## まとめ

- まち・ひと・しごと創生法第1条は、**計画（総合戦略）の作成と、推進本部の設置**を並べて定めています。企画課の仕事も**作ることと回すことの2つ**です
- 企画課は**権限を持ちません。**持っているのは計画に書き込む権限と、場を設計する権限だけです。この構造は民間の経営企画とほぼ同じです
- 庁内の「総合計画の策定」は、求人票では**「中期経営計画の策定」「計画管理」「事業評価」**と書かれています。**検索する言葉を変えるところから始めてください**
- 評価が高くなるのは、**経営企画・事業企画／自治体を顧客にする企業／自治体と組んで動かす事業を持つ企業**の3方向です
- 職務経歴書では、**計画の名前ではなく担当した工程**を書き、**策定後に何が動いたか**を必ず足してください
- **権限がなかったことは弱みではありません。**権限がないまま動かした経験こそが読まれます

在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。

## よくある質問

### 企画課は「何でも屋」で専門性がないと言われますが、不利になりますか

なりません。むしろ、**担当した工程を具体的に書けば、専門性は説明できます。**現状分析とデータの整理、指標の設計、審議会の設計と運営、庁内調整、進捗管理。どれも民間に対応する職種があります。不利になるのは「何でもやりました」と書いたときで、**工程を選んで書けば印象は変わります。**

### 総合計画しか担当していなくても、転職先はありますか

あります。総合計画は**全部署の事業を1つの体系に並べる作業**なので、範囲としてはかなり広い仕事です。書き方としては、計画そのものより**「どうやって全部署から材料を集め、体系に落としたか」**を書いてください。民間の中期経営計画の策定と、工程がほぼ同じです。

### 財政課と企画課では、どちらが転職に有利ですか

有利・不利ではなく、**接続先が違います。**財政課は数字で配分を決める側なので財務企画・予実管理に、企画課は計画と体制を作る側なので経営企画・事業企画に接続しやすくなります。両方を経験しているなら、**「決める側と回す側の両方を知っている」**という説明が管理部門の求人でよく効きます。財政課側の整理は[財政課の経験は民間で何と呼ばれるか](dept-zaisei-honyaku.html)にあります。
