服装で選考の結果が変わることは、**ほとんどありません。**

ただし、**確認の手間が生じる場面**はあります。指定を読み違える、季節に合っていない、画面越しで印象が変わる。**いずれも、準備で避けられます。**

この記事では、**判断の基準**を扱います。面接の全体像は[公務員からの転職面接｜全体の流れと準備](senko-mensetsu-nagare.html)にあります。

## 「職の信用」を意識してきた経験は、そのまま使えます

**公務員の方は、この論点にすでに慣れています。**

**地方公務員法第33条**です。

> 職員は、**その職の信用を傷つけ、又は職員の職全体の不名誉となるような行為**をしてはならない。

**職の信用**という概念が、法律に置かれています。

**窓口に立つとき、住民説明会に出るとき、議会に出席するとき。****場に応じた身なりを判断してきたはず**です。

**面接の服装も、同じ考え方で決まります。****相手と場に合わせる。**それだけです。

**「自分らしさ」を表現する場ではありません。**

## 基本：指定がなければスーツ

| 状況 | 服装 |
|---|---|
| 指定なし | **スーツ**（無地または目立たない柄） |
| 「服装自由」 | **襟のある服装**。スーツでも問題になりません |
| 「私服でお越しください」 | 襟のある服装。**スーツは避けたほうが自然** |
| 現場の見学を伴う | 事前に確認。**動きやすい服装**を求められることがある |

**2つ目の「服装自由」は、判断に迷う表現**です。

**多くの場合、「スーツでなくてよい」という意味**であって、**「何でもよい」という意味ではありません。**

**迷った場合は、スーツか、それに近い服装を選んでください。**指定を外して減点されることは、まずありません。

## 季節の扱い

| 時期 | 実務 |
|---|---|
| 夏（軽装の期間） | 上着なし、襟のあるシャツで問題ないことが多い |
| 冬 | 上着を脱いだ状態で整っているか確認 |
| 雨天 | 傘や靴の水滴。**受付の前に整える** |

**夏の軽装については、応募先の案内に記載があればそれに従ってください。**

**記載がない場合は、上着を持参して、会場の様子で判断する**という方法があります。

**役所でも、期間を定めた軽装の取組がある自治体が多い**はずです。**同じ判断で構いません。**

## 画面越しの場合

**対面と、見え方が変わります。**

| 項目 | 注意 |
|---|---|
| 色 | **濃い色のほうが、画面では締まって見える** |
| 柄 | 細かい柄は、**画面で乱れて見えることがある** |
| 明るさ | 暗い背景に暗い服装だと、**輪郭が沈む** |
| 映る範囲 | **胸から上。**下も整えておく（立つ場面がある） |

**1つ目と3つ目は、逆に見えることがあります。**

**背景が暗い場合、濃い色の服装だと全体が沈みます。****背景を明るくするか、光を当てるか、どちらかで調整してください。**

**画面越しの準備は**[Web面接の準備と注意点](senko-mensetsu-web.html)**に整理しています。**

## 職種による違い

| 職種 | 傾向 |
|---|---|
| 事務・営業・企画 | **スーツ**が基本 |
| 技術職（建設・設備） | スーツ。**現場の見学があれば別途案内される** |
| 医療・福祉の事業者 | スーツ。清潔感が重視される |
| 情報システム | 服装が自由な会社も多いが、**面接はスーツが無難** |

**4つ目について補足します。**社員の服装が自由な会社でも、**面接ではスーツで臨む応募者が多い**とされています。

**社風に合わせる必要はありません。**入社後に合わせれば足ります。

:::insight
服装について、面談で伺っていて感じるのは、**公務員の方は、この論点でほとんど失敗しないこと**です。理由は明確で、**窓口や説明会で「場に合わせる」判断を日常的にしてきたから**です。むしろ、**気にしすぎて準備に時間を使ってしまう**ほうが問題になります。新しくスーツを買い直す、靴を新調する。**その時間は、書類の要約欄を直すほうに使ってください。**判断に迷ったときの基準は1つで、**「その場にいる人と、極端に違わないか」**です。面接官がスーツなら、スーツで違和感がない。**それで足ります。**もう1点、**在職中に平日の面接を受ける場合、職場からスーツで出るのが難しい**という相談があります。その場合は、**夕方以降の時間帯で調整する**か、**画面越しの面接が可能か確認する**という方法があります。日程の調整は、相談できる部分です。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 持ち物

**服装より、持ち物のほうが判断に迷う場面が多い**かもしれません。

| 持ち物 | 要否 |
|---|---|
| 提出済みの職務経歴書と履歴書 | **必ず持参。**手元に置いて構いません |
| 求人票を印刷したもの | あると、逆質問の確認に使えます |
| 筆記具とメモ | **持参。**メモを取ることは問題ありません |
| 身分を証明するもの | 受付で求められる場合があります |
| 印鑑 | 通常は不要。**指定があれば持参** |

**1つ目を忘れる方がいます。**面接では、**書類に沿って質問されます。**手元に無いと、数字や期間を確認できません。

**2つ目は、応募から時間が経っている場合に効きます。**複数社に応募していると、**どの求人のどの条件だったかが混ざります。**印刷して持っておくと、その場で確認できます。

**なお、メモを取ること自体は、多くの場合で歓迎されます。**ただし、**書き続けて相手を見なくなるのは避けてください。**要点だけにとどめます。

## 身だしなみの確認

| 項目 | 確認 |
|---|---|
| 髪 | 顔にかからない。**画面越しでは、影に注意** |
| 手元 | 爪。**資料を指す場面がある** |
| 持ち物 | 書類の入るかばん。**手に持てる大きさ** |
| 靴 | 汚れ。**雨天は替えを検討** |
| 香り | **強い香りは避ける** |

**3つ目について補足します。**対面の面接では、**書類を渡されることがあります。**折らずに持ち帰れるかばんを用意してください。

**5つ目は、意外に指摘されにくく、印象に残りやすい部分**です。

**また、当日に体調を崩した場合は、無理に受けずに連絡してください。**日程の変更は、**多くの場合で調整されます。**無理に受けて本来の受け答えができないほうが、双方にとって損になります。連絡は、**分かった時点で早いほうが確実**です。

## 在職中に平日の面接を受けるとき

| 状況 | 対処 |
|---|---|
| 職場からスーツで出られない | **夕方以降に調整**するか、**着替えの場所を確保** |
| 年次休暇を取りにくい | **画面越しの面接が可能か確認** |
| 面接が複数社になる | **同日にまとめる**（間を30分以上空ける） |

**着替えの場所としては、有料の個室のスペースや、駅の設備**を使う方法があります。

**慌ただしい移動は、面接の前の集中に影響します。**余裕のある日程を組んでください。

[経験の言い換えから相談する](../apply.html)こともできます。

**同日に複数社を回る場合は、面接の間に15分程度の余裕を作り、その時間で次の応募先の求人票を読み返してください。**社名や職種を取り違えたまま臨むと、**その一点で印象が決まります。**

## よくある失敗

**1. 「服装自由」を「何でもよい」と読む**

**襟のある服装**が基本です。

**2. 画面越しで、背景と服装が同系色**

**輪郭が沈みます。**

**3. 上着を脱いだ状態を確認していない**

**冬は、脱いだ後の状態も見られます。**

**4. 書類の入らないかばんで行く**

**資料を渡されることがあります。**

**5. 服装の準備に時間をかけすぎる**

**書類の見直し**のほうが効きます。

**6. 移動の余裕がない日程を組む**

**面接の前の集中**に影響します。

:::insight
ここまで服装の話をしておいて逆のことを言いますが、**この論点に判断で迷う場面は、実際にはほとんどありません。**指定がなければスーツ、指定があればそれに従う。**この2つで、大半が決まります。**面談で拝見していると、**服装よりも、当日の時間の使い方で失敗する方**のほうが多いです。移動に余裕がなく、**面接の直前まで慌てていて、用意した答えが出てこない。**画面越しの面接で、**接続の確認を直前にして、開始が遅れる。**こちらのほうが、結果に影響します。**準備の順序としては、①日程と移動の余裕、②接続や経路の確認、③服装**です。服装は3番目で足ります。そして、**面接の前の30分は、何も新しいことをせず、書類を読み返すだけにしてください。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方公務員法第33条**は、**その職の信用を傷つける行為**を禁じています。**場に応じた判断は、すでに経験しています**
- **指定がなければスーツ。**「服装自由」は、**襟のある服装**という意味に読んでください
- **画面越しでは、背景と服装の色が同系だと輪郭が沈みます**
- **書類の入るかばん**を用意してください。資料を渡されることがあります
- **服装の準備に時間をかけすぎない。**書類の見直しのほうが効きます
- 準備の順序は、**①日程と移動の余裕 ②接続や経路 ③服装**です

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### スーツを持っていません

**新しく揃える必要があるかは、応募先によります。**技術職で現場が中心の職種や、服装が自由な会社では、**襟のある服装で足りる**場合があります。**まず、応募先の案内を確認してください。**必要な場合も、**面接に対応できるものが1着あれば足ります。**色は、濃い色で無地であれば問題になりません。**複数の会社を受ける場合も、同じもので構いません。**なお、**購入に時間をかけて応募が遅れるのは本末転倒**です。手持ちのもので対応できるかを先に確認してください。

### 髪の色やひげは、どこまで許容されますか

**応募先の業界と職種によって幅があります。**判断の目安は、**その会社の公式サイトに出ている社員の写真**です。採用のページや、事業の紹介のページに、**実際の社員が写っていることがあります。**そこから、おおよその傾向が分かります。**ただし、面接の場では、普段より整えた状態で臨むのが無難**です。入社後に合わせられる部分は、**入社後で足ります。**なお、**清潔感については、どの業界でも共通して見られます。**髪、爪、靴。**この3点が整っていれば、大きく外すことはありません。**

### マスクを着けたまま面接を受けてよいですか

**応募先の案内に従ってください。**記載がない場合は、**着けたまま入室し、相手の様子を見て判断する**という方法があります。外すよう求められることもあれば、着けたままで進むこともあります。**体調に不安がある場合は、着けたままで構いません。**その旨を一言添えれば足ります。なお、**画面越しの面接では、外すのが一般的**です。表情が伝わりにくくなるためです。**体調が悪い場合は、日程の変更を相談してください。**無理に受けるより、**変更を申し出るほうが確実**です。
