**施設や設備の管理に関わってきた方から、「資格をどう使うか」**というご相談を伺います。

**選任が義務づけられている資格**は、需要の構造がはっきりしています。

この記事では、**その構造**と、**経験との接続**を扱います。

**⚠ 免状の要件と手続は、所管するところの公表を確認してください。****この記事では、個別の要件には触れません。**

## 選任が、設置する者の義務として定められています

**電気事業法第43条第1項**です。

> **事業用電気工作物を設置する者は、事業用電気工作物の工事、維持及び運用に関する保安の監督をさせるため、主務省令で定めるところにより、主任技術者免状の交付を受けている者のうちから、主任技術者を選任しなければならない。**

**「選任しなければならない」**と定められています。

**そして、選任できるのは、免状の交付を受けている者**です。

**つまり、一定の設備を持つ事業者では、この資格を持つ人が必要になる**という構造です。

**資格の需要が、法律の条文から生じている**ということです。

**この点が、他の多くの資格と違います。**

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 施設の管理・運営 | **設備の保安の監督** |
| ② 指定管理・受託の会社 | 複数の施設を持つ |
| ③ 製造・物流の拠点 | 設備の維持 |
| ④ 建物の管理 | 保守、点検 |
| ⑤ 発注者支援 | **発注する側の視点** |

**②について。**

**公の施設の運営を担う会社では、設備の保安の体制が必要**です。

**公営企業や施設の管理を経験した方は、この領域と重なります。**

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 行政での経験との接続

| 経験 | 民間での読まれ方 |
|---|---|
| ① 施設・設備の管理 | **保全の計画、点検の管理** |
| ② 保守の委託の管理 | 委託先の管理、履行の確認 |
| ③ 工事の発注と監督 | 発注者としての監督 |
| ④ 事故・停止への対応 | 初動、報告、再発の防止 |
| ⑤ 更新の計画 | 中長期の計画、予算 |
| ⑥ 法令に基づく点検 | 記録の整備 |

**②と⑤が、行政ならでは**です。

**②について。**

**保守を委託し、仕様に基づいて履行を確認してきた経験**です。

**⑤について。**

**設備の更新を、予算の年度と合わせて計画した経験**は、**民間の設備の投資の計画と同じ動作**です。

**扱いは**[財務諸表の読み方｜公会計との違いから入る](skill-zaimu.html)**にも整理しています。**

## 書き方の例

**悪い例**

> 施設の管理を担当しました。

**良い例**

> ◯◯（延床面積約◯平方メートル、受変電設備を含む）の管理を担当。**保守の委託◯件について、仕様の作成から履行の確認までを実施。****法令に基づく点検の記録を整備し、指摘事項の是正を管理。**設備の更新について、**◯か年の計画を作成し、年度ごとの予算に反映。**停電や故障が生じた際は、**初動の手順に沿って対応し、経緯と再発の防止の措置を記録。**

**「規模」「委託の管理」「記録」「計画」「対応」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

:::insight
設備の管理について、**面談でお伝えしているのが「更新の計画を書いてください」**という点です。**日々の点検や保守は、委託していることが多い**です。ところが、**どの設備を、いつ、どの順で更新するかを決める**のは、発注する側の仕事です。**耐用の年数、故障の状況、予算の見通し、工事の時期。**これらを踏まえて順番を決め、**年度ごとの予算に落とす。****この作業は、民間の設備の投資の計画と同じ動作**です。しかも、**行政では、予算の年度と議決の手続が加わる**ため、**より長い見通しで組み立てる**ことになります。書類には、**「◯か年の更新の計画を作成し、年度ごとの予算に反映」**と書いてください。**「施設の管理を担当」では、この判断が伝わりません。**資格と併せて書くと、**管理する立場として読まれます。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 資格の位置づけ

| 状況 | 扱い |
|---|---|
| ① 選任の対象となる事業所 | **資格が前提になります** |
| ② 応募条件に記載がある | 満たす材料になる |
| ③ 管理・発注の側 | **経験のほうが具体な場合も** |
| ④ 免状の区分 | **扱える範囲が定められています** |
| ⑤ 目的が曖昧 | 優先順位を下げてください |

**④について。**

**⚠ 免状の区分と、扱える範囲は、所管の公表を確認**してください。

**この記事では触れません。**

**なお、取れば転職できる、という関係にはありません。**

**何を管理し、どう判断したか**が、評価の対象です。

## 取る前に考えること

| 確認すること | 内容 |
|---|---|
| ① 目的 | **選任されるのか、管理に回るのか** |
| ② 免状の要件 | 所管の公表を確認 |
| ③ 実務で書ける材料 | 委託、点検、更新、対応 |
| ④ 期限 | 応募の時期に間に合うか |
| ⑤ 会社の支援 | 取得の支援の制度 |

**①で大きく分かれます。**

**選任される立場**を目指すのか、**発注や管理の側に回る**のか。

**後者であれば、資格が必須でない求人があります。**

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 実績の整理 | **施設の規模、設備の種類、委託の件数** |
| 記録の確認 | 点検の記録、是正の経緯 |
| 更新の計画の整理 | 年数、優先順位の根拠 |
| 求人を読む | 週に30分 |

**1行目です。**

**台帳や決裁の資料から、規模と件数を確認**してください。

**根拠のない数は書かないでください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 担当した施設 | **規模、設備の種類、期間** |
| 委託の管理 | 仕様、履行の確認 |
| 点検と是正 | 記録の残し方 |
| 事故・停止への対応 | 3件、初動と処置 |
| 立場 | **選任者か、管理・発注側か** |

**4行目です。**

**なお、特定の事案が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

## 記録の整備という材料

**設備の管理では、記録が成果物になります。**

| 記録 | 内容 |
|---|---|
| ① 点検の記録 | 実施の日、結果、担当 |
| ② 是正の経緯 | 指摘、対応、確認 |
| ③ 故障・停止の記録 | 発生、初動、復旧、原因 |
| ④ 更新の履歴 | 何を、いつ、いくらで |
| ⑤ 図面・台帳 | 現況との整合 |

**⑤が見落とされやすい**です。

**図面や台帳が現況と合っていないと、更新の計画が立てられません。**

**現況に合わせて台帳を整理した経験**があれば、書いてください。

**この作業は、引き継いだ側でなければ分からない**ものです。

**「台帳と現況の相違を確認し、◯件を修正」**という形で書けます。

## よくある失敗

**1. 「施設の管理」で止める**

**規模と設備の種類**を書いてください。

**2. 更新の計画を書かない**

**設備の投資の計画**と同じ動作です。

**3. 委託の管理を書かない**

**仕様と履行の確認**は経験です。

**4. 点検の記録を書かない**

**法令に基づく記録の整備**です。

**5. 立場を書かない**

**選任者か管理・発注側か**を明記してください。

**6. 免状の区分を確認しない**

**扱える範囲**が定められています。

**7. 要件を人づてで判断する**

**所管の公表**を確認してください。

**8. 取れば転職できると考える**

**何を管理しどう判断したか**が評価の対象です。

:::insight
ここまで「管理の経験」を強調しておいて逆のことを言いますが、**選任される立場を目指すなら、扱いが変わります。**面談で拝見していると、**管理や発注の経験だけで、選任が前提の求人に応募する方**がいらっしゃいます。**電気事業法第43条のとおり、選任できるのは免状の交付を受けている者**です。**経験では代えられません。**ですから、**「どちらに行きたいか」を先に決めてください。**選任される立場を目指すなら、**免状の取得が前提**になります。一方、**施設の運営の管理、委託先の管理、発注者支援**であれば、**いまの経験がそのまま使えます。**そして、**後者のほうが、行政の経験と重なる範囲が広い**です。**求人票の応募条件で、選任を前提としているかを確認**してください。**この確認を飛ばすと、条件が合いません。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **電気事業法第43条第1項**は、**事業用電気工作物を設置する者が、保安の監督をさせるため、免状の交付を受けている者のうちから主任技術者を選任しなければならない**としています
- **資格の需要が、法律の条文から生じています**
- 効くのは、**施設の管理・運営、指定管理・受託の会社、製造・物流の拠点、建物の管理、発注者支援**です
- **更新の計画を作った経験**を書いてください。設備の投資の計画と同じ動作です
- **保守の委託の管理**も、行政ならではの材料です
- **選任される立場を目指すか、管理・発注に回るか**を先に決めてください
- **選任は、免状の交付を受けている者に限られます。**経験では代えられません

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 事務職として施設の管理に関わっていました

**書けます。**技術職でなくても、**委託の契約、点検の記録の管理、更新の予算の要求、事故時の報告**に関わっていれば、材料になります。書き方は、**「保守の委託◯件について、仕様の確認から契約、履行の確認までの手続を担当」**という形です。**技術的な判断を担っていない場合は、そう書いてください。**「技術的な確認は担当課が実施し、契約と記録の管理を担当」。**できる範囲を正確に書く**ほうが、入社後に困りません。扱いは[契約書の読み方｜自治体の契約実務との差](skill-keiyakusho.html)に整理しています。

### 公営企業の経験は、どう評価されますか

**公と民の両方が分かる立場として読まれます。**公営企業では、**公共の目的を持ちながら、収支を意識して運営する**ことになります。**この経験は、指定管理や受託の事業で直接使えます。**書き方は、**「◯◯事業において、設備の維持と収支の管理の両方を担当」**という形です。扱いは[出先機関・出資団体からの転職](senko-tachiba-shussaki.html)にも整理しています。なお、**料金や収支に関わった経験**があれば、併せて書いてください。**設備の管理だけでなく、事業の運営として読まれます。**

### 資格の取得を、会社が支援してくれますか

**会社の制度によります。**求人票や採用のページで、**取得の支援の有無**を確認してください。**入社後の取得を前提とする求人**もあります。この場合、**応募の時点で資格がなくても選考が進む**ことがあります。なお、**選任が前提の職**では、**入社時点での保有が要件**となることがあります。判断の目安は、**求人票の「必須」の欄**です。読み方は[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。**確認してから応募してください。**
