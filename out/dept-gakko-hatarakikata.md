学校事務の働き方には、**他の職場にない前提**があります。

**一年の日程が、最初から決まっている**ことです。

いつ始まり、いつ休みで、いつ終わるか。**年度が始まる前から、ほぼ全部が決まっています。**

これは、**予定が立てやすいという意味でもあり、動かせないという意味でもあります。**

この記事では、一年の波と、成果が見えにくくなる構造、そして民間に移ったときに何が変わるかを整理します。**不満の話ではなく、構造の話**として読んでください。転職の場面で、自分の仕事をどう説明するかに直結します。

言い換えは[学校事務の経験は民間で何と呼ばれるか](dept-gakko-honyaku.html)、行き先は[学校事務からの転職先](dept-gakko-tenshokusaki.html)、書類は[職務経歴書](dept-gakko-shokumu.html)、面接は[面接で聞かれること](dept-gakko-mensetsu.html)に分けています。

## 休業日が、規則で決まっています

まず、一年の日程が決まっている根拠を条文で確認します。

学校教育法施行規則第61条は、こう定めています。

**公立小学校における休業日は、次のとおりとする。**

そして、**国民の祝日に関する法律に規定する日、日曜日及び土曜日、学年の始期又は終期の前後における休業日で当該学校を設置する地方公共団体の教育委員会が定めるもの**が並びます。

**つまり、長期の休業も、教育委員会が定めるものとして決まっています。**

**この「決まっている」ことが、学校事務の働き方を形づくります。**

- **工事は、長期の休業中にしかできない**
- **教材は、年度の初めに間に合わせる必要がある**
- **行事の前には、必ず支出がある**
- **年度末には、支払いを締めて、徴収金を精算する**

**日程が動かせないので、逆算するしかありません。**

**面接では、この構造を一度言ってください。**

> 学校は、**一年の日程が最初から決まっています。**工事は長期の休業中、教材は年度の初め、行事の前には必ず支出がある。**動かせない日程から逆算して、執行の時期を先に押さえる**という仕事の仕方でした。

**「動かせない日程から逆算する」**——これは、**繁閑がはっきりした拠点を持つ事業**で、そのまま必要になります。

## 一年の波

| 時期 | 主な仕事 | 忙しさ |
|---|---|---|
| 4月 | **新入学・進級、教職員の異動、教材の一斉配備、就学援助の一斉申請、年度当初の予算の配分** | 最も高い |
| 5〜6月 | 徴収金の開始、健康診断に関する事務、行事に伴う契約 | 高 |
| 7〜8月 | **長期の休業中に工事が集中。**立会いと確認 | 高 |
| 9〜12月 | 行事に伴う支出、次年度の予算要求、備品の整理 | 中 |
| 1〜3月 | **卒業・入学の準備、支払いの締め、徴収金の精算、表簿の整理と保存** | 最も高い |
| 毎日 | 開校時間中は、来客・電話・教員からの依頼が入り続ける | — |

**山は2つ**あります。

**1つ目は4月**です。**新入学と進級で対象が一斉に入れ替わり**、同時に**教職員の異動**があります。**教材の配備も、就学援助の申請も、予算の配分も、この月に重なります。**

**2つ目は1〜3月。**年度末の支払いを締め、**徴収金を精算して残額を返し**、**表簿を整理して保存年限を管理**します。**そして、次の4月の準備が並行して走ります。**

**そして、毎日の制約があります。**開校している間は、**来客、電話、教員からの依頼**が入り続けます。**まとまった作業の時間を、意識して作らないと取れません。**

:::insight
学校事務の働き方で、面接のときに説明しにくいのが、**「割り込みが前提の中で、締切のある作業をしていた」**という点です。開校時間中は、来客も電話も教員からの依頼も入ります。一方で、支払いにも、表簿の整理にも、就学援助の取次ぎにも締切があります。面接でこれを「常に中断されて大変でした」と言うと、**段取りができない人**に聞こえます。言い換えるなら、**「割り込みが入る前提で、締切のある作業の時間を先に確保していた」**です。具体的には、**来客が少ない時間帯に締切のある作業を寄せる、締切から逆算して着手日を決めておく、中断しても戻れるように作業の単位を小さく区切る。**このうち一つでも言えると、**設計している人**として読まれます。**民間の拠点の管理部門も、まったく同じ環境**です。電話も来客も社内からの依頼も入る中で、月次の締めをこなします。**「割り込みの中で締切を守る設計」を話せる人は、意外に多くありません。**
:::

## 成果が見えにくいのは、職の構造によるものです

学校事務の成果が評価に結びつきにくいのには、**3つの構造的な理由**があります。**評価してもらえないという話ではなく、職の構造からそうなる**という話です。

**1. 成果が「間違いなく回ったこと」の形をとる**

支払いが遅れなかった。徴収金が合っていた。表簿が揃っていた。**どれも、何も起きないという形でしか表れません。**

一方、**間違えたときだけ表に出ます。**

**2. 同じ職の人が、その職場にいない**

**一人職**であることが多いため、**比べる相手がいません。**そして、**評価する側（校長）も、事務の専門家ではありません。**

**何が難しく、何が工夫なのかが、外から見えにくい**という構造です。

**3. 学校の成果は、教育の成果として整理される**

学校がうまく回っていても、**それは教育の成果**として語られます。**事務の寄与は、分けて数えられません。**

この3つのうち、**1つ目と2つ目は、書き方で置き換えられます。**

**1つ目は、「間違いの件数」ではなく「扱った量」**です。予算の執行額、徴収金の額、調達と支払の件数、対象となる児童生徒数と教職員数。**「これだけの量を、一人で、間違いなく回した」**という形なら書けます。

**2つ目は、「自分で作った仕組み」**です。執行の時期の一覧、手続の区分の一覧、保存年限の一覧。**比べる相手がいなくても、作ったものは残ります。**

## 民間に移ると変わる4つのこと

**1. 同じ職種の人が、周りにいる**

一人職ではなくなります。**相談できる相手ができる**一方で、**比べられる対象もできます。**

**これは、慣れるまで戸惑う部分です。**ただし、**「一人で全部を回してきた」という経験は、比較の中でむしろ際立ちます。**

**2. 収入の側がある**

公立の学校事務は、**費用だけを管理**してきました。民間では、**売上や入金の側**があります。

**ここは新しく覚える部分**です。**面接でも、正直に言ったほうが通ります。**

**3. 成果が数字で測られる**

企業では、**処理の件数、期間、エラー率、コスト**が指標になります。**「適正に回した」では止まりません。**

だから、**「扱った量」を持っていることが、そのまま説明の材料になります。**

**4. 制度を覚え直す**

会計の制度も、決裁の範囲も、使うシステムも違います。**制度そのものは一から**です。

**ただし、「決められた手続に合わせて正確に回す」という仕事の仕方は変わりません。**

## 在職中に残しておくべき記録

転職を考え始めたら、**在職中に手元に控えておくもの**があります。辞めてからでは集めにくくなります。

| 残すもの | 使う場面 | 注意 |
|---|---|---|
| **児童生徒数と教職員数** | 職務要約 | **拠点の規模がいちばん伝わる。公表されている** |
| **年間の予算の執行額** | 職務要約、実績 | **扱っていた金額。手元の資料から拾える** |
| **学校徴収金の年間の額** | 職務要約、実績 | **公費と分けて書く** |
| 調達・支払の年間の件数 | 実績 | 概数で可 |
| **経験した学校数と、それぞれの規模** | 職務要約 | **複数校なら必ず書く** |
| 施設の延べ床面積 | 担当業務 | 公表されている |
| 備品の登録件数 | 担当業務 | 資産管理の規模が伝わる |
| 保存年限を管理していた表簿の種類数 | 実績 | 記録管理の実務として効く |

**5行目が見落とされやすい項目です。**複数校を経験していれば、**「規模の違う拠点を、それぞれの運用に合わせて回してきた」**と書けます。**これは、多拠点を扱う企業で重要な視点**です。

そして、**書いてはいけないもの**も確認しておきます。

- 指導要録、出席簿、健康診断に関する表簿の内容
- 児童生徒や保護者に関する一切の情報
- 就学援助の申請や認定に関する個別の状況
- 徴収金の未納に関すること
- 教職員の履歴、給与、勤務、服務に関する個別の情報
- 特定の学校の内部の状況や、評判に関すること
- 公表前の工事や整備の計画

**書けるのは、「何を、どう管理し、どれだけの量を扱ったか」までです。**

:::insight
ここまで転職の前提で書いてきましたが、**残る判断のほうが妥当な場面もあります。**学校事務は、**一校目と二校目で、書ける内容がはっきり変わる**仕事です。一校目だけだと、**「その学校のやり方」しか知らない**ことになります。二校目に移ると、**学校によって運用が違うことが分かり**、**「規模も運用も違う拠点を、それぞれに合わせて回してきた」**と書けるようになります。これは、**多拠点を扱う企業でいちばん効く視点**です。まだ一校目なら、**異動を一度経てからのほうが、説明の幅が明確に出ます。**もう一つ、**簿記2級の学習**は、在職中に進めておく価値があります。**公会計で身についた実務を、企業会計の言葉に置き換えられる**ようになり、**書類でも面接でもいちばん効きます。**逆に、**すでに二校以上を経験し、簿記にも着手しているなら、待つ理由はあまりありません。**応募先が決まっていない段階のほうが、整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## つまずきやすい点

**1. 「常に中断されて大変でした」と説明する**

**「割り込みが入る前提で、締切のある作業の時間を先に確保していた」**と言い換えてください。

**2. 「間違いがなかった」を成果として書く**

**「扱った量」で書いてください。**「これだけの量を、一人で、間違いなく回した」という形です。

**3. 自分で作った仕組みを書かない**

**比べる相手がいなくても、作ったものは残ります。**執行の時期の一覧、手続の区分、保存年限の管理。

**4. 経験した学校数と規模を控えていない**

**「規模も運用も違う拠点を、それぞれに合わせて回してきた」**という、多拠点で効く視点になります。

**5. 退職後の手続きを確認しないまま動く**

退職手当や共済の扱いは在職期間で変わります。**所属の人事担当課と共済組合で先に確認してください。**公務員には雇用保険が適用されないため、辞めてから探すと収入のない期間がそのまま持ち出しになります（[公務員に雇用保険がない理由](seido-shitsugyo-nashi.html)）。

どの経験がどの方向で値が付くかは、募集の出方で変わります。[どの経験に値が付くのかから相談できます](../apply.html)。

## まとめ

- 学校教育法施行規則第61条は、**公立小学校における休業日**を定めています。**長期の休業も、教育委員会が定めるものとして決まっています**
- **日程が動かせないので、逆算するしかありません。**工事は長期の休業中、教材は年度の初め、行事の前には必ず支出がある
- 一年の山は**4月（入れ替わりと異動と配備が重なる）**と**1〜3月（締めと精算と保存、そして次年度の準備）**です
- 成果が見えにくいのは、**「間違いなく回ったこと」の形をとる／同じ職の人が職場にいない／学校の成果は教育の成果として整理される**という3つの構造によるものです
- **「間違いの件数」ではなく「扱った量」**、**「自分で作った仕組み」**で書いてください
- 民間に移ると、**同じ職種の人が周りにいる／収入の側がある／数字で測られる／制度を覚え直す**の4点が変わります

## よくある質問

### 残業は多い職場ですか

学校や年によって違うため、一般化はできません。ただし、**構造として、4月に入れ替わりと異動と配備が重なること**、**1〜3月に締めと精算と次年度の準備が重なること**、**開校時間中は割り込みが入り続けること**は、どこでも共通します。面接で聞かれたら、**一年の日程が最初から決まっているため、山の時期も決まっている**という構造を説明するのが正確です。個別の職場の事情をそのまま話す必要はありません。

### 一人職だったことは、不利になりますか

**職場の規模によって、評価の向きが変わります。**分業が進んだ大きな会社では、**「チームで働いた経験がない」と見られる**ことがあります。一方、**少人数の拠点や事業所では、「一人で全部を回せる人」**として、いちばん求められます。面接では、**「一人でしたが、教員や設置者や業者と常にやり取りしていたので、独りで完結していたわけではありません」**と添えると、**協働の経験も伝わります。**

### 異動して1年ですが、経歴として使えますか

**一年を通していれば使えます。**この仕事は、**4月の入れ替わりから、年度末の締めと精算までを一巡して、初めて全体が見えます。**一巡していれば、**執行の時期の設計も、徴収金の精算も、表簿の保存も説明できます。**逆に、まだ一巡していない段階だと、**年度末の処理が書けません。**判断の目安は、**年度末の締めと、翌年度の準備を一度通したことがあるか**です。書き方は[職務経歴書](dept-gakko-shokumu.html)に整理しています。
