**「公務員の経験が活きる求人が見つからない」**というご相談を伺います。

**探し方の問題であることが多い**です。

この記事では、**求人が存在する構造**と、**探すときの軸**を扱います。

## 行政の仕事を民間が担う仕組みは、法律に置かれています

**地方自治法第244条の2第3項**です。

> 普通地方公共団体は、**公の施設の設置の目的を効果的に達成するため必要があると認めるときは**、条例の定めるところにより、**法人その他の団体**であつて当該普通地方公共団体が指定するもの（略「指定管理者」という。）に、**当該公の施設の管理を行わせることができる。**

**同条第5項**は、**指定の期間**について定めています。

> 指定管理者の指定は、**期間を定めて行うものとする。**

**同条第6項**は、**議会の議決**を必要としています。

**つまり、公の施設の管理を民間の団体が担う仕組みが、法律に置かれている**ということです。

**そして、指定は期間を定めて行われます。**

**期間ごとに、担う団体が改めて決まる**という構造です。

**この構造があるため、担い手の側に継続的な人の需要が生じます。**

**指定管理者制度はその一例**で、ほかにも**業務の委託、発注者支援、制度の運用の支援**など、**行政の仕事を民間が担う形は複数あります。**

**公務員としての経験が使える求人は、この領域に集まっています。**

## 探すときの3つの軸

| 軸 | 内容 | 経験の使い方 |
|---|---|---|
| ① 顧客が行政 | 自治体・官公庁を相手にする事業 | **そのまま使えます** |
| ② 規制を受ける側 | 許認可・監査・報告が必要な業界 | 制度の理解が使えます |
| ③ 機能だけ | 行政と関係が薄い業界 | 担ってきた機能が使えます |

**①から探してください。**

**業界の選び方そのものは**[業界の選び方と、志望動機への落とし方](senko-shibo-gyokaierabi.html)**に整理しています。**

**この記事では、①を具体的にどう探すか**を扱います。

## ①——顧客が行政の事業

| 事業の形 | 仕事の例 |
|---|---|
| 施設の管理 | 公の施設の運営、利用者の対応、収支の管理 |
| 業務の受託 | 窓口の運営、審査の事務、相談の対応 |
| 発注者支援 | 工事の監督の補助、積算、工程の管理 |
| 計画・制度の支援 | 計画の策定の支援、調査、資料の作成 |
| 情報システム | 自治体向けのシステムの導入・運用 |
| 建設コンサルタント | 調査、設計、施工の監理 |

**この6つが、経験の重なりが大きい領域**です。

**どれも、行政の仕事の進め方を知っていること自体が要件になります。**

**予算の年度、議会の時期、決裁の流れ、公表の手順。**

**これらは、外から入った人には見えにくい**ものです。

行政が相手の求人はまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## 求人票で使われている言葉

**「公務員歓迎」と書かれている求人だけを探すと、数が限られます。**

**次の言葉を手がかりにしてください。**

| 分野 | 求人票に出る言葉 |
|---|---|
| 施設 | 指定管理、施設運営、公共施設、管理運営 |
| 委託 | 業務委託、受託運営、BPO、窓口業務 |
| 支援 | 発注者支援、施工管理、積算、監督補助 |
| 制度 | 公共政策、制度設計、行政支援、補助金 |
| 調達 | 入札、公共調達、提案書、プロポーザル |
| システム | 自治体向け、公共分野、基幹システム |
| 営業 | 官公庁営業、自治体営業、公共営業 |

**この言葉が求人票にあれば、行政が相手の事業**です。

**「公務員歓迎」の記載がなくても該当します。**

**むしろ、記載がないほうが競合が少ない**ことがあります。

:::insight
求人の探し方で、**面談でお伝えしているのが「職種名ではなく、業務の中身で探してください」**という点です。行政の仕事を民間で担う求人は、**職種名がばらばら**です。同じ「窓口の運営」でも、求人票の職種名は「カスタマーサポート」「オペレーション」「事務」「公共サービス」と分かれます。**職種名で絞ると、同じ仕事が検索から漏れます。**ですから、**仕事内容の欄に出てくる言葉で探す**ほうが確実です。「自治体」「官公庁」「公共」「委託」「指定管理」。**この言葉が仕事内容の欄にあれば、相手が行政です。**そして、**応募条件の欄に繰り返し出てくる言葉**を見てください。「行政の実務経験」「公共分野の知識」「折衝の経験」。**この言葉があれば、経験が要件として求められている**ということです。**求人票は、応募しなくても読めます。**先に5件読むと、必要な経験が見えてきます。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 探す手段

| 手段 | 特徴 |
|---|---|
| 求人の検索サイト | 数が多い。**条件で絞れる** |
| 人材の紹介 | 非公開の求人がある。条件の確認を任せられる |
| 企業の採用ページ | 掲載されていない職種が出ることがある |
| 業界の団体・イベント | 事業の全体像が分かる |

**1つ目と2つ目を併用**してください。

**検索サイトは、自分で範囲を広げられます。**

**紹介は、条件の確認と日程の調整を任せられます。**

**在職中は時間が限られる**ため、**確認の手間を分けるほうが進みます。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 探す時期

| 時期 | 傾向 |
|---|---|
| 年度の変わり目の前 | 体制の整備にともなう募集が出ることがあります |
| 期の変わり目 | 会社の人員の計画によります |
| 事業の受託が決まった後 | **担い手の確保が必要になります** |

**3つ目です。**

**指定管理者の指定や業務の受託が決まると、その事業を担う人が必要になります。**

**この時期に募集が出ることがあります。**

**ただし、時期は事業ごとに異なる**ため、**待つより、条件を登録しておいて知らせを受ける**ほうが確実です。

## 絞り込みの手順

| 順 | やること |
|---|---|
| 1 | 自分の機能を3つ書き出す |
| 2 | ①〜③の軸で、候補の領域を決める |
| 3 | **仕事内容の欄の言葉**で検索する |
| 4 | 同じ領域の求人票を5件読む |
| 5 | 応募条件に繰り返し出る言葉を拾う |
| 6 | 自分の経験と重なるかを確認する |

**4と5が要**です。

**5件読むと、その領域で求められているものが見えます。**

**そこから、職務経歴書の書き方が決まります。**

## 在職中の進め方

| 項目 | 内容 |
|---|---|
| 検索の時間 | **週に1回、30分で足ります** |
| 条件の登録 | 一度登録すれば知らせが届きます |
| 求人票の保存 | 気になったものを残しておく |
| 比較 | 月に1回、残したものを並べて見る |

**4つ目をしてください。**

**1件ずつ見ていると、条件の相場が分かりません。**

**5件から10件を並べると、自分が何を重く見ているかが見えてきます。**

**勤務地なのか、業務の内容なのか、働き方なのか。**

**この優先順位が決まると、応募する先が絞れます。**

**なお、この作業は応募の意思を固めなくてもできます。**

**在職中に、情報を集める段階として進めて差し支えありません。**

## よくある失敗

**1. 「公務員歓迎」の求人だけを探す**

**数が限られます。**

**2. 職種名で絞る**

**同じ仕事が漏れます。**

**3. 勤務地を先に絞りすぎる**

**候補が減ります。職種を広げてください。**

**4. 求人票を1件だけ見て判断する**

**5件読むと傾向が見えます。**

**5. 応募条件を読まない**

**必要な経験が分かりません。**

**6. 非公開の求人の存在を前提に置かない**

**公開されていない募集があります。**

**7. 条件を登録せずに、出るのを待つ**

**時期は読めません。**

:::insight
ここまで探し方の話をしておいて逆のことを言いますが、**行政が相手の求人に絞る必要はありません。**面談で拝見していると、**「公務員の経験が活きる求人でなければ応募できない」と考えている方**がいらっしゃいます。ところが、**実際に決まる先は、行政と関係が薄い会社であることもあります。**理由は、**担ってきた機能のほうが評価されるから**です。審査の判断、契約の管理、債権の管理、対外の説明。**これらは、業界を問わず必要とされます。**ですから、**①で探し始めて、②③に広げる**という順序が現実的です。①は経験がそのまま重なるため説明が楽ですが、**求人の数そのものは②③のほうが多い**です。**説明の手間と、候補の数は逆の関係**にあります。**どちらから始めてもよいのですが、片方だけで完結させないでください。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方自治法第244条の2第3項**は、**公の施設の管理を指定管理者に行わせることができる**と定めています。**指定は期間を定めて行われ**、議会の議決を要します
- **行政の仕事を民間が担う仕組みが法律に置かれている**ため、**担い手の側に人の需要が生じます**
- 探す軸は、**①顧客が行政 ②規制を受ける側 ③機能だけ**の3つです
- **職種名ではなく、仕事内容の欄の言葉で探して**ください
- **「公務員歓迎」の記載がなくても該当する求人があります**
- **同じ領域の求人票を5件読む**と、求められる経験が見えます
- **①で始めて、②③に広げて**ください。片方だけで完結させないでください

## よくある質問

### 検索しても、行政が相手の求人が出てきません

**検索の語を変えてみてください。**「公務員」で検索すると、**求人票にその言葉が入っているものしか出ません。**代わりに、「自治体」「官公庁」「公共」「指定管理」「業務委託」「発注者支援」で検索してください。**仕事内容の欄に出てくる言葉**です。また、**職種の絞り込みを外して**みてください。職種名がばらばらなため、**職種で絞ると漏れます。**そのうえで、**勤務地の範囲を1段広げて**ください。行政が相手の事業は拠点が分散しているため、**隣接する地域に候補がある**ことがあります。それでも数が少ない場合は、**②規制を受ける側**の領域に広げてください。

### 非公開の求人とは何ですか

**公開の媒体に掲載していない募集**のことです。掲載しない理由は複数あります。**応募が多くなりすぎるのを避ける、組織の変更を公表したくない、後任の募集であることを知られたくない**など、**会社側の事情**です。**人材の紹介を通じて紹介される**形が一般的です。なお、**非公開であることが、条件がよいことを意味するわけではありません。**内容を確認したうえで判断してください。当社を通す場合、**企業へ推薦する形で選考が進みます。**条件の確認や日程の調整をお任せいただけます。**在職中で時間が取りにくい場合は、この手間が省けます。**

### 求人票の情報だけでは、実態が分かりません

**求人票は、明示すべき事項が定められた書類**です。**書かれていることの正確さと、書かれていない部分の把握**を分けて考えてください。**書かれていない部分**を知るには、3つの方法があります。1つは、**同じ会社の求人票を複数見る**こと。もう1つは、**面接で聞く**こと。3つ目は、**紹介を通す場合、企業に確認してもらう**ことです。なお、**求人票の読み方そのもの**は別の記事で整理します。**見るべき欄と、そこから分かることには型があります。**まずは、**同じ領域の求人票を5件読んで、共通する記載と異なる記載を見分ける**ところから始めてください。
