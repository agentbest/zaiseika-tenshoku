**消防士からの転職では、「民間に同じ仕事がない」と感じる方**がいらっしゃいます。

**ところが、消防の知識を要件とする業務が、民間の側に置かれています。**

この記事では、**その構造**と、**経験の示し方**を扱います。

## 事業所には、防火管理者を置く義務があります

**消防法第8条第1項**です。

> **学校、病院、工場、事業場、興行場、百貨店**（略）**その他多数の者が出入し、勤務し、又は居住する防火対象物で政令で定めるものの管理について権原を有する者は、政令で定める資格を有する者のうちから防火管理者を定め、**政令で定めるところにより、当該防火対象物について**消防計画の作成、当該消防計画に基づく消火、通報及び避難の訓練の実施、消防の用に供する設備、消防用水又は消火活動上必要な施設の点検及び整備、火気の使用又は取扱いに関する監督、避難又は防火上必要な構造及び設備の維持管理並びに収容人員の管理その他防火管理上必要な業務を行わせなければならない。**

**同条第2項**は、**選任したときの届出**を義務づけています。

**業務の中身が、条文に列挙されている**点に注目してください。

| 条文に挙げられた業務 | 誰が担うか |
|---|---|
| 消防計画の作成 | **民間の事業所の側** |
| 消火・通報・避難の訓練 | 同上 |
| 設備・施設の点検及び整備 | 同上 |
| 火気の監督 | 同上 |
| 避難・防火上の構造及び設備の維持管理 | 同上 |
| 収容人員の管理 | 同上 |

**これらは、消防が査察や指導で見てきた項目**です。

**つまり、指導してきた側の知識が、民間では担う側の業務**になります。

## 経験を分ける

| 要素 | 実際にやっていること |
|---|---|
| ① 警防（消火・救助） | 現場の判断、部隊の運用、安全の管理 |
| ② 救急 | 観察、処置、搬送、記録 |
| ③ 予防（査察・指導） | **基準への適合の確認、是正の指導** |
| ④ 通信・指令 | 情報の集約、出動の判断 |
| ⑤ 訓練・教育 | 計画、実施、評価 |
| ⑥ 事務 | 許可、届出の審査、統計 |

**③が、民間で最も直接に使えます。**

**防火対象物の査察、消防用設備等の確認、消防計画の審査。**

**これらは、民間の防火管理や設備の点検の業務と、裏表の関係**にあります。

## 書き方の例

**悪い例**

> ◯◯消防署で、消防士として勤務しました。

**良い例**

> ◯◯において、**警防、救急、予防の各業務を担当。**予防の業務では、**管内の防火対象物◯件の査察を実施し、消防計画の内容の確認と、設備の維持管理に関する是正の指導を担当。**救急の業務では、**年間約◯件の出動に対応し、所定の様式に基づく記録を作成。****新規に配置された職員◯名に対する訓練の計画と実施**を担当。

**「件数」「基準の確認」「記録」「訓練」**が入っています。

**⚠ 具体の災害・事故が特定される記述は避けてください。****守秘の義務は、退職した後も続きます。**

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 言い換えの対応

| 消防の言葉 | 民間での読まれ方 |
|---|---|
| 査察・立入検査 | **基準に照らした確認、監査** |
| 是正の指導 | 改善の要求、是正の管理 |
| 消防計画の審査 | 計画の妥当性の確認 |
| 訓練の計画・実施 | **研修の設計・実施** |
| 現場の指揮 | 現場の統括、初動の判断 |
| 安全の管理 | 労働安全、リスクの管理 |
| 救急の記録 | 記録の作成、証跡の管理 |
| 出動の判断 | 優先順位の判断 |

**1行目と4行目が中心**です。

**「基準に照らして確認し、是正させる」**という動作は、**監査や品質の管理と同じ構造**です。

## 民間での使いどころ

| 領域 | 使える経験 |
|---|---|
| ① 防火管理・安全管理 | **査察の視点がそのまま** |
| ② 消防用設備の点検・整備 | 設備の知識 |
| ③ 施設の管理・運営 | 維持管理、避難の計画 |
| ④ 事業の継続の計画 | 災害時の体制、訓練 |
| ⑤ 警備・危機の管理 | 初動、体制の構築 |
| ⑥ 医療・介護の現場 | 救急の経験 |
| ⑦ 行政が相手の事業 | **制度と手続きの理解** |

**①と④について。**

**多数の人が利用する施設を持つ会社では、防火管理の体制が必要**です。

**査察を受ける側に回る**という形になります。

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 何を担当したか | **部門、期間、件数** |
| どう判断したか | 手順（事案の詳細ではなく） |
| 指導の経験 | 訓練の計画と実施 |
| 交替の勤務への考え | 勤務の条件 |
| 保有する資格 | **取得の年と、使った場面** |

**5行目です。**

**資格は、名称と取得の年を記載**してください。

**求人によっては、資格が応募条件**になっています。

**なお、資格の受験の要件は、所管するところの公表を確認**してください。

:::insight
消防士の方のご相談で、**面談でお伝えしているのが「予防の業務を前面に出してください」**という点です。多くの方が、**警防や救急の経験を中心に書かれます。**現場の経験は重要ですが、**民間の求人票と直接つながるのは、予防の業務のほう**です。理由は、**消防法第8条が、事業所の側に防火管理者を置く義務を課している**からです。消防計画の作成、訓練の実施、設備の点検、避難の管理。**これらは、査察で見てきた項目そのもの**です。つまり、**「何を見られるか」を知っている人**が、事業所の側で求められます。そして、**規模の大きい施設を持つ会社ほど、この体制が必要**です。商業施設、病院、ホテル、工場、物流の拠点。**書類には、「防火対象物◯件の査察を実施」と件数を書いてください。**現場の経験は、**その後に添える**構成にすると読まれます。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 準備の順序

| 順 | やること |
|---|---|
| 1 | 配置された部門と期間を書き出す |
| 2 | **予防の業務を先に整理する**（件数、対象） |
| 3 | 訓練・指導の経験を書き出す |
| 4 | 保有する資格を整理する |
| 5 | 民間の言葉に置き換える |
| 6 | 求人を読む |

**2が要**です。

**査察の件数、対象の用途、指導した内容。**

**事案を特定せずに、範囲と動作で書いてください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 在職中の進め方

| 項目 | 内容 |
|---|---|
| 記録 | 担当した件数、対象の種別 |
| 資格の確認 | 受験の要件と時期 |
| 求人を読む | 週に30分 |
| 日程の確保 | **交替の勤務との調整** |

**4行目です。**

**交替の勤務では、日程の確保が難しい場合があります。**

**オンラインでの実施が可能かを、応募の段階で確認**してください。

**扱いは**[選考スケジュールの組み方](senko-sagasu-schedule.html)**に整理しています。**

## よくある失敗

**1. 警防・救急だけを書く**

**予防の業務**を前面に出してください。

**2. 件数を書かない**

**範囲が伝わりません。**

**3. 訓練の計画・実施を書かない**

**研修の設計**として読まれます。

**4. 資格を書かない**

**応募条件になる**ことがあります。

**5. 事案の詳細を書こうとする**

**範囲と動作**で書いてください。

**6. 「民間に同じ仕事がない」と考える**

**事業所の側に義務**が課されています。

**7. 交替の勤務との調整を後回しにする**

**面接の日程に影響**します。

**8. 行政が相手の事業を見ない**

**制度と手続きの理解**が前提になります。

:::insight
ここまで予防の話をしておいて逆のことを言いますが、**救急の経験は、医療・介護の現場で強く評価されます。**面談で拝見していると、**「資格がないので医療の分野は難しい」と考える方**がいらっしゃいます。ところが、**施設の運営の側では、急変への初動を担える人が不足しています。**高齢者の施設、障害者の施設、大規模な商業施設、イベントの運営。**その場で観察し、優先順位を判断し、救急の要請につなぐ。****この判断を落ち着いてできる人**は、多くありません。そして、**記録を残す習慣**も身についています。書類には、**「年間約◯件の出動に対応し、観察と処置、搬送、記録を担当」**と書いてください。**保有する資格があれば、併せて記載**してください。**資格が必須の求人と、経験を評価する求人は別**です。応募条件の欄を読んで判断してください。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **消防法第8条第1項**は、一定の防火対象物の管理について権原を有する者に、**防火管理者を定め、消防計画の作成、訓練の実施、設備の点検及び整備、火気の監督、避難上の構造及び設備の維持管理、収容人員の管理**を行わせることを義務づけています
- **これらは、消防が査察で見てきた項目**です。**指導してきた側の知識が、民間では担う側の業務**になります
- **予防の業務を前面に出して**ください。査察の件数と対象を書いてください
- **査察・是正の指導は、監査・品質の管理と同じ構造**です
- **訓練の計画・実施は、研修の設計**として読まれます
- **救急の経験は、医療・介護の現場で評価**されます
- **事案の詳細ではなく、範囲と動作**で書いてください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 資格がないと、応募できませんか

**求人によります。**消防用設備等の点検や整備の業務では、**資格が必須**とされることがあります。一方、**防火管理、施設の管理、安全の管理**の業務では、**実務の経験が評価される**ことがあります。また、**入社後の取得を支援する制度**がある会社もあります。求人票や採用のページで、**取得の支援の有無**を確認してください。なお、**資格の受験の要件は、実務の経験の年数と内容で定められている**ことがあります。**消防での実務が要件に算入されるかは、その資格を所管するところの公表を確認**してください。**在職中に取得できるなら、そのほうが負担が小さい**です。

### 交替の勤務から、日勤の仕事に移れますか

**求人の条件によります。**施設の管理や警備の分野では、**交替や夜間の勤務が条件**となることがあります。一方、**防火管理、安全の管理、点検の計画、行政が相手の事業**では、**日勤が中心**の求人があります。**求人票の勤務時間の欄**を確認してください。なお、**交替の勤務に慣れている点は、説明の材料**になります。「不規則な勤務の中で、記録と引継ぎを正確に行ってきた」という形です。**勤務の形の希望は、応募の段階で伝えて**差し支えありません。**伏せて入社すると、調整ができません。**

### 体力を活かす仕事以外に、選択肢はありますか

**あります。**予防の業務で身につけた**基準の確認と是正の指導**は、**監査、品質の管理、安全の管理**で使えます。また、**訓練の計画と実施**は、**研修の設計・実施**にあたります。さらに、**通信・指令の経験**は、**情報を集約して優先順位を判断する業務**——運行の管理、コールセンターの統括、設備の監視——と構造が近いものです。判断の目安は、**求人票の仕事内容**です。「基準」「点検」「訓練」「計画」「記録」といった言葉があれば、**経験が接続します。**扱いは[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)に整理しています。
