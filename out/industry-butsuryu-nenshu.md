物流を検討される方から、**心配そうに伺うことがあります。**

**「長時間働く業界だと聞いています」**

**この業界には、その印象が付いて回ります。**ところが、**制度の側から見ると、事情が違います。**

**勤務時間と乗務時間については、法令上、基準を遵守する義務が事業者に課されています。**しかも、**その遵守の状況は、行政の監査の対象**です。

この記事では、**何が根拠になっているか**と、**職種によって働き方がどう違うか**を扱います。業界の構造は[未経験から物流に入るには](industry-butsuryu-mikeiken.html)にあります。

**⚠ なお、給与の水準について、当社が数字でお答えすることはできません。**会社ごとに事情が違いますし、**裏を取っていない数字を並べるのは、この記事の趣旨に反します。**

## 勤務時間と乗務時間には、遵守すべき基準があります

**貨物自動車運送事業法第15条**です。

> **（輸送の安全）第十五条　一般貨物自動車運送事業者は、次に掲げる事項に関し国土交通省令で定める基準を遵守しなければならない。**
>
> 一　事業用自動車の数、荷役その他の事業用自動車の運転に附帯する作業の状況等に応じて必要となる**員数の運転者及びその他の従業員の確保**、事業用自動車の運転者がその**休憩又は睡眠のために利用することができる施設の整備及び管理**、事業用自動車の運転者の**適切な勤務時間及び乗務時間の設定**その他事業用自動車の**運転者の過労運転を防止するために必要な事項**

**「適切な勤務時間及び乗務時間の設定」**が、**遵守すべき基準の対象**として条文に書かれています。

**⚠ ただし、この条文が直接の対象としているのは、事業用自動車の運転者**です。**管理部門や事務の職種の労働時間は、この条文ではなく、労働基準法の枠組みで管理されます。**

**ここを取り違えないでください。**

**それでも、この条文を知っておく意味があります。****運転者の勤務時間を管理する仕事が、法令に紐づいて存在する**からです。**その管理を担うのが、運行管理の職種**です。

## 安全管理規程を定める義務があります

**同法第14条**です。

> **（安全管理規程等）第十四条　一般貨物自動車運送事業者**（その事業用自動車の数が国土交通省令で定める数未満であるものを除く。以下この条において同じ。）**は、安全管理規程を定め、貨物の運送を開始する日**（中略）**までに、国土交通省令で定めるところにより、**（中略）**届け出なければならない。**

**規程を定め、届け出る**——この構造です。

**つまり、この業界には「規程にもとづいて運用し、記録を残し、監査を受ける」仕組みが、法令として組み込まれています。**

**役所の仕事の進め方と、構造が同じ**です。そして、**この構造を回せる人が、この業界では足りていません。**

## 給与の根拠は、条例から就業規則に変わります

**いま、給与の根拠になっているのは条例です。**

**地方公務員法第24条第1項**は、**「職員の給与は、その職務と責任に応ずるものでなければならない」**と定め、**同条第2項**は、**生計費・国や他の地方公共団体の職員・民間事業の従事者の給与その他の事情を考慮して定められなければならない**としています。

**民間企業では、この構造がありません。**

**労働基準法第89条**は、**常時10人以上の労働者を使用する使用者に、就業規則の作成と行政官庁への届出**を義務づけ、**記載事項として「賃金の決定、計算及び支払の方法、賃金の締切り及び支払の時期並びに昇給に関する事項」**を挙げています。

| | 役所 | 物流会社 |
|---|---|---|
| 根拠 | **条例** | **就業規則・給与規程** |
| 見られるか | **公表されている** | 在職者は見られる。応募時は要確認 |
| 職種による差 | 職種の区分が限られる | **現場と管理で体系が別のことがある** |
| 拠点による差 | 基本的に無い | **拠点ごとに手当が違うことがある** |

**3行目が、この業界の特徴**です。**運転者・作業者と、管理・事務では、給与の決まり方が別の体系**になっていることがあります。**応募する職種がどちらの体系かを確認してください。**

## 働き方は、職種で大きく分かれます

| 職種 | 勤務の時間帯 | 突発の多さ | 役所との差 |
|---|---|---|---|
| 運行管理 | **早朝・夜間の点呼がある** | **多い** | 差が大きい |
| 倉庫の運営管理 | 入出庫の時間に沿う | 中程度 | 差が大きい |
| 安全・コンプライアンス | 通常の時間帯が多い | **監査の時期に集中** | **近い** |
| 総務・人事 | 通常の時間帯 | 少ない | **近い** |
| 経理 | 通常の時間帯 | **締めの時期に集中** | **近い** |
| 物流の企画・改善 | 通常の時間帯 | 中程度 | 近い |
| 荷主側の物流部門 | **荷主企業の勤務時間に沿う** | 中程度 | **近い** |

**「物流は長時間」という印象の多くは、上の2つと、現場の作業の職種**から来ています。

**下の5つは、他の業界の管理部門と大きく変わりません。**

**⚠ 求人を見るときに、この違いを意識してください。**同じ会社の中でも、**職種によって生活の組み立て方がまったく違います。**

## 荷主側の物流部門という選択肢

[未経験から物流に入るには](industry-butsuryu-mikeiken.html)でも触れましたが、**製造業や小売業の中にある物流の部署**は、**働き方の面でも候補に入れる価値があります。**

| | 物流会社 | 荷主側の物流部門 |
|---|---|---|
| 勤務時間 | 拠点の稼働に影響される | **荷主企業の勤務時間** |
| 仕事の中身 | **自社で運ぶ・預かる** | **委託先の選定と管理、コストの管理** |
| 相手 | 荷主、乗務員、作業者 | **物流会社、社内の各部門** |
| 効く経験 | 記録・規程・労務の管理 | **契約と、履行の確認** |

**契約や委託の管理をしてきた方**は、**右の列のほうが経験と重なります。**

:::insight
面談で伺っていて、**物流を検討される方が最初に見落とすのが「拠点の場所」**です。求人票の勤務地の欄に市区町村名が書いてあっても、**物流の拠点は、その市の中心部ではありません。**高速道路の出入口の近く、港や空港の周辺、工業団地の中。**公共交通機関でたどり着きにくい場所**にあることが、珍しくありません。結果として、**自動車での通勤が前提**になります。これは、不利とは限りません。**通勤の時間が短くなる、駐車場が確保されている、住居の費用が抑えられる**という面もあります。実際、**役所からの転職で、満員電車から解放された**という話も伺います。一方で、**お子さんの送迎や、ご家族の通勤との兼ね合い**で成り立たない場合もあります。ですから、**求人に応募する前に、実際の所在地を地図で確認してください。**そして、**面接に行くときは、可能なら想定している通勤の手段で行ってみてください。**朝の時間帯に、実際にどのくらいかかるか。**この確認を一度しておくと、入ったあとに「思っていたのと違う」が起こりません。**選考に進んでからでも遅くありませんが、**内定が出てからでは遅い**です。
:::

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 場面 | 効く理由 |
|---|---|
| 規程にもとづく運用 | **要綱にもとづいて処理してきた** |
| 記録の整備と保存 | 後から検証される前提の書類の作り方 |
| 勤務時間の管理 | **超過勤務の命令と実績の管理の経験** |
| 監査・立入への対応 | **検査する側にいた** |
| 委託先の管理 | 契約と履行の確認の経験 |
| 締切のある業務を回す | 予算・決算の日程で動いてきた |

**効きにくい場所**

| 場面 | 効きにくい理由 |
|---|---|
| 突発の事態への即応 | **事故・渋滞・天候で計画が崩れる** |
| 料金の設定と交渉 | 値決めの判断を自分でする |
| 現場の作業の段取り | 時間単位で動く感覚 |
| 早朝・夜間の勤務 | **生活のリズムが変わる** |

**1つ目について、災害対応・選挙の事務・感染症の対応を経験した方**は、**「当日に計画が崩れる」状況を知っています。**その経験は、そのまま材料になります。

## 入る前に確認しておくこと

**労働基準法第15条第1項**は、**労働契約の締結に際して、賃金・労働時間その他の労働条件を明示しなければならない**と定めています。**条件を示してもらうことは、権利として認められています。**

| 確認すること | どこで確認するか |
|---|---|
| 賃金の決定・計算・支払の方法、昇給 | **給与規程・労働条件通知書** |
| 就業の場所（**拠点の所在地**） | **労働条件通知書** |
| 始業・終業の時刻、休憩、休日 | 就業規則 |
| **交替制・早朝・夜間の有無** | **面接で確認する** |
| **点呼の立会いがあるか** | **面接で確認する**（運行管理の職種） |
| 現場と管理で給与の体系が違うか | 給与規程 |
| 転居を伴う異動の範囲 | 面接で確認する |

**4つ目と5つ目は、必ず確認してください。**生活の組み立て方に直結します。

**とくに点呼の立会い**は、**運行管理の職種では中核の業務**です。**時間帯が早朝や深夜に及ぶことがあります。**

ここまで確認の話をしてきましたが、**当社の見解を申し上げます。**この業界に対して、**「働き方が厳しい」という印象だけで候補から外すのは、もったいない**と考えています。理由は2つあります。1つは、**この記事で整理したとおり、職種によって働き方がまったく違う**ことです。総務・人事・経理・安全の職種は、**他の業界の管理部門と大きく変わりません。**印象は、現場の職種から来ています。もう1つは、**この業界がいま、働き方を見直している最中**だということです。労働時間の規制、荷役作業の負担の軽減、共同配送、自動化。**現場の作業の方法そのものが変わりつつあります。**そして、この見直しを進めるには、**規程を作り直し、記録の取り方を変え、委託先との契約を見直す**必要があります。これは、**制度の改正に合わせて要綱と様式を作り直してきた公務員の方が、いちばん慣れている作業**です。ですから、**「この業界は厳しいから」ではなく、「この職種の条件はどうか」で判断してください。**そして、**確認した結果、条件が合わずに見送るという結論**も、正しい結論です。**確かめたうえでの判断**であれば、次に迷ったときの材料が増えています。当社が、いまの職を辞めることをお勧めすることはありません。

## まとめ

- **貨物自動車運送事業法第15条**は、**運転者及びその他の従業員の確保、休憩又は睡眠のための施設の整備及び管理、適切な勤務時間及び乗務時間の設定**などについて、**国土交通省令で定める基準を遵守しなければならない**と定めています
- ⚠ **この条文が直接の対象としているのは、事業用自動車の運転者**です。**管理・事務の職種は、労働基準法の枠組みで管理されます**
- **同法第14条**は、一定規模以上の事業者に**安全管理規程を定め、届け出る**ことを義務づけています。**規程・記録・監査の構造は、役所と同じ**です
- **給与の根拠が、条例から就業規則・給与規程に変わります。**⚠ **現場と管理で体系が別のことがあります**
- 働き方は**職種で大きく分かれます。****総務・人事・経理・安全・企画は、他業界の管理部門と大きく変わりません**
- ⚠ **荷主側の物流部門**は、**荷主企業の勤務時間に沿う**ため、生活の条件を優先する場合の候補になります
- ⚠ **拠点の所在地を、応募前に地図で確認してください。**自動車での通勤が前提のことがあります
- **点呼の立会いの有無**は、運行管理の職種では必ず確認してください
- **「この業界は厳しいから」ではなく、「この職種の条件はどうか」で判断**してください

## よくある質問

### 求人票に「みなし残業」と書かれています。どう読めばよいですか

**一定時間ぶんの時間外労働に対する割増賃金を、あらかじめ定額で支払う仕組み**を指していることが多いです。確認していただきたいのは、**「何時間ぶんが含まれているか」「超えた場合はどうなるか」**の2点です。定められた時間を超えた部分については、**別に支払われるのが原則**です。**面接で確認して構いません。**あわせて、**基本給と手当の内訳**も確認してください。総額だけを比べると、構成の違いが見えません。なお、**当社が会社ごとの運用をお伝えすることはできません。**求人票と規程で確認してください。判断に迷う内容があれば、**書面で示してもらう**ようにしてください。

### 繁忙期は、いつですか

**扱う荷物によって違います。**消費財を扱う拠点では、**年末や、大型の連休の前**に荷動きが増える傾向があります。一方、**建設資材や工業製品を扱う拠点**では、**年度末**に集中することがあります。**役所の年度末と重なるかどうか**は、応募先によります。確認のしかたは、面接で**「一年のうち、いちばん忙しいのはいつ頃ですか」**と聞くことです。あわせて、**その時期に管理部門がどう関わるか**も聞いてください。現場が忙しくても、**経理や総務の職種では影響が限られる**こともあります。自分の職種での影響を確認してください。

### 退職の時期は、いつにするのが良いですか

**この記事では判断できません。**退職手当の算定、共済の扱い、年次有給休暇の残りなど、**個別の事情で変わります。**所属の人事担当部署と、**共済組合の窓口で確認**してください。一般論として申し上げられるのは、**内定が出てから退職の意思を伝えるほうが、選択肢が残る**ということだけです。あわせて、**物流では繁忙期を避けた入社時期を相談される**ことがあります。現職の引き継ぎに必要な期間は、**選考の段階で伝えておいてください。**なお、**当社が、いまの職を辞めることをお勧めすることはありません。**確認した結果、残るという結論も正しい結論です。
