千葉県庁の給与データを他県と並べると、一見おかしなことが起きています。**平均給料月額が、東北の県よりも低い。**

首都圏にあり、地域手当も支給されている県で、なぜそうなるのか。答えは給与水準ではなく、**職員の年齢構成**にあります。この数字の読み方を間違えると、自分の市場価値の見積もりまでずれます。

この記事では、まず公表されている数字を正しく読み解き、そのうえで県庁の経験が民間のどの言葉に置き換わるのかを整理します。

## 千葉県庁の給与水準を、数字で確認する

総務省の調査によると、千葉県の一般行政職は次のとおりです（令和6年4月1日現在）。

| 項目 | 千葉県 |
|---|---|
| ラスパイレス指数 | 99.6 |
| 平均年齢 | 40.1歳 |
| 平均給料月額 | 306,300円 |
| 諸手当月額 | 105,214円 |
| 平均給与月額 | 411,514円 |
| 平均給与月額（国ベース） | 359,477円 |
| 地域手当（国の指定基準） | 9.2% |
| 地域手当（実際の支給割合） | 約10.89% |

### 平均給料月額306,300円を、低いと読まない

近隣・他県と並べると、違和感の正体が見えます。

| 都県 | 平均年齢 | 平均給料月額 | ラスパイレス指数 |
|---|---|---|---|
| **千葉県** | **40.1歳** | **306,300円** | **99.6** |
| 埼玉県 | 41.8歳 | 319,400円 | 100.3 |
| 山形県 | 43.7歳 | 331,100円 | 100.2 |
| 秋田県 | 43.0歳 | 324,600円 | 100.1 |

**千葉県の平均年齢40.1歳は、際立って若い水準です。**そして給料は年齢が上がれば上がるので、**平均年齢が低い団体は、平均給料月額も低く出ます。**

ここで効いてくるのがラスパイレス指数です。この指数は**学歴や経験年数の差を補正して**計算されるため、年齢構成の影響を取り除いた比較ができます。千葉県は99.6。国の水準とほぼ同じです。

つまり、**「平均給料月額が低い」のは水準が低いからではなく、若い職員が多いから**だということです。

:::insight
この読み違いは、転職の判断に直接影響します。**平均給料月額を見て「自分の県は水準が低い」と考え、民間の提示額を過小に見積もってしまう。**あるいは逆に、年齢の高い県と比べて焦る。どちらも、比べているものが違います。**自分の市場価値を測るのに、団体の平均は使えません。**使うのは、自分の源泉徴収票の支払金額です。そのうえで求人票の想定年収と突き合わせてください。団体間の比較に使えるのはラスパイレス指数のほうで、これは自分の給与とは別の話です。**2つの数字を混ぜて読まないでください。**
:::

### 地域手当も、国の指定基準を上回っている

**国が指定する基準は9.2%なのに、実際の支給割合は約10.89%。**首都圏では、東京都だけが基準を下回り（約19.63%に対し約18.72%）、埼玉県・神奈川県・千葉県は上回っています。

ただし**地域手当は民間企業にはない概念です。**求人票が提示するのは基本給と諸手当を含んだ年収であって、手当の内訳では書かれていません。手当の名目ごとに比べようとすると、必ず噛み合いません。

## 県庁の経験は、民間で何と呼ばれるか

| 県庁での仕事 | 求人票での言い方 |
|---|---|
| 予算の要求・査定、財政計画 | 予実管理、投資判断、経営企画 |
| 港湾・空港に関わる計画と調整 | インフラ企画、物流ネットワーク設計 |
| 企業誘致・立地支援 | 事業開発、用地開発、アライアンス |
| 都市計画・住宅政策 | 都市開発、不動産企画 |
| 観光の誘客・受入環境整備 | 観光事業企画、地域ブランディング |
| 農林水産の産地形成・輸出支援 | 事業開発、産地開発、海外展開 |
| 県土整備の設計・積算・監督 | 発注者支援、施工管理 |
| 市町村への助言・支援 | パートナー支援、カスタマーサクセス |
| 内部管理（人事・財政・総務・会計） | コーポレート、管理部門 |
| 議会対応、条例・規則の改正 | 渉外、法務、規程整備 |

部署ごとの詳しい対応は[自治体の部署別 仕事ガイド](../zukan.html)にまとめています。財政課であれば[財政課の経験は民間で何と呼ばれるか](dept-zaisei-honyaku.html)で、さらに細かく分解しています。

## 千葉で、どの経験が値になるか

**1. 国際物流と空港・港湾**

成田空港と東京湾岸の港湾を抱える県として、県庁には物流と立地に関わる実務があります。**用地、環境影響、地元調整、他の管理者との協議、周辺整備。**

物流施設の開発は全国で進んでいますが、**立地に伴う行政手続きと地元調整を実際に通した人は、事業者側にほとんどいません。**この経験は、物流不動産、商社、フォワーダーから見て希少です。

**2. 素材・エネルギーの産業集積**

京葉臨海部の産業集積。大型施設の立地、安全に関する協議、環境の手続き。**規制の厳しい業界で、行政側の考え方を知っている人**は、事業者にとって採用しにくい人材です。脱炭素の投資が進むいま、この領域の需要は増えています。

**3. 都市の課題と地方の課題が同居している**

人口が集中する地域と、減少が進む地域が同じ県内にあります。**都市計画と施設の再編、その両方の文脈を理解している**ことになります。デベロッパー、まちづくり、インフラ運営の企業から見れば、これは貴重です。

**4. 農林水産と観光**

農業産出額が全国上位の県であり、観光地も抱えています。産地形成、輸出支援、受入環境の整備。**行政の立場で座組みを作った経験**は、食品・観光関連の事業者や地域商社から見て希少です。

**5. 市町村を相手にしてきた経験**

規模も体制もばらばらな市町村を相手に、温度差をどう埋めたか。「連絡調整」ではなく、**複数顧客を持つアカウント業務の経験**として書けば、そのまま職務能力になります。

## 都内の求人を、勤務地で切らない

千葉県は都内への通勤圏にあり、**転居せずに都内の求人に応募できます。**判断の誤りは、通勤時間だけで線引きしてしまうことです。

近年はリモート可、週数日出社といった勤務形態の求人が増えています。とくに自治体を顧客にする企業は、担当エリアに出向くことが仕事なので、本社への出社頻度が低い場合があります。

**まず職種で絞り、そのあとに勤務形態を確認する。**勤務地から検索すると、県内では出会えない職種が最初から視界に入りません。

## 職務経歴書に、県庁の仕事をどう落とすか

**制度名ではなく、判断したことを書く**

「○○推進事業を担当」では読み手に何も残りません。事業名は庁内でしか意味を持たない固有名詞です。**何件を、どういう基準で審査し、どこで判断が割れて、どう決着させたか。**

**若さを弱みにしない**

平均年齢40.1歳の組織にいると、庁内では「まだ若手」と扱われます。しかし**民間の中途採用では、30代は最も選択肢が広い年代です。**庁内の相対評価を、外の基準だと思わないでください。判断の目安は年数ではなく、**いま担当している領域を一巡させたかどうか**です。制度の設計から実行、翌年度の見直しまでを見ていれば、書ける材料は揃っています。

**異動歴を「立ち上げの回数」に変える**

数年ごとの異動を「専門性がない」と書くのは、自分から評価を下げる書き方です。異なる制度領域を短期間で立ち上げてきた経験は、民間では**キャッチアップの速さ**として読まれます。編年式で並べ、それぞれの配属で最初の数か月に何を習得したかを1行添えてください。

## 技術職の場合は、探し方が変わる

**発注者側の経験そのものが職種になる**

「発注者支援」という職種が、建設コンサルタント業界には確立しています。設計の審査、積算の確認、工事の監督、住民説明。県庁でやってきたことが、そのまま職務内容として書かれた求人です。

**資格が入口で効く**

技術士、施工管理技士、測量士、電気主任技術者。事務職では資格より実績が先ですが、技術職では資格が応募の入口になる場面があります。**実務経験の年数が受験要件になっているものは、在職中でなければ積めません。**

**港湾・臨海部の実務は特殊な資産になる**

港湾施設、護岸、埋立地の管理。この領域を扱える技術者は限られており、民間側でも慢性的に不足しています。

## 面接で必ず詰められる2つのこと

**「意思決定のスピードに耐えられるか」**

行政は手続きの段数が多く、決裁を経て動きます。民間は月次で数字を締め、その場で方針を変えます。稟議の段数を弁解せず、**自分の判断で動かした範囲を具体的に答えてください。**

**「数字への意識があるか」**

「利益を意識したことはありますか」という形で聞かれます。「行政なので利益はありません」と答えると、そこで話が終わります。事業の優先順位を付けた、単価の根拠を詰めた、複数案を比べた。**同じ思考をしていたことを、民間の言葉で説明できるか**が見られています。

## 在職中に進めるときの注意点

**服務上の扱いを先に確かめる**

在職中に得た情報を持ち出すことは避けなければなりませんし、退職後の営業活動についても扱いを確認しておいたほうが安全です。**判断に迷う場合は、応募の前に人事担当課に制度上の取扱いを確認してください。**

**面接の日程は、議会日程から逆算する**

地方自治法第211条は、長が毎会計年度予算を調製し、年度開始前に議会の議決を経なければならないと定めています。都道府県は年度開始前30日までに予算を議会へ提出するようにしなければならない、とも書かれています。決算は、出納閉鎖後3か月以内の長への提出、監査委員の審査、議会の認定という順です（第233条）。**予算編成の山と定例会の会期中は、平日日中の面接を入れるのが難しくなります。**

**在職中に決める**

公務員には雇用保険が適用されないため、辞めてから探すと収入のない期間がそのまま持ち出しになります（[公務員に雇用保険がない理由](seido-shitsugyo-nashi.html)）。

:::insight
ここまで転職の話を書いてきましたが、**残る判断にも理があります。**平均年齢40.1歳という若い組織にいるなら、**焦って動く必要はありません。**いま担当している領域で通しの経験が積み切れていないなら、それを終えてから動くほうが、書けることは確実に厚くなります。首都圏に位置するぶん「動くなら転居を伴う」という制約もないので、機が熟すまで待っても選択肢はそれほど減りません。ただし、自分の経験が外でどう呼ばれるかを知っておくことには、動かない場合でも意味があります。次の異動希望を出すときの材料が変わるからです。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

- **平均給料月額306,300円が東北の県より低いのは、平均年齢40.1歳という若い年齢構成のためです。**水準が低いわけではありません
- **ラスパイレス指数（年齢構成を補正済み）と平均給料月額（補正なし）を混ぜて読まないでください**

## よくある質問

### 平均給料月額が他県より低いのは、損をしているということですか

**そうではありません。**平均給料月額は年齢構成の影響を受けるため、若い職員が多い団体ほど低く出ます。千葉県の平均年齢40.1歳は際立って若い水準です。年齢構成を補正したラスパイレス指数では99.6と、国とほぼ同水準です。**自分の給与が同年代の他県職員と比べてどうかを知りたいなら、団体の平均ではなく、自分の給料表の号給を見てください。**

### 30代前半ですが、動くのは早すぎますか

**年数より、通しで回した経験があるかどうかです。**千葉県では30代前半は庁内で若手にあたりますが、民間の中途採用では最も選択肢が広い年代です。判断の目安は、**いま担当している領域を一巡させたかどうか。**制度の設計から実行、そして翌年度の見直しまでを見ていれば、書ける材料は揃っています。庁内の相対評価を、外の基準だと思わないでください。

### 都内の企業に転職すると、通勤が現実的ではないのですが

**毎日通う前提で考えないでください。**リモート可、週数日出社の求人が増えています。とくに自治体を顧客にする企業は、担当エリアに出向くことが仕事なので、本社への出社頻度が低い場合があります。**募集要項の勤務形態の記載まで確認してから判断してください。**
