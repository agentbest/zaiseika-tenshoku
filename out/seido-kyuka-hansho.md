半日だけ休みたいときは、「半日だから残数から0.5日を引く」と決めず、本人に適用される休暇の単位と勤務の割振りを確認します。国の年次休暇、地方の条例による休暇、民間企業の時間単位年休は、同じ仕組みではありません。

本記事は2026年11月時点の公開情報にもとづきます。国では2026年4月に年次休暇の15分単位の対象が見直されています。古い説明の「時間単位は1時間だけ」をそのまま使わず、現行規定と所属の申請方法を確認してください。

## 「半日」の呼び方より使う制度を確認する

午前又は午後に勤務しない予定でも、半日単位の独立した制度を使うのか、年次休暇を時間単位で請求するのかは所属の制度によります。休暇システムの画面の名称だけでは、根拠や残数の減り方までわかりません。

| 確認すること | 質問の例 |
| --- | --- |
| 休暇の種類 | 年次休暇か、子の看護等の特別休暇か |
| 取得の単位 | 日、半日、時間、15分等のどれが使えるか |
| 対象の勤務 | その日の始業・終業・休憩は何時か |
| 換算 | 時間で使った分を何時間で1日に換算するか |
| 残数と申請 | 端数、繰越分、承認、変更をどう処理するか |

例えば、午後の予定のために休みたいという仮のケースでも、通常の勤務日と、フレックスタイム等により勤務時間が変わった日では確認する時間帯が異なります。勤務予定を見ずに「午後は必ず4時間」と固定しないでください。

勤務しない事由によって別の休暇が使える場合もありますが、対象者、事由、必要な証明、取得単位がそれぞれ定められています。本人が使いたい時間だけを基に休暇名を決めるのではなく、制度の要件を先に確認します。

## 国の年次休暇は日を原則に時間・15分も確認する

人事院規則15-14第20条は、年次休暇の単位を1日とし、特に必要があると認められるときは1時間又は15分を単位とすることができると定めています。同条に一般の「半日」という単位が並んでいるわけではありません。

人事院の2026年4月改正の概要では、全ての常勤職員と非常勤職員について、特に必要と認められる場合に15分単位でも年次休暇を取得できるようになったと説明しています。以前の交替制等勤務職員に限った取扱いと、2026年11月の現行制度を区別します。

ただし、細かい単位があることは、承認手続がなくなることを意味しません。勤務時間法第17条第3項には取得時期の承認が規定され、公務の運営に支障がある場合を除き承認しなければならないとされています。申請経路や締切、予定が変わったときの修正は所属で確認してください。

時間帯を申請する際は、休憩時間を勤務しない時間と混ぜないようにします。例えば通院に必要な外出の時刻と、勤務に戻る時刻を整理し、その間の勤務時間についてどの範囲を請求するかを確かめます。診療の予定が変わった場合の扱いも担当へ尋ねます。

## 時間を日に換算する基準と実際の勤務を分ける

国の規則15-14第20条第2項では、通常の区分について、時間又は15分単位で使用した年次休暇を日に換算する際は7時間45分を1日とする規定があります。短時間勤務等では別の区分に応じた時間数が定められています。

仮にこの7時間45分換算が適用され、3時間と4時間45分の年次休暇を別々に使用した場合、合計7時間45分を1日と換算する計算になります。これは各申請が所属の規定に沿っていることを前提にした算術例であり、午前・午後がそれぞれ0.5日になるという意味ではありません。

また、1日単位で使用できる場合も勤務の割振りに関する運用があります。フレックスタイムや交替制で、その日の勤務が長い・短い場合は、1日として請求できるのか、時間で請求するのかを確認します。単位の名前と、実際に勤務しない時間数、残数への計上を分けて把握してください。

| 仮の整理 | 注意する点 |
| --- | --- |
| 通常勤務日に数時間休む | 開始・終了、休憩、使用する単位を確認 |
| 午前又は午後を休む | 半日制度か時間請求か、実際の勤務時間を確認 |
| 日ごとに勤務が異なる | 当日の割振りと日換算の基準を分ける |
| 短時間勤務へ変更する | 変更前後の残数と換算の扱いを確認 |

残数に分単位の端数がある場合も、本人が都合よく切り上げて使えると判断しないでください。取得単位と残数の換算を担当に確認し、システムの表示が理解できないときは計算の内訳を尋ねます。

:::insight
時間休を確認するときは、制度名より「何時から何時まで勤務しないのか」を先に書くと、誤解を減らせると考えます。午前休、午後休という呼び方は便利ですが、勤務の割振りや休憩が違えば、同じ言葉でも必要な時間数は変わります。さらに、申請する単位と残数を日に換算する基準も別です。私たちは、本人の予定、当日の勤務、適用する休暇の三つを並べて担当へ確認する方法を勧めます。細かく取得できることだけを制度の良さとせず、まとまった休養も含めて本人の目的に合う取り方を考えたいところです。手続がわかれば、現職で通院や家族の用事と仕事を調整するための具体的な判断材料になります。
:::

## 短時間勤務・非常勤は本人の区分で確かめる

国の規則15-14第20条には、育児短時間勤務職員等、斉一型・不斉一型の短時間勤務職員に関する換算区分があります。すべての職員について7時間45分を機械的に当てはめないでください。

非常勤職員については、規則15-15とその運用等に基づく制度を確認します。2026年4月の見直しには取得単位だけでなく、一定の任期で採用された非常勤職員の年次休暇付与を前倒しする内容もあります。「15分で取得できること」と「いつ、何日が付与されるか」は別の確認です。

本人の任用通知、週の勤務日数と時間、現在の付与日・残数を基に担当へ尋ねます。短時間勤務を開始・終了した年は、変更前に使った休暇と変更後の残数に調整があるかも確認してください。表示された日数だけを他の勤務形態の人と比較しないことが大切です。

地方公務員法第24条第5項は勤務条件を条例で定めるとしています。地方の職員は自治体の条例・規則を読み、国の15分単位への改正が自分にも同じ時期に適用されたと決めつけないようにします。

申請後は、承認された時間帯と実際の出退勤の記録、残数の減り方を照合します。予定より早く戻った、用事が延びた、勤務の割振りが変更されたという場合の修正方法も確認してください。勤怠の記録を本人の都合で書き換えたり、休憩時間を追加して請求したりせず、所属の正式な手続で整理します。

## 特別休暇は年休と同じ単位とは限らない

国の規則15-14第22条には、特別休暇ごとの期間や単位等が定められています。不妊治療に係る休暇、配偶者出産、育児参加、子の看護等、短期介護の対象となる特定休暇については、1日又は1時間という単位の規定と、残日数の全てを使う際の1時間未満の端数の扱いがあります。

年次休暇に15分単位が追加されたことから、これらの特別休暇もすべて15分単位になった、と推測しないでください。結婚休暇や夏季休暇なども、連続性や取得期間、休日の扱いを個別に確認します。

病気休暇や介護時間、育児関係の勤務時間の措置も別制度です。短時間勤務の時間、特別休暇、年次休暇を組み合わせる場合は、同じ時間帯を重ねて申請せず、どの制度で勤務しないのかを明確にします。

## 民間の時間単位年休は労使協定と年5日以内を確認する

転職先の民間企業では、労働基準法第39条第4項に基づく時間単位年休の制度を確認します。同項は労使協定で対象労働者や日数等を定め、日数は年5日以内としています。国の公務員の年次休暇に、そのまま同じ上限を当てはめる説明はできません。

厚生労働省のQ&Aは、時間単位年休の1日の時間数に1時間未満の端数がある場合の切上げを説明しています。所定労働時間7時間45分なら8時間とする例があり、国の規則の7時間45分換算とは異なります。

民間の半日単位の扱いも、会社の制度を確認します。半日で休めることと、時間単位年休の労使協定があることは別です。転職先を比較する場合は、取得単位だけでなく、入社時の付与、時間年休の上限、申請経路も尋ねると条件を具体化できます。

:::insight
休暇制度を仕事選びの条件にする場合は、「時間休あり」という一項目だけで比べないことが大切です。いつ付与され、どの単位で使え、どの勤務時間を対象に請求するかがわかって初めて、通院や育児等の予定と照らせます。私たちは、今の所属で利用できる制度を確認し、その条件で働き続ける判断も同じように尊重します。転職先では公務員と異なる法律や会社規程による取扱いがあり、単位が細かいほど必ず本人に合うとも限りません。希望する休み方と必要な勤務条件を整理し、具体的な予定で使い方を確認してください。応募を急ぐためではなく、現職を含む選択肢を落ち着いて比較するための材料になります。
:::

働き方の条件を調べたい場合は、[公務員経験を活かせる仕事](../?gov=1)を情報収集に利用できます。現職の休暇制度の確認と並行して、希望条件を整理できます。

## よくある質問

### 公務員の半日休暇は必ず0.5日ですか

所属の制度によります。国の年次休暇の単位は日を原則とし、特に必要な場合に時間又は15分単位を使えます。勤務の割振りと取得単位、日換算の基準を確認してください。

### 国の年次休暇は2026年も1時間未満では使えませんか

2026年4月から、全ての常勤・非常勤職員について、特に必要と認められる場合に15分単位の取得も可能となっています。地方は本人の条例・規則等を確認します。

### 年休が15分単位なら子の看護等休暇も同じですか

別に確認します。国の特定の特別休暇には日又は時間という単位と端数の扱いがあります。休暇の種類、本人の勤務形態、使用したい残数を担当へ伝えてください。
