**「利用したことがないので、何を頼めるのか分からない」**というご相談を伺います。

**役所では、紹介の仕組みを使う機会がありません。**

この記事では、**費用の仕組み**と、**何を任せられるか**を扱います。

## 求職者が手数料を負担する仕組みではありません

**職業安定法第32条の3第2項**です。

> 有料職業紹介事業者は、前項の規定にかかわらず、**求職者からは手数料を徴収してはならない。**ただし、手数料を求職者から徴収することが**当該求職者の利益のために必要であると認められるとき**として厚生労働省令で定めるときは、同項各号に掲げる場合に限り、手数料を徴収することができる。

**原則として、求職者から手数料を取ってはならない**と定められています。

**同条第1項**は、**事業者が手数料を受けられる場合**を定めており、**厚生労働省令で定める種類と額**、または**届け出た手数料表**に基づく場合に限られます。

**したがって、費用は採用する企業の側が負担する仕組み**になっています。

**「相談するとお金がかかるのではないか」という心配は、この点を確認すれば解消します。**

**当社の場合も、ご利用は無料です（紹介手数料は採用企業の負担です）。**

## 任せられること

| 項目 | 内容 |
|---|---|
| ① 求人の紹介 | 条件に合うものを選ぶ |
| ② 条件の確認 | 求人票に書かれていない点の照会 |
| ③ 書類の確認 | 職務経歴書の書き方 |
| ④ 日程の調整 | 面接の時間帯、連絡の方法 |
| ⑤ 推薦 | 企業へ推薦する形で選考が進みます |
| ⑥ 条件の確認と調整 | 内定の段階での確認 |
| ⑦ 辞退の連絡 | 辞退する場合の連絡 |

**②と④が、在職中には効きます。**

**②について。**

**配属先の所在地、募集の背景、残業の実態。**

**これらは、応募の前に照会できます。**

**自分で聞きにくいことを、確認してもらう**という使い方です。

**④について。**

**在職中は、面接の時間帯が限られます。**

**平日の夜、土日、オンライン。**

**調整が可能かどうかを、先に確認してもらえます。**

## 伝えるべきこと

| 項目 | 内容 |
|---|---|
| ① 在職中であること | 日程と連絡の配慮に関わります |
| ② 勤務の条件 | 勤務地、時間、休日、転勤の可否 |
| ③ 時期 | いつ頃を考えているか |
| ④ 譲れない条件 | 何が満たされないと難しいか |
| ⑤ 家庭の事情 | 勤務に関わる範囲で |
| ⑥ 経験の中身 | 何を担当してきたか |

**④を言葉にしてください。**

**「なんとなく合わない」では、次の紹介の精度が上がりません。**

**勤務地なのか、業務の内容なのか、働き方なのか。**

**1つでも明確にしておくと、紹介の範囲が決まります。**

**⑥について。**

**役所の仕事は、職名だけでは中身が伝わりません。**

**「用地課」「財政課」ではなく、「何を相手に、何を確認し、何を決めていたか」**で伝えてください。

**言い換えは**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 面談で聞かれること

| 項目 | 趣旨 |
|---|---|
| 経験の内容 | 何ができるかの把握 |
| 希望の条件 | 紹介の範囲を決める |
| 時期 | 進め方を決める |
| 検討の状況 | 他に進めているものがあるか |
| 転職の理由 | 条件の優先順位を知るため |

**5つ目は、選考ではありません。**

**何を変えたいかが分かると、合う求人を選べる**ためです。

**まとまっていなくても差し支えありません。**

**話しながら整理する**ことができます。

[経験の言い換えから相談する](../apply.html)こともできます。

:::insight
紹介の使い方で、**面談でお伝えしているのが「決めていなくても構いません」**という点です。**「転職すると決めてから相談するもの」と考えている方**が多くいらっしゃいます。ところが、**決めてから相談すると、比べる材料がない状態で判断することになります。**条件を知らないまま「辞める」と決めて、**その後に求人を見て、条件が合わずに困る**という順序です。逆のほうが進みます。**先に条件を知り、合う求人があるかを確認してから、判断する。**この順序であれば、**いまの職場に残るという結論も、同じ材料から出てきます。**面談で伺った例では、**条件を並べた結果、現職を続ける判断をされた方**もいらっしゃいます。**それは相談が無駄だったという意味ではありません。****判断の材料が揃ったということです。**ですから、**情報を集める段階で使って差し支えありません。**在職中でも、情報収集だけでも構いません。
:::

## 在職中の進め方

| 項目 | 内容 |
|---|---|
| 連絡の時間帯 | 対応できる時間を伝える |
| 連絡の方法 | 電話かメールか |
| 面談 | オンラインで短時間から |
| 書類 | 下書きの段階で相談できます |
| 応募の時期 | 条件が合うものが出てからで構いません |

**1つ目と2つ目を最初に伝えてください。**

**勤務時間中に電話が来ると、対応が難しくなります。**

**3つ目について。**

**対面での面談を前提とする必要はありません。**

**オンラインで短時間から進められます。**

## 任せられないこと

| 項目 | 理由 |
|---|---|
| 応募するかの判断 | **本人の判断**です |
| 面接で話す内容 | 本人が話します |
| 退職の手続き | 所属との間で進めます |
| 家族との調整 | 本人の領域です |
| 条件の確約 | **採用の可否は企業が決めます** |

**5つ目を確認してください。**

**紹介は、あっせんです。**

**採用の可否や条件を確約するものではありません。**

**「必ず決まる」という説明があれば、内容を確認**してください。

## 応募先の管理

| 項目 | やること |
|---|---|
| 応募した先の記録 | 会社名、日付、経路 |
| 重複の回避 | **同じ会社に複数の経路から応募しない** |
| 選考の状況 | どこまで進んでいるか |
| 期限 | 返事の期限 |

**2つ目に注意してください。**

**同じ会社に複数の経路から応募が届くと、選考が進めにくくなる**ことがあります。

**応募の前に、経路を決めておいてください。**

## 進み方の目安

| 段階 | 内容 |
|---|---|
| 1 | 登録・面談（条件と経験の共有） |
| 2 | 求人の紹介 |
| 3 | 書類の準備 |
| 4 | 応募・推薦 |
| 5 | 面接（複数回のことがあります） |
| 6 | 内定・条件の確認 |
| 7 | 退職の手続き・入社 |

**在職中の場合、1から6までに数か月かかることがあります。**

**期間は、条件の絞り方と、求人が出る時期によって変わります。**

**7について。**

**退職の手続きには時間がかかります。**

**内定が出てから入社までの期間を、あらかじめ相手に伝えておいてください。**

**所属の規程による手続きの期間は、先に確認**しておくと調整がしやすくなります。

## よくある失敗

**1. 転職を決めてから相談する**

**比べる材料がない状態になります。**

**2. 条件を伝えない**

**紹介の範囲が決まりません。**

**3. 在職中であることを伝えない**

**日程の調整ができません。**

**4. 譲れない条件を言葉にしない**

**次の紹介の精度が上がりません。**

**5. 経歴を職名だけで伝える**

**中身が伝わりません。**

**6. 同じ会社に複数の経路から応募する**

**選考が進めにくくなります。**

**7. 断る理由を伝えない**

**理解が更新されません。**

:::insight
ここまで使い方の話をしておいて逆のことを言いますが、**紹介に任せきりにしないでください。**面談で拝見していると、**登録した後、紹介を待つだけになってしまう方**がいらっしゃいます。ところが、**自分で求人を読む作業には、別の意味があります。**掲載されている求人を読むと、**その領域で何が求められているかが分かります。**応募条件の欄に繰り返し出てくる言葉。仕事内容の欄に書かれている業務の範囲。**これらは、職務経歴書と面接の材料になります。**そして、**自分で読んでいると、紹介された求人の位置づけが分かります。**相場を知らないまま1件だけ示されると、**比べる基準がありません。****読む作業と、任せる作業を分けてください。**読むのは自分、確認と調整は任せる。**この分け方が、在職中には現実的**です。行政が相手の求人は、まとまって見られる場所があります。
:::

## まとめ

- **職業安定法第32条の3第2項**は、**有料職業紹介事業者は求職者から手数料を徴収してはならない**と定めています。**費用は採用する企業が負担する仕組み**です
- 任せられるのは、**求人の紹介、条件の確認、書類の確認、日程の調整、推薦、辞退の連絡**です
- 伝えるのは、**在職中であること、勤務の条件、時期、譲れない条件、経験の中身**です
- **転職を決めてから相談する必要はありません。**情報を集める段階で使えます
- **採用の可否や条件を確約するものではありません**
- **同じ会社に複数の経路から応募しない**でください
- **自分で求人を読む作業は続けて**ください。相場が分かります

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 経歴に自信がありません。相談してよいものですか

**構いません。**役所での経験は、**民間の言葉に置き換えられていないだけ**であることが多く、**話しながら整理する**ことができます。たとえば、用地の折衝は**権利関係の調査と、利害の対立する相手との合意形成**です。審査の事務は**基準に照らした判断と、その記録**です。**動作で言い換えると、受け皿が見つかります。**なお、**職務経歴書ができていなくても相談できます。**下書きの段階、あるいは何も書いていない段階でも差し支えありません。**何を書けばよいかを決めるところから**始められます。部署ごとの言い換えは[自治体の部署別 仕事ガイド](../zukan.html)に整理しています。

### 紹介された求人に、応募しないままでもよいですか

**差し支えありません。**紹介は、**条件に合う可能性がある求人を示すもの**です。**応募するかは本人の判断**です。内容を確認して、合わなければ断って構いません。**断る理由を伝えていただけると、次の紹介の精度が上がります。**なお、**応募を急かされる状況は避けてください。**判断に必要な情報が揃っていない段階で応募すると、**選考の途中で辞退することになります。**辞退そのものはできますが、**確認してから応募するほうが、負担が小さい**です。**期限を確認して、その中で判断**してください。

### 行政が相手の求人を扱っているところは、どう見分けますか

**掲載されている求人の中身を見てください。**「自治体」「官公庁」「公共」「指定管理」「業務委託」「発注者支援」。**これらの言葉が出てくる求人がどの程度あるか**で、扱いの範囲が分かります。また、**面談の場で、行政が相手の事業を扱っているかを直接聞いて差し支えありません。**「公務員からの転職を扱った実績はありますか」という聞き方でも構いません。なお、**扱いの幅は、紹介するところによって異なります。**1か所で完結させる必要はありません。**公開されている求人で相場をつかみながら、条件を登録しておく**という進め方が現実的です。探し方は[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)に整理しています。
