早期退職募集制度は、職員が募集要項に沿って応募し、認定等を経て定年前に退職する仕組みです。単に早い時期に辞職することや、上司から退職について話をされたこととは区別します。

確認する順序は、本人に適用される募集要項、対象条件、応募方法、認定、退職すべき期日です。相談しただけで応募になる、応募すれば全員が認定される、という制度ではありません。本記事は2026年11月時点の公開情報にもとづきます。

## 国の応募認定退職と旧勧奨退職を分ける

内閣官房の説明では、国の早期退職募集制度に基づく応募認定退職は、平成25年11月1日から可能になりました。従来の国の勧奨退職は同年10月31日で廃止されています。

現在の国の根拠は、国家公務員退職手当法第8条の2などです。同条は、年齢別構成の適正化を目的とする募集と、組織の改廃や官署等の移転を円滑に行うための募集を区別しています。対象職員も、募集の類型と具体的な要項によって確認する必要があります。

「公務員ならいつでも早期退職制度に申し込める」という意味ではありません。どの機関が、どの職員を、いつ募集しているかを確認します。地方では、その団体や退職手当組合の条例、年度の要項等が根拠です。国の法律の条件をすべての自治体へそのまま当てはめないでください。

退職を勧める行為、本人の辞職、分限免職等との違いは[退職勧奨の説明](seido-ninyo-taishoku-kansho.html)で整理しています。この記事では、募集要項が示された後に何を確認するかを中心に説明します。

## 募集要項を確認表にする

国の法第8条の2第2項は、募集の類型、退職すべき期日又は期間、人数、募集期間などを要項で周知する仕組みを定めています。本人は「早期退職の案内があった」という情報だけで進めず、要項と添付資料を確認します。

| 確認する項目 | 読み取る内容 |
| --- | --- |
| 募集主体と年度 | 自分の任命・退職手当を扱う機関の案内か |
| 対象職員 | 任用、職種、職位、年齢、勤続等の条件 |
| 応募できない区分 | 任期、定年到達、懲戒処分等の除外条件 |
| 退職すべき期日・期間 | 認定後に守る日付と、具体日を別途定める場合 |
| 募集期間 | 受付開始・終了の日時、提出方法 |
| 募集人数等 | 応募受付と認定の上限、超過時の方法 |
| 通知 | 認定・不認定の通知方法、時期 |
| 取下げ・変更 | 様式、受付先、期限、認定への影響 |

対象条件の基準日にも注意します。申請日現在の年齢なのか、退職すべき期日現在なのかでは確認する数字が変わります。単に「何歳以上」という一部分を抜き出さず、本人の生年月日と基準日を照合してください。

年齢や勤続が条件を満たすことと、定年前早期退職特例の割増まで適用されることも同じではありません。募集対象の範囲と、退職手当の算定条件を別に確認します。

## 応募と取下げは本人の自発的な意思による

国の法第8条の2第4項は、応募と応募の取下げを職員の自発的な意思に委ね、強制してはならないとしています。説明を受けたこと、試算を依頼したこと、関心があると伝えたことと、所定の応募は区別します。

現行の書面様式を定める内閣官房令第1条は、応募申請書と応募取下げ申請書を定めています。同令第2条は認定・不認定の通知、第3条は必要な場合の退職すべき期日の通知を扱います。本人に適用される最新の様式と提出経路を担当へ確認してください。

提出前に分からない点があれば、制度の照会として質問を整理します。本人がまだ退職を決めていないなら、その段階も明確にして相談できます。一方、正式な申請書を出す場合は、単なる相談のメモと同じだと考えず、書類の目的と提出後の手続きを確認します。

提出後は受付の確認方法を要項で確認します。メールを送信した記録や申請画面の操作だけで、受付・認定まで済んだと判断しないでください。受付の連絡がない場合に問い合わせる時期が指定されていれば、その案内に従います。

## 応募できない場合と不認定を別に読む

国の法第8条の2第3項には、臨時的任用や法律により任期を定める職員、所定の期日等までに定年に達する者、一定の懲戒処分を受けている者など、応募できない区分があります。例外や対象時点も含め、本人の任用を示して確認します。

さらに、同条第5項には認定しない場合があります。要項等への不適合、応募後の一定の処分、公務に対する信頼への支障、継続して勤務させることが特に必要な場合などです。募集人数を超える場合には、あらかじめ周知された方法による制限もあり得ます。

そのため「条件を満たして応募したから、退職日は確定」とは言えません。不認定の理由と本人の処分歴への推測も分けます。認定されなかったという結果だけで、非違行為がある、本人の評価が低いと決め付けないでください。

国の同条第6項は、認定又は不認定を書面で通知し、不認定の場合には理由も示す仕組みです。正式な通知を確認し、不明点は担当へ照会します。個別の決定の適法性は、一般記事では判断できません。

:::insight
早期退職募集の資料では、対象者であること、応募が受け付けられること、認定されること、退職手当の特例が適用されることを分けて読むことを勧めます。これらを一つの「利用できる」という言葉にまとめると、どの条件が確認済みなのか分かりにくくなります。要項の項目ごとに本人の条件と未確認事項を並べると、担当へ何を尋ねるかが具体的になります。特に、募集人数と受付人数、期日と期間、相談と申請の違いは、説明を聞いただけでは見落としやすい点です。口頭の見通しより正式な資料と通知を基準に整理すれば、退職を検討する場合も、応募せず現職を続ける場合も、本人の判断に必要な材料を確かめられます。
:::

## 令和8年度相良村の例で要項の読み方を確認

相良村の令和8年度募集要項は、常時勤務する職員の対象条件、退職すべき期日、募集人数、受付期間、応募・取下げ、認定通知等を公表しています。要項には別添もあり、募集人数と応募受付人数を分け、人数を超える場合の扱いを示しています。

公表された当初の募集期間は令和8年6月1日から9月30日までです。確認時点の11月には、この当初期間を過ぎています。要項には延長する場合の周知についても定めがありますが、その条項があるだけで延長が実施されたとは言えません。現在の受付状況は担当確認が必要です。

応募できない職員の区分や不認定事由、本人の同意による退職期日の変更があり得る場合も記載されています。募集要項の本文だけでなく、注記や別添まで読む必要がある例です。

これは相良村の公開例です。同村の日付や受付方法を、本人の機関に共通する期限として使わないでください。自分の募集要項で同じ項目を確認するための参考にします。

## 認定後も退職日と条件を確認する

国の法第8条の2第7項は、募集実施要項に退職すべき「期間」を記載した場合、認定後に具体的な期日を定めて通知する仕組みです。「この期間内なら本人が自由に退職日を選べる」とは限りません。

同条第8項には、応募を取り下げた場合、所定の期日に退職しなかった場合、一定の処分を受けた場合などの認定の失効に関する規定もあります。認定通知を得た後に、本人だけの判断で退職日を変えないでください。

国では退職すべき期日が到来するまでの応募取下げの規定がありますが、本人が使う様式と受付先を確認して進めます。地方の取下げや期日変更は、その条例・要項に沿って確認します。一般の辞職願を口頭で撤回する説明とは区別してください。

認定後に転職先の入社日を相談する場合も、退職期日の制約を踏まえて調整します。正式な退職日と最終登庁日、引継ぎ、休暇の承認、共済の資格喪失日はそれぞれ別に確認します。認定があれば年休を希望どおり取得できる、引継ぎが不要になる、といった保証はありません。

## 退職手当の試算と生活の手続きを別に整理する

退職手当の試算を依頼する場合は、退職理由、年齢、勤続、俸給・給料、適用日、認定の条件を担当へ示します。定年引上げに伴う経過措置もあるため、古い説明資料の対象年齢だけで計算しないでください。

割増の読み方は[勧奨退職と退職手当の割増](seido-ninyo-kansho-taishoku-teate.html)で整理します。手当の試算が示されたことと、応募や認定が済んだことも異なります。

医療保険、年金、住民税、家族の資格、共済貸付等の精算は別の手続きです。退職手当があることを前提に、未確認の支払予定を固めないようにします。税・社会保険・年金は一般的な説明と本人の扱いが異なる場合があるため、共済組合、年金事務所、税務署等の担当へ確認してください。

:::insight
募集要項が公表されたことを、本人が退職を決める理由にする必要はありません。希望する仕事、勤務条件、今後の生活を整理し、現職の継続や配置の相談と比べて考えられます。募集へ応募しない選択も、条件を確認したうえで情報収集にとどめる選択もあります。外部の求人を調べる場合は、手当の見込みだけでなく、担当する仕事、入社日、勤務地、保険や年金の手続きを含めて確認します。制度を利用できるかどうかと、その選択が本人に合うかは別です。認定や給付の未確認事項を確定扱いせず、必要な説明を得たうえで、本人が納得できる順序で判断することを大切にしたいと考えます。
:::

外部の仕事も比べたい場合は、[公務員経験を整理する案内](../?gov=1)を任意の情報収集に使えます。現職の制度確認を先に進めても構いません。

## よくある質問

### 早く辞職すれば早期退職募集の扱いになりますか？

単なる辞職と応募認定退職は別です。対象の募集、所定の応募、認定、退職期日などの条件を確認してください。

### 応募すれば必ず認定されますか？

国の法令には不認定事由と人数制限等の規定があります。地方も本人の要項等を確認します。受付の連絡と認定通知も区別してください。

### 認定後は退職日を自由に変えられますか？

本人だけで変更しないでください。所定期日の退職が認定の条件となる場合があります。取下げや期日変更は適用制度と担当へ確認します。

## 要項と正式通知をそろえてから予定を立てる

対象、期限、受付、認定、期日を項目に分けて確認します。現在の受付状況や不明点は、本人の募集を扱う担当へ照会してください。
