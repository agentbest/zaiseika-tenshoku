観光や地域振興に関わりたい、というご相談は、**公務員の方から繰り返し伺います。**

**「観光協会や、地域の事業に関わる仕事を探しています」**

**この探し方には、一つ落とし穴があります。**

**「観光」という言葉で探すと、候補が狭くなる**のです。**この分野は、法令の区分でいくつもの事業に分かれていて、それぞれに別の職種があります。**

この記事では、**法令の区分から業界の構造を整理し、未経験から入る道筋**を扱います。

## 旅行を手配する事業には、登録が要ります

**旅行業法第3条**です。

> **（登録）第三条　旅行業又は旅行業者代理業を営もうとする者は、観光庁長官の行う登録を受けなければならない。**

**短い条文ですが、この分野の性格を示しています。**

**旅行の手配を業として行うには、登録が要る。**誰でも始められる事業ではありません。

**登録の制度がある**ということは、**要件があり、それを満たし続ける義務があり、行政の確認がある**ということです。

## 泊める事業には、許可が要ります

**旅館業法第3条第1項**です。

> **旅館業を営もうとする者は、都道府県知事**（保健所を設置する市又は特別区にあつては、市長又は区長。第四項を除き、以下同じ。）**の許可を受けなければならない。**ただし、旅館・ホテル営業又は簡易宿所営業の（後略）

**こちらは許可**で、**相手は都道府県知事（保健所を設置する市・特別区では市長・区長）**です。

**つまり、保健所で旅館業の許可を扱っていた方**は、**この事業の手続きを、すでに知っています。**

**「手配する」と「泊める」で、制度も所管も違う**——ここが、この分野を理解する最初の区切りです。

## 業界は、6つに分かれます

| 区分 | 何をするか | 公務員からの入りやすさ |
|---|---|---|
| **観光協会・観光地域づくり法人** | 地域の観光の企画、情報の発信、受入れの整備 | **経験が直結する** |
| **まちづくり会社・地域商社** | 特産品の開発と販売、施設の運営 | **入りやすい** |
| 宿泊事業者 | 宿の運営、予約の管理、施設の管理 | 管理部門なら入りやすい |
| 旅行事業者 | 旅行の企画と手配、法人の取引 | 分野による |
| 交通・体験の事業者 | 二次交通、体験の提供 | 入りやすい |
| **観光のコンサルタント** | 計画の策定の支援、調査、事業の設計 | **経験が直結する** |

**上の2つと、いちばん下が、公務員からいちばん自然に移れる領域**です。

**理由は、仕事の相手が行政と地域の事業者だから**です。

**⚠ 呼び方について一つ。**地域の観光を推進する法人は、**「観光協会」のほか「観光地域づくり法人」**という呼び方でも募集が出ます。**英字の略称で書かれることもあります。**候補を探すときは、**複数の呼び方で検索してください。**一つの言葉だけで探すと、募集を見落とします。

## 観光協会と地域の法人という選択肢

**この領域の仕事は、公務員の方に馴染みがあります。**

| 仕事の中身 | 役所での対応する経験 |
|---|---|
| 地域の関係者との調整 | **商工会、事業者、住民との調整** |
| 計画の策定 | **観光の計画、総合計画の策定** |
| 補助金の申請と実績の報告 | **交付する側にいた** |
| 情報の発信 | 広報の経験 |
| イベントの企画と運営 | **行事の実施、許可の取りまとめ** |
| 統計の取りまとめ | 調査、統計の事務 |
| 会議体の運営 | 審議会・委員会の事務 |

**右の列が、そのまま左の列に対応します。**

**⚠ ただし、収入の作り方が変わります。**

**役所では、予算が先にありました。**この領域では、**会費、受託、補助、自主事業**の組み合わせで運営されています。**予算を使う仕事から、原資を確保する仕事に近づきます。**

## 許可・登録を出す側から、受ける側へ

**この移り方も、実務として自然です。**

| 役所の側 | 事業者の側 |
|---|---|
| 旅館業の許可の申請を審査する | **申請の書類を作り、提出する** |
| 施設の基準を確認する | 基準を満たす状態を維持する |
| 立入検査を行う | **検査を受け、指摘に対応する** |
| 変更の届出を受ける | 変更のたびに手続きを取る |
| 補助金を交付する | **申請し、実績を報告する** |

**保健所、商工、観光、文化の部署にいた方**は、**左の列をやってきています。**

**とくに、補助金の交付の経験**です。**この分野の事業者は、国や自治体の補助の制度を使うことが多く、申請書を作れる人が要ります。**

**交付する側の観点を知っている**のは、**大きな差**になります。

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 場面 | 効く理由 |
|---|---|
| 補助金の申請と実績の報告 | **交付する側の観点を知っている** |
| 行政との協議 | **相手の意思決定の流れと時期が読める** |
| 地域の関係者との調整 | 商工会・事業者・住民との調整の経験 |
| 計画の策定 | **策定の手順を知っている** |
| 会議体の運営 | 審議会・委員会の事務 |
| 統計・調査の取りまとめ | 調査の設計と集計の経験 |
| 許認可の手続き | **申請する側に回れる** |

**効きにくい場所**

| 場面 | 効きにくい理由 |
|---|---|
| 売上を作る | **予算を使う仕事とは方向が逆** |
| 価格の設定 | 値決めの判断を自分でする |
| 繁忙期の現場の対応 | **土日・連休が忙しい** |
| 情報の発信で人を動かす | 知らせることと動いてもらうことは別 |
| 少人数での兼務 | 分掌の外を自分で拾う |

**3つ目が、この分野の大きな特徴**です。

**観光は、土日、連休、長期の休暇に繁忙期が来ます。**役所の暦とは、**逆の動き方**になります。

:::insight
面談で拝見していて、**この分野を志望される方がいちばん見落としているのが「休みの曜日」**です。観光や地域の振興に関わる仕事は、**人が動く日に忙しくなります。**土日、祝日、大型の連休、夏休み、年末年始。**役所で土日が休みだった生活から、平日休みの生活に変わる**ことがあります。これは、**良い面もあります。**平日の役所や銀行の窓口に行ける、旅行や買い物が空いている時期にできる、子どもの学校行事に平日の代休を充てられる。**実際、「こちらのほうが暮らしやすい」とおっしゃる方もいます。**一方で、**ご家族が土日休みの場合、家族と過ごす時間の作り方が変わります。**お子さんが小さいご家庭では、ここが大きな判断の分かれ目になります。ですから、**求人に応募する前に、ご家族と話しておいてください。**面接で「土日の勤務は可能ですか」と聞かれてから考え始めると、その場で答えられません。⚠ なお、**この分野でも、観光のコンサルタントや、行政からの受託が中心の法人**では、**平日中心の勤務**であることがあります。**同じ「観光」でも、職種によって暦が違います。**
:::

## 入り方の手順

| 順 | やること | 目安 |
|---|---|---|
| 1 | 自分の機能を3つ書き出す（計画、補助、調整、広報など） | 30分 |
| 2 | **職種名で求人を検索する**（観光、地域、企画、事業推進） | 1時間 |
| 3 | **地域の法人の求人**を、自治体の公表や関係団体の情報から探す | 1時間 |
| 4 | 出てきた組織の**収入の構成**を調べる | 1時間 |
| 5 | 求人票の**勤務の曜日と時間帯**を確認する | 20分 |
| 6 | 応募条件を**5件読み比べる** | 1時間 |

**3つ目が、この分野では効きます。**

**観光協会や地域の法人の募集は、一般の求人サイトに出ないことがあります。****自治体の公表、関係団体の情報、法人の公式サイト**に直接出ることが多い。**定期的に見ておいてください。**

**4つ目も重要です。**[NPO・公益法人の年収と働き方](industry-npo-nenshu.html)でも扱いましたが、**収入の種類で財源が切れる時期が違います。**会費、補助、受託、自主事業。**自分の職がどの収入に紐づくかを確認してください。**

[経験の言い換えから相談する](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担です）。

## 面接で聞かれやすいこと

| 聞かれること | 何を見られているか |
|---|---|
| 土日や連休の勤務は可能ですか | **前提の確認** |
| 補助金の申請をした経験はありますか | **この分野の実務** |
| 地域の事業者と話した経験はありますか | 調整の経験 |
| 売上や集客の数字に関わることをどう考えますか | **予算を使う仕事との違い** |
| 行政との協議で、どちらの立場に立ちますか | **元の所属に引きずられないか** |

**2つ目は、交付する側にいた方には、語れる質問**です。

**答え方は、審査の観点**にしてください。「交付する側として、事業の目的と実施の内容が対応しているか、経費の区分が適切か、成果をどう測るかを見ていました。申請する側でも、その観点で組み立てられます」。

**4つ目は、構造の理解で答えます。****「予算は使い切ってよい上限として管理されますが、事業の収支は収入を作る方向です。方向が違うと理解しています」**と言えると、**覚悟の表明より説得力があります。**

:::insight
ここまで入り方の話をしてきましたが、**この分野を検討するときに、見ておいていただきたい点**があります。**組織の規模と、雇用の形**です。観光協会や地域の法人は、**職員が数名という規模**であることが珍しくありません。これは、**裁量が大きい**という利点がある一方で、**一人で複数の役割を担う**ということでもあります。広報も経理も補助金の申請も、**同じ人がやる。**そして、**雇用の形**も確認が要ります。**行政からの受託や補助を財源とする職で、期間が定められている**場合があります。⚠ これは悪いことではありませんが、**期間の定めがあるかどうかは、求人票と労働条件の通知で必ず確認してください。**期間の定めがある場合、**その後どうなる見込みか**も聞いてよい質問です。「これまで、期間の満了後に継続された方はいらっしゃいますか」。**答えにくそうにされた場合も、それ自体が情報**です。そして、⚠ **前の職場と取引のある法人に移る場合、再就職に関する規程の確認が要ります。**観光協会や地域の法人は、**自治体から補助や委託を受けている**ことが多く、**自分が担当していた相手方に移る形**になりやすい。**所属の人事担当部署と、適用される条例・規程を必ず確認してください。**この記事では、個別の事情について判断できません。
:::

## まとめ

- **「観光」という言葉だけで探すと、候補が狭くなります。**法令の区分でいくつもの事業に分かれています
- **旅行業法第3条**は、**旅行業又は旅行業者代理業を営もうとする者に、観光庁長官の行う登録**を義務づけています
- **旅館業法第3条第1項**は、**旅館業を営もうとする者に、都道府県知事（保健所設置市・特別区では市長・区長）の許可**を義務づけています
- 業界は、**観光協会・地域の法人／まちづくり会社・地域商社／宿泊／旅行／交通・体験／コンサルタント**に分かれます
- **公務員から入りやすいのは、観光協会・地域の法人、まちづくり会社、観光のコンサルタント**です
- ⚠ **予算を使う仕事から、原資を確保する仕事に近づきます。**会費・補助・受託・自主事業の組み合わせです
- ⚠ **土日・連休が繁忙期**になります。**役所の暦とは逆の動き方**です。ご家族と先に話しておいてください
- ⚠ **観光協会等の募集は、一般の求人サイトに出ないことがあります。**自治体の公表や法人のサイトを定期的に見てください
- ⚠ **雇用の期間の定めと、再就職に関する規程**を、応募の前に確認してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 観光の部署にいたことがありません

**移れる場合があります。**この分野で効くのは、**観光の知識そのものより、補助の制度・計画の策定・地域の調整の経験**です。**商工、農林、文化、生涯学習、企画**の部署にいた方は、**材料を持っています。**とくに、**補助金の交付事務**は、部署を問わず評価されます。また、**保健所で旅館業や食品営業の許可**を扱っていた方は、**宿泊や飲食の事業者側の手続き**に直接つながります。書き方は、**「観光の経験はありませんが、◯件の補助の申請を審査し、地域の事業者◯者と調整してきました」**という形です。**制度の名前ではなく、動作で書いてください。**

### 収入を作る仕事が不安です

**不安に感じるのは自然です。**ただし、**いきなり売上の責任を負う職ばかりではありません。**観光協会や地域の法人では、**補助金の申請、受託事業の管理、会員の対応**といった、**原資を確保する仕事の中でも行政寄りの部分**があります。ここは、**交付する側にいた経験がそのまま効きます。**そのうえで、**自主事業や物販に関わる場面**が出てきたときに、**値付けや採算を学んでいく**という順番で構いません。面接では、**「収入を作る経験はありませんが、補助の申請と実績の管理はできます」**と、**できる範囲を具体的に**伝えてください。**盛らないほうが、入ったあとが楽**です。

### 地元に戻って働きたいのですが、求人がありません

**探し方を変えてみてください。**この分野の募集は、**一般の求人サイトに出ないことがあります。**自治体の公表、観光協会や地域の法人の公式サイト、関係する団体の案内。**直接見に行くほうが、見つかることがあります。**また、**募集が出ていない時期でも、問い合わせから始める方法**があります。「採用の予定があれば教えてほしい」という短い連絡で足ります。⚠ ただし、**すぐに動く前提で問い合わせないでください。**半年後に欠員が出たときに連絡が来た、という例もあります。**急いで結論を求めない形の接点の作り方**として、覚えておいてください。なお、**⚠ 移住や住まいの条件も、先に確認しておく**ほうが判断が早くなります。
