自治体の人事の制度には、**職員を大学院や海外の研究機関、国の機関などに派遣して学ばせる研修**があります。財政課の職員が公共政策の大学院に派遣される、自治大学校で学ぶ、国の省庁に派遣される——いずれも、自治体が費用を負担して職員を育てる制度です。

この研修派遣は、**自己啓発等休業（本人の費用で学ぶ）とは、費用の負担が逆**です。そのため、**派遣で学んだ職員が、派遣の途中や派遣の後すぐに退職すると、自治体が負担した費用の償還を求められることがあります。**転職を考えている方にとって、派遣の経験は経歴の強みであると同時に、**退職の時期に法律と条例の線がある**制度です。

この記事では、**研修派遣の根拠、留学費用の償還の仕組み、償還が免除される場合、転職の時期の考え方**を整理します。**償還の有無と計算は自治体の条例による**ので、派遣を受けた方、これから受ける方は、人事の担当課で条例を確かめてください。自己啓発等休業は[自己啓発等休業](seido-kyuka-jikokeihatsu.html)に書いています。

## 根拠——研修は任命権者が行う

地方公務員法第39条は、**職員には、その勤務能率の発揮及び増進のために、研修を受ける機会が与えられなければならない**（第1項）、**研修は任命権者が行う**（第2項）と定めています。大学院派遣、海外派遣、国の機関への派遣研修は、この研修の一形態で、**任命権者の命令（研修命令）により、給与を受けながら学ぶ**制度です。

| 項目 | 研修派遣（第39条） | 自己啓発等休業（第26条の5） |
|---|---|---|
| **誰の意思か** | **任命権者の命令**（本人の希望を踏まえることが多い） | 本人の申請 |
| **費用** | **自治体が負担**（学費、旅費など） | **本人が負担** |
| **給与** | **支給される**（研修は職務） | 支給されない |
| **身分** | 職員のまま | 職員のまま（休業） |
| **退職後の償還** | **条例により、留学費用の償還を求められることがある** | 償還の問題は生じない |

## 留学費用の償還——国の法律と、自治体の条例

国家公務員については、**国家公務員の留学費用の償還に関する法律**が定めています。地方公務員には、この法律の第12条が、自治体の条例による償還の根拠になります。

| 条文 | 内容 |
|---|---|
| **第1条**（目的） | 留学の成果を公務に活用させ、国民の信頼を確保する |
| **第2条**（定義） | 「留学」は大学院の課程またはこれに相当する外国の大学の課程などでの研修。「留学費用」は旅費その他の留学に必要な費用 |
| **第3条**（償還） | 留学を命ぜられた職員が、**留学の期間内**に離職した場合は**留学費用の総額**を、**留学の期間の末日の翌日から在職期間が5年に達するまで**に離職した場合は**在職期間に応じて100分の100から逓減する率を乗じた額**を償還しなければならない |
| **第4条**（適用除外） | 公務上の傷病による免職、定年退職、任期の満了による退職、任命権者の要請に応じて特別職などになるための退職など、一定の場合は償還しない |
| **第12条**（地方公共団体） | 留学に相当する研修を実施する自治体は、研修を命ぜられた職員が第3条の期間に相当する期間内に離職した場合に、**費用の全部または一部を償還させることができる。**償還の額などは、**第3条から第6条までを基準として条例で定める** |

**自治体は「償還させることができる」で、義務ではありません。**条例を定めていない自治体では償還の制度がなく、定めている自治体では国の法律を基準にした仕組みになっています。

## 償還の仕組み（国の法律を基準にした条例の場合）

| 離職の時期 | 償還する額 |
|---|---|
| **派遣の期間内**に離職 | **費用の総額**に相当する額 |
| **派遣の終了後、在職期間が5年に達するまで**に離職 | 総額に、**在職期間が長くなるほど100分の100から逓減する率**を乗じた額（規則・条例で率を定める） |
| **派遣の終了後、5年を超えて**在職してから離職 | **償還なし** |

**派遣の終了から5年が、償還の有無の境目**です（国の法律を基準にした場合）。5年の在職期間には、休職の期間などは含まれません（第3条第3項）。

**償還の対象は「留学に相当する研修」**で、大学院の課程やこれに相当する外国の大学での研修が典型です。国の機関への派遣研修、自治大学校での研修、短期の海外研修が対象に含まれるかは、自治体の条例の定義によります。

## 償還が免除される場合（国の法律の第4条を基準にした条例の場合）

| 場合 | 償還 |
|---|---|
| 公務上・通勤による傷病で免職された場合 | なし |
| 定年退職 | なし |
| 任期の満了による退職 | なし |
| 任命権者の要請に応じて特別職などになるための退職 | なし |
| 死亡 | なし（第3条第2項） |
| **自己都合の退職（転職）** | **あり**（期間内なら） |

**転職のための退職は、償還の対象**です。派遣を受けた方が転職を考えるなら、派遣の終了からの在職期間と、償還の額を先に確かめてください。

## 転職の時期——考え方

| 状況 | 考え方 |
|---|---|
| **派遣中** | 退職すれば費用の総額の償還。**派遣中の転職は、制度の趣旨からも、償還の額からも、避けるべき** |
| **派遣の終了後、5年未満** | 在職期間に応じて逓減した額の償還。**償還の額を人事の担当課に照会し、転職先の条件と並べて判断** |
| **派遣の終了後、5年以上** | 償還なし。転職の時期に法律・条例の制限はない |
| **派遣の経歴** | 大学院の学位、海外の経験、国の機関の経験は、転職先で評価される。**償還の期間を過ぎてから転職すれば、経歴の強みだけが残る** |

**償還は法律・条例の定める金銭の問題で、償還すれば退職は自由**です。ただし、派遣は自治体が費用を負担して育てた投資で、償還の期間内の転職は、金銭の問題を超えて、職場との関係と、後に続く職員の派遣の機会に影響します。

:::insight
面談で伺うと、**大学院派遣から戻って2年で転職を考え、償還の条例があることを人事に言われて初めて知った**という方がいます。額を聞くと、転職の時期を3年遅らせるほうが合理的だと分かり、その間に派遣で学んだことを公務で生かして、経歴として説明できる形にしてから転職しました。逆に、**償還の条例がない自治体で、派遣から戻ってすぐに転職して、「育ててもらって辞めた」と受け取られ、前職との関係が切れた**という方もいます。ここで1つ提案があります。**派遣を受けた方は、転職を考える前に、人事の担当課で「償還の条例の有無、自分の場合の償還の期間と額」を確かめてください。**条例があれば額で判断でき、なくても、派遣の終了から一定の期間を公務で働くことが、職場との関係と経歴の説明の両方で有利です。**派遣で得た学位と経験は、償還の期間を過ぎてから転職すれば、強みだけが残ります。**
:::

## 転職するとどうなるか

派遣を受けた方、これから受ける方にとって、効いてくる点は3つです。

**1. 派遣中と派遣後5年未満の退職は、償還の対象になり得る**

**条例の有無と額を先に確かめる。**額が分かれば、転職の時期を判断できます。

**2. 償還の期間を過ぎれば、制限はない**

**派遣の経歴は転職先で評価される強み**です。期間を過ぎてから転職すれば、強みだけが残ります。

**3. これから派遣を受けるなら、償還の条件を理解してから**

**派遣を受けた後の5年間は、転職の時期に制約がかかる**ことを、派遣を希望する前に理解しておいてください。

## 手続きと期限

| 順序 | 手続き | 時期 | 場所 |
|---|---|---|---|
| 派遣を希望する前 | 償還の条例の有無と内容を確かめる | 希望を伝える前 | 人事の担当課、例規集 |
| 派遣中 | 研修に専念。転職活動は制度の趣旨に反する | 派遣の期間 | ── |
| 派遣の終了後 | 学んだことを公務で生かす。派遣の終了日を記録しておく | 復帰後 | ── |
| 転職を考えたら | 派遣の終了からの在職期間と、償還の額を照会 | 転職を考えた時点 | 人事の担当課 |
| 償還の期間内に退職する場合 | 償還の額と納付の方法を確かめ、退職手当との関係を整理 | 退職前 | 人事の担当課 |
| 償還の期間を過ぎたら | 制限なし | ── | ── |

## 誤解されやすい点

**「研修派遣と自己啓発等休業は同じ」と思い込む**

**費用の負担が逆です。**研修派遣は自治体が費用を負担し、償還の問題が生じ得ます。

**「償還は国家公務員だけの制度」と思い込む**

**法律の第12条により、自治体は条例で償還の制度を設けられます。**条例の有無を確かめてください。

**「派遣の終了後はすぐ辞めてもよい」と思い込む**

**国の法律を基準にした条例では、終了後5年未満の退職は在職期間に応じた償還の対象**です。

**「償還すれば何の問題もない」と思い込む**

**金銭の面では解決しますが、職場との関係と、後に続く職員の派遣の機会に影響します。**

:::insight
ここまで償還の話を書いておいて逆のことを言いますが、**派遣を受けたことは、転職の障害ではなく、強みです。**償還の期間は有限で、過ぎれば学位と経験だけが残ります。それでも1本の記事にしたのは、**償還の条例を知らずに転職を進めて、額を聞いて慌てる方を面談で見る**からです。額と期間を先に確かめれば、転職の時期は自分で決められます。そのうえで、**自分の経験に値を付けてくれる業界の見込みと、同じ紙に並べてください。**片方だけでは比較になりません。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 研修派遣は、地方公務員法第39条の研修として**任命権者の命令で行われ、自治体が費用を負担し、給与も支給されます。**本人の費用で学ぶ自己啓発等休業とは費用の負担が逆です
- 国家公務員の留学費用の償還に関する法律第12条により、**自治体は条例で、留学に相当する研修を命ぜられた職員が一定の期間内に離職した場合に費用を償還させることができます**
- 国の法律を基準にした条例では、**派遣の期間内の離職は費用の総額、派遣の終了後5年未満の離職は在職期間に応じて逓減した額**を償還し、**5年を超えれば償還はありません**（第3条）
- **定年退職、任期の満了、公務上の傷病による免職などは償還の対象外**ですが、**転職のための自己都合の退職は対象**です（第4条）
- 派遣を受けた方は、**転職を考える前に、償還の条例の有無、期間、額を人事の担当課で確かめてください**
- **償還の期間を過ぎてから転職すれば、派遣で得た学位と経験は強みだけが残ります**

## よくある質問

### 大学院派遣から戻って3年です。転職すると、いくら償還することになりますか

**自治体の条例によりますが、国の法律を基準にした条例なら、派遣の費用の総額に、在職期間3年に応じて逓減した率を乗じた額です。**国家公務員の留学費用の償還に関する法律第3条第1項第2号は、留学の期間の末日の翌日から在職期間が5年に達するまでに離職した場合、費用の総額に、在職期間が長くなるほど100分の100から一定の割合で逓減する率を乗じた額を償還すると定めています。自治体の条例はこれを基準として率を定めているので、3年在職した時点での率を人事の担当課に照会すれば、額が分かります。費用の総額には、学費のほか、旅費その他の派遣に必要な費用として条例で定めるものが含まれ、給与は含まれないのが一般的です。**額を聞いたうえで、あと2年在職して償還をゼロにするか、償還して今転職するかを、転職先の条件と並べて判断してください。**償還の期間の5年には、休職の期間などは含まれないので（第3条第3項）、派遣の終了後に休職があった方は、在職期間の数え方も確かめてください。条例を定めていない自治体では償還の制度そのものがありませんが、その場合も、派遣の終了から一定の期間を公務で働いてから転職するのが、職場との関係を保つ形です。

### これから大学院派遣を受けるか迷っています。転職の可能性があるなら受けないほうがよいですか

**転職の時期に5年の制約がかかることを理解したうえで、派遣で得られる学位と経験の価値と比べて判断してください。**派遣を受ければ、給与を受けながら大学院で学べ、学位と経験は転職先でも評価されます。一方で、国の法律を基準にした条例なら、派遣の終了後5年未満の転職は償還の対象になり、5年間は転職の時期に制約がかかります。「派遣を受けて、5年以上公務で学びを生かしてから転職する」という計画なら、派遣は転職の準備としても合理的です。「派遣を受けて、すぐに転職する」という計画なら、償還の額と職場との関係の両面で不利なので、派遣を受けずに自己啓発等休業（本人の費用、償還なし）や勤務時間外の修学を選ぶほうが筋が通ります。**派遣を受ける前に、人事の担当課で償還の条例の有無と内容を確かめ、自分の転職の時期の見込みと照らしてください。**派遣は自治体の投資なので、受けるなら、学びを公務で生かす期間を置くことが、制度を使う人の責任です。

### 派遣中に転職先から内定が出ました。派遣を途中でやめて転職できますか

**制度上は退職できますが、派遣の期間内の離職は費用の総額の償還の対象になり、制度の趣旨からも避けるべきです。**国の法律を基準にした条例では、派遣の期間内に離職した場合、自治体が支出した費用の総額に相当する額を償還します（第3条第1項第1号）。学費と旅費の総額なので、派遣の終了後の逓減した額より大きくなります。加えて、任命権者の命令による研修を途中で放棄して転職する形は、自治体と派遣先の大学院の両方との関係に影響し、後に続く職員の派遣の機会にも響きます。内定が出たなら、転職先に「現在、自治体の命令で大学院に派遣されており、修了まで○か月ある。修了後の入社にできないか」と相談してください。派遣で学位を取ってから入社する形は、転職先にとっても価値があり、入社日を待ってもらえることは少なくありません。待ってもらえない場合は、償還の額、経歴の説明、職場との関係の3つを並べて判断することになりますが、派遣の途中で辞める形が有利になることは、ほとんどありません。
