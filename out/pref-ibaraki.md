茨城県庁で働いてきた方の転職は、地方県庁の一般的なパターンとは前提が違います。**転居せずに首都圏の求人に応募できる**からです。

このことは選択肢の広さである一方、判断を難しくもします。県内で探すのか、都内まで含めるのか、その線引きから決めなければならない。そして多くの方が、その線引きを**通勤時間だけで決めてしまい、職種の選択肢を狭めています。**

この記事では、まず公表されている数字で自分の位置を確認し、そのうえで県庁の経験が民間のどの言葉に置き換わるのかを整理します。

## 茨城県庁の給与水準を、数字で確認する

総務省の調査によると、茨城県の一般行政職は次のとおりです（令和6年4月1日現在）。

| 項目 | 茨城県 |
|---|---|
| ラスパイレス指数 | 100.2 |
| 平均年齢 | 41.8歳 |
| 平均給料月額 | 322,000円 |
| 諸手当月額 | 89,036円 |
| 平均給与月額 | 411,036円 |
| 平均給与月額（国ベース） | 364,449円 |
| 地域手当（国の指定基準） | 6.0% |
| 地域手当（実際の支給割合） | 約7.46% |

### 地域手当の「国基準」と「実支給」がずれている

ここが茨城県の数字でいちばんの読みどころです。**国が指定する基準は6.0%なのに、実際の支給割合は約7.46%。**1.4ポイントほど上回っています。

同じ調査で近隣を見ると、栃木県が国基準3.5%に対し実支給約4.40%、群馬県は国基準2.5%で実支給も約2.50%。**上回っている県と、基準どおりの県があります。**

地域手当は、民間賃金の高い地域に支給される手当です。国の指定基準は市町村単位で決まっており、都道府県が独自の判断で支給割合を設定する余地があります。

:::insight
この差は、転職を考えるうえで見落とせません。**地域手当は民間企業にはない概念です。**求人票が提示するのは、基本給と諸手当を含んだ年収であって、「地域手当◯%」という内訳では書かれていません。相談の場でよく起きるのが、地域手当を含んだ現在の額面を基準に「これより下は受けられない」と判断し、**実際には条件の良い求人を最初から外している**ケースです。比べるときは、源泉徴収票の支払金額と、求人票の想定年収を突き合わせてください。手当の名目ごとに比べようとすると、必ず噛み合いません。
:::

### 平均年齢41.8歳という数字

もう一点。**茨城県の平均年齢41.8歳は、他県と比べて若い水準です。**山形県43.7歳、秋田県43.0歳、群馬県42.8歳、栃木県42.3歳。

平均年齢が低いということは、若手の比率が相対的に高いということです。上のポストが詰まりにくい一方、**同年代の職員が多く、庁内の相対評価では自分の位置が見えにくい**面もあります。外の基準と比べるときは、庁内の感覚をいったん外してください。

そして、上の平均は自分の給与ではありません。民間の求人票と比べるときは、**自分の源泉徴収票の支払金額**を使ってください。

## 県庁の経験は、民間で何と呼ばれるか

| 県庁での仕事 | 求人票での言い方 |
|---|---|
| 予算の要求・査定、財政計画 | 予実管理、投資判断、経営企画 |
| 企業誘致・立地支援 | 事業開発、用地開発、アライアンス |
| 港湾・工業用地の管理 | インフラ運営、アセットマネジメント |
| 科学技術・研究支援の施策 | 産学連携、技術企画、事業開発 |
| 農林水産の産地形成・輸出支援 | 事業開発、産地開発、海外展開 |
| 県土整備の設計・積算・監督 | 発注者支援、施工管理 |
| 防災・原子力安全の計画と協議 | リスク管理、BCP、規制対応 |
| 市町村への助言・支援 | パートナー支援、カスタマーサクセス |
| 議会対応、条例・規則の改正 | 渉外、法務、規程整備 |

部署ごとの詳しい対応は[自治体の部署別 仕事ガイド](../zukan.html)にまとめています。財政課であれば[財政課の経験は民間で何と呼ばれるか](dept-zaisei-honyaku.html)で、さらに細かく分解しています。

## 茨城で、どの経験が値になるか

**1. 首都圏の求人に、転居せずに応募できる**

これが最大の条件です。都内に本社がある企業、とくに自治体を顧客にする企業や建設コンサルタントは、**東京勤務で全国の自治体を担当する**ポジションを持っています。県北からでも通える範囲に、県内では出会えない職種があります。

注意点は、通勤時間だけで線引きしないことです。**リモート可の求人や、週数日出社の求人が増えています。**「毎日通えるか」で切ると、選択肢が不必要に狭くなります。

**2. 研究機関と産学連携**

つくばを抱える県として、県庁には科学技術と研究支援の施策があります。**研究機関と企業をつなぐ実務、補助制度の設計、実証事業の調整。**産学連携やディープテックの事業開発では、この経験が直接読まれます。

**3. 港湾・素材・エネルギー**

鹿島の産業集積、港湾の管理、エネルギー関連施設。**大型の立地に伴う地元調整、安全に関する協議、インフラの手当て**は、事業者から見て最も苦労する部分です。この経験を持つ人は、外から採用しようとしても見つかりません。

**4. 市町村を相手にしてきた経験**

規模も体制もばらばらな市町村を相手に、温度差をどう埋めたか。「連絡調整」ではなく、**複数顧客を持つアカウント業務の経験**として書けば、そのまま職務能力になります。

## 職務経歴書に、県庁の仕事をどう落とすか

**制度名ではなく、判断したことを書く**

「○○推進事業を担当」では読み手に何も残りません。事業名は庁内でしか意味を持たない固有名詞です。**何件を、どういう基準で審査し、どこで判断が割れて、どう決着させたか。**この形にすると職務能力として読まれます。

**本庁と出先機関を書き分ける**

本庁は制度の設計と全県調整、出先は現場対応と個別案件の処理と、職務の性質がまったく違います。**どちらをどれだけ経験したかを書き分ける**と、読み手が配属をイメージできます。両方あるなら、制度を作る側と回す側の両方を見たという強い材料です。

**異動歴を「立ち上げの回数」に変える**

数年ごとの異動を「専門性がない」と書くのは、自分から評価を下げる書き方です。異なる制度領域を短期間で立ち上げてきた経験は、民間では**キャッチアップの速さ**として読まれます。編年式で並べ、それぞれの配属で最初の数か月に何を習得したかを1行添えてください。

## 技術職の場合は、探し方が変わる

**発注者側の経験そのものが職種になる**

「発注者支援」という職種が、建設コンサルタント業界には確立しています。設計の審査、積算の確認、工事の監督、住民説明。県庁でやってきたことが、そのまま職務内容として書かれた求人です。

**資格が入口で効く**

技術士、施工管理技士、測量士、電気主任技術者。事務職では資格より実績が先ですが、技術職では資格が応募の入口になる場面があります。**在職中に取れるものがあるなら、動く前に取っておくと選択肢が広がります。**実務経験の年数が受験要件になっているものは、在職中でなければ積めません。

**首都圏の案件を担当できる**

茨城からであれば、都内の建設コンサルタントに勤めて首都圏の案件を担当する、という選択も現実的です。**扱う案件の規模が変わる**ため、経験の積み方そのものが変わります。

## 面接で必ず詰められる2つのこと

**「意思決定のスピードに耐えられるか」**

行政は手続きの段数が多く、決裁を経て動きます。民間は月次で数字を締め、その場で方針を変えます。稟議の段数を弁解せず、**自分の判断で動かした範囲を具体的に答えてください。**

**「数字への意識があるか」**

「利益を意識したことはありますか」という形で聞かれます。「行政なので利益はありません」と答えると、そこで話が終わります。事業の優先順位を付けた、単価の根拠を詰めた、複数案を比べた。**同じ思考をしていたことを、民間の言葉で説明できるか**が見られています。

## 在職中に進めるときの注意点

**服務上の扱いを先に確かめる**

在職中に得た情報を持ち出すことは避けなければなりませんし、退職後の営業活動についても扱いを確認しておいたほうが安全です。**判断に迷う場合は、応募の前に人事担当課に制度上の取扱いを確認してください。**

**面接の日程は、議会日程から逆算する**

地方自治法第211条は、長が毎会計年度予算を調製し、年度開始前に議会の議決を経なければならないと定めています。都道府県は年度開始前30日までに予算を議会へ提出するようにしなければならない、とも書かれています。決算は、出納閉鎖後3か月以内の長への提出、監査委員の審査、議会の認定という順です（第233条）。**予算編成の山と定例会の会期中は、平日日中の面接を入れるのが難しくなります。**

**在職中に決める**

公務員には雇用保険が適用されないため、辞めてから探すと収入のない期間がそのまま持ち出しになります（[公務員に雇用保険がない理由](seido-shitsugyo-nashi.html)）。

:::insight
茨城県庁の方にいちばん多い判断の誤りは、**「通勤できる範囲」で求人を絞ってしまうこと**です。勤務地から検索すると、都内本社で全国の自治体を担当する求人や、リモート中心の求人が最初から視界に入りません。順序を変えてください。**まず職種で絞り、そのあとに勤務形態を確認する。**そのうえで通えないなら外せばよいだけです。県内在住のまま、県内では出会えない職種に就いている方は実際にいます。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 残る判断も、等しく扱う

ここまで転職の話を書いてきましたが、動かない判断にも理があります。

県庁は、県内では数少ない「制度を作る側」の職場です。しかも異動によって複数の領域を横断できる。この積み方は民間企業ではあまりできません。いま担当している領域で通しの経験が積み切れていないなら、それを終えてから動くほうが、書けることは確実に厚くなります。

首都圏に近いという条件は、**急がなくてよい理由**にもなります。地方県庁のように「動くなら転居を伴う」という制約がないぶん、機が熟すまで待っても選択肢はそれほど減りません。異動の希望が通る見込みがあるなら、まずそちらを試すのも合理的です。

ただし、自分の経験が外でどう呼ばれるかを知っておくことには、動かない場合でも意味があります。**次の異動希望を出すときの材料が変わる**からです。

## まとめ

- 茨城県の一般行政職は**ラスパイレス指数100.2、平均給与月額411,036円**（令和6年4月1日現在・総務省調査）
- **地域手当は国の指定基準6.0%に対し、実際の支給割合は約7.46%**。栃木県も同様に上回り、群馬県は基準どおりです
- **地域手当は民間にない概念です。**手当の名目ごとに比べようとすると必ず噛み合いません。源泉徴収票の支払金額で比べてください
- 平均年齢41.8歳は他県より若い水準です。**庁内の相対評価を、外の基準だと思わないでください**
- 経験が効く方向は、**首都圏の求人／研究機関と産学連携／港湾・素材・エネルギー／市町村を相手にした経験**の4つです
- **勤務地から検索しない。**職種で絞ってから勤務形態を確認する順序に変えてください
- 首都圏に近いことは、**急がなくてよい理由**にもなります。残る判断にも理があります

## よくある質問

### 都内の企業に転職すると、通勤が現実的ではないのですが

**毎日通う前提で考えないでください。**近年はリモート可、週数日出社といった勤務形態の求人が増えています。とくに自治体を顧客にする企業は、担当エリアに出向くことが仕事なので、本社への出社頻度が低い場合があります。**募集要項の「勤務地」欄だけでなく、勤務形態の記載まで確認してください。**通えないと判断するのは、その後で十分です。

### 地域手当がなくなると、実質的に給与が下がりませんか

**下がる場合はあります。**ただし民間企業の給与体系には地域手当という区分がなく、勤務地の物価や相場は基本給や各種手当に織り込まれています。したがって「地域手当の分だけ減る」という比べ方自体が成り立ちません。**現在の源泉徴収票の支払金額**を基準にして、求人票の想定年収と比べてください。

### 30代前半ですが、動くのは早すぎますか

**年数より、通しで回した経験があるかどうかです。**茨城県の一般行政職の平均年齢は41.8歳ですから、30代前半は庁内では若手にあたります。ただし民間の中途採用では、30代前半は最も選択肢が広い年代です。判断の目安としては、**いま担当している領域を一巡させたかどうか。**制度の設計から実行、そして翌年度の見直しまでを見ていれば、書ける材料は揃っています。
