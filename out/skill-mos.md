**「事務の資格を取るべきか」**というご相談を伺います。

**答えは、応募したい求人によって分かれます。**

この記事では、**判断の基準**を扱います。

**⚠ 試験の内容・等級・受験の方法は、実施する団体の公表を確認してください。****この記事では個別の内容には触れません。**

## 検定には、国が行う枠組みがあります

**職業能力開発促進法第44条第1項**です。

> **技能検定は、厚生労働大臣が、厚生労働省令で定める職種**（略）**ごとに、厚生労働省令で定める等級に区分して行う。**ただし、検定職種のうち、等級に区分することが適当でない職種として厚生労働省令で定めるものについては、等級に区分しないで行うことができる。

**技能検定は、厚生労働大臣が行うもの**と定められています。

**一方、民間の団体が実施する資格もあります。**

**この違いを押さえておいてください。**

| 種類 | 位置づけ |
|---|---|
| ① 免許・国家資格 | **法令により、職に就く要件**となることがある |
| ② 国家検定 | 法律に基づき国が行う検定 |
| ③ 民間の資格 | 団体が独自に実施する |

**③は、法令上の効力を持つものではありません。**

**求人票に書かれていれば意味があり、書かれていなければ判断の中心にはならない。**

**これが、扱いの基本**です。

## 取るべき人

| 状況 | 理由 |
|---|---|
| ① 応募条件に記載がある | **満たす材料になる** |
| ② 実務の経験がない | 到達を示すものが他にない |
| ③ ブランクがある | 学習していることを示せる |
| ④ 到達を測りたい | 自分の現在地の確認 |
| ⑤ 会社の支援がある | 入社後に取得を求められる場合 |

**①と②が中心**です。

**②について。**

**事務の経験がない、または短い場合、操作の水準を示すものが他にありません。**

**この場合、資格が材料になります。**

**一方、行政で長く事務をしてきた方は、実務の経験のほうが具体**です。

## 取らなくてよい人

| 状況 | 理由 |
|---|---|
| ① 応募条件に記載がない | **判断の中心にならない** |
| ② 実務で作った表がある | **経験のほうが具体** |
| ③ 応募の時期が近い | 書類の作成が優先 |
| ④ 他に足りないものがある | 職務経歴書、条件の整理 |
| ⑤ 目的が曖昧 | 「何か取っておきたい」だけ |

**②が、公務員からの転職では多い**です。

**年間◯件のデータを1行1件で管理する表を作り、検算の手順を組み込んだ。**

**この説明のほうが、資格の名称より伝わります。**

**扱いは**[Excel｜民間で最初に問われる水準はどこか](skill-excel.html)**に整理しています。**

## 代わりに書けるもの

| 材料 | 書き方の例 |
|---|---|
| 作った表の規模 | 年間約◯件、項目◯列 |
| 使った機能 | 集計、検索、条件の判定 |
| 統制の工夫 | 選択式の入力、条件による表示 |
| 検算 | 2通りの方法で突き合わせ |
| 引継ぎ | 様式として整備し、交代時に使用 |

**この5つが書ければ、水準は伝わります。**

**資格の名称だけを書くより、具体**です。

**とくに、3行目と4行目は、実務でしか身につきません。**

**入力の誤りを防ぐ仕組みを作った、合計を別の方法で確かめた。**

**この2つが書ければ、操作ができるだけの人とは区別されます。**

**行政の事務では、どちらも当たり前に行ってきたはず**です。

**当たり前だと思っている部分にこそ、材料があります。**

**書き出してみてください。**

**思ったより多く出てくることがあります。**

:::insight
資格について、**面談でお伝えしているのが「何を証明したいのかを先に決めてください」**という点です。**「何か資格を取っておきたい」というご相談**が少なくありません。ところが、**資格は、証明したいことがあって初めて意味を持ちます。**操作ができることを示したいのか、学習を続けていることを示したいのか、応募条件を満たしたいのか。**目的によって、取るべきものが変わります。**そして、**行政で長く事務をしてきた方の場合、証明すべきは操作ではないことが多い**です。むしろ、**制度に沿って運用してきたこと、記録を残してきたこと、担当が交代しても回る形を作ってきたこと。****これらは、資格では示せません。**書類で書くしかない部分です。ですから、**資格の検討より先に、職務経歴書を1通仕上げてください。**書いてみると、**足りないものが具体に分かります。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 判断の手順

| 順 | やること |
|---|---|
| 1 | **応募したい求人を5件読む** |
| 2 | 応募条件に資格の記載があるか確認 |
| 3 | 必須か、歓迎かを分ける |
| 4 | 実務で書ける材料を並べる |
| 5 | **足りない場合にだけ、取得を検討** |
| 6 | 期限に間に合うかを確認 |

**1と5が要**です。

**読まずに取ると、要件でないものを取ることになります。**

**読み方は**[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)**に整理しています。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| できる範囲 | **正確に、限定して** |
| 作った表の実例 | 規模、用途、工夫 |
| 検算の方法 | どう確かめたか |
| 学習の状況 | 継続しているか |
| 取得の理由 | **なぜ取ったか** |

**5行目です。**

**資格を書いた場合、取得の理由を聞かれる**ことがあります。

**「業務で必要だった」「到達を確かめたかった」**など、**理由を用意**しておいてください。

**「何となく」では、目的が伝わりません。**

## 資格を書くときの注意

| 注意 | 内容 |
|---|---|
| ① 名称を正確に | **略称でなく、正式な名称で** |
| ② 取得の年を書く | いつ取ったか |
| ③ 等級・区分を書く | 段階がある場合 |
| ④ 登録・更新の状況 | 有効かどうか |
| ⑤ 関係するものを選ぶ | 応募先に関係するもの |

**②が抜けやすい**です。

**取得の年がないと、現在も使える状態かが分かりません。**

**④について。**

**登録や更新が必要な資格では、状況を確認**しておいてください。

**失効していることに、応募の後で気づく**という事態を避けられます。

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 実務の材料の整理 | **作った表と、その運用** |
| 使った機能の書き出し | 関数、集計の方法 |
| 求人を読む | 週に30分 |
| 資格の状況の確認 | 登録、更新 |

**1行目を先にしてください。**

**手元にある材料を整理すると、足りないものが分かります。**

**そのうえで、必要なら取得を検討する**という順序です。

## よくある失敗

**1. 求人票を読まずに取る**

**要件でないもの**を取ることになります。

**2. 実務の経験を書かずに資格だけ書く**

**経験のほうが具体**です。

**3. 応募の時期が近いのに学習を始める**

**書類の作成が優先**です。

**4. 必須と歓迎を分けない**

**扱いが違います。**

**5. できる範囲を広く書く**

**入社後に困ります。**

**6. 取得の理由を用意しない**

**目的が伝わりません。**

**7. 「何か取っておきたい」で選ぶ**

**証明したいことを先に決めて**ください。

**8. 取れば転職できると考える**

**要件を満たす材料の1つ**です。

:::insight
ここまで「取らなくてよい」寄りの話をしておいて逆のことを言いますが、**学習していること自体は、面接で使えます。**面談で拝見していると、**在職中に何もしていないことを気にされる方**がいらっしゃいます。資格の有無とは別に、**「制度の改正に対応するため、継続して学習している」「業務の効率化のために、表計算の機能を学んでいる」**という事実は、**学ぶ習慣がある人**として読まれます。とくに、**未経験の領域に応募する場合**、この点は見られます。ですから、**資格を取るかどうかにかかわらず、いま学んでいることを1つ用意しておいてください。**そして、**学んだ結果を業務に使った**なら、そこまで書いてください。「学んだ機能を用いて、◯◯の集計の手順を作り直した」。**学習と成果がつながっていると、実務に結び付く人として読まれます。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **職業能力開発促進法第44条**は、**技能検定を厚生労働大臣が職種ごとに等級に区分して行う**としています
- 資格は、**①免許・国家資格 ②国家検定 ③民間の資格**に分かれます。**③は法令上の効力を持つものではありません**
- **求人票に書かれていれば意味があり、書かれていなければ判断の中心にはなりません**
- **取るべき**なのは、**応募条件に記載がある、実務の経験がない、ブランクがある**場合です
- **取らなくてよい**のは、**実務で作った表がある、応募の時期が近い**場合です
- **作った表の規模・機能・統制・検算・引継ぎ**が書ければ、水準は伝わります
- **何を証明したいのかを先に決めて**ください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 応募条件に「基本的な操作ができる方」とあります

**実務の経験で応募できます。**この書き方は、**特定の資格を求めるものではありません。**書類には、**作った表の規模と、使った機能**を書いてください。「年間約◯件のデータを管理する表を作成し、集計・検索・条件の関数を使用」という形です。なお、**面接で操作について聞かれることがあります。**「どの機能をよく使いますか」という質問です。**答えられるよう、実際に使ったものを整理**しておいてください。**できないことは書かない**でください。扱いは[Excel｜民間で最初に問われる水準はどこか](skill-excel.html)に整理しています。

### 資格を取る時間があるなら、何をすべきですか

**優先順位は3つです。**1つ目は、**職務経歴書を1通仕上げること。**書いてみると、足りないものが具体に分かります。2つ目は、**求人を読んで条件を絞ること。**応募したい領域が決まると、必要なものが見えます。3つ目は、**制度の確認**です。退職の手続き、退職手当の扱い。**これらは時期に直接関わります。**資格の検討は、**この3つが終わってからで差し支えありません。**扱いは[選考スケジュールの組み方](senko-sagasu-schedule.html)に整理しています。

### 資格を複数持っていますが、全部書くべきですか

**応募先に関係するものを選んでください。**関係のない資格を並べると、**何を見せたいのかが伝わりません。**目安は、**応募条件に挙げられているもの、業務に関係するもの、取得の年が新しいもの**です。なお、**取得の年は必ず記載**してください。古い資格は、**現在も使える状態か**を確認されることがあります。また、**登録や更新が必要な資格**については、**状況を確認**しておいてください。扱いは[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)に整理しています。
