内部監査・リスク管理部門への転職では、公務での検査や確認を、企業の内部監査の経験へ自動的に置き換えません。資料の照合、照会、記録、改善事項の整理には説明できる工程がありますが、監査計画、評価、報告、フォローアップをどこまで本人が担ったかは別に確認します。求人の専門実務と、自分の担当を並べることから始めましょう。

本記事は2026年11月時点の公開情報にもとづきます。確認日は2026年11月25日です。株式会社博展の公式自社採用「内部監査（課長候補）」を一例にします。非公開の評価基準や、業界全体の採用傾向を示すものではありません。募集継続と本人の条件への該当は、当該求人の採用窓口へ確認してください。

## 内部監査、内部統制、リスク管理を区分する

内部監査という仕事を調べるときは、事業部や子会社等の業務を確認し、課題と改善を報告する役割と、日々の業務を実行する役割を分けます。内部統制の整備・運用・評価、リスクの把握と対応、法務や情報セキュリティ等も、会社によって担当が異なります。部門名だけで全領域を同じ実務にしないことが基本です。

博展の当該求人は、経営直轄の内部監査室で、業務監査、内部統制、認証業務を幅広く担当すると説明しています。具体的にはリスクアセスメントにもとづく監査計画、事業部・子会社への往査やヒアリング、報告書、経営陣等への報告、J-SOX評価、認証業務、改善提案とフォローアップなどです。

同じ求人に複数の仕事があることから、すべての会社の内部監査部門が同じ範囲を担当するとはいえません。リスク管理の職種を希望する場合も、日々のリスク対応を実施するのか、仕組みを整えるのか、監査するのかを具体的に確認します。会社の規模、事業、グループ構成と当該募集を一組で読みます。

また、監査法人が外部の立場で行う監査や、公務での検査・監査、日常の伝票確認と、企業内の内部監査を同じ職歴として扱いません。共通する確認の工程があっても、根拠、対象、責任、報告先が異なります。経験の接点と専門実務への該当を分けて示してください。

## 公式求人の必須条件が示す役割

博展の当該募集は課長候補であり、上場企業またはそれに準ずる企業での業務監査・J-SOXの実務経験を必須とし、年数は5年以上を目安として掲げています。加えて、リスクアセスメントから監査計画、往査、報告書、改善提案まで一連の監査を主導した経験が記載されています。

必須欄には、現場、経営層、監査法人などとの調整・折衝と、経営層へ課題や改善策を論理的に伝える文章・プレゼンテーションの力もあります。年数だけ満たせばほかの経験は不要という意味にはしません。公務の勤務年数を、そのまま対象企業の監査経験の年数として数えないでください。

歓迎欄には、子会社監査、テーマ監査、認証制度の運用、CIA等の関連資格、簿記2級程度の知識、業務標準化等が示されています。資格や知識は専門実務の条件の代わりではありません。歓迎の経験を必須へ強めたり、必須の一連の監査経験を歓迎へ弱めたりしないようにします。

| 求人の条件・仕事 | 本人が整理すること | 同一視しないこと |
| --- | --- | --- |
| 監査計画とリスクの把握 | 本人が対象や手順を決めた範囲 | 決定済みの一覧を受け取った経験 |
| 往査・ヒアリング | 聞いた事項、記録、確認の根拠 | 他者の判断や指摘 |
| 報告と改善提案 | 本人が分析し、記載・提案した内容 | 組織の最終判断と成果 |
| 資格・知識 | 保有、合格、学習の区分 | 実務の代替や権限の保証 |

これは当該課長候補の条件です。内部監査のすべての求人に同じ年数を求めるという説明ではありません。他の職種や役割を検討する場合は、実際の募集を改めて確認してください。[公務員経験を整理しながら求人を比較する](../?gov=1)際も、本人の現在の担当に合う条件かを一つずつ照合します。

## 公務経験で説明の材料になる工程

まず、根拠を確認して資料を照合した工程です。何を対象とし、どの規程や手順を参照し、どの項目を確認したかを示します。「法令に詳しい」「正確性がある」という自己評価だけでなく、本人が行った作業として説明します。ただし、すべての法分野や企業の会計基準を扱えると広げません。

次に、不明点の照会と記録です。回答が必要な事項を分け、担当へ問い合わせ、確認済みと未回答を区別して残した経験は具体化できます。相手へ聞いたことと、本人が評価して結論を出したことは別です。上司や専門部署へ判断を依頼した場合は、その分担を保ちます。

第三に、課題や改善事項を整理した工程があります。指摘の案を作ったのか、根拠資料を集めたのか、対応状況を確認したのかを分けて説明します。組織としての決定、実行部門が行った改善、委託先が構築した仕組みは本人の実績に加えません。効果を計測していなければ、改善率を後から作る必要もありません。

公務で監査を担当した人も、計画、実査、記録、報告、改善状況の確認のどこに関わったかを示します。行政の制度や対象と、企業の事業・会計・内部統制との違いを残してください。担当名だけで同一視せず、応募先の専門実務への該当は窓口で確認します。

:::insight
監査に近い経験を伝えるときは、指摘したという一語でまとめず、根拠と本人工程を分けることを勧めます。資料を照合したこと、相手へ確認したこと、評価を行ったこと、改善を提案したことは別の経験です。公務の対象と企業の事業では前提も異なるため、同じ監査という名称だけで実務を換算できません。本人が決めた範囲と、他者へ判断を依頼した範囲を整理してください。経験を大きく広げなくても、確認と記録の進め方は説明できます。そのうえで必須の専門実務に該当するかを窓口へ尋ねましょう。資格や学習は別の欄に残し、経験条件を満たしたことにしない準備を勧めます。
:::

## 独立した架空例：確認業務の経験表

以下は説明用に作成した架空例です。実在の職員の経歴、相談、採用結果ではありません。本人の応募へ使う場合は事実に置き換え、実施していない工程や確認できない成果は削除してください。

| 項目 | 架空の記入例 |
| --- | --- |
| 本人の担当 | 自治体の庶務として支出関係資料の確認を担当 |
| 実施した作業 | 所定の項目と添付の有無を照合し、不足を整理 |
| 照会したこと | 判断が必要な事項を会計担当へ確認するためメモを作成 |
| 他者の判断 | 会計上の適否は専門部署、承認は決裁者 |
| 求人との接点 | 根拠を参照した照合、確認待ちの記録と引継ぎ |
| 未経験 | 企業の監査計画、J-SOX評価、一連の監査の主導 |
| 条件の照合 | 当該課長候補の専門実務を満たすとは判断できない |
| 次の確認 | 本人の担当を示し、対象実務と合う職務を確認 |

この例は「所定の項目と添付を照合し、判断が必要な事項を会計担当へ照会するため整理しました」と説明できます。「企業の内部監査を主導しました」と書くと、本人工程と対象が変わります。監査に接点があるという話と、必須条件を満たすことは分けます。

本人が実際に公務の監査計画や実査を担当した場合は、その事実に置き換えます。計画案の作成、確認項目の検討、ヒアリング、報告書のどこを担当したかを示し、決裁者の権限や会議体の判断を加えません。外部へ示せる範囲で、対象と本人の役割を具体化してください。

数値がないことを理由に、未計測の損失防止額や改善率、不備の発見件数を作る必要はありません。確認した根拠、記録、判断を仰いだ先、対応状況を説明できます。実際に計測したものがあっても、秘密や個人情報の取扱いを確認し、本人の実績の範囲に限ります。

[担当した確認工程と希望職種を相談用にまとめる](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担）。経験や希望条件によって、面談や求人紹介を案内できない場合があります。

## 経験を整理して、担当と確認体制を尋ねる

博展の当該求人は、既存のメンバーとペアで監査を進め、監査の品質や標準化を担う役割を説明しています。入職後は現行のプロセスや関係者との関係を理解する案内がありますが、未経験者が一連の専門実務を初めから学べる枠とは読みません。求人が求める経験と役割を保って確認します。

本人からの質問は、対象となる事業、監査の範囲、報告先、既存の体制、資料へのアクセス、改善の実行部門との関係などに分けられます。公務での経験を説明したうえで、異なる制度や業務をどこから理解するかを相談します。これは本人が確認する事項であり、採用側の面接質問や評価を予告するものではありません。

リスク管理を希望する場合も、監査室に入ることだけで希望する担当が決まるとは考えません。日々のリスク対応、仕組みの整備、内部統制の評価、認証の運用のどこを担うかを確認してください。個別の専門知識や経験が必要な場合は、本人の現在の範囲を明記します。

資格の学習や過去の外部監査の経験がある人も、内部監査のすべてを経験済みとしません。監査法人として行った作業と企業内で担う作業、公務の検査と企業の内部統制を区分します。関連する経験があることと、当該募集に該当することは別々に照合します。

## 雇用と勤務の条件も別に確認する

当該求人は正社員、試用期間3か月、フレックス、リモートワークを記載しています。一方、原則として週3日以上の出社を推奨する案内もあります。リモートという語だけで完全在宅と考えず、実際の出社、往査、会議や報告の予定を確認します。試用中の扱いと本人への条件も別に聞いてください。

給与や手当には採用時の処遇による記載があるため、役職名だけで個人の適用を決めません。給与の内訳、勤務の管理、時間外や休日対応、本人の役割を採用窓口へ確認します。求人の制度説明を一般の法的判断や本人の確定条件へ広げず、公開情報で不明な点を質問として残しましょう。

現職の勤務と生活上の条件も、自分の実際の状況を使って比較します。公務の経験が役立つ接点があっても、勤務や役割が希望と合わなければ応募を見送れます。内定前に退職することを前提にせず、現職を続けながら情報を集めることも同じ選択肢です。

## 守秘を保った資料で説明する

応募資料に実際の監査調書、指摘事項、住民や企業の個別情報、未公開の不備やシステムの詳細を持ち出さないでください。名前を消しても利用できるとは限りません。個人端末や外部の生成AIに内部資料を入力することも避け、公開情報と本人工程の説明から構成します。

法令や規程を確認した経験を話す場合も、内部の運用や脆弱性まで明かす必要はありません。本人が外部へ説明できる範囲で、何を照合し、どこで判断を仰いだかを伝えます。学習作例を作るなら独立した架空データを用い、現職の資料を匿名化して転用しないようにします。

行政上の便宜や職務で知った連絡先を、応募先へ提供できる利点として売り込まないことも基本です。守るべき情報の持出しは経験の証明ではありません。示せない資料が求められる場合は、秘密を開示せず、説明可能な形式を採用窓口へ相談してください。

:::insight
内部監査への関心があっても、すべての確認業務を専門実務へ言い換える必要はありません。本人がどこで根拠を読み、何を照合し、誰へ判断を依頼したかを示すことを勧めます。その経験と求人の計画、評価、報告、改善の主導との違いを確認すると、現在の条件に合うかを判断できます。資格や知識は別に説明し、実務の不足を隠す表現には使わないでください。仕事の対象や勤務が希望と合わない場合は、ほかの職種を調べることや現職を続けることも選べます。秘密を持ち出して実績を示す必要もありません。適切に説明できる事実を土台に、担当の範囲、確認体制、契約の条件を一つずつ確かめましょう。
:::

## まとめ：接点と専門実務を分けて示す

内部監査・リスク管理部門では、業務監査、内部統制、リスク対応、認証等の役割を区分します。公務の照合や照会は本人工程として説明し、企業の一連の内部監査へ自動換算しません。必須経験と歓迎資格、本人と他者の判断、勤務の制度と個別条件を分けて確認しましょう。

[LINEで相談の進め方を確認する](https://line.me/R/ti/p/@697nxhbt)際は、内部資料を送らず、外部へ伝えられる担当、未経験の専門実務、希望する役割を整理してください。

## よくある質問

### 公務の検査経験は内部監査経験になりますか？

同じものとは決めません。根拠、対象、本人工程、報告先を示し、当該求人の専門実務への該当を採用窓口へ確認してください。

### 関連資格があれば実務の条件を満たせますか？

資格と実務は別です。今回の課長候補求人では資格は歓迎で、専門実務や一連の監査を主導した経験等が必須です。条件を区分して照合します。

### 実際の監査資料を提出して経験を説明できますか？

内部資料や個人情報を持ち出さないでください。匿名化だけで利用可能とは限りません。公開情報と本人工程で説明し、示せる形式を採用窓口に相談します。
