**「一度出たら、もう戻れないのではないか」**というご相談を伺います。

**制度の枠組みを確認しておくと、判断がしやすくなります。**

この記事では、**採用の仕組み**と、**確認すべき点**を扱います。

**⚠ 募集の有無・要件・時期は、団体ごとに異なります。****必ず、各団体が公表する募集要項を確認してください。**

## 採用は、競争試験又は選考によります

**地方公務員法第17条の2第1項**です。

> **人事委員会を置く地方公共団体においては、職員の採用は、競争試験によるものとする。**ただし、人事委員会規則（略）**で定める場合には、選考**（**競争試験以外の能力の実証に基づく試験**をいう。以下同じ。）**によることを妨げない。**

**同条第2項**です。

> **人事委員会を置かない地方公共団体においては、職員の採用は、競争試験又は選考によるものとする。**

**採用の方法が、競争試験又は選考と定められている**ということです。

**つまり、「戻る」場合も、改めて採用の手続きを経る**ことになります。

**在職していた事実によって、当然に復職するという仕組みではありません。**

**一方、選考は「競争試験以外の能力の実証に基づく試験」**と定義されています。

**民間での経験が、能力の実証として扱われる枠組みがある**ということです。

## 戻る場合の主な枠組み

| 枠組み | 内容 |
|---|---|
| ① 一般の採用試験 | 年齢などの要件は団体による |
| ② 経験者を対象とする採用 | **民間での職務経験が要件** |
| ③ 任期を定めた採用 | 専門性を活かす枠組み |
| ④ 会計年度任用 | 任期は会計年度の単位 |
| ⑤ 国・他の団体 | 募集の枠組みは団体による |

**②が、民間を経験した方の入口**です。

**職務経験の年数が要件として定められている**ことがあります。

**③について。**

**任期を定めた採用の仕組み**は[任期付職員の任期満了後の進路](senko-tachiba-ninkitsuki.html)に整理しています。

**⑤について。**

**元いた団体に限らず、他の団体の募集も対象**になります。

**居住地や勤務地の条件に応じて、選べる範囲が変わります。**

## 確認すること

| 項目 | 確認先 |
|---|---|
| 募集の有無と時期 | **各団体の公表** |
| 要件（年齢、経験の年数） | 募集要項 |
| 選考の方法 | 同上 |
| 採用後の処遇の扱い | 同上、または担当課 |
| 退職手当・共済・年金の通算 | **共済組合、年金事務所** |

**1行目です。**

**募集は、各団体が公表します。**

**人づての情報ではなく、公表されている募集要項を確認**してください。

**5行目について。**

**通算の扱いは制度によります。**

**金額と要件は、共済組合と年金事務所に確認**してください。

**この記事では、金額には触れません。**

## 民間の経験が評価される点

| 経験 | 行政での使いどころ |
|---|---|
| ① 顧客への対応 | 住民・事業者への対応 |
| ② 収支・原価の管理 | 予算、委託の管理 |
| ③ 事業の推進 | 計画の実行、進行の管理 |
| ④ 外部との交渉 | 事業者との協議 |
| ⑤ 民間の実務の理解 | **委託、指定管理、公民の連携** |

**⑤が、経験者を対象とする採用で見られる部分**です。

**行政が民間と組む場面が増えているため、双方を知っている人**が求められることがあります。

**書類には、「発注を受ける側の実務を理解している」**という形で書いてください。

## 戻る前提で辞めないこと

**ここは、はっきり書いておきます。**

| 確認 | 内容 |
|---|---|
| 募集の有無 | **毎年あるとは限りません** |
| 要件 | 年齢や経験の年数が定められます |
| 競争 | 選考を経る必要があります |
| 時期 | 公表の時期は団体による |

**「いつでも戻れる」という前提は、置かないでください。**

**募集があるか、要件を満たすか、選考を通るか。**

**いずれも、その時点で決まります。**

**したがって、転職の判断は、戻ることを前提とせずに行ってください。**

:::insight
「戻れるか」というご質問に対して、**面談でお伝えしているのが「戻る道があることと、戻る前提で動くことは別です」**という点です。**経験者を対象とする採用の枠組みは、多くの団体で設けられています。**ですから、**道がないわけではありません。**ところが、**募集の有無は年によって変わり、要件も団体によって異なります。**「数年民間で経験を積んで、また戻ればよい」と考えて辞めると、**その時点で募集がないという事態**が起こり得ます。ですから、**判断は「戻れなくても納得できるか」で行ってください。**そのうえで、**戻る道があることは、判断を軽くする材料として使えます。**退路が完全に断たれるわけではない、という理解です。そして、**民間で得た経験は、戻った場合にも使えます。**委託や指定管理の相手方の実務を知っている人は、**行政の側でも必要とされています。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 在職中にしておくこと

| 項目 | 内容 |
|---|---|
| 制度の確認 | **退職手当、共済、年金の扱い** |
| 記録 | 担当した業務、件数 |
| 募集の情報 | 経験者の採用の実施の状況 |
| 条件の整理 | 戻る場合の勤務地・職種 |

**1行目です。**

**退職の前に、通算の扱いを確認**してください。

**退職の時期によって扱いが変わることがあります。**

**扱いは**[退職手当はいつ振り込まれるか](senko-taishoku-shikyubi.html)**も併せて確認してください。**

**3行目について。**

**在職中に、経験者を対象とする採用の実施の状況を見ておく**と、見通しが立ちます。

[経験の言い換えから相談する](../apply.html)こともできます。

## 民間での過ごし方

| 項目 | 内容 |
|---|---|
| 実績の記録 | **件数、規模、役割** |
| 資格 | 取得、更新 |
| 分野の一貫性 | 経験がつながる形で |
| 期間 | 要件の年数を意識する |

**4行目です。**

**経験者を対象とする採用では、職務経験の年数が要件となる**ことがあります。

**短期間で移ると、年数が満たせない**場合があります。

**要件を確認したうえで、期間を考えてください。**

**3行目について。**

**分野を頻繁に変えると、経験がつながりにくくなります。**

**戻る場合も、民間で続ける場合も、一貫した分野のほうが説明がしやすくなります。**

## よくある失敗

**1. 「いつでも戻れる」と考える**

**募集があるとは限りません。**

**2. 募集要項を確認しない**

**要件は団体によって異なります。**

**3. 通算の扱いを確認しない**

**退職の時期で変わる**ことがあります。

**4. 戻る前提で転職を決める**

**戻れなくても納得できるか**で判断してください。

**5. 民間での実績を記録しない**

**選考の材料**になります。

**6. 元いた団体だけを見る**

**他の団体の募集**も対象です。

**7. 経験の年数の要件を見ない**

**短期間で移ると満たせない**ことがあります。

**8. 人づての情報で判断する**

**公表されている募集要項**を確認してください。

:::insight
ここまで「戻る」話をしておいて逆のことを言いますが、**戻らずに、行政に関わり続けるという道もあります。**面談で拝見していると、**「行政の仕事がしたいなら、公務員に戻るしかない」と考える方**がいらっしゃいます。ところが、**行政の仕事を民間が担う仕組みは、法律に置かれています。**指定管理者、業務の受託、発注者支援、制度の運用の支援。**相手が行政である仕事は、民間の側に多くあります。**そして、**その領域では、行政の内側を知っている人が要件になります。**予算の年度、議会の時期、決裁の流れ、報告の様式。**これらは、外から入った人には見えにくい。**ですから、**「行政に関わりたい」という気持ちと、「公務員に戻りたい」という選択は、分けて考えてください。**前者であれば、**戻らなくても実現できます。**探し方は[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)に整理しています。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方公務員法第17条の2**は、**職員の採用を競争試験又は選考による**としています。**選考は「競争試験以外の能力の実証に基づく試験」**と定義されています
- **戻る場合も、改めて採用の手続きを経ます。**当然に復職する仕組みではありません
- 枠組みは、**①一般の採用試験 ②経験者を対象とする採用 ③任期を定めた採用 ④会計年度任用 ⑤他の団体**です
- **募集の有無・要件・時期は、各団体の公表**で確認してください
- **退職手当・共済・年金の通算**は、共済組合と年金事務所に確認してください
- **「いつでも戻れる」という前提は置かないでください。**判断は、**戻れなくても納得できるか**で行ってください
- **行政に関わり続けたいだけなら、戻らなくても実現できます**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 経験者を対象とする採用は、どこで調べますか

**各団体のウェブサイトです。**「職員採用」「採用情報」のページに、**募集要項が掲載**されます。**実施の有無、区分、要件、日程**が示されます。なお、**毎年実施されるとは限りません。**また、**職種によって実施の状況が異なります。**在職中に、**関心のある団体の過去数年の実施の状況**を見ておくと、見通しが立ちます。**人づての情報では、要件を取り違える**ことがあります。**必ず、公表されている募集要項を直接確認**してください。**他の団体の募集も対象**になるため、**範囲を広げて見て**ください。

### 民間での経験は、どの程度評価されますか

**募集の区分によります。**経験者を対象とする採用では、**職務経験の年数が要件**として定められていることがあります。そのうえで、**選考では、担当した業務の中身**が見られます。評価されやすいのは、**行政の業務に接続する経験**です。委託や指定管理の受託側の実務、事業の企画と推進、収支の管理、外部との交渉。**「発注を受ける側の実務を理解している」**という点は、**公民の連携の場面で使えます。**書類には、**件数・規模・役割**を書いてください。**扱いは募集要項の選考の方法に示されます。**

### 戻ることを考えながら、民間で働くのは中途半端でしょうか

**中途半端にはなりません。**ただし、**「戻るまでのつなぎ」として働くと、実績が積み上がりません。**民間での経験が評価されるのは、**担当した業務の中身**です。腰を据えて取り組んだ結果が、**戻る場合の材料にもなります。**ですから、**目の前の仕事に取り組むことと、選択肢を持っておくことは両立します。**なお、**要件の年数を意識する**ことは必要です。短期間で移ると、経験の年数が満たせないことがあります。**判断の目安は、募集要項の要件**です。**確認したうえで、期間を考えてください。**そして、**戻らない判断をしても、それは失敗ではありません。**
