農業や食品の分野への転職を考える方から、**こう伺うことがあります。**

**「農業をやりたいわけではないのですが、この分野に関われますか」**

**関われます。**そして、**むしろそちらのほうが道が広い**です。

**この分野は、作る人だけで成り立っているわけではありません。****許可、基準、表示、流通、販売、そして管理部門。**それぞれに仕事があります。

**そして、その多くが法令の手続きと結びついています。**この記事では、**法令の区分から業界の構造を整理し、未経験から入る道筋**を扱います。

## 食品を扱う営業には、許可が要ります

**食品衛生法第55条第1項**です。

> **前条に規定する営業を営もうとする者は、厚生労働省令で定めるところにより、都道府県知事の許可を受けなければならない。**

**その「前条」——第54条**です。

> **都道府県は、公衆衛生に与える影響が著しい営業**（食鳥処理の事業を除く。）**であつて、政令で定めるものの施設につき、厚生労働省令で定める基準を参酌して、条例で、公衆衛生の見地から必要な基準を定め**（後略）

**この2つの条文の関係を見てください。**

**都道府県が条例で施設の基準を定め、その基準を満たす施設について知事が許可する。**

**⚠ そして、許可の窓口は保健所**です。

**保健所で食品営業の許可や監視を担当していた方**は、**この分野の事業者が何を求められているかを、すでに知っています。**

## 農地を動かすにも、許可が要ります

**農地法第3条第1項**です。

> **（農地又は採草放牧地の権利移動の制限）第三条　農地又は採草放牧地について所有権を移転し、又は地上権、永小作権、質権、使用貸借による権利、賃借権若しくはその他の使用及び収益を目的とする権利を設定し、若しくは移転する場**（合には、当事者が農業委員会の許可を受けなければならない。後略）

**農地は、自由に売買できません。**

**つまり、この分野に新しく参入しようとする事業者は、手続きを踏む必要がある**ということです。

**農業委員会の事務を担当していた方**は、**この手続きの中身を知っています。**

**「作る」と「加工・販売する」で、制度も所管も違う**——ここが、この分野を理解する最初の区切りです。

## 業界は、6つに分かれます

| 区分 | 何をするか | 公務員からの入りやすさ |
|---|---|---|
| 生産（農業法人など） | 作物の生産、出荷 | 現場の経験が要る |
| **食品の製造** | 加工、品質の管理、表示 | **管理部門なら入りやすい** |
| **卸・流通** | 集荷、保管、配送、取引 | **契約の経験が効く** |
| 小売・外食 | 販売、店舗の運営 | 管理部門なら入りやすい |
| **地域商社・産地の法人** | 特産品の開発、販路の開拓 | **経験が直結する** |
| **農業・食品のコンサルタント** | 計画、補助の活用、制度の対応 | **経験が直結する** |

**下の2つと、食品の製造の管理部門が、公務員からいちばん自然に移れる領域**です。

## 食品の製造には、管理部門があります

**[未経験から製造業の管理部門に入るには](industry-seizo-mikeiken.html)で扱った構造が、そのまま当てはまります。**

**食品の工場も、工場です。**総務、人事、経理、法務、環境・安全。**そして、食品ならではの職種として、品質保証と表示の管理**があります。

| 職種 | 何をするか | 公務員の経験との重なり |
|---|---|---|
| 品質保証 | 基準への適合、監査への対応、苦情の処理 | **監視・指導の経験** |
| 表示の管理 | 法令に沿った表示の確認 | **基準に当てはめる訓練** |
| 環境・安全 | 排水、廃棄物、労働安全 | **環境部局の経験** |
| 総務・人事・経理 | 一般の管理部門の業務 | そのまま |
| 購買・調達 | 原料の調達、取引先の管理 | **契約の経験** |

**品質保証と表示の管理は、保健所や食品の監視を担当していた方に直結します。**

**⚠ 表示については、複数の法令が関わります。**食品の表示に関する制度は、**所管や制度の区分が分かれている**ため、**応募先が何を扱っているかを確認してください。**

## 許可を出す側から、受ける側へ

**この移り方は、実務として自然です。**

| 役所の側 | 事業者の側 |
|---|---|
| 食品営業の許可の申請を審査する | **申請の書類を作り、提出する** |
| 施設の基準への適合を確認する | 基準を満たす状態を維持する |
| 立入検査・収去検査を行う | **検査を受け、指摘に対応する** |
| 苦情・食中毒の調査を行う | **原因の究明と再発の防止** |
| 農地の権利移動を審査する | 手続きを取る |
| 補助金を交付する | **申請し、実績を報告する** |

**左の列をやってきた方は、右の列で何が求められるかが分かります。**

**とくに、「どこで指摘を受けるか」**です。**これは、外から学ぶのが難しい知識**です。

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 場面 | 効く理由 |
|---|---|
| 許可・届出の手続き | **審査する側の観点を知っている** |
| 監査・立入検査への対応 | **検査する側にいた** |
| 基準への適合の確認 | 要件に当てはめる訓練 |
| 苦情・事故への対応 | **調査の手順を知っている** |
| 補助金の申請と実績の報告 | 交付する側にいた |
| 記録の整備と保存 | 後から検証される前提の書類 |
| 産地・生産者との調整 | **農政の部署の経験** |

**効きにくい場所**

| 場面 | 効きにくい理由 |
|---|---|
| 原価と歩留まりの管理 | **予算の執行とは見る方向が違う** |
| 販路の開拓 | 売り込む仕事は役所に少ない |
| 価格の交渉 | 値決めの判断を自分でする |
| 現場の作業の段取り | 時間単位で動く感覚 |
| 季節と天候に合わせる | **計画が自然条件で崩れる** |

**最後の1つが、この分野の特徴**です。

**農産物は、天候で収量も時期も変わります。**計画どおりに進まないことが前提の仕事です。

:::insight
面談で拝見していて、**この分野を受ける方がいちばん取りこぼしているのが「食中毒や苦情の調査をした経験」**です。皆さん、**「衛生の監視をしていました」と一言で片づけて**しまわれます。ところが、**食品の事業者にとって、事故が起きたときの対応は、会社の存続に関わります。**そして、**その場面で何が起きるかを知っている人は、社内にほとんどいません。**保健所の側にいた方は、**調査の手順を知っています。**いつ、誰に、何を聞き取るか。どの記録が求められるか。検体をどう扱うか。公表はどう行われるか。**さらに重要なのは、「事故が起きる前に、何を揃えておけば説明できるか」を知っていること**です。原料の受入れの記録、加熱の温度と時間の記録、従業員の健康の確認の記録。**これらが揃っていないと、原因を絞り込めません。**そして、**揃えるのは事故の前でなければ間に合いません。**ですから、職務経歴書には、**「衛生監視」ではなく「食品営業施設の監視指導を年間◯件、有症苦情の調査を◯件担当」**と書いてください。**そして面接では、「事故が起きる前に揃えておくべき記録」を語れるようにしておいてください。**これが語れる方は、**品質保証の職種で、その場で評価が変わります。**
:::

## 入り方の手順

| 順 | やること | 目安 |
|---|---|---|
| 1 | 自分が扱った**法令の名前**を書き出す | 30分 |
| 2 | **職種名で求人を検索する**（品質保証、品質管理、総務など） | 1時間 |
| 3 | 出てきた会社の**扱う品目と工場の場所**を確認する | 1時間 |
| 4 | **地域商社・産地の法人**の募集も探す | 1時間 |
| 5 | 求人票の**応募条件を5件読み比べる** | 1時間 |
| 6 | **勤務地と勤務の時間帯**を確認する | 20分 |

**1つ目が効きます。**食品衛生法、農地法、食品表示に関する法令、農薬に関する法令、家畜に関する法令。**扱った法令が、そのまま検索の手がかりになります。**

**4つ目を飛ばさないでください。**[未経験から観光・地域振興に入るには](industry-kanko-mikeiken.html)と同じで、**地域の法人の募集は一般の求人サイトに出ないことがあります。**

[経験の言い換えから相談する](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担です）。

## 面接で聞かれやすいこと

| 聞かれること | 何を見られているか |
|---|---|
| どの法令を、どの立場で扱っていましたか | **経験の具体性** |
| 立入検査では、何を見ていましたか | **受け入れる側に回れるか** |
| 事故が起きたときの対応の経験はありますか | **品質保証の中核** |
| 現場の方と話をした経験はありますか | 工場での立ち位置 |
| 勤務地が工場でも構いませんか | **前提の確認** |

**2つ目は、指摘した話ではなく、見ていた観点**にしてください。「記録が揃っているか、実際の運用が手順書と一致しているか、変更があったときに確認されているか」。**これは、そのまま事業者側の自主点検の観点になります。**

**5つ目は、正直に答えてください。**食品の工場は、**産地や物流の拠点の近く**にあることが多く、**都市部から離れている**ことがあります。

:::insight
ここまで入り方の話をしてきましたが、**この分野を検討するときに、見ておいていただきたい点**があります。**この分野は、いま制度の変わり目にある**ということです。衛生管理の手法の見直し、表示の制度の整備、輸出に向けた基準への対応、人手不足への対応。**事業者の側で、やらなければならないことが増えています。**これは、**未経験から入る方にとっては追い風**です。理由は、**「これまでのやり方を知っている人」だけでは対応できない課題が増えているから**です。制度の改正に合わせて、**手順書を作り直す、記録の取り方を変える、社内の教育をやり直す。**この種の仕事は、**現場からの登用で育った人には経験の無い領域**です。一方、**役所の側で制度の改正に合わせて要綱と様式を作り直してきた方**にとっては、**やったことのある作業**です。ですから、**「未経験だから不利」と考えないでください。**面接で聞けます。「制度の改正への対応は、どなたが担当されていますか」。**答え方で、その会社の構えが分かります。**そして、**いま動くかどうかを決めきらないまま、この分野の動きを見ておく**だけでも意味があります。在職のまま、情報収集だけのご相談も承っています。
:::

## まとめ

- **この分野は、作る人だけで成り立っていません。**許可、基準、表示、流通、販売、管理部門にそれぞれ仕事があります
- **食品衛生法第54条**は、**都道府県が条例で施設の基準を定める**ことを規定し、**第55条第1項**は、**その営業を営もうとする者が都道府県知事の許可を受けなければならない**と定めています。⚠ **窓口は保健所**です
- **農地法第3条第1項**は、**農地又は採草放牧地の権利の移転・設定に、農業委員会の許可**を求めています。**農地は自由に売買できません**
- **「作る」と「加工・販売する」で、制度も所管も違います**
- 業界は、**生産／食品の製造／卸・流通／小売・外食／地域商社・産地の法人／コンサルタント**に分かれます
- **公務員から入りやすいのは、食品の製造の管理部門、地域商社・産地の法人、コンサルタント**です
- **品質保証と表示の管理**は、**保健所や食品の監視を担当していた方に直結**します
- ⚠ **「衛生監視」を一言で片づけないでください。****「事故が起きる前に揃えておくべき記録」を語れる方は、その場で評価が変わります**
- ⚠ **勤務地が産地や物流の拠点の近くになることがあります。**早い段階で確認してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 食品や農業の部署にいたことがありません

**総務・人事・経理・法務から探してください。**食品の会社の管理部門は、**他の業種の管理部門と、仕事の中身が大きく違うわけではありません。**行政での対応する経験が、そのまま材料になります。そのうえで、**この分野ならではの部分**を押さえておくと話が通じます。**衛生の管理に関する手順がある、表示の確認が要る、季節で生産量が変わる。**面接で「食品の工場では、衛生の管理の手順の運用があると伺っています」と言えるだけで、**調べてきた人**として受け取られます。また、**契約や委託の経験**があれば、**卸・流通の分野や、購買・調達の職種**が候補になります。

### 農業委員会の事務をしていました。使えますか

**使えます。**⚠ とくに、**農地の権利移動や転用の手続き**を扱っていた方は、**農業法人や、農地を使う事業者の側**で経験が効きます。新規に参入する事業者にとって、**農地法の手続きは最初の関門**です。どういう申請が通り、どこで止まるかを知っている人は、**社内にほとんどいません。**また、**担い手の育成や、経営に関する制度**を担当していた方は、**補助の制度の活用**に直接つながります。書き方は、**「農地法にもとづく権利移動の許可の審査を年間◯件」**と、**法令名と件数**を入れてください。**「農政の事務」では伝わりません。**

### 技術職です。土木や建築の経験は使えますか

**使えます。**食品の工場は**建物と設備の集合体**で、**衛生の管理の観点から、施設の構造に求められる条件**があります。役所で**工事の発注と監督**をしていた方なら、**仕様書の作成、業者との協議、検査**の経験がそのまま重なります。また、**排水や廃棄物に関する届出**を扱っていた方は、**工場側の対応する業務に直接つながります。**農業の分野では、**農業用の施設、用排水路、ほ場の整備**に関わる職もあります。探し方は、**「設備管理」「施設管理」「工務」**といった職種名です。**食品や農産物の知識は、入ってから覚える前提**で構いません。
