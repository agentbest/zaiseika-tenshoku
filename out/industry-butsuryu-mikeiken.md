物流への転職を検討される方から、**こう伺うことがあります。**

**「トラックを運転するわけではないので、何をする仕事か分かりません」**

**もっともな疑問です。**「物流」という言葉が指す範囲が広く、**運ぶ仕事だけを指しているわけではない**からです。

**整理の手がかりは、法令にあります。****この業界は、許可や登録で区切られていて、その区切りがそのまま事業の種類**になっています。

この記事では、**法令の区分から業界の構造を整理し、未経験から入る道筋**を扱います。

## 運ぶ事業には、許可が要ります

**貨物自動車運送事業法第3条**です。

> **（一般貨物自動車運送事業の許可）第三条　一般貨物自動車運送事業を経営しようとする者は、国土交通大臣の許可を受けなければならない。**

**短い条文ですが、この業界の性格を決めています。**

**「許可を受けなければならない」**です。**誰でも始められる事業ではありません。**

**許可の制度がある**ということは、**許可の要件があり、その要件を満たし続ける義務があり、行政による監査がある**ということです。

**役所で許認可を扱ってきた方なら、この構造の意味がすぐ分かるはずです。**

## 預かる事業には、登録が要ります

**倉庫業法第3条**です。

> **（登録）第三条　倉庫業を営もうとする者は、国土交通大臣の行う登録を受けなければならない。**

**こちらは登録**です。

**「運ぶ」と「預かる」で、別の制度になっている**——ここが、物流業界を理解する最初の区切りになります。

| 機能 | 根拠 | 事業の呼ばれ方 |
|---|---|---|
| 運ぶ（自動車） | **貨物自動車運送事業法の許可** | 運送会社、トラック事業者 |
| 預かる | **倉庫業法の登録** | 倉庫会社 |
| 運ぶ＋預かる＋管理 | 両方 | **総合物流** |
| 荷主に代わって手配する | 事業の形による | 利用運送、物流の企画 |
| 荷主の中で物流を担う | — | **荷主企業の物流部門** |

**最後の行を見落とさないでください。**

**製造業や小売業の中に、物流を担当する部署があります。**ここも、**物流の仕事**です。**そして、公務員から入りやすいのは、この領域を含みます。**

## 物流の仕事は、機能で分かれます

| 職種 | 何をするか | 未経験からの入りやすさ |
|---|---|---|
| 運行管理 | **乗務員の勤務・健康の管理、点呼、記録** | **入りやすい** |
| 倉庫の運営管理 | 入出庫、在庫、作業の割り当て | 入りやすい |
| 安全・コンプライアンス | **監査への対応、法令の遵守の体制** | **経験が直結する** |
| 総務・人事 | 採用、労務、就業規則 | **入りやすい** |
| 経理 | 決算、運賃の精算 | **入りやすい** |
| 営業・提案 | 荷主への提案、料金の設定 | 経験が要る |
| 物流の企画・改善 | 拠点の配置、輸送の経路、在庫の設計 | 分析の経験が効く |
| 荷主側の物流部門 | 委託先の管理、コストの管理 | **契約の経験が効く** |

**運行管理と安全の分野は、法令に紐づく仕事**です。**記録を残し、基準に沿って運用し、監査を受ける。****この構造は、役所の仕事と同じ**です。

## 許可を出す側から、受ける側へ

**この移り方は、実務として自然です。**

| 役所の側 | 事業者の側 |
|---|---|
| 許可・登録の申請を審査する | **申請の書類を作り、提出する** |
| 要件を満たしているかを確認する | 要件を満たす状態を維持する |
| 監査・立入を行う | **監査を受け、指摘に対応する** |
| 報告を求める | 報告を作成する |
| 変更の届出を受ける | **変更のたびに手続きを取る** |

**左の列をやってきた方は、右の列で何が求められるかが分かります。**

**とくに、運輸支局や、自治体で道路・交通に関わる事務を担当していた方**は、**この業界の手続きの構造を、すでに知っています。**

**⚠ ただし、貨物自動車運送事業の許可は国土交通大臣の権限**です。**自治体の事務ではありません。**ですから、**「同じ許認可を扱っていた」という形にはなりません。**

**書くべきなのは、「許認可という仕組みの中で、審査する側にいた」という点**です。**制度が違っても、審査と監査の構造は共通しています。**

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 場面 | 効く理由 |
|---|---|
| 監査・立入への対応 | **検査する側にいた** |
| 記録の整備と保存 | **後から検証される前提の書類の作り方** |
| 社内の規程・手順の整備 | 要綱を条文の形で書いてきた |
| 労務の管理 | 勤務時間の管理と、規程にもとづく運用 |
| 委託先の管理 | **契約と、履行の確認の経験** |
| 行政への手続き | 様式のどこでつまずくかを知っている |
| 苦情・近隣対応 | 窓口で受けてきた |

**効きにくい場所**

| 場面 | 効きにくい理由 |
|---|---|
| 料金の設定と交渉 | **値決めの判断を自分でする** |
| 荷主への提案 | 売り込む仕事は役所に少ない |
| 現場の作業の段取り | **時間単位で動く現場の感覚** |
| 突発の事態への即応 | 事故・渋滞・天候で計画が崩れる |
| 現場の作業者との距離の取り方 | 相手の職種が違う |

**4つ目が、この業界の特徴**です。

**物流は、計画どおりに進まないことが前提**の仕事です。**事故、渋滞、天候、設備の故障。**そのたびに、**手配をやり直します。**

**役所の仕事は、締切は厳しくても、当日に計画が崩れることは多くありません。**ここは、**慣れが要る部分**です。

**ただし、災害対応や、選挙の事務、感染症の対応を経験した方**は、**「当日に計画が崩れる」状況を知っています。**面接で、その経験を出してください。

**5つ目も、慣れが要ります。**物流の現場では、**乗務員や作業者の方と、管理の側が日常的に接します。**役所で、**出先機関や現業の部署と調整してきた方**には、掴みやすい距離感です。一方、**本庁の内部の部署だけを経験してきた方**は、**最初に戸惑う**ことがあります。**構えとしては、「決めたことを伝える」より「先に聞く」**ほうが、この業界では早く受け入れられます。

:::insight
面談で拝見していて、**この業界でいちばん需要と供給がずれているのが「運行管理」**です。運行管理者は、**乗務員の勤務の割り当て、点呼、健康状態の確認、記録の保存**を担う仕事で、**法令に沿って運用しなければならない**部分が多くあります。ところが、**この仕事の担い手が、恒常的に足りていません。**理由の一つは、**現場からの登用が中心で、事務の経験を持つ人が入ってこないこと**です。結果として、**記録の管理が場当たりになり、監査で指摘を受ける**という循環が起こりやすい。そこに、**記録を前提に動く習慣を持った人**が入ると、**部署の動き方が変わります。**そして、公務員の方が持っている**「勤務時間を規程にもとづいて管理する」経験**は、この仕事の中核と直接重なります。役所で、**超過勤務の命令と実績の管理、休暇の承認、職員の健康管理の手続き**を担当していた方は、**やることの構造をすでに知っています。**⚠ なお、**運行管理者として選任されるには資格の要件があります。**要件と試験については、**所管する国土交通省や試験を実施する機関の公表を確認してください。**当社が確認していない内容は、この記事には載せていません。**資格が無い状態で補助の立場から入る道**もあります。
:::

## 入り方の手順

| 順 | やること | 目安 |
|---|---|---|
| 1 | 自分の機能を3つ書き出す（管理、契約、労務、記録など） | 30分 |
| 2 | **職種名で求人を検索する**（運行管理、倉庫管理、総務など） | 1時間 |
| 3 | 出てきた会社の**事業の種類**を確認する（運送か倉庫か両方か） | 1時間 |
| 4 | **荷主側の物流部門**の求人も見る | 30分 |
| 5 | 求人票の**応募条件を5件読み比べる** | 1時間 |
| 6 | **拠点の場所と勤務の時間帯**を確認する | 30分 |

**4つ目を飛ばさないでください。**

**製造業や小売業の中にある物流の部署**は、**物流会社とは働き方が違います。**委託先の管理、コストの管理、在庫の設計が中心で、**現場の作業からは距離があります。****契約や委託の管理をしてきた方には、こちらのほうが合う**ことがあります。

**6つ目も重要です。**物流の拠点は、**高速道路の出入口や港の近く**に置かれることが多く、**都市部の中心から離れている**ことがあります。**また、早朝や夜間の勤務がある職種**もあります。

## 面接で聞かれやすいこと

| 聞かれること | 何を見られているか |
|---|---|
| 計画が崩れたときに、どう動きましたか | **突発への対応** |
| 現場の方と話をした経験はありますか | **立ち位置の理解** |
| 早朝や夜間の勤務は可能ですか | **前提の確認** |
| 記録の管理をした経験はありますか | **この業界の中核** |
| 物流の経験がないが、大丈夫ですか | 学ぶ構え |

**1つ目は、災害・選挙・感染症の対応の経験がある方には、語れる質問**です。

**答え方は、慌てなかったという話ではなく、何を優先したか**にしてください。「まず、動かせない期限を確認しました。次に、人手が足りない部分を洗い出して、応援の要請を出しました」。**優先順位の付け方が見られています。**

**3つ目は、正直に答えてください。**職種によって、**勤務の時間帯がまったく違います。**入ってから困るのはご本人です。

:::insight
ここまで入り方の話をしてきましたが、**この業界を検討するときに、見ておいていただきたい点**があります。**この業界は、いま制度の変わり目にある**ということです。労働時間の規制、再配達の削減、共同配送、自動化された倉庫。**現場の作業の方法そのものが、見直されている最中**です。これは、**未経験から入る方にとっては、むしろ追い風**になります。理由は、**「これまでのやり方を知っている人」だけでは対応できない課題が増えているから**です。制度の改正に合わせて、**規程を作り直す、記録の取り方を変える、委託先との契約を見直す。**この種の仕事は、**現場からの登用で育った人には、経験の無い領域**です。一方、**役所の側で制度の改正に合わせて要綱と様式を作り直してきた方**にとっては、**やったことのある作業**です。ですから、**「未経験だから不利」と考えないでください。**確認していただきたいのは、**その会社が、変化にどう向き合っているか**です。面接で聞けます。「制度の改正への対応は、どなたが担当されていますか」。**答え方で、その会社の構えが分かります。**そして、**いま動くかどうかを決めきらないまま、この業界の動きを見ておく**だけでも意味があります。在職のまま、情報収集だけのご相談も承っています。
:::

## まとめ

- **物流は「運ぶ」だけの業界ではありません。**法令の区分が、そのまま事業の種類になっています
- **貨物自動車運送事業法第3条**は、**一般貨物自動車運送事業を経営しようとする者に、国土交通大臣の許可**を義務づけています
- **倉庫業法第3条**は、**倉庫業を営もうとする者に、国土交通大臣の行う登録**を義務づけています
- **「運ぶ」と「預かる」で別の制度**です。**両方を担う会社、荷主企業の中の物流部門**もあります
- 未経験から入りやすいのは、**運行管理・倉庫の運営管理・安全・総務・人事・経理**です
- **許可を出す側から受ける側へ**という移り方は自然です。ただし**貨物自動車運送事業の許可は国の権限**なので、**「同じ許認可を扱っていた」とは書けません**
- 効きにくいのは、**料金の設定、提案、現場の段取り、突発への即応**です。**災害・選挙・感染症の対応の経験**は、突発への対応の材料になります
- ⚠ **荷主側の物流部門も見てください。**契約と委託の管理が中心で、**働き方が物流会社とは違います**
- ⚠ **拠点の場所と勤務の時間帯**を、早い段階で確認してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 運転免許は必要ですか

**職種によります。**管理や事務の職種では、**要件になっていない募集もあります。**ただし、**拠点が公共交通機関から離れている**ことが多いため、**通勤の手段として必要になる**場合があります。また、**複数の拠点を回る職種**では、要件に挙げられていることがあります。判断の目安は、**求人票の応募条件**です。書かれていなければ、**選考の場で確認すれば足ります。**なお、**大型の免許や、フォークリフトの資格**は、**現場の作業をする職種の要件**であって、**管理や事務の職種では通常求められません。**募集の職種を確認してから判断してください。

### 早朝や夜間の勤務は、必ずありますか

**職種と拠点によります。**現場の運営に直接関わる職種では、**荷物の動く時間帯に合わせる**必要があります。一方、**総務・人事・経理・企画**のような職種では、**通常の時間帯**であることが多いです。確認のしかたは、面接で**「この職種の方の、標準的な勤務の時間帯を教えてください」**と聞くことです。あわせて、**交替制があるかどうか**も確認してください。なお、**荷主側の物流部門**は、**荷主企業の勤務時間に沿う**ため、この点では負担が軽いことがあります。生活の条件を優先する場合は、そちらも候補に入れてください。

### 年齢が高めです。未経験の業界に移れますか

**職種によります。****運行管理、安全・コンプライアンス、総務、経理**のような機能の職種では、**行政での実務の年数が、そのまま経験として読まれます。**とくに、**記録の管理と、規程にもとづく運用**を長く担当してきた方は、**年数が不利になりにくい**です。理由は、この業界で**事務の経験を持つ人の応募が少ないから**です。ただし、**役職の名称は、そのままでは評価に結びつきません。**「係長を◯年」ではなく、**「◯人の勤務時間の管理と、年間◯件の手続きを担当」**という形で、**担った範囲と件数**で書いてください。応募する職種を機能で選ぶと、**年齢より経験の中身が見られます。**
