**財政や会計を担当してきた方から、「どこまで取る意味があるか」**というご相談を伺います。

**会計帳簿の作成は、法律上の義務**です。

この記事では、**その前提**と、**効いてくる場面**を扱います。

**⚠ 試験の内容・級・実施の方法は、実施する団体の公表を確認してください。****この記事では、個別の内容には触れません。**

## 会計帳簿の作成は、義務として定められています

**会社法第432条第1項**です。

> **株式会社は、法務省令で定めるところにより、適時に、正確な会計帳簿を作成しなければならない。**

**同条第2項**です。

> **株式会社は、会計帳簿の閉鎖の時から十年間、その会計帳簿及びその事業に関する重要な資料を保存しなければならない。**

**作成と保存が、義務として定められている**ということです。

**つまり、会社では、日々の取引が帳簿に記録される**ことになります。

**簿記は、この記録の仕組み**です。

**したがって、会社の数字を扱う職種では、前提となる知識**になります。

**行政の会計とは、記録の考え方が異なります。**

**扱いは**[財務諸表の読み方｜公会計との違いから入る](skill-zaimu.html)**に整理しています。**

## 効いてくる転職先

| 領域 | 使いどころ |
|---|---|
| ① 経理・財務 | **日々の記録、決算の補助** |
| ② 管理部門 | 予算の管理、実績の集計 |
| ③ 事業の企画 | 計画と実績の差異 |
| ④ 会計の事務の受託 | 記帳、集計 |
| ⑤ 自治体が相手の事業 | **公会計と企業会計の両方** |

**⑤について。**

**自治体を顧客とする会社では、相手が公会計、自社が企業会計**という状況になります。

**両方を踏まえて考えられる人**は、そこで必要とされます。

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 行政の経験との重なり

| 行政での経験 | 重なる部分 |
|---|---|
| ① 予算の編成 | **見積りの根拠の確認** |
| ② 執行の管理 | 進捗と残額の把握 |
| ③ 決算の作成 | 実績の集計 |
| ④ 契約と支払 | 取引の流れ |
| ⑤ 財産の管理 | 資産の把握 |
| ⑥ 監査への対応 | 記録と根拠 |

**④が、簿記の理解につながります。**

**契約し、履行を確認し、支払う。**

**この流れは、会社では取引として記録されます。**

**行政の事務で見てきた流れが、記録の形に置き換わる**と考えてください。

## どこまで取るか

| 目的 | 必要な範囲 |
|---|---|
| 会社の資料を読む | **基礎の考え方で足ります** |
| 集計や報告を担う | 中位の範囲が役立ちます |
| 経理を職務とする | 実務と併せて必要になります |

**求人によって、求められる範囲が違います。**

**「簿記の知識」と書かれていても、どの水準かは求人ごとに異なります。**

**求人票の応募条件と、仕事内容の欄を確認**してください。

**読み方は**[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)**に整理しています。**

:::insight
簿記について、**面談でお伝えしているのが「実務と併記してください」**という点です。**資格だけを書くと、知識として読まれます。**ところが、**予算の編成や執行の管理を担当してきた方**であれば、**数字を扱う実務の経験**があります。**この2つを重ねると、意味が変わります。**「年間約◯億円の事業予算の編成と執行の管理を担当。見積りの根拠を確認し、四半期ごとに執行の状況を確認」。**そのうえで資格を併記すると、「数字を扱ってきた人が、企業会計の枠組みも学んでいる」と読まれます。**そして、**採用する側が知りたいのは、入社後にどう動けるか**です。**記録の形は違っても、数字を確認する習慣は同じ。**この点を書いてください。**資格の級だけを並べても、動き方は伝わりません。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 書き方の例

**悪い例**

> 簿記の資格を取得しました。

**良い例**

> ◯◯課において、**年間約◯億円の事業予算の編成と執行の管理**を担当。**◯課・◯件の要求について、見積りの根拠と積算の内容を確認。**執行の状況を**四半期ごとに確認し、補正の要否を整理。**決算にあたり、**実績を集計のうえ、成果を説明する資料を作成。****（資格の欄）◯年に取得**

**資格の欄と、職務の欄が分かれています。**

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 取る前に考えること

| 確認すること | 内容 |
|---|---|
| ① 応募したい求人の条件 | **記載があるか、どの水準か** |
| ② 実務で書ける材料 | 予算、執行、決算 |
| ③ 目的 | 読むためか、職務とするためか |
| ④ 期限 | 応募の時期に間に合うか |
| ⑤ 次の段階 | 続けて学ぶ予定があるか |

**②を先に並べてください。**

**書ける材料があるなら、受験より書類の作成が先**です。

**なお、取れば転職できる、という関係にはありません。**

**何を確認し、どう管理したか**が、評価の対象です。

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 実績の整理 | **予算の規模、担当した事業の数** |
| 確認の手順の整理 | 何を見てきたか |
| 学習の計画 | 繁忙期を避けて |
| 求人を読む | 週に30分 |

**3行目です。**

**予算の編成や決算の時期は、学習が止まりやすい**です。

**年間で取れる時間を、先に見積もってください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 担当した規模 | **予算の額、事業の数** |
| 見積りの確認 | 何を見たか |
| 公会計との違い | **理解を示す** |
| 学習の状況 | 続けているか |
| できる範囲 | 正確に、限定して |

**3行目です。**

**違いを説明できると、適応の見通しが伝わります。**

**なお、特定の事案が分かる説明は避けてください。**

## 記録の考え方の違い

**公会計と企業会計では、記録の考え方が異なります。**

| 項目 | 公会計 | 企業会計 |
|---|---|---|
| 記録の単位 | **歳入・歳出** | 取引ごとの仕訳 |
| 時点 | 現金の動きが中心 | **発生した時点** |
| 見るもの | 予算との対比 | 損益と財政状態 |
| 期間 | 会計年度で独立 | 継続を前提 |
| 資産・負債 | 別に管理 | **一覧で把握** |

**2行目が、最も戸惑う部分**です。

**代金を支払った時点ではなく、取引が生じた時点で記録する**という考え方です。

**行政では、支出の手続が完了した時点で処理**してきたはずです。

**この違いを理解すると、決算の数字の読み方が変わります。**

**そして、面接では、この違いを説明できると適応の見通しが伝わります。**

**「同じです」と言わず、違いを踏まえていると示してください。**

## よくある失敗

**1. 資格だけを書く**

**実務と併記**してください。

**2. 予算の規模を書かない**

**扱った数字の大きさ**が伝わりません。

**3. 見積りの確認を書かない**

**原価の妥当性の確認**にあたります。

**4. 公会計との違いに触れない**

**適応の見通し**が伝わりません。

**5. どの水準が必要かを確認しない**

**求人ごとに違います。**

**6. 繁忙期を計算に入れない**

**学習が止まります。**

**7. できる範囲を広く書く**

**入社後に困ります。**

**8. 取れば転職できると考える**

**何を確認し管理したか**が評価の対象です。

:::insight
ここまで「実務が先」という話をしておいて逆のことを言いますが、**学ぶと、行政の数字の見え方も変わります。**面談で拝見していると、**予算と決算を扱ってきたのに、資産と負債を一覧で見る習慣がない方**がいらっしゃいます。公会計では、**歳入歳出の管理が中心**になるためです。簿記を学ぶと、**「持っているもの」と「負っているもの」を並べて見る**という考え方が入ります。**この視点は、在職中の業務でも使えます。**公有財産、地方債、基金。**これらを並べて見ると、見え方が変わります。**ですから、**転職の材料としてだけでなく、いまの業務の理解を深める手段としても位置づけてください。****この順序であれば、途中で止めても損になりません。**そして、**結果として書類に書ける材料が増えます。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **会社法第432条**は、**適時に、正確な会計帳簿を作成すること**と、**閉鎖の時から十年間の保存**を義務づけています
- **簿記は、この記録の仕組み**です。会社の数字を扱う職種では前提となる知識になります
- 効くのは、**経理・財務、管理部門、事業の企画、会計の事務の受託、自治体が相手の事業**です
- **行政の契約と支払の流れ**が、会社では取引として記録されます
- **どの水準が必要かは、求人ごとに違います。**応募条件を確認してください
- **資格だけを書かず、実務と併記**してください
- **学ぶと、行政の数字の見え方も変わります**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 会計の担当ではありませんでした

**数字を扱った経験で書いてください。**予算の要求、執行の管理、契約と支払、実績の集計。**これらは、どの部署でも担っている**ことがあります。書き方は、**「担当する事業の予算約◯千万円について、要求の資料を作成し、執行の状況を管理」**という形です。**規模が小さくても、工程は同じ**です。なお、**数字の確認の習慣**があれば、それも材料です。「支出の前に根拠の資料と突き合わせる手順を整備」。扱いは[Excel｜民間で最初に問われる水準はどこか](skill-excel.html)にも整理しています。

### 実務の経験なしで、経理に移れますか

**求人の条件によります。**「経理の実務経験◯年以上」が必須の求人では、**資格では代えられません。**一方、**「未経験可」「業界経験不問」**と書かれている求人や、**管理部門の一般の事務**では、**資格と数字を扱った経験で応募できる**ことがあります。判断の目安は、**求人票の「必須」の欄**です。なお、**自治体を顧客とする会社**では、**公会計の理解が求められる**場面があり、**行政の経験が直接評価される**ことがあります。読み方は[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。

### 学習の順序に決まりはありますか

**基礎から進めるのが一般的です。**ただし、**どこまで進めるかは目的によります。**会社の資料を読むためであれば、**基礎の考え方で足りる**ことがあります。一方、**経理を職務とする**のであれば、**実務と併せて必要**になります。**⚠ 級の構成や出題の範囲は、実施する団体の公表を確認**してください。**この記事では触れません。**なお、**応募の時期が近い場合は、優先順位を下げて**ください。扱いは[選考スケジュールの組み方](senko-sagasu-schedule.html)に整理しています。
