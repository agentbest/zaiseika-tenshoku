観光・地域振興を検討される方から、**こう伺うことがあります。**

**「観光の実務を知らないので、評価されないのではないでしょうか」**

**そうではありません。**この分野が足りていないのは、**観光の知識を持つ人ではなく、制度の手続きを回せる人**です。

**理由は、事業者と地域の側が何を義務として負っているかを見れば分かります。**この記事では、**そこから逆算して、どの経験が評価されるか**を扱います。

業界の構造は[未経験から観光・地域振興に入るには](industry-kanko-mikeiken.html)、選考の進み方は[観光・地域振興の選考フローと、面接で見られている観点](industry-kanko-senko.html)にあります。

## 事業者には、続けて満たすべき義務があります

**旅館業法第4条第1項**です。

> **営業者は、旅館業の施設について、換気、採光、照明、防湿及び清潔その他宿泊者の衛生に必要な措置を講じなければならない。**

**同条第2項**は、**この措置の基準を都道府県が条例で定める**と規定しています。

**注目していただきたいのは、この義務が「許可を取るとき」だけのものではない**という点です。

**営業を続けている間、ずっと満たし続けなければなりません。**

**[未経験から観光・地域振興に入るには](industry-kanko-mikeiken.html)で扱った旅館業法第3条**が**許可**を定め、**第4条**が**続けて満たすべき措置**を定めている。**この2段構えが、この分野の事業の性格**です。

**保健所で旅館業の監視をしていた方**は、**何を見られるかを知っています。**

## 地域の側にも、法律上の位置づけがあります

**観光立国推進基本法第4条第1項**です。

> **（地方公共団体の責務）第四条　地方公共団体は、基本理念にのっとり、観光立国の実現に関し、国との適切な役割分担を踏まえて、自主的かつ主体的に、その地方公共団体の区域の特性を生かした施策を策定し、及び実施する責務を有する。**

**「施策を策定し、及び実施する責務」**です。

**つまり、自治体は観光に関する施策を作り、実施しなければならない。****そして、その実施の多くは、観光協会や地域の法人への補助や委託という形をとります。**

**この構造から、次のことが言えます。**

| 自治体の側 | 地域の法人の側 |
|---|---|
| 施策を策定する | **施策に沿った事業を提案する** |
| 補助を交付する | **申請し、実績を報告する** |
| 委託する | **仕様に沿って実施し、完了を報告する** |
| 計画の進捗を検証する | **数字を出して説明する** |

**右の列を担える人**が、**この分野では足りていません。**

**理由は、観光への関心から入ってくる方が多く、補助や委託の実務を知っている人が少ないから**です。

## 評価される経験は、5つに整理できます

| 経験 | この分野での使われ方 | なぜ評価されるか |
|---|---|---|
| ① 補助金の交付・審査 | 補助の申請と実績の報告 | **交付する側の観点を知っている** |
| ② 委託の発注・検査 | 受託事業の実施と完了報告 | **仕様書の読み書きができる** |
| ③ 計画の策定 | 事業の設計、計画への位置づけ | **策定の手順を知っている** |
| ④ 許認可・監視 | 施設の基準への適合の確認 | **旅館業法第4条の措置を知っている** |
| ⑤ 会議体・行事の運営 | 理事会・総会、催事の運営 | 段取りを組める |

**①と②が、いちばん求められています。**

**この分野の組織は、補助と受託が財源の柱**であることが多く、**申請書と報告書を書ける人がいないと、事業が回りません。**

**そして、この書類は、行政の側が読んで判断します。****行政が何を見るかを知っている人が、いちばん通る申請書を書けます。**

**④は、宿泊や飲食に関わる職種で効きます。**保健所で**旅館業や食品営業の許可・監視**を担当していた方は、**事業者側の対応に直接つながります。**

## 言い換えの表

**職務経歴書に、役所の言葉のまま書かないでください。**

| 役所での言い方 | この分野に伝わる言い方 |
|---|---|
| 補助金の交付決定 | **申請の審査、要件の確認、実績報告の検査** |
| 補助事業の実績報告の確認 | 事業の成果と経費の対応の確認 |
| 業務委託の契約事務 | **仕様の作成、履行の確認、完了検査** |
| 観光の計画の策定 | 現状の分析、目標の設定、施策の組み立て |
| 旅館業・食品営業の許可の審査 | **施設の基準への適合の確認** |
| 立入検査・監視指導 | **現地での運用状況の確認と是正の要求** |
| 行事・イベントの実施 | **企画、出展者の選定、会場の構成、告知** |
| 審議会の庶務 | 会議体の招集・議事・記録の運営 |
| 統計・調査の事務 | 調査の設計、集計、報告 |

**⚠ 件数と規模を必ず入れてください。**「補助金の交付」ではなく**「年間◯件、総額◯円規模の補助の審査」**です。

**⚠ 金額は、公表されている範囲で書けます。**予算書・決算書は公表されているため、**自分が担当した事業の規模は示せます。**内部の事情や、特定の事業者に関する情報は書かないでください。

## 評価されにくい経験

**正直に書いておきます。**

| 経験 | 評価されにくい理由 |
|---|---|
| 施策の提案 | **課題はすでに分かっている** |
| 庁内の根回しの経験 | 相手も組織の形も違う |
| 前例の踏襲を徹底した実績 | 少人数で判断する場面が多い |
| 在籍年数そのもの | 年数より、何を担ったか |
| 役職の名称 | **対応する段階が組織側に無い** |

**1つ目について、もう一度**。

**[観光・地域振興の選考フローと、面接で見られている観点](industry-kanko-senko.html)でも触れましたが、この分野の組織は「課題は分かっているが手が足りない」という状態にあります。**

**「何をしたいか」ではなく「何を引き受けられるか」**を書いてください。

**5つ目についても補足します。**役職の名称が効かないのは、**組織の段階が役所と対応していないから**です。職員が数名という法人では、**係長も課長もありません。**書くなら、**「◯人の事務の進行を管理し、年間◯件を処理した」**という形で、**担った範囲と件数**にしてください。**段階の名前は、読む側に情報を渡しません。**

:::insight
面談で拝見していて、**この分野を受ける方がいちばん取りこぼしているのが「補助金を出す側だった経験」**です。皆さん、**「補助金の事務をしていました」と一言で片づけて**しまわれます。ところが、**この分野の組織にとって、補助の申請書は収入に直結します。**通らなければ、その事業は実施できません。そして、**申請書が通らない理由は、たいてい書き方にあります。**事業の目的と実施の内容が対応していない、経費の区分が要綱と合っていない、成果の測り方が書かれていない。**交付する側にいた方は、これを毎年見てきています。**どういう申請書が差し戻されるか、どこを補正させられるか、審査の場で何が問題になるか。**この知識は、外から学ぶのが難しい。**民間の側にいる人は、**差し戻された理由を推測するしかありません。**ですから、職務経歴書には、**「補助金の事務」ではなく「年間◯件の申請の審査を担当。要件への適合と経費の区分を確認し、実績報告の検査まで一連を担当」**と書いてください。**そして、面接では「通らない申請書の共通点」を話せるようにしておいてください。**これが語れる方は、**その場で評価が変わります。**
:::

## 職務経歴書での並べ方

| 位置 | 書くもの |
|---|---|
| 冒頭の要約（3〜4行） | **補助・委託・計画のうち、担った機能** |
| 職歴の1つ目 | 直近の担当。**件数と規模を入れる** |
| 職歴の2つ目以降 | **応募先の事業に近いものを前へ** |
| 実績の欄 | **「引き受けられること」が伝わる内容** |
| 資格・研修 | 関連する学習の状況 |

**冒頭の要約を必ず付けてください。**この分野では、**代表や事務局長が書類を読みます。**読む時間は限られています。

**実績の欄は、「担当した」ではなく「何ができるか」**が伝わるように書いてください。**着任後すぐに引き取れる仕事が分かる**と、**採る側の判断が速くなります。**

[経験の言い換えから相談する](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担です）。

## 面接で聞かれやすいこと

| 聞かれること | 何を確かめられているか |
|---|---|
| 補助金の申請をした経験はありますか | **①の経験** |
| 通らない申請書の共通点は何ですか | **実務の深さ** |
| 委託の仕様書を書いた経験はありますか | ②の経験 |
| 地域の事業者と話した経験はありますか | ③の関係づくり |
| 入って最初に何を引き受けられますか | **即戦力になる部分** |

**2つ目に、具体的に答えられるようにしておいてください。**

**5つ目は、必ず用意してください。****「補助金の申請と実績の報告は、着任後すぐに引き取れます」**という形です。

:::insight
ここまで「評価される」話をしてきましたが、**申し上げておきたいことが2つ**あります。**1つ目は、評価される経験があることと、移ったほうがよいことは別**だということです。補助の審査をした事実、委託を発注した事実、計画を作った事実。**異動しても残ります。**ですから、**動く理由は別に必要**です。**2つ目は、この分野に特有の確認**です。⚠ **観光協会や地域の法人は、自治体から補助や委託を受けている**ことが多く、**自分が担当していた相手方に移る形**になりやすい。**再就職に関する規制は、国家公務員と地方公務員で異なり、地方公務員については自治体ごとに定めがあります。**離職前の職務との関係で、**一定期間、特定の行為が制限される**場合があります。⚠ **この記事では、個別の事情について判断できません。所属の人事担当部署と、適用される条例・規程を必ず確認してください。**⚠ そして、**地域に関わる方法は転職だけではありません。**在職のまま関わる道もあります。**ただし、兼業・副業についても所属の規程で扱いが定められています。**何ができるかは、**同じく人事担当部署に確認してください。**当社が、いまの職を辞めることをお勧めすることはありません。
:::

## まとめ

- **この分野が足りていないのは、観光の知識を持つ人ではなく、制度の手続きを回せる人**です
- **旅館業法第4条第1項**は、**営業者が施設について換気、採光、照明、防湿及び清潔その他宿泊者の衛生に必要な措置を講じなければならない**と定め、**第2項**で**基準を都道府県が条例で定める**としています
- **この義務は、許可を取るときだけのものではなく、営業を続けている間ずっと**続きます
- **観光立国推進基本法第4条第1項**は、**地方公共団体が施策を策定し、実施する責務を有する**と定めています。**その実施の多くは、地域の法人への補助や委託という形をとります**
- 評価される経験は、**①補助金の交付・審査 ②委託の発注・検査 ③計画の策定 ④許認可・監視 ⑤会議体・行事の運営**の5つです
- ⚠ **①と②がいちばん求められています。**補助と受託が財源の柱で、**申請書と報告書を書ける人がいないと事業が回りません**
- ⚠ **「補助金の事務」を一言で片づけないでください。****「通らない申請書の共通点」を語れる方は、その場で評価が変わります**
- ⚠ **「何をしたいか」ではなく「何を引き受けられるか」**を書いてください
- ⚠ **再就職と兼業・副業の規程**を、所属の人事担当部署に確認してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 補助金の事務をしたことがありません

**②③⑤で組み立ててください。****委託の発注と検査、計画の策定、行事の運営**は、部署を問わず発生します。とくに、**業務委託の契約事務**は、**受託事業の実施と完了報告**に直接対応します。仕様の読み方、履行の確認、完了検査。**やることの構造が同じ**です。また、**行事やイベントの実施**を担当した方は、**企画、出展者の選定、会場の構成、告知**という一連を経験しています。これは、**この分野の催事の運営とほぼ同じ**です。書き方は、**件数と、一連を担ったこと**を入れてください。**補助金の経験が無いことを、応募しない理由にしないでください。**

### 保健所にいました。観光の分野で使えますか

**使えます。**⚠ とくに、**旅館業や食品営業の許可・監視**を担当していた方は、**宿泊や飲食に関わる職種で直接効きます。**旅館業法第4条の措置は、**営業を続ける間ずっと満たすべきもの**なので、**事業者側には日常的な確認の仕事があります。**何を見られるかを知っている人は、**その確認の手順を作れます。**また、**食品衛生に関する知識**は、**地域商社の特産品の開発や、催事での提供**に関わります。書き方は、**「◯◯法にもとづく許可の審査を年間◯件、監視指導を◯件」**と、**法令名と件数**を入れてください。**「衛生の事務」では伝わりません。**

### 技術職です。土木や建築の経験は使えますか

**使えます。**観光の分野では、**観光の施設、公衆トイレ、遊歩道、案内の標識、駐車場**など、**整備と維持管理の対象**が多くあります。役所で**工事の発注と監督**をしていた方なら、**仕様書の作成、業者との協議、検査**の経験がそのまま重なります。とくに、**受入れ環境の整備に関する補助の制度**を使う場面では、**技術の理解と手続きの理解の両方がある人**が要ります。また、**指定管理者制度で施設を所管していた方**は、**施設の運営を担う法人の側**で経験が効きます。探し方は、**「施設」「整備」「受入環境」**といった言葉が仕事内容に入っている募集です。
