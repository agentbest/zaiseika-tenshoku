商社への転職を検討されている方から、**同じ順番で質問をいただきます。**

**「給与は上がりますか」**

**「働き方は、きつくなりますか」**

**どちらも、当社が数字でお答えできる問いではありません。**会社ごとに事情が違いますし、**裏を取っていない数字を並べるのは、この記事の趣旨に反します。**

そのかわりに扱うのは、**「何が根拠になっているか」が、役所と商社でどう変わるか**です。ここが分かると、**求人票と就業規則のどこを見ればよいか**が決まります。

未経験から入る道筋は[未経験から商社に入るには](industry-shosha-mikeiken.html)にあります。

## 給与の根拠が、条例から就業規則に変わります

**いま、給与の根拠になっているのは条例です。**

**地方公務員法第24条第1項**です。

> **職員の給与は、その職務と責任に応ずるものでなければならない。**

**同条第2項**は、**「生計費並びに国及び他の地方公共団体の職員並びに民間事業の従事者の給与その他の事情を考慮して定められなければならない」**と定めています。

**つまり、給与の水準を決めるときに考慮すべきものが、法律に書かれている**ということです。そして、**その結果は条例という形で公表されます。**

**民間企業では、この構造がありません。**

**労働基準法第89条**です。

> **常時十人以上の労働者を使用する使用者は、次に掲げる事項について就業規則を作成し、行政官庁に届け出なければならない。**次に掲げる事項を変更した場合においても、同様とする。
>
> 一　**始業及び終業の時刻、休憩時間、休日、休暇**並びに労働者を二組以上に分けて交替に就業させる場合においては就業時転換に関する事項

**第2号**として、**賃金の決定、計算及び支払の方法、賃金の締切り及び支払の時期並びに昇給に関する事項**が挙げられています。

| | 役所 | 商社（民間企業） |
|---|---|---|
| 根拠 | **条例** | **就業規則・給与規程** |
| 決め方 | 法律の考慮事項にもとづく | **会社が定める** |
| 見られるか | **公表されている** | **在職者は見られる。**応募の段階では要確認 |
| 改定 | 議会の議決を経る | 会社の手続きによる |

**ここがいちばん大きな変化**です。**条例を見れば分かる状態から、会社の規程を見なければ分からない状態**になります。

**ですから、選考の過程で規程を確認してください。**これは失礼な質問ではありません。

## 時間外労働には、法律上の限度時間があります

**「商社は忙しい」と一括りに語られがち**ですが、**制度の枠組みは決まっています。**

**労働基準法第36条**は、**労使の書面による協定を届け出た場合に、労働時間・休日の規定にかかわらず労働させることができる**という構造の条文です。

そして、**同条第4項**です。

> **前項の限度時間は、一箇月について四十五時間及び一年について三百六十時間**（第三十二条の四第一項第二号の対象期間として三箇月を超える期間を定めて同条の規定により労働させる場合にあっては、一箇月について四十二時間及び一年について三百二十時間）**とする。**

**限度時間が、法律の条文に書かれています。**

**これは商社に限った話ではなく、民間企業に共通の枠組み**です。**役所にいると「民間は青天井」という印象を持ちがち**ですが、**制度としてはそうなっていません。**

**そのうえで、確認していただきたいのは、実際の運用**です。**協定の内容、特別条項の有無、実際の平均的な時間**。これは**会社ごとに違うので、面接で聞いてください。**

**なお、時間外・休日・深夜の労働には、労働基準法第37条により割増賃金**が必要です。**役所の時間外勤務手当と、考え方は同じ**です。

## 出張の多い職種には、みなしの仕組みがあります

**商社の営業や調達の職種では、社外で働く時間が長くなります。**

**労働基準法第38条の2第1項**です。

> **労働者が労働時間の全部又は一部について事業場外で業務に従事した場合において、労働時間を算定し難いときは、所定労働時間労働したものとみなす。**ただし、当該業務を遂行するためには通常所定労働時間を超えて労働することが必要となる場合においては、厚生労働省令で定めるところにより、**当該業務の遂行に通常必要とされる時間労働したものとみなす。**

**「労働時間を算定し難いとき」に、みなす**という仕組みです。

**同条第2項**は、**労使の書面による協定があるときは、その協定で定める時間を「通常必要とされる時間」とする**と定めています。

**この仕組みが適用される職種かどうかで、働き方の見え方が変わります。**

**⚠ 確認していただきたいのは、自分が応募する職種に適用されるかどうか**です。**内勤の管理の職種では、通常の時間管理**であることがほとんどです。

## 働き方は、職種で大きく分かれます

| 職種 | 出張 | 時間の見通し | 役所との差 |
|---|---|---|---|
| 営業・調達 | **多い** | 相手の都合に左右される | **差が大きい** |
| 貿易の実務 | 少ない | 船の日程と締切に沿う | **締切の性質が近い** |
| 経理・財務 | 少ない | **決算期に集中する** | **近い**（出納閉鎖と同じ構造） |
| 法務・輸出管理 | 少ない | 案件の発生による | **近い**（審査の事務と同じ） |
| 事業投資の管理 | 中程度 | 投資先の日程による | 差が大きい |
| 物流・在庫 | 少ない | 日々の運用 | 近い |

**「商社の働き方」は、この表のどこに入るかで別物**です。

**役所から移った方が馴染みやすいのは、下の4つ**です。**締切が制度や暦で決まっていて、自分で組み立てられる**からです。

**営業と調達は、相手の都合が優先されます。**ここは、**役所の窓口業務とも違う性質**です。

:::insight
面談で伺っていて、**商社に移った方が最初に戸惑うのが「休む理由を説明しなくてよい」**という点です。役所では、年次有給休暇を取るときに、**周りへの気兼ねと、繁忙期を外す配慮**が習慣になっている方が多い。移った先で、**「取りたい日に出して構いません」と言われて、かえって落ち着かない**という話を何度も伺いました。**労働基準法第39条**による年次有給休暇の仕組みは、**役所も民間も同じ枠組み**です。違うのは、**運用の空気**のほうです。とくに、**担当が一人で回っている職種**では、**自分が休む日の段取りを自分で作る**必要があります。引き継ぎのメモを残す、取引先に事前に伝えておく、締切の前後を外す。**この段取りは、役所で培った習慣がそのまま使えます。**係の中で休暇を回してきた方は、**段取りの作り方を知っています。**ですから、戸惑いは最初だけです。**むしろ、自分で段取りを組める人のほうが、この環境では休めます。**気兼ねが減るぶん、**自分で設計する部分が増える**というだけの違いです。
:::

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 場面 | 効く理由 |
|---|---|
| 締切が決まっている業務を回す | **予算・決算・議会の日程で動いてきた** |
| 記録を残して説明する | 監査を受ける前提の書類の作り方 |
| 規程や手続きを整える | **要綱を条文の形で書いてきた** |
| 相手の組織の決定の流れを読む | **官公庁が相手の案件で直接効く** |
| 複数の関係先を調整する | 庁内・庁外の調整の経験 |

**効きにくい場所**

| 場面 | 効きにくい理由 |
|---|---|
| 相手の都合で予定が動く働き方 | **自分の暦で組み立ててきた** |
| 損益の数字を毎月見る | 予算の執行率とは見る意味が違う |
| 値決めと採算の判断 | **自分で決める場面が役所には少ない** |
| 相場の変動への対応 | 感覚は経験で付く |
| 短い周期での方針の変更 | 役所より変更の頻度が高いことがある |

**効きにくい場所の1つ目**が、**いちばん生活に影響します。**

**面接で「予定が動くことに抵抗はありますか」と聞かれたら、事実で答えてください。**家庭の事情で難しい時間帯があるなら、**入る前に伝えておくほうが良い**です。

## 入る前に確認しておくこと

**労働基準法第15条第1項**は、**使用者が労働契約の締結に際し、労働者に対して賃金、労働時間その他の労働条件を明示しなければならない**と定めています。**明示すべき事項は、労働基準法施行規則第5条**に具体的に並んでいます。

**つまり、条件を示してもらうことは、権利として認められています。**

| 確認すること | どこで確認するか |
|---|---|
| 賃金の決定・計算・支払の方法、昇給 | **給与規程・労働条件通知書** |
| 就業の場所と、従事すべき業務 | **労働条件通知書**（転勤の範囲を含む） |
| 始業・終業の時刻、休憩、休日 | 就業規則 |
| 時間外労働の有無と、協定の内容 | **面接で確認する** |
| みなし労働時間の適用の有無 | **面接で確認する** |
| 賞与や手当の仕組み | 給与規程 |

**「就業の場所と従事すべき業務」**は、**商社では特に確認してください。**[未経験から商社に入るには](industry-shosha-mikeiken.html)でも触れましたが、**勤務地が変わる異動がある**ためです。

**⚠ 遠慮して聞かないまま入ると、あとで折り合いません。**確認は、**入社の意思がある前提で聞く**と、角が立ちません。

[経験の言い換えから相談する](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担です）。

**4つ目は、必ず答えを用意しておいてください。**

**「特にありません」は、良い答えではありません。**入ったあとに食い違う可能性を残します。**勤務地、時間帯、休日のどれかで、譲れない点があるなら、この場で言ってください。**

:::insight
ここまで確認の話をしてきましたが、**当社の見解を1つ申し上げます。**この業界を検討される方の中には、**いまの職場の働き方に疲れて、外に出れば変わると考えている方**がいらっしゃいます。**ここは、慎重に見てください。**商社の職種によっては、**時間の使い方は役所より不規則になります。**相手の都合で予定が動き、出張があり、勤務地が変わることもある。**「忙しさの総量」が減るとは限りません。**変わるのは、**忙しさの性質**です。役所の忙しさが**「暦と制度で決まった山が来る」**ものだとすれば、商社の忙しさは**「相手の事情で山が動く」**ものです。どちらが楽かは、**その人が何に消耗するか**で変わります。**予測できない予定に消耗する方**には、商社の営業の職種は向きません。逆に、**同じ時期に同じ山が来ることに飽きている方**には、向いています。ですから、**「働き方を変えたい」という動機の場合は、何を変えたいのかを一段細かくしてください。**総量なのか、性質なのか、時間帯なのか、相手なのか。**そこが決まらないうちは、動かずに整理するほうが早い**です。在職のまま、整理だけのご相談も承っています。
:::

## まとめ

- **給与の根拠が、条例から就業規則・給与規程に変わります**
- **地方公務員法第24条**は、給与が**職務と責任に応ずるもの**であること、**生計費・国や他団体の職員・民間事業の従事者の給与その他の事情を考慮して定められること**を定めています
- **労働基準法第89条**は、**常時10人以上の労働者を使用する使用者に、就業規則の作成と届出**を義務づけています。**賃金の決定・計算・支払の方法、昇給に関する事項**も記載事項です
- **労働基準法第36条第4項**は、**限度時間を一箇月について45時間、一年について360時間**（一定の場合は42時間・320時間）と定めています。**制度として青天井ではありません**
- **同法第38条の2**は、**事業場外で労働時間を算定し難いとき**のみなしの仕組みを定めています。**適用の有無は職種によります**
- 働き方は**職種で別物**です。**貿易の実務・経理・法務・物流は、役所の締切の性質に近い**です
- **労働基準法第15条**と**施行規則第5条**により、**条件の明示は権利**です。**勤務地と業務の範囲を必ず確認**してください
- **変わるのは忙しさの総量ではなく、性質**であることがあります。**何を変えたいのかを一段細かく**してください

## よくある質問

### 求人票に「みなし残業」と書かれています。どう読めばよいですか

**2つの仕組みが、同じ言葉で呼ばれていることがあります。**1つは、**一定時間ぶんの時間外労働に対する割増賃金を、あらかじめ定額で支払う仕組み**です。もう1つは、**この記事で扱った労働基準法第38条の2の事業場外のみなし**です。**求人票の表記だけでは区別できないことがある**ので、**面接で「何時間ぶんが含まれているか」「超えた場合はどうなるか」を確認**してください。定額で支払う仕組みの場合、**定められた時間を超えた部分については、別に支払われる**のが原則です。**確認しにくいと感じる方が多い項目ですが、入ってからでは変えられません。**なお、当社が会社ごとの運用をお伝えすることはできません。**求人票と規程で確認してください。**

### 現在の手当がいくつもあります。移ると、どう変わりますか

**手当の構成は、会社ごとに違います。**役所の手当は、**地方自治法第204条にもとづき条例で定められている**ため、種類と支給の要件が公表されています。**民間企業では、給与規程で定められます。**確認のしかたは、**「基本給と手当の内訳」を労働条件通知書で示してもらう**ことです。扶養、住居、通勤、単身赴任など、**いま受けている手当に相当するものがあるかどうか**を、項目ごとに突き合わせてください。**総額だけを比べると、構成の違いが見えません。**とくに、**住居に関する手当と、転居を伴う異動の際の扱い**は、商社では確認しておく価値があります。

### 退職の時期は、いつにするのが良いですか

**この記事では判断できません。**退職手当の算定、共済の扱い、年次有給休暇の残りなど、**個別の事情で変わります。**所属の人事担当部署と、**共済組合の窓口で確認**してください。一般論として申し上げられるのは、**内定が出てから退職の意思を伝えるほうが、選択肢が残る**ということだけです。**当社が、いまの職を辞めることをお勧めすることはありません。**確認した結果、**残るという結論になっても、それは正しい結論**です。条件を並べて比べたうえでの判断であれば、**どちらの結論でも、次に迷ったときの材料が増えています。**在職のまま、情報を取るだけのご相談も承っています。
