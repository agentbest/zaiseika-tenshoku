商社への転職の相談で、**最初に確かめることがあります。**

**「商社の、何をする人になりたいですか」**

この問いに答えにくいのは、**「商社」という言葉が、仕事の中身を指していないから**です。**銀行や建設会社と違い、商社は業種というより機能の名前**です。

**機能が分かれば、自分の経験が使える場所も見えます。**この記事では、**商法の定義から商社の機能を整理し、未経験から入る道筋**を扱います。

## 商社の機能は、法律の定義に書かれています

**商法第551条**です。

> **（定義）第五百五十一条　この章において「問屋」とは、自己の名をもって他人のために物品の販売又は買入れをすることを業とする者をいう。**

**「自己の名をもって、他人のために」**です。

**自分の名前で契約を結ぶが、経済的な利益は他人のもの**という構造です。これが、**取次ぎ**と呼ばれる機能です。

**商法第502条**は、**営業としてするときに商行為となる行為**を列挙していて、その**第11号**が**「仲立ち又は取次ぎに関する行為」**です。

**商社の原型は、ここにあります。**

**売りたい人と買いたい人の間に立ち、自分の名前で契約を引き受ける。**そのかわりに、**代金の回収、物流、品質の確認、為替の処理**といった、**当事者同士では処理しきれない部分を引き受けます。**

**つまり、商社の価値は「間に立って、面倒を引き受けること」**にあります。

**この整理は、公務員の方には掴みやすいはずです。**役所も、**住民と事業者、国と現場、制度と個別の事情の間に立って、面倒を引き受ける**仕事をしています。

## 商社は、3つに分かれます

| 種類 | 扱う範囲 | 中途採用の性格 |
|---|---|---|
| 総合商社 | **分野を限定しない。**資源、インフラ、食品、機械、化学など | **職種を絞った募集が中心** |
| 専門商社 | **特定の分野に特化**（鉄鋼、機械、医療、化学、繊維など） | 分野の知識か、実務の機能で採る |
| メーカー系商社 | **親会社の製品の販売を担う** | 製品の分野の知識が要ることが多い |

**この3つは、中途で入る難度が違います。**

**総合商社**は、**新卒で採用して育てる形が長く続いてきた**業界です。中途の募集は、**経理、法務、デジタル、人事、事業投資の管理**など、**職種を絞った形で出る**ことが多くなります。

**専門商社**は、**分野と機能の両方で採ります。**その分野の知識があるか、**営業・調達・貿易の実務ができるか。**

**未経験から入りやすいのは、専門商社**です。分野の数が多く、**公務員が関わってきた分野と重なるもの**も見つかります。

## 商社の中の仕事は、機能で分かれます

| 機能 | 何をするか | 未経験からの入りやすさ |
|---|---|---|
| 営業（トレーディング） | 売り先と仕入れ先をつなぎ、条件を詰める | 分野による |
| 調達 | 仕入れ先の開拓、価格と納期の交渉 | 分野による |
| 貿易の実務 | **輸出入の書類、通関、船積み、決済** | **入りやすい** |
| 与信・審査 | 取引先の信用の確認、限度額の管理 | **審査の経験が効く** |
| 経理・財務 | 決算、資金の管理、為替の管理 | **入りやすい** |
| 法務・コンプライアンス | 契約の確認、**輸出管理**、社内の規程 | **入りやすい** |
| 事業投資の管理 | 出資先の管理、事業計画の確認 | 経験が要る |
| 物流・在庫の管理 | 保管、輸送、在庫の適正化 | 入りやすい |

**未経験から入るなら、下の6つのどれかから探してください。**

**営業と調達は、分野の知識と人脈が要る**ことが多く、**未経験で入るには説明が要ります。**

## 輸出管理という仕事があります

**商社に、行政の経験が直接効く仕事があります。**

**外国為替及び外国貿易法第48条第1項**です。

> **国際的な平和及び安全の維持を妨げることとなると認められるものとして政令で定める特定の地域を仕向地とする特定の種類の貨物の輸出をしようとする者は、政令で定めるところにより、経済産業大臣の許可を受けなければならない。**

**同条第3項**は、**国際収支の均衡の維持、外国貿易及び国民経済の健全な発展、我が国が締結した条約その他の国際約束の誠実な履行**などのために、**承認を受ける義務を課することができる**と定めています。

**つまり、輸出には許可や承認が要る場合がある**ということです。

**商社の中には、この確認を専門に担う部署**があります。**扱う貨物がどの区分に当たるか、仕向地がどこか、用途は何か**を確認して、**必要なら手続きを取る。**

**この仕事の性質は、役所の許認可の審査と、ほとんど同じ**です。

| 役所の許認可 | 輸出管理 |
|---|---|
| 申請の内容が要件に当たるかを確認する | **貨物が規制の区分に該当するかを確認する** |
| 要件に当たれば、手続きを進める | 該当すれば、許可の申請を行う |
| 判断に迷う事案は、上位庁に照会する | **判断に迷う事案は、所管に確認する** |
| 記録を残す | **記録を残す**（後から確認を受ける） |

**許認可の審査をしてきた方が、いちばん自然に移れる職種**です。

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 場面 | 効く理由 |
|---|---|
| 輸出管理・通関に関わる確認 | **該当性の判断という動作が同じ** |
| 契約の確認と、条件の整理 | 契約事務の経験がそのまま重なる |
| 与信・審査の事務 | **要件に当てはめて判断する訓練を受けている** |
| 官公庁が相手の案件 | **相手の意思決定の流れと時期が読める** |
| 補助金を使う案件 | 交付する側にいた |
| インフラ・資源の分野 | **制度の枠組みを理解している** |
| 記録と報告の整備 | 監査を受ける前提の書類の作り方 |

**効きにくい場所**

| 場面 | 効きにくい理由 |
|---|---|
| 新しい取引先の開拓 | **売り込む仕事は、役所にはほとんど無い** |
| 価格の交渉 | 値決めの判断を自分でする |
| 相場の動きを読む | 市況の感覚は経験で付く |
| 海外の現地での交渉 | 言語と商習慣 |
| 損益の責任を負う | **予算の執行と、利益を出すことは別** |

**効きにくい場所の1つ目と2つ目は、正直に伝えて構いません。**

**面接では、「やったことが無い」と言ったうえで、近い経験を出す**のが自然です。用地の折衝、滞納の整理、事業者との協議。**利害が対立する相手と話をまとめた経験**は、どの役所にもあります。

:::insight
商社を志望される方に、**面談でお伝えしていることがあります。**それは、**「総合商社に中途で入る」を目標に置かないでください**ということです。理由は、**難度の話ではなく、入り口の設計の話**です。総合商社の中途の募集は、**職種を絞って出ます。**経理、法務、輸出管理、デジタル。**つまり、入り口は「商社に入る」ではなく「その職種で入る」**です。ところが、**「商社に入りたい」という形で探すと、その職種の募集が目に入りません。**実際、**募集の見出しが「管理部門」や「コーポレート」になっていて、商社という言葉が前に出ていない**ことがよくあります。ですから、**探し方を職種に変えてください。**自分が担える機能——審査、契約、経理、許認可の確認——で探すと、**商社の求人が候補に入ってきます。**そして、**入ったあとに分野へ移る道**は、中に入ってからのほうが開きます。**専門商社でも同じ**です。分野で探すより、**機能で探すほうが、候補の数が変わります。**これは商社に限らず、この業界の外でも同じ考え方が使えます。
:::

## 入り方の手順

| 順 | やること | 目安 |
|---|---|---|
| 1 | **自分の機能を3つ**書き出す（審査、契約、経理、調整など） | 30分 |
| 2 | その機能で、**求人を検索する**（業種ではなく職種で） | 1時間 |
| 3 | 出てきた会社のうち、**商社に当たるものを分ける** | 30分 |
| 4 | **扱っている分野**を、公式サイトで確認する | 1時間 |
| 5 | 自分が関わった分野と**重なるものを前へ** | 30分 |
| 6 | 求人票の**応募条件を5件読み比べる** | 1時間 |

**6つ目で、その職種の共通の要件が見えます。**

**「貿易実務の経験」が必須と書かれているものと、「未経験可」と書かれているものが混在**しているはずです。**未経験可のものから当たってください。**

**なお、貿易の実務を扱うなら、通関士や貿易実務の検定などの学習が接点になります。**ただし、**資格を取ってから応募する必要はありません。**学習中であることを伝えるだけでも、**関心の本気度は伝わります。**

**⚠ 試験の内容や難度は、実施する団体の公表を確認してください。**当社が確認していない情報は、この記事には載せていません。

## 面接で聞かれやすいこと

| 聞かれること | 何を見られているか |
|---|---|
| なぜ商社なのですか | **機能で答えられるか** |
| 数字の責任を負うことに、抵抗はありますか | 予算の執行との違いを分かっているか |
| 海外との関わりについて、どう考えていますか | **勤務地の前提の確認** |
| 前例の無い案件に、どう向き合いますか | **判断の作り方** |
| 語学はどの程度ですか | 事実の確認 |

**3つ目は、正直に答えてください。**海外の勤務が前提の職種と、国内で完結する職種があります。**前提が違うまま進むと、あとで折り合いません。**

**5つ目も、盛らないでください。**入ってから困るのはご本人です。**「読み書きは業務で扱えるが、交渉の経験は無い」**のように、**できる範囲を具体的に**言うほうが信用されます。

:::insight
ここまで入り方の話をしてきましたが、**この業界を検討するときに、もう一つ見ておいていただきたい点**があります。**転勤と異動の幅**です。商社は、**扱う分野と拠点の両方で人が動く**ことがあります。役所の異動が「同じ市の中で部署が変わる」ことであるのに対し、**商社の異動は勤務地そのものが変わる**場合がある。**ここは、役所より幅が広いことがあります。**ですから、**「異動が多いのが嫌で役所を出る」という動機**の方は、**この業界では解決しないことがあります。**確認のしかたは単純で、**面接で直接聞くこと**です。「この職種の方は、これまでどういう異動をされていますか」。**答えにくい質問ではありません。**そして、**確認した結果、条件が合わないなら、他の業界を見てください。**商社が合う方は、**分野が変わることを面白いと感じる方**です。役所で**3年ごとに分野が変わることを嫌ではないと感じていた方**は、実は相性が良い。**逆に、同じ分野を深めたい方は、専門商社か、別の業界のほうが合います。**どちらが良いという話ではなく、**自分がどちらかを先に決めてください。**
:::

## まとめ

- **商社は業種ではなく機能の名前**です。**商法第551条**は、**問屋を「自己の名をもって他人のために物品の販売又は買入れをすることを業とする者」**と定義しています
- **商法第502条第11号**は、**「仲立ち又は取次ぎに関する行為」**を営業的商行為に挙げています。**間に立って面倒を引き受けるのが、商社の原型**です
- 商社は**総合・専門・メーカー系**に分かれます。**未経験から入りやすいのは専門商社**です
- 中の仕事は機能で分かれます。**貿易の実務・与信・経理・法務・物流**が、未経験から入りやすい入り口です
- **外為法第48条第1項**により、**特定の地域を仕向地とする特定の種類の貨物の輸出には、経済産業大臣の許可**が要ります。**この確認を担う輸出管理は、許認可の審査と動作が同じ**です
- ⚠ **「商社に入る」ではなく「その職種で入る」で探してください。**募集の見出しに商社という言葉が出ないことがあります
- 効きにくいのは、**開拓・値決め・相場・海外での交渉・損益の責任**です。**正直に伝えて、近い経験を出す**のが自然です
- **転勤と異動の幅は、役所より広いことがあります。**面接で確認してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 語学ができません。商社は難しいですか

**職種によります。**海外との取引を直接担う職種では要件になりますが、**国内の取引が中心の専門商社**や、**経理・法務・輸出管理などの管理の職種**では、**要件になっていない募集もあります。**判断の目安は、**求人票の応募条件**です。「英語での折衝の経験」が必須と書かれていれば要りますし、**書かれていなければ、選考の場で問われても事実を答えれば足ります。**なお、**輸出管理の仕事では、規制の文書を読む場面があります。**読解は要りますが、**交渉とは別の能力**です。語学が要るかどうかを「商社だから」で決めず、**募集ごとに確認してください。**

### 年齢が高めです。未経験の分野に移れますか

**職種によります。**営業や調達の職種では、**その分野の経験を求められることが多い**一方、**経理・法務・輸出管理・与信**のような機能の職種では、**行政での実務の年数が、そのまま経験として読まれます。**とくに、**審査や契約の事務を長く担当してきた方**は、**年数が不利になりにくい**です。ただし、**役職の名称は、そのままでは評価に結びつきません。**「係長を◯年」ではなく、**「◯件の審査を担当し、判断の基準を整理した」**という形で、**担った範囲と件数**で書いてください。応募する職種を機能で選ぶと、**年齢より経験の中身が見られます。**

### 専門商社は、どの分野を見ればよいですか

**自分が業務で関わった分野から見てください。**建設や設備の担当なら**建材・機械**、環境や廃棄物なら**資源・リサイクル**、福祉や医療の担当なら**医療機器・医薬**、農林なら**食品・農業資材**。**許認可や検査で現場を見てきた分野は、業界の構造がすでに頭に入っています。**その理解は、入ったあとに効きます。**関わった分野が思い当たらない場合は、機能で探して、出てきた会社の分野を後から見る**という順でも構いません。**分野を先に決めきらないほうが、候補は広がります。**
