中途採用の面接で、**ほぼ必ず出る質問**です。

**「意見が対立したときに、どう調整されましたか」**

公務員の方は、**材料を豊富に持っている質問**です。庁内の部門間、住民と行政、事業者と行政。**利害が対立する場面が、日常的にあります。**

ところが、答えが**「粘り強く話し合いました」**で終わることが少なくありません。

**聞かれているのは、姿勢ではなく手順**です。

この記事では、**その組み立て**を扱います。書類での書き方は[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)にあります。

## 利害の調整は、制度に組み込まれています

**行政手続法第10条**です。

> 行政庁は、申請に対する処分であって、**申請者以外の者の利害を考慮すべきこと**が当該法令において許認可等の要件とされているものを行う場合には、必要に応じ、**公聴会の開催その他の適当な方法により当該申請者以外の者の意見を聴く機会を設けるよう努めなければならない。**

**申請者と、それ以外の者の利害。**両方を考慮する必要がある場合に、**意見を聴く機会を設ける。**

つまり、**利害が対立する場面で、双方の意見を聴いたうえで決める**という手続きが、**制度として組み込まれています。**

**この仕組みの中で仕事をしてきた経験は、そのまま調整の経験**です。

## 結論：4段で答える

| 段 | 内容 |
|---|---|
| ① 構造 | **誰と誰が、何について対立していたか** |
| ② 立ち位置 | **自分はどちらの立場だったか**（中立か、一方か） |
| ③ やったこと | **手順として何をしたか**（ここが核心） |
| ④ 結果 | **どう決まったか、何が残ったか** |

**②を明示してください。**中立の調整役だったのか、自分も当事者の一方だったのか。**これによって、話の意味が変わります。**

## 公務員が持つ3類型

| 類型 | 例 |
|---|---|
| 庁内の部門間 | 予算の査定、所管の境界、計画の優先順位、システムの要件 |
| 住民と行政 | 施設の建設、料金の改定、制度の変更、工事の影響 |
| 事業者と行政 | 指導と是正、契約の変更、補助の要件、許認可の条件 |

**3つとも、性質が違います。**

**庁内の部門間は、指揮命令の関係がない相手との調整**です。**民間の部門横断の仕事に、いちばん近い構造**です。

**住民との調整は、相手を選べない状態での説明**です。**顧客対応の経験として読まれます。**

**事業者との調整は、規制する側とされる側**です。**立場の非対称があるので、それを踏まえた話し方が要ります。**

## 答え方の例

> 道路の改良の事業で、沿道の事業者の方と、通行する住民の方の利害が対立した場面がありました。工事の期間中の通行の規制について、事業者は営業への影響を、住民は通学路の安全を懸念されていました。（①）
>
> 私は事業の担当で、中立の立場ではなく、事業を進める側でした。（②）
>
> 進め方としては、まず双方から個別に聞き取りをして、**懸念の中身を具体的に分けました。**事業者の懸念は「搬入の車両が入れない期間の長さ」、住民の懸念は「通学の時間帯の車両の通行」でした。同じ「通行の規制」でも、**問題にしている部分が違うことが分かりました。**
>
> そのうえで、規制の時間帯を通学の時間を外す形に変え、搬入の経路を工程ごとに切り替える案を作りました。工期は約◯週間延びましたが、双方の主要な懸念は外れる形になりました。（③）
>
> 全員が納得したわけではありません。工期の延長について、庁内では調整が必要でした。ただ、事業は予定どおり完了しています。（④）

**③で、「懸念の中身を分けた」という手順が示されています。**

**これが、調整の実務です。**「話し合った」ではなく、**「対立の中身を分解した」**という記述になっています。

## 調整の手順を、言葉にする

**③で使える手順を挙げます。**

| 手順 | 内容 |
|---|---|
| 分解 | 「反対」の中身を、具体的な懸念に分ける |
| 前提を揃える | 双方が使っている数字や事実を一致させる |
| 選択肢を作る | 案を2つ以上用意し、比較できる形にする |
| 順番を決める | 合意できる部分から先に確定させる |
| 記録する | 決まったことと、保留したことを文書に残す |

**5つとも、役所の実務では日常的にやっていること**です。

**とくに「前提を揃える」は、民間でも同じ形で必要になります。**数字の出どころが違うまま議論しても、合意には至りません。

:::insight
この質問で、**評価が高くなるのは「全員が納得した」と言わない答え**です。面談で伺っていると、**きれいに収まった話を選ぼうとする方**が多いのですが、**実務を知っている面接官ほど、全員が納得する結末を信用しません。**現実には、**どちらかが譲る、あるいは双方が一部ずつ諦める**のが通常です。ですから、**「双方の主要な懸念は外せましたが、◯◯については折り合いませんでした」**と述べるほうが、**話の信頼性が上がります。**加えて、**折り合わなかった部分をどう処理したか**まで話せると、さらに具体的になります。記録に残した、次年度に持ち越した、上位の会議に上げた。**処理の方法があること自体が、実務の経験**です。もう1点、**「粘り強く」「丁寧に」という副詞は使わないでください。**手順を述べれば、粘り強さは伝わります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 「分解」の具体例を持っておく

**③でいちばん効くのが「分解」**です。面接で1つ例を出せるようにしておいてください。

| 表面の主張 | 分解した後 |
|---|---|
| 「この計画には反対だ」 | 計画の目的には賛成、実施の時期と負担の配分に反対 |
| 「予算が足りない」 | 総額ではなく、初年度に集中する配分に無理がある |
| 「うちの所管ではない」 | 業務の一部は所管、残りは別課。**境界が定義されていない** |
| 「その条件では受けられない」 | 価格ではなく、納期と検査の方法に無理がある |

**4つとも、「反対」の一語の中に、合意できる部分が含まれています。**

**分解しないまま賛否を問うと、全体が否決されます。**分解すれば、**合意できる部分から確定させられます。**

この作業は、**民間でも同じ形で必要**です。「難しいです」と言われたときに、**何が難しいのかを分けて聞く。**面接でこの話ができると、**手順を持っている人として読まれます。**

## 話してはいけないこと

| ✕ | 理由 |
|---|---|
| 相手が特定できる記述 | 守秘に関わります |
| 住民の方を批判する表現 | **立ち位置が疑われます** |
| 内部の検討の経緯 | 未公表の検討の過程は話しません |
| 特定の議員や団体の関与 | 政治的な文脈は持ち込みません |
| 「相手が理解してくれた」 | **自分の手順**を述べてください |

**2つ目に注意してください。**住民や事業者との対立の話をするときに、**相手の態度を評価する表現**が入ると、**「この人は顧客をそう見るのか」**と受け取られます。

**懸念の中身を説明するにとどめてください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## よくある失敗

**1. 「粘り強く話し合いました」で終える**

**手順**を述べてください。

**2. 自分の立ち位置を言わない**

**中立か当事者か**で、話の意味が変わります。

**3. 「全員が納得しました」と言う**

**折り合わなかった部分**を述べるほうが信頼されます。

**4. 相手の態度を評価する**

**顧客をどう見るか**が疑われます。

**5. 結果だけを話す**

**③の手順**が、この質問の核心です。

**6. 副詞で語る**

「丁寧に」「誠実に」。**手順を述べれば伝わります。**

:::insight
ここまで答え方の話をしておいて逆のことを言いますが、**この質問は、公務員の経歴でいちばん差が付きやすい質問**でもあります。理由は、**民間の応募者の多くが、社内の調整の話しか持っていないから**です。役所の方は、**指揮命令の関係がない相手、立場の違う相手、選べない相手との調整**を、日常的に経験しています。**しかも、根拠を示しながら進める習慣がある。**この経験は、**自治体を顧客とする会社だけでなく、規制の強い業界や、利害関係者の多い事業でも求められます。**準備としては、**3類型から1つずつ、計3件の材料を用意**しておいてください。応募先によって、**庁内の話が効く場合と、住民との話が効く場合**があります。どれを出すかを選べる状態にしておくと、面接の対応の幅が広がります。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- 答えは、**①対立の構造 ②自分の立ち位置 ③手順 ④結果と残ったもの**の4段。**③が核心**です
- **行政手続法第10条**は、申請者以外の者の利害を考慮すべき場合に、**公聴会その他の方法で意見を聴く機会を設けるよう努める**ことを求めています
- 材料は、**庁内の部門間・住民と行政・事業者と行政**の3類型。**性質が違うので、応募先で使い分けてください**
- 手順は、**分解・前提を揃える・選択肢を作る・順番を決める・記録する**の5つです
- **「全員が納得した」と言わない。**折り合わなかった部分と、その処理を述べてください
- **相手の態度を評価する表現**は使いません。懸念の中身の説明にとどめます

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 調整の結果、自分の案が通らなかった経験しかありません

**それも材料になります。**むしろ、**通らなかったときの処理**は、実務的な話になります。「自分の案は採用されませんでしたが、相手の案の懸念点を3点整理して記録に残し、実施の段階で確認する項目として引き継ぎました」という形です。**自分の主張が通ることが、調整の成功ではありません。**決まった内容を実行できる状態にすることが目的です。加えて、**なぜ通らなかったかを分析できている**なら、それも述べてください。判断の材料が足りなかったのか、時期が合わなかったのか。**分析があると、次に活かせる人として読まれます。**

### 対立というほどのものを経験していません

**「意見が違った場面」で構いません。**予算の要求で、事業課と財政課で必要額の認識が違った。システムの要件で、業務側と情報部門で優先順位が違った。**日常的な協議の中にも、利害の違いはあります。**答えるときは、**「大きな対立ではありませんでしたが」と前置きせずに**、構造から述べてください。規模の大小は、評価の対象ではありません。**手順が語れるかどうか**です。むしろ、**日常の協議で手順を持っている人**のほうが、実務では信頼されます。

### 住民の方との対立を話すと、印象が悪くなりませんか

**話し方によります。**避けるのは、**相手の態度を評価する表現**です。「感情的な方で」「話が通じない方で」といった記述が入ると、**顧客への姿勢が疑われます。**一方、**懸念の中身を具体的に説明し、それにどう対応したかを述べる**のであれば、印象が悪くなることはありません。むしろ、**相手を選べない立場での対応の経験**として読まれます。書き方の考え方は[住民対応の経験を、顧客対応として書く](senko-shokumu-jumin.html)と同じです。**「どこで」ではなく「どうやって」で話してください。**
