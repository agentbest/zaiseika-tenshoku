印刷・広告制作を調べるとき、公務で原稿や数字の根拠を確認し、修正事項を整理した経験には、工程として示せる接点があります。ただし、発注や校正を担当したことと、自らデザイン、DTP編集、印刷や製本を行ったことは別です。具体的な求人へ照合します。

本記事は2026年11月時点の公開情報にもとづきます。確認日は2026年11月25日です。新日本印刷の公式中途募集を例に確認方法を示します。公務員への非公開の評価理由や採用率を示すものではありません。

## 営業、制作、DTP、生産の工程を分ける

新日本印刷の中途採用一覧は、営業、企画営業、DTPオペレーター、生産管理、生産オペレーター、仕上製本等の仕事を拠点別に案内しています。一つの会社でも、必要な経験と勤務、本人が責任を持つ工程は職務で異なります。

今回確認したのは高松本社と東京支社のDTPオペレーターです。MacやWindowsでIllustrator、Photoshop、InDesign等を使い、レイアウト、編集、写真の調整、版面設計等を行う仕事が説明されています。

原稿の内容を確認することと、実際に紙面やデータを作ることは別です。会社のDTP、デザイン、印刷機の操作、納期や工程を担う生産管理等を、印刷物に関わるという一言でまとめないようにします。

印刷と広告制作の関係も、個々の会社の事業と求人で読みます。広告の企画や営業、デザイン等の全工程を、一つのDTP求人の担当にしません。会社のサービス一覧と本人の初期役割を分けてください。

行政で広報や発注を担当した場合も、情報の確認、原稿作成、修正指示、デザイン、DTPデータ作成、印刷・製本等を分けます。委託先や別部署が行った技術作業を本人の経験へ加えないようにします。

[行政に接点のある掲載求人を調べる](../?gov=1)際も、印刷物への関心と、本人が担当する工程・契約を別に比較できます。

## 原稿確認の経験を、根拠と作業の単位で説明する

公務で原稿を確認した経験は、対象、参照した根拠、確認項目、修正や質問の整理、他者の判断に分けられます。いつの数字か、用語や期間が一致するか等、本人が確かめた工程を具体的にできます。

関係課の修正を取りまとめたことと、紙面の構成やデザインを決めたことは別です。本人が日程を整えたのか、必要事項を説明したのか、データを編集したのかを分けてください。「制作を管理した」という表現で作業が広くならないようにします。

DTPの仕事との接点を考えられても、工程が近いことと採用条件を満たすことは別です。本人の使用した道具と実施した作業を原文へ照合し、対象になるか不明な内容は窓口へ確認します。

Word等で原稿を作ったこと、PDFへ修正を記したこと、デザインソフトで紙面を作ったことも同じではありません。ソフトの名前だけで全機能に習熟しているとせず、何を操作したかを具体的に示します。

入稿や色、版面等の専門的な判断を他者が行ったなら、その分担を残します。自分が確認した内容と、制作会社の技術判断を分けることで、行っていない専門作業を経験済みにせず説明できます。

## 未経験歓迎と学歴の応募条件を分ける

確認した高松と東京のDTP募集は、専門学校、高専、短大、四年制大学卒以上を応募資格として挙げています。職種・業種の未経験や第二新卒を歓迎する説明もありますが、学歴の条件を消さないようにします。

未経験から入った人がいるという会社の説明は、本人が採用される保証ではありません。本人の学歴と、どの作業が経験で何が未経験かを分けて確認します。公務員という身分だけで適合を判断しないようにします。

応募資格にソフトの実務年数等が列挙されていないからといって、すべての職務で条件なしとは読みません。初期に必要な操作や学ぶ範囲、現在の募集対象が不明なら、正式な職名と拠点を添えて質問できます。

DTPの未経験歓迎を、営業や生産等の別職務へそのまま移さないことも必要です。会社の一覧から対象の個別募集を開き、職名、勤務地、条件、勤務を一組で記録します。旧ページや他拠点の内容を混ぜません。

学習や資格も取得済み、合格済み、学習中、受験予定を分けます。ソフトを学んでいることと仕事で実施した経験は別です。意欲の説明で実務を追加せず、本人が確認できる作業を示せます。

:::insight
原稿を確認した経験は、根拠の照合、修正事項の整理、関係者への質問に分けて示すことを勧めます。一方で、委託先が行ったDTP編集や色の調整、印刷を本人の作業へ加える必要はありません。未経験歓迎の募集でも、学歴等の応募条件は別に確認できます。本人の行動、使った道具、他者の権限、未経験を一項目ずつ原文へ対応させる方法を使えます。ソフトの名前だけで設計や入稿の全工程を経験済みにせず、具体的な操作を説明してください。対象になるか不明な作業や初期の習得範囲は、正式な拠点と職名を添えた質問に残せます。確認済みと未回答の事項も分けて記録できます。
:::

## 本人の判断と、組織の成果を区別する

広報物や印刷物を作る事業に関わった場合、企画の提案、原稿の作成、確認、決裁、実際の編集・制作、配布等を分けます。上司や専門部署、委託先が行ったことを本人の実績へ加えないようにします。

事業者との調整も、日程の連絡なのか、仕様や修正事項の質問なのか、契約条件を決めたのかで意味が変わります。行政の発注側と、会社で提案・受注を行う側を同じ営業経験として扱いません。

改善は、課題を見つけた段階、提案、採用、実施、効果確認を別にします。測っていない制作時間や費用の削減率、配布後の反応や相手の満足を作りません。必要項目や未回答を整理したことを、その範囲で説明できます。

本人に制作や印刷等の前職があるなら、勤務先や契約、期間、対象、作業を公務の履歴と別に示せます。在籍全体と特定の工程の期間を分け、複数業務の分担も残してください。見学や学習だけの内容を実務に加えません。

将来担いたい仕事と経験済みの仕事も別です。制作へ関心があることを、すでに全工程を独力で行える事実と混ぜず、初期担当と確認する相手を質問できます。本人が説明できる範囲を保って準備します。

## 独立した架空の記入例で、経験と未確認を残す

以下は経験整理のための独立した架空例です。実在の応募者、面接の回答、採用実績ではありません。本人が使う場合は事実に置き換え、未実施の行動や持っていない経験は削除してください。

| 項目 | 架空の記入内容 |
|---|---|
| 本人の担当 | 自治体で広報原稿の確認と関係課への照会 |
| 実施した工程 | 対象年度と数値の根拠を確かめ、修正と質問を一覧化 |
| 他者の権限 | 掲載の決裁は上司、デザイン・DTP・印刷は制作会社 |
| 道具の経験 | 本人が行った原稿の入力と資料作成、確認記録 |
| 未経験 | Illustrator等でのDTP編集、版面設計、印刷機の操作 |
| 学歴 | 四年制大学卒業。本人が証明できる事実として確認 |
| 関心 | 根拠を確認し、相手へ必要事項を伝える工程 |
| 未確認 | 初期担当、必要な操作と習得範囲、勤務、雇用と試用 |
| 次の行動 | 正式な拠点・職名を示して条件と役割を質問する |
| 現職の比較 | 現在の根拠確認や説明を深める進路も残す |

この例では、広報物を所管したことを自ら編集・印刷した実務へ変えていません。本人の学歴も架空例から写さず、自分の証明できる事実へ置き換えてください。会社が評価したという架空の反応を加える必要もありません。

本人がデザイン等を実施している場合は、道具、対象、期間、担当範囲を具体的に示せます。公開可否や権利、契約、個人情報等を確認し、委託先が制作したものをすべて本人の作品としてまとめないようにします。

[担当工程と応募条件を整理する](../apply.html)場合も、内部資料を渡さず本人の言葉で説明できます。ご利用は無料です（紹介手数料は採用企業の負担）。経験や希望によっては、面談・求人紹介を提供できない場合があります。

## 高松と東京の勤務条件を一つにしない

高松のDTP募集は通常の勤務時間を示しています。東京の同職は、9時から18時と12時から21時の、週ごとの交替シフトを説明しています。同じ職名だから勤務が同一になるとは扱いません。

休日もそれぞれの会社カレンダー等の説明を読みます。基本が土日という表記から、毎週本人の希望する曜日が固定されるとは決めません。拠点と職務を示して、具体的な適用を確認できます。

勤務地は高松本社と東京支社で別です。求人に現在の場所があることを、将来ずっと一つの場所へ固定される保証へ変えません。本人の初期担当と、場所や業務の変更範囲を窓口へ質問できます。

給与は年齢、経験、能力を考慮し規程による説明です。公務の年数だけで額を割り当てず、固定と変動、手当や賞与の本人への適用を確認します。他社や別拠点の制度を同じ職種という理由で移さないようにします。

雇用形態や試用等の未記載事項も別求人から補完しません。中途募集という名称だけで契約の内容を決めず、本人への正式な提示で確認します。制度や研修の説明があっても習熟や配属の保証とはしません。

## 選考の方法と本人への正式な案内を分ける

確認したDTP募集は、書類選考、面接1～2回、適性検査を選考方法として挙げています。記載からすべての実施順や方法を確定せず、本人への正式な案内で確認します。ほかの職務へ同じ方法を移さないようにします。

公開情報から未記載の設問や課題、採点、面接心理を作りません。本人の課題、行動、分担、確認した結果、未経験を整理して準備できます。未公開の選考内容や他の応募者の回答を使うことも前提にしません。

作品や資料を用意する場合も、提出の必要と形式、本人の担当と権利を確認します。職務で扱った内部データや委託先の制作物を、名前だけ消して自由に使えるとは判断しないようにします。学習の作品と業務実績も区別します。

書類の作成、本人確認、送信、案内受領、正式提示を別の段階で記録できます。質問したことと回答されたこと、希望を伝えたことと配属が確約されたことは別です。一般の可能性の説明か本人の予定かも確認してください。

募集が更新されれば会社・拠点・職名と確認日を残して読み直します。旧ページや他社の条件を混ぜず、違いがある項目は具体的に質問できます。未回答を了承済みとして住居や退職の確定予定へ入れないようにします。

## 情報を守り、現職継続も同じ工程で比べる

住民や相談者、事業者の個人情報、非公開の原稿、写真、見積、仕様、契約、調達、事業計画等を持ち出しません。名前を消せば使えるとも判断せず、内部資料を私用AIへ入力しないようにします。公開情報と一般化した本人の工程で準備できます。

行政上の便宜や内部人脈を、制作の受注や案件獲得の強みとして提供する約束もしません。本人の確認や説明の経験を話すことと、現職の立場、権限、連絡先を私的に使うことを分けます。

書類を短くする際も、他者の判断や未経験を削って意味を変えないようにします。整理を支援してもらった場合も最後は本人が読み、どの記述がどの事実を指すか説明できる形を保てます。

現職で情報の根拠確認や説明を深める進路も比較できます。会社側で制作や生産へ移りたい場合も、どの工程を担いたいかと必要な条件を確かめます。印刷物への関心や応募の開始だけで退職を先に決める必要はありません。

[掲載中の求人を比べる](../)際も、現職を含め、本人が望む役割と必須の勤務条件を同じ表へ並べられます。

:::insight
印刷物に関わるという共通点があっても、行政の原稿確認と会社側の編集・生産では本人の工程が変わります。現職の根拠確認や説明を深めたいのか、制作や印刷の実行へ移りたいのかを分ける方法を勧めます。現職で希望する仕事を続けられるなら、残る判断も比較対象です。公務経験を低く扱う必要はなく、行っていないデザインやDTP、印刷を加える必要もありません。必要な条件、初期担当と分担、拠点別の勤務、契約を確認し、応募や登録だけで退職を先に決めず、正式な説明と条件がそろった段階で考えられます。不明な項目を保留にすることも判断のための方法です。
:::

## まとめとよくある質問

印刷・広告制作は職務と拠点を単位に確認します。発注や校正、本人の確認、提供側のデザイン・DTP・生産を分け、条件へ照合してください。

### 広報の担当歴をDTP実務として書けますか

同じとは扱いません。本人の原稿確認や修正整理等と、委託先のデータ編集・印刷を分け、行っていない工程を加えないようにします。

### 未経験歓迎なら学歴の条件もありませんか

確認した募集には専門学校、高専、短大、四年制大学卒以上の応募資格があります。未経験の歓迎と別に本人の事実で確認します。

### 同じDTPなら勤務時間は同じですか

紹介した高松と東京でも異なります。東京には週ごとの交替シフトの説明があり、対象の拠点・職務で本人への適用を確認します。
