愛知県庁で働いてきた方の転職は、地方県庁とは前提が違います。**県内に、全国有数の規模の民間市場がある**からです。転居を伴わずに、多様な職種にアクセスできます。

そのぶん、判断は難しくなります。選択肢が多すぎて絞れない。そして多くの方が、**現在の額面を基準に絞り込んでしまい、比べ方を間違えています。**

この記事では、まず公表されている数字を正しく読み解き、そのうえで県庁の経験が民間のどの言葉に置き換わるのかを整理します。

## 愛知県庁の給与水準を、数字で確認する

総務省の調査によると、愛知県の一般行政職は次のとおりです（令和6年4月1日現在）。

| 項目 | 愛知県 |
|---|---|
| ラスパイレス指数 | 101.0 |
| 平均年齢 | 41.5歳 |
| 平均給料月額 | 324,000円 |
| 諸手当月額 | 106,525円 |
| 平均給与月額 | 430,525円 |
| 平均給与月額（国ベース） | 377,124円 |
| 地域手当（国の指定基準） | 8.5% |
| 地域手当（実際の支給割合） | 約10.85% |

### 地域手当の上乗せ幅が、ここまでで最大

読みどころはここです。**国が指定する基準は8.5%なのに、実際の支給割合は約10.85%。**差は約2.35ポイントで、この記事で扱ってきた都道府県のなかで最も大きい上乗せです。

並べると位置がはっきりします。

| 都県 | 国の指定基準 | 実際の支給割合 | 差 |
|---|---|---|---|
| **愛知県** | **8.5%** | **約10.85%** | **＋約2.35** |
| 埼玉県 | 8.3% | 約10.51% | ＋約2.2 |
| 神奈川県 | 約12.21% | 約14.24% | ＋約2.0 |
| 滋賀県 | 6.0% | 約7.88% | ＋約1.9 |
| 東京都 | 約19.63% | 約18.72% | **－約0.9** |

地域手当は民間賃金の高い地域に支給される手当で、国の指定基準は市町村単位で決まっていますが、**都道府県が独自の判断で支給割合を設定する余地があります。**東京都のように基準を下回る例もあれば、愛知県のように大きく上回る例もあります。

:::insight
この表を「地域手当が高い団体ほど得だ」と読まないでください。**地域手当は民間企業にはない概念です。**求人票が提示するのは基本給と諸手当を含んだ年収であって、「地域手当◯%」という内訳では書かれていません。相談でよく起きるのが、地域手当を含んだ現在の額面を基準に「これより下は受けられない」と判断し、**実際には条件の良い求人を最初から外している**ケースです。比べるときは、源泉徴収票の支払金額と、求人票の想定年収を突き合わせてください。手当の名目ごとに比べようとすると、必ず噛み合いません。
:::

### 平均年齢41.5歳という数字

もう一点。**愛知県の平均年齢41.5歳は、他県と比べて若い水準です。**長野県45.0歳、新潟県44.2歳、三重県43.5歳と並べると、その差が見えます。

平均年齢が低いということは、平均給料月額も低めに出るということです。愛知県の324,000円は、この年齢構成を含んだ数字です。**ラスパイレス指数（学歴や経験年数を補正済み）とは意味が違うので、混ぜて読まないでください。**

そして、上の平均は自分の給与ではありません。民間の求人票と比べるときは、**自分の源泉徴収票の支払金額**を使ってください。

| 企業誘致・立地支援 | 事業開発、用地開発、アライアンス |
| 産業支援・技術支援の施策 | 産学連携、技術企画、事業開発 |
| 港湾・物流の計画と調整 | インフラ企画、物流ネットワーク設計 |

| 農林水産の産地形成・輸出支援 | 事業開発、産地開発、海外展開 |
| 環境・エネルギー政策 | サステナビリティ、GX事業企画 |

## 愛知で、どの経験が値になるか

**1. ものづくりの集積を、行政側から支えてきた経験**

自動車を中心とした製造業の集積が、全国でも際立って厚い県です。県庁には**企業誘致、用地の確保、インフラの手当て、補助制度の設計、人材確保の支援、産学連携**といった実務があります。

進出や増設を考える企業から見れば、これは自分たちが最も苦労する部分です。**行政側で受け入れる仕事を経験した人は、外から採用しようとしても見つかりません。**

加えて、この県では**産業構造の転換**が現在進行形の課題です。電動化、脱炭素、サプライチェーンの見直し。**転換期の産業支援を実務として扱った経験**は、事業会社の企画部門やコンサルティング会社から見て、いま最も需要のある領域のひとつです。

**2. 港湾と物流**

港湾を抱える県として、物流と立地に関わる実務があります。**用地、環境影響、地元調整、他の管理者との協議。**物流施設の開発が全国で進むなか、立地に伴う行政手続きを知っている人は事業者側にほとんどいません。

**3. 大都市圏の交通と都市計画**

大規模な交通インフラの計画と協議。**関係者が多く、期間が長く、判断が割れる案件**を扱ってきた経験は、民間ではプロジェクトマネジメントとして読まれます。書くときは事業名ではなく、**関係者の数と、判断の決着のさせ方**で書いてください。

**4. 市町村を相手にしてきた経験**

政令市から小規模な町村まで、規模の幅が大きい県です。**同じ制度でも、相手の体制によって進め方をまったく変えなければならない。**この経験は、自治体を顧客にする企業から見ると、そのまま実務能力です。

売る側からいちばん見えないのが、この規模ごとの違いです。**県の立場で全域を回ってきた方は、この地図を頭の中に持っています。**

## 選択肢が多いときの、絞り方

愛知県庁の方の相談で多いのが、「どこから見ればよいか分からない」です。手順を3つに分けてください。

**1. 職種を先に決める**

県内に多様な職種があるため、勤務地で絞る意味が小さくなります。**先に絞るべきは職種**です。いまの経験がそのまま効く職種か、経験を持ち替える職種か。この2つは準備の量がまったく違います。

**2. 業界を2〜3に絞る**

同じ職種でも、業界によって評価される経験が変わります。**行政経験が効く業界を2〜3に絞ってから、企業を見てください。**自治体を顧客にする企業、規制の多い業界、まちづくり・不動産、そして製造業の企画・管理部門が典型です。

**3. 比べるのは源泉徴収票**

現在の額面を基準にする場合、**手当の内訳ではなく、源泉徴収票の支払金額**を使ってください。地域手当は民間にはない区分です。

## 職務経歴書に、県庁の仕事をどう落とすか

**制度名ではなく、判断したことを書く**

「○○推進事業を担当」では読み手に何も残りません。事業名は庁内でしか意味を持たない固有名詞です。**何件を、どういう基準で審査し、どこで判断が割れて、どう決着させたか。**

**産業支援は「支援」で終わらせない**

何社を相手に、どういう基準で選び、何を提供し、結果どうなったか。**ここまで書けば、事業開発やアライアンスの経験として読まれます。**

**異動歴を「立ち上げの回数」に変える**

異なる制度領域を短期間で立ち上げてきた経験は、民間では**キャッチアップの速さ**として読まれます。編年式で並べ、それぞれの配属で最初の数か月に何を習得したかを1行添えてください。

## 技術職の場合は、探し方が変わる

**発注者側の経験そのものが職種になる**

「発注者支援」という職種が、建設コンサルタント業界には確立しています。設計の審査、積算の確認、工事の監督、住民説明。県庁でやってきたことが、そのまま職務内容として書かれた求人です。

**資格が入口で効く**

技術士、施工管理技士、測量士、電気主任技術者。**実務経験の年数が受験要件になっているものは、在職中でなければ積めません。**取れるものがあるなら、動く前に取っておいてください。

**大規模インフラの実務は希少性が高い**

大規模な改良、輻輳する事業者との協議、長期にわたる工程管理。この規模の案件を発注者側で扱った技術者は限られており、民間側でも慢性的に不足しています。

## 面接で必ず詰められる2つのこと

**「意思決定のスピードに耐えられるか」**

行政は手続きの段数が多く、決裁を経て動きます。民間は月次で数字を締め、その場で方針を変えます。稟議の段数を弁解せず、**自分の判断で動かした範囲を具体的に答えてください。**

**「数字への意識があるか」**

「利益を意識したことはありますか」という形で聞かれます。「行政なので利益はありません」と答えると、そこで話が終わります。事業の優先順位を付けた、単価の根拠を詰めた、複数案を比べた。**同じ思考をしていたことを、民間の言葉で説明できるか**が見られています。

## 在職中に進めるときの注意点

**服務上の扱いを先に確かめる**

在職中に得た情報を持ち出すことは避けなければなりませんし、退職後の営業活動についても扱いを確認しておいたほうが安全です。**判断に迷う場合は、応募の前に人事担当課に制度上の取扱いを確認してください。**応募先が現在の担当業務の相手方である場合は、とくに慎重に扱う必要があります。

**面接の日程は、議会日程から逆算する**

地方自治法第211条は、長が毎会計年度予算を調製し、年度開始前に議会の議決を経なければならないと定めています。都道府県は年度開始前30日までに予算を議会へ提出するようにしなければならない、とも書かれています。決算は、出納閉鎖後3か月以内の長への提出、監査委員の審査、議会の認定という順です（第233条）。**予算編成の山と定例会の会期中は、平日日中の面接を入れるのが難しくなります。**

**在職中に決める**

公務員には雇用保険が適用されないため、辞めてから探すと収入のない期間がそのまま持ち出しになります（[公務員に雇用保険がない理由](seido-shitsugyo-nashi.html)）。

:::insight
ここまで転職の話を書いてきましたが、**残る判断にも理があります。**平均年齢41.5歳という若い組織にいるなら、焦って動く必要はありません。いま担当している領域で通しの経験が積み切れていないなら、それを終えてから動くほうが、書けることは確実に厚くなります。県内に大きな民間市場があるぶん、**「動くなら転居を伴う」という制約がなく、機が熟すまで待っても選択肢はそれほど減りません。**異動の希望が通る見込みがあるなら、まずそちらを試すのも合理的です。ただし、自分の経験が外でどう呼ばれるかを知っておくことには、動かない場合でも意味があります。次の異動希望を出すときの材料が変わるからです。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 愛知県の一般行政職は**ラスパイレス指数101.0、平均給与月額430,525円**（令和6年4月1日現在・総務省調査）
- **地域手当は国の指定基準8.5%に対し、実際の支給割合は約10.85%。差は約2.35ポイントで、ここまでで最大の上乗せ**です
- **地域手当は民間にない概念です。**源泉徴収票の支払金額と、求人票の想定年収で比べてください
- 平均年齢41.5歳は若い水準です。**ラスパイレス指数（補正済み）と平均給料月額（補正なし）を混ぜて読まないでください**

- 選択肢が多いので、**先に職種、次に業界を2〜3に絞る**という順序が有効です

## よくある質問

### 地域手当がなくなると、実質的に給与が下がりませんか

**下がる場合はあります。**ただし民間企業の給与体系には地域手当という区分がなく、勤務地の物価や相場は基本給や各種手当に織り込まれています。したがって「地域手当の分だけ減る」という比べ方自体が成り立ちません。**現在の源泉徴収票の支払金額**を基準にして、求人票の想定年収と比べてください。名古屋圏勤務の求人であれば、相場はその前提で組まれています。

### 産業構造の転換に関わった経験は、どう書けばよいですか

**施策名ではなく、判断の中身で書いてください。**どの分野を重点に置くと決めたのか、その根拠は何だったか、既存の支援先とどう折り合いをつけたか。転換期の意思決定は、民間の事業ポートフォリオの見直しとまったく同じ構造です。**何を残し、何を落とし、それを誰にどう説明したか**まで書けば、事業企画の経験として読まれます。

### 県庁と名古屋市役所では、転職のしやすさが違いますか

**経験の翻訳という点では、大きな違いはありません。**どちらも制度を回す側の経験です。強いて言えば、県は広域と市町村の調整の仕事が多く、市は住民と事業者を直接相手にする仕事が多いため、**「誰を相手にしてきたか」の説明の仕方が変わります。**自治体向けの事業を持つ企業では県の経験が、住民接点のあるサービス業では市の経験が噛み合いやすい傾向があります。
