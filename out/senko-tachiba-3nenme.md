**「3年は続けたほうがよい」と言われた、というご相談を伺います。**

**この目安に、根拠はあるのでしょうか。**

この記事では、**制度の前提**と、**判断の材料**を扱います。

## 年数を定めた規定はありません

**民法第627条第1項**です。

> **当事者が雇用の期間を定めなかったときは、各当事者は、いつでも解約の申入れをすることができる。**この場合において、雇用は、**解約の申入れの日から二週間を経過することによって終了する。**

**期間の定めのない雇用では、いつでも解約の申入れができる**という原則です。

**「◯年勤めなければならない」という定めは、置かれていません。**

**なお、公務員の勤務関係は任用によるもの**です。

**退職の手続きは、条例・規則によって定められています。**

**申出の時期や手続きの流れは、所属の人事担当に確認**してください。

**いずれにしても、「3年」という年数に、法令上の根拠があるわけではありません。**

**目安として語られているもの**です。

## では、何を基準にするか

| 基準 | 確認すること |
|---|---|
| ① 続けにくい理由が、配置で解消するか | **異動の周期と、希望の仕組み** |
| ② その分野で身につくものが残っているか | 次の段階で担う業務 |
| ③ 条件の合う求人が存在するか | 実際に探してみる |
| ④ 説明できる状態か | **変わる理由を言葉にできるか** |
| ⑤ 体調・生活 | 続けられる状態か |

**この5つで判断してください。**

**年数ではなく、材料で決める**という形です。

**④が揃っていない段階で動くと、次も同じ理由で続きにくくなります。**

## ①——配置で解消するか

| 続けにくい理由 | 配置で変わるか |
|---|---|
| 業務の量 | **課によって異なります** |
| 扱う内容 | 変わります |
| 対外の対応の多さ | 変わります |
| 人との関わり | 変わることがあります |
| 組織の全体の風土 | 変わりにくい |
| 働き方の制度 | 団体全体の制度による |

**5行目と6行目です。**

**これらは、配置が変わっても残ります。**

**一方、上の4つは、課が変われば変わる**ことがあります。

**役所は、数年で配置が変わる仕組み**になっています。

**次の異動で状況が変わる可能性を、材料に入れてください。**

## 3年目で書けること

| 項目 | 内容 |
|---|---|
| 担当した業務 | 件数、対象、範囲 |
| 制度への対応 | 改正、新しい事業 |
| 対外の対応 | 相手と内容 |
| 改善 | 様式、手順、記入例 |
| 使ったシステム | 名称と、何をしたか |

**1行目です。**

**3年あれば、年間の業務の周期を複数回経験しています。**

**当初予算の編成、議会の時期、決算、異動。**

**1年目には見えなかった全体の流れが見えている**はずです。

**これは、書類に書ける内容**です。

**書き方は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 面接での説明

| 避けたい説明 | 置き換え |
|---|---|
| 3年目なので、そろそろ | **何をしたいかを述べる** |
| 合わなかった | 続けたい部分と、続けにくい部分を分ける |
| 周りも辞めている | 自分の理由を述べる |
| 成長できない | 何を身につけたいかを述べる |

**1行目です。**

**年数を理由にすると、次も年数で動くと受け取られます。**

**理由は、業務の中身で語ってください。**

**「担当した◯◯の業務のうち、◯◯の部分を続けたいと考えた。いまの職場では、その部分の比重が小さい」**という形です。

:::insight
年数について、**面談でお伝えしているのが「3年という目安は、材料が揃う時期の目安として使ってください」**という点です。**「3年勤めないと評価されない」という意味に受け取る方**が多いのですが、実際に効いているのは別の理由だと考えています。**1年目・2年目は、判断の材料が少ない。**配属された課しか知らず、年間の業務の周期も一巡していません。**3年経つと、複数の課を経験し、周期も複数回見ています。**つまり、**「いまの職場で続けにくい理由」が、課の問題なのか、組織の問題なのかを見分けられるようになる。**この見分けがつく時期が、おおむね3年目あたりだということです。ですから、**3年という数字を守るのではなく、材料が揃ったかどうかで判断してください。**材料が早く揃う方もいます。**そして、体調に影響が出ている場合は、年数の話より先に対処してください。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 準備の順序

| 順 | やること |
|---|---|
| 1 | 続けにくい理由を、業務の要素に分ける |
| 2 | **配置で変わるものか見分ける** |
| 3 | 異動の希望の仕組みを確認する |
| 4 | 求人を読み、条件の合うものがあるか確認する |
| 5 | 職務経歴書を1通作る |
| 6 | 判断する |

**4と5を、判断の前に置いてください。**

**条件の合う求人が存在するかを知らないまま判断すると、想定が立ちません。**

**5について。**

**書いてみると、自分の経験の整理がつきます。**

**書けることが思ったより多い**ということも、**少ない**ということも分かります。

[経験の言い換えから相談する](../apply.html)こともできます。

## 在職中の進め方

| 項目 | 内容 |
|---|---|
| 業務の記録 | 月に1回、数行 |
| 求人を読む | 週に30分 |
| 制度の確認 | 異動の希望、退職の手続き |
| 条件の見直し | 月に1回 |

**3行目です。**

**退職の手続きの期間は、制度の照会として確認できます。**

**退職の意思を伝える必要はありません。**

**扱いは**[選考スケジュールの組み方](senko-sagasu-schedule.html)**に整理しています。**

## 3年目に確認しておくこと

| 項目 | 確認先 |
|---|---|
| 異動の希望の仕組み | 人事担当 |
| 次の段階で担う業務 | 上司、先輩 |
| 退職の手続きの期間 | 人事担当 |
| 退職手当の扱い | 給与担当 |
| 研修・資格の機会 | 人事担当 |

**2行目です。**

**次の段階で何を担うことになるかを、先に聞いておいてください。**

**いまの業務の延長なのか、別の役割が加わるのか。**

**これが分かると、②の判断ができます。**

**5行目について。**

**在職中に得られる研修や資格の機会**があります。

**取得してから動くという選択**もあります。

**時期と要件を確認**してください。

**資格は、在職中に取るほうが負担が小さいことがあります。**

## よくある失敗

**1. 年数だけで判断する**

**材料で判断**してください。

**2. 配置で変わるかを見分けない**

**課によって変わるものがあります。**

**3. 異動の希望の仕組みを確認しない**

**手段が1つ減ります。**

**4. 求人を見ずに決める**

**条件の合うものがあるか分かりません。**

**5. 面接で年数を理由にする**

**業務の中身で語って**ください。

**6. 3年目で書けることを少なく見積もる**

**周期を複数回経験しています。**

**7. 体調の問題を年数の話に混ぜる**

**先に対処**してください。

**8. 書類を作らずに判断する**

**書くと整理がつきます。**

:::insight
ここまで年数の話をしておいて逆のことを言いますが、**3年勤めたからといって、転職しなければならないわけではありません。**面談で拝見していると、**「3年経ったから動かなければ」と考える方**がいらっしゃいます。**年数は、動く理由にも、動かない理由にもなりません。**判断の基準は、**いまの職場で担いたい仕事があるかどうか**です。あるなら、**その仕事に就ける見込みを確認してください。**異動の希望、必要な経験、時期。**見込みが立つなら、残る理由になります。**一方、**見込みが立たない、あるいは担いたい仕事が外にあるなら、動く理由になります。**どちらの場合も、**材料は同じ**です。担いたい仕事、就ける見込み、条件。**この3つを並べて判断してください。**そして、**判断を先送りにしても、材料を集める作業は進められます。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **民法第627条第1項**は、**期間の定めのない雇用では、いつでも解約の申入れができる**と定めています。**「◯年勤めなければならない」という定めはありません**
- **公務員の退職の手続きは、条例・規則**によります。**所属に確認**してください
- 判断は、**①配置で解消するか ②身につくものが残っているか ③条件の合う求人があるか ④説明できる状態か ⑤体調・生活**の5つで行ってください
- **組織の風土と働き方の制度は、配置が変わっても残ります**
- **3年目は、年間の周期を複数回経験している**時期です。書けることがあります
- **面接で年数を理由にしない**でください。業務の中身で語ってください
- **3年経ったから動く、という理由にもなりません**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 3年未満で応募すると、書類で落ちますか

**求人の条件によります。**応募条件に**「◯年以上の実務経験」**と書かれている場合、**その年数が必要**です。一方、「基礎的な事務の経験」「行政での実務経験」と書かれている場合は、**年数が明示されていません。**この場合、**経験の中身で判断されます。**なお、**未経験を前提とする募集**では、年数より**学ぶ姿勢と基礎的な処理の力**が見られることがあります。判断の目安は、**求人票の「必須」の欄**です。読み方は[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。**条件を読んでから判断**してください。

### 周りに相談すると、続けるよう言われます

**相談する相手によって、返ってくる答えが変わります。**役所の中で相談すれば、**続ける前提の助言**が返ってくることが多いです。これは、**相手がその立場で見ているから**であって、助言が間違っているという意味ではありません。**材料の1つとして受け取ってください。**そのうえで、**外の情報も集めてください。**どんな仕事があるか、条件はどうか、自分の経験がどう読まれるか。**両方の材料が揃って、初めて比べられます。**なお、**相談した相手に決めてもらう必要はありません。**判断は、ご本人のものです。**材料を集める作業を、相談と並行して進めてください。**

### 異動の希望を出すのと、転職を考えるのは両立しますか

**両立します。**異動の希望を出したうえで、**外の求人も見る**という進め方で差し支えありません。**どちらも、材料を集める作業**だからです。異動が通れば、**続けにくい理由が解消する**かもしれません。通らなければ、**外の選択肢を検討する材料**になります。なお、**異動の希望を出したことが、転職の意思として受け取られることはありません。**希望を出す仕組みは、**通常の人事の手続き**です。**求人を読むことも、応募の意思がなくてもできます。**並行して進めて、**結果が出た段階で判断**してください。
