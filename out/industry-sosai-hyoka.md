葬祭・冠婚葬祭の会社で公務員経験を説明するときは、相談、企画や施行、運営の補助、事務等の職務を分けます。公務での届出の案内、問い合わせの整理、関係者との連絡にも、本人が説明できる工程があります。そのことと、葬儀を施行した経験や専門の役割を担ったことは別に確認できます。

本記事は2026年11月時点の公開情報にもとづきます。確認日は2026年11月25日です。採用側の非公開の評価基準や採否の理由は確認できません。また、ご遺族の心理を一般化したり、特定の対応で気持ちが変わると説明したりするものではありません。公式の職務と本人の事実を照合します。

## 雇用する法人と具体的な職務を確認する

京王メモリアルの公式募集ページは、京王フェアウェルサポートの採用として、新卒、中途、パート・アルバイトを分けて案内しています。今回確認するのは、葬祭ディレクター・スタッフの正社員の中途募集です。ブランドの表示だけでなく、本人を雇用する会社を確認します。

その中途募集は、式場の設営や運営、司会進行、葬儀の企画や打合せ、搬送や手続き、事前の相談やその後の支援等を示しています。行政の死亡に関わる届出を案内したことと、この一連の施行の仕事を担ったことは別に読みます。

燦ホールディングスの採用サイトにも、株式会社葬仙の仕事が紹介されています。葬儀ディレクターと、準備や片付け、事務所内の作業等を行うサービス・フロントスタッフを分けています。持株会社と今回採用する事業会社、別のグループ会社を混ぜないようにします。

葬祭と、婚礼等の別の事業も同じ条件とは限りません。今回確認した葬祭の職務を、冠婚葬祭に関わる全ての会社や職種へ広げません。別の仕事を希望する場合は、その法人の正式な募集で担当と条件を読み直します。

| 分ける対象 | 確認する内容 | 経験の照合で残す違い |
| --- | --- | --- |
| 法人 | 今回本人を採用する会社 | ブランドや持株会社だけの理解 |
| 施行と運営 | 企画、準備、進行、連絡等 | 行政の届出や案内だけの経験 |
| 補助と事務 | 個別に担当する作業 | 別の職種の全工程 |
| 採用区分 | 中途の正社員等 | 新卒やパートの選考と勤務 |

職務の違いを比較したい方は、[掲載中の求人を仕事内容から確認できます](../?gov=1)。葬祭という名称に加えて、本人が行う工程を読むために使えます。

## 公務の説明は対象と確認した範囲を示す

公務で手続きの案内を担当した場合は、どの質問を聞き、何を確認して、どこまで説明したかを記述できます。本人で判断できない内容を専門担当へ照会したなら、その工程を示します。申請や許可を別の担当が決定した場合、その権限まで本人の実務にはしません。

死亡に関わる窓口での案内を経験していても、葬儀の企画や見積、施行をしたことには自動的になりません。担当した手続きと、会社でこれから担う仕事を別々に確認します。本人の経験は具体的に残し、未経験の専門実務を追加しないようにします。

相手の希望を整理した経験があれば、質問の対象や確認した手順を説明できます。ただし、ご遺族が何を感じていたか、どの言葉で安心したか等を、確認していないのに実績として書く必要はありません。本人が実施した確認や説明の工程を中心に記述します。

公務の窓口と、事業者として契約やサービスを提案する仕事も同じではありません。本人が費用や商品の提案、契約を担当していないなら、その実務を加えません。今回の職務でどこまで担当するかを、正式な募集と案内から確認します。

:::insight
死亡に関わる手続きの案内を経験していても、葬儀の施行を経験したことと同じにはなりません。本人が質問を聞き、必要な情報を確認し、どこまで説明したかを残します。許可や専門上の判断を別の担当が行ったなら、その権限も分けます。接点のある説明や連絡の工程は具体的に示せますが、企画や見積、搬送、式の進行等を担当していなければ未経験として残せます。ご遺族の気持ちを推測して成果を作る必要もありません。採用側の評価を予測するより、本人が実際に行ったことと今回の仕事を同じ意味で比較できる説明にすることを優先できます。
:::

## 連絡や運営は本人の作成物までたどる

公務で会議や行事の運営を担当した場合は、会場、案内、受付、関係者への連絡、当日の役割等を分けます。全体の方針を上司が決め、進行を外部が担当したなら、本人が行った部分を具体的にします。運営という名称だけで全ての工程を含めないようにします。

葬仙の仕事紹介も、施行や運営と、場面によって専門スタッフが支える役割を分けています。今回どの担当を採用するのかを確認し、公務の行事を運営した経験から、専門の式の進行まで経験したとはしません。

日程の調整では、希望を取りまとめたこと、相手へ確認したこと、回答を受けて確定したことを分けられます。希望日を連絡したことだけで会場の利用が確定したとは扱いません。本人が何を決め、何を他者へ確認したかを残すことが大切です。

事務でも、扱った書類や入力、照会した項目を具体的に示せます。費用の書類を確認したことと、契約や支出を決定する権限は別です。別の業界の事務を経験していても、今回の会社で同じ手順が使われるとは断定しません。

## 架空の整理表で経験と未経験を並べる

以下は書き方のために独立して作成した架空例です。実在の応募者、企業の回答、実際の面談の記録ではありません。特定の求人の必須条件を満たす例でもありません。使う際は本人の事実へ置き換え、未実施のことを削除してください。

| 項目 | 架空の記入例 |
| --- | --- |
| 検討する仕事 | 葬祭の施行に関わる職務と、運営の補助を別々に調べている |
| 公務での担当 | 一般の手続きの問い合わせを整理し、必要な窓口を案内した |
| 自分の作業 | 質問の対象を確認し、公開の案内と担当部署への照会をもとに説明した |
| 他者の判断 | 手続きの可否や専門上の判断は担当部署が行った |
| 未経験 | 葬儀の企画、見積、搬送、設営、司会、施行全体の管理 |
| 応募条件の確認 | 社会人経験、年齢の条件、免許と運転、今回の採用区分を照合する |
| 未確認 | 個別の配属、勤務の運用、本人へ提示される条件 |

この例なら、質問の整理と窓口の案内が本人の工程です。「葬祭の全工程を支援した」と書くと、していない施行の仕事まで含むように読めます。本人が作った案内や確認した内容を、実際の範囲で説明できます。

窓口の利用者がどのような気持ちになったかを、確認していなければ加えません。心理的な効果を結果にする代わりに、どの情報を調べ、誰へ確認し、何を伝えたかを書けます。相談の詳細や個人が分かる記録を応募に持ち出す必要もありません。

経験の範囲を整理したい方は、[職務経歴と希望する仕事の照合を相談できます](../apply.html)。ご利用は無料です（紹介手数料は採用企業の負担）。経験や希望等により、求人の紹介や面談等をご提供できない場合があります。

## 未経験歓迎でも今回の応募条件を残す

京王フェアウェルサポートの前記中途募集は、学歴不問で職種や業務の未経験を歓迎しています。一方、正社員、契約社員、派遣社員としての社会人経験があることと、年齢の条件を示しています。未経験歓迎を全ての条件がないという意味にはしません。

年齢は三十五歳までという記載があり、業界や業種の経験者は年齢を問わないという案内もあります。公務での届出の所管を、そのまま業界の経験者と判断しません。本人の職歴がどの対象か不明なら、今回の採用担当へ具体的な担当を示して確認します。

普通自動車免許はAT限定可で、運転に支障がないことが必須とされています。免許の保有と、今回の業務で求められる運転の条件を照合します。公務での説明の経験だけで、この条件を代替するとは判断しません。

葬仙の会社紹介のFAQは、業界未経験でも応募できる旨と、運転する職種では免許が必要なことを説明しています。ただし、これは別の法人の案内です。京王の中途募集の条件を緩める根拠にはせず、個別の職種と正式な募集を確認します。

## 勤務や契約は経験の接点と別に確認する

京王の前記中途募集は正社員で契約期間の定めがなく、試用期間は三か月、その間の給与や待遇に変更はないとしています。パートの登用実績や選考を、中途の正社員の条件へ混ぜません。今回の区分を固定して読みます。

勤務は月単位のシフトで、日勤と夜勤が示されています。初年度の夜勤の扱いも記載されていますが、それだけで将来も日中のみの仕事とはしません。中途の夜勤の休憩と、新卒の欄の記載は別に確認します。

給与は経験等を考慮して決め、各種の手当や賞与等も案内しています。制度の存在から本人の支給を確定せず、正式な条件を確認します。給与額の大小を理由に応募を勧めず、場所や時間、契約と合わせて比較できます。

:::insight
説明や連絡の経験に接点があっても、葬祭の仕事の全てを経験済みとする必要はありません。今回の施行や運営の担当を読み、本人の作業と未経験を別々に残します。その上で、社会人経験や年齢、免許と運転の条件を確認できます。勤務についても、日勤や夜勤、初年度の扱い、契約の区分を分けて読みます。業界未経験を歓迎する案内や研修の制度は、本人の採用や希望の勤務を保証するものではありません。条件が合う募集がまだなければ、現職を続けて比較する判断も同等です。退職を先に決めず、仕事内容と本人への提示を確認して選択できます。
:::

## 個人情報を使わず応募先ごとに説明を整える

職歴のメモは、対象、目的、自分の作業、他者の判断、未経験を分けて作れます。窓口の案内と行事の運営を別の時期にしていたなら、期間と担当も分けます。複数の部署の作業を合わせて、葬祭の企画から施行まで全体を担ったことにはしません。本人が自分の言葉で説明できる工程を確定してから、求人と照合します。

資格の支援や研修の制度を調べる場合も、何の職務のために必要かを先に確認します。制度があることと、本人が同じ時期に取得や担当の拡大へ進むことは別です。保有している資格、学習中、取得の予定を分け、予定だけを完了した実績として記入しないようにします。

勤務の希望がある場合は、本人の希望として整理できます。日中だけを希望していることと、その条件で採用側が承認したことは別です。正式な回答を受けるまでは未確認として残し、対応できる範囲を広げて答える必要はありません。

公務で扱った届出の内容、亡くなった方やご遺族の情報、相談の記録、内部の連絡先や審査の資料等を応募に持ち出しません。業務の名簿を応募後の営業等に使える情報として提供する必要もありません。内部資料を私用の端末や外部の生成AIへ渡すことも避けます。

説明用の表が必要なら、架空の内容で独立して作成したことを明記できます。相手の事情を詳しく再現するより、本人が確認した情報と行った工程を示せます。専門上の判断や権限は、担当した人のものとして残します。

別の法人や職種を検討する場合は、社名だけを差し替えず、仕事と条件を読み直します。過去の担当は変えず、どの工程が今回の仕事と接するかを選べます。条件への回答を受けた場合も、今回の法人と職種の回答として記録します。

募集の受付や条件は閲覧時に公式の最新情報を確認します。終了した募集は過去の参考です。在職中に準備する場合も、公務の勤務と私用を分け、面談等は所属の休暇の手続きを確認して調整できます。現職を続ける判断も残せます。

確認事項をまとめたい方は、[LINEで経験や職務の違いを短く整理することもできます](https://line.me/R/ti/p/@697nxhbt)。情報収集の段階でも利用できます。

## よくある質問

### 死亡に関わる窓口の経験は施行の経験になりますか

行政の手続きの案内と、葬儀の企画や施行は別です。本人が何を確認し、どこまで説明し、誰へ引き継いだかを示せます。搬送や設営、司会等を実施していなければ、その実務は加えず今回の職務と照合します。

### 未経験歓迎なら年齢や免許も問いませんか

今回の京王の中途募集には、社会人経験や年齢、免許と運転の条件があります。業界の経験者について別の案内もあるため、本人の職歴と照合します。他社の未経験歓迎の説明を使って、今回の条件を省略することはできません。

### 転職を決めていなくても仕事を比較できますか

比較できます。職務、応募条件、勤務する場所や時間、契約を整理できます。この記事は退職を勧めるものではなく、現職を続ける判断も同等です。本人の経験の接点と、生活上対応できる条件を分けて確認できます。
