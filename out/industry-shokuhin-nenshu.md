農業・食品の分野を検討される方に、**最初にお伝えしている条文**があります。

**この分野には、労働時間の規定が適用されない事業があります。**

**これは、違法な運用の話ではありません。****法律にそう書かれています。**

**知らずに入ると、想定と食い違います。**逆に、**知っていれば、確認すべきことがはっきりします。**

この記事では、**何が根拠になっているか**と、**職種によって何が変わるか**を扱います。業界の構造は[未経験から農業・食品に入るには](industry-shokuhin-mikeiken.html)にあります。

**⚠ なお、給与の水準について、当社が数字でお答えすることはできません。**会社ごとに事情が違いますし、**裏を取っていない数字を並べるのは、この記事の趣旨に反します。**

## 農業の事業は、労働時間の規定の適用除外です

**労働基準法第41条**です。

> **（労働時間等に関する規定の適用除外）第四十一条　この章、第六章及び第六章の二で定める労働時間、休憩及び休日に関する規定は、次の各号の一に該当する労働者については適用しない。**
>
> **一　別表第一第六号（林業を除く。）又は第七号に掲げる事業に従事する者**

**その「別表第一」**を見てください。

> **六　土地の耕作若しくは開墾又は植物の栽植、栽培、採取若しくは伐採の事業その他農林の事業**
>
> **七　動物の飼育又は水産動植物の採捕若しくは養殖の事業その他の畜産、養蚕又は水産の事業**

**第六号から林業を除いたもの——つまり農業——と、第七号の畜産・養蚕・水産の事業**に従事する者には、**労働時間、休憩及び休日に関する規定が適用されません。**

**⚠ 理由は、これらの事業が天候や生物の状態に左右され、時間で区切れないから**だと説明されます。

**⚠ ここで、取り違えないでいただきたいことが3つ**あります。

| よくある誤解 | 実際 |
|---|---|
| 「何をしてもよい」ということ | **違います。**年次有給休暇や深夜業の割増など、**適用される規定はあります** |
| 食品の工場も同じ | **違います。**食品の製造は別表第一の別の号に当たり、**適用除外ではありません** |
| 農業法人の事務職も同じ | **確認が必要です。**従事する業務によります |

**2つ目が、この記事でいちばん重要な点**です。

## 食品の製造は、適用除外ではありません

**[未経験から農業・食品に入るには](industry-shokuhin-mikeiken.html)で整理したとおり、この分野は「作る」と「加工・販売する」で分かれます。**

**そして、働き方の枠組みも分かれます。**

| 区分 | 労働時間の規定 |
|---|---|
| 農業・畜産・水産の事業に従事 | **第41条第1号により適用除外** |
| 食品の製造 | **適用される** |
| 卸・流通、小売 | **適用される** |
| 地域商社、コンサルタント | **適用される** |

**公務員から入りやすい職種——食品の製造の管理部門、品質保証、地域商社、コンサルタント——は、いずれも適用される側**です。

**⚠ ですから、「農業の分野は労働時間が青天井」という理解で候補を外さないでください。**

**一方、農業法人に入る場合は、自分の従事する業務がどちらに当たるかを確認してください。**

## 給与の根拠は、条例から就業規則に変わります

**地方公務員法第24条第1項**は、**「職員の給与は、その職務と責任に応ずるものでなければならない」**と定め、**同条第2項**は、**生計費・国や他の地方公共団体の職員・民間事業の従事者の給与その他の事情を考慮して定められなければならない**としています。

**労働基準法第89条**は、**常時10人以上の労働者を使用する使用者に、就業規則の作成と行政官庁への届出**を義務づけ、**記載事項として「賃金の決定、計算及び支払の方法、賃金の締切り及び支払の時期並びに昇給に関する事項」**を挙げています。

| | 役所 | 農業法人・食品会社 |
|---|---|---|
| 根拠 | **条例** | **就業規則・給与規程** |
| 見られるか | **公表されている** | 在職者は見られる。応募時は要確認 |
| 繁閑 | 年度の暦 | **収穫期・製造の繁忙期** |
| 規程の整備 | 完備 | **小規模な法人では整備の途中のことも** |

## 働き方は、職種で分かれます

| 職種 | 繁忙の時期 | 勤務の時間帯 | 役所との差 |
|---|---|---|---|
| 生産（農業法人） | **収穫期・作付けの時期** | 日の出に合わせることも | **差が大きい** |
| 食品の製造の現場 | **製造の繁忙期** | 交替制のことがある | 差が大きい |
| **品質保証** | **監査・検査の時期** | 通常の時間帯が多い | **近い** |
| **総務・人事・経理** | 決算・給与の時期 | 通常の時間帯 | **近い** |
| 購買・調達 | 原料の調達の時期 | 通常の時間帯 | 近い |
| **地域商社・コンサルタント** | **催事・年度末** | 通常の時間帯 | **近い** |

**下の4つは、他の業界の管理部門と大きく変わりません。**

**⚠ ただし、食品の製造では、工場の稼働に合わせた対応**が出てきます。早朝の立会い、休日の点検、事故が起きたときの呼び出し。**頻度は会社と職種によります。**

:::insight
面談で伺っていて、**この分野に移った方が最初に戸惑うのが「季節で仕事の量が変わる」**という点です。役所の繁忙は、**予算・決算・議会・異動**という、**暦で決まった山**でした。この分野の繁忙は、**作物の生育と天候**で動きます。収穫が前倒しになれば、加工も出荷も前倒しになる。**予定していた日程が、自然条件で動きます。**これを不便と感じる方と、**面白いと感じる方**に分かれます。そして、**管理部門であっても無関係ではありません。**原料が予定より早く入れば、受入れの記録も、支払いの処理も、その時期に寄ります。⚠ ですから、確認していただきたいのは、**「年間のうち、いちばん忙しいのはいつで、それは何で決まりますか」**という質問です。暦で決まるのか、天候で決まるのか。**天候で決まると答えられた場合、その振れ幅も聞いてください。**「例年、どのくらい前後しますか」。**この2問で、生活の組み立て方が読めます。**なお、**年次有給休暇の仕組みそのものは、適用除外の事業であっても適用されます。**取りにくい時期があるかどうかは、運用の話です。**制度の話と運用の実態は別**なので、分けて確認してください。
:::

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 場面 | 効く理由 |
|---|---|
| 許可・届出の手続き | **審査する側の観点を知っている** |
| 監査・検査への対応 | **検査する側にいた** |
| 記録の整備と保存 | 後から検証される前提の書類 |
| 補助金の申請と実績の報告 | **交付する側にいた** |
| 規程・手順書の整備 | 要綱を条文の形で書いてきた |
| 事故・苦情への対応 | **調査の手順を知っている** |

**効きにくい場所**

| 場面 | 効きにくい理由 |
|---|---|
| 天候で予定が動く | **自分の暦で組み立ててきた** |
| 原価と歩留まりの管理 | 予算の執行とは見る方向が違う |
| 現場の作業の段取り | 時間単位で動く感覚 |
| 価格の交渉 | 値決めの判断を自分でする |
| 早朝・交替制の対応 | 生活のリズムが変わる |

**1つ目が、この分野の特徴**です。

**ただし、災害対応を経験した方**は、**「自然条件で計画が崩れる」状況を知っています。**その経験は、材料になります。

## 入る前に確認しておくこと

**労働基準法第15条第1項**は、**労働契約の締結に際して、賃金・労働時間その他の労働条件を明示しなければならない**と定めています。**明示すべき事項は、労働基準法施行規則第5条**に具体的に並んでいます。

| 確認すること | どこで確認するか |
|---|---|
| 賃金の決定・計算・支払の方法、昇給 | **給与規程・労働条件通知書** |
| **従事する業務の内容** | **労働条件通知書** |
| ⚠ **労働時間の規定の適用の有無** | **面接で確認する** |
| 就業の場所（**工場・産地の所在地**） | 労働条件通知書 |
| **交替制・早朝の勤務の有無** | **面接で確認する** |
| 繁忙期と、それが何で決まるか | **面接で確認する** |
| 年次有給休暇の取得の実態 | 面接で確認する |

**3つ目を、農業法人に応募する場合は必ず確認してください。**

**⚠ 聞き方は、「私が従事する業務は、労働基準法第41条第1号の適用除外に当たりますか」**で構いません。**この質問に明確に答えられる会社は、労務の管理が整っています。**

**逆に、質問の意味が通じない、あるいは曖昧にされる場合**は、**その反応自体が判断材料**です。

## まとめ

- **労働基準法第41条第1号**は、**別表第一第六号（林業を除く。）又は第七号に掲げる事業に従事する者**について、**労働時間、休憩及び休日に関する規定を適用しない**と定めています
- **別表第一第六号**は**「土地の耕作若しくは開墾又は植物の栽植、栽培、採取若しくは伐採の事業その他農林の事業」**、**第七号**は**「動物の飼育又は水産動植物の採捕若しくは養殖の事業その他の畜産、養蚕又は水産の事業」**です
- ⚠ **「何をしてもよい」という意味ではありません。**年次有給休暇など、**適用される規定はあります**
- ⚠ **食品の製造、卸・流通、小売、地域商社、コンサルタントは、適用除外ではありません。****公務員から入りやすい職種は、いずれも適用される側**です
- **農業法人に応募する場合は、自分の従事する業務がどちらに当たるかを確認**してください
- **給与の根拠が、条例から就業規則・給与規程に変わります**
- ⚠ **繁忙が、暦ではなく天候で決まる**ことがあります。**「いちばん忙しいのはいつで、それは何で決まりますか」「例年どのくらい前後しますか」**の2問で読めます
- **年次有給休暇の制度と、取得の実態は別**です。分けて確認してください
- ⚠ **一つの職種が合わなくても、この分野ごと諦める必要はありません**

## よくある質問

### 農業法人の事務職は、適用除外になりますか

**⚠ この記事では判断できません。**適用除外の対象は、**第41条第1号が定める事業に「従事する者」**です。**従事する業務の実態によって判断される**ため、職名だけでは決まりません。確認のしかたは、**面接で直接聞くこと**です。「私が従事する業務は、労働基準法第41条第1号の適用除外に当たりますか」。そのうえで、**労働条件通知書に記載される「従事すべき業務」の内容**を確認してください。⚠ **判断に迷う場合は、労働基準監督署に相談できます。**当社が個別の事案について判断することはできません。なお、**適用除外であっても、年次有給休暇や深夜業の割増など、適用される規定はあります。**「すべての保護が無くなる」ということではありません。

### 収穫期だけ極端に忙しいのでしょうか

**職種によります。**生産に直接関わる職種では、**収穫期と作付けの時期に集中**します。一方、**総務・人事・経理**のような職種では、**決算や給与の時期**が繁忙で、これは他の業界と変わりません。**品質保証**は、**監査や検査の時期**に集中します。確認のしかたは、面接で**「この職種の方の、一年の忙しさの山を教えてください」**と聞くことです。あわせて、**繁忙期に管理部門がどう関わるか**も聞いてください。現場が忙しくても、**職種によっては影響が限られる**ことがあります。⚠ **自分の職種での影響を確認してください。**

### 退職の時期は、いつにするのが良いですか

**この記事では判断できません。**退職手当の算定、共済の扱い、年次有給休暇の残りなど、**個別の事情で変わります。**所属の人事担当部署と、**共済組合の窓口で確認**してください。あわせて、**この分野では入社の時期を繁忙期の前後で相談される**ことがあります。現職の引き継ぎに必要な期間は、**選考の段階で伝えておいてください。**⚠ また、**産地の法人や、自治体から補助・委託を受けている法人に移る場合は、再就職に関する規程の確認も要ります。**所属の人事担当部署と、適用される条例・規程を確認してください。**当社が、いまの職を辞めることをお勧めすることはありません。**
