**「任期が短く、経歴が細切れに見える」**というご相談を伺います。

**これは、制度の仕組みによるもの**です。

この記事では、**その前提**と、**書き方**を扱います。

## 任期は、制度として定められています

**地方公務員法第22条の2第1項**は、**会計年度任用職員の採用**について定めています。

**同条第2項**です。

> **会計年度任用職員の任期は、その採用の日から同日の属する会計年度の末日までの期間の範囲内で任命権者が定める。**

**同条第3項**です。

> **任命権者は、前二項の規定により会計年度任用職員を採用する場合には、当該会計年度任用職員にその任期を明示しなければならない。**

**同条第4項**は、**勤務の実績を考慮したうえでの任期の更新**を定めています。

**同条第6項**です。

> **任命権者は、会計年度任用職員の採用又は任期の更新に当たつては、職務の遂行に必要かつ十分な任期を定めるものとし、必要以上に短い任期を定めることにより、採用又は任期の更新を反復して行うことのないよう配慮しなければならない。**

**任期が会計年度の単位になるのは、制度がそう定めているから**です。

**本人の勤務の評価によって短く区切られているわけではありません。**

**この点は、書類でも面接でも説明できます。**

## 経歴の書き方

| 書き方 | 内容 |
|---|---|
| **通算で書く** | 「◯年◯月〜◯年◯月（会計年度任用職員として更新）」 |
| 年度ごとに並べない | 細切れに見えます |
| 制度の名称を明記 | **任期が制度によることが伝わります** |
| 担当した業務を中心に | 期間より中身 |

**1行目です。**

**同じ職場で継続して勤務している場合、通算の期間で書いて差し支えありません。**

**「◯年間、◯◯の業務を担当（会計年度任用職員）」**という形です。

**年度ごとに行を分けると、実態より短く見えます。**

## 何を書くか

| 要素 | 内容 |
|---|---|
| ① 担当した業務 | 件数、対象、工程 |
| ② 使った制度・システム | 名称と、何をしたか |
| ③ 対外の対応 | 相手と、内容 |
| ④ 改善した点 | 様式、手順、記入例 |
| ⑤ 引継ぎ・指導 | 新しく入った方への説明 |
| ⑥ 勤務の形 | 時間、日数 |

**①と④が中心**です。

**④について。**

**「非常勤だから改善の提案はしていない」と考える方**がいらっしゃいます。

**ところが、日々の業務の中で、様式を直した、説明の文面を作った、手順を書き出した**ということはあるはずです。

**規模が小さくても、自分で動いた事実**になります。

## 書き方の例

**悪い例**

> ◯◯市（会計年度任用職員）　◯年度、◯年度、◯年度

**良い例**

> ◯◯市 ◯◯課（会計年度任用職員として◯年間）
> ◯◯に関する申請の受付から審査までを担当。**年間約◯件を処理**し、要件の確認とシステムへの入力、**窓口での説明**を実施。**説明の文面と記入例を作成**し、問い合わせの件数の減少に寄与。新しく配置された方への**業務の引継ぎ**を担当。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 面接での説明

| 聞かれること | 答え方 |
|---|---|
| なぜ任期が区切られているか | **制度上、会計年度の単位と定められている** |
| なぜ正職員ではないか | 採用の枠組みが別であること |
| なぜ民間を見るか | **何をしたいか**を述べる |
| 長く働けるか | 条件が合えば、という前提で |

**1行目です。**

**「制度上、任期が会計年度の単位と定められているため」**と説明すれば足ります。

**本人の評価によるものではない**という点が伝わります。

**3行目について。**

**「安定したいから」だけでは、次の条件が伝わりません。**

**担当してきた業務のうち、続けたい部分を述べて**ください。

:::insight
会計年度任用職員の方のご相談で、**面談でお伝えしているのが「職歴を年度で刻まないでください」**という点です。書類を拝見すると、**年度ごとに行を分けて書かれている**ことがあります。**同じ職場で3年続けていても、3行に分かれていると、短期間の勤務を繰り返した人に見えます。****これは、実態と違います。**制度上、任期が会計年度の単位と定められているだけで、**担当してきた業務は継続しています。**ですから、**通算の期間で1行にまとめ、括弧で「会計年度任用職員として更新」と添えてください。**そのうえで、**業務の中身を書く。**読む側が見ているのは、**何をどれだけ担当したか**です。そして、**面接で任期について聞かれたら、制度の仕組みを説明すれば足ります。**弁解する必要はありません。**説明できる事実**です。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 見る領域

| 領域 | 内容 |
|---|---|
| ① 同じ業務の受託 | **窓口の運営、事務の受託** |
| ② 一般の事務 | 管理部門、営業の事務 |
| ③ 顧客の対応 | 一次の受付、相談 |
| ④ 分野の専門 | 資格や経験に応じた領域 |
| ⑤ 行政が相手の事業 | 制度と手続きの理解 |

**①が、経験と最も重なります。**

**自治体の窓口や事務を受託する会社**があります。

**同じ業務を、別の立場で担う**形です。

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 準備の順序

| 順 | やること |
|---|---|
| 1 | 通算の期間を確認する |
| 2 | 担当した業務と件数を書き出す |
| 3 | **改善した点を書き出す** |
| 4 | 任期についての説明を用意する |
| 5 | 求人を読む |
| 6 | 職務経歴書を作る |

**3が要**です。

[経験の言い換えから相談する](../apply.html)こともできます。

## 在職中の進め方

| 項目 | 内容 |
|---|---|
| 記録 | 担当した件数、作成した資料 |
| 制度の確認 | **次年度の任期、更新の時期** |
| 求人を読む | 週に30分 |
| 日程の確保 | 年度の変わり目を避ける |

**2行目です。**

**次年度の任期がどうなるかは、時期が来れば示されます。**

**その時期を、人事担当に確認**しておいてください。

**分かれば、逆算して準備できます。**

**扱いは**[選考スケジュールの組み方](senko-sagasu-schedule.html)**に整理しています。**

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 何を担当したか | **件数、工程、期間** |
| 単独で処理できる範囲 | どこまで任されていたか |
| 立ち上がりの速さ | **引継ぎから何か月で担えたか** |
| 改善した点 | 作った資料、直した様式 |
| 勤務の条件 | 時間、日数の希望 |

**3行目です。**

**限られた期間で業務を覚えてきた経験**は、中途採用で見られる部分と重なります。

**「配属から◯か月で単独の処理に移行」**という形で答えられるよう整理しておいてください。

**5行目について。**

**フルタイムを希望するのか、短時間を希望するのか**を先に決めてください。

**条件が決まっていれば、求人を絞る軸になります。**

## よくある失敗

**1. 年度ごとに行を分けて書く**

**通算で書いて**ください。

**2. 制度の名称を書かない**

**任期が制度による**ことが伝わりません。

**3. 件数を書かない**

**規模が伝わりません。**

**4. 改善した点を書かない**

**自分で動いた事実**になります。

**5. 「安定したいから」だけで説明する**

**次の条件が伝わりません。**

**6. 任期について弁解する**

**説明できる事実**です。

**7. 更新の時期を確認しない**

**逆算できません。**

**8. 受託の会社を見ない**

**同じ業務を別の立場で担えます。**

:::insight
ここまで書き方の話をしておいて逆のことを言いますが、**会計年度任用職員として働いてきた方は、民間の採用で有利に働く面があります。**面談で拝見していると、**「非常勤だったので、経歴として弱い」と考える方**がいらっしゃいます。ところが、**採用する側が気にするのは、入社後にすぐ動けるか**です。会計年度任用職員は、**限られた期間で業務を覚え、成果を出すことを繰り返してきた**という経験があります。**引継ぎを受けて、短期間で立ち上がる。**これは、中途採用で求められる動作そのものです。そして、**複数の課や職場を経験している方**であれば、**新しい環境への適応が速い**という説明ができます。書類には、**「配属から◯か月で業務を引き継ぎ、年間約◯件を単独で処理」**と書いてください。**立ち上がりの速さは、評価される材料**です。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方公務員法第22条の2第2項**は、**会計年度任用職員の任期を、採用の日から会計年度の末日までの範囲**と定めています
- **同条第6項**は、**必要以上に短い任期を定めて反復しないよう配慮する**ことを求めています
- **任期が会計年度の単位になるのは、制度がそう定めているから**です。**本人の評価によるものではありません**
- 経歴は、**通算の期間で書いて**ください。年度ごとに分けないでください
- **改善した点**を書いてください。規模が小さくても、自分で動いた事実になります
- 面接では、**制度の仕組みを説明すれば足ります**
- **短期間で立ち上がってきた経験**は、中途採用で評価されます

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 複数の課を経験していますが、まとめ方が分かりません

**在籍の一覧と、機能のまとめを分けて書いてください。**まず、**在籍の一覧**として「◯◯市（会計年度任用職員）◯年◯月〜◯年◯月」と通算で1行を置き、**その下に配属先を並べます。**次に、**機能のまとめ**として「基準に照らした確認」「窓口での説明」「データの入力と集計」のように、**動作の軸でまとめ直します。**複数の課を経験している場合、**同じ動作を繰り返している**ことが多く、まとめ直すと厚みが出ます。扱いは[異動が多い公務員の職務経歴書の並べ方](senko-shokumu-ido.html)に整理しています。

### 正職員の採用試験と、民間の両方を受けてもよいですか

**差し支えありません。**時期が重なる場合は、**日程を先に確認**してください。採用試験は、**募集要項で日程が公表されます。**民間の選考は、**在職中の事情を伝えれば調整の対象**になります。なお、**どちらを優先するかは、条件を並べてから決めて**ください。勤務地、勤務時間、業務の内容、雇用の形。**この4つを比べると、判断ができます。**扱いは[何社くらい受けるべきか](senko-sagasu-fukusu.html)に整理しています。**両方を見ること自体が、比べる材料になります。**

### 勤務の時間が短く、経験として足りない気がします

**時間ではなく、担当した範囲で書いてください。**短時間の勤務でも、**担当した業務の工程と件数**は書けます。「週◯日の勤務で、年間約◯件を処理」という形にすれば、**条件と成果の両方が伝わります。**また、**短時間の勤務を前提とする求人**もあります。フルタイムに限らず、**勤務の形を条件として示して**差し支えありません。なお、**勤務の形を伏せて応募すると、入社後に合わなくなります。**希望する勤務の時間と日数を、**応募の段階で伝えて**ください。条件が合う求人に絞るほうが、結果として続きます。
