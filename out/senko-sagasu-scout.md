**登録した後に、連絡が届くことがあります。**

**「スカウト」「オファー」といった名称で届くもの**です。

この記事では、**見極めの観点**と、**確認すること**を扱います。

## 情報の表示にはルールがあります

**職業安定法第5条の4第1項**です。

> 公共職業安定所、特定地方公共団体及び職業紹介事業者、労働者の募集を行う者及び募集受託者、募集情報等提供事業を行う者並びに労働者供給事業者は、この法律に基づく業務に関して（略）**求人若しくは労働者の募集に関する情報**（略）を提供するときは、当該情報について**虚偽の表示又は誤解を生じさせる表示をしてはならない。**

**同条第2項**です。

> 労働者の募集を行う者及び募集受託者は、この法律に基づく業務に関して広告等により労働者の募集に関する情報（略）を提供するときは、**正確かつ最新の内容に保たなければならない。**

**同条第3項**は、**紹介事業者等に対して、正確かつ最新の内容に保つための措置**を義務づけています。

**つまり、募集に関する情報には、「虚偽・誤解を生じさせない」「正確かつ最新に保つ」というルールが置かれている**ということです。

**ですから、内容が曖昧な連絡について、確認を求めて差し支えありません。**

**確認すること自体が、この仕組みに沿った行動**です。

## 届くものの種類

| 種類 | 送り主 | 特徴 |
|---|---|---|
| ① 企業からの連絡 | 採用する会社 | 具体的な求人が示されます |
| ② 紹介事業者からの連絡 | 紹介を行う事業者 | 面談の案内が中心 |
| ③ 一括して送られるもの | どちらもあり得ます | **宛名や内容が一般的** |

**③が最も多い**です。

**登録した条件に該当する人へ、まとめて送られているもの**です。

**この場合、自分の経歴を読んだうえでの連絡とは限りません。**

**それ自体は問題ではありませんが、扱い方が変わります。**

## 見極めの観点

| 観点 | 見るところ |
|---|---|
| ① 宛名 | 氏名が入っているか |
| ② 経歴への言及 | **どの経験を見たかが書かれているか** |
| ③ 求人の具体性 | 会社名、職種、勤務地が示されているか |
| ④ 条件の記載 | 業務の内容、勤務時間、賃金の構成 |
| ⑤ 返信の期限 | 期限が示されているか |
| ⑥ 送り主 | 誰からの連絡か明示されているか |

**②が分かれ目**です。

**「◯◯の経験を拝見しました」と具体的に書かれていれば、経歴を読んだうえでの連絡**です。

**一方、「あなたのご経験にマッチする求人があります」だけの場合、条件での抽出**であることが多いです。

**③について。**

**会社名が示されていない連絡は、面談の案内**です。

**求人そのものの紹介ではありません。**

**この区別をしておくと、期待の置き方が変わります。**

## 返信の前に確認すること

| 確認すること | 理由 |
|---|---|
| 送り主の名称と許可番号 | 事業者であれば明示されています |
| 求人の有無 | 具体的な求人があるのか、面談の案内か |
| 応募になるのか | **返信が応募の扱いになるか** |
| 情報の提供先 | どの企業に情報が渡るか |
| 在職中の配慮 | 連絡の方法と時間帯 |

**3つ目を確認してください。**

**返信した時点で応募の扱いになる仕組み**の場合があります。

**「関心があります」と返しただけのつもりが、選考が始まる**ことがあります。

**書かれていない場合は、聞いて差し支えありません。**

:::insight
スカウトについて、**面談でお伝えしているのが「届いた数を、評価と受け取らないでください」**という点です。**連絡が多く届くと、需要があると感じられます。**逆に、**届かないと評価が低いのかと不安になる方**がいらっしゃいます。ところが、**送られる仕組みは、登録した条件での抽出であることが多い**です。**勤務地、経験の年数、職種の区分。**これらが条件に合えば送られます。**経歴の中身を読んだ結果とは限りません。**ですから、**数の多さは、条件に合う募集が多い領域かどうかを表しているにすぎません。**公務員からの転職では、**職種の区分が合いにくいため、届く数が少なくなる**ことがあります。**これは評価ではなく、区分の問題**です。役所の仕事は、**民間の職種の区分に収まりにくい**ためです。**数ではなく、中身を見てください。**そして、**届かない場合も、探し方を変えれば候補は見つかります。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 内容が曖昧な場合

| 曖昧な記載 | 確認すること |
|---|---|
| 「好条件の求人」 | **具体的な条件** |
| 「多数の求人」 | 条件に合うものの有無 |
| 「高い評価」 | 何を見ての評価か |
| 「早めの返信を」 | 期限の理由 |
| 会社名が不明 | どの段階で示されるか |

**確認を求めて差し支えありません。**

**職業安定法第5条の4は、虚偽の表示・誤解を生じさせる表示を禁じ、正確かつ最新の内容に保つことを求めています。**

**内容が示されない連絡について、判断を急ぐ必要はありません。**

## 在職中に注意すること

| 項目 | 内容 |
|---|---|
| 連絡の方法 | 勤務時間中の電話を避けたい旨を伝える |
| 勤務先への配慮 | **関係する会社を対象から外せるか** |
| 情報の公開の範囲 | 登録の設定を確認する |
| 返信の時間帯 | 勤務時間外で差し支えありません |

**2つ目を確認してください。**

**在職中の勤務先と取引のある会社から連絡が届くことがあります。**

**この場合、対象から外す設定や申し出ができるかを確認**してください。

**3つ目について。**

**登録の内容がどこまで見えるかの設定**があります。

**勤務先の名称を伏せる設定がある場合、確認しておいてください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 断るとき

| 項目 | 内容 |
|---|---|
| 返信の要否 | **返信しなくても差し支えありません** |
| 断る場合 | 「今回は見送ります」で足ります |
| 理由 | 伝えても、伝えなくても構いません |
| 今後の連絡 | 停止の設定ができることがあります |

**1つ目です。**

**一括して送られた連絡に、すべて返信する必要はありません。**

**2つ目について。**

**面談まで進んだ場合は、連絡を入れてください。**

**日程が押さえられている場合があります。**

## 受けてみる価値がある場合

| 場面 | 理由 |
|---|---|
| 会社名と職種が具体的 | 内容を確認できます |
| 行政が相手の事業 | **経験が重なる可能性があります** |
| 経歴への言及がある | 読んだうえでの連絡です |
| 条件が合っている | 応募の候補になります |

**2つ目です。**

**指定管理、業務委託、発注者支援、自治体向けのシステム。**

**これらの領域からの連絡は、経験が重なる可能性が高い**です。

**内容を確認する価値があります。**

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## よくある失敗

**1. 届いた数を評価と受け取る**

**条件での抽出であることが多い**です。

**2. 返信が応募になるか確認しない**

**選考が始まることがあります。**

**3. 会社名が不明なまま進める**

**求人の紹介か、面談の案内かを分けてください。**

**4. 期限を理由に急いで返す**

**期限の理由を確認**してください。

**5. 勤務先への配慮を伝えない**

**関係する会社から連絡が届くことがあります。**

**6. 面談の約束をしたまま連絡しない**

**日程が押さえられています。**

**7. 内容を確認せずに断る**

**条件が合う場合があります。**

:::insight
ここまで見極めの話をしておいて逆のことを言いますが、**スカウトを待つ進め方にしないでください。**面談で拝見していると、**登録した後、連絡が来るのを待つだけになってしまう方**がいらっしゃいます。ところが、**公務員からの転職では、職種の区分が合いにくいため、条件での抽出に引っかかりにくい**という事情があります。**役所の仕事は、民間の職種の名前が付いていないだけ**で、経験が使えないわけではありません。**ただし、機械的な抽出では拾われにくい。**ですから、**自分から探す作業と、条件を伝えて紹介を受ける作業**のほうが、結果として早く進みます。**スカウトは、届いたら確認する程度の位置づけ**で足ります。**届かないことを、評価が低いと受け取らないでください。**区分の問題であって、経験の問題ではありません。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **職業安定法第5条の4**は、**募集に関する情報について、虚偽の表示・誤解を生じさせる表示を禁じ**、**正確かつ最新の内容に保つこと**を求めています
- 届くものには、**①企業からの連絡 ②紹介事業者からの連絡 ③一括して送られるもの**があります
- **経歴への言及があるか**と、**会社名・職種が具体的か**で区別してください
- **返信が応募の扱いになるか**を確認してください
- **届いた数を評価と受け取らないでください。**条件での抽出であることが多いです
- **在職中は、勤務先に関係する会社を対象から外せるか**を確認してください
- **待つ進め方にしないでください。**自分で探す作業と併せて進めてください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### スカウトが届きません。経歴に問題があるのでしょうか

**職種の区分の問題であることが多いです。**多くの仕組みは、**登録された職種・経験の年数・勤務地**などの条件で抽出しています。役所の職名は、**民間の職種の区分に対応していない**ため、**抽出の対象に入りにくい**という事情があります。対処は2つです。1つは、**登録の内容を、民間の言葉に置き換えること。**「用地課」ではなく「用地の取得・権利関係の調査・折衝」と書く。もう1つは、**自分から探す作業を並行すること**です。**待つ仕組みだけに頼らないでください。**言い換えは[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)に整理しています。

### 「あなたの経験を高く評価しています」と書かれていました

**何を見ての評価かを確認して差し支えありません。**具体的な業務や経験への言及があれば、**経歴を読んだうえでの連絡**です。一方、**評価の言葉だけで、どの経験を指しているか書かれていない場合、条件での抽出**であることがあります。**確認の仕方は、「どの経験を評価いただいたかを教えてください」で足ります。**答えの具体性で判断できます。なお、**評価の言葉そのものを判断の材料にしないでください。**見るのは、**求人の中身と条件が自分に合うか**です。**会社名、職種、勤務地、業務の内容**が示されているかを先に確認してください。

### 返信したら、すぐに面接の日程を求められました

**準備ができていなければ、時期を調整して差し支えありません。**「書類の準備に時間をいただきたい」「在職中のため、日程の調整が必要です」と伝えてください。**急いで受けて、準備のないまま進むほうが負担になります。**なお、**返信の時点で応募の扱いになっていたかどうか**を確認してください。応募になっている場合、**辞退の連絡が必要**です。**応募していないつもりで連絡を絶つと、企業側に影響します。**今後は、**返信の前に「返信は応募の扱いになりますか」と確認**しておくと、この行き違いを避けられます。
