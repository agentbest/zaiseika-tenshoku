NPO・公益法人への転職を考え始めた方から、**いちばん多く伺う不安**があります。

**「実際のところ、生活は成り立つのでしょうか」**

この問いに、**当社が数字でお答えすることはできません。**法人ごとに事情が違いますし、**当社が裏を取っていない数字を並べるのは、この記事の趣旨に反します。**

そのかわりに、**この記事では「どこを見れば自分で確かめられるか」**を扱います。

**NPO・公益法人には、給与の原資の出方と、それを外から読める仕組みに、民間企業とは違う特徴**があります。そこを理解しておくと、**求人票の条件だけを見て判断するより、ずっと正確に見当がつきます。**

未経験から入る道筋は[NPO・公益法人に未経験から入るには](industry-npo-mikeiken.html)にあります。

## まず、法人の形で原資の出方が変わります

**「NPO」と一括りにされますが、法人の形はいくつもあります。**そして、**形によって、お金の入り方と外への開き方が違います。**

| 法人の形 | 根拠となる法律 | 外への開き方 |
|---|---|---|
| 特定非営利活動法人（NPO法人） | 特定非営利活動促進法 | 事業報告書等の備置きと閲覧の定めがある |
| 認定特定非営利活動法人 | 同法（認定の制度） | 上記に加えて、寄附の税制上の扱いが変わる |
| 公益社団法人・公益財団法人 | 公益認定法 | **役員の報酬等の支給の基準まで開かれる** |
| 一般社団法人・一般財団法人 | 一般社団・財団法人法 | 公益認定を受けていない分、定めが軽い |
| 社会福祉法人 | 社会福祉法 | 福祉の制度の中で別に定めがある |

**求人票に「社団法人」と書いてあるだけでは、公益認定を受けているかどうかは分かりません。****「公益社団法人」なのか「一般社団法人」なのか**を、必ず正式名称で確認してください。

**ここが、この記事でいちばん実務的な話**です。

## 公益法人には、報酬等の支給の基準を定めることが求められています

**公益認定法第5条**は、公益認定の基準を並べた条文です。その**第14号**に、次の定めがあります。

> 十四　その理事、監事及び評議員に対する報酬等（報酬、賞与その他の職務遂行の対価として受ける財産上の利益及び退職手当をいう。以下同じ。）について、内閣府令で定めるところにより、民間事業者の役員の報酬等及び従業員の給与、当該法人の経理の状況その他の事情を考慮して、不当に高額なものとならないような支給の基準を定めているものであること。

そして、**同法第20条**です。

> **公益法人は、第五条第十四号に規定する報酬等の支給の基準に従って、その理事、監事及び評議員に対する報酬等を支給しなければならない。**

**基準を定めるだけでなく、その基準に従って支給しなければならない**と書かれています。

さらに、**同法第21条第2項**は、毎事業年度の経過後に作成して備え置く書類として、**第3号に「第五条第十四号に規定する報酬等の支給の基準を記載した書類」**を挙げています。

そして**同条第5項**が、決定的です。

> **何人も、公益法人の業務時間内は、いつでも、**第一項に規定する書類、第二項各号に掲げる書類、定款、社員名簿及び（中略）計算書類等（以下「財産目録等」という。）について、次に掲げる請求をすることができる。

**「何人も」**です。**その法人の関係者でなくても、応募する前の段階でも、請求できます。**

**多くの公益法人は、この書類を自分の公式サイトに置いています。**請求の手続きを取らなくても、**サイトで読めることのほうが多い**です。

## ⚠ ただし、これは役員の話です

**ここを取り違えないでください。**

**第5条第14号も第20条も、対象は「理事、監事及び評議員」**です。**職員（従業員）の給与は、この基準の対象ではありません。**

| 対象 | 支給の基準の定め | 外から読めるか |
|---|---|---|
| 理事・監事・評議員 | **公益法人には定めがある** | 備置きと閲覧の対象 |
| 職員（従業員） | この条文の対象ではない | 求人票と、面接で聞くしかない |

**では、役員の基準を読む意味がないかというと、そうではありません。**

**第14号は、基準を定めるときに「民間事業者の役員の報酬等及び従業員の給与、当該法人の経理の状況その他の事情」を考慮する**と書いています。**つまり、その法人が自分の経理の状況をどう見ているかが、基準の文面に出ます。**

**役員の基準の作り方が丁寧な法人は、職員の給与の決め方も整っていることが多い**です。逆に、**基準が抽象的な一文で済んでいる法人**は、**内部の規程全般がその水準**だと考えておくほうが安全です。

**NPO法人の場合は、この基準の定めがありません。**ただし、**特定非営利活動促進法第28条**が、**事業報告書、計算書類、財産目録、役員名簿等を事務所に備え置き、閲覧させる**ことを定めています。**計算書類を見れば、人件費の規模と収入の構成は読めます。**

## 給与の原資は、収入の種類で性質が変わります

**法人の収入は、種類によって「いつ切れるか」が違います。**ここが、**給与の安定と直結します。**

| 収入の種類 | 期間の区切り | 給与への効き方 |
|---|---|---|
| 会費 | 継続するが増減する | **基礎的な部分を支える** |
| 寄附 | 年によって変わる | 変動が大きい |
| 補助金・助成金 | **年度や事業の期間で切れる** | その事業の担当者の身分に直結する |
| 行政からの委託 | **契約の期間で切れる** | 更新の見込みが読みどころ |
| 自主事業（販売・講座・施設の運営など） | 継続する | **法人の自立の度合いを示す** |

**役所の側にいた方なら、この表の意味がすぐ分かるはずです。**

**補助金の交付要綱を書いていた側**なら、**交付の期間が区切られていること、次年度の継続が予算の成立を待つこと**を知っています。**委託の仕様書を作っていた側**なら、**契約の期間と、次の入札で相手が変わりうること**を知っています。

**その仕組みの、受け取る側に回る**のが、この転職です。

**求人票を見るときは、「その職のお金が、どの収入から出ているか」を確認してください。**面接で聞いて構いませんし、**聞いたときの答え方で、法人の経理の見通しの持ち方が分かります。**

**「自主事業と会費で、人件費の基礎を賄っている」**と即答できる法人と、**「補助金が付いているので大丈夫です」**という答え方をする法人では、**見通しの質が違います。**

## 働き方は、役所とどう変わるか

**給与より、こちらのほうが変化が大きい**とお聞きすることが多いです。

| 場面 | 役所での状態 | 法人での状態 |
|---|---|---|
| 異動 | **数年ごとに部署が変わる** | **基本的に変わらない。**同じ事業を続ける |
| 職務の範囲 | 分掌で区切られている | **区切りが緩い。**広報も経理も担当することがある |
| 決裁 | 段階が多い | **段階が少ない。**理事長まで近い |
| 人数 | 係・課の単位で複数 | **一人で一事業ということがある** |
| 繁忙の波 | 予算・決算・議会の時期 | **事業の実施の時期と、報告書の提出の時期** |
| 相手 | 住民・事業者・他の行政機関 | **会員・寄附者・行政・受益者**と幅が広い |

**「異動がない」を、良いと取るか悪いと取るか**で、この転職の評価は分かれます。

**同じ分野を続けられる**のは、**役所で3年ごとに分野が変わることに疲れた方**にとっては、大きな利点です。一方で、**合わなかったときに、異動で環境が変わることは期待できません。**

**職務の範囲が緩い**のも同じです。**自分で決められる幅が広い**のは利点ですが、**分掌に守られない**ということでもあります。「これは自分の担当ではない」という整理が、**役所ほど通りません。**

:::insight
面談で拝見していて、**この転職でいちばん誤差が出やすいのが「決裁の段階が少ない」**という点です。皆さん、**意思決定が速くなることを期待して**お話しされます。実際そのとおりなのですが、**速いということは、自分の判断がそのまま結果になるということ**でもあります。役所では、**係長・課長・部長の確認を通る間に、抜けや偏りが拾われていました。**その工程が無くなると、**確認していたつもりの内容が、確認されないまま外へ出ます。**移った方から最初の半年でよく伺うのが、**「自分の判断を誰も止めてくれないことが、こんなに怖いとは思わなかった」**という言葉です。対処は単純で、**自分で確認の手順を作ること**です。役所で回っていた合議の工程を、**チェックの表に落として、自分で一度通してから出す。**この習慣を持ち込んだ方は、**早い段階で「仕事が丁寧だ」と言われます。**段階が少ない組織ほど、**丁寧さが個人の習慣に依存する**からです。ここは、役所の経験がそのまま効く場所です。
:::

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 場面 | 効く理由 |
|---|---|
| 補助金・助成金の申請書を作る | **交付する側の様式と審査の観点を知っている** |
| 行政からの委託の実施と報告 | 仕様書の読み方、実績報告の書き方が身に付いている |
| 行政との協議・調整 | **相手の意思決定の流れと時期が読める** |
| 規程・要綱を整える | 条文の形で書くことに慣れている |
| 会計の書類を整える | **証憑と支出の根拠を揃える習慣がある** |
| 理事会・評議員会の運営 | 審議会・委員会の事務の経験がそのまま重なる |

**効きにくい場所**

| 場面 | 効きにくい理由 |
|---|---|
| 寄附を集める | **お願いして集める仕事は、役所にはほとんどない** |
| 会員を増やす | 継続的な関係を作って維持する仕事 |
| 自主事業で収入を作る | **値付けと採算の判断を自分でする** |
| 広報でお金を動かす | 知らせることと、動いてもらうことは別 |
| 少人数での兼務 | 分掌の外の仕事を自分で拾う |

**この2つの表の差が、そのまま転職後の学習の量**です。

**効きにくい場所は、「できない」ではなく「役所では経験する機会が無かった」**というだけです。**入ってから覚える前提で、面接でも正直に言って構いません。**

## 入る前に確認しておくこと

**応募を決める前に、外から読める資料があります。**

| 資料 | どこにあるか | 読み取れること |
|---|---|---|
| 計算書類（活動計算書・貸借対照表） | 法人の公式サイト、または事務所での閲覧 | **収入の構成と人件費の規模** |
| 事業報告書 | 同上 | 前年度に何をどこまでやったか |
| 役員名簿 | 同上 | 常勤か非常勤か、外部の理事がいるか |
| 報酬等の支給の基準（公益法人） | 同上 | **規程の作り方の丁寧さ** |
| 定款 | 同上 | 事業の範囲、理事の代表権の制限の有無 |
| 事業計画書・収支予算書（公益法人） | 同上 | **これから何に人を使う予定か** |

**この6つを読むと、求人票の1枚では分からないことが、かなり分かります。**

**とくに、事業計画書と収支予算書**です。**採用しようとしている職が、計画のどの事業に紐づいているか**が読めます。**新規の事業に紐づいているなら、その事業の財源の期間を確認してください。**

**読み方は、役所の予算書を読んできた方にとっては難しくありません。**項目の並びが違うだけで、**「何にいくら使う予定か」という構造は同じ**です。

## 面接で聞かれやすいこと

| 聞かれること | 何を見られているか |
|---|---|
| なぜ行政ではなく、この法人なのか | **役所の外でやりたいことが具体化しているか** |
| 給与の条件について、どう考えているか | **条件の確認から逃げない人か** |
| 一人で担当することに抵抗はないか | 分掌の外を拾えるか |
| 寄附や会員の増加に関わることになるが、どうか | **効きにくい場所への向き合い方** |
| 行政との協議で、どちらの立場に立つか | **元の所属に引きずられないか** |

**2つ目は、遠慮せずに確認して構いません。**条件を聞かずに入って、**あとで折り合わずに短期間で辞める**ほうが、法人にとっても負担です。

**5つ目は、公務員から移った方に必ず聞かれます。**答え方は、**「法人の側に立ちます。ただし、行政の側の制約も分かるので、通らない要求をしないで済みます」**という形が自然です。

:::insight
ここまで確認の話をしてきましたが、**当社として申し上げておきたいことが1つ**あります。**条件を確認した結果、いまの職を続けるという結論になっても、それは正しい結論です。**面談でお会いする方の中には、**「相談した以上、動かないといけない」と考えてしまう方**がいらっしゃいます。そのようなことはありません。**確認したうえで残る判断は、確認せずに残るのとは中身が違います。**何が違うかというと、**次に迷ったときに、もう一度ゼロから調べ直さなくて済む**ということです。法人の形の違い、収入の構成の読み方、計算書類のどこを見るか。**この記事で扱ったことは、いま動かなくても消えません。**そして、**お子さんの進学や、住宅の返済の時期**など、**条件の意味が変わる時点**はこの先に何度か来ます。そのときに、**すでに一度調べてある状態**でいるのは、**まったく調べていない状態とは違います。**急いで決める理由がないなら、**調べただけの段階で止めておいてください。**在職のまま、情報だけ取るご相談も承っています。
:::

## まとめ

- **法人の形で、お金の入り方と外への開き方が違います。**求人票の「社団法人」が**公益なのか一般なのか**を、正式名称で確認してください
- **公益認定法第5条第14号**は、**理事・監事・評議員の報酬等について「不当に高額なものとならないような支給の基準」を定めていること**を、公益認定の基準としています
- **同法第20条**は、**その基準に従って支給しなければならない**と定めています
- **同法第21条第2項第3号・第5項**により、**その基準を記載した書類は備え置かれ、「何人も」閲覧等を請求できます**
- ⚠ **ただし、これは役員の話です。**職員の給与はこの基準の対象ではありません。**求人票と面接で確認**してください
- **NPO法人には、特定非営利活動促進法第28条**による**事業報告書・計算書類等の備置きと閲覧**の定めがあります
- **収入の種類（会費・寄附・補助金・委託・自主事業）で、財源が切れる時期が違います。**自分の職がどの収入に紐づくかを確認してください
- **働き方の変化は、給与より大きい**ことがあります。**異動が無い・職務の範囲が緩い・決裁の段階が少ない**の3つです
- **確認した結果、動かないという結論も正しい結論**です

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 求人票に給与が幅で書いてあります。どう読めばよいですか

**幅の下限を基準に考えてください。**そのうえで、**面接の段階で「どの条件のときに幅のどこになるか」を確認**してください。法人の側も、**経験と担当する事業によって変わるので幅で出している**ことがほとんどです。聞きにくいと感じる方が多いのですが、**確認しないまま入って、想定と違って早期に辞めるほうが、双方にとって負担が大きい**です。あわせて、**昇給の仕組みがあるかどうか**も確認してください。**給与の規程があるか、あるとして改定の実績があるか。**規程が無い法人もあり、それ自体は違法ではありませんが、**見通しの立て方が変わります。**なお、**当社が法人ごとの相場をお伝えすることはできません。**確認できない数字を出さない方針のためです。

### 財源が補助金の職は、避けたほうがよいですか

**一概には言えません。**確認していただきたいのは、**「その補助金が終わったあと、法人がその事業をどうする予定か」**です。**自主事業に切り替える計画がある、他の財源に乗せ換える見込みがある**という答えなら、**期間の区切りは一区切りであって終わりではありません。**一方、**「そのときは考えます」という答え**なら、**その期間で職が終わる可能性**を織り込んでおく必要があります。**補助金の期間そのものは、事業計画書と収支予算書で確認できます。**役所の側で交付する事務をしていた方なら、**交付要綱の書き方から、継続の見込みの立てやすさも読めるはずです。**その読みは、そのまま使ってください。

### 副業や兼業は、法人によって扱いが違いますか

**違います。**法人ごとの就業規則によります。**役所では地方公務員法の定めの中で扱われていた話**ですが、**移ったあとは、法人の規則が根拠になります。**確認のしかたは、**選考の終盤で就業規則の該当箇所を見せてもらう**のが確実です。なお、**小規模な法人では、就業規則そのものが整備の途中**ということもあります。その場合は、**口頭での確認ではなく、書面で条件を示してもらってください。**労働条件の明示は、法人の規模にかかわらず求められています。**条件を書面でもらうことを遠慮する必要はありません。**入る前に確認しておくことで、**後から食い違う場面を減らせます。**
