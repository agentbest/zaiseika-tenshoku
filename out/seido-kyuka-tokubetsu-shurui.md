特別休暇には、結婚や親族の死亡、出産・育児、看護・介護、公的活動、災害等に対応するものがあります。ただし、年次休暇のように理由を問わず同じ残日数から使う制度ではありません。必要な事由と対象者、期間を確認して申請します。

本記事は2026年11月時点の公開情報にもとづきます。一般職の国家公務員の例を起点に、地方との違いを整理します。本人の適用規程、常勤・非常勤等の区分、給与と承認は所属の人事・服務担当へ確認してください。

## 国の分類と自分の所属の分類を分けて読む

一般職の職員の勤務時間、休暇等に関する法律第16条は、年次休暇、病気休暇、特別休暇、介護休暇、介護時間を別に定めています。同法第19条が特別休暇の枠組み、人事院規則15-14第22条が具体的な事由と期間を定めています。

一方、地方公務員法第24条第5項は勤務条件を条例で定める仕組みです。国の表にある名称や日数を、すべての自治体職員の条件と考えません。条例、規則、運用の通知と本人の勤務形態を合わせて読みます。

例えば横浜市の一般職職員の休暇条例では、病気休暇も特別休暇の区分に入っています。国では病気休暇が別の区分です。同じ言葉でも制度のまとめ方が違うため、一覧に載っている名称だけで比較しないことが必要です。

また、育児休業や病気休職は、休暇の一覧とは別の任用・休業制度です。「長く休むものはすべて特別休暇」という整理にはしません。給与や共済給付の扱いも、それぞれの根拠で確認します。

## 結婚・忌引は出来事と対象期間を確かめる

人事院規則15-14第22条には、結婚に伴う行事等の休暇や、親族の死亡に伴う葬儀・服喪等の休暇があります。結婚は対象期間と連続日数、忌引は別表の親族区分と連続日数等が条件です。

| 事由の例 | 本人が確認すること |
| --- | --- |
| 結婚 | 基準となる日、取得できる期間、連続の扱い |
| 親族の死亡 | 続柄、対象の関係、必要な行事、日数と移動 |
| 父母の追悼 | 忌引との違い、対象行事、死亡後の期間 |

国家公務員の結婚休暇は連続する5日の範囲内で、運用通知は暦日で扱うとしています。横浜市の規則では結婚休暇は連続する6日の範囲内です。この日数差だけでなく、週休日・休日の計算方法等も異なります。

取得できる事由が生じたことと、希望する日をすべて対象にできることは別です。本人が適用される規程の対象期間内に、どの行事や準備があるかを担当へ伝えてください。結婚と忌引の詳細は、それぞれの記事で具体的に確認します。

## 出産・育児・看護の休暇と育児休業を区別する

国の特別休暇には、産前・産後、保育時間、妻の出産、男性の育児参加、子の看護等があります。対象者、子の年齢、目的、日数や時間の単位が違います。家族に関係する休みという理由で、一つの制度として扱いません。

例えば子の看護等休暇は、看護だけでなく、規程に定める予防接種、学級閉鎖等の際の世話、対象行事への参加等も確認します。ただし、あらゆる学校行事や家庭の用事が対象になるわけではありません。子の年齢や事由を現在の規程で確かめます。

育児休業は、これらの日単位・時間単位の特別休暇とは別に承認等を受ける制度です。休業期間、共済の手当金、掛金免除も、休暇が有給かどうかと同じ質問ではありません。

国と自治体、常勤と非常勤で、年齢の対象や年間上限、数える期間が異なることもあります。自分の休暇年度が暦年か年度か、任期や勤務日数による条件があるかも確認します。古い制度一覧だけで対象外又は対象と決めないでください。

## 介護は短期の休暇と長期の休暇・時間を分ける

人事院規則15-14第22条には、要介護者の介護その他の世話に対応する短期の休暇があります。一方、勤務時間法の介護休暇や介護時間は別制度です。対象家族、介護が必要な状態、期間と給与を分けて確認します。

介護休暇を取得すれば、短期の介護に関する休暇も同じ条件で使える、あるいはどれも無給、とは限りません。病院への付添い、手続きの代行、日々の介護等について、どの制度で相談すべきかを人事担当へ聞きます。

必要な情報は、対象者との関係、本人が行う世話、希望する日・時間等です。家族の事情を職場全体へ広く説明する必要があると考えず、承認に必要な範囲と確認資料の提出先を担当と整理してください。

:::insight
休暇を調べるときは、制度の名称を探す前に、何のために、いつ、どれくらい勤務を離れる必要があるかを整理する方法を勧めます。看護や介護のように似た名称が並ぶ場面でも、目的と期間が分かれば、担当へ具体的に相談できるためです。本人用の表には、使えると確認できた制度、確認待ちの条件、申請に必要な資料を分けて残します。休暇の相談を転職の意思表示と結び付ける必要はありません。現職の制度を確認して働き続けることにも意味があります。制度があることだけで生活との両立を決めず、実際に本人へ適用する条件と必要な手続きをそろえることが、納得できる判断の土台になると考えます。
:::

働き方も比較したい場合は、[公務員向け求人情報](../?gov=1)を見ることもできます。現在の制度を確認することと、外の仕事を選ぶことは別の判断です。

## 公的活動や災害にも目的別の規定がある

国の特別休暇には、公民権の行使、官公署への出頭、骨髄等ドナー、社会貢献活動、災害時の出勤困難等もあります。休日を増やすために自由に選ぶ制度ではなく、それぞれの要件を確認します。

2026年6月施行の人事院規則改正では、被害者参加人として裁判所等へ出頭する場合が官公署出頭休暇の対象に加わっています。現在の第22条第1項第2号にも記載があります。古い一覧で見つからない場合は、現行の条文と運用を確認してください。

ボランティアについては、無報酬であることや対象活動、親族のみの支援を除く等の条件があります。災害に関係する活動でも、自分の住居の復旧、被災者支援、交通機関の事故による出勤困難では、確認する事由と期間が違います。

夏季休暇も特別休暇の一つですが、国の対象期間と自治体の期間・日数が同じとは限りません。取得できる時期、連続又は分割、週休日の扱いを確認し、他の特別休暇と一括して計算しないようにします。

## 有給・無給と手当の扱いは本人の制度で確認する

横浜市の例では、条例第2条が年次休暇・特別休暇を有給とし、介護休暇・介護時間を給与減額の対象として区分しています。これは同条例の対象者についての説明です。自治体や任用が違えば、別の規程を確認します。

国家公務員の非常勤職員は、人事院規則15-15第4条が有給の休暇と無給の休暇を区分しています。結婚や親族死亡等の有給の休暇も定められているため、「非常勤だから特別な事由の休暇は一切ない」と決めないでください。一方、一部の休暇には勤務日数等の対象条件があります。

有給という説明でも、すべての手当が在職中と同額のまま出るという意味にはしません。勤務実績に関係する手当や給与計算で確認が必要な項目は、給与担当へ聞きます。共済の給付があるかどうかも別に確認します。

また、事由別の休暇は年次休暇と同じように残日数を翌年へ持ち越すとは限りません。前年に使わなかったから今年の結婚や看護の日数へ加えられる、といった計算はしないでください。

## 申請は適用規程と必要な資料を確認して進める

国の勤務時間法第21条、人事院規則15-14第25条・第27条には、承認や請求の扱いがあります。原則として事前の請求を行い、やむを得ず事前にできない場合は事情を付して事後の承認を求める仕組みです。産前・産後等には別の申出・届出もあります。

地方も所属の規則で確認します。横浜市の規則には、事前承認と休暇簿による請求、やむを得ない事情で事前請求できない場合の手続きがあります。国の申請書や締切をそのまま自治体の本人用に使いません。

| 申請前 | 確認する内容 |
| --- | --- |
| 本人の区分 | 常勤、短時間、会計年度任用等 |
| 事由 | 規程にあるどの要件に当たるか |
| 取得範囲 | 対象期間、上限、連続・分割、時間単位 |
| 日数計算 | 暦日か勤務日か、週休日・休日 |
| 手続き | 請求先、承認、添付資料、変更時の連絡 |

相談や確認だけを、申請が承認されたことと混同しないでください。日程が変わる場合は対象期間と申請内容を見直します。承認済みの日数や、今後使える枠を本人の記録にも残すと、同じ事由を重ねて計算することを防げます。

仕事内容や勤務条件の整理には[相談フォーム](../apply.html)も利用できます。ご利用は無料です（紹介手数料は採用企業の負担）。個別の休暇承認は所属の担当窓口へ確認してください。

:::insight
休暇制度を勤務先の比較に使うときは、名称の数より、本人が必要とする場面に対応できるかを見ることを勧めます。同じ結婚休暇や介護の休暇でも、対象期間や給与、勤務形態の条件が違えば、使い方も変わるためです。現職の条件を先に整理し、転職先では就業規則や採用条件に沿って質問すると、名前だけの比較を避けられます。家族の予定や本人の生活に合うなら、現職を続ける選択にも理があります。制度が足りないと感じた場合も、直ちに退職を結論にせず、勤務時間の調整や他の制度で対応できるかを確認できます。未確認の条件を不安の材料にせず、担当の回答を基に本人の選択肢を整える姿勢が大切だと考えます。
:::

## よくある質問

### 特別休暇は年次休暇と同じように自由に使えますか

事由別の要件、対象期間、承認等があります。年次休暇の残日数から使う制度とは分け、本人の事情がどの事由に当たるか確認してください。

### 非常勤や会計年度任用職員も対象ですか

任用と規程により確認します。国の非常勤には規則15-15の休暇がありますが、地方の会計年度任用職員等へそのまま適用するものではありません。

### 病気休暇や育児休業もすべて特別休暇ですか

分類は制度によります。国では病気休暇は別区分ですが、横浜市の例では特別休暇に含まれます。育児休業や病気休職も別の根拠で確認します。

情報収集の相談には[LINE](https://line.me/R/ti/p/@697nxhbt)も利用できます。休暇を確認することを退職の理由にせず、現職を続ける選択も含めて考えられます。
