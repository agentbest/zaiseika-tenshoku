**用地や財産の事務を担当してきた方から、「登記の経験は使えるか」**というご相談を伺います。

**業務の範囲が、法律に定められています。**

この記事では、**その中身**と、**経験との接続**を扱います。

**⚠ 受験・登録の要件と手続は、所管するところの公表を確認してください。****この記事では、個別の要件には触れません。**

## 業務が、法律に列挙されています

**司法書士法第3条第1項**です。

> **司法書士は、この法律の定めるところにより、他人の依頼を受けて、次に掲げる事務を行うことを業とする。**
>
> 一 **登記又は供託に関する手続について代理すること。**
>
> 二 **法務局又は地方法務局に提出し、又は提供する書類又は電磁的記録**（略）**を作成すること。**（略）

**登記や供託の手続の代理**と、**書類の作成**が、業務として挙げられています。

**行政の用地や財産の事務では、この手続の相手方として関わってきた**はずです。

**依頼する側、または自ら申請する側にいた経験**が、接続の材料になります。

**⚠ 業務の範囲と、行える事務は法律で定められています。****詳細は所管の公表を確認**してください。

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 用地の取得の支援 | **権利関係の調査、手続** |
| ② 不動産の管理・取引 | 登記の確認、調査 |
| ③ 金融・保証 | 担保に関する手続 |
| ④ 相続・財産の相談 | 権利者の調査 |
| ⑤ 自治体が相手の事業 | 手続と基準の理解 |

**①が、最も直接に重なります。**

**公共の事業に伴う用地の取得では、調査から契約、登記までの一連があります。**

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 行政での経験との接続

| 経験 | 民間での読まれ方 |
|---|---|
| ① 登記の確認 | **登記記録の読み取り** |
| ② 権利者の調査 | 相続、共有の整理 |
| ③ 書類の準備 | 必要な書類の見立て |
| ④ 契約と登記の手続 | 手続の管理 |
| ⑤ 財産の台帳の管理 | 現況との整合 |
| ⑥ 関係者との調整 | 同意の取得 |

**①と②が、実務の中心**です。

**②について。**

**相続が複数代にわたる土地の権利者の調査**は、**年数がないとできません。**

**扱いは**[不動産鑑定士｜用地買収の経験からの接続](skill-kanteishi.html)**にも整理しています。**

## 書き方の例

**悪い例**

> 用地の担当で、登記の手続をしていました。

**良い例**

> 公共事業に係る用地の取得を担当。**年間約◯件について、登記記録を確認のうえ権利者を特定し、必要な書類を整理。****相続が複数代にわたる案件◯件について、権利者◯名の調査と同意の取得**を実施。契約から**所有権の移転の登記までの手続を管理。**公有財産の台帳について、**現況との相違◯件を確認し、修正。**

**「件数」「調査」「手続の管理」「台帳」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

:::insight
登記の実務について、**面談でお伝えしているのが「調査の難しさを書いてください」**という点です。**「登記の手続をしていた」と書かれると、定型の事務として読まれます。**ところが、**用地の実務で時間がかかるのは、手続そのものではなく、その前の調査**です。登記記録の名義が古い、相続が複数代にわたる、共有者が多数いる、所在が分からない。**この状態から、権利者を特定し、同意を得るまでが仕事**です。そして、**この作業を経験している人は、多くありません。**民間でも、**相続や共有が絡む不動産の案件**では、同じ調査が必要になります。書類には、**「相続が複数代にわたる案件◯件について、権利者◯名の調査と同意の取得を実施」**と書いてください。**件数と人数があると、難易度が伝わります。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 資格の位置づけ

| 状況 | 扱い |
|---|---|
| ① 登記の代理を業とする | **登録が前提になります** |
| ② 応募条件に記載がある | 満たす材料になる |
| ③ 調査・支援の業務 | **経験のほうが具体な場合も** |
| ④ 長く続ける前提がある | 学習に時間がかかります |
| ⑤ 目的が曖昧 | 優先順位を下げてください |

**①について。**

**⚠ 業として行える事務の範囲は、法律で定められています。**

**要件と範囲は、所管の公表を確認**してください。

**なお、取れば転職できる、という関係にはありません。**

**何を調査し、どう手続を管理したか**が、評価の対象です。

## 調査の観点という材料

| 観点 | 内容 |
|---|---|
| ① 登記記録 | **名義、権利の種類、順位** |
| ② 相続の関係 | 戸籍の収集、範囲の確定 |
| ③ 共有 | 持分、共有者の数 |
| ④ 境界・面積 | 実測との差 |
| ⑤ 添付の書類 | 揃い、有効期限 |

**⑤が、実務の差が出る部分**です。

**どの書類が必要で、いつ取得すべきかを見立てられる**かどうか。

**この見立ては、経験からしか身につきません。**

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 実績の整理 | **件数、権利者の数、案件の類型** |
| 調査の整理 | 難しかった案件の経緯 |
| 要件の確認 | 所管の公表を確認 |
| 求人を読む | 週に30分 |

**1行目です。**

**決裁の資料や台帳から確認**してください。

**根拠のない数は書かないでください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 担当した件数と類型 | **年間の件数、案件の種類** |
| 調査の進め方 | 難しかった事例 |
| 書類の見立て | 必要な書類の判断 |
| 同意の取得 | 折衝の手順 |
| 手続の管理 | 契約から登記まで |

**2行目です。**

**なお、特定の権利者や物件が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

## 手続の管理という材料

**契約から登記までの工程は、そのまま書けます。**

| 工程 | 内容 |
|---|---|
| ① 権利者の確定 | **登記記録、戸籍の確認** |
| ② 同意の取得 | 説明、折衝 |
| ③ 契約 | 内容の確認、決裁 |
| ④ 書類の収集 | 印鑑証明、住民票等 |
| ⑤ 登記の申請 | 自ら、または委託 |
| ⑥ 完了の確認 | 記録の確認、台帳への反映 |

**④と⑥が見落とされやすい**です。

**④について。**

**有効期限のある書類は、取得の時期を誤ると取り直しになります。**

**この段取りを管理してきた経験**は、実務の水準として伝わります。

**⑥について。**

**登記の完了後に、記録と台帳を突き合わせる作業**です。

**ここを飛ばすと、後から相違が見つかります。**

## よくある失敗

**1. 「登記の手続をしていた」で止める**

**その前の調査**が中心です。

**2. 権利者の数を書かない**

**難易度**が伝わりません。

**3. 書類の見立てを書かない**

**経験からしか身につかない**部分です。

**4. 台帳の整理を書かない**

**現況との整合**を確認した経験です。

**5. 同意の取得の手順を書かない**

**強制力のない関係での合意形成**です。

**6. 資格がないと応募できないと考える**

**調査・支援の求人**があります。

**7. 要件を人づてで判断する**

**所管の公表**を確認してください。

**8. 取れば転職できると考える**

**何を調査し管理したか**が評価の対象です。

:::insight
ここまで経験の話をしておいて逆のことを言いますが、**学習に時間がかかる資格であることは、先に踏まえてください。**面談で拝見していると、**「登記の実務に触れていたから、取りやすいのでは」と考える方**がいらっしゃいます。ところが、**業務で扱う範囲と、試験で問われる範囲は一致しません。**実務で見てきたのは、**用地の取得に関わる一部**です。**在職中の学習には、相応の期間**がかかります。ですから、**転職の時期と重ねない判断**もあります。**先に転職し、落ち着いてから学ぶ**という順序です。あるいは、**資格を使わない領域で、調査の経験を活かす**という選択もあります。用地の取得の支援、不動産の調査、相続に関する相談の補助。**資格がなくても応募できる求人があります。****どちらを選ぶかを、先に決めてください。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **司法書士法第3条第1項**は、**登記又は供託に関する手続の代理**と、**法務局等に提出する書類等の作成**を業務として挙げています
- **行政の用地や財産の事務では、この手続の相手方として関わってきた**はずです
- 効くのは、**用地の取得の支援、不動産の管理・取引、金融・保証、相続・財産の相談、自治体が相手の事業**です
- **手続そのものより、その前の調査**を書いてください
- **相続が複数代にわたる案件の権利者の調査**は、年数がないとできません
- **書類の見立て**は、経験からしか身につかない部分です
- **学習に時間がかかります。**転職の時期と重ねない判断もあります

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 登記は委託していました

**依頼する側の経験で書いてください。**「登記の手続を司法書士に委託し、必要な書類の準備と内容の確認を担当」という形です。**どの書類が必要かを見立て、揃えてきた経験**は、材料になります。また、**委託の前提として、権利者の調査と同意の取得**を担っていたはずです。**そちらが中心**です。書き方は、**「権利者の調査と同意の取得を実施のうえ、登記の手続を委託し、完了を確認」**という形にしてください。扱いは[契約書の読み方｜自治体の契約実務との差](skill-keiyakusho.html)にも整理しています。

### 資格がなくても、不動産の分野に移れますか

**求人によります。**登記の代理を業とする職では、**登録が前提**になります。一方、**用地の取得の支援、不動産の調査、管理、相続に関する相談の補助**では、**資格が必須でない求人**があります。判断の目安は、**求人票の「必須」の欄**です。なお、**行政での用地の経験が要件として挙げられる**ことがあります。この場合、**経験が直接評価されます。**読み方は[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。**資格の有無で、候補を狭めないでください。**

### 公有財産の管理の経験は、書けますか

**書けます。**台帳の管理、現況との照合、貸付や処分の手続、境界の確認。**これらは、不動産の管理の業務と重なります。**書き方は、**「公有財産◯件の台帳を管理し、現況との相違◯件を確認のうえ修正。貸付の契約◯件と、処分の手続◯件を担当」**という形です。**件数があると、規模が伝わります。**なお、**台帳と現況の整合を取る作業**は、引き継いだ側でなければ分からない部分です。**この経験は、資産の管理の業務で評価されます。**扱いは[電気主任技術者｜公営企業・インフラ運営での評価](skill-denkishunin.html)にも触れています。
