**「直接応募したほうがよいのか」**というご相談を伺います。

**経路によって、何が変わるのかが見えにくい**ためです。

この記事では、**違いの中身**と、**使い分けの目安**を扱います。

## 個人情報の取扱いには規律があります

**職業安定法第5条の5第1項**です。

> 公共職業安定所、特定地方公共団体、**職業紹介事業者及び求人者**（略）は、それぞれ、その業務に関し、**求職者**（略）**の個人情報**（略）を**収集し、保管し、又は使用するに当たつては、その業務の目的の達成に必要な範囲内で**、厚生労働省令で定めるところにより、**当該目的を明らかにして**求職者等の個人情報を収集し、並びに**当該収集の目的の範囲内でこれを保管し、及び使用しなければならない。**

**同条第2項**です。

> 公共職業安定所等は、**求職者等の個人情報を適正に管理するために必要な措置を講じなければならない。**

**「職業紹介事業者及び求人者」**が、**どちらも対象に含まれている**点に注目してください。

**紹介事業者も、応募先の企業も、同じ規律の下にあります。**

**目的を明らかにして収集し、目的の範囲内で保管・使用する。**

**経路が増えても、この規律は変わりません。**

## 何が変わるか

| 項目 | 直接応募 | 紹介経由 |
|---|---|---|
| 申込み先 | **企業に直接** | 紹介事業者を経由 |
| 求人の入手 | 自分で探す | 紹介を受ける |
| 条件の照会 | 自分で聞く | **照会してもらえる** |
| 日程の調整 | 自分で行う | **調整してもらえる** |
| 書類の準備 | 自分で行う | 確認を受けられる |
| 辞退の連絡 | 自分で行う | 代わりに連絡してもらえる |
| 費用 | かかりません | かかりません |

**3行目と4行目が、在職中には大きい**です。

**配属先の所在地、募集の背景、残業の実態。**

**自分で聞きにくいことを、応募の前に照会できます。**

**7行目について。**

**どちらの経路でも、求職者が費用を負担する仕組みではありません。**

**扱いは**[転職エージェントの使い方](senko-sagasu-agent.html)**に整理しています。**

## 直接応募が向く場面

| 場面 | 理由 |
|---|---|
| 応募先が決まっている | 経路を挟む必要がありません |
| 紹介で扱われていない | 企業の採用ページだけの募集があります |
| 自分のペースで進めたい | やり取りの数が減ります |
| 少数に絞って出す | 調整の必要が小さい |

**2つ目です。**

**企業の採用ページにのみ掲載されている募集**があります。

**探し方の1つとして、候補の会社の採用ページを直接見る**方法があります。

**とくに、行政が相手の事業を担う会社では、自社のページだけで募集していることがあります。**

## 紹介経由が向く場面

| 場面 | 理由 |
|---|---|
| 在職中で時間が限られる | **日程の調整を任せられます** |
| 条件の確認が必要 | 応募の前に照会できます |
| 複数を並行して見たい | 進行の管理を任せられます |
| 経歴の言い換えに迷う | 書類の確認を受けられます |
| 掲載されていない募集を見たい | 紹介を通じて示されます |

**1つ目と4つ目**です。

**役所の経験は、職名だけでは中身が伝わりません。**

**どう書けば読まれるかを確認できる**点は、最初の1通を書くときに効きます。

**書き方は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

:::insight
経路の選び方で、**面談でお聞きしているのが「その会社を、どこで知りましたか」**という点です。**既に応募先が決まっていて、企業の採用ページから応募できる状態なら、直接応募で差し支えありません。**経路を挟む理由がないためです。一方、**「行政が相手の会社を探している」という段階なら、紹介を併用するほうが早い**です。理由は、**候補の会社を自分で挙げるところから始まるから**です。役所で接していた事業者は、**担当していた分野の関係先に限られます。**その範囲の外に、**同じ経験が使える会社があります。**ですから、**会社が決まっているかどうかで、経路の選び方が変わります。**決まっているなら直接、探す段階なら併用。**この分け方が現実的**です。そして、**併用しても、同じ会社に重複して応募しなければ問題は生じません。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 重複に注意する

| 場面 | 起きること |
|---|---|
| 同じ会社に2つの経路から応募 | **選考が進めにくくなります** |
| 経路の記録がない | どこから応募したか分からなくなります |
| 紹介を受けた後に直接応募 | 重複になります |

**応募の前に、経路を決めてください。**

**記録は、会社名・日付・経路の3項目**で足ります。

**紹介を受けた求人に、後から直接応募しないでください。**

**既に紹介された時点で、企業に情報が渡っていることがあります。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 選考で有利・不利があるか

| 項目 | 実際 |
|---|---|
| 経路による選考の差 | **企業が見るのは経験と条件**です |
| 書類の扱い | 同じ基準で読まれます |
| 面接の内容 | 変わりません |
| 条件の決まり方 | 企業の制度によります |

**経路そのものが判断を変えるものではありません。**

**ただし、紹介経由の場合、推薦する形で選考が進みます。**

**経歴の補足が添えられる**点は、直接応募との違いです。

**一方、直接応募では、志望の動機を自分の言葉で最初から伝えられます。**

**どちらにも理由があります。**

## 併用する場合の進め方

| 順 | やること |
|---|---|
| 1 | 応募先の候補を一覧にする |
| 2 | 各社について、経路を決める |
| 3 | 紹介に伝える会社と、直接出す会社を分ける |
| 4 | 記録を残す |
| 5 | 進行を確認する |

**2が要**です。

**1社につき1経路**に固定してください。

**3について。**

**紹介を使う場合、応募済みの会社を伝えておいてください。**

**重複を避けられます。**

## 個人情報の扱いで確認できること

| 確認すること | 内容 |
|---|---|
| 収集の目的 | 何のために使われるか |
| 提供の範囲 | どの企業に渡されるか |
| 同意の取り方 | 推薦の前に確認があるか |
| 保管の期間 | いつまで保持されるか |
| 削除の求め | 申し出ができるか |

**2つ目と3つ目を確認してください。**

**紹介を通す場合、推薦する前に応募先の確認があるかどうか**が要点です。

**在職中の勤務先に関係する会社がある場合、その旨を伝えておくと、対象から外せます。**

**当社では、推薦する前に応募先を確認しています。**

**なお、これらは応募の前に聞いて差し支えありません。**

**「どの範囲に情報が渡りますか」という照会で足ります。****応募の前であれば、いつでも確認できます。**

## よくある失敗

**1. 同じ会社に複数の経路から応募する**

**選考が進めにくくなります。**

**2. 経路を記録しない**

**どこから応募したか分からなくなります。**

**3. 紹介を受けた求人に、後から直接応募する**

**重複になります。**

**4. 経路で有利・不利が決まると考える**

**経験と条件で判断されます。**

**5. 在職中に、すべてを自分で調整する**

**日程の調整が負担になります。**

**6. 企業の採用ページを見ない**

**そこだけの募集があります。**

**7. 紹介に応募済みの会社を伝えない**

**重複します。**

:::insight
ここまで違いの話をしておいて逆のことを言いますが、**経路を選ぶことに時間をかけないでください。**面談で拝見していると、**「どちらから出すのが得か」を考えるうちに、応募の時期が遅れる方**がいらっしゃいます。**求人には掲載の期間があります。**行政が相手の事業では、**受託や指定の時期に合わせて募集が出る**ため、**時期を逃すと次がいつになるか読めません。**ですから、**経路の検討は「重複しないように決める」までで足ります。**得かどうかではなく、**混乱しないように分ける**という観点です。そして、**迷ったら、条件の確認が必要かどうかで決めてください。**確認したいことがあるなら紹介、既に条件が分かっていて応募先も決まっているなら直接。**この1問で決まります。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **職業安定法第5条の5**は、**紹介事業者と求人者の双方**に、**目的を明らかにして個人情報を収集し、その範囲内で保管・使用すること**と、**適正な管理の措置**を義務づけています
- 変わるのは、**求人の入手、条件の照会、日程の調整、辞退の連絡**です。**費用はどちらもかかりません**
- **応募先が決まっているなら直接、探す段階なら併用**が現実的です
- **企業の採用ページだけの募集**があります。候補の会社は直接見てください
- **経路そのものが選考の判断を変えるものではありません**
- **1社につき1経路**に固定し、**会社名・日付・経路**を記録してください
- **紹介を受けた求人に、後から直接応募しない**でください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 直接応募のほうが、採用されやすいと聞きました

**企業が見るのは、経験と条件**です。**経路によって選考の基準が変わるものではありません。**なお、**企業の側の事情として、採用にかかる費用の違いはあります。**ただし、**それが選考の判断を左右するかは、企業の方針によります。**費用の違いを理由に、**経験が合わない人を採用することはありません。**判断の目安は、**自分がその求人の条件に合っているかどうか**です。合っていれば、**どちらの経路でも選考は進みます。**合っていなければ、経路を変えても結果は変わりません。**経路ではなく、条件の合い方を見てください。**

### 紹介で示された会社に、自分でも応募できますか

**同じ求人については、避けてください。**既に紹介された時点で、**企業に情報が渡っていることがあります。**この状態で直接応募すると、**同じ人の応募が2つ届き、選考が進めにくくなります。**なお、**紹介を受けたが応募しなかった場合**の扱いは、**紹介を受けたところに確認**してください。一定の期間が経過していれば、扱いが変わることがあります。**自己判断で出さず、先に確認**してください。**同じ会社の別の職種に応募したい場合**も、**経路を決めてから**進めてください。

### 在職中は、どちらが進めやすいですか

**日程の調整が必要な場合、紹介のほうが手間は少なくなります。**面接の時間帯、連絡の方法、書類の提出の時期。**これらを自分で調整すると、平日の日中に対応する場面が増えます。**一方、**応募先が1社か2社に絞られている場合、直接でも負担は大きくありません。**判断の目安は、**並行して見る数**です。**数が増えるほど、調整の手間が増えます。**なお、**どちらの場合も、連絡できる時間帯を先に伝えておいてください。**勤務時間中の電話を避けたい旨は、**伝えれば配慮の対象になります。**
