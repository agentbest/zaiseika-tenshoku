**資料を作り慣れている方でも、提案の資料では勝手が違います。**

**目的が違う**ためです。

この記事では、**違い**と、**足すべき技術**を扱います。

## 議会への説明書は、提出が義務づけられています

**地方自治法第122条**です。

> **普通地方公共団体の長は、議会に、第二百十一条第二項に規定する予算に関する説明書その他当該普通地方公共団体の事務に関する説明書を提出しなければならない。**

**「説明書」**という言葉が使われています。

**提案書でも、企画書でもありません。**

**事務の内容を説明するための書類**です。

**そして、提出が義務づけられています。**

**つまり、行政の資料は「説明のために出すもの」**という性格を持ちます。

**この性格が、作り方を決めています。**

## 目的の違い

| 項目 | 議会・庁内の資料 | 提案の資料 |
|---|---|---|
| 目的 | **正確に説明する** | **決めてもらう** |
| 読み手 | 議員、上司、監査 | 顧客、経営層 |
| 分量 | 網羅する | **絞る** |
| 構成 | 経緯、現状、内容 | **結論、理由、効果** |
| 数字 | 正確さを優先 | **意味が伝わることを優先** |
| 図表 | 表が中心 | 図が中心 |
| 想定する読み方 | 手元で読む | **その場で見る** |

**3行目と7行目が中心**です。

**議会の資料は、後から検証されることを前提に作られます。**

**提案の資料は、その場で見ながら聞かれます。**

**1枚に載せる情報の量が、まったく違います。**

## 行政で身についていること

| 技術 | 内容 |
|---|---|
| ① 正確さ | **数字と事実の確認** |
| ② 根拠の明示 | どの資料、どの条文によるか |
| ③ 校正 | 誤りを残さない |
| ④ 期限の管理 | 議会の日程に合わせる |
| ⑤ 想定問答との連動 | 問われる点を資料に反映 |
| ⑥ 定型の踏襲 | 読み手が探しやすい |

**①と③が、民間でも評価されます。**

**提案の資料でも、数字の誤りは信用に直結します。**

**「確認してから出す」という習慣は、そのまま使えます。**

## 足すべき技術

| 技術 | 内容 |
|---|---|
| ① 結論を1枚目に置く | **最初に何を決めてほしいか** |
| ② 1枚1メッセージ | 1枚で言うことを1つに |
| ③ 情報を削る | **載せない判断** |
| ④ 図で示す | 関係、流れ、比較 |
| ⑤ 相手の利得を書く | 相手にとっての意味 |
| ⑥ 次の行動を示す | 最後の1枚 |

**③が、最も難しい部分**です。

**行政の資料は、網羅性が求められるため、削る訓練をしていません。**

**「この1枚から、何を落とせるか」**を考える習慣が要ります。

**なお、削るのは本体からであって、根拠を捨てるわけではありません。**

**根拠は、参考の資料として別に用意**してください。

## 作り直しの手順

**過去に作った説明の資料を使って練習できます。**

| 順 | やること |
|---|---|
| 1 | 結論を1枚目に移す |
| 2 | 経緯を後ろに回す |
| 3 | **1枚あたりの情報を半分に減らす** |
| 4 | 表の一部を図に置き換える |
| 5 | 最後の1枚に、依頼を書く |
| 6 | 根拠を参考の資料にまとめる |

**3が要**です。

**削った内容は、参考の資料に移してください。**

**捨てるのではなく、置く場所を変える**という作業です。

:::insight
資料について、**面談でお伝えしているのが「校正の習慣を書いてください」**という点です。**「資料の作成」とだけ書かれても、民間の読み手には水準が分かりません。**ところが、**「議会に提出する資料について、数字の根拠を突き合わせたうえで複数名で校正する運用を担当」**と書かれていると、**具体に伝わります。**そして、**この習慣は、民間で不足していることがあります。**提案の資料に誤った数字が載る、前回の案件の社名が残っている、単位が揃っていない。**これらは、実際に起きています。**そして、**数字の誤りは、その場で信用を失います。**行政では、**議会に出す資料に誤りがあると、訂正の手続が必要になる**ため、確認が習慣になっています。書類には、**「確認の手順」**を書いてください。**作った資料の数より、この運用のほうが伝わります。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 行政が相手の事業 | **提案書と仕様の読み合わせ** |
| ② 調査・コンサルティング | 報告書の作成 |
| ③ 事業の企画 | 社内の提案 |
| ④ 広報・渉外 | 対外の資料 |
| ⑤ 管理部門 | 経営層への報告 |

**①について。**

**行政を相手とする提案では、根拠を求められます。**

**「なぜこの金額か」「どの基準によるのか」。**

**説明の資料を作ってきた経験は、そのまま使えます。**

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 作った資料の種類 | **議会、住民、事業者向け** |
| 確認の手順 | 校正、突き合わせ |
| 分量への向き合い方 | 絞る意識があるか |
| 図表の使い分け | 表と図の選び方 |
| 期限の守り方 | 逆算の仕方 |

**3行目です。**

**「行政では網羅するが、提案では絞ると理解している」**と示せると、適応の見通しが伝わります。

**なお、特定の事案が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 学ぶ前に考えること

| 確認すること | 内容 |
|---|---|
| ① すでにある経験 | **作った資料の種類と運用** |
| ② 足りない部分 | 構成、分量、図 |
| ③ 応募したい求人の条件 | 資料の作成が挙がっているか |
| ④ 期限 | 応募の時期までに間に合うか |

**②について。**

**講座を受けるより、手元の資料を作り直すほうが早い**ことがあります。

**なお、講座を受ければ転職できる、という関係にはありません。**

**何を、誰に向けて、どう作ってきたか**が、評価の対象です。

## 書き方の例

**悪い例**

> 議会資料や説明資料の作成を担当しました。

**良い例**

> ◯◯に関する事務について、**議会へ提出する説明の資料（◯ページ）と、住民説明会の資料（◯枚）を作成。****数字の根拠を原資料と突き合わせ、複数名で校正する手順を整備。**説明会では、**制度の流れを図に整理し、質問の多かった点を翌回の資料に反映。**庁内向けには、**◯◯の比較検討の資料を作成し、課内会議での判断に使用。**

**「種類」「分量」「確認の手順」「反映」「使われ方」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

**なお、資料の枚数だけを並べないでください。**

**何のために作り、どう使われたか**が中心です。

## よくある失敗

**1. 「資料の作成」とだけ書く**

**種類と運用**を書いてください。

**2. 校正の習慣を書かない**

**民間で不足している**部分です。

**3. 経緯から始める**

**提案では結論が先**です。

**4. 1枚に情報を詰める**

**その場で見られる前提**にしてください。

**5. 削ると根拠が消えると考える**

**参考の資料に移して**ください。

**6. 図を使わない**

**関係と流れ**は図が向きます。

**7. 依頼を書かずに終える**

**次の行動**を示してください。

**8. 講座を受ければ進めると考える**

**誰に向けてどう作ったか**が評価の対象です。

:::insight
ここまで「絞る」話をしておいて逆のことを言いますが、**網羅できることは、条件が合えば強みになります。**面談で拝見していると、**民間の作法に合わせようとして、網羅性を捨ててしまう方**がいらっしゃいます。ところが、**行政を相手とする提案や、規制を受ける業種の報告書では、網羅性が求められます。**要件を1つでも落とすと、審査で減点される。報告の項目が欠けると、差し戻される。**このとき、「漏れなく書く」技術が効きます。**そして、**漏れなく書くには、項目を立てて埋めるという作業の型**が必要です。行政の資料は、**この型で作られています。**ですから、**絞る技術と網羅する技術の両方を持ち、相手によって使い分ける**という形にしてください。面接では、**「提案の資料は絞る。仕様や報告は漏れなく書く。相手によって使い分けている」**と話せると、実務が分かっていると読まれます。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方自治法第122条**は、**長が議会に、予算に関する説明書その他の事務に関する説明書を提出しなければならない**としています
- **行政の資料は「説明のために出すもの」**です。この性格が作り方を決めています
- **議会の資料は正確に説明するため、提案の資料は決めてもらうため**のものです
- 行政で身につくのは、**正確さ、根拠の明示、校正、期限の管理、想定問答との連動**です
- 足すのは、**結論を1枚目に、1枚1メッセージ、削る、図、相手の利得、次の行動**です
- **削るのは本体からであって、根拠は参考の資料に移して**ください
- **絞る技術と網羅する技術を、相手によって使い分けて**ください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 作成した資料を、応募先に見せられますか

**庁内の文書には、公表されていない情報が含まれることがあります。****持ち出しや提示の可否は、所属の規程を確認**してください。なお、**公表されている資料**（広報紙、公表された計画、議会に提出され公開されている資料）であれば、**公表の範囲で示せる**ことがあります。判断に迷う場合は、**内容を見せず、作業の説明にとどめて**ください。「◯◯に関する説明の資料を、◯枚構成で作成。数字の根拠を突き合わせたうえで複数名で校正」という形で、**作り方は説明できます。**守秘の義務は、退職した後も続きます。

### 図を作るのが苦手です

**まず、表を図に置き換える練習から始めてください。**関係を示す図、流れを示す図、比較を示す図。**この3種類で、多くの場面は足ります。**凝った図は必要ありません。なお、**会社によって、使う様式や配色が決まっている**ことがあります。**入社後に、既存の資料を見て合わせる**のが確実です。**応募の段階で、図の技術を理由に候補を狭めないでください。**求人票の応募条件に「資料作成の経験」と書かれていれば、**説明の資料の作成も該当します。**読み方は[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。

### 提案の資料は、どこで型を学べますか

**応募先が公表している資料を読むのが早いです。**事業の説明、サービスの紹介、投資家向けの資料。**その会社が、外に向けてどう説明しているか**が分かります。そのうえで、**手元の説明の資料を作り直す**練習をしてください。結論を先に、分量を半分に、依頼を最後に。**この3点だけでも、形が変わります。**なお、**話す技術については**[プレゼンテーション｜説明と提案は別の技術](skill-presen.html)**に整理しています。**資料と話し方は、別の技術として分けて考えてください。
