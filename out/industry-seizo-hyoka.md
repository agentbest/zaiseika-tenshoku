製造業の管理部門を検討される方から、**遠慮がちにこう伺う**ことがあります。

**「役所の事務が、工場で役に立つでしょうか」**

**立ちます。**しかも、**ご本人がいちばん軽く見ている部分**が評価されます。

**理由は、会社の側が何を義務として負っているかを見れば分かります。**この記事では、**法令上の体制から逆算して、どの経験が評価されるか**を扱います。

職種の整理は[未経験から製造業の管理部門に入るには](industry-seizo-mikeiken.html)、選考の進み方は[製造業の管理部門の選考フローと、面接で見られている観点](industry-seizo-senko.html)にあります。

## 工場には、調査審議する会議体が求められています

**労働安全衛生法第17条第1項**です。

> **（安全委員会）第十七条　事業者は、政令で定める業種及び規模の事業場ごとに、次の事項を調査審議させ、事業者に対し意見を述べさせるため、安全委員会を設けなければならない。**
>
> 一　**労働者の危険を防止するための基本となるべき対策に関すること。**
>
> 二　**労働災害の原因及び再発防止対策で、安全に係るものに関すること。**

そして、**同法第19条第1項**です。

> **事業者は、第十七条及び前条の規定により安全委員会及び衛生委員会を設けなければならないときは、それぞれの委員会の設置に代えて、安全衛生委員会を設置することができる。**

**同条第2項**は、**委員の構成**を定めており、**総括安全衛生管理者、安全管理者、衛生管理者、産業医などが委員に含まれる**構造になっています。

**ここで注目していただきたいのは、この会議体の性格**です。

**「調査審議させ、事業者に対し意見を述べさせるため」**に設けられる。**議題が法令で定まっていて、構成員も定まっていて、意見を述べさせることが目的**です。

**これは、役所の審議会・委員会と、まったく同じ構造**です。

## 会議体を回す仕事は、想像以上に評価されます

**審議会の事務をやってきた方なら、次の作業が思い浮かぶはずです。**

| 会議体の事務 | 具体的にやること |
|---|---|
| 招集の手続き | 日程の調整、通知、定足数の確認 |
| 議題の整理 | **何を諮るか、どこまで決めるか** |
| 資料の作成 | 前提の説明、論点の提示 |
| 議事の進行 | **時間配分、発言の整理** |
| 議事録の作成 | **後から検証される前提の記録** |
| 決まったことの実行 | 担当への割り振り、進捗の確認 |

**この6つを、決まった周期で回し続けられる人**は、**民間では貴重です。**

**理由は、会議体を回す仕事が「誰の本業でもない」から**です。工場では、**安全の担当者が、本来の業務の合間にやっている**ことが少なくありません。結果として、**議事録が溜まる、決まったことが実行されない**という状態になりがちです。

**役所は、審議会の運営を庶務として制度的に担ってきました。**この経験は、**そのまま持ち込めます。**

## 評価される経験は、5つに整理できます

| 経験 | 製造業での呼ばれ方 | なぜ評価されるか |
|---|---|---|
| ① 審議会・委員会の事務 | 安全衛生委員会の運営 | **法令上設けなければならない会議体** |
| ② 届出の受理・審査 | 環境・安全の届出、報告 | **出す側で、どこで漏れるかが分かる** |
| ③ 立入検査・監視 | 監査・検査への対応 | **受ける側の準備ができる** |
| ④ 要綱・規程の作成 | 社内規程、作業手順の整備 | 条文の形で書くことに慣れている |
| ⑤ 契約・入札の事務 | 購買、設備投資の契約 | 条件を読んで詰める動作が同じ |

**①が、この記事でいちばん申し上げたい点**です。

**②と③は、[未経験から製造業の管理部門に入るには](industry-seizo-mikeiken.html)で扱ったとおり、環境部局・保健所・消防の経験が直結します。**

**大気汚染防止法第6条第1項**が**「ばい煙発生施設を設置しようとするとき」の都道府県知事への届出**を義務づけているとおり、**工場は複数の法令の届出の対象**です。**受け取る側にいた経験は、出す側でそのまま使えます。**

**④も効きます。**工場には、**作業の手順書、点検の様式、記録の書式**が大量にあります。**これを整えられる人**は、どの工場でも要ります。

## 言い換えの表

**職務経歴書に、役所の言葉のまま書かないでください。**

| 役所での言い方 | 製造業に伝わる言い方 |
|---|---|
| 審議会の庶務 | **法令にもとづく会議体の招集・議事・記録の運営** |
| 届出の受理・審査 | **◯◯法にもとづく届出の審査と、適合性の確認** |
| 立入検査 | **現地での運用状況の確認と、是正の要求** |
| 要綱の制定・改正 | 内部規程・様式の作成と改正 |
| 起案・決裁 | 稟議の作成と、関係部署との合議の取りまとめ |
| 支出負担行為の確認 | 発注前の、予算と契約の条件の確認 |
| 入札の執行 | 調達手続きの運用と、業者の選定 |
| 監査の指摘への対応 | **指摘への対応と、再発防止の仕組みの整備** |
| 苦情・相談の対応 | 近隣・関係先からの問い合わせへの対応 |

**⚠ 法令名を必ず入れてください。**この業界では、**「環境関係の許認可」より「大気汚染防止法にもとづく届出」**のほうが、**読む側の受け取り方が変わります。**

**最後の行について補足します。**工場には、**近隣からの騒音・においの問い合わせ**が入ります。**役所の窓口で苦情を受けてきた経験は、この対応に直結します。**

## 評価されにくい経験

**正直に書いておきます。**

| 経験 | 評価されにくい理由 |
|---|---|
| 特定の制度の細かい運用の知識 | **その法令の対象でない工場では使えない** |
| 庁内の根回しの経験 | 相手も組織の形も違う |
| 前例の踏襲を徹底した実績 | 前例の無い場面が定期的に起こる |
| 在籍年数そのもの | 年数より、何を担ったか |
| 役職の名称 | **対応する段階が会社側に無い** |

**「課長補佐を◯年」という書き方は、この業界では効きません。**

**書くなら、「◯人の係の事務の進行を管理し、年間◯件を処理した」**です。**段階の名前ではなく、担った範囲と件数**で書いてください。

:::insight
面談で拝見していて、**製造業を受ける方がいちばん取りこぼしているのが、苦情や近隣対応の経験**です。皆さん、**「クレーム対応をしていました」と一言で片づけて**しまわれます。ところが、工場にとって**近隣との関係は、操業そのものに関わる問題**です。騒音、におい、粉じん、車両の出入り。**これらの申し出が自治体に入り、そこから工場に照会が来る**という流れを、**役所の側から見てきた方**は、**何が起きるか分かっています。**そして、**この対応には型があります。**まず事実を確認する、測定の記録を出せる状態にしておく、相手の言い分を記録に残す、改善の見込みを期限で示す。**役所の窓口でやってきたことと、同じです。**工場の側では、この対応を**技術系の社員が本業の合間にやっている**ことが多く、**記録の残し方が場当たりになりがち**です。そこに、**記録を前提に動く習慣を持った人**が入ると、**次に同じ申し出が来たときに説明ができる状態**になります。職務経歴書には、**「クレーム対応」ではなく「住民からの苦情の受付、事実確認、事業者への照会、改善の確認までの一連の対応を年間◯件」**と書いてください。**一連の流れを担っていたことが伝わります。**
:::

## 職務経歴書での並べ方

| 位置 | 書くもの |
|---|---|
| 冒頭の要約（3〜4行） | **扱った法令名と、担った機能** |
| 職歴の1つ目 | 直近の担当。**件数と規模を入れる** |
| 職歴の2つ目以降 | **応募先の工場に関わる法令を扱ったものを前へ** |
| 実績の欄 | **「変えた話」**（様式を作った、基準を整理した） |
| 資格・研修 | 衛生管理者、公害防止管理者などの学習 |

**冒頭の要約を必ず付けてください。**製造業の中途採用では、**配属先の部門長や工場の管理職が書類を読みます。**読む時間は限られています。

**実績の欄は、「担当した」ではなく「何が変わったか」**で書いてください。**自分が来る前と、去ったあとで何が違うか。**

**⚠ 公表されていない内部の事情や、特定の事業者に関する情報は書かないでください。**守秘の観点に加えて、**それを書く人は、次の職場の情報も外で話す**と見られます。

[経験の言い換えから相談する](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担です）。

## 面接で聞かれやすいこと

| 聞かれること | 何を確かめられているか |
|---|---|
| どの法令を、どの立場で扱っていましたか | **経験の具体性** |
| 委員会や審議会を回した経験はありますか | **①の経験** |
| 立入検査では、何を見ていましたか | 受け入れる側に回れるか |
| 近隣からの申し出に対応した経験はありますか | **工場にとって直接の関心事** |
| 製品や工程の知識がないが、大丈夫ですか | 学ぶ構え |

**3つ目は、指摘した話ではなく、見ていた観点**で答えてください。「記録が残っているか、実際の運用が届出の内容と一致しているか、変更があったときに手続きが取られているか」。**これは、そのまま工場側の自主点検の観点になります。**

**5つ目は、正直に答えて構いません。****「知識はありませんので、まず現場を見せていただきながら、どの工程がどの法令の対象になるかを対応付けます」**で足ります。

:::insight
ここまで「評価される」話をしてきましたが、**申し上げておきたいことがあります。**評価される経験があることと、**移ったほうがよいことは、別**です。面談で、**「思ったより評価されると分かったので、動かないといけない気がしてきました」**とおっしゃる方がいらっしゃいます。そうではありません。**この経験は、消えません。**届出の審査を担った事実、立入検査を担った事実、会議体を回した事実。**異動して別の分野に移っても、担った事実は残ります。**ですから、**いま動く理由が他にある場合**——通勤の事情、家族の事情、担いたい役割が変わった——**その理由で判断してください。**「評価されるから」は、**動く理由としては弱い**です。むしろ、**いまの職場で、その経験がさらに厚くなる見込みがあるなら、厚くしてから動くほうが選択肢は広がります。**とくに、**環境や安全の分野は、担当した法令の数と年数で評価が変わります。**大気だけを扱っていた方が、**水質や廃棄物も担当する**ようになると、書ける内容が一段変わる。**その異動が近いなら、待つ判断にも理があります。**評価されるという事実は、**動くと決めたときに使える材料**であって、**動く理由ではありません。**在職のまま、整理だけのご相談も承っています。
:::

## まとめ

- **評価される経験は、会社が負っている義務から逆算できます**
- **労働安全衛生法第17条第1項**は、**政令で定める業種及び規模の事業場ごとに、安全委員会を設けなければならない**と定めています。**調査審議させ、事業者に意見を述べさせるための会議体**です
- **同法第19条**は、**安全委員会と衛生委員会に代えて、安全衛生委員会を設置できる**と定め、**委員の構成**も定めています
- **この会議体は、役所の審議会・委員会と同じ構造**です。**招集・議題・資料・議事録・実行を回せる人は、民間では貴重**です
- 評価される経験は、**①審議会・委員会の事務 ②届出の受理・審査 ③立入検査・監視 ④要綱・規程の作成 ⑤契約・入札の事務**の5つです
- **大気汚染防止法第6条第1項**のとおり、**工場は複数の法令の届出の対象**です。**受け取る側の経験は、出す側で使えます**
- ⚠ **職務経歴書には、法令名を必ず入れてください。**「環境関係の許認可」より「大気汚染防止法にもとづく届出」です
- ⚠ **苦情・近隣対応の経験を「クレーム対応」で片づけないでください。**工場にとっては操業に関わる問題です
- **評価されることと、移ったほうがよいことは別**です。動く理由は、別に必要です

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 事務職で、環境や安全の法令を扱ったことがありません

**①④⑤の経験で組み立ててください。**審議会の庶務、要綱の作成、契約と入札の事務。**どれも、製造業の管理部門の仕事に対応するものがあります。**総務・人事・経理・法務の職種であれば、**行政での対応する経験が、そのまま材料になります。**そのうえで、**製造業ならではの部分を押さえておく**と話が通じます。交替制の勤務がある、安全衛生委員会がある、工場ごとに条件が違うことがある。**調べてきたことが伝われば、差が付きます。**法令の経験が無いことを、応募しない理由にしないでください。なお、**衛生管理者や公害防止管理者に関する学習**を始めておくと、関心の本気度が伝わります。⚠ **試験の内容や難度は、実施する団体の公表を確認してください。**

### 技術職です。設計や施工管理の経験は使えますか

**使えます。**工場は**建物と設備の集合体**なので、**施設の管理、修繕の計画、設備の更新の発注**を担う職種があります。役所で**工事の発注と監督**をしていた方なら、**仕様書の作成、業者との協議、検査**の経験がそのまま重なります。また、**設備を新設・変更するときに届出が必要な場合がある**ため、**技術の理解と手続きの理解の両方がある人**は、この分野で強いです。探し方は、**「設備管理」「施設管理」「工務」**といった職種名です。**製造業の求人は職種名が会社ごとに違う**ので、**仕事内容の欄を読んで判断してください。**製品の技術の知識は、入ってから覚える前提で構いません。

### 窓口や相談の業務しか経験がありません

**②③と、近隣対応の面で材料になります。**窓口の業務は、**相手の事情を聞き取り、制度に当てはめ、結論を伝え、記録に残す**という構造です。これは、**工場が近隣や行政からの問い合わせに対応する動作と同じ**です。とくに、**苦情や、制度の要件に当てはまらない相談に対応した経験**は、**説明の責任を負う場面の経験**として読まれます。書き方は、**件数と、一連の流れを担ったこと**を入れてください。「年間◯件の相談に対応し、事実確認から改善の確認までを担当した」。**判断の方針を自分で整理した、という部分が評価されます。**総務・人事の職種であれば、この経験は十分な材料になります。
