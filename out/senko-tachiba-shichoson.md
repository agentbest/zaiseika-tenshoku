**窓口、給付、現場。**

**市区町村の仕事は、住民に最も近い位置**にあります。

**この経験が民間でどう読まれるか**を扱います。

## 基礎的な地方公共団体と位置づけられています

**地方自治法第2条第3項**です。

> **市町村は、基礎的な地方公共団体として、第五項において都道府県が処理するものとされているものを除き、一般的に、前項の事務を処理する**ものとする。

**同条第2項**は、**地域における事務**を処理するとしています。

**同条第5項**では、**都道府県が広域・連絡調整・専門の事務**を担うとされています。

**つまり、そこから除かれた「地域における事務」を、一般的に市町村が処理する**という構造です。

| 団体 | 位置づけ |
|---|---|
| 市町村 | **基礎的な地方公共団体**。地域における事務を一般的に処理 |
| 都道府県 | 市町村を包括する広域の地方公共団体 |

**「一般的に」**という言葉が置かれている点が特徴です。

**特定の分野に限らず、地域の事務を幅広く担う**ということです。

## 経験の特徴

| 特徴 | 具体の例 |
|---|---|
| ① 住民への直接の対応 | 窓口、電話、訪問、説明会 |
| ② 給付・賦課の事務 | 申請の受付、要件の確認、決定、通知 |
| ③ 現場 | 施設の管理、収集、保育、学校、消防 |
| ④ 地域の事業者との関係 | 許可、委託、指導、協議 |
| ⑤ 制度の運用の幅 | **複数の制度を同時に担当** |
| ⑥ 少人数での運営 | 1人で複数の事務を担当 |

**①と⑤が、民間で読まれる中心**です。

**⑥について。**

**規模の小さい団体では、1人が複数の制度を担当します。**

**これは、「担当の範囲が広い」という書き方になります。**

## 書き方の例

**悪い例**

> ◯◯市◯◯課で、窓口業務を担当しました。

**良い例**

> ◯◯に関する申請の受付から決定までを担当。**年間約◯件の申請について、要件の確認、システムへの入力、決定の起案、通知の発送を実施。**制度改正に伴い、**要綱と様式を改正し、対象者約◯件への周知と、窓口の説明の手順を整備。****苦情の申出があった事案について、経緯を整理し、対応の方針を作成。**

**「件数」「工程」「作ったもの」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 言い換えの対応

| 役所の言葉 | 民間での読まれ方 |
|---|---|
| 窓口の対応 | **顧客の対応、一次の受付** |
| 申請の審査 | 基準に照らした確認、与信に近い判断 |
| 決定の起案 | 判断と、その記録 |
| 苦情への対応 | 顧客の苦情の対応、是正 |
| 要綱・様式の整備 | 業務の手順の設計 |
| 委託の管理 | 外部の委託先の管理 |
| 収納・滞納の整理 | **債権の管理と回収** |

**7行目です。**

**滞納の整理は、民間では債権の管理にあたります。**

**分割の相談、財産の調査、滞納の処分。**

**この経験は、金融、通信、不動産の管理、医療の事務などで使えます。**

## 民間での使いどころ

| 領域 | 使える経験 |
|---|---|
| ① 窓口の運営の受託 | **住民対応の経験がそのまま** |
| ② 債権の管理 | 収納・滞納の整理 |
| ③ 顧客の対応 | 苦情、説明、一次の受付 |
| ④ 施設の運営 | 指定管理、現場の管理 |
| ⑤ 福祉・介護・保育 | 現場と制度の両方を知っている |
| ⑥ 自治体向けの事業 | **現場の実務が分かる** |

**⑥について。**

**自治体向けのシステムやサービスの会社では、「現場で実際にどう使われるか」を知っている人**が求められます。

**窓口でシステムを使った経験は、導入の支援の業務で直接使えます。**

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 何を担当したか | **件数、工程、範囲** |
| 難しい対応の経験 | 3件、経緯と結論 |
| 複数の制度を担当した経験 | 同時に扱った数 |
| 改善した点 | 様式、手順、記入例 |
| 対人の場面での姿勢 | 説明の工夫 |

**2行目です。**

**対応が難しかった場面は、必ず聞かれる**と考えて用意してください。

**何が難しく、どう整理し、どう結論づけたか。**

**なお、特定の住民が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

:::insight
市区町村の職員の方のご相談で、**面談でお伝えしているのが「窓口の経験を、軽く見ないでください」**という点です。多くの方が、**「窓口しかやっていない」**とおっしゃいます。ところが、**窓口の業務は、複数の動作が組み合わさった仕事**です。相手の話を聞き取る、要件に当てはまるか確認する、制度を説明する、書類を点検する、判断して起案する、通知を出す、苦情に対応する。**これを、相手が選べない状況で、毎日繰り返しています。**民間の顧客の対応では、**相手を選べる場面**があります。役所の窓口には、それがありません。**そして、感情的な場面も含めて、記録を残しながら対応している。**この経験は、**顧客の対応を担う部署で高く評価されます。**書類には、**「年間約◯件の対応」**と数を書き、**「苦情の申出があった事案について、経緯を整理し、対応の方針を作成」**と、**処理した事実**を書いてください。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 準備の順序

| 順 | やること |
|---|---|
| 1 | 担当した制度を書き出す（同時に扱った数も） |
| 2 | 件数、工程、範囲を確認する |
| 3 | **改善した点を書き出す** |
| 4 | 民間の言葉に置き換える |
| 5 | 求人を読む |
| 6 | 職務経歴書を作る |

**3が要**です。

**様式を直した、記入例を作った、手順を書き出した、説明の資料を作った。**

**規模が小さくても、自分で動いた事実**になります。

[経験の言い換えから相談する](../apply.html)こともできます。

## 在職中の進め方

| 項目 | 内容 |
|---|---|
| 記録 | 担当した件数、同時に扱った制度の数 |
| 資料の確認 | 分掌、決裁の区分 |
| 求人を読む | 週に30分 |
| 日程の確保 | **年度の変わり目と、申告・賦課の時期を避ける** |

**4行目です。**

**市区町村は、年度の変わり目に手続きが集中**します。

**税や保険の賦課の時期も、分野ごとに異なります。**

**自分の繁忙期を書き出してから、選考の時期を決めてください。**

**扱いは**[選考スケジュールの組み方](senko-sagasu-schedule.html)**に整理しています。**

## よくある失敗

**1. 「窓口しかやっていない」と考える**

**複数の動作が組み合わさった仕事**です。

**2. 件数を書かない**

**範囲が伝わりません。**

**3. 滞納の整理を書かない**

**債権の管理**として読まれます。

**4. 改善した点を書かない**

**自分で動いた事実**になります。

**5. 複数の制度を担当した経験を書かない**

**担当の範囲の広さ**になります。

**6. システムを使った経験を書かない**

**自治体向けの事業**で使えます。

**7. 繁忙期に選考を始める**

**年度の変わり目は避けてください。**

**8. 特定の住民が分かる説明をする**

**守秘の義務は退職後も続きます。**

:::insight
ここまで経験の話をしておいて逆のことを言いますが、**市区町村の職員が持っている最大の材料は「現場を知っていること」です。**面談で拝見していると、**制度の設計に関わっていないことを気にされる方**がいらっしゃいます。ところが、**自治体向けの事業を行う会社が最も欲しがっているのは、現場の実務を知っている人**です。理由は、**制度の条文は読めても、窓口で何が起きるかは分からないから**です。申請書のどの欄で住民が迷うか、どの説明で納得が得られないか、繁忙期に窓口がどう回るか、システムのどの画面で手が止まるか。**これらは、現場にいないと分かりません。**そして、**この理解が、導入の支援や業務の設計の品質を左右します。**ですから、書類には**「窓口で実際にどう運用したか」**を書いてください。**制度を作る側の経験がないことは、弱みではありません。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方自治法第2条第3項**は、**市町村を基礎的な地方公共団体**とし、**地域における事務を一般的に処理する**としています
- **「一般的に」**という言葉のとおり、**幅広い事務を担う**点が特徴です
- **窓口の業務は、複数の動作が組み合わさった仕事**です。軽く見ないでください
- **滞納の整理は、債権の管理**として読まれます
- **複数の制度を同時に担当した経験**は、担当の範囲の広さになります
- **現場の実務を知っていること**が、自治体向けの事業では最大の材料になります
- 書くのは、**件数・工程・範囲・改善した点**です

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 小規模な団体で、扱った件数が少ないです

**件数の少なさは、担当の範囲の広さで補えます。**規模の小さい団体では、**1人が複数の制度を担当する**ことが一般的です。書き方は、**「◯◯、◯◯、◯◯の3つの制度を同時に担当し、受付から決定、統計の作成までを一貫して実施」**という形です。**工程を一貫して担った**という点は、規模の大きい団体では得にくい経験です。また、**制度改正への対応も、1人で担う**ことがあります。「改正に伴い、要綱・様式・説明の資料を作成」と書けば、**設計に近い動作**が伝わります。**件数ではなく、範囲と工程で書いてください。**

### 専門性がないと感じます

**専門性は、分野の名前ではなく動作で示せます。**基準に照らした判断、相手への説明、記録の作成、苦情への対応、システムの運用。**これらを何年続けたかが、専門性の中身**です。とくに、**例外の処理**は評価されます。「制度の要件に当てはまらない事案について、類似の事例と関係法令を確認したうえで判断の方針を整理し、◯件を処理」という形で書いてください。**年数がないとできないこと**です。扱いは[同じ部署が長い場合の職務経歴書](senko-shokumu-onajibusho.html)にも整理しています。**分野の名前で考えると見つかりませんが、動作で考えると受け皿があります。**

### 住民対応の経験は、どの職種で使えますか

**顧客の対応を担う職種**です。具体には、**一次の受付、苦情の対応、契約の手続きの案内、窓口の運営の受託**などがあります。また、**債権の管理**（金融、通信、医療の事務、不動産の管理）でも、**滞納の整理の経験**が直接使えます。さらに、**自治体向けの事業**では、**窓口の実務を知っていること自体が要件**になることがあります。求人票では、「カスタマーサポート」「オペレーション」「公共サービス」など、**職種名が分かれます。**職種名ではなく、**仕事内容の欄**で探してください。扱いは[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)に整理しています。
