国家公務員が地方自治体へ「出向する」と説明された場合は、まず正式な任用と身分の扱いを確認します。国の職員を退職して地方の職へ任用される場合と、併任や研修等の説明を受ける場合では、必要な通知、給与、服務、共済の手続きが異なります。

本記事は2026年11月時点の公開情報にもとづきます。国と地方の人事交流に関する公式資料と法令を基に、国から地方へ移るときの確認を整理します。「出向」という通称だけで、在籍、復帰、退職手当の通算を確定するものではありません。

## 出向は身分保持を一律に意味する言葉ではない

内閣人事局が2026年に公表した人事交流資料は、2025年10月1日現在の国と地方の交流を扱っています。その集計でいう出向は、出向元への復帰を前提とすることなどを条件としています。復帰を前提とするという説明と、国の身分が在籍中ずっと残るという説明は別です。

同資料は交流の実施状況であり、すべての職員の給与や任用手続きを一つに定める規程ではありません。個別の通知を確認し、誰が、どの職に、いつ任命するのかを明らかにする必要があります。

| 説明を受けた事項 | 本人が確認すること |
| --- | --- |
| 国を退職して自治体へ移る | 辞職等の手続きと地方の任命、双方の日付 |
| 併任となる | 兼ねる職、各身分の根拠、解除の条件 |
| 研修・実務研修として赴く | 元の身分、研修命令、受入先での権限 |
| 交流終了後に戻る予定 | 戻る際の採用・任用と必要な手続き |

これは本人が説明を分類するための表です。どの形態も自由に選べるという意味ではなく、職種や案件の根拠に沿って確認します。

## 国の退職と地方の任用はそれぞれ通知を見る

国を退職して自治体の職員となる場合、地方側の職に任命されるための手続きが必要です。地方公務員法第6条は任命権者を、第15条の2は採用等の定義を、第17条は欠員を補う任命の方法を定めています。国での職名が、そのまま地方側の任命通知になるわけではありません。

本人が確認するのは、国の手続きの名称、最終在職日、地方での官職・職名、任命日、任期の有無です。前任者がどの形態だったかという話だけで、自分の身分も同じと判断しないようにします。

併任と説明される場合は、国の官職と地方の職をそれぞれ特定し、どちらの根拠で併任するかを確認します。任命通知、勤務の命令、事務分掌、給与の決定は別の資料で示される場合があります。「二つの名称が付くから給与も二重」という理解はしません。

研修であれば、受入先の職に任命されるのか、元の身分で研修を行うのかを確認します。実際に自治体の庁舎で仕事をするという場所の事実だけでは、処分や決裁を行う権限、勤務時間、服務の適用は分かりません。

## 地方公共団体間派遣や官民交流とは分ける

地方自治法第252条の17は、普通地方公共団体間の職員派遣を定めています。派遣先の身分も併せ持つことや費用負担の規定がありますが、この規定を国から地方への交流に、そのまま共通の根拠として使うことはできません。

また、官民人事交流法による交流派遣は、国と民間企業等の間の別の制度です。人事院の概要にある国の身分保持、企業との労働契約、期間等を、地方自治体への出向へ流用しないことが必要です。

国と地方の人事交流を推進する方針があることも、本人に希望先への異動請求権や同じ条件での復帰を保証するものではありません。令和8年度の人事管理運営方針は交流の推進を示していますが、個別の任用は正式な担当間の調整と根拠によって確認します。

他の制度との比較は[公務員の出向と在籍出向・転籍](seido-ninyo-shukko-shurui.html)でも整理しています。制度名と任命主体を確認してから、必要な手続きへ進んでください。

:::insight
出向の説明を受けたときは、「戻る予定があるから今までと同じ」と考える前に、身分と期間の資料をそろえることを勧めます。国を退職するのか、どの地方の職に任命されるのか、戻るときはどの手続きを取るのかが分かれば、給与や共済を尋ねる順序も整理できます。本人の適性や仕事の評価と、制度上どの形態で交流するかは別の問題です。退職という言葉だけで不利益を推測したり、交流という言葉だけで手続き不要と受け取ったりする必要はありません。現在の公務を続ける中で経験する役割として、通知と正式な説明に基づき条件を確かめることが、落ち着いた判断につながります。
:::

一般の転職との違いも整理したい場合は、[公務員向けの仕事の情報](../?gov=1)を参照できます。交流を希望する相談は所属の人事担当で行い、外部の応募とは分けて進めます。

## 給与と服務は支払元・任用先・業務を照合する

地方の職員として任用される場合は、地方側の給与条例等と本人の格付けを確認します。国の俸給月額、地域手当、役職名がそのまま引き継がれるとは限りません。給与の前歴換算と退職手当の勤続通算も、別の計算です。

人事担当へは、どの機関が給与を支払うか、手当の対象、期末・勤勉手当等の算定、勤務時間、休暇、旅費を分けて照会します。費用をどの組織が負担するかという取決めと、本人へ何が支給されるかの説明も分けて確認してください。

服務では、現在の職務上の指揮命令、決裁権限、相談や報告の経路を確認します。元の府省へ業務報告をする予定があっても、自治体の未公表情報を本人の判断で転送してよいという意味ではありません。正式な情報共有の範囲と経路を確認します。

引継ぎは双方の組織の手順に従い、住民情報や契約資料を私物端末へ移す方法を取りません。職務経験を後に説明するときも、担当した役割と公開できる範囲を区別してください。

## 共済の異動と年金の記録は別々に確認する

国から地方へ移るときは、医療の資格喪失・取得、被扶養者の認定、年金の異動を本人の任用区分に応じて確認します。国と地方の両方に共済があるから、本人の届出がすべて不要とは考えないようにします。

公式例として、防衛省共済組合の長期組合員向け案内は、退職翌日に地方公務員となる場合について、組合員転出届書の手続きを説明しています。これは当該組合の案内です。書類名、提出経路、対象区分は本人の所属組合へ確認し、他組合の締切を全国一律のものとして使わないでください。

医療の給付を受ける保険者が変わることと、過去の年金記録がなくなることは異なります。厚生年金、公務員期間の経過的職域部分、退職等年金給付について、対象期間と照会先を確認します。

家族についても、旧資格が終わる日と新たな認定を確認します。マイナンバーカードに表示される情報だけで資格日を判断せず、資格確認書等の扱い、更新までの受診方法も担当へ尋ねます。貸付、貯金、団体保険等は別の契約や制度として精算・継続の条件を確認してください。

## 退職手当は国と地方双方の規定で通算を確認する

国家公務員退職手当法第20条第2項は、所定の事由で引き続いて地方公務員等となり、地方側の規定で国の勤続期間を通算することとされている場合に、国の退職手当を支給しない仕組みを定めています。

この条文は、国から地方へ移る全員に一律の通算を保証するものではありません。移る経過、任命の連続性、地方側の退職手当規定、過去の支給の有無を双方の担当で照合する必要があります。自分の判断で退職手当を受け取らなければ通算できるという仕組みとも違います。

国へ戻る場合にも、同法第7条等の在職期間の扱いと、必要な事実を確認します。地方での在職期間をどう数えるか、どの書類で引き継ぐか、除算等があるかを担当へ聞いてください。

給与の経験年数、退職手当の勤続期間、年金の加入期間は別々に回答を受けます。一つの制度で「通算する」と説明されても、残り二つが同じ条件で確定したわけではありません。

:::insight
通算の説明は、制度名を付けて記録することを勧めます。「勤務期間はつながる」という一言だけでは、給与の前歴、退職手当、年金のどの話か分からなくなるためです。本人が国と地方の担当に同じ日付と履歴を示し、それぞれの回答を照合すれば、どこが未確認かが見えます。出向であることを理由に待遇がすべて保全されると期待する必要も、退職を伴うことだけで過去の経験が失われると考える必要もありません。仕事内容や生活上の条件は制度の確認と別に検討できます。現職を続ける中での交流、現在の担当の継続、一般の採用への応募を混同せず、本人が必要な情報をそろえる進め方を大切にしたいところです。
:::

## 期間終了と復帰は予定と正式決定を分ける

出向元への復帰を前提とする場合でも、開始時に説明された予定期間、正式な地方の任期、国への復帰時の任用は区別します。任期のない地方の職へ採用される場合もあり、交流の予定期間と法定の任期を同じ欄に書かないことが大切です。

復帰の調整窓口、期間変更の確認時期、終了時の引継ぎ、給与・共済の届出を開始前から整理します。復帰先の官職や勤務地がまだ決まっていなければ、未定事項として扱います。元の席や同じ役職への復帰を本人の希望だけで確約しません。

| 時点 | 主な確認事項 |
| --- | --- |
| 開始前 | 退職・任命・併任等の通知、勤務条件、各資格日 |
| 期間中 | 業務・服務、条件変更、担当間の正式な連絡 |
| 終了前 | 復帰の予定と決定、必要書類、引継ぎ |
| 復帰時 | 任用、給与、共済、勤続資料の受渡し |

希望する経験や勤務条件の比較は[相談フォーム](../apply.html)でも受け付けています。ご利用は無料です（紹介手数料は採用企業の負担）。人事交流の正式な取扱いは、国と地方双方の担当へ確認してください。

## よくある質問

### 出向なら国の職員の身分は必ず残りますか？

通称だけでは分かりません。国を退職して地方の職へ任用される場合や、併任・研修等の扱いを、正式な通知で確認します。復帰の予定があることと身分保持は別です。

### 自治体へ移れば退職手当は必ず通算されますか？

一律ではありません。国の退職手当法と地方側の規定、移る経過と任命日、過去の支給等を確認します。給与や年金の通算とは別に、双方の退職手当担当へ照会してください。

### 期間が終われば同じ部署へ戻れますか？

復帰を前提とすることと、以前の部署・役職が保証されることは同じではありません。予定期間、任用手続き、復帰先の決定時期を正式な担当へ確認します。

職務経験を整理したい場合は、[LINE相談](https://line.me/R/ti/p/@697nxhbt)も利用できます。現職継続や制度利用を含め、情報収集の段階から相談できます。
