群馬県庁で働いてきた方の職務経歴書を見せていただくと、県の産業構造がそのまま反映されています。工業団地の造成と分譲、企業誘致、道路と物流、農業の産地形成。

これらは**民間企業がいま人を探している領域**とかなりの部分で重なります。ところが、庁内の言葉のままでは求人票と噛み合わないため、応募しても伝わりません。

この記事では、まず公表されている数字で自分の位置を確認し、そのうえで置き換えの手順を整理します。

## 群馬県庁の給与水準を、数字で確認する

総務省の調査によると、群馬県の一般行政職は次のとおりです（令和6年4月1日現在）。

| 項目 | 群馬県 |
|---|---|
| ラスパイレス指数 | 100.0 |
| 平均年齢 | 42.8歳 |
| 平均給料月額 | 327,700円 |
| 諸手当月額 | 72,071円 |
| 平均給与月額 | 399,771円 |
| 平均給与月額（国ベース） | 358,767円 |
| 地域手当（国の指定基準） | 2.5% |
| 地域手当（実際の支給割合） | 約2.50% |

**ラスパイレス指数100.0**は、国家公務員の給与水準とちょうど同じという意味です。

### 北関東3県で、地域手当の扱いが分かれている

読みどころはここです。北関東3県を並べると、地域手当の扱いがはっきり分かれています。

| 県 | 国の指定基準 | 実際の支給割合 |
|---|---|---|
| 茨城県 | 6.0% | 約7.46% |
| 栃木県 | 3.5% | 約4.40% |
| **群馬県** | **2.5%** | **約2.50%** |

**群馬県は基準どおり**で、茨城県と栃木県は基準を上回っています。地域手当は民間賃金の高い地域に支給される手当で、国の指定基準は市町村単位で決まっていますが、都道府県が独自の判断で支給割合を設定する余地があります。

そのうえで群馬県のラスパイレス指数は100.0。**上乗せ手当ではなく、給料表そのものの水準が国と同じ**という構造です。

:::insight
この違いは、県外の自治体や民間と比べるときに効いてきます。**地域手当は民間企業にはない概念です。**求人票が提示するのは基本給と諸手当を含んだ年収であって、「地域手当◯%」という内訳では書かれていません。相談でよく起きるのが、手当の名目ごとに比べようとして話が噛み合わなくなるケースです。**比べるときは、源泉徴収票の支払金額と、求人票の想定年収を突き合わせてください。**群馬県のように上乗せがない場合、額面が読みやすいぶん、この比較はしやすいはずです。
:::

なお、上の平均は自分の給与ではありません。全年齢の平均です。民間の求人票と比べるときは、**自分の源泉徴収票の支払金額**を使ってください。

## 県庁の経験は、民間で何と呼ばれるか

| 県庁での仕事 | 求人票での言い方 |
|---|---|
| 予算の要求・査定、財政計画 | 予実管理、投資判断、経営企画 |
| 工業団地の造成・分譲 | 用地開発、不動産開発、事業開発 |
| 企業誘致・立地支援 | 事業開発、アライアンス |
| 道路・物流網の整備 | インフラ企画、物流ネットワーク設計 |
| 内部管理（人事・財政・総務・会計） | コーポレート、管理部門 |
| 観光の誘客・受入環境整備 | 観光事業企画、地域ブランディング |
| 農林水産の産地形成・輸出支援 | 事業開発、産地開発、海外展開 |
| 県土整備の設計・積算・監督 | 発注者支援、施工管理 |
| 市町村への助言・支援 | パートナー支援、カスタマーサクセス |
| 議会対応、条例・規則の改正 | 渉外、法務、規程整備 |

部署ごとの詳しい対応は[自治体の部署別 仕事ガイド](../zukan.html)にまとめています。財政課であれば[財政課の経験は民間で何と呼ばれるか](dept-zaisei-honyaku.html)で、さらに細かく分解しています。

## 群馬で、どの経験が値になるか

**1. 工業団地と用地開発**

群馬県は内陸型の工業団地の集積が進んだ県で、県庁には造成と分譲の実務があります。**用地の取得、地権者との交渉、造成の発注、進出企業への対応、インフラの手当て。**

これは民間の**不動産開発・用地開発とまったく同じ構造**です。デベロッパー、物流施設の開発事業者、そして進出する企業そのものから見て、この一連を通した経験は希少です。書くときは団地名ではなく、**面積、地権者の数、交渉にかかった期間、想定外の事態をどう処理したか**で書いてください。

**2. 物流と交通の結節点**

高速交通網の結節点にある県として、県庁には道路と物流に関わる実務があります。**用地、環境影響、地元調整、他の管理者との協議。**物流施設の開発が全国で進むなか、立地に伴う行政手続きを知っている人は、事業者側にほとんどいません。

**3. ものづくりの県での企業支援**

自動車、輸送用機器、食品。県庁の企業支援と誘致の実務は、進出する企業から見れば、自分たちが最も苦労する部分です。補助制度の設計、人材確保の支援、取引先とのマッチング。**企業側が自力ではたどり着けない情報を、行政の立場で扱ってきた**ことになります。

**4. 観光の受入環境と地域ブランディング**

温泉地を抱える県として、観光の受入環境整備、地域資源の売り込み、事業者との連携の実務があります。**行政の立場で観光の座組みを作った経験**は、観光関連の事業者や地域商社から見て希少です。

**5. 市町村を相手にしてきた経験**

規模も体制もばらばらな市町村を相手に、温度差をどう埋めたか。「連絡調整」ではなく、**複数顧客を持つアカウント業務の経験**として書けば、そのまま職務能力になります。小規模町村を相手にしてきた経験はとくに値がつきます。担当が1人で何役も兼ねている、専任の技術職がいない。**こうした事情は、売る側からはほとんど見えません。**

## 首都圏の求人も、視野に入れてよい

群馬県は新幹線と高速道路で首都圏とつながっており、**転居せずに都内の求人に応募できる**位置にあります。

ここで多いのが、通勤時間だけで線引きしてしまう判断です。近年はリモート可、週数日出社といった勤務形態の求人が増えています。とくに自治体を顧客にする企業は、担当エリアに出向くことが仕事なので、本社への出社頻度が低い場合があります。

**募集要項の「勤務地」欄だけでなく、勤務形態の記載まで確認してください。**順序としては、**まず職種で絞り、そのあとに勤務形態を確認する。**勤務地から検索すると、県内では出会えない職種が最初から視界に入りません。

## 職務経歴書に、県庁の仕事をどう落とすか

**制度名ではなく、判断したことを書く**

「○○推進事業を担当」では読み手に何も残りません。事業名は庁内でしか意味を持たない固有名詞です。**何件を、どういう基準で審査し、どこで判断が割れて、どう決着させたか。**

**本庁と出先機関を書き分ける**

本庁は制度の設計と全県調整、出先は現場対応と個別案件の処理と、職務の性質がまったく違います。**どちらをどれだけ経験したかを書き分ける**と、読み手が配属をイメージできます。

**異動歴を「立ち上げの回数」に変える**

数年ごとの異動を「専門性がない」と書くのは、自分から評価を下げる書き方です。異なる制度領域を短期間で立ち上げてきた経験は、民間では**キャッチアップの速さ**として読まれます。編年式で並べ、それぞれの配属で最初の数か月に何を習得したかを1行添えてください。

## 技術職の場合は、探し方が変わる

**発注者側の経験そのものが職種になる**

「発注者支援」という職種が、建設コンサルタント業界には確立しています。設計の審査、積算の確認、工事の監督、住民説明。県庁でやってきたことが、そのまま職務内容として書かれた求人です。

**資格が入口で効く**

技術士、施工管理技士、測量士、電気主任技術者。事務職では資格より実績が先ですが、技術職では資格が応募の入口になる場面があります。**実務経験の年数が受験要件になっているものは、在職中でなければ積めません。**

**造成と用地の実務は、民間の開発でそのまま使える**

工業団地の造成に関わった技術職は、物流施設や産業用地の開発事業者から見て即戦力です。**土地利用の規制、造成の設計、インフラの引き込み、近隣対応。**同じ手順を民間側でも踏みます。

## 面接で必ず詰められる2つのこと

**「意思決定のスピードに耐えられるか」**

行政は手続きの段数が多く、決裁を経て動きます。民間は月次で数字を締め、その場で方針を変えます。稟議の段数を弁解せず、**自分の判断で動かした範囲を具体的に答えてください。**

**「数字への意識があるか」**

「利益を意識したことはありますか」という形で聞かれます。「行政なので利益はありません」と答えると、そこで話が終わります。事業の優先順位を付けた、単価の根拠を詰めた、複数案を比べた。**同じ思考をしていたことを、民間の言葉で説明できるか**が見られています。

## 在職中に進めるときの注意点

**服務上の扱いを先に確かめる**

在職中に得た情報を持ち出すことは避けなければなりませんし、退職後の営業活動についても扱いを確認しておいたほうが安全です。**判断に迷う場合は、応募の前に人事担当課に制度上の取扱いを確認してください。**

**面接の日程は、議会日程から逆算する**

地方自治法第211条は、長が毎会計年度予算を調製し、年度開始前に議会の議決を経なければならないと定めています。都道府県は年度開始前30日までに予算を議会へ提出するようにしなければならない、とも書かれています。決算は、出納閉鎖後3か月以内の長への提出、監査委員の審査、議会の認定という順です（第233条）。**予算編成の山と定例会の会期中は、平日日中の面接を入れるのが難しくなります。**

**在職中に決める**

公務員には雇用保険が適用されないため、辞めてから探すと収入のない期間がそのまま持ち出しになります（[公務員に雇用保険がない理由](seido-shitsugyo-nashi.html)）。

:::insight
ここまで転職の話を書いてきましたが、**残る判断にも理があります。**とくに用地や造成のように、着手から完了まで年単位かかる案件を担当している場合、途中で抜けると着手したところまでしか書けません。**通しで一巡させてから動くほうが、書けることは確実に厚くなります。**首都圏に近い群馬県は、地方県庁のように「動くなら転居を伴う」という制約がないぶん、機が熟すまで待っても選択肢はそれほど減りません。異動の希望が通る見込みがあるなら、まずそちらを試すのも合理的です。ただし、自分の経験が外でどう呼ばれるかを知っておくことには、動かない場合でも意味があります。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 群馬県の一般行政職は**ラスパイレス指数100.0、平均給与月額399,771円**（令和6年4月1日現在・総務省調査）
- **地域手当は国の指定基準2.5%どおり**。北関東で基準を上回っているのは茨城県と栃木県で、群馬県は基準どおりです
- 上乗せがないぶん**額面が読みやすい**構造です。源泉徴収票の支払金額と求人票の想定年収で比べてください
- 経験が効く方向は、**工業団地と用地開発／物流と交通／ものづくりの企業支援／観光／市町村を相手にした経験**の5つです
- 用地・造成の経験は**団地名ではなく、面積・地権者の数・期間・想定外の処理**で書いてください
- **勤務地から検索しない。**職種で絞ってから勤務形態を確認する順序に変えてください

## よくある質問

### 工業団地や用地の経験は、民間のどこで評価されますか

**不動産開発、物流施設の開発事業者、建設コンサルタント、そして進出する企業の用地担当**です。共通しているのは、いずれも「地権者との交渉と行政手続きを通さないと事業が進まない」領域だという点です。用地取得は民間側でも最も難しい工程で、経験者が慢性的に不足しています。行政の立場で通した経験は、そのまま読まれます。

### 地域手当が基準どおりだと、他県より不利ですか

**自治体間の比較としては、額面が低く出る要因にはなります。**ただし転職の判断材料としては別の話です。民間の給与体系に地域手当という区分はなく、勤務地の相場は基本給や各種手当に織り込まれています。**現在の源泉徴収票の支払金額**を基準にして、求人票の想定年収と比べてください。上乗せがないぶん、比較そのものはしやすいはずです。

### 40代からでも転職できますか

年代よりも、説明できる実績があるかどうかです。群馬県の一般行政職の平均年齢は42.8歳ですから、同年代の相談は多くあります。40代の場合、若手と同じ土俵で伸びしろを売るのではなく、**特定の制度領域や大型案件を通しで回した経験**を軸にすると噛み合います。用地の取得を完了まで見届けた、工業団地の分譲を軌道に乗せた。年数がなければ積めない経験のほうが、この年代では強い材料になります。
