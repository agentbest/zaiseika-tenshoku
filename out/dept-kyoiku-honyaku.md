教育委員会事務局からの転職で、いちばん困るのは**「担当していた範囲が広すぎて、説明できない」**ことです。

学校の施設、教職員の配置、就学の事務、教科書、給食、端末の整備、社会教育、文化財。

**「教育委員会にいました」と言っても、何をしていたかが伝わりません。**

ところが、**この幅の広さには、法律上の理由があります。**そして、**幅を説明できる形に直すと、民間での見え方が変わります。**

この記事では、その対応を整理します。訳語の対応表、中核スキルの工程分解、そして**民間の多拠点の本部とどこが同じでどこが違うか**まで扱います。

## 職務権限が、条文に列挙されています

まず、この幅の広さがどこから来ているかを条文で確認します。

地方教育行政の組織及び運営に関する法律第21条は、教育委員会が管理し、執行する事務を**列挙**しています。

**教育委員会は、当該地方公共団体が処理する教育に関する事務で、次に掲げるものを管理し、及び執行する。**

そして、**学校その他の教育機関の設置、管理及び廃止**から始まり、**職員の任免その他の人事、児童生徒の就学、教育課程、教科書その他の教材の取扱い、校舎その他の施設及び設備の整備、教育関係職員の研修、学校給食、社会教育**など、**多数の事務が並びます。**

**つまり、幅が広いのは、法律がそう定めているからです。**

そして、**この列挙が意味するのは、「学校という拠点を成り立たせるために必要なものが、全部この一覧に入っている」**ということです。

**建物、人、教材、給食、研修、そして学校の外の教育まで。**

**民間でいえば、多拠点を持つ事業の本部**です。

- **拠点の設置と統廃合**
- **人の配置**
- **設備と教材の調達**
- **標準の展開と、実施状況の確認**
- **拠点からの相談への対応**

**本部が担う機能が、そのまま並んでいます。**

**面接では、この構造を一度言ってください。**

> 学校という拠点を成り立たせるために必要なものを、**本部として一通り扱っていました。**施設、人の配置、教材、給食、研修。**民間でいう多拠点の本部の機能とほぼ同じ範囲です。**

**「幅が広い」ではなく「本部の機能を一通り」**と言い換える。**これだけで、伝わり方が変わります。**

## 民間での訳語

履歴書や職務経歴書では、**自治体の中でしか通じない言葉を、募集要項に出てくる言葉に置き換えます。**

| 自治体での呼び方 | 民間での呼ばれ方 |
|---|---|
| 学校の設置・統廃合 | 拠点の設置と再編 |
| 学校施設の整備・長寿命化計画 | 施設の資産管理、中長期の保全計画 |
| 教職員の配置に関する事務 | 要員の配置調整 |
| 就学の事務（学区、指定校の変更） | 割当ての設計、対象の管理 |
| 就学援助の認定・支給 | 給付の認定と支払 |
| 教育課程に関する指導・助言 | 標準の展開と実施状況の確認 |
| 教科書の採択に関する事務 | 選定の委員会の事務局 |
| 学校給食の運営 | 給食の運営、食品衛生の管理 |
| 学校の情報環境の整備 | 端末とネットワークの調達・運用 |
| 教職員の研修 | 教育設計、人材育成の企画 |
| 教育委員会の会議の運営 | 合議体の事務局 |
| 学校からの相談への対応 | 拠点からの照会対応、現場支援 |

**「教育委員会にいました」ではなく、「多拠点の本部で、施設・要員・調達・標準の展開を担当していました」**と置き換えるのが基本です。

## 中核スキルを5つの工程に分ける

この部署の仕事は、**5つの工程**に分解できます。**多拠点の本部の工程と、ほぼ同じ形**です。

**① 基準を渡す**

国が定めた基準や方針を、**学校が実際に使える形に直して渡します。**

通知をそのまま流しても、現場は動きません。**何を、いつまでに、どうするのか。**そこまで整理して初めて、実施されます。

**② 人と物を配る**

教職員の配置、施設の整備、教材、端末、給食。

**限られた予算と人員を、複数の拠点にどう配るか**という配分の設計です。**全部の学校に同じだけ配ることはできません。**

**そして、この工程には期日が二重にかかります。**学校には**年度の暦**があり、入学、行事、長期の休業が固定されています。**工事は長期の休業中にしかできず、教材は年度の初めに間に合わせる必要があります。**つまり、**予算の年度と、学校の暦の両方に合わせて配る**ことになります。**「二つの暦に合わせて配分する」**という制約は、**繁閑がはっきりした拠点を持つ事業でも同じ**です。

**③ 動かす**

就学の事務、行事、会議、給食の運営。**日程が決まっていて、動かせないものが多い**工程です。

**④ 見る**

学校の状況を把握し、**実施されているかを確認します。**

報告を受ける、訪問する、点検と評価を行う。**「渡した基準が、実際に使われているか」**を見る工程です。

**⑤ 直す・作る**

統廃合の検討、施設の整備計画、制度の見直し。

**児童生徒の数が変われば、拠点の配置も変わります。**この判断を、**数年から数十年の単位**で考えます。

## 民間の多拠点の本部と、どこが同じでどこが違うか

**同じところ**

**1. 標準を作って展開し、実施状況を確認する**

**本部が標準を作り、拠点が実施し、本部が確認する。**この流れは、**チェーンの本部でもまったく同じ**です。

**2. 限られた資源を、拠点に配分する**

**人も物も予算も有限**です。どの拠点に、どれだけ配るか。**この配分の設計は、多拠点の本部の中心的な仕事**です。

**3. 拠点からの相談を受ける**

**現場で起きたことが、本部に上がってきます。**判断が必要なもの、他の拠点にも関係するもの、制度の見直しにつながるもの。**仕分けて処理する**という工程が共通します。

**違うところ**

**1. 拠点に、独立した責任者がいる**

学校には**校長**がいて、**学校の管理と所属職員の監督**を担います。**本部の指示が、そのまま現場の作業になるわけではありません。**

**この「指揮命令が単純でない相手を動かす」という経験**は、**フランチャイズの本部や、独立性の高い拠点を持つ事業**で、そのまま必要になります。

**2. 人事の権限が、単純でない**

市町村立の学校の教職員は、**都道府県が給与を負担し、任命する**という仕組みがあります。**市町村の教育委員会は、その配置について意見を述べる立場**です。

**「自分たちで決められない人事を、調整で動かしてきた」**という経験になります。

**3. 意思決定が合議体で行われる**

教育委員会は**合議制の機関**です。事務局が案を作り、**会議で決まります。**

**「合議体に諮って決める」**という工程を持っている点は、**取締役会や委員会を持つ企業の本部**と同じ構造です。

:::insight
教育委員会事務局の方が職務経歴書で損をしやすいのは、**担当した事務を時系列で全部並べてしまうこと**です。施設、就学、教職員、教科書、給食、社会教育。**幅が広いぶん、並べると6つも7つも項目ができ、どれも浅く見えます。**実際には、**それぞれが本部の機能の一つ**なのですが、**並べただけでは「雑多な事務をしていた人」**になります。書き方としては、**機能で束ねてください。**「施設と資産の管理（学校◯校、延べ床面積約◯万平方メートル）」「要員の配置調整（教職員◯人規模）」「調達と標準の展開（端末◯台、教材の選定）」「拠点の運営支援（◯校からの照会対応）」。**この4つに束ねると、多拠点の本部の経歴として一気に読めるようになります。**そして、**それぞれに規模の数字を添える。**学校数、児童生徒数、教職員数、延べ床面積。**幅は、束ねて規模を添えて初めて強みになります。**
:::

## 評価が高くなりやすい4つの方向

**1. 多拠点を持つ事業の本部**

小売、飲食、サービス、教育、介護。**拠点が多く、本部が標準を作って展開する事業**であれば、**工程がそのまま移せます。**

**とくに、独立性の高い拠点を持つ事業**——フランチャイズ、業務委託の拠点、専門職が責任者を務める拠点——では、**「指揮命令が単純でない相手を動かしてきた」経験**が直接効きます。

**書くときは、所管していた拠点の数を必ず入れてください。**

**2. 教育産業（学習塾・教材・教育サービス）の本部**

**教育課程の基準、教材の選定、研修の設計。**この3つは、教育産業の本部が扱っているものと直接重なります。

**学校がどういう基準で動いているかを知っている**ことは、**学校を顧客にする事業では前提の知識**になります。

**3. 自治体を顧客にする企業（校務支援・学習の情報基盤）**

校務支援のシステム、学習の情報基盤、端末の導入と運用、教材のサービス。

**発注する側にいた経験**に加えて、**学校の実務を知っていること**が提案の材料になります。**この領域は、学校の実態を知る人材を強く求めています。**

[公務員の経験が活きる求人を見てみる](../?gov=1)

**4. 施設・資産の管理**

**学校施設の整備と、長寿命化の計画**に関わっていた方は、この方向が開きます。

**自治体が持つ施設のうち、学校は延べ床面積で大きな割合**を占めます。**その整備計画を扱ってきた**というのは、**企業の資産管理や、拠点の再編の部署**でそのまま通用する経験です。

:::insight
方向を決めるときに、**残る判断のほうが妥当だと感じる場面**もあります。教育委員会事務局は、**担当している係によって、書ける内容がまったく変わる**部署です。総務・施設なのか、学務（就学）なのか、指導（教育課程）なのか、社会教育なのか。**このうち、民間でいちばん値が付くのが施設と、調達・情報環境の整備**です。どちらも**規模の数字が出しやすく、民間に同じ職種がある**ためです。**一方、指導や社会教育は、民間での対応先が限られます。**まだ一つの係しか経験していない段階なら、**もう一つの係を経てからのほうが、束ねて書ける機能が増えます。**もう一つ、**学校施設の長寿命化計画や、統廃合の検討**は、**数年に一度しか回らない**ので、**在籍のタイミングで経験できるかが決まります。**関われる見込みがあるなら、それを経てからという判断もあります。在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## つまずきやすい点

**1. 担当した事務を時系列で並べる**

**機能で束ねてください。**施設と資産／要員の配置／調達と標準の展開／拠点の運営支援の4つです。

**2. 「幅が広い」で終える**

**「本部の機能を一通り」**と言い換えてください。

**3. 規模の数字を書かない**

**学校数、児童生徒数、教職員数、延べ床面積、端末の台数。**公表されている資料から取れます。

**4. 「指揮命令が単純でない」経験を書かない**

**フランチャイズや、専門職が責任者を務める拠点を持つ事業**で、直接効きます。

**5. 個別の事案に触れる**

**児童生徒や保護者に関すること、学校や教職員の個別の状況、いじめや事故に関する情報。**すべて書けません。工程と規模で書いてください。

どの経験に値が付くかは、募集の出方で変わります。[どの経験に値が付くのかから相談できます](../apply.html)。

## まとめ

- 地方教育行政法第21条は、教育委員会が管理・執行する事務を**列挙**しています。**幅が広いのは、法律がそう定めているから**です
- 列挙されているのは、**学校という拠点を成り立たせるために必要なもの全部**——つまり**多拠点の本部の機能**です
- 民間での訳語は、**拠点の設置と再編／施設の資産管理／要員の配置調整／標準の展開と実施状況の確認／調達**が中心になります
- 中核スキルは**①基準を渡す ②人と物を配る ③動かす ④見る ⑤直す・作る**の5工程です
- 民間の多拠点の本部と**同じ**なのは、標準を展開して確認すること・限られた資源を配分すること・拠点からの相談を受けること
- **違う**のは、拠点に独立した責任者がいること・人事の権限が単純でないこと・意思決定が合議体で行われることです

## よくある質問

### 教員の資格がないと、教育関係の仕事には就けませんか

**事務や本部の職種では、資格が前提にならないことが多くあります。**教育産業でも、**教材の企画、教室の運営管理、学校への提案、システムの導入**といった職種は、**教える資格とは別の能力**が求められます。面接では、**「授業をする側ではなく、学校が成り立つように施設・人・教材を整える側でした」**と正確に言ってください。**役割の線をはっきりさせるほうが読まれ方がよくなります。**

### 指導主事の方（教員出身）と、事務職では書き方が違いますか

**違います。**教員出身の方は、**授業と学校の運営の経験**が軸になり、**教育産業の教材や研修の方向で強くなります。**一方、**事務職の方は、施設・調達・配分・契約**が軸で、**多拠点の本部や、施設の資産管理の方向で強くなります。**どちらが上ということではなく、**軸が違う**ので、**自分がどちらの軸にいるかを先に決めてから書く**と、書類がぶれません。

### 社会教育（公民館・図書館）を担当していた場合は

**「施設の運営と、講座の企画・委託管理」**として書けます。利用者数、施設数、年間の講座数、委託の件数。**民間でいう施設運営や、イベントの企画運営に近い工程**です。なお、地方教育行政法第23条は、**条例の定めにより、図書館・博物館・公民館などの事務を長が管理・執行することができる**としています。**団体によって所管が違う**ので、書類では**「教育委員会の所管として担当」**か**「長の所管として担当」**かを正確に書いてください。
