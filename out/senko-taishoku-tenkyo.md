**転居をともなう転職では、確認する項目が増えます。**

**勤務地が変わるだけでなく、生活の基盤が動く**ためです。

この記事では、**確認すべき労働条件**と、**単身赴任を検討するときの整理**を扱います。

## 就業の場所は、契約の内容です

**労働基準法第15条**です。

> 使用者は、**労働契約の締結に際し**、労働者に対して**賃金、労働時間その他の労働条件を明示しなければならない。**この場合において、賃金及び労働時間に関する事項その他の厚生労働省令で定める事項については、厚生労働省令で定める方法により明示しなければならない。
>
> ２ 前項の規定によつて**明示された労働条件が事実と相違する場合**においては、労働者は、**即時に労働契約を解除することができる。**
>
> ３ 前項の場合、**就業のために住居を変更した労働者**が、契約解除の日から十四日以内に帰郷する場合においては、使用者は、**必要な旅費を負担しなければならない。**

**第3項が、転居をともなう場合を想定した規定**です。

**「就業のために住居を変更した労働者」**という文言が置かれています。

**法律が、転居をともなう就業を前提に、条件の相違への手当てを置いている**ということです。

**裏を返せば、明示の内容を確認しておくことが重要**だという意味でもあります。

## 公務員の異動との違い

| | 公務員の異動 | 転職にともなう転居 |
|---|---|---|
| 根拠 | 任命権者の発令 | **労働契約** |
| 勤務地 | 発令で決まる | **契約の内容として明示される** |
| 費用 | 条例・規程による | **会社の規程による** |
| 範囲 | 団体の区域が中心 | 会社の定めによる |

**2行目が最大の違い**です。

**勤務地が契約の内容になる**ため、**契約の前に確認できます。**

**発令を待つのではなく、条件として聞く**という進め方になります。

## 確認する項目

| 項目 | 確認すること |
|---|---|
| ① 就業の場所 | **具体的な所在地**（本社の住所ではない場合があります） |
| ② 転勤の有無 | **今後の異動の可能性と範囲** |
| ③ 赴任にかかる費用 | 引越し費用の負担の有無と範囲 |
| ④ 住居に関する制度 | 社宅、借上げ、手当の有無 |
| ⑤ 着任の時期 | いつから勤務するか |
| ⑥ 家族の帯同 | 前提となっているか |

**①を求人票の段階で確認**してください。

**求人票の勤務地が「本社」と書かれていても、配属先が別**であることがあります。

**②が見落とされやすい**です。

**入社時の勤務地が希望どおりでも、その後の異動の範囲が広い**ことがあります。

**「転勤の可能性の有無」と「ある場合の範囲」**を、**内定の前に確認**してください。

## ③——費用の扱い

| 確認すること | 内容 |
|---|---|
| 引越し費用 | 負担の有無、上限、対象の範囲 |
| 赴任にかかる旅費 | 本人分、家族分 |
| 一時金 | 制度の有無 |
| 支給の時期 | 立替えか、前払いか |
| 手続き | 見積りの提出、業者の指定 |

**4つ目を確認してください。**

**立替えの場合、まとまった額を先に用意する必要があります。**

**支給が入社後になることもあります。**

**資金の計画に影響する**ため、時期まで確認してください。

**なお、退職手当の支給の時期も併せて確認**してください。扱いは[退職手当はいつ振り込まれるか](senko-taishoku-shikyubi.html)に整理しています。

:::insight
転居をともなう転職で、**面談でお聞きしているのが「配属先の住所を確認しましたか」**という点です。求人票の勤務地の欄は、**本社や事業所の名称だけ**で書かれていることがあります。ところが、**実際の配属先が別の場所**であったり、**顧客先での勤務**であったりする場合があります。行政が相手の事業では、**役所の庁舎内に常駐する形**の職場もあります。**通勤の時間は、住所が分からないと計算できません。**そして、**住まいを決める時期にも関わります。**入社前に住まいを決める必要がある場合、**住所が分からないと物件を絞れません。**ですから、**内定の前後で、配属先の所在地を確認**してください。聞き方は「配属予定先の所在地を教えていただけますか。通勤と住まいの検討のためです」で足ります。**理由を添えると、答えが得られやすくなります。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 単身赴任を検討する場合

| 項目 | 整理すること |
|---|---|
| 期間の見込み | 何年を想定するか |
| 費用 | 二重の住居費、帰省の費用 |
| 家族の分担 | 家事、育児、介護 |
| 帰省の頻度 | 現実に可能な回数 |
| 会社の制度 | 手当、帰省の費用の扱い |

**2つ目が大きい**です。

**住居が二つになると、支出の構成が変わります。**

**手取りの変化と併せて、支出まで並べて判断**してください。

**3つ目について。**

**同居していたときに分担していたことが、片方に寄ります。**

**この点は、家族と先に話してください。**伝え方は[家族への伝え方と、反対されたときの整理](senko-taishoku-kazoku.html)に整理しています。

## 転居の段取り

| 順 | やること |
|---|---|
| 1 | 配属先の所在地を確認 |
| 2 | 住まいの範囲を決める |
| 3 | 家族の予定を確認（学校、保育、通院） |
| 4 | 退職の時期と入社の時期を決める |
| 5 | 引越しの時期を決める |
| 6 | 各種の手続き |

**3を早めに**してください。

**学校の転校、保育の手続きは、時期が決まっています。**

**入社の時期と合わない**ことがあります。

**4について。**

**退職の日と入社の日の間に、引越しの期間を確保できるか**を確認してください。

**続けて入社すると、引越しの時間が取れない**ことがあります。

[経験の言い換えから相談する](../apply.html)こともできます。

## 住宅の借入がある場合

| 確認すること | 内容 |
|---|---|
| 転居後の扱い | 契約の内容を確認 |
| 賃貸に出す場合 | 金融機関への確認が必要な場合があります |
| 返済の口座 | 変更の要否 |

**2つ目は、確認が必要です。**

**居住を前提とした借入の場合、転居後の扱いについて定めがあることがあります。**

**扱いは**[住宅ローンがある状態での転職](senko-taishoku-loan.html)**に整理しています。**

## 手続きの一覧

| 手続き | 窓口 |
|---|---|
| 転出・転入の届出 | 市区町村 |
| 国民健康保険・共済の切替え | 共済組合・転職先・市区町村 |
| 年金の手続き | 年金事務所・転職先 |
| 住民税の扱い | 市区町村 |
| 運転免許の住所の変更 | 警察署 |
| 学校・保育の手続き | 転居先の市区町村 |

**4つ目です。**

**住民税は、その年の1月1日に住んでいた市区町村が課税する仕組み**です。

**年の途中で転居しても、その年の扱いは変わりません。**

**転居先の市区町村から通知が来るとは限らない**ため、**扱いを確認**してください。

## よくある失敗

**1. 配属先の所在地を確認しない**

**通勤の時間が計算できません。**

**2. 転勤の可能性を確認しない**

**入社後に範囲が分かります。**

**3. 費用の支給の時期を確認しない**

**立替えが必要な場合があります。**

**4. 学校・保育の手続きの時期を見ない**

**入社の時期と合わないことがあります。**

**5. 引越しの期間を確保しない**

**退職と入社が続くと時間が取れません。**

**6. 単身赴任の費用を収入だけで判断する**

**支出の変化を並べてください。**

**7. 明示された条件を書面で確認しない**

**後から確認できません。**

:::insight
ここまで確認の話をしておいて逆のことを言いますが、**転居をともなう求人を、最初から候補から外さないでください。**面談で拝見していると、**「転居はできないので」と、勤務地で候補を絞りきってしまう方**がいらっしゃいます。ところが、**条件を確認してみると、在宅勤務と組み合わせることで通える**場合や、**将来的に希望する地域への配属が可能**な場合があります。また、**行政が相手の事業は、各地に拠点がある**ことが多く、**同じ会社の別の拠点で募集が出る**こともあります。ですから、**「転居できない」という条件は、会社を外す理由ではなく、勤務地を相談する材料**として使ってください。伝え方は「転居が難しい事情があります。◯◯の範囲で勤務できる拠点はありますか」です。**相談してみて初めて、候補が残ることがあります。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **労働基準法第15条**は、**労働契約の締結に際して労働条件を明示すること**、**事実と相違する場合は即時に契約を解除できること**、**その場合の帰郷の旅費を使用者が負担すること**を定めています
- **勤務地は契約の内容**です。発令を待つのではなく、**契約の前に確認**できます
- **配属先の具体的な所在地**と、**転勤の可能性と範囲**を、内定の前に確認してください
- **費用は、負担の範囲だけでなく支給の時期**まで確認してください
- 単身赴任は、**収入だけでなく支出の変化**を並べて判断してください
- **学校・保育の手続きの時期**と、**引越しの期間**を先に確保してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 転勤の可能性は、どう聞けばよいですか

**条件の確認として聞いて差し支えありません。**聞き方は、「入社後の異動の可能性について教えてください。範囲はどの程度でしょうか」です。**「転勤はしたくありません」から入ると、条件の交渉に見えます。**まず、**制度としてどうなっているかを聞く。**そのうえで、**自分の事情を伝える**という順序です。なお、**求人票に「転勤なし」と書かれていても、範囲の定めを確認**してください。事業所の統廃合などで、**将来的に勤務地が変わる可能性**はあります。**書面で明示された内容を、入社前に確認**しておいてください。

### 内定の後に、勤務地が違うと分かりました

**まず、明示された内容を確認**してください。**書面で示された就業の場所と、実際の配属先が違う場合、その点を相手に確認**します。**行き違いである場合もあります。**そのうえで、**条件が合わなければ、辞退することもできます。**労働基準法第15条第2項は、**明示された労働条件が事実と相違する場合に、労働者が即時に労働契約を解除できる**と定めています。**入社後であっても、規定が置かれている**ということです。ただし、**入社前に気づいて確認するほうが、負担は小さい**です。**書面で確認する習慣を持ってください。**

### 単身赴任と、家族での転居のどちらがよいでしょうか

**比べる項目を揃えてください。**費用（住居費、帰省の費用、通勤の費用）、時間（通勤、帰省）、家族の予定（学校、仕事、介護）、期間の見込み。**この4つを並べます。**そのうえで、**期間の見込みが立つかどうか**が分かれ目になることが多いです。**数年で戻る見込みがあるなら単身赴任、長く続く見込みなら転居**という整理が一般的です。ただし、**見込みが立たない場合もあります。**その場合は、**一定の期間で見直す前提**にしておく方法があります。なお、**この判断は自分だけで決められません。**家族と条件を並べて話してください。
