環境課の経験は、求人票の言葉に直すと**まったく別の名前**で呼ばれています。

**「廃棄物の処理、環境保全に関する業務」**

**この書き方では、民間の採用担当には何も伝わりません。**

実際にやっていたのは、**1日も止められない処理のオペレーションを、委託先を使って回しながら、同時に規制する側にも立つ**という仕事です。

**この2つを同時に持っている職種は、民間にはあまりありません。**

この記事では、**庁内の呼び名を民間の言葉に置き換え、中核スキルを5つの工程に分けて**整理します。

## 「支障が生じないうちに」——止められない仕事です

最初に、この仕事の性格を条文で押さえます。**経験の値を決める部分**です。

廃棄物の処理及び清掃に関する法律第6条の2第1項は、こう定めています。

**市町村は、一般廃棄物処理計画に従つて、その区域内における一般廃棄物を生活環境の保全上支障が生じないうちに収集し、これを運搬し、及び処分……しなければならない。**

**「支障が生じないうちに」。**

**そして、「しなければならない」。**

**ここが要点です。**

**市町村には、ごみを集める義務があります。**しかも、**「支障が生じないうちに」——つまり、遅れてはいけません。**

**予算がないから今月は集めない、という選択がありません。**

**これは、民間でいえば、止められないオペレーションです。**

電気、水道、通信、物流。**「今日は休みます」が許されない事業**と、同じ構造にあります。

**そして、もう一つ重要な点があります。**

**排出される量を、こちらでは決められません。**住民が出す量は、住民が決めます。**それを、決まった体制で、毎日受け止めます。**

**需要を選べないまま、供給の体制だけで対応する。**

**これは、民間のオペレーションの仕事で、いちばん難しい部分です。**

## 民間での訳語

| 庁内での呼び名 | 民間での呼ばれ方 |
|---|---|
| 収集運搬の委託 | **配送・回収のオペレーション管理／委託先の管理** |
| 処理施設の管理 | **プラントの運転管理・設備の保全** |
| 最終処分場の管理 | **処分場の運営・埋立の進行管理** |
| 一般廃棄物処理計画 | **中期の事業計画・需要予測** |
| 資源化・減量の施策 | **リサイクルの企画・回収率の改善** |
| 分別の啓発 | **利用者向けの行動変容の設計** |
| 不法投棄の対応 | **不正利用の調査・現場の対応** |
| 公害の苦情対応 | **クレーム対応・原因の調査** |
| 騒音・振動・水質の測定 | **環境測定・データの管理** |
| 地球温暖化対策の実行計画 | **排出量の算定・削減計画の策定** |
| 環境影響評価に関する事務 | **アセスメントの手続の管理** |
| 環境基本計画の策定 | **中期計画の立案・指標の設計** |

**上から3行目までが、いちばん値の付く並び**です。**止められない業務を、委託先を使って回してきた**——**これは、オペレーションの管理そのものです。**

## 中核スキルを5つの工程に分ける

**この部署の中核は、「止められない処理を、他人の手を借りて回しながら、同時に規制もかけること」**です。

**工程1：回す（収集・運搬・処分の日々の運用）**

収集の区域と曜日の設計、車両と人員の配置、施設への搬入の管理、休日と年末年始の体制。

**この工程に固有の制約があります。****1日でも止まると、生活に直結します。**そして、**祝日と年末年始が、いちばん出る時期**です。**出す量が増える日に、働ける人が減る。**この逆転を、**毎年、先に設計しておく必要があります。**

**民間の物流や回収の事業でも、まったく同じ問題が起きます。**

**工程2：任せる（委託と施設の管理）**

収集運搬の委託、施設の運転の委託、処理の契約、監督と検査。

**この工程に固有の制約があります。****委託先の人手と車両に上限があります。**そして、**単価は入札で決まりますが、安すぎると事業者が続きません。**人が集まらず、車両も更新できなくなるからです。

**つまり、「安く買う」ことが目的にならない**——**ここは、民間の調達とは考え方が違います。**ただし、**「続けられる価格でなければ、供給が止まる」という感覚**は、**近年は民間の調達でも同じように言われています。**

**工程3：減らす（資源化と減量）**

分別の区分の設計、資源化の推進、生ごみの減量、啓発。

**この工程に固有の制約があります。****住民の行動に依存します。**そして、**分別を強制できません。**罰則で動かせる仕組みではないため、**分かりやすさと、続けやすさで設計するしかありません。**

**これは、民間でいう利用者の行動の設計**です。**説明の仕方、表示の作り方、容器の形。**この積み重ねで、**回収率が数ポイント動きます。**

**工程4：止める（規制・苦情・不法投棄）**

騒音、振動、悪臭、水質、大気。苦情の受付、現地の確認、測定、指導。

**この工程に固有の制約があります。****証拠がないと動けません。**苦情が来ても、**測定して基準を超えていなければ、規制の根拠がありません。**しかも、**騒音も悪臭も、夜間や休日に発生します。**

**だから、「いつ、どこで、どう測るか」を設計する**ことが実務の中心になります。

**この経験は、民間の品質管理や、設備の不具合の調査と同じ形**をしています。

**工程5：測る（計画と数値の目標）**

環境基本計画、地球温暖化対策の実行計画、排出量の算定、進捗の管理。

**この工程に固有の制約があります。****排出量は、市の努力だけでは動きません。**景気、人口、産業の構造、電力の排出係数。**自分では動かせない要因のほうが大きい**という状態で、**それでも目標を立て、進捗を説明する**必要があります。

**この「自分では動かせない要因が大きい指標を、説明し続ける」という経験**は、**企業のサステナビリティの部門で、そのまま同じことをします。**

:::insight
この経歴でいちばん多い損は、**「ごみの担当でした」と書いてしまう**ことです。この一言だと、**窓口で苦情を受けていた人**に読まれます。実際には、**数万世帯から毎日出るものを、決まった体制で、遅れずに受け止め続けてきた**わけです。書くなら、**「人口◯万人・約◯万世帯を対象に、収集運搬の委託◯件（車両◯台）と処理施設の運転を管理し、年間約◯トンの処理を担当」**という形です。**世帯数、車両の台数、年間の処理量。**この3つが並ぶと、**オペレーションの規模**が一発で伝わります。面談で確認すると、**この数字は全部、公表されている資料か、事業の概要に載っています。**ところが、**書類に書いている方はほとんどいません。****「毎日のことなので、実績だと思っていなかった」**とおっしゃいます。**しかし、止まらない業務を回してきたことは、それ自体が実績です。**物流、設備、インフラの分野では、**「止めなかった」ことが、いちばん評価される**のですから。
:::

## 民間の処理・回収のオペレーションと、どこが同じでどこが違うか

**同じところ**

1. **止められない。**1日の遅れが、そのまま影響として出ます
2. **委託先の容量が制約になる。**人と車両がなければ、計画だけでは回りません
3. **需要を自分で決められない。**出る量は、こちらでは選べません

**違うところ**

1. **利用者を選べない。**払っていない人も、分別しない人も、対象から外せません
2. **単価を上げられない。**手数料は条例で決まっていて、事業の都合では動かせません
3. **「やめてもらう」ことができない。**民間なら断れる相手でも、断れません
4. **苦情が、直接、個人に来る。**間にサポートの部署が入らないことが多くあります

**1番目が、いちばん大きい違い**です。

民間のサービスは、**利用者を選び、条件に合わない相手とは契約しません。**この仕事では、**区域内のすべてが対象です。**

**この前提で回してきた**ということは、**例外の多い環境で運用を設計できる**ということでもあります。

## 評価が高くなりやすい4つの方向

**1. 廃棄物処理・リサイクルの企業**

**発注する側にいた経験**が、そのまま効きます。**自治体が何を見て業者を選び、どこで契約が切れるか**を知っている人は、**営業でも、運営でも強い立場に立てます。**

**2. プラント・環境設備・施設の運営**

**処理施設の運転の管理、搬入の管理、維持補修の発注。**この経験は、**施設の運営を受託する会社で、直接必要とされます。**

**3. 自治体を顧客とする企業（計画・脱炭素・環境の調査）**

**計画の作られ方と、進捗の説明の仕方**を知っていることが効きます。**排出量の算定に関わっていたなら、それは強い経験です。**

**4. 企業の環境管理・サステナビリティの部門**

**規制の側にいた経験**が効きます。**どの法令で、何が、どう規制されているか**を読める人は、**企業の内部では貴重です。**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## つまずきやすい点

**1. 「ごみの担当」と書く**

**世帯数・車両の台数・年間の処理量**で書いてください。**オペレーションの規模**が伝わります。

**2. 苦情対応を、雑務として扱う**

**原因の調査と、測定の設計**です。**品質管理と同じ形**をしています。

**3. 委託先との関係を「発注」で済ませる**

**容量の管理と、続けられる価格の設計**まで書いてください。

**4. 排出量の目標を、達成できなかった話にする**

**自分では動かせない要因が大きい指標を、説明し続けた経験**として書いてください。

**5. 規制の側と、運営の側を分けずに書く**

**両方を持っていること自体が、この経歴の特徴**です。応募先に合わせて前に出すほうを変えてください。

自分の経歴がどう言い換えられるかは、一度話しながら整理したほうが早いことが多いです。[どの経験に値が付くのかから相談できます](../apply.html)。

:::insight
ここまで書いておいて逆のことを言いますが、**この経歴は、いま動かない判断にも理があります。**理由は、**脱炭素と資源循環の分野が、いま制度の切り替えの途中**にあるからです。排出量の算定の方法も、資源化の枠組みも、数年のうちに変わっていきます。**その渦中で実務を回している人は、制度が固まった後には作れません。**そして、**企業の側は、これから人を必要とします。**規制が増えるほど、**「行政が何を見ているか」を知っている人の値は上がります。**つまり、**いま在職して実務を積むことが、そのまま準備になっている**という状態です。**確かめてほしいのは、自分がいま担当しているのが、廃棄物の運営なのか、規制なのか、計画なのか**です。**運営が中心なら、処理やプラントの会社。****規制が中心なら、企業の環境管理。****計画が中心なら、自治体を顧客とする会社。****それぞれ、必要な数字が違います。**先に、自分の担当の中心を決めてから、数字を集めてください。応募先が決まっていない段階のほうが、整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 廃棄物処理法第6条の2は、**「生活環境の保全上支障が生じないうちに収集し、運搬し、処分しなければならない」**と定めています
- つまり、**1日も止められない業務**です。しかも、**出る量はこちらで決められません**
- **需要を選べないまま、供給の体制だけで対応する**——**民間のオペレーションで、いちばん難しい部分**です
- 中核スキルは、**①回す ②任せる ③減らす ④止める ⑤測る**の5工程に分かれます
- 違うのは、**①利用者を選べない ②単価を上げられない ③やめてもらえない ④苦情が直接来る**の4点です
- **「ごみの担当」ではなく、世帯数・車両の台数・年間の処理量**で書いてください

## よくある質問

### 公害の苦情対応しか担当していません。書けることはありますか

**十分に書けます。**苦情の対応は、**①受付と聞き取り ②現地の確認 ③測定の実施 ④基準との照合 ⑤事業者への指導 ⑥記録**という工程で成り立っています。**これは、民間の品質管理や、設備の不具合の調査と同じ形**です。書くなら、**「騒音・振動・悪臭・水質に関する苦情を年間◯件受け、現地の確認と測定を行い、基準との照合のうえで指導を実施」**という形です。とくに、**「測定して基準内だった場合に、どう説明したか」**は、**この仕事のいちばん難しい部分**です。**そこを説明できると、対応の技術として読まれます。**

### 環境基本計画の策定に関わりました。どう書けばよいですか

**「計画の策定」ではなく、「指標の設計と、進捗の説明」**として書いてください。計画そのものより、**どの指標を選び、どう測り、達成できない年にどう説明したか**が実務です。書くなら、**「環境基本計画について、◯分野の指標の設定と、年次の進捗の取りまとめを担当。外部の要因で動く指標について、要因を分解して示す形に整理した」**という形です。**これは、民間の中期計画やサステナビリティの報告と、まったく同じ作業**です。

### 廃棄物と公害と温暖化を全部やっていました。どう書き分けますか

**通算の年数を前に出して、3つに分けて書いてください。**冒頭に、**「環境行政に通算◯年」**と置き、そのうえで、**「廃棄物（◯万世帯、年間◯トン、委託◯件）」「公害（苦情◯件、測定◯地点）」「温暖化（実行計画、排出量の算定）」**と並べます。**共通しているのは、「自分では量を決められないものを、体制と説明で扱ってきた」という構造**です。それを1行入れておくと、**バラバラの経験に見えません。**行き先の絞り方は[環境課から転職しやすい業界と職種](dept-kankyo-tenshokusaki.html)に整理しました。
