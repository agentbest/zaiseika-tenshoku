**「入門の資格に意味はあるのか」**というご相談を伺います。

**位置づけを理解したうえで使えば、意味が出る場面があります。**

この記事では、**その場面**を扱います。

**⚠ 試験の内容・区分・実施の方法は、所管するところの公表を確認してください。****この記事では、個別の内容には触れません。**

## 学ぶ機会は、制度として定められています

**地方公務員法第39条第1項**です。

> **職員には、その勤務能率の発揮及び増進のために、研修を受ける機会が与えられなければならない。**

**同条第2項・第3項**です。

> ２ **前項の研修は、任命権者が行うものとする。**
>
> ３ **地方公共団体は、研修の目標、研修に関する計画の指針となるべき事項その他研修に関する基本的な方針を定めるものとする。**

**研修を受ける機会が与えられなければならない**、と定められています。

**そして、団体は研修の方針を定めるものとされています。**

**つまり、職員が学ぶことは、制度として前提に置かれている**ということです。

**この前提は、民間でも同じ**です。

**入社時点ですべてを備えている必要はなく、入社後に学ぶ枠組みがあります。**

**入門の資格は、その入口にある**ものと位置づけてください。

## 意味が出る場面

| 場面 | 理由 |
|---|---|
| ① 応募条件に記載がある | **満たす材料になる** |
| ② 分野を変える | 学習していることを示せる |
| ③ 用語を揃えたい | **会話の前提が揃う** |
| ④ 体系的に学びたい | 範囲が決まっている |
| ⑤ 学ぶ習慣を示したい | 継続の一歩として |

**③が、実務では最も効きます。**

**技術の担当者や事業者との会話で、言葉の意味が分かる。**

**これだけで、確認のやり取りが減ります。**

**②について。**

**情報の分野に関わる職種へ移る場合、学習の開始点として示せます。**

## 意味が出にくい場面

| 場面 | 理由 |
|---|---|
| ① 応募条件に記載がない | 判断の中心にならない |
| ② 実務の経験がある | **経験のほうが具体** |
| ③ 技術を職務とする求人 | 水準が足りないことがあります |
| ④ 応募の時期が近い | 書類の作成が優先 |
| ⑤ 目的が曖昧 | 「何か取っておきたい」だけ |

**③について。**

**設計や開発を職務とする求人**では、**入門の資格では水準を示せない**ことがあります。

**求人票の応募条件を確認**してください。

**読み方は**[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)**に整理しています。**

## 情報政策課以外の職員が書ける材料

| 材料 | 書き方の例 |
|---|---|
| ① 現場での利用 | **窓口で年間約◯件の処理に使用** |
| ② 帳票・様式の整理 | ◯種類を◯種類に統合 |
| ③ 手順書の作成 | 操作の手順を係内に共有 |
| ④ 問い合わせの対応 | 職員からの質問に回答 |
| ⑤ 情報の取扱い | 規程に沿った運用 |
| ⑥ 更改への関与 | 業務側として要件を確認 |

**⑤が、見落とされやすい**です。

**個人情報を含む業務では、権限、保存、持ち出しの扱いを日常的に判断**してきたはずです。

**扱いは**[Googleスプレッドシート｜庁内のExcel運用との違い](skill-spreadsheet.html)**に整理しています。**

## 書くときの注意

| 注意 | 内容 |
|---|---|
| ① 取得の年を書く | いつ取ったか |
| ② 実務と併記 | **資格だけを書かない** |
| ③ 立場を明記 | 業務側であること |
| ④ できる範囲を限定 | 技術の実務まで含めない |
| ⑤ 関係するものを選ぶ | 応募先に関係するか |

**②が重要**です。

**入門の資格を単独で書くと、それ以上のものがないと読まれる**ことがあります。

**実務の材料と組み合わせて**ください。

:::insight
入門の資格について、**面談でお伝えしているのが「目的を1つに絞ってください」**という点です。**「持っていて損はない」という理由で受ける方**がいらっしゃいます。ところが、**目的が曖昧なまま取ると、書類でも面接でも使えません。**「なぜ取ったのですか」と聞かれて、**答えに詰まる**ことになります。一方、**目的がはっきりしていれば、短く説明できます。**「システムの更改に関わることになり、事業者との会話で言葉が分からず困ったため」。**この一言があるだけで、受け取られ方が変わります。**学ぶきっかけが実務にあった、という説明になるからです。そして、**学んだ結果を業務に使った**なら、そこまで書いてください。「用語が分かるようになり、要件の確認の場で質問ができるようになった」。**資格と実務がつながっていることが、伝わります。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 取る前に考えること

| 確認すること | 内容 |
|---|---|
| ① 応募したい求人の条件 | **記載があるか** |
| ② 実務で書ける材料 | 利用、整理、手順書 |
| ③ 目的 | **1つに絞る** |
| ④ 期限 | 応募の時期に間に合うか |
| ⑤ 次の段階 | 続けて学ぶ予定があるか |

**⑤について。**

**入門の段階で止まる場合と、続けて学ぶ場合では、説明が変わります。**

**「入口として取り、いまは◯◯を学んでいる」**と言えると、**継続が伝わります。**

**なお、取れば転職できる、という関係にはありません。**

**何のために学び、どう使ったか**が、評価の対象です。

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 実務の整理 | **利用、整理、手順書、情報の取扱い** |
| 学ぶ目的の言語化 | なぜ学ぶのか |
| 研修の機会の確認 | 団体の制度 |
| 求人を読む | 週に30分 |

**3行目です。**

**地方公務員法第39条のとおり、研修の機会は制度として置かれています。**

**団体が実施する研修に、情報に関するものがあるか確認**してください。

**受講の事実も、書類に書けます。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 取得の理由 | **1つの理由で短く** |
| その後の学習 | 続けているか |
| 実務での使用 | 使った場面 |
| 立場 | 業務側であること |
| できる範囲 | **正確に、限定して** |

**1行目です。**

**「何となく」では、目的が伝わりません。**

**実務の場面と結び付けて説明**してください。

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 自治体向けの事業 | **現場の運用が分かる** |
| ② 業務の改善の支援 | 工程と仕組みの対応 |
| ③ 事務の受託 | 手順の整備 |
| ④ 管理部門 | 情報の取扱いの規律 |
| ⑤ 営業事務・導入の支援 | 顧客への説明 |

**①について。**

**自治体を顧客とする事業では、現場でどう使われるかを知っている人**が求められます。

**入門の資格は、その理解に用語を足すもの**という位置づけです。

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## よくある失敗

**1. 資格だけを書く**

**実務の材料**と組み合わせてください。

**2. 取得の理由を用意しない**

**面接で聞かれます。**

**3. 技術を職務とする求人に単独で出す**

**水準が足りないことがあります。**

**4. 情報の取扱いの経験を書かない**

**日常的に判断**してきたはずです。

**5. 続きの学習に触れない**

**継続**が伝わりません。

**6. 目的を複数挙げる**

**1つに絞って**ください。

**7. 応募の時期が近いのに受験を優先する**

**書類の作成が先**です。

**8. 取れば転職できると考える**

**何のために学びどう使ったか**が評価の対象です。

:::insight
ここまで「目的を絞って」という話をしておいて逆のことを言いますが、**取ったこと自体を隠す必要はありません。**面談で拝見していると、**「入門の資格だから書かないほうがよいのでは」と迷う方**がいらっしゃいます。ところが、**書かない理由もありません。**取得の年と、取った理由が添えられていれば、**学ぶ意思がある人**として読まれます。とくに、**分野を変える転職**では、**行動に移したという事実**が材料になります。「関心がある」と言うだけの人と、**実際に学び始めた人**では、受け取られ方が違います。ですから、**資格の欄に書き、面接で理由を説明できる状態にしておく。**これで足ります。**書くか書かないかで悩む時間より、実務の材料を整理する時間**に充ててください。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方公務員法第39条**は、**研修を受ける機会が与えられなければならない**とし、**団体が研修の方針を定める**としています。**学ぶことは制度の前提**です
- 意味が出るのは、**応募条件に記載がある、分野を変える、用語を揃えたい、体系的に学びたい、学ぶ習慣を示したい**場合です
- 意味が出にくいのは、**記載がない、実務の経験がある、技術を職務とする求人**の場合です
- **資格だけを書かないでください。**実務の材料と組み合わせてください
- **情報の取扱いの経験**は、見落とされやすい材料です
- **目的を1つに絞って**ください。面接で短く説明できる状態にしてください
- **取ったこと自体を隠す必要はありません**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 年齢が高いと、入門の資格は不利に見えますか

**そのようなことはありません。**見られているのは、**取得の理由と、その後の使い方**です。「システムの更改に関わることになり、事業者との会話で必要だったため」という理由があれば、**実務に結び付いた学習**として読まれます。なお、**年齢にかかわりなく均等な機会を与えることは、労働施策総合推進法第9条に定めがあります。**扱いは[50代の公務員が転職するとき](senko-tachiba-50dai.html)にも整理しています。**資格の段階より、実務の材料の厚みのほうが見られます。**両方を書いてください。

### 上位の資格を目指すべきですか

**目的で判断してください。**技術を職務とするのであれば、**上位の範囲が必要**になることがあります。一方、**業務側の担当、導入の支援、調達**であれば、**用語が分かる水準で足りる**場面があります。判断の目安は、**求人票の応募条件**です。なお、**続けて学んでいること自体は、面接で説明できます。**「入口として取り、いまは◯◯を学んでいる」。**段階を踏んでいることが伝わります。**扱いは[応用情報技術者｜SIer・ITコンサルへの転職で](skill-oyojoho.html)に整理しています。

### 情報政策課の経験がないと、関連の求人は難しいですか

**求人によります。**「業務側の担当」「導入の支援」「現場の運用の理解」を求める求人では、**現場でシステムを使ってきた経験が評価される**ことがあります。自治体向けのシステムの会社では、**窓口でどう使われるかを知っている人**が必要とされます。書き方は、**「基幹のシステムを用いて年間約◯件の処理を担当」「不具合の原因を切り分けたうえで担当課へ連絡」**という形です。扱いは[基本情報技術者｜非IT職の公務員が取る意味](skill-kihonjoho.html)に整理しています。**部署の名称ではなく、やったことで書いてください。**
