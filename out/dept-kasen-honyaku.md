河川・砂防課の経験は、求人票の言葉に直すと**まったく別の名前**で呼ばれています。

**「河川の維持管理、砂防に関する業務」**

**この書き方では、民間の採用担当には何も伝わりません。**

実際にやっていたのは、**いつ来るか分からない事態に備えて、平時のうちに手を打っておく**という仕事です。

**そして、備えの成果は、何も起きなかったときにしか現れません。**

この記事では、**庁内の呼び名を民間の言葉に置き換え、中核スキルを5つの工程に分けて**整理します。

## 4つのことを、同時に満たすよう求められています

最初に、この仕事の立ち位置を条文で押さえます。**経験の値を決める部分**です。

河川法第1条は、目的をこう定めています。

**この法律は、河川について、洪水、津波、高潮等による災害の発生が防止され、河川が適正に利用され、流水の正常な機能が維持され、及び河川環境の整備と保全がされるようにこれを総合的に管理することにより……**

**4つ並んでいます。**

| 求められること | 中身 |
|---|---|
| **災害の防止** | 洪水、津波、高潮から守る |
| **適正な利用** | 水を使う、空間を使う |
| **流水の正常な機能の維持** | 水量と水質を保つ |
| **河川環境の整備と保全** | 生きものと景観を守る |

**ここが要点です。**

**そして、この4つは、しばしば互いに引っ張り合います。**

**洪水を防ぐには、流れやすくします。**しかし、**流れやすくすると、生きものの環境が変わります。**

**水を使えば、流れる量が減ります。**それは、**正常な機能の維持と衝突することがあります。**

**つまり、この仕事は、「両立しないものを、同時に成り立たせる」ことを求められています。**

**そして、条文はそれを「総合的に管理する」と書いています。**

**民間でいえば、これは相反する要求の間で判断する仕事**です。**安全と費用、品質と納期、性能と環境。****どの業種にも、同じ構造の判断があります。**

**この判断を、災害という「起きたら取り返しがつかないもの」を相手にやってきた**——**それが、この経歴の中身です。**

## 民間での訳語

| 庁内での呼び名 | 民間での呼ばれ方 |
|---|---|
| 河川の維持管理 | **設備・施設の保全** |
| 河川のパトロール | **巡回点検・状態の監視** |
| 護岸・堤防の補修 | **設備の補修・更新の計画** |
| 砂防施設の管理 | **防災設備の維持** |
| 土砂災害の警戒区域に関する事務 | **危険度の区分と、周知** |
| 水防の体制 | **緊急時の対応の体制** |
| 河川区域内の占用と許可 | **敷地の使用の許可・共用の管理** |
| 浚渫・除草の発注 | **維持作業の発注と管理** |
| 内水の排水（ポンプ） | **設備の運転の管理** |
| ハザードマップの作成と周知 | **危険の情報の可視化と伝達** |
| 災害時の被害の調査と報告 | **被害の算定と報告** |
| 国・県との協議 | **上位の機関との調整** |

**上から5行目までが、いちばん値の付く並び**です。**点検して、状態を把握して、直す順番を決めて、備える**——**これは、防災の設備の保全そのものです。**

## 中核スキルを5つの工程に分ける

**この部署の中核は、「起きたら取り返しのつかないものに、平時のうちに備えること」**です。

**工程1：見る（点検と巡回）**

護岸、堤防、水門、排水のポンプ、砂防の施設、土砂の危険な箇所。

**この工程に固有の制約があります。****傷みが、見えにくい。**護岸の裏側、堤防の中、水の中。**表から見えない部分が、実際には壊れかけていることがあります。**

そして、**普段は水があって近づけない場所**もあります。

**だから、水が少ない時期に点検の計画を組みます。**

**これは、民間の設備でいう「止められる期間に点検する」という発想と、まったく同じ**です。

**工程2：備える（施設の整備と補修）**

護岸の補修、堤防の改修、水門やポンプの更新、砂防の施設の整備。

**この工程に固有の制約があります。****水のある場所では、施工できる時期が限られます。**出水の時期を避け、**渇水の時期に集中させます。**

そして、**川は上流から下流までつながっています。**一箇所だけ強くしても、**弱いところに水が集まります。**

**つまり、「全体の中で、どこが弱いか」を見て判断する必要があります。**

**これは、民間の設備でも同じです。****系統全体を見ないと、対策が意味を持ちません。**

**工程3：区分する（危険な区域の指定と周知）**

土砂災害の警戒区域、浸水が想定される区域、ハザードマップ。

**この工程に固有の制約があります。****区域を指定すると、そこに住んでいる人の資産に影響します。**だから、**説明が必要になります。**

そして、**「危険だ」と伝えることと、「不安にさせない」ことの間に、線を引く必要があります。**

**伝えなければ逃げてもらえない。****強く言いすぎると、地価や生活に影響する。**

**この「危険の情報を、正確に、過度に不安を煽らずに伝える」という技術**は、**民間の品質や安全に関わる情報の公表で、そのまま同じ**です。

**工程4：構える（水防と緊急の対応）**

水位の監視、水防の体制、避難の情報の判断への関与、災害時の対応。

**この工程に固有の制約があります。****判断の時間が短い。**そして、**空振りが前提です。**

**「念のため」の体制を敷いて、何も起きない。**それが、**いちばん良い結果**です。

しかし、**空振りが続くと、体制を維持する説明が難しくなります。**

**この「空振りを前提にした体制を、維持し続ける」という経験**は、**民間の事業継続の計画で、まったく同じ課題になっています。**

**工程5：調べる（被害の調査と報告）**

災害が起きた後の被害の確認、査定に向けた資料の作成、国や県への報告。

**この工程に固有の制約があります。****期限が決まっています。**そして、**現地に入れるようになってからしか始められません。**

**つまり、着手できる日は選べないのに、報告の期限は動かない**という状態になります。

**だから、この工程では、様式を先に決めておくことが実務の中心になります。**被害の類型ごとに、**何を測り、何を写真に残し、どう記録するか。**これを決めておかないと、**現地に入れた日から、手順を考えることになります。****そして、その時間はありません。****「起きる前に、起きた後の手順を決めておく」**——**これは、民間の事故や障害への対応と、まったく同じ考え方**です。

:::insight
この経歴でいちばん多い損は、**「河川の維持管理」と書いてしまう**ことです。この一言だと、**川の草を刈っていた人**に読まれます。実際にやっていたのは、**いつ来るか分からない事態に備えて、限られた予算で、どこから手を打つかを決めること**でした。書くなら、**「管理する河川◯河川・延長約◯キロメートル、水門◯基、排水のポンプ場◯か所、砂防の施設◯基を担当。点検の結果と上下流の関係から優先順位を付け、年間◯件・総額約◯万円の整備と補修を発注」**という形です。**とくに「施設の数」を書いてください。**水門、ポンプ、樋門、砂防の堰堤。**これらは、民間でいえば設備です。**面談で伺うと、**皆さん数を把握しています。**それだけ日常的な数字なのに、**書類には書かれていません。****防災の設備を扱う会社でも、インフラの保全の部門でも、「どれだけの設備を見ていたか」がいちばん最初に見られます。**
:::

## 民間のリスク管理・設備の保全と、どこが同じでどこが違うか

**同じところ**

1. **備えの成果は、何も起きないこと。**だから見えにくい
2. **系統全体を見る必要がある。**一箇所だけ強くしても意味がありません
3. **点検できる時期が限られる。**止められる期間に合わせて計画します

**違うところ**

1. **相手が自然。**交渉も、予測も、思いどおりにはなりません
2. **起きたときの被害が、人命に直結する。**やり直しがききません
3. **空振りが前提。**何も起きない体制を、毎年維持します
4. **効果が数十年後に出る。**今年の整備が効くのは、何十年か先の一度かもしれません

**3番目が、いちばん説明しにくい部分**です。

**「準備したのに、何も起きなかった」——それが成功です。**

**しかし、その状態が続くと、「本当に必要なのか」と問われます。**

**この問いに、毎年答えてきた**——**それは、民間の事業継続の部門が、いま直面している問題とまったく同じ**です。

## 評価が高くなりやすい4つの方向

**1. 建設コンサルタント（河川・砂防・防災の計画）**

**点検、整備の計画、ハザードマップ、避難の計画。****自治体から受託する業務の中心**です。**発注し、成果を確認してきた経験**が直接効きます。

**2. 建設会社（河川の工事、法面、防災の施設）**

**発注する側にいた経験**が効きます。**施工できる時期が限られること、上下流の関係**を知っている人は、**工程を組む側で強くなります。**

**3. 企業の防災・事業継続の部門**

**ハザードマップを作り、水防の体制を回してきた経験**は、**企業が自社の拠点の水害の備えを作るときに、そのまま使えます。**

**4. 損害保険・リスクの調査**

**被害の調査と査定の経験**、**浸水の想定区域の読み方**は、**保険の引受けや、事故の調査の分野で必要とされます。**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## つまずきやすい点

**1. 「河川の維持管理」と書く**

**管理した延長と、施設の数**を書いてください。**それが経験の規模です。**

**2. 4つの目的が衝突することを説明しない**

**相反する要求の間で判断してきた**——**これは、どの業種にもある構造です。**

**3. 空振りの体制を、成果として説明しない**

**何も起きない体制を維持してきた**——**事業継続の分野では、そのまま同じ課題です。**

**4. 危険の情報の伝え方を書かない**

**正確に、過度に不安を煽らずに伝える**——**これは技術です。**

**5. 被害の調査を、臨時の作業として扱う**

**着手日は選べないのに期限は動かない**——**この段取りの話が効きます。**

自分の経歴がどう言い換えられるかは、一度話しながら整理したほうが早いことが多いです。[どの経験に値が付くのかから相談できます](../apply.html)。

:::insight
ここまで書いておいて逆のことを言いますが、**この経歴は、いま需要が増えている分野にあります。**理由は、**豪雨の災害が続いていること**です。自治体の側では、**点検も、計画も、避難の情報の整理も、仕事が増えています。**そして、**受託する会社も、企業の防災の部門も、人を探しています。**とくに、**企業の事業継続の部門**は、**「自社の拠点が浸水したらどうなるか」を真面目に検討し始めています。**そこで足りないのが、**ハザードマップの読み方と、水がどう来るかを現実的に想定できる人**です。面談で伺うと、**「うちの市の川のことしか分かりません」とおっしゃいます。**しかし、**水の流れ方の考え方は、どこでも同じ**です。**上流で降った雨がいつ来るか、どこから溢れるか、どこに逃げるか。****この読み方を持っていることが、そのまま値になります。**在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 河川法第1条は、**災害の防止・適正な利用・流水の正常な機能の維持・河川環境の整備と保全**の4つを挙げ、**「総合的に管理する」**と定めています
- **この4つは、しばしば互いに引っ張り合います。**つまり、**両立しないものを同時に成り立たせる仕事**です
- 中核スキルは、**①見る ②備える ③区分する ④構える ⑤調べる**の5工程に分かれます
- 違うのは、**①相手が自然 ②被害が人命に直結 ③空振りが前提 ④効果が数十年後**の4点です
- **「何も起きない体制を、毎年維持する」**——**民間の事業継続の部門が、いま直面している問題と同じ**です
- **管理した延長と、施設の数**が、**そのまま経験の規模として読まれます**

## よくある質問

### 技術職ですが、設計は外注していました

**それで構いません。**むしろ、**発注する側として、何を求め、何を確認していたか**が書けます。書くなら、**「河川の整備と補修について、委託の仕様の作成、設計の成果の確認、工事の発注と監督を担当」**という形です。**建設コンサルタントに移る場合、「発注者が何を見ているか」を知っていることが、そのまま強みになります。**設計そのものの経験がないことは、**先に言っておけば問題になりません。**

### 砂防の担当が中心でした。河川とは違いますか

**扱う対象は違いますが、構造は同じです。**砂防は、**土砂が動くことに備える仕事**で、**点検、施設の整備、危険な区域の指定と周知、警戒の体制**という工程は、**河川とほぼ同じ**です。書くなら、**「砂防の施設◯基の点検と管理、土砂災害の警戒区域に関する事務、警戒の体制の運用を担当」**という形です。とくに、**土砂災害の警戒区域の指定に関わった経験**は、**区域を指定して住民に説明する**という、**難しい部分を通した証明**になります。

### 水防の当番が負担で、転職を考えています

**この点は、移る先によって変わります。**インフラや設備の分野では、**緊急時の出動は残ります。**ただし、**当番の体制と、その扱い**が違うことがあります。確かめてほしいのは、**「出動そのもの」が負担なのか、「個人で背負っていること」が負担なのか**です。**後者なら、体制の問題なので、移った先で解決する可能性があります。**逆に、**出動そのものを避けたいのであれば、計画や調査に寄った方向**——建設コンサルタント、企業の防災の企画——**を選ぶほうが確実です。**行き先の絞り方は[河川・砂防課から転職しやすい業界と職種](dept-kasen-tenshokusaki.html)に整理しました。
