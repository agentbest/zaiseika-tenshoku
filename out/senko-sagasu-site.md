**どちらも使ったことがない、というご相談を伺います。**

**役割が違うため、併用するのが現実的**です。

この記事では、**仕組みの違い**と、**日々の使い分け**を扱います。

## 届出制と許可制

**職業安定法第43条の2第1項**です。

> **特定募集情報等提供事業を行おうとする者**は、厚生労働省令で定めるところにより、氏名又は名称及び住所その他の厚生労働省令で定める事項を**厚生労働大臣に届け出なければならない。**

**届出**です。

**一方、職業紹介のほうは許可制**です。

**同法第30条第1項**です。

> **有料の職業紹介事業を行おうとする者は、厚生労働大臣の許可を受けなければならない。**

| | 転職サイト（募集情報等提供） | 紹介（職業紹介） |
|---|---|---|
| 仕組み | **届出** | **許可** |
| 役割 | 募集の情報を提供する | **雇用関係の成立をあっせんする** |
| 応募の相手 | 会社に直接 | 紹介を経由 |
| 求職者の費用 | かかりません | かかりません |

**2行目の違いが、使い分けの根拠**です。

**情報を提供するものと、あっせんするもの**では、できることが違います。

**仕組みの違いそのもの**は[非公開求人とは何か](senko-sagasu-hikoukai.html)**に整理しています。**

## 役割の違い

| やること | 転職サイト | 紹介 |
|---|---|---|
| 求人を探す | **自分で** | 示されます |
| 条件を絞る | 自分で | 伝えて任せます |
| 書かれていない点の確認 | 自分で聞く | **照会できます** |
| 応募 | 自分で | 推薦の形で |
| 日程の調整 | 自分で | **任せられます** |
| 辞退の連絡 | 自分で | 任せられます |

**1行目と3行目**です。

**自分で探す作業には、相場が分かるという効果**があります。

**一方、書かれていない点の確認は、紹介のほうが手間が少なくなります。**

## 週単位の使い分け

| 曜日・時間 | やること | 使うもの |
|---|---|---|
| 平日の夜（30分） | 新着の求人を見る | **転職サイト** |
| 平日の夜（適宜） | 連絡の確認と返信 | 紹介 |
| 週末（1時間） | 候補を並べて比べる | 両方 |
| 週末（必要時） | 書類を整える | 紹介の確認を受ける |
| 随時 | 面接の日程の調整 | **紹介に任せる** |

**1行目です。**

**新着を見る作業は、短時間で継続できます。**

**週に30分でも、数週間で相場が見えてきます。**

**5行目について。**

**在職中の日程の調整が、最も時間を取られる部分**です。

**ここを任せると、負担が大きく減ります。**

## 転職サイトの使い方

| 設定 | 内容 |
|---|---|
| 検索の語 | **職種名ではなく、仕事内容の言葉** |
| 条件の保存 | 検索の条件を保存します |
| 新着の通知 | 条件に合う求人が出たときに届きます |
| 公開の範囲 | **勤務先に関する設定を確認** |
| 気になる求人 | 後で比べるために残します |

**1行目です。**

**「自治体」「官公庁」「公共」「指定管理」「業務委託」「発注者支援」。**

**これらの語で探してください。**

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

**4行目について。**

**在職中は、登録の内容がどこまで見えるかの設定を確認**してください。

## 紹介の使い方

| 項目 | 内容 |
|---|---|
| 伝えること | 在職中であること、条件、時期 |
| 確認を頼むこと | 配属先、募集の背景、勤務の実態 |
| 任せること | 日程の調整、辞退の連絡 |
| 頻度 | 連絡できる時間帯を伝えます |

**2行目が、最も使いどころのある部分**です。

**自分では聞きにくい事項を、応募の前に確認できます。**

**扱いは**[転職エージェントの使い方](senko-sagasu-agent.html)**に整理しています。**

:::insight
使い分けで、**面談でお伝えしているのが「探す作業は手放さないでください」**という点です。**紹介に登録すると、探す作業まで任せられると考える方**がいらっしゃいます。ところが、**自分で求人を読む作業には、別の効果があります。**応募条件の欄に繰り返し出てくる言葉。仕事内容の欄に書かれている業務の範囲。**これらは、職務経歴書と面接の材料になります。**そして、**相場が分かると、示された求人の位置づけが判断できます。**1件だけ示されて、それが妥当かどうかは、**他を見ていなければ分かりません。**一方で、**日程の調整と条件の照会は、任せたほうが早い**です。在職中は、平日の日中に電話をかける時間が取りにくいためです。**読むのは自分、確認と調整は任せる。**この分け方が、在職中には合っています。**両方が同じ作業をしても、時間が増えるだけ**です。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 記録のしかた

| 項目 | 内容 |
|---|---|
| 会社名 | 一覧にします |
| 知った経路 | **サイトか、紹介か** |
| 応募の経路 | 1社につき1つ |
| 現在の段階 | 書類／面接／内定 |
| 次の予定 | 日時と方法 |

**2行目と3行目を分けて記録**してください。

**サイトで見つけた求人を、紹介経由で応募することもあります。**

**知った経路と応募の経路は、別のもの**です。

**同じ会社に複数の経路から応募すると、選考が進めにくくなります。**

**扱いは**[直接応募とエージェント経由の違い](senko-sagasu-direct.html)**に整理しています。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 進め方の例

| 週 | やること |
|---|---|
| 1週目 | 条件を書き出す。サイトに登録し、検索の条件を保存する |
| 2週目 | 求人を20件読む。応募条件の言葉を拾う |
| 3週目 | 職務経歴書の1通目を作る |
| 4週目 | 紹介に登録し、条件を伝える |
| 5週目以降 | 新着を見ながら、条件の合うものに応募する |

**3週目までを先に**してください。

**書類ができていないと、求人が出たときに間に合いません。**

**4週目について。**

**条件を伝えるとき、3週目までに拾った言葉が使えます。**

**「この領域の求人を見たい」と具体的に伝えられます。**

## 同じ求人が両方に出ていた場合

| 状況 | 対応 |
|---|---|
| サイトで見つけ、紹介でも示された | **応募の経路を1つに決める** |
| 既にサイトから応募した | 紹介にその旨を伝える |
| 紹介から先に示された | 自分で直接応募しない |
| どちらから出すか迷う | 確認したい事項があるかで決める |

**4行目です。**

**配属先や募集の背景を確認したい場合、紹介経由のほうが照会できます。**

**条件が既に分かっていて、応募先も決まっている場合は、直接でも差し支えありません。**

**判断の基準は、得かどうかではなく、確認が必要かどうか**です。

## 続けるための工夫

| 工夫 | 内容 |
|---|---|
| 時間を決める | **曜日と時間を固定する** |
| 範囲を決める | 新着だけを見る |
| 記録を1か所に | 表を1つにまとめる |
| 区切りを作る | 月に1度、候補を見直す |

**1行目です。**

**「時間があるときに見る」では続きません。**

**曜日と時間を決めておくと、短時間でも継続します。**

**4行目について。**

**月に1度、残した求人を並べて見ると、条件の優先順位が見えてきます。**

## よくある失敗

**1. 探す作業を手放す**

**相場が分からなくなります。**

**2. 日程の調整を全部自分でする**

**在職中は負担が大きくなります。**

**3. 職種名で検索する**

**同じ仕事が漏れます。**

**4. 新着の通知を設定しない**

**時期を逃します。**

**5. 知った経路と応募の経路を混同する**

**重複の原因になります。**

**6. 書類を後回しにする**

**求人が出たときに間に合いません。**

**7. 公開の範囲の設定を確認しない**

**在職中は確認してください。**

:::insight
ここまで使い分けの話をしておいて逆のことを言いますが、**両方に登録することが目的ではありません。**面談で拝見していると、**登録先を増やして、連絡の対応だけで時間が過ぎてしまう方**がいらっしゃいます。**登録は準備であって、選考ではありません。**そして、**在職中に使える時間は限られています。**週に1時間か2時間。**この中で、どこに時間を使うかを決めてください。**優先順位は、**①職務経歴書を1通仕上げる ②条件を絞る ③求人を読む**です。**この3つができていれば、登録先が1つでも2つでも進みます。**逆に、**この3つが終わっていない状態で登録先だけ増やしても、同じ説明を繰り返すことになります。**ですから、**まず1通仕上げてください。**そこから先は、進みが速くなります。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **職業安定法第43条の2第1項**は、**特定募集情報等提供事業**について**届出**を定めています。**同法第30条第1項**の職業紹介は**許可制**です
- **情報を提供するもの**と、**雇用関係の成立をあっせんするもの**では、できることが違います
- **探す作業は手放さないでください。**相場が分かります
- **日程の調整と条件の照会は、任せたほうが早い**です
- 検索は、**職種名ではなく、仕事内容の言葉**で行ってください
- **知った経路と応募の経路を分けて記録**してください
- **職務経歴書を1通仕上げてから**、登録先を増やしてください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### どちらを先に使えばよいですか

**転職サイトを先に**使ってください。理由は、**相場をつかむ作業が先にあるほうが、紹介で条件を伝えやすくなるから**です。求人を20件ほど読むと、**その領域で何が求められているかが見えます。**「この領域の、この職種を見たい」と具体的に伝えられる状態で紹介に登録すると、**示される求人の精度が上がります。**逆に、**条件が曖昧なまま登録すると、合わない求人が並びます。**なお、**急いでいる場合は同時で構いません。**その場合も、**登録の後に求人を読む作業を続けて**ください。**読む作業は、どの段階でも効きます。**

### 通知が多くて、対応しきれません

**条件を絞ってください。**通知が多いのは、**検索の条件が広い**ことを意味します。勤務地、職種、キーワード。**いずれかを絞ると減ります。**また、**通知の頻度の設定**があることがあります。毎日から週1回に変えるだけで、**まとめて確認できます。**なお、**すべてに目を通す必要はありません。**件名と会社名で判断して、**気になるものだけ開く**形で足ります。**見落としが心配な場合は、条件を保存しておいて、週末にまとめて検索する**という方法もあります。**通知に追われる状態は、続きません。**

### 紹介に登録したら、サイトは見なくてよいですか

**見続けてください。**理由は2つあります。1つは、**掲載されている求人と、紹介される求人が同じとは限らない**こと。会社の採用ページやサイトにのみ掲載されている募集があります。もう1つは、**相場が分かる**ことです。**示された求人の条件が妥当かどうかは、他を見ていなければ判断できません。**なお、**見る時間は週に30分で足ります。**新着だけを確認する形です。**同じ求人が両方に出ていた場合は、応募の経路を1つに決めて**ください。**重複すると、選考が進めにくくなります。**
