人材派遣会社の選考を調べるときは、会社自身の社員への応募と、派遣スタッフとしての登録を分けます。公式の自社採用サイトから、対象の職務と雇用形態を確認してください。公務の窓口経験は本人の工程で説明し、営業等の未経験を残せます。

本記事は2026年11月時点の公開情報にもとづきます。確認日は2026年11月25日です。個別求人とキャリア採用FAQを使って確認方法を示します。非公開の面接質問、採点、心理や通過率を示すものではありません。

## 自社採用の選考と、スタッフ登録の手続を分ける

パーソルテンプスタッフの公式採用サイトは、新卒とキャリア・契約社員の募集を分けています。会社自身のフォロー営業等への応募と、派遣の仕事を探すための登録を混ぜないようにします。応募先の会社と仕事の相手を確認します。

アデコの公式の新卒・キャリア採用案内も、自社への入社を検討する人向けで、無期雇用社員向けと明記しています。別の会社の契約社員募集と同じ条件とは扱いません。自社採用という共通点と、個々の雇用区分を分けます。

人材派遣の営業、就業中スタッフのフォロー、人材紹介、受託業務の運営やSV等は、担当する工程が異なります。会社の事業一覧を一つの応募職務へまとめず、正式職名、必須条件、契約形態を一組で記録してください。

勤務先として表示される場所と雇用主も別に確認します。派遣先や顧客企業、受託現場等の名称だけで契約の相手を決めません。本人の雇用主、対象の職務、実際の勤務場所を対応させて読む方法を使えます。

[行政に接点のある掲載求人を調べる](../?gov=1)際も、自社社員の募集か、どの職務・契約の選考かを分けて比較できます。

## 東京フォロー営業の公開フローを、当該求人の例として読む

パーソルテンプスタッフの確認した東京フォロー営業は、書類選考、Webテスト・オンライン面接1～2回、内定という流れを示しています。フローが変更になる場合の記載もあるため、本人への正式な案内を確認します。

この手順は当該求人の公開情報です。同社のすべての職務や、他社の人材営業・紹介・受託運営等へ共通の手順として移しません。別の勤務地や採用区分の内容を混ぜず、応募する正式な職名を確認してください。

公開されたテストや面接の存在から、未記載の設問や採点を確定しないようにします。本人が実施した工程、他者の権限、未経験、希望を整理して準備できます。未公開の試験内容や他の応募者の回答を入手して使うことを前提にしません。

確認した求人の名称は12月入社の募集です。11月25日時点では応募の案内がありますが、締切日が記載されていないことを無期限の受付と扱いません。現在の表示と本人の入社時期の相談を確認してください。

書類を作ったこと、応募したこと、検査を終えたこと、面接の案内を受けたことは別の段階です。本人が使う連絡先と受信方法を確認し、届いた案内がどの職務のものかを記録できます。応募だけで採用が決まった扱いにはしません。

## アデコのキャリアFAQを、別会社の案内として読む

アデコのキャリアFAQは、応募部門との面接を2回予定し、変更の可能性もあると説明しています。選考案内のページも、募集職種等でフローが異なる場合があるとしています。回数をすべての人への確約にはしません。

複数のポジションへの応募については、一つのポジションのみへの応募を求め、選考終了後の別ポジションへの応募は可能と案内しています。これをテンプスタッフの応募ルールへ移さず、会社ごとの手続で確認します。

同FAQは学歴・年齢・国籍等の制限を設けないとしていますが、個別職務の実務条件まで不要になる意味にはしません。一般的なキャリア採用の案内と、応募する求人の必須・歓迎を別に照合してください。

入社日や面接日の相談に応じる案内があっても、本人が希望した日程へ必ず決まる意味にはしません。質問したことと回答されたこと、希望を伝えたことと正式な予定を受領したことを分けます。

会社のFAQと個別求人の表記で対象が不明なときは、正式職名と確認日を添えて窓口へ質問できます。自分に都合のよい一方だけで手順や条件を決めず、本人への案内で確認する方法を使えます。

:::insight
面接回数や検査の存在は、公開された手順として確認できますが、非公開の設問や採点までは決まりません。本人の確認、説明、記録、引継ぎを具体的に準備する方法を勧めます。公務の窓口を経験したことと、法人営業や人材契約を経験したことは別です。応募条件の必須と歓迎を読み、行っていない業務は未経験として残してください。別会社のFAQや新卒の手順を中途の個別求人へ移さず、正式な職名で確認できます。書類、検査、面接の案内を段階別に記録すると、本人に届く案内に応じて準備を追加できます。希望する役割と選考の進行も分けて考えます。
:::

## 応募条件を、本人の工程で照合する

確認した東京フォロー営業の必須は、業務上のPC利用、人とコミュニケーションを取りながら働いた経験、相手の立場で考えられること、複数の社内システム利用に抵抗がないことです。一項目だけでほかの必須をなくしません。

営業・人材ビジネスの経験は歓迎とされています。営業経験を独自に必須へ変えず、PC等の必須も省きません。本人の実務と照合し、不明な経験の対象は窓口へ確認します。公務員という身分だけで適合を判断しないようにします。

PCの経験は、入力、集計、資料作成等の本人の行動で示せます。複数の道具を使ったことと、未利用の会社固有システムに習熟していることは別です。学習や見学を実務へ加えず、必要な操作と未経験を分けてください。

対人業務も、相手から何を聞き、どの根拠を確認し、どこへ質問したかを整理できます。相手の気持ちや満足度を確認した事実がなければ、架空に加えません。本人が相手の状況を考えて行った行動を説明します。

## 経験の説明は、他者の判断と分担を残す

公務で事業者へ連絡したことと、法人営業で受注や契約を進めたことは別です。本人が日程を整えたのか、質問を整理したのか、条件を決めたのかを分けます。決裁や専門判断を他者が行った場合は、その権限を残してください。

フォロー営業の求人は、新規開拓なしとしていますが、就業中スタッフの確認や企業訪問、後任案件の受注、契約手続等を挙げています。相談を聞くだけの職務とせず、本人がどの範囲を担うかを質問できます。

改善については、提案、採用、実施、効果確認を分けます。測っていない時間や費用の削減率、確認していない満足度を追加しません。本人が実施した確認や、未回答を整理した結果を具体的に示せます。

経験期間も、在籍の全期間と対象の作業を実施した期間を区別します。複数業務を兼ねていたなら分担を残し、部署名だけで専門実務の年数を数えないようにします。将来の希望を過去の経験へ変えないことも必要です。

## 独立した架空の準備例で、本人の状況を残す

以下は選考の準備方法を示す独立した架空例です。実在の応募者、面接での回答、採用結果ではありません。本人が使う場合は事実に置き換え、未実施の行動や持っていない経験は削除してください。

| 項目 | 架空の記入内容 |
|---|---|
| 本人の担当 | 自治体で制度の窓口説明と担当への質問整理 |
| 実施した工程 | 必要事項を確認し、未回答を記録して引き継いだ |
| PCの経験 | 表への入力・集計、説明資料の作成 |
| 他者の権限 | 専門判断と決裁は担当部署・上司 |
| 未経験 | 法人営業の受注、人材サービスの契約、スタッフの就業フォロー |
| 要件の照合 | 対象求人の必須を一項目ずつ本人の事実へ対応させる |
| 選考の段階 | 求人を読了。応募・検査・面接は未実施 |
| 未受領 | 本人への日時、面接や検査の具体的な案内 |
| 質問の準備 | 初期担当、分担、契約更新、勤務条件を確認する |
| 現職との比較 | 現在の説明や確認を深める判断も残す |

この例では、公開フローを読んだことと、面接が決まったことを分けています。相手の反応や選考結果を架空に加えていません。本人の工程と未経験を説明することと、案内を受けることは別です。

本人に営業等の前職がある場合は、その勤務先、期間、相手、担当の工程を公務の履歴と分けられます。資格や学習も、取得済み、合格済み、学習中、受験予定を区別し、未取得を保有済みにしません。

[経験と応募先の準備を整理する](../apply.html)場合も、内部資料を渡さず本人の工程のメモを使えます。ご利用は無料です（紹介手数料は採用企業の負担）。経験や希望によっては、面談・求人紹介を提供できない場合があります。

## 提出と質問、本人への正式提示を分ける

書類の作成後は、本人が事実を確認します。短くしたことで他者の判断や未経験が消えていないか、「調整」の範囲が実施した作業より広くなっていないかを読み返せます。支援を受けて作った文章も、本人が説明できる形を保ちます。

提出先、対象の職名、必要書類、連絡先を確認し、必要な情報だけを送ります。求められていない内部資料や第三者の連絡先を添付せず、送信前後の状態を別に記録できます。問い合わせた事項を回答済みと扱わないようにします。

質問は応募条件、手続、予定役割、勤務条件へ分けられます。一般的な可能性の説明と、本人の初期担当に対する回答も別です。希望を伝えたことを了承や確約の意味にせず、未回答は未確認と残してください。

確認したフォロー営業は契約社員で、通常1年単位、1年を超えない期間の契約と更新の判断、通算5年の上限があります。条件付きの正社員登用も本人の保証にはしません。職務の選考に進むことと、契約の希望がそろうことは別です。

在宅の可能性があっても、外出が多く、研修終了まで原則終日出社の説明があります。フレックスも相手のある仕事として読み、本人が毎日自由な時刻や場所だけで働けるとは決めません。勤務と変更範囲の適用を確認します。

募集が更新された場合は、正式な会社名・職名と確認日を残して見直します。以前の案内と現在の条件に違いがあれば、その項目を添えて質問できます。他社や新卒の情報を混ぜず、回答前の事項を確定させないようにします。

## 情報を守り、現職継続も比較する

住民や相談者、事業者の個人情報、非公開の契約、審査、調達や組織内部の情報を持ち出しません。名前だけ消せば使えるとも判断せず、内部資料を私用AIへ入力しないようにします。公開情報と一般化した本人の工程で準備できます。

行政上の便宜や内部人脈を、営業や事業獲得の強みとして提供する約束もしません。現職の立場・権限を私的に使うことと、本人の説明や確認の経験を話すことを分けます。

現職で相談内容の確認や説明を深める選択も比較できます。人材会社で企業とスタッフの双方を支えたい場合も、どの工程を望むかと条件を確認します。面接の案内や通過だけで、退職を先に決める必要はありません。

[掲載中の求人を比較する](../)際も、現職を含め、本人の希望する役割と必須の生活条件を同じ表へ並べられます。

:::insight
選考が進むことと、本人に合う仕事や契約条件がそろうことは別です。説明や確認を深めたいのか、企業とスタッフ双方への営業・フォローへ移りたいのかを分ける方法を勧めます。現職で希望する工程を続けられるなら、残る判断も比較対象です。公務経験を低く見る必要はなく、行っていない営業や人材契約を加える必要もありません。応募要件、初期担当、分担、契約や勤務の条件を確認し、応募や登録だけで退職を先に決めず、本人への正式な説明がそろった時点で考えられます。公開フローと本人の案内を分け、不明な事項を保留にすることも判断のための方法です。
:::

## まとめとよくある質問

自社社員への応募と派遣登録を分け、職務ごとのフローで確認します。必須条件、本人の工程、未受領の案内を整理し、正式な手順に沿って準備してください。

### 人材派遣会社の面接回数は共通ですか

共通とは扱いません。紹介したテンプスタッフの個別求人とアデコのFAQも別の案内です。変更の可能性を読み、本人への正式案内で確認します。

### 公務の窓口経験を営業経験として書けますか

同じとは扱いません。確認、説明、記録、引継ぎ等の本人の工程を示し、受注や人材契約等を行っていなければ未経験として分けます。

### Webテストで必ず出る問題は分かりますか

公開情報から未記載の設問や採点は確定できません。本人の経歴と職務を整理し、検査の具体的な手続は正式な案内に従います。
