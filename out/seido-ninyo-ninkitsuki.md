自治体の採用情報に「任期付職員（○○担当）」という募集が出ているのを見たことがあるはずです。DXの推進、財政の専門的な分析、公会計の導入、大規模な事業の期間中の増員——**期間を限って、専門的な知識や経験を持つ人を採用する**仕組みが、任期付職員です。

任期付職員は、**地方公共団体の一般職の任期付職員の採用に関する法律**に基づき、常勤の職員として、任期を定めて採用されます。会計年度任用職員（非常勤、年度内の任期）とは違い、**常勤で、任期は最長5年**、給与の特例もあります。転職を考える公務員にとっては、**民間に出た後に任期付職員として公務に戻る道**として、また、**転職先の候補として他の自治体の任期付職員**を考える材料として、知っておく価値があります。

この記事では、**任期付職員の4つの形、任期、給与、会計年度任用職員との違い、転職との関係**を整理します。**採用の要件、任期、給与は条例による**ので、応募を考える方は募集の要項で確かめてください。特定任期付職員（高度の専門的知識を持つ職員）は[特定任期付職員（専門的知識を持つ職員）](seido-ninyo-tokutei.html)に書いています。

## 4つの形——法律の条文

| 形 | 条文 | 要件 | 任期 |
|---|---|---|---|
| **特定任期付職員** | 第3条第1項 | **高度の専門的な知識経験または優れた識見**を有する者を、それを一定の期間活用して遂行することが特に必要な業務に従事させる | **5年を超えない範囲**（第6条第1項） |
| **一般任期付職員** | 第3条第2項 | **専門的な知識経験**を有する者を、それが必要な業務に従事させる場合で、部内で育成に相当の期間を要するなどの事由がある | **5年を超えない範囲**（第6条第1項） |
| **時限的な業務の任期付職員** | 第4条 | **一定の期間内に終了することが見込まれる業務**、または**一定の期間内に限り業務量の増加が見込まれる業務**に従事させる | **3年を超えない範囲**（条例で定める場合は5年）（第6条第2項） |
| **任期付短時間勤務職員** | 第5条 | 第4条の業務、住民サービスの提供時間の延長・繁忙時の体制の充実など | **3年を超えない範囲**（条例で定める場合は5年）（第6条第2項） |

**第3条は「人」の専門性に着目した採用、第4条・第5条は「業務」の時限性に着目した採用**です。採用はいずれも選考により、条例で定めるところによります（第3条第1項・第2項、第4条第1項、第5条第1項）。

## 任期と給与

| 項目 | 内容 |
|---|---|
| **任期の明示** | 採用の際に任期を明示（第6条第3項） |
| **任期の更新** | 条例で定めるところにより、採用した日から5年（第4条・第5条の採用は3年）を超えない範囲で更新できる（第7条） |
| **他の職への任用** | 採用の趣旨に反しない場合に限り、任期中に他の職に任用できる（第8条） |
| **給与** | 地方の法律に給与の定めはなく、**自治体の給与条例**による。特定任期付職員には、国の任期付職員法第7条の俸給表に準じた専用の給料表と業績手当を条例で設けている自治体が多い。一般任期付・時限的業務の任期付は、常勤の職員の給料表による |
| **身分** | **常勤の職員**（一般職）。地方公務員法の服務（職務専念義務、守秘義務、営利企業への従事等の制限など）が及ぶ |
| **共済・退職手当** | 常勤の職員として共済の組合員。退職手当は条例（任期の期間に応じた扱い） |

**任期付職員は、任期がある点を除けば、常勤の職員と同じ身分**です。会計年度任用職員との最大の違いは、ここにあります。

## 会計年度任用職員との違い

| 項目 | 任期付職員 | 会計年度任用職員 |
|---|---|---|
| **根拠** | 任期付職員法 | 地方公務員法第22条の2 |
| **身分** | **常勤**（任期付短時間勤務職員を除く） | **非常勤** |
| **任期** | 最長5年（時限的業務は3年、条例で5年） | 最長で会計年度の末日まで |
| **翌年度** | 任期の範囲内で継続 | 新たな採用（再度の任用） |
| **採用の要件** | 専門的な知識経験、または時限的な業務 | 職の内容による |
| **給与** | 給料と手当（特定任期付は専用の給料表） | 報酬と条例による手当（パートタイム） |
| **共済** | 組合員 | 勤務時間による |
| **営利企業への従事等の制限** | 対象 | パートタイムは対象外 |

**「任期がある常勤の職員」が任期付職員、「年度内の非常勤の職員」が会計年度任用職員**です。応募を考える方は、この違いで、どちらが自分の状況に合うかが決まります。

## 転職との関係——3つの場面

| 場面 | 内容 |
|---|---|
| **民間に出た後、任期付職員として公務に戻る** | 民間で得た専門性（DX、会計、法務、広報など）を持つ人を、自治体が任期付で採用する募集は増えている。**財政課の経験に民間の専門性を加えた人材は、財政・公会計・DXの任期付職員の候補になる** |
| **他の自治体の任期付職員に転職する** | 財政の専門的な業務（公会計、財政の分析、行政改革）の任期付職員を募集する自治体がある。**公務員から公務員への転職の1つの形** |
| **転職先で「任期付」の意味を説明する** | 自治体向けの企業で働く場合、自治体の任用の形態（常勤、任期付、会計年度任用）を理解していることが、提案の精度に効く |

**任期付職員は、民間と公務を行き来する道の1つ**です。任期があるので「戻る」というより「期間を限って公務に関わる」形ですが、任期中は常勤の職員として働けます。

## 応募する場合の注意

| 点 | 内容 |
|---|---|
| **要件** | 募集の要項に、求める専門的な知識経験（資格、実務の年数、業務の内容）が示される。財政課の経験と民間の経験の両方を、要件に沿って書く |
| **任期** | 任期の長さと更新の可否を確かめる。任期の満了後の道（再度の応募、民間への復帰）を並行して考える |
| **給与** | 特定任期付は専用の給料表、それ以外は常勤の給料表による格付け。民間の給与との差を確かめる |
| **退職手当** | 任期の期間に応じた計算。前の公務員の在職期間との通算の有無は条例による |
| **再就職者の働きかけの規制** | 前に在職した自治体の役職員への働きかけの規制（地方公務員法第38条の2）は、他の自治体の任期付職員になっても、前の自治体との関係で及ぶ |

:::insight
面談で伺うと、**財政課から民間の会計事務所に転職した方が、数年後に「公会計の導入」の任期付職員の募集を見て、元の自治体とは別の自治体に応募し、採用された**というケースがあります。財政課の実務と、民間で得た会計の専門性の両方が、任期付職員の要件にちょうど合っていました。逆に、**任期付職員を「常勤と同じでずっと働ける」と思って応募し、任期の満了で戸惑った**という方もいます。ここで1つ提案があります。**転職を考える公務員は、「民間に出た後、任期付職員として公務に関わる道がある」ことを、選択肢の1つとして頭に置いてください。**財政課の経験に民間の専門性が加われば、任期付職員の要件に合う場面が増えます。**任期があることを前提に、任期の満了後の道を並行して持てば、公務と民間を行き来する働き方も現実的です。**
:::

## 転職するとどうなるか

転職を考えている方にとって、任期付職員で効いてくる点は3つです。

**1. 民間に出た後、任期付職員として公務に関わる道がある**

**財政課の経験に民間の専門性を加えた人材は、財政・公会計・DXの任期付職員の候補**になります。

**2. 任期付職員は常勤で、会計年度任用職員とは身分が違う**

**共済、給与、服務は常勤の職員と同じ**で、任期がある点だけが違います。

**3. 任期の満了後の道を並行して持つ**

**最長5年（時限的業務は3年）**なので、満了後の再度の応募や民間への復帰を、任期中に準備してください。

## 手続きと期限

| 順序 | 手続き | 時期 | 場所 |
|---|---|---|---|
| 転職を考えたら | 任期付職員の募集の傾向（財政、公会計、DXなど）を、自治体の採用情報で把握する | 早めに | 自治体の採用情報 |
| 民間で専門性を積む | 財政課の経験に加える専門性（会計、DX、法務など）を意識する | 転職後 | 転職先 |
| 募集を見つけたら | 要件（専門的な知識経験）、任期、給与、更新の可否を確かめる | 募集の時期 | 募集の要項 |
| 応募 | 選考（書類、面接など） | 募集の時期 | 任命権者 |
| 採用 | 任期の明示。常勤の職員として共済に加入 | 採用の日 | 人事の担当課 |
| 任期中 | 満了後の道（再度の応募、民間への復帰）を並行して準備 | 任期中 | ── |

## 誤解されやすい点

**「任期付職員は非常勤」と思い込む**

**常勤の職員です**（任期付短時間勤務職員を除く）。会計年度任用職員とは根拠も身分も違います。

**「任期付職員は誰でも応募できる」と思い込む**

**専門的な知識経験（第3条）または時限的な業務（第4条・第5条）が要件**で、募集の要項で要件が示されます。

**「任期は更新すればずっと続く」と思い込む**

**更新は任期の上限（5年または3年、条例で5年）の範囲内**です（第7条）。上限を超えて続けることはできません。

**「一度公務員を辞めると公務には戻れない」と思い込む**

**任期付職員は、民間で得た専門性を持つ人を公務が採用する仕組み**で、戻る道の1つです。経験者採用の道もあります。

:::insight
ここまで任期付職員の話を書いておいて逆のことを言いますが、**任期付職員として公務に戻ることは、転職の目標ではなく、選択肢の1つです。**民間で続ける道も、他の自治体に転職する道も、どれも合理的です。それでも1本の記事にしたのは、**「公務員を辞めたら二度と公務には関われない」という思い込みが、転職の判断を重くしている**のを面談で見るからです。任期付職員という道があることを知れば、転職は片道切符ではなくなります。そのうえで、**自分の経験に値を付けてくれる業界の見込みと、同じ紙に並べてください。**片方だけでは比較になりません。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 任期付職員は、**地方公共団体の一般職の任期付職員の採用に関する法律**により、**特定任期付（高度の専門的知識経験、第3条第1項）、一般任期付（専門的知識経験、第3条第2項）、時限的な業務（第4条）、任期付短時間勤務（第5条）**の4つの形で採用されます
- 任期は**第3条の採用は5年以内、第4条・第5条の採用は3年以内（条例で定める場合は5年）**で、任期の上限の範囲内で更新できます（第6条、第7条）
- **常勤の職員**（任期付短時間勤務職員を除く）で、共済の組合員となり、地方公務員法の服務が及びます。会計年度任用職員（非常勤、年度内の任期）とは身分が違います
- **民間に出た後、財政課の経験に民間の専門性を加えて任期付職員として公務に関わる道**があります。財政・公会計・DXの任期付職員の募集が増えています
- **任期の満了後の道を、任期中に並行して準備**してください。転職は片道切符ではありません
- 特定任期付職員の詳しい仕組みは[特定任期付職員（専門的知識を持つ職員）](seido-ninyo-tokutei.html)に書いています

## よくある質問

### 民間に転職した後、元の自治体の任期付職員に応募できますか

**応募を禁じる規定はありませんが、再就職者の働きかけの規制（地方公務員法第38条の2）との関係と、自治体の採用の判断によります。**任期付職員の採用は、専門的な知識経験などの要件を満たす者を選考により採用するもので、元の職員であることを理由に応募を禁じる規定はありません。財政課の経験に民間の専門性を加えた方は、元の自治体の財政・公会計の任期付職員の要件に合うことがあります。ただし、退職後に営利企業等の地位に就いている間は第38条の2の働きかけの規制が及び、元の自治体の役職員に対する契約等事務に関する働きかけはできません。任期付職員として採用されれば、自治体の職員に戻るので、その間は規制の対象ではありません。実務上は、元の自治体が元の職員を任期付で採用することに慎重な場合と、経験者として歓迎する場合があり、自治体の判断です。元の自治体に限らず、他の自治体の任期付職員の募集も候補になるので、財政・公会計・DXの募集を広く見るのが現実的です。任期の満了後に民間に戻る場合、再び第38条の2の規制が及ぶことも頭に置いてください。

### 任期付職員の給与は、民間と比べてどうですか

**特定任期付職員は専用の給料表と業績手当、それ以外の任期付職員は常勤の職員の給料表による格付けで、民間の給与との比較は募集の要項の額で行ってください。**地方の任期付職員法には給与の定めがなく、給与は自治体の給与条例によります。多くの自治体が、国の一般職の任期付職員の採用及び給与の特例に関する法律第7条（特定任期付職員の俸給表）に準じて、特定任期付職員（第3条第1項）に高度の専門性に応じた専用の給料表と、業績に応じた業績手当を条例で設けています。一般任期付職員（第3条第2項）と時限的な業務の任期付職員（第4条）は、常勤の職員の給料表により、経験に応じて格付けされます。募集の要項には、給料表の号給の目安や年間の給与の見込みが示されることが多いので、民間の給与と並べて比べてください。常勤の職員として共済に加入し、期末手当・勤勉手当、通勤手当などの手当も支給されます。退職手当は任期の期間に応じた計算で、任期が短いと額は小さくなります。民間の専門職の給与より低いことも高いこともあり、任期付職員の給与を選ぶ理由は、額だけでなく、公務の業務に関わる価値と、任期の後の経歴の価値を含めて判断することになります。

### 任期付職員として働いた後、また民間に戻れますか

**戻れます。任期の満了は自然な区切りで、任期中に得た公務の経験は民間でも評価されます。**任期付職員は任期が明示された常勤の職員で、任期の満了で退職するのは制度の設計どおりです。任期の満了後に民間に戻る場合、任期中に得た公務の経験（財政、公会計、DXの実務）は、自治体向けの企業、会計事務所、コンサルティングなどで、公務と民間の両方を知る人材として評価されます。任期中に守るのは、地方公務員法の服務（職務専念義務、守秘義務、営利企業への従事等の制限）で、任期中に民間の転職先を探すこと自体は、勤務時間外であれば問題ありません。任期の満了後は、再就職者の働きかけの規制（第38条の2）が及び、任期中に在職した自治体の役職員への契約等事務に関する働きかけは離職後2年間できません。**任期の満了の1年前から、民間への復帰の準備（転職支援への相談、応募先の選定）を並行して進める**と、満了と同時に次の道に移れます。任期付職員を経て民間に戻り、また別の自治体の任期付職員になる、という行き来をしている方もいます。
