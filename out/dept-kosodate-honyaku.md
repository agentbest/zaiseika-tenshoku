子育て支援課からの転職で、いちばん説明されていないのはこれです。

**この部署は、「足りないものを、基準で配る」仕事をしてきた**ということ。

保育所の定員は決まっています。申込みがそれを超えたとき、**誰から入れるかを決めなければなりません。**

しかも、**その基準は公開されていて、説明を求められます。**

**限られた供給を、公開された基準で配分し、外からの説明に耐える。**これは、民間でもそのまま必要とされる能力です。

この記事では、その対応を整理します。訳語の対応表、中核スキルの工程分解、そして**民間の需給調整・給付管理の仕事とどこが同じでどこが違うか**まで扱います。

## 「保育しなければならない」と書かれています

まず、この部署の立ち位置を条文で確認します。**民間に説明するときの、いちばん強い材料**です。

児童福祉法第24条第1項は、こう定めています。

**市町村は、この法律及び子ども・子育て支援法の定めるところにより、保護者の労働又は疾病その他の事由により、その監護すべき乳児、幼児その他の児童について保育を必要とする場合において、次項に定めるところによるほか、当該児童を保育所において保育しなければならない。**

**「保育しなければならない」**です。

**努力目標ではありません。**保育を必要とする場合には、**保育する義務**が市町村にあります。

ところが、**保育所の定員は有限**です。そして、**保育所を運営するのは、多くの場合、民間の事業者**です。

**つまり、この部署は、こういう位置にいます。**

- **応えなければならない義務がある**
- **供給は有限で、しかも自分たちで自由に増やせない**
- **足りないときは、基準を決めて配分する**
- **その基準は公開され、説明を求められる**

**この4つが同時に成り立つ仕事は、民間にもあまりありません。**

**面接では、この構造を一度言ってください。**

> 応える義務がある一方で、供給が有限です。**基準を決めて配分し、その基準を公開して説明する**という仕事でした。

**「限られた供給を、公開された基準で配る」**——この一文で、仕事の性格が伝わります。

## 民間での訳語

履歴書や職務経歴書では、**自治体の中でしか通じない言葉を、募集要項に出てくる言葉に置き換えます。**

| 自治体での呼び方 | 民間での呼ばれ方 |
|---|---|
| 保育の必要性の認定 | 要件の認定、資格の判定 |
| 保育所等の利用調整（入所選考） | 需給の調整、割当ての設計と実施 |
| 待機の状況の把握 | 需要と供給のギャップの分析 |
| 児童手当の認定・支払 | 給付の認定と支払管理 |
| 児童扶養手当の認定・現況届 | 給付の認定、年次の資格確認 |
| 保育料の算定・徴収 | 料金の算定、債権管理 |
| 施設型給付・地域型保育給付の支払 | 事業者への給付の支払 |
| 施設の確認・指導監査 | 委託先・加盟事業者の審査と監査 |
| 整備計画・定員の拡大 | 供給能力の計画、拠点の整備 |
| 子ども・子育て支援事業計画 | 中期の事業計画、需要予測 |
| 子育て支援事業の企画・委託 | 事業の企画と委託管理 |
| 相談・通告への対応 | 相談窓口、緊急時の対応 |

**「子育て支援の窓口」ではなく、「認定」「配分」「給付」「委託管理」に分けて書く**のが基本です。

## 中核スキルを5つの工程に分ける

この部署の仕事は、**5つの工程**に分解できます。

**① 要件を認定する**

**保育を必要とする状態にあるか**を認定します。就労、疾病、介護、求職、就学。**事由ごとに要件があり、証明する書類も違います。**

児童手当や児童扶養手当も同じで、**要件に当てはまるかを確認して認定します。**

**そして、認定は一度で終わりません。**就労の状況が変わる、きょうだいが生まれる、転居する。**そのたびに要件を確認し直します。**児童手当も児童扶養手当も、**年に一度、資格が続いているかを確認する手続**があり、**対象の全員分を期間内に処理**します。**「認定して終わり」ではなく、継続して確認し続ける**という点が、この工程の実際です。

**② 割り当てる**

**この部署でいちばん難しい工程です。**

定員を超える申込みがあったとき、**優先順位をつけて割り当てます。**基準は指数などの形で公開され、**同じ指数なら何で差をつけるかまで定めておく**必要があります。

**そして、決まった後には説明があります。**なぜ入れなかったのか、なぜあの家庭が先だったのか。**基準が公開されているからこそ、説明ができます。**

**③ 払う**

児童手当、児童扶養手当、施設型給付。**認定した内容に基づいて支払います。**

**支払は期日が決まっていて、対象は数万件規模になることもあります。**一括処理の誤りは、件数分に波及します。

**④ 集める**

保育料を算定し、徴収します。**所得に応じて階層が決まる**ため、**課税資料の確定に合わせて年度途中で切り替わります。**

**⑤ 増やす・整える**

**整備の計画、施設の確認と指導監査、子ども・子育て支援事業計画の策定。**

**供給を増やすのは、基本的に事業者**です。だから、**計画で見通しを示し、整備の支援を用意し、参入を促す**という間接的な手段を使います。

## 民間の需給調整・給付管理と、どこが同じでどこが違うか

**同じところ**

**1. 需要と供給を突き合わせる**

**申込みに対して、供給が足りるか。**足りなければ、どう配分するか。**予約や割当てを扱う事業では、まったく同じ課題**です。

**2. 要件を認定して給付する**

**要件への当てはめと、支払の管理。**保険や手当の実務と同じ工程です。

**3. 供給側の質を、確認と監査で管理する**

施設の確認、指導監査。**民間でいう加盟店の審査や、委託先の品質管理**と同じ構造です。

**違うところ**

**1. 需要が読めるのに、供給を自分で作れない**

**出生数と就業の状況から、数年先の需要はかなり正確に読めます。**ところが、**保育所を建てて運営するのは事業者**です。

**「読めているのに、直接は作れない」**という制約の中で、**計画と支援で供給を引き出してきた**——これが、この経歴の特徴です。

**2. 配分の基準が公開され、説明責任がある**

民間の割当てでは、**基準を公開しないことが普通**です。抽選や先着で処理することもできます。

**この部署は、基準を公開し、個別に説明します。**「なぜこの順番なのか」を、**制度の形で答えられるようにしてきた**わけです。

**3. 断ることができない**

要件を満たす申込みを、**受け付けないという選択肢はありません。**

**需要を絞れない中で、配分の設計だけで対応してきた**という経験になります。

:::insight
子育て支援課の方が職務経歴書で損をしやすいのは、**②の「利用調整」を書かないこと**です。書類には「保育所の入所事務」とだけ書かれていて、**限られた定員を、公開された基準で配分していた**という中身が消えています。ところが、これは民間でも難易度の高い仕事です。**需要が供給を超えている状態で、誰に配るかを決め、決めた理由を説明する。**しかも、**外れた人には不満が残る**という前提で運用します。書くなら、**「年間◯件の申込みについて、公開された基準に基づき利用の調整を実施。同一の指数となる場合の優先の考え方を整理し、決定後の説明に用いる資料として文書化した」**という形で、**配分の設計として**書いてください。**「入所事務」の一語では、抽選係のように読まれます。**基準を設計し、説明に耐える形にした——**ここがこの経歴の中心です。**
:::

## 評価が高くなりやすい4つの方向

**1. 保育・教育の事業者の本部**

**確認の基準、運営の基準、給付の仕組み、指導監査で何を見られるか。**監督する側にいた経験は、**事業者側にとって直接の価値**です。

**加算の要件や、指導で指摘されやすい点**を知っている人は、**現場を経験した園長にはない角度**を持っています。**監督してきた規模（確認している施設数、指導の件数）**も書いてください。

**この方向で書くときは、扱っていた施設の種類も入れてください。**認可保育所、認定こども園、地域型保育、認可外。**種類ごとに基準も給付の仕組みも違う**ので、**複数の種類を横断して見てきた**という事実が、一つの種類しか知らない管理者との違いになります。

**2. 人材サービス（保育・教育分野）**

保育士の採用支援、人材の紹介、派遣。

**この分野の人材サービスで難しいのは、制度の理解**です。**配置の基準、資格の要件、加算に関わる人員の要件。**これを知らないと、事業者が本当に必要としている人が分かりません。

**制度側から来た人は、そこを最初から理解しています。**

**3. 自治体を顧客にする企業・子育て分野のシステム**

保育の利用調整のシステム、手当の支給のシステム、施設の管理、子育ての情報提供。

**発注する側にいた経験**に加えて、**制度の実務を知っていること**が提案の材料になります。**利用調整は仕組みが複雑で、実務を知らないと設計できません。**

[公務員の経験が活きる求人を見てみる](../?gov=1)

**4. 企業の両立支援・福利厚生**

**従業員の育児と仕事の両立**を支える役割です。

**保育の制度、手当の制度、利用の手続。**これを社内で説明できる人は、企業側に多くありません。**制度を知っていること自体が、直接の価値**になります。

:::insight
方向を決めるときに、**残る判断のほうが妥当だと感じる場面**もあります。子育て支援課は、**担当している工程によって、書ける内容がまったく変わる**部署です。手当の認定と支払だけなのか、**利用調整まで担当しているのか**、**施設の確認・指導に関わっているのか**、**整備の計画に参加したことがあるのか。**このうち、**民間でいちばん値が付くのが利用調整と、施設の確認・指導**です。利用調整は配分の設計として、確認・指導は事業者側への転職で、それぞれ直接の価値になります。まだ手当の事務が中心の段階なら、**利用調整に回ってからのほうが、選べる方向が明確に増えます。**もう一つ、**子ども・子育て支援事業計画は数年に一度しか策定されない**ので、**在籍のタイミングで経験できるかどうかが決まります。**次の策定が近いなら、それを経てからという判断もあります。在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## つまずきやすい点

**1. 「子育て支援の窓口」で丸める**

**認定・配分・給付・委託管理**は、性質の違う4つの仕事です。

**2. 利用調整を「入所事務」と書く**

**抽選係のように読まれます。****配分の設計**として書いてください。

**3. 一括処理の規模を書かない**

**手当の支払は数万件規模**になることがあります。企業の請求処理と同じ規模感で語れます。

**4. 規模を書かない**

**対象児童数、認定の件数、利用調整の申込件数、確認している施設数、年間の給付額。**公表されている資料から取れます。

**5. 個別の事案に触れる**

**世帯の状況、就労の事情、選考の結果、通告に関する情報。**すべて書けません。工程と件数で書いてください。

どの経験に値が付くかは、募集の出方で変わります。[どの経験に値が付くのかから相談できます](../apply.html)。

## まとめ

- 児童福祉法第24条は、保育を必要とする場合に、市町村が**保育しなければならない**と定めています。**義務です**
- ところが**供給は有限で、運営するのは多くの場合、民間の事業者**です。**足りないときは、基準を決めて配分し、その基準を公開して説明します**
- 民間での訳語は、**要件の認定／需給の調整と割当て／給付の認定と支払管理／委託先の監査／中期の事業計画**が中心になります
- 中核スキルは**①要件を認定する ②割り当てる ③払う ④集める ⑤増やす・整える**の5工程です
- 民間の需給調整と**同じ**なのは、需要と供給を突き合わせること・要件を認定して給付すること・供給側の質を管理すること
- **違う**のは、需要が読めるのに供給を自分で作れないこと・配分の基準が公開され説明責任があること・断ることができないことです

## よくある質問

### 保育士の資格がないと、保育の分野では働けませんか

**本部や管理の職種では、資格が前提にならないことが多くあります。**求められるのは、**制度の理解、確認と運営の基準、給付の仕組み、指導で見られる点**です。現場の保育とは別の能力として評価されます。面接では、**「保育の実務は経験していないが、制度の運用と施設の監督を担当していた」**と正確に言ってください。**役割の線をはっきりさせるほうが読まれ方がよくなります。**

### 児童手当の事務しか担当していませんが、書けることはありますか

**「大量の給付の認定と支払管理」として書けます。**対象は数万人規模になることがあり、**支払の期日が決まっていて、要件の確認と、変更への対応が常に走ります。**これは、**企業の給付金や報酬の一括支払と同じ工程**です。書くときは、**対象者数、年間の支給額、認定と変更の件数**を必ず添えてください。そのうえで、**利用調整や施設の確認に担当が広がれば、書ける内容が大きく増えます。**

### 通告や相談の対応は、どこまで書けますか

**担当していた事実と、手順までです。**「相談の受付、関係機関との連携、必要な場合の通告の手続を担当」。**ここまでにとどめてください。**件数、内容、対象者、判断の経緯。**いずれも書けません。**この分野は**扱いが最も慎重を要する情報**なので、**書類でも面接でも、自分から線を引いて示すこと**が、そのまま評価になります。
