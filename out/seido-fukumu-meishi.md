財政課で働くと、庁内の各課、他の自治体、金融機関、国の機関、事業者、監査法人など、多くの人と名刺を交換します。**転職を考えるとき、この名刺と人脈をどう扱えるかは、資料の持ち出しよりも判断が難しい問題**です。

名刺は紙1枚で、持ち出しても分からない。人脈は頭の中にあって、持ち出しという言葉が当てはまらない。それでも、**名刺に書かれた情報は、自治体の業務で得た個人情報**で、**人脈を転職先の営業に使えば、前職の立場で得た関係の利用**になります。

この記事では、**名刺と人脈の扱いを、地方公務員法第34条と個人情報保護法第67条の線で整理**します。**個人情報の扱いの細目は自治体の規程による**ので、名刺の管理のルールは所属の担当課で確かめてください。資料の持ち出しは[在職中に得た情報の持ち出し](seido-fukumu-joho.html)に書いています。

## 名刺は「業務に関して知り得た個人情報」

個人情報保護法第67条は、個人情報の取扱いに従事する行政機関等の職員**または職員であった者**が、**その業務に関して知り得た個人情報の内容をみだりに他人に知らせ、または不当な目的に利用してはならない**と定めています。

| 要素 | 名刺への当てはめ |
|---|---|
| **個人情報か** | 氏名、所属、役職、連絡先が書かれた名刺は個人情報 |
| **業務に関して知り得たか** | 自治体の職員として交換した名刺は、業務に関して知り得たもの |
| **職員であった者も対象か** | **対象。**退職後も第67条は及ぶ |
| **禁じられること** | **みだりに他人に知らせること、不当な目的に利用すること** |

第180条は、業務に関して知り得た保有個人情報を、**自己または第三者の不正な利益を図る目的で提供し、または盗用**したときの罰則（1年以下の拘禁刑又は50万円以下の罰金）です。名刺の情報を転職先の営業リストとして提供する形は、この条文との関係を考える必要があります。

**すべての名刺の利用が禁じられるわけではありません。**「みだりに」「不当な目的」「不正な利益を図る目的」が要件です。個人的な挨拶や、相手の同意を得た連絡は、これに当たらないと考えられます。線は、**相手の同意なく、転職先の営業や第三者への提供に使うこと**です。

## 名刺そのものの持ち出し

| 名刺の管理の形 | 退職時の扱い |
|---|---|
| **自治体が管理している**（名刺の管理システム、部署の共有のファイル） | 自治体の保有する個人情報。**持ち出せない** |
| **個人で管理している**（自分の名刺入れ、個人の名刺ホルダー） | 自治体の規程により、業務で得た名刺は自治体の情報として返却・廃棄を求める自治体がある。**規程を確かめる** |
| **私的な関係で交換した名刺**（勉強会、私的な集まり） | 自治体の業務で得たものではなく、個人のもの |

**多くの自治体で、業務で交換した名刺は、退職時に返却または廃棄する扱い**になっています。自分の名刺入れに入っていても、業務で得たものは自治体の情報です。規程で明確に定めていない自治体もあるので、担当課に確かめてください。**持ち出せなくても、連絡先が要る相手には、退職の挨拶の際に個人の連絡先を交換すれば足ります。**

## 人脈の扱い——「関係」は持っていける、「立場」は持っていけない

人脈は頭の中にあり、持ち出しという概念が当てはまりません。線は、**人脈を何のために、どう使うか**です。

| 使い方 | 扱い |
|---|---|
| **退職の挨拶をする** | 問題ない。業務上の相手に退職を知らせるのは通常の礼儀。**転職先の宣伝を兼ねない** |
| **個人的な関係として連絡を続ける** | 問題ない。相手が同意して個人の連絡先を交換した関係 |
| **転職先で、相手の同意を得て仕事の相談をする** | 相手が応じるなら問題ない。**前職の立場で得た非公開の情報を使わない**（第34条） |
| **転職先の営業のために、名刺の情報を使って一斉に連絡する** | **第67条の「みだりに」「不当な目的」に当たり得る。**相手の同意もない |
| **名刺の情報を転職先の営業リストに載せる、同僚に渡す** | **第67条・第180条の問題。**第三者への提供 |
| **前職の自治体の役職員に、転職先のために働きかける** | **第38条の2の対象**（離職後2年間、契約等事務に関する要求・依頼の禁止） |

**「関係」は持っていけます。前職で信頼を築いた相手が、あなた個人を信頼して連絡を続けてくれるなら、それはあなたの人脈です。「立場」は持っていけません。**財政課の職員だから会ってくれた相手に、退職後に転職先の立場で同じ扱いを求めることはできず、名刺の情報を営業に流用することは、法律の線を越えます。

## 退職の挨拶の仕方

退職の挨拶は、人脈を「関係」として持っていく、正当な機会です。

| 点 | 内容 |
|---|---|
| **誰に** | 業務上の関係があった相手。庁内、他の自治体、金融機関、事業者など |
| **何を伝えるか** | 退職すること、お世話になった礼、後任の紹介（自治体の了解の範囲で） |
| **転職先を伝えるか** | 相手との関係による。**伝える場合も、転職先の営業を兼ねない** |
| **個人の連絡先** | 相手が望めば交換する。**相手の連絡先を一方的に控えない** |
| **時期** | 退職の申出が受理され、職場が公表を了解した後。**在職中の挨拶は、自治体の職員としての挨拶** |

**挨拶の中で「転職先でもよろしく」と営業を始めることは、在職中なら職務専念義務と信用失墜行為の問題、退職後なら人脈の流用の問題**になります。挨拶は挨拶で終え、転職先での関係は、相手が望んだ場合に、退職後に改めて始める。この順序が、法律の面でも、相手との信頼の面でも正しい形です。

:::insight
面談で伺うと、**自治体向けの営業の仕事に転職した方が、在職中の名刺を全部持ち出して、転職先で「前職の人脈」として使おうとした**というケースがあります。名刺の情報は業務で得た個人情報で、相手の同意なく営業に使うことは第67条の線を越え、しかも相手からの信頼を失います。「財政課の人だと思っていたのに、営業の電話がかかってきた」という印象は、転職先の評判にも響きます。逆に、**退職の挨拶で個人の連絡先を交換し、転職後に相手から「今どうしている」と連絡が来て、そこから仕事の相談につながった**という方は、関係を人脈として正しく持っていっています。ここで1つ提案があります。**退職の挨拶で、「この人とは個人として関係を続けたい」と思う相手に、自分の個人の連絡先を渡してください。**相手の連絡先を控えるのではなく、自分の連絡先を渡す。**連絡が来るかどうかは相手が決める。**それが、名刺の情報を持ち出さずに、人脈を持っていく方法です。
:::

## 転職するとどうなるか

転職を考えている方にとって、名刺と人脈で効いてくる点は3つです。

**1. 名刺は持ち出さず、個人の連絡先を渡す**

**業務で得た名刺は自治体の情報**です。関係を続けたい相手には、退職の挨拶で自分の連絡先を渡します。

**2. 人脈は「関係」として持っていき、「立場」の流用はしない**

**相手があなた個人を信頼して続けてくれる関係は、あなたの人脈**です。名刺の情報を営業に流用すれば、法律の線を越え、信頼も失います。

**3. 前職の自治体の役職員への働きかけは、第38条の2の対象**

**人脈が古巣の職員である場合、離職後2年間、契約等事務に関する要求・依頼はできません**（[地方公務員に再就職規制はあるのか](seido-fukumu-chihou.html)）。

## 手続きと期限

| 順序 | 手続き | 時期 |
|---|---|---|
| 退職を決めたら | 自治体の名刺・個人情報の管理の規程を確かめる | 早めに |
| 退職の申出の後 | 業務上の相手に退職の挨拶。転職先の営業を兼ねない | 職場が公表を了解した後 |
| 挨拶のとき | 関係を続けたい相手に、自分の個人の連絡先を渡す。相手の連絡先を一方的に控えない | 挨拶のとき |
| 退職時 | 業務で得た名刺を、規程に従って返却または廃棄 | 退職日 |
| 退職後 | 相手から連絡があれば、個人の関係として続ける。転職先の営業に名刺の情報を使わない | 継続 |
| 退職後 | 古巣の役職員への契約等事務に関する働きかけをしない | 離職後2年間（自ら決定したものは期間なし） |

## 誤解されやすい点

**「名刺は自分が交換したものだから自分のもの」と思い込む**

**自治体の業務で得た個人情報**です（個人情報保護法第67条）。規程に従って返却・廃棄します。

**「人脈は頭の中にあるから自由に使える」と思い込む**

**関係は持っていけますが、名刺の情報の流用と、前職の立場の利用は線を越えます。**

**「退職の挨拶で転職先を宣伝してよい」と思い込む**

**挨拶は挨拶で終えます。**在職中の営業は職務専念義務と信用失墜行為の問題です。

**「退職すれば個人情報保護法は関係ない」と思い込む**

**第67条は「職員であった者」を対象**にしています。

:::insight
ここまで名刺と人脈の話を書いておいて逆のことを言いますが、**名刺を持ち出せないことは、転職の不利にはなりません。**本当の人脈は、名刺の枚数ではなく、あなた個人を信頼して連絡を続けてくれる人の数です。それでも1本の記事にしたのは、**「前職の人脈」を売りにして転職し、名刺の流用で信頼を失う方を面談で見る**からです。**自分の連絡先を渡し、連絡が来るかは相手に任せる。**それで残った関係が、あなたの人脈です。そのうえで、**自分の経験に値を付けてくれる業界の見込みと、同じ紙に並べてください。**片方だけでは比較になりません。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 業務で交換した名刺は、**自治体の業務に関して知り得た個人情報**で、個人情報保護法第67条は**「職員であった者」にも、みだりに他人に知らせること・不当な目的に利用することを禁じています**
- 名刺そのものは、**多くの自治体で退職時に返却または廃棄**する扱いです。規程を確かめてください
- 人脈は、**相手があなた個人を信頼して続けてくれる「関係」として持っていけます。**名刺の情報を転職先の営業に流用すること、前職の「立場」を転職先で使うことは、線を越えます
- **退職の挨拶で、自分の個人の連絡先を渡す**のが、名刺を持ち出さずに人脈を持っていく方法です。相手の連絡先を一方的に控えず、転職先の営業を兼ねません
- 人脈が前職の自治体の役職員である場合、**第38条の2により、離職後2年間、契約等事務に関する働きかけはできません**
- 前職の立場で得た**非公開の情報を、人脈との会話で使わないこと**は、第34条の守秘義務です

## よくある質問

### 他の自治体の財政課の担当者と、勉強会で親しくなりました。転職後も連絡を取ってよいですか

**個人の関係として連絡を続けることは問題ありません。**相手が自治体の職員であっても、勉強会で築いた個人的な関係は、あなたの人脈です。退職の挨拶で個人の連絡先を交換し、相手が連絡を続けてくれるなら、それは相手の同意に基づく関係で、個人情報保護法第67条の「みだりに」「不当な目的」には当たりません。注意するのは3点です。第1に、**転職先の営業のために、その関係を使って相手の自治体に働きかけること**は、相手の立場を難しくし、相手が自治体の職員である以上、相手の側の服務の問題にもなります。第2に、**前職で知った非公開の情報を会話で使わないこと**（第34条）。第3に、相手が自分の前職の自治体の職員であれば、**第38条の2の働きかけの規制**（離職後2年間、契約等事務に関する要求・依頼の禁止）が及びます。個人の関係と、転職先の仕事の関係を分けて、後者は相手が望んだ場合に、相手の勤務先のルールの範囲で、というのが線です。

### 転職先の上司から「前職の人脈のリストを出してほしい」と言われました。どうすればよいですか

**名刺の情報をリストにして渡すことはできません。**業務で得た名刺の情報は自治体の業務に関して知り得た個人情報で、転職先に提供することは、個人情報保護法第67条の「みだりに他人に知らせ」に当たり、営業の目的で提供すれば第180条（第三者の不正な利益を図る目的での提供）との関係も問題になります。相手の同意もありません。上司には、「公務員の個人情報保護の義務は退職後も続くので、前職で得た名刺の情報を提供することはできない」と伝えてください。**代わりに提供できるのは、自分の経験と、業界の構造の理解**です。どの部署がどういう判断をするか、どういう時期にどういう提案が通りやすいか、という仕事の進め方の知識は、個人情報でも秘密でもありません。個人の関係として続いている相手については、相手が望めば、相手の同意を得て転職先の担当者を紹介する形はあり得ますが、それも相手が決めることです。法令の理解が浅い転職先である場合、この対応がその後の信頼にも関わるので、はっきり伝えるのが得です。

### 退職の挨拶で、転職先を伝えてよいですか

**相手との関係によりますが、伝えること自体は問題ありません。転職先の営業を兼ねないことが線です。**業務上の相手に退職を知らせ、礼を述べ、後任を紹介するのが挨拶で、その中で「次は○○で働きます」と伝えることは、通常の範囲です。避けるべきなのは、「転職先でもぜひよろしく」「今度、提案に伺います」と、挨拶の中で営業を始めることで、在職中なら職務専念義務（第35条）と信用失墜行為の禁止（第33条）の問題、退職後なら前職の立場の流用の問題になります。転職先が自治体向けの企業で、相手が将来の顧客になり得る場合は、なおさら挨拶と営業を分けてください。**挨拶は挨拶で終え、自分の個人の連絡先を渡し、連絡が来たら個人の関係として応じ、仕事の話は相手が望んだときに、相手の勤務先のルールの範囲で。**この順序を守った方は、転職後も前職の相手との関係が続き、業界によっては仕事につながっています。
