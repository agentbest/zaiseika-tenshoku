保健所や衛生課の経験を、職務経歴書にどう書けばよいか。ここでつまずく方が多いのは、**「保健所」と書いた瞬間に、読む側の想像が「健康相談の窓口」で止まる**からです。

「保健所において衛生行政に従事」と書くと、**役所で健康の相談を受けていた人**に読まれます。実際には、**飲食店や食品工場に立ち入って検査し、営業の許可を出し、食中毒や感染症が出れば原因を追い、精神保健や母子保健の相談を受け、統計を取り、市町村や医療機関の間を調整していた**わけですが、それが伝わりません。

この記事では、**民間での訳語**と、**中核スキルの分解**を並べます。

## 「企画、調整、指導」と14の事項が並んでいます

まず、この仕事の立ち位置を条文で押さえます。**地域保健法第6条**です。

> 保健所は、次に掲げる事項につき、企画、調整、指導及びこれらに必要な事業を行う。
> 一 地域保健に関する思想の普及及び向上に関する事項
> 二 人口動態統計その他地域保健に係る統計に関する事項
> 三 栄養の改善及び食品衛生に関する事項
> 四 住宅、水道、下水道、廃棄物の処理、清掃その他の環境の衛生に関する事項
> 五 医事及び薬事に関する事項

この後、**保健師、公共医療、母子と老人の保健、歯科、精神保健、難病、感染症、試験検査**と続き、**14の事項**が列挙されています。

**ここが、この仕事の性格を決めています。**

**扱う事項が、14もある。**しかも、条文の頭に書かれているのは、**「企画、調整、指導」**です。**自分で全部やるのではなく、企画して、関係者を調整して、指導する。**

つまり、**この経歴の方は、「健康に関わることなら何でも、関係者を動かして進める」という条件で働いてきた**ことになります。**食品の工場も、病院も、薬局も、飲食店も、市町村も、相手です。**

民間で人を採る側から見ると、これは**「規制の側にいて、しかも複数の業種を横に見てきた人」**です。**品質保証、コンプライアンス、産業保健、危機管理、渉外**——**同じ骨の仕事は、民間にいくつもあります。**

## 民間での訳語

| 行政での言い方 | 民間での言い方 |
|---|---|
| 食品衛生監視 | 品質保証、衛生監査、サプライヤー監査 |
| 営業の許可と施設の検査 | 許認可の対応、施設の基準の適合の確認 |
| 食中毒の調査 | 原因の究明、是正措置、再発の防止 |
| 感染症の発生時の対応 | 危機の管理、事業の継続計画、初動の設計 |
| 積極的疫学調査 | 調査の設計、データの分析、原因の特定 |
| 環境衛生の監視（旅館・公衆浴場・理美容） | 施設の衛生管理、多店舗の監査 |
| 医事・薬事の監視 | 薬事、医療機関との渉外、法令の遵守 |
| 保健指導・健康相談 | 産業保健、健康経営、保健事業 |
| 精神保健の相談 | メンタルヘルスの支援、従業員支援 |
| 人口動態統計・地域診断 | データの分析、健康課題の可視化 |
| 衛生上の試験検査 | 品質管理、分析、検査の実務 |
| 市町村・医療機関との連絡調整 | 関係機関との調整、地域連携 |
| 住民への普及啓発 | 健康教育、広報、研修の企画 |

**この表を職務経歴書にそのまま貼る必要はありません。**ただ、**自分がやっていたことに、民間で通じる名前が付いている**ことは、知っておいてください。

## 中核スキルを5つの工程に分ける

**この経歴の中核は、「基準で確かめ、外れたら止め、原因を追い、関係者を動かす」ことです。**5つの工程に分けます。

**工程1：見る**

人口動態統計、届出、相談の記録。**地域の健康の状態を、数字と届出から把握します。**

**この工程に固有の制約があります。****数字が来るのを、待つ側ではない**ということです。医師の届出、飲食店からの報告、住民からの相談。**来た情報を集めるだけでは足りず、来ない情報を取りに行く。**この地域で何が増えているか、どの施設に問題があるか。**兆しを先に見つける仕事**です。これは、**品質の管理でいう「傾向の監視」と同じ**で、民間でもそのまま求められます。

**工程2：許す**

営業の許可、届出の受理、施設の検査。**基準に合っているかを確かめて、営業を認めます。**

**この工程に固有の制約があります。****基準に合えば、許可しなければならない**ということです。好き嫌いで決められない。**逆に、合わなければ、相手がどれだけ困っていても認められない。**この「基準で判断する」経験は、**民間の許認可の対応や、取引先の認定で、そのまま効きます。**

**工程3：確かめる**

立入検査、監視、収去、指導。**営業が始まった後も、基準の内側にあるかを確かめ続けます。**

**この工程に固有の制約があります。****相手の事業所に、自分が入っていく**ということです。相手は、来てほしくない。それでも入って、見て、直すべき点を伝える。**関係を壊さずに、指摘する技術**です。これは、**民間の監査や、サプライヤーの品質の管理で、いちばん求められる部分**です。

**工程4：止める**

食中毒や感染症が出たときの初動、営業の停止、原因の調査。**影響が広がる前に止めて、原因を追います。**

**この工程に固有の制約があります。****止める判断が、相手の営業に直結する**ということです。しかも、**原因が確定する前に、止めなければならない場面がある。**確定を待てば、被害が広がる。**確定していない段階で判断し、その後で原因を追って、説明する。**この形の危機の対応は、**食品でも、製薬でも、製造でも、同じ課題**です。

**工程5：つなぐ**

市町村、医療機関、学校、福祉、警察。**保健所は、自分だけでは完結しません。**

**この工程に固有の制約があります。****相手に命令できない場面が多い**ということです。市町村には助言、医療機関には協力の依頼。**指示ではなく、調整で動かす。**この経験は、**民間でいえば、関係機関との渉外、地域連携、複数の部門をまたぐ調整**に当たります。**権限がないところで動かしてきた人**は、民間の管理部門で希少です。

:::insight
この5つの工程のうち、**職務経歴書でいちばん書かれていないのが、工程3**です。面談で伺うと、**「食品衛生監視員として監視指導を行っていました」**という一行で終わってしまいます。ところが、中身を聞くと、**年間で数百の施設に立ち入り、施設の基準と衛生管理の記録を確認し、不備があれば改善の期限を切って、再度確かめに行っていた**という話が出てきます。**これは、監査そのもの**です。民間でいえば、**サプライヤー監査、工場の衛生監査、多店舗の品質の確認**に当たります。**「監視指導」という言葉は、求人票にはまったく出てきません。**同じ仕事は、**「品質保証」「監査」「QA」**と書かれています。書くなら、**「年間約◯施設の立入検査を担当。施設の基準と衛生管理の記録を確認し、不備約◯件について改善の指導と再確認を実施」**という形です。**件数が入ると、監査の経験として読まれます。**この一行があると、**食品の会社の品質保証の部門で、読まれ方が変わります。**
:::

## 民間の品質保証・産業保健と、どこが同じでどこが違うか

**同じ点は3つあります。**

- **基準に対する適合を、検査と記録で確かめている**こと
- **外れたときの初動と原因の究明を、手順として持っている**こと
- **複数の関係者を、権限ではなく調整で動かしている**こと

**違う点は4つあります。**

| 違い | 行政（保健所・衛生課） | 民間（品質保証・産業保健） |
|---|---|---|
| 相手を選べるか | 管内の全施設・全住民が相手 | 自社と取引先に限られる |
| 立場 | 規制する側。立ち入り、止められる | 規制される側。行政の立入りを受ける |
| 判断の根拠 | 法令と基準。裁量は小さい | 法令に加えて、自社の方針と取引先の要求 |
| 利益の扱い | 目的ではない | 品質と利益の両立が求められる |

**この4つのうち、移った後にいちばん効くのは、2番目**です。**規制する側にいた人**は、**規制される側に回ると、「行政が何を見に来るか」を知っている担当になります。**食品の会社でも、製薬でも、**この知識を外部から採るのは難しい。**

**もう1つ、効き方が大きいのは4番目**です。行政では、**基準を満たすかどうかだけを見ていました。**民間では、**基準を満たしたうえで、コストと納期も見ます。**ここは、**移った後に足される部分**です。**ただし、足されるだけ**です。**基準で判断する軸そのものは、変わりません。**

## 評価が高くなりやすい4つの方向

**1. 食品メーカー・外食チェーンの品質保証**

**立入検査、施設の基準、食中毒の初動。**規制する側の経験が、そのまま効きます。

**2. 製薬・医療機器・薬局チェーンの薬事**

**医事と薬事の監視、許認可の対応。**行政との折衝を知っている人が求められます。

**3. 産業保健・健康経営の支援**

**保健指導、精神保健の相談、健康課題の分析。**保健師や管理栄養士の免許がそのまま効きます。

**4. 衛生管理のコンサルティング・検査機関**

**基準の解釈、記録の設計、研修の企画。**行政の側で指導してきた人が、そのまま指導する側に回れます。

**なお、この4方向は、求める経験が違います。**1番と4番は、**食品と環境の衛生**を見ます。2番は、**医事と薬事**を見ます。3番は、**保健指導と相談**を見ます。**同じ保健所の経歴でも、食品衛生監視員か、薬事の担当か、保健師かによって、通りやすい方向が変わる**ということです。**自分がどの工程を長くやってきたかを、先に整理しておいてください。**

どの経験に値が付くのかから、[相談できます](../apply.html)。在職中でも、情報収集だけでも構いません。

## つまずきやすい点

**1. 「衛生行政に従事」で丸める**

**見る／許す／確かめる／止める／つなぐ**の5つに分けてください。

**2. 件数を書かない**

**立入の施設数、許可の件数、相談の件数、調査した事案の数。**桁だけでも入れてください。

**3. 監視指導を、事務として書く**

**監査**です。**基準と記録を確認し、改善を指導し、再確認した**と書いてください。

**4. 食中毒や感染症の対応を、苦労話にする**

**確定前に止める判断と、その後の原因の究明を、手順として運用していた**と書いてください。

**5. 調整の経験を書き落とす**

**権限のない相手を、調整で動かしてきた**経験です。**民間の管理部門で希少です。**

:::insight
この経歴の方に、**最初に確かめていただきたい数字が4つ**あります。**管内の人口、年間の立入の施設数、許可と届出の件数、相談の件数**です。この4つが並ぶと、**書類の読まれ方が変わります。**「保健所において衛生行政に従事」と書かれた1行と、**「管内人口約◯万人の保健所において、食品営業施設約◯施設を対象に年間約◯件の立入検査、約◯件の営業許可の審査、食中毒の調査◯件を担当」**という1行では、**読む側が想定する仕事の規模が違うから**です。**これらは所内の統計にある数字**なので、**在職中に控えておけば足ります。**もう1つ。**この経歴は、免許を持っている方が多い経歴**です。獣医師、薬剤師、保健師、管理栄養士。**免許は、それ自体が求人票の条件に書かれています。**ただし、**免許だけで読まれると、「行政にいた免許の人」で止まります。****免許の隣に、規制する側で何を見てきたかを置く。**この組み合わせが、民間でいちばん採りにくい経歴です。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 地域保健法第6条は、**保健所が「企画、調整、指導」を行う事項を14項目にわたって列挙**しています。食品衛生、環境衛生、医事薬事、母子保健、精神保健、感染症、試験検査などです
- つまり、**保健所・衛生課は「健康に関わることなら何でも、関係者を動かして進める」仕事**をしています
- 民間での訳語は、**品質保証、監査、許認可の対応、危機の管理、産業保健、渉外**です
- 中核スキルは、**①見る ②許す ③確かめる ④止める ⑤つなぐ**の5工程に分けられます
- 民間との違いは、**相手を選べるか、規制する側かされる側か、判断の根拠、利益の扱い**の4点です
- 先に、**管内の人口・立入の施設数・許可の件数・相談の件数**の4つを控えてください

## よくある質問

### 事務職で、監視員や保健師の資格はありません

**それでも書けます。**保健所の事務は、**営業許可の申請の受付と審査、届出の処理、各種の統計の集計、医療機関や市町村との連絡調整、予算と契約、感染症の発生時の事務局**など、**免許がなくても担っている部分が広くあります。**とくに、**感染症の発生時に、相談の窓口や関係機関との調整の事務局を回した経験**は、**民間でいえば危機の対応の事務局**です。書くなら、**「営業許可の申請約◯件の受付と審査の事務、感染症の発生時の相談窓口と関係機関との調整の事務局を担当。技術上の判断は監視員と保健師が実施」**と、**自分の範囲を明示してください。**

### 保健師で、相談の仕事が中心です。民間で通じるのは産業保健だけですか

**産業保健は、いちばん近い方向ですが、1つではありません。**保健師の仕事は、**個別の相談と、地域の健康課題の分析と、関係機関との調整**の3つでできています。**このうち後ろの2つが、民間で見落とされやすい部分**です。健康課題の分析は、**データから優先順位を決める仕事**で、健康経営の企画に直接つながります。関係機関との調整は、**医療機関、学校、福祉をまたいで動かしてきた経験**で、民間の管理部門や、地域包括の事業を手がける会社で読まれます。**相談の件数だけでなく、分析と調整の実績を並べる**と、行き先が広がります。

### 保健所の人員が減っていて、業務が回りません。この経験は評価されますか

**むしろ、限られた人員で幅の広い事項を回してきたこと自体が、経験として読まれます。**14の事項を、少人数で担っている保健所は多くあります。**「営業許可、立入検査、食中毒の調査、環境衛生の監視を、◯人で管内◯施設について担当」**という書き方をすると、**一人が見る範囲の広さが伝わります。**民間の品質保証の部門も、**少人数で複数の工場や店舗を見ている**ことが大半で、**幅の広さは歓迎される側**です。ただし、**負荷が高かったことと、経験が薄いことは別**です。負荷を苦労話にせず、**回していた範囲と件数**で書いてください。行き先の分け方は[保健所・衛生課から転職しやすい業界と職種](dept-hoken-tenshokusaki.html)に整理しています。
