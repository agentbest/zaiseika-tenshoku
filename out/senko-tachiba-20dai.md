**採用されてから数年の段階で、今後を考える方がいらっしゃいます。**

**在職の年数が短いことを、不安に感じている**という相談です。

この記事では、**評価される点**と、**書類の組み立て**を扱います。

## 年齢による扱いには、法律上の定めがあります

**労働施策の総合的な推進並びに労働者の雇用の安定及び職業生活の充実等に関する法律第9条**です。

> **事業主は**、労働者がその有する能力を有効に発揮するために必要であると認められるときとして厚生労働省令で定めるときは、**労働者の募集及び採用について**、厚生労働省令で定めるところにより、**その年齢にかかわりなく均等な機会を与えなければならない。**

**募集と採用について、年齢にかかわりない均等な機会**が定められています。

**例外は、厚生労働省令で定める場合に限られる**構造です。

**求人票に年齢の記載がある場合、その理由が示されていることがあります。**

**年齢そのものより、求められている経験が自分に当てはまるか**を見てください。

## 何が見られているか

| 項目 | 内容 |
|---|---|
| ① 基礎的な事務の処理 | 正確さ、期限の管理 |
| ② 制度や手順の理解 | 規程に沿って処理してきた経験 |
| ③ 対外の対応 | 住民・事業者への説明 |
| ④ 学ぶ速さ | 新しい制度への対応の経験 |
| ⑤ 定着の見込み | **なぜ変わるのかの説明** |

**⑤が要**です。

**在職の年数が短い場合、理由の説明が求められることがあります。**

**これは、責められているのではなく、確認されている**という位置づけです。

**「次も短くならないか」という関心**に答えれば足ります。

## 理由の組み立て

| 避けたい書き方 | 置き換え |
|---|---|
| 仕事が合わない | **担当した業務の中で、続けたい部分と、続けにくい部分を分ける** |
| 人間関係 | 業務の進め方の話に置き換える |
| やりがいがない | 何をしたいかを具体的に書く |
| 将来が不安 | 何を身につけたいかを書く |

**1行目です。**

**「合わない」の中身を分けてください。**

**業務の量なのか、扱う内容なのか、判断の範囲なのか、対外の対応なのか。**

**分けると、次に求める条件が決まります。**

**そして、条件が決まっていれば、「次も短くならない」理由の説明になります。**

## 経験が短い場合の職務経歴書

| 項目 | 書き方 |
|---|---|
| 在籍の期間 | そのまま書きます |
| 担当した業務 | **件数、対象、範囲を具体に** |
| 使った制度・システム | 名称と、何をしたか |
| 対外の対応 | 相手と、内容 |
| 改善した点 | **小さくても書く** |

**2行目です。**

**年数が短くても、扱った件数や対象は書けます。**

**「窓口の対応を担当」ではなく、「窓口で年間約◯件の申請を受け付け、要件の確認と決定の起案を担当」**と書く。

**5行目について。**

**様式を直した、記入例を作った、確認の手順を書き出した。**

**規模が小さくても、自分で動いた事実**になります。

**書き方は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 経験の少なさを補うもの

| 補うもの | 内容 |
|---|---|
| 条件の明確さ | **何を求めているかが決まっている** |
| 準備の具体性 | 調べた内容、質問の用意 |
| 制度の理解 | 行政の仕組みを知っている |
| 資格・学習 | 取得したもの、学んでいること |

**1行目です。**

**経験が短い方ほど、条件がはっきりしていることが効きます。**

**何をしたいか、どの領域で働きたいか、どこまでできるか。**

**これが言葉になっていると、判断がしやすくなります。**

:::insight
在職の年数が短い方のご相談で、**面談でお伝えしているのが「短いこと自体を説明しようとしないでください」**という点です。多くの方が、**「まだ◯年ですが」から話し始めます。**ところが、**聞かれているのは年数ではなく、何をしてきたかと、次に何をしたいか**です。年数の話から始めると、**その後の説明も、弁解の形になります。**代わりに、**担当した業務を具体的に説明してください。**「年間◯件の申請を処理し、要件の確認と決定の起案を担当しました」。**これは、年数に関係なく事実です。**そのうえで、**次に求める条件を述べる。**この順序であれば、**年数は話の前提にすぎなくなります。**そして、**行政の仕組みを知っていること自体が、経験の一部**です。予算の年度、議会の時期、決裁の流れ。**これは、外から入った人には見えにくいものです。**年数が短くても、**この理解は身についています。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 準備の順序

| 順 | やること |
|---|---|
| 1 | 担当した業務を書き出す（件数・対象・範囲） |
| 2 | **続けたい部分と、続けにくい部分を分ける** |
| 3 | 次に求める条件を決める |
| 4 | 求人を読む |
| 5 | 職務経歴書を作る |
| 6 | 条件に合うものに応募する |

**2が要**です。

**この作業は、転職しない場合にも意味があります。**

**続けにくい部分が、配置の変更で解消する**こともあります。

**その場合、異動の希望として整理**できます。

**判断は、材料が揃ってからで差し支えありません。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 業務の記録 | 件数、対象、担当した範囲 |
| 制度の確認 | 退職の手続き、退職手当の扱い |
| 求人を読む | 週に30分で足ります |
| 資格・学習 | 業務に関わるもの |

**1行目です。**

**日々の業務の件数や範囲は、後から思い出しにくい**ものです。

**今のうちに記録しておくと、書類を作るときに使えます。**

**これは、転職しない場合にも、人事評価の資料として使えます。**

**記録は、月に1回、数行で足ります。**

**担当した件数と、その月に新しく扱ったこと。**

**この2つを残しておくだけで、材料になります。**

## 残るという判断

| 場面 | 考えること |
|---|---|
| 異動の可能性がある | **次の配置で状況が変わるか** |
| 経験を積みたい分野がある | その分野に配置される見込み |
| 資格・研修の機会 | 在職中に得られるもの |
| 条件を比べた結果 | いまのほうが合っている場合 |

**1行目です。**

**役所では、数年で配置が変わることがあります。**

**続けにくい部分が、配置の変更で解消する**なら、**残る理由になります。**

**条件を並べた結果、いまのほうがよいと分かることもあります。**

**それは、検討が無駄だったという意味ではありません。**

## よくある失敗

**1. 年数の説明から始める**

**何をしてきたか**から話してください。

**2. 「合わない」の中身を分けない**

**次の条件が決まりません。**

**3. 件数や範囲を書かない**

**年数が短くても書けます。**

**4. 小さな改善を書かない**

**自分で動いた事実**になります。

**5. 異動の可能性を計算に入れない**

**配置で解消する場合があります。**

**6. 業務の記録を残さない**

**後から思い出しにくくなります。**

**7. 条件を決めずに応募する**

**定着の見込みの説明ができません。**

:::insight
ここまで進め方の話をしておいて逆のことを言いますが、**急いで決める必要はありません。**面談で拝見していると、**「若いうちのほうが動きやすい」と聞いて、焦って進めようとする方**がいらっしゃいます。ところが、**条件が決まっていない状態で応募すると、次も同じ理由で続きにくくなります。**先にすべきは、**何が続けにくかったのかを言葉にすること**です。この作業には時間がかかります。**業務の量だったのか、扱う内容だったのか、判断の範囲だったのか。**日々の中で感じたことを書き留めていくと、**数か月で輪郭が出てきます。**そして、**その間に異動があれば、状況が変わることもあります。**在職中であれば、**待つことに費用はかかりません。**求人を読む、制度を確認する、業務を記録する。**これらは並行してできます。****判断は、材料が揃ってからで差し支えありません。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **労働施策総合推進法第9条**は、**募集及び採用について、年齢にかかわりなく均等な機会を与えなければならない**と定めています。**例外は省令で定める場合に限られます**
- 見られているのは、**基礎的な事務の処理、制度の理解、対外の対応、学ぶ速さ、定着の見込み**です
- **「なぜ変わるのか」の説明**は、責められているのではなく確認されています
- **「合わない」の中身を、業務の要素に分けて**ください
- 年数が短くても、**件数・対象・範囲**は書けます。**小さな改善も書いて**ください
- **年数の説明から始めない**でください
- **異動で状況が変わる可能性**も、判断の材料に入れてください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 3年は続けるべきだと言われます

**判断はご本人のものです。**年数についての一般論より、**自分の状況を材料で見てください。**材料は3つです。1つは、**続けにくい部分が、配置の変更で解消するかどうか。**異動の周期と、自分の希望が通る可能性を確認してください。2つ目は、**その分野で身につくものが、まだあるかどうか。**3つ目は、**条件の合う求人が、いま存在するかどうか**です。**この3つを並べると、判断ができます。**なお、**年数が短いことが選考で問われることはあります。**ただし、**問われるのは理由の説明**であって、**年数そのものではありません。**説明ができる状態になっているかで判断してください。

### 書くことが少なく、職務経歴書が埋まりません

**業務を分解してください。**「窓口の対応」は、**受付、要件の確認、書類の点検、システムへの入力、決定の起案、通知の発送、問い合わせへの回答**に分けられます。**それぞれについて、件数、対象、期間を書く**と、分量が出ます。また、**担当した制度の名称と、その制度で何を判断していたか**を書いてください。さらに、**使ったシステム、作成した資料、参加した研修**も材料になります。**年数ではなく、扱った範囲で書く**のが基本です。埋まらない場合は、**1日の業務の流れを時系列で書き出す**ところから始めてください。

### 未経験の職種に応募できますか

**応募条件によります。**求人票の「必須」の欄を見てください。**業界や職種の経験が必須とされている場合、応募が難しい**ことがあります。一方、**「基礎的な事務の経験」「顧客折衝の経験」「行政での実務経験」**が挙げられている場合、**該当します。**行政が相手の事業では、**行政の実務経験が要件として挙げられている**ことがあります。**この場合、年数の短さより、経験の中身が見られます。**探し方は[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)に整理しています。**条件を読んでから判断**してください。
