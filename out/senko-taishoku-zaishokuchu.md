転職を考え始めたときに、**最初に迷う点**です。

**在職しながら探すか、退職してから探すか。**

**民間から民間への転職**でも論点になりますが、**公務員の場合は、制度の面で決定的な違いがあります。**

この記事では、**その違いと、判断の考え方**を扱います。

## 失業給付は、支給されません

**まず、制度の前提を確認します。**

**雇用保険法第6条**は、**適用除外**を定めています。**第6号**です。

> **国、都道府県、市町村その他これらに準ずるものの事業に雇用される者**のうち、離職した場合に、他の法令、条例、規則等に基づいて支給を受けるべき諸給与の内容が、**求職者給付及び就職促進給付の内容を超える**と認められる者であつて、厚生労働省令で定めるもの

**この規定により、地方公務員には雇用保険が適用されないのが通常**です。

**つまり、退職しても失業給付は支給されません。**

**民間の会社を辞めた場合との、いちばん大きな違い**です。

**退職してから探す場合、収入がない期間を自分の蓄えで賄うことになります。**

**この点を理解したうえで判断してください。**

## 在職中に探す場合

| 利点 | 欠点 |
|---|---|
| **収入が続く** | 面接の日程が組みにくい |
| 期間の制約がない | 書類を作る時間が限られる |
| **条件が合わなければ見送れる** | 活動が長期化しやすい |
| 残る判断もできる | 職場に知られる心配がある |

**1つ目と3つ目が、大きい利点**です。

**収入があるぶん、条件の合わない求人を見送れます。**

**「早く決めなければ」という圧力が働かないため、判断の質が保てます。**

## 退職してから探す場合

| 利点 | 欠点 |
|---|---|
| 時間を自由に使える | **収入がない**（失業給付も出ない） |
| 面接の日程を組みやすい | 期間の制約が生じる |
| 準備に集中できる | **条件を妥協する材料**になる |
| 入社の時期を選べる | 離職期間の説明が必要になる |

**2つ目と3つ目に注意してください。**

**蓄えの範囲で決めなければならなくなると、条件の合わない先に妥協する材料**になります。

**面談で伺っていると、この形で入社して、短期間で再び動くことになった方**がいらっしゃいます。

## 退職後に生じる負担

**収入が途切れること以外にも、退職後には手続きと支出が生じます。**

| 項目 | 内容 |
|---|---|
| 健康保険 | 共済組合の任意継続か、国民健康保険か。**保険料の負担が生じます** |
| 年金 | 厚生年金から国民年金へ。**保険料の納付が必要**です |
| 住民税 | 前年の所得に対して課税されます。**収入がなくても納付が必要**です |
| 各種の手続き | 市区町村の窓口、年金事務所での手続き |

**3つ目が、見落とされやすい点**です。

**住民税は、前年の所得に対して課税される仕組み**です。**退職した年の翌年も、納付が生じます。**

**収入がない期間に、前年の所得に対する税を納めることになります。**

**扱いは個別の事情によるため、市区町村の窓口と、所属の給与の担当で確認**してください。

**これらの負担を見込んだうえで、支えられる期間を計算してください。**

## 判断の材料

| 問い | 判断 |
|---|---|
| 収入がない期間を、どのくらい支えられるか | **半年分あるか** |
| 在職中に面接の日程を組めるか | 画面越しの面接が使えるか |
| 退職の時期に制約があるか | 規程、引継ぎ、繁忙期 |
| 健康上の事情があるか | 療養が必要なら、別の判断 |

**1つ目が出発点です。**

**転職活動は、数か月かかるのが通常**です。**在職中であれば、時間の制約があるぶん、さらに長くなります。**

**その期間を、収入なしで支えられるかを先に確認してください。**

## 原則は、在職中

**制度の面から考えると、在職中に探すほうが合理的です。**

| 理由 | 内容 |
|---|---|
| ① 失業給付がない | **収入が途切れる** |
| ② 判断の質 | 妥協する材料が生まれない |
| ③ 残る選択肢 | **比べたうえで、残る判断もできる** |
| ④ 説明の負担 | 離職期間の説明が要らない |

**③について補足します。**

**在職中であれば、「やはり残る」という判断ができます。**

**退職してしまうと、その選択肢はありません。**

:::insight
在職中に探すことの利点で、**面談でいちばん実感されるのが「断れること」**です。条件が合わない、仕事の内容が想定と違う、面接で違和感があった。**在職していれば、見送る判断ができます。**一方、**退職して収入がない状態だと、「とりあえず決めなければ」という圧力が働きます。**面談で伺った例では、**退職後3か月で貯えが減り、条件を下げて決めた方**がいらっしゃいました。その後、**1年以内に再び転職活動をすることになっています。**つまり、**急いで決めたことが、結果的に遠回りになった**わけです。**雇用保険法第6条により、公務員には失業給付がありません。**この制度の違いは、**民間からの転職を前提にした一般の助言では触れられないことが多い**です。**在職中に探すことを、原則としてください。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 退職してから探すほうがよい場合

**例外もあります。**

| 状況 | 理由 |
|---|---|
| 健康上の事情がある | **療養が優先**です |
| 家族の事情で、勤務の継続が難しい | 介護など |
| 資格の取得に専念する必要がある | 実務経験の要件を満たした後など |
| 在職中に日程がまったく組めない | 業務の性質による |

**4つ目は、実際には少ない**です。

**画面越しの面接と、勤務時間の後の枠を使えば、多くの場合は調整できます。**

**組み方は**[平日日中の面接をどう調整するか](senko-mensetsu-jikan.html)**にあります。**

**「日程が組めない」と決める前に、確認してください。**

## 折衷の進め方

**「在職中か退職後か」の二択ではない進め方**もあります。

| 形 | 内容 |
|---|---|
| 在職中に応募し、内定後に退職 | **いちばん多い形**。収入が途切れません |
| 在職中に情報収集だけ進める | 求人を見る、書類を作る。応募は後で |
| 退職の時期を決めてから応募 | 退職が先に決まっている場合（介護など） |
| 休職からの復帰に合わせる | 療養中で、復帰の見込みがある場合 |

**2つ目は、動き出す前の段階で有効**です。

**応募しなくても、求人を見ることはできます。**書類を作ることもできます。

**「探す」と「応募する」を分けて考えると、始めやすくなります。**

**面談で伺っていると、「まだ決めていないので相談できない」とおっしゃる方**がいますが、**決めていない段階のほうが、整理する意味があります。**

## 在職中の制約への対処

| 制約 | 対処 |
|---|---|
| 面接の日程 | **画面越しの面接**が可能か確認 |
| 書類を作る時間 | **1通目に休日を半日**使う |
| 応募先ごとの調整 | 15〜30分で済む形にしておく |
| 職場に知られる心配 | **3つの線を守る**（勤務時間・資源・情報） |

**4つ目は**[在職中の転職活動で守るべきこと](senko-taishoku-himitsu.html)**にあります。**

[経験の言い換えから相談する](../apply.html)こともできます。

## よくある失敗

**1. 失業給付が出ると思っている**

**雇用保険法第6条**により、公務員には適用されません。

**2. 蓄えを確認せずに退職する**

**半年分あるか**を先に確認してください。

**3. 「日程が組めない」と決めつける**

**画面越しの面接**を確認してください。

**4. 退職後の期間を短く見積もる**

**数か月かかるのが通常**です。

**5. 残る選択肢を捨てる**

**在職中なら、比べたうえで残れます。**

**6. 一般の助言をそのまま当てはめる**

**制度の前提が違います。**

:::insight
ここまで在職中を勧めておいて逆のことを言いますが、**在職中の活動には、精神的な負担があります。**面談で伺っていると、**「決まっていない状態を抱えたまま働くのがつらい」**という声を聞きます。業務をこなしながら、夜や休日に書類を作り、休暇を取って面接を受ける。**これが数か月続きます。**対処としては、**期間を区切ること**です。「3か月やってみて、そこで一度見直す」と決めておくと、**終わりが見えます。**そして、**進んでいないと感じたら、一度止めて構いません。**応募を止めて、求人を見ることだけ続ける、という形でも足ります。**在職中である以上、急ぐ理由は多くありません。**焦らずに続けられることが、**在職中に探すことの本来の利点**です。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **雇用保険法第6条**の適用除外により、**地方公務員には雇用保険が適用されないのが通常**です。**退職しても失業給付は支給されません**
- **原則は、在職中に探す**ことです。収入が続き、判断の質が保てます
- **在職中なら、条件が合わなければ見送れます。**残る判断もできます
- 退職してから探す場合、**収入がない期間を支えられるか**を先に確認してください
- **療養や介護が必要な場合**は、退職してからの判断にも理があります
- **「日程が組めない」と決める前に、画面越しの面接が可能かを確認**してください

## よくある質問

### 退職手当があるので、しばらくは生活できます

**退職手当は、支給の時期を確認してください。**退職の日の直後に支給されるとは限りません。**所属の規程で、支給の時期が定められています。**また、**退職所得には課税の仕組みがあります。**手取りの額を確認したうえで、**何か月分に相当するか**を計算してください。そのうえで、**転職活動が想定より長引く可能性**も見込んでください。**数か月かかるのが通常**です。なお、**退職手当を生活費として使うと、次の転職や老後の備えに影響**します。**在職中に探せるなら、そのほうが確実**です。

### 在職中だと、応募先に迷惑をかけませんか

**迷惑にはなりません。**中途採用では、**在職中の応募者が多数**です。応募先も、**入社まで数か月かかることを前提に採用の計画を立てています。**ただし、**入社可能な時期を明確に伝えてください。**「◯月◯日に入社できます」と言える状態であれば、**その日が2か月後でも問題になりません。**曖昧なまま進めるほうが、調整が難しくなります。時期の決め方は[入社日の決め方](senko-mensetsu-nyushabi.html)にあります。

### 退職してから探すと、不利になりますか

**離職期間の長さによります。**数か月であれば、**理由を1文で説明できれば問題になりません。**一方、**1年以上になると、その期間に何をしていたかを具体的に聞かれます。**説明の仕方は、次の記事で整理します。なお、**離職していること自体が不利になるわけではありません。**療養、介護、資格の取得。**理由が説明できれば、受け止められます。**心配すべきなのは、**期間の長さより、説明できるかどうか**です。
