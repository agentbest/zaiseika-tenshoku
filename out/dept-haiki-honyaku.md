廃棄物・清掃課の経験は、求人票の言葉に直すと**まったく別の名前**で呼ばれています。

**「ごみの収集、処理施設に関する業務」**

**この書き方では、民間の採用担当には何も伝わりません。**

実際にやっていたのは、**将来の発生量を見込んで、それに合わせて設備と体制を決める**という仕事です。

**しかも、その設備は数十年使うものです。**

この記事では、**庁内の呼び名を民間の言葉に置き換え、中核スキルを5つの工程に分けて**整理します。

## 「発生量及び処理量の見込み」を、計画に定めます

最初に、この仕事の性格を条文で押さえます。**経験の値を決める部分**です。

廃棄物の処理及び清掃に関する法律第6条は、こう定めています。

**市町村は、当該市町村の区域内の一般廃棄物の処理に関する計画（以下「一般廃棄物処理計画」という。）を定めなければならない。**

**そして第2項は、計画に定める事項として、こう挙げています。**

**一 一般廃棄物の発生量及び処理量の見込み／二 一般廃棄物の排出の抑制のための方策に関する事項／三 分別して収集するものとして……**

**一号を読んでください。**

**「発生量及び処理量の見込み」。**

**将来どれだけ出るかを、予測して、計画に書く。****これが法律で義務づけられています。**

**ここが要点です。**

**そして、この見込みが、すべての土台になります。**

- **施設の処理能力**（どれだけの規模で建てるか）
- **最終処分場の容量**（何年もつか）
- **収集の車両と人員**（何台、何人で回るか）
- **委託の規模と費用**（いくらの契約にするか）

**見込みを誤ると、施設が足りなくなるか、過大な設備を数十年抱えることになります。**

**民間でいえば、これは需給の計画です。**

**そして、施設の建設は、装置産業の設備投資とまったく同じ判断**をしています。**数十億から数百億の投資を、30年先の需要の見込みに基づいて決める。**

**この判断の内側にいた**——**それが、この経歴の値です。**

## 民間での訳語

| 庁内での呼び名 | 民間での呼ばれ方 |
|---|---|
| 一般廃棄物処理計画の策定 | **需給計画・中期の生産計画** |
| 発生量の見込み | **需要予測** |
| 施設の整備計画 | **設備投資の計画** |
| 処理能力の設定 | **生産能力の設計** |
| 最終処分場の残余容量の管理 | **在庫・容量の管理** |
| 施設の基幹的改良 | **設備の大規模改修・延命化** |
| 分別の区分の設計 | **製品ラインの設計** |
| 集積所の配置 | **拠点の配置設計** |
| 収集の順路の設計 | **配送ルートの最適化** |
| 委託の仕様の作成 | **業務委託の要件定義** |
| 広域化・一部事務組合 | **共同出資・共同運営の事業体** |
| 災害廃棄物処理計画 | **事業継続の計画** |

**上から5行目までが、いちばん値の付く並び**です。**需要を予測して、設備の能力を決めて、容量を管理する**——**これは、装置産業の計画の仕事そのものです。**

## 中核スキルを5つの工程に分ける

**この部署の中核は、「数十年先を見て、いまの設備と体制を決めること」**です。

**工程1：見込む（発生量と処理量の予測）**

人口の推計、世帯数、一人あたりの排出量、事業系の量、資源化の見込み。

**この工程に固有の制約があります。****一人あたりの排出量は、制度で動きます。**有料化をすれば減り、分別の区分を増やせば燃やす量が減ります。**つまり、予測の前提が、自分たちの政策によって変わります。**

**外部の環境を予測するのではなく、自分の打ち手を含めて予測する。****これは、民間の需要予測でも、価格や販促を織り込む場合と同じ構造**です。

**工程2：配る（分別の区分と収集の体制）**

何をどう分けるか、週に何回出せるか、どの区分を資源化に回すか。

**この工程に固有の制約があります。****区分を増やすほど、収集の便数が増えて費用が上がります。**逆に、**減らせば資源化率が下がります。**しかも、**変えるたびに、全世帯に周知しなければなりません。**

**この判断は、民間でいう品目を増やすかどうかの判断**と同じです。**増やせば選ばれやすくなるが、物流と管理の費用が上がる。**

**工程3：回す（収集の順路と委託）**

区域の割り振り、曜日の設計、順路、車両と人員、委託の仕様。

**この工程に固有の制約があります。****集積所の場所を、行政が自由に決められません。**多くの場合、**自治会や利用する世帯が管理しています。**だから、**「ここに置いたほうが効率がよい」と分かっていても、動かせない**ことがあります。

**つまり、拠点の位置が固定された状態で、ルートを組むということです。****民間の配送では、拠点を動かせる余地がありますが、ここにはありません。**

**工程4：燃やす・埋める（施設の運転と残余の容量）**

搬入の管理、運転の監督、補修の計画、最終処分場の残りの容量の把握。

**この工程に固有の制約があります。****施設は、止められません。**そして、**補修は、搬入の少ない限られた期間にしかできません。**加えて、**最終処分場は、埋まったら終わりです。**次を作るには、**用地の選定から供用まで十年以上かかります。**

**だから、「残り何年か」を常に見ている**ことになります。**これは、民間でいえば、在庫のスペースや、設備の寿命の管理と同じ考え方**です。

**工程5：畳む・建てる（施設の更新と広域化）**

老朽化した施設の更新、他の市町村との共同処理、一部事務組合の運営。

**この工程に固有の制約があります。****用地の選定、住民への説明、他市との調整、国の交付金の手続。****すべてを通すのに、十年以上かかります。**

**つまり、いま判断しないと間に合いません。**そして、**その判断をする時点では、完成するころに自分は担当していません。**

**これは、民間の大規模な設備投資でも同じ**です。**決める人と、使う人が別**という構造にあります。

:::insight
この経歴でいちばん多い損は、**「ごみの収集の担当でした」と書いてしまう**ことです。この一言だと、**現場の作業を思い浮かべられます。**実際にやっていたのは、**将来の発生量を予測し、施設の能力を決め、最終処分場の残りを管理し、数十億の投資の判断の材料を作ること**でした。書くなら、**「一般廃棄物処理計画において、人口の推計と排出の原単位から発生量を見込み、処理施設（日量◯トン）と最終処分場（残余容量◯年分）の必要な能力を算定」**という形です。**とくに「残余容量」という言葉を書いてください。**これは、**「残りどれだけ入るか」を常に見ていた証明**で、**民間でいう容量の管理そのもの**です。面談で伺うと、**皆さん残余の年数を即答されます。**それだけ日常的に意識している数字なのに、**書類には一行も書かれていません。**この一行があると、**「設備と容量を見ていた人」として読まれます。**
:::

## 民間の需給計画・設備投資と、どこが同じでどこが違うか

**同じところ**

1. **需要の予測に基づいて、設備の能力を決める**
2. **設備は、分割できない。**必要な分だけ少しずつ作る、ということができません
3. **稼働を止められない。**補修の時期を、需要の少ない時期に合わせます

**違うところ**

1. **需要を増やせない。**営業で量を増やす、という発想がそもそもありません
2. **価格を動かせない。**手数料は条例で決まっています
3. **撤退できない。**採算が合わないから畳む、という選択がありません
4. **立地を選べない。**区域が決まっていて、他の地域に移せません

**1番目が、いちばん大きい違い**です。

民間の装置産業は、**設備が余れば、営業で需要を取りに行きます。**この仕事では、**むしろ減らすことが目的**です。

**つまり、「需要を減らしながら、設備の稼働を維持する」という逆向きの計画**を立ててきたことになります。

**これは、人口が減る地域で事業を続ける会社が、いま直面している問題とまったく同じ**です。

## 評価が高くなりやすい4つの方向

**1. プラントメーカー・施設の運営受託**

**発注する側にいた経験**が、そのまま効きます。**自治体がどの時期に、何を見て、どう決めるか**を知っている人は、**提案の時期を外しません。**

**2. 収集運搬・リサイクルの事業**

**委託の仕様を書いていた経験**と、**順路と体制の設計**が効きます。**「発注者が継続の判断で何を見るか」を知っていることも、大きな強みです。**

**3. 自治体を顧客とするコンサルタント（計画・施設の整備）**

**計画の作られ方と、交付金の手続**を知っていることが効きます。**施設の整備は、計画から供用まで十年がかりの案件**で、**その全体を見たことがある人は多くありません。**

**4. エネルギー（廃棄物の発電、燃料化）**

**搬入される量と質の見込み**が、そのまま事業の前提になります。**この見込みを立てられる人**は、**事業の成立を判断する側で必要とされます。**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## つまずきやすい点

**1. 「ごみの収集」と書く**

**需要の予測と、設備の能力の設計**です。**そう書いてください。**

**2. 残余容量を書かない**

**日常的に見ていた数字**なのに、**書類には書かれていません。**

**3. 施設の更新を「担当していた」で終える**

**十年がかりの案件で、どの段階を持ったか**を書いてください。

**4. 集積所の制約を説明しない**

**拠点の位置が動かせない状態でルートを組んだ**——**これは、難しい条件です。**

**5. 「量を減らすのが目的」だったことを書かない**

**需要を減らしながら稼働を維持する計画**は、**人口が減る地域の会社が、いま直面している問題**です。

自分の経歴がどう言い換えられるかは、一度話しながら整理したほうが早いことが多いです。[どの経験に値が付くのかから相談できます](../apply.html)。

:::insight
ここまで書いておいて逆のことを言いますが、**この経歴は、施設の更新の時期にいるかどうかで、値がはっきり変わります。**処理施設は、おおむね20年から30年で更新の検討に入ります。**その時期に担当していれば、用地の検討、方式の比較、交付金の手続、住民への説明、他市との調整——この全部に関わることになります。**そして、**これを通しで経験した人は、全国的にも多くありません。**プラントメーカーも、コンサルタントも、**この経験を持つ人を探しています。**逆に、**更新の時期ではない自治体にいる場合、日常の運営が中心になります。**それも価値のある経験ですが、**「十年がかりの案件を通した」という話にはなりません。****確かめてほしいのは、自分の市の施設が、いまどの段階にあるか**です。**更新の検討がこれから始まるなら、そこに関わってから動くほうが、選べる範囲が広くなります。**在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 廃棄物処理法第6条は、一般廃棄物処理計画に**「発生量及び処理量の見込み」**を定めることを義務づけています
- **この見込みが、施設の能力、処分場の容量、車両と人員、委託の規模のすべての土台**になります
- **民間でいえば、需給の計画と、装置産業の設備投資の判断**です
- 中核スキルは、**①見込む ②配る ③回す ④燃やす・埋める ⑤畳む・建てる**の5工程に分かれます
- 違うのは、**①需要を増やせない ②価格を動かせない ③撤退できない ④立地を選べない**の4点です
- **「需要を減らしながら、設備の稼働を維持する」**——**人口が減る地域の会社が、いま直面している問題と同じ**です

## よくある質問

### 施設は一部事務組合の所管で、市は収集だけです

**その場合は、線を引いて書いてください。****「処理は◯市町で構成する一部事務組合が実施。市は収集運搬と搬入の管理、組合との協議を担当」**という形です。そのうえで、**組合との協議は、それ自体が書ける経験**です。**負担金の算定、搬入の計画、施設の整備の合意。****複数の自治体が共同で一つの事業体を運営する**——**これは、民間でいう共同出資の会社の運営と同じ構造**です。**「関わっていない」のではなく、「協議する側にいた」と書いてください。**

### 収集の現場（直営）に出ていました。事務職として書けますか

**書けます。**直営の収集は、**現場の作業と、運行の管理の両方**を含みます。書くべきは、**①担当した区域と世帯数 ②車両と人員の体制 ③安全の管理（作業中の事故の防止）④住民からの申出への対応 ⑤収集の実績の記録**です。とくに**③**は、**民間の物流や作業の現場で、そのまま必要とされる経験**です。**「作業していた」ではなく、「安全と運行を管理していた」**と書いてください。**なお、体を動かす仕事から内勤に移る場合は、記録と計画の部分を前に出す**と、書類が合いやすくなります。

### 災害廃棄物の処理に関わりました。どう書けばよいですか

**「事業継続と、臨時の体制の設計」**として書いてください。中身は、**①仮置場の選定と運営 ②搬入の管理と分別 ③処理先の確保（他の自治体や民間への依頼）④費用の記録と国への報告**の4つです。**とくに③は、平常時の処理能力を超えた分を、外部に振り分ける判断**で、**民間でいう代替の供給先の確保と同じ**です。書くなら、**「災害により発生した廃棄物約◯トンについて、仮置場◯か所の運営と、処理先の確保、費用の記録を担当」**という形です。**この経験を持つ人は多くありません。**行き先の絞り方は[廃棄物・清掃課から転職しやすい業界と職種](dept-haiki-tenshokusaki.html)に整理しました。
