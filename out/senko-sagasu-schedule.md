**在職中の転職では、日程の組み方が結果を左右します。**

**時間が限られているため**です。

この記事では、**逆算の仕方**と、**時期の選び方**を扱います。

## 行政の仕事には、年度の周期があります

**地方自治法第211条第1項**です。

> **普通地方公共団体の長は、毎会計年度予算を調製し、年度開始前に、議会の議決を経なければならない。**この場合において、普通地方公共団体の長は、遅くとも年度開始前、都道府県及び（略）指定都市にあつては**三十日**、その他の市及び町村にあつては**二十日**までに当該予算を議会に提出するようにしなければならない。

**予算は、年度が始まる前に議決を経る**という仕組みです。

**提出の期限も、日数で定められています。**

**この周期があるため、行政の仕事は年度で区切られます。**

**そして、行政が相手の事業も、この周期に沿って動きます。**

| 時期 | 行政の側 | 事業を担う側 |
|---|---|---|
| 秋から冬 | 予算の編成 | 提案、見積り |
| 年度の変わり目の前 | 議決、契約の準備 | **体制の準備** |
| 年度の始め | 事業の開始 | 着任、立ち上げ |

**2行目です。**

**事業が決まると、担う人が必要になります。**

**この時期に募集が出ることがあります。**

## 逆算で組む

| 順 | 決めること |
|---|---|
| 1 | **入社したい時期** |
| 2 | 退職の手続きに必要な期間 |
| 3 | 内定から入社までの期間 |
| 4 | 選考にかかる期間 |
| 5 | 応募を始める時期 |
| 6 | 準備を始める時期 |

**1から順に引いていきます。**

**2を最初に確認してください。**

**所属の規程による手続きの期間があります。**

**この期間が分からないと、逆算ができません。**

## 2——退職の手続きの期間

| 確認すること | 確認先 |
|---|---|
| 退職の申出の時期 | **所属の人事担当** |
| 手続きの流れ | 同上 |
| 引継ぎの期間 | 所属長 |
| 年次休暇の残り | 給与担当 |
| 退職手当の手続き | 給与担当 |

**1つ目を、早い段階で確認**してください。

**制度の照会として聞くことができます。**

**退職の意思を伝える必要はありません。**

**「退職する場合の手続きの流れを知りたい」という聞き方で足ります。**

## 在職中の繁忙を避ける

| 時期 | 繁忙になりやすい部署 |
|---|---|
| 秋から冬 | 財政、企画（予算の編成） |
| 議会の時期 | 全庁（答弁、資料） |
| 年度の変わり目 | 人事、会計、税、保育 |
| 出納整理の時期 | 会計、契約 |
| 申告の時期 | 税 |

**自分の部署の繁忙期を書き出してください。**

**その時期に面接を入れると、対応が難しくなります。**

**逆に、繁忙期の前後は時間が取りやすい**ことがあります。

**選考は、数週間から1か月以上にわたることが一般的**です。

**開始の時期を、繁忙期と重ならないように選んでください。**

:::insight
日程について、**面談でお聞きしているのが「議会の時期を外していますか」**という点です。役所の繁忙は、**部署ごとに違うように見えて、議会の時期は全庁に及びます。**答弁の準備、資料の作成、質問の取りまとめ。**この期間に面接を複数回入れると、対応が難しくなります。**そして、**選考は自分の都合だけで日程が決まりません。**相手の予定もあります。**開始してから繁忙期に入ると、途中で止まります。**選考が長引くと、**企業側の採用の計画とずれる**ことがあります。ですから、**応募を始める前に、向こう3か月の自分の予定を書き出してください。**議会、予算、決算、異動の時期。**空いている期間が2か月以上あるところから始める**ほうが、途中で止まりません。**時期を選べること自体が、在職中の利点**です。急いでいないのであれば、使ってください。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 面接の日程の作り方

| 方法 | 内容 |
|---|---|
| オンライン | 移動の時間が不要です |
| 始業前・終業後 | 対応の可否は会社によります |
| 土日 | 同上 |
| 年次休暇 | 半日単位で取得できる場合があります |
| 時間単位の休暇 | 制度がある団体があります |

**1つ目を先に確認**してください。

**移動の時間がかからないぶん、日程が組みやすくなります。**

**4つ目と5つ目について。**

**取得の理由を詳しく説明する必要はありません。**

**制度の範囲で取得できます。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 入社の時期の決め方

| 時期 | 考えること |
|---|---|
| 年度の変わり目 | **手続きが集中します** |
| 年度の途中 | 引継ぎの調整が必要です |
| 事業の開始に合わせる | 立ち上げから関われます |
| 家族の予定 | 学校、保育、転居 |

**1行目です。**

**年度末の退職は、手続きが集中する時期**にあたります。

**退職手当の支給の時期にも影響**することがあります。扱いは[退職手当はいつ振り込まれるか](senko-taishoku-shikyubi.html)に整理しています。

**3行目について。**

**行政が相手の事業では、年度の始めに事業が動きます。**

**この時期に合わせた入社が求められる**ことがあります。

**ただし、調整が可能な場合もあります。**

**応募の段階で、入社の時期の相談が可能かを確認**してください。

## 記録しておくこと

| 項目 | 内容 |
|---|---|
| 各社の選考の段階 | 書類／面接／内定 |
| 次の予定 | 日時と方法 |
| 返事の期限 | いつまでか |
| 自分の繁忙 | 議会、予算、決算 |
| 手続きの期限 | 退職の申出の時期 |

**4つ目を同じ表に入れてください。**

**選考の予定と、自分の繁忙を別々に管理すると、重なりに気づけません。**

## 準備に必要な時間

| 準備 | 目安 |
|---|---|
| 条件の整理 | 1時間から2時間 |
| 求人を読む | 週に30分から1時間 |
| 職務経歴書の1通目 | **半日から1日** |
| 2通目以降 | 1時間程度 |
| 面接の準備 | 1社あたり1時間から2時間 |

**3行目に時間がかかります。**

**最初の1通は、経験を民間の言葉に置き換える作業を含む**ためです。

**2通目以降は、求人に合わせて差し替える形**になります。

**ですから、応募を始める前に、1通目を作っておいてください。**

**求人が出てから作り始めると、掲載の期間に間に合わないことがあります。**

**書き方は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 止まったときの進め方

| 状況 | やること |
|---|---|
| 繁忙で動けない | **条件の整理と求人を読む作業は続ける** |
| 結果が来ない | 期限を確認する |
| 候補が尽きた | 探す軸を変える |
| 気持ちが続かない | 期間を区切って休む |

**1行目です。**

**面接ができない時期でも、読む作業は続けられます。**

**この期間に候補を溜めておくと、動ける時期に一気に進められます。**

## よくある失敗

**1. 退職の手続きの期間を確認しない**

**逆算ができません。**

**2. 繁忙期に選考を始める**

**途中で止まります。**

**3. 議会の時期を計算に入れない**

**全庁に及びます。**

**4. 入社の時期を先に決めない**

**逆算の起点がありません。**

**5. 家族の予定を入れない**

**転居や学校の手続きと重なります。**

**6. 選考の期間を短く見積もる**

**複数回行われることが一般的**です。

**7. 予定を1つの表にまとめない**

**重なりに気づけません。**

:::insight
ここまで逆算の話をしておいて逆のことを言いますが、**計画どおりに進まないことのほうが多い**です。面談で拝見していると、**日程を細かく決めて、ずれたところで止まってしまう方**がいらっしゃいます。ところが、**選考の進み方は相手の都合にも左右されます。**書類の結果が遅れる、面接の日程が先になる、条件の確認に時間がかかる。**いずれも珍しいことではありません。**ですから、**決めておくのは「入社したい時期」と「退職の手続きに必要な期間」の2つで足ります。**この2つがあれば、**ずれたときに、どこを詰めればよいかが分かります。**残りは、進みながら調整して差し支えありません。そして、**間に合わない場合、時期をずらすという選択**があります。行政が相手の事業では、**募集が周期で生じる**ため、**次の機会が来ます。**焦って条件を落とすより、**時期を変えるほうが結果として合う**ことがあります。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方自治法第211条第1項**は、**予算を年度開始前に議決を経ること**と、**提出の期限（都道府県・指定都市は30日、その他の市町村は20日）**を定めています。**行政の仕事は年度で区切られます**
- **行政が相手の事業も、この周期に沿って動きます**
- 日程は、**入社したい時期から逆算**してください
- **退職の手続きに必要な期間**を、最初に確認してください。制度の照会として聞けます
- **議会の時期は全庁に及びます。**選考の開始を重ねないでください
- **空いている期間が2か月以上あるところから始めて**ください
- **決めておくのは2つで足ります。**残りは進みながら調整してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 退職の申出は、いつまでにすればよいですか

**所属の規程によります。**条例や規則で、**退職の申出の時期に関する定めが置かれている**ことがあります。また、**引継ぎに必要な期間**も考慮されます。**人事担当に確認**してください。**制度の照会として聞けます。**なお、**確認の時点で退職の意思を伝える必要はありません。**「退職する場合の手続きを知りたい」という聞き方で足ります。**次の職の見込みが立つ前に意思を伝える必要はありません。**ただし、**復職を前提とした人員の配置が組まれている場合**など、早めに伝えるほうが所属の調整がしやすいこともあります。**次の職の見込みとの兼ね合いで判断**してください。

### 内定が出てから入社まで、どのくらい必要ですか

**退職の手続きの期間によります。**引継ぎ、年次休暇の消化、手続きの期間。**これらを合わせると、1か月から数か月になることがあります。**重要なのは、**この期間を、応募の段階で相手に伝えておくこと**です。「内定後、入社まで◯か月程度必要です」と先に伝えておけば、**企業側も計画を立てられます。**伝えずに進めて、**内定後に時期が合わないことが分かるほうが問題**になります。なお、**入社の時期を調整できる求人もあります。**確認の仕方は、「入社の時期について、どの程度の幅がありますか」で足ります。

### 選考の途中で、繁忙期に入ってしまいました

**その旨を伝えてください。**「業務の都合で、◯月は日程の調整が難しい」と伝えれば、**待てるかどうかの確認**ができます。会社によっては、**採用の時期が決まっていて待てない**場合もあります。その場合は、**そこで判断することになります。**ただし、**伝えずに連絡が遅れるほうが、印象として残ります。**先に伝えておいてください。なお、**紹介を通している場合、この連絡を任せられます。**在職中の事情を伝えておけば、**相手への説明も含めて調整の対象**になります。**止まっている間も、条件の整理は進められます。**
