「在職中に転職活動をしてよいのか」は、公務員の転職で最初に出てくる問いです。前の記事で、第38条（営利企業への従事等の制限）は兼業の規定で、転職活動の対象ではないと書きました。**もう1つ、転職活動と関係する条文が、第35条の職務専念義務です。**

第35条は、**転職活動を禁じる規定ではありません。**勤務時間と職務上の注意力を職責の遂行に用いる義務で、**転職活動を「いつ、どこで、何を使って」行うか**に線を引く規定です。

この記事では、**第35条の条文と、転職活動の各場面での線引き**を整理します。休暇の取り方は自治体の勤務時間条例や規則によるので、**自分の自治体の休暇の制度は人事の担当課で確かめてください。**第38条との関係は[地方公務員法38条は在職中の規定であること](seido-fukumu-38jo.html)に、副業の許可は[在職中の副業・兼業の許可](seido-fukumu-fukugyo.html)に書いています。

## 条文——第35条

第35条は、**職員は、法律又は条例に特別の定がある場合を除く外、その勤務時間及び職務上の注意力のすべてをその職責遂行のために用い、当該地方公共団体がなすべき責を有する職務にのみ従事しなければならない**と定めています。

| 要素 | 内容 |
|---|---|
| **何を** | **勤務時間**と**職務上の注意力**のすべて |
| **何に** | 職責の遂行のため。自治体の職務にのみ従事 |
| **例外** | **法律又は条例に特別の定がある場合**（休暇、休職、職務専念義務の免除など） |

**対象は「勤務時間」と「職務上の注意力」**です。勤務時間外の行動は、この条文の直接の対象ではありません。転職活動を勤務時間外に行い、勤務時間中は職務に集中していれば、第35条には触れません。

## 転職活動の場面ごとの線引き

| 場面 | 第35条との関係 | どうするか |
|---|---|---|
| **応募書類の作成** | 勤務時間中に行えば違反 | 勤務時間外、自宅で |
| **転職支援サービスへの登録・面談** | 同上 | 勤務時間外に。面談はオンラインなら夜間、対面なら休暇で |
| **面接** | 勤務時間中に無断で抜ければ違反 | **年次有給休暇を取って行く** |
| **勤務時間中の電話・メールの応答** | 私用の連絡は職務ではない | 応募先には「勤務時間中は応答できない」と伝え、昼休みか勤務時間外に折り返す |
| **公用の端末・メールでの応募** | 職務外の使用。情報の管理の規則にも反する | **私用の端末とメールアドレスで** |
| **勤務時間中の職場での転職の相談** | 職務上の注意力を職務以外に向ける | 勤務時間外に、職場の外で |

**線は明確です。勤務時間中は職務に、転職活動は勤務時間外に。**面接は年次有給休暇で行き、連絡は私用の端末で受ける。この2つを守れば、第35条の問題は生じません。

## 面接のための年次有給休暇

年次有給休暇は、労働基準法第39条により、**労働者が請求する時季に与えなければならず、請求された時季に与えることが事業の正常な運営を妨げる場合に限り、他の時季に変更できる**とされています（第5項）。地方公務員法第58条第3項は労働基準法の一部を適用除外としていますが、**第39条第5項は除外されておらず、地方公務員にも適用されます。**

| 点 | 内容 |
|---|---|
| **理由を言う必要** | **ありません。**年次有給休暇の取得に理由は要りません。「私用」で足ります |
| **時季の変更** | 事業の正常な運営を妨げる場合に限られます。繁忙期の予算編成の最中などは変更を求められることがあります |
| **半日・時間単位** | 自治体の勤務時間条例や規則によります。半日や時間単位の休暇があれば、面接の時間だけ取れます |
| **急な面接** | 前日や当日の請求も、事業の運営を妨げなければ認められます。ただし、職場の慣行として早めの申出を求められることが多いので、面接の日程は余裕を持って調整します |

**「面接のため」と言う必要はありませんが、嘘をつく必要もありません。**「私用のため」で申請し、聞かれても「私用です」で通ります。**理由を偽って別の休暇（病気休暇など）を使うことは、信用失墜行為や虚偽の申請として、別の問題になります。**

## 退職の申出の時期と職務専念義務

転職先が決まって退職を申し出るまでの期間、**職務専念義務は変わりません。**内定を受けた後も、退職日までは職員です。

| 場面 | 第35条との関係 |
|---|---|
| 内定後、退職日までの勤務 | **義務は同じ。**引継ぎを含めて職務に専念 |
| 引継ぎの資料の作成 | 職務の一部。勤務時間中に行う |
| 転職先の入社の準備（書類、健康診断） | 勤務時間外に。健康診断は休暇で |
| 転職先の業務を入社前に始める | 第35条とは別に、**第38条の対象**（報酬を得て従事） |

**退職を申し出た後に、職務への注意力が下がることは、周囲が最も見ている点**です。転職先が決まった後こそ、引継ぎを含めて職務に専念することが、円満な退職と、転職先への評判の両方につながります。

## 違反した場合

第35条に違反すると、**第29条の懲戒処分の対象**になり得ます（職務上の義務に違反し、又は職務を怠った場合）。勤務時間中に職場の端末で応募書類を作成していた、面接のために無断で職場を離れた、といった場合が典型です。**転職を控えた時期の懲戒処分は、退職手当と転職先への説明に影響します。**

:::insight
面談で伺うと、**「在職中に転職活動をすると職務専念義務に反する」と考えて、退職してから活動を始めるつもりの方**がいます。第35条は勤務時間と注意力の規定で、勤務時間外の転職活動は対象ではありません。退職してから始めると、空白の期間の資金と、「無職の応募者」として見られる不利の両方を背負います。逆に、**勤務時間中に職場の端末で応募先とメールをやり取りしていて、上司に見られた**という方もいます。これは第35条の問題で、しかも信頼を失います。ここで1つ提案があります。**転職活動の連絡先を、私用のメールアドレスと私用の端末に固定して、勤務時間中は一切開かないと決めてください。**面接は年次有給休暇で、理由は「私用」。**この2つのルールで、職務専念義務と転職活動は、完全に両立します。**在職中に活動を終えて、退職日の翌日に入社するのが、制度の面でも資金の面でも最も有利な形です。
:::

## 転職するとどうなるか

転職を考えている方にとって、職務専念義務で効いてくる点は3つです。

**1. 転職活動は在職中にできる**

**第35条は勤務時間と注意力の規定**で、勤務時間外の活動は対象外です。退職してから始める必要はありません。

**2. 面接は年次有給休暇で、理由は「私用」**

**取得に理由は要りません**（労働基準法第39条）。偽の理由を使わないことが、信用の面で大切です。

**3. 連絡は私用の端末で、勤務時間外に**

**公用の端末とメールを使わない**のが、第35条と情報管理の両方の線です。

## 手続きと期限

| 場面 | すること | 根拠 |
|---|---|---|
| 転職活動を始める | 私用のメールアドレスと端末を用意する | 第35条 |
| 応募書類の作成 | 勤務時間外に、自宅で | 第35条 |
| 面接の日程調整 | 年次有給休暇の取れる日で。半日・時間単位の休暇があれば活用 | 労働基準法第39条、自治体の勤務時間条例 |
| 年次有給休暇の申請 | 「私用」で申請。繁忙期は時季の変更を求められることがある | 第39条第5項 |
| 勤務時間中の応募先からの連絡 | 応答せず、昼休みか勤務時間外に折り返す | 第35条 |
| 内定後、退職日まで | 引継ぎを含めて職務に専念。入社の準備は勤務時間外に | 第35条 |

## 誤解されやすい点

**「職務専念義務があるから在職中に転職活動はできない」と思い込む**

**対象は勤務時間と職務上の注意力**です。勤務時間外の活動は対象外です。

**「面接のための休暇は理由を言わないと取れない」と思い込む**

**年次有給休暇に理由は要りません。**「私用」で足ります（労働基準法第39条）。

**「昼休みなら職場の端末で応募先に連絡してよい」と思い込む**

**昼休みは勤務時間外ですが、公用の端末の私用は情報管理の規則に反します。**私用の端末で。

**「退職を申し出たら職務専念義務は緩む」と思い込む**

**退職日までは職員で、義務は同じ**です。

:::insight
ここまで職務専念義務の話を書いておいて逆のことを言いますが、**職務専念義務は、転職の判断を左右するものではありません。**勤務時間外に活動し、面接は休暇で行く。それだけです。それでも1本の記事にしたのは、**この条文を理由に「退職してから活動する」と決めて、空白の期間と無職の応募という不利を自分で作ってしまう方を面談で見る**からです。第35条は勤務時間の規定で、転職活動の時期を決める規定ではありません。**在職中に活動して、退職日の翌日に入社する。**それが制度の面でも資金の面でも最も有利で、第35条はそれを妨げません。そのうえで、**自分の経験に値を付けてくれる業界の見込みと、同じ紙に並べてください。**片方だけでは比較になりません。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 地方公務員法第35条の職務専念義務は、**勤務時間と職務上の注意力のすべてを職責の遂行に用いる義務**で、**転職活動そのものを禁じる規定ではありません**
- **勤務時間外の転職活動は対象外**です。応募書類の作成、転職支援サービスとの面談は勤務時間外に、自宅で行います
- **面接は年次有給休暇で。**取得に理由は要らず、「私用」で足ります（労働基準法第39条第5項。地方公務員にも適用）。偽の理由を使わないでください
- **連絡は私用の端末とメールアドレスで、勤務時間外に。**公用の端末の使用は第35条と情報管理の両方に反します
- **内定後、退職日までも義務は同じ**です。引継ぎを含めて職務に専念します
- 違反は**第29条の懲戒処分の対象**になり得ます。転職を控えた時期こそ慎重に

## よくある質問

### 面接が平日の昼間にしか設定できません。休暇の申請で「転職活動のため」と言う必要がありますか

**ありません。**年次有給休暇は、労働基準法第39条により、労働者が請求する時季に与えなければならないもので、取得の理由を申告する義務はありません。「私用のため」で申請し、聞かれても「私用です」で足ります。地方公務員法第58条第3項は労働基準法の一部を適用除外としていますが、第39条第5項（時季の指定と変更）は除外されておらず、地方公務員にも適用されます。**避けるべきなのは、理由を偽ること**です。病気休暇や忌引など、理由を要件とする休暇を偽って使うと、虚偽の申請として第33条の信用失墜行為や第29条の懲戒の問題になります。半日や時間単位の年次有給休暇の制度があれば、面接の時間だけ取れるので、自治体の勤務時間条例や規則を確かめてください。繁忙期は時季の変更を求められることがあるので、面接の日程は複数の候補を応募先に示して、休暇の取れる日に合わせるのが現実的です。

### 転職支援のサービスから、勤務時間中に電話がかかってきます。どうすればよいですか

**勤務時間中は応答せず、昼休みか勤務時間外に折り返してください。**勤務時間中に私用の電話に出ることは、第35条の「職務上の注意力のすべてを職責遂行のために用い」に反します。転職支援のサービスには、最初の登録の時点で「勤務時間中は電話に出られないので、連絡は夜間か、メールで」と伝えておくと、向こうも合わせてくれます。応募先の企業からの連絡も同じで、「日中は勤務中のため、折り返しは夕方以降になります」と一言添えておけば、公務員の事情として理解されます。**公用の電話番号や職場のメールアドレスを連絡先にしない**のは、第35条だけでなく、職場の情報管理と、転職活動を職場に知られない観点からも大切です。連絡先は私用の携帯電話と私用のメールアドレスに固定して、勤務時間中はその端末を見ないと決めておくのが、最も簡単な線引きです。

### 内定を受けて退職を申し出ました。退職日までの数か月、転職先の準備に時間を使ってよいですか

**勤務時間中は、引継ぎを含めた職務に専念してください。転職先の準備は勤務時間外に。**退職を申し出た後も、退職日までは職員で、第35条の職務専念義務は変わりません。引継ぎの資料の作成は職務の一部なので勤務時間中に行い、転職先から求められる入社の書類や健康診断は、勤務時間外か年次有給休暇で対応します。**転職先の業務を入社前に有償で始めることは、第35条とは別に、第38条の兼業の許可の対象**なので、退職日の翌日からにしてください。退職を申し出た後に職務への集中が下がると、周囲の印象が悪くなり、引継ぎの不備が後任と、転職先への評判の両方に響きます。逆に、最後まで職務に専念して引継ぎを丁寧に行った方は、前職の同僚との関係が転職後も続き、業界によっては転職先の仕事にも生きます。残りの勤務は、転職先への準備ではなく、前職を丁寧に終える期間として使うのが、結果として転職先にも有利です。
