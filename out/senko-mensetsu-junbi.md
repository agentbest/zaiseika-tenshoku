受諾してから入社までの期間は、**思っているよりやることが多い**です。

退職の手続き、引継ぎ、保険と年金、税、入社の準備。**並行して進める必要があります。**

**そして、自治体を顧客とする会社に移る場合は、もう1つ確認すべきことがあります。**

この記事では、**その全体**を扱います。入社の日の決め方は[入社日の決め方](senko-mensetsu-nyushabi.html)にあります。

## 離職後の規制を、先に確認する

**自治体を顧客とする会社に移る方は、この条文を必ず読んでください。**

**地方公務員法第38条の2第1項**です。要点だけ取り出すと、次のような内容です。

> 職員であつた者であつて離職後に営利企業等の地位に就いている者は（中略）**離職前五年間に在職していた**地方公共団体の執行機関の組織（中略）の職員（中略）に対し、当該地方公共団体（中略）と当該営利企業等（中略）との間で締結される売買、貸借、請負その他の契約（中略）に関する事務（中略）であつて**離職前五年間の職務に属するものに関し、離職後二年間**、職務上の行為をするように、又はしないように**要求し、又は依頼してはならない。**

**要点は3つ**です。

| 要素 | 内容 |
|---|---|
| 相手 | **離職前5年間に在職していた組織の職員** |
| 対象 | その自治体との**契約等の事務**で、**離職前5年間の職務に属するもの** |
| 期間 | **離職後2年間** |

**つまり、元の職場に対する営業活動には制限がかかり得ます。**

**入社前に、応募先と共有しておいてください。**「前職の自治体に対しては、一定期間、この範囲の働きかけができません」と伝えておくと、**入社後の担当の割り振りで配慮されます。**

**条文の適用の範囲は、個別の事情によって判断されます。**判断に迷う場合は、**所属の人事担当や、応募先の法務の担当に確認**してください。

**なお、届出が求められる場合があります。**各自治体の条例や規則で、**再就職の届出の制度**が定められていることがあります。**所属の規程を確認してください。**

## やることの一覧

| 分類 | 内容 | 時期 |
|---|---|---|
| ① 退職 | 意思の表明、書類の提出、貸与品の返還 | 規程に従う |
| ② 引継ぎ | 資料の作成、後任への説明 | 退職の1か月前から |
| ③ 保険 | 共済組合から健康保険への切替え | 退職の前後 |
| ④ 年金 | 手続きと、期間の確認 | 退職の前後 |
| ⑤ 税 | 住民税の扱い、退職所得の申告 | 退職の時期による |
| ⑥ 入社の準備 | 提出書類、健康診断、必要な学習 | 入社の1か月前から |

**③④⑤は、個別性が高い**ため、**共済組合、年金事務所、市区町村の窓口、税務署**で確認してください。

**一般的な取扱いと、自分の場合が異なることがあります。**

## ②——引継ぎの進め方

| 順 | やること |
|---|---|
| 1 | 担当業務の一覧を作る |
| 2 | 進行中の案件の状況を書き出す |
| 3 | 関係する相手先と、連絡の経緯を整理 |
| 4 | 資料の所在を明示 |
| 5 | 後任が決まったら、対面で説明 |

**1から4は、後任が決まる前に作れます。**

**年度末は、異動の内示が遅れることがあります。**後任が決まってから始めると、**間に合いません。**

**文書での引継ぎを厚めに準備**してください。

**この作業は、職務経歴書の担当業務欄とほぼ同じ内容**になります。**すでに書類を作っているなら、その内容が使えます。**

## ⑥——入社の準備

| 項目 | 内容 |
|---|---|
| 提出する書類 | 年金手帳、雇用保険の番号、源泉徴収票、口座の情報など |
| 健康診断 | 求められる場合がある |
| 学習 | 業界の基礎、必要な道具の操作 |
| 挨拶の準備 | 入社初日の自己紹介 |

**3つ目について補足します。**入社前の学習は、**重いものは不要**です。

**応募先の公式サイトと、公表されている資料を読み返す**だけで足ります。**業界の専門的な知識は、入社後に学ぶのが通常**です。

**ただし、未経験の分野に移る場合、基礎的な用語だけは押さえておく**と、最初の1か月が楽になります。

:::insight
入社までの期間で、**いちばん見落とされやすいのが、離職後の規制の確認**です。面談で伺っていると、**自治体を顧客とする会社に移る方が、この点を知らないまま入社の準備を進めている**ことがあります。入社後に、**「前の職場に営業に行ってほしい」と言われて、初めて制限に気づく**という形です。**これは、本人にとっても会社にとっても困る状況**です。対処は簡単で、**内定の受諾の前後に、応募先に伝えておくこと**です。「前職の自治体に対しては、地方公務員法上の制限があります」と一言伝えれば、**多くの会社は理解します。**むしろ、**元の職場以外の自治体を担当する**という形に整理されるのが通常です。加えて、**制限があるのは「働きかけ」であって、知識や経験を使うこと自体ではありません。**制度の理解や業務の知識は、**そのまま使えます。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 期間別の進め方

**受諾から入社まで、2〜3か月あることが多い**です。時期で分けると整理しやすくなります。

| 時期 | 主にやること |
|---|---|
| 受諾の直後 | 離職後の規制の確認、退職の申し出、入社の日の確定 |
| 1か月目 | 引継ぎの資料の作成、貸与品の整理 |
| 2か月目 | 後任への説明、保険と年金の確認 |
| 最終の週 | 返還、挨拶、書類の受け取り |
| 退職後〜入社 | 保険と年金の手続き、入社の提出書類 |

**最終の週に受け取る書類**は、次の入社の手続きで使います。**離職に関する証明、源泉徴収票、年金に関する書類。**受け取り忘れると、**後から連絡して取り寄せる**ことになります。

**一覧にして、受け取ったものに印を付けてください。**

## 退職までの過ごし方

**残りの期間の過ごし方が、元の職場との関係を決めます。**

| ✕ | ○ |
|---|---|
| 引継ぎを後回しにする | **早い段階から資料を作る** |
| 業務への関与を減らす | 最後まで通常どおり担当する |
| 転職先を詳しく話す | 聞かれた範囲で答える |
| 不満を漏らす | 述べない |

**3つ目について補足します。**転職先を聞かれることはありますが、**詳しく話す必要はありません。**

**とくに、その会社が自治体と取引がある場合**、**在職中に具体的な話をすることは避けてください。**

**「民間の会社です」という程度で足ります。**

## 入社初日までに、整えておくこと

| 項目 | 内容 |
|---|---|
| 生活の準備 | 通勤の経路、勤務の時間に合わせた生活 |
| 書類の整理 | 提出物の確認、控えの保管 |
| 記録の処分 | 転職活動の記録のうち、不要なもの |
| 連絡先 | 元の同僚との連絡手段（必要な範囲で） |

**4つ目について補足します。**退職後も、**業務の照会が来ることがあります。**

**ただし、地方公務員法第34条の守秘の義務は、退職後も続きます。**答えられるのは、**自分の記憶の範囲の一般的な事柄**であって、**個別の案件の内部の情報ではありません。**

[経験の言い換えから相談する](../apply.html)こともできます。

## よくある失敗

**1. 離職後の規制を確認しない**

**入社後に困ります。**受諾の前後に共有してください。

**2. 引継ぎを後任が決まってから始める**

**間に合いません。**文書での準備を先に。

**3. 保険と年金の手続きを調べない**

**空白期間があると、手続きが必要**になります。

**4. 転職先を詳しく話す**

**聞かれた範囲で足ります。**

**5. 最後の期間に業務への関与を減らす**

**元の職場との関係が、そこで決まります。**

**6. 入社前の学習を重くしすぎる**

**基礎的な用語**で足ります。

:::insight
ここまで準備の話をしておいて逆のことを言いますが、**この期間にやるべきことの中心は、手続きではなく引継ぎ**です。手続きは、**確認して順に進めれば終わります。**一方、引継ぎは、**やり方によって残るものが変わります。**面談で伺っていると、**丁寧に引き継いで辞めた方は、その後も元の職場と自然な関係が続いています。**自治体を顧客とする業界では、**それが仕事の上でも意味を持ちます。**もちろん、**法律上の制限は守ったうえで**の話です。逆に、**引継ぎを雑にして辞めた場合、その評価は残ります。**業界は狭く、**人は動きます。**最後の1か月は、**次の仕事の準備の期間であると同時に、これまでの仕事を締める期間**でもあります。**どちらも手を抜かないほうが、後で効きます。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方公務員法第38条の2第1項**は、**離職前5年間の職務に属する契約等の事務**について、**離職後2年間**、元の組織の職員への働きかけを制限しています
- **自治体を顧客とする会社に移る場合は、受諾の前後に応募先へ伝えて**ください。担当の割り振りで配慮されます
- **再就職の届出の制度**が定められている場合があります。**所属の規程を確認**してください
- やることは、**①退職 ②引継ぎ ③保険 ④年金 ⑤税 ⑥入社の準備**の6分類です
- **③④⑤は個別性が高い**ため、共済組合・年金事務所・市区町村・税務署で確認してください
- **引継ぎは、後任が決まる前に文書で準備。**年度末は内示が遅れることがあります

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 離職後の規制は、どの職種に移る場合でも関係しますか

**規制の対象は、契約等の事務に関する働きかけ**です。したがって、**自治体と契約関係を持たない事業の会社に移る場合、直接には関わらないことが多い**とされています。ただし、**その会社が将来的に自治体と取引を始める可能性**もあります。判断に迷う場合は、**所属の人事担当に確認**してください。また、**条例や規則で、再就職に関する届出の制度**が設けられている場合があります。**制限の有無にかかわらず、届出が必要なことがある**ため、**規程は必ず確認**してください。

### 住民税の扱いが分かりません

**退職の時期によって扱いが変わります。**一般に、住民税は**前年の所得に対して、6月から翌年5月にかけて納める**仕組みです。在職中は給与から差し引かれていますが、**退職後は自分で納める形に変わる**のが通常です。**退職の月によって、一括で差し引かれる場合と、納付書で納める場合があります。**扱いは個別の事情によるため、**所属の給与の担当と、市区町村の窓口で確認**してください。**次の勤務先で給与から差し引く形に切り替えられる**こともあります。入社の手続きのときに相談してください。

### 入社前に、元の同僚に挨拶しておくべきですか

**通常の範囲で構いません。**退職の挨拶は、**所属の慣行に従えば足ります。**注意するのは、**転職先の詳細を広く伝えないこと**です。とくに、**その会社が自治体と取引がある場合**、在職中に具体的な話をすると、**誤解を招くことがあります。**「民間の会社に移ります」という程度にとどめてください。なお、**退職後に連絡を取ること自体は問題ありません。**ただし、**地方公務員法第38条の2の制限**に触れる働きかけは避けてください。**個人的な連絡と、業務上の働きかけは、分けて考える**必要があります。
