職務経歴書の相談で、両極端の書類を拝見します。

**1つは、A4で5枚。**在籍したすべての部署について、担当した事務が箇条書きで並んでいます。

**もう1つは、A4で1枚。**20年の経歴が、3行の職歴と、自己PRの定型文で終わっています。

**どちらも、読まれ方が同じ**です。**前者は読み切られず、後者は情報が足りません。**

この記事では、**枚数の決め方**を扱います。書類全体の型は[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)にあります。

## 結論：A4で2枚が基準

| 経験の年数 | 目安の枚数 |
|---|---|
| 3年目以内 | **1枚**（2枚あると水増しを疑われる） |
| 4〜15年 | **2枚** |
| 管理職・技術職で担当の範囲が広い | **2〜3枚**（3枚を超えない） |
| 応募先から様式の指定がある | **指定に従う** |

**2枚が基準である理由は、読む側の時間**です。書類の選考では、**1通あたり数分**で判断されることが珍しくありません。**3枚目以降は、面接の場で開かれることはあっても、選考の段階では読まれにくい**と考えたほうが確実です。

## 読む側には、基準があります

書類が「何枚なら読まれるか」を考えるより、**読む側が何を見ているか**から決めたほうが早いです。

参考になるのが、**役所の側で申請を審査するときの考え方**です。

**行政手続法第5条**です。

> 行政庁は、審査基準を定めるものとする。
>
> ２ 行政庁は、審査基準を定めるに当たっては、許認可等の性質に照らしてできる限り具体的なものとしなければならない。
>
> ３ 行政庁は、行政上特別の支障があるときを除き（中略）審査基準を公にしておかなければならない。

**審査には基準があり、できる限り具体的で、公にされている。**申請を審査した経験のある方なら、**基準に対して過不足なく書かれた申請書が、いちばん処理しやすい**ことをご存じのはずです。

**採用の書類選考も、同じ構造**です。**求人票の「応募条件」と「仕事内容」が、その基準に当たります。**

つまり、**枚数は「基準に対して過不足がないか」で決まります。**求人票に書かれている要素が全部あれば、1枚でも足ります。無関係な情報が3枚あっても、評価は上がりません。

**「何枚書くか」ではなく、「求人票のどの要素に答えたか」で組み立ててください。**

## 2枚の配分

| 位置 | 内容 | 分量 |
|---|---|---|
| 1枚目の上 | 職務要約 | 5行 |
| 1枚目の中〜下 | 担当業務（機能ごと） | 2/3ページ程度 |
| 2枚目の上〜中 | 実績（3〜5項目） | 1/2ページ程度 |
| 2枚目の下 | 活かせる経験・資格 | 5行程度 |

**1枚目で「何ができる人か」が分かる状態**にしてください。**2枚目は、裏づけ**です。

**逆に、1枚に収まらないことを恐れて内容を薄くする必要もありません。**2枚目に実績が3項目並んでいる書類は、**1枚で終わっている書類より確実に読まれます。**判断の基準は枚数ではなく、**1行ずつが応募先に関係しているかどうか**です。関係のない行は、**何枚であっても読み飛ばされます。**

## 削る順番

**5枚になってしまった書類は、次の順で削ります。**

| 順 | 削るもの |
|---|---|
| 1 | 応募先と関係のない部署の記述（在籍の一覧の1行に圧縮） |
| 2 | 担当業務の重複（同じ機能を複数の部署で書いている） |
| 3 | 根拠法令の列挙 |
| 4 | 実績のうち、4番目以降の項目 |
| 5 | 研修の受講歴、庁内の表彰 |

**削っても情報は減りません。**同じ機能を3か所で書いているなら、**1か所にまとめて年数を通算するほうが強くなります。**

**削ってはいけないのは、数字と、自分が判断した範囲**です。ここを削ると、**残った分量が薄くなります。**

:::insight
書類の選考で、**最後まで読まれるかどうかを決めているのは、1枚目の上の5行**です。面談で伺っていて感じるのは、**枚数を気にされる方ほど、要約欄が弱いこと**です。**5枚書いても、1枚目の上に「一般行政事務に従事」とあれば、2枚目に進みません。**逆に、**要約の5行に規模と判断の範囲が入っていれば、3枚でも最後まで読まれます。**枚数の調整に時間をかけるより、**先に要約の5行を作り直すほうが、効果が出るのが早い**です。もう1つ、**応募先ごとに書き直すのは要約欄だけで足ります。**担当業務と実績は、**順番の入れ替えで対応できます。**この作り方にしておくと、**1社あたり30分で書類を仕上げられる**ようになります。応募の数が必要な時期に効いてきます。要約の作り方は[職務経歴書の要約欄｜最初の5行で何を書くか](senko-shokumu-yoyaku.html)にまとめています。
:::

## 増やしてよい場合

**次の場合は、3枚になっても構いません。**

- **技術職**で、扱った工種や構造物の種類が多い場合（一覧の表を入れる）
- **管理職**で、所管した部門と担当した制度が複数にわたる場合
- **資格と実務の対応**を表で示す必要がある場合
- 応募先が**詳細な記載を求めている**場合

**ただし、3枚目は「表」にしてください。**文章で3枚目を作ると、読まれません。**工種の一覧、担当した制度の一覧、資格と実務の対応表**であれば、**参照される資料**として機能します。

## 1枚目だけで判断されたとき、何が伝わるか

**書類を作り終えたら、1枚目だけを印刷して読んでみてください。**確認するのは3点です。

| 確認する点 | 満たしていない場合 |
|---|---|
| 扱っていた組織と業務の規模が分かるか | 要約欄に人口・予算・件数のどれかを足す |
| 何の機能を担ってきた人か分かるか | 担当業務を部署名ではなく機能で並べ直す |
| 自分で決めていた範囲が分かるか | 決裁・査定・審査・決定のいずれかの語で範囲を書く |

**3点とも満たしていれば、2枚目は裏づけとして読まれます。**満たしていない場合、**2枚目を厚くしても補えません。**

**この確認は、応募のたびに繰り返す必要はありません。**1度整えておけば、**以降は応募先に合わせて順番を入れ替えるだけ**で足ります。

## 体裁の実務

| 項目 | 目安 |
|---|---|
| 用紙 | A4、横書き |
| 文字の大きさ | 10.5〜11ポイント |
| 余白 | 上下左右 20ミリ前後 |
| 見出し | 太字か罫線で区切る。装飾は不要 |
| 提出の形式 | 指定がなければ、データで提出できる形式に |
| 写真 | 職務経歴書には不要（履歴書に貼る） |

**手書きである必要はありません。**指定がなければ、**作成したデータをそのまま提出できる形に整えてください。**

[経験の言い換えから相談する](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担です）。

## よくある失敗

**1. 在籍したすべての部署を同じ分量で書く**

**応募先との関係で分量を変えてください。**

**2. 1枚に収めようとして、数字を削る**

**削るのは重複と無関係な記述**です。数字は残します。

**3. 3枚目を文章で書く**

**表にしてください。**文章の3枚目は読まれません。

**4. 余白を詰めて情報を押し込む**

**読みにくい書類は、読まれません。**削るほうが早いです。

**5. 枚数を先に決めてから書く**

**求人票の要素に答えてから、結果として枚数が決まります。**

**6. 応募先ごとに全文を書き直す**

**要約欄だけで足ります。**時間の配分を間違えると、応募の数が減ります。

:::insight
ここまで枚数の話をしておいて逆のことを言いますが、**枚数で落ちることは、ほとんどありません。**書類の選考で落ちる理由の大半は、**求人票の要素に答えていないこと**です。たとえば、求人票に「自治体との折衝の経験」と書かれているのに、書類に折衝の経験が書かれていない。**持っているのに、書いていない**という例が、いちばん多いです。対処は単純で、**応募する前に、求人票の「応募条件」と「仕事内容」を1行ずつ読み、自分の書類のどこがそれに当たるかを指差しで確認すること**です。当たる部分が無ければ、**書き足すか、その求人は見送る**。この確認を1回入れるだけで、書類の通過率は変わります。**枚数の調整は、その後で構いません。**応募先が決まっていない段階のほうが、整理する意味があります。
:::

## まとめ

- **A4で2枚が基準。**3年目以内は1枚、管理職や技術職で範囲が広い場合は3枚までです
- **行政手続法第5条**は、審査基準を**できる限り具体的に定め、公にしておく**ことを求めています。**求人票の応募条件と仕事内容が、選考の基準に当たります**
- 枚数は、**求人票の要素に対して過不足がないか**で決まります
- 削る順番は、**無関係な部署 → 重複 → 法令の列挙 → 4番目以降の実績 → 研修歴**です
- **数字と、自分が判断した範囲は削りません**
- 3枚目を作るなら、**文章ではなく表**にしてください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 応募先から「A4で1枚以内」と指定されました

**指定に従ってください。**そのうえで、1枚に入れる優先順位は、**①要約（5行）②応募先に関係する機能2つ ③実績2項目 ④資格**です。**在籍の一覧は、期間と所属だけの1行にまとめてください。**削りきれない場合は、**面接で補足する前提で、書類は骨組みに徹する**と割り切るほうが読まれます。なお、**1枚の指定がある場合は、他の応募者も同じ条件**です。情報量の不足は、相対的には不利になりません。**指定を超えることのほうが、印象に影響します。**

### 転職の回数が多く、どうしても2枚に収まりません

**在籍ごとではなく、機能ごとにまとめてください。**同じ種類の仕事を複数の勤務先で経験しているなら、**「◯◯の業務を通算◯年」として1か所にまとめられます。**そのうえで、**在籍の一覧を表で下に置けば、期間の確認はできます。**この構成なら、5社でも2枚に収まります。注意点は、**在籍の期間に空白がある場合、その行も書くこと**です。書かないと、**確認のやり取りが増えます。**公務員の異動の扱いは[異動が多い公務員の職務経歴書の並べ方](senko-shokumu-ido.html)と考え方が同じです。

### 手書きとデータ、どちらがよいですか

**指定がなければ、データで構いません。**手書きが有利になる場面は、現在ではほとんどありません。むしろ、**データのほうが修正と使い回しがしやすい**ぶん、応募先ごとの調整がしやすくなります。気をつけるのは、**提出の形式**です。編集ができる形式のまま送ると、**相手の環境で体裁が崩れることがあります。**指定がなければ、**体裁が固定される形式に変換して送るほうが確実**です。ファイルの名前は、**自分の氏名と書類の種類が分かるもの**にしてください。相手が管理しやすくなります。
