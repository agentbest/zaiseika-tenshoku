製造業の管理部門の選考について、**公務員の方が戸惑う点**が2つあります。

**「工場見学が選考に入っていました」**

**「内定の前に、健康診断の話が出ました」**

**どちらも、この業界では普通のこと**です。**そして、どちらにも理由があります。**

**製造業の選考は、「この人が工場で働けるか」を確かめる工程**を含みます。**それは、法令上の義務と結びついています。**

この記事では、**選考の流れと、面接で見られている観点**を扱います。職種の整理は[未経験から製造業の管理部門に入るには](industry-seizo-mikeiken.html)、志望動機の組み立ては[製造業の管理部門の志望動機](industry-seizo-shiboudoki.html)にあります。

## 入社したら、安全衛生の教育が行われます

**選考の終盤で出てくる話の、根拠になる条文**です。

**労働安全衛生法第59条**です。

> **（安全衛生教育）第五十九条　事業者は、労働者を雇い入れたときは、当該労働者に対し、厚生労働省令で定めるところにより、その従事する業務に関する安全又は衛生のための教育を行なわなければならない。**
>
> **２　前項の規定は、労働者の作業内容を変更したときについて準用する。**

**「雇い入れたときは」**です。**管理部門であっても、労働者として雇い入れられる以上、対象になります。**

そして、**同法第66条第1項**です。

> **事業者は、労働者に対し、厚生労働省令で定めるところにより、医師による健康診断**（中略）**を行わなければならない。**

**健康診断も、事業者の義務**です。

**つまり、内定の前後で健康診断の話が出るのは、特別な扱いではありません。****法令上やらなければならないこと**が、**手続きとして組まれている**だけです。

**⚠ 役所でも同じ仕組みがあります。**驚く必要はありませんが、**時期と内容は確認してください。**

## 工場見学が選考に入る理由

**多くの製造業で、選考の途中に工場の見学が入ります。**

**これは、会社が応募者を試しているのではありません。****双方の確認の工程**です。

| 見られていること | 確かめられていること |
|---|---|
| **現場の雰囲気への反応** | 工場で働くことに抵抗がないか |
| 質問の中身 | **何に関心を持つ人か** |
| 音・におい・温度への反応 | **実際の環境に耐えられるか** |
| 現場の人との接し方 | 管理部門としての立ち位置 |

**応募者の側も、ここで確認してください。**

**工場は、会社によってまったく違います。**清潔で静かな工場もあれば、**音が大きく、季節によって暑さ・寒さが厳しい工場**もあります。**毎日通う場所として、自分に合うかどうか**は、**見なければ分かりません。**

**見学の機会が選考に無い場合**は、**こちらから申し出て構いません。**「配属される事業所を拝見できますか」。**この申し出自体が、真剣度として受け取られます。**

**⚠ 見学のときに、安全の指示には必ず従ってください。**保護具の着用、立入の範囲、撮影の可否。**ここでの振る舞いは、見られています。**

## 選考の流れは、職種で分かれます

| 職種 | 流れの型 | 回数の目安 |
|---|---|---|
| 総務・人事 | 書類 → 人事 → 部門長 → 役員 | **3回前後** |
| 経理・財務 | 書類 → 部門長 → 役員 | 2〜3回 |
| 法務 | 書類 → 部門長 → 役員 | 2〜3回 |
| 環境・安全 | 書類 → **工場の担当** → 工場長 → 本社 | **3〜4回＋見学** |
| 品質保証 | 書類 → 部門長 → **現場の確認** → 役員 | 3〜4回 |
| 購買・調達 | 書類 → 部門長 → 役員 | 2〜3回 |

**環境・安全と品質保証は、工場での面接が入ります。**

**面接官が、本社の人事ではなく、工場の管理職**になることが多い。**質問が実務に寄る**のはそのためです。

**もうひとつ、役所の採用試験と違う点があります。****筆記試験は、無いか軽い**ことです。**教養試験・専門試験で選抜する仕組みではありません。**書類と面接で判断されます。

**⚠ そのぶん、職務経歴書の比重が大きくなります。**

## 面接で見られている観点は、5つです

| 観点 | 具体的に確かめられること |
|---|---|
| ① 法令の経験の具体性 | **どの法令を、どの立場で扱ったか** |
| ② 現場との距離の取り方 | **指導する目線で来ないか** |
| ③ 記録の作り方 | 後から検証される前提の書類を作れるか |
| ④ 勤務地の前提 | **工場勤務・転居を伴う異動の可否** |
| ⑤ 学ぶ構え | 製品や工程の知識をどう埋めるか |

**①は、公務員の強い持ち札**です。

**答え方は、法令名を必ず入れてください。**「環境関係の許認可を担当」ではなく、**「大気汚染防止法にもとづくばい煙発生施設の設置及び変更の届出の審査を年間◯件、立入検査を◯件」**です。

**②は、この業界で最も警戒される点**です。[製造業の管理部門の志望動機](industry-seizo-shiboudoki.html)でも触れましたが、**「法令にもとづいて適切に指導します」という答え方は、評価を落とします。**

**管理部門は、現場を指導する部署ではなく、現場が動ける条件を整える部署**です。

**答え方は、「まず、現場が何に困っているかを聞きます」**という形にしてください。

**⑤も、用意しておいてください。**

> 製品や工程の知識はありませんので、最初の3か月は現場を見せていただきながら、どの工程がどの法令の対象になるかを自分で対応付けていきます。手続きの実務は、並行して進められると考えています。

:::insight
選考に同席させていただいていて、**製造業の面接で、公務員の方がいちばん取りこぼしている質問**があります。**「これまでで、いちばん困った案件は何ですか」**です。多くの方が、**うまく処理できた話**を選んで答えられます。ところが、この質問で確かめられているのは、**成功の実績ではなく、困ったときにどう動くか**です。工場の管理部門では、**前例の無い事態が定期的に起こります。**設備を入れ替えたら届出の区分が変わった、法令が改正されて対応の期限が決まった、検査で予想しなかった指摘を受けた。**そのときに、誰に聞き、何を調べ、どの順で処理するか**が見られています。ですから、答えるべきは、**困った経験そのもの**です。「制度の要件のどれにも当てはまらない申請が来たことがあります。過去の類似の事例を調べ、所管に照会し、判断の方針を整理してから処理しました」。**この答えには、調べる・聞く・整理する・決める、という4つの動作が入っています。**そして、**この4つは、工場で法令の対応をするときの動作とまったく同じ**です。うまくいった話より、**困った話のほうが評価されます。**用意しておいてください。
:::

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 場面 | 効く理由 |
|---|---|
| 法令についての質問 | **条文にもとづいて答える訓練を受けている** |
| 書類の作り込み | 記録を残す習慣 |
| 検査・監査への対応の質問 | **検査する側にいた** |
| 前提条件の確認 | 確認する習慣がある |
| 委員会・会議体の運営 | 審議会の事務と同じ構造 |

**効きにくい場所**

| 場面 | 効きにくい理由 |
|---|---|
| 成果を数字で語る | **役所では個人の成果として記録されない** |
| 自己紹介を短く話す | 説明が経緯から始まりがち |
| 製品や工程についての質問 | 知識が無い |
| 想定外の質問への即答 | **前例を確認してから答える習慣** |

**2つ目は、事前の練習で直ります。**

**結論から先に言ってください。**「担ってきたのは、大気と水質の届出の審査です。年間◯件を扱っていました」。**この順序に変えるだけで、伝わり方が変わります。**

**1つ目については、「変えた話」を探してください。**様式を作った、判断の基準を整理した、照会の件数が減った。**自分が来る前と、去ったあとで何が違うか**です。

## 準備の手順

| 順 | やること | 目安 |
|---|---|---|
| 1 | 扱った**法令名と件数**を書き出す | 1時間 |
| 2 | **「困った案件」を3つ**書き出す | 1時間 |
| 3 | 応募先の**工場の所在地と製品**を確認する | 1時間 |
| 4 | その工場が**どの法令の対象か**を推測する | 30分 |
| 5 | **最初の3か月**の答えを作る | 30分 |
| 6 | **確認する項目を3つ**決める（勤務地・異動・休日） | 20分 |

**6つ目を必ずやってください。**[製造業の管理部門の年収と働き方](industry-seizo-nenshu.html)で触れたとおり、**勤務地、転居を伴う異動の範囲、休日が会社の暦で決まる割合**は、この業界では確認が要ります。

[経験の言い換えから相談する](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担です）。

## 逆質問で使えるもの

| 質問 | 何が分かるか |
|---|---|
| この職種の方は、本社と工場のどちらに在籍していますか | **勤務地の前提** |
| 前任の方は、どういう経緯で離れましたか | 定着の状況 |
| 年間の休日のうち、会社の暦で決まる割合は | **生活の組み立て方** |
| 入って最初に任せたいことは何ですか | 期待されている役割 |
| 行政との窓口は、どなたが担当されていますか | **自分の位置づけ** |

**5つ目は、環境・安全の職種を志望する場合に有効**です。**自分が窓口になるのか、技術系の社員と分担するのか**で、仕事の中身が変わります。

## 内定から入社まで

**労働基準法第15条第1項**により、**労働契約の締結に際して、賃金・労働時間その他の労働条件の明示**が求められます。**書面で条件を確認してください。**

**そのうえで、製造業では次のことが起こります。**

| 起こること | 根拠・理由 |
|---|---|
| 健康診断の案内 | **労働安全衛生法第66条**（事業者の義務） |
| 入社時の安全衛生教育 | **労働安全衛生法第59条第1項** |
| 保護具の支給・サイズの確認 | 工場に立ち入るため |
| 入社日の調整 | **生産の計画に合わせることがある** |

**4つ目について、現職の引き継ぎに必要な期間は、選考の段階で伝えておいてください。**急かされることもあれば、待ってもらえることもあります。

:::insight
ここまで対策の話をしてきましたが、**こちらからも見るべき点**があります。**工場見学のときに、現場がどう見えるか**です。整理整頓の状態、掲示物が更新されているか、通路が確保されているか、作業をしている方が保護具を着けているか。**これは、役所で立入検査をしてきた方なら、見慣れた観点**のはずです。**その目で、遠慮なく見てください。**理由は2つあります。1つは、**自分が入ったあとに担当する状態**だからです。整っていない工場に入るなら、**最初の仕事はそこを整えることになります。**それを承知で入るのと、知らずに入るのとでは、心構えが違います。もう1つは、**会社の姿勢が出るから**です。応募者に見せる場所ですら整っていない場合、**見せない場所の状態は推して知るべし**という判断ができます。逆に、**見学のときに「ここはまだ改善の途中です」と正直に説明する会社**は、**中の議論が健全である可能性が高い**です。選考は、**採点されるだけの場ではありません。**そして、**合わないと判断して辞退することは、失礼ではありません。**確かめた結果、**いまの職に残るという結論**も、同じ資格で成り立ちます。当社が、いまの職を辞めることをお勧めすることはありません。
:::

## まとめ

- **工場見学と健康診断の話が出るのは、この業界では普通のこと**です
- **労働安全衛生法第59条第1項**は、**労働者を雇い入れたときの安全又は衛生のための教育**を義務づけ、**第2項**は**作業内容を変更したとき**に準用すると定めています
- **同法第66条第1項**は、**医師による健康診断**を事業者の義務としています
- **工場見学は、双方の確認の工程**です。**自分に合う環境かどうかを、こちらも見てください**。見学が無い場合は**申し出て構いません**
- 選考は**書類と面接**で、**筆記試験は無いか軽い**です。**職務経歴書の比重が大きくなります**
- 見られている観点は、**①法令の経験の具体性 ②現場との距離の取り方 ③記録の作り方 ④勤務地の前提 ⑤学ぶ構え**の5つです
- ⚠ **①は法令名を必ず入れて**答えてください。②で**「適切に指導します」と答えないでください**
- **「いちばん困った案件は何ですか」には、うまくいった話ではなく、困った話を**答えてください
- **面接は、こちらが会社を見る場**でもあります。**工場の状態を、立入検査の目で見てください**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 在職中です。工場見学の日程は調整してもらえますか

**調整してもらえることが多いです。**ただし、**工場は稼働の計画があるため、面接ほど自由には動かせません。**候補の日を複数もらったら、**早めに返すほうが調整が楽**です。土曜に対応してもらえる場合もありますが、**稼働していない日に見ても、実際の環境は分かりません。**可能であれば、**稼働している平日に半日の休暇を取って行く**ほうが、見る価値があります。遠方の場合は、**一次面接をオンラインで行い、二次で現地**という組み方が一般的です。なお、**交通費の扱いは会社によって違います。**確認しておくと、気兼ねなく行けます。

### 健康上の事情があります。伝えるべきですか

**職務に影響する範囲で、伝えておくほうが安全です。**たとえば、**特定の物質への反応、立ち作業や高所作業の可否、就業時間の制約**など、**配属先や業務の割り当てに関わること**です。伝えることで、**工場の中でも立ち入る範囲が限られる職種に調整してもらえる**ことがあります。一方、**職務に影響しない事柄まで話す必要はありません。**伝える時期は、**選考の終盤か、内定の前後**が一般的です。⚠ **判断に迷う場合は、主治医に相談してください。**この記事では、個別の事情について判断できません。なお、**健康診断の結果の取り扱いについては、会社の産業医や人事に確認**してください。

### 複数の製造業を並行して受けても問題ありませんか

**問題ありません。**中途採用では一般的です。むしろ、**工場を複数見ることには意味があります。**同じ業種でも、**工場によって環境がまったく違う**からです。2〜3社見ると、**自分が何に反応するかが分かります。**音が気になるのか、においが気になるのか、それとも慣れそうなのか。**1社だけだと、比べる基準がありません。**進め方のこつは、**日程を少しずらすこと**です。同じ週に最終面接が重なると、条件を比べる時間が取れません。なお、**他社の選考が進んでいることは、聞かれたら正直に伝えて構いません。**会社名を出さずに「他社の選考も進んでいます」で足ります。
