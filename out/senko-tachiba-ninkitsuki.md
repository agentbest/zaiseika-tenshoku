**任期の満了が見えてきた段階でのご相談**です。

**制度の趣旨を踏まえると、説明がしやすくなります。**

この記事では、**選択肢**と、**任期中に整えること**を扱います。

## 専門性を活用するための制度です

**地方公共団体の一般職の任期付職員の採用に関する法律第3条第1項**です。

> **任命権者は、高度の専門的な知識経験又は優れた識見を有する者をその者が有する当該高度の専門的な知識経験又は優れた識見を一定の期間活用して遂行することが特に必要とされる業務に従事させる場合には、条例で定めるところにより、職員を選考により任期を定めて採用することができる。**

**同条第2項**は、**専門的な知識経験を有する者**について、**部内で確保することが困難な場合**などに、**任期を定めて採用できる**としています。

**同法第6条第1項**です。

> **第三条第一項又は第二項の規定により採用される職員の任期は、五年を超えない範囲内で任命権者が定める。**

**同条第3項**は、**任期の明示**を求めています。

**つまり、「専門性を一定の期間活用する」ことが制度の前提**です。

**任期の満了は、予定どおりの経過**であって、**勤務の評価によるものではありません。**

**この点は、選考の場でそのまま説明できます。**

## 選択肢

| 選択肢 | 内容 |
|---|---|
| ① 民間へ移る | 経験を活かせる領域へ |
| ② 他の団体の任期付 | **同種の募集がある** |
| ③ 常勤の採用試験 | 経験者の採用など |
| ④ 同じ分野の専門職 | 独立、業務の受託 |
| ⑤ 任期の更新・再度の採用 | **制度と条例による** |

**⑤について。**

**扱いは団体の条例と運用によります。**

**可能性の有無を、早めに人事担当に確認**してください。

**②について。**

**任期付の募集は、複数の団体で行われています。**

**同じ分野での経験が、そのまま要件に当たる**ことがあります。

## 任期中に整えること

| 項目 | 内容 |
|---|---|
| ① 実績の記録 | **担当した案件、成果物、件数** |
| ② 成果物の控え | 公表された資料の範囲で |
| ③ 資格・登録 | 取得、更新 |
| ④ 分野の動向 | 制度の改正、技術の動き |
| ⑤ 関係先との関係 | 継続できる形で |
| ⑥ 満了の時期の確認 | **逆算の起点** |

**①が最も重要**です。

**任期付では、特定の業務に集中して従事する**ことが多く、**成果が形に残りやすい**という特徴があります。

**計画、報告書、システム、要綱、手引。**

**何を作り、何を残したかを書き出してください。**

**②について。**

**公表されている資料であれば、その範囲で示せます。**

**公表されていないものは、内容に触れずに「◯◯を作成」と書いてください。**

## 書き方の例

**悪い例**

> ◯◯市の任期付職員として勤務しました。

**良い例**

> ◯◯市において、**◯◯の分野の専門職として任期を定めて採用**され、◯年間従事。**◯◯に関する計画の策定を担当し、現状の分析、関係課との調整、審議会への説明、意見の募集への対応を実施。****◯◯の仕組みを新たに構築し、運用の手順と要綱を整備。**職員◯名に対する研修を◯回実施。

**「採用の趣旨」「作ったもの」「関わった範囲」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 面接での説明

| 聞かれること | 答え方 |
|---|---|
| なぜ任期が終わるのか | **制度上、期間を定めた採用であるため** |
| 何を担当したか | 作ったもの、関わった範囲 |
| 常勤にならなかった理由 | **採用の枠組みが別であること** |
| 次に何をしたいか | 分野を続けるか、変えるか |
| いつから働けるか | 満了の時期 |

**1行目と3行目です。**

**制度の仕組みを説明すれば足ります。**

**弁解の形にしないでください。**

**5行目について。**

**満了の時期が決まっているため、入社の時期を明確に示せます。**

**これは、在職中の方より有利な点**です。

:::insight
任期付職員の方のご相談で、**面談でお伝えしているのが「満了の時期が決まっていることを、強みとして使ってください」**という点です。在職中の方の選考では、**「いつから働けるか」が不確定**になりがちです。退職の手続きにどれだけかかるか、引継ぎがどうなるか。**採用する側は、計画が立てにくい。**一方、任期付の方は、**満了の日が決まっています。**「◯年◯月末で任期が満了し、◯月から勤務できます」と、**最初から示せる。**この確実さは、採用の計画を立てる側にとって扱いやすいものです。そして、**任期の満了が勤務の評価によるものではないことも、制度の説明で伝わります。**ですから、**書類の冒頭に、採用の趣旨と任期を明記してください。**「◯◯の分野の専門職として任期を定めて採用（◯年◯月〜◯年◯月）」。**この1行で、経歴の位置づけが伝わります。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 時期の逆算

| 時期 | やること |
|---|---|
| 満了の1年前 | 更新の可能性を確認、実績を整理 |
| 8か月前 | 職務経歴書を作る、求人を読む |
| 6か月前 | **応募を始める** |
| 3か月前 | 選考、条件の確認 |
| 満了 | 退職の手続き |

**満了の6か月前を目安に応募を始めてください。**

**選考には、1社あたり1か月前後かかることがあります。**

**複数を並行して見る場合、余裕が必要です。**

**扱いは**[選考スケジュールの組み方](senko-sagasu-schedule.html)**に整理しています。**

**なお、任期の満了と同時に次の勤務を始める必要はありません。**

**空白の期間を置く場合、健康保険や年金の手続きが生じます。**

**扱いを、所属の担当に確認**しておいてください。

[経験の言い換えから相談する](../apply.html)こともできます。

## 見る領域

| 領域 | 内容 |
|---|---|
| ① 同じ分野の民間 | **専門性がそのまま** |
| ② 行政が相手の事業 | 制度の支援、調査、システム |
| ③ 他の団体の任期付 | 同種の募集 |
| ④ 調査・コンサルティング | 計画の策定の経験 |
| ⑤ 業務の受託 | 構築した仕組みの運用 |

**②と④が、任期付の経験と重なりやすい**です。

**計画を作り、仕組みを構築した経験**は、**支援する側の業務でそのまま使えます。**

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## よくある失敗

**1. 採用の趣旨を書かない**

**経歴の位置づけ**が伝わりません。

**2. 任期の満了を弁解する**

**制度の説明**で足ります。

**3. 作ったものを書かない**

**成果が形に残りやすい**立場です。

**4. 更新の可能性を確認しない**

**選択肢が1つ減ります。**

**5. 応募を始めるのが遅い**

**6か月前**を目安にしてください。

**6. 満了の時期を強みとして使わない**

**入社の時期を明確に示せます。**

**7. 他の団体の任期付を見ない**

**同種の募集があります。**

**8. 公表されていない内容を書く**

**守秘の義務は退職後も続きます。**

:::insight
ここまで制度の話をしておいて逆のことを言いますが、**任期付で得た経験は、分野の外でも使えます。**面談で拝見していると、**「この分野でしか働けない」と考える方**がいらっしゃいます。ところが、**任期付の方が担ってきた動作は、分野を問わず共通**しています。**外から入り、短期間で組織の事情を把握し、前例のない仕組みを作り、関係者を説得して動かす。**これは、**新しい事業の立ち上げ**で必要とされる動作そのものです。しかも、**役所という、手続きと合意形成に時間がかかる組織で実行してきた。**この経験は、**行政が相手の事業を立ち上げる会社**で高く評価されます。ですから、**分野の名前で候補を絞らないでください。**書類には、**「前例のない◯◯の仕組みを、関係課◯者との調整を経て構築」**と書いてください。**構築の過程そのものが、持ち運べる経験**です。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方公共団体の一般職の任期付職員の採用に関する法律第3条**は、**高度の専門的な知識経験又は優れた識見を一定の期間活用する**ために、任期を定めた採用ができるとしています
- **同法第6条第1項**は、**任期を5年を超えない範囲**と定めています
- **任期の満了は、予定どおりの経過**です。**勤務の評価によるものではありません**
- **更新・再度の採用の可能性**を、早めに人事担当に確認してください
- **作ったもの（計画、仕組み、要綱、手引）**を書いてください
- **満了の時期が決まっていることは、強み**です。入社の時期を明確に示せます
- **応募は、満了の6か月前**を目安に始めてください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 任期の更新は、期待してよいですか

**制度と条例、運用によります。**更新や再度の採用の可否は、**団体によって扱いが異なります。**また、**業務の必要性や予算の状況**にも左右されます。**確認の仕方は、人事担当に「任期の満了後の取扱いについて、制度の説明を伺いたい」で足ります。****時期も併せて確認**してください。なお、**可能性があっても、確定するのは満了の直前**ということがあります。**その場合、並行して外の選択肢も見ておく**ほうが確実です。**どちらかに絞る必要はありません。**扱いは[何社くらい受けるべきか](senko-sagasu-fukusu.html)に整理しています。

### 民間から任期付に入り、また民間へ戻る場合の説明は

**一貫した軸を示してください。**「民間で◯◯の経験を積み、行政の側から同じ分野に関わるために任期付として従事し、両方の立場を理解したうえで、再び◯◯に取り組みたい」という形です。**行き来したこと自体が、説明の材料**になります。**発注する側と受ける側の両方を知っている**という点は、**行政が相手の事業では強み**です。なお、**任期中に得たものを具体に示して**ください。制度の理解、手続きの流れ、関係者の動き方。**「戻る」のではなく「視野を広げて再び関わる」**という組み立てにすると、一貫します。

### 満了まで時間がなく、準備が間に合いません

**優先順位を付けてください。**最優先は、**①職務経歴書を1通仕上げること**です。次に、**②求人を読んで条件を絞ること**。この2つができていれば、応募は始められます。**実績の細かい整理は、後からでも間に合います。**なお、**満了の時期が決まっているため、入社の時期を明確に示せる**という強みがあります。これを伝えれば、**選考を急いでもらえる場合**があります。「◯月末で任期が満了するため、それまでに決めたい」と、**時期を先に伝えて**ください。紹介を通す場合、**この事情を踏まえて日程を調整**できます。扱いは[転職エージェントの使い方](senko-sagasu-agent.html)に整理しています。
