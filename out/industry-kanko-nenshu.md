観光・地域振興を検討される方から、**同じ順番で質問をいただきます。**

**「給与はどうなりますか」**

**「土日が休めなくなりますか」**

**1つ目に、当社が数字でお答えすることはできません。**組織ごとに事情が違いますし、**裏を取っていない数字を並べるのは、この記事の趣旨に反します。**

**2つ目のほうが、生活への影響は大きい**です。そして、こちらは**制度の仕組みから説明できます。**

この記事では、**何が根拠になっているか**と、**暦がどう変わるか**を扱います。業界の構造は[未経験から観光・地域振興に入るには](industry-kanko-mikeiken.html)にあります。

## 給与の根拠が、条例から就業規則に変わります

**いま、給与の根拠になっているのは条例です。**

**地方公務員法第24条第1項**は、**「職員の給与は、その職務と責任に応ずるものでなければならない」**と定め、**同条第2項**は、**生計費・国や他の地方公共団体の職員・民間事業の従事者の給与その他の事情を考慮して定められなければならない**としています。

**民間の組織では、この構造がありません。**

**労働基準法第89条**は、**常時10人以上の労働者を使用する使用者に、就業規則の作成と行政官庁への届出**を義務づけ、**記載事項として「賃金の決定、計算及び支払の方法、賃金の締切り及び支払の時期並びに昇給に関する事項」**を挙げています。

| | 役所 | 観光協会・地域の法人など |
|---|---|---|
| 根拠 | **条例** | **就業規則・給与規程** |
| 見られるか | **公表されている** | 在職者は見られる。応募時は要確認 |
| 規程の整備 | 完備している | **整備の途中のことがある** |
| 財源 | 予算 | **会費・補助・受託・自主事業** |

**3行目に注意してください。**

**職員が数名という規模の法人では、就業規則そのものが整備の途中**ということがあります。**それ自体が違法とは限りませんが、条件の確認のしかたが変わります。**

**⚠ 口頭での確認ではなく、書面で条件を示してもらってください。**

## 1か月単位の変形労働時間制という仕組みがあります

**観光の分野で、知っておいていただきたい条文**です。

**労働基準法第32条の2第1項**です。

> **使用者は、当該事業場に、労働者の過半数で組織する労働組合がある場合においてはその労働組合、労働者の過半数で組織する労働組合がない場合においては労働者の過半数を代表する者との書面による協定により、又は就業規則その他これに準ずるものにより、一箇月以内の一定の期間を平均し一週間当たりの労働**時間が（中略）**を超えない定めをしたときは、**（中略）**労働させることができる。**

**「一箇月以内の一定の期間を平均し」**です。

**[製造業の管理部門の年収と働き方](industry-seizo-nenshu.html)で扱った第32条の4が「一箇月を超え一年以内」だったのに対し、こちらは一箇月以内**です。

**観光の分野で使われる理由は、月の中で忙しい日と そうでない日がはっきり分かれるから**です。

| 時期 | 働き方 |
|---|---|
| 土日・祝日・連休 | **人が動くので忙しい** |
| 平日 | 準備と事務が中心 |
| 繁忙期（連休・夏・年末年始） | **まとまって忙しい** |
| 閑散期 | 企画と計画の時期 |

**⚠ この仕組みが適用される職種かどうかは、組織と職種によります。****面接で確認してください。**

**適用される場合、時間外労働の数え方が変わります。**所定の労働時間が日によって違うため、**「8時間を超えたら時間外」という単純な数え方にならない**ことがあります。

## 暦が、役所とずれます

**これが、この分野でいちばん大きな変化**です。

| | 役所 | 観光・地域振興 |
|---|---|---|
| 土日・祝日 | **休み** | **繁忙期**（職種による） |
| 大型連休 | 休み | **いちばん忙しい** |
| 年度末 | **忙しい** | 職種による |
| 平日 | 忙しい | **休みを取りやすい** |
| 議会の時期 | 忙しい | **受託が中心なら影響する** |

**[未経験から観光・地域振興に入るには](industry-kanko-mikeiken.html)でも触れましたが、これは良い面と難しい面の両方があります。**

**良い面は、平日に動けること。**役所や銀行の窓口、混まない時期の旅行、子どもの学校行事への平日の代休。

**難しい面は、ご家族が土日休みの場合**です。**家族と過ごす時間の作り方が変わります。**

**⚠ ただし、職種によります。****観光のコンサルタントや、行政からの受託が中心の法人**では、**平日中心の勤務**であることがあります。

## 職種別に整理します

| 職種 | 勤務の曜日 | 繁忙の波 | 役所との差 |
|---|---|---|---|
| 観光協会・地域法人の企画 | **土日の行事がある** | 連休・イベント | 中程度 |
| 観光協会の受入れ・案内 | **土日が中心** | 連休・シーズン | **差が大きい** |
| 地域商社の販売・物販 | **土日が中心** | 催事の時期 | 差が大きい |
| 宿泊事業者の管理部門 | 平日中心のことも | 繁忙期 | 中程度 |
| 観光のコンサルタント | **平日中心** | **年度末・計画の納期** | **近い** |
| 行政からの受託事業 | **平日中心** | **年度末** | **近い** |

**下の2つは、役所の暦とほとんど同じ**です。

**「観光に関わりたいが、土日は休みたい」という方**は、**この2つを軸に探してください。**

:::insight
面談で伺っていて、**この分野に移った方が最初に戸惑うのが「休みの取り方」**です。役所では、**年次有給休暇を自分の都合で取る**のが基本でした。観光協会や地域の法人では、**人が少ないため、自分が休む日の段取りを自分で作る**必要があります。誰に引き継ぐか、その日の来客や問い合わせをどうするか、前後の日で何を済ませておくか。**これは、係の中で休暇を回してきた方には、難しくありません。**むしろ、戸惑うのは**「繁忙期には休めない」という前提**のほうです。役所では、繁忙期でも年休は取れました。**この分野では、大型連休に全員が出る**ことがあります。そのかわり、**閑散期にまとまって休む**という組み方をしている組織もあります。ですから、確認していただきたいのは、**「年間の休日を、どういう形で取っていますか」**です。面接で聞けます。⚠ そして、**年次有給休暇の仕組みそのものは、役所も民間も同じ枠組み**です。**取れないのが当たり前という説明をされた場合は、その説明のしかた自体を判断材料にしてください。**制度の話と、運用の実態は別です。
:::

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 場面 | 効く理由 |
|---|---|
| 補助金の申請と実績の報告 | **交付する側の観点を知っている** |
| 受託事業の管理 | **仕様書と実績報告の読み書き** |
| 年度末の納期に合わせる | **予算・決算の日程で動いてきた** |
| 行政との協議 | 相手の意思決定の流れが読める |
| 会議体の運営 | 審議会・委員会の事務 |

**効きにくい場所**

| 場面 | 効きにくい理由 |
|---|---|
| 土日・連休の勤務 | **暦が逆になる** |
| 売上を作る | 予算を使う仕事とは方向が逆 |
| 来客・現場の対応 | **予定が来客で崩れる** |
| 少人数での兼務 | 分掌の外を自分で拾う |
| 価格の設定 | 値決めの判断を自分でする |

**1つ目が、生活に直結します。**難しい事情があるなら、**選考の早い段階で伝えてください。**

## 入る前に確認しておくこと

**労働基準法第15条第1項**は、**労働契約の締結に際して、賃金・労働時間その他の労働条件を明示しなければならない**と定めています。**明示すべき事項は、労働基準法施行規則第5条**に具体的に並んでいます。

**条件を示してもらうことは、権利として認められています。**

| 確認すること | どこで確認するか |
|---|---|
| 賃金の決定・計算・支払の方法、昇給 | **給与規程・労働条件通知書** |
| **期間の定めの有無** | **労働条件通知書** |
| 就業の場所と、従事すべき業務 | 労働条件通知書 |
| **土日・祝日の勤務の有無と頻度** | **面接で確認する** |
| **変形労働時間制の適用の有無** | **面接で確認する** |
| 年間の休日の取り方 | **面接で確認する** |
| その職の財源（補助・受託・自主事業） | **面接で確認する** |
| 就業規則の整備の状況 | 面接で確認する |

**2つ目を、必ず確認してください。**

**[未経験から観光・地域振興に入るには](industry-kanko-mikeiken.html)でも触れましたが、行政からの受託や補助を財源とする職で、期間が定められている**場合があります。**期間の定めがある場合、その後どうなる見込みかも聞いてよい質問**です。

**7つ目も重要です。**財源が受託や補助なら、**その期間が職の期間と連動する**ことがあります。

[経験の言い換えから相談する](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担です）。

| 聞かれること | 何を見られているか |
|---|---|

| 繁忙期に、どう対処してきましたか | 段取りの作り方 |
| 一人で複数の役割を担うことに抵抗はありますか | **少人数の組織への構え** |

**1つ目は、正直に答えてください。**難しい事情があるなら、**職種を調整してもらえる**ことがあります。

**5つ目に「特にありません」と答えないでください。**入ったあとに食い違う可能性を残します。

:::insight
ここまで確認の話をしてきましたが、**当社の見解を申し上げます。**この分野は、**「やりがい」で条件の確認が後回しになりやすい**領域です。地域への思い入れがある方ほど、**「条件の話をするのは失礼ではないか」**と感じられます。**そんなことはありません。**確認せずに入って、**土日の勤務が家庭の事情と合わずに短期間で辞める**ほうが、**採る側にとっても負担が大きい**のです。とくに、職員が数名という組織では、**一人辞めることの影響が大きくなります。**ですから、**条件の確認は、相手のためでもあります。**そして、確認の結果、**いまの職を続けるという結論になっても、それは正しい結論です。**面談でお会いする方の中には、**「地域に関わりたい」という気持ちを、転職でしか実現できないと考えている方**がいらっしゃいます。実際には、**在職のまま地域の活動に関わる道**もあります。⚠ ただし、**職員の兼業・副業については、所属の規程で扱いが定められています。**何ができるかは、**所属の人事担当部署に確認してください。**この記事では判断できません。当社が、いまの職を辞めることをお勧めすることはありません。
:::

## まとめ

- **給与の根拠が、条例から就業規則・給与規程に変わります**
- **地方公務員法第24条**は、給与が**職務と責任に応ずるもの**であること、**生計費・国や他団体の職員・民間事業の従事者の給与その他の事情を考慮して定められること**を定めています
- **労働基準法第89条**は、**常時10人以上の労働者を使用する使用者に就業規則の作成と届出**を義務づけています。⚠ **小規模な法人では整備の途中のことがあります**
- **労働基準法第32条の2**は、**一箇月以内の一定の期間を平均して**一週間当たりの労働時間を定める仕組みを規定しています。⚠ **適用の有無は組織と職種によります**
- ⚠ **暦が役所とずれます。**土日・祝日・大型連休が**繁忙期**になる職種があります
- **良い面（平日に動ける）と難しい面（家族と休みが合わない）の両方**があります。ご家族と先に話してください
- ⚠ **観光のコンサルタントと、行政からの受託が中心の法人は、平日中心**です。**土日を休みたい方は、この2つを軸に**探してください
- **労働基準法第15条**と**施行規則第5条**により、**条件の明示は権利**です。⚠ **期間の定めの有無と、その職の財源**を必ず確認してください
- ⚠ **「やりがい」で条件の確認を後回しにしないでください。**確認は、相手のためでもあります

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 給与が下がる前提で考えるべきですか

**組織と職種によるため、一概には言えません。**⚠ **当社が相場をお伝えすることはできません。**確認していただきたいのは、**総額だけでなく、構成**です。基本給と手当の内訳、昇給の仕組みがあるか、賞与の扱い。**給与の規程があるか、あるとして改定の実績があるか**も確認してください。規程が無い組織もあり、それ自体は違法とは限りませんが、**見通しの立て方が変わります。**また、**通勤や住居の条件も併せて考えてください。**地方の拠点であれば、**通勤の時間や住居の費用が変わる**ことがあります。**総額の比較だけで判断すると、生活の実感とずれます。**

### 期間の定めがある職は、避けたほうがよいですか

**一概には言えません。**確認していただきたいのは、**「その期間が終わったあと、組織がその職をどうする予定か」**です。**自主事業に切り替える計画がある、次の受託に乗せる見込みがある**という答えなら、**期間の区切りは一区切りであって終わりではありません。**一方、**「そのときは考えます」という答え**なら、**その期間で職が終わる可能性**を織り込んでおく必要があります。**あわせて、これまでの実績を聞いてください。**「期間の満了後に継続された方はいらっしゃいますか」。**役所で補助や委託を交付する側にいた方なら、財源の継続の見込みは読めるはず**です。その読みを使ってください。

### 移住を伴う場合、何を確認すべきですか

**住まい、通勤、家族の就業と就学**の4つです。**住居の支援がある組織**もありますが、**自己負担の額、利用できる期間、退去の条件**を確認してください。通勤については、**自動車が前提になる地域**が多いため、**免許と車の確保**が必要かを見てください。ご家族が一緒に移る場合、**配偶者の就業先と、お子さんの就学先**の見通しが、判断の中心になります。⚠ **自治体によっては移住に関する支援の制度がありますが、要件と内容は自治体ごとに違います。****移住先の自治体の公表を確認してください。**当社が確認していない制度の内容は、この記事には載せていません。**先に現地を訪ねておく**ことも、強くお勧めします。
