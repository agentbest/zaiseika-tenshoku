設計事務所の選考を調べるときは、会社名に加え、建築設計、都市計画、企画営業、事務等のどの職務かを先に確認します。公務員として発注や許認可に関わったことを、自ら設計や専門判断を行った経験へ置き換えず、本人の工程から照合します。

本記事は2026年11月時点の公開情報にもとづきます。確認日は2026年11月25日です。公式のキャリア募集を例に選考準備を整理します。面接の「観点」は本人が準備する項目であり、非公開の質問、採点、面接官の心理や通過率を推測するものではありません。

## 総合設計の仕事と、一人の担当を分ける

日本設計の公式な仕事紹介は、建築だけでなく、都市、構造、設備、監理やコスト等の専門領域が協働する仕事を説明しています。構想から実現まで関わるという会社全体の役割と、応募者が担当する工程は同じではありません。

日建設計の募集要項にも、技術系の複数領域と、事務・営業・広報等の区分があります。設計事務所へ入ることを、全員が建築設計を行うことと一つにしないでください。関係する相手、成果物、判断範囲を個別の募集で確認します。

正式な法人も区別します。日本設計と日建設計は別の会社であり、日建設計の案内にもグループ各社の応募先を別途確認する説明があります。似た名称、グループのブランド、採用システムの運営者を混ぜず、契約上の雇用主と職務を対応させます。

行政側として設計者の説明を受けた立場、委託の担当、許認可の手続き、自ら計画や設計を行う立場も分けます。公務で関係した案件と同じ分野であっても、必要な実務や資格があるかは独立した確認です。

[行政に接点のある掲載求人を見る](../?gov=1)ときも、会社の分類の次に正式な職務を確認できます。設計事務所や希望領域の求人が常に掲載されるとは限りません。

## 公開された試験内容と、本人への日程案内を分ける

日本設計の確認した建築設計、都市計画、企画推進の募集には、書類審査、適性検査、面接という試験内容が記載されています。応募方法では必要書類を郵送し、書類を通過した方へ面接を行うと案内されています。これを他社の共通フローにはしません。

確認した記載だけでは、本人の面接回数、適性検査の具体的な形式、実施日時は確定できません。募集にある試験内容の一覧から、未公開の細かい順番や面接質問を作らないようにします。正式な案内の職名、提出物、期限、実施方法を確認してください。

日建設計の公式応募入口は、希望する職種を選び、該当する求人から応募する方式を案内しています。一般の募集要項と、実際に選ぶ職務の内容を照合します。海外現地法人の応募案内や新卒採用の案内を、本人の国内キャリア採用へ混ぜないことが必要です。

応募を送ったことと面接が決まったこと、面接で希望を話したことと条件が確約されたことも別です。選考状況のメモでは、書類作成、本人確認、提出、案内受領を分けて記録できます。連絡の速さから合否や採用側の事情を予想しないようにします。

## 専門実務と資格は、必須と歓迎を区別する

日本設計の建築設計募集は、対象業務の実務経験と一級建築士の資格を必要としています。都市計画の募集は、関連する調査・計画立案や事業推進の実務経験に加え、技術士、一級建築士、再開発プランナーのいずれかを必要資格として示しています。

実務と資格をどちらか一つでよい条件に変えません。資格を学習していることと、資格を持っていることも別です。この説明は求人の条件であり、資格法上の業務範囲をこの記事で判断するものではありません。

企画推進は必要資格なしと記載されていますが、建築設計・関連領域での企画と営業の実務経験を求めています。行政の発注担当として受注者へ連絡したことを、そのまま受注側の営業実務としないでください。資格不要を実務経験不要へ読み替えません。

日建設計の一般のキャリア要項には、募集職での実務経験3年以上と、国内外で勤務可能であることが示されています。資格や語学は歓迎として記載されています。日本設計の必要資格と日建設計の歓迎を混ぜず、個別の職務の最新の条件も照合します。

## 提出する実績資料は、本人の工程と権限を示す

日本設計の建築設計の募集は個人作品集、都市計画は職務経歴や個人業務実績・作品事例、企画推進は業務実績を紹介する資料など、職務ごとに提出物が異なります。規定の履歴書や用紙・サイズの指定も、当該の職務で確認してください。

作品や実績を求められても、行政で保管する図面や内部文書を自由に持ち出してよい意味ではありません。本人が作成した部分、委託先の設計、上司の決裁、公開・利用できる範囲を分けます。提出できない資料はその範囲を守って説明します。

公表済みの事業であっても、委託先の図面を本人の設計作品にしないでください。本人は要求条件の確認や会議の調整を行ったなら、その工程を説明します。専門的な計算や設計を行っていなければ、未経験と残します。

:::insight
公務で設計者と連絡した経験を説明するときは、本人が確認した条件と、専門家が行った設計を分けることを勧めます。会議の論点を整理し、関係課の回答をそろえた工程は本人の事実ですが、図面や計算の作成経験にはなりません。作品や実績を求められる場合も、組織全体の成果を本人の制作物として扱わず、担当範囲と他者の判断を示します。これは面接官の採点を予想する方法ではなく、公開職務と本人の経験をそろえる方法です。必要資格や実務が不明なら、それを大きな表現で埋めず、対象範囲を質問に残せます。未経験の工程も初期の役割を確認する材料になります。
:::

## 独立した架空例で、選考前の照合表を作る

以下はこの記事だけの架空例です。実在の応募者や選考事例ではなく、会社の回答も設定していません。本人の事実へ置き換え、未実施の作業を削除してください。

| 項目 | 架空の本人による記入 |
|---|---|
| 関心のある工程 | 都市や施設の検討に関わる資料整理と関係者調整 |
| 本人の実務 | 発注側として要求条件の担当箇所を確認し、関係課への質問をまとめた |
| 他者の役割 | 設計と専門計算は委託先、方針決定と契約の決裁は上司 |
| 接点として示す作業 | 条件照合、会議の論点整理、回答のとりまとめ |
| 未経験 | 自らの建築設計、専門的な構造計算、受注営業 |
| 要件の確認 | 資格の保有状況と担当期間を本人の事実で確認し、個別要件へ照合する |
| 提出物の確認 | 作品や実績の指定を確認。内部図面は持ち出さない |
| 選考の状況 | 公式募集を読了。応募は未実施 |
| 未確認 | 本人の実務が対象へ含まれるか、初期役割、契約と勤務条件 |
| 次の行動 | 正式な法人と職名を記録し質問を整理する |

この例は、発注の経験だけで設計職へ応募条件を満たすという設定ではありません。資格も架空の保有状態を付けていません。本人の事実で要件を確認し、接点と未経験を分けるための表です。

[担当経験と応募要件の対応を相談する](../apply.html)場合も、内部図面や契約資料を添えず、自分の工程を説明するメモを使えます。ご利用は無料です（紹介手数料は採用企業の負担）。経験や希望によっては、面談・求人紹介を提供できない場合があります。

## 契約と勤務条件も、職務ごとに確認する

日本設計の確認した建築設計、都市計画、企画推進の欄には、1年間の有期契約、条件に基づく更新、通算3年の上限、試用2か月という記載があります。社員登用の実績もありますが、本人の更新や登用を保証する意味にはしません。

同じ会社の別職務に違う条件がある場合、その内容を混ぜないようにします。有期であることと、将来の社員登用の紹介を別に記録します。正式な期間や更新、試用中の条件、雇用主を本人への提示で確認してください。

勤務地は現在の場所と変更範囲を分けます。日建設計の国内外勤務可能という条件や、日本設計の国内外の事業所・現場等への変更範囲を、本人が希望する場所へ固定される保証に変えないでください。

フレックスや在宅勤務の制度が紹介されていても、担当する顧客対応や現場の予定、出社の必要を本人だけで自由に決められるとは限りません。初期にどの業務を担い、どの時間と場所で連携するかを確認します。制度の存在と本人への適用を別に扱います。

## 情報管理を守り、現職も比較する

住民や事業者の情報、非公開の計画、内部の契約・調達・許認可の情報を持ち出したり、私用AIへ入力したりして応募原稿を作らないでください。名前だけ消せば自由に利用できるとも判断せず、公開情報と本人の工程で説明します。

現職の行政上の便宜や内部人脈を、受注のために提供できることを強みにしません。経験は、条件の確認、説明、関係者との連携等として示せます。現在の権限を転職先へ渡す約束にはしないようにします。

募集の確認日と職名を残し、更新があれば以前の条件と分けて読み直します。質問したことと回答を受けたことも別に記録し、一般の制度の紹介と本人の予定業務への説明を確かめます。未確認の条件を前提に、住居や退職の予定を先に確定しないでください。

説明に使う事例は、対象期間も工程ごとにそろえます。プロジェクトに在籍した期間と、本人が設計や調整を担当した期間は同じとは限りません。途中から担当した場合は、引継ぎ後に行った作業を説明します。既存の検討資料を更新したことを、自分が構想全体を立案した経験へ変えないでください。前任者や専門家の成果と本人の行動を分けると、追加の説明でも範囲を保てます。

事例の結果も、提出した資料、関係者へ確認した事項、方針決定の有無に分けられます。本人が改善案を示しただけの段階なら、設計や工事が完了した結果まで加えません。公表された事業の効果がある場合でも、それを本人だけの成果として記載しないことが必要です。測っていない工期や費用の削減率を作らず、確認できた内容を示します。

面接の案内を受ける前に、未経験の工程について質問を整理できます。自分の実務が条件へ含まれるかという質問と、入職後にどの責任を任されるかという質問は別です。資格の保有や本人の勤務条件についても、不明点を予想で埋めません。窓口から説明を受けた場合は、会社全体の可能性を示したのか、本人の予定役割への回答なのかを確認します。

提出資料は指定の形式と内容を優先して点検します。手書きの履歴書やサイズの指定がある職務では、その案内を確認し、別職務の書類だけで足りると判断しません。提出前の本人確認と、実際の送信・郵送を別に記録することもできます。案内の宛先と対象職務を、送る前にもう一度照合してください。

本人が必須とする条件と調整できる希望を分けます。特定の地域で働く必要があることと、将来専門分野を深めたいことは別です。在職中に要件や仕事を調べる進め方もあり、応募を始めたことだけで退職を先に決める必要はありません。

[行政に接点のある掲載求人を比較する](../?gov=1)際は、現職を含め、本人が担いたい工程と働く条件を並べられます。

:::insight
都市や建築に関心があっても、発注側で条件を整理したいのか、自ら設計や提案を担いたいのかで選ぶ役割は変わります。現職で希望する工程を深められるなら、残る判断も比較対象です。面接の案内や会社への関心を、必要な実務や資格、勤務場所が合う根拠にしないようにします。本人の必須条件と調整できる希望を分け、未確認の項目を質問へ残すことを勧めます。登用実績や柔軟な制度も本人への保証ではありません。担当する責任と正式な条件がそろう時点まで調べ、応募や選考の進行だけで退職を決めず、仕事と生活の両面で進路を考えられます。
:::

## まとめとよくある質問

設計事務所の選考は、法人と職務ごとの実務・資格・提出物を確認します。発注や許認可の担当と設計実務を分け、未確認の質問や条件を作らずに準備してください。

### 資格があれば設計職へ応募できますか

資格と実務の条件は別です。紹介した募集にも両方を求める職務があります。学習中と保有も分け、本人の実務と最新の原文を照合します。

### 発注した案件の図面を作品集へ使えますか

自由に使えるとは判断できません。本人と委託先の担当、公開・利用できる範囲を確認し、他者の設計を自分の作品にしません。秘密や個人情報も持ち出しません。

### 面接は何回ですか

確認した募集の試験内容だけでは本人の回数は確定できません。正式な案内で日時、検査、提出物等を確認します。他職務や新卒のフローを転用しないでください。
