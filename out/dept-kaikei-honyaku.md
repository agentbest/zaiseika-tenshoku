会計課や出納室から転職しようとすると、たいてい「経理」という言葉に行き着きます。

間違いではありません。ただ、それだけで探すと**求人の幅がかなり狭くなります。**会計課の仕事は、民間でいう経理より広い範囲を含んでいるからです。支払の実行、資金の管理、物品や有価証券の保管、そして支出が適正かどうかの審査。これらは民間では別々の部署に分かれていることがあります。

この記事では、会計課・出納室の仕事を分解して、それぞれが求人票でどう書かれているかを並べます。訳語が分かれば、検索する言葉も応募先の選び方も変わります。

## 会計課・出納室が制度上どこに立っているか

先に、この部署の立ち位置を押さえます。ここが、民間に説明するときのいちばんの材料になります。

地方自治法第170条第1項は、法律又はこれに基づく政令に特別の定めがあるものを除くほか、**会計管理者は、当該普通地方公共団体の会計事務をつかさどる**と定めています。

そして第2項が、その会計事務を例示しています。

1. **現金の出納及び保管**（現金に代えて納付される証券、基金に属する現金を含む）
2. **小切手を振り出すこと**
3. **有価証券の出納及び保管**（公有財産又は基金に属するものを含む）
4. **物品の出納及び保管**（使用中の物品に係る保管を除く）
5. **現金及び財産の記録管理**
6. **支出負担行為に関する確認**
7. **決算を調製し、これを長に提出すること**

第171条は、会計管理者の事務を補助させるため**出納員その他の会計職員を置く**と定めています。

そして、いちばん重要なのが第232条の4です。

第1項は、**会計管理者は、長の命令がなければ、支出をすることができない**。

第2項は、**その命令を受けた場合においても、支出負担行為が法令又は予算に違反していないこと、及び債務が確定していることを確認したうえでなければ、支出をすることができない**。

ここを読み違えないでください。

**命令する人と、実際に払う人が分かれています。**そして、**払う側は命令に従うだけではなく、自分で確認する義務を負っています。**

これは民間でいう**職務分離**そのものです。発注する人と支払う人を分け、支払う側が独立して確認する。内部統制の教科書に出てくる型を、会計課は法律に基づいて毎日運用しています。

## 会計課・出納室が実際にやっていること

制度の枠の中で、担当が手を動かしているのはおおむね次の仕事です。

- 支出命令を受けて、支出負担行為の内容と証拠書類を審査する
- 審査を通ったものについて、支払を実行する
- 収入の調定と収納の処理、収納状況の把握
- 指定金融機関とのやり取り、公金の管理
- 資金の残高を見て、支払の日程を調整する
- 物品や有価証券の出納と保管、台帳の管理
- 例月出納検査、決算審査、監査への対応
- 決算を調製し、長に提出する
- 公会計の財務書類（貸借対照表、行政コスト計算書など）の作成

**審査で差し戻す**のが、この部署の中心にある仕事です。契約書がない、検収の記録がない、予算の費目が違う、債務が確定していない。これらを見つけて返す。返される側からすれば、面倒な部署に見えます。

ただ、これは担当者の性格の問題ではありません。**第232条の4第2項が、確認しないまま払うことを禁じている**からです。

## 出納整理期間と例月出納検査――外から説明しにくい2つ

会計課の仕事のうち、民間の人に説明しにくいものが2つあります。どちらも、説明できると強い材料になります。

**1つは、出納整理期間です。**

地方自治法第235条の5は、**普通地方公共団体の出納は、翌年度の5月31日をもって閉鎖する**と定めています。

会計年度は3月31日に終わりますが、出納は5月31日まで開いています。3月末までに債務が確定した支出を、4月と5月に処理できるということです。

民間には、この期間に対応する仕組みがありません。だから「年度末が2回来る」という感覚は、そのままでは伝わりません。**説明するなら、「決算の締めが2段階になっている」と言い換えてください。**実務としては、4月から5月にかけて前年度分と当年度分を並行して扱うことになります。これは民間でいえば、**期をまたいだ仕訳を2か月間並行処理する**のに近い形です。

**もう1つは、例月出納検査です。**

第235条の2第1項は、**普通地方公共団体の現金の出納は、毎月例日を定めて監査委員がこれを検査しなければならない**と定めています。第3項では、検査の結果に関する報告を議会と長に提出しなければならない、とされています。

**毎月、外部の目が入る。**しかも結果は議会に報告される。

民間で毎月これがある企業は多くありません。会計課の担当は、**常に第三者が見る前提で帳簿と証拠書類を整えてきた**ことになります。この習慣は、内部統制や監査の求人でそのまま評価されます。

## 庁内の言葉と、求人票の言葉の対応

ここからが本題です。上の仕事は、求人票では別の言葉で書かれています。

| 庁内での言い方 | 求人票での言い方 |
|---|---|
| 支出負担行為の確認・審査 | 支払審査、購買統制、内部統制、経費精算の承認 |
| 支出命令に基づく支払の実行 | 支払業務、決済業務、買掛金管理 |
| 収入の調定・収納 | 売掛金管理、入金消込、債権管理 |
| 指定金融機関とのやり取り | 銀行対応、金融機関折衝、決済インフラの運用 |
| 資金の残高管理と支払日程の調整 | 資金繰り、資金管理、トレジャリー |
| 物品の出納・保管、台帳 | 在庫管理、固定資産管理、購買 |
| 有価証券の出納・保管 | 有価証券管理、資産管理 |
| 現金及び財産の記録管理 | 記帳、固定資産台帳の整備 |
| 決算の調製 | 決算業務、月次・年次決算、開示資料の作成 |
| 公会計の財務書類の作成 | 財務諸表の作成、連結決算 |
| 例月出納検査・監査への対応 | 監査対応、内部監査対応 |
| 会計規則・要領の整備 | 規程整備、業務設計、統制文書の作成 |

並べてみると、**経理だけでなく、財務・購買・内部統制の3領域にまたがっている**ことが分かります。ひとつの課で全部を見ているのは、民間ではむしろ珍しい形です。

:::insight
会計課の方の書類で、いちばんもったいないのが**「出納事務を担当」で止めてしまうこと**です。求人票にこの言葉はありません。同じ仕事は「支払審査」「内部統制」「買掛金管理」と書かれています。とくに**「支出負担行為の確認」を内部統制の言葉に置き換えられていない方が多い**です。これは地方自治法第232条の4第2項が定めた独立した確認義務で、民間でいえば職務分離の要になる工程です。検索する語を「経理」から「支払審査」「購買統制」「内部統制」に変えるだけで、出てくる求人の層が変わります。言葉を持っていないだけで、自分に合う求人が最初から視界に入っていない方が少なくありません。
:::

## この経験がとくに高く評価される場所

同じ会計課出身でも、行き先によって値の付き方が変わります。大きく3つです。

### 1. 経理・財務

いちばん自然な接続先です。決算、支払、資金管理をそのまま持ち込めます。

ここで効くのは、**件数の多さと、締切が動かないこと**です。会計課は自治体のすべての支払を通す部署なので、扱う件数が多く、しかも年度末と出納整理期間という動かない締切があります。この環境で正確さを保ってきた経験は、そのまま実務経験として読まれます。

公会計の財務書類を作っていた経験があれば、**発生主義の考え方を一度通っている**ので、複式簿記への接続も説明しやすくなります。

[財政・会計の経験が効く求人を見てみる](../?fin=1)

### 2. 内部統制・監査

近年、求人が増えている方向です。

会計課の「支出負担行為の確認」は、**命令する人から独立して確認する**という構造そのものです。この構造を制度として運用してきた人は、企業の内部統制部門で必要とされる視点を最初から持っています。

しかも会計課の場合、**差し戻した経験がある**という点が強い。統制の仕組みを作る人は多くても、実際に止めた経験がある人は多くありません。

### 3. 自治体を顧客にする金融・システム

指定金融機関の担当部署、公金収納のサービス、自治体向けの財務会計システムを扱う企業です。

ここでは、**会計課の実務を知っていること自体が希少**です。支出命令がどう回り、どの書類が必要で、どこで止まるのか。外から見ても分かりません。システムの導入で現場が止まる原因の多くは、この理解の欠落から来ます。

[行政が相手の求人を見てみる](../?gov=1)

## 職務経歴書でつまずきやすい点

**1. 「正確さ」だけで書いてしまう**

「正確な事務処理を心がけた」は、書いても何も伝わりません。正確なのは前提だからです。**何件を、どの基準で審査し、どのくらい差し戻したか**を書いてください。件数と基準が入ると、同じ内容が実務経験として読まれます。

**2. 差し戻した話を書かない**

財政課の「落とした案件」と同じ構造です。差し戻しは後ろ向きに見えると考えて書かない方が多いのですが、**逆です。**止めた経験は、内部統制の文脈でいちばん強い材料になります。

**3. 簿記の有無で判断してしまう**

「簿記を持っていないから経理は無理」と考えて、最初から候補を外してしまう例があります。公会計の財務書類を作っていたなら、発生主義の考え方は通っています。**資格の有無より、何を作っていたかを先に書いてください。**

**4. 制度の説明に紙幅を使う**

支出負担行為や調定の仕組みを丁寧に説明してしまうケースです。読み手は制度の解説を求めていません。**制度は1〜2行に畳み、自分が何を判断したかに紙幅を使ってください。**

自分の経歴がどう言い換えられるかは、一度話しながら整理したほうが早いことが多いです。[どの経験に値が付くのかから相談できます](../apply.html)。

:::insight
ここまで書いておいて逆のことを言いますが、**会計課にいるうちに動かないほうがよい場合もあります。**とくに、**決算を一度も通していない段階**です。出納整理期間から決算の調製、監査委員の審査、議会の認定までを一度通ると、書けることの厚みがはっきり変わります。もう一つ、**公会計の財務書類の作成に関わる機会があるなら、それを待つ価値があります。**発生主義に一度触れているかどうかで、経理・財務の求人での説明のしやすさが変わるためです。異動の希望が出せる時期なら、そちらを先に確かめるのも十分に理のある判断です。転職は、選択肢を増やすための手段であって、目的ではありません。
:::

## まとめ

- 地方自治法第170条は、会計管理者の会計事務を**現金の出納、小切手の振出し、有価証券・物品の出納、記録管理、支出負担行為の確認、決算の調製**の7つで例示しています
- 第232条の4は、**会計管理者は長の命令があっても、法令・予算への適合と債務の確定を確認したうえでなければ支出できない**としています。**命令する人と払う人が分かれ、払う側が独立して確認する**構造です
- これは民間でいう**職務分離**そのもので、内部統制の要になる工程です
- 庁内の「出納事務」は、求人票では**「支払審査」「買掛金管理」「資金管理」「内部統制」**と書かれています。**検索する言葉を変えるところから始めてください**
- 評価が高くなるのは、**経理・財務／内部統制・監査／自治体を顧客にする金融・システム**の3方向です
- 職務経歴書では、正確さではなく**件数・審査の基準・差し戻した経験**を書いてください

在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。

## よくある質問

### 簿記の資格がないと、経理の求人は難しいですか

応募先によります。書類選考の材料として効く場面はありますが、**「簿記を取れば転職できる」という関係ではありません。**公会計の財務書類を作っていた経験があれば、発生主義の考え方は一度通っているので、学習そのものは進みやすいはずです。一方、自治体向けのシステムや金融の企業では、簿記より**会計課の実務を知っていること**のほうが評価されます。**先に応募先の方向を決めてから、必要かどうかを判断してください。**

### 会計課と財政課では、どちらが転職に有利ですか

有利・不利ではなく、**接続先が違います。**財政課は経営企画・財務企画の方向に、会計課は経理・財務と内部統制の方向に接続しやすくなります。会計課のほうが、民間の職種としての対応が明確なぶん、求人を探しやすい面があります。財政課の側は[財政課の経験は民間で何と呼ばれるか](dept-zaisei-honyaku.html)に整理しています。

### 出納員の発令を受けていたことは、書類に書けますか

書けますし、書いたほうがよい情報です。地方自治法第171条に基づく発令で、**現金の出納や物品の出納を自分の名義で扱う立場**だったことを示します。ただし制度名だけでは伝わらないので、「現金の出納について権限を委任され、年間◯件を処理した」のように、**権限の中身と扱った量を添えてください。**
