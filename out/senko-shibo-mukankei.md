自治体を顧客とする会社なら、経験はそのまま使えます。**書き方は**[自治体向け事業の会社への志望動機](senko-shibo-govmuke.html)**にあります。**

**問題は、行政とほとんど関係のない業界に応募する場合**です。

消費者向けの事業、製造業、流通、飲食。**顧客も、扱う制度も、これまでとは重なりません。**

この記事では、**その場合の組み立て**を扱います。

## 業界を選ぶことは、自由です

**前提として、確認しておきます。**

**日本国憲法第22条第1項**です。

> 何人も、公共の福祉に反しない限り、居住、移転及び**職業選択の自由**を有する。

**職業選択の自由。**

**どの業界を選ぶかは、本人が決めることです。**

**「公務員だから、行政関係の仕事に行くべき」ということはありません。**

ただし、**説明の難易度は上がります。**顧客も制度も重ならないぶん、**接続を自分で作る必要があるから**です。

## 接続できるのは、機能だけ

| 接続の種類 | この場合 |
|---|---|
| 同じ顧客 | **使えません** |
| 同じ制度 | 使えないことが多い |
| **同じ機能** | **ここで接続します** |
| 同じ困りごと | 使える場合がある |

**機能で接続する、というのが基本の方針**です。

**機能とは、「何をしていたか」**です。

| 機能 | 行政と関係ない業界での対応 |
|---|---|
| 債権の管理と回収 | 通信、小売の未収金、リース |
| 申請の審査 | 保険の査定、与信の審査、会員の審査 |
| 契約と調達 | 製造業の購買、外注の管理 |
| 窓口の運営 | 顧客の対応の部門、サポートの運営 |
| 記録と文書の管理 | 品質の記録、内部統制の文書 |
| 統計と分析 | 販売の分析、需要の予測 |

**右側は、いずれも行政と無関係な業界にある仕事**です。

**「役所の仕事は特殊だから使えない」ということはありません。**

## 業界を選んだ理由が要る

**機能で接続できても、「なぜこの業界か」は別に必要**です。

**ここが、いちばん難しい部分**です。

| ✕ | ○ |
|---|---|
| 「新しい分野に挑戦したい」 | **その業界の何に関心があるか**を具体的に |
| 「成長している業界だから」 | 業界の成長が、**自分の仕事とどう関わるか** |
| 「幅広い経験を積みたい」 | **その業界で何を担うか** |

**業界を選んだ理由の材料**を挙げます。

| 材料 | 内容 |
|---|---|
| 利用者としての経験 | その業界のサービスを使ってきた実感 |
| 役所での接点 | 許認可、指導、統計で接したことがある |
| 課題の認識 | その業界が抱える課題を知っている |
| 機能の需要 | 自分の機能が、その業界で不足している |

**4つ目が、いちばん説明しやすい**です。

> 製造業では、品質に関する記録の管理と、監査への対応が求められると理解しています。私は、監視指導の側で記録の様式を整備し、検査に対応してきました。その経験が、記録を作る側でも使えると考えました。

**「業界に関心がある」ではなく、「この業界に、自分の機能の需要がある」**という筋です。

## 未経験であることを認める

**行政と関係のない業界では、業界の知識がありません。**

**これを隠さないでください。**

> 業界の商習慣や、実際の業務の進め方については分かっていません。入社後に覚える必要があると考えています。

**そのうえで、「何なら持ち込めるか」を述べてください。**

**分かっていないことを認めたうえで、持ち込めるものを示す。**この形が、いちばん信頼されます。

:::insight
行政と関係のない業界に応募する方に、**面談で伺っているのが「なぜ、行政関係を選ばないのか」**です。経験がそのまま使える選択肢があるのに、**あえて使わない理由**があるはずだからです。多くの方の答えは、**「同じ相手と同じ仕組みの中で働き続けることに、区切りをつけたい」**という趣旨になります。**それは、正当な理由**です。そして、**面接でも同じことを聞かれます。**「自治体向けの会社のほうが、経験が活きるのでは」。**この問いに答えを用意しておいてください。**答え方としては、**「経験が活きる度合いより、扱う対象を変えたいことを重く見ました」**という形があります。**経験が活きないことを認めたうえで、それでも選ぶ理由を述べる。**この筋が通っていると、**業界の知識がないことは、大きな問題になりません。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

**③を書くと弱くなると考える方がいますが、逆です。**知らないことを知っていると述べる人のほうが、**入社後の立ち上がりを見積もりやすい**と受け取られます。

## 志望動機の型

| 段 | 内容 |
|---|---|
| ① 業界を選んだ理由 | **自分の機能の需要がある**という筋で |
| ② 機能での接続 | 具体的な場面と数字 |
| ③ 分かっていないこと | 業界の知識は未経験だと認める |
| ④ 入社後の行動 | 最初に何をするか |

**③を入れるのが、この場合の特徴**です。

**自治体向けの会社であれば、③は要りません。**知識があるからです。

**関係のない業界では、③があるほうが誠実に受け取られます。**

## 役所での接点を、思い出しておく

**「行政と関係がない」と思っている業界でも、接点があることがあります。**

| 接点の形 | 例 |
|---|---|
| 許認可・届出 | 飲食、旅館、理美容、薬局、運送、建設 |
| 補助金・助成 | 製造業の設備投資、商店街、農林水産 |
| 統計の調査 | 事業所の調査、経済に関する統計 |
| 指導・監査 | 食品、環境、労働、廃棄物 |
| 入札の参加 | 物品の納入、印刷、清掃、警備 |

**5つとも、役所の側から接してきた場面**です。

**その業界の会社が、行政に対してどういう手続きをしているかを知っている**ということは、**その会社の中では希少な知識**です。

**たとえば、許認可の更新の時期や、必要な書類の実態を知っている。**これは、総務や管理の部門で役立つ知識です。

**「関係がない」と決める前に、自分が接したことのある業界かどうかを確認してください。**接点があれば、志望動機の材料になります。

## 業界研究の最低限

**応募の前に、次の3つは確認してください。**

| 確認 | 見る場所 |
|---|---|
| その業界の顧客は誰か | 公式サイト、業界の解説 |
| 収益はどこから生じるか | 事業の説明 |
| その会社の位置づけ | 同業他社との比較 |

**3つとも、公表されている情報で分かります。**

**深い知識は不要ですが、この3つを知らずに応募すると、面接の会話が成立しません。**

[経験の言い換えから相談する](../apply.html)こともできます。

**なお、接点があった場合でも、特定の事業者の情報は書けません。**地方公務員法第34条の守秘の義務は、退職後も続きます。書けるのは、**制度上そうなっている一般的な事柄**までです。

## よくある失敗

**1. 「挑戦したい」で業界の理由を済ませる**

**その業界である理由**になりません。

**2. 機能での接続を書かない**

**唯一の接続点**です。

**3. 業界の知識があるふりをする**

**面接の会話で崩れます。**

**4. 「なぜ行政関係を選ばないのか」に答えを用意していない**

**必ず聞かれます。**

**5. 業界の基本を調べずに応募する**

**会話が成立しません。**

**6. 経験が使えないと決めつける**

**機能は、どの業界にもあります。**

:::insight
ここまで書き方の話をしておいて逆のことを言いますが、**行政と関係のない業界を選ぶ場合、通過する割合は下がることが多い**です。理由は単純で、**経験の対応が薄いから**です。同じ求人に、**その業界の経験がある応募者**がいれば、そちらが選ばれます。**これは、書き方では補いきれません。**ですから、**この方向で進める場合は、応募の件数と期間を長めに見込んでください。**在職中であれば、**急ぐ必要はありません。**そして、**候補を1つの業界に絞らないでください。**行政関係の求人も並行して見ておくと、**比べる材料ができます。**面談で伺っていると、**両方を見た結果、行政関係を選んだ方**も、**関係のない業界を選んだ方**も、どちらもいらっしゃいます。**比べたうえで決めるのが、いちばん納得できます。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **日本国憲法第22条第1項**は、**職業選択の自由**を定めています。**どの業界を選ぶかは、本人が決めることです**
- 接続できるのは、**機能だけ**です。債権の管理、審査、調達、窓口、記録、分析
- **業界を選んだ理由が別に必要**です。「自分の機能の需要がある」という筋が説明しやすい形です
- **業界の知識がないことは、認めてください。**そのうえで、持ち込めるものを示します
- **「なぜ行政関係を選ばないのか」への答え**を用意してください
- 応募の前に、**顧客・収益の源・会社の位置づけ**の3つは確認してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 業界の経験がないと、書類で落ちますか

**求人票の応募条件によります。**「◯◯業界での経験」が必須なら、**書類の段階で通りにくい**です。一方、「顧客折衝の経験」「業務改善の経験」といった**機能で書かれた条件**であれば、業界が未経験でも応募できます。**応募条件の書かれ方を見てください。**なお、**未経験者を対象とした募集**もあります。その場合は、**立ち上がりの速さと、学ぶ姿勢**が見られます。示し方は[学習意欲をどう示すか](senko-mensetsu-manabi.html)に整理しています。**業界の経験がないこと自体は、応募できない理由にはなりません。**

### 志望動機で、前職の話をどのくらい書きますか

**②の機能での接続の部分だけ**で足ります。全体の半分程度です。**役所の業務の説明が長くなると、読む側が追えません。**とくに、行政と関係のない業界では、**制度の説明をされても分からない**ためです。書くときは、**制度の名前を出さずに、機能で書いてください。**「生活保護の決定を担当」ではなく、「申請の内容を確認し、要件に該当するかを判断して決定する業務を、年間約◯件担当」という形です。**業界の外の人が読んで分かる言葉**にしてください。

### 年齢が上がるほど、業界を変えるのは難しくなりますか

**年代によって、求められるものが変わります。**20代・30代前半であれば、**立ち上がりの速さと学ぶ姿勢**が見られます。40代以降では、**入社直後に持ち込めるもの**が重く見られます。したがって、**年代が上がるほど、機能での接続を具体的に書く必要**があります。「管理の経験」「折衝の経験」といった、**業界を問わず使える機能**を前に出してください。なお、**業界を変えると処遇が下がることがあります。**この点は、[「年収が下がっても大丈夫か」への答え方](senko-mensetsu-nenshudown.html)に整理しています。**条件も含めて判断してください。**
