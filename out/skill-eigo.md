**「転職のために英語を勉強すべきか」**というご相談を伺います。

**答えは、職種によって分かれます。**

この記事では、**必要になる職種**と、**ならない職種**を扱います。

## 行政の側でも、場面はあります

**地方自治法第10条第2項**です。

> **住民は、法律の定めるところにより、その属する普通地方公共団体の役務の提供をひとしく受ける権利を有し、その負担を分任する義務を負う。**

**同条第1項**は、**市町村の区域内に住所を有する者を住民**としています。

**国籍による区別は、条文に置かれていません。**

**つまり、外国籍の住民も、この条の住民に含まれます。**

**したがって、窓口や相談の場面で、言語の対応が必要になることがあります。**

**すでに経験している方もいらっしゃるはず**です。

**その経験は、書類に書ける材料**になります。

## 何が求められるか——技能を分ける

| 技能 | 使う場面 |
|---|---|
| ① 読む | 資料、仕様書、報告、メール |
| ② 書く | メール、資料、報告 |
| ③ 聞く | 会議、打合せ、電話 |
| ④ 話す | 交渉、説明、対応 |

**求人によって、求められる技能が違います。**

**「英語ができる」という一言では、条件に合っているか判断できません。**

**求人票に「読み書きができる方」「会議での議論ができる方」と書かれている**ことがあります。

**どの技能が、どの程度求められているか**を確認してください。

## 必要になる職種

| 職種・領域 | 求められる技能 |
|---|---|
| ① 海外との取引がある事業 | 読む・書くが中心 |
| ② 外資系の会社 | 社内の文書、会議 |
| ③ 国際に関する事業 | 話す・聞くを含む |
| ④ 観光・インバウンド | 対応の場面による |
| ⑤ 技術の分野（仕様・規格） | **読むが中心** |
| ⑥ 研究・調査 | 文献を読む |

**⑤について。**

**技術の分野では、規格や仕様の原文が英語**であることがあります。

**この場合、必要なのは「読む」技能**です。

**話す技能は、求められないことがあります。**

## 必要にならない職種

| 職種・領域 | 理由 |
|---|---|
| ① 行政が相手の事業 | **相手が日本の行政機関** |
| ② 国内の顧客が中心の事業 | 取引が国内で完結 |
| ③ 地域に密着した事業 | 対象が地域の住民・事業者 |
| ④ 制度の運用の支援 | 日本の法令が対象 |

**①が、公務員からの転職では中心**になります。

**指定管理、業務の受託、発注者支援、自治体向けのシステム。**

**これらの事業では、相手が日本の行政機関**です。

**英語が応募条件になることは、多くありません。**

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

:::insight
英語について、**面談でお聞きしているのが「応募したい求人の応募条件を見ましたか」**という点です。**「英語くらいできないと」と、漠然と不安を抱えている方**がいらっしゃいます。ところが、**求人票を5件読むと、英語の要件が書かれているものは限られます。**とくに、**行政が相手の事業では、応募条件に語学が挙がることは多くありません。**相手が日本の行政機関だからです。**一方、要件がある求人では、書き方が具体**です。「英文の資料を読める方」「海外の拠点との会議に参加できる方」。**技能まで指定されています。**ですから、**先にすべきは、勉強ではなく求人票を読むこと**です。応募したい領域の求人を5件読み、**英語が条件に挙がっているかを確認する。**挙がっていなければ、**その時間は、職務経歴書の作成に使うほうが効きます。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 学ぶ前に考えること

| 確認すること | 内容 |
|---|---|
| ① 応募したい求人に要件があるか | **求人票を5件読む** |
| ② どの技能が求められるか | 読む・書く・聞く・話す |
| ③ 期限 | 応募の時期までに間に合うか |
| ④ 他に優先することはないか | 書類、条件の整理 |
| ⑤ 現在の到達を測る必要があるか | 検定の位置づけ |

**①を最初に置いてください。**

**要件がない求人に応募するのであれば、学習は転職の条件になりません。**

**③について。**

**語学の力は、短期間では大きく変わりません。**

**応募の時期が近い場合、いま持っている力で応募できる求人を探す**ほうが現実的です。

**④について。**

**職務経歴書ができていない段階で語学の学習を始めると、応募の時期が遅れます。**

**優先順位を確認**してください。

**なお、資格や検定を取れば転職できる、という関係にはありません。**

**要件として挙げられている場合に、条件を満たす材料になる**というものです。

## 検定・試験の位置づけ

| 場面 | 扱い |
|---|---|
| 応募条件に記載がある | **満たす材料になります** |
| 記載がない | 判断の中心にはなりません |
| 到達を測りたい | 自分の現在地の確認に使えます |
| 実務の経験がある | **経験のほうが具体に書けます** |

**4行目です。**

**在職中に英語を使った場面があるなら、そちらを書いてください。**

**「外国籍の住民への窓口の対応を担当」「英文の資料を読み、内容を要約して庁内に共有」**という形です。

**検定の点数より、使った場面のほうが具体**です。

**書き方は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 在職中に使った場面の書き方

| 場面 | 書き方の例 |
|---|---|
| 窓口の対応 | 外国籍の住民への対応を年◯件担当 |
| 資料の作成 | 多言語の案内の作成に関与 |
| 文献・規格 | 英文の規格を確認し、仕様に反映 |
| 会議 | 海外からの視察の受入れに対応 |
| 研修 | 語学の研修を受講（◯年） |

**5行目です。**

**団体の研修で語学を学んだ場合、受講の事実を書いて差し支えありません。**

**ただし、実務で使った場面があるなら、そちらを先に書いて**ください。

## 求人票での確認の仕方

| 欄 | 見るところ |
|---|---|
| 応募条件（必須） | **語学が挙がっているか** |
| 応募条件（歓迎） | 挙がっていても必須ではありません |
| 仕事内容 | 海外・英文・グローバルという語 |
| 配属先 | 海外の拠点との関係 |
| 求める人物像 | 抽象的な記載は判断の材料にしにくい |

**1行目と2行目を分けてください。**

**「歓迎」に挙がっている場合、満たしていなくても応募できます。**

**3行目について。**

**応募条件に記載がなくても、仕事内容の欄に「海外」「英文」という語があれば、使う場面があります。**

**その場合、どの程度かを面接で確認**してください。

**読み方は**[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)**に整理しています。**

## よくある失敗

**1. 求人票を読まずに学習を始める**

**要件があるか**を先に確認してください。

**2. 「英語ができる」とだけ書く**

**技能と場面**を書いてください。

**3. 技能の区別をしない**

**読む・書く・聞く・話す**で求められるものが違います。

**4. 実務で使った場面を書かない**

**検定の点数より具体**です。

**5. 書類より先に学習を始める**

**応募の時期が遅れます。**

**6. 行政が相手の事業でも必要だと考える**

**相手は日本の行政機関**です。

**7. 短期間で大きく変わると考える**

**時間がかかります。**

**8. 取れば転職できると考える**

**要件を満たす材料の1つ**です。

:::insight
ここまで「必要ない場合が多い」という話をしておいて逆のことを言いますが、**英語を学ぶこと自体を止める理由はありません。**面談で拝見していると、**「転職に必要ないなら、やめておこう」と判断される方**がいらっしゃいます。ところが、**転職の条件としては不要でも、入社後に役立つ場面はあります。**行政が相手の事業でも、**海外の事例を調べる、規格や技術の資料を読む、外国籍の住民への対応を含む業務を担う**といった場面はあります。そして、**学習そのものが、面接で話せる材料**になります。「制度の改正に対応するため、継続して学習している」という姿勢は、**学ぶ習慣がある人**として読まれます。ですから、**転職の準備としては優先順位を下げ、長く続ける前提で学ぶ**という位置づけにしてください。**応募の時期に間に合わせようとしない**ことが要点です。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方自治法第10条**は、**区域内に住所を有する者を住民**とし、**住民が役務の提供をひとしく受ける権利**を定めています。**国籍による区別は条文に置かれていません**
- **窓口や相談で言語の対応を経験している場合、書類に書ける材料**になります
- 求められる技能は、**読む・書く・聞く・話す**で異なります。**「英語ができる」では判断できません**
- **行政が相手の事業では、応募条件に語学が挙がることは多くありません**
- **学ぶ前に、応募したい求人の条件を5件読んで**ください
- **検定は、要件がある場合に満たす材料**です。**取れば転職できる、という関係にはありません**
- **実務で使った場面があるなら、そちらを先に書いて**ください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 応募条件に「英語力は問わない」と書かれていました

**その求人では、要件ではありません。**記載があるということは、**応募をためらう人がいることを会社が想定している**ということでもあります。**気にせず応募して差し支えありません。**なお、**入社後に使う場面があるかどうかは、面接で確認**できます。「業務の中で英語を使う場面はありますか」という聞き方です。**あるとしても、どの技能が、どの程度かで負担が変わります。**「英文の資料を読む程度」と「会議で議論する」では、まったく違います。**確認したうえで判断**してください。

### 検定を受けるなら、どの程度を目指せばよいですか

**応募したい求人の記載を基準にしてください。**求人票に**具体の基準が書かれている場合、それが目安**です。記載がない場合、**基準を自分で決める必要はありません。**なお、**検定の勉強そのものは、到達を測る手段として使えます。**現在地が分かると、**必要な時間の見当がつきます。**ただし、**応募の時期が近い場合は、優先順位を下げて**ください。**いま持っている力で応募できる求人**を探すほうが、時期に間に合います。扱いは[選考スケジュールの組み方](senko-sagasu-schedule.html)に整理しています。

### 外国籍の住民への対応の経験は、どう書きますか

**件数と、対応の方法を書いてください。**「外国籍の住民への窓口の対応を年約◯件担当。翻訳の仕組みと多言語の案内を用いて、制度の説明と申請の受付を実施」という形です。**使った手段まで書く**と、実務の様子が伝わります。また、**多言語の案内や説明の資料を作成した経験**があれば、**作ったもの**として書いてください。なお、**この経験は、語学の力とは別に評価される**ことがあります。**言語が通じにくい相手に、制度を説明して手続きを進めた**という点は、**顧客対応の経験**として読まれます。
