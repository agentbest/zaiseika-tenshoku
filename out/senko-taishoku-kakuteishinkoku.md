退職した年は、**確定申告が必要になることがあります。**

**在職中は、年末調整で完結していた**ため、**申告をしたことがない方も多い**はずです。

この記事では、**必要になる場合と、準備**を扱います。

**⚠ 税の取扱いは個別性が高いため、この記事は一般的な整理にとどめます。****必ず税務署で確認してください。**

## 年末調整は、最後に給与を支払う者が行います

**仕組みを、条文で確認します。**

**所得税法第190条**です。

> 給与所得者の扶養控除等申告書を提出した居住者で（中略）その年中に支払うべきことが確定した給与等の金額が二千万円以下であるものに対し、その提出の際に経由した給与等の支払者が**その年最後に給与等の支払をする**場合において（中略）

**「その年最後に給与等の支払をする者」**が、年末調整を行う。

**つまり、年内に次の勤務先に入れば、そこで年末調整が行われる**のが通常です。

**一方、年内に次の勤務先がなければ、年末調整を行う者がいません。**

**その場合、自分で確定申告をすることになります。**

**在職中に確定申告をしていた方（医療費控除や寄附金控除など）は、同じ手順で進められます。**

## 必要になる場合

| 状況 | 一般的な扱い |
|---|---|
| 年内に次の勤務先に入る | **次の勤務先で年末調整**（前職の源泉徴収票を提出） |
| 年内に入らない（年をまたぐ） | **確定申告**が必要になることがあります |
| 離職期間がある | 同上 |
| 副収入がある | 金額によって申告が必要 |

**2つ目と3つ目が、退職に特有の場面**です。

**12月31日時点で、どこにも勤務していない場合、年末調整が行われません。**

**その年に支払われた給与について、自分で申告することになります。**

## 準備する書類

**一般的な項目**です。**個別の事情によって異なります。**

| 書類 | 入手先 |
|---|---|
| 源泉徴収票 | **退職した所属**（在職中の分） |
| 退職所得に関する書類 | 所属の給与の担当 |
| 控除に関する証明 | 保険会社、市区町村など |
| 国民年金・国民健康保険の納付の記録 | 納付書、通知 |
| 本人確認の書類、口座の情報 | 自分で用意 |

**1つ目を、退職の手続きのときに受け取ってください。**

**退職後に交付される場合もあります。**受け取りの時期を確認しておいてください。

**4つ目について補足します。**離職期間中に納付した**国民年金や国民健康保険の保険料**は、**控除の対象になることがあります。**

**納付の記録を保管しておいてください。**

**この記事では、具体的な計算や金額は示しません。**控除の額や税率は、**個別の事情によって変わります。**

## 退職手当の扱い

| 項目 | 一般的な内容 |
|---|---|
| 課税の仕組み | **他の所得と分けて計算される仕組み**があります |
| 申告書 | 「退職所得の受給に関する申告書」の提出を求められることがあります |
| 提出した場合 | 源泉徴収で完結することが多い |
| 提出しなかった場合 | **確定申告が必要になることがあります** |

**2つ目を、退職の手続きのときに確認してください。**

**提出の有無で、その後の手続きが変わります。**

**不明な点は、所属の給与の担当と税務署に確認してください。**

**申告が必要かどうかは、年が明けてから判断することになります。**ただし、**書類の準備は退職の時点から始められます。**

## 申告の時期

| 項目 | 一般的な内容 |
|---|---|
| 対象の期間 | **1月1日から12月31日**までの所得 |
| 申告の時期 | 翌年の**2月から3月**とされています |
| 方法 | 税務署の窓口、郵送、電子での申告 |

**還付を受ける申告は、時期が異なる場合があります。**

**税務署で確認してください。**

:::insight
確定申告について、**面談でお伝えしているのが「還付になることがある」**という点です。年の途中で退職すると、**在職中に差し引かれていた所得税が、結果として多すぎる状態**になることがあります。理由は、**月々の源泉徴収が、1年間その水準で働く前提で計算されているから**です。年の途中で収入が止まれば、**年間の所得は想定より少なくなります。**そのため、**申告により還付を受けられる場合**があります。加えて、**離職期間中に納付した国民年金や国民健康保険の保険料も、控除の対象になることがあります。**面談で伺っていると、**「申告が面倒だから」と放置して、還付を受けそびれた方**がいらっしゃいます。**申告は、義務である場合と、還付のために行う場合があります。**どちらに当たるかは、**税務署で確認すれば分かります。**在職中は年末調整で完結していたぶん、**なじみがないだけ**です。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 年内に次の勤務先に入る場合

| 順 | やること |
|---|---|
| 1 | 退職した所属から**源泉徴収票**を受け取る |
| 2 | 次の勤務先に**提出** |
| 3 | 次の勤務先で**年末調整**が行われる |
| 4 | 控除に関する書類を、勤務先の指示により提出 |

**1を忘れると、3ができません。**

**受け取りの時期を、退職の手続きのときに確認してください。**

**なお、退職手当に関する書類は、給与の源泉徴収票とは別**です。

## 控除の対象になり得るもの

**離職期間があると、在職中は給与から差し引かれていたものを、自分で納めることになります。**

| 項目 | 一般的な扱い |
|---|---|
| 国民年金の保険料 | **社会保険料控除**の対象になることがあります |
| 国民健康保険の保険料 | 同上 |
| 任意継続の保険料 | 同上 |
| 生命保険料など | 証明書にもとづく控除の対象になることがあります |
| 医療費 | 一定の要件を満たす場合 |

**1つ目から3つ目は、在職中は給与から差し引かれていたもの**です。

**自分で納めた分は、記録を保管しておいてください。**

**納付書の控えや、送られてくる証明が必要になることがあります。**

**なお、家族の分を自分が納めた場合の扱いは、要件によって異なります。****税務署で確認してください。**

## 書類を保管する

| 保管するもの | 期間の目安 |
|---|---|
| 源泉徴収票（給与・退職手当） | 申告が終わるまで |
| 保険料の納付の記録 | 同上 |
| 控除に関する証明 | 同上 |
| 申告の控え | **数年**（後で確認が必要になることがあります） |

**4つ目を残しておいてください。**

**翌年以降の申告や、各種の手続きで、前年の所得を証明する必要が生じる**ことがあります。

**1つの封筒にまとめておくだけで足ります。**

## 確定申告が要るかどうかの確認

| 順 | やること |
|---|---|
| 1 | **12月31日時点の勤務の状況**を確認 |
| 2 | その年の収入の内訳を整理 |
| 3 | **税務署に相談**（一般的な相談に応じています） |
| 4 | 必要に応じて申告 |

**3を使ってください。**

**税務署では、申告に関する相談を受け付けています。**

**申告の時期は窓口が混み合うため、早めに相談するほうが確実**です。

[経験の言い換えから相談する](../apply.html)こともできます。

**なお、税務署の相談は、申告の時期でなくても受け付けています。**退職の直後に、**「この年は申告が必要になりますか」と一般的に相談**しておくと、準備するものが分かります。

## よくある失敗

**1. 源泉徴収票を受け取らない**

**年末調整にも確定申告にも必要**です。

**2. 退職所得に関する申告書の扱いを確認しない**

**提出の有無**で手続きが変わります。

**3. 保険料の納付の記録を保管しない**

**控除の対象**になることがあります。

**4. 申告が不要だと思い込む**

**還付になる**ことがあります。

**5. 申告の時期に窓口へ行く**

**混み合います。**早めに相談してください。

**6. 一般的な説明だけで判断する**

**個別性が高い**ため、税務署で確認してください。

:::insight
ここまで申告の話をしておいて逆のことを言いますが、**年内に次の勤務先に入るのであれば、多くの場合この検討は不要**です。**前職の源泉徴収票を提出すれば、次の勤務先で年末調整が行われます。**所得税法第190条のとおり、**「その年最後に給与等の支払をする者」**が処理するためです。つまり、**3月31日退職、4月1日入社**という形であれば、**確定申告をせずに済むことが多い**わけです。**健康保険も年金も、空白がなければ手続きが簡略になります。**つまり、**空白を作らないことで、手続きの多くが減ります。**もちろん、療養や介護で期間が必要な場合は別です。ただ、**「なんとなく空けた」結果として手続きが増える**のは、避けられます。**空白を作るかどうかは、意図して決めてください。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **所得税法第190条**により、**その年最後に給与等の支払をする者**が年末調整を行います
- **年内に次の勤務先に入れば、そこで年末調整**が行われるのが通常です
- **年をまたぐ場合や離職期間がある場合、確定申告が必要になる**ことがあります
- **源泉徴収票を、退職の手続きのときに受け取って**ください
- **離職期間中に納付した国民年金・国民健康保険の保険料**は、控除の対象になることがあります
- **申告が不要だと思い込まない。**還付になることがあります

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 確定申告をしたことがありません

**税務署の相談を使ってください。**申告の時期には、**相談の窓口が設けられる**のが通常です。必要な書類を持参すれば、**作成の案内を受けられる**ことがあります。加えて、**電子での申告の仕組み**もあります。**画面の案内に沿って入力する形**で、計算は自動で行われます。初めての方でも、**書類が揃っていれば対応できる**ことが多いです。なお、**時期が近づくと窓口が混み合います。**早めに準備し、**分からない点は事前に相談**してください。

### 退職手当の源泉徴収票は、いつもらえますか

**所属によって時期が異なります。**退職手当の支給の時期と合わせて交付されることが多いとされていますが、**規程によります。**退職の手続きのときに、**交付の時期と方法を確認**してください。なお、**給与の源泉徴収票とは別の書類**です。**両方を受け取る必要**があります。**退職後に郵送される場合**もあるため、**住所が変わる場合は届け出てください。**届かないまま放置すると、申告の際に困ります。

### 申告をしないと、どうなりますか

**申告が義務である場合と、還付のために行う場合で異なります。**義務である場合に申告しないと、**加算や延滞に関する取扱いが生じる**ことがあります。一方、**還付のための申告であれば、しなくても不利益はありませんが、還付を受けられません。**どちらに当たるかは、**その年の収入と源泉徴収の状況によります。**判断は、**税務署に相談すれば分かります。**「申告が必要かどうかを知りたい」と伝えれば、**確認してもらえます。**迷ったまま放置するより、**一度相談**してください。
