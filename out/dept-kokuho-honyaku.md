国保年金課からの転職で、いちばんもったいないのはこれです。

**この部署が「保険会社と同じ仕事をしている」ことに、本人が気づいていない。**

加入者を管理し、保険料を算定して集め、請求の内容を点検して給付を支払い、他人の行為による事故については相手方に求償する。

**これは、保険の実務そのものです。**

しかも、扱っている規模は大きく、**人口20万人の市なら、被保険者は数万人**にのぼります。

この記事では、その対応を整理します。訳語の対応表、中核スキルの工程分解、そして**保険会社の実務とどこが同じでどこが違うか**まで扱います。

## 「保険者」である、という立場です

まず、この部署の立ち位置を条文で確認します。**民間に説明するときの、いちばん強い材料**です。

国民健康保険法第3条第1項は、こう定めています。

**都道府県は、当該都道府県内の市町村とともに、この法律の定めるところにより、国民健康保険を行うものとする。**

**「国民健康保険を行うもの」**——つまり、**保険者**です。

保険者とは、**保険料を集め、保険事故が起きたときに給付を行う主体**のことです。生命保険会社も、損害保険会社も、健康保険組合も、同じ立場にあります。

**つまり、この部署にいた人は、「保険を運営する側」にいました。**

代理店として売る側でも、加入者として使う側でもなく、**収支を管理し、支払の可否を判断する側**です。

**この一点を最初に言えるかどうか**で、説明の通りやすさが変わります。

> 保険者として、被保険者の資格管理、保険料の賦課と収納、給付の支払、第三者行為求償までを担当していました。

**この一文で、事務職ではなく保険実務の経験者として読まれます。**

なお、第3条は都道府県と市町村が**ともに**行うとしています。**財政の運営は都道府県が担い、資格の管理や保険料の賦課徴収、給付の窓口は市町村**という役割分担です。**面接では、この分担も一言添えると正確になります。**

## 民間での訳語

履歴書や職務経歴書では、**自治体の中でしか通じない言葉を、募集要項に出てくる言葉に置き換えます。**

| 自治体での呼び方 | 民間での呼ばれ方 |
|---|---|
| 資格の取得・喪失の処理 | 被保険者管理、契約の成立・消滅の管理 |
| 保険料の賦課 | 保険料の算定、料率の適用 |
| 保険料の収納・滞納整理 | 債権管理、回収業務 |
| 減免・徴収猶予の審査 | 支払条件の変更審査 |
| 高額療養費・療養費の支給 | 保険金の支払審査 |
| レセプトの点検 | 請求内容の点検、支払査定 |
| 第三者行為求償 | 求償事務、代位求償 |
| 特定健診・保健事業 | 加入者向けの予防サービス、健康データの活用 |
| 医療費通知 | 加入者への給付明細の通知 |
| 国民年金の届出の受付・相談 | 制度の窓口対応、申請の受付 |
| 資格管理システムの運用 | 契約管理システムの運用 |
| 国保運営協議会の事務 | 運営委員会の事務局 |

**「国保の窓口」ではなく、「被保険者管理」「支払審査」「債権管理」に分けて書く**のが基本です。それだけで、対応する求人が見えてきます。

## 中核スキルを5つの工程に分ける

この部署の仕事は、**5つの工程**に分解できます。**保険会社の実務と、ほぼ同じ形**です。

**① 資格を確定する**

**いつから、いつまで加入していたか**を確定します。

就職して社会保険に入れば国保を抜け、退職すれば戻ってきます。**この異動が日々発生し、しかも届出が遅れることが多い**ため、**遡って資格を直す処理**が常に発生します。

**資格が確定しないと、保険料も給付も決まりません。**すべての起点です。

**そして、この工程がいちばん時間を取ります。**届出が遅れた場合、**さかのぼって資格を作り、その期間の保険料を計算し直し、すでに他の保険で受けた給付との調整まで行う**ことになります。**一件の遡及が、賦課と給付の両方に波及する**という構造です。

**② 保険料を決める**

所得、世帯の構成、加入者数から算定します。**所得が確定してから本算定を行う**ため、年度の途中で額が変わります。

**「一度決めたら終わり」ではなく、更正が繰り返される**のが特徴です。

**③ 集める**

納付書の発送、口座振替、納付の確認、督促、滞納整理。そして、**払えない人への減免と徴収猶予の審査**があります。

**払えないのか、払わないのか。**この見極めが、この工程の中心です。

**④ 払う**

高額療養費、療養費、出産育児一時金、葬祭費。**請求の内容を点検して、支給の可否と額を決めます。**

**レセプトの点検**も含まれます。**請求された診療の内容が、制度の範囲に収まっているか**を確認する作業です。

**⑤ 取り戻す・防ぐ**

交通事故など**他人の行為が原因で給付を行った場合、相手方に費用を求償**します。

そして、**資格を遡って直す、重複加入を見つける、誤った給付を返してもらう**という工程があります。

## 保険会社の実務と、どこが同じでどこが違うか

**同じところ**

**1. 収支が構造として見える**

**入るのは保険料、出るのは給付。**この構造は同じです。収支の見通しを立て、料率の改定を検討する。**保険という仕組みの中で仕事をしてきた**という点が共通します。

**2. 請求を点検してから支払う**

**請求されたとおりに払うわけではありません。**内容を点検し、制度の範囲に収まっているかを確認します。**支払査定という仕事が、そのまま存在します。**

**3. 滞納と回収の管理がある**

保険料が払われなければ、督促し、回収します。**分割の相談を受け、支払能力を見て条件を決める。**民間の債権管理と同じ判断です。

**違うところ**

**1. 加入を断れず、選べない**

民間の保険は、**引受を審査して断ることができます。**健康状態や過去の事故歴で、加入を制限できます。

**国民健康保険は、断れません。**しかも、**他の医療保険に入っていない人は必ず加入する**ため、**加入者の構成を選べません。**

**この違いは大きく、面接で説明する価値があります。**「選べない集団を、制度の枠内で運営してきた」という経験です。

**2. 商品を設計できない**

給付の内容も、保険料の算定の枠組みも、**法令で決まっています。**民間の保険会社のように、**新しい商品を作ることはできません。**

**移った先では、設計に関われる**ということでもあります。

**3. 加入者が「顧客」ではない**

民間の保険には、契約を選んだ顧客がいます。**国保の被保険者は、制度上そこに入っているだけ**で、選んだわけではありません。

**だから、説明の仕方が違います。**納得を得るために、**制度の根拠から説明する**必要があります。**この訓練は、規制のかかった商品を扱う部署で効きます。**

**4. 制度が頻繁に変わる**

給付の割合、限度額、軽減の基準。**法令の改正が定期的にあり、そのたびにシステムと手引きを直します。**民間の保険でも約款の改定はありますが、**自分たちの意思と無関係に外から変更が来る**という点が違います。**「改正に合わせて運用を作り直した経験」は、制度改正の多い業界でそのまま評価されます。**

:::insight
国保年金課の方が職務経歴書で損をしやすいのは、**「保険者だった」と書かないこと**です。書類には「国民健康保険の資格・賦課・給付に関する業務」と書かれていて、**保険を運営する側にいたという事実が読み取れません。**保険業界の採用担当が見ているのは、**保険の仕組みの中で働いた経験があるか**です。被保険者管理、保険料の算定、支払審査、求償。**この4つの語を使うだけで、同じ業界の言葉で話せる人として読まれます。**さらに効くのが**規模**です。「被保険者数約◯万人、年間の保険料調定額約◯億円、給付費約◯億円」。**これは公表されている事業報告や決算から取れます。**民間の中堅の保険代理店や共済よりも大きな規模を扱っていることが珍しくなく、**規模を書かないと、その事実が伝わりません。**「窓口業務」ではなく「保険者としての実務」と書く。**ここが最初の分かれ目です。**
:::

## 評価が高くなりやすい4つの方向

**1. 生命保険・損害保険・共済の実務**

**契約管理、支払審査、査定、求償**を担う部署です。**工程が同じ**なので、説明がそのまま通ります。

とくに、**支払審査（給付の可否と額を決める仕事）**と、**求償（他人の行為による損害を相手方に請求する仕事）**は、**民間でもそのままの名前で存在します。**

**2. 健康保険組合・協会けんぽ・後期高齢者医療広域連合**

**まったく同じ仕事**です。被保険者の資格管理、保険料、給付、レセプトの点検、保健事業。

**制度は違いますが、工程は同じ**なので、立ち上がりが早くなります。**健康保険組合は、経験者を採りたい一方で母数が小さい**という事情があります。

**3. 債権管理・回収の実務**

**保険料の滞納整理**の経験が効きます。督促、納付の相談、分割の設定、支払能力の見極め。

**「払えないのか、払わないのか」を見極めてきた経験**は、民間の債権管理でそのまま必要になります。

[財政・会計の経験が効く求人を見てみる](../?fin=1)

**4. 自治体を顧客にする企業・医療関連のサービス**

国保のシステム、レセプトの点検の受託、健康データの活用の支援、保健事業の受託。

**発注する側にいた経験**に加えて、**制度の実務を知っていること**が提案の材料になります。**この領域は、制度を理解している人材を強く求めています。**

:::insight
方向を決めるときに、**残る判断のほうが妥当だと感じる場面**もあります。国保年金課は、**担当している工程によって、書ける内容がまったく変わる**部署です。資格と賦課だけの担当なのか、**給付（支払審査）まで担当しているのか**、**滞納整理まで担当しているのか**。このうち、**民間でいちばん値が付くのが給付と求償**です。支払審査と求償は、**保険会社にそのままの名前で存在する仕事**だからです。まだ資格と賦課だけの段階なら、**給付に回ってからのほうが、選べる方向が明確に増えます。**もう一つ、**レセプトの点検や、データを使った保健事業**に関わる機会があるなら、それも大きな材料です。**医療のデータを扱った経験は、民間側で不足しています。**いずれも、いまの場所でしか積めません。在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## つまずきやすい点

**1. 「保険者だった」と書かない**

**被保険者管理・保険料の算定・支払審査・求償。**この4語を使ってください。

**2. 規模を書かない**

**被保険者数、年間の調定額、給付費。**公表されている事業報告から取れます。

**3. 給付と求償を落とす**

**民間にそのままの名前で存在する仕事**です。担当していたなら、必ず前に出してください。

**4. 「窓口業務」で丸める**

**資格・賦課・収納・給付・求償**は、性質の違う5つの仕事です。分けて書いてください。

**5. 個別の事案に触れる**

**被保険者の疾病や所得の状況、減免の個別の判断、滞納の相手方。**すべて書けません。手続の構造で書いてください。

どの経験に値が付くかは、募集の出方で変わります。[どの経験に値が付くのかから相談できます](../apply.html)。

## まとめ

- 国民健康保険法第3条は、都道府県が**当該都道府県内の市町村とともに**国民健康保険を行うと定めています。**市町村は保険者**です
- **保険料を集め、給付を行う側にいた**というのが、この経歴の芯です
- 民間での訳語は、**被保険者管理／保険料の算定／支払審査／求償事務／債権管理**が中心になります
- 中核スキルは**①資格を確定する ②保険料を決める ③集める ④払う ⑤取り戻す・防ぐ**の5工程です
- 保険会社の実務と**同じ**なのは、収支が構造として見えること・請求を点検してから支払うこと・滞納と回収の管理があること
- **違う**のは、加入を断れず選べないこと・商品を設計できないこと・加入者が選んだ顧客ではないこと・制度が外から頻繁に変わることです

## よくある質問

### 保険の資格を持っていないと、保険業界には入れませんか

**入口では必須とされないことが多くあります。**募集人の資格は、**契約を募集する職種（営業・代理店）で必要**になるもので、**契約管理や支払審査の部署では、入社後に取得する形**が一般的です。この経歴で狙うのは、**募集ではなく実務側**なので、資格がないことが理由で止まることは多くありません。**面接では、募集の経験はないことを正確に言ったうえで、査定と管理の経験を前に出してください。**

### 年金の窓口の経験は、どう書けばよいですか

**「制度の窓口対応と申請の受付」**として書けます。国民年金の実務は、**資格の届出の受付、保険料の免除・納付猶予の申請の受付、裁定請求の受付**が中心で、**決定そのものは日本年金機構が行います。**ここは正確に書いてください。**「受付と、要件の確認と、制度の説明」までが担当範囲**という書き方なら、誤解が生じません。そのうえで、**複雑な制度を、選んだわけではない相手に説明してきた経験**として位置づけると価値が伝わります。

### レセプトの点検は、専門知識がないとできない仕事ですか

**点検の深さによります。**医療的な妥当性の審査は審査支払機関が行い、**市町村が行うのは、資格の誤り、給付割合の誤り、重複請求といった事務的な点検が中心**です。ただし、**この事務的な点検こそが、民間の支払査定でも大きな比重を占めます。**面接では、**「医学的な審査は審査支払機関が担い、こちらは資格と給付要件に関する点検を担当していた」**と正確に線を引いてください。そのほうが、役割の理解がある人として読まれます。
