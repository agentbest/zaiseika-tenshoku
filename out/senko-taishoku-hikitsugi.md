退職までの期間で、**いちばん時間を使うのが引継ぎ**です。

手続きは、確認して順に進めれば終わります。**一方、引継ぎは、やり方によって残るものが変わります。**

この記事では、**進め方**を扱います。時期の決め方は[退職時期の決め方｜年度末と年度途中](senko-taishoku-jiki.html)にあります。

## 記録は、組織の資源です

**引継ぎの考え方は、文書の管理の目的と重なります。**

**公文書等の管理に関する法律第1条**です。

> この法律は、国及び独立行政法人等の諸活動や歴史的事実の**記録**である公文書等が、健全な民主主義の根幹を支える**国民共有の知的資源**として（中略）行政文書等の適正な管理（中略）を図り、もって行政が適正かつ効率的に運営されるようにするとともに（中略）することを目的とする。

**記録は、共有の資源。**

**同法第34条**により、**地方公共団体も、この法律の趣旨にのっとって文書の管理に努める**こととされています。

**引継ぎとは、自分の頭の中にある情報を、組織の資源に変える作業**です。

**「自分が知っていること」を「誰でも参照できる形」にする。**これが目的です。

## 3つの作業に分かれる

| 作業 | 内容 | 時期 |
|---|---|---|
| ① 資料の作成 | 担当業務の一覧、手順、進行中の案件 | **後任が決まる前から** |
| ② 後任への説明 | 対面での説明、同行 | 後任が決まってから |
| ③ 関係先への連絡 | 他課、事業者、住民の担当者 | 退職の直前 |

**①が、いちばん重要です。**

**そして、①だけは後任が決まる前から進められます。**

**年度末は、異動の内示が遅れることがあります。**後任が決まってから始めると、**間に合いません。**

## ①——資料に書くこと

| 項目 | 内容 |
|---|---|
| 担当業務の一覧 | 業務名、根拠となる規定、年間の件数 |
| 年間の流れ | いつ、何が起きるか（繁忙期を含む） |
| 進行中の案件 | 状況、期限、次にやること |
| 関係する相手先 | 他課、事業者、関係機関 |
| 資料の所在 | 文書の場所、データの保存先 |
| 例外の処理 | **標準の手順で処理できない案件の扱い** |
| 過去の経緯 | 判断の根拠になった経緯 |

**6つ目が、いちばん価値のある部分**です。

**標準的な事務は、マニュアルがあれば引き継げます。**

**引き継げないのは、「こういう場合はこうする」という判断の部分**です。

**その業務を長く担当している人ほど、この部分を多く持っています。**

## 例外の処理を、書き出す方法

**思い出しにくい部分なので、手がかりを挙げます。**

| 手がかり | 問い |
|---|---|
| 相談された場面 | **後輩や同僚から、何を聞かれたか** |
| 迷った場面 | 判断に時間がかかった案件は何か |
| 前例を調べた場面 | 過去の文書を探した案件は何か |
| 上司に相談した場面 | 自分では決められなかった案件は何か |

**4つとも、「標準から外れた案件」**です。

**そのとき、どう判断したか。**それを書けば、例外の処理の記録になります。

## ②——後任への説明

| 順 | やること |
|---|---|
| 1 | 資料を渡し、**読んでもらう** |
| 2 | 疑問点を聞いて、**資料に追記** |
| 3 | 年間の流れを、対面で説明 |
| 4 | 進行中の案件を、個別に説明 |
| 5 | 可能であれば、**実際の業務に同行** |

**2を飛ばさないでください。**

**後任が分からなかった部分が、資料の弱い部分**です。

**その場で口頭で答えて終わらせず、資料に追記してください。**

**次の担当者にも使えます。**

## ③——関係先への連絡

| 相手 | 伝えること |
|---|---|
| 他課の担当 | 後任の氏名と連絡先 |
| 事業者 | 担当が変わる旨（**時期は所属の判断で**） |
| 関係機関 | 同上 |

**外部への連絡は、所属の判断に従ってください。**

**自分の判断で先に伝えないこと。**組織としての連絡の段取りがあります。

:::insight
引継ぎで、**面談でお伝えしているのが「資料は後任のためだけに作るものではない」**という点です。担当業務の一覧、年間の流れ、進行中の案件、例外の処理。**これらを書き出す作業は、職務経歴書の担当業務欄とほぼ同じ内容**になります。すでに書類を作っている方は、**その内容が使えます。**逆に、まだ書類を作っていない方は、**引継ぎの資料が職務経歴書の材料**になります。**どちらから始めても、もう一方に使えます。**そして、**この作業には、もう1つの効果**があります。**自分が何をしてきたかが、可視化される**ことです。面談で伺っていると、**引継ぎの資料を作る過程で、「思ったより多くのことをしていた」と気づく方**が少なくありません。**その気づきは、面接での答えにも使えます。**引継ぎは、最後の業務であると同時に、**自分の仕事を整理する機会**でもあります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 後任が決まらない場合

**年度の途中の退職では、後任が補充されないことがあります。**

| 状況 | 対応 |
|---|---|
| 残る職員が兼務する | **複数人に分けて引き継ぐ** |
| 後任が後日着任する | **文書だけで引き継げる形に** |
| 一部が未定 | 上司に判断を仰ぐ |

**2つ目を前提に、資料を作ってください。**

**「誰が読んでも分かる」形にしておけば、後任が決まっていなくても渡せます。**

**口頭でしか伝わらない情報を残さないこと**が、この場合の条件です。

## 資料の形式

**凝った形式にする必要はありません。**

| 資料 | 形式 |
|---|---|
| 担当業務の一覧 | 表（業務名・根拠・件数・時期） |
| 年間の流れ | 月ごとの表 |
| 進行中の案件 | 案件ごとに数行 |
| 例外の処理 | 「こういう場合は、こうする」の箇条書き |
| 資料の所在 | 文書の分類番号、保存先の一覧 |

**5つとも、既存の様式があれば、それに従ってください。**

**所属で引継書の様式が定められていることがあります。**その場合、**様式に沿って作れば足ります。**

**様式が無い場合でも、新しく作り込む必要はありません。**普段の業務で使っている表や、進捗の管理の表を、**そのまま引き継げる形に整えるだけ**で構いません。

**手を加えるとすれば、「自分にしか分からない略語や記号」を開く**ことです。自分用に作った表には、**略語が多く含まれています。**それを開くだけで、資料として使える形になります。

## 進め方の目安

| 時期 | やること |
|---|---|
| 退職の2か月前 | 担当業務の一覧を作る |
| 1か月半前 | 年間の流れと例外の処理を書く |
| 1か月前 | 進行中の案件を整理 |
| 3週間前 | 後任への説明（決まっていれば） |
| 2週間前 | 関係先への連絡 |
| 最終週 | 返還、書類の受け取り |

**最初の2つは、後任が決まる前でも進められます。**

[経験の言い換えから相談する](../apply.html)こともできます。

**なお、作成した資料は、所属の文書として保存してください。**自分の手元だけに置くと、**退職後に参照できなくなります。**保存の場所は、上司と決めておいてください。

## よくある失敗

**1. 後任が決まってから始める**

**間に合いません。**①は先に進められます。

**2. 口頭で済ませる**

**後任が変わると、また説明が必要**になります。

**3. 例外の処理を書かない**

**いちばん引き継ぎにくい部分**です。

**4. 後任の疑問を、資料に追記しない**

**次の担当者にも使えます。**

**5. 外部へ自分の判断で連絡する**

**所属の段取り**に従ってください。

**6. 標準の手順だけを書く**

**マニュアルで足りる部分**です。

:::insight
ここまで進め方の話をしておいて逆のことを言いますが、**完璧な引継ぎを目指さないでください。**面談で拝見していると、**引継ぎの資料を作り込みすぎて、最終週まで終わらない方**がいらっしゃいます。ところが、**受け取る側にも限界があります。**100ページの資料を渡されても、**読み切れません。**目安としては、**担当業務の一覧がA4で1〜2枚、年間の流れが1枚、進行中の案件が1件あたり数行、例外の処理が1〜2枚。**合計で10枚程度に収まれば十分です。**書ききれない部分は、「相談してください」と連絡先を残す**ほうが現実的です。ただし、**退職後の連絡には、守秘の線があります。**地方公務員法第34条の義務は退職後も続くため、**答えられるのは一般的な事柄まで**です。この線は、退職の前に確認しておいてください。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **公文書管理法第1条**は、記録を**共有の知的資源**と位置づけています。**引継ぎは、自分の頭の中の情報を組織の資源に変える作業**です
- 作業は、**①資料の作成 ②後任への説明 ③関係先への連絡**の3つ。**①は後任が決まる前から進められます**
- 資料に書くのは、**業務の一覧・年間の流れ・進行中の案件・関係先・資料の所在・例外の処理・過去の経緯**です
- **例外の処理**が、いちばん価値のある部分です。相談された場面、迷った場面から思い出してください
- **後任の疑問は、口頭で答えず、資料に追記**してください
- **完璧を目指さない。**合計10枚程度で十分です

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 引継ぎの時間が業務中に取れません

**担当業務の一覧だけは、先に作ってください。**これは、**30分から1時間**で作れます。業務名、根拠の規定、年間の件数。**この3列だけの表で足ります。**残りは、**上司に相談して時間を確保**してください。引継ぎは、**退職する職員の個人的な作業ではなく、組織として必要な業務**です。時間が取れない状態が続くなら、**その旨を上司に伝えてください。**業務の割り振りを調整してもらえることがあります。**「自分の時間でやるもの」と考えないでください。**

### 後任が経験の浅い職員です

**資料の粒度を細かくしてください。**経験のある職員であれば「◯◯の要領による」で通じる部分も、**経験が浅い場合は手順まで必要**です。加えて、**判断の基準を明示**してください。「この場合は係長に相談」「この金額を超えたら課長決裁」といった線引きです。**経験の浅い方がいちばん困るのは、どこまで自分で決めてよいかが分からないこと**です。なお、**後任が着任してから疑問が出ることもあります。**連絡先を残す場合は、**守秘の線を確認したうえで**にしてください。

### 退職後に、業務の照会が来た場合は

**答えられる範囲があります。****地方公務員法第34条の守秘の義務は、退職後も続きます。**答えられるのは、**制度の一般的な仕組みや、自分が使っていた方法**までです。**個別の案件の内部の情報や、未公表の検討の経緯は、答えられません。**判断に迷う場合は、**「その件は、現在の担当の方にご確認ください」**と述べれば足ります。なお、**頻繁に照会が来る状態は、引継ぎの資料が不十分だった証拠**でもあります。**退職の前に、想定される質問を資料に書き足しておく**ほうが、双方にとって楽です。
