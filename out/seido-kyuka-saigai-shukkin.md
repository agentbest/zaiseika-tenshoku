災害時に出勤できない場合は、本人や家族の状況、交通の障害、所属の動員・連絡体制、適用される休暇を分けて確認します。避難情報や運休があれば全員が自動で休暇になる、又は公務員ならどのような危険でも必ず登庁する、という一律の説明はできません。

本記事は2026年11月時点の公開情報にもとづきます。国の一般職の特別休暇と地方の規則例を中心に、制度上の確認を整理します。現場の危険、避難や移動の可否、緊急動員の具体的な判断をこの記事で代行しません。安全に関する公的な案内と所属の正式な連絡・指示を確認してください。

## 本人の被災・通勤・業務を分ける

災害という原因が同じでも、勤務しない理由や担当する業務は異なります。「災害休暇」という呼び方だけで、対象や期間、申請方法が同じだと考えないことが大切です。

| 状況 | 制度上の確認 |
| --- | --- |
| 自宅が損壊し復旧や避難が必要 | 本人被災に関する特別休暇の要件 |
| 交通機関の事故等で出勤が著しく困難 | 出勤困難に関する休暇の対象期間 |
| 退勤途上の身体の危険を避ける | 危険回避の休暇の要件と所属の指示 |
| 災害対応を命じられる | 動員区分、業務命令、勤務場所、勤務記録 |
| 私的に被災者支援へ参加する | ボランティア休暇等の対象と承認 |

同じ職員に複数の事情が重なる場合もあります。例えば、災害対応の動員対象である一方、自宅の被災により移動できないという仮の状況なら、その両方を所属へ伝えます。一つの制度の説明から、別の事情が当然に無視されると考えないようにします。

平時のうちに、通常の上司につながらないときの連絡先、緊急時の連絡方法、本人の配備や参集の区分、家族等の状況を報告する事項を確認しておくと、必要な照会を分けやすくなります。

## 国の本人被災の休暇は7日の範囲に条件がある

人事院規則15-14第22条第1項第16号には、地震、水害、火災等により現住居が滅失・損壊し、復旧作業等を行う又は一時的に避難している場合などの特別休暇があります。本人と同一世帯の人の生活に必要な水・食料等が著しく不足し、本人以外に確保できる人がいない場合等も規定されています。

期間は7日の範囲内です。被害が出た地域に住むすべての職員へ7日が自動で付与されるという意味ではなく、勤務しないことが相当と認められる要件を確認します。国の運用は、原則として連続する7暦日として扱う旨を示しています。

運用には、単身赴任に係る配偶者等の住居の被災や、一定の大規模な災害で本人の現住居以外・親族の住居が被災した場合等に関する例もあります。ただし、親族が被災すれば規模や状況を問わず同じ休暇になる、と一般化しないでください。

本人は、被災した住居との関係、被害、復旧や避難の状況、勤務できない期間を担当へ伝えます。罹災証明等が必要か、すぐそろわない資料を後から出せるかも所属で確認します。書類を取るために危険な現場へ戻ることを、制度上の準備として勧めるものではありません。

## 出勤困難と退勤途上の危険回避は別の号

同規則第22条第1項第17号は、災害又は交通機関の事故等で出勤が著しく困難と認められる場合について、必要と認められる期間の休暇を定めています。第18号は、退勤途上の身体の危険を回避するため勤務しないことがやむを得ないと認められる場合を定めています。

自宅の復旧に関する7日の規定を、交通障害による出勤困難にもそのまま当てはめないようにします。逆に、運休中は本人の状況や他の事情を問わず無期限に休暇、と考えることもできません。対象になる事由と必要な期間を確認します。

連絡するときは、現在地、通常の経路、運休や道路の状況、勤務開始や継続に関する支障、連絡できる方法等を必要な範囲で伝えます。別経路で移動すべきか、どの時点で戻るべきかなどの具体的な安全判断を、一般記事の制度説明から決めないでください。

交通が復旧した後や避難先が変わった場合も、勤務の再開、休暇の対象期間、在宅等の取扱いを所属へ確認します。通勤困難の休暇が認められたことを、全期間の勤務免除や在宅勤務の承認と同じ意味にしないことが必要です。

:::insight
災害時の制度確認では、「出勤か休暇か」の二択を先に迫るより、本人の被害と移動の支障、所属の指示を別々に整理することが大切だと考えます。住居の復旧、交通障害、業務上の参集では確認する事実が異なります。私たちは、平時に本人の連絡先と報告事項を確かめ、緊急時にはわかる範囲の情報を正式な窓口へ伝えられる形にしておくことを勧めます。必要書類がすぐにそろわない場合も、その事情を含めて照会できます。制度の説明を、現場の危険を軽く見るためにも、職場への不安を強めるためにも使わないようにしたいところです。安全と手続の判断を混ぜず、状況の変化に応じて連絡を更新する姿勢が重要です。
:::

## 業務上の動員と私的な支援活動を区別する

国家公務員法第98条、地方公務員法第32条には、法令と上司の職務上の命令に従う義務が規定されています。地方公務員法第35条には職務専念義務の規定もあります。災害対応の業務命令、配備計画、参集方法は、本人の所属と役割に基づいて確認します。

災害だから通常の勤務地とは別の場所へ本人判断で参集する、私的な支援活動を公務の派遣として扱う、といったことは避けます。被災状況によって参集が困難な場合の報告先、業務や勤務場所を変更する権限、勤務実績を誰へ報告するかを確認してください。

一方、国の規則第22条第1項第4号の社会貢献活動に関する特別休暇は、本人が自発的かつ無報酬で一定の支援活動をする場合等の制度です。専ら親族への支援となる活動の除外や、対象活動、年5日の範囲等の要件があります。命令を受けた公務の応援と同じ休暇ではありません。

他自治体等への派遣や研修、ボランティア参加については、勤務命令なのか、職務専念義務の免除なのか、休暇なのかを具体的に確認します。名称が「支援」でも、旅費、補償、勤務や休暇の扱いが同じとは限りません。

## 事前請求が難しいときは理由と事後手続を確認する

国の規則15-14第27条は、原則として事前の休暇請求を定める一方、災害等のやむを得ない事情で事前請求できなかった場合には、事由を付して事後に承認を求められるとしています。これは災害時に連絡や申請がすべて不要になるという意味ではありません。

通信が使えるか、安全に連絡できるかを踏まえ、所属の緊急時の方法で状況を伝えます。つながらなかった場合は、その時刻や方法も、後から説明できる範囲で記録します。連絡のために危険な場所へ移動するよう、この記事から判断することは避けてください。

同規則第25条には特別休暇の承認に関する規定があります。申請する休暇の号、対象期間、事実の確認方法を担当に尋ねます。本人が画面で休暇名を選んだだけで、正式な承認まで済んだと考えないようにします。

| 後から照合する事項 | 記録する内容 |
| --- | --- |
| 状況 | 被災、避難、交通障害等の概要と期間 |
| 連絡 | 相手、日時、連絡できなかった事情 |
| 指示 | 勤務場所、参集、勤務継続や中断の正式な案内 |
| 休暇 | 申請した制度、承認された期間、追加資料 |
| 勤務実績 | 実際に勤務した時間と担当への報告 |

本人の被災に関する資料と、住民対応等の業務資料は分けて扱います。個人情報を含む業務記録を、私的な申請のために一括で持ち出す必要はありません。

## 地方の規則は本人の自治体で読む

地方の例として、横須賀市の勤務時間・休暇等に関する条例施行規則第9条には、現住居の滅失・損壊に伴う復旧作業等のため勤務しない場合の7日以内の休暇と、出勤が著しく困難な場合の必要期間の休暇等があります。

国と似た表現があっても、対象となる職員、事由、期間の計算、退勤時の扱い、申請先まで同じと推測しないでください。同市の規則例を、全国共通の休暇表として使うものでもありません。会計年度任用職員や企業職員等も、本人に適用される規程を確認します。

通常の遅刻、私的な事情による欠勤、災害時の特別休暇、業務命令による在宅等は区別します。避難情報や交通の通知を確認資料として用いる場合でも、それだけで個別の休暇区分が自動確定するとは限りません。

## 平時の確認と発災後の勤務精算を分ける

平時に確認するのは連絡網、配備区分、本人の事情の申出先、必要書類、勤務と休暇の記録方法です。災害が起きた後は、安全や業務の状況を踏まえて所属と連絡し、落ち着いてから実際の勤務と承認された休暇を照合します。

休日や時間外に対応した場合の手当、振替等は別の根拠で確認します。災害対応だから給与の扱いはすべて同じ、後で休めば勤務記録は不要と考えないようにしてください。[週休日の振替と代休](./seido-kyuka-kyujitsu-furikae.html)も制度の区分を確認する参考になります。

:::insight
災害対応に関わる働き方を比較するときは、危険への不安を理由に進路を急いで決める必要はありません。現在の所属の役割、本人の配備や連絡体制、被災した場合の相談経路を知ることは、働き続けるためにも役立ちます。私たちは、実際に確認できない動員の頻度や職場の負担を想像で書かず、本人に適用される制度と公表された業務内容から考えることを重視します。ほかの仕事を調べる場合も、災害時の業務継続、勤務場所、連絡方法等を必要な範囲で確認できます。まず生活と手続を整え、進路は本人の希望に合う時期に検討してください。情報収集をすることも、現職の制度を確認して残ることも、任意の選択です。
:::

平時に仕事の条件を比較したい場合は、[公務員経験を活かせる仕事](../?gov=1)を情報収集に利用できます。災害時の安全確保や生活の立て直しを優先し、進路の判断を急ぐ必要はありません。

## よくある質問

### 電車が止まれば自動で特別休暇になりますか

交通障害だけで全員同じ扱いとは判断できません。出勤が著しく困難な状況、必要な期間、所属の指示と手続を確認します。移動の具体的な安全判断を記事で代行することはできません。

### 被災者の支援に行く日は公務になりますか

業務命令による支援と、自発的なボランティア活動は別です。命令、派遣、職専免、休暇のどの扱いかを確認します。本人が公務と決めて参加するものではありません。

### 災害で事前に休暇申請できなかったらどうしますか

国にはやむを得ない事情を付して事後承認を求める規定があります。安全に連絡できる状況で所属の方法に従い、事情、期間、必要資料を確認します。地方は本人の規程で確かめてください。
