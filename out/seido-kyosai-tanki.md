病院の窓口では、マイナ保険証や資格確認書で現在の資格を確認し、年齢等に応じた自己負担で診療を受けます。**それが、共済組合の「短期給付」**です。民間の健康保険に相当します。

短期給付には、医療費のほかにも、**病気で働けない間の手当、出産の費用、家族の医療費**などが含まれます。**退職後の新たな診療、旧資格期間の給付、任意継続や退職後の継続給付は別に確認します。**退職の翌日から旧資格で受診し続けることはできませんが、すべての給付が一律に終了するわけではありません。

本記事は2026年11月時点の公開情報にもとづきます。

この記事では、**短期給付の中身と、退職で何がどう変わるか**を、地方公務員等共済組合法の条文で整理します。**自分の組合の給付の詳細は、所属の共済組合で確認してください。**共済の全体は[地方公務員共済組合の仕組み](seido-kyosai-shikumi.html)に書いています。

## 短期給付の種類——第53条

地方公務員等共済組合法第53条第1項は、短期給付を次のように列挙しています。

| 区分 | 給付 | 中身 |
|---|---|---|
| **医療** | 療養の給付、入院時食事療養費、入院時生活療養費、保険外併用療養費、療養費、訪問看護療養費、移送費 | 組合員本人の医療費。マイナ保険証や資格確認書で資格を確認して受ける |
| **家族の医療** | 家族療養費、家族訪問看護療養費、家族移送費 | 被扶養者の医療費 |
| **高額の医療** | 高額療養費、高額介護合算療養費 | 法定制度ごとの限度額・算定期間と対象負担を確認 |
| **出産** | 出産費、家族出産費 | 本人・被扶養者の出産の費用 |
| **死亡** | 埋葬料、家族埋葬料 | 本人・被扶養者の死亡 |
| **休業** | **傷病手当金**、出産手当金、休業手当金 | 働けない間の所得の補填 |

**「医療」と「休業」の2つの性格がある**ことが、短期給付の特徴です。医療費の給付は民間の健康保険と同じ骨で、休業の手当も民間の健康保険にあります。

第54条は、組合が政令で定めるところにより、これらに**併せて「これに準ずる短期給付」を行うことができる**と定めています。**附加給付**と呼ばれ、たとえば高額療養費の自己負担の上限をさらに下げる給付を行っている組合があります。**附加給付の有無と中身は保険者ごとに違う**ため、次の加入先にも確認します。

## 傷病手当金——働けない間の手当

短期給付のうち、転職を考える方に最も関わるのが**傷病手当金**です。第68条第1項は、こう定めています。

> 組合員（中略）が公務によらないで病気にかかり、又は負傷し、療養のため引き続き勤務に服することができない場合には、勤務に服することができなくなつた日以後三日を経過した日から、その後における勤務に服することができない期間、傷病手当金を支給する。

| 項目 | 内容（第68条） |
|---|---|
| **要件** | 公務によらない病気・負傷で、療養のため引き続き勤務できない |
| **支給の開始** | 勤務できなくなった日以後**3日を経過した日**から |
| **額** | 直近12か月の標準報酬の月額の平均の**22分の1**に相当する額の**3分の2**（1日につき） |
| **期間** | **1年6か月**（結核性の病気は3年） |

**公務による病気や負傷は、公務災害補償の側で扱われます。**傷病手当金は、公務によらない場合の給付です。

## 退職で、何がどう変わるか

退職すると、原則として在職時の組合員資格は翌日に失われます（第39条）。**退職後の診療には、その時点の資格を確認します。**旧資格期間の診療分が退職後に支給される場合もあり、給付日だけで資格や対象期間を判断しません。

| 給付 | 退職の翌日から |
|---|---|
| **医療費の給付** | 新たな診療は任意継続・国保・転職先の保険・家族の扶養等、次の資格で確認 |
| **家族の医療費** | 本人と家族それぞれの次の資格・扶養認定を確認 |
| **高額療養費** | 診療時の資格に対応する保険者で確認。旧資格分の後日支給は別 |
| **附加給付** | 旧資格分、任意継続の対象給付、次の保険者の制度を区別 |
| **傷病手当金** | 原則として終わる（例外は次の項） |

**空白を作らないことが、いちばん大事**です。退職の翌日から転職先の健康保険に入るなら空白はありませんが、間があくなら、任意継続か国民健康保険に切り替えます。任意継続は、第144条の2により、**退職の日の前日まで1年以上組合員であった者が、退職の日から20日以内に申し出る**ことで、**最長2年、短期給付を受け続けられる**仕組みです。ただし、任意継続を理由として新たに傷病手当金・出産手当金が支給されるものではありません。**在職中からの継続給付は別の要件で確認**します。大阪市職員共済組合は、任意継続の保健給付・附加給付と休業給付等の制限を区分しています。

## 退職後の傷病手当金——在職中に受けていた場合

在職中に傷病手当金を受けていた方が退職する場合、**退職後も引き続き支給を受けられる仕組み**があります。第68条は、**1年以上組合員であった者が退職した際に傷病手当金を受けている場合には、その者が退職しなかったとしたならば受けることができる期間、継続して支給する**と定めています。**要件は「1年以上の組合員期間」と「退職の際に受けていること」**で、退職の日と支給の状態の関係で扱いが変わります。**在職中に傷病手当金を受けている方が退職を考えるなら、退職前に必ず共済組合に確認してください。**

:::insight
退職後の医療を準備する際は、給付が振り込まれる日と、受診時の資格を分けて考えることが大切です。在職中の診療分が退職後に支給されても、旧資格で受診を続けられる意味ではありません。マイナンバーカードは返却せず、新しい保険への加入と資格情報の更新を確認します。資格確認書等の返納は発行元の案内に従ってください。私たちは、本人と家族の資格日、旧資格分の未支給給付、任意継続で受けられる給付を別々に一覧にする方法が役立つと考えます。附加給付は退職だけで一律に終了と決めず、組合と次の加入先で対象と手続きを確認してください。切替時の受診方法も保険者と医療機関へ尋ね、給付の見込みと必要な支払いを分けて準備します。
:::

## 転職するとどうなるか

転職を考えている方にとって、短期給付で効いてくる点は3つです。

**1. 退職後の受診には、現在の保険資格を確認する**

**健康保険の空白を作らない**ことが最優先です。切替えの選択肢は[退職後の健康保険、3つの選択肢](seido-kenko-sentaku.html)に書いています。

**2. 附加給付は、旧資格・任意継続・次の保険者で確認する**

医療費が続いている方は、**共済組合の附加給付と転職先の制度を比べてください。**

**3. 在職中に傷病手当金を受けているなら、退職前に共済組合に確認する**

退職後の継続給付の要件は、退職の日と支給の状態で変わります。**退職日を決める前に確認**してください。

## 手続きと期限

| 場面 | すること | 期限・場所 |
|---|---|---|
| 退職時 | 資格確認書等の返納物を確認。マイナンバーカードは返却しない | 共済担当。旧保険証は有効期限が終了 |
| 任意継続を選ぶ | 申出と初回の掛金の払込み | 申出は原則**退職の日から起算して20日以内**（第144条の2）。初回掛金は指定期日を別に確認 |
| 国民健康保険を選ぶ | 加入の手続き | 資格喪失後14日以内に住所地へ。必要書類を確認 |
| 転職先の健康保険に入る | 転職先が資格取得の届出 | 入社日 |
| 切替時に医療を受ける | 新資格の確認方法を相談。全額負担した場合の療養費等も確認 | 保険者・医療機関。資格と制度の条件による |

任意継続は退職日からの起算、初回掛金の期限、組合の事務締切を分けて確認します。国保にも届出期限があり、証明書が間に合わなければ窓口へ相談します。加入日と実際の受診時の確認方法は別です。

## 誤解されやすい点

**「最終出勤後や退職後も、旧資格で月末まで受診できる」と思い込む**

最終出勤日と退職日を区別し、退職の翌日以後の新しい資格を確認してください。旧保険証は2025年12月1日までに有効期限を終えており、現在の受診書類ではありません。

**「任意継続なら、傷病手当金も続く」と思い込む**

任意継続によって新たな傷病手当金・出産手当金の権利が生じるわけではありません。在職中からの継続給付は別の要件で確認します。

**「附加給付は民間の健康保険にもある」と思い込む**

保険者ごとの制度なので、次の加入先に有無と内容を確認します。任意継続で対象となる給付も所属組合へ確認してください。

**「傷病手当金を受けながら退職すると、すぐに打ち切られる」と思い込む**

**1年以上組合員であった者が退職の際に受けていれば、継続して支給されます**（第68条）。要件は退職前に共済組合で確認してください。

:::insight
医療保険の違いを確認することは、退職するか残るかを一つの給付だけで決めることではありません。現在の共済、任意継続、次の加入先について、対象となる医療費、計算単位、給付の時期、掛金や保険料を分けて比べる必要があります。私たちは、本人や家族が継続できる働き方と、確認した制度条件を同じ紙に並べる方法が役立つと考えます。現職の勤務時間や通院との両立が希望に合うなら、残る選択にも理があります。他の仕事を検討する場合も、給付の名称だけで差を判断せず、保険者へ対象と手続きを尋ねてください。未確認の給付を生活費の前提にせず、必要な治療や家族の資格を確かめたうえで、仕事内容と勤務条件を合わせて考えましょう。
:::

## まとめ

- 短期給付は、**療養の給付（医療費）、家族の医療費、高額療養費、出産費、埋葬料、傷病手当金・出産手当金・休業手当金**などです（地方公務員等共済組合法第53条）。民間の健康保険に相当します
- 組合は**附加給付**——たとえば自己負担の上限をさらに下げる給付——を行うことができ、中身は組合ごとに違います（第54条）
- **傷病手当金は、公務によらない病気・負傷で働けなくなった日以後3日を経過した日から、標準報酬の月額の平均の22分の1の3分の2を、最長1年6か月**支給します（第68条）
- **退職後の新たな診療は次の資格で確認します。**任意継続（第144条の2）・国保・新勤務先の保険・家族の扶養等を確認し、在職中からの傷病手当金等の継続給付は別に扱います
- **在職中に傷病手当金を受けている方は、退職後の継続給付の要件を退職前に共済組合で確認**してください
- **附加給付は旧資格期間の給付、任意継続、次の保険者の制度を分けて確認**します。詳しくは[医療費の自己負担と附加給付](seido-kyosai-iryou-futan.html)で整理しています

## よくある質問

### 退職の翌日に病院に行く予定があります。何を確認しますか

その時点の新しい保険資格を確認します。マイナ保険証の資格情報の更新、資格確認書等の交付や切替時の受診方法を、保険者と医療機関へ尋ねてください。マイナンバーカードは返却しませんが、新しい加入の手続きは必要です。やむを得ず全額を支払った場合の療養費等は加入先へ確認します。受診日を制度の都合だけで変えるのではなく、必要な治療について医療機関へ相談してください。

### 共済組合の附加給付で、医療費の自己負担が少なくて済んでいました。転職先ではどうなりますか

**転職先の健康保険の制度によります。**附加給付は地方公務員等共済組合法第54条により組合が行うことができる給付で、組合ごとに中身が違います。**民間の健康保険では、健康保険組合によっては同様の付加給付を行っているところもありますが、協会けんぽにはありません。**転職先がどの健康保険に入っているか、付加給付があるかを、内定の段階で担当部門に聞いてください。医療費が続いている方は、**共済組合の附加給付の額と、転職先の制度の自己負担の上限を並べて比べる**と、差が数字で見えます。差があっても、それが転職の判断を変える桁かどうかは、年間の医療費の水準によります。

### 傷病手当金を受けながら、退職を考えています。退職後も受けられますか

**退職前に、必ず共済組合に確認してください。**地方公務員等共済組合法第68条は、1年以上組合員であった者が退職した際に傷病手当金を受けている場合には、退職しなかったとしたならば受けることができる期間、継続して支給すると定めています。**要件は「1年以上の組合員期間」と「退職の際に受けていること」で、退職の日と支給の状態の関係で扱いが変わります。**退職日を決める前に、共済組合に「退職後の継続給付の要件」を確かめてください。なお、在職中からの継続給付と、任意継続への加入は別の仕組みです。任意継続に入るだけで新たに傷病手当金が支給されるものではありません。
