病院の窓口で組合員証を出すと、医療費の3割の負担で済む。**それが、共済組合の「短期給付」**です。民間の健康保険に相当します。

短期給付には、医療費のほかにも、**病気で働けない間の手当、出産の費用、家族の医療費**などが含まれます。**退職すると、これらは退職の翌日から使えなくなります。**在職中に当たり前に使っていた給付が、翌日から別の制度に切り替わる——ここを知らないまま退職日を迎える方が多くいます。

この記事では、**短期給付の中身と、退職で何がどう変わるか**を、地方公務員等共済組合法の条文で整理します。**自分の組合の給付の詳細は、所属の共済組合で確認してください。**共済の全体は[地方公務員共済組合の仕組み](seido-kyosai-shikumi.html)に書いています。

## 短期給付の種類——第53条

地方公務員等共済組合法第53条第1項は、短期給付を次のように列挙しています。

| 区分 | 給付 | 中身 |
|---|---|---|
| **医療** | 療養の給付、入院時食事療養費、入院時生活療養費、保険外併用療養費、療養費、訪問看護療養費、移送費 | 組合員本人の医療費。窓口で組合員証を出して受ける |
| **家族の医療** | 家族療養費、家族訪問看護療養費、家族移送費 | 被扶養者の医療費 |
| **高額の医療** | 高額療養費、高額介護合算療養費 | 1か月の自己負担が上限を超えた分 |
| **出産** | 出産費、家族出産費 | 本人・被扶養者の出産の費用 |
| **死亡** | 埋葬料、家族埋葬料 | 本人・被扶養者の死亡 |
| **休業** | **傷病手当金**、出産手当金、休業手当金 | 働けない間の所得の補填 |

**「医療」と「休業」の2つの性格がある**ことが、短期給付の特徴です。医療費の給付は民間の健康保険と同じ骨で、休業の手当も民間の健康保険にあります。

第54条は、組合が政令で定めるところにより、これらに**併せて「これに準ずる短期給付」を行うことができる**と定めています。**附加給付**と呼ばれ、たとえば高額療養費の自己負担の上限をさらに下げる給付を行っている組合があります。**附加給付の有無と中身は組合ごとに違い、民間の健康保険にはないことが多い**部分です。

## 傷病手当金——働けない間の手当

短期給付のうち、転職を考える方に最も関わるのが**傷病手当金**です。第68条第1項は、こう定めています。

> 組合員（中略）が公務によらないで病気にかかり、又は負傷し、療養のため引き続き勤務に服することができない場合には、勤務に服することができなくなつた日以後三日を経過した日から、その後における勤務に服することができない期間、傷病手当金を支給する。

| 項目 | 内容（第68条） |
|---|---|
| **要件** | 公務によらない病気・負傷で、療養のため引き続き勤務できない |
| **支給の開始** | 勤務できなくなった日以後**3日を経過した日**から |
| **額** | 直近12か月の標準報酬の月額の平均の**22分の1**に相当する額の**3分の2**（1日につき） |
| **期間** | **1年6か月**（結核性の病気は3年） |

**公務による病気や負傷は、公務災害補償の側で扱われます。**傷病手当金は、公務によらない場合の給付です。

## 退職で、何がどう変わるか

**短期給付は、組合員の資格がある間の給付**です。退職すると、資格は退職の日の翌日に失われ、**その日から組合員証は使えません。**

| 給付 | 退職の翌日から |
|---|---|
| **医療費の給付** | **使えない。**任意継続、国民健康保険、転職先の健康保険のいずれかに切り替える |
| **家族の医療費** | 同上。被扶養者も同時に資格を失う |
| **高額療養費** | 切り替えた先の制度で受ける |
| **附加給付** | **終わる。**転職先の健康保険にはないことが多い |
| **傷病手当金** | 原則として終わる（例外は次の項） |

**空白を作らないことが、いちばん大事**です。退職の翌日から転職先の健康保険に入るなら空白はありませんが、間があくなら、任意継続か国民健康保険に切り替えます。任意継続は、第144条の2により、**退職の日の前日まで1年以上組合員であった者が、退職の日から20日以内に申し出る**ことで、**最長2年、短期給付を受け続けられる**仕組みです。ただし、**傷病手当金と出産手当金は、任意継続組合員には支給されません**（第68条第1項の括弧書きで任意継続組合員が除かれています）。

## 退職後の傷病手当金——在職中に受けていた場合

在職中に傷病手当金を受けていた方が退職する場合、**退職後も引き続き支給を受けられる仕組み**があります。第68条は、**1年以上組合員であった者が退職した際に傷病手当金を受けている場合には、その者が退職しなかったとしたならば受けることができる期間、継続して支給する**と定めています。**要件は「1年以上の組合員期間」と「退職の際に受けていること」**で、退職の日と支給の状態の関係で扱いが変わります。**在職中に傷病手当金を受けている方が退職を考えるなら、退職前に必ず共済組合に確認してください。**

:::insight
面談で伺うと、**退職の翌日に病院に行って、組合員証が使えないことを窓口で知った**という方がいます。退職の翌日から資格がないので、その日の医療費はいったん全額を負担し、後から切り替えた先の制度に請求する形になります。**戻りますが、手間と時間がかかります。**もう1つ、**共済組合の附加給付で自己負担の上限が下がっていたことを、転職先の健康保険で初めて気づいた**という方もいます。附加給付は組合ごとの制度で、転職先にはないことが多い。持病があって医療費が続いている方には、この差は小さくありません。ここで1つ提案があります。**退職日が決まったら、「退職の翌日に組合員証が使えない」ことを前提に、健康保険の切替えの手続きの日付を先に決めてください。**任意継続なら20日以内、国民健康保険なら退職後速やかに、転職先なら入社日。**そして、共済組合に附加給付の有無を確かめ、転職先の健康保険と比べる。**この2つで、切替えの空白と、給付の差の両方が見えます。
:::

## 転職するとどうなるか

転職を考えている方にとって、短期給付で効いてくる点は3つです。

**1. 退職の翌日から、組合員証は使えない**

**健康保険の空白を作らない**ことが最優先です。切替えの選択肢は、別の記事に整理します。

**2. 附加給付は、転職先の健康保険にはないことが多い**

医療費が続いている方は、**共済組合の附加給付と転職先の制度を比べてください。**

**3. 在職中に傷病手当金を受けているなら、退職前に共済組合に確認する**

退職後の継続給付の要件は、退職の日と支給の状態で変わります。**退職日を決める前に確認**してください。

## 手続きと期限

| 場面 | すること | 期限・場所 |
|---|---|---|
| 退職時 | 組合員証と被扶養者の証を返納 | 自治体の共済の担当 |
| 任意継続を選ぶ | 申出と初回の掛金の払込み | **退職の日から20日以内**（第144条の2）。初回の掛金を期日までに払わないと不成立 |
| 国民健康保険を選ぶ | 加入の手続き | 資格喪失後、速やかに市区町村へ |
| 転職先の健康保険に入る | 転職先が資格取得の届出 | 入社日 |
| 退職の翌日以降に医療を受けた | 切り替えた先の制度に療養費を請求 | 制度ごとの期限内に |

**期限が明確なのは、任意継続の20日**です。他の切替えも、空白の日数だけ全額負担の医療費が発生するので、速やかに行ってください。

## 誤解されやすい点

**「退職しても、月末までは組合員証が使える」と思い込む**

**退職の翌日から使えません。**月末退職でも、翌月1日から資格がありません。

**「任意継続なら、傷病手当金も続く」と思い込む**

**任意継続組合員には傷病手当金と出産手当金は支給されません**（第68条第1項の括弧書き）。医療費の給付が続くだけです。

**「附加給付は民間の健康保険にもある」と思い込む**

**組合ごとの制度で、転職先にはないことが多い**部分です。

**「傷病手当金を受けながら退職すると、すぐに打ち切られる」と思い込む**

**1年以上組合員であった者が退職の際に受けていれば、継続して支給されます**（第68条）。要件は退職前に共済組合で確認してください。

:::insight
ここまで短期給付の話を書いておいて逆のことを言いますが、**短期給付の違いは、転職の判断を決めるものではありません。**健康保険は民間にもあり、医療費の給付の骨は同じです。違うのは、附加給付の有無と、切替えの手続きの手間です。面談で伺うと、**「共済の健康保険が手厚いから辞められない」とおっしゃる方**の話を聞くと、**附加給付の実際の額を確かめていない**ことがほとんどです。確かめると、年間の医療費の水準によっては、判断の材料として小さいことが多い。逆に、持病で医療費が続いている方は、確かめたうえで転職先の制度と比べる価値があります。**どちらも、確かめてから決める。**そのうえで、**自分の経験に値を付けてくれる業界の見込みと、同じ紙に並べてください。**片方だけでは比較になりません。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 短期給付は、**療養の給付（医療費）、家族の医療費、高額療養費、出産費、埋葬料、傷病手当金・出産手当金・休業手当金**などです（地方公務員等共済組合法第53条）。民間の健康保険に相当します
- 組合は**附加給付**——たとえば自己負担の上限をさらに下げる給付——を行うことができ、中身は組合ごとに違います（第54条）
- **傷病手当金は、公務によらない病気・負傷で働けなくなった日以後3日を経過した日から、標準報酬の月額の平均の22分の1の3分の2を、最長1年6か月**支給します（第68条）
- **退職の翌日から組合員証は使えません。**任意継続（退職の日から20日以内、最長2年）、国民健康保険、転職先の健康保険のいずれかに切り替えます（第144条の2）。**任意継続では傷病手当金は支給されません**
- **在職中に傷病手当金を受けている方は、退職後の継続給付の要件を退職前に共済組合で確認**してください
- **附加給付は転職先にはないことが多い**ので、医療費が続いている方は比べてください

## よくある質問

### 退職の翌日に病院に行く予定があります。組合員証は使えますか

**使えません。**短期給付は組合員の資格がある間の給付で、資格は退職の日の翌日に失われます。月末退職でも、翌月1日から使えません。**退職の翌日に受診するなら、その時点で加入している制度の証が要ります。**転職先に翌日入社するなら転職先の健康保険（証が届くまでは資格の証明の手続きを転職先に確認）、任意継続なら共済組合の新しい組合員証、国民健康保険なら市区町村の保険証です。**証が間に合わない場合は、いったん全額を負担して、後から加入している制度に療養費を請求**する形になります。受診の予定がある方は、切替えの手続きを退職前に済ませておくか、受診の日を調整してください。

### 共済組合の附加給付で、医療費の自己負担が少なくて済んでいました。転職先ではどうなりますか

**転職先の健康保険の制度によります。**附加給付は地方公務員等共済組合法第54条により組合が行うことができる給付で、組合ごとに中身が違います。**民間の健康保険では、健康保険組合によっては同様の付加給付を行っているところもありますが、協会けんぽにはありません。**転職先がどの健康保険に入っているか、付加給付があるかを、内定の段階で担当部門に聞いてください。医療費が続いている方は、**共済組合の附加給付の額と、転職先の制度の自己負担の上限を並べて比べる**と、差が数字で見えます。差があっても、それが転職の判断を変える桁かどうかは、年間の医療費の水準によります。

### 傷病手当金を受けながら、退職を考えています。退職後も受けられますか

**退職前に、必ず共済組合に確認してください。**地方公務員等共済組合法第68条は、1年以上組合員であった者が退職した際に傷病手当金を受けている場合には、退職しなかったとしたならば受けることができる期間、継続して支給すると定めています。**要件は「1年以上の組合員期間」と「退職の際に受けていること」で、退職の日と支給の状態の関係で扱いが変わります。**退職日を決める前に、共済組合に「退職後の継続給付の要件」を確かめてください。なお、任意継続組合員には傷病手当金は支給されない（第68条第1項）ので、継続給付は任意継続とは別の仕組みです。
