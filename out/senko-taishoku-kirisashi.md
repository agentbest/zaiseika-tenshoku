内定を受諾したら、**次は職場に伝える番**です。

**ここでつまずく方が多くいます。**言い出しにくい、いつ言えばよいか分からない、誰に言えばよいか迷う。

この記事では、**相手・時期・伝え方**を扱います。書面の出し方は[退職願・退職届の書き方と出す相手](senko-taishoku-negai.html)にあります。

## 最初に伝えるのは、直属の上司です

**組織の中の関係は、制度で定められています。**

**地方公務員法第32条**です。

> 職員は、その職務を遂行するに当つて、法令、条例、地方公共団体の規則及び地方公共団体の機関の定める規程に従い、且つ、**上司の職務上の命令に忠実に従わなければならない。**

**上司の職務上の命令に従う。**

**日常の業務は、この関係の上で動いています。**

**退職は、その関係を終える話**です。**だから、最初に伝えるのは直属の上司**になります。

**人事の担当に先に相談したり、同僚に先に話したりすると、上司が最後に知ることになります。**

**それは、その後の引継ぎの調整に影響します。**

## 伝える順番

| 順 | 相手 | 時期 |
|---|---|---|
| 1 | **直属の上司**（係長・課長補佐など） | 入社日が確定した直後 |
| 2 | 課長など、所属の長 | 上司の判断で同席または別途 |
| 3 | 人事の担当 | 書面の提出に合わせて |
| 4 | 同僚 | **所属の長の了解を得てから** |
| 5 | 関係する他課・外部 | 引継ぎの段階で |

**4を自分の判断で進めないでください。**

**誰に、いつ伝えるかは、所属の長が決める**のが通常です。

**先に同僚に伝わると、業務の割り振りや、周囲の受け止めに影響します。**

## 時期の目安

| 状況 | 伝える時期 |
|---|---|
| 規程に定めがある | **その期間を見込んで逆算** |
| 定めがない | **1〜2か月前**が一般的とされています |
| 引継ぎに時間がかかる | 早めに |
| 年度末の退職 | 年内から年明けにかけて |

**入社日が確定してから伝えてください。**

**確定前に伝えると、日程が動いたときに修正が必要**になります。

**逆に、遅すぎると引継ぎの時間が取れません。**

## 伝える場の作り方

| 項目 | 実務 |
|---|---|
| 場所 | **個室か、人のいない場所**（執務室では避ける） |
| 時期 | 繁忙期の直前や、会議の直前は避ける |
| 方法 | **対面。**やむを得ない場合は電話 |
| 時間 | 15〜30分程度を見込む |
| 切り出し方 | 「お時間をいただけますか」と先に伝える |

**5つ目について補足します。**

**「ご相談があります」と切り出すと、相談の話になります。**

**すでに決まっているなら、「ご報告したいことがあります」**のほうが、**内容と合っています。**

## 最初の一言

**次の3点を、最初の1分で伝えてください。**

| 順 | 内容 |
|---|---|
| ① | **退職したいと考えていること** |
| ② | **希望する退職日** |
| ③ | **引継ぎに協力する意思** |

> お時間をいただきありがとうございます。私事で恐縮ですが、◯月◯日をもって退職させていただきたいと考えております。引継ぎについては、できる限りの準備をいたします。

**3文で足ります。**

**①を曖昧にしないでください。**「考えている段階で」と述べると、**相談として受け取られます。**

**決まっているなら、決まっていると伝える。**これが、いちばん誠実です。

## 聞かれることへの備え

| 質問 | 答え方 |
|---|---|
| 「どこに行くのか」 | **業種程度で足ります**（詳細は不要） |
| 「いつから考えていたのか」 | 「数か月前から検討していました」 |
| 「不満があったのか」 | **人や組織への不満は述べない** |
| 「考え直す余地はないか」 | **意思が固いことを、丁寧に伝える** |
| 「引継ぎはどうするのか」 | **準備している旨を述べる** |

**1つ目について補足します。**

**転職先を詳しく伝える必要はありません。**とくに、**その会社が自治体と取引がある場合は、在職中に具体的な話をすることは避けてください。**

**「民間の会社です」という程度で足ります。**

:::insight
切り出す場面で、**面談でいちばん多い相談が「言い出せないまま時間が過ぎる」**です。理由を伺うと、**「上司に迷惑をかける」「時期が悪い」**という答えが返ってきます。ただ、**時期が良いタイミングは、まず来ません。**役所の業務には、年度末も、予算の編成も、議会もあります。**どこかに必ず繁忙期があります。**そして、**遅れるほど引継ぎの時間が減り、結果として迷惑が大きくなります。**対処としては、**入社日が確定したら、その週のうちに伝える**と決めてしまうことです。面談で拝見していると、**伝えた後は、むしろ楽になる方が大半**です。決まっていることを抱えている状態のほうが、**業務にも影響します。**言い出しにくいのは自然ですが、**早く伝えることが、いちばん相手のためになります。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 伝える前に、手元で整えておくこと

**その場で聞かれることに答えられるよう、次の4点を整理しておいてください。**

| 項目 | 内容 |
|---|---|
| 希望する退職日 | **日で答える。**「年度末ごろ」では調整が進みません |
| 引継ぎに必要な期間の見積もり | 担当業務の量から逆算した日数 |
| 進行中の案件の一覧 | 年度をまたぐものを含めて |
| 年次休暇の残日数 | 消化を希望するかどうか |

**2つ目と3つ目を用意しておくと、その場で引継ぎの計画の話に進めます。**

**「引継ぎはどうするのか」と聞かれて、「これから考えます」と答えると、**相手は**判断の材料を持てません。**

**一覧を手元に持っていれば、「この案件は◯月までに、この案件は後任へ」という話ができます。**

**用意に要するのは1時間程度**です。**伝える前日にでも作れます。**

## 部署の状況で、時期を微調整する

**同じ1〜2か月前でも、部署の事情で適切な週が変わります。**

| 状況 | 避けたい週 |
|---|---|
| 議会の開会中 | 会期中と、その直前の準備の週 |
| 予算の編成期 | 要求の締切の直前 |
| 窓口の繁忙期 | 申請が集中する時期の直前 |
| 監査の対応中 | 実地の監査の前後 |

**避けるのは「その週」であって、「その月」ではありません。**

**数日ずらせば足りることがほとんど**です。**時期を大きく後ろにずらすと、引継ぎの時間が減ります。**

## 伝えた後にすること

| 順 | やること |
|---|---|
| 1 | 上司と、**退職日と引継ぎの計画**を相談 |
| 2 | 所属の長への報告の段取りを確認 |
| 3 | 同僚へ伝える時期を、**上司と決める** |
| 4 | 書面を提出 |
| 5 | 引継ぎの資料の作成に着手 |

**3を確認してください。**

**「いつ、誰に、どこまで伝えてよいか」**を、上司と決めておくと、**周囲との関係が保てます。**

[経験の言い換えから相談する](../apply.html)こともできます。

**なお、伝えた直後に業務の割り振りが変わることがあります。**新しい案件を持たない、長期の業務から外れる、といった形です。**これは通常の調整**であって、排除ではありません。**引継ぎの時間を作るための措置**と受け止めてください。

## よくある失敗

**1. 同僚に先に話す**

**上司が最後に知ることになります。**

**2. 「相談があります」と切り出す**

**決まっているなら、報告の形**にしてください。

**3. 入社日が確定する前に伝える**

**日程が動いたときに修正が必要**です。

**4. 執務室で立ち話として伝える**

**場を作ってください。**

**5. 転職先を詳しく話す**

**業種程度で足ります。**

**6. 言い出せないまま遅れる**

**引継ぎの時間が減ります。**

:::insight
ここまで伝え方の話をしておいて逆のことを言いますが、**伝えた後の反応は、想像より穏やかであることが多い**です。面談で伺っていると、**「怒られると思っていたが、そうでもなかった」**という感想をよく聞きます。理由は単純で、**上司の側も、職員が辞めることを経験しているから**です。役所では、定年、育児、介護、家庭の事情で、**人が抜ける場面が日常的にあります。**組織として、**対応の仕組みはあります。**むしろ、**伝えた後に関係が悪くなるのは、伝え方や引継ぎの進め方が雑だった場合**です。丁寧に伝え、**最後まで業務を担い、引継ぎを整える。**この3つを守れば、**関係は保てます。**そして、**自治体を顧客とする業界に移る場合、その関係は仕事の上でも意味を持ちます。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方公務員法第32条**は、**上司の職務上の命令に忠実に従う**ことを定めています。**最初に伝えるのは直属の上司**です
- 順番は、**①直属の上司 ②所属の長 ③人事の担当 ④同僚 ⑤関係先**。**④を自分の判断で進めないで**ください
- 時期は、**入社日が確定してから。**規程に定めがあれば、その期間を逆算します
- **場を作ってください。**執務室での立ち話は避けます
- 最初の1分で、**①退職の意思 ②希望する退職日 ③引継ぎへの協力**の3点を伝えます
- **「相談があります」ではなく「報告したいことがあります」。**決まっているなら、そう伝えてください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 直属の上司と関係が良くありません

**それでも、最初に伝えてください。**順序を飛ばすと、**後の調整がさらに難しくなります。**伝える内容は、**事実と日程だけ**で足ります。感情の部分に触れる必要はありません。「◯月◯日をもって退職したいと考えております」と述べ、**引継ぎに協力する意思を添える。**それで手続きは進みます。なお、**どうしても直接伝えることが難しい事情がある場合は、所属の長か人事の担当に相談**してください。**事情によっては、経路が調整されることがあります。**ただし、原則は直属の上司です。

### 上司が不在がちで、時間が取れません

**予定を押さえてください。**「◯分ほどお時間をいただきたいのですが」と、**先に依頼する**形です。内容を先に伝える必要はありません。**それでも時間が取れない場合は、電話でも構いません。**重要なのは、**早く伝えること**です。対面にこだわって時期が遅れるより、**電話で伝えて、後日改めて相談の場を持つ**ほうが確実です。なお、**メールだけで済ませるのは避けてください。**記録として残す必要がある場合も、**口頭で伝えた後に送る**という順にしてください。

### 異動の内示が出た直後に、退職を伝えることになりました

**その場合も、早く伝えてください。**内示の後に退職が判明すると、**配置の調整をやり直すことになります。**遅れるほど、影響が大きくなります。伝えるときは、**内示を受けた事実に触れたうえで、退職の意思を述べる**形になります。「内示をいただいたところ恐縮ですが」という一言を添えれば足ります。**謝りすぎる必要はありません。**なお、**内示の前に伝えられるなら、そのほうが望ましい**です。人事の作業は、**年明けから動いている**ことがあります。
