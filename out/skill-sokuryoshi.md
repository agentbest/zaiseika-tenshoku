**道路や用地の事務を担当してきた方から、「測量の資格は使えるか」**というご相談を伺います。

**資格の位置づけが、法律で決まっている分野**です。

この記事では、**その構造**と、**経験との接続**を扱います。

**⚠ 受験・登録の要件と手続は、所管するところの公表を確認してください。****この記事では、個別の要件には触れません。**

## 公共測量に従事する者は、登録された者に限られます

**測量法第48条第1項**です。

> **技術者として基本測量又は公共測量に従事する者は、第四十九条の規定に従い登録された測量士又は測量士補でなければならない。**

**同条第2項・第3項**です。

> ２ **測量士は、測量に関する計画を作製し、又は実施する。**
>
> ３ **測量士補は、測量士の作製した計画に従い測量に従事する。**

**技術者として従事する者が、登録された者に限られる**という構造です。

**そして、計画を作る立場と、計画に従って従事する立場が、条文で分けられています。**

**この構造があるため、測量を行う事業者には、資格を持つ人が必要になります。**

**資格の需要が、法律の条文から生じている**ということです。

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 測量の事業 | **資格が前提になります** |
| ② 建設コンサルタント | 調査、設計、成果の確認 |
| ③ 発注者支援 | **発注する側の視点** |
| ④ 用地の取得の支援 | 境界、面積の確認 |
| ⑤ 施工管理 | 現場の測定 |

**③が、公務員からの転職で中心**になります。

**発注する側として、仕様を作り、成果を確認してきた経験**は、支援の業務で直接使えます。

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 発注する側で身についていること

| 経験 | 民間での読まれ方 |
|---|---|
| ① 仕様の作成 | **求める成果の記述** |
| ② 成果の確認 | 検査、照査の観点 |
| ③ 境界の確認 | 権利者との立会い |
| ④ 図面・座標の扱い | 成果の読み取り |
| ⑤ 工程の管理 | 調査から設計までの流れ |
| ⑥ 関係者との調整 | 権利者、他の企業者 |

**②と③が、発注する側ならでは**です。

**②について。**

**提出された成果のどこを見るか**を知っていることは、**支援の業務でそのまま使えます。**

**③について。**

**立会いの場で、権利者に説明し、同意を得てきた経験**です。

**扱いは**[不動産鑑定士｜用地買収の経験からの接続](skill-kanteishi.html)**にも整理しています。**

## 書き方の例

**悪い例**

> 道路の担当で、測量の発注をしていました。

**良い例**

> ◯◯の事業において、**発注者として、測量の業務◯件の仕様の作成から成果の確認までを担当。**延長約◯メートルの区間について、**現地の状況と既存の資料を確認のうえ、求める成果と精度を仕様に記載。****境界の立会いに年◯件同行し、権利者への説明と同意の取得**を担当。成果について、**図面と座標の整合を確認し、検査を実施。**

**「立場」「件数」「規模」「立会い」「検査」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

:::insight
測量に関わってきた方について、**面談でお伝えしているのが「成果を受け取る側にいた経験を書いてください」**という点です。**自分で観測や計算をしていなくても、仕様を作り、提出された成果を確認し、検査をしてきた**はずです。**どの精度を求めるか、どの資料と整合を見るか、どこで差し戻すか。****これは、受け取る側にいないと身につきません。**そして、**発注者支援や建設コンサルタントでは、この視点が業務の前提**になります。発注者が何を見るかを知っている人は、**手戻りの少ない成果を作れます。**書類には、**「発注者として、仕様の作成から成果の確認までを担当」**と明記してください。**「測量の発注をしていました」では、この立場が伝わりません。**資格の有無より、まずこの整理をしてください。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 資格の位置づけ

| 状況 | 扱い |
|---|---|
| ① 測量に従事する | **登録が前提になります** |
| ② 応募条件に記載がある | 満たす材料になる |
| ③ 発注する側の支援 | **経験のほうが具体な場合も** |
| ④ 技術者として配置される | 資格が必要になることがあります |
| ⑤ 目的が曖昧 | 優先順位を下げてください |

**①と④について。**

**測量法第48条のとおり、技術者として従事するには登録が必要**です。

**⚠ 受験・登録の要件と手続は、所管の公表を確認**してください。

**なお、取れば転職できる、という関係にはありません。**

**何を発注し、どう確認したか**が、評価の対象です。

## 取る前に考えること

| 確認すること | 内容 |
|---|---|
| ① 目的 | **従事するのか、支援に回るのか** |
| ② 受験・登録の要件 | 所管の公表を確認 |
| ③ 実務で書ける材料 | 仕様、検査、立会い |
| ④ 期限 | 応募の時期に間に合うか |
| ⑤ 在職中の学習 | 続けられるか |

**①で大きく分かれます。**

**現場で測量に従事する**のか、**発注や管理の側に回る**のか。

**後者であれば、資格がなくても応募できる求人があります。**

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 実績の整理 | **件数、延長、区間、事業の種類** |
| 検査の観点の整理 | 何を見たか |
| 立会いの整理 | 件数、説明の内容 |
| 求人を読む | 週に30分 |

**1行目です。**

**設計書や決裁の資料から、延長と件数を確認**してください。

**根拠のない数は書かないでください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 担当した事業 | **種類、規模、期間** |
| 仕様の作り方 | 求める精度、成果の範囲 |
| 検査の観点 | 何を確認したか |
| 立会いの経験 | 説明の進め方 |
| 立場 | **発注者か、受注者か** |

**5行目です。**

**発注する側の経験であることを明記**してください。

**なお、特定の権利者や物件が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

## 成果を受け取る側の確認の観点

**検査で見る項目は、そのまま書ける材料になります。**

| 観点 | 内容 |
|---|---|
| ① 範囲 | **仕様で求めた区間・面積と一致するか** |
| ② 精度 | 求めた水準を満たすか |
| ③ 整合 | 既存の資料・隣接する成果との突き合わせ |
| ④ 成果物の一式 | 図面、記録、報告の揃い |
| ⑤ 記載の正確さ | 名称、数値、単位 |

**③が、経験の差が出る部分**です。

**隣接する区間の成果や、過去の資料と合わない場合の扱い**を判断してきたはずです。

**この判断は、支援する側でも必要になります。**

**書類には、「既存の資料との突き合わせを実施し、相違が生じた場合の確認の手順を整理」**と書いてください。

## よくある失敗

**1. 「発注していました」で止める**

**仕様から検査まで**を書いてください。

**2. 立場を書かない**

**発注者か受注者か**を明記してください。

**3. 検査の観点を書かない**

**受け取る側の視点**が価値です。

**4. 立会いの経験を書かない**

**権利者への説明**は希少な経験です。

**5. 規模を書かない**

**延長、件数、区間**を書いてください。

**6. 資格がないと応募できないと考える**

**支援する側の求人**があります。

**7. 要件を人づてで判断する**

**所管の公表**を確認してください。

**8. 取れば転職できると考える**

**何を発注しどう確認したか**が評価の対象です。

:::insight
ここまで「発注する側の経験」を強調しておいて逆のことを言いますが、**現場に出る求人では、資格が前提になります。**面談で拝見していると、**発注の経験だけで現場の求人に応募し、条件が合わずに止まる方**がいらっしゃいます。**測量法第48条のとおり、技術者として公共測量に従事するには登録が必要**です。ですから、**「どちらに行きたいか」を先に決めてください。**現場に出たいなら、**資格の取得が前提**になります。一方、**発注者支援、管理、調整の職務**であれば、**いまの経験がそのまま使えます。**そして、**後者のほうが、行政の経験と重なる範囲が広い**です。仕様、検査、立会い、関係者との調整。**求人票の仕事内容の欄で、現場に出るかどうかを確認**してください。**この確認を飛ばすと、条件が合いません。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **測量法第48条**は、**技術者として基本測量又は公共測量に従事する者を、登録された測量士又は測量士補に限る**とし、**計画を作る立場と従事する立場**を分けています
- **資格の需要が、法律の条文から生じています**
- 効くのは、**測量の事業、建設コンサルタント、発注者支援、用地の取得の支援、施工管理**です
- **成果を受け取る側にいた経験**を書いてください。検査の観点は、受け取る側にしか身につきません
- **立会いで権利者に説明し、同意を得た経験**は希少です
- **現場に出るか、発注・管理に回るか**を先に決めてください
- **現場に出る求人では、資格が前提**になります

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 事務職ですが、測量の発注に関わっていました

**書けます。**技術職でなくても、**仕様の確認、契約の手続、成果の受領、検査の立会い**に関わっていれば、材料になります。書き方は、**「測量の業務◯件について、仕様の確認から契約、成果の受領までの手続を担当」**という形です。**手続の管理**として読まれます。なお、**技術的な判断を担っていない場合は、そう書いてください。**「技術的な確認は担当課が実施し、契約と進行の管理を担当」。**できる範囲を正確に書く**ほうが、入社後に困りません。扱いは[契約書の読み方｜自治体の契約実務との差](skill-keiyakusho.html)に整理しています。

### 測量士補から始めるべきですか

**目的で判断してください。**現場で従事することを目指すのであれば、**段階を踏む方法**があります。一方、**発注や管理の側に回る**のであれば、**資格が必須でない求人**もあります。**⚠ 受験・登録の要件と、資格ごとの位置づけは、所管するところの公表を確認**してください。**この記事では触れません。**なお、**在職中に要件を満たしているなら、在職中に進めるほうが負担が小さい**ことがあります。**証明の書類が必要になる場合、所属での手続が要る**こともあります。**時期と手続を、早めに確認**してください。

### 図面や座標の扱いは、どう書けばよいですか

**確認した観点で書いてください。**「提出された成果について、図面と座標の整合、既存の資料との突き合わせを実施」という形です。**何を確認したかが分かると、実務の水準が伝わります。**また、**使ったソフトや形式**がある場合、**範囲を明示して併記**してください。「◯◯の形式の成果を確認できます」。**できないことは書かないでください。**なお、**扱った規模**も併せて書いてください。延長、面積、件数。**数があると、範囲が伝わります。**
