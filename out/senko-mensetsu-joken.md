内定の提示を受けたとき、**条件に相談の余地があるかどうか**は、多くの方が気にする点です。

**「交渉すると、印象が悪くなるのではないか」**

役所では、**給与も勤務条件も条例で定まっています。**個人が交渉する場面がありません。そのため、**この場面に慣れていない**のは自然なことです。

この記事では、**相談できる範囲と伝え方**を扱います。提示を受ける場の全体は[オファー面談で確認すべきこと](senko-mensetsu-offer.html)にあります。

## 合意により変更できる、と書かれています

**まず、制度の前提を確認します。**

**労働契約法第8条**です。

> **労働者及び使用者は、その合意により、労働契約の内容である労働条件を変更することができる。**

**合意により、労働条件を変更できる。**

つまり、**条件は固定されたものではなく、合意で動き得るもの**として制度が組まれています。

**相談すること自体は、制度の前提の範囲内**です。

ただし、**合意が前提**である以上、**相手が応じなければ変わりません。**「交渉すれば通る」という話ではありません。

## 相談できる範囲と、難しい範囲

| 項目 | 相談の余地 |
|---|---|
| 入社の日 | **比較的相談しやすい** |
| 勤務地（複数の拠点がある場合） | 相談の余地がある |
| 働き方（在宅勤務、時差出勤） | 制度の範囲内で相談できる |
| 処遇 | **等級の幅の範囲内**であれば相談の余地 |
| 担当する業務 | 募集の枠によるため、難しいことが多い |
| 等級・役職 | **制度で決まっているため、難しい** |
| 賞与や退職金の制度 | **会社の制度そのもの**なので、変更できません |

**上の3つは、相談しやすい部分**です。

**下の3つは、個人のために制度を変えることになるため、応じられないのが通常**です。

**「何でも相談できる」わけでも、「何も相談できない」わけでもありません。**

## 伝えるときは、根拠を添える

**金額だけを伝えると、応じにくくなります。**

| ✕ | ○ |
|---|---|
| 「もう少し上げていただけませんか」 | 「求人票の◯◯の経験について、◯年の実務があります。その点を踏まえてご検討いただけますでしょうか」 |
| 「他社はもっと高いです」 | 「他社からも提示をいただいており、条件面で迷っています」 |
| 「生活が厳しいので」 | 「現在の年間の支給を基準に考えており、◯◯程度であれば判断しやすくなります」 |

**根拠になるのは、求人票に挙げられている要件と、自分の実務の対応**です。

**2つ目について補足します。**他社の提示を引き合いに出すこと自体は、**事実として伝える範囲であれば問題ありません。**

**ただし、金額を並べて比較を求める形にすると、条件だけで動く人と受け取られます。**

## 伝える時期

| 時期 | 適否 |
|---|---|
| 応募の段階 | 希望を伝えるのは可。**交渉ではなく前提の共有** |
| 面接の途中 | **早すぎます。**仕事の話が中心の段階です |
| 提示を受けた後 | **適切な時期** |
| 受諾した後 | **避けてください。**合意した内容の変更になります |

**4つ目を守ってください。**

**受諾した後の再交渉は、信頼に影響します。**入社前の段階で、**条件を確認せずに受諾したことになる**からです。

**だから、受諾の前に確認してください。**

**相談は、1回にまとめてください。**処遇、入社の日、勤務地を別々に持ち出すと、**やり取りが長くなり、双方の負担が増えます。**確認したい点を整理して、**一度に伝える**ほうが進みます。

## 人材会社を経由する場合

**担当者に依頼できます。**

| 依頼できること |
|---|
| 処遇の相談（根拠を添えて伝えてもらう） |
| 入社の日の調整 |
| 勤務地や働き方の確認 |
| 提示の内訳の確認 |

**直接伝えにくい内容ほど、間に入ってもらうほうが進めやすい**です。

**担当者は、応募先の制度の幅を把握していることがあります。**「その会社は等級ごとに幅が決まっているので、この範囲であれば相談できます」といった情報を持っている場合があります。

**自分で全部を交渉する必要はありません。**

:::insight
条件の相談で、**公務員の方が最初につまずくのが「自分の水準が分からない」という点**です。役所では、**給与は条例と規則で定まり、同じ年次であれば大きな差がありません。**そのため、**「自分の経験がどの程度の水準に当たるのか」を測る物差しを持っていない**方が多くいらっしゃいます。対処としては、**同じ職種の求人票を複数見て、提示されている範囲を把握すること**です。求人票には、**想定される範囲が記載されていることが多い**です。**3件から5件見れば、おおよその幅が分かります。**そのうえで、自分の提示がその範囲のどのあたりかを確認する。**根拠のない要望は通りませんが、範囲の中で位置を確認することは、正当な検討**です。加えて、**入社時点の額より、上がり方のほうが長期では影響します。**評価の仕組みを確認するほうが、交渉より実質的なことがあります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 処遇以外で調整できる部分

**処遇が動かない場合でも、他の部分で調整できることがあります。**

| 項目 | 相談の例 |
|---|---|
| 入社の日 | 退職の手続きに合わせて、1〜2か月後ろにする |
| 初期の配属 | 希望する業務に近い部署から始められないか |
| 在宅勤務の運用 | 入社後どの段階から利用できるか |
| 研修の期間 | 未経験の分野について、立ち上がりの支援があるか |
| 役割の見直しの時期 | 評価の最初の機会がいつか |

**5つ目が、実質的な意味を持つことがあります。**

**入社時点の等級が動かなくても、最初の評価の機会が半年後なのか1年後なのかで、その後の見通しが変わります。**

**「入社後、最初に評価いただけるのはいつ頃でしょうか」**と確認しておくと、**処遇の相談をしなくても、見通しが立ちます。**

**条件は、金額だけではありません。**自分が何を優先するかを決めてから、**動かせる部分を探す**ほうが、結果として納得できる形になります。

## 相談しない判断もある

**提示された条件に納得しているなら、相談する必要はありません。**

**「交渉しないと損」という考え方は、実態に合いません。**

**むしろ、次の場合は相談を見送るほうが確実です。**

| 状況 | 理由 |
|---|---|
| 提示が求人票の範囲の上限に近い | **動く余地が小さい** |
| 未経験の職種で、教育を前提とした採用 | 立ち上がりを見てからの評価になる |
| 条件以外が決め手になっている | 相談で関係が変わるほうが損 |

**3つ目について補足します。**仕事の内容や体制が決め手なのであれば、**その条件を確保することを優先**してください。

[経験の言い換えから相談する](../apply.html)こともできます。

**なお、相談した内容と、その回答は記録に残してください。**口頭で「入社後に見直す」と言われた場合、**その時期と条件を確認して書き留めておく**ほうが確実です。入社後に確認したくなったときの材料になります。

## よくある失敗

**1. 金額だけを伝える**

**根拠**を添えてください。

**2. 他社の金額を並べて比較を求める**

**条件だけで動く人**と受け取られます。

**3. 面接の途中で条件を持ち出す**

**時期が早すぎます。**

**4. 受諾した後に再交渉する**

**合意した内容の変更**になります。

**5. 制度そのものの変更を求める**

**個人のために制度は変えられません。**

**6. 相談しないと損だと考える**

**納得しているなら、相談の必要はありません。**

:::insight
ここまで相談の話をしておいて逆のことを言いますが、**条件の相談で結果が大きく動くことは、多くありません。**等級ごとの幅が決まっている会社では、**幅の中での調整**にとどまります。ですから、**相談に期待をかけすぎないでください。**それよりも、**応募の段階で条件の合う求人を選ぶ**ほうが、はるかに効きます。求人票には、想定される範囲が記載されていることが多いです。**その範囲が自分の条件と合わない求人には、最初から応募しない。**この選び方のほうが、後の調整より確実です。面談でも、**希望の条件を先に伺って、その範囲の求人を中心にお示しする**という進め方をしています。**条件は、交渉で作るより、選ぶ段階で揃えるほうが早い。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **労働契約法第8条**は、**労働者及び使用者が、その合意により労働条件を変更することができる**としています
- 相談しやすいのは、**入社の日・勤務地・働き方**。**等級や制度そのものは、変更できません**
- 処遇は、**等級の幅の範囲内**であれば相談の余地があります
- **金額だけを伝えない。**求人票の要件と自分の実務の対応を**根拠として添えて**ください
- 時期は、**提示を受けた後。****受諾した後の再交渉は避けて**ください
- **条件は、交渉で作るより、応募の段階で選ぶほうが確実**です

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 相談したことで、内定が取り消されることはありますか

**相談を理由に取り消されることは、通常ありません。**労働契約法第8条が示すとおり、**条件は合意により変更できるもの**です。相談すること自体が問題になる場面は、多くありません。ただし、**伝え方によっては印象に影響します。**金額を並べて比較を求める、期限を切って要求する、受諾後に蒸し返す。**この3つは避けてください。**また、**相談の結果、条件が変わらなかった場合に、そのまま受諾するかどうかは自分で決められます。**相談したから受諾しなければならない、ということはありません。

### 現在の処遇を正確に伝えるべきですか

**伝えるのが通常**です。多くの場合、**提示の算定に使われます。**そのため、**年間の支給の額を正確に把握しておいてください。**基本の給料、諸手当、賞与。**この3つを合計した年間の額**です。なお、**実際より高く伝えるのは避けてください。**源泉徴収票の提出を求められることがあり、**食い違うと信頼に影響します。**一方、**低く伝える必要もありません。**正確に伝えたうえで、**「現在の水準を基準に考えています」**と述べれば足ります。

### 入社の日の相談は、どのくらい動かせますか

**会社の事情によります。**前任者の退職が迫っている場合や、事業の立ち上げの時期が決まっている場合は、**動かせる幅が小さい**ことがあります。一方、増員の募集であれば、**1〜2か月の調整は応じられることが多い**とされています。相談するときは、**理由を添えてください。**「所属の規程で、退職の申し出から◯か月を要します」という形です。**制度上の理由であれば、理解されます。**なお、**入社の日を遅らせる相談は、早いほど調整しやすい**です。提示を受けた段階で伝えてください。
