結論から書きます。**条件の相談は、内定の提示を受けてから受諾するまでの間なら、してかまいません。**労働契約法第8条は、労働者と使用者は合意によって労働条件を変更できると定めています。相談すること自体は、制度の前提の範囲内です。ただし合意が前提なので、相手が応じなければ変わりません。

| 項目 | 相談のしやすさ |
|---|---|
| 入社日 | しやすい。理由を添えれば1〜2か月の調整は相談の対象になる |
| 働き方（在宅勤務、時差出勤） | 会社の制度の範囲内なら相談できる |
| 勤務地（複数の拠点がある場合） | 相談の余地がある |
| 処遇 | 等級ごとの幅の中なら相談の余地がある |
| 担当業務 | 募集の枠で決まっているので難しいことが多い |
| 等級・役職、賞与や退職金の制度 | 会社の制度そのものなので、個人のためには変わらない |

役所では給与も勤務条件も条例で決まっていて、個人が交渉する場面がありません。慣れていないのは自然なことです。この記事では、相談できる範囲、伝え方、時期を整理します。提示を受ける場の全体は[オファー面談で確認すべきこと](senko-mensetsu-offer.html)にあります。

## まず確かめる——提示された条件は書面で明示される

相談の前に、何が提示されているかを正確に読む必要があります。労働基準法第15条は、使用者が労働契約を結ぶときに、賃金・労働時間その他の労働条件を明示しなければならないと定めています。求人の段階でも、職業安定法第5条の3により、求人企業や職業紹介事業者は労働条件を明示する義務があります。

2024年4月からは、明示する事項に次の3つが加わりました（厚生労働省の求職者向け資料）。

| 追加された明示事項 | 意味 |
|---|---|
| 従事すべき業務の変更の範囲 | 雇入れ直後だけでなく、将来の配置転換も含めた業務の範囲 |
| 就業場所の変更の範囲 | 将来の転勤を含めた勤務地の範囲 |
| 有期契約を更新する場合の基準 | 通算契約期間や更新回数の上限 |

公務員から移る方は、異動が当たり前の環境にいたので、ここを読み飛ばしがちです。**「変更の範囲」が「会社の定める業務」「会社の定める事業所」となっているのか、具体的に限られているのかで、入社後の働き方は大きく変わります。**転勤を避けたい、特定の業務を続けたい、という希望があるなら、相談はここから始めるのが筋です。

## 伝えるときは、根拠を添える

金額だけを伝えると、相手は応じる理由を見つけられません。

| 避けたい言い方 | 根拠を添えた言い方 |
|---|---|
| 「もう少し上げていただけませんか」 | 「求人票の◯◯の要件について、◯年の実務があります。その点を踏まえてご検討いただけますか」 |
| 「他社はもっと高いです」 | 「他社からも提示をいただいており、条件面で迷っています」 |
| 「生活が厳しいので」 | 「現在の年間の支給額を基準に考えており、◯◯程度であれば判断しやすくなります」 |

根拠になるのは、**求人票に挙げられた要件と、自分の実務の対応**です。予算編成、契約事務、議会対応のように、役所の仕事を求人票の言葉に置き換えて示してください。他社の提示があることは、事実として伝える分には問題ありません。金額を並べて比較を迫る形にすると、条件だけで動く人と受け取られます。

確認したいことは**1回にまとめて**伝えてください。処遇、入社日、勤務地を別々に持ち出すと、やり取りが長くなり、双方の負担が増えます。

:::insight
条件の相談で、公務員の方が最初につまずくのは「自分の水準が分からない」という点です。給与表で決まる世界にいたので、自分の経験が市場でどのくらいに当たるかを測る物差しがありません。対処は、同じ職種の求人票を3〜5件並べることです。求人票には賃金の明示が義務付けられているので、幅が書かれています。並べればおおよその相場が見え、自分の提示がその幅のどこにあるかが分かります。根拠のない要望は通りませんが、幅の中で位置を確かめるのは正当な検討です。それと、入社時点の額より、その後の上がり方のほうが長い目では効きます。評価の仕組みを聞くほうが、交渉より実質的なこともあります。
:::

## 伝える時期

| 時期 | 適否 |
|---|---|
| 応募の段階 | 希望を伝えるのは可。交渉ではなく前提の共有 |
| 面接の途中 | 早い。仕事の話が中心の段階 |
| 提示を受けた後、受諾の前 | **相談に適した時期** |
| 受諾した後 | 避ける。合意した内容を変えることになる |

受諾した後の再交渉は、信頼に響きます。条件を確かめずに受諾したことになるからです。迷う点があるなら、受諾の前に聞いてください。回答の期限が短いときは、期限の延長を相談すること自体は不自然ではありません。

## 処遇以外で調整できること

処遇が動かなくても、他の部分で調整できることがあります。

| 項目 | 相談の例 |
|---|---|
| 入社日 | 退職の手続きに合わせて後ろにする |
| 初期の配属 | 希望する業務に近い部署から始められないか |
| 在宅勤務の運用 | 入社後どの段階から使えるか |
| 最初の評価の時期 | 入社後、最初に評価を受けるのはいつか |

最後の項目が、実質的な意味を持つことがあります。入社時の等級が動かなくても、最初の評価が半年後か1年後かで見通しが変わります。「入社後、最初に評価いただけるのはいつ頃でしょうか」と聞いておけば、処遇の相談をしなくても先が見えます。

口頭で「入社後に見直す」と言われたら、その時期と条件を確かめて書き留めてください。入社後に確かめたくなったときの材料になります。

## 人材会社を経由する場合

担当者に相談を任せられます。処遇の相談（根拠を添えて伝えてもらう）、入社日の調整、勤務地や働き方の確認、提示の内訳の確認です。担当者は応募先の等級の幅を把握していることがあり、「この範囲なら相談できる」という目安を持っている場合があります。直接言いにくいことほど、間に入ってもらうほうが進めやすくなります。

自分の経歴がどう言い換えられるかは、一度話しながら整理したほうが早いことが多いです。[相談の申込みはこちら](../apply.html)

## 相談しない判断もある

提示に納得しているなら、相談する必要はありません。「交渉しないと損」という考え方は実態に合いません。次の場合は見送るほうが確実です。

- 提示が求人票の幅の上限に近い（動く余地が小さい）
- 未経験の職種で、育成を前提にした採用（立ち上がりを見てからの評価になる）
- 仕事の内容や体制が決め手になっている（相談で関係が変わるほうが損）

:::insight
ここまで相談の話をしておいて逆のことを言いますが、条件の相談で結果が大きく動くことは多くありません。等級ごとの幅が決まっている会社では、幅の中での調整にとどまります。それよりも、応募の段階で条件の合う求人を選ぶほうがはるかに効きます。求人票の幅が自分の条件と合わない求人には、最初から応募しない。この選び方のほうが、後の調整より確実です。面談でも、希望の条件を先に伺い、その範囲の求人を中心にお示ししています。条件は、交渉で作るより、選ぶ段階でそろえるほうが早い。そして、提示を見たうえで今の職場に残ると決めるのも、まっとうな判断です。
:::

## まとめ

- 労働契約法第8条により、労働条件は合意で変更できます。相談は**提示を受けてから受諾するまで**に
- 動きやすいのは入社日・働き方・勤務地。等級や制度そのものは動きません
- 2024年4月から、**業務と就業場所の「変更の範囲」**の明示が義務になりました。転勤や業務の希望があるなら、ここを先に確かめます
- 金額だけでなく、**求人票の要件と自分の実務の対応**を根拠として添え、1回にまとめて伝えます
- 条件は、交渉より、応募の段階で選ぶほうが確実です

本記事は2026年10月時点の公開情報にもとづきます。

## よくある質問

### 相談したことで、内定が取り消されることはありますか

相談を理由に取り消されることは、通常は考えにくいです。労働契約法第8条のとおり、条件は合意で変えられるものだからです。ただし、伝え方は印象に影響します。金額を並べて比較を迫る、期限を切って要求する、受諾した後に蒸し返す、の3つは避けてください。相談した結果、条件が変わらなくても、受諾するかどうかは自分で決められます。相談したから受諾しなければならない、ということはありません。

### 現在の給与を正確に伝えるべきですか

正確に伝えてください。提示額の算定に使われることが多いからです。給料、諸手当、期末・勤勉手当を合わせた年間の額を、源泉徴収票の支払金額で確かめておきます。実際より高く伝えるのは避けてください。源泉徴収票の提出を求められることがあり、食い違うと信頼に響きます。低く伝える必要もありません。正確に伝えたうえで「現在の水準を基準に考えています」と述べれば足ります。

### 入社日はどのくらい動かせますか

会社の事情によります。前任者の退職が迫っている、事業の立ち上げ時期が決まっている、といった場合は動かせる幅が小さくなります。増員の募集なら、調整に応じてもらえる余地があります。相談するときは理由を添えてください。「年度末の予算・決算の区切りまで引き継ぎがあり、◯月◯日以降の入社を希望します」のように、業務上の理由を具体的に示すと理解されやすくなります。入社日の相談は早いほど調整しやすいので、提示を受けた段階で伝えてください。

### 提示の書面では、どこを見ればよいですか

まず、金額の内訳です。年収の提示が「基本給」「固定残業代」「賞与の見込み」に分かれているか、固定残業代が何時間分か、賞与が業績で変わるかを確かめます。役所の期末・勤勉手当と違い、民間の賞与は業績や評価で上下することがあるので、見込み額をそのまま確定額として受け取らないでください。次に、業務と就業場所の「変更の範囲」、試用期間の有無と長さ、時間外労働の有無です。分からない言葉があれば、受諾の前に質問してかまいません。書面で確かめた内容は、受諾後の食い違いを防ぐ記録にもなります。
