指定管理者として施設運営に関わる会社を調べるとき、公務で利用者へ説明した経験や資料を確認した経験には、工程として示せる接点があります。ただし、施設を所管したことと、自ら受付や集客、運営を担ったことは別です。募集職務ごとに確認します。

本記事は2026年11月時点の公開情報にもとづきます。確認日は2026年11月25日です。制度は地方自治法の本則、採用は会社の個別募集で確認しています。特定の応募者への非公開の評価や、採用されやすさを示すものではありません。

## 指定される団体と、本人の採用を分ける

地方自治法244条の2第3項は、条例の定めるところにより、自治体が指定する法人その他の団体に公の施設の管理を行わせることができるとしています。同条4項は管理の基準や業務の範囲等を条例で定め、5項は指定に期間を設けるとしています。

この制度上の指定と、施設で働く個人の雇用は別です。自治体が設置する施設でも、会社の求人へ応募する場合は、その会社と本人の契約を確認します。公的な施設に勤務するという理由だけで、自治体職員の任用や給与と同じには扱いません。

施設の設置主体、指定を受ける団体、共同事業体の構成員、業務を受託する会社、本人の雇用主を分けます。施設名に自治体の名称が入っていても、正式な雇用主を自治体と補完しないようにします。募集主体と契約形態を確認してください。

同条7項は事業報告書、10項は自治体による報告の求めや調査等を規定しています。ただし、法人の制度上の業務と、本人が最初に担当する工程は別です。自治体に報告する仕事があることから、本人がすべての報告や判断を担うとは決めません。

また、指定期間の終了と、本人の雇用の取扱いを同じ意味にしません。指定の期間だけで雇用継続や終了を断定せず、契約の期間、更新、配置等は本人への条件で確認します。指定が更新されるとも、本人の希望する施設に必ず残れるとも補完しないようにします。

[行政に接点のある掲載求人を調べる](../?gov=1)際も、制度上の関係と、本人の職務・契約条件を別に比較できます。

## 受付事務の募集から、説明と確認の接点を読む

サントリーパブリシティサービスの枚方市総合文化芸術センターの募集は、施設予約や貸出、チケット販売、利用者案内、システム入力、資料作成、鍵や備品の貸出等を挙げています。受付と事務の両面がある職務として読みます。

公務の窓口で利用目的を確認し、手続を説明し、必要な項目を記録した経験は、その工程として整理できます。誰へ何を説明し、不明点をどう確認し、他者へ引き継いだかを示せます。住民や利用者の個人情報を開示する必要はありません。

一方、会社の予約システム、チケット販売、使用料の授受等を経験したかは別です。行政の窓口経験を、その施設の受付全業務へ広げません。本人が行った案内と、未経験のシステムや金銭管理を分けてください。

同募集の資格欄には、接客・サービス業の経験、企業や施設等での事務経験、Word・Excelの資料作成の初級程度が列挙されています。ページに未経験歓迎の説明もありますが、資格欄を消して経験条件がすべて不要と決めないようにします。

本人の公務での対応がどの項目の対象になるか、必要な経験の組合せが不明な場合は、担当工程を示して窓口に確認できます。独自に一つの経験だけでよいと縮めず、列挙された項目をそれぞれ照合してください。

## 広報企画の必須と、行政調整の歓迎を分ける

同社の港区立みなと芸術センターの広報・マーケティング募集は、施設の認知、来館促進、会員獲得等に向けた業務を示しています。確認時点では2027年11月開館予定で、開館前から仕組みを構築する説明です。すでに開館している施設の実態として書きません。

必須は、広報・マーケティング・販売促進・営業企画のいずれかの実務、集客や顧客・会員獲得、ファン育成を目的とした施策の企画・実行、社内外と連携してプロジェクトを進めた経験という構成です。最初の選択肢だけを取り出して、残りの必須をなくしません。

行政や複数企業との調整経験は歓迎項目にあります。公務での行政調整があっても、それだけで上記の企画・実行等を満たすとは扱いません。必須と歓迎を別にし、本人がどの作業を実施したかで確認します。

公務の広報担当にいた場合も、制度のお知らせ、媒体の入稿確認、来場者獲得を目的とした施策の企画、実行、効果の検証は異なる工程です。部署名からすべてを経験済みとせず、対象、目的、本人の行動と他者の権限を分けてください。

同募集は必須要件に関する経験と、その経験を同社でどう活かしたいかを応募フォームや書類へ記載するよう案内しています。本人の事実と将来の希望をつなぎ、未経験を経験済みに変えない形で説明を準備できます。

:::insight
行政との調整が歓迎される募集でも、それだけで職務の必須実務がそろうとは限りません。受付事務と広報企画では、求める工程も異なります。本人が行った説明や資料確認を具体的に示しながら、集客施策の企画・実行や現場運営を実施したかは別に確認する方法を勧めます。施設の所管経験を、運営全体の経験へ広げる必要はありません。公開要件にある必須と歓迎を分け、本人の行動、他者の判断、未経験を対応させます。対象になるか不明な経験や条件の組合せは、正式な職名を添えた質問に残せます。公務の在籍先や部署名だけで一致を作らないことが出発点です。
:::

## 所管した立場と、現場で担った立場を明確にする

公務で施設を担当していた場合、仕様や報告の確認、関係者への照会、予算事務、利用者への説明等を分けます。実際の受付、販売、集客、設備操作、現場の人員配置等を他者が行っていたなら、その役割を本人の実務に入れないようにします。

本人が質問をまとめたことと、運営方針を決めたことも別です。決裁は上司、専門判断は担当部署、現場運営は会社等であれば、その分担を残します。組織全体で行った結果を、一人の判断で実現した実績へ広げないでください。

改善についても、課題を見つけた段階、提案した段階、採用された段階、実施や効果を確認した段階を分けます。本人が効果を測っていなければ、売上や来場者の増加率等を加えません。確認できた工程を具体的に示す方法を使えます。

経験の期間は、在籍期間と対象の作業を実施した期間を区別します。複数業務を兼ねていたなら分担を説明し、施設担当だった全期間を専門的なマーケティングや運営に従事した年数として記入しないようにします。

## 独立した架空の記入例で、経験と質問を分ける

以下は経験整理のための独立した架空例です。実在の応募者、面接での回答、採用実績ではありません。本人が使う場合は事実に置き換え、未実施の行動や持っていない経験は削除してください。

| 項目 | 架空の記入内容 |
|---|---|
| 本人の立場 | 自治体で施設に関わる報告の確認と利用者への制度説明 |
| 実施した工程 | 報告の対象月と指標の定義を確認し、質問を一覧化 |
| 説明の経験 | 必要な手続と確認先を案内した |
| 他者の権限 | 方針決裁は上司、現場運営と専門判断は運営者・専門担当 |
| 未経験 | チケット販売、施設予約システム、集客施策の企画・実行 |
| PCの経験 | 本人が行った表の入力・集計と説明資料作成のみ記入 |
| 要件の確認 | 受付の経験対象を確認。広報の必須を満たすとは記入しない |
| 未確認 | 初期担当、勤務シフト、本人の契約と変更範囲 |
| 次の行動 | 正式職名を添え、経験の対象と担当範囲を質問する |
| 現職の比較 | 現在の確認・説明を深める進路も残す |

この例は、施設に関わった公務経験を消さず、実施していない業務も加えていません。未経験の欄を残すことで、必要な操作や初期の分担を具体的な質問へ変えられます。会社から回答があったという架空のやり取りを付け足す必要はありません。

本人に接客や店舗運営等の前職がある場合は、公務の在籍とは別に、雇用主、担当、期間、作業を記録できます。学習や見学の経験と実務も分け、応募要件への適合は公式募集と本人の事実で確認してください。

[担当経験と応募職務を整理する](../apply.html)場合も、内部資料を渡さず本人の言葉で工程を説明できます。ご利用は無料です（紹介手数料は採用企業の負担）。経験や希望によっては、面談・求人紹介を提供できない場合があります。

## 会社の雇用区分と、施設の勤務条件を確認する

枚方の確認した募集はフルタイム契約社員のパートナー社員と明記しています。週5日で土日祝を含む交代シフトとし、すべてのシフトに勤務可能なことを示しています。同ページにある短時間の別求人と日数・時間を混ぜないようにします。

正社員登用制度や実績の説明もありますが、本人が必ず登用される意味にはしません。契約の期間、更新の対象や条件、初期の担当等を個別に確認します。募集がフルタイムであることと、期間の定めのない雇用であることも別です。

港区の広報募集は、開館前と開館後の勤務例を分け、土日祝を含む週5日としています。勤務する時期と施設の開館予定を確認し、現在の作業場所と将来の場所を同じと決めません。雇用区分等の未記載事項は、別の受付募集から補完せず質問に残します。

個別求人にある請負契約の表示と、本人の雇用契約の区分も混同しません。企業と施設の業務関係、会社と本人の契約を分けて確認します。指定管理制度があることだけで、本人を自治体の職員や個人事業主と決めないようにします。

希望休の申請が可能であることと、すべて希望どおりの勤務になることも別です。本人の必須の生活条件を先に整理し、通勤、時間帯、勤務日、役割や変更範囲等を質問できます。希望を伝えた段階を正式な提示と同じにしません。

質問や回答を記録する際は、正式職名と確認日を残します。一般的な可能性の説明なのか、本人の予定職務への回答なのかを区別してください。募集が更新された場合も、以前の条件や別施設の説明を移さず、対象の項目を読み直せます。応募書類を作成した段階と、送信や面接案内を受領した段階も別に記録できます。

## 情報を守り、現職継続も同じ工程で比べる

住民や利用者の個人情報、非公開の契約、審査、調達、施設の保安に関わる内部資料等を持ち出しません。名前だけ消せば使えるとも判断せず、私用AIへの入力も避けます。公開情報と一般化した担当工程で準備できます。

行政上の便宜や内部人脈を、事業獲得や施設運営の強みとして提供する約束もしません。所管の立場で得た連絡先や内部事情を私的に使うことと、本人の確認・説明の経験を話すことは別です。

現職で施設や利用者への説明を深めることも比較できます。運営会社へ移りたい場合は、自ら担当したいのが受付、企画、集客等のどの工程かを確かめます。公的施設に関わりたいという希望だけで、退職を先に決める必要はありません。

[掲載中の求人を比較する](../)際も、現職を含め、本人が担いたい工程と必須の勤務条件を同じ表へ並べられます。

:::insight
公的施設に関わる仕事でも、行政側の確認と会社側の運営では本人の工程が変わります。どちらを希望するかを先に分けることを勧めます。現職で説明や根拠確認を続けられるなら、残る判断も同じように比較できます。現場の受付や集客へ移りたい場合は、必要な操作や実務、初期の分担、勤務シフトを確認できます。経験を低く見る必要はなく、行っていない運営を追加する必要もありません。公開要件と本人の事実を照合し、応募や登録の開始だけで退職を決めず、本人への役割と条件の説明がそろった段階で考えられます。不明点を保留にすることも判断のための方法です。
:::

## まとめとよくある質問

指定管理制度と会社の採用は分けて確認します。所管と現場の実施、必須と歓迎、本人の経験と未経験を区別し、職務別に照合してください。

### 公務で施設を所管していれば運営経験になりますか

同じ経験とは扱いません。本人が行った報告確認や説明等を示し、受付や販売、集客等を実施していなければ未経験として分けます。

### 行政との調整経験だけで広報職の条件を満たしますか

紹介した港区の募集では行政調整は歓迎です。広報等の実務、集客等の企画・実行、内外と連携した推進の必須も別に照合します。

### 指定期間があれば本人の雇用期間も同じですか

制度の指定と雇用は別です。本人の契約期間、更新、配置等は会社への確認事項にし、指定だけから継続や終了を断定しません。
