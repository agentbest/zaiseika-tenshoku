財政課の予算編成の時期の時間外勤務は、転職を考える理由として最も多く聞くものの1つです。「月100時間を超えた」「年度末は終電が続いた」——面談で伺う数字は、民間の上限規制の水準を超えていることがあります。

地方公務員の時間外勤務には、**民間と違う仕組み**があります。**36協定なしで時間外勤務を命じられる**代わりに、**条例・規則で上限が定められ**、国の例では**原則として月45時間・年360時間、他律的な業務の比重が高い部署では月100時間未満・年720時間**です。財政課がどちらに当たるかで、上限が変わります。

この記事では、**地方公務員の時間外勤務の法律上の仕組み、上限の水準、財政課の位置づけ、民間との違い、転職の判断への使い方**を整理します。**上限の具体的な水準は自治体の条例・規則による**ので、自分の自治体の規定と、自分の部署の指定は人事の担当課で確かめてください。

## 仕組み——36協定がなくても命じられる

| 規定 | 内容 |
|---|---|
| **労働基準法第36条** | 使用者は、労使協定（36協定）を締結し届け出た場合に、その協定の範囲で時間外労働をさせることができる。限度時間は**月45時間・年360時間**（第4項）。特別条項でも**年720時間、月100時間未満、2〜6か月平均80時間**（第5項・第6項） |
| **労働基準法第33条第3項** | **公務のために臨時の必要がある場合**、官公署の事業（別表第1に掲げる事業を除く）に従事する国家公務員及び地方公務員については、第36条によらずに時間外労働をさせることができる |
| **地方公務員法第24条第5項** | 職員の給与、勤務時間その他の勤務条件は**条例で定める** |

**財政課などの非現業の部署は、労働基準法第33条第3項により、36協定なしで時間外勤務を命じられます。**第36条の上限は直接には適用されず、その代わりに、**自治体が条例・規則で上限を定める**仕組みです。多くの自治体が、国の人事院規則に準じた上限を条例・規則で定めています。

## 上限の水準——国の例（人事院規則一五―一四第16条の2の2）

| 区分 | 上限 |
|---|---|
| **原則**（他律的部署以外） | **1か月45時間、1年360時間** |
| **他律的業務の比重が高い部署**（各省各庁の長が指定） | **1か月100時間未満、1年720時間、2〜6か月の平均80時間、1か月45時間を超えるのは1年に6か月まで** |
| **特例業務**（大規模災害への対処など） | 上限を超えることができるが、6か月以内に要因の整理・分析・検証を行う |

**「他律的業務」**は、業務量、業務の実施時期その他の業務の遂行に関する事項を自ら決定することが困難な業務と定義されています。**財政課の予算編成は、議会の日程と各課の要求に左右されるので、他律的部署に指定されていることが多い**です。指定されていれば上限は月100時間未満・年720時間で、民間の特別条項の上限と同じ水準です。

## 財政課の実態と、上限の関係

| 時期 | 典型的な状況 | 上限との関係 |
|---|---|---|
| **予算編成（秋〜年明け）** | 各課の要求の査定、財政当局の内示、復活要求 | 他律的部署の上限（月100時間未満）に近づくことがある。**月45時間を超えるのは年6か月まで**の制限に注意 |
| **議会（2〜3月）** | 予算の説明、質問への対応 | 同上 |
| **決算・統計（5〜9月）** | 決算統計、健全化判断比率 | 原則の上限の範囲に収まることが多い |
| **年間** | ── | **年720時間**が他律的部署の上限。予算編成と議会で集中すると近づく |

**上限は「命じてよい時間の上限」で、「働かせてよい時間」ではありません。**上限を超える時間外勤務は、特例業務に当たらない限り、命じられないはずのものです。**上限を超えている実態があるなら、それは制度の運用の問題**で、転職の理由として説明できる客観的な材料になります。

## 民間との違い

| 項目 | 地方公務員（非現業） | 民間 |
|---|---|---|
| **根拠** | 労働基準法第33条第3項＋条例・規則 | 労働基準法第36条＋36協定 |
| **協定** | 不要 | **36協定が必要**（労働者の過半数代表との書面の協定、届出） |
| **上限** | 条例・規則（国の例で月45時間・年360時間、他律的部署は月100時間未満・年720時間） | 法律（月45時間・年360時間、特別条項で年720時間・月100時間未満・複数月平均80時間） |
| **上限を超えた場合** | 制度の運用の問題（罰則はない） | **罰則の対象**（第36条第6項違反） |
| **時間外の手当** | 条例（時間外勤務手当） | 労働基準法第37条（割増賃金） |

**上限の水準は、他律的部署なら民間の特別条項とほぼ同じ**です。違いは、民間では上限違反に罰則があるのに対し、公務員では条例・規則の運用の問題である点と、36協定という労使の合意の手続きがない点です。**転職先の時間外労働は、36協定の内容で上限が決まる**ので、内定の段階で36協定の特別条項の有無と上限を確かめると、転職先の働き方が見えます。

## 転職の判断への使い方

| 点 | 内容 |
|---|---|
| **自分の時間外勤務の実態を数字で持つ** | 月ごとの時間外勤務の時間を、給与明細か勤務時間の記録から書き出す。**上限と比べる** |
| **上限を超えているか** | 超えていれば、制度の運用の問題。転職の理由として客観的に説明できる |
| **上限の範囲内だが多い** | 他律的部署の上限（月100時間未満）は、民間の特別条項の上限と同じ水準。**転職しても同じ水準の企業はある** |
| **転職先の36協定** | 内定の段階で、36協定の特別条項の有無、上限、実績を聞く。**求人票の「残業月20時間程度」は平均で、繁忙期の実態は別** |
| **時間外の手当** | 公務員は時間外勤務手当が条例で支給される。転職先の割増賃金の支給の実態（固定残業代の有無、みなし労働時間制の有無）を確かめる |

**「残業が多いから転職」は、転職先の残業の実態を確かめなければ、同じ状況に移るだけ**です。自分の数字と、転職先の36協定と実績を並べてください。

:::insight
面談で伺うと、**財政課の予算編成の時期の時間外勤務が「月100時間を超えた」という方**がいます。他律的部署の上限は月100時間未満なので、超えていれば上限の違反で、制度の運用の問題です。この事実は、転職の理由として客観的に説明でき、面接でも「制度の上限を超える状態が続いた」と事実で話せます。逆に、**「残業が多い」という印象だけで転職して、転職先の繁忙期の残業が前職と同じ水準だった**という方もいます。求人票の「月20時間程度」は年間の平均で、繁忙期は別でした。ここで1つ提案があります。**自分の月ごとの時間外勤務の時間を、直近2年分、紙に書き出してください。**上限と比べれば、制度の運用の問題か、制度の範囲内の忙しさかが分かります。**そのうえで、転職先の36協定の特別条項と繁忙期の実績を聞く。**数字と数字を並べれば、「残業が多いから」が、根拠のある判断に変わります。
:::

## 転職するとどうなるか

転職を考えている方にとって、時間外勤務の上限で効いてくる点は3つです。

**1. 自分の実態を数字で持ち、上限と比べる**

**上限を超えていれば制度の運用の問題で、転職の理由として客観的に説明できます。**

**2. 転職先の36協定を確かめる**

**特別条項の有無、上限、繁忙期の実績。**求人票の平均ではなく、繁忙期の数字を聞いてください。

**3. 時間外の手当の支給の実態を確かめる**

**固定残業代、みなし労働時間制の有無**で、同じ時間でも手取りが変わります。

## 手続きと期限

| 順序 | すること | 時期 |
|---|---|---|
| 転職を考えたら | 自治体の条例・規則の上限と、自分の部署が他律的部署に指定されているかを確かめる | 最初に |
| 同時に | 自分の月ごとの時間外勤務の時間を、直近2年分書き出す | 最初に |
| 上限を超えている場合 | 所属または人事の担当課に、上限の運用について確かめる（転職とは別に、改善を求める道もある） | 早めに |
| 内定の段階 | 転職先の36協定の特別条項の有無と上限、繁忙期の実績、時間外の手当の支給の実態を聞く | 内定後 |
| 入社後 | 労働時間の記録を自分でも持つ | 継続 |

## 誤解されやすい点

**「公務員には残業の上限がない」と思い込む**

**条例・規則で上限が定められています。**国の例で月45時間・年360時間、他律的部署は月100時間未満・年720時間です。

**「民間に行けば残業は必ず減る」と思い込む**

**民間の特別条項の上限は、他律的部署の上限とほぼ同じ水準**です。転職先の36協定と実績で決まります。

**「上限を超えても仕方がない」と思い込む**

**上限は命じてよい時間の上限で、超える状態は制度の運用の問題**です。

**「求人票の残業時間は繁忙期も同じ」と思い込む**

**平均であることが多く、繁忙期の実態は別**です。内定の段階で聞いてください。

:::insight
ここまで上限の話を書いておいて逆のことを言いますが、**時間外勤務の多さは、それだけでは転職の理由として弱いことがあります。**転職先の繁忙期が同じ水準なら、状況は変わりません。それでも1本の記事にしたのは、**「残業が多い」という印象を、上限と比べた数字に変えれば、転職の理由が客観的になり、転職先の選び方も変わる**からです。数字を持てば、転職するかどうかも、どこに行くかも、根拠を持って決められます。そのうえで、**自分の経験に値を付けてくれる業界の見込みと、同じ紙に並べてください。**片方だけでは比較になりません。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 財政課などの非現業の地方公務員は、**労働基準法第33条第3項により、36協定なしで時間外勤務を命じられます。**その代わりに、**条例・規則で上限**が定められています（地方公務員法第24条第5項）
- 国の例（人事院規則一五―一四第16条の2の2）では、**原則として月45時間・年360時間、他律的業務の比重が高い部署は月100時間未満・年720時間・2〜6か月平均80時間・月45時間超は年6か月まで**です。多くの自治体が国の例に準じています
- **財政課は他律的部署に指定されていることが多く**、上限は民間の特別条項（労働基準法第36条第5項・第6項）とほぼ同じ水準です。違いは、民間では上限違反に罰則があること、36協定の手続きがあることです
- **上限は命じてよい時間の上限**で、超える状態は制度の運用の問題です。転職の理由として客観的に説明できます
- **自分の月ごとの時間外勤務を直近2年分書き出し、上限と比べ、転職先の36協定の特別条項と繁忙期の実績と並べる**と、「残業が多い」が根拠のある判断に変わります
- 転職先の**時間外の手当の支給の実態（固定残業代、みなし労働時間制）**も確かめてください

## よくある質問

### 財政課は「他律的部署」に当たりますか

**自治体の指定によりますが、予算編成を担う財政課は他律的部署に指定されていることが多いです。**人事院規則一五―一四第16条の2の2は、他律的業務を「業務量、業務の実施時期その他の業務の遂行に関する事項を自ら決定することが困難な業務」と定義し、その比重が高い部署を各省各庁の長が指定すると定めています。自治体の規則も同様の仕組みで、任命権者が部署を指定します。財政課の予算編成は、議会の日程、各課の要求の時期と内容、国の予算や地方財政対策の動向に左右され、自ら業務量と時期を決めることが困難なので、指定の要件を満たしやすい部署です。指定されていれば上限は月100時間未満・年720時間・2〜6か月平均80時間・月45時間超は年6か月までで、指定されていなければ月45時間・年360時間です。**自分の部署がどちらに指定されているかは、人事の担当課に確かめてください。**指定されていない部署で月45時間を超える時間外勤務が続いているなら、上限の運用の問題として所属に確かめる根拠になります。

### 上限を超える時間外勤務が続いています。転職の面接で理由として話してよいですか

**事実として話せます。制度の上限と自分の数字を並べて、客観的に説明する形が適切です。**「残業が多かった」という印象ではなく、「自治体の規則で他律的部署の上限は月100時間未満・年720時間と定められているが、予算編成の時期に上限を超える月が続いた」のように、制度と事実で話せば、面接官は理解しやすく、前職を貶める発言にもなりません（信用失墜行為の禁止との関係は[信用失墜行為とは何か](seido-fukumu-shinyo.html)に書いています）。注意するのは、時間外勤務の多さだけを転職の理由にすると、「転職先でも繁忙期があれば辞めるのでは」と受け取られることです。**「上限を超える状態が続き、制度の運用の改善を求めたが変わらなかったので、自分の経験を別の形で生かせる場を探した」**のように、事実と、自分の判断と、転職先で何をしたいかをつなげると、理由として筋が通ります。転職先の繁忙期の実態も内定の段階で確かめ、同じ状況に移らないようにしてください。

### 転職先の残業の実態は、どう確かめればよいですか

**36協定の特別条項の有無と上限、繁忙期の月の実績、時間外の手当の支給の実態の3つを、内定の段階で聞いてください。**求人票の「残業月20時間程度」は年間の平均であることが多く、繁忙期の実態は別です。36協定は事業場ごとに締結され、特別条項があれば年720時間・月100時間未満・複数月平均80時間まで時間外労働が可能なので、特別条項の有無で上限が大きく変わります。「36協定に特別条項はありますか。繁忙期の月の時間外労働の実績はどのくらいですか」と聞くのは、労働条件の確認として自然で、悪い印象にはなりません。時間外の手当は、労働基準法第37条により割増賃金が支給されますが、固定残業代（一定時間分を給与に含める）やみなし労働時間制（裁量労働制、事業場外みなし）を採っている企業では、同じ時間でも手取りが変わり、固定残業代を超えた分の支給の実態も確かめる必要があります。公務員の時間外勤務手当は条例で時間に応じて支給されるので、転職先の仕組みが違えば、手取りの見込みも変わります。転職の支援を受けている場合は、担当者がこれらを企業に確かめてくれます。
