危機管理・防災課からの転職では、**この経歴が求人票の言葉と結びついていない**ことが、いちばんの障害になります。

「防災」という職種名の求人は、民間にほとんどありません。

ところが、**同じ仕事は確実にあります。企業の危機管理・事業継続の部門**です。

そして、**この領域も、経験者の母数が小さい**という事情があります。計画を作り、訓練を回し、実際の事象で本部を動かした経験を持つ人は、民間側に多くありません。

この記事では、その対応を整理します。訳語の対応表、中核スキルの工程分解、そして**企業の危機管理部門とどこが同じでどこが違うか**まで扱います。

## 「保護する責務を有する」と書かれています

まず、この部署の立ち位置を条文で確認します。**民間に説明するときの、いちばん強い材料**です。

災害対策基本法第5条第1項は、こう定めています。

**市町村は、基本理念にのつとり、基礎的な地方公共団体として、当該市町村の地域並びに当該市町村の住民の生命、身体及び財産を災害から保護するため、関係機関及び他の地方公共団体の協力を得て、当該市町村の地域に係る防災に関する計画を作成し、及び法令に基づきこれを実施する責務を有する。**

そして第2項では、**市町村長は、前項の責務を遂行するため、消防機関、水防団その他の組織の整備並びに当該市町村の区域内の公共的団体その他の防災に関する組織及び自主防災組織の充実を図る**ことが定められています。

読み解くと、3つのことが分かります。

**1. 計画を作ることと、実施することの両方が責務**です。作って終わりではありません。

**2. 「関係機関及び他の地方公共団体の協力を得て」**行います。**自分の組織だけでは完結しません。**

**3. 消防、水防団、公共的団体、自主防災組織**という、**指揮命令が及ばない相手の体制まで整える**ことが含まれています。

**3つ目が、この経歴でいちばん特殊な部分です。**

**命令できない相手を動かす仕組みを作ってきた。**これは、企業の危機管理でも同じ課題です。**グループ会社、委託先、取引先、テナント。**危機のときに動いてもらう必要があるが、直接の指揮権はない。**まったく同じ構造です。**

## 民間での訳語

履歴書や職務経歴書では、**自治体の中でしか通じない言葉を、募集要項に出てくる言葉に置き換えます。**

| 自治体での呼び方 | 民間での呼ばれ方 |
|---|---|
| 地域防災計画の策定・修正 | 事業継続計画の策定、危機管理規程の整備 |
| 業務継続計画（行政の継続） | 事業継続計画（BCP） |
| ハザードマップの作成 | リスクの特定と可視化、被害想定 |
| 防災訓練の企画・運営 | 訓練・演習の設計、机上演習の実施 |
| 災害対策本部の運営 | 緊急時対応体制の運営、対策本部の設営 |
| 防災行政無線・情報伝達 | 緊急連絡体制、安否確認の仕組み |
| 備蓄物資の管理 | 資材・在庫の管理、調達計画 |
| 民間事業者との応援協定 | 相互支援協定、調達先の複線化 |
| 自主防災組織の育成 | 関係先の体制整備、外部組織との連携 |
| 受援計画の策定 | 外部支援の受け入れ設計 |
| 避難所の指定と運営 | 拠点の開設・運営設計 |
| 対応の検証と計画の修正 | 事後検証、計画の見直し |

**「防災」を「危機管理」「事業継続」に置き換える**のが基本です。それだけで、対応する求人が見えてきます。

## 中核スキルを5つの工程に分ける

この部署の仕事は、**5つの工程**に分解できます。**企業の危機管理部門の工程と、ほぼ同じ形**です。

**① 想定する**

どの災害が、どの規模で起きうるか。**被害の見積もりを作ります。**

浸水の深さ、揺れの大きさ、想定される避難者数、断水・停電の期間。**ここが甘いと、その後の計画がすべて甘くなります。**

**② 計画に落とす**

**誰が、何を、どの順番でやるか**を決めます。

最も難しいのは、**「誰が」の部分**です。災害時には、担当者が出勤できない場合があります。**役職ではなく、その場にいる人が動ける形にする**必要があります。

**③ 備える**

物資の備蓄、協定の締結、資機材の整備、訓練の実施。

**協定がいちばん手間がかかります。**相手方との交渉、内容の調整、更新の管理。**そして、締結しただけでは動きません。**訓練で一度動かしてみないと、実際には機能しません。

**④ 動かす**

実際に事象が起きたとき、**対策本部を立て、情報を集め、判断を出し、記録を残します。**

**このとき、情報は必ず不足しています。**全部そろってから決めることはできません。**分かっている範囲で判断し、次に何を確認するかを決める**のが仕事になります。

**⑤ 直す**

対応が終わった後、**何ができて何ができなかったかを検証し、計画を修正します。**

**この工程を回している組織は、民間にも多くありません。**訓練はするが、検証して計画に戻すところまでやっている会社は限られます。

## 企業の危機管理部門と、どこが同じでどこが違うか

**同じところ**

**1. 起きていないことに資源を割く仕事**

**何も起きなければ、かけた費用は無駄に見えます。**この説明を毎年しなければならない点は、企業でもまったく同じです。

**2. 訓練しないと、計画は動かない**

**紙に書いてあるだけの計画は、実際には機能しません。**訓練で一度通してみて、初めて穴が見えます。**この感覚を持っている人は、民間でも多くありません。**

**3. 指揮権のない相手を動かす必要がある**

自治体では自主防災組織や協定事業者、企業ではグループ会社や委託先。**命令ではなく、合意と訓練で動いてもらう**という点が共通です。

**違うところ**

**1. 対象を選べない**

企業は、守る対象を事業の重要度で絞れます。**自治体は、住民全体が対象**で、絞ることができません。

**この違いは、優先順位のつけ方に出ます。**自治体では、**「誰を先に助けるか」ではなく「どの機能を先に戻すか」**で優先順位をつけてきました。**この考え方は、企業の事業継続でもそのまま使えます。**

**2. 判断が権限の行使になる**

企業の危機対応は、**社内の判断**です。自治体では、避難に関する指示など、**住民に対する権限の行使**が含まれます。

**判断の重さが違う**ぶん、**根拠と記録の残し方が厳密**になります。**この厳密さは、企業でも歓迎されます。**

**3. 訓練の相手が組織の外にいる**

企業の訓練は、基本的に社内で完結します。**自治体では、住民、自主防災組織、消防団、協定事業者、他の自治体**が相手です。

**組織の外の人を巻き込んで訓練を設計した経験**は、**グループ全体や取引先を含む訓練を設計する場面**で、そのまま活きます。

:::insight
危機管理・防災課の方が職務経歴書で損をしやすいのは、**⑤の「検証して計画に戻す」工程を書かないこと**です。書類に並ぶのは「地域防災計画の改定」「防災訓練の実施」という工程名で、**実際の事象や訓練の後に、何ができなかったかを洗い出して計画を直した**という部分が消えています。ここは企業でも弱い領域です。訓練は毎年やっているが、**その結果を計画に反映している会社は多くありません。**書き方としては、**「◯年の◯◯への対応後、初動の連絡経路と本部の設営手順について課題を整理し、地域防災計画および職員行動マニュアルの該当箇所を改定した」**のように、**事象 → 検証 → 改定という順で書いてください。**「訓練を実施した」だけでは、回数の話にしかなりません。**回した実績ではなく、回して直した実績**を書くのが、この経歴でいちばん効く一手です。
:::

## 評価が高くなりやすい4つの方向

**1. 企業の危機管理・事業継続（BCP）部門**

**いちばん直線的につながる方向**です。計画、訓練、本部の運営、検証。**工程が同じ**なので、説明がそのまま通ります。

**特に評価されるのが、実際に本部を動かした経験**です。訓練しか経験のない人と、**実際の事象で本部に入った人**では、話せることの厚みが違います。

**2. 総務・施設のリスク管理**

事業所の安全管理、防火管理、安否確認の仕組み、備蓄の管理。**企業の総務部門が担っている部分**です。

**防火管理者や防災士の資格**があると、この方向は通りやすくなります。

**3. 防災関連のメーカー・コンサルティング会社**

防災用品、無線・情報システム、避難所の資機材、ハザードマップの作成支援、計画策定の支援。

**発注する側にいた経験**に加えて、**自治体が何を必要としているかを知っていること**が、そのまま提案の材料になります。

**4. インフラ・ライフライン企業の保安部門**

電力、ガス、水道、鉄道、通信。**これらの企業は、災害時に自治体と連携する側**です。

**自治体側の動き方を知っている人**は、連携の設計で重宝されます。**協定を結んだ相手の事情を、内側から知っている**ことになります。

[公務員の経験が活きる求人を見てみる](../?gov=1)

:::insight
方向を決めるときに、**残る判断のほうが妥当だと感じる場面**もあります。危機管理・防災課は、**実際の事象を経験しているかどうかで、経歴の厚みが大きく変わる**部署です。訓練の設計と、実際に本部を立てて対応した経験は、**話せる内容の密度がまったく違います。**そして、これは**在籍中に起きるかどうかで決まる**ため、自分では選べません。まだ一度も本部運営を経験していない段階なら、**書けるのは計画と訓練までになります。**ただし、**起きるのを待つというのは、性質上おかしな話**でもあります。判断の目安としては、**地域防災計画の改定を一度通し、訓練を一巡設計しているなら、本部の経験がなくても書けます。**そのうえで、**受援計画や協定の締結に関わる予定があるなら、それを終えてからのほうが材料は増えます。**在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## つまずきやすい点

**1. 「防災」という言葉のまま書く**

**「危機管理」「事業継続」に置き換えてください。**求人票に出てくるのはこちらの語です。

**2. 検証して計画に戻した実績を書かない**

**回した実績ではなく、回して直した実績**を書いてください。

**3. 指揮権のない相手を動かした経験を落とす**

**自主防災組織、協定事業者、他の自治体。**企業のグループ会社・委託先と同じ構造です。

**4. 数字を持っていない**

想定した被害の規模、避難所の指定数、備蓄品目数、協定の締結数、訓練の参加者数、対象人口。**公表されている計画から取れます。**

**5. 実際の対応を細かく話しすぎる**

**個別の被災状況や、対応に当たった個人が分かる話は書けません。**手順と検証の構造で書いてください。

どの経験に値が付くかは、募集の出方で変わります。[どの経験に値が付くのかから相談できます](../apply.html)。

## まとめ

- 災害対策基本法第5条は、市町村に**計画を作成し、及び実施する責務**を課し、**消防機関・水防団・自主防災組織の充実**まで求めています
- **指揮命令が及ばない相手の体制を整えてきた**ことが、この経歴でいちばん特殊な部分です。企業のグループ会社・委託先と同じ構造です
- 民間での訳語は、**事業継続計画／危機管理規程／訓練・演習の設計／緊急時対応体制／相互支援協定**が中心になります
- 中核スキルは**①想定する ②計画に落とす ③備える ④動かす ⑤直す**の5工程です
- 企業の危機管理と**同じ**なのは、起きていないことに資源を割くこと・訓練しないと計画は動かないこと・指揮権のない相手を動かすこと
- **違う**のは、対象を選べないこと・判断が権限の行使になること・訓練の相手が組織の外にいることです

## よくある質問

### 消防や技術の専門知識がなくても、この経歴は使えますか

**使えます。**危機管理・防災課の事務職は、**消火や救助そのものを担うわけではありません。**計画を作り、体制を整え、訓練を設計し、本部で情報を回すのが役割です。企業の危機管理部門も同じで、**専門技術より、計画と体制と訓練を回せるかどうか**が問われます。面接では、**「技術的な対応は消防や専門機関が担い、自分は計画と体制と情報の整理を担当していた」**と正確に言ってください。

### 防災士の資格は取っておいたほうがよいですか

**方向によっては効きます。**企業の総務・施設のリスク管理や、防災関連のメーカー・コンサルに応募する場合、**共通の語彙を持っていることの証明**になります。ただし、**危機管理・防災課での実務経験があるなら、資格が入口の条件になることはほとんどありません。**優先するなら、**実際に何を作り、何を回したか**を書けるようにするほうが先です。

### 国民保護計画や有事対応の経験は、書いてよいですか

**計画の存在と、担当した範囲までは書けます。**国民保護計画は公表されているものが多く、**策定や改定に関わったこと自体は書けます。**ただし、**具体的な想定の内容、施設の脆弱な部分、対応の詳細**は書けません。書くなら、**「国民保護計画の改定に関わり、関係機関との連絡体制の部分を担当した」**という、**担当範囲を示すにとどめてください。**
