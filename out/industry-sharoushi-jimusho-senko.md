社労士事務所・労務コンサルの選考は、法人名だけで共通の流れを想定せず、応募する拠点と職種の募集要項から確認します。公務員から応募する場合も、仕事の対象、本人の担当工程、PC操作、未経験の専門実務を整理することが準備になります。「面接で見られる観点」は公開された仕事内容と条件から考える準備事項であり、非公開の採点基準や質問を断定するものではありません。

本記事は2026年11月時点の公開情報にもとづきます。確認日は2026年11月25日です。SATO社会保険労務士法人の東京の社会保険料計算事務スタッフ求人を例に、公開された選考と本人が行う準備を分けます。最新の募集継続、本人の選考日程、提出方法は応募先に確認してください。

## 法人と職種を決めてから選考を読む

社労士事務所の仕事には、社会保険手続きに関する事務、給与計算、顧客対応、労務相談、業務を支えるシステムなど、異なる担当があります。同じ法人でも、事務職と専門相談の担当で求められる経験や業務の範囲が同じとは限りません。小規模な事務所と分業する法人でも担当の持ち方は異なるため、名称だけで仕事を推定しないことが基本です。

SATO社会保険労務士法人の公式サイトは社会保険手続きのアウトソーシング等を案内しています。公式採用サイトの東京正社員採用では、社会保険料計算事務スタッフと社内SE・ツール開発・RPA運用保守が別に掲載されています。社内SEの技術経験を、事務職の応募条件に混ぜて読む必要はありません。逆に、事務職が未経験を対象にしていても、技術職の経験要件まで不要になるわけではありません。

本記事の例はSATO社会保険労務士法人の東京の募集です。グループ内の日本社労士法人など別法人の選考、新卒採用のQ&A、他拠点の案内を、そのまま当該キャリア求人の手順として使いません。求人を保存する際は、法人、拠点、職種、確認日を一緒に記録します。

## 公開されている流れと、確認が必要な事項

東京の社会保険料計算事務スタッフ求人は、エントリーから応募し、一次面接と適性検査、二次面接を経て内定という流れを記載しています。一次面接の欄には履歴書・職務経歴書、適性検査には性格・価値観、二次面接にはアンケートとExcelスキルチェックが示されています。一次面接はWEBで対応する旨も掲載されています。

これは当該職種の公開フローです。社労士事務所全体が必ず同じ回数や方法になるとはいえません。また、公開ページからは、実際の設問、採点の配点、通過の基準、どの回答を評価するかまでは確認できません。性格検査について特定の回答を選べば有利になると考えず、本人の事実と考えを一貫して答える準備をします。

| 公開されている段階 | 本人が準備すること | 応募先へ確認すること |
| --- | --- | --- |
| エントリー | 法人・拠点・職種・雇用形態の希望を照合 | 募集継続、入力後の連絡、提出方法 |
| 一次面接と適性検査 | 職歴、応募理由、本人の担当範囲を整理 | 実施日時、接続案内、提出期限 |
| 二次面接等 | Excelの使用歴と未経験操作を整理 | 実施場所、持参物、検査の案内 |
| 内定後 | 職務と本人に提示された条件を確認 | 契約、入職時期、回答期限 |

求人には選考期間の目安や入職日の相談に関する案内がありますが、本人に同じ期間で内定が出る保証にはなりません。現職の勤務、休暇の手続き、退職に関する所属の案内と、企業側の選考予定を分けて調整してください。選考参加のために無断で勤務を離れることや、内定前に退職することを前提にしません。

仕事の比較から始めたい場合は、[公務員経験を整理して求人を確認する](../?gov=1)こともできます。応募先が決まってから、当該求人の案内を基準に準備を具体化しましょう。

## 職務経歴書は、資料と確認の流れまで書く

当該求人は随時改定と算定基礎届を中心に、給与データのチェック、報酬月額の判定、保険料の改定確認、必要なデータの作成を仕事内容に挙げています。応募条件は業界経験不問ですが、高卒以上、基本的なPCスキル、ExcelのVLOOKUPやIFの利用、事務経験が記載されています。業界経験不問と、事務経験や操作条件がないことは別です。

公務の職歴では、部署名と在籍期間に加え、本人がどの資料を扱い、どの項目を確認し、疑問を誰へ照会し、どこで承認を受けたかを書きます。「調整力」「正確性」といった言葉に具体的な工程を添えるためです。所属全体の処理や上司の判断を本人の成果として書かないでください。

保険窓口で案内していた場合も、企業の社会保険料計算を行ったことにはなりません。自治体職員の給与を扱っていた場合は、本人の入力、確認、例外処理の照会と、システムの計算や決裁者の判断を分けます。民間企業の実務が未経験なら、その点を明記したうえで、共通する工程を説明できます。

Excelについては、関数名を知っていること、学習で操作したこと、実務で使用したことを区別します。実務経験があるなら、どの情報を照合するためにどの機能を使ったかを、秘密や個人情報を含めず説明します。学習用に作った表を、現職で導入した成果物のように示してはいけません。

:::insight
選考準備では、質問を予想して答えを増やす前に、自分の担当の境界を確かめることを勧めます。求人にはデータ確認やExcelの利用が書かれていても、採点の細かな基準までは公表されていません。そこで本人が準備できるのは、実際に使った資料の種類、確認の手順、判断を仰いだ相手を整理することです。うまく言うために未経験の計算や他者の決裁を加えると、担当の説明が変わってしまいます。公開条件に対応する事実と、入職後に学ぶ必要がある範囲を分けておけば、面接は仕事の分担を確認する機会にもできます。資料の内容を持ち出さず、外部へ説明できる工程を言葉にするところから始めてください。
:::

## 独立した架空例：面接前の確認表

次は説明用に作成した架空の準備例です。実在の相談、面接での回答、採用結果を再現したものではありません。使う場合は本人の事実に置き換え、実施していない項目は削除してください。

| 項目 | 架空の記入例 |
| --- | --- |
| 応募対象 | 社会保険料の確認・計算に関わる事務職を検討 |
| 本人の経験 | 庶務担当として届出の記載と添付資料の有無を照合 |
| 具体的な工程 | 不足項目を整理し、担当部署に確認するためのメモを作成 |
| 他者が行ったこと | 制度上の判断と最終承認は担当部署と上司が実施 |
| PCの経験 | 実務では表の入力・並べ替えを担当。IFは学習用の架空表で練習中 |
| 未経験 | 企業の算定基礎届・随時改定の実務、VLOOKUPの実務使用 |
| 先に確認する事項 | 現在の操作経験で応募条件を満たすか、配属後の確認担当 |

この例では、PC条件を満たしていると断定できないため、応募前の確認が必要です。「勉強するつもり」をすでに操作できる事実に置き換えません。応募先が求める状態を確認し、学習してから応募する、別の求人と比較する、現職を続けながら情報を集めるなどの選択を残します。

説明の練習では、結論を長く飾るより、本人の作業を短く言えるか確かめます。たとえば「届出の不足を確認し、判断が必要な事項は担当部署へ照会しました」と話し、計算や判断をしていない点を保ちます。自己評価を強めるための件数や効果を後から作る必要はありません。

[職務経歴と応募条件を相談用に整理する](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担）。経験や希望条件によって、面談や求人紹介を案内できない場合があります。

## 面接では、自分から確認する事項も整理する

当該職種は社内担当者やチームとの連携が中心で、クライアントとの直接のやり取りは基本的にないと説明しています。ただし、必要な確認をどの担当者が行い、本人がどの範囲まで対応するかは、具体的な配属によって確認したい事項です。担当する顧客数や処理の量を推測せず、業務を教わる順序やチェック体制を聞きます。

また、雇用形態は正社員・契約社員で、試用期間中の6か月は契約社員と記載されています。登用を前提とする説明と、本人の登用決定は別です。契約期間、更新、登用に関する説明、本人に提示される勤務条件を確認します。内定という連絡だけで、希望した職務や雇用条件のすべてが確定したと思わないようにしてください。

質問は、求人に書かれていない点を一つずつ明確にするために用意します。「未経験ですが大丈夫ですか」とまとめるより、「現在は届出の内容確認までを担当しており、保険料計算は未経験です。入職直後の担当と、計算結果の確認者を教えてください」と分けると、聞きたい範囲が伝わります。これは本人が確認するための例であり、採用側が出す質問や好まれる答えの予告ではありません。

## 応募情報と現職の情報を分ける

公式のエントリーページは、応募情報の利用目的として採用申込みの受付、連絡、選考を掲げています。応募する際は、同ページの個人情報の取扱いを読んだうえで、希望する勤務地や雇用形態を照合します。フォームの任意欄へ、現職の職員名や個別案件、給与資料を入力する必要はありません。

職務経歴書や練習資料にも、内部の届出、名簿、顧客・住民情報を持ち出さないでください。匿名化だけで外部利用が可能になるとは限りません。個人の端末や生成AIに実際の内部資料を入力することも避け、公開情報と自分の担当工程で説明を組み立てます。行政上の便宜や職務上の連絡先を応募活動に用いません。

社労士法第2条と第27条には業務や一定の業務の制限が定められています。事務職に応募できることから、無資格で独立して他人の申請や代理を引き受けられるとは考えません。社労士法人内の役割、専門判断の担当、指示・確認の体制を確かめます。資格の取得や学習と、担当できる実務の経験も別々に説明してください。

:::insight
選考が進んでも、内定を得ることだけを判断の基準にしないよう勧めます。事務職として求められる操作を満たしているかに加え、専門判断を誰が担うか、本人は何を確認するか、どの雇用形態で働くかを理解する必要があります。求人にある研修や登用の案内は大切な情報ですが、本人の習得や契約の結果まで決まったものではありません。確認した内容と未回答の事項を分けて残し、現職の勤務や生活条件とも照合してください。条件が合わなければ、応募を見送ることや現職を継続することも選べます。進捗に合わせて結論を急ぐより、本人が納得して引き受けられる仕事かを一段ずつ確かめる準備を勧めます。
:::

## 選考の連絡を受けたら、予定表を更新する

予定表には面接の候補日だけでなく、提出物、提出期限、連絡先、確認待ちの事項を記入します。求人の掲載内容と個別の案内に違いがある場合は、どちらを使うか自分で推測せず、採用窓口に確かめてください。検査の受検や書類の提出が完了したつもりでも、相手の受領や次の予定が確認できているかは別です。

辞退や日程の変更を希望する場合も、企業への連絡と、所属で申請した休暇などの手続きは別々に対応します。応募をやめたことで、ほかの手続きが自動で取り消されるとは考えません。本人の予定を変更するときは、関係する連絡と必要な手続きを一つずつ見直しましょう。選考の進行状況だけで勤務や退職の日を決めないようにします。

## まとめ：公開フローと本人の事実を準備する

社労士事務所の選考を調べるときは、法人、拠点、職種ごとの公開案内を確認します。今回の東京事務職の面接・検査を業界共通の手順にせず、本人の実施方法と期限は応募先の連絡で照合しましょう。非公開の設問や評価の理由を想像するより、仕事内容と応募条件に対応する本人の事実を整えることが準備になります。

[LINEで相談の進め方を確認する](https://line.me/R/ti/p/@697nxhbt)際も、担当した工程、未経験の実務、希望する条件を分けて伝えてください。進路の判断を保留し、現職を続けながら比較することもできます。

## よくある質問

### 社労士事務所はどこも同じ回数の面接ですか？

法人・拠点・職種によって異なります。本記事の一次面接・適性検査、二次面接等は、SATO社会保険労務士法人の東京の当該職種の例です。最新の案内を確認してください。

### Excelの検査では何が出ますか？

公開ページはスキルチェックの実施を示していますが、設問や配点は確認できません。求人にある操作条件と本人の使用歴を照合し、実施方法は応募先へ確認します。

### 試用期間が終われば必ず正社員になりますか？

当該求人は登用を前提とする説明がありますが、本人の結果を保証するものではありません。試用中の契約、期間、更新、登用の扱いと本人への提示条件を確認してください。
