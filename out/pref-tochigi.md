栃木県庁で働いてきた方の転職相談で、いちばん多く聞く言葉は「自分の経験が県外で通じるのか分からない」です。

結論を先に書くと、**通じます。**ただし、そのままの言葉では伝わりません。庁内の職名と事業名で書かれた職務経歴書を、民間の求人票が使っている言葉に置き換える必要があります。

この記事では、まず公表されている数字で自分の位置を確認し、そのうえで置き換えの手順を整理します。

## 栃木県庁の給与水準を、数字で確認する

総務省の調査によると、栃木県の一般行政職は次のとおりです（令和6年4月1日現在）。

| 項目 | 栃木県 |
|---|---|
| ラスパイレス指数 | 99.4 |
| 平均年齢 | 42.3歳 |
| 平均給料月額 | 322,200円 |
| 諸手当月額 | 70,502円 |
| 平均給与月額 | 392,702円 |
| 平均給与月額（国ベース） | 352,711円 |
| 地域手当（国の指定基準） | 3.5% |
| 地域手当（実際の支給割合） | 約4.40% |

**ラスパイレス指数99.4**は、国家公務員の給与水準を100としたときに、わずかに下回っているという意味です。近隣は茨城県100.2、群馬県100.0、埼玉県や東京都はさらに高い水準になります。

### 地域手当の「国基準」と「実支給」がずれている

読みどころはここです。**国が指定する基準は3.5%なのに、実際の支給割合は約4.40%。**0.9ポイントほど上回っています。

北関東で並べると、茨城県が国基準6.0%に対し実支給約7.46%、群馬県は国基準2.5%で実支給も約2.50%。**上回っている県と、基準どおりの県があります。**

地域手当は民間賃金の高い地域に支給される手当で、国の指定基準は市町村単位で決まっています。都道府県が独自の判断で支給割合を設定する余地があるため、こうした差が生じます。

:::insight
この構造が、転職のときに誤解を生みます。**地域手当は民間企業にはない概念です。**求人票が提示するのは基本給と諸手当を含んだ年収であって、「地域手当◯%」という内訳では書かれていません。相談でよく起きるのが、地域手当を含んだ現在の額面を基準に「これより下は受けられない」と判断し、**実際には条件の良い求人を最初から外している**ケースです。比べるときは、源泉徴収票の支払金額と、求人票の想定年収を突き合わせてください。手当の名目ごとに比べようとすると、必ず噛み合いません。
:::

なお、上の平均は自分の給与ではありません。全年齢の平均です。民間の求人票と比べるときは、**自分の源泉徴収票の支払金額**を使ってください。

## 県庁の経験は、民間で何と呼ばれるか

| 県庁での仕事 | 求人票での言い方 |
|---|---|
| 予算の要求・査定、財政計画 | 予実管理、投資判断、経営企画 |
| 地域交通の計画・整備・補助 | モビリティ事業企画、交通コンサル |
| 企業誘致・立地支援 | 事業開発、用地開発、アライアンス |
| 産業支援・技術支援の施策 | 産学連携、技術企画、事業開発 |
| 観光の誘客・受入環境整備 | 観光事業企画、地域ブランディング |
| 農林水産の産地形成・輸出支援 | 事業開発、産地開発、海外展開 |
| 県土整備の設計・積算・監督 | 発注者支援、施工管理 |
| 市町村への助言・支援 | パートナー支援、カスタマーサクセス |
| 議会対応、条例・規則の改正 | 渉外、法務、規程整備 |

部署ごとの詳しい対応は[自治体の部署別 仕事ガイド](../zukan.html)にまとめています。財政課であれば[財政課の経験は民間で何と呼ばれるか](dept-zaisei-honyaku.html)で、さらに細かく分解しています。

## 栃木で、どの経験が値になるか

**1. 地域交通の再編と整備**

栃木県は、地域交通の分野で全国から参照される事例を持つ県です。**新しい交通機関を、計画から合意形成、整備、運行の枠組みづくりまで通した経験**は、全国の自治体がいま知りたがっているものです。

民間側では、交通事業者、まちづくり、モビリティ関連の事業者、そして自治体向けのコンサルティング会社が、この経験を求めています。**「やった人がまだ少ない」というのが、そのまま希少性になります。**

書くときのこつは、路線名や事業名ではなく、**関係者の数と、反対をどう合意に変えたか**で書くことです。この構造は、民間の新規事業や大型プロジェクトとまったく同じです。

**2. ものづくりの県での企業支援**

自動車、輸送用機器、精密機械、医療機器。栃木県は製造業の集積があり、県庁には企業支援と誘致の実務があります。**用地の確保、インフラの手当て、補助制度の設計、地元との調整。**進出する企業から見れば、自分たちが最も苦労する部分です。

**3. 観光の受入環境と地域ブランディング**

日光、那須。観光客の受入環境整備、地域資源の売り込み、事業者との連携。**行政の立場で観光の座組みを作った経験**は、観光関連の事業者や地域商社から見て希少です。

**4. 市町村を相手にしてきた経験**

規模も体制もばらばらな市町村を相手に、温度差をどう埋めたか。「連絡調整」ではなく、**複数顧客を持つアカウント業務の経験**として書けば、そのまま職務能力になります。

小規模町村を相手にしてきた経験はとくに値がつきます。担当が1人で何役も兼ねている、専任の技術職がいない、予算が小さいから提案の刻み方を変えなければならない。**こうした事情は、売る側からはほとんど見えません。**県の立場で市町村を回ってきた方は、この地図を頭の中に持っています。

**5. 内部管理部門の経験**

人事、財政、総務、会計。県庁の内部管理部門の仕事は、民間企業のコーポレート部門とほぼ同じ構造です。制度の設計と運用、全部署の調整、決裁と記録。**製造業の管理部門や、支社の総務・経理といった職と噛み合います。**転居を伴わずに職種を変えたい場合、この方向は現実的な選択肢になります。

## 首都圏の求人も、視野に入れてよい

栃木県は新幹線で首都圏とつながっており、**転居せずに都内の求人に応募できる**位置にあります。

ここで多いのが、通勤時間だけで線引きしてしまう判断です。近年はリモート可、週数日出社といった勤務形態の求人が増えています。とくに自治体を顧客にする企業は、担当エリアに出向くことが仕事なので、本社への出社頻度が低い場合があります。

**募集要項の「勤務地」欄だけでなく、勤務形態の記載まで確認してください。**通えないと判断するのは、その後で十分です。順序としては、**まず職種で絞り、そのあとに勤務形態を確認する。**勤務地から検索すると、県内では出会えない職種が最初から視界に入りません。

## 職務経歴書に、県庁の仕事をどう落とすか

**制度名ではなく、判断したことを書く**

「○○推進事業を担当」では読み手に何も残りません。事業名は庁内でしか意味を持たない固有名詞です。**何件を、どういう基準で審査し、どこで判断が割れて、どう決着させたか。**

**本庁と出先機関を書き分ける**

本庁は制度の設計と全県調整、出先は現場対応と個別案件の処理と、職務の性質がまったく違います。**どちらをどれだけ経験したかを書き分ける**と、読み手が配属をイメージできます。

**異動歴を「立ち上げの回数」に変える**

数年ごとの異動を「専門性がない」と書くのは、自分から評価を下げる書き方です。異なる制度領域を短期間で立ち上げてきた経験は、民間では**キャッチアップの速さ**として読まれます。編年式で並べ、それぞれの配属で最初の数か月に何を習得したかを1行添えてください。

## 技術職の場合は、探し方が変わる

**発注者側の経験そのものが職種になる**

「発注者支援」という職種が、建設コンサルタント業界には確立しています。設計の審査、積算の確認、工事の監督、住民説明。県庁でやってきたことが、そのまま職務内容として書かれた求人です。

**資格が入口で効く**

技術士、施工管理技士、測量士、電気主任技術者。事務職では資格より実績が先ですが、技術職では資格が応募の入口になる場面があります。**実務経験の年数が受験要件になっているものは、在職中でなければ積めません。**取れるものがあるなら、動く前に取っておいてください。

**交通・都市計画の実務は特殊な資産になる**

道路だけでなく、公共交通の計画に関わった技術職は、いま民間で強く求められています。**需要予測、事業スキームの検討、他事業者との協議。**この一連を経験している技術者は多くありません。

## 面接で必ず詰められる2つのこと

**「意思決定のスピードに耐えられるか」**

行政は手続きの段数が多く、決裁を経て動きます。民間は月次で数字を締め、その場で方針を変えます。稟議の段数を弁解せず、**自分の判断で動かした範囲を具体的に答えてください。**

**「数字への意識があるか」**

「利益を意識したことはありますか」という形で聞かれます。「行政なので利益はありません」と答えると、そこで話が終わります。事業の優先順位を付けた、単価の根拠を詰めた、複数案を比べた。**同じ思考をしていたことを、民間の言葉で説明できるか**が見られています。

## 在職中に進めるときの注意点

**服務上の扱いを先に確かめる**

在職中に得た情報を持ち出すことは避けなければなりませんし、退職後の営業活動についても扱いを確認しておいたほうが安全です。**判断に迷う場合は、応募の前に人事担当課に制度上の取扱いを確認してください。**

**面接の日程は、議会日程から逆算する**

地方自治法第211条は、長が毎会計年度予算を調製し、年度開始前に議会の議決を経なければならないと定めています。都道府県は年度開始前30日までに予算を議会へ提出するようにしなければならない、とも書かれています。決算は、出納閉鎖後3か月以内の長への提出、監査委員の審査、議会の認定という順です（第233条）。**予算編成の山と定例会の会期中は、平日日中の面接を入れるのが難しくなります。**

**在職中に決める**

公務員には雇用保険が適用されないため、辞めてから探すと収入のない期間がそのまま持ち出しになります（[公務員に雇用保険がない理由](seido-shitsugyo-nashi.html)）。

:::insight
ここまで転職の話を書いてきましたが、**残る判断にも理があります。**とくに、いま担当している事業が数年後に「実際に通した経験」として書けるかどうかで、職務経歴書の厚みは大きく変わります。途中で抜けると、着手したところまでしか書けません。首都圏に近い栃木県は、地方県庁のように「動くなら転居を伴う」という制約がないぶん、**機が熟すまで待っても選択肢はそれほど減りません。**異動の希望が通る見込みがあるなら、まずそちらを試すのも合理的です。ただし、自分の経験が外でどう呼ばれるかを知っておくことには、動かない場合でも意味があります。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 栃木県の一般行政職は**ラスパイレス指数99.4、平均給与月額392,702円**（令和6年4月1日現在・総務省調査）
- **地域手当は国の指定基準3.5%に対し、実際の支給割合は約4.40%**。茨城県も同様に上回り、群馬県は基準どおりです
- **地域手当は民間にない概念です。**源泉徴収票の支払金額と、求人票の想定年収で比べてください
- 経験が効く方向は、**地域交通の再編と整備／ものづくりの県での企業支援／観光の受入環境／市町村を相手にした経験**の4つです
- 交通の分野は**「やった人がまだ少ない」**ことがそのまま希少性になります。路線名ではなく、関係者の数と合意の作り方で書いてください
- **勤務地から検索しない。**職種で絞ってから勤務形態を確認する順序に変えてください

## よくある質問

### 地域交通の経験は、どんな企業で評価されますか

**交通事業者、まちづくりや都市開発の企業、モビリティ関連の事業者、そして自治体向けのコンサルティング会社**です。共通しているのは、いずれも「行政と組まなければ事業が進まない」領域だという点です。計画の作り方、合意形成の進め方、補助制度の使い方を知っている人は、外から採用しようとしても簡単には見つかりません。

### 都内の企業に転職すると、通勤が現実的ではないのですが

**毎日通う前提で考えないでください。**リモート可、週数日出社の求人が増えています。とくに自治体を顧客にする企業は、担当エリアに出向くことが仕事なので、本社への出社頻度が低い場合があります。募集要項の勤務形態まで確認してから判断してください。

### 30代ですが、県外に出ないと選択肢は増えませんか

**そうとは限りません。**栃木県内にも製造業の事業所や、県外企業の拠点があります。加えて、県内在住のまま都内本社の企業に所属する形も現実的です。**先に職種を決めてから勤務地を確認する順序**にすれば、県内・県外という二択で考える必要はなくなります。
