退職の手続きのうち、**返還と共済に関する部分**を扱います。

**全体の一覧は**[退職時の手続き一覧](senko-taishoku-tetsuzuki.html)**にあります。**

**返還は、最終出勤日までに終えるのが通常**です。

## 貸与されているものは、物品です

**返還が必要な理由を、制度から確認します。**

**地方自治法第239条第1項**です。

> この法律において「**物品**」とは、普通地方公共団体の所有に属する動産で次の各号に掲げるもの以外のもの及び**普通地方公共団体が使用のために保管する動産**（政令で定める動産を除く。）をいう。

**自治体が所有する動産、または使用のために保管する動産が「物品」**です。

**端末、鍵、被服、書籍。**貸与されているものは、**この物品に当たります。**

**個人の所有物ではありません。**

**管理の方法は、各自治体の規則で定められています。**

**返還を忘れると、退職後に連絡と郵送が生じます。**

## 返還するもの

**一般的な項目**です。**所属によって異なります。**

| 分類 | 例 |
|---|---|
| 身分を示すもの | 職員証、名札、入退館の証 |
| 鍵・機器 | 執務室の鍵、ロッカーの鍵、端末、携帯電話 |
| 被服 | 作業服、制服、安全に関する装備 |
| 書籍・資料 | 例規集、業務用の図書、貸出の資料 |
| 証明書 | 資格に関する証、公用の旅券など |
| 健康保険証 | **退職日以降**（他と時期が違う） |

**6つ目の時期が違う点に注意してください。**

**端末や鍵は最終出勤日まで**ですが、**健康保険証は退職日まで有効**であるのが通常です。

**返還の方法（持参か郵送か）を、所属に確認してください。**

**所属によっては、返還の一覧が様式として用意されています。**その場合は、**様式に沿って進めれば足ります。**

## 返還の進め方

| 順 | やること | 時期 |
|---|---|---|
| 1 | **貸与物の一覧**を所属に確認 | 1か月前 |
| 2 | 手元にあるものを照合 | 3週間前 |
| 3 | 見当たらないものを申告 | **早めに** |
| 4 | 返還 | 最終出勤日まで |
| 5 | 健康保険証の返還 | 退職日以降 |

**3を先延ばしにしないでください。**

**紛失している場合、手続きが必要になることがあります。**

**最終出勤日に判明すると、時間が足りません。**

**照合の作業自体は、30分程度で終わります。**一覧と手元を突き合わせるだけです。

## データと文書の扱い

| 対象 | 扱い |
|---|---|
| 業務のデータ | **私物の端末や記録媒体に残さない** |
| 個人的に作った資料 | 業務で作ったものは**組織のもの** |
| 共有の場所 | 引継ぎの資料として整理して残す |
| 私物の記録媒体 | **持ち込んでいないか確認** |

**2つ目について補足します。**

**自分用に作った表や手順書でも、業務のために作成したものは組織の文書**です。

**持ち出すことはできません。**

**引継ぎの資料として、共有の場所に残してください。**

**地方公務員法第34条の守秘の義務は、退職後も続きます。**

## 共済組合に関する手続き

| 項目 | 内容 | 確認先 |
|---|---|---|
| 資格の喪失 | 退職により喪失 | 所属、共済組合 |
| 健康保険の切替え | 任意継続か、国民健康保険か、次の勤務先か | **共済組合、市区町村** |
| 年金の扱い | 記録の確認、次の制度への移行 | 年金事務所、共済組合 |
| 貸付の残高 | 借入がある場合の精算 | **共済組合** |
| 積立の扱い | 貯金や保険の商品がある場合 | 共済組合 |

**4つ目と5つ目を忘れやすい**です。

**共済組合の貸付を利用している場合、退職時の扱いを確認してください。**

**一括での返済を求められることがあります。**

**積立や保険の商品も、退職によって扱いが変わることがあります。**

:::insight
返還と共済の手続きで、**面談でお伝えしているのが「借入と積立を先に確認してください」**という点です。貸与物の返還は、**一覧をもらえば済みます。**一方、**共済組合の貸付や、積立の商品は、自分から確認しないと出てきません。**とくに、**住宅に関する貸付を利用している場合、退職時の扱いが大きく影響**することがあります。一括での返済が必要になれば、**退職手当の使途が変わります。**面談で伺った例では、**退職を決めた後にこの点に気づき、時期を調整した方**がいらっしゃいます。**確認は、退職の意思を伝える前でもできます。**共済組合に、**「退職した場合の取扱い」を一般的に問い合わせる**ことは可能です。**在職中の早い段階で確認しておいてください。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

**なお、共済組合の窓口は、所属の庶務を経由する場合と、直接問い合わせる場合があります。**どちらの経路かを、**先に確認**してください。

## 健康保険の選択

**離職期間が生じる場合、選択が必要になります。**

| 選択肢 | 概要 |
|---|---|
| 共済組合の任意継続 | 一定の期間、継続して加入できる制度 |
| 国民健康保険 | 市区町村が運営 |
| 家族の被扶養者になる | 要件を満たす場合 |

**保険料の負担は、それぞれ異なります。**

**比較するには、両方の窓口で金額を確認する必要があります。**

**任意継続には、申出の期限があります。**

**退職の1か月前には、確認に着手してください。**

**詳しくは、後の記事で整理します。**

## 退職の前に確認しておくこと

**共済組合に関する事項は、退職の意思を伝える前でも確認できます。**

| 確認 | 聞き方 |
|---|---|
| 貸付の残高と、退職時の扱い | 「退職した場合の取扱いを教えてください」 |
| 積立や保険の商品の扱い | 同上 |
| 任意継続の制度の有無と期限 | 一般的な制度の説明として |
| 年金の記録 | 加入期間の確認 |

**4つとも、一般的な問い合わせとして聞けます。**

**「退職を検討しています」と述べる必要はありません。**

**制度の説明を求める形であれば、意向が伝わることもありません。**

**とくに、1つ目は判断に影響します。**貸付の残高が大きい場合、**退職の時期を調整する理由になり得ます。**

**在職中の早い段階で確認しておいてください。**

## 退職後に届くもの

**返還だけでなく、退職後に受け取るものもあります。**

| 届くもの | 時期 |
|---|---|
| 退職手当の支給に関する通知 | 規程による |
| 源泉徴収票 | 退職後に交付されることがあります |
| 共済組合からの通知 | 資格喪失、精算に関するもの |
| 年金に関する通知 | 記録の確認 |

**住所が変わる場合は、所属と共済組合に届け出てください。**

**届かないまま放置されると、手続きが遅れます。**

**転居の予定がある場合は、退職の前に伝えておいてください。**

## 空白なく次に入る場合

| 項目 | 扱い |
|---|---|
| 健康保険 | **次の勤務先で加入**の手続き |
| 年金 | 同上 |
| 共済の資格喪失 | 所属で処理 |
| 貸付・積立 | **自分で確認**が必要 |

**空白がない場合でも、4つ目は自分で確認してください。**

**健康保険と年金が自動で切り替わるからといって、共済のすべてが自動で処理されるわけではありません。**

[経験の言い換えから相談する](../apply.html)こともできます。

**なお、これらの通知には、確認や返送が必要なものが含まれます。**退職後は、**郵便物を数か月は確認する習慣**にしておいてください。

## よくある失敗

**1. 貸与物の一覧を確認しない**

**返し忘れ**が生じます。

**2. 紛失の申告を先延ばしにする**

**手続きが必要**になることがあります。

**3. 業務で作った資料を持ち出す**

**組織の文書**です。

**4. 共済の貸付を確認しない**

**一括での返済**を求められることがあります。

**5. 健康保険の選択を直前に決める**

**比較に時間がかかります。**

**6. 健康保険証を最終出勤日に返す**

**退職日まで有効**であるのが通常です。

:::insight
ここまで手続きの話をしておいて逆のことを言いますが、**返還そのもので困ることは、ほとんどありません。**一覧をもらい、照合して、返す。**作業としては単純**です。時間がかかるのは、**共済に関する確認と、健康保険の選択**のほうです。とくに、**保険料の比較**は、窓口で金額を出してもらう必要があり、**即日では終わりません。**面談でお伝えしているのは、**「返還は最終週、共済は1か月前」**という配分です。**先にやるのは共済のほう**です。そして、**貸付の有無だけは、退職を決める前に確認してください。**扱いによっては、**退職の時期の判断に影響**します。**時期の決め方は**[退職時期の決め方｜年度末と年度途中](senko-taishoku-jiki.html)**にあります。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方自治法第239条第1項**は、**自治体が所有し、または使用のために保管する動産**を「物品」としています。**貸与物は個人の所有物ではありません**
- 返還は、**身分を示すもの・鍵と機器・被服・書籍・証明書**。**健康保険証だけは退職日以降**です
- **貸与物の一覧を1か月前に確認**し、**紛失は早めに申告**してください
- **業務で作った資料は組織の文書**です。持ち出せません
- **共済組合の貸付と積立は、自分から確認**してください。一括での返済を求められることがあります
- **健康保険の選択は、1か月前に着手。**任意継続には申出の期限があります

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 貸与物を紛失していました

**早めに所属に申告してください。**紛失の届出や、**弁償の手続き**が必要になることがあります。扱いは、**所属の規則で定められています。**最終出勤日に判明すると、**手続きの時間が足りません。**照合は、**3週間前までに済ませてください。**なお、**自宅に持ち帰ったまま忘れているもの**もあります。書籍、資料、備品。**心当たりのある場所を確認**してください。**退職後に見つかった場合も、郵送などで返還**することになります。放置しないでください。

### 共済組合の任意継続と国民健康保険、どちらがよいですか

**保険料と、扶養の範囲で比較してください。**任意継続は、**在職中の保険料の算定を基礎とする仕組み**が一般的とされていますが、**制度の詳細は共済組合によって異なります。**一方、国民健康保険は、**前年の所得にもとづいて算定される**のが通常です。**どちらが有利かは、個別の事情によります。**加えて、**扶養している家族がいる場合、扱いが変わることがあります。**比較するには、**共済組合と市区町村の両方で金額を確認**してください。**この記事では、具体的な金額や計算は示しません。**

### 退職後に、職場から返還の連絡が来ました

**すみやかに対応してください。**返し忘れがあった場合、**郵送での返還**を求められるのが通常です。**送付の方法（書留など）を確認**してください。端末や鍵など、**取扱いに注意が必要なもの**は、指示に従ってください。なお、**このやり取りを避けるために、最終出勤日までに一覧と照合しておく**ことを勧めます。**退職後のやり取りは、双方にとって手間**です。**受け取る書類の確認と同じタイミングで、返還も完了させてください。**
