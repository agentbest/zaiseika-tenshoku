**用地や財産の事務を担当してきた方から、「この資格で何が開くか」**というご相談を伺います。

**設置が義務づけられている資格**は、需要の構造がはっきりしています。

この記事では、**その構造**と、**経験との接続**を扱います。

**⚠ 受験・登録の要件と手続は、所管するところの公表を確認してください。****この記事では、個別の要件には触れません。**

## 事務所ごとに、設置が義務づけられています

**宅地建物取引業法第31条の3第1項**です。

> **宅地建物取引業者は、その事務所その他国土交通省令で定める場所**（以下この条及び第五十条第一項において「事務所等」という。）**ごとに、事務所等の規模、業務内容等を考慮して国土交通省令で定める数の成年者である専任の宅地建物取引士を置かなければならない。**

**事務所等ごとに、一定の数の専任の者を置かなければならない**という構造です。

**つまり、事業者の側に、この資格を持つ人が必要になる**ということです。

**資格の需要が、法律の条文から生じている**点は、**衛生管理者や電気主任技術者と同じ**です。

**扱いは**[衛生管理者｜総務・人事からの転職で使える場面](skill-eisei.html)**にも整理しています。**

## どの転職先で開くか

| 領域 | 使いどころ |
|---|---|
| ① 不動産の取引 | **設置の対象となる事業所** |
| ② 不動産の管理 | 賃貸の管理、契約 |
| ③ 用地の取得の支援 | 権利関係の調査 |
| ④ 金融・保証 | 担保の評価に関わる場面 |
| ⑤ 自治体が相手の事業 | 公有財産の活用 |

**⑤について。**

**公有財産の貸付や処分**に関わる事業があります。

**行政の側の手続を知っている人**が、そこで必要とされます。

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 行政での経験との接続

| 経験 | 民間での読まれ方 |
|---|---|
| ① 権利関係の調査 | **登記、相続、共有の整理** |
| ② 現地の確認 | 状況、境界、接道 |
| ③ 契約の手続 | 内容の確認、決裁 |
| ④ 相手方への説明 | 条件、手続の説明 |
| ⑤ 台帳の管理 | 現況との整合 |
| ⑥ 貸付・処分の事務 | 公有財産の活用 |

**①と⑥が、行政ならでは**です。

**⑥について。**

**公有財産の貸付や処分の手続**を経験している方は、**同じ分野の民間の業務と接続します。**

**扱いは**[司法書士｜登記実務と行政経験](skill-shihoshoshi.html)**にも整理しています。**

## 書き方の例

**悪い例**

> 財産の管理を担当しました。

**良い例**

> ◯◯課において、**公有財産◯件の管理を担当。**登記記録と現況を照合し、**相違◯件を確認のうえ台帳を修正。**貸付の契約を**年約◯件、処分の手続を◯件担当し、**相手方への条件の説明と契約の手続を実施。**境界の立会いに年◯件同行し、**隣接する権利者との調整を担当。

**「件数」「照合」「契約」「説明」「立会い」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

:::insight
この資格について、**面談でお伝えしているのが「設置の義務がある資格は、扱いが違う」**という点です。多くの資格は、**持っていると評価される**という位置づけです。一方、**設置が法律で義務づけられている資格**は、**事務所ごとに必要な人数が決まる**という構造を持ちます。**つまり、求人の側に「この人がいないと成り立たない」事情がある。**これは、応募する側から見ると、**条件が明確**だということです。求人票に「必須」と書かれていれば、**資格があることが選考の前提**になります。そして、**用地や財産の実務と組み合わさると、候補が絞られます。**権利関係の調査、現地の確認、契約の手続。**同じ動作を、立場を変えて行う**ことになります。書類には、**資格の欄に資格を、職務の欄に財産や用地の実務**を書いてください。**両方が揃っていることが、この領域での強みです。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 確認の観点という材料

| 観点 | 内容 |
|---|---|
| ① 登記記録 | **名義、権利の種類、順位** |
| ② 現況 | 利用の状況、占有 |
| ③ 境界・面積 | 実測との差 |
| ④ 制限 | 区域、用途、接道 |
| ⑤ 添付の書類 | 揃い、有効期限 |

**②と④が、実務の差が出る部分**です。

**②について。**

**登記記録と現況が合わない場合の扱い**を判断してきたはずです。

**この判断は、取引の場面でも必要になります。**

## 取る前に考えること

| 確認すること | 内容 |
|---|---|
| ① 応募したい求人の条件 | **必須か、歓迎か** |
| ② 実務で書ける材料 | 調査、契約、台帳 |
| ③ 設置の対象となる職か | 専任の扱い |
| ④ 期限 | 応募の時期に間に合うか |
| ⑤ 会社の支援 | 取得の支援の制度 |

**⑤について。**

**入社後の取得を支援する制度**がある会社もあります。

**この場合、応募の時点で保有していなくても選考が進む**ことがあります。

**なお、取れば転職できる、という関係にはありません。**

**何を調査し、どう手続を進めたか**が、評価の対象です。

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 実績の整理 | **件数、財産の種類、契約の数** |
| 調査の整理 | 難しかった案件の経緯 |
| 要件の確認 | 所管の公表を確認 |
| 求人を読む | 週に30分 |

**1行目です。**

**台帳や決裁の資料から確認**してください。

**根拠のない数は書かないでください。**

[経験の言い換えから相談する](../apply.html)こともできます。

**守秘の義務は、退職した後も続きます。**

## 行政の側にいたことの意味

**取引の相手方が自治体である場面があります。**

| 場面 | 行政の側の事情 |
|---|---|
| ① 公有財産の貸付・処分 | **議決、公募、価格の決め方** |
| ② 用地の取得 | 補償の基準、予算の年度 |
| ③ 開発・立地 | 許認可、協議の順序 |
| ④ 施設の整備 | 契約の方法、工程 |
| ⑤ 移転・代替地 | 手続の流れ |

**①が要**です。

**公有財産の処分には、議決や公募の手続が関わることがあります。**

**この手続を知らないと、相手方の動きが読めません。**

**いつ決まるのか、何が必要なのか、誰の判断が要るのか。**

**行政の側にいた人は、この見通しが立ちます。**

**書類には、「公有財産の貸付・処分の手続を担当」**と明記してください。

## よくある失敗

**1. 「財産の管理」で止める**

**件数と手続**を書いてください。

**2. 登記と現況の照合を書かない**

**実務の差が出る部分**です。

**3. 貸付・処分の事務を書かない**

**同じ分野の民間の業務**と接続します。

**4. 境界の立会いを書かない**

**隣接の権利者との調整**は希少です。

**5. 必須か歓迎かを見ない**

**扱いが違います。**

**6. 取得の支援の制度を確認しない**

**入社後に取れる**場合があります。

**7. 要件を人づてで判断する**

**所管の公表**を確認してください。

**8. 取れば転職できると考える**

**何を調査し手続を進めたか**が評価の対象です。

:::insight
ここまで「設置の義務」の話をしておいて逆のことを言いますが、**資格が開くのは、求人の範囲であって、仕事の中身ではありません。**面談で拝見していると、**「資格を取れば、不動産の仕事ができる」と考える方**がいらっしゃいます。ところが、**入社後に担う仕事は、会社と職種によって大きく違います。**売買の仲介、賃貸の管理、用地の取得の支援、資産の活用の企画。**求められる動きも、勤務の形も違います。**売買の仲介では、**休日の対応や個人の顧客への対応**が中心になる場合があります。一方、**用地の取得の支援や、法人・自治体を相手とする業務**では、**平日の日中が中心**になることがあります。ですから、**資格を取る前に、「どの仕事をしたいか」を決めてください。**求人票の仕事内容と勤務の条件を読めば、**違いが見えます。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **宅地建物取引業法第31条の3第1項**は、**事務所等ごとに、一定の数の成年者である専任の宅地建物取引士を置かなければならない**としています
- **資格の需要が、法律の条文から生じています**
- 開くのは、**不動産の取引、不動産の管理、用地の取得の支援、金融・保証、自治体が相手の事業**です
- **権利関係の調査と、貸付・処分の事務**が、行政ならではの材料です
- **登記記録と現況の照合**は、実務の差が出る部分です
- **入社後の取得を支援する制度**がある会社もあります
- **資格が開くのは求人の範囲であって、仕事の中身ではありません**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 用地の担当でしたが、財産の管理は未経験です

**用地の経験で書いてください。**権利関係の調査、現地の確認、権利者との折衝、契約から登記までの手続。**これらは、不動産の取引の業務と動作が重なります。**書き方は、**「公共事業に係る用地の取得を担当。年間約◯件の物件の調査と、権利者との折衝を実施」**という形です。扱いは[不動産鑑定士｜用地買収の経験からの接続](skill-kanteishi.html)に整理しています。**財産の管理の経験がなくても、調査と折衝の経験があれば接続します。**

### 資格を取ると、どの程度求人が増えますか

**求人票の記載で確認してください。**「必須」とされている求人には、**資格がないと応募できません。**一方、「歓迎」であれば、**満たしていなくても応募できます。**なお、**設置が義務づけられている職**では、**入社時点での保有が要件**となることがあります。判断の目安は、**応募条件の欄**です。読み方は[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。**「増える」かどうかは、応募したい領域の求人を5件読めば分かります。**

### 在職中に取得できますか

**要件と時期を確認してください。**学習の期間は、**手元の知識と取れる時間**によります。年間でどれだけ時間が取れるかを、**繁忙期を含めて見積もって**ください。なお、**登録には手続が必要になることがあります。****⚠ 要件と手続は、所管の公表を確認**してください。また、**在職中に取得しておくと、応募できる求人が広がった状態で探せます。**一方、**入社後の取得を支援する制度**がある会社もあります。**どちらの順序でも進められます。**扱いは[建築施工管理技士｜取得の順序と転職時期](skill-kenchikusekou.html)にも整理しています。
