**総務や人事を担当してきた方から、「どの資格が使えるか」**というご相談を伺います。

**選任が義務づけられている資格**は、需要の構造がはっきりしています。

この記事では、**その構造**と、**経験との接続**を扱います。

**⚠ 受験の要件・手続は、資格を所管するところの公表を確認してください。****この記事では個別の要件には触れません。**

## 選任が、事業者の義務として定められています

**労働安全衛生法第12条第1項**です。

> **事業者は、政令で定める規模の事業場ごとに、都道府県労働局長の免許を受けた者その他厚生労働省令で定める資格を有する者のうちから、厚生労働省令で定めるところにより、当該事業場の業務の区分に応じて、衛生管理者を選任し、その者に**（略）**衛生に係る技術的事項を管理させなければならない。**

**「選任し」「管理させなければならない」**と定められています。

**そして、選任できるのは、免許を受けた者その他の資格を有する者**です。

**つまり、一定の規模の事業場では、この資格を持つ人が必要になる**という構造です。

**資格の需要が、法律の条文から生じている**ということです。

**この点が、他の多くの資格と違います。**

## 何を管理する立場か

**同法第10条第1項に掲げる業務のうち、衛生に係る技術的事項を管理する**とされています。

| 領域 | 内容の例 |
|---|---|
| ① 健康障害の防止 | 作業の環境、設備 |
| ② 健康の保持増進 | 健診、面談の運用 |
| ③ 教育 | 安全衛生に関する教育 |
| ④ 原因の調査と再発の防止 | 事故や不調が生じた場合 |
| ⑤ 記録 | 実施の記録の整備 |

**⚠ 具体の業務の範囲と要件は、法令と所管の公表を確認**してください。

**この記事では、構造の説明にとどめます。**

**⑤について。**

**記録の整備は、行政の事務で身についている部分**です。

**何を、いつ、誰が実施したかを残す。**

**この習慣は、そのまま持ち込めます。**

**記録がないと、実施したことを説明できません。**

**行政では、この点が徹底されています。****書類にも書ける材料です。**

## 行政での経験との接続

| 行政での経験 | 接続する部分 |
|---|---|
| ① 職員の健康の管理 | 健診の運用、面談の手配 |
| ② 安全衛生に関する会議の事務 | **委員会の運営** |
| ③ 庁舎・施設の管理 | 作業の環境の確認 |
| ④ 公務災害の事務 | 原因の整理、再発の防止 |
| ⑤ 研修の企画 | 教育の実施 |
| ⑥ 規程の整備 | 手順の文書化 |

**②が、最も直接に接続します。**

**会議を運営し、議事を記録し、指摘を担当課につなぐ。**

**この動作は、民間の事業場でも同じ**です。

**④について。**

**災害や不調の原因を整理し、再発の防止の手順を作った経験**は、そのまま使えます。

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 総務・人事 | **選任の対象となる事業場** |
| ② 施設の管理 | 環境の確認、記録 |
| ③ 製造・物流 | 現場の安全と衛生 |
| ④ 受託・指定管理の会社 | 複数の施設を持つ |
| ⑤ 医療・介護の事業 | 職員の健康の管理 |

**①について。**

**一定の規模の事業場では、選任が必要**です。

**このため、総務や人事の求人で、資格が応募条件として挙げられる**ことがあります。

**「必須」か「歓迎」か**を、求人票で確認してください。

**読み方は**[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)**に整理しています。**

:::insight
選任が義務づけられた資格について、**面談でお伝えしているのが「需要の理由が条文にある資格は、扱いが違う」**という点です。多くの資格は、**持っていると評価される**という位置づけです。一方、**衛生管理者のように、法律で選任が義務づけられている資格**は、**事業場ごとに必要な人数が決まっている**という構造を持ちます。**つまり、求人の側に「この人がいないと成り立たない」という事情がある。**これは、応募する側から見ると、**条件が明確**だということです。求人票に「必須」と書かれていれば、**資格があることが選考の前提**になります。そして、**総務や人事の実務経験と組み合わさると、候補が絞られます。**書類には、**資格の欄に資格を、職務の欄に安全衛生に関する事務の経験**を書いてください。**両方が揃っていることが、この領域での強みになります。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 取る前に考えること

| 確認すること | 内容 |
|---|---|
| ① 受験の要件 | **実務の経験の年数と内容** |
| ② 行政での実務の扱い | 要件に算入されるか |
| ③ 応募したい求人の条件 | 必須か、歓迎か |
| ④ 期限 | 応募の時期までに間に合うか |
| ⑤ 取得の支援 | 会社の制度の有無 |

**①と②が要**です。

**受験の要件は、実務の経験の年数と内容で定められていることがあります。**

**行政での実務が要件に算入されるかは、所管するところの公表を確認**してください。

**人づての情報で判断しないでください。**

**なお、資格を取れば転職できる、という関係にはありません。**

**要件として挙げられている場合に、条件を満たす材料になる**というものです。

## 書き方の例

**悪い例**

> 総務課で、職員の健康管理を担当しました。

**良い例**

> ◯◯課において、**職員約◯名を対象とする健診の運用**を担当。受診の勧奨から結果の管理、**面談の手配までの手順を整備。****安全衛生に関する会議（委員◯名）の事務を担い、指摘事項を担当課へ連絡し、改善の状況を記録。**公務災害の事務では、**発生の経緯を整理し、再発の防止の手順を作成。**

**「対象の人数」「運用」「会議の事務」「再発の防止」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 対象の規模 | **職員の人数、施設の数** |
| 健診の運用 | 勧奨、管理、面談 |
| 会議の運営 | 頻度、議題、記録 |
| 事故・不調への対応 | 3件、経緯と処置 |
| 記録の整備 | 何を、どう残したか |

**4行目です。**

**なお、特定の職員が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

## よくある失敗

**1. 資格だけを書く**

**実務の経験**と併せて書いてください。

**2. 受験の要件を人づてで判断する**

**所管の公表**を確認してください。

**3. 必須か歓迎かを見ない**

**扱いが違います。**

**4. 会議の事務を書かない**

**委員会の運営**として読まれます。

**5. 公務災害の事務を書かない**

**原因の整理と再発の防止**にあたります。

**6. 対象の規模を書かない**

**人数と施設の数**を書いてください。

**7. 取得の支援の有無を確認しない**

**入社後に取れる**場合があります。

**8. 取れば転職できると考える**

**要件を満たす材料の1つ**です。

:::insight
ここまで資格の話をしておいて逆のことを言いますが、**資格がなくても、総務・人事の求人には応募できます。**面談で拝見していると、**「資格がないので、この分野は無理だ」と考える方**がいらっしゃいます。ところが、**応募条件を読むと、「必須」ではなく「歓迎」と書かれている求人が多い**ものです。そして、**総務や人事で実際に求められているのは、制度の運用と記録の正確さ**です。給与、勤怠、社会保険、採用、教育、規程。**これらは、行政の人事・給与の事務で扱ってきた内容と重なります。**しかも、**行政では、法令と条例に沿って運用してきた**ため、根拠を確認する習慣があります。**この習慣が、労務の分野では効きます。**ですから、**資格は「あれば候補が広がるもの」と位置づけ、まずは実務の経験で応募できる求人を探してください。**そのうえで、**入社後の取得**という順序もあります。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **労働安全衛生法第12条第1項**は、**政令で定める規模の事業場ごとに衛生管理者を選任し、衛生に係る技術的事項を管理させなければならない**としています
- **資格の需要が、法律の条文から生じている**という点が、他の資格と違います
- 接続するのは、**職員の健康の管理、安全衛生に関する会議の事務、施設の管理、公務災害の事務、研修、規程の整備**です
- **会議の事務が、最も直接に接続**します
- **受験の要件と、行政での実務の扱いは、所管の公表を確認**してください
- **資格の欄に資格を、職務の欄に安全衛生の事務の経験**を書いてください
- **資格がなくても、総務・人事の求人には応募できます**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 行政での実務は、受験の要件に算入されますか

**所管するところの公表を確認してください。**受験の要件は、**実務の経験の年数と内容**で定められていることがあります。どの職務が該当するかは、**公表されている案内で確認**するのが確実です。**人づての情報や、以前の記憶で判断しないでください。**要件は改められることがあります。なお、**在職中に要件を満たしているなら、在職中に受けるほうが負担が小さい**ことがあります。**証明の書類が必要になる場合、所属での手続が要る**こともあります。**時期と手続を、早めに確認**してください。

### 資格を持っていると、どの程度有利ですか

**求人票の書き方によります。**「必須」であれば、**資格があることが選考の前提**です。「歓迎」であれば、**満たしていなくても応募できます。**なお、**選任が義務づけられている資格**は、**事業場ごとに必要な人数が決まる**ため、**求人の側に事情がある**ことがあります。この場合、**資格と実務の両方を持つ人が絞られます。**ただし、**資格だけでは判断されません。**総務や人事の実務の経験と併せて書いてください。読み方は[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。

### 総務・人事の経験を、どう書けばよいですか

**対象の規模と、運用した制度で書いてください。**「職員約◯名を対象とする給与の事務を担当」「人事評価の運用を担当し、面談の手順と様式を整備」という形です。**行政では、法令と条例に沿って運用してきた**という点も書けます。「条例と規則に基づき、◯◯の手続を運用。改正に伴い、要綱と様式を改正」。**根拠を確認する習慣**が伝わります。なお、**給与や社会保険の事務は、民間でも同じ動作**です。扱いは[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)に整理しています。
