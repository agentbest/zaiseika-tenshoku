障害年金の確認では、退職日より先に、原因となった病気やけがの初診日と、その日の年金加入制度を整理します。公務員を退職した後の請求でも、在職中の初診日が関係する場合があります。現在の勤務先だけで相談先を決めないことが大切です。

本記事は2026年11月時点の公開情報にもとづきます。公務員期間がある方の制度と準備を一般的に説明します。受給権や等級の判定は共済組合・年金事務所等が行い、治療や就労の医学的判断は主治医に相談してください。

## 障害を事由とする制度を分ける

障害基礎年金は国民年金法、障害厚生年金は厚生年金保険法に基づく給付です。厚生年金の加入期間に初診日がある人は、障害厚生年金の対象となるかを確認します。要件に該当する一級・二級の方には、障害基礎年金も関係します。

公務員期間には、一元化前の経過的職域部分や、公務障害年金という別の給付もあります。病休中の給与、共済の傷病手当金、公務災害補償も、それぞれ根拠と目的が違います。

| 制度・手続き | 最初に確認する点 |
| --- | --- |
| 障害基礎年金 | 初診日の加入状況、納付等と障害の要件 |
| 障害厚生年金 | 厚生年金加入中の初診日、認定日等 |
| 経過的職域部分 | 一元化前の共済期間に初診日があるか |
| 公務障害年金 | 公務による傷病、組合員資格等の要件 |
| 傷病手当金 | 勤務不能、給与、年金との調整 |
| 公務災害補償 | 災害認定と補償制度の対象 |

障害者手帳を持っていることだけで年金の等級や支給が決まるものではありません。年金には独自の基準と必要資料があります。病名から本人が等級を当てはめたり、手帳がないから相談できないと決めたりせず、制度の窓口で確認します。

## 初診日は最後に受診した日や休職日ではない

厚生年金保険法第47条は、原因となる傷病について初めて医師・歯科医師の診療を受けた日を初診日とし、その日の被保険者資格などを要件にしています。休職発令の日、診断書を勤務先へ出した日、専門病院へ紹介された日と、必ず一致するわけではありません。

たとえば、共済の一般組合員であった期間に初診日があり、退職後も治療を続ける仮例では、請求時に民間勤務や国民年金加入となっていても、当初の加入制度が確認の軸になります。一方、退職後に新たな傷病の初診日がある場合は、その日の制度が関係します。

過去の受診が今回の障害の原因となった傷病の初診に当たるかは、本人の記憶だけで決めません。診療の経過を整理し、医療機関の記録と請求先の案内で確認します。病院名や病名が途中で変わった場合も、関係する情報を窓口に伝えてください。

短期組合員であることと、共済が実施する厚生年金の対象であることも別です。健康保険の資格だけから年金の請求先を決めず、初診日にどの厚生年金へ加入していたかを確認します。

## 納付要件と障害認定日を確認する

障害厚生年金には、初診日、障害の状態、保険料納付という要件があります。日本年金機構は、初診日の前日に、初診月の前々月までの被保険者期間について、納付済みと免除の期間を合わせて三分の二以上とする原則を説明しています。共済や民間の厚生年金期間だけでなく、過去の国民年金の期間も確認の対象になります。

また、初診日が2036年3月末までで、初診日に65歳未満の場合には、直近一年の未納がないことによる特例があります。初診日後に納めたから必ず要件を満たす、という判断はしません。未納・免除・学生納付特例等の記録と、判定の対象月を窓口へ確認してください。

障害認定日は原則として初診日から一年六か月を経過した日で、それ以前に傷病が治った場合等の例外があります。厚生年金保険法第47条と国民年金法第30条に、それぞれ認定日や障害の要件が置かれています。例外に該当するかを本人が医学的に判断するのではなく、医師と請求先へ資料を示します。

:::insight
申請準備では、病気の経過と勤務の経過を別の列に並べることを勧めます。初めて受診した時期、転院、休暇、休職、退職が一つの文章に混ざると、初診日にどの制度へ加入していたかが見えにくくなります。年月が曖昧な部分は推測して確定させず、確認が必要と書いたまま窓口へ相談できます。資料を作る目的は、本人が等級を予測することではなく、担当が必要な証明を案内できる状態にすることです。治療を優先し、負担が大きければ準備を分けて進めても構いません。仕事を続けるか退職するかの結論を、書類整理と同時に出す必要もありません。制度の相談と医学的な相談を分けると、次に尋ねる事項が明確になります。
:::

## 認定日請求と事後重症では開始時期が違う

障害認定日に要件に該当する場合は、認定日による請求を確認します。日本年金機構は、認定日の翌月分からの支給と、遡って受けられる分に時効の限度があることを説明しています。昔の受診記録を集めれば期間にかかわらず全額を受け取れる、とは考えません。

認定日には要件を満たさず、その後重くなった場合には、事後重症による請求があります。厚生年金保険法第47条の2、国民年金法第30条の2に関係する制度です。機構案内では請求日の翌月分からの支給となり、請求書は65歳の誕生日の前々日までに提出する必要があります。

どちらの請求に当たるかで診断書の対象時点や必要な証明も変わります。現在の状態の診断書だけで過去の認定日も証明できると決めず、先に請求先の案内を受けます。老齢年金の繰上げを請求済みの場合など、他の年金があることも相談時に伝えてください。

## 共済期間の請求は初診日の実施機関へ相談

公立学校共済組合兵庫支部は、一般組合員期間に初診日がある場合、現職・退職を問わず支部へ相談するよう案内しています。国家公務員共済組合連合会も、初診日の種別の実施機関へ障害厚生年金を請求し、他の実施機関へは提出できない点を示しています。老齢年金と同じ窓口の扱いと考えないでください。

地方職員共済組合の請求案内には、請求書、診断書、病歴・就労状況申立書、受診状況等証明書が示されています。本人の必要資料、窓口、本部・支部の区分は、所属していた共済へ確認します。

| 相談前のメモ | 確認する内容 |
| --- | --- |
| 初診時の勤務先と年金制度 | 担当する実施機関 |
| 医療機関と受診の順序 | 初診日証明、転院時の資料 |
| 現在と認定日時点の状態 | 必要な診断書の様式と対象日 |
| 休暇・休職・就労の経過 | 申立書の記載事項 |
| 受給中・請求中の給付 | 年金と傷病手当金等の調整 |

初診の医療機関が廃止されている、記録が残っていない等の事情も、その時点で請求できないと決めず窓口へ伝えます。代わる資料の可否と確認方法を尋ねてください。診断書は医師に作成を依頼し、申立書では実際の生活や就労状況を事実に沿って記載します。

相談や提出を家族等に手伝ってもらう場合は、委任状や本人確認の方法を受付先へ尋ねます。病歴のメモや診断書には機微な情報が含まれるため、送付先が正式な窓口かを確かめ、指定された経路で扱ってください。勤務先に提出した診断書と年金用の診断書は、目的や様式が同じとは限りません。手元にある書類だけで代用できると考えず、必要なものを担当から確認します。

受給の決定後も、指定された診断書等の提出、住所や受取口座の変更、他年金や給付の決定など、必要な届出を確認します。一度の決定で以後の連絡が不要になるとは限りません。通知書の期限と提出先を控え、連絡が届く住所を保つことも大切です。

## 一元化前の職域部分と公務障害年金を区別

公立学校共済組合は、2015年9月以前の組合員期間に初診日がある場合の経過的職域加算額を説明しています。過去に公務員期間があるだけで、退職後の別の傷病へ同じ部分が付くというものではありません。初診日と対象期間を照合します。

公務障害年金は、年金払い退職給付の一つです。地方公務員等共済組合法第97条に、公務による傷病、初診日の資格、障害認定日等の要件があります。公務外の傷病に係る障害厚生年金や、公務災害補償と同じ制度ではありません。認定や併給の関係をそれぞれの担当へ確認します。

傷病手当金との調整にも注意します。同法第68条には、同じ傷病の障害厚生年金等を受けられる場合の調整があります。公立学校共済組合も、給与や年金の額による給付制限を案内しています。年金の決定が遡った場合は、対象月と返還等の有無を短期給付担当へ伝え、両方の全額を見込んで使わないようにします。詳しい期間は[傷病手当金の記事](seido-kyosai-shobyo.html)も参照できます。

:::insight
健康上の事情があるときは、給付の見込みだけで働き方を決めないことを大切にしたいと思います。年金の受給条件と、治療に適した勤務の形は同じ問いではありません。主治医や所属の相談先と負担を確認し、休暇、休職、復職時の調整、現職を続ける案も含めて考えられます。外の仕事の情報が必要になっても、応募の時期を同時に決める必要はありません。未決定の給付を確実な収入として扱わず、分かっている支出と制度の照会事項を分けておくと、判断材料を整えやすくなります。治療や家族の予定を優先し、検討をいったん止めることも選択肢です。相談サービスは、本人が利用したいときに使うものだと考えます。
:::

## よくある質問

### 退職した後でも共済へ障害年金を請求できますか

初診日が共済の対象期間にある場合、退職後でも担当共済への請求となることがあります。現在の加入先だけで決めず、初診日と加入履歴を示して確認します。

### 休職していなければ障害年金の対象外ですか

休職発令があるかだけで判定する制度ではありません。初診日、納付要件、障害の状態等を確認します。働いていることのみで受給可否を一律判断せず、実際の状況を請求先へ伝えてください。

### 傷病手当金と年金を両方全額受けられますか

同じ傷病の年金等には調整が関係します。対象期間や額、遡及決定の有無によって精算が必要な場合があるため、決定通知を共済の短期給付担当へ示してください。

働き方の情報を本人の希望で調べる場合には、[公務員経験に関係する求人](../?gov=1)を閲覧できます。[相談フォーム](../apply.html)や[LINEの案内](https://line.me/R/ti/p/@697nxhbt)も任意です。ご利用は無料です（紹介手数料は採用企業の負担）。医療資料や年金申請書を転職相談へ提出する必要はありません。治療や給付の判断は、それぞれの専門窓口へ相談してください。
