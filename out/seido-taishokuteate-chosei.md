結論から書きます。**退職手当は「基本額＋調整額」で、調整額は、在職中の職の区分ごとに決まった月額を、高い順に60か月分足した額です。**転職による退職（自己都合等）では、勤続年数で次のように減ります（国家公務員退職手当法第6条の4第4項）。

| 自己都合等で辞めたときの勤続年数 | 調整額 |
|---|---|
| 9年以下 | **0円** |
| 10年以上24年以下 | **2分の1** |
| 25年以上 | 全額 |

基本額の支給率は勤続20年で自己都合の減額がなくなりますが、**調整額の減額は24年まで続きます。**境目が違うので、20年を超えたから減額はない、と考えると見落とします。また、基本額には官民均衡のための**調整率（現在は100分の83.7）**が掛かりますが、**調整額には掛かりません。**

この記事では、国の法律の条文で調整額の仕組みを整理します。地方公務員の退職手当は所属自治体の条例で決まります（地方自治法第204条）。国の制度に準じる自治体が多いものの、**区分・額・境目は自分の自治体の条例で確かめてください。**基本額の側は[基本額の計算の考え方](seido-taishokuteate-kihongaku.html)で扱っています。

## 調整額の計算——区分の月額を「高い順に60か月」

第6条の4第1項は、在職した各月に、その月にいた職員の区分に応じた額（調整月額）を付け、**額が多いものから順位を付けて、第1順位から第60順位までを合計する**と定めています。ポイントは3つです。

1. **月ごとに区分の額が付く。**その月にどの区分にいたかで決まります
2. **区分の額は法律に列挙されている。**区分そのものは、職制上の段階や職務の級などを考慮して政令で定めます（第3項）
3. **直近60か月ではなく、高い順に60か月。**在職中でいちばん上の区分にいた月から数えます

国の調整月額と、内閣人事局が示している行政職の級との対応は次のとおりです。

| 区分 | 主な職（行政職俸給表） | 調整月額 |
|---|---|---|
| 第1号 | 指定職（上位） | 95,400円 |
| 第2号 | 指定職（その他） | 78,750円 |
| 第3号 | 10級 | 70,400円 |
| 第4号 | 9級 | 65,000円 |
| 第5号 | 8級 | 59,550円 |
| 第6号 | 7級 | 54,150円 |
| 第7号 | 6級 | 43,350円 |
| 第8号 | 5級 | 32,500円 |
| 第9号 | 4級 | 27,100円 |
| 第10号 | 3級 | 21,700円 |
| 第11号 | その他 | 0円 |

内閣人事局の例では、7級に24か月、6級に36か月いた人の調整額は、54,150円×24＋43,350円×36＝**2,860,200円**です。上の区分に5年（60か月）以上いれば、その60か月だけで調整額が決まります。

## 自己都合退職での減り方

第4項は、調整額を減らす・支給しない場合を定めています。転職に関わるのは、自己都合等退職者の第3号と第4号です。

| 退職の区分 | 勤続期間 | 調整額 |
|---|---|---|
| 自己都合等 | 9年以下 | 0円 |
| 自己都合等 | 10年以上24年以下 | 第1項の額の2分の1 |
| 自己都合等 | 25年以上 | 第1項の額 |
| 自己都合等以外 | 1年以上4年以下 | 第1項の額の2分の1 |
| 自己都合等以外 | 5年以上 | 第1項の額 |

たとえば上の例（2,860,200円）の人が勤続20年で転職すると、調整額は2分の1の1,430,100円です。勤続25年なら全額です。

この表から分かるのは、**勤続24年と25年の間で、調整額が倍になる**ことです。基本額の支給率は勤続年数に応じて少しずつ上がるのに対し、調整額は境目で一気に変わります。退職の時期を考えている方は、自分の勤続期間が24年と25年のどちらに入るかを、月単位で確かめてください。勤続期間の数え方（休職や育児休業の期間の扱い、端数の扱い）は条例で決まっているので、人事の担当課に聞くのが確実です。同じように、勤続9年と10年の間では、ゼロから2分の1に変わります。

## 調整率83.7/100は基本額だけに掛かる

退職手当には、民間の退職給付との均衡を取るための**調整率**があります。国は平成30年1月1日から100分の87を**100分の83.7**に引き下げ、自治体も条例で順次引き下げました（高知県は平成30年2月1日施行）。高知県の公表資料は、計算式を「基本額（退職日の給料月額×退職理由別支給率×調整率）＋退職手当調整額」と示しています。**調整率が掛かるのは基本額で、調整額には掛かりません。**見込みを出すときに、調整額にまで83.7/100を掛けると過小になります。

在職中でも、情報収集だけでも構いません。[相談の申込みはこちら](../apply.html)

:::insight
面談で伺うと、基本額の見込みは自分で出しているのに、調整額を「多少の加算」と思っている方がいます。ところが、6級以上に5年いた方の調整額は、国の額で見ても数百万円の桁です。そして、自己都合等で勤続24年以下ならそれが半分になります。基本額の支給率だけを見て「20年を超えたから減額はない」と考えると、調整額の側を見落とします。逆に、勤続9年以下の方は調整額がゼロなので、基本額だけで見込みを立てて構いません。**まず、自分が9年以下・10〜24年・25年以上のどこにいるかを確かめてください。**それだけで見込みの精度が一段上がります。
:::

## 自分の調整額を見積もる手順

退職の意思を伝えなくても、次の手順で桁は分かります。

1. 自治体の退職手当条例と規則で、調整額の条と区分の別表を読む（国の第6条の4に当たる部分）
2. 自分の職務の級の履歴を、月単位で書き出す
3. 級を区分に当てはめて月額を付け、高い順に60か月分を合計する
4. 自己都合等で勤続24年以下なら2分の1、9年以下ならゼロにする

人事の担当課に見込みを聞くときは、「調整額は何号区分で何か月分か」まで聞くと、答えの中身が分かります。基本額と調整額を分けて聞いておけば、退職の時期を動かしたときにどちらがどう変わるかも、自分で見当を付けられます。条例の読み方は[退職手当条例の読み方](seido-taishokuteate-jorei.html)に整理しています。

## 誤解されやすい点

**「調整額は管理職だけ」**：国の形では3級（第10号）から額が付きます。0円は第11号だけです。

**「直近5年分」**：高い順に60か月です。降任して直近の区分が下がっても、過去の上の区分の月が先に数えられます。

**「20年を超えれば減額はない」**：基本額はそうですが、調整額は自己都合等で24年以下なら2分の1です。

**「国の額がそのまま当てはまる」**：上の表は国の法律です。自治体の条例で区分と額を確かめてください。

:::insight
ここまで書いておいて逆のことを言いますが、調整額が半分になる勤続24年以下の方に、「25年まで待つべきだ」とは申し上げていません。待てば増える額は条文で計算できますが、その数年の間に、自分の経験に値を付けてくれる求人が同じ条件で残っているかは分からないからです。役職に就いて予算や人を動かしてきた経験は、民間の求人票では「予算管理」「組織マネジメント」という言葉で読まれ、年齢とともに値の付き方が変わります。待つ判断にも理はあります。大事なのは、調整額の見込みと、いま動いた場合の行き先の見込みを同じ紙に並べることです。片方だけを詰めても比較になりません。
:::

## まとめ

- 調整額は、在職した各月に区分ごとの月額を付け、**高い順に60か月分**を足した額です（第6条の4第1項）
- 国の月額は第1号95,400円から第10号（行政職3級）21,700円、第11号は0円です
- 自己都合等では、**勤続9年以下でゼロ、10年以上24年以下で2分の1**、25年以上で全額です（第4項）
- 調整率100分の83.7は**基本額にだけ**掛かり、調整額には掛かりません
- 地方公務員は条例で決まるので、区分・額・境目は自分の自治体の条例で確かめてください

本記事は2026年10月時点の公開情報にもとづきます。

## よくある質問

### 係長になって3年です。調整額はどのくらい積み上がっていますか

国の形で言えば、高い順に60か月分です。係長に当たる区分の36か月と、その前の区分の24か月を足した額が、第1項の額になります。そのうえで、自己都合等で勤続24年以下なら2分の1、9年以下ならゼロです。係長がどの級・どの区分に当たるかは自治体の俸給表と条例の別表で決まるので、人事の担当課に、制度の照会として「自分の級は何号区分か」を聞くのが確実です。

### 一度課長になって、その後に係長に戻りました。調整額はどうなりますか

高い順に順位を付けるので、課長に当たる区分の月が先に数えられます。直近が係長でも、過去の課長の月が60か月の中に入るので、調整額の側で降任が不利になる形にはなっていません。一方、基本額は退職日の俸給月額が基準なので、降任で俸給月額が下がった場合は、減額前の俸給月額を基礎にする特例（第5条の2）が関わります。調整額と基本額で扱いが違う点に注意してください。

### 自治体の条例に「調整額」という言葉がありません

その自治体では調整額の仕組みを採っていないか、別の名前で職の区分を反映しているかのどちらかです。条例の目次で、職務の級に応じた加算の条があるかを確かめてください。無ければ、見込みは基本額だけで立てれば足ります。あれば、別表の区分と額を国の形と比べてください。基本額に掛かる調整率が83.7/100かどうかも、同じ条例の附則で確かめられます。

### 定年や勧奨で辞める場合と、転職で辞める場合で、調整額はどれだけ違いますか

国の法律では、自己都合等以外の退職で勤続5年以上なら、調整額は第1項の額の全額です。自己都合等の退職では、勤続9年以下でゼロ、10年以上24年以下で2分の1です。たとえば第1項の額が280万円の人が勤続15年で辞める場合、自己都合等なら140万円、自己都合等以外なら280万円で、差は140万円になります。勤続25年以上になると、どちらの辞め方でも全額です。どの退職がどちらに当たるかは、自治体の条例の定義で決まるので、自分の辞め方がどちらになるかを人事の担当課に確かめてください。
