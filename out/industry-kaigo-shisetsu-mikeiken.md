介護施設の運営会社を未経験から検討するときは、会社名より先に職務を確認します。事務職の経験不問と、介護の資格が必須の募集は別です。公務の窓口対応や資料確認を説明しながら、直接の介助や専門判断を行った経験にはしないようにします。

本記事は2026年11月時点の公開情報にもとづきます。確認日は2026年11月25日です。SOMPOケアの公式個別求人を使い、確認方法を示します。未経験ならどの仕事にも応募できるという意味や、採用・登用の保証ではありません。

## 運営会社への入社と、担当する専門職を分ける

介護施設の運営会社には、直接のケア、看護、相談・支援、施設内の事務、本社の管理等、異なる職務の募集があります。同じ会社の仕事でも、求める資格、経験、勤務、契約は職務ごとに確認します。会社の事業全体を一つの担当へまとめないようにします。

SOMPOケアのキャリア採用サイトも、仕事や施設を分けて求人を案内しています。今回確認したのは、流山おおたかの森の事務員パートと、横須賀の介護福祉士正社員の募集です。別施設・別職務の条件を一組にしません。

公務で介護に関わる制度や施設を所管したことと、運営会社の現場で働いたことも別です。制度案内、資料照合、照会、専門判断、実際の介助や記録等の工程を分けてください。自治体の職員としての任用と会社の採用も区別します。

施設名、会社、本人の雇用主、勤務場所を確認します。公的な制度に関わる施設であることだけで、自治体の給与や勤務が続くとは考えません。正式な募集職名と契約形態を対応させて読みます。

[行政に接点のある掲載求人を調べる](../?gov=1)際も、制度との接点と、本人が担当する現場の工程を別に比較できます。

## 事務経験不問でも、必要な操作と勤務の条件は残る

ラヴィーレ流山おおたかの森の事務員パートは、事務職経験不問とし、介護業界や事務が未経験の人も歓迎する説明です。一方で、ExcelやWordの基本操作ができること、土日を含めたシフト勤務ができることを応募条件にしています。

未経験歓迎という表記から、この二つの条件を消さないようにします。経験を問わないことと、操作や勤務への条件がないことは別です。本人のPC利用と勤務の制約を、項目別に照合してください。

仕事内容は、ソフトを利用する経理の入力、来訪者受付、電話応対、スタッフのサポート等です。経理の経験がない場合も教える説明がありますが、民間の決算や税務をすべて担う職務として広げません。具体的な入力と確認の範囲を質問できます。

公務で表へ入力し、資料を照合し、電話で必要事項を確認した経験は、その工程として説明できます。ただし、求人先のソフトをすでに利用できることや、施設の経理全体を経験したことにはしません。新たに学ぶ操作を分けて残します。

本人が土日の勤務を難しいと考えているなら、その条件を先に整理できます。仕事内容への関心があっても、必須の勤務が合うかは別です。希望を伝えたことだけで例外が認められた扱いにせず、対象の窓口へ確認します。

## 介護福祉士の資格必須を、経験歓迎と混ぜない

ラヴィーレ横須賀の確認した正社員募集は、介護福祉士の資格を持つことが応募条件です。介護施設での経験は、あればなお歓迎という記載です。経験が歓迎であることから、資格も不要と読み替えないようにします。

本人が資格を持たない場合は、この求人を無資格の入口として紹介しません。資格を学習中、取得予定、合格済み、保有済みで分け、取得していないものを取得済みとして記入しないでください。個別募集の条件へ照合します。

同募集は、起床、食事、入浴や着替え、排泄、移動の援助、レクリエーション、記録等の仕事を挙げています。公務で住民へ制度を案内した経験を、直接の介助を行った経験として数えません。本人の行動と未経験を分けます。

正社員や介護職への関心と、今回の資格条件がそろうことも別です。別職務を探す場合も公式の現行募集を確認し、資格取得や事務職への入社を経れば必ず介護職へ異動できるという未確認の道筋を作らないようにします。

一つの職務で経験不問の記載があることから、会社のすべての専門職で同じ条件と考えません。事務パートの応募条件と、介護福祉士正社員の資格・勤務をそれぞれ記録すると、混同を防げます。

:::insight
未経験という言葉は、何の業務について書かれているかを分けて読むことを勧めます。事務経験不問でもPC操作と勤務条件があり、介護施設の経験が歓迎でも資格が必須の求人があります。本人の確認や電話対応を具体的に示しながら、直接の介助や専門判断を経験したことにしません。未経験の工程を残すことは、公務の経験を低く扱うことではありません。本人の作業、他者の権限、必要な資格を別にして募集へ照合できます。学習中を保有済みにせず、条件の対象が不明な点は正式な職名を添えた質問に残す方法を使えます。会社名だけで共通条件を作らないことが出発点です。
:::

## 公務の経験を、確認と引継ぎの工程で説明する

窓口で相談を受けた場合、本人が何を聞き、どの根拠や必要事項を確かめ、何を説明し、誰へ引き継いだかを整理できます。相手の個人情報を開示せず、一般化した担当工程で説明します。

資料の不一致を確認したことと、専門的な結論を自分で判断したことは別です。上司や専門部署が決裁・判断を行ったなら、その分担を残してください。組織全体で行った支援やサービスを、一人の実績へ広げないようにします。

相手へ説明する工夫を記す場合も、相手の心情や満足を確認した事実がなければ作りません。どの情報を確かめ、説明の順序をどう整理したか等、本人の行動を根拠にできます。

改善は、提案、採用、実施、効果確認を段階別にします。本人が測っていない時間や費用の削減率、未確認の成果を追加しません。資料の対象期間や未回答事項を整理したことを、その範囲で説明できます。

## 独立した架空の整理例で、未経験と希望を残す

以下は経験整理のための独立した架空例です。実在の応募者、面接の回答、採用結果ではありません。本人が使う場合は事実に置き換え、未実施の行動や持っていない経験・資格は削除してください。

| 項目 | 架空の記入内容 |
|---|---|
| 本人の担当 | 自治体で福祉制度の案内と資料照合 |
| 実施した工程 | 必要事項を確認し、未回答の質問を担当部署へ引き継いだ |
| PCの経験 | 本人が行った表への入力と資料作成 |
| 他者の権限 | 専門判断や最終の決裁は担当部署・上司 |
| 未経験 | 直接の介助、施設の経理ソフト、介護事業所での事務 |
| 資格 | 介護福祉士は保有していない |
| 募集との照合 | 事務のPCと土日シフトを確認。資格必須の介護職へ適合とは記入しない |
| 未確認 | 初期担当、具体的なシフト、契約更新の本人への適用 |
| 次の行動 | 正式職名と施設名を添え、要件と役割を質問する |
| 現職の比較 | 現在の説明や根拠確認を深める選択も残す |

この例では、介護の制度を担当したことを資格や介助の実務へ変えていません。資格を持たないことから、別職務の事務まで同じ条件と考えることも避けています。どの求人を、どの条件で検討するかを分けるための表です。

本人に民間の事務や介護等の前職がある場合は、公務の在籍とは別に勤務先、期間、作業を記入できます。在籍の全期間と特定の業務の期間を区別し、見学や学習を実務として加えないようにします。

[担当工程と応募する職務を整理する](../apply.html)場合も、内部資料を持ち出さず本人の言葉で説明できます。ご利用は無料です（紹介手数料は採用企業の負担）。経験や希望によっては、面談・求人紹介を提供できない場合があります。

## 契約期間と勤務を、職務ごとに確認する

確認した事務パートは毎年3月末までの有期雇用で、勤務実績や業務量等を考慮する原則更新、更新上限なしと記載されています。上限がないことと、本人が必ず継続できることは別です。期間の定めのない正社員の募集として扱いません。

同事務募集は試用期間なしで、週3～4日、土日を含むシフトとされています。勤務の時間帯や具体的な日程の本人への適用を確認します。土日を含む条件を省いて、平日のみの事務職として紹介しないようにします。

一方、横須賀の介護福祉士募集は正社員・試用6か月同条件で、夜間を含む勤務時間を示しています。事務パートの勤務を移さず、本人の資格と希望する働き方の両方を確認してください。

介護職の公開給与例には、夜勤や日祝等の手当の前提もあります。本人の勤務回数や給与額をその例で固定せず、公開構成と正式提示を分けます。事務パートと正社員の給与制度を混ぜないことも必要です。

同じ会社でも施設や業務、契約が違えば比較する項目は変わります。初期担当、業務の範囲、確認する相手、勤務場所と変更範囲等を職務別に質問できます。希望した内容を配属確約のように扱わないでください。

## 正式な選考案内と、本人の準備を区別する

事務パートの確認した募集は、面接の設定、面接1～2回、結果通知の流れを示しています。介護福祉士の募集には適性検査や、場合により書類選考からになる説明もあります。別職務の手順を一つへまとめないようにします。

公開情報にない設問、採点、面接官の心理を作りません。本人の課題、行動、分担、確認できた結果、未経験を整理できます。結果通知等の目安も、本人への確約とせず正式な連絡で確認してください。

書類の作成、本人の事実確認、送信、案内の受領は別の段階です。提出先と対象の施設・職務、必要物を確認し、求められていない情報を追加して送りません。質問した事項を回答済みとみなさないようにします。

募集が更新された場合は、正式な施設名・職名と確認日を残して読み直します。保存した古い情報や同じ会社の別求人を、現在の応募先へ移さないようにします。違いがある項目は窓口へ質問できます。

## 情報を守り、現職継続も同じ条件で比べる

住民や相談者、利用者、事業者の個人情報、非公開の審査、契約、事業計画、調達等を持ち出しません。名称を削れば使えるとも判断せず、内部資料を私用AIへ入力しないようにします。公開情報と一般化した本人の工程で準備します。

行政上の便宜や内部人脈を、営業や事業獲得のために提供する約束もしません。本人の確認や説明の経験を話すことと、現職の立場や権限、連絡先を私的に使うことを分けます。

本人の希望は必須と調整できる内容に分けられます。通勤、勤務日、時間帯、契約形態等を整理し、未回答を了承済みとして住居や退職の確定予定へ入れません。仕事内容への関心と生活の条件がそろうことは別です。

現職で福祉制度の説明や根拠確認を深める判断も比較できます。運営会社へ移る場合も、事務か直接のケアか、本人がどの工程を担いたいかを確かめます。未経験の募集があることだけで、退職を先に決める必要はありません。

[掲載中の求人を比べる](../)際も、現職を含め、役割と本人の必須条件を同じ表へ並べられます。

:::insight
介護に関わる仕事でも、行政の説明、施設内の事務、直接のケアでは本人の工程が変わります。何を担いたいかを先に分ける方法を勧めます。現職で根拠確認や説明を深められるなら、残る判断も同じように比較できます。会社の現場へ移りたい場合は、必要な資格や操作、初期担当、勤務と契約を確認できます。公務経験を低く扱う必要はなく、行っていない介助や専門判断を加える必要もありません。応募や登録だけで退職を先に決めず、本人への正式な説明と条件がそろった段階で考えられます。未確認を保留にすることも、生活条件を守って判断するための方法です。
:::

## まとめとよくある質問

未経験の確認は会社全体ではなく職務ごとに行います。事務経験不問、必要操作、専門資格、勤務と契約を分け、公務の工程と照合してください。

### 事務経験不問ならPCが使えなくても条件は同じですか

別の条件です。紹介した事務パートは基本PC操作と土日を含むシフト勤務を応募条件としています。本人の事実で確認してください。

### 施設経験が歓迎なら介護福祉士資格も不要ですか

紹介した横須賀の募集は資格が必須です。経験の歓迎と資格条件を分け、無資格の入口として扱わないようにします。

### 原則更新・上限なしなら雇用は保証されますか

同じ意味ではありません。勤務実績や業務量等による判断の記載があり、本人の契約期間と更新の適用を確認してください。
