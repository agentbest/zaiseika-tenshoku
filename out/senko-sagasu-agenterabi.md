**「どこに相談すればよいか分からない」**というご相談を伺います。

**数が多く、違いが見えにくい**ためです。

この記事では、**選ぶときの観点**と、**合わないときの切り替え方**を扱います。

## 許可を受けて行う事業です

**職業安定法第30条第1項**です。

> **有料の職業紹介事業を行おうとする者は、厚生労働大臣の許可を受けなければならない。**

**許可制**です。

**同条第2項**は、**申請書に記載する事項**として、**事業所の名称と所在地**、**職業紹介責任者の氏名**などを挙げています。

**つまり、事業所ごとに責任者が置かれる仕組み**になっています。

**許可を受けた事業者には、許可番号が付されます。**

**当社も許可を受けて事業を行っています（有料職業紹介事業　13-ユ-316964）。**

**許可番号が明示されているかは、最初に確認できる点**です。

## 実績の情報が提供されます

**職業安定法第32条の16第3項**です。

> 有料職業紹介事業者は、厚生労働省令で定めるところにより、**当該有料職業紹介事業者の紹介により就職した者の数**、当該有料職業紹介事業者の紹介により就職した者（期間の定めのない労働契約を締結した者に限る。）のうち**離職した者**（略）**の数**、**手数料に関する事項**その他厚生労働省令で定める事項に関し**情報の提供を行わなければならない。**

**就職した人の数、離職した人の数、手数料に関する事項**が、**情報提供の対象**とされています。

**紹介した後に離職した人の数まで含まれている**点が特徴です。

**選ぶときの材料として使える情報が、制度として用意されている**ということです。

## 選ぶときの観点

| 観点 | 見るところ |
|---|---|
| ① 扱う領域 | **行政が相手の求人をどの程度扱っているか** |
| ② 許可の明示 | 許可番号が示されているか |
| ③ 確認の正確さ | 照会した内容に、事実で答えるか |
| ④ 日程の配慮 | 在職中の事情に対応するか |
| ⑤ 情報の出し方 | **できないことを、できないと言うか** |
| ⑥ 求人の示し方 | 条件に合う理由を説明するか |

**①が、公務員からの転職では効きます。**

**扱う領域が違えば、紹介される求人も変わります。**

**「公務員からの転職を扱った実績はありますか」**という聞き方で確認して差し支えありません。

**⑤が分かれ目**です。

**採用の可否は企業が決めます。**

**「必ず決まる」「確実に通る」という説明があれば、内容を確認**してください。

## 最初の面談で見えること

| 場面 | 見えること |
|---|---|
| 経歴の聞き方 | 役所の仕事の中身を理解しようとするか |
| 条件の聞き方 | 譲れない条件を確認するか |
| 求人の示し方 | **なぜこの求人かを説明するか** |
| 時期の扱い | 急かすか、待てるか |
| 質問への答え | 分からないことを調べると言うか |

**3つ目が要**です。

**条件に合う理由の説明がないまま求人が並ぶ場合、条件が伝わっていない**ことがあります。

**この場合、条件を言い直してみてください。**

**それでも変わらなければ、切り替えを検討して差し支えありません。**

:::insight
選び方について、**面談でお伝えしているのが「1回目で判断しないでください」**という点です。最初の面談は、**こちらが経験と条件を把握する場**でもあります。**この段階で示せる求人は、条件の理解が粗い状態で選んだもの**です。ですから、**1回目に示された求人が合わないこと自体は、判断の材料になりません。**見るべきは、**2回目にどう変わるか**です。条件を言い直した後、**紹介の範囲が変わるかどうか。**変われば、条件が伝わっています。**変わらなければ、扱っている領域と合っていない**可能性があります。公務員からの転職では、**行政が相手の事業を扱っているかどうか**で、示せる求人が大きく変わります。**1か所で完結させる必要はありません。**複数を使って、**条件の伝わり方を比べて**ください。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 合わないときのサイン

| サイン | 内容 |
|---|---|
| 条件と違う求人が続く | 条件が伝わっていない |
| 応募を急かされる | 判断の時間が取れない |
| 質問に答えが返らない | 確認が行われていない |
| 連絡の方法の希望が通らない | **在職中の配慮がない** |
| 辞退を認めない | 判断は本人のものです |

**2つ目と5つ目**です。

**応募するかは本人の判断**です。

**急かされる状況で決めると、選考の途中で辞退することになります。**

**4つ目について。**

**勤務時間中の連絡を避けたい旨を伝えたのに変わらない場合、在職中の進行が難しくなります。**

## 切り替えるときの手順

| 順 | やること |
|---|---|
| 1 | **応募中の案件を確認する** |
| 2 | 進行中の選考をどうするか決める |
| 3 | 新しいところに、応募済みの会社を伝える |
| 4 | 重複しないよう経路を分ける |
| 5 | 辞退する場合は連絡する |

**1が最初**です。

**応募中の案件がある場合、途中で経路を変えると混乱します。**

**進行中のものは、そのまま進める**ほうが整理しやすくなります。

**3について。**

**新しいところには、既に応募した会社名を伝えてください。**

**同じ会社に複数の経路から応募が届くと、選考が進めにくくなる**ことがあります。

[経験の言い換えから相談する](../apply.html)こともできます。

## 複数を使う場合

| 項目 | やること |
|---|---|
| 応募先の記録 | 会社名、日付、経路 |
| 経路の固定 | 1社につき1経路 |
| 連絡の管理 | 対応できる範囲にとどめる |
| 条件の統一 | 伝える条件を揃える |

**4つ目です。**

**伝える条件が場所によって違うと、比べられません。**

**同じ条件を伝えて、示される求人の違いを見る**ほうが、判断しやすくなります。

**なお、数を増やすほど、在職中の対応が負担になります。**

**2か所から3か所**を目安にしてください。

## 最初に伝えておくこと

| 項目 | 内容 |
|---|---|
| 在職中であること | 日程と連絡の配慮に関わります |
| 連絡できる時間帯 | 勤務時間中を避けるか |
| 連絡の方法 | 電話かメールか |
| 進めている他の経路 | 重複を避けるため |
| 判断の時期 | いつ頃までに決めたいか |

**4つ目を伝えておいてください。**

**他に進めている経路があること自体は、伝えて差し支えありません。**

**伝えておくと、同じ求人が重複して示されることを避けられます。**

**5つ目について。**

**時期を伝えておくと、紹介の進め方が変わります。**

**「半年かけて見たい」と「3か月以内に決めたい」では、示される求人の範囲が変わります。**

**急いでいない場合、その旨を伝えて差し支えありません。**

## よくある失敗

**1. 1回目の紹介で判断する**

**2回目の変化を見て**ください。

**2. 条件を伝え直さない**

**伝わっていないだけの場合があります。**

**3. 応募中に経路を変える**

**混乱します。進行中のものは進めてください。**

**4. 応募済みの会社を伝えない**

**重複します。**

**5. 数を増やしすぎる**

**在職中の対応が負担になります。**

**6. 急かされたまま応募する**

**途中で辞退することになります。**

**7. 辞退の連絡をしない**

**次の選考に影響することがあります。**

:::insight
ここまで選び方の話をしておいて逆のことを言いますが、**合う先を探すこと自体が目的になると、進みません。**面談で拝見していると、**複数に登録して、面談を重ねるうちに時間が過ぎてしまう方**がいらっしゃいます。**登録と面談は準備であって、選考ではありません。**そして、**どこを使っても、判断するのは本人です。**条件を決めるのも、応募を決めるのも、辞退を決めるのも変わりません。**任せられるのは、確認と調整の部分**です。ですから、**選ぶ基準は「条件が伝わるか」と「確認してもらえるか」の2点**で足ります。この2点が満たされていれば、**そこで進めて差し支えありません。**そして、**進めながら合わないと分かれば、その時点で切り替えられます。****最初に正解を選ぶ必要はありません。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **職業安定法第30条第1項**により、**有料の職業紹介事業は厚生労働大臣の許可**を受けて行われます。**許可番号の明示**は最初に確認できる点です
- **同法第32条の16第3項**により、**就職した者の数、離職した者の数、手数料に関する事項**の情報提供が義務づけられています
- 選ぶ観点は、**扱う領域、許可の明示、確認の正確さ、日程の配慮、情報の出し方**です
- **「必ず決まる」という説明があれば、内容を確認**してください
- **1回目の紹介で判断せず、条件を言い直した後の変化**を見てください
- 切り替えるときは、**応募中の案件を先に確認**してください
- **2か所から3か所**を目安に、**同じ条件を伝えて比べて**ください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 断りにくいのですが、どう伝えればよいですか

**理由を短く伝えて差し支えありません。**「他で進めることにしました」「条件を見直すため、いったん止めます」で足ります。**詳しい説明は不要**です。なお、**応募中の案件がある場合は、その扱いを先に決めてください。**進行中の選考をそのまま進めるのか、辞退するのか。**この点を伝えないまま連絡を絶つと、企業側にも影響します。**辞退する場合は、**その旨を伝えてください。**連絡は、メールで構いません。**気まずさを理由に連絡しないほうが、後で困ります。**

### 公務員からの転職を扱っているか、どう確かめますか

**直接聞いて差し支えありません。**「公務員からの転職を扱った実績はありますか」「行政が相手の事業の求人はどの程度ありますか」という聞き方です。**答えの具体性で判断**できます。**業種や事業の形（指定管理、業務委託、発注者支援など）を挙げて説明できるか**を見てください。また、**掲載されている求人の中身**でも分かります。「自治体」「官公庁」「公共」「指定管理」といった言葉が出てくる求人がどの程度あるか。**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

### 途中で切り替えると、印象が悪くなりませんか

**選考に影響するものではありません。**応募先の企業が見るのは、**応募者の経験と条件**です。**どの経路から応募したかで判断が変わるものではありません。**ただし、**同じ会社に複数の経路から応募が届くと、選考が進めにくくなる**ことがあります。**切り替える前に、応募済みの会社を整理**してください。また、**進行中の選考は、そのまま進めるほうが整理しやすい**です。**途中で経路を変えると、企業側の窓口も変わります。**切り替えは、**進行中の案件が片付いた段階**で行うほうが、混乱が少なくなります。
