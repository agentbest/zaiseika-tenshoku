産業振興課の経験を、求人票の言葉に直すと**まったく別の名前**になります。

**「産業振興、企業立地、雇用対策に関する業務」**

**この書き方では、民間の採用担当に何も伝わりません。**

実際にやっていたのは、**地域の産業の構造を読み、企業を回り、企業と大学・金融機関・人材をつなぎ、立地と設備の判断材料を揃える**という、**法人向けの関係構築の仕事**です。

**しかも、売るものを持たずに、それをやっています。**

この記事では、**庁内の呼び名を民間の言葉に置き換え、中核スキルを5つの工程に分けて**整理します。

## 支援には、4つの種類があります

最初に、この仕事の範囲を条文で押さえます。**自分がどれをやっていたかを分けるため**です。

中小企業基本法第5条は、基本方針をこう定めています。

**一 中小企業者の経営の革新及び創業の促進並びに創造的な事業活動の促進を図ること。／二 中小企業の経営資源の確保の円滑化を図ること、中小企業に関する取引の適正化を図ること等により、中小企業の経営基盤の強化を図ること。／三 経済的社会的環境の変化に即応し、中小企業の経営の安定を図ること、事業の転換の円滑化を図ること等により、その変化への適応の円滑化を図ること。／四 中小企業に対する資金の供給の円滑化及び中小企業の自己資本の充実を図ること。**

**4つ並んでいますが、中身がまったく違います。**

| 号 | 中身 | 民間でいえば |
|---|---|---|
| 一 | **創業と、事業の革新を促す** | **新規事業の立ち上げ支援・インキュベーション** |
| 二 | **経営資源（人・技術・設備・取引先）の確保** | **人材確保・技術導入・販路開拓の支援** |
| 三 | **環境の変化への適応、事業の転換** | **事業構造の転換の支援** |
| 四 | **資金の供給と、自己資本の充実** | **ファイナンス・融資** |

**産業振興課の中心は、多くの場合、一号と二号**です。

**創業の支援、産学連携、設備投資、人材の確保、販路の開拓。**

**四号（資金）は商工の融資担当が、三号（経営の安定）は相談の窓口が持っていることが多く、部署によって分かれます。**

**書類では、この4つのどれをやっていたかを最初に分けてください。**「産業振興」とだけ書くと、**4つ全部を薄くやっていた人に読まれます。**

**「経営資源の確保——とくに人材と技術の側を担当していた」**と書けば、**範囲が一発で伝わります。**

## 民間での訳語

| 庁内での呼び名 | 民間での呼ばれ方 |
|---|---|
| 企業訪問・実態調査 | **法人向けのヒアリング・アカウント管理** |
| 産学連携の橋渡し | **アライアンス・共同研究のコーディネート** |
| ビジネスマッチング | **商談会の企画運営・パートナー開拓** |
| 企業立地の誘致 | **拠点開発・立地提案** |
| 設備投資の支援 | **法人向けの提案・導入支援** |
| 人材確保・合同説明会 | **採用支援・リクルーティングイベントの運営** |
| インターンシップの推進 | **大学・学校との連携、新卒採用の設計** |
| 創業支援・インキュベーション | **スタートアップ支援・アクセラレーション** |
| 産業の実態調査・統計の整理 | **市場調査・マーケットリサーチ** |
| 販路開拓（展示会の出展支援） | **販売チャネルの開拓支援・展示会の運営** |
| 雇用対策・就労の支援 | **人材サービスの企画** |
| 産業振興の計画づくり | **事業戦略の策定・中期計画の立案** |

**上から3行目までが、いちばん値の付く並び**です。**企業を回り、相手の事情を把握し、つないで価値を出す**——**これは、法人向けの仕事そのものです。**

## 中核スキルを5つの工程に分ける

**この部署の中核は、「売るものを持たずに、企業との関係を作って動かすこと」**です。

**工程1：読む（産業の構造を把握する）**

事業所の数、業種の構成、製造品の出荷額、従業者数、雇用の状況、事業者の年齢。**これを見て、地域の産業がどうなっているかを読みます。**

**この工程に固有の制約があります。****使える統計は、数年前のものしかありません。**調査から公表まで時間がかかるためです。**だから、統計だけを見ていると、現場の感覚と合わなくなります。**とくに、**業況の変化は、統計に出るころには終わっています。**そこで、**企業訪問で補う**ことになります。**「古い数字と、いまの現場の声を突き合わせて判断する」**——これは、**民間の市場調査でも同じことをします。**

**工程2：回る（企業訪問とヒアリング）**

**この工程に固有の制約があります。****訪問しても、こちらが渡せるものが限られています。**補助金の案内と、つなぎ先の紹介。**それだけです。**値引きもできませんし、契約も結べません。

**つまり、売るものがない状態で、相手の時間をもらう**ことになります。**それでも話を聞いてもらうには、こちらが先に情報を持っていく**しかありません。他社の動き、制度の変更、人材の状況、補助の公募の予定。**「会うと何か得られる」という状態を作る。**

**これは、民間の法人営業で最初に求められることと同じ**です。**しかも、売るものがない分、条件は厳しいほうです。**

**工程3：つなぐ（マッチングと産学連携）**

企業と企業、企業と大学、企業と支援機関。**課題を持つ側と、解ける側を引き合わせます。**

**この工程に固有の制約があります。****つないだ後、成果が出るかどうかは当事者次第で、こちらには何も残りません。**しかも、**特定の企業に肩入れできません。**紹介する相手を選ぶときに、**「この会社が優れているから」という理由で絞ることが難しい**という制約があります。

**だから、つなぐ前の条件の整理が、実質的な仕事になります。****何を求めているのか、何なら出せるのか、いつまでに必要か。**ここを整理してから引き合わせないと、**会っただけで終わります。**

**工程4：揃える（人材の確保と雇用）**

合同の説明会、インターンシップ、学校との連携、就労の支援。

**この工程に固有の制約があります。****人材は、市の境界を越えて動きます。**育てても、**別の市の企業に就職します。**それでも続ける理由を、**予算の説明として毎年組み立てる**必要がありました。

**この「範囲の外に流出することを前提に、それでもやる理由を立てる」**という経験は、**民間の採用や人材育成でそのまま必要になります。**育てた人が辞めることを前提に、**それでも育てる理由を経営に説明する**——**同じ構造です。**

**工程5：支える（立地・設備・技術）**

企業立地の奨励、設備投資の支援、技術の相談、公設試験研究機関との連携。

**この工程に固有の制約があります。****立地の判断をするのは、企業の本社です。**こちらが出せる条件（用地、奨励金、インフラ、許認可の見通し）は、**判断材料の一つにしかなりません。**しかも、**他の自治体と並べて比較されます。**

**だから、条件そのものより、「判断材料を漏れなく、早く揃えること」が勝負になります。**用地の情報、インフラの容量、必要な許認可とその期間、使える支援制度。**これを一度に出せるかどうか。**

**これは、民間の提案でいう「相手の意思決定に必要な材料を先回りして揃える」**ことと同じです。

:::insight
この経歴でいちばん多い損は、**「企業訪問をしていました」と書いてしまう**ことです。この一言だと、**挨拶に回っていた人**に読まれます。実際には、**訪問の前に統計と業況を調べ、相手の課題を聞き出し、制度や支援機関につなぎ、その後の状況を追っていた**はずです。書くべきは、**「年間◯社を訪問し、業種別に課題を整理。うち◯件を支援機関・大学・金融機関につなぎ、◯件が制度の活用や共同の取組に進んだ」**という形です。**訪問した社数と、つないだ件数、そのうち進んだ件数。**この3つが並ぶと、**法人向けの関係構築の実務として読まれます。**面談で確認すると、**訪問の記録は残っていることがほとんど**です。ただ、**「つないだ後どうなったか」を追っていない場合がある**ので、**在職中に、その結果まで控えておいてください。**そこまであると、**「関係を作って、動かして、結果を確認できる人」**になります。
:::

## 民間の法人向けの仕事と、どこが同じでどこが違うか

**同じところ**

1. **売るものがなくても、先に情報を持っていく必要がある**
2. **相手の事情を把握してからでないと、提案が刺さらない**
3. **つないで価値を出す。**自分が作らなくても、組み合わせで成果が出ます

**違うところ**

1. **売上が立たない。**動かした結果が、**金額として自分の側に残りません**
2. **どこにも肩入れできない。**特定の企業を有利に扱えません
3. **成果が相手のものになる。**企業が伸びても、記録に残るのは件数だけです
4. **人が出ていっても、止められない。**育てた人材が域外に出ることを、前提にするしかありません

**2番目が、民間に移ってからいちばん変わる部分**です。

民間では、**特定の顧客に深く入り込みます。**時間も情報も、**成果が見込める相手に寄せます。**行政ではできなかったことです。

**この違いは、面接で自分から言っておくと、構造を理解している人として読まれます。**

## 評価が高くなりやすい4つの方向

**1. 自治体を顧客とする企業の事業側**

**産業振興の施策を作る側にいた経験**が、そのまま提案に効きます。**どの部署が、どの時期に、何を検討するか**を知っている人は強いです。

**2. 地域金融機関・信用保証・地域商社**

**企業を回って課題を聞き、支援先につなぐ**——**地域金融の渉外と、ほぼ同じ動き**です。**すでに同じ企業を訪問していた**ことも多く、入ってからが速くなります。

**3. 人材サービス・採用支援**

**合同説明会、インターン、学校との連携**は、この分野でそのまま同じ仕事です。**企業側の採用の事情と、学校側の事情の両方を知っている**人は多くありません。

**4. 産業支援機関・技術系の商社やコンサル**

**企業の課題を聞いて、解ける相手につなぐ**という形が中心の仕事です。**公設試験研究機関や大学との関係**を持っていた経験が効きます。

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## つまずきやすい点

**1. 「産業振興」とだけ書く**

**4つの方針のどれをやっていたか**を分けてください。**人材と技術なのか、資金なのか、創業なのか。**

**2. 「企業訪問」で終える**

**訪問した社数、つないだ件数、進んだ件数**の3つを並べてください。

**3. つないだ後を追っていない**

**在職中に控えておいてください。**ここまであると、評価がまったく変わります。

**4. 統計の整理を、事務作業として扱う**

**市場調査**です。**古い統計と現場の声を突き合わせていた**なら、そう書いてください。

**5. 人材が域外に出ることを、成果が出なかったこととして話す**

**流出を前提に、それでもやる理由を立てていた**——**これは、民間の人材育成と同じ構造**です。

自分の経歴がどう言い換えられるかは、一度話しながら整理したほうが早いことが多いです。[どの経験に値が付くのかから相談できます](../apply.html)。

:::insight
ここまで書いておいて逆のことを言いますが、**この部署の経験は、在職の年数が長いほど値が上がります。**理由は単純で、**企業との関係は、年数でしか作れない**からです。1年目の担当者が訪問しても、聞ける話は限られます。**3年、5年と同じ企業を回っている人には、業況も、人の入れ替わりも、設備の更新の予定も、そのまま話してもらえます。**そして、**この関係は、地域の金融機関や企業に移ったときに、そのまま効きます。**逆に、**異動して数年が経つと、同じ担当者には会えなくなります。**なので、**「いま動くべきか」を考える前に、自分がその地域でどれだけの企業と話せる状態にあるかを見てください。**その関係が厚いなら、**地元の金融機関や企業への転職では、かなり強い立場にあります。**薄いなら、**もう少しこの部署で関係を作ってからでも遅くありません。**在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 中小企業基本法第5条は、**①創業と経営の革新 ②経営資源の確保 ③変化への適応 ④資金の供給**という**4つの基本方針**を定めています
- 産業振興課の中心は、多くの場合**一号と二号**です。**書類では、自分がどれをやっていたかを最初に分けてください**
- 中核スキルは、**①読む ②回る ③つなぐ ④揃える ⑤支える**の5工程に分かれます
- **売るものを持たずに企業との関係を作ってきた**——これは、**法人向けの仕事として、条件はむしろ厳しいほう**です
- 違うのは、**①売上が立たない ②どこにも肩入れできない ③成果が相手のものになる ④人が出ていっても止められない**の4点です
- **「企業訪問をしていました」ではなく、訪問した社数・つないだ件数・進んだ件数**を書いてください

## よくある質問

### 商工観光課との違いは、書類でどう出せばよいですか

**扱っていた支援の種類で分けてください。**商工の担当が中心なら、**補助制度の設計と執行、制度融資、小規模事業者の支援**が前に来ます。産業振興が中心なら、**企業訪問、産学連携、立地、人材の確保**が前に来ます。**自治体によって課の名前と分担が違う**ので、**名前ではなく中身で書くのが確実**です。「産業振興課」と書いても、**民間の採用担当には何を担当していたか分かりません。**冒頭に、**「経営資源の確保——とくに人材・技術・立地の支援を担当」**と1行入れてください。それだけで、**その後の記述の読まれ方が揃います。**

### 企業訪問の中で聞いた話は、面接で使えますか

**個別の企業の話は使えません。**業況、設備の計画、人の状況、取引先。**どれも、こちらの立場だから話してもらえた情報**です。話せるのは、**訪問の設計と、そこから作った整理のほうです。**たとえば、**「年間◯社を、業種と規模で分けて訪問。聞き取りの項目を統一して、業種別の課題を年度ごとに比較できる形にした」**という形です。**個別の内容ではなく、自分が作った仕組み**を話してください。**これは、民間の法人向けの活動管理と同じ**ものとして読まれます。

### 産学連携の担当でしたが、専門知識がないので不安です

**技術そのものの知識は、求められていません。**この仕事で評価されるのは、**「課題を持つ側と、解ける側の言葉を翻訳したこと」**です。企業は自分の課題を技術の言葉で説明できませんし、研究者は自分の技術を事業の言葉で説明できません。**その間に立って、条件（何を求めているか、いつまでに、いくらまで、誰が権利を持つか）を整理した**——**ここが仕事の中身**です。書くなら、**「企業と大学の間で、求める成果・期間・費用・知的財産の扱いを事前に整理したうえで引き合わせ、年間◯件の共同の取組に進んだ」**という形になります。行き先の絞り方は、別の記事に整理します。
