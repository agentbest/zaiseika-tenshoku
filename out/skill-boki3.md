**「まず何か取るなら」**というご相談で、最初に挙がることが多い資格です。

**効く場面と、効かない場面があります。**

この記事では、**その分かれ目**を扱います。

**⚠ 試験の内容・級・実施の方法は、実施する団体の公表を確認してください。****この記事では、個別の内容には触れません。**

## 帳簿の作成は、法律上の義務です

**商法第19条第1項**です。

> **商人の会計は、一般に公正妥当と認められる会計の慣行に従うものとする。**

**同条第2項**です。

> **商人は、その営業のために使用する財産について、法務省令で定めるところにより、適時に、正確な商業帳簿**（会計帳簿及び貸借対照表をいう。以下この条において同じ。）**を作成しなければならない。**

**「一般に公正妥当と認められる会計の慣行に従う」**とされています。

**つまり、会社の記録には、共通の作法がある**ということです。

**簿記は、その作法の入口**です。

**株式会社については、会社法第432条にも定めがあります。**

**扱いは**[簿記2級を取る意味と、効いてくる転職先](skill-boki2.html)**に整理しています。**

## 効く場面

| 場面 | 理由 |
|---|---|
| ① 応募条件に記載がある | **満たす材料になる** |
| ② 数字を扱う職種を見る | 共通の作法を知れます |
| ③ 分野を変える | 学習していることを示せる |
| ④ 会社の資料を読みたい | **読み方の入口** |
| ⑤ 次の段階へ進む前提 | 基礎として |

**④が中心**です。

**決算の資料や、事業の計画の数字を読むとき**に、**用語の意味が分かります。**

**扱いは**[財務諸表の読み方｜公会計との違いから入る](skill-zaimu.html)**に整理しています。**

## 効きにくい場面

| 場面 | 理由 |
|---|---|
| ① 応募条件に記載がない | 判断の中心にならない |
| ② 予算・決算の実務がある | **経験のほうが具体** |
| ③ 経理を職務とする求人 | 水準が足りないことがあります |
| ④ 応募の時期が近い | 書類の作成が優先 |
| ⑤ 目的が曖昧 | 「何か取っておきたい」だけ |

**②が、公務員からの転職では多い**です。

**予算の要求、執行の管理、決算の資料の作成。**

**これらの経験のほうが、具体に書けます。**

## 行政の経験との重なり

| 行政での経験 | 重なる部分 |
|---|---|
| ① 予算の要求 | **見積りの根拠** |
| ② 執行の管理 | 残額と進捗の把握 |
| ③ 契約と支払 | 取引の流れ |
| ④ 決算の資料 | 実績の集計 |
| ⑤ 財産の管理 | 資産の把握 |
| ⑥ 数字の確認 | 突き合わせ、検算 |

**⑥が、実務の材料**です。

**支出の前に根拠の資料と突き合わせる、合計を別の方法で確かめる。**

**この習慣は、資格とは別に評価されます。**

**扱いは**[Excel｜民間で最初に問われる水準はどこか](skill-excel.html)**に整理しています。**

:::insight
入門の簿記について、**面談でお伝えしているのが「目的を『読めるようになること』に置いてください」**という点です。**「転職に有利になるか」で判断すると、答えは求人次第**になります。応募条件に記載がなければ、**判断の中心にはなりません。**ところが、**目的を「会社の資料を読めるようになること」に置くと、話が変わります。**応募先の決算の資料を読む、事業の構成を確かめる、面接で質問を作る。**これらは、どの求人でも役に立ちます。**そして、**読めるようになると、企業調査の質が上がります。**扱いは[応募前の企業調査で見るべき資料](senko-sagasu-kigyochosa.html)に整理しています。**受験するかどうかは、その後で決めて差し支えありません。**学習の途中でも、**読む力は付きます。**目的を絞れば、**短い期間でも効果が出ます。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 書き方の例

**悪い例**

> 簿記の資格を取得しました。

**良い例**

> ◯◯課において、**担当する事業の予算約◯千万円について、要求の資料を作成し、執行の状況を管理。****支出の前に根拠の資料と突き合わせる手順を整備し、誤りの防止に対応。**決算にあたり、**実績を集計のうえ報告の資料を作成。****（資格の欄）◯年に取得**

**資格の欄と、職務の欄が分かれています。**

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 取る前に考えること

| 確認すること | 内容 |
|---|---|
| ① 応募したい求人の条件 | **記載があるか** |
| ② 実務で書ける材料 | 予算、執行、決算 |
| ③ 目的 | **読むためか、条件を満たすためか** |
| ④ 期限 | 応募の時期に間に合うか |
| ⑤ 次の段階 | 続けて学ぶ予定があるか |

**③を1つに絞ってください。**

**目的が曖昧なまま取ると、書類でも面接でも使えません。**

**なお、取れば転職できる、という関係にはありません。**

**何を管理し、どう確認したか**が、評価の対象です。

## 書くときの注意

| 注意 | 内容 |
|---|---|
| ① 取得の年を書く | いつ取ったか |
| ② 実務と併記 | **資格だけを書かない** |
| ③ 級を正確に | 段階がある場合 |
| ④ できる範囲を限定 | 経理の実務まで含めない |
| ⑤ 次の段階に触れる | 続けていれば |

**⑤について。**

**「入口として取り、いまは◯◯を学んでいる」**と言えると、**継続が伝わります。**

**⚠ 合格していない段階を保有と書かないでください。**

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 実務の整理 | **予算の規模、確認の手順** |
| 目的の言語化 | なぜ学ぶのか |
| 求人を読む | 週に30分 |
| 企業の資料を読む | 決算の資料、採用のページ |

**4行目です。**

**学んだ内容を、実際の資料で試す**と、定着します。

**応募先の候補の資料を読むと、そのまま準備にもなります。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 取得の理由 | **1つの理由で短く** |
| その後の学習 | 続けているか |
| 実務との関係 | 数字を扱った経験 |
| 公会計との違い | 理解を示す |
| できる範囲 | **正確に、限定して** |

**1行目です。**

**「何となく」では、目的が伝わりません。**

**実務の場面と結び付けて説明**してください。

## 読めるようになると変わること

| 場面 | 変わること |
|---|---|
| ① 応募先を調べる | **規模と事業の構成が分かる** |
| ② 求人票を読む | 会社の状況の見当がつく |
| ③ 面接で質問する | 具体の問いが作れる |
| ④ 条件を判断する | 制度の背景が読める |
| ⑤ 入社後 | 会議の数字が追える |

**③が、最も直接に効きます。**

**「主力の事業はどちらですか」「この分野は今後どう位置づけられますか」。**

**資料を読んだうえでの質問**は、準備の有無として伝わります。

**扱いは**[有価証券報告書の読み方｜転職者が見るべき箇所](senko-sagasu-yuho.html)**にも整理しています。**

## よくある失敗

**1. 資格だけを書く**

**実務と併記**してください。

**2. 目的を絞らない**

**書類でも面接でも使えません。**

**3. 数字の確認の習慣を書かない**

**資格とは別に評価**されます。

**4. 経理の実務まで含めて書く**

**できる範囲を限定**してください。

**5. 取得の年を書かない**

**いつの知識か**が分かりません。

**6. 応募の時期が近いのに受験を優先する**

**書類の作成が先**です。

**7. 記載のない求人でも必須だと考える**

**判断の中心にはなりません。**

**8. 取れば転職できると考える**

**何を管理し確認したか**が評価の対象です。

:::insight
ここまで「効く場面／効かない場面」の話をしておいて逆のことを言いますが、**最初の一歩としては、悪くない選択です。**面談で拝見していると、**「何から始めればよいか分からない」という状態で止まっている方**がいらっしゃいます。この状態では、**何も進みません。**そして、**入門の簿記は、範囲が決まっていて、短い期間で一巡できる**という特徴があります。**学ぶ習慣を取り戻す手段**としては、使いやすい。**そのうえで、学んだ結果を企業の資料で試せば、転職の準備にもなります。**ですから、**「これを取れば転職できる」とは考えず、「止まっている状態を動かす一歩」として使ってください。**そして、**動き始めたら、書類の作成と求人を読む作業を並行**してください。**資格だけで終わらせないことが、要点**です。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **商法第19条**は、**商人の会計は一般に公正妥当と認められる会計の慣行に従う**とし、**適時に、正確な商業帳簿を作成しなければならない**としています
- **会社の記録には、共通の作法があります。**簿記は、その作法の入口です
- 効くのは、**応募条件に記載がある、数字を扱う職種を見る、分野を変える、会社の資料を読みたい**場合です
- 効きにくいのは、**記載がない、予算・決算の実務がある、経理を職務とする求人**の場合です
- **目的を「読めるようになること」に置く**と、どの求人でも役に立ちます
- **資格だけを書かず、実務と併記**してください
- **止まっている状態を動かす一歩**として使ってください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 予算や決算を担当したことがありません

**扱った数字で書いてください。**担当する事業の予算、物品の購入、委託の契約、使用料の収納。**どの部署でも、数字を扱う場面があります。**書き方は、**「担当する事業の予算約◯百万円について、執行の状況を管理し、残額を月次で確認」**という形です。**規模が小さくても、工程は同じ**です。なお、**確認の手順**を書くと、実務の水準が伝わります。「支出の前に根拠の資料と突き合わせる手順を整備」。扱いは[Excel｜民間で最初に問われる水準はどこか](skill-excel.html)に整理しています。

### 上位の級まで進むべきですか

**目的によります。**会社の資料を読むためであれば、**入門の範囲で足りる**ことがあります。一方、**経理や管理を職務とする**のであれば、**上位の範囲が役立ちます。**判断の目安は、**応募したい求人の応募条件**です。なお、**続けて学んでいること自体は、面接で説明できます。**「入口として取り、いまは◯◯を学んでいる」。**段階を踏んでいることが伝わります。**扱いは[簿記2級を取る意味と、効いてくる転職先](skill-boki2.html)に整理しています。**⚠ 級の構成は、実施する団体の公表を確認**してください。

### 学んだ内容を、どう転職の準備に使えますか

**応募先の資料を読んでください。**決算の資料、事業の説明、採用のページ。**用語が分かると、事業の構成や規模が読めます。**そのうえで、**面接で聞く質問を作る**という使い方ができます。「主力の事業はどちらになりますか」「この分野は、今後どのように位置づけられていますか」。**調べた内容を、質問の材料にする**という形です。扱いは[応募前の企業調査で見るべき資料](senko-sagasu-kigyochosa.html)に整理しています。**学習と準備を、同じ作業にしてください。**
