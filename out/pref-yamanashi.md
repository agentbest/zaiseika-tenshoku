山梨県庁の給与データには、意外に思われる特徴があります。**ラスパイレス指数100.5は、東京都と同じ水準**です。

「地方だから給与水準が低い」という思い込みを持ったまま転職活動を始めると、判断を誤ります。数字を正しく読み解くところから始めてください。

この記事では、まず公表されている数字を確認し、そのうえで県庁の経験が民間のどの言葉に置き換わるのかを整理します。

## 山梨県庁の給与水準を、数字で確認する

総務省の調査によると、山梨県の一般行政職は次のとおりです（令和6年4月1日現在）。

| 項目 | 山梨県 |
|---|---|
| ラスパイレス指数 | 100.5 |
| 平均年齢 | 42.8歳 |
| 平均給料月額 | 328,900円 |
| 諸手当月額 | 76,465円 |
| 平均給与月額 | 405,365円 |
| 平均給与月額（国ベース） | 364,438円 |
| 地域手当（国の指定基準） | 2.75% |
| 地域手当（実際の支給割合） | 約3.63% |

### ラスパイレス指数100.5が意味すること

この指数は、国家公務員の給与水準を100としたときの比較値で、**学歴や経験年数の差を補正して**計算されます。したがって、団体間の給与水準を直接比べられます。

並べると、山梨県の位置が見えます。

| 都県 | ラスパイレス指数 | 地域手当（実支給） |
|---|---|---|
| 東京都 | 100.5 | 約18.72% |
| **山梨県** | **100.5** | **約3.63%** |
| 神奈川県 | 100.0 | 約14.24% |
| 静岡県ほか多くの県 | 99〜100前後 | 県により異なる |

**東京都と同じ100.5**です。しかも地域手当は約3.63%で、東京都の約18.72%とは大きく違います。

つまり、**上乗せ手当ではなく、給料表そのものの水準が高い**ということです。地域手当という上乗せを除いた土台の部分で、山梨県は国と同等以上の水準を持っています。

:::insight
この事実は、転職の判断に直接効きます。相談の場で「地方の県庁だから、民間に移れば上がるはずだ」と考えている方に会うことがありますが、**山梨県の場合、その前提が成り立つとは限りません。**逆に「地方だから自分の水準は低いはずだ」と考えて、提示された条件を安く見積もってしまう方もいます。どちらも、確かめずに動いています。**確かめる方法は簡単です。自分の源泉徴収票の支払金額を出して、求人票の想定年収と並べる。**団体の平均でも、ラスパイレス指数でもありません。自分の実額です。ここを飛ばして印象で判断すると、条件の良い求人を外したり、逆に安い条件を受けたりします。
:::

なお地域手当は、国の指定基準2.75%に対し実際の支給割合が約3.63%で、上回っています。**平均給料月額（年齢構成の影響を受ける）とラスパイレス指数（補正済み）は意味が違うので、混ぜて読まないでください。**

## 県庁の経験は、民間で何と呼ばれるか

| 県庁での仕事 | 求人票での言い方 |
|---|---|
| 予算の要求・査定、財政計画 | 予実管理、投資判断、経営企画 |
| 企業誘致・立地支援 | 事業開発、用地開発、アライアンス |
| 産業支援・技術支援の施策 | 産学連携、技術企画、事業開発 |
| 観光の誘客・受入環境整備 | 観光事業企画、地域ブランディング |
| 農業（果樹・ワイン）の産地形成 | 事業開発、産地開発、ブランド戦略 |
| 移住・定住の促進 | マーケティング、コミュニティ運営 |
| 森林・環境政策 | サステナビリティ、GX事業企画 |
| 県土整備の設計・積算・監督 | 発注者支援、施工管理 |
| 市町村への助言・支援 | パートナー支援、カスタマーサクセス |
| 内部管理（人事・財政・総務・会計） | コーポレート、管理部門 |
| 議会対応、条例・規則の改正 | 渉外、法務、規程整備 |

部署ごとの詳しい対応は[自治体の部署別 仕事ガイド](../zukan.html)にまとめています。財政課であれば[財政課の経験は民間で何と呼ばれるか](dept-zaisei-honyaku.html)で、さらに細かく分解しています。

## 山梨で、どの経験が値になるか

**1. 首都圏に近い立地を扱った経験**

山梨県は首都圏に隣接し、企業の生産拠点や研究拠点の立地が進んでいます。県庁には**用地の確保、インフラの手当て、補助制度の設計、地元との調整**という実務があります。

進出する企業から見れば、これは自分たちが最も苦労する部分です。**行政側で受け入れる仕事を経験した人は、外から採用しようとしても見つかりません。**

**2. ブランド農産物と地域ブランディング**

果樹、ワイン。全国的に知られたブランドを持つ県として、県庁には産地形成と販路開拓の実務があります。**行政の立場でブランドの座組みを作った経験**は、食品メーカー、商社、地域商社、そしてブランド事業を持つ企業から見て希少です。

とくに輸出は許認可と補助金の塊なので、**制度を知っていること自体が実務能力**にあたります。

**3. 観光と受入環境**

観光地を抱える県として、誘客、受入環境の整備、事業者との連携、混雑や環境負荷への対応。**観光を「増やす」だけでなく「捌く」側の経験**は、観光関連の事業者から見て、いま最も足りていない視点です。

**4. 移住・二拠点居住の受け皿づくり**

首都圏に近い立地から、移住や二拠点居住の受入施策があります。**人を呼び込み、定着させるまでの設計**は、民間ではマーケティングとコミュニティ運営に相当します。不動産、住宅、地域事業を持つ企業から見て、この経験は読みやすいものです。

**5. 市町村を相手にしてきた経験**

規模も体制もばらばらな市町村を相手に、温度差をどう埋めたか。「連絡調整」ではなく、**複数顧客を持つアカウント業務の経験**として書けば、そのまま職務能力になります。

## 首都圏の求人も、視野に入れてよい

山梨県は中央道と中央本線で首都圏とつながっており、**転居せずに都内の求人に応募できる**位置にあります。

ここで多いのが、通勤時間だけで線引きしてしまう判断です。近年はリモート可、週数日出社といった勤務形態の求人が増えています。とくに自治体を顧客にする企業は、担当エリアに出向くことが仕事なので、本社への出社頻度が低い場合があります。

**まず職種で絞り、そのあとに勤務形態を確認する。**勤務地から検索すると、県内では出会えない職種が最初から視界に入りません。

## 職務経歴書に、県庁の仕事をどう落とすか

**制度名ではなく、判断したことを書く**

「○○推進事業を担当」では読み手に何も残りません。事業名は庁内でしか意味を持たない固有名詞です。**何件を、どういう基準で審査し、どこで判断が割れて、どう決着させたか。**

**ブランドの仕事は「PR」で終わらせない**

産地形成や地域ブランディングを「PR活動を担当」と書いてしまう方がいます。これでは何ができる人なのか伝わりません。**どの事業者を何者巻き込み、どういう基準を作り、売り先をどう開拓したか。**ここまで書けば、事業開発の経験として読まれます。

**異動歴を「立ち上げの回数」に変える**

異なる制度領域を短期間で立ち上げてきた経験は、民間では**キャッチアップの速さ**として読まれます。編年式で並べ、それぞれの配属で最初の数か月に何を習得したかを1行添えてください。

## 技術職の場合は、探し方が変わる

**発注者側の経験そのものが職種になる**

「発注者支援」という職種が、建設コンサルタント業界には確立しています。設計の審査、積算の確認、工事の監督、住民説明。県庁でやってきたことが、そのまま職務内容として書かれた求人です。

**資格が入口で効く**

技術士、施工管理技士、測量士、電気主任技術者。**実務経験の年数が受験要件になっているものは、在職中でなければ積めません。**取れるものがあるなら、動く前に取っておいてください。

**山地・森林と防災の実務は特殊な資産になる**

急峻な地形での道路、砂防、森林管理。この条件下での設計と維持管理を経験した技術者は、同じ条件を持つ地域の事業では強く求められます。**管理延長ではなく、限られた予算でどう優先順位を付けたか**を書いてください。

## 面接で必ず詰められる2つのこと

**「意思決定のスピードに耐えられるか」**

行政は手続きの段数が多く、決裁を経て動きます。民間は月次で数字を締め、その場で方針を変えます。稟議の段数を弁解せず、**自分の判断で動かした範囲を具体的に答えてください。**

**「数字への意識があるか」**

「利益を意識したことはありますか」という形で聞かれます。「行政なので利益はありません」と答えると、そこで話が終わります。事業の優先順位を付けた、単価の根拠を詰めた、複数案を比べた。**同じ思考をしていたことを、民間の言葉で説明できるか**が見られています。

## 在職中に進めるときの注意点

**顔が知られている前提で動く**

県内の企業の多くは、県庁と何らかの接点を持っています。取引先、許認可の相手方、補助事業の対象。**在職中の活動が伝わりやすい環境**だという前提で進めてください。応募先が現在の担当業務の相手方である場合は、とくに慎重に扱う必要があります。

**服務上の扱いを先に確かめる**

在職中に得た情報を持ち出すことは避けなければなりませんし、退職後の営業活動についても扱いを確認しておいたほうが安全です。**判断に迷う場合は、応募の前に人事担当課に制度上の取扱いを確認してください。**

**面接の日程は、議会日程から逆算する**

地方自治法第211条は、長が毎会計年度予算を調製し、年度開始前に議会の議決を経なければならないと定めています。都道府県は年度開始前30日までに予算を議会へ提出するようにしなければならない、とも書かれています。決算は、出納閉鎖後3か月以内の長への提出、監査委員の審査、議会の認定という順です（第233条）。**予算編成の山と定例会の会期中は、平日日中の面接を入れるのが難しくなります。**

**在職中に決める**

公務員には雇用保険が適用されないため、辞めてから探すと収入のない期間がそのまま持ち出しになります（[公務員に雇用保険がない理由](seido-shitsugyo-nashi.html)）。

:::insight
ここまで転職の話を書いてきましたが、**残る判断にも理があります。**首都圏に近い山梨県は、地方県庁のように「動くなら転居を伴う」という制約がないぶん、**機が熟すまで待っても選択肢はそれほど減りません。**いま担当している領域で通しの経験が積み切れていないなら、それを終えてから動くほうが、書けることは確実に厚くなります。異動の希望が通る見込みがあるなら、まずそちらを試すのも合理的です。ただし、自分の経験が外でどう呼ばれるかを知っておくことには、動かない場合でも意味があります。次の異動希望を出すときの材料が変わるからです。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 山梨県の一般行政職は**ラスパイレス指数100.5、平均給与月額405,365円**（令和6年4月1日現在・総務省調査）
- **ラスパイレス指数は東京都と同じ100.5**です。しかも地域手当は約3.63%と低く、**給料表そのものの水準が高い**構造です
- 「地方だから水準が低い」という前提で動くと判断を誤ります。**自分の源泉徴収票の支払金額と、求人票の想定年収を並べてください**
- 経験が効く方向は、**首都圏に近い立地の実務／ブランド農産物／観光の受入環境／移住・二拠点居住／市町村支援**の5つです
- ブランドの仕事は「PR」で終わらせない。**事業者を何者巻き込み、どういう基準を作り、売り先をどう開拓したか**で書いてください
- **勤務地から検索しない。**職種で絞ってから勤務形態を確認する順序に変えてください

## よくある質問

### 地方の県庁なのに、なぜラスパイレス指数が高いのですか

**ラスパイレス指数は給料月額を国と比べた指数で、地域の物価や賃金水準を反映していません。**地域の相場を反映するのは地域手当のほうで、山梨県は約3.63%です。したがって「給料表の水準は国と同等以上、地域手当は低め」という組み合わせになります。**転職の判断材料としては、指数より手取りから固定費を引いた後にいくら残るか**のほうが実用的です。

### 都内の企業に転職すると、通勤が現実的ではないのですが

**毎日通う前提で考えないでください。**リモート可、週数日出社の求人が増えています。とくに自治体を顧客にする企業は、担当エリアに出向くことが仕事なので、本社への出社頻度が低い場合があります。**募集要項の勤務形態の記載まで確認してから判断してください。**

### 観光やブランドの仕事は、民間のどこで評価されますか

**食品メーカー、商社、地域商社、観光関連の事業者、そしてブランド事業を持つ企業**です。共通しているのは、いずれも「複数の事業者をまとめないと事業が進まない」領域だという点です。行政の立場で座組みを作り、基準を決め、売り先を開拓した経験は、そのまま事業開発として読まれます。書くときは施策名ではなく、巻き込んだ事業者の数と、決めた基準の中身で書いてください。
