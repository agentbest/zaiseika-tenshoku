**土木、建築、電気、機械、化学、農業。**

**技術職の転職は、事務職と進め方が違います。**

この記事では、**違いの中身**と、**経験の示し方**を扱います。

## 技術者を置くことが、法律で義務づけられています

**建設業法第26条第1項**です。

> **建設業者は、その請け負つた建設工事を施工するときは、当該建設工事に関し**（略）**当該工事現場における建設工事の施工の技術上の管理をつかさどるもの（以下「主任技術者」という。）を置かなければならない。**

**同条第2項**は、一定の金額以上の下請契約を締結する場合について、**監理技術者を置かなければならない**としています。

**同条第3項**です。

> **公共性のある施設若しくは工作物又は多数の者が利用する施設若しくは工作物に関する重要な建設工事で政令で定めるもの**については、前二項の規定により置かなければならない主任技術者又は監理技術者は、**工事現場ごとに、専任の者でなければならない。**

**つまり、技術者を置くことが、事業を行う前提になっている**ということです。

**この構造があるため、技術職では、資格と実務の経験が要件として明示されます。**

**事務職との最大の違いは、ここ**です。

## 事務職との違い

| 項目 | 事務職 | 技術職 |
|---|---|---|
| 応募条件 | 経験の内容で記載 | **資格が明示されることがある** |
| 経験の示し方 | 業務の動作で説明 | **工種・規模・役割で説明** |
| 求人の探し方 | 職種名が分かれる | **分野名で探せる** |
| 評価の仕方 | 言い換えが必要 | **そのまま通じることが多い** |
| 領域 | 幅が広い | 分野が明確 |

**4行目です。**

**技術職は、経験が民間の言葉に置き換えやすい**という特徴があります。

**「道路の改良工事の監督」は、民間でもそのまま通じます。**

**一方、事務職は、制度の名前を動作に言い換える作業が必要**になります。

## 発注する側の経験の位置づけ

| 役所での立場 | 民間での位置づけ |
|---|---|
| 発注者 | **発注者支援、コンサルタント** |
| 監督 | 施工の管理、品質の確認 |
| 設計の審査 | 設計、照査 |
| 積算 | 積算、原価の管理 |
| 維持管理 | 保全の計画、点検 |
| 許認可の審査 | 申請の支援、法令の確認 |

**1行目です。**

**発注した側の経験は、発注者支援の業務でそのまま使えます。**

**仕様の考え方、積算の根拠、工程の管理、検査の視点。**

**これらは、発注した側にいないと身につきません。**

**一方、施工そのものの経験とは別**です。

**求人票の仕事内容で、どちらを求めているかを確認**してください。

## 技術職が使える領域

| 領域 | 内容 |
|---|---|
| ① 建設コンサルタント | 調査、設計、施工の監理 |
| ② 発注者支援 | 監督の補助、積算、工程の管理 |
| ③ 施工の管理 | 現場の管理 |
| ④ 設備・保全 | 施設の維持管理 |
| ⑤ 審査・検査 | 申請の確認、性能の評価 |
| ⑥ 事業者側の技術の窓口 | 許認可の対応、行政との折衝 |

**⑥が見落とされやすい**です。

**規制を受ける側の会社では、行政の考え方を理解している技術者が求められます。**

**許認可の申請、監査への対応、制度の改正への対応。**

**発注する側・審査する側にいた経験が、そのまま使えます。**

## 資格の扱い

| 項目 | 内容 |
|---|---|
| 応募条件 | **資格が必須とされることがあります** |
| 実務の経験 | 資格の要件になることがあります |
| 在職中の取得 | **時期と要件を確認** |
| 取得の支援 | 会社の制度による |

**3行目です。**

**資格の受験の要件は、実務の経験の年数と内容で定められていることがあります。**

**役所での実務が要件に算入されるかは、その資格の定めによります。**

**必ず、その資格を所管するところの公表を確認**してください。

**この記事では、個別の資格の要件には触れません。**

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 何を担当したか | **工種、規模、期間、役割** |
| どこまで自分で決めたか | 判断した事項 |
| 難しい局面の対応 | 3件、経緯と結論 |
| 資格と実務の対応 | 保有する資格と、使った場面 |
| 現場に出られるか | 勤務の条件 |

**1行目です。**

**工種と規模を数で示してください。**

**「道路の改良工事、延長約◯メートル、工事費約◯千万円、監督として◯件」**という形です。

**なお、特定の工事が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

:::insight
技術職のご相談で、**面談でお伝えしているのが「発注する側にいた経験を、そのまま書いてください」**という点です。技術職の方は、**「自分は施工をしていないので、現場の経験がない」**とおっしゃることがあります。ところが、**発注者支援や建設コンサルタントの求人で求められているのは、発注した側の視点**です。仕様書をどう組み立てるか、積算の根拠をどう確認するか、工程の遅れをどう扱うか、検査で何を見るか。**これらは、施工の経験からは身につきません。**そして、**この視点を持つ人が不足している領域**があります。理由は、**役所の外には、発注する側の立場が存在しないから**です。ですから、書類には**「発注者として」**と明記してください。**「◯◯工事の監督員として、仕様の確認、工程の管理、完成の検査を担当」**という形です。**立場を書くだけで、読まれ方が変わります。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 準備の順序

| 順 | やること |
|---|---|
| 1 | **担当した工事・業務を工種ごとに書き出す** |
| 2 | 規模、期間、役割を確認する |
| 3 | 保有する資格を整理する |
| 4 | 判断した事項を書き出す |
| 5 | 求人を読む |
| 6 | 職務経歴書を作る |

**1が要**です。

**技術職の職務経歴書は、工種ごとに整理する**のが読まれやすい形です。

**書き方は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 在職中の進め方

| 項目 | 内容 |
|---|---|
| 記録 | 担当した工事・業務の一覧 |
| 資格の確認 | 受験の要件と時期 |
| 求人を読む | 週に30分 |
| 日程の確保 | **年度末の完成検査の時期を避ける** |

**4行目です。**

**技術職は、年度の終わりに完成検査と引渡しが集中**します。

**選考の開始を、この時期と重ならないように選んでください。**

**扱いは**[選考スケジュールの組み方](senko-sagasu-schedule.html)**に整理しています。**

## よくある失敗

**1. 「発注者として」と書かない**

**立場を書くと読まれ方が変わります。**

**2. 工種と規模を書かない**

**数で示して**ください。

**3. 施工の経験がないことを理由に諦める**

**発注した側の視点**が求められる領域があります。

**4. 資格の要件を確認しない**

**所管するところの公表**を確認してください。

**5. 規制を受ける側の会社を見ない**

**技術の窓口**という役割があります。

**6. 維持管理の経験を書かない**

**保全の計画**として読まれます。

**7. 年度末に選考を始める**

**検査と引渡しが集中**します。

**8. 現場に出る条件を確認しない**

**勤務の形が変わります。**

:::insight
ここまで技術の話をしておいて逆のことを言いますが、**技術職の方が持っている「調整」の経験は、もっと書かれてよいものです。**面談で拝見していると、**工種や規模は詳しく書くのに、関係者との調整を書かない方**がいらっしゃいます。ところが、**公共の工事では、調整が仕事の大きな部分**を占めます。沿道の住民への説明、関係機関との協議、他の企業者との工程の調整、用地の担当との連携。**これらは、技術の知識だけではできません。**そして、民間の現場でも**同じ調整が必要**です。近隣への対応、発注者との協議、下請との工程の調整。**やっていることは近い**です。ですから、書類には**「沿道の住民約◯件への説明と、苦情への対応を担当」「関係機関◯者との協議を経て、工程を◯か月短縮」**と書いてください。**技術と調整の両方ができる**という点が、評価される部分です。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **建設業法第26条**は、**主任技術者・監理技術者の設置**を義務づけ、一定の工事では**工事現場ごとの専任**を求めています。**技術者の配置が事業の前提**になっています
- このため、**資格と実務の経験が、応募条件として明示される**ことがあります
- **経験が民間の言葉に置き換えやすい**点が、事務職との違いです
- **「発注者として」と明記**してください。立場を書くと読まれ方が変わります
- 工種・規模・期間・役割を、**数で示して**ください
- **規制を受ける側の会社**にも、技術の窓口という役割があります
- **調整の経験**を書いてください。技術と調整の両方ができる点が評価されます

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 設計や施工の実務がなく、監督と検査が中心でした

**その経験を求めている領域があります。****発注者支援**の業務では、**監督の補助、積算、工程の管理、検査の立会い**が中心になります。**発注した側の経験が、そのまま業務の内容と重なります。**また、**建設コンサルタント**では、**発注者の立場を理解している人**が、業務の管理や協議の場面で求められることがあります。書類には、**「監督員として、工事◯件の工程の管理と完成の検査を担当」**と具体に書いてください。なお、**設計の実務を求める求人**では、条件が異なります。**求人票の仕事内容で、どちらを求めているかを確認**してください。

### 資格を取ってから転職したほうがよいですか

**要件と時期によります。**応募条件に資格が必須とされている場合、**取得してからのほうが選べる求人が増えます。**一方、**入社後の取得を支援する制度**がある会社もあります。求人票や採用のページで、**取得の支援の有無**を確認してください。なお、**受験の要件は、実務の経験の年数と内容で定められていることがあります。**役所での実務が要件に算入されるかは、**その資格を所管するところの公表を確認**してください。**在職中に受験の要件を満たしている場合、在職中に取得するほうが負担が小さい**ことがあります。**時期を先に確認**してください。

### 技術職から事務の仕事に移ることはできますか

**できます。**技術の分野で身につけた**工程の管理、積算、協議、資料の作成**は、事務の仕事でも使えます。とくに、**行政が相手の事業では、技術の知識を持つ事務の担当**が求められることがあります。提案書の作成、仕様の確認、契約の管理。**技術が分かる人が、事務の側にいると進みやすい**ためです。なお、**職種を変える場合、説明の組み立てが必要**になります。なぜ変えるのか、何を持ち込めるのか。**この2つを用意してください。**扱いは別の記事で整理します。**まずは、求人票の応募条件を読んで、自分の経験が該当するかを確認**してください。
