製造業の志望動機で、**よく見かける書き出し**があります。

**「日本のものづくりを支える仕事に関わりたいと考えました」**

**管理部門の選考では、これはあまり効きません。**

理由は2つあります。**1つは、その一文が、どの製造業にも当てはまること。**もう1つは、**管理部門の仕事が、ものづくりそのものではないこと**です。

**管理部門が担っているのは、工場が動き続けるための条件を整えること**です。**そして、その条件の多くは、法令上の義務として決まっています。**

この記事では、**そこから志望動機を組み立てる手順**を扱います。職種の整理は[未経験から製造業の管理部門に入るには](industry-seizo-mikeiken.html)、条件の確かめ方は[製造業の管理部門の年収と働き方](industry-seizo-nenshu.html)にあります。

## 工場は、届け出て動いています

**管理部門の仕事の性格を、条文で見ておきます。**

**大気汚染防止法第6条第1項**です。

> **ばい煙を大気中に排出する者は、ばい煙発生施設を設置しようとするときは、環境省令で定めるところにより、次の事項を都道府県知事に届け出なければならない。**
>
> 二　**工場又は事業場の名称及び所在地**
>
> 三　ばい煙発生施設の種類
>
> 四　**ばい煙発生施設の構造**
>
> 五　ばい煙発生施設の使用の方法
>
> 六　**ばい煙の処理の方法**

**「設置しようとするとき」**です。**動かし始めてからではありません。**

そして、**労働安全衛生法第10条第1項**は、**総括安全衛生管理者を選任**し、**「労働者の危険又は健康障害を防止するための措置に関すること」「労働者の安全又は衛生のための教育の実施に関すること」**などを統括管理させなければならない、と定めています。

**この2つが示しているのは、工場が「届け出て、体制を整えたうえで動いている」**ということです。

**その手続きと体制を担うのが、管理部門**です。

**志望動機は、ここに接続させてください。**「ものづくりを支える」ではなく、**「工場が動き続ける条件を整える側に回る」**です。

## 3つの層に分けます

| 層 | 問い | 材料の出どころ |
|---|---|---|
| ① 機能 | **なぜ、管理部門なのか** | 役所での担当の経験 |
| ② 会社 | **なぜ、この会社・この工場なのか** | 公表資料 |
| ③ 立場 | **なぜ、行政ではなく事業者の側なのか** | 自分の考えの変化 |

**「ものづくりへの関心」は、②の一部にはなりますが、①と③の代わりにはなりません。**

## ① 管理部門を選んだ理由は、経験から取ります

**公務員の方には、強い材料があります。**

| 役所での担当 | 管理部門での対応する仕事 |
|---|---|
| 環境部局での届出の受理・審査 | **環境の届出、報告、測定の管理** |
| 保健所での監視・指導 | 衛生の管理、基準への適合の確認 |
| 消防での査察 | **防火の管理、設備の点検の管理** |
| 労働・産業振興での事業者対応 | 労務、安全衛生委員会の運営 |
| 契約・入札の事務 | 購買、契約の審査 |
| 人事・給与の事務 | 人事、労務、賃金の計算 |
| 会計・出納 | 経理、支払いの管理 |

**書き方は、「担当しました」で止めないでください。****何を見ていたか**を書きます。

> 環境部局で、ばい煙発生施設の設置及び変更の届出の審査を担当していました。届出の内容と、実際の設備の運用が一致しているかを立入検査で確認する立場です。書類が整っていても、変更の手続きが漏れている事例を繰り返し見てきました。

**「受け取る側から見て、どこで漏れるかを知っている」**という形になっています。**これが、工場側にとっては欲しい知識**です。

## ② 会社と工場は、公表資料から取ります

**製造業には、公表されている資料が多くあります。**

| 資料 | 志望動機に使える材料 |
|---|---|
| 公式サイトの事業の紹介 | **何を作っているか、どこに工場があるか** |
| 環境や安全に関する報告 | **どの法令の対象になっているか** |
| 沿革 | 何から始まって、どこへ広げたか |
| 求人票の仕事内容 | その職種の日々の中身 |
| 工場の紹介のページ | **規模、所在地、取得している認証** |

**使い方は、「読みました」ではなく「読んで、自分の経験とどこが重なったか」**です。

> 貴社の工場が、私が在籍していた自治体の隣接する区域にあることを拝見しました。同じ都道府県の環境の基準のもとで運用されている工場ですので、届出の様式と、自治体側の運用の癖が分かります。着任後、早い段階で手続きの実務に入れると考えています。

**この書き方は、地理と制度の両方を確認していないとできません。**

**⚠ ただし、前の職場の内部の事情や、特定の事業者に関する情報は書かないでください。**守秘の観点に加えて、**それを書く人は、次の職場の情報も外で話す**と見られます。**制度の一般的な運用の話に留めてください。**

## ③ 行政ではなく、事業者の側である理由

**公務員から応募する場合、必ず問われます。**

**相手が確かめたいのは2つ**です。

| 相手の懸念 | 確かめたいこと |
|---|---|
| **指導する目線のまま来ないか** | 会社の側に立てるか |
| **現場と話ができるか** | 管理部門としての立ち位置 |

**1つ目が、この業界では特に警戒されます。**

**理由は、工場の側が、行政の指導を受ける立場にあるから**です。**「元役所の人が来て、社内で指導を始める」**という状態は、**会社にとって歓迎できるものではありません。**

**答え方の型は、「基準を満たす仕組みを、内側から作る側へ」**です。

> 立入検査では、基準に適合しているかを確認する立場でした。適合させる仕組みを日常的に回しているのは、事業者の側です。指摘をする側ではなく、指摘を受けない状態を作る側で、経験を使いたいと考えました。

**もう一つの型は、「一度きりの確認ではなく、継続して関わりたい」**です。

> 検査は、年に一度、その時点の状態を見るものです。設備の更新や、法令の改正への対応が、その間にどう進んでいるかは、外からは見えません。継続して関わる立場に移りたいと考えました。

**どちらの型も、行政を否定していません。****役割が違う、という整理**になっています。

**⚠ 避けてください——役所の批判から入る書き方**です。「規制が形式的だった」「現場を見ていなかった」。**この書き出しは、読む側から見ると、次は当社の悪いところを外で言う人に見えます。**

:::insight
面接に同席させていただいていて、**この業界で評価が分かれる瞬間**があります。**「現場の方と、どう関わりますか」**という質問への答え方です。よくあるのは、**「法令にもとづいて、適切に指導します」**という答えです。これは、**この業界ではいちばん警戒される答え方**です。工場の管理部門は、**現場に指導する部署ではなく、現場が動けるように条件を整える部署**だからです。評価される答え方は、**「まず、現場が何に困っているかを聞きます」**という形です。たとえば、記録の様式が現場の作業の流れに合っていないと、**記録が後回しになり、結果として書類が揃わなくなります。**これは現場の怠慢ではなく、**様式の設計の問題**です。役所の側にいた方なら、**申請の様式が事業者の実務に合っていないと、書類が揃わない**という経験をお持ちのはずです。**同じ構造です。**そして、この視点を持っている方は、**「本社が言ってきた」と受け取られずに済みます。**役所で、本庁と出先の間の調整をしてきた方は、**この距離の取り方をすでに知っています。**面接では、その経験を出してください。
:::

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 経験 | 志望動機での使い方 |
|---|---|
| 届出の受理・審査 | **出す側で、どこで漏れるかが分かる** |
| 立入検査・監視 | **検査を受ける側の準備ができる** |
| 要綱・規程の作成 | 社内の規程と手順の整備 |
| 審議会・委員会の事務 | 安全衛生委員会の運営 |
| 契約・入札の事務 | 購買と契約の審査 |
| 本庁と出先の調整 | **管理部門と現場の距離の取り方** |

**効きにくい場所**

| 経験の不足 | 面接での扱い方 |
|---|---|
| 製品や工程の知識 | **入ってから覚える前提で話す** |
| 原価の管理 | 予算の執行との違いを説明する |
| 交替制の職場の労務管理 | 規程にもとづく運用の経験を出す |
| 現場での作業の経験 | **無いことを認めて、聞く姿勢を示す** |

**最後の1つは、隠さないでください。**

**「現場の作業をしたことはありません。ですから、まず聞くところから始めます」**という言い方で足ります。**知ったふりをするほうが、この業界では信用を落とします。**

## 材料を集める順番

| 順 | やること | 目安 |
|---|---|---|
| 1 | 自分が扱った**法令の名前**を書き出す | 30分 |
| 2 | **受け取る側として、どこで漏れを見たか**を3つ書き出す | 1時間 |
| 3 | 応募先の**工場の所在地と、作っているもの**を確認する | 1時間 |
| 4 | その工場が**どの法令の対象か**を推測する | 30分 |
| 5 | ③の型（内側から作る側へ／継続して関わりたい）を決める | 20分 |
| 6 | ①②③を**つなげて300字**にまとめる | 40分 |

**2つ目が、この業界では効きます。**

**「受け取る側から見た、つまずきやすい点」**は、**工場側では手に入りにくい知識**です。**そこを具体的に書けると、志望動機が他の応募者と別物になります。**

## 面接で聞かれやすいこと

| 聞かれること | 何を確かめられているか |
|---|---|
| なぜ管理部門なのですか | **機能で答えられるか** |
| 現場の方と、どう関わりますか | **立ち位置の理解** |
| 行政との協議で、どちらの立場に立ちますか | **元の所属に引きずられないか** |
| 製品の知識がないが、大丈夫ですか | 学ぶ構え |
| 勤務地が工場でも構いませんか | 前提の確認 |

**3つ目は、必ず聞かれます。**

**答え方は、「会社の側に立ちます。ただし、行政の側の制約も分かるので、通らない要求をしないで済みます」**という形が自然です。**「元の所属に配慮します」と答えないでください。**

:::insight
ここまで組み立て方の話をしてきましたが、**逆のことも申し上げます。**志望動機を完成させてから応募しようとして、**動き出しが止まってしまう方**がいらっしゃいます。実際には、**①と②の材料が揃った段階で応募して構いません。**③は、**選考の過程で固まります。**「なぜ行政ではないのか」を問われて、**答えながら自分の考えが整理される**ということが、実際によく起こります。そして、**もう一つ申し上げておきます。**この作業をしてみて、**「自分は、指摘する側のほうが向いている」**という結論になることもあります。**それも正しい結論です。**規制する側の仕事に納得して残る方は、実際にいらっしゃいます。**確かめたうえで残るのと、確かめずに残るのとでは、次に迷ったときの材料が違います。**届出の実務を出す側から見るとどうなるか、工場がどの法令の対象になっているか。**この記事で扱ったことは、いま動かなくても消えません。**そして、**行政の側で異動して別の分野に移っても、担った事実は残ります。**急いで決める理由がないなら、**調べただけの段階で止めておいてください。**在職のまま、情報だけ取るご相談も承っています。
:::

## まとめ

- **「ものづくりを支えたい」は、管理部門の志望動機にはなりません。**どの製造業にも当てはまるためです
- **大気汚染防止法第6条第1項**は、**ばい煙発生施設を設置しようとするときに、都道府県知事への届出**を義務づけています。**動かす前の手続き**です
- **労働安全衛生法第10条第1項**は、**総括安全衛生管理者の選任**と、**危険又は健康障害を防止するための措置、安全又は衛生のための教育**などの統括管理を義務づけています
- **工場は「届け出て、体制を整えたうえで動いている」**のであり、**その手続きと体制を担うのが管理部門**です
- 志望動機は、**①機能（なぜ管理部門か） ②会社・工場 ③行政ではない理由**の3層に分けます
- ①の材料は、**届出の審査、立入検査、契約、人事、会計**にあります。**「担当した」ではなく「何を見ていたか」**で書きます
- ③は、**「基準を満たす仕組みを内側から作る側へ」**または**「継続して関わりたい」**の型で書きます。**役所の批判から入らない**でください
- ⚠ **「指導する目線のまま来ないか」が、この業界では最も警戒されます。****管理部門は、現場を指導する部署ではなく、現場が動ける条件を整える部署**です

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 環境や安全の法令を扱ったことがありません

**①の層を、別の経験で組み立ててください。**契約、人事、会計、窓口の対応。**管理部門の仕事は、環境と安全だけではありません。**総務・人事・経理・法務の職種であれば、**行政での対応する経験が、そのまま材料になります。**書き方は、**「◯◯の事務を担ってきたので、その機能で貢献したい」**という形です。そのうえで、**製造業ならではの部分を押さえておく**と話が通じます。交替制の勤務がある、安全衛生委員会がある、工場ごとに条件が違うことがある。**調べてきたことが伝われば、それだけで差が付きます。**法令の経験が無いことを、応募しない理由にしないでください。

### 志望する会社が、環境の問題を起こしたことがあります。触れるべきですか

**自分から持ち出さないでください。**志望動機で触れると、**採点する立場に立っている**ように読まれます。**聞かれた場合のみ、事実として確認したことを述べてください。**答え方は、**「公表されている内容は拝見しました。再発を防ぐ仕組みを作る側で関わることに、意味があると考えています」**という形です。**批判にも、擁護にもならない位置**に置くのがこつです。なお、**公表されていない事情を、前職で知り得た立場から話すことは避けてください。**守秘の観点に加えて、**この人は情報を外で話すと受け取られます。**判断に迷うときは、**触れないほうが安全**です。

### 同じ都道府県の工場のほうが有利ですか

**届出の実務という点では、材料にはなります。**都道府県ごとに、**上乗せの条例や、運用の細かい部分に違いがある**ためです。ただし、**それが決定的な要素になるわけではありません。**法令の構造は全国で共通ですし、**自治体ごとの運用は、入ってから確認すれば足ります。**むしろ、**同じ都道府県であることを強調しすぎると、前の職場との関係を期待していると受け取られる**ことがあります。**⚠ 元の所属との関係を、有利さとして示さないでください。**書くなら、**「様式と手続きの流れに慣れているので、立ち上がりが速い」**という、**能力の話に留めてください。**勤務地の条件としては、通勤の事情のほうが実務的です。
