複数の応募先から、同時期に結果が出ることがあります。

**選べる状況は、望ましい状況**です。ただし、**期限が短いことが多く、迷う時間は限られます。**

**条件を並べただけでは決まりません。**同じくらいの条件で並ぶと、**かえって判断が難しくなります。**

この記事では、**比べる軸と、決め方**を扱います。

## 受諾は、合意です

**判断の重さを、条文で確認しておきます。**

**労働契約法第6条**です。

> 労働契約は、労働者が使用者に使用されて労働し、使用者がこれに対して賃金を支払うことについて、**労働者及び使用者が合意することによって成立する。**

**合意によって成立する。**

**受諾の意思を示すことは、合意の一方の側を構成します。**軽く扱えるものではありません。

**受諾した後に撤回すると、応募先は採用の計画をやり直すことになります。**他の候補者の選考を終えている場合、**その影響も生じます。**

**だから、受諾の前に判断してください。**逆に言えば、**受諾の前であれば、迷って構いません。**

## 比べる5つの軸

**条件だけで比べないでください。**

| 軸 | 見るもの |
|---|---|
| ① 仕事の内容 | **入社直後に担当する業務**。3年後ではなく、まず最初 |
| ② 任される範囲 | 判断できる範囲、相談の相手、決裁の段数 |
| ③ 条件 | 処遇、勤務地、働き方、評価の仕組み |
| ④ 環境 | 部署の人数、教育の体制、中途で入った人の状況 |
| ⑤ 見通し | 事業の方向、募集の背景（増員か後任か） |

**①を最初に置いてください。**

**入社後の毎日は、①でできています。**条件は生活を支えますが、**日々の時間を占めるのは仕事の内容**です。

## 面接の記録を使う

**判断の材料は、すでに手元にあります。**

**面接の直後に残した記録**を読み返してください。残し方は[面接後に残しておくべき記録](senko-mensetsu-memo.html)にあります。

| 読み返す項目 | 何が分かるか |
|---|---|
| 説明された業務の内容 | ①の具体 |
| 配属先の人数と構成 | ④の環境 |
| 答えが曖昧だった質問 | **受け入れの想定が固まっているか** |
| 面接直後の感触 | **時間が経つと薄れる情報** |

**3つ目と4つ目が、条件表には現れない情報**です。

**「入社後の3か月で何を担当するか」に具体的な答えが返ってきた会社**と、**曖昧だった会社**では、**受け入れの体制に差があることがあります。**

## 点数化しない

**比較の表を作って点数を付ける方法**は、一見合理的ですが、**勧めていません。**

**理由は、重みの置き方で結果が変わるから**です。

| 問題 | 内容 |
|---|---|
| 重みが恣意的 | 処遇に3点、仕事の内容に5点。**この配分に根拠がない** |
| 数えられるものに寄る | 処遇や通勤の時間は数えられるが、**仕事の内容は数えにくい** |
| 結論が先にある | 点数を付けながら、**望む結果になるよう調整してしまう** |

**代わりに、次の問いに答えてください。**

> **1年後、どちらの会社で働いている自分のほうが、具体的に想像できるか。**

**想像できるほうが、情報が多い会社**です。**情報が多いということは、判断の材料が揃っているということ**です。

:::insight
複数の内定で迷ったときに、面談でお聞きしているのは、**「入社初日に、どの席に座って、何をしているか想像できますか」**という質問です。具体的に答えられる会社と、答えられない会社があります。**答えられる会社は、面接で業務の説明が具体的だった会社**です。これは、**受け入れの想定が固まっている**ことの表れでもあります。逆に、**条件は良いが、入社後の姿が浮かばない**という場合、**「入社したら何をするのか」が最後まで詰まっていない**可能性があります。その場合、**受諾の前にもう一度確認**してください。多くの会社は、**受諾の前の質問に応じます。**「入社後の最初の3か月で担当する業務を、もう少し具体的に伺えますか」。**この確認をしたうえで決めれば、後から迷いません。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 受諾の前に確認しておくこと

**受諾は合意の一方を構成するため、その前に確認を済ませてください。**

| 確認 | 方法 |
|---|---|
| 労働条件の書面 | **提示を受けて、内容を読む。**口頭の説明と照らす |
| 担当する業務 | 面接での説明と、書面の職務の内容が一致しているか |
| 就業の場所 | 変更の範囲が記載されていれば、その内容 |
| 入社の日 | **退職の手続きに要する期間**と合うか |
| 試用の期間 | 期間と、その間の条件 |

**1つ目は、必ず書面で受け取ってください。**

**労働基準法第15条第1項**により、**労働条件は明示されるもの**です。**口頭の説明だけで受諾しないでください。**

**4つ目も、先に確認が要ります。**所属の規程で退職の申し出の時期が定められている場合、**入社の日がそれに合わないと、調整が必要**になります。

**確認に数日かかる旨を伝えれば、待ってもらえるのが通常**です。

## 比べる軸に順位を付ける

**5つの軸すべてで勝る会社は、まずありません。****自分にとっての順位**を、先に決めてください。

| 状況 | 上位に来やすい軸 |
|---|---|
| 家族の事情がある | ③条件、③のうち勤務地と働き方 |
| 分野を続けたい | ①仕事の内容 |
| 早く裁量を持ちたい | ②任される範囲 |
| 未経験の分野に移る | ④環境（教育の体制） |

**順位を決めてから比べると、迷う時間が短くなります。**

**順位が決まらない場合は、**[5年後10年後のキャリアを聞かれたとき](senko-mensetsu-5nen.html)**で挙げた、管理の方向と専門の方向のどちらに向かうかを先に決めてください。**方向が決まれば、軸の順位も決まります。

## 期限の調整

**回答の期限は、相談できます。**

| 状況 | 伝え方 |
|---|---|
| 他社の結果を待っている | 「他社の選考が◯日に終わりますので、その後にお返事させてください」 |
| 家族と相談したい | 「家族と相談のうえ、◯日までにお返事いたします」 |
| 条件を確認したい | 「条件を書面で確認させていただいたうえで判断いたします」 |

**3つとも、正当な理由**です。

**期限を自分から示してください。**「少し考えさせてください」だけだと、**いつまでか分からず、相手が動けません。**

**なお、他社の選考を理由にすることは、隠す必要がありません。**中途採用では、複数の応募が通常です。

## 辞退の伝え方

**受諾しない会社には、早く伝えてください。**

| 項目 | 内容 |
|---|---|
| 時期 | **決めたらすぐ。**遅れるほど、相手の採用の計画に影響します |
| 方法 | 電話またはメール。**人材会社の経由なら担当者から** |
| 理由 | **簡潔に。**詳しく述べる必要はありません |
| 態度 | 時間を割いてもらったことへの謝意を添える |

**理由は、「他社に決めました」で足ります。**

**比較の内容を詳しく述べる必要はありません。**相手にとって、**その情報は使い道がない**からです。

**丁寧に辞退しておくと、将来また応募する可能性が残ります。**同じ会社が、**数年後に別の募集をする**ことがあります。

[経験の言い換えから相談する](../apply.html)こともできます。

## よくある失敗

**1. 条件だけで比べる**

**入社後の毎日は、仕事の内容でできています。**

**2. 点数化する**

**重みの置き方で結果が変わります。**

**3. 記録を読み返さない**

**判断の材料は、すでに手元にあります。**

**4. 期限を自分から示さない**

**相手が動けません。**

**5. 受諾した後に撤回する**

**合意の一方を構成します。**受諾の前に判断してください。

**6. 辞退の連絡を遅らせる**

**相手の採用の計画に影響します。**

:::insight
ここまで選び方の話をしておいて逆のことを言いますが、**複数の内定から選ぶ場面で、「どちらを選んでも大きく外れない」ことは珍しくありません。**両方とも選考を通った、ということは、**どちらも経験が評価されたということ**です。面談で伺っていると、**決めた後に「もう一方にすべきだったのでは」と考え続けてしまう方**がいらっしゃいます。ただ、**入社後の満足は、選んだ会社そのものより、入ってからの動き方で決まる部分が大きい**というのが実際のところです。ですから、**決めたら振り返らないでください。**判断の材料が揃った状態で決めたのであれば、**それが最善の判断**です。そして、**どちらも選ばないという判断にも理があります。**条件が揃わないのであれば、**いまの職場に残る**という選択も、比べたうえでの判断です。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **労働契約法第6条**は、労働契約が**労働者及び使用者が合意することによって成立する**としています。**受諾は、合意の一方を構成します**
- 比べる軸は、**①仕事の内容 ②任される範囲 ③条件 ④環境 ⑤見通し**の5つ。**①を最初に**置いてください
- **面接の記録を読み返して**ください。答えが曖昧だった質問と、直後の感触が材料になります
- **点数化は勧めません。**重みの置き方で結果が変わります
- 代わりに、**1年後の自分を具体的に想像できるか**で判断してください
- **回答の期限は相談できます。**自分から期限を示してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 内定を保留したまま、他社の選考を進めてよいですか

**進めて構いませんが、期限の範囲内にしてください。**内定を出した会社は、**回答を待っている間、他の候補者への対応を止めている**ことがあります。**無期限に待たせることはできません。**対処としては、**先に内定が出た会社に、事情を伝えて期限を相談する**ことです。「他社の選考が◯日に終わります」と具体的に伝えれば、**多くの場合は待ってもらえます。**あわせて、**選考中の会社にも、内定が出ている旨を伝えて構いません。**日程が早まることがあります。**隠して引き延ばすのが、いちばん調整を難しくします。**

### 条件が良いほうと、仕事が面白そうなほうで迷います

**「1年後に想像できるか」で判断してください。**そのうえで申し上げると、**条件の差が生活に影響する水準かどうか**を、具体的に確認してください。**月々の収支に影響するのか、貯蓄の速度が変わる程度なのか。**前者であれば、条件を重く見る理由になります。後者であれば、**仕事の内容を優先する判断にも理があります。**加えて、**条件は入社後に変わり得ます。**評価の仕組みがある会社では、**数年で差が縮まる**こともあります。**入社時点の条件だけで判断しないでください。**

### 現職に残るという選択肢も、比べてよいですか

**比べてください。**むしろ、**その比較をせずに決めるほうが危険**です。現職に残る場合の条件（処遇、担当する分野、異動の見込み、働き方）を、**内定先と同じ軸で並べてください。**面談でも、**この比較をしたうえで、残る判断をされた方**がいらっしゃいます。それは、**活動が無駄だったということではありません。**比べる材料が揃ったうえでの判断です。なお、**内定を辞退して残る場合も、辞退の連絡は丁寧にしてください。**将来また応募する可能性が残ります。
