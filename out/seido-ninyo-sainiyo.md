60歳が近づいた公務員が考える選択肢は、かつては「定年退職して再任用」か「定年退職して民間へ」の2つでした。定年の引上げで、この構図は変わっています。**フルタイムで定年まで続ける、定年前再任用短時間勤務で時間を減らす、引上げの途中の世代は暫定再任用で65歳まで働く、そして民間に転職する**——4つの道が並びます。

この記事では、**公務員として続ける3つの道と、民間に転職する道を、給与、退職手当、年金、働く期間、仕事の中身の軸で比べる**ための材料を整理します。民間の側の制度として、高年齢者雇用安定法が定める65歳までの雇用確保と70歳までの就業確保も条文で押さえます。**額はすべて自治体の条例と転職先の条件による**ので、この記事は比較の枠組みです。

## 公務員として続ける3つの道

| 道 | 内容 | 根拠 |
|---|---|---|
| **フルタイムで定年まで** | 60歳以降も常時勤務を要する職で、定年退職日まで働く。給与は当分の間60歳時点の7割水準（国の例） | 地方公務員法第28条の6、人事院の説明 |
| **定年前再任用短時間勤務** | 60歳以降で退職し、選考により短時間勤務の職に採用され、定年退職日相当日まで働く | 第22条の4 |
| **暫定再任用**（定年引上げの期間中の経過措置） | 定年の段階的引上げの期間中、定年退職した者などを、65歳到達年度まで、フルタイムまたは短時間で再任用する（任期1年以内、更新可） | 改正法の附則による経過措置（内閣人事局・人事院の説明） |

**暫定再任用は、定年が65歳に達するまでの間の経過措置**で、引上げの途中の世代が、定年退職の後に65歳まで働くための制度です。令和13年度に定年が65歳になれば、役割を終えます。

## 民間の側の制度——高年齢者雇用安定法

| 条文 | 内容 | 転職先で意味すること |
|---|---|---|
| **第8条** | 事業主が定年を定める場合、**60歳を下回ることができない** | 転職先の定年は60歳以上 |
| **第9条** | 65歳未満の定年を定めている事業主は、**65歳までの安定した雇用を確保するため**、定年の引上げ、継続雇用制度の導入、定年の廃止のいずれかを講じなければならない | **転職先は、65歳までは雇用を確保する義務がある**（多くは継続雇用＝再雇用） |
| **第10条の2** | 65歳以上70歳未満の定年を定めている事業主などは、**70歳までの就業確保措置**（定年の引上げ、継続雇用、業務委託など）を講ずるよう**努めなければならない** | 70歳までは努力義務。企業により対応が分かれる |

**民間に転職しても、65歳までは法律で雇用の確保が義務づけられています。**ただし、継続雇用（再雇用）の場合、60歳の定年後の給与は大きく下がる企業が多く、公務員の7割水準より低いこともあれば、高いこともあります。**転職先の「60歳の定年後の継続雇用の条件」を、内定の段階で確かめる**のが、比較の最も大切な点です。

## 比較の軸

| 軸 | 公務員として続ける | 民間に転職 |
|---|---|---|
| **60歳以降の給与** | 7割水準（国の例）。短時間勤務なら勤務時間に応じた額 | 転職先の給与。60歳の定年後の継続雇用では大きく下がる企業が多い |
| **退職手当** | 60歳以降の退職は定年退職として算定（国の経過措置） | 同じ時点で受取り。転職先の退職金は勤続が短いので少額か、なし |
| **年金** | 共済の年金（厚生年金相当）。受給は原則65歳から | 転職先の厚生年金に加入。共済の記録と通算 |
| **働く期間** | 定年退職日（引上げの途中の世代は暫定再任用で65歳まで） | 65歳までは雇用確保の義務。70歳までは努力義務 |
| **仕事の中身** | 自治体の業務。管理職は役職定年で離れる | 財政・会計の経験を生かす業務。管理職や専門職として迎えられることもある |
| **健康保険** | 共済（短時間勤務は勤務時間による） | 転職先の健康保険 |
| **確かめる先** | 人事の担当課、共済組合 | 転職先の人事、転職支援 |

## 場面ごとの考え方

| 場面 | 考え方 |
|---|---|
| **経験を外で生かしたい** | 民間への転職。財政・会計の経験は、自治体向けの企業、監査法人、会計事務所、金融機関などで評価される。**60歳以降の処遇を確かめる** |
| **時間を減らして続けたい** | 定年前再任用短時間勤務。短時間の給与と、転職先のフルタイムの給与を、時間当たりで比べる |
| **収入を維持したい** | フルタイムで定年まで（7割水準）と、転職先の給与を比べる。**転職先によっては7割水準を上回る** |
| **65歳まで働きたい** | 引上げの途中の世代は暫定再任用。民間は65歳までの雇用確保の義務がある。**どちらも65歳までの道はある** |
| **管理職を離れたくない** | 役職定年で公務員の管理職は離れる。民間で管理職として迎えられる転職先を探す |

**「公務員として続ける」と「民間に転職する」のどちらが有利かは、一般論では決まりません。**軸ごとに、自分の額と条件を入れて比べる作業が要ります。

:::insight
面談で伺うと、**「再任用は給与が下がるから民間へ」と決めた方が、転職先の60歳の定年後の継続雇用の給与を確かめておらず、入社2年後に公務員の7割水準より低い額になった**というケースがあります。逆に、**「民間は不安定だから再任用」と決めた方が、財政課長の経験を高く評価する転職先の条件を見て、判断を変えた**こともあります。ここで1つ提案があります。**60歳の前年度に、人事の担当課で「フルタイムで続けた場合、短時間勤務にした場合、暫定再任用の場合の給与と退職手当の見込み」を、転職先で「入社時の給与、60歳の定年後の継続雇用の条件、65歳以降の扱い」を、それぞれ確かめて、65歳までの年ごとの収入を1枚の表にしてください。**表にすると、印象で決めていたことが、額で見えます。**その表に、仕事の中身と健康の見込みを書き添えれば、判断の材料は揃います。**
:::

## 転職するとどうなるか

60歳前後で転職を考えている方にとって、効いてくる点は3つです。

**1. 公務員として続ける道は3つある**

**フルタイム、定年前再任用短時間勤務、暫定再任用。**それぞれの給与と期間を確かめてください。

**2. 民間は65歳までの雇用確保が義務、70歳までは努力義務**

**転職先の60歳の定年後の継続雇用の条件**が、比較の最も大切な点です。

**3. 65歳までの年ごとの収入を1枚の表に**

**印象ではなく額で比べる。**仕事の中身と健康の見込みを書き添えてください。

## 手続きと期限

| 順序 | 手続き | 時期 | 場所 |
|---|---|---|---|
| 60歳の前年度 | フルタイム・短時間勤務・暫定再任用の給与と退職手当の見込みを照会 | 59歳 | 人事の担当課 |
| 同時に | 転職先の入社時の給与、60歳の定年後の継続雇用の条件、65歳以降の扱いを確かめる | 59歳 | 転職支援、転職先 |
| 表を作る | 65歳までの年ごとの収入を、道ごとに並べる | 59歳 | 自分で |
| 公務員として続ける場合 | 意思確認に応じ、希望する形を申し出る | 自治体の定める時期 | 任命権者 |
| 転職する場合 | 内定の条件を確かめ、退職の時期を60歳以降にすると退職手当の扱いが変わることを踏まえて退職日を決める | 内定後 | 人事の担当課 |

## 誤解されやすい点

**「再任用は給与が低いから民間のほうが必ず得」と思い込む**

**転職先の60歳の定年後の継続雇用の給与は大きく下がる企業が多く**、公務員の7割水準を下回ることもあります。

**「民間は60歳で終わり」と思い込む**

**高年齢者雇用安定法第9条により、65歳までの雇用確保が事業主の義務**です。70歳までは努力義務です。

**「暫定再任用は誰でも使える」と思い込む**

**定年引上げの期間中の経過措置**で、対象は定年退職した者などに限られ、令和13年度に定年が65歳になれば役割を終えます。

**「退職手当は再任用のほうが有利」と思い込む**

**60歳以降の退職は、再任用でも転職でも、定年退職として算定する経過措置**（国の例）が及びます。

:::insight
ここまで比較の話を書いておいて逆のことを言いますが、**再任用か転職かは、額の比較だけで決まるものではありません。**仕事の中身、働く時間、健康、家族の事情が、額と同じ重さを持ちます。それでも1本の記事にしたのは、**額の比較すらしないまま、印象で決める方を面談で見る**からです。65歳までの表を作れば、額の部分は片づき、残りの判断に集中できます。そのうえで、**自分の経験に値を付けてくれる業界の見込みと、同じ紙に並べてください。**片方だけでは比較になりません。応募先が決まっていない段階のほうが、むしろ整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 60歳以降に公務員として続ける道は、**フルタイムで定年まで（7割水準）、定年前再任用短時間勤務（第22条の4）、引上げの途中の世代の暫定再任用（経過措置）**の3つです
- 民間の事業主には、**高年齢者雇用安定法第9条により65歳までの雇用確保の義務、第10条の2により70歳までの就業確保の努力義務**があります。定年は60歳を下回れません（第8条）
- **60歳以降の退職手当の扱いは、再任用でも転職でも同じ**（定年退職として算定する国の経過措置）で、比べるのはその後の働き方と収入です
- 比較の最も大切な点は、**転職先の60歳の定年後の継続雇用の条件**です。大きく下がる企業が多く、公務員の7割水準との比較が要ります
- **65歳までの年ごとの収入を、道ごとに1枚の表にする**と、印象で決めていたことが額で見えます
- 額の比較に、**仕事の中身、働く時間、健康、家族の事情**を書き添えて判断してください

## よくある質問

### 民間に転職した場合、60歳の定年後はどうなりますか

**高年齢者雇用安定法第9条により、65歳までは雇用の確保が事業主の義務ですが、継続雇用（再雇用）の条件は企業により大きく違います。**転職先の定年が60歳なら、定年後に継続雇用制度（再雇用）で65歳まで働くのが一般的な形で、その際の給与、勤務時間、業務は、就業規則と再雇用の契約で定められます。給与は定年前より大きく下がる企業が多く、公務員の60歳以降の7割水準を下回る場合もあれば、上回る場合もあります。65歳以上70歳未満の定年や継続雇用の上限を定めている企業は、第10条の2により70歳までの就業確保の努力義務があり、対応は企業により分かれます。**内定の段階で「定年は何歳か、定年後の継続雇用の給与と業務はどうなるか、65歳以降の扱いはどうか」を確かめてください。**転職先の定年が65歳以上なら、60歳の定年後の給与の減額はなく、公務員より有利な場合もあります。転職の支援を受けている場合は、担当者がこれらを企業に確かめてくれます。

### 暫定再任用とは何ですか。自分は対象ですか

**定年の段階的引上げの期間中に、定年退職した者などを65歳到達年度まで再任用する経過措置で、引上げの途中の世代が対象です。**定年が61歳から64歳の年度に定年退職した職員は、65歳までの期間が残るので、その間を働くための制度として、改正法の附則で暫定再任用が設けられています（内閣人事局・人事院の説明）。フルタイムまたは短時間勤務で、任期は1年以内、65歳到達年度まで更新できます。令和13年度に定年が65歳になれば、定年退職の時点で65歳なので、暫定再任用の役割は終わります。自分が対象かどうかは、定年退職の年度と生年月日で決まるので、人事の担当課に「自分の定年退職日と、暫定再任用の対象になるか、給与はどうなるか」を確かめてください。暫定再任用の給与は、従前の再任用の給与に準じた水準で、60歳以降の7割水準とは別の体系です。民間への転職と比べる場合は、暫定再任用で65歳まで働いた場合の年ごとの収入と、転職先の65歳までの年ごとの収入を並べます。

### 財政課長でした。民間で管理職として働けますか

**財政・会計の管理職の経験は、自治体向けの企業、監査法人、会計事務所、公益法人などで管理職や専門職として評価されることがあります。転職先の60歳以降の処遇と合わせて確かめてください。**役職定年で公務員の管理職を離れる方にとって、管理職としての経験を外で生かす転職は、経験の価値を最も高く保つ道の1つです。自治体の予算編成、決算、起債、財政の健全化に関する実務と、課の管理の経験は、自治体を顧客とする企業の管理職、監査法人の公会計部門、公益法人の事務局の管理職などで求められます。ただし、60歳前後での転職は、転職先の定年と継続雇用の条件が、入社後数年で効いてくるので、入社時の役職と給与だけでなく、60歳の定年後の扱い、65歳以降の扱いを内定の段階で確かめる必要があります。定年が65歳以上の企業や、役員・顧問として迎える形なら、60歳の定年後の減額がなく、管理職の経験を長く生かせます。**役職定年の1〜2年前から、管理職の経験を評価する転職先を調べ、60歳以降の処遇を並べて判断する**のが、経験を最も生かせる形です（[役職定年](seido-ninyo-yakushoku.html)）。
