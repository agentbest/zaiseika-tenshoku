**自衛官からの転職は、職種によって進め方が大きく変わります。**

**経験の中身が、職種ごとに異なる**ためです。

この記事では、**分け方**と、**示し方**を扱います。

**⚠ 在職中の求職や再就職については、別に定めや手続きがあります。****必ず、所属の担当（援護に関する部署を含む）に確認してください。**

## 任務が、法律で定められています

**自衛隊法第3条第1項**です。

> **自衛隊は、我が国の平和と独立を守り、国の安全を保つため、我が国を防衛することを主たる任務とし、必要に応じ、公共の秩序の維持に当たるものとする。**

**同条第2項**は、**主たる任務の遂行に支障を生じない限度**において行う活動として、**我が国の平和及び安全の確保に資する活動**、**国際協力の推進を通じた活動**を挙げています。

**同条第3項**です。

> **陸上自衛隊は主として陸において、海上自衛隊は主として海において、航空自衛隊は主として空においてそれぞれ行動することを任務とする。**

**任務の範囲が定められ、その中で職種が分かれている**という構造です。

**つまり、「自衛官」という一括りではなく、担当した職種で経験が決まる**ということです。

## 職種ごとに経験を分ける

| 分野 | 民間で近い業務 |
|---|---|
| ① 整備 | **設備・機械の保全、点検、修理** |
| ② 補給・輸送 | 調達、在庫の管理、物流 |
| ③ 施設・土木 | 建設、重機の運用、施設の管理 |
| ④ 通信・電子 | 通信網、機器の運用、情報の管理 |
| ⑤ 衛生 | 医療の補助、救急、健康の管理 |
| ⑥ 会計・人事 | 予算、給与、人事の事務 |
| ⑦ 教育・訓練 | 研修の設計・実施 |
| ⑧ 指揮・管理 | 組織の運営、人の育成 |

**①〜④は、民間の求人と直接つながります。**

**⑥について。**

**組織の中の事務は、業種を問わず必要とされます。**

**予算の執行、物品の管理、人事の記録。**

**これらは、一般の企業の管理部門と同じ動作です。**

## 書き方の例

**悪い例**

> ◯◯に勤務し、整備を担当しました。

**良い例**

> **◯◯（人員約◯名の部隊）において、車両◯両の整備を担当。**定期の点検の計画を作成し、**年間約◯件の整備を実施。**部品の在庫と発注の管理を担い、**不具合の傾向を整理して点検の項目に反映。****新規に配置された隊員◯名に対する技能の指導**を担当。

**「規模」「件数」「改善」「指導」**が入っています。

**⚠ 装備の性能、運用の詳細、部隊の配置など、特定される記述は避けてください。****守秘の義務は、退職した後も続きます。**

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 言い換えの対応

| 自衛隊の言葉 | 民間での読まれ方 |
|---|---|
| 整備・点検 | **設備の保全、予防の保全** |
| 補給・需品 | 調達、在庫の管理 |
| 輸送 | 物流、配車の計画 |
| 部隊の運用 | 現場の統括、人員の配置 |
| 教育・訓練 | 研修の設計・実施 |
| 安全の管理 | 労働安全、危険の予知 |
| 演習の計画 | **計画の立案、段取りの設計** |
| 点検の記録 | 記録の管理、証跡 |

**1行目と7行目です。**

**「予防の保全」という言葉**は、製造業や設備の管理で使われます。

**壊れる前に点検し、交換する**という考え方は、**そのまま通じます。**

## 民間での使いどころ

| 領域 | 使える経験 |
|---|---|
| ① 設備・機械の保全 | 整備、点検、記録 |
| ② 物流・調達 | 補給、在庫、輸送 |
| ③ 建設・施設の管理 | 施設、重機、安全 |
| ④ 通信・情報 | 機器の運用、情報の管理 |
| ⑤ 安全・防災の管理 | 訓練、体制の構築 |
| ⑥ 人材の育成 | 教育、訓練の設計 |
| ⑦ 行政が相手の事業 | **手続きと組織の理解** |

**⑤について。**

**災害への備えを担う部署**を持つ会社があります。

**訓練の計画、備蓄の管理、体制の構築。**

**経験が直接使えます。**

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 何を担当したか | **職種、規模、件数** |
| 判断の経験 | 手順（運用の詳細ではなく） |
| 指導の経験 | 人数、方法 |
| 組織への適応 | 民間の進め方への考え |
| 保有する資格・免許 | **取得の年と、使った場面** |

**5行目です。**

**在職中に取得した資格や免許は、民間でも使えることがあります。**

**名称と取得の年を、正確に記載**してください。

**なお、資格の読み替えや、受験の要件については、所管するところの公表を確認**してください。

:::insight
自衛官の方のご相談で、**面談でお伝えしているのが「職種を先に書いてください」**という点です。**「自衛官でした」だけでは、何ができるかが伝わりません。**整備なのか、補給なのか、通信なのか、施設なのか。**職種によって、つながる求人がまったく違います。**そして、**多くの方が、自分の職種を民間の言葉に置き換えていません。**車両や機器の整備は、**設備の保全**です。補給や需品は、**調達と在庫の管理**です。演習の計画は、**段取りの設計**です。**この置き換えをするだけで、読まれ方が変わります。**さらに、**規模を書いてください。**扱った車両の数、管理した物品の点数、指導した人数。**数があると、範囲が伝わります。**書類の冒頭に、**「◯◯の職種として、◯年間、◯◯を担当」**と置いてください。**その1行で、読む側が求人と照らし合わせられます。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 準備の順序

| 順 | やること |
|---|---|
| 1 | **在職中の求職・再就職の定めを確認する** |
| 2 | 担当した職種と期間を書き出す |
| 3 | 規模、件数、改善した点を確認する |
| 4 | 保有する資格・免許を整理する |
| 5 | 民間の言葉に置き換える |
| 6 | 求人を読む |

**1を最初に置いてください。**

**所属の担当（援護に関する部署を含む）に、手続きと進め方を確認**してください。

**制度の照会として聞くことができます。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 在職中の進め方

| 項目 | 内容 |
|---|---|
| 制度の確認 | **手続き、時期、援護の仕組み** |
| 記録 | 担当した職種、規模、件数 |
| 資格の確認 | 取得済みのもの、取得できるもの |
| 求人を読む | 週に30分 |

**1行目です。**

**任期や定年の時期によって、進め方が変わります。**

**時期を確認したうえで、逆算して準備してください。**

**在職中にできる準備と、退職の後でなければできないことを分けておくと、迷いが減ります。**

**扱いは**[選考スケジュールの組み方](senko-sagasu-schedule.html)**に整理しています。**

## よくある失敗

**1. 職種を書かない**

**何ができるか**が伝わりません。

**2. 民間の言葉に置き換えない**

**整備＝設備の保全**です。

**3. 規模を書かない**

**範囲が伝わりません。**

**4. 資格・免許を書かない**

**民間でも使える**ことがあります。

**5. 運用の詳細を書こうとする**

**規模と動作**で書いてください。

**6. 手続きの確認を後回しにする**

**進め方が変わります。**

**7. 指導の経験を書かない**

**研修の設計**として読まれます。

**8. 管理部門の経験を軽く見る**

**業種を問わず必要**とされます。

:::insight
ここまで職種の話をしておいて逆のことを言いますが、**職種に関係なく評価される部分があります。それは「決められた手順を、確実に回してきたこと」です。**面談で拝見していると、**この点を当たり前だと思っている方**がいらっしゃいます。ところが、**民間では、手順が決まっていても守られない場面**が少なくありません。点検の記録が抜ける、引継ぎが口頭で終わる、確認が省かれる。**そして、それが事故や不具合の原因になります。**自衛隊で身についた、**記録を残す、順番を飛ばさない、確認を二重にする**という習慣は、**製造、設備、物流、医療**のいずれでも必要とされます。書類には、**「定められた手順に基づく点検を◯件実施し、記録を作成」**と書いてください。**地味に見えますが、この一文が効きます。**そして、**この習慣は、職種が変わっても持ち運べます。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **自衛隊法第3条**は、**防衛を主たる任務**とし、**必要に応じ公共の秩序の維持**に当たるとしています。**その範囲の中で職種が分かれています**
- **「自衛官でした」ではなく、職種を先に書いて**ください
- **整備＝設備の保全、補給＝調達と在庫の管理、演習の計画＝段取りの設計**と置き換えてください
- **規模（数）を書いて**ください。範囲が伝わります
- **在職中の求職・再就職の定めを、最初に確認**してください
- **資格・免許は、名称と取得の年**を記載してください
- **決められた手順を確実に回してきたこと**は、職種を問わず評価されます

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 手続きは、どこに確認すればよいですか

**所属の担当**です。**再就職の援護に関する部署が置かれている**ことがあります。確認するのは、**①在職中に行える範囲 ②手続きの時期と方法 ③利用できる仕組み**の3点です。**制度の照会として聞くことができます。**なお、**任期や定年の時期によって、進め方が変わります。**時期を確認したうえで、**逆算して準備**してください。扱いは[選考スケジュールの組み方](senko-sagasu-schedule.html)に整理しています。**人づての情報ではなく、担当に直接確認**してください。内容は、身分や職種によって異なります。

### 職務経歴書に、どこまで書いてよいですか

**職種、期間、規模、件数、担った役割**までは書けます。**書かないのは、装備の性能、運用の詳細、部隊の配置など、特定される記述**です。書き方は、**「車両◯両の整備を担当」「定期の点検の計画を作成し、年間約◯件を実施」**という形です。**動作と数で書く**と、守秘を守りながら経験が伝わります。**判断に迷う記述は、書かないでください。**なお、**記載の範囲については、所属の担当に照会**できます。**一般的な説明を求めて差し支えありません。**面接でも、**「守秘の義務があるため、詳細には触れられませんが」**と前置きすれば、手順の説明はできます。

### 民間の働き方に適応できるか不安です

**不安の中身を分けてください。**時間の使い方、指示の受け方、成果の測られ方、人との関わり方。**それぞれで、実際の違いは異なります。**確認の仕方は、**面接で「一日の業務の流れを教えてください」と聞くこと**です。具体が分かると、想像がつきます。なお、**手順に沿って確実に進める習慣は、民間でも求められます。**変わるのは、**手順を自分で作る場面が増える**という点です。「こう決まっている」ではなく、「こう決めたほうがよい」と提案する場面が出てきます。**この点は、入社後に慣れる部分**です。**心配の中身を、面接で確認してから判断**してください。
