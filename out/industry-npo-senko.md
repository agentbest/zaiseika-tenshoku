NPO・公益法人の選考を受けた方から、**同じ戸惑い**を伺います。

**「一次面接から3週間、連絡がありません」**

**「面接に、人事の方が一人も出てきませんでした」**

**どちらも、異常ではありません。**この業界の**組織の作りから、そうなる**というだけです。

**仕組みを知らないまま受けると、無いはずの意味を読み取って不安になります。**この記事では、**選考がそう動く理由**と、**面接で実際に見られている観点**を扱います。

志望動機の組み立ては[NPO・公益法人の志望動機](industry-npo-shiboudoki.html)、未経験から入る道筋は[NPO・公益法人に未経験から入るには](industry-npo-mikeiken.html)にあります。

## 業務は、理事の合議で決まる建て付けになっています

**選考の速度を決めているのは、意思決定の仕組みです。**

**特定非営利活動促進法第15条**です。

> **（役員の定数）第十五条　特定非営利活動法人には、役員として、理事三人以上及び監事一人以上を置かなければならない。**

**理事は3人以上**と定められています。そして、**同法第17条**です。

> **（業務の執行）第十七条　特定非営利活動法人の業務は、定款に特別の定めのないときは、理事の過半数をもって決する。**

**「理事の過半数をもって決する」**です。**定款に特別の定めが無ければ、業務は合議で決まります。**

さらに、**同法第16条**です。

> **（理事の代表権）第十六条　理事は、すべて特定非営利活動法人の業務について、特定非営利活動法人を代表する。**ただし、定款をもって、その代表権を制限することができる。

**原則として理事全員が代表権を持ち、定款で制限できる**という構造です。**多くの法人は、定款で理事長に代表権を集めています。**

**ここから、選考について2つのことが言えます。**

| 仕組み | 選考への出方 |
|---|---|
| **業務は理事の過半数で決する**（定款に定めが無ければ） | **採用が理事会の議題になる法人がある。**理事会の開催まで結論が出ない |
| 定款で理事長に権限を集められる | **理事長の判断で即決する法人もある。**法人によって速度が違う |

**つまり、「遅い」のではなく「どこで決めるかが法人ごとに違う」**のです。

**理事は非常勤であることが多く、本業を別に持っています。**理事会が2か月に1回という法人であれば、**面接から結論まで、そのぶん待つことになります。**

**公益法人も構造は同じ**です。**公益認定法第5条第1号**が**「公益目的事業を行うことを主たる目的とするものであること」**を認定の基準としているとおり、**法人の意思は事業の目的に沿って組織的に決まる**建て付けになっています。

## 選考フローは、法人の規模で2つに分かれます

| | 小規模な法人 | 一定の規模がある法人 |
|---|---|---|
| 書類 | 理事長・事務局長が直接読む | 事務局の担当者が一次で読む |
| 一次面接 | **理事長がいきなり出てくる** | 事務局長・部門の責任者 |
| 二次面接 | 理事が複数出てくる／実務の体験 | 理事長・常務理事 |
| 最終 | **理事会での承認を待つ** | 理事長の決裁 |
| 全体の期間 | **読みにくい。**理事会の日程次第 | 比較的読める |
| 人事の担当者 | **いない**ことが多い | 総務が兼務していることが多い |

**「人事の方が出てこない」のは、人事の部署が無い**からです。**採用は、事務局長や理事長の仕事の一部**として行われています。

**これは、応募する側にとっては有利に働く面があります。**

**決める人が、最初から出てくる**からです。民間企業のように、**人事の一次面接で機械的に落とされる工程が、そもそも存在しない**ことが多い。**書類が通れば、決定権のある人と直接話せます。**

**一方で、不利に働く面もあります。**

**選考の手順が整っていないので、連絡の間隔が読めません。**進捗の連絡が来ないまま2〜3週間、というのは珍しくありません。**催促して構いません。**むしろ、**期日を確認する連絡は、丁寧な人という印象**になります。

## 面接に出てくる人と、その人が見ているもの

| 出てくる人 | 見ているもの |
|---|---|
| 理事長 | **法人の目的と、この人の関心が重なっているか** |
| 事務局長 | **明日から一緒に回せるか。**実務の手際 |
| 部門の責任者 | 担当する事業の中身が分かっているか |
| 非常勤の理事 | **外の目線。**組織に合いそうか |
| 経理の担当者 | 数字と書類を扱えるか |

**役所の採用面接と、いちばん違うのがここ**です。

**役所では、面接官は人事委員会や人事課の側**にいて、**配属先の人は出てきません。**法人では、**入ったあとに隣の席に座る人が面接に出てきます。**

**ですから、質問の性格が変わります。**「あなたの強みは」という抽象的な問いより、**「この事業を担当したら、最初の1か月で何をしますか」**のような、**実務に寄った問い**が増えます。

## 見られている観点は、5つに整理できます

| 観点 | 具体的に確かめられること |
|---|---|
| ① 目的への接続 | **定款の事業のどれに関わりたいか**を言えるか |
| ② 行政ではない理由 | 一時的な感情で動いていないか |
| ③ 一人で回せるか | **分掌の外を拾える構えがあるか** |
| ④ 相手の事情を読めるか | 行政・会員・寄附者と話せるか |
| ⑤ 条件の確認から逃げないか | **後から食い違わない人か** |

**③は、公務員から応募する方に必ず確認されます。**

**役所では、担当が分掌で区切られていました。**法人では、**「広報も経理も自分でやる」という場面**が出てきます。**ここに抵抗があるかどうかを、遠回しに聞かれます。**

**答え方は、経験に寄せてください。**

> 係の人員が減った年に、通常の担当に加えて、システムの更改の業務側の窓口と、新しい要綱の作成を兼務しました。手が回らない時期はありましたが、優先の順番を決めて、期限の近いものから処理していました。

**「やったことがある」と言えれば、それで足ります。**

**⑤は、意外と見られています。**給与や勤務の条件を聞かずに「やりがいがあれば」という応募者は、**法人の側から見ると、入ったあとに折り合わずに辞める懸念**として映ります。**条件は、堂々と確認してください。**

:::insight
選考の進め方でご相談が多いのが、**「催促してもよいものか」**という点です。**してください、というのが当社の見解**です。理由は、**この業界の法人には、応募者の管理を専任でしている人がいないことが多いから**です。事務局長が、通常の事業を回しながら採用も見ています。**連絡が止まっているのは、優先順位の問題であって、落選の合図ではない**ことがほとんどです。実際、**催促の連絡をしたら「すみません、理事会が来週なので、そこで諮ります」と返ってきた**という例を、何度も伺っています。**聞かなければ、その情報は出てきませんでした。**催促の文面は、**期日の確認の形**にするのが角が立ちません。「◯月◯日までに結論をいただけると、こちらの検討も進めやすいのですが、見通しはいかがでしょうか」。この書き方なら、**急かしている印象になりません。**そして、**この連絡自体が、選考の材料になります。**期日を確認して調整する行為は、**入ったあとに行政や会員と進める仕事と、同じ動作**だからです。黙って待っている応募者より、**動作を見せた応募者のほうが記憶に残ります。**
:::

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 場面 | 効く理由 |
|---|---|
| 理事会・評議員会の運営を聞かれる | **審議会・委員会の事務がそのまま重なる** |
| 行政との協議の進め方を聞かれる | **相手の意思決定の流れと時期を知っている** |
| 補助金・委託の実務を聞かれる | 交付する側・発注する側にいた |
| 規程や要綱の整備を聞かれる | 条文の形で書くことに慣れている |
| 説明の資料を求められる | **議会・住民への説明資料を作ってきた** |

**効きにくい場所**

| 場面 | 効きにくい理由 |
|---|---|
| 面接の場で数字を示すことを求められる | 役所では**成果を数で語る場面が少ない** |
| 「最初の1か月で何をしますか」 | **前例の無い状態から組み立てる問い** |
| 寄附・会員の増加について聞かれる | 経験が無い領域 |
| 兼務への構えを聞かれる | 分掌に守られてきた |

**2つ目は、事前に用意しておいてください。**

**答え方の型は、「聞く → 読む → 整理する」**です。

> 最初の1か月は、まず前年度の事業報告書と、現在進行中の案件の資料を読ませていただきます。そのうえで、関係する方に順に話を聞いて、いま誰が何を持っているかを整理します。手を入れるのは、その次だと考えています。

**いきなり改善案を語る答えは、評価が割れます。**中に入る前の提案は、**事情を知らないまま言っている**と受け取られることがあるためです。

## 準備の手順

| 順 | やること | 目安 |
|---|---|---|
| 1 | **定款と事業報告書**を読む | 1時間 |
| 2 | **事業計画書と収支予算書**を読む | 30分 |
| 3 | 応募する職が、**どの事業に紐づくか**を特定する | 30分 |
| 4 | ①〜⑤の観点で、**自分の答えを書き出す** | 1時間 |
| 5 | 「最初の1か月」の答えを**作っておく** | 30分 |
| 6 | **条件面で確認する項目**を3つ決める | 20分 |

**合計で4時間ほど**です。

**6つ目を必ずやってください。**その場で思いつかず、聞き逃したまま進むことが多い部分です。**給与の決まり方、その職の財源、就業規則の整備の状況。**この3つは、確認しておくと後が楽になります。

[経験の言い換えから相談する](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担です）。

## 逆質問で使えるもの

| 質問 | 何が分かるか |
|---|---|
| この職は、どの事業に紐づいていますか | **財源の期間** |
| 前任の方は、どういう経緯で離れましたか | 定着の状況 |
| 採用の決定は、どの会議で行われますか | **選考の見通し** |
| 入って最初に任せたいことは何ですか | 期待されている役割 |
| 職員の方の人数と、担当の分け方を教えてください | **兼務の度合い** |

**3つ目は、遠慮なく聞いて構いません。**理事会で決まるのか、理事長の決裁なのか。**答えを聞けば、待つ期間の見当がつきます。**

:::insight
ここまで対策の話をしてきましたが、**この業界の選考には、こちらからも見るべき点があります。**それは、**選考の進め方そのものが、その法人の仕事の進め方を映している**ということです。連絡の期日を示してくれるか、面接で聞かれたことに具体的な答えが返ってくるか、条件の質問をしたときに逃げずに答えるか。**この3つが揃わない法人は、入ったあとの進め方も同じ**である可能性が高いです。とくに、**条件の質問への答え方**は見ておいてください。「そこは追々」「うちは待遇より志で来てもらっています」という返し方をされた場合、**入ったあとに条件の話を持ち出しにくい組織**である可能性があります。逆に、**規程の該当箇所をその場で示してくれる法人**は、**内部の整備が進んでいる**と考えてよいです。選考は、**採点されるだけの場ではありません。**こちらも見ています。**合わないと判断して辞退することは、失礼ではありません。**そして、**いまの職に残るという結論**も、同じ資格で成り立ちます。受けてみて確かめた結果であれば、それは**情報が増えたうえでの判断**です。
:::

## まとめ

- **特定非営利活動促進法第15条**は、**理事3人以上・監事1人以上**を置くことを定めています
- **同法第17条**は、**定款に特別の定めが無ければ、業務は理事の過半数をもって決する**と定めています。**採用が理事会の議題になる法人があります**
- **同法第16条**により、**理事は原則として全員が代表権を持ち、定款で制限できます。**理事長に権限を集めている法人は、**即決することもあります**
- **「連絡が来ない」のは、落選の合図ではない**ことがほとんどです。**期日の確認の形で催促して構いません**
- **人事の担当者は、いないことが多い**です。**決定権のある人が最初から出てきます**
- 見られている観点は、**①目的への接続 ②行政ではない理由 ③一人で回せるか ④相手の事情を読めるか ⑤条件の確認から逃げないか**の5つです
- **「最初の1か月で何をしますか」は、事前に用意**してください。**聞く→読む→整理する**の順で答えます
- **選考の進め方は、その法人の仕事の進め方を映します。**こちらも見てください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 在職中です。面接の日程は調整してもらえますか

**調整してもらえることが多いです。**理由は、**この業界の法人が、在職中の応募者に慣れているから**です。職員の多くが他の職場から移ってきており、**平日の夜や土曜の面接に応じる法人もあります。**遠方であれば、**一次面接をオンラインで行う**という対応も一般的になっています。**申し出るときは、希望の時間帯を先に示すほうが早く決まります。**「平日の18時以降、または土曜であれば伺えます」という形です。なお、**理事が出てくる面接は、理事の都合に左右されます。**候補の日を複数もらったら、**早めに返すほうが調整が楽**です。日程の詰め方も、**調整の手際として見られています。**

### 求人が公募されていません。応募する方法はありますか

**問い合わせから始める方法があります。**この業界では、**公募せずに、知り合いの紹介や問い合わせから採用に至る**ことが少なくありません。人員に余裕が無く、**公募して選考する手間をかけられない**という事情もあります。問い合わせの形は、**「採用の予定があれば教えてほしい」という短い連絡**で足ります。そのときに、**どの事業に関心があるかを1〜2行添える**と、相手が判断しやすくなります。なお、**すぐに返事が無くても、記録には残ります。**半年後に欠員が出たときに連絡が来た、という例もあります。**急いで結論を求めない形での接点の作り方**として、覚えておいてください。

### 選考の途中で、条件が想定と違うと分かりました。どうすればよいですか

**その時点で確認してください。**進んでから戻るほうが、双方の負担が大きくなります。確認のしかたは、**「◯◯について、求人票では△△と拝見しましたが、実際の運用はいかがでしょうか」**という形です。**責めるのではなく、事実を合わせる**という並びにすると、話しやすくなります。多くの場合、**求人票の記載が古いか、書き方が曖昧だった**というだけです。そのうえで、**条件が合わないと判断したら、辞退して構いません。**選考の途中で辞退することは、**この業界では珍しくありません。**丁寧に理由を伝えて辞退した方が、**別の時期に改めて声をかけられた**という例もあります。無理に合わせて入るより、**そのほうが関係は続きます。**
