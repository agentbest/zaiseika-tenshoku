農業・食品の選考について、**公務員の方が戸惑う点**が2つあります。

**「求人票に、聞いたことのない資格が並んでいました」**

**「工場見学のあとで、白衣を着て現場に入りました」**

**どちらも、この分野では普通のこと**です。**そして、どちらにも理由があります。**

**資格が並ぶのは、法令で選任が義務づけられている職があるから。**現場に入るのは、**この分野の仕事が現場と切り離せないから**です。

この記事では、**選考の流れと、面接で見られている観点**を扱います。業界の構造は[未経験から農業・食品に入るには](industry-shokuhin-mikeiken.html)、志望動機の組み立ては[農業・食品の志望動機](industry-shokuhin-shiboudoki.html)にあります。

## 専任の管理者を置く義務がある施設があります

**食品衛生法第48条第1項**です。

> **乳製品、第十二条の規定により内閣総理大臣が定めた添加物その他製造又は加工の過程において特に衛生上の考慮を必要とする食品又は添加物であつて政令で定めるものの製造又は加工を行う営業者は、その製造又は加工を衛生的に管理させるため、その施設ごとに、専任の食品衛生管**理者を置かなければならない。

**「その施設ごとに、専任の」**です。

**[観光・地域振興の選考フローと、面接で見られている観点](industry-kanko-senko.html)で扱った旅行業務取扱管理者**や、**[物流の選考フローと、面接で見られている観点](industry-butsuryu-senko.html)の運行管理者**と、**構造が同じ**です。

**⚠ ただし、この義務の対象は、すべての食品の施設ではありません。**条文のとおり、**乳製品、内閣総理大臣が定めた添加物、その他「特に衛生上の考慮を必要とする食品又は添加物であつて政令で定めるもの」**の製造・加工を行う営業者です。

**⚠ 資格の要件については、所管する厚生労働省の公表を確認してください。**当社が確認していない内容は、この記事には載せていません。

**そして、品質保証や表示の管理の職種では、この資格が必須要件になっていない募集も多くあります。**

## 求人票の資格は、「必須」か「歓迎」かで読み分ける

| 書かれ方 | 意味 |
|---|---|
| **必須要件**の欄にある | **無いと応募できない** |
| **歓迎要件**の欄にある | **無くても応募できる** |
| 「取得支援あり」とある | **入ってから取る前提** |
| 「◯◯または同等の経験」 | **経験で代替できる** |

**4つ目の書き方が、この分野にもあります。**

**行政での食品営業の監視指導の経験**が、ここに当たる場合があります。**迷ったら、応募の前に問い合わせて構いません。**

**⚠ そして、総務・人事・経理・購買の職種では、これらの資格は関係ありません。**

## 選考の流れは、職種で分かれます

| 職種 | 流れの型 | 回数の目安 |
|---|---|---|
| 品質保証 | 書類 → 部門長 → **工場見学** → 役員 | **3回前後** |
| 表示の管理 | 書類 → 部門長 → 役員 | 2〜3回 |
| 総務・人事・経理 | 書類 → 人事 → 部門長 → 役員 | 3回前後 |
| 購買・調達 | 書類 → 部門長 → 役員 | 2〜3回 |
| 地域商社・産地の法人 | 書類 → 代表・責任者 | **1〜2回。速い** |
| 農業法人 | 書類 → 責任者 → **現場の体験** | 2回前後 |

**品質保証では、工場見学が選考に入る**ことが多いです。

**⚠ そして、見学にとどまらず、白衣・帽子・マスクを着けて製造の区域に入る**ことがあります。

**これは、双方の確認の工程**です。

| 見られていること | 確かめられていること |
|---|---|
| 入室の手順に従えるか | **決められた手順を守る人か** |
| 質問の中身 | **何に関心を持つ人か** |
| におい・温度・音への反応 | **毎日通える環境か** |
| 現場の方との接し方 | 管理部門としての立ち位置 |

**応募者の側も、ここで確認してください。**

**食品の工場は、品目によって環境がまったく違います。**冷蔵の区域が中心の工場、加熱の工程で高温になる工場、においが強い工場。**毎日通う場所として自分に合うかは、入らなければ分かりません。**

**⚠ 入室の手順には、必ず従ってください。**手洗い、粘着ローラー、履き替え。**ここでの振る舞いは、見られています。**

## 面接で見られている観点は、5つです

| 観点 | 具体的に確かめられること |
|---|---|
| ① 法令の経験の具体性 | **どの法令を、どの立場で扱ったか** |
| ② 現場との距離の取り方 | **指導する目線で来ないか** |
| ③ 事故への対応 | **起きたときに何をするか** |
| ④ 記録の作り方 | 検査に耐える書類を作れるか |
| ⑤ 勤務地の前提 | **工場・産地の所在地** |

**①は、公務員の強い持ち札**です。

**答え方は、法令名を必ず入れてください。**「食品衛生の事務」ではなく、**「食品衛生法にもとづく営業許可の審査を年間◯件、監視指導を◯件、有症苦情の調査を◯件」**です。

**②は、この分野で最も警戒される点**です。[農業・食品の志望動機](industry-shokuhin-shiboudoki.html)でも触れましたが、**「法令にもとづいて適切に指導します」という答え方は、評価を落とします。**

**「まず、記録を書いている場面を見せてください」**が、評価される答え方です。

**③は、品質保証の中核**です。

> 有症の申し出があった場合、まず発症の状況と喫食の状況を時系列で押さえます。並行して、該当する製造日の記録——原料の受入れ、加熱の温度と時間、従業員の健康の確認——を揃えます。この3つが揃っていないと、原因を絞り込めません。

**この答えができる方は、その場で評価が変わります。**

:::insight
選考に同席させていただいていて、**この分野で公務員の方がいちばん損をしている場面**があります。**「監視指導では、どういう施設が改善されにくいと感じましたか」**という質問への答え方です。多くの方が、**施設の側の問題**として答えられます。「記録が残っていない施設」「手順書が古いままの施設」。**内容としては正しいのですが、これだけでは半分です。**この質問で聞かれているのは、**「なぜ改善されないのか、その理由まで見ていたか」**です。評価される答えは、こうなります。「記録が残っていない施設には、共通して、記録の様式が作業の流れに合っていないという特徴がありました。記入する場所が作業台から離れている、書く欄が多すぎる、誰が書くか決まっていない。**様式を作り直した施設は、次の監視で改善されていました。**」⚠ **ここには、原因を構造で見る目と、改善の打ち手の両方が入っています。**そして、これは**入ったその日から使える知識**です。工場の側は、**自社の様式が使いにくいことに気づきにくい。**外から多数の施設を見てきた人だけが、比べられます。**「たくさん見てきた」ことが、この分野では価値になります。**
:::

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 場面 | 効く理由 |
|---|---|
| 法令についての質問 | **条文と運用の両方を知っている** |
| 検査・監査への対応 | **検査する側にいた** |
| 事故への対応の手順 | 調査の経験 |
| 書類の作り込み | 記録を残す習慣 |
| 多数の施設を見てきた経験 | **比べられる** |

**効きにくい場所**

| 場面 | 効きにくい理由 |
|---|---|
| 成果を数字で語る | **役所では個人の成果として記録されない** |
| 自己紹介を短く話す | 説明が経緯から始まりがち |
| 製品や工程についての質問 | 知識が無い |
| 原価についての質問 | 予算の執行とは見る方向が違う |

**3つ目は、正直に答えて構いません。****「知識はありませんので、まず工程を見せていただきながら、どの工程がどの管理点に当たるかを対応付けます」**で足ります。

## 準備の手順

| 順 | やること | 目安 |
|---|---|---|
| 1 | 扱った**法令名と件数**を書き出す | 1時間 |
| 2 | **「改善されにくい施設の共通点と、その理由」**を整理する | 1時間 |
| 3 | 応募先の**製品と工場の場所**を確認する | 1時間 |
| 4 | **事故が起きたときの手順**を、自分の言葉で書く | 30分 |
| 5 | **最初の3か月**の答えを作る | 30分 |
| 6 | **確認する項目を3つ**決める（勤務地・時間帯・呼び出し） | 20分 |

**2つ目が、この分野で最も効く準備**です。**面接でそのまま使えます。**

## 逆質問で使えるもの

| 質問 | 何が分かるか |
|---|---|
| 品質保証は何名の体制ですか | **一人あたりの負担** |
| 行政の監視への対応は、どなたが担当されていますか | **自分の位置づけ** |
| 事故が起きたときの連絡の手順はありますか | **備えの状況** |
| 繁忙期は、何で決まりますか | 生活の組み立て方 |
| 入って最初に引き受けてほしいことは何ですか | 期待されている役割 |

**3つ目は、聞く価値があります。**手順が定まっている会社と、**「そのときは考えます」という会社**では、**入ったあとの負担が違います。**

## 内定から入社まで

**労働基準法第15条第1項**により、**労働契約の締結に際して、賃金・労働時間その他の労働条件の明示**が求められます。**書面で条件を確認してください。**

**この分野で特に確認していただきたいのは、次の3つ**です。

| 確認すること | 理由 |
|---|---|
| 就業の場所（**工場・産地の所在地**） | 都市部から離れていることがある |
| **呼び出しの有無**（事故・苦情の発生時） | 品質保証では起こりうる |
| ⚠ **労働時間の規定の適用の有無** | **農業法人の場合**（[年収と働き方](industry-shokuhin-nenshu.html)参照） |

:::insight
ここまで対策の話をしてきましたが、**この分野を受けるときに、こちらからも見るべき点**があります。**工場見学のときに、現場がどう見えるか**です。整理整頓の状態、掲示物が更新されているか、記録が手の届く場所にあるか、作業している方が手順どおりに動いているか。**これは、監視指導をしてきた方なら、見慣れた観点**のはずです。**その目で、遠慮なく見てください。**理由は2つあります。1つは、**自分が入ったあとに担当する状態**だからです。整っていない工場に入るなら、**最初の仕事はそこを整えることになります。**それを承知で入るのと、知らずに入るのとでは、心構えが違います。もう1つは、**会社の姿勢が出るから**です。応募者に見せる工程ですら整っていない場合、**見せない場所の状態は推して知るべし**という判断ができます。逆に、**「ここはまだ改善の途中です」と正直に説明する会社**は、**中の議論が健全である可能性が高い。**⚠ そして、**合わないと判断して辞退することは、失礼ではありません。**確かめた結果、**いまの職に残るという結論**も、同じ資格で成り立ちます。当社が、いまの職を辞めることをお勧めすることはありません。
:::

## まとめ

- **食品衛生法第48条第1項**は、**乳製品、内閣総理大臣が定めた添加物その他「特に衛生上の考慮を必要とする食品又は添加物であつて政令で定めるもの」**の製造・加工を行う営業者に、**施設ごとに専任の食品衛生管理者を置く**ことを義務づけています
- ⚠ **すべての食品の施設が対象ではありません。****総務・人事・経理・購買の職種には関係しません**
- 求人票では、**必須要件か歓迎要件か**を見分けてください。**「◯◯または同等の経験」に、行政での監視指導の経験が当たる場合があります**
- **品質保証では、工場見学が選考に入り、製造の区域に入ることがあります。**⚠ **入室の手順には必ず従ってください**
- **見学は双方の確認の工程**です。**毎日通える環境かを、こちらも見てください**
- 見られている観点は、**①法令の経験の具体性 ②現場との距離の取り方 ③事故への対応 ④記録の作り方 ⑤勤務地の前提**の5つです
- ⚠ **①は法令名と件数を入れて**答えてください。②で**「適切に指導します」と答えないでください**
- ⚠ **「改善されにくい施設の共通点と、その理由」**を整理しておいてください。**多数の施設を見てきたことが、この分野では価値になります**
- ⚠ **呼び出しの有無と、農業法人の場合は労働時間の規定の適用**を確認してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 在職中です。工場見学の日程は調整してもらえますか

**調整してもらえることが多いです。**ただし、**工場は製造の計画があるため、面接ほど自由には動かせません。**候補の日を複数もらったら、**早めに返すほうが調整が楽**です。⚠ **稼働していない日に見ても、実際の環境は分かりません。**可能であれば、**稼働している平日に休暇を取って行く**ほうが、見る価値があります。遠方の場合は、**一次面接をオンラインで行い、二次で現地**という組み方が一般的です。なお、**製造の区域に入る場合、健康状態の申告を求められる**ことがあります。当日の体調に不安があれば、**無理をせず申し出てください。**食品の工場では、それが正しい振る舞いです。

### 資格を取ってから応募すべきですか

**必須要件でなければ、先に応募して構いません。**この分野の中途採用では、**実務の経験が先に見られます。**行政での許可の審査、監視指導、事故の調査。**これらの経験があるなら、資格の有無で足切りされない募集があります。**⚠ **ただし、必須要件に挙げられている募集には応募できません。**求人票で確認してください。⚠ **資格の要件については、所管する厚生労働省や実施する機関の公表を確認してください。**当社が確認していない内容はお伝えできません。なお、**「取得支援あり」と書かれている会社**は、**入ってから取る前提**で採用しています。この場合、**学習を始めていることを伝える**と、意欲が伝わります。

### 現場の作業を経験しないと、管理はできないと言われました

**会社によって考え方が違います。**「まず製造の現場を経験してもらう」という方針の会社もあれば、**「管理の経験がある人を管理の職として採る」**という会社もあります。**どちらが正しいという話ではありません。**確認のしかたは、面接で**「入社後、製造の現場を経験する期間はありますか」**と聞くことです。期間が決まっているなら、**その後にどの職に就くのか**もあわせて確認してください。⚠ **「いずれ品質保証に」という口約束だけで入るのは避けてください。**期間と、その後の職について、**書面か、少なくとも具体的な説明**をもらってください。なお、**一定期間現場を見ること自体は、この分野の管理の仕事に確実に効きます。**
