**事業を担当してきた方から、「管理の経験をどう証明するか」**というご相談を伺います。

**証明の手段は、資格だけではありません。**

この記事では、**手段の選び方**を扱います。

**⚠ 受験・更新の要件と手続は、実施する団体の公表を確認してください。****この記事では、個別の要件には触れません。**

## 複数年度の事業は、予算で定めます

**地方自治法第214条**です。

> **歳出予算の金額、継続費の総額又は繰越明許費の金額の範囲内におけるものを除くほか、普通地方公共団体が債務を負担する行為をするには、予算で債務負担行為として定めておかなければならない。**

**翌年度以降に債務を負担する行為は、予算で定めておく**という仕組みです。

**つまり、複数年度にわたる事業は、着手の前に議決を経ている**ということです。

**期間、総額、内容が、あらかじめ決まっている状態で進む。**

**この枠組みの中で事業を回した経験は、プロジェクト管理の型と重なります。**

**期間と予算が決まっている中で、範囲を管理し、期限内に終える。**

**民間の案件でも、同じ構造**です。

## 証明の手段は3つ

| 手段 | 内容 |
|---|---|
| ① 実績で示す | **規模、期間、関係者の数、結果** |
| ② 資格で示す | 要件を満たす場合 |
| ③ 両方 | 実績＋資格 |

**①が基本**です。

**②は、実績を補うもの**と考えてください。

**③が最も強い**形ですが、**①だけでも応募はできます。**

**扱いは**[プロジェクト管理｜計画策定の経験を型として使う](skill-projectkanri.html)**に整理しています。**

## 実績で示すときの材料

| 材料 | 書き方の例 |
|---|---|
| ① 規模 | **予算約◯億円、関係課◯課、事業者◯者** |
| ② 期間 | ◯か年、または◯か月 |
| ③ 体制 | 職員◯名、委託の範囲 |
| ④ 工程の管理 | 月次で確認、遅れへの対応 |
| ⑤ 変更の扱い | 変更の契約、範囲の調整 |
| ⑥ 結果 | 完了、成果、振り返り |

**①と⑤が中心**です。

**⑤について。**

**当初の計画どおりに終わらなかった場面で、何を基準に決めたか**を書いてください。

**範囲を絞った、期限を延ばした、費用を追加した。**

**いずれも、管理の判断**です。

## 資格で示すときの前提

| 確認すること | 内容 |
|---|---|
| ① 受験の要件 | **実務の経験の年数と内容** |
| ② 行政での実務の扱い | 要件に算入されるか |
| ③ 更新の要否 | 継続の手続があるか |
| ④ 応募条件の記載 | 必須か、歓迎か |
| ⑤ 費用と期間 | 準備にかかるもの |

**①と②が要**です。

**⚠ 要件と手続は、実施する団体の公表を確認してください。**

**人づての情報で判断しないでください。**

**③について。**

**更新の手続が必要な資格では、維持にも手間がかかります。**

**続ける前提があるかを、先に考えてください。**

:::insight
管理の経験について、**面談でお伝えしているのが「資格より、規模と変更の扱いです」**という点です。**「管理の経験を客観的に示したい」というご相談**を受けます。ところが、**中途採用で見られているのは、資格の有無より、どの規模の案件を、どう進めたか**です。予算の額、関係した課や団体の数、委託事業者の数、期間。**この4つを並べれば、規模は伝わります。**そして、**もう1つ効くのが、計画どおりに終わらなかったときの判断**です。行政の事業では、**補正や変更の契約、繰越し**といった手続を経験しているはずです。**これは、民間の案件で言えば、範囲や期限を組み直す判断**にあたります。書類には、**「工期の変更が生じた際、優先する範囲を整理したうえで変更の契約を締結」**と書いてください。**資格は、この実績を補うもの**です。順序を逆にしないでください。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 書くときの注意

| 注意 | 内容 |
|---|---|
| ① 取得の年を書く | いつ取ったか |
| ② 更新の状況 | **有効かどうか** |
| ③ 実績と併記 | **資格だけを書かない** |
| ④ 規模を数で | 予算、人数、期間 |
| ⑤ 立場を明記 | 発注者か、受注者か |

**⑤が重要**です。

**行政での管理は、発注する側の立場**です。

**受注する側の管理とは、担う範囲が違います。**

**「発注者として、工程の管理と受入れの確認を担当」**と、立場を明記してください。

**扱いは**[契約書の読み方｜自治体の契約実務との差](skill-keiyakusho.html)**に整理しています。**

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 行政が相手の事業 | **年度と手続の前提が分かる** |
| ② 導入の支援 | 工程、関係者の調整 |
| ③ 建設・施設の分野 | 工期、予算、検査 |
| ④ 事業の推進 | 計画から実行まで |
| ⑤ 受託の管理 | 履行、変更、報告 |

**①について。**

**行政を相手とする案件は、年度で区切られ、議会の日程に影響されます。**

**債務負担行為や繰越しの仕組みを知っている人**は、工程を現実的に引けます。

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 実績の整理 | **規模、期間、体制、結果** |
| 変更の場面の整理 | 何を基準に決めたか |
| 要件の確認 | 実施する団体の公表 |
| 求人を読む | 週に30分 |

**1行目を先にしてください。**

**予算の資料や決裁の文書から、金額と期間を確認**してください。

**根拠のない数は書かないでください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 規模 | **予算、関係者の数、期間** |
| 遅れへの対応 | 3件、原因と処置 |
| 変更の扱い | 手続と、影響の評価 |
| 関係者の巻き込み方 | 誰に、どの順で |
| 立場 | **発注者か、受注者か** |

**2行目です。**

**計画どおりに進まなかった案件**は、必ず聞かれると考えて用意してください。

**なお、特定の事案が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

## 行政の管理で身についていること

| 習慣 | 民間での意味 |
|---|---|
| ① 期間と総額が先に決まる | **枠の中で組み立てる** |
| ② 議決・決裁を経る | 承認の手続を踏む |
| ③ 進捗を定期に報告する | 経営層への報告 |
| ④ 変更に手続が要る | 変更の管理 |
| ⑤ 完了を検査で確認する | 検収の観点 |
| ⑥ 結果を公表する | 振り返りと説明 |

**①が、民間の案件と最も近い**部分です。

**予算と期間が決まった状態で始まるため、範囲の調整で帳尻を合わせる**ことになります。

**この感覚は、そのまま使えます。**

**④について。**

**変更に手続が要る環境で進めてきた**ため、**勝手に範囲を広げない**という習慣があります。

**民間でも、範囲が曖昧なまま進んで費用が膨らむ事例があります。**

## よくある失敗

**1. 資格だけで示そうとする**

**実績が基本**です。

**2. 規模を書かない**

**予算、人数、期間**を書いてください。

**3. 変更の扱いを書かない**

**管理の判断**です。

**4. 立場を書かない**

**発注者か受注者か**を明記してください。

**5. 受験の要件を人づてで判断する**

**実施する団体の公表**を確認してください。

**6. 更新の手続を考えない**

**維持にも手間**がかかります。

**7. 実績の整理より受験を先にする**

**書ける材料**を並べてください。

**8. 取れば転職できると考える**

**どの規模をどう進めたか**が評価の対象です。

:::insight
ここまで「実績が基本」という話をしておいて逆のことを言いますが、**資格が効く場面もあります。**面談で拝見していると、**行政の事業の規模が、民間の読み手に伝わりにくい**という場面があります。予算の額が大きくても、**「役所の事業だから」と割り引かれることがある。**一方、**共通の枠組みで示された資格**は、**業界をまたいで理解されます。**ですから、**分野を大きく変える転職**や、**行政と関わりの薄い会社に応募する場合**には、資格が補いになります。逆に、**行政を相手とする事業に応募するなら、実績のほうが直接伝わります。**相手が、その規模と手続の意味を知っているからです。**どちらに応募するかで、優先順位が変わります。****応募先を決めてから、取得を検討してください。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方自治法第214条**は、**翌年度以降に債務を負担する行為は、予算で債務負担行為として定めておかなければならない**としています
- **複数年度の事業は、期間・総額・内容が決まった状態で進みます。**この枠組みでの経験は、管理の型と重なります
- 証明の手段は、**①実績 ②資格 ③両方**です。**①が基本**です
- 実績では、**規模・期間・体制・工程の管理・変更の扱い・結果**を書いてください
- **計画どおりに終わらなかったときの判断**が、管理の中身です
- **立場（発注者か受注者か）を明記**してください
- **分野を大きく変える場合には、資格が補いになります**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 大規模な事業を担当したことがありません

**規模より、型が一巡しているかを書いてください。**小さな事業でも、**目的の設定、計画、実行、進捗の確認、報告**は同じです。「◯◯事業（予算約◯百万円、関係課◯課）を担当し、計画の作成から実施、決算の資料の作成までを一貫して担当」という形です。**一貫して担った**という点は、規模の大きい組織では得にくい経験です。なお、**複数の事業を同時に担当していた**場合、その数も書いてください。**並行して進める力**として読まれます。扱いは[プロジェクト管理｜計画策定の経験を型として使う](skill-projectkanri.html)に整理しています。

### 受験の要件を満たしているか分かりません

**実施する団体の公表を確認してください。**受験や更新の要件は、**実務の経験の年数や内容で定められていることがあります。**どの職務が該当するかは、**公表されている案内で確認**するのが確実です。**人づての情報や、以前の記憶で判断しないでください。**なお、**準備に時間と費用がかかる**場合があります。**応募の時期が決まっているなら、間に合うかを先に確認**してください。扱いは[選考スケジュールの組み方](senko-sagasu-schedule.html)に整理しています。

### 委託事業者に任せていた部分は、書けますか

**管理した側として書いてください。**「委託事業者◯者に対し、仕様に基づく履行の確認と工程の調整を実施。遅れの見込まれる工程について、代替の手順を協議のうえ決定」という形です。**自分が手を動かしていなくても、判断と調整は担っています。**なお、**発注する側の立場**であることを明記してください。**受注する側の管理とは、担う範囲が違います。**扱いは[契約書の読み方｜自治体の契約実務との差](skill-keiyakusho.html)に整理しています。**「任せていた」ではなく「管理していた」**と書いてください。
