建築指導課の経験は、求人票の言葉に直すと**まったく別の名前**で呼ばれています。

**「建築確認、建築指導に関する業務」**

**この書き方では、民間の採用担当には何も伝わりません。**

実際にやっていたのは、**図面と条文を突き合わせて、建てられるかどうかを判定し、建った後も基準を満たしているかを確かめる**という仕事です。

**そして、この判定ができる人は、民間の側にも多くありません。**

この記事では、**庁内の呼び名を民間の言葉に置き換え、中核スキルを5つの工程に分けて**整理します。

## 「最低の基準を定めて」

最初に、この仕事の立ち位置を条文で押さえます。**経験の値を決める部分**です。

建築基準法第1条は、目的をこう定めています。

**この法律は、建築物の敷地、構造、設備及び用途に関する最低の基準を定めて、国民の生命、健康及び財産の保護を図り、もつて公共の福祉の増進に資することを目的とする。**

**「最低の基準を定めて」。**

**ここが要点です。**

**この法律は、「良い建物」を定めているのではありません。****ここから下は許さない、という線を定めています。**

**つまり、扱ってきたのは、「最低限を満たしているかどうか」の判定です。**

**これは、民間でいえば、品質の基準の適合性の確認**にあたります。

**そして、この構造には、2つの意味があります。**

**1つ目は、基準を満たしていれば、原則として認めなければならない**ということです。**気に入らないから通さない、ということができません。**

**2つ目は、基準を満たしていなければ、どんな事情があっても通せない**ということです。**期限が迫っていても、費用がかかっていても、変わりません。**

**この「裁量のない判定」を、毎日やってきた**——**それが、この経歴の値です。**

**民間では、この判定を外部に頼っています。**そして、**頼る前に社内で見当を付けられる人がいれば、手戻りが減ります。**

## 民間での訳語

| 庁内での呼び名 | 民間での呼ばれ方 |
|---|---|
| 建築確認の審査 | **法令適合性の確認・法規のチェック** |
| 構造の審査 | **構造の安全性の確認** |
| 中間検査・完了検査 | **工程の検査・竣工の検査** |
| 建築の相談 | **計画の初期段階の法規の相談** |
| 定期報告の受理と確認 | **設備・建物の維持の管理の確認** |
| 違反の建築物への対応 | **是正の指導・不適合への対応** |
| 特定行政庁としての事務 | **許認可の実務** |
| 道路の位置の指定 | **接道の要件の整理** |
| 用途の変更の審査 | **用途の適合性の判定** |
| 既存不適格の判断 | **既存の建物の法令上の扱いの整理** |
| 建築計画概要書の閲覧 | **建物の履歴の情報の管理** |
| 耐震改修の促進 | **既存の建物の安全性の向上の支援** |

**上から4行目までが、いちばん値の付く並び**です。**図面と条文を突き合わせて可否を判定し、現地で確かめる**——**これは、設計でも施工でも、必ず必要になる機能です。**

## 中核スキルを5つの工程に分ける

**この部署の中核は、「図面と現物が、基準に適合しているかを判定すること」**です。

**工程1：読む（図面と条文を突き合わせる）**

配置図、平面図、立面図、断面図、構造の計算書。それに対して、**用途、建ぺい率、容積率、高さ、斜線、日影、採光、換気、防火、避難、構造。**

**この工程に固有の制約があります。****確認すべき項目が、非常に多い。**そして、**そのうち1つでも見落とすと、建った後に問題になります。**

だから、**順番と、チェックの形が決まっていきます。**どの図面から見るか、どの数字を先に確かめるか。

**これは、民間の品質の確認でも同じです。****項目が多い検査を、漏れなく、同じ品質で繰り返す**——**その技術が問われます。**

**工程2：確かめる（現地と、実物を見る）**

中間の検査、完了の検査、違反の疑いがある建物の現地の確認。

**この工程に固有の制約があります。****図面どおりに建っているとは限りません。**そして、**完成してからでは見えない部分があります。**だから、**中間の検査は、隠れてしまう前に見ます。**

**「見えなくなる前に確かめる」**——**これは、民間の施工の管理や、設備の検査と、まったく同じ考え方**です。

**工程3：相談に応じる（申請の前に、見当を付ける)**

計画の初期段階での相談、他法令との関係の整理、必要な手続の案内。

**この工程に固有の制約があります。****この段階では、まだ図面が固まっていません。**だから、**確定的なことは言えません。**しかし、**方向が違っていれば、早く言わなければ相手が損をします。**

**つまり、「断定はできないが、方向は示す」という話し方が必要**になります。

**これは、民間の相談の場面でも、そのまま求められる技術**です。

**工程4：直させる（違反と、不適合への対応）**

違反の建築物への指導、是正の計画の確認、経過の記録。

**この工程に固有の制約があります。****すでに建っているものを直すのは、造るより難しい。**費用も、時間も、居住している人の事情もあります。**そして、相手は納得していないことが多い。**

だから、**「何がどう基準に合っていないか」を、書面で正確に示す**ところから始まります。**感情ではなく、条文と数字で話す。**

**この経験は、民間の不適合への対応や、品質の問題の処理で、そのまま同じ形をしています。**

**工程5：記録する（情報を残し、公開する）**

建築計画概要書の管理と閲覧、台帳の整備、定期報告の受理。

**この工程に固有の制約があります。****建物は数十年残るので、記録も数十年必要です。**そして、**後から「この建物は適法か」を問われます。**増築のとき、売買のとき、相続のとき。

**つまり、この記録は、将来の取引の前提になります。**

:::insight
この経歴でいちばん多い損は、**「建築確認の事務」と書いてしまう**ことです。この一言だと、**書類を受け付けていた人**に読まれます。実際にやっていたのは、**図面と条文を突き合わせて、適合しているかを判定すること**でした。しかも、**確認すべき項目は数十あり、1つの見落としが建物の安全に直結します。**書くなら、**「建築確認の申請を年間◯件審査し、用途・形態の制限・構造・防火・避難の各項目について適合を判定。中間検査と完了検査を年間◯件実施」**という形です。**とくに「件数」を書いてください。**面談で伺うと、**皆さん件数を即答されます。**それだけ日常的な数字なのに、**書類には書かれていません。****そして、民間の設計事務所や施工会社では、「何件見たか」が経験の量として読まれます。**新人が見る件数と、十年見た人の件数では、**判定の速さも、気づく点も違います。**その差が、そのまま値になります。
:::

## 民間の法規の確認・品質の管理と、どこが同じでどこが違うか

**同じところ**

1. **項目が多い確認を、漏れなく繰り返す。**チェックの形を作ることが技術になります
2. **図面と現物を突き合わせる。**図面どおりとは限りません
3. **不適合を、書面で正確に示す。**感情ではなく、条文と数字で

**違うところ**

1. **裁量がない。**基準を満たせば認め、満たさなければ通しません
2. **相手を選べない。**申請してきた人は、すべて対象です
3. **納期を動かせない。**審査には期間の定めがあります
4. **見落としの責任が、行政に及ぶ。**確認した以上、そこに責任が生じます

**1番目が、民間との最大の違い**です。

民間の側では、**「どうすれば通るか」を考えます。**行政では、**「通るか通らないか」だけを判定します。**

**この違いを理解していることが、民間に移ったときにそのまま効きます。**

**なぜなら、「通らないもの」を早く見分けられるからです。**

## 評価が高くなりやすい4つの方向

**1. 設計事務所・組織設計（法規の担当）**

**法規の確認を専門に担う役割**があります。**確認申請の前に、社内で適合を見る仕事**です。**審査する側にいた人は、この役割でそのまま通用します。**

**2. 指定確認検査機関**

**建築確認と検査を、民間で行う機関**です。**業務の中身が、行政でやっていたこととほぼ同じ**になります。**この経歴の、いちばん直接的な行き先**です。

**3. ハウスメーカー・建設会社（技術の管理・品質の管理）**

**現場が基準に適合しているかを確認する役割**です。**検査の経験と、違反への対応の経験**が効きます。

**4. 不動産（デューデリジェンス・既存の建物の調査）**

**既存の建物が適法かどうかを調べる仕事**です。**既存不適格の判断や、建築計画概要書の読み方**を知っている人は、**この分野では希少です。**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## つまずきやすい点

**1. 「建築確認の事務」と書く**

**「図面と条文を突き合わせた適合の判定」**です。**そう書いてください。**

**2. 件数を書かない**

**民間では、何件見たかが経験の量として読まれます。**

**3. 検査の経験を埋もれさせる**

**「見えなくなる前に確かめる」**——**施工の管理と同じ考え方**です。

**4. 違反への対応を、揉め事として扱う**

**条文と数字で不適合を示した**——**品質の問題の処理と同じ形**です。

**5. 裁量がなかったことを、弱みとして話す**

**裁量がないからこそ、通らないものを早く見分けられます。**

自分の経歴がどう言い換えられるかは、一度話しながら整理したほうが早いことが多いです。[どの経験に値が付くのかから相談できます](../apply.html)。

:::insight
ここまで書いておいて逆のことを言いますが、**この経歴は、資格の有無で行き先の幅が大きく変わります。**建築基準法に関わる仕事の多くは、**建築士の資格を前提としています。**とくに、**指定確認検査機関の確認検査員**は、**建築基準適合判定資格者**——**いわゆる判定士**——の資格が要件になります。そして、**この資格の受験には、建築士の資格と実務の経験が必要**です。**つまり、在職中に受けておくかどうかで、選べる範囲がまったく違ってきます。**面談で伺うと、**「受けようと思いながら、忙しくて」とおっしゃる方が多くあります。**しかし、**行政にいる間のほうが、実務の経験の要件を満たしやすく、周りに受けた人もいます。****もし、この分野で長く続けるつもりがあるなら、資格を取ってから動くほうが、選べる求人がはっきり増えます。**急いで動く理由がないなら、**その順番のほうが有利です。**応募先が決まっていない段階のほうが、整理する意味があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 建築基準法第1条は、**「最低の基準を定めて」**と定めています。**良い建物ではなく、ここから下は許さないという線**です
- つまり、扱ってきたのは、**「最低限を満たしているかどうか」の判定**——**民間でいう適合性の確認**です
- **基準を満たせば認め、満たさなければ通さない。****この裁量のない判定を、毎日やってきました**
- 中核スキルは、**①読む ②確かめる ③相談に応じる ④直させる ⑤記録する**の5工程に分かれます
- 違うのは、**①裁量がない ②相手を選べない ③納期を動かせない ④見落としの責任が及ぶ**の4点です
- **審査と検査の件数**は、**民間では経験の量として読まれます。**必ず書いてください

## よくある質問

### 事務職で、図面の審査はしていません。書けることはありますか

**十分に書けます。**建築指導課の事務は、**申請の受付、手数料、台帳の管理、建築計画概要書の閲覧、定期報告の受理、統計の報告**など、**判定以外の実務が広くあります。**とくに、**建築計画概要書の閲覧**は、**不動産の取引で必ず使われる情報**です。**誰が、何のために閲覧に来るかを知っていること**は、**不動産の調査の分野でそのまま役に立ちます。**書くなら、**「建築確認に係る申請の受付と台帳の管理、建築計画概要書の閲覧の対応を年間◯件担当」**という形です。

### 違反の建築物への対応が中心でした。どう書けばよいですか

**「不適合への対応と、是正の管理」**として書いてください。中身は、**①通報や発見の端緒 ②現地の確認と記録 ③何がどう基準に合っていないかの特定 ④文書での通知 ⑤是正の計画の確認 ⑥経過の記録**の6つです。**これは、民間の品質の問題への対応と、まったく同じ工程**です。とくに、**「相手が納得していない状態で、条文と数字で話を進める」**という部分は、**経験がないとできません。**書くなら、**「違反の疑いのある建築物について、年間◯件の現地の確認と記録、文書による通知、是正の経過の管理を担当」**という形です。**個別の案件や、所有者が特定できる書き方は避けてください。**

### 建築士の資格を持っていません。不利になりますか

**方向によります。****指定確認検査機関の確認検査員や、設計の実務**は、**資格が要件**です。一方、**不動産の調査、建物の管理、自治体を顧客とする企業、建築計画概要書を扱う業務**では、**資格がなくても、制度と実務を知っていることが評価されます。**また、**建設会社の技術の管理の部門**では、**現場の経験と組み合わせて見られる**ため、資格が必須の条件ではないこともあります。**まず、資格がなくても入れる方向を確かめて、必要であれば働きながら取る**——この順番も現実的です。行き先の絞り方は[建築指導課から転職しやすい業界と職種](dept-kenchiku-tenshokusaki.html)に整理しました。
