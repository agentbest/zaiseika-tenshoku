監査委員事務局からの転職では、**この経歴の強さが本人に自覚されていない**ことが、いちばんもったいない点です。

「監査委員の補助をしていました」と言う方が多いのですが、実際にやっていたのは、**年間の監査計画を組み、資料の提出を求め、帳票と実態を突き合わせ、指摘を文書にし、是正されたかを確認する**という一連の作業です。

**これは、企業の内部監査部門の仕事そのものです。**

しかも、**内部監査の経験者は、民間の中途採用市場で常に不足しています。**

この記事では、その対応を整理します。訳語の対応表、中核スキルの工程分解、そして**企業の内部監査とどこが同じでどこが違うか**まで扱います。

## 「代表監査委員が任免する」職員であることが、立ち位置を決めています

まず、この部署の立ち位置を条文で確認します。**民間に説明するときの、いちばん強い材料**です。

地方自治法第200条は、監査委員の事務局について定めています。

**都道府県の監査委員に事務局を置く。市町村の監査委員に条例の定めるところにより、事務局を置くことができる。**

そして、こう続きます。

**事務局長、書記その他の職員は、代表監査委員がこれを任免する。**

**市長ではなく、代表監査委員が任免します。**

さらに、同条は**事務局長は監査委員の命を受け、書記その他の職員又は第百八十条の三の規定による職員は上司の指揮を受けて、それぞれ監査委員に関する事務に従事する**と定めています。

**これが何を意味するか。**

監査委員事務局は、**監査される側（市長部局）の人事から切り離されています。**

企業の内部監査でも、**独立性をどう担保するか**は最大の論点です。社長直轄にする、取締役会に直属させる、報酬や人事を執行から切り離す。**どの会社も工夫している部分**です。

**その独立性が、法律で最初から与えられている組織にいた**ということになります。

**この一点を最初に言えるかどうか**で、説明の通りやすさが変わります。

## 民間での訳語

履歴書や職務経歴書では、**自治体の中でしか通じない言葉を、募集要項に出てくる言葉に置き換えます。**

| 自治体での呼び方 | 民間での呼ばれ方 |
|---|---|
| 定期監査・財務監査 | 内部監査（財務監査） |
| 行政監査 | 業務監査、オペレーショナル監査 |
| 例月出納検査 | 月次の出納・現預金の検証 |
| 決算審査 | 決算内容の確認、監査対応 |
| 健全化判断比率の審査 | 財務指標のレビュー |
| 監査計画の策定 | 年間監査計画の立案 |
| 監査の実施（往査） | 現地往査、実査 |
| 資料の提出要求 | 証憑の徴求 |
| 監査結果報告・意見の提出 | 監査報告書の作成、改善提言 |
| 措置状況の確認・公表 | 是正措置のモニタリング |
| 指定管理者・補助金交付先の監査 | 委託先・関係会社の監査 |
| 住民監査請求の処理 | 申立て・内部通報の調査 |

**「監査委員の補助」ではなく、「内部監査の実務」と置き換える**のが基本です。それだけで、対応する求人が見えてきます。

## 中核スキルを5つの工程に分ける

この部署の仕事は、**5つの工程**に分解できます。**企業の内部監査の工程と、ほぼ同じ形**です。

**① 年間の計画を組む**

どの部署を、いつ、どの観点で監査するか。**すべてを毎年見ることはできないので、優先順位をつけます。**

前年度の指摘、予算の規模、契約の件数、過去の事故。**どこに危険があるかを見立てて、限られた回数を配分する**工程です。

**② 資料を求める**

「関係書類を出してください」では、監査は進みません。**どの帳票の、いつからいつまでの、どの範囲を求めるか**を特定します。

**求める資料を特定できるかどうかで、監査の深さが決まります。**

**③ 突き合わせる**

帳票と現物。規程と実態。予算と執行。契約書と検査調書。

**「書いてあること」と「行われたこと」が一致しているかを見る**工程です。**ここが監査の本体**になります。

そして、**差が見つかったときに、誤りなのか、運用上そうなっているだけなのかを切り分けます。**規程どおりでない処理にも、合理的な理由がある場合があります。**切り分けずに全部を指摘にすると、報告が読まれなくなります。**

**④ 報告に書く**

見つかったことを文書にします。**このとき、「指摘」と「意見」を分けます。**

**指摘は、是正が必要なもの。意見は、改善が望ましいもの。**この区別を誤ると、相手が動きません。**強く書きすぎても、弱く書きすぎても効果が落ちます。**

**書く前に、事実関係を相手方に確認する**のも工程の一部です。認識の食い違いを報告に載せてしまうと、是正そのものが進みません。

**⑤ 是正を確認する**

指摘に対して、どう措置したかを確認します。**そして、措置の状況は公表されます。**

**報告して終わりではなく、直ったかどうかまでを見る。**ここまでが工程です。

## 企業の内部監査と、どこが同じでどこが違うか

**同じところ**

**1. 独立性が、仕組みとして担保されている**

**監査される側の人事から切り離されている**という設計は、企業の内部監査でも同じです。**第200条がそれを法律で定めている**ぶん、自治体のほうが徹底しています。

**2. 計画 → 往査 → 報告 → フォローアップというサイクル**

**年間計画を立て、現地で調べ、報告書を書き、是正を確認する。**この4段階は、企業の内部監査でもまったく同じです。

**3. 指摘は、受け入れられて初めて意味を持つ**

**正しいことを書いても、相手が動かなければ何も変わりません。**だから、書き方と、事前のすり合わせが仕事の一部になります。**この感覚を持っている人は、民間でも多くありません。**

**違うところ**

**1. 監査の結果が公表される**

企業の内部監査の報告書は、社内文書です。**自治体の監査結果は公表されます。**

**外に出る前提で書く**という訓練を受けているのは、**この経歴の強み**です。開示を扱う部門でも効きます。

**2. 外部から申立てを受ける仕組みがある**

住民監査請求という、**住民が直接、監査を求められる仕組み**があります。企業でいえば、**内部通報や株主からの申立てに近い**ものです。

**申立てを受けて調査し、結論を出し、公表する。**この経験は、企業のコンプライアンス部門で高く読まれます。

**3. 監査の主体は合議体であり、事務局は補助職員**

監査委員は複数人の合議体で、識見を有する者と議員から選ばれます。**事務局は、その判断を支える立場**です。

**「自分が指摘したのではなく、監査委員の判断を実務として組み立てた」**という整理になります。ここは正確に言ってください。**ただし、実務の中身は事務局が担っている**ので、工程として書けば経験として十分に通ります。

:::insight
監査委員事務局の方が職務経歴書で損をしやすいのは、**「補助」という言葉を使ってしまうこと**です。地方自治法上の役割としては正確なのですが、**書類に「監査委員の補助業務」と書くと、資料をそろえていた人に読まれます。**実際には、計画の案を作り、資料の求め方を決め、突合を実施し、報告の原案を書いているのが事務局です。書き方としては、**「監査委員の判断のもと、年間◯件の監査について、計画の立案から往査、報告書の原案作成、措置状況の確認までの実務を担当」**のように、**判断の主体は監査委員だと明示したうえで、実務の範囲を全部書いてください。**この書き方なら、正確さも保たれ、経験の幅も伝わります。**「補助」の一語で丸めることが、いちばん損をします。**
:::

## 評価が高くなりやすい4つの方向

**1. 企業の内部監査部門**

**いちばん直線的につながる方向**です。計画、往査、報告、フォローアップ。**工程が同じ**なので、説明がそのまま通ります。

**内部監査は経験者が不足している領域**なので、**未経験から育てるより、公的機関での経験がある人を採る**という判断が働きます。

**2. 経理・会計、決算の実務**

**決算審査と例月出納検査**の経験です。**出納の実在性を月次で検証する**という作業は、企業の月次決算の統制とそのまま重なります。

**財務諸表を読む力**があることも、この方向では前提として評価されます。

**公会計の経験は、そのままでは企業会計に置き換わりません。**ただし、**「数字の裏づけを帳票までたどる」という習慣**は共通なので、そこを前に出してください。

**3. リスク管理・コンプライアンス**

**住民監査請求の処理**の経験が効きます。**申立てを受け、事実関係を調べ、結論を出し、公表する。**企業の内部通報対応と構造が同じです。

**4. 自治体を顧客にする企業・監査法人の公会計部門**

包括外部監査の支援、公会計の整備、自治体向けの内部統制の支援。**自治体の監査の実際を内側から知っていること**が、そのまま提案の材料になります。

[財政・会計の経験が効く求人を見てみる](../?fin=1)

:::insight
方向を決めるときに、**残る判断のほうが妥当だと感じる場面**もあります。監査委員事務局は、**一巡に一年かかる部署**です。年間の監査計画、定期監査、例月出納検査を12回、決算審査、健全化判断比率の審査。**丸一年を通して、ようやく主要な工程が一度ずつ回ります。**さらに、**住民監査請求を一度でも処理しているかどうか**で、コンプライアンス方向の説明力が変わります。これは件数が読めないので、**在籍中に当たるかどうかは運**でもあります。まだ一巡していない段階なら、**書類に書ける件数そのものが足りません。**一方で、一巡していて、簿記の学習も進んでいるなら、**内部監査は経験者が不足している領域なので、早めに動くほうが選択肢は多くなります。**在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## つまずきやすい点

**1. 「監査委員の補助」と書く**

**判断の主体は監査委員だと明示したうえで、実務の範囲を全部書いてください。**

**2. 独立性を書かない**

**第200条で代表監査委員が任免する**という一点が、内部監査方向での強い材料になります。

**3. 「指摘」と「意見」の区別を書かない**

**この区別ができることが、監査の実務を知っている証拠**です。

**4. フォローアップを落とす**

**是正されたかを確認するところまで**が工程です。企業の内部監査でも、ここが弱い組織は多くあります。

**5. 数字を持っていない**

年間の監査件数、対象部署数、例月出納検査の回数、指摘の件数、措置済みの件数。**公表されている監査結果から取れます。**

どの経験に値が付くかは、募集の出方で変わります。[どの経験に値が付くのかから相談できます](../apply.html)。

## まとめ

- 地方自治法第200条は、事務局の職員を**代表監査委員が任免する**と定めています。**監査される側の人事から切り離されている**ことが、この経歴の芯です
- 民間での訳語は、**内部監査（財務監査・業務監査）／年間監査計画／証憑の徴求／監査報告書の作成／是正措置のモニタリング**が中心になります
- 中核スキルは**①年間の計画を組む ②資料を求める ③突き合わせる ④報告に書く ⑤是正を確認する**の5工程です
- 企業の内部監査と**同じ**なのは、独立性が仕組みで担保されていること・計画から追跡までのサイクル・指摘は受け入れられて初めて意味を持つこと
- **違う**のは、監査結果が公表されること・住民監査請求という外部からの申立てがあること・判断の主体が合議体であることです
- 評価が高くなりやすいのは、**内部監査／経理・会計／リスク管理とコンプライアンス／自治体を顧客にする企業と公会計**の4方向です

## よくある質問

### 簿記の資格がなくても、内部監査の求人に応募できますか

**応募はできますが、日商簿記2級があると通りやすくなります。**監査委員事務局では決算審査や例月出納検査を扱っているため、**実務としては財務の数字に触れています。**ただし、企業会計と公会計は体系が違うので、**簿記2級で企業会計の側を一度通しておく**と、面接での説明が楽になります。応募と並行して進める方法が現実的です。

### 「監査委員の補助」という立場で、実務経験として認められますか

**工程として書けば、認められます。**大事なのは、**判断の主体が監査委員であることを正確に書いたうえで、実務の範囲を具体的に書く**ことです。計画の原案、資料の特定、突合の実施、報告書の原案、措置状況の確認。**これらを担当していれば、企業の内部監査の担当者が日常的にやっていることと同じ**です。**曖昧に「補助」と書くことだけを避けてください。**

### 監査の対象部署から嫌がられる経験は、話してよいですか

**関係の作り方として話すなら有効です。**ただし、**特定の部署や個人が分かる形では話せません。**書けるのは、**「指摘と意見を分け、事前に事実関係を確認したうえで報告に載せる運用にしていた」**という、**摩擦を減らすための手続**です。企業の内部監査でも、**監査される側との関係の作り方**は必ず聞かれる論点なので、**手続として答えられると強く読まれます。**
