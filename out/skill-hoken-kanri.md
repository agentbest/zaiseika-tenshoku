**資格を持つ方から、「公立を離れたら資格は使えないのか」**というご相談を伺います。

**資格は、職場ではなく人に付きます。**

この記事では、**その前提**と、**使える領域**を扱います。

## 資格に伴う義務は、資格を離れた後も続きます

**児童福祉法第18条の22**です。

> **保育士は、正当な理由がなく、その業務に関して知り得た人の秘密を漏らしてはならない。保育士でなくなつた後においても、同様とする。**

**「保育士でなくなつた後においても、同様とする」**と定められています。

**義務が、資格を離れた後も続く**ということです。

**これは、資格が個人に結び付いていることの裏返し**でもあります。

**勤務先が変わっても、資格そのものは変わりません。**

**保健師についても、**[保健師・看護師から民間へ](senko-tachiba-hokenshi.html)**に整理したとおり、免許に基づく資格**です。

**公立で働いていたか、私立で働いていたかは、資格の内容に影響しません。**

## 資格の扱いを3つに分ける

| 扱い | 内容 |
|---|---|
| ① 資格が必須 | **その資格がなければ就けない職** |
| ② 資格が評価される | 必須ではないが、経験として読まれる |
| ③ 資格の知識が活きる | 資格は問われないが、理解が役立つ |

**①だけを探すと、候補が限られます。**

**②と③にも広げてください。**

**②について。**

**保育や保健の知識を持つ人を、相談や企画の担当として求める**場面があります。

**③について。**

**制度を作る側、支える側の仕事**では、資格そのものは問われなくても、**理解があることが前提**になります。

## 保育士の資格が使える領域

| 領域 | 扱い |
|---|---|
| ① 保育所・認定こども園 | **①資格が必須** |
| ② 企業内の保育の施設 | ①資格が必須 |
| ③ 学童・児童の発達の支援 | 施設によります |
| ④ 保育の運営の会社（本部） | ②評価される |
| ⑤ 保育に関するサービス | ②③ |
| ⑥ 自治体が相手の事業 | ③知識が活きる |

**④が見落とされやすい**です。

**複数の園を運営する会社には、本部の職務**があります。

**運営の管理、職員の採用と育成、制度への対応、行政との協議。**

**現場の経験と資格を持つ人が、本部で必要とされます。**

**扱いは**[公立保育士から民間へ](senko-tachiba-hoikushi.html)**にも整理しています。**

## 保健師の資格が使える領域

| 領域 | 扱い |
|---|---|
| ① 企業の健康の管理 | **①②** |
| ② 健診の機関 | ①② |
| ③ 保険・共済 | ②③ |
| ④ 介護・福祉の事業 | ②③ |
| ⑤ 健康に関するサービス | ②③ |
| ⑥ 自治体が相手の事業 | ③知識が活きる |

**①について。**

**企業の中で、従業員の健康の管理を担う職務**があります。

**個別の相談と、集団の傾向の把握の両方**を行うため、行政での動作に近いものです。

## 登録・免許の確認

| 確認すること | 内容 |
|---|---|
| 登録・免許の状況 | **有効かどうか** |
| 氏名の変更 | 手続が済んでいるか |
| 証明の書類 | 提示を求められることがあります |
| 研修の受講 | 分野による |

**1行目と2行目を確認**してください。

**氏名が変わっている場合、手続が必要**なことがあります。

**⚠ 手続と要件は、資格を所管するところの公表を確認**してください。

**この記事では、個別の要件には触れません。**

:::insight
資格について、**面談でお伝えしているのが「資格と経験を分けて書いてください」**という点です。**「保育士として勤務」「保健師として勤務」**とだけ書かれていると、**資格を持つ他の方と区別がつきません。**資格は、**持っていることが前提として読まれます。**差がつくのは、**その資格で何をしてきたか**です。何人を担当したか、どの年齢や層を扱ったか、保護者や対象者とどう関わったか、記録や計画をどう作ったか、制度の事務に関わったか。**そして、公立で働いてきた方には、私立や医療機関の方にはない経験があります。**入所や入園の事務、監査への対応、計画の策定、関係機関との連携。**これらは、運営の側で必要とされます。**書類には、**資格の欄には資格を、職務の欄には経験を書く**という分け方をしてください。**混ぜると、どちらも薄く読まれます。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 担当した対象と規模 | **人数、年齢、期間** |
| 記録・計画の作成 | 作ったものの種類 |
| 難しい対応の経験 | 3件、経緯と結論 |
| 制度の事務の経験 | **公立ならではの材料** |
| 勤務の条件 | 時間、シフト、夜間 |

**4行目です。**

**制度の運用に関わった経験は、運営の側で評価されます。**

**なお、特定の対象者が分かる説明は避けてください。**

**守秘の義務は、資格を離れた後も続きます。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 資格を活かせないと感じたとき

| 状況 | 考えること |
|---|---|
| 現場に戻りたくない | **②③の領域を見る** |
| 体力に不安がある | 相談・企画・管理の職務 |
| 勤務の条件が合わない | 短時間、日勤中心の求人 |
| 分野を変えたい | 資格の知識が活きる領域 |

**1行目です。**

**現場の職務に限らず、資格の知識を前提とする職務**があります。

**教材や制度に関わる事業、行政を相手とする事業、相談の窓口。**

**資格を捨てる必要はありません。**

## 書き方の例

**悪い例**

> 保育士として◯年勤務しました。

**良い例**

> **資格：保育士（登録◯年）**
> ◯◯において、**◯歳児クラス（児童◯名、職員◯名）の担任**を担当。年間・月間の指導の計画と個別の記録を作成。**保護者◯世帯との面談を年◯回実施。**行事の企画・運営を担い、**新規に採用された職員◯名への指導**を実施。**監査への対応として書類の整備**を担当。

**資格の欄と、職務の欄が分かれています。**

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 探すときの手順

| 順 | やること |
|---|---|
| 1 | **働き方の条件を先に決める**（時間、日数、通勤） |
| 2 | 資格が必須の求人を見る |
| 3 | 資格が評価される求人に広げる |
| 4 | 知識が活きる領域まで広げる |
| 5 | 条件に合うものを比べる |

**1を最初に置いてください。**

**条件が決まっていないと、比べられません。**

**3と4に広げると、候補の数が変わります。**

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## よくある失敗

**1. 資格が必須の職だけを探す**

**②③にも広げて**ください。

**2. 資格と経験を混ぜて書く**

**どちらも薄く読まれます。**

**3. 規模を書かない**

**人数、年齢、期間**を書いてください。

**4. 制度の事務の経験を書かない**

**公立ならではの材料**です。

**5. 登録・免許の状況を確認しない**

**氏名の変更**の手続を確認してください。

**6. 本部の職務を見ない**

**運営の管理、育成、行政との協議**があります。

**7. 現場に戻ることを前提にする**

**知識が活きる領域**もあります。

**8. 特定の対象者が分かる説明をする**

**守秘の義務は資格を離れた後も続きます。**

:::insight
ここまで領域の話をしておいて逆のことを言いますが、**資格があることで、選択を狭めてしまう場合があります。**面談で拝見していると、**「せっかく資格があるのだから」と考えて、資格を使う職だけを見る方**がいらっしゃいます。ところが、**資格は、選択肢を増やすためのもの**です。**使わない選択をしても、資格が消えるわけではありません。**登録や免許が有効であれば、**数年後に戻ることもできます。**ですから、**「資格を使うか」ではなく、「どう働きたいか」から考えてください。**勤務の時間、通勤、業務の内容、続けられる条件。**これらが合う求人を探し、その中に資格が活きるものがあれば選ぶ。****この順序のほうが、結果として続きます。**そして、**資格を使わない期間があっても、経験は残ります。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **児童福祉法第18条の22**は、**保育士の秘密保持義務**を定め、**保育士でなくなった後も同様**としています。**義務が続くのは、資格が個人に結び付いているから**です
- **勤務先が変わっても、資格そのものは変わりません**
- 資格の扱いは、**①必須 ②評価される ③知識が活きる**の3つに分かれます。**①だけを探さないでください**
- 保育士では、**運営の会社の本部の職務**が見落とされやすい領域です
- 保健師では、**企業の健康の管理**が行政での動作に近い領域です
- **資格と経験を分けて書いて**ください。差がつくのは経験のほうです
- **「資格を使うか」ではなく「どう働きたいか」**から考えてください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 長く現場を離れていますが、戻れますか

**登録や免許が有効であれば、資格は続いています。**ただし、**制度や運用は変わっている**ことがあります。復帰の前に、**最近の動向を確認**しておくと安心です。なお、**復帰を支援する仕組みが置かれている場合**があります。**居住する市区町村や、資格を所管するところの公表を確認**してください。求人の側でも、**ブランクのある方を前提とした募集**があります。求人票に「ブランク可」「復帰の支援あり」と記載があるものを見てください。**短時間の勤務から始める**という選択もあります。

### 資格があると、給与の条件は変わりますか

**会社の制度によります。**資格に応じた手当が定められている場合と、**基本給に含まれている場合**があります。求人票の賃金の欄で、**基本給と手当の区分**を確認してください。なお、**この記事では金額には触れません。**内定の段階で、**書面で提示を受けて**ください。読み方は[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。**資格があることと、条件がよいことは、直接には結び付きません。**業務の内容と条件で判断してください。

### 資格を使わない職に就いたら、無駄になりますか

**無駄にはなりません。**資格の取得の過程で学んだ内容は、**知識として残ります。**制度の仕組み、対象者の状況、関係機関の役割。**これらは、資格を前提としない職務でも使える場面があります。**とくに、**行政を相手とする事業**では、**福祉や保健の分野の制度を理解している人**が求められます。また、**登録や免許が有効であれば、将来戻ることもできます。**扱いは[職種を変える転職と、変えない転職](senko-tachiba-shokushutenkan.html)に整理しています。**選択肢として残しておく**という考え方で差し支えありません。
