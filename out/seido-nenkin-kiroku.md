共済期間が年金記録に見当たらないときは、最初に確認した画面、更新年月、対象期間をそろえます。最近の異動がまだ表示されていない場合と、加入記録そのものを調べる必要がある場合は別です。表示だけで「記録が消えた」と決めず、管理する機関へ照会します。

本記事は2026年11月時点の公開情報にもとづきます。共済期間がある方の確認と照会の準備を説明します。個人の記録や訂正の判断は、共済組合・年金事務所等の担当窓口で確認してください。

## 定期便・ネット・共済通知を分けて集める

厚生年金保険法第28条は、実施機関が原簿に氏名、資格の取得・喪失日、標準報酬、基礎年金番号等を記録する仕組みを定めています。本人が見る通知や画面は、そうした記録を確認するための入口です。通知に載る範囲と、機関が管理する記録の全体を同一と考えないことが大切です。

日本年金機構は、ねんきんネットで共済の加入月数、標準報酬月額、標準賞与額、年金見込額等を確認できると説明しています。ただし制約があり、共済記録は定期便の情報を使うため、基本的に年一回の更新です。

| 資料・画面 | 確認すること |
| --- | --- |
| ねんきん定期便 | 作成時点、加入期間、記録の対象と見込額の前提 |
| ねんきんネット | 表示された期間、更新日、各月の区分 |
| 共済の加入記録通知 | 共済が管理する対象期間、標準報酬等 |
| 給付算定基礎額残高通知書 | 年金払い退職給付の対象期間、付与額、利息等 |
| 採用・異動・退職の本人資料 | 実際の勤務履歴との照合 |

年金払い退職給付の給付算定基礎額は、老齢厚生年金の年額とは別です。公立学校共済組合は専用の残高通知書を案内しています。定期便の一つの欄にすべてが載る前提にせず、制度名ごとに資料を分けます。詳しい構造は[退職等年金給付の仕組み](seido-nenkin-taishoku-kyufu.html)も参照できます。

## 更新時差と本当の相違を分ける

退職や採用の直後に確認した画面に新しい期間がない場合は、更新の対象時点を確認します。民間の記録と共済記録で更新の仕組みが同じとは限りません。新しい資格の手続きを済ませたことと、画面に表示されたことを別に扱います。

公立学校共済組合の2026年10月更新案内は、複数の厚生年金種別の期間がある場合、情報整備に時間がかかり、定期便の送付月が遅れることも説明しています。誕生月に届かないという理由だけで未加入と断定しないでください。

一方、相違をすべて更新待ちで片づけることも避けます。日本年金機構のFAQは、共済の標準報酬月額や標準賞与額がハイフンで表示される場合、記録整備が必要として専用窓口への照会を案内しています。画面の注記と、どの項目が不明なのかを担当へ示します。

確認メモには「ログインした日」と「記録の更新日」を別々に残します。後日見直した際、同じ期間の表示が更新されたかを比較できるようにします。表示の基準日が違う通知を並べて、数字だけの不一致と判断しないことが必要です。

## 加入履歴を年月順に作る

最初に作るのは、勤務先と加入制度を並べた履歴です。正確な日が不明なら、分かる年月と未確認の箇所を分けて記載します。履歴をきれいに見せるために、空白期間を推測で埋める必要はありません。

| 期間 | 本人が確認する資料 | 照会したい点 |
| --- | --- | --- |
| 公務員になる前 | 年金手帳等、本人の給与明細 | 国民年金・民間の厚生年金期間 |
| 採用・共済間異動 | 採用や異動の通知、共済の通知 | 取得日、旧共済と新共済の接続 |
| 休業等の期間 | 本人宛ての決定・通知 | 加入区分、免除等の記録 |
| 退職と転職 | 退職承認、次の資格情報 | 喪失日、次の取得日、空白の扱い |
| 改姓等の時期 | 本人の旧姓資料、番号通知 | 記録が同じ本人へ結び付いているか |

基礎年金番号と、共済の組合員番号・加入者番号は同じものではありません。古い年金手帳や通知に異なる番号がある場合は、そのまま別人の記録と判断せず、番号の種類と統合の必要性を照会します。改姓前の名義、住所の変更、勤務先の名称変更も、記録を探す手掛かりとして伝えます。

一元化前後をまたぐ期間は、2015年9月以前と10月以後を区別して照合します。ただし一元化を境に履歴が分かれて見えること自体を、期間が消えた証拠にしないでください。どの制度名で何か月表示されているかを確認します。

:::insight
記録の照会では、「足りない気がする」という問いを、何年何月のどの項目が手元の資料と違うかに分けると、調査の入口を作りやすくなります。加入月数が合わないのか、報酬の欄が空なのか、見込額の前提が違うのかでは、確認する情報が変わるためです。本人用の表には、表示の内容、手元の資料、分からない理由を並べ、結論は担当へ確認した後に記します。更新待ちの可能性があっても、疑問を記録しておく意味はあります。仕事を続ける場合にも転職する場合にも、正しい履歴は共通の土台になります。年金の確認を退職の意思表示と結び付けず、制度の照会として進める形を勧めます。
:::

## 記録を管理する機関へ照会する

同じ定期便に載っていても、記録の提供元は一つとは限りません。国家公務員共済組合連合会のQ&Aは、共済期間と一般の厚生年金期間等について、内容の問い合わせ先を区分しています。地方の本人記録は加入していた共済の担当へ確認してください。

共済の加入期間・標準報酬等は担当共済、民間の一般厚生年金や国民年金の記録は年金事務所等へ相談するのが基本の整理です。どの機関の記録か分からない場合は、定期便や画面を用意して専用窓口へ確認します。ネットの操作や表示の相談と、原簿の内容を調べる相談も分けます。

公立学校共済組合には、マイナ手続きポータルによる電子交付の案内があり、年金加入記録や給付算定基礎額残高等を確認できます。ただし対象外となる人の区分もあります。本人の共済で利用できるサービス、対象者、更新時点を確認し、すべての共済で同じ画面が使えるとは考えません。

照会時は、本人確認に必要な資料、番号、相違がある期間、手元の通知の名称をまとめます。電話で相談する場合も、まず公式サイト等から窓口を確認します。個人番号や暗証番号を、必要性の分からない相手に送らないようにしてください。

## 調査の相談と法定の訂正請求は別

厚生年金保険法第28条の2には、第一号厚生年金被保険者等の記録に係る訂正請求の規定があります。厚生労働省は、年金記録の訂正請求手続きについて、年金事務所での受付や必要資料を案内しています。

ただし、この厚生労働省の訂正請求手続きでは、国家・地方公務員共済の組合員期間等は対象外と明示されています。「厚生年金へ一元化したから、共済期間もすべて同じ訂正請求書で処理される」とは考えません。対象の共済へ、記録の確認・修正に必要な手順を尋ねます。

国民年金や民間の厚生年金期間についても、問い合わせをした時点で直ちに法定の訂正請求となるわけではありません。表示や番号の確認、加入先の調査、届出内容の確認などを経て、必要な手続きを担当と整理します。

証拠になり得る資料には、本人の給与明細、源泉徴収票、年金手帳、勤務先から交付された通知等があります。ただし、一つの資料があるだけで希望どおり訂正される保証ではありません。資料がない場合も、その事情と分かる事実を伝え、調査方法を確認します。受付先、確認日、提出した写し、回答と次の手順を保管してください。

## 退職前後の書類は本人交付分を安全に残す

記録照合のために、住民情報、庁内の人事台帳、他職員の給与資料等を私的に持ち出す必要はありません。本人に交付された資料を保管し、足りないものは所属や共済へ正式に照会・再交付を依頼します。業務用メールを私用アドレスへまとめて転送する方法も避けます。

紙の原本と提出用の写し、電子データを区分し、送付先の指定に従います。家族等が相談を手伝う場合は、委任や本人確認の方法を窓口へ確認します。転職先へ伝える基礎年金番号と、記録訂正に使う詳細な資料も用途が違います。転職先にすべての履歴資料や個人番号入り通知を一括で渡す必要があると決めないでください。

照会の回答後は、対象期間と修正内容を次の通知で照合します。調査中の事項は未決定として残し、回答前の見込額を確定した年金額に置き換えません。定期便の見込額自体にも年齢等による前提があるため、記録の確認と将来の金額の比較を区別してください。

仕事の選択肢も本人の希望で調べる場合は、[公務員向け求人情報](../?gov=1)を材料にできます。年金記録の調査が終わる前に応募を決める必要はありません。

:::insight
記録の確認が一段落しても、それだけで転職するかどうかの答えが出るわけではありません。確認できた加入期間は過去の事実であり、これから選ぶ仕事の内容や家族の予定は別の判断材料です。現職を続ける場合の見通し、働き方を変える場合の希望、外の仕事の条件を同じ基準で並べると、制度への疑問だけに判断が引っ張られにくくなります。照会中の空欄を無理に埋めず、調査の回答を待ちながら他の情報を整理する進め方もできます。いま動かない選択にも、情報だけ集める選択にも意味があります。記録の整備は本人が選択するための基盤であり、退職を促す理由として扱わない姿勢を大切にしたいと思います。
:::

## よくある質問

### ねんきんネットに最近の共済期間がありません

共済の情報は基本的に年一回の更新という制約があります。表示の基準日と対象期間を確認し、更新時差か、調査が必要な相違かを窓口へ尋ねます。表示されないという理由だけで、未加入と断定しないでください。

### 共済期間の訂正も年金事務所へ請求しますか

厚生労働省の法定の訂正請求手続きでは、公務員共済の組合員期間等は対象外です。共済記録の確認・修正は、対象の共済に手順を照会します。どの制度の期間か不明な場合は資料を示して確認してください。

### 給付算定基礎額残高通知が届かなければ記録がないのですか

送付対象や時期は共済の案内で確認します。公立学校共済組合では採用年度や待機者の年齢等で対象を区分しています。未着だけで記録がないと決めず、担当へ加入期間と照会方法を尋ねてください。

経験や希望を言葉にしたいときは、[相談フォーム](../apply.html)を利用できます。ご利用は無料です（紹介手数料は採用企業の負担）。[LINEの案内](https://line.me/R/ti/p/@697nxhbt)を読むことも任意です。年金資料を転職相談へ送る必要はなく、記録の確認は共済・年金事務所等が窓口となります。
