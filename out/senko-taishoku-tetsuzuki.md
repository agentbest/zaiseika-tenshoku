退職が決まった後、**手続きが一度に来ます。**

**職場での手続き、公的な手続き、次の勤務先での手続き。**それぞれ、**担当も期限も違います。**

この記事では、**全体の一覧**を扱います。個別の項目は、後の記事で詳しく整理します。

## 入るときに宣誓をし、出るときに手続きをする

**公務員として働き始めたとき、宣誓をしています。**

**地方公務員法第31条**です。

> 職員は、条例の定めるところにより、**服務の宣誓をしなければならない。**

**入るときに、条例に基づく手続きがある。**

**出るときにも、同じように手続きがあります。**

**身分の得喪は、制度の上で管理されています。**

**そして、手続きの内容は、自治体ごとに条例と規則で定められています。**

**この記事では、一般的な項目を挙げます。****実際の手続きは、所属の規程と人事の担当に確認してください。**

## 3つの経路に分かれる

| 経路 | 担当 | 時期 |
|---|---|---|
| ① 職場での手続き | 所属、人事・給与の担当 | 退職日まで |
| ② 公的な手続き | 市区町村、年金事務所、共済組合 | 退職日の前後 |
| ③ 次の勤務先での手続き | 応募先の人事 | 入社日の前後 |

**①と②を混同しないでください。**

**①は、所属が案内してくれます。**

**②は、自分で動く必要があります。**

## ①——職場での手続き

| 項目 | 内容 |
|---|---|
| 退職の書面 | 規程で定める様式 |
| 貸与物の返還 | 端末、鍵、証明書、被服など |
| 健康保険証の返還 | 退職日以降 |
| 引継ぎ | 資料の作成、後任への説明 |
| 書類の受け取り | 離職に関する証明、源泉徴収票など |
| 年次休暇の整理 | 残日数の確認と消化 |

**5つ目を忘れないでください。**

**次の入社の手続きで使う書類**です。受け取り忘れると、**後から連絡して取り寄せる**ことになります。

**受け取る書類の一覧を作り、印を付けてください。**

## ②——公的な手続き

| 項目 | 確認先 | 期限の目安 |
|---|---|---|
| 健康保険 | 共済組合、市区町村 | **退職後すみやかに** |
| 年金 | 年金事務所、市区町村 | 同上 |
| 住民税 | 所属の給与の担当、市区町村 | 退職の時期による |
| 退職手当 | 所属の人事・給与の担当 | 規程による |

**空白なく次の勤務先に入る場合、①〜②の手続きの多くは簡略になります。**

**空白が生じる場合、自分で手続きする必要があります。**

**いずれも個別性が高いため、必ず窓口で確認してください。**

## ③——次の勤務先での手続き

| 提出するもの | 備考 |
|---|---|
| 年金の記録に関する書類 | 基礎年金番号が分かるもの |
| 雇用保険の番号 | **公務員は加入していないのが通常**です |
| 源泉徴収票 | その年に給与の支払いがある場合 |
| 口座の情報 | 給与の振込先 |
| 扶養に関する書類 | 該当する場合 |

**2つ目について補足します。**

**雇用保険法第6条**の適用除外により、**地方公務員は雇用保険に加入していないのが通常**です。

**そのため、「雇用保険被保険者証を提出してください」と言われても、持っていない**ことがあります。

**その旨を伝えれば、次の勤務先で新たに手続きされます。**

:::insight
手続きで、**面談でいちばん多い混乱が「誰に聞けばよいか分からない」**という点です。対処としては、**最初に人事の担当に、手続きの一覧をもらうこと**です。多くの自治体で、**退職者向けの案内**が用意されています。**それを受け取れば、①の部分は整理できます。**一方、**②の公的な手続きは、所属の案内に含まれないことがあります。**とくに、**離職期間が生じる場合の健康保険と年金**は、**自分で選んで手続きする必要があります。**共済組合の任意継続にするか、国民健康保険にするか。**保険料の負担が異なるため、比較して決めることになります。**この比較には、**それぞれの窓口で金額を確認する**必要があります。**退職の1か月前には着手してください。**在職中は時間が限られるため、早めに動くほうが確実です。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 受け取る書類

**最終出勤日の前後に受け取るもの**を挙げます。**所属によって名称や有無が異なります。**

| 書類 | 用途 |
|---|---|
| 退職に関する証明 | 次の勤務先への提出、公的な手続き |
| 源泉徴収票 | **その年の年末調整か、確定申告** |
| 年金に関する書類 | 記録の確認、次の勤務先への提出 |
| 共済組合の資格喪失に関する書類 | 健康保険の切替え |
| 退職手当に関する書類 | 支給の内容の確認、税の申告 |

**2つ目に注意してください。**

**その年の1月から退職までの給与について、源泉徴収票が交付されます。**

**年内に次の勤務先に入る場合、そちらに提出して年末調整を受ける**のが通常です。

**年をまたぐ場合や、離職期間がある場合は、確定申告が必要になることがあります。**

**扱いは個別の事情によるため、税務署で確認してください。**

## 退職手当に関する手続き

| 項目 | 内容 |
|---|---|
| 申請 | 所属の規程による |
| 支給の時期 | 規程による。**退職日の直後とは限りません** |
| 税の申告 | **退職所得に関する申告書**の提出を求められることがあります |
| 支給額の確認 | 明細で確認 |

**3つ目について補足します。**

**退職所得の課税には、他の所得と分けて計算される仕組み**があります。

**申告書を提出するかどうかで、源泉徴収の扱いが変わることがあります。**

**所属の給与の担当の案内に従い、不明な点は税務署で確認**してください。

## 時期別の進め方

| 時期 | やること |
|---|---|
| 退職の2か月前 | 人事の担当から**手続きの一覧**を受け取る |
| 1か月半前 | **健康保険の選択**を検討（比較のため窓口で確認） |
| 1か月前 | 貸与物の一覧を確認、引継ぎの資料を作成 |
| 2週間前 | 受け取る書類の一覧を作成 |
| 最終週 | 返還、書類の受け取り |
| 退職後 | ②の公的な手続き（空白がある場合） |
| 入社時 | ③の提出 |

**最初の項目を先にしてください。**

**一覧があれば、残りは順に進めるだけ**です。

**この表は、退職の1か月前に一度、人事の担当と突き合わせてください。**所属によって項目が増減します。**自分の場合に該当するものだけを残せば、実際にやることは減ります。**

## 確認先の一覧

| 事項 | 確認先 |
|---|---|
| 退職の手続き全般 | 所属の人事の担当 |
| 給与、住民税 | 所属の給与の担当 |
| 退職手当 | 所属の人事・給与の担当、規程 |
| 共済（健康保険・年金） | **共済組合** |
| 国民健康保険、国民年金 | **市区町村の窓口** |
| 厚生年金 | 年金事務所、次の勤務先 |
| 税 | **税務署**、市区町村 |

**税・社会保険・年金は、個別の事情によって扱いが異なります。**

**この記事に書いてあるのは一般的な整理**です。**必ず、上の窓口で確認してください。**

[経験の言い換えから相談する](../apply.html)こともできます。

**なお、手続きの多くは、退職日の前後に集中します。**その時期は引継ぎの最終盤とも重なるため、**前倒しできるものは前倒し**してください。健康保険の選択の検討と、受け取る書類の一覧の作成は、**1か月前にできます。**

## よくある失敗

**1. 手続きの一覧をもらわない**

**人事の担当が用意していることがあります。**

**2. 受け取る書類を確認しない**

**後から取り寄せる**ことになります。

**3. 公的な手続きを所属が案内してくれると思う**

**②は自分で動く**必要があります。

**4. 健康保険の選択を直前に決める**

**比較に時間がかかります。**

**5. 雇用保険被保険者証を探す**

**公務員は加入していないのが通常**です。

**6. 一般的な説明だけで判断する**

**個別性が高い**ため、窓口で確認してください。

:::insight
ここまで手続きの話をしておいて逆のことを言いますが、**手続きそのものに時間をかけすぎないでください。**面談で拝見していると、**手続きの調べ物に時間を使い、引継ぎが後回しになっている方**がいらっしゃいます。ところが、**手続きは、窓口で聞けば教えてもらえます。**自分で調べ尽くす必要はありません。一方、**引継ぎは、自分にしかできません。**担当してきた業務の内容、例外の処理、進行中の案件。**これは、窓口で聞いても出てきません。**優先順位としては、**引継ぎが先、手続きは窓口に聞きながら順に**です。**手続きの一覧を最初に受け取っておけば、抜けは防げます。**残りの時間は、引継ぎに使ってください。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方公務員法第31条**は、**条例の定めるところにより服務の宣誓をする**としています。**身分の得喪は、制度の上で管理されています**
- 手続きは、**①職場 ②公的 ③次の勤務先**の3経路。**②は自分で動く**必要があります
- **最初に、人事の担当から手続きの一覧を受け取って**ください
- **受け取る書類の一覧を作り、印を付けて**ください。取り寄せの手間が防げます
- **雇用保険は、公務員は加入していないのが通常**です（雇用保険法第6条）
- **税・社会保険・年金は個別性が高い。**必ず窓口で確認してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 手続きの一覧をもらえませんでした

**人事の担当に、直接尋ねて構いません。**「退職に伴う手続きについて、必要なものを教えていただけますか」と聞けば足ります。**退職者向けの案内が用意されていない自治体もあります。**その場合は、**この記事の①の項目を挙げて、該当するものを確認**してください。加えて、**過去に退職した同僚がいれば、その方に聞く**という方法もあります。ただし、**在職中に転職活動を知られたくない場合は、人事の担当に直接聞くほうが確実**です。手続きの確認は、**退職が決まってからで構いません。**

### 空白なく次の勤務先に入る場合も、手続きは要りますか

**簡略になりますが、必要な手続きはあります。**健康保険と年金は、**次の勤務先で加入の手続きが行われる**のが通常です。ただし、**共済組合の資格喪失の手続き**は、所属で行われます。また、**住民税の扱い**は、退職の時期によって変わります。**次の勤務先で給与から差し引く形に切り替えられる**場合もあります。いずれも、**所属の給与の担当と、次の勤務先の人事に確認**してください。**空白がないからといって、何もしなくてよいわけではありません。**

### 手続きに必要な書類を、退職後に取り寄せられますか

**取り寄せられますが、時間がかかります。**在籍していた所属に連絡し、**発行を依頼する**ことになります。**郵送でのやり取りになるため、数週間かかる**ことがあります。**入社の手続きに間に合わない可能性**があるため、**在職中に受け取っておくほうが確実**です。受け取る書類の一覧を作り、**最終出勤日までに揃っているか確認**してください。なお、**源泉徴収票は、退職後に交付される**ことがあります。**受け取りの時期と方法を、給与の担当に確認**しておいてください。
