下水道課から民間に移るとき、**行き先は1つではありません。**

**むしろ、この経歴は、法律の側が行き先を3つに分けてくれている**という、めずらしい経歴です。設計に関わってきたのか、工事の監督をしてきたのか、処理場の運転を回してきたのか。**どこを長くやってきたかで、通る求人が変わります。**

この記事では、**向いている5つの方向**と、**合いにくい方向**を並べます。**資格と検索語**も最後に付けます。

言い換えは[下水道課の経験は民間で何と呼ばれるか](dept-gesuido-honyaku.html)に書いています。

## 設計・工事の監督管理・維持管理に、資格の線が引かれています

行き先の話に入る前に、この分野の構造を条文で押さえます。**下水道法第22条**です。

> 公共下水道管理者は、公共下水道を設置し、又は改築する場合（政令で定める場合を除く。）においては、その設計（その者の責任において設計図書を作成することをいう。）又はその工事の監督管理（その者の責任において工事を設計図書と照合し、それが設計図書のとおりに実施されているかどうかを確認することをいう。）については、政令で定める資格を有する者以外の者に行わせてはならない。
> 2 公共下水道管理者は、公共下水道の維持管理のうち政令で定める事項については、政令で定める資格を有する者以外の者に行なわせてはならない。

**ここが、行き先を分ける線です。**

**設計、工事の監督管理、維持管理。**この3つについて、**資格を持つ者以外にやらせてはならない**と法律が定めています。

**そして、この3つは、民間の側でも、そのまま3つの業種に対応しています。**

- **設計**——建設コンサルタント
- **工事の監督管理**——工事の会社、施工の管理
- **維持管理**——処理場の運転を受託する会社、管路の保全の会社

つまり、**この分野では、自分がどの資格の線の内側で働いてきたかが、そのまま行き先の当たりになります。**3つのうち2つを経験しているなら、それは強みです。

## 向いている5つの方向

### 1. 処理場の運転・維持管理を受託する会社

| 項目 | 内容 |
|---|---|
| 効く経験 | **処理場の運転、水質の管理、委託の仕様、履行の確認の視点** |
| 求められる形 | 自治体からの受託、現場の運転と保全、提案書の作成 |
| 入りやすさ | **高い。**発注者が何を見るかを知っている |

**書くときの注意。****委託の仕様を作る側だったことを書いてください。**受託の会社がいちばん欲しいのは、**「この自治体は何を求めるか」を読める人**です。**履行の確認で何を見ていたかを、そのまま書けます。**

**この方向に固有の制約もあります。**処理場の運転は、**複数年でまとめて受託する形（包括的な委託）が広がっています。**期間が終われば、次の公募があります。**負ければ、その現場が無くなる。**しかも、**引き継ぐのは、流入を選べない、生き物を扱う設備**です。**引き継ぎの数週間で微生物の状態を崩すと、放流の水質に出ます。****そこを理解したうえで、提案と引き継ぎの設計に関われる人**が求められています。

### 2. 管路の調査・更生・工事の会社

| 項目 | 内容 |
|---|---|
| 効く経験 | **カメラ調査の発注、更生の工法の選定、道路の占用の調整、夜間の工事の段取り** |
| 求められる形 | 自治体からの受注、施工の管理、緊急の復旧 |
| 入りやすさ | **高い。**人が足りていない分野 |

**書くときの注意。****「流しながら直す」段取りを書いてください。**下水は止められません。**水を迂回させて、その間に管の中で工事をする。**この条件を知っている人は、**受注の側でも工程を立てられます。**

**この方向に固有の制約もあります。**管路の工事は、**掘ってみないと分からない部分**が残ります。他の埋設物、土の状態、管の中の堆積。**発注の側にいたときは設計の変更として処理していた場面が、受注の側では、その日の工程の判断になります。**しかも、**道路を掘っている間は、沿道の生活に影響が出続けます。****道路を止められる時間の限界と、水を止められない条件の両方を知っていること**は、**この方向でいちばん早く役に立つ知識**です。

### 3. 水処理のプラント・機械のメーカー

| 項目 | 内容 |
|---|---|
| 効く経験 | **設備の更新の判断、ポンプ、送風機、脱水機、電気設備の運転と更新** |
| 求められる形 | 設備の提案、設計の支援、試運転、保守 |
| 入りやすさ | **中〜高。**運転してきた側の知識が求められる |

**書くときの注意。****設備の更新の検討に関わったなら、その経緯を書いてください。**どの設備を、どういう理由で、いくらで更新したか。**メーカーの側は、「更新の意思決定がどう進むか」を知りたい**からです。

**この方向に固有の制約もあります。**メーカーの側に回ると、**自社の製品の範囲で解を出すことになります。**在職中は、どの方式が自分の処理場に合うかを、白紙から選べました。**移った後は、自社が扱う方式の中で、いちばん合う形を提案する。**この違いに、最初は窮屈さを感じる方もいます。**一方で、1つの方式を深く知ることになる**ので、**数年で、その分野の中では他に代えがたい人になります。**

### 4. 建設コンサルタント・計画の支援

| 項目 | 内容 |
|---|---|
| 効く経験 | **ストックマネジメント計画、全体計画、経営の戦略、使用料の試算、浸水対策の計画** |
| 求められる形 | 受託、調査、計画の策定支援、資産の管理の支援 |
| 入りやすさ | **中〜高。**計画と数字の両方を見てきた人は多くない |

**書くときの注意。****計画の名前を書いてください。**ストックマネジメント計画、経営の戦略、浸水対策の計画。**改定に関わっただけでも書けます。**

**この方向に固有の制約もあります。**受託の側から計画を作ると、**成果物は報告書です。**実際に更新が進むかどうかは、**その後の予算と使用料の判断に委ねられます。**在職中は、計画を作った後に自分で動かす立場でしたが、**移った後は、作ったところで手が離れる。**この切れ方を物足りなく感じる方もいます。**一方で、複数の自治体の計画に関わることで、比べる目が付きます。**1つの自治体の事情しか知らない状態から出られる、という利点を取る方も多い方向です。

### 5. 民間の工場の排水処理・環境の分析・汚泥の処理

| 項目 | 内容 |
|---|---|
| 効く経験 | **放流水質の管理、除害施設の指導、汚泥の処理と処分、測定と記録** |
| 求められる形 | 工場の排水処理の担当、分析、廃棄物の管理 |
| 入りやすさ | **中。**求人は業種が広く、構造の一致度が高い |

**書くときの注意。****「規制する側にいた」と書いてください。**除害施設の指導で、**工場の排水を見に行き、基準を説明し、改善を求めてきた。**その経験は、**工場の側に回ると、「行政が何を見るか」を知っている担当になります。**

**この方向に固有の制約もあります。****立場が逆になる**ということです。在職中は、基準を示す側でした。**移った後は、基準を守る側で、行政の立入りを受ける側になります。**この逆転を、**面白いと感じるか、居心地が悪いと感じるかは、人によります。**一方で、**行政が何を確かめに来るかを知っている人**は、工場の側では**外部から採りにくい**ので、**入った後の評価は安定しやすい方向**です。

:::insight
この5つの方向で、**いちばん多い失敗は1番**で起きます。**「受託の会社なら、現場の仕事は今と同じだ」と考えて入り、実際には提案書と公募の担当になる例**です。受託の会社は、**発注者の事情を知っている人を、現場ではなく提案の部門に置きたがります。**その仕事が合う方には良い配属ですが、**処理場の運転を続けたくて移った方には、食い違いになります。**面接で、**「入社後の配属は、現場の運転か、提案と受注か」**を確かめないまま進むと起きます。もう1つ、**2番の工事の会社でも似た形があります。**現場の代理人として採られるつもりで入り、**積算と入札の担当になる例**です。**発注の側の経験は、受注の側では「入札に勝つための知識」として読まれる**ので、そちらに配置されやすい。**どちらの配属を求めているかを、書類の段階で書いておく**ほうが、食い違いを防げます。
:::

## 合いにくい方向

**次の5つは、この経歴からは遠い方向です。**

| 方向 | 理由 |
|---|---|
| 短い周期で作り替える仕事 | 下水道の資産は数十年単位。時間の感覚が合わない |
| 相手を探すところから始まる営業 | 区域の全員が相手だった経験と、前提が違う |
| 個人の数字で評価される仕事 | 処理場も管路も、体制で回してきた。個人の成績の感覚が薄い |
| 在庫と需要の調整が中心の職 | 下水道には在庫がない。流れてきたものを、その場で処理してきた |
| 現場のない職 | 管の中と処理場を見て判断してきた強みが使われない |

**「できない」ということではありません。****持っている経験が、使われない**ということです。

## 役に立つ資格

| 資格 | 効く方向 |
|---|---|
| 下水道技術検定（第1〜3種） | 受託の会社、コンサルティング、工事の会社 |
| 下水道管路管理技士 | 管路の調査と更生の会社 |
| 技術士（上下水道部門） | コンサルティング、計画の策定支援 |
| 土木施工管理技士・管工事施工管理技士 | 管路の工事、建設会社 |
| 公害防止管理者（水質） | 工場の排水処理、環境の分析、プラント |
| 電気主任技術者 | 処理場の設備の運転と保全 |
| 簿記 | 経営の企画、公営企業会計の経験と組み合う |

**持っていない資格を、応募のために先に取る必要はありません。**ただ、**受けようとしている方向に対応する資格があるなら、「取得予定」と書くだけでも効きます。**在職中に下水道技術検定を受けている方は、**それを書くだけで、1番と4番の読まれ方が変わります。**

## つまずきやすい点

**1. 「下水道の仕事は役所にしかない」と考える**

**受託の会社、工事の会社、メーカー、コンサルティング、工場の排水処理。****同じ分野の民間側が、そのまま並んでいます。**

**2. 発注の側の経験を、低く見積もる**

**受託の会社に、発注の側を知っている人は多くありません。**

**3. 除害施設の指導を、書き落とす**

**工場の排水を見に行き、改善を求めてきた経験**です。**工場の側では、それを知っている人が要ります。**

**4. 資格がないことを、応募しない理由にする**

**取得予定と書けます。**実務の経験のほうが先に見られます。

**5. 方向を1つに絞ってしまう**

**現場寄りと計画寄りで、書類の順番を変えるだけで、両方に出せます。**

掲載中の求人も見られます。[行政が相手の求人を見てみる](../?gov=1)。

:::insight
この経歴の方から、**「下水道の民間の会社が、どこにあるのか分からない」**という声をよく伺います。当然で、**下水道の受託や管路の工事を手がける会社は、一般の知名度が高くありません。**ところが、**自治体の側から見れば、毎年顔を合わせている会社**です。**処理場の委託の受託者、カメラ調査と更生の工事の入札の参加者、設備のメーカー、計画を作ったコンサルタント。****名簿は、手元にあります。**そのうえで、もう1つ。**この経歴は、上水道の経歴の方と、同じ会社を受けることになります。**受託の会社もコンサルティングも、上下水道をまとめて手がけているところが大半だからです。**そのとき、下水道の側だけが持っている材料が2つあります。**生き物を扱う処理場の運転と、雨水の対応です。**「上下水道」と丸めずに、この2つを先に出すと、上水道の経歴の方と並んだときに、読まれ方が変わります。**どの方向にどう出すかは、**手元の経歴の中身を見ないと決められません。**在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 下水道法第22条は、**設計、工事の監督管理、維持管理のうち政令で定める事項について、資格を有する者以外に行わせてはならない**と定めています
- つまり、**この3つの線が、そのまま民間の3つの業種に対応しています。**自分がどの線の内側で働いてきたかが、行き先の当たりになります
- 向いているのは、**①処理場の受託の会社 ②管路の調査・更生・工事 ③プラントのメーカー ④コンサルティング ⑤工場の排水処理・環境の分析**の5方向です
- 合いにくいのは、**短い周期の仕事、相手を探す営業、個人の数字の仕事、在庫の調整、現場のない職**です
- 資格は、**下水道技術検定、下水道管路管理技士、技術士、施工管理技士**などが効きます。**取得予定でも書けます**
- 検索語は、**「下水道課」ではなく「下水処理場」「管きょ更生」「水処理」「包括的民間委託」**に言い換えてください

## よくある質問

### 事務職で、技術の判断はしていません

**それでも、5つの方向のうち2つは残ります。**1番の受託の会社と、4番のコンサルティングです。**この2つで見られるのは、委託の契約と履行の確認、使用料と受益者負担金の実務、水洗化の促進、公営企業会計、経営の戦略**で、**いずれも技術の判断ではありません。**書くなら、**「委託の仕様の作成、履行の確認、使用料の賦課と徴収、公営企業会計による決算を担当。技術上の判断は技術職が実施」**と、**自分の範囲を明示してください。**とくに、**水洗化の促進の経験**は、**受託の会社の営業の企画で読まれやすい経験**です。

### 雨水と浸水の対策が中心で、処理場のことは分かりません

**その場合は、行き先の当たりが少し変わります。**5つの方向のうち、**4番のコンサルティングの浸水対策の計画と、2番の工事の会社の雨水の管路とポンプ場**が中心になります。加えて、**河川や砂防の側の行き先が、そのまま重なります。**雨水の対応は、**いつ来るか決められないものに、平常時の手順で備える仕事**です。この形は、**事業の継続計画や危機の対応の設計として、業種を問わず読まれます。**行き先の並べ方は[河川・砂防課から転職しやすい業界と職種](dept-kasen-tenshokusaki.html)が近いので、併せて読んでください。

### 何社くらい受けるものですか

**方向を2つに絞って、各3社から5社**が、**この経歴では動かしやすい形**です。理由は、**方向ごとに書類の順番を変える必要がある**からです。現場寄りの会社には運転と保全を先に、計画寄りの会社には計画と数字を先に置く。**2つまでなら、書類を2通用意すれば足ります。**3つ以上に広げると、**どれも中途半端な順番になりがち**です。なお、**受ける数より、順番のほうが結果に効きます。**書類の書き方は[下水道課の職務経歴書｜書き出しから実績の出し方まで](dept-gesuido-shokumu.html)に整理しています。
