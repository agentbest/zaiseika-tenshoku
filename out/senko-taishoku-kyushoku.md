**休職中に、今後のことを考える方がいらっしゃいます。**

この記事では、**制度上の位置づけ**と、**検討の順序**を扱います。

**⚠ 体調に関わることは、主治医の判断が先です。****この記事は制度の一般的な整理にとどめます。**

**⚠ 休職の要件・期間・給与の扱いは、条例と規程によって異なります。****必ず所属と共済組合に確認してください。**

## 休職は、懲戒ではありません

**地方公務員法第28条第2項**です。

> 職員が、次の各号に掲げる場合のいずれかに該当するときは、その意に反して、これを休職することができる。
>
> 一 **心身の故障のため、長期の休養を要する場合**
>
> 二 刑事事件に関し起訴された場合

**この条は、見出しが「降任、免職、休職等」**となっています。

**分限**に関する規定で、**懲戒の規定とは別**です。

**同条第3項**は、次のように定めています。

> 職員の意に反する降任、免職、休職及び降給の**手続及び効果**は、法律に特別の定めがある場合を除くほか、**条例で定めなければならない。**

**「効果」が条例に委ねられている**ということです。

**期間、給与の扱い、復職の手続き。これらは団体の条例と規程によって定められています。**

**したがって、一般論で判断せず、自分の団体の定めを確認してください。**

## 順序——体調が先です

| 順 | やること |
|---|---|
| 1 | **主治医の判断を確認する** |
| 2 | 休職の期間と、期限を確認する |
| 3 | 復職の手続きを確認する |
| 4 | **それから、今後の選択肢を考える** |
| 5 | 情報を集める |

**1を飛ばさないでください。**

**転職活動は、面接や書類の作成を伴います。**

**体調によっては、時期を待つほうがよい場合があります。**

**主治医に、活動の可否と、どの程度なら差し支えないかを確認**してください。

## 2——期限の確認

| 確認すること | 確認先 |
|---|---|
| 休職の期間の上限 | **所属の人事担当** |
| 給与の扱い | 同上 |
| 期間が満了したときの扱い | 同上 |
| 共済組合の給付 | **共済組合** |
| 復職の手続き | 所属 |

**3つ目を確認してください。**

**期間の満了に関する定めは、条例に置かれています。**

**期限が分かれば、判断の時期も決まります。**

**分からないまま時間が過ぎると、選べる範囲が狭くなります。**

## 3つの選択肢

| 選択肢 | 内容 |
|---|---|
| ① 復職する | 元の職場、または配置の変更を伴う復職 |
| ② 復職してから考える | 一度戻って、状態を見てから判断 |
| ③ 転職する | 退職して、次の勤務先へ |

**②が見落とされやすい**です。

**休職中に結論を出す必要はありません。**

**復職して、しばらく働いてから判断する**という順序もあります。

**復職後に配置が変わることで、状況が変わる**こともあります。

**配置の変更について、所属に相談できる場合があります。**

**この点は、復職の手続きの中で確認してください。**

:::insight
休職中のご相談で、**面談でお伝えしているのが「いま決めなくてよい」**という点です。休職中は、**判断の材料が揃いにくい時期**です。体調が戻っていない段階では、**何が原因で、何を変えれば改善するのかが見えにくい。**この状態で転職先を決めると、**同じ条件の職場を選んでしまう**ことがあります。面談で伺った例では、**復職して配置が変わったことで、続けられるようになった方**がいらっしゃいます。一方、**復職した後に、改めて環境を変える判断をされた方**もいらっしゃいます。**どちらも、一度状態を確かめてから決めています。**ですから、**休職の期間に情報を集めることは意味がありますが、結論を出す必要はありません。**期限だけ確認して、**判断はその手前まで持ち越して差し支えありません。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 選考での扱い

**休職の事実を、応募の段階で詳しく説明する義務はありません。**

**ただし、勤務に関わる範囲は、整理しておくほうが後の齟齬が減ります。**

| 項目 | 整理しておくこと |
|---|---|
| 現在の状態 | **就業が可能な状態か** |
| 勤務の条件 | 時間、日数、業務の内容 |
| 主治医の見解 | 就業に関する判断 |
| 配慮の要否 | 必要な場合、その内容 |

**1つ目が前提**です。

**就業が可能な状態であることを、主治医に確認**してください。

**4つ目について。**

**配慮が必要な場合、伝えないまま入社すると、調整ができません。**

**伝える範囲は、勤務に関わる部分で足ります。**

**病名や経緯を詳しく説明する必要はありません。**

## 職務経歴書の書き方

| 項目 | 書き方 |
|---|---|
| 在籍の期間 | **在籍しているため、現在までで書きます** |
| 休職の期間 | 詳細を記載する義務はありません |
| 直近の業務 | 休職の前に担当していた業務 |
| 空白の説明 | 必要に応じて面接で |

**1つ目です。**

**休職中も在職中である**ため、**退職していない状態で書きます。**

**書き方の基本は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

**4つ目について。**

**直近の業務の記載が古い場合、面接で確認されることがあります。**

**その場合に、どう答えるかを先に決めておいてください。**

## 答え方の整理

**聞かれたときに答える内容を、先に用意しておきます。**

| 要素 | 内容 |
|---|---|
| 事実 | 休職していること |
| 現状 | 就業が可能な状態であること |
| 見通し | 勤務の条件 |
| 意欲 | 何をしたいか |

**2つ目と3つ目が中心**です。

**過去の経緯を長く説明するより、現在と今後を簡潔に伝える**ほうが伝わります。

**そして、主治医の判断を根拠として示せる状態にしておいてください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 退職を決める前に確認すること

| 項目 | 確認先 |
|---|---|
| 退職手当の扱い | 所属の給与担当 |
| 共済組合の給付の扱い | 共済組合 |
| 保険の切替え | 共済組合・転職先 |
| 年金の手続き | 年金事務所 |
| 住民税の扱い | 市区町村 |

**2つ目を確認してください。**

**休職中に受けている給付がある場合、退職によって扱いが変わることがあります。**

**なお、退職しても失業給付が出ない点は**[公務員に失業給付が出ない理由と、代わりの備え](senko-taishoku-shitsugyo.html)**に整理しています。**

**なお、これらの確認は、復職する場合にも必要になるもの**です。**退職を前提としなくても、制度の照会として聞いて差し支えありません。**

## よくある失敗

**1. 主治医に確認せずに活動を始める**

**体調が優先**です。

**2. 休職の期限を確認しない**

**判断の時期が決まりません。**

**3. 復職という選択肢を外して考える**

**一度戻ってから判断する**こともできます。

**4. 就業が可能でない段階で応募する**

**入社後に無理が生じます。**

**5. 経緯を詳しく説明しようとする**

**現在と今後で足ります。**

**6. 給付の扱いを確認せずに退職の時期を決める**

**共済組合に確認**してください。

**7. 同じ条件の職場を選んでしまう**

**何を変えたいかを言葉にしてから**探してください。

:::insight
ここまで慎重な話をしておいて逆のことを言いますが、**休職の経験があること自体が、選考の結論を決めるわけではありません。**面談で拝見していると、**「休職したから、もう採用されない」と考えている方**がいらっしゃいます。ところが、**採用する側が確認したいのは、入社後に働ける状態かどうか**です。**就業が可能であることが確認でき、勤務の条件が合えば、判断はそこで進みます。**そして、**何を変えたいかを言葉にできている方のほうが、説明が通ります。**業務の量なのか、時間なのか、人との関わり方なのか、扱う内容なのか。**これが整理されていると、条件で求人を絞れます。**逆に、**整理がないまま探すと、同じ条件の職場を選びやすくなります。**ですから、**回復を待つ期間は、この整理に使える時間**でもあります。急いで決めるための時間ではありません。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方公務員法第28条第2項**は、**心身の故障のため長期の休養を要する場合**等に**意に反して休職することができる**と定めています。**分限の規定で、懲戒とは別**です
- **同条第3項**により、**手続と効果は条例で定められています。**期間・給与の扱いは**所属に確認**してください
- **順序は、主治医の判断 → 期限の確認 → 選択肢の検討**です
- **復職してから判断する**という選択肢を外さないでください
- 選考では、**現在の状態と勤務の条件**が中心です。**経緯を詳しく説明する必要はありません**
- 退職の前に、**給付・保険・年金・住民税の扱い**を確認してください
- **何を変えたいかを言葉にしてから**探してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 休職していることを、面接で伝える必要がありますか

**在籍している以上、在職中として書類を出します。**そのうえで、**直近の業務や現在の状況を聞かれた場合は、事実を伝えるほうが後の齟齬が減ります。**伝える範囲は、**就業が可能な状態であること**と、**勤務の条件**です。**病名や経緯を詳しく説明する必要はありません。**なお、**入社後に配慮が必要な場合、伝えておかないと調整ができません。**この点は、**内定の前後で相談**してください。伝えずに入社して、**必要な調整が受けられないほうが、結果として続きにくくなります。**

### 復職してから転職するほうがよいのでしょうか

**判断の材料が揃いやすいという意味では、復職してからのほうが確実です。**理由は2つあります。1つは、**就業が可能な状態であることを、実際の勤務で確認できる**こと。もう1つは、**配置が変わることで状況が改善する場合がある**ことです。一方、**休職の期間に情報を集めること自体は、復職の判断と両立します。**求人を見る、制度を確認する、職務経歴書を下書きする。**これらは結論を先に決めなくてもできます。**なお、**休職の期間には上限があります。**期限が近い場合は、**所属と相談しながら時期を組んでください。**

### いまの仕事が合っていない気がします。何から整理すればよいですか

**「何が負担だったか」を、業務の要素に分けてください。**業務の量、時間の長さ、締切の頻度、人との関わり方、扱う内容、判断の責任。**この6つのどれが大きかったかを分けると、求人を絞る軸になります。**たとえば、量が問題だったなら、**担当の範囲が明確な求人**を見る。人との関わりが問題だったなら、**対外の折衝が中心でない職種**を見る。**「合わない」という言葉のままだと、条件に落とせません。**分けた結果、**いまの職場で配置が変われば済む**と分かることもあります。**その場合は、復職の相談が先**になります。
