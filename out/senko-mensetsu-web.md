画面越しの面接は、**在職中の方にとって利点があります。**

移動の時間が要らないため、**昼休みや夕方の短い時間でも調整できます。**年次休暇を使わずに受けられる場合もあります。

ただし、**対面とは別の準備が要ります。**とくに、**在職中の方には、守秘の面での注意**があります。

この記事では、**準備と注意点**を扱います。面接の全体像は[公務員からの転職面接｜全体の流れと準備](senko-mensetsu-nagare.html)にあります。

## 職場から接続しない

**最初に、これを挙げます。**

**地方公務員法第34条第1項**です。

> 職員は、職務上知り得た秘密を漏らしてはならない。**その職を退いた後も、また、同様とする。**

**職務上知り得た秘密を漏らしてはならない。**この義務は、**退職後も続きます。**

**職場から接続すると、この線を越える可能性があります。**

| 場面 | 起こり得ること |
|---|---|
| 執務室から接続 | **背景に、掲示物や書類、他の職員が映る** |
| 会議室から接続 | 予定表やホワイトボードの記載が映る |
| 端末の画面を共有 | **業務のシステムの画面が映る** |
| 音声 | 周囲の会話が入る |

**1つ目と3つ目は、実際に起こります。**

**背景に映った掲示物の内容が、外部に出てよい情報とは限りません。**

**接続は、自宅か、外部の個室**から行ってください。**職場の端末や通信の設備を私的な用途で使うことにも、規程上の問題が生じ得ます。**

## 準備する4点

| 点 | 確認すること |
|---|---|
| ① 接続 | 開始の10分前に接続を確認。**予備の通信手段**を用意 |
| ② 背景 | 無地の壁か、落ち着いた背景。**映り込みを確認** |
| ③ 音声 | **マイク付きのイヤホン**があると聞き取りやすい |
| ④ 光 | 顔に光が当たる向き。**逆光を避ける** |

**④が見落とされやすい点**です。

**窓を背にすると、逆光で顔が暗くなります。**窓を正面か横にするか、**手元の照明を顔の側に置いてください。**

**背景をぼかす機能や、仮想の背景**を使うこともできますが、**通信の状態によっては動作が不安定**になります。**無地の壁が確実**です。

## 話し方を、対面から変える

| 項目 | 画面越しでの調整 |
|---|---|
| 速度 | **やや遅く。**音声の遅延があるため |
| 間 | 相手が話し終えてから、**一拍おいて**話し始める |
| 目線 | **カメラを見る時間**を作る（画面を見続けると伏し目に見える） |
| 相槌 | **やや大きめに。**画面では動きが伝わりにくい |
| 資料 | 手元に職務経歴書を置いてよい。**読み上げない** |

**2つ目が、いちばん効きます。**

**音声には遅延があるため、相手の言葉に食い気味に答えると、話が重なります。**一拍おくだけで、**会話が滑らかになります。**

**手元のメモは、使って構いません。**ただし、**目線が下がり続けると、読んでいると分かります。**キーワードだけのメモにしてください。

## 画面の共有を求められた場合

**一部の会社では、実務の確認として画面の共有を求めることがあります。**

**その場合、次の点に注意してください。**

| 注意 | 内容 |
|---|---|
| 共有する範囲 | **画面全体ではなく、特定のウィンドウ**を選ぶ |
| 通知 | **通知が表示されない設定**にしておく |
| 開いているもの | 共有の前に、**他のファイルを閉じる** |
| 職務の資料 | **業務に関わるファイルは、端末に置かない** |

**4つ目が前提です。**在職中の方が、**職務の資料を私物の端末に保存していること自体が問題**になります。

**面接で示す資料は、自分で作った職務経歴書だけ**です。

:::insight
画面越しの面接で、**在職中の方からいちばん多い相談が「場所がない」**です。自宅に個室がない、家族がいる時間帯しか調整できない。**この場合、いくつか方法があります。**有料の個室のスペース、公共の施設の貸室、車内。**いずれも、通信の状態を事前に確認してください。**ただし、**避けたほうがよいのは、飲食店や公共の交通機関の中**です。**周囲の会話が入るうえ、こちらの声も周囲に聞こえます。**在職中の転職活動であることが、**意図せず周囲に伝わる**ことになります。そして、**面接の相手にも、環境は伝わります。**背後の音や映像で、**準備の程度が分かってしまう。**面談で伺っていると、**場所の確保だけで応募を諦めてしまう方**がいらっしゃいますが、**多くの場合、方法はあります。**日程と場所の調整は、相談できる部分です。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 在職中の日程の組み方

**画面越しの面接は、時間帯の選択肢が広がります。**組み方の例を挙げます。

| 時間帯 | 使い方 |
|---|---|
| 始業前 | 8時台に設定できる場合がある。**自宅から接続** |
| 昼休み | 45分〜60分の枠。**面接が長引く可能性を伝えておく** |
| 勤務時間の後 | 18時以降。**最も調整しやすい** |
| 年次休暇の半日 | 複数社をまとめて受ける場合 |

**2つ目を使う場合は、あらかじめ「◯時までしか時間が取れません」と伝えてください。**途中で切らざるを得なくなるより、**先に枠を示すほうが確実**です。

**4つ目は、効率がよい方法**です。半日の休暇で、**2社から3社の面接を入れられます。**ただし、**間を30分以上空けてください。**面接が延びることがあります。

**日程の調整は、人材会社を経由している場合、担当者が行います。**制約を伝えておけば、その範囲で組まれます。

## トラブルが起きたとき

| トラブル | 対処 |
|---|---|
| 接続が切れた | **慌てずに再接続。**繋がらなければ、電話かメールで連絡 |
| 音声が聞こえない | **チャットで状況を伝える**（機能があれば） |
| 相手の声が途切れる | **「一部聞き取れませんでした」と伝えて、聞き直す** |
| 途中で音が入った | 一言詫びて、続ける。**長い説明は不要** |

**3つ目を遠慮しないでください。**聞き取れないまま答えると、**質問と答えがずれます。**

**聞き直すことで印象が下がることは、まずありません。**

**事前に、連絡用の電話番号とメールアドレス**を手元に置いておくと、トラブル時に慌てません。

**なお、接続に使う機器は、可能であれば私物の端末を使ってください。**職場から貸与されている端末で外部の会議の仕組みに接続することは、**情報セキュリティの方針に抵触する場合**があります。

## 服装と、映る範囲

| 項目 | 実務 |
|---|---|
| 服装 | **指定がなければスーツ。**襟のある服装であれば問題になりません |
| 映る範囲 | **胸から上。**背後に映るものを確認する |
| 姿勢 | 画面との距離を一定に。**近すぎない** |
| 時計・書類 | 手元に置いて構いません |

**「上だけ整えればよい」と考えるのは避けてください。**立ち上がる場面が生じることがあります。

[経験の言い換えから相談する](../apply.html)こともできます。

## よくある失敗

**1. 職場から接続する**

**背景と音声で、守秘の線を越える可能性**があります。

**2. 逆光になっている**

**顔が暗くなります。**光の向きを確認してください。

**3. 相手の言葉に食い気味に答える**

**一拍おいて**から話し始めてください。

**4. 手元の資料を読み上げる**

**目線が下がり続けると、読んでいると分かります。**

**5. 聞き取れないまま答える**

**聞き直してください。**印象は下がりません。

**6. 飲食店や移動中に接続する**

**周囲に会話が聞こえます。**

:::insight
ここまで準備の話をしておいて逆のことを言いますが、**画面越しの面接は、公務員の方にとって有利な面があります。**理由は2つあります。1つは、**手元に資料を置けること**です。書類の数字や、用意した4つの答えのキーワードを、**見ながら話せます。**対面では難しい準備が、画面越しなら使えます。もう1つは、**在職中でも受けやすいこと**です。年次休暇を取らずに、**昼休みや勤務時間の後に調整できる**場合があります。面談で伺っていると、**「平日に休みを取りにくいので、転職活動ができない」**という方が少なくありません。**画面越しの面接が使える応募先であれば、その制約はかなり小さくなります。**応募の前に、**選考が画面越しで行われるかを確認**してください。人材会社を経由している場合は、担当者が確認できます。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方公務員法第34条第1項**は、**職務上知り得た秘密を漏らしてはならない**とし、**退職後も同様**としています
- **職場から接続しないでください。**背景、音声、画面の共有で線を越える可能性があります
- 準備するのは、**①接続 ②背景 ③音声 ④光**の4点。**逆光は見落とされやすい**点です
- 話し方は、**やや遅く、一拍おいて、カメラを見る時間を作る**。相槌はやや大きめにします
- 画面の共有を求められたら、**特定のウィンドウを選び、通知を切る**。職務の資料は端末に置きません
- **聞き取れなければ、聞き直してください。**印象は下がりません

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 自宅の通信の状態が不安定です

**事前に確認して、不安があれば対策してください。**有線での接続が可能であれば、**無線より安定します。**それも難しい場合は、**接続の前に他の機器の通信を止める**だけでも改善することがあります。それでも不安が残る場合は、**面接の冒頭で伝えて構いません。**「通信が不安定になる可能性があります。切れた場合は、再接続いたします」。**先に伝えておけば、切れたときの対応が早くなります。**また、**電話での面接に切り替えられるか**を、事前に確認しておく方法もあります。

### 録画されることはありますか

**会社によっては、録画する場合があります。**その場合、**事前に同意を求められるのが通常**です。同意しない選択もできますが、**選考の進め方に影響する可能性**はあります。気になる場合は、**録画の目的と、保管の期間を確認**してください。採用の選考で扱われる個人情報は、**業務の目的の達成に必要な範囲内**とされています。なお、**こちらから相手を録画することは避けてください。**相手の同意なく記録することは、問題になり得ます。メモを取ることは、通常は問題ありません。

### 対面の面接と、評価に差はありますか

**選考の基準そのものは、変わらないのが通常**です。ただし、**伝わり方には差が出ます。**画面越しでは、**表情の細かい変化や、場の空気が伝わりにくい**ため、**言葉で明確に述べる比重が上がります。**対面なら雰囲気で伝わる部分を、**言葉にする必要がある**ということです。対処としては、**結論を先に述べ、短く区切って話す**ことです。長い説明は、画面越しではさらに伝わりにくくなります。なお、**最終の面接だけは対面で行う**会社もあります。その場合は、**移動の時間を見込んで日程を調整**してください。
