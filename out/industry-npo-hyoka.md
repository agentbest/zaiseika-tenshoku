NPO・公益法人への転職を考える方から、**遠慮がちにこう伺う**ことがあります。

**「私がやってきたのは、事務です。評価されるものがあるでしょうか」**

**あります。**しかも、**ご本人がいちばん軽く見ている部分**が評価されます。

**理由は、法人の側が何を義務として負っているかを見れば分かります。**この記事では、**法令上の義務から逆算して、どの経験が評価されるか**を整理します。

選考の進み方は[NPO・公益法人の選考フローと、面接で見られている観点](industry-npo-senko.html)、志望動機の組み立ては[NPO・公益法人の志望動機](industry-npo-shiboudoki.html)にあります。

## 法人は、会計について法令上の原則を負っています

**特定非営利活動促進法第27条**です。

> **（会計の原則）第二十七条　特定非営利活動法人の会計は、この法律に定めるもののほか、次に掲げる原則に従って、行わなければならない。**
>
> 二　**会計簿は、正規の簿記の原則に従って正しく記帳すること。**
>
> 三　計算書類（活動計算書及び貸借対照表をいう。次条第一項において同じ。）及び財産目録は、**会計簿に基づいて活動に係る事業の実績及び財政状態に関する真実な内容を明瞭に表示したもの**とすること。
>
> 四　**採用する会計処理の基準及び手続については、毎事業年度継続して適用し、みだりにこれを変更しないこと。**

**3つとも、「やったほうがよい」ではなく「行わなければならない」**と書かれています。

**第4号に注目してください。****「毎事業年度継続して適用し、みだりにこれを変更しない」**です。

**これは、役所の会計をやってきた方にとっては、当たり前の作法**です。**科目の立て方を年度ごとに変えない。**前年度と比較できる形で作る。**決算のときに、前年度と同じ切り方になっているかを確認する。**

**その当たり前が、法人の側では担い手の少ない仕事**になっています。

## 公益法人には、収支の均衡を図る義務があります

**公益認定法第14条**です。

> **（公益目的事業の収入及び費用）第十四条　公益法人は、その公益目的事業を行うに当たっては、**内閣府令で定めるところにより、**当該公益目的事業に係る収入をその実施に要する適正な費用**（当該公益目的事業を充実させるため将来において必要となる資金として内閣府令で定める方法により積み立てる資金を含む。）**に充てることにより、内閣府令で定める期間において、その収支の均衡が図られるようにしなければならない。**

**「収支の均衡が図られるようにしなければならない」**です。

**公益目的事業で、費用を超える収入を溜め込む形にはできない**という建て付けです。**つまり、収入と費用を対応させて管理し続ける必要があります。**

**この管理は、役所の予算の執行管理と、やっていることがほとんど同じ**です。

| 役所でやっていたこと | 法人で求められること |
|---|---|
| 予算の執行率を月次で見る | **事業ごとの収支の進捗を見る** |
| 節・細節で支出を分ける | 事業区分ごとに費用を配賦する |
| 流用・補正の判断 | 期中の計画の修正 |
| 決算で不用額を整理する | **期間内で収支の均衡を図る** |
| 前年度と比較できる形で作る | **継続性の原則（法第27条第4号）** |

**左の列を、当たり前だと思ってきた方が多い**です。**右の列を担える人を、法人は探しています。**

## 評価される経験は、5つに整理できます

| 経験 | 法人の側での呼ばれ方 | なぜ評価されるか |
|---|---|---|
| ① 予算の編成と執行管理 | 事業予算の管理 | **収支の均衡を図る義務に直結する** |
| ② 会計・出納・決算 | 経理、決算 | **正規の簿記の原則と継続性の原則** |
| ③ 補助金・助成金の交付事務 | 申請、実績報告 | **審査する側の観点を知っている** |
| ④ 要綱・規程の作成 | 内部規程の整備 | 規程が未整備の法人が多い |
| ⑤ 審議会・委員会の事務 | 理事会・評議員会の運営 | **形式が要る会議体を回せる** |

**①と②が、いちばん求められています。**

**理由は単純で、この業界に会計を担える人が少ないから**です。**事業の分野に関心を持って入ってくる方が多く、経理は誰かが兼務している**という状態の法人が少なくありません。

**「会計しかやっていません」という方は、この業界ではむしろ強い**です。

**③も効きます。**補助金の申請書を書くとき、**交付する側が何を見るかを知っている**のは大きな差になります。**「審査で落ちる書き方」が分かる**からです。

**④は、意外に思われるかもしれません。**法人の規模が小さいと、**就業規則・経理規程・旅費規程が整っていない**ことがあります。**要綱を条文の形で書いてきた経験は、そのまま使えます。**

**⑤は、理事会・評議員会の運営です。**招集の手続き、議事録の作成、定足数の確認。**審議会の事務をやってきた方には、見慣れた仕事**です。

## 言い換えの表

**職務経歴書に書くときは、役所の言葉のままにしないでください。**

| 役所での言い方 | 法人に伝わる言い方 |
|---|---|
| 予算の要求と査定の補助 | **年間◯件の事業予算の積算と、査定への対応** |
| 予算の執行管理 | 事業ごとの収支の進捗の管理と、期中の計画の修正 |
| 歳入歳出の整理 | **収入と費用の対応付け、事業区分ごとの整理** |
| 決算統計の作成 | 年度の実績の取りまとめと、前年度との比較の整理 |
| 補助金の交付決定 | **申請の審査、要件の確認、実績報告の検査** |
| 要綱の制定・改正 | 内部の規程の作成と改正、様式の整備 |
| 審議会の庶務 | **会議体の招集、資料の作成、議事録の作成** |
| 監査の対応 | **指摘への対応と、再発防止の仕組みの整備** |

**右の列は、そのまま求人票の言葉に近い**です。

**この言い換えをしないまま出すと、読む側が「何ができる人か」を判断できません。**同じ経験でも、**書き方で通過率が変わります。**

## 評価されにくい経験

**正直に書いておきます。**

| 経験 | 評価されにくい理由 |
|---|---|
| 特定の制度の細かい運用の知識 | **その制度を扱わない法人では使えない** |
| 庁内の調整の経験 | 相手も組織の形も違う |
| 前例を踏襲した処理の実績 | **前例の無い場面が多い** |
| 在籍年数そのもの | 年数より、何を担ったか |
| 役職の名称 | **法人の側に対応する段階が無い** |

**「係長を◯年」という書き方は、この業界ではあまり効きません。**

**書くなら、「◯人の係の事務の進行を管理し、◯件を処理した」**です。**段階の名前ではなく、担った範囲**で書いてください。

**それから、制度の細かい知識**です。**その制度を扱う法人なら強い材料**ですが、**扱わない法人には響きません。**応募先によって、**前に出す経験を入れ替えてください。**

:::insight
面談で拝見していて、**この業界への転職でいちばん惜しいのが、会計の経験を書かない方**です。「経理は自分の専門ではないので」「◯年しかやっていないので」とおっしゃって、職務経歴書の後ろのほうに小さく書かれています。**逆にしてください。**理由は、**法人の側の求人の出方**にあります。事業の担当者は、**その分野に関心のある方からの応募が集まります。**ところが、**会計や事業予算の管理を担える人の応募は、ほとんど来ません。**結果として、**事務局長が事業をやりながら経理も見ている**という状態の法人が多くあります。そこに、**予算の執行管理を業務としてやってきた人が応募してくる**と、**法人の側の受け取り方は「ようやく来た」**に近いものになります。しかも、この経験は**分野を問いません。**福祉でも環境でも国際協力でも、**収支の管理は同じ構造**です。分野の経験が無いことを気にされる方ほど、**分野に左右されない経験を持っている**ことが多い。職務経歴書の最初の3行に、**予算・会計の経験を置いてください。**それだけで、読まれ方が変わります。
:::

## 職務経歴書での並べ方

| 位置 | 書くもの |
|---|---|
| 冒頭の要約（3〜4行） | **予算・会計・補助金のうち、担った範囲** |
| 職歴の1つ目 | **直近の担当。**件数と金額の規模を入れる |
| 職歴の2つ目以降 | 分野の経験。**応募先に近いものを前へ** |
| 実績の欄 | **制度の改正、システムの更改、計画の策定への対応** |
| 資格・研修 | 簿記、会計の研修、その分野の研修 |

**冒頭の要約を必ず付けてください。**法人の側は、**人事の専任がいないことが多く、読む時間が限られています。**

**金額や件数は、公表されている範囲で書いて構いません。**予算書・決算書は公表されているので、**自分が担当した事業の規模は、公表資料の範囲で示せます。**

**⚠ 内部の事情や、公表されていない数字は書かないでください。**守秘の観点もありますし、**それを書く人は、次の職場の事情も外で話す**と見られます。

[経験の言い換えから相談する](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担です）。

## 面接で聞かれやすいこと

| 聞かれること | 何を確かめられているか |
|---|---|
| 会計の実務は、どこまでご自身で | **兼務で回せるかどうか** |
| 会計のソフトは使えますか | **役所のシステムとの違いへの構え** |
| 事業の計画と実績の差を、どう扱ってきましたか | 期中の修正ができるか |
| 監査で指摘を受けた経験はありますか | **指摘への向き合い方** |
| 分野の経験が無いが、大丈夫ですか | 学ぶ構えがあるか |

**2つ目は、正直に答えて構いません。**役所の財務会計システムは独特なので、**市販の会計ソフトの経験が無い方がほとんど**です。

**答え方は、「仕組みは同じなので、操作は覚えます」**という形です。**仕訳の考え方と、科目の対応が分かっていれば、ソフトは手続きの問題**です。

**4つ目は、良い材料になります。**指摘を受けたこと自体ではなく、**そのあと何を変えたか**を話してください。**チェックの項目を様式にした、確認の担当を分けた。**仕組みで直した話は、**そのまま法人で使える経験**として聞かれます。

:::insight
ここまで「評価される」話をしてきましたが、**申し上げておきたいことがあります。**評価される経験があることと、**移ったほうがよいことは、別**です。面談で、**「評価されると分かったので、動かないといけない気がしてきました」**とおっしゃる方がいらっしゃいます。そうではありません。**いまの職場で、その経験がさらに厚くなる見込みがあるなら、厚くしてから動くほうが選択肢は広がります。**とくに、**予算・会計の経験は、年数と担当した規模で評価が変わります。**係の担当として回していた方が、**取りまとめの側に立つ**と、書ける内容が一段変わります。**その段階が近いなら、待つ判断にも理があります。**一方で、**この経験は消えません。**異動で会計から離れても、**担った事実は残ります。**ですから、**いま動く理由が他にある場合**——通勤の事情、家族の事情、分野への関心——**その理由で判断してください。**「評価されるから」は、**動く理由としては弱い**です。評価されるという事実は、**動くと決めたときに使える材料**であって、**動く理由ではありません。**在職のまま、材料の整理だけのご相談も承っています。
:::

## まとめ

- **評価される経験は、法人が負っている義務から逆算できます**
- **特定非営利活動促進法第27条**は、会計について**正規の簿記の原則による記帳**、**計算書類の真実な内容の明瞭な表示**、**会計処理の基準及び手続の継続適用**を、**行わなければならない**ものとして定めています
- **公益認定法第14条**は、公益目的事業について**収支の均衡が図られるようにしなければならない**と定めています
- **この2つを担える人が、この業界には少ない**です。**予算の執行管理と会計の経験は、そのまま需要と重なります**
- 評価される経験は、**①予算の編成と執行管理 ②会計・出納・決算 ③補助金の交付事務 ④要綱・規程の作成 ⑤審議会の事務**の5つです
- **職務経歴書は、役所の言葉のままにしない**でください。**言い換えの表**のとおり、担った範囲と件数で書きます
- 評価されにくいのは、**特定の制度の細かい運用、庁内の調整、前例の踏襲、在籍年数、役職の名称**です
- **職務経歴書の最初の3行に、予算・会計の経験を置いて**ください
- **評価されることと、移ったほうがよいことは別**です。動く理由は、別に必要です

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 簿記の資格がありません。会計の経験として書けますか

**書けます。**資格の有無と、実務を担ったかどうかは別です。**公金の出納、支出負担行為の確認、決算統計の作成**を担当していたなら、それは会計の実務です。**書き方は、「担当した事務の内容」を具体的に並べる形**にしてください。「支出負担行為の審査を年間◯件」「決算の資料の作成を◯年」。そのうえで、**資格を取るなら簿記が分かりやすい**です。役所の会計と企業の会計では記録の考え方が違うので、**その違いを説明できるようになると、面接での説得力が上がります。**ただし、**資格を取ってから応募する必要はありません。**実務があるなら、先に応募して構いません。学びながら進めるという伝え方で足ります。

### 会計以外の部署しか経験がありません。それでも評価されますか

**されます。**この記事で会計を前に出したのは、**需要と供給の差がいちばん大きいから**であって、他の経験が評価されないという意味ではありません。**窓口で相談を受けた経験、許認可で現場を見た経験、計画を策定した経験**は、いずれも材料になります。とくに、**その法人が扱う分野と重なる部署にいた方**は、**分野の理解という点で強い**です。整理のしかたは、**「誰を相手に、何を確認し、何を決めていたか」**で言い換えることです。制度の名前で書くと伝わりませんが、**動作で書くと受け皿が見つかります。**部署ごとの言い換えは[自治体の部署別 仕事ガイド](../zukan.html)に整理しています。

### 技術職です。事務の経験がありませんが、応募できますか

**応募できます。**法人の中には、**施設の維持管理、環境の調査、災害の復旧支援**など、**技術の知識が要る事業**を持つところがあります。また、**建物や設備を持っている法人**では、**修繕の計画と発注を担える人**が求められます。役所で**工事の発注と監督**をしていた方なら、**仕様書の作成、業者との協議、検査**の経験がそのまま使えます。探し方は、**分野ではなく、法人が何を持っているかで見る**ことです。**施設を運営している法人、フィールドを持っている法人**が候補になります。なお、**技術職の方は、会計や規程の経験が無いことを気にされることが多い**のですが、**技術の側から入って、あとから覚える形で問題ありません。**
