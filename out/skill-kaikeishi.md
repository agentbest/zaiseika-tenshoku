**財政や会計を担当してきた方から、「目指すべきか」**というご相談を伺います。

**判断の前に、前提を確認してください。**

この記事では、**業務の中身**と、**現実的な選び方**を扱います。

**⚠ 受験・登録の要件と手続は、所管するところの公表を確認してください。****この記事では、個別の要件には触れません。**

## 業務が、法律に定められています

**公認会計士法第2条第1項**です。

> **公認会計士は、他人の求めに応じ報酬を得て、財務書類の監査又は証明をすることを業とする。**

**同条第2項**です。

> **公認会計士は、前項に規定する業務のほか、公認会計士の名称を用いて、他人の求めに応じ報酬を得て、財務書類の調製をし、財務に関する調査若しくは立案をし、又は財務に関する相談に応ずることを業とすることができる。**

**第1項の監査又は証明**と、**第2項の調製・調査・立案・相談**が、業務として書かれています。

**第2項の「財務に関する調査若しくは立案」「相談」**は、**行政の財政の事務と重なる動作**です。

**つまり、資格がなくても、近い仕事はあります。**

**この点を先に押さえてください。**

## 目指す場合の前提

| 前提 | 内容 |
|---|---|
| ① 学習の期間 | **相応の期間がかかります** |
| ② 在職との両立 | 繁忙期の影響を受けます |
| ③ 目的 | 監査を業とするのか、近い仕事か |
| ④ 年齢・生活 | 期間中の収入と生活 |
| ⑤ 代わりの選択肢 | 資格を使わない道 |

**③で大きく分かれます。**

**監査又は証明を業とする**のであれば、**資格が前提**です。

**一方、財務の調査や立案、相談に近い仕事**であれば、**資格がなくても就ける求人があります。**

**⑤について。**

**この点を検討せずに学習を始めると、途中で迷います。**

## 代わりの選択肢

| 選択肢 | 内容 |
|---|---|
| ① 管理部門 | **予算の管理、実績の集計** |
| ② 事業の企画 | 計画と実績の差異の説明 |
| ③ 内部監査 | 手続の確認、是正 |
| ④ 自治体が相手の事業 | 公会計の理解 |
| ⑤ 公会計の支援 | 制度の理解 |

**④と⑤が、行政の経験と最も重なります。**

**自治体を顧客とする会社では、公会計の仕組みを理解している人**が必要とされます。

**年度の区切り、議決の時期、繰越の扱い、支出の手続。**

**扱いは**[財務諸表の読み方｜公会計との違いから入る](skill-zaimu.html)**に整理しています。**

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 行政での経験で書けること

| 経験 | 民間での読まれ方 |
|---|---|
| ① 予算の編成 | **予算の策定、資源の配分** |
| ② 執行の管理 | 予算の管理、進捗の確認 |
| ③ 決算の作成 | 実績の集計、報告 |
| ④ 見積りの確認 | 原価の妥当性の確認 |
| ⑤ 監査への対応 | 内部統制、是正 |
| ⑥ 公表の資料 | 数字を伝わる形にする |

**⑤が見落とされやすい**です。

**監査を受ける側として、指摘に対応し、手続を整えてきた経験**です。

**この経験は、内部監査の業務でも使えます。**

:::insight
この資格について、**面談でお伝えしているのが「先に代わりの選択肢を見てください」**という点です。**学習に相応の期間がかかる**資格です。そして、**在職中に始めると、繁忙期の影響を受けます。**予算の編成、決算、議会。**この時期に学習が止まることは、避けにくい。**ですから、**始める前に、「資格がなくても就ける求人があるか」を確認してください。**行政の財政や会計の経験は、**管理部門、事業の企画、内部監査、自治体を顧客とする事業**で評価されます。**求人票を5件読んで、応募できるものがあるなら、まずそちらを試す。**そのうえで、**条件が合わない場合に、資格を検討する。**この順序であれば、**学習を始めるかどうかの判断に、材料が揃います。**逆の順序だと、**数年後に「やはり違った」となる可能性**があります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 目指す場合の進め方

| 順 | やること |
|---|---|
| 1 | **要件と手続を確認する**（所管の公表） |
| 2 | 学習の期間を見積もる |
| 3 | 在職中の繁忙期を書き出す |
| 4 | 続けられる形かを確認する |
| 5 | 代わりの選択肢と比べる |
| 6 | 判断する |

**3と4が要**です。

**予算の編成、決算、議会の時期は、学習が止まります。**

**年間で、どれだけの時間が取れるか**を、先に見積もってください。

**なお、取れば転職できる、という関係にはありません。**

**何を担当し、どう判断したか**が、評価の対象です。

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 実績の整理 | **予算の規模、担当した事業の数** |
| 監査への対応の整理 | 指摘と是正の経緯 |
| 公表資料の整理 | 作成に関わったもの |
| 求人を読む | 週に30分 |

**1行目を先にしてください。**

**手元にある材料を整理すると、資格が必要かどうかが見えます。**

**根拠のない数は書かないでください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 担当した規模 | **予算の額、事業の数** |
| 見積りの確認 | 何を見たか |
| 監査への対応 | 指摘と是正 |
| 公会計と企業会計の違い | 理解を示す |
| 学習の状況 | 続けているか |

**4行目です。**

**違いを説明できると、適応の見通しが伝わります。**

**扱いは**[財務諸表の読み方｜公会計との違いから入る](skill-zaimu.html)**に整理しています。**

## 書き方の例

**悪い例**

> 財政課で、予算と決算を担当しました。

**良い例**

> ◯◯課において、**年間約◯億円の当初予算の編成に関わり、◯課・◯件の要求について内容と積算を確認。**執行の状況を**四半期ごとに確認し、補正の要否を整理。**決算にあたり、**実績を集計のうえ、成果を説明する資料を作成。**監査の指摘◯件について、**是正の手順を整理し、翌年度の運用に反映。**

**「規模」「査定」「確認の周期」「監査への対応」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 学習の期間を見積もる観点

| 観点 | 確認すること |
|---|---|
| ① 出題の範囲 | **所管の公表を確認** |
| ② 手元の知識 | どこから始めるか |
| ③ 取れる時間 | 平日、休日、繁忙期 |
| ④ 進め方 | 独学か、講座か |
| ⑤ 見直しの時期 | いつ判断し直すか |

**⑤を決めておいてください。**

**「半年後に進み方を確認する」と決めておく**と、**続けるか切り替えるかを判断できます。**

**期限を決めずに始めると、判断の機会が来ません。**

## よくある失敗

**1. 代わりの選択肢を見ずに始める**

**先に求人票を5件**読んでください。

**2. 繁忙期を計算に入れない**

**学習が止まります。**

**3. 実績の整理を後回しにする**

**資格が必要かどうか**が見えません。

**4. 監査への対応を書かない**

**内部監査の業務**でも使えます。

**5. 公会計の理解を書かない**

**自治体が相手の事業**で求められます。

**6. 目的を決めずに学習を始める**

**監査を業とするのか、近い仕事か**で変わります。

**7. 要件を人づてで判断する**

**所管の公表**を確認してください。

**8. 取れば転職できると考える**

**何を担当しどう判断したか**が評価の対象です。

:::insight
ここまで「代わりの選択肢を」という話をしておいて逆のことを言いますが、**目指すと決めたなら、在職中に始めるほうが現実的です。**面談で拝見していると、**「退職してから集中しよう」と考える方**がいらっしゃいます。ところが、**収入が途切れた状態での学習は、期間が読めないという不安が加わります。**そして、**途中で方針を変えたくなったとき、職歴に空白が生じている**という状態になります。一方、**在職中であれば、学習が遅れても生活は続きます。**そして、**途中で「やはり別の道にする」と決めても、経歴は積み上がっています。**ですから、**目指すのであれば、在職中に始め、進み方を見て判断する**という形が現実的です。**進捗が想定より遅ければ、その時点で切り替えられます。**⚠ 退職を前提とした計画は、**生活の見通しを立てたうえで**判断してください。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **公認会計士法第2条第1項**は**財務書類の監査又は証明**を、**第2項**は**調製、財務に関する調査若しくは立案、相談**を業務としています
- **第2項の調査・立案・相談は、行政の財政の事務と重なる動作**です。**資格がなくても近い仕事があります**
- 目指す前提は、**学習の期間、在職との両立、目的、生活、代わりの選択肢**です
- **代わりの選択肢は、管理部門、事業の企画、内部監査、自治体が相手の事業、公会計の支援**です
- **先に求人票を5件読んで、応募できるものがあるか確認**してください
- **監査を受ける側として対応した経験**は、内部監査の業務でも使えます
- **目指すなら、在職中に始めて進み方を見る**ほうが現実的です

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 財政課の経験は、どこまで評価されますか

**予算の規模と、担った工程で書いてください。**「年間約◯億円の予算の編成に関わり、◯課の要求の査定を担当」「執行の状況を四半期ごとに確認し、補正の要否を整理」という形です。**査定の経験**は、**見積りの妥当性を判断してきた動作**として読まれます。なお、**公会計と企業会計の違いを説明できる**と、適応の見通しが伝わります。扱いは[財務諸表の読み方｜公会計との違いから入る](skill-zaimu.html)に整理しています。**資格がなくても、書ける材料は多くあります。**

### 働きながら学習を続けられますか

**繁忙期を書き出してから判断してください。**予算の編成、決算、議会の時期は、**学習が止まりやすい期間**です。年間で、**どの月にどれだけ時間が取れるか**を先に見積もってください。そのうえで、**続けられる形かを確認**します。なお、**団体によっては、研修や自己啓発に関する制度**が置かれていることがあります。**人事担当に確認**してください。扱いは[ITパスポート｜情報政策課以外でも意味があるか](skill-itpassport.html)にも触れています。**制度の有無で、進め方が変わります。**

### 途中で方針を変えてもよいですか

**構いません。**学習を始めたことと、最後まで進めることは別です。**進み方を見て、判断を変えて差し支えありません。**なお、**途中までの学習も、書類に書ける場合があります。**「財務に関する学習を継続」という形で、**学ぶ習慣がある人**として読まれます。ただし、**合格していない段階を保有と書かないでください。**事実と異なる記載になります。**在職中に始めておけば、切り替えの判断がしやすくなります。**扱いは[選考スケジュールの組み方](senko-sagasu-schedule.html)に整理しています。
