医薬品卸や医療機器の仕事を調べるときは、営業、薬事、技術、事務等の職務を分けます。公務での説明や調整、医療や福祉に関わる所管の経験は、本人が担当した工程として整理できます。そのことと、販売や技術、医療の専門実務を担ったことは別に確認します。

本記事は2026年11月時点の公開情報にもとづきます。確認日は2026年11月25日です。採用側の非公開の評価基準や採否の理由は確認できません。以下は公式の仕事内容と本人の事実を照合する観点であり、公務員の経歴があれば特定の評価を得られるという説明ではありません。

## 卸とメーカー、職務の担当を別々に読む

メディセオの公式キャリア採用の営業の案内は、医薬MSと試薬MSを分けています。医薬MSは、病院、診療所、調剤薬局等へ訪問し、医薬品や医療機器等の販売と情報の提供を行う仕事です。試薬MSは、病院や検査センターへ検査機器や試薬を提案し、メーカーとも連携する仕事を示しています。

伊藤超短波の名古屋営業所の中途募集は、業務用医療機器の営業です。販売代理店への営業、自社製品の説明やデモンストレーション、納入と使用方法の説明、展示会やセミナーの企画運営等が示されています。卸の営業と同じ仕事としてまとめず、誰に何を提案するかを確認します。

医薬品卸のMSと、医薬情報担当者を表すMRの呼び名も混同しません。メディセオは、同社のMSにMR認定試験への挑戦を推奨し、合格したMSをARと称する仕組みを説明しています。この案内から、全ての会社のMSが同じ条件や資格であるとは広げません。

医療機器の販売、メーカーの開発や保守、病院で実際に機器を使用する医療職も、それぞれの担当を確認します。製品の説明をする仕事を、診療や治療を行う仕事と同じにしません。公務での許認可や制度の案内から、専門の医療行為を担ったことにも変えないようにします。

| 分ける対象 | 今回読む内容 | 経験を広げないための線引き |
| --- | --- | --- |
| 医薬品卸 | 医薬MS、試薬MSの営業 | 制度の案内を販売実績にしない |
| 医療機器メーカー | 代理店営業や製品説明等 | 所管を製品技術の全実務にしない |
| 専門職 | 薬事、開発、保守、医療職等 | 営業の条件を専門資格へ流用しない |
| 事務 | 今回の募集の有無と担当 | 営業の募集から事務採用を作らない |

仕事の違いを見比べたい方は、[掲載中の求人を職務から確認できます](../?gov=1)。医療に関わるという共通点だけでなく、今回本人が行う工程を読むために使えます。

## 説明の経験は確認と引継ぎの範囲を示す

公務の窓口で制度を説明した経験は、相手の疑問を聞き、公開の資料や担当部署へ確認し、必要な案内をした工程として書けます。本人がどこまで回答し、どこから専門担当へ引き継いだかを分けます。申請や許可の判断を別の担当が行ったなら、その権限まで本人の実務にはしません。

医薬品や医療機器の営業に接点を探す場合も、説明の方法と専門の内容を区別します。問い合わせの対象を整理したことは本人の経験ですが、医薬品の情報や機器の使い方を説明したことがないなら、その実務を経験済みとはしません。扱った情報と確認先を具体的に示せます。

相手の要望をまとめる経験も同様です。医療機関や福祉の事業者と連絡した経験があっても、商品の販売、受注、価格の交渉を担ったかは別です。実施していない販売の実績を足さず、連絡や説明のどの工程に接点があるかを確認します。

製品の安全や使い方に関する判断は、担当する職務と権限を確認します。応募の準備のために、読者が医療の判断をしたり、機器の操作を独自に案内したりする必要はありません。今回の求人にある担当範囲と、必要な教育や資格の案内を確認します。

:::insight
公務の「事業者対応」を営業の仕事と照合するなら、誰の何の疑問を整理したかを先に示せます。制度の手順を確認して伝えたことと、医薬品や医療機器を提案して販売したことは同じではありません。本人が実施した説明、照会、引継ぎを書き、商品や技術の専門実務は別に残します。医療に関わる部署名だけで、診療や製品の知識まで経験済みとする必要はありません。情報の確認先と自分の権限を分けることは、経験を小さく扱うためではなく、仕事内容を同じ意味で比較するための整理です。採用側の心理を予測するより、本人が説明できる工程を確定することを優先できます。
:::

## 応募資格は不問の対象と必要な条件を分ける

メディセオの前記医薬MSと試薬MSは、短大・大卒以上と、普通自動車運転免許を応募資格に示し、AT限定可としています。医療業界の経験や、医薬品または試薬に関する知識は問わないとされています。この不問の対象と、学歴や免許の条件を分けて読みます。

同じページでは、事務職は現在募集を行っていないとされています。営業に関する条件や勤務の案内があるからといって、事務でも同じ時期に応募できるとは判断しません。募集の有無と職種の条件を、閲覧時に改めて確認します。

伊藤超短波の名古屋の営業は、学歴不問としています。必須の職歴は、営業職の経験があること、または医療、介護、リハビリ、健康、スポーツの業界で勤務経験があることという選択の形です。加えて普通自動車運転免許が必要です。学歴不問を、職歴や免許も不要という意味には広げません。

公務で医療や介護の所管を担当したことが、同求人の求める業界での勤務経験に該当するかは、記載だけで自動的に判断しません。本人がどの組織で何を担当したかを具体的に整理し、意味が不明なら今回の採用担当へ確認します。営業経験の有無とも別に照合できます。

## 架空の整理表で所管と販売を区別する

以下は書き方を示すために独立して作成した架空例です。実在の応募者、採用企業の回答、面談の記録ではありません。特定の求人の必須条件を満たす例でもありません。使う場合は本人の事実へ置き換え、実施していない工程は削除してください。

| 項目 | 架空の記入例 |
| --- | --- |
| 検討する仕事 | 卸の営業と医療機器メーカーの営業を別々に調べている |
| 公務での担当 | 事業者向け説明会の案内と問い合わせの取りまとめを担当した |
| 本人の作業 | 質問の内容を分類し、専門担当に確認して、案内する手順を整理した |
| 他者の判断 | 制度の専門判断と説明会の方針は、専門担当と上司が決めた |
| 実施していないこと | 医薬品や機器の販売、価格交渉、保守作業、診療や治療 |
| 応募条件の確認 | 学歴と免許、求人が求める職歴に自分の経験が該当するかを別に照合する |
| 未確認 | 個別の配属先、職歴の条件の解釈、本人へ提示される勤務条件 |

この例では、質問の整理と確認が本人の工程です。「医療事業の営業や技術を一貫して担当」とすると、実施していない販売や保守等を含むように読めます。部署の名称から広げず、自分で作ったものと他者の判断を分けて説明できます。

成果を測っていないなら、医療機関の満足や事業の効率が向上したといった結果を作りません。整理した案内の項目、誰へ確認したか、どの範囲を引き継いだか等、本人が確かめられる事実で記述できます。相手の心理も推測して加えないようにします。

経験の範囲を整理したい方は、[職歴と希望する仕事の照合を相談できます](../apply.html)。ご利用は無料です（紹介手数料は採用企業の負担）。経験や希望等により、求人の紹介や面談等をご提供できない場合があります。

## 個別の勤務地と雇用条件も確認する

メディセオの確認したページは、医薬MSと試薬MSで募集する地域を分けて掲載しています。本人が希望する場所がある場合は、今回の職種の受付と配属を確認します。営業職としての共通の待遇案内から、自分の具体的な配属や将来の異動まで確定したとは判断しません。

同ページは経験や能力等を考慮した給与や各種手当等を案内しています。ただし、本人への金額や適用は正式な提示で確認します。雇用期間や試用等についても、記載から確認できない条件を他社の例で補いません。共通制度があることと、本人の条件が決まることは別です。

伊藤超短波の前記募集は、正社員で試用期間があると示しています。試用の具体的な長さや条件を、本文にない内容で加えません。名古屋の勤務先が示されていても、その後の範囲や本人の具体的な担当は正式な案内で確かめます。

同求人の給与欄には、外勤手当として固定残業代を含むことが示されています。月給の全てを基本給と読まず、含まれる手当と扱いを確認します。超過の扱いや本人に適用される構成が不明なら採用担当へ照会します。給与額を理由に応募を勧める必要はありません。

募集は受付や地域が変わる可能性があるため、閲覧時に公式情報を確認します。終了した募集は過去の仕事内容や条件の参考として扱います。応募を送信したことと、受付、選考、条件の提示は別々に記録できます。

:::insight
医療に関わる会社でも、卸の営業と機器メーカーの営業では、扱う商品や相手、応募条件が変わります。医療業界の経験を問わない募集と、営業または特定の業界での勤務を求める募集を分けて読めます。公務の所管の経験を自動的に条件へ当てはめず、本人の工程を具体的に示して不明な点を確認します。その上で、勤務地、契約、勤務時間、給与の構成を並べると、仕事への関心と生活の条件を別々に比較できます。研修や資格への支援があることも、本人の採用や配属を約束するものではありません。条件がまだ合わなければ、現職を続けて情報を集める選択も同等に残せます。
:::

## 応募前に情報と権限の扱いをそろえる

経験を伝えるメモは、応募先を変えても本人の担当範囲が変わらないように読み直します。卸の営業へ応募するときも、メーカーの営業へ応募するときも、制度の案内は制度の案内として残せます。相手や目的、確認した情報、引き継いだ先を具体的にし、求人の名称だけに合わせて販売や技術の実績を追加しないようにします。

希望する仕事がまだ定まらない場合も、職種別の必須条件と本人が対応できる勤務を並べるところから比較できます。応募の可否と、本人が希望するかどうかは別の判断です。

公務で扱った事業者や医療機関の担当者の連絡先、患者や住民の個人情報、相談の詳細、内部の審査や許認可の資料を持ち出しません。業務で得た名簿を、応募後の営業に使える人脈として提供する必要もありません。本人の経験は、対象や工程を個人が分からない形で説明できます。

応募資料を作るために内部資料を私用の端末や外部の生成AIへ渡すことも避けます。説明に表や図が必要なら、実際の資料を転用せず、架空の内容で独立して作成したことを明記できます。公表された情報を使う場合も、公表の範囲と本人の担当を区別します。

専門の仕事に関心があれば、必要な資格、教育、担当の範囲を今回の職種として調べます。一般の制度説明の経験を、薬事の判断や機器の技術判断、医療行為の権限へ移しません。学習したことと実務で担当したことも別に記録します。

複数の求人を比較する際は、必須、歓迎、本人の事実、未確認の欄を分けて残します。ある会社から条件の回答を受けても、それを別の会社へ自動的に広げないようにします。法人と職種、確認日を一緒に記録すると、今回の条件として読み直せます。

在職中に応募の準備をすることも可能です。公務の勤務と私用を分け、面接の候補は所属の休暇等の手続きを確認して調整します。退職を先に決める必要はありません。現職で経験を続けながら、仕事と条件の合う募集を比較できます。

確認事項を短くまとめたい方は、[LINEで経験や職種の違いを整理することもできます](https://line.me/R/ti/p/@697nxhbt)。情報収集の段階でも利用できます。

## よくある質問

### 医療や福祉の公務経験があれば営業経験になりますか

本人が何を担当したかを確認します。制度の説明、問い合わせの整理、関係者との連絡は具体的な経験として書けます。ただし、医薬品や機器を提案して販売した実務とは別です。今回の求人の条件と本人の事実を照合し、対象経験の意味が不明なら採用担当へ確認します。

### 医療業界の経験不問なら資格も不要ですか

不問とされる対象と、今回必要な条件を分けます。メディセオの確認した営業の募集は、医療業界の経験や知識を問わない一方、学歴と普通免許を示しています。他の専門職の資格や技術の条件へ、この案内を広げることはできません。

### 転職するか決めていなくても比較できますか

比較できます。職務と応募資格、勤務地や契約、勤務の条件を整理できます。この記事は退職を勧めるものではなく、現職を続ける判断も等しく扱えます。経験が接する仕事があっても、採用や条件を保証するものではないため、今回の正式な案内を確認します。
