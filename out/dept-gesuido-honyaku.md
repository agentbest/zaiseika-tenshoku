下水道課の経験を、職務経歴書にどう書けばよいか。ここでつまずく方が多いのは、**「下水道」と書いた瞬間に、読む側の想像が「汚水」で止まる**からです。

「下水道事業に従事」と書くと、**役所で下水の手続きをしていた人**に読まれます。実際には、**区域の全戸から水を集め、微生物で処理し、基準を満たして川や海に返し、雨水から街を守り、使用料でその全部を回していた**わけですが、それが伝わりません。

この記事では、**民間での訳語**と、**中核スキルの分解**を並べます。

## 「遅滞なく排水設備を設置しなければならない」と書かれています

まず、この仕事の立ち位置を条文で押さえます。**下水道法第10条**です。

> 公共下水道の供用が開始された場合においては、当該公共下水道の排水区域内の土地の所有者、使用者又は占有者は、遅滞なく、次の区分に従つて、その土地の下水を公共下水道に流入させるために必要な排水管、排水渠その他の排水施設（以下「排水設備」という。）を設置しなければならない。

**ここが、水道と逆になっています。**

水道は、**申込みを拒めない**側でした。下水道は、**相手に接続を義務づけている**側です。**区域の中の土地は、供用が始まれば、遅滞なく排水設備を付けて、公共下水道に流さなければならない。**

つまり、**この経歴の方は、「来た人を断らない」のではなく、「区域の全員に来てもらう」という条件で、設備と使用料を回してきた**ことになります。

そして、**第20条**は、使用料について**「能率的な管理の下における適正な原価をこえないものであること」**と定めています。**全員をつなぎ、処理して、原価の範囲で回す。**この3つが、仕事の骨です。

民間で人を採る側から見ると、これは**「区域の全戸を相手に、水処理のプラントと地下の管路を、独立採算で運営してきた人」**です。**水処理、環境の設備、プラントの運転、インフラの保全**——**同じ骨の仕事は、民間にいくつもあります。**

## 民間での訳語

| 行政での言い方 | 民間での言い方 |
|---|---|
| 下水道事業の運営 | 公益事業の運営、インフラ事業の運営 |
| 処理場の運転管理 | 水処理プラントの運転管理、設備の保全 |
| 管きょの維持管理 | 管路の保全、地下インフラの維持管理 |
| 管きょのカメラ調査 | 設備の診断、劣化の調査 |
| 管更生・改築 | 設備の更新、更新工事の管理 |
| 排水設備の確認と検査 | 施工の審査、技術基準の適合の確認 |
| 指定工事店の指定 | 協力会社の認定と管理 |
| 水洗化の促進、接続の勧奨 | 加入の促進、顧客の獲得 |
| 使用料の賦課と徴収 | 請求の管理、債権の管理 |
| 放流水質の管理 | 品質管理、環境の測定、法令の遵守 |
| 除害施設の指導 | 取引先への技術の指導、受入れの基準の管理 |
| 雨水対策・浸水対策 | リスクの管理、事業の継続計画 |
| ストックマネジメント計画 | 資産の管理、設備の投資の計画 |
| 汚泥の処理と有効利用 | 副産物の処理、資源化、廃棄物の管理 |

**この表を職務経歴書にそのまま貼る必要はありません。**ただ、**自分がやっていたことに、民間で通じる名前が付いている**ことは、知っておいてください。

## 中核スキルを5つの工程に分ける

**この経歴の中核は、「選べないものを、全部受け入れて、基準まで戻す」ことです。**5つの工程に分けます。

**工程1：集める**

管きょ、マンホール、ポンプ場。**区域の全戸から、自然の勾配で流し、必要なところはポンプで上げて、処理場まで運びます。**

**この工程に固有の制約があります。****設備が地下にあって、しかも中を流れているのは、こちらで選べない水**だということです。雨の日には、**本来入らないはずの水が入ってきます。**油や異物も流れてくる。**見えない設備の中で、何が起きているかを、マンホールの水位とカメラの映像から推定する技術**です。これは、**地下の設備を保全する会社で、直接に評価される部分**です。

**工程2：処理する**

沈殿、生物処理、消毒。**微生物の力で、汚れを取ります。**

**この工程に固有の制約があります。****生き物を扱っている**ということです。機械は止めれば止まりますが、**微生物は止められません。**流入の量と質が変われば、**微生物の状態も変わる。**それを、**水温、送る空気の量、返送する汚泥の量で、毎日調整し続けます。**この形の運転は、**化学のプラント、食品の工場、民間の排水処理と共通**しています。

**工程3：返す**

放流の水質を測り、基準を満たしていることを確かめて、川や海に戻します。**汚泥は、脱水して、処分するか、資源として使います。**

**この工程に固有の制約があります。****出口の基準を外したときの影響が、自分の組織の外に出る**という点です。川の下流には、他の自治体の取水口があります。だから、**測って終わりではなく、外れそうなときに誰が何をするかまで、手順にしてあります。**この形の品質の管理は、**環境の測定、工場の排水処理、廃棄物の管理の分野と共通**しています。

**工程4：回す**

使用料の賦課、徴収、水洗化の促進。**多くの自治体では、水道の料金と併せて請求します。**

**この工程に固有の制約があります。****原価をこえてはならないと、法律に書かれている**ということです。しかも、**接続してもらわなければ、使用料は入りません。**だから、下水道課には、**「つないでください」と戸別に働きかける仕事があります。**水洗化率、接続率。**これは、民間でいえば、加入の促進**です。**行政の中でこの仕事をしている部署は、そう多くありません。**

**工程5：守る**

雨水の排除、浸水の対策、ポンプ場の運転。**大雨のときに、街を水から守ります。**

**この工程に固有の制約があります。****いつ来るかを、こちらで決められない**ということです。しかも、**来たときには、判断の時間が数十分しかない。**ポンプをいつ動かすか、ゲートをいつ操作するか。**平常時に、手順を作り込んでおくしかない仕事**です。この形の備えは、**事業の継続計画、危機の対応の設計として、民間でそのまま求められます。**

:::insight
この5つの工程のうち、**職務経歴書でいちばん書かれていないのが、工程4**です。面談で伺うと、**「水洗化の促進を担当していました」**という一行で終わってしまいます。ところが、中身を聞くと、**未接続の世帯を台帳から抽出し、戸別に訪問し、工事の費用の助成の制度を説明し、指定工事店を紹介し、接続まで追いかけていた**という話が出てきます。**これは、加入の促進そのもの**です。民間でいえば、**既存の顧客の掘り起こし、契約の獲得、代理店との連携**に当たります。**「水洗化率」という言葉は、求人票にはまったく出てきません。**同じ仕事は、**「加入促進」「稼働率の改善」「未契約者への働きかけ」**と書かれています。書くなら、**「処理区域内の未接続約◯戸を対象に、戸別の訪問と助成制度の案内を実施し、年間約◯戸の接続を実現」**という形です。**この一行があると、技術だけでなく、数字を動かせる人として読まれます。**
:::

## 民間の水処理プラント・設備の保全と、どこが同じでどこが違うか

**同じ点は3つあります。**

- **24時間動く設備を、計画と点検で保全している**こと
- **出口の基準に対する適合を、測定と記録で証明している**こと
- **更新の投資を、長期の計画として積み上げている**こと

**違う点は4つあります。**

| 違い | 行政（下水道課） | 民間（水処理・プラント） |
|---|---|---|
| 相手を選べるか | 区域内は接続が義務。相手を選ばない | 契約の相手を選べる |
| 入口を選べるか | 何が流れてくるかは選べない。除害施設の指導で近づける | 原料や受入れの規格を決められる |
| 料金の決め方 | 条例で定める。原価をこえない | 市場と原価で決める |
| 利益の扱い | 独立採算だが、利益の最大化は目的ではない | 利益が事業の目的に含まれる |

**この4つのうち、移った後にいちばん効くのは、2番目**です。**入口を選べない設備を回してきた経験**は、**民間でも希少**です。民間の工場の排水処理は、**自分の工場の排水**だけを扱います。**何が来るか分かっている。**その環境に移ると、**むしろ楽に感じる**方が多い部分です。

**もう1つ、効き方が大きいのは4番目**です。公営企業会計を扱ってきたなら、**費用を積み上げて、収入と突き合わせて、資金の残高を見る**という作業は、**すでにやってきたこと**です。**「利益」という項目が足されるだけ**で、数字の見方を学び直すわけではありません。

## 評価が高くなりやすい4つの方向

**1. 処理場の運転を受託する会社**

**運転、水質の管理、委託の仕様の作成、履行の確認。**発注の側にいた経験が、そのまま効きます。

**2. 管路の調査・更生・工事の会社**

**カメラ調査の発注、更生の工法の選定、道路の占用の調整、夜間の工事の段取り。****供用中の管を、流しながら直す**という条件を知っている人は、外から採りにくい。

**3. 水処理のプラント・機械のメーカー**

**設備の更新の判断、機械と電気の更新、試運転。**運転してきた側の知識が求められます。

**4. 建設コンサルタント・計画の支援**

**ストックマネジメント計画、全体計画、経営の戦略、浸水対策の計画。**計画の側の経験がある方に向きます。

**なお、この4方向は、求める経験が違います。**1番と3番は、**処理場の運転と設備**を見ます。2番は、**管路と工事**を見ます。4番は、**計画と経営の数字**を見ます。**同じ下水道課の経歴でも、処理場か管路か本庁かによって、通りやすい方向が変わる**ということです。**自分がどの工程を長くやってきたかを、先に整理しておいてください。**

どの経験に値が付くのかから、[相談できます](../apply.html)。在職中でも、情報収集だけでも構いません。

## つまずきやすい点

**1. 「下水道事業に従事」で丸める**

**集める／処理する／返す／回す／守る**の5つに分けてください。

**2. 規模の数字を書かない**

**処理区域内の人口、処理の能力、管きょの延長、水洗化率。**桁だけでも入れてください。

**3. 水洗化の促進を、事務として書く**

**加入の促進**です。**戸数と、動かした数字が伝わる形にしてください。**

**4. 雨水の対応を、苦労話にする**

**平常時に手順を作り込み、大雨のときにその手順で動いた**と書いてください。

**5. 公営企業会計の経験を書き落とす**

**独立採算の事業の運営**です。**損益と資金を見ていたなら、そう書いてください。**

:::insight
この経歴の方に、**最初に確かめていただきたい数字が4つ**あります。**処理区域内の人口、処理場の能力、管きょの延長、水洗化率**です。この4つが並ぶと、**書類の読まれ方が変わります。**「下水道事業に従事」と書かれた1行と、**「処理区域内人口約◯万人、日量約◯万立方メートルの処理場と管きょ延長約◯キロメートルの下水道事業において、処理場の運転管理と管きょの更新の計画を担当」**という1行では、**読む側が想定する事業の規模が違うから**です。**これらは公表されている数字**なので、**在職中に控えておけば足ります。**もう1つ。**上水道と下水道は、求人票では「上下水道」とまとめて書かれています。**つまり、**水道局の経歴の方が受けている会社に、そのまま出せる**ということです。受託の会社もコンサルティングも、上下の両方を手がけているところが大半です。**「下水道しか知らない」と狭く考える必要はありません。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## まとめ

- 下水道法第10条は、**供用が開始された区域の土地の所有者等は、遅滞なく排水設備を設置しなければならない**と定めています
- つまり、**下水道課は「区域の全員に来てもらう」条件で、設備と使用料を回す仕事**をしています。第20条は、使用料が**原価をこえないこと**を求めています
- 民間での訳語は、**インフラ事業の運営、水処理プラントの運転管理、管路の保全、加入の促進、請求と債権の管理、資産の管理**です
- 中核スキルは、**①集める ②処理する ③返す ④回す ⑤守る**の5工程に分けられます
- 民間との違いは、**相手を選べるか、入口を選べるか、料金の決め方、利益の扱い**の4点です
- 先に、**処理区域内の人口・処理場の能力・管きょの延長・水洗化率**の4つを控えてください

## よくある質問

### 事務職で、処理場や管きょの技術的なことは分かりません

**それでも書けます。**下水道課の事務は、**使用料の賦課と徴収、受益者負担金の賦課、水洗化の促進、指定工事店の指定、契約と入札、公営企業会計の決算、経営の戦略の策定**など、**技術以外の部分が広くあります。**とくに、**水洗化の促進**は、**行政の中で数少ない「加入を働きかける」仕事**で、**民間ではそのまま営業の企画や既存顧客の担当に接続します。**書くなら、**「使用料と受益者負担金の賦課、水洗化の促進、公営企業会計による決算を担当。技術上の判断は技術職が実施」**と、**自分の範囲を明示してください。**

### 小さな町で、浄化槽や農業集落排水も一緒に担当しています

**それは、幅として書けます。**公共下水道、農業集落排水、浄化槽は、**処理の方式と規模が違う3つの仕組み**です。**それを同じ担当で見てきた**ということは、**「規模と方式に応じて、処理の仕組みを使い分けてきた」**という経験になります。民間の水処理の会社は、**大きな処理場から小さな装置まで扱っています。**書くなら、**「公共下水道、農業集落排水、合併処理浄化槽の3方式について、維持管理と使用料を一体で担当」**という形です。**兼務を薄さとして書かず、方式の幅として書いてください。**

### 人口が減って処理場の統廃合が進んでいて、先が不安です

**その動きは、むしろ経験の価値を上げる方向に働いています。**処理場を統合する、広域で運営する、運転を包括して委託する。**いずれも、発注の側の事情と、現場の両方が分かる人が必要になる動き**です。受託の会社の側にも、計画を作るコンサルティングの側にも、**その両方を持っている人は多くありません。**不安の中身が「今の職場が続くか」であれば、**それは別の話として考える必要があります**が、**経験そのものが古くなるという心配は、この分野では当てはまりにくい**と考えています。行き先の分け方は[下水道課から転職しやすい業界と職種](dept-gesuido-tenshokusaki.html)に整理しています。
