**技術職の方から、「この資格はどの場面で効くのか」**というご相談を伺います。

**業務の範囲が、法律に定義されています。**

この記事では、**その中身**と、**経験との組み合わせ方**を扱います。

**⚠ 受験・登録の要件と手続は、所管するところの公表を確認してください。****この記事では、個別の要件には触れません。**

## 業務が、法律に定義されています

**技術士法第2条第1項**です。

> **この法律において「技術士」とは、第三十二条第一項の登録を受け、技術士の名称を用いて、科学技術**（人文科学のみに係るものを除く。以下同じ。）**に関する高等の専門的応用能力を必要とする事項についての計画、研究、設計、分析、試験、評価又はこれらに関する指導の業務**（他の法律においてその業務を行うことが制限されている業務を除く。）**を行う者をいう。**

**計画、研究、設計、分析、試験、評価、指導**が、業務として挙げられています。

**この並びは、建設コンサルタントの業務と重なります。**

**調査し、分析し、計画を作り、設計し、評価する。**

**つまり、資格の定義そのものが、業務の説明**になっています。

**このため、応募条件で扱われる場面があります。**

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 建設コンサルタント | **計画、調査、設計、評価** |
| ② 発注者支援 | 監督の補助、成果の確認 |
| ③ 維持管理・点検 | 診断、保全の計画 |
| ④ 調査・分析の事業 | 技術的な検討 |
| ⑤ 自治体が相手の事業 | 制度と手続の理解 |

**①と②が中心**です。

**②について。**

**発注する側で成果を確認してきた経験**は、支援の業務でそのまま使えます。

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 発注する側で身についていること

| 経験 | 民間での読まれ方 |
|---|---|
| ① 仕様の作成 | **求める成果の記述** |
| ② 成果の確認 | 照査、検査の観点 |
| ③ 計画の策定 | 中長期の計画、優先順位 |
| ④ 積算の確認 | 費用の妥当性 |
| ⑤ 関係機関との協議 | 調整、合意の形成 |
| ⑥ 現場の判断 | 状況に応じた対応 |

**②と③が、行政ならでは**です。

**③について。**

**限られた予算の中で、どの箇所を先に手当てするかを決めた経験**です。

**扱いは**[土木施工管理技士｜発注者側の経験と組み合わせる](skill-dobokusekou.html)**にも整理しています。**

## 書き方の例

**悪い例**

> 道路の設計の委託を発注していました。

**良い例**

> ◯◯の事業において、**発注者として、調査・設計の業務◯件（延長約◯メートル、委託費約◯千万円）を担当。****現地の状況と既存の資料を踏まえ、求める成果と検討の範囲を仕様に記載。**成果について、**関係する基準との整合を確認し、照査の結果を踏まえて協議。****◯か年の整備の計画を作成し、優先順位の根拠を整理。**関係機関◯者との協議を担当。

**「立場」「件数」「規模」「成果の確認」「計画」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

:::insight
技術士について、**面談でお伝えしているのが「優先順位を決めた経験を書いてください」**という点です。**建設コンサルタントの業務には、計画の策定**が含まれます。そして、**計画で最も難しいのは、どれを先にやるかを決めること**です。**予算には限りがあり、すべてを同時には手当てできません。**どの箇所が、どの程度傷んでいて、どこから着手すべきか。**行政の技術職は、この判断を毎年してきたはずです。**点検の結果、事業の計画、予算の見通し、地域の状況。**これらを踏まえて順番を決め、説明してきた。****この経験は、支援する側では直接の業務**になります。書類には、**「◯か年の整備の計画を作成し、優先順位の根拠を整理」**と書いてください。**「設計を発注していた」では、この判断が伝わりません。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 資格の位置づけ

| 状況 | 扱い |
|---|---|
| ① 応募条件に記載がある | **満たす材料になる** |
| ② 技術的な管理を担う | 配置の要件となることがあります |
| ③ 発注者支援・管理 | **経験と併せて評価されます** |
| ④ 入社後の取得 | 支援の制度がある会社も |
| ⑤ 目的が曖昧 | 優先順位を下げてください |

**③について。**

**資格だけでも、経験だけでもなく、両方が揃うと候補が広がります。**

**⚠ 受験・登録の要件、部門の区分は、所管の公表を確認**してください。

**なお、取れば転職できる、という関係にはありません。**

**何を検討し、どう判断したか**が、評価の対象です。

## 成果を確認する観点という材料

| 観点 | 内容 |
|---|---|
| ① 検討の範囲 | **仕様で求めた範囲と一致するか** |
| ② 基準との整合 | 適用した基準、根拠 |
| ③ 条件の設定 | 前提の置き方 |
| ④ 比較案 | 代替案の検討 |
| ⑤ 成果物の一式 | 図面、報告、数量 |

**③と④が、経験の差が出る部分**です。

**前提をどう置いたかで、結論が変わります。**

**この確認をしてきた経験は、支援する側で必要とされます。**

**④について。**

**代替案が示されているか、比較の観点が妥当かを見てきた経験**です。

**比較の表を確認し、採用した理由を決裁の文書に整理した**という形で書けます。

**判断の根拠を残す習慣は、そのまま持ち込めます。**

**支援の業務では、発注者に説明できる形で残すことが求められます。****この点も、行政での作法と同じです。**

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 実績の整理 | **件数、規模、分野** |
| 計画の整理 | 優先順位の根拠 |
| 要件の確認 | 所管の公表を確認 |
| 証明の書類の準備 | 所属での手続 |

**4行目を早めに**してください。

**在職中のほうが、手続が簡単**です。

**根拠のない数は書かないでください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 担当した分野 | **工種、規模、件数** |
| 成果の確認 | 何を見たか |
| 計画の考え方 | 優先順位の根拠 |
| 協議の経験 | 相手と、論点 |
| 立場 | **発注者か、受注者か** |

**3行目です。**

**なお、特定の事業や事業者が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

## よくある失敗

**1. 「発注していた」で止める**

**成果の確認と計画**を書いてください。

**2. 優先順位の根拠を書かない**

**計画で最も難しい部分**です。

**3. 成果の確認の観点を書かない**

**支援する側で必要**とされます。

**4. 規模を書かない**

**件数、延長、委託費**を書いてください。

**5. 立場を書かない**

**発注者か受注者か**を明記してください。

**6. 証明の書類の準備を後回しにする**

**在職中のほうが簡単**です。

**7. 要件を人づてで判断する**

**所管の公表**を確認してください。

**8. 取れば転職できると考える**

**何を検討しどう判断したか**が評価の対象です。

:::insight
ここまで資格の話をしておいて逆のことを言いますが、**取得を待ってから動く必要はありません。**面談で拝見していると、**「資格を取ってから応募しよう」と考えて、数年動かない方**がいらっしゃいます。ところが、**発注者支援や維持管理の求人では、実務の経験が要件になっている**ことがあります。**資格が必須でない求人**もあります。そして、**入社後の取得を支援する制度**を持つ会社もあります。この場合、**働きながら進めるほうが、要件の面でも進めやすい**ことがあります。ですから、**まず求人票を5件読んで、資格が必須かどうかを確認してください。**必須でなければ、**いま応募できます。**必須の求人だけを目指して待つと、**その間の経験が書類に反映されません。**扱いは[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **技術士法第2条第1項**は、**計画、研究、設計、分析、試験、評価又はこれらに関する指導の業務**を行う者と定義しています
- **この並びが、建設コンサルタントの業務と重なります**
- 効くのは、**建設コンサルタント、発注者支援、維持管理・点検、調査・分析の事業、自治体が相手の事業**です
- **優先順位を決めた経験**を書いてください。計画で最も難しい部分です
- **成果を確認する観点（範囲・基準・条件の設定・比較案）**も材料になります
- **証明の書類の準備は、在職中に**済ませてください
- **取得を待ってから動く必要はありません。**必須でない求人があります

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 設計を自分でしたことがありません

**発注者としての経験で書いてください。**仕様の作成、成果の確認、協議、計画の策定。**これらは、設計を自分で行わなくても担っています。**書き方は、**「発注者として、調査・設計の業務◯件の仕様の作成から成果の確認までを担当」**という形です。なお、**発注者支援の業務では、この経験が直接の業務**になります。設計そのものを求める求人とは、条件が異なります。**求人票の仕事内容の欄で、どちらを求めているかを確認**してください。扱いは[技術職の転職｜事務職と何が違うか](senko-tachiba-gijutsu.html)に整理しています。

### 受験の要件に、行政の実務は算入されますか

**所管するところの公表を確認してください。**要件は、**実務の経験の年数と内容**で定められていることがあります。どの職務が該当するかは、**公表されている案内で確認**するのが確実です。**人づての情報や、以前の記憶で判断しないでください。**なお、**証明の書類が必要になる場合、所属での手続が要る**ことがあります。**在職中に確認し、必要なら書類を整えておいてください。**退職した後では、依頼に手間がかかります。**部門の区分**についても、同じく公表を確認してください。

### 維持管理の担当でしたが、書けますか

**書けます。**点検の業務の発注、診断の結果の確認、補修の優先順位の判断、保全の計画の作成。**これらは、技術的な検討そのもの**です。書き方は、**「点検の業務◯件を発注者として担当。診断の結果を踏まえ、◯か年の補修の計画を作成し、優先順位の根拠を整理」**という形です。**維持管理の分野は、需要が続いている領域**でもあります。扱いは[電気主任技術者｜公営企業・インフラ運営での評価](skill-denkishunin.html)にも整理しています。**新設の事業に限らず、維持管理の経験も材料です。**
