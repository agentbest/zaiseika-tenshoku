塾・予備校への志望動機は、教育への関心だけでなく、今回どの仕事を希望するのかを示すところから組み立てられます。授業を担う講師と、校舎運営や学校向けの営業、本部の企画は同じではありません。公務で担当した仕事を具体的に整理し、未経験の分野と応募条件も並べて考えます。

本記事は2026年11月時点の公開情報にもとづきます。確認日は2026年11月25日です。採用側の非公開の質問や評価、面接官の心理は確認できません。以下の型や架空例は本人の考えと事実を整理するためのもので、特定の表現によって採用されると保証するものではありません。

## 法人と希望する職務を最初に定める

河合塾グループの公式採用情報は、学校法人河合塾、株式会社河合塾マナビス、株式会社河合塾進学研究社等の採用を分けて案内しています。同じグループ名であっても、雇用する法人と今回の募集を確認します。別の法人の事業や制度を、希望先の条件として述べないようにします。

学校法人河合塾のキャリア採用は、講師職以外の総合職です。校舎運営、学校営業、教育コンテンツ開発、教育研究、事業企画が示されています。「教育に関わりたい」という理由から、どの仕事に関心があるのかをもう一段具体的にできます。

校舎専門職員は、生徒や保護者への対応、入塾相談、イベントやアルバイト管理などの運営を担います。入塾促進、生徒募集のための企画や案内等も含まれています。相談だけをする仕事と想像せず、今回の担当範囲を読んだ上で志望する理由を考えます。

講師を希望する場合は、対象の教科や指導の役割、応募条件を講師の個別募集で確かめます。総合職や校舎専門職員の募集で教員資格の有無を問わないとされていても、それを全ての講師の条件へ広げることはできません。担当する仕事が異なるためです。

| 志望先について書く項目 | 調べる内容 | 本人の経験と分けるもの |
| --- | --- | --- |
| 法人 | 今回本人を雇用する正式な主体 | グループの別法人の条件 |
| 職種 | 講師、校舎運営、営業、企画等 | 教育という業界全体への関心 |
| 業務 | 生徒対応、募集、制作等の担当 | 過去に実施していない仕事 |
| 勤務 | 配属、異動、時間帯、契約の区分 | 本人が希望するだけの条件 |

職務の違いを見比べたい方は、[掲載中の求人から仕事内容を確認できます](../?gov=1)。業界名と一緒に、応募先で本人が担当する工程を読むために使えます。

## 関心を持った理由と実施した仕事を別々に書く

教育への関心を持ったきっかけは、本人の事実に沿って書けます。公務で説明会や地域の講座に関わった経験も、その範囲で述べられます。ただし、受験指導をしたことがないのに、生徒の合格を支えたという実績を作る必要はありません。

関心の理由は「これから取り組みたいこと」、職務経歴は「これまで実施したこと」と分けて考えます。たとえば説明や問い合わせの整理を経験し、今後は校舎で学習の選択に関わる運営を調べている、と整理できます。過去の仕事と将来の希望を一つの実績にしないようにします。

公務の仕事を否定して転職の理由を作る必要もありません。制度の対象や手順を確認して伝えた経験は、そのまま本人の仕事です。現職で担える範囲を理解した上で、別の事業で担当したい役割があるのかを考えます。残る判断にも同じように理由があります。

学校営業に関心があるなら、公式に示された商品の販売やニーズの把握、関連部門への提案等を読めます。学校へ行政の案内を送った経験は、そのまま販売や受注の実績にはなりません。相手の要望を整理した工程と、これから担当したい営業の仕事を分けて述べます。

:::insight
志望動機に「説明の経験を生かしたい」と書くなら、何を説明したかを先に確定できます。制度の対象を調べて案内した経験と、進路や学習方法を案内した経験は同じではありません。本人が実施した確認、説明、引継ぎを書き、応募先で新たに学ぶ入試や商品等の知識を別に置きます。その上で、校舎運営や学校営業のどの工程に関心があるかを述べると、経験と希望の境目が残ります。教育に関わる部署名だけで職務を広げたり、採用されるために指導や販売の実績を足したりする必要はありません。本人の事実から希望へ順に説明することが、仕事内容を照合する土台になります。
:::

## 志望動機を職務、経験、未経験、条件で組み立てる

最初に今回希望する職務を置きます。校舎運営なら、進路の支援、入塾相談、授業の運営、募集イベント等のうち、公開情報のどこに関心があるかを具体的にします。全てを経験済みとする必要はなく、希望する担当を明確にするための作業です。

次に接点のある経験を一つ選びます。地域の講座で案内文と受付の手順を作ったなら、その対象、本人の作業、他者の判断を説明できます。講座全体の目的と本人が作ったものを分けると、何を担当していたかが分かります。

その後に未経験を置きます。大学入試の進路指導、教科指導、入塾促進、商品販売等を担っていなければ、そのまま未経験として残せます。求人で必須とされる経験については、学ぶ意欲だけで充足したとは判断しません。必須条件の照合と今後学びたい内容は別です。

最後に勤務や契約についての理解を確認します。全国転勤が条件の職種と地域を限定した職種では、選ぶ理由が変わり得ます。志望する気持ちから、対応できない場所や時間帯まで可能と答える必要はありません。本人の希望と実際の条件を照合します。

## 独立して作成した架空の組み立て例

以下は書き方を示すための架空例です。実在の応募者や企業の回答、面談の記録ではありません。特定の求人の必須条件を満たす例でもありません。使う際は本人の事実へ置き換え、未実施の内容を削除してください。文章をそのまま本人の経験として使うことはできません。

| 要素 | 架空の記入例 |
| --- | --- |
| 希望する仕事 | 大学受験の校舎運営に関心があり、講師とは分けて検討している |
| 公開情報から読んだ点 | 校舎運営には相談だけでなく、授業の運営や募集イベントも含まれる |
| 本人が担当したこと | 地域講座の参加案内を作り、申込受付の確認項目を整理した |
| 具体的な工程 | 会場担当に場所を確認し、申込者向けの案内文へ反映した |
| 他者が担当したこと | 講座内容と予算は上司が決め、講義は外部講師が行った |
| 未経験 | 大学入試の指導、教科の授業、入塾促進や売上管理は経験していない |
| 条件の確認状況 | 勤務時間と異動、契約の区分を比較中。個別の配属回答は受けていない |

この表からは、たとえば次のような文章を作れます。「地域講座では、参加案内と申込受付の手順を担当しました。場所等の情報を確認し、参加者へ伝える工程を経験しています。今後は校舎運営の仕事を検討しており、相談だけでなく授業の運営や募集も含む職務として調べています。進路指導や入塾促進は未経験なので、応募条件を照合した上で、必要な知識や担当範囲を確認したいと考えています。」

これは完成した合格例ではありません。本人に別の経験があれば、取り上げる仕事も変わります。また、この段階では特定の法人を選んだ理由が十分でなければ、公式の事業や募集の記載から、どこに関心があるのかを本人が追加して考えます。

経験と希望のつなぎ方を整理したい方は、[志望する仕事と職歴の伝え方を相談できます](../apply.html)。ご利用は無料です（紹介手数料は採用企業の負担）。経験や希望等により、求人の紹介や面談等をご提供できない場合があります。

## 応募資格と雇用の違いを理由に含めて確認する

学校法人河合塾の総合職のキャリア採用は、四年制大学卒業以上で社会人経験があることと、全国転勤が可能であることを示しています。希望や適性に合った職種から始めるという案内で、本人が望む一つの部門へ必ず配属されるとは読めません。配属の希望と正式な決定を分けます。

校舎専門職員も、四年制大学卒業以上と社会人経験を応募資格に挙げています。地域や校舎を限定した募集ですが、所属エリア内の通勤圏で校舎が変わる範囲があります。地域に関わる希望を述べる場合も、一つの校舎で将来ずっと働けると前提にしないようにします。

同職員は、契約の終期、更新の条件、通算の上限がある有期の募集です。総合職への登用試験の制度も示されています。ただし、制度があることと、応募した本人が更新や登用の対象になることは別です。登用だけを前提に、今回の有期の条件を読まずに志望しないようにします。

勤務時間についても、校舎で働く場合のシフトを確認します。生徒が利用する時間帯に関心があっても、自分が実際に対応できるかは生活の予定と照合する必要があります。仕事内容への関心、勤務の希望、今回の提示条件を分けることで、志望動機と条件面の回答をそろえられます。

募集の受付や地域は変わる可能性があります。この記事の確認日の情報から常に応募可能とは判断せず、閲覧時に最新の公式案内を確認します。終了した募集を参照する場合は、過去の職務や条件の参考として扱い、今の募集と混ぜません。

:::insight
「地域で教育に関わりたい」という理由でも、職種の選択と勤務の条件は別に確認できます。地域を限定した校舎専門職員を調べるなら、有期の契約や更新の条件まで読みます。総合職を調べるなら、全国転勤や職種が変わる可能性も比較します。登用の制度や研修があるという記載だけで、本人の将来の配属や契約を決めつける必要はありません。志望動機は、生活上対応できない条件を可能と言うための文章ではなく、希望する役割と本人の経験を伝えるものです。条件がまだ合わなければ、現職で説明や運営の経験を続けながら調べる選択も、応募と同じ重さで残せます。
:::

## 応募先ごとに根拠を確認して書き直す

志望動機を別の法人へ使う際は、社名だけを差し替えず、仕事内容から見直します。学校向けの営業を希望した文章と、校舎運営を希望した文章では、関心を置く工程が変わります。本人の職歴は同じでも、どの経験と今回の職務を並べるかは応募先ごとに整理できます。

求人の言葉を使うときは、経験した事実と一致するかを確認します。公務で「調整」と呼んでいた仕事でも、営業交渉、教材編集、進路指導の全てを含むとは限りません。相手、目的、本人の作業、決定した人を短く説明し、未経験の専門実務は加えないようにします。

成果の数字を測っていないなら、募集が増えた、相談が改善したといった結果を作りません。本人が確認した案内や手順の作成、連絡の記録等の事実で記述できます。相手の気持ちや、参加者の将来に与えた影響についても、確認していないことは書きません。

生徒や保護者の氏名、成績、相談の詳細、学校や自治体の内部資料を応募のために持ち出さないことも大切です。私用の端末や外部の生成AIに内部資料を渡して文章を作る必要はありません。必要な説明用の表は、架空の内容で独立して作成し、実際の資料と区別します。

書き直した後は、過去の担当、今後の希望、条件の確認状況が混ざっていないかを読みます。本人が未確認の配属を確定と書いたり、企業から受けていない回答を加えたりしないようにします。志望先の公式情報と本人の事実を、最後まで別々に確認できます。

考えを短く整理したい方は、[LINEで志望する役割や確認事項をまとめることもできます](https://line.me/R/ti/p/@697nxhbt)。応募を決める前の情報収集としても使えます。

## よくある質問

### 教育に関心があるという理由だけでは足りませんか

関心は本人の理由として書けます。その上で、講師、校舎運営、営業、企画等のどの仕事を希望するのかを具体的にできます。公式に示された職務と、本人が担当した工程を並べると、経験と今後の希望を分けて説明できます。特定の表現が採用につながるという保証ではありません。

### 教育部署の経験がなくても志望動機は書けますか

部署名だけで志望動機が決まるわけではありません。本人が実施した説明、案内の作成、受付や関係者との連絡等を具体的に整理できます。ただし、その経験だけで応募条件を満たすとは限りません。学歴、社会人経験、転勤等の条件は今回の募集と照合し、指導や募集の未経験も区別します。

### 現職に残るか迷っている段階でも整理できますか

整理できます。応募を先に決めず、どの仕事に関心があるか、どの経験が接するか、勤務や契約が合うかを比較できます。現職を続ける判断も同等です。この記事は退職を勧めるものではありません。応募を進める場合も、公開情報と正式な案内を確認し、本人が対応できる範囲で準備します。
