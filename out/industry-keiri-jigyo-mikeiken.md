未経験から事業会社の経理・財務を考えるときは、企業で働いたことがないのか、決算や税務、資金管理の実務を経験していないのかを分けます。公務で予算や支出の照合を担当した経験は説明できますが、民間企業の会計実務をすべて経験したことにはなりません。資格や学習歴と実務も分け、求人の条件と本人工程を照合しましょう。

本記事は2026年11月時点の公開情報にもとづきます。確認日は2026年11月25日です。SREホールディングスとフジテレビジョンの公式自社採用を例にします。未経験者全員が応募できる、資格があれば採用されるという説明ではありません。最新の募集と本人の経験への適用は、当該求人の採用窓口へ確認してください。

## どの仕事が未経験かを分ける

経理・財務という名称でも、仕訳、支払いや入金、月次・年次決算、税務、連結、開示、資金の運用・調達、管理会計など異なる工程があります。会社がすべてを扱っていても、採用される人が初めから全部を担当するとは限りません。担当者、リーダー候補、専門職などの役割も分けて調べます。

SREの主計リーダー候補は、決算、会計処理の立案、経費や出納の承認、予実管理、子会社管理、監査法人対応等を挙げています。経験と志向に応じて連結、開示、税務なども担当する案内です。職種名に経理とあるから、初めて会計を学ぶ人向けの補助事務とは読みません。

フジテレビジョンの経理・財務は、決算や開示、支払いや債権回収、資金計画・運用・調達などを示しています。持株会社の業務を担当する場合や将来の配置転換にも触れています。雇用主と担当会社の範囲、現在の応募職務と将来の可能性を区分します。

公務の会計は、予算や支出を扱う制度の中で行う仕事です。本人が何を計算し、何を確認し、誰が判断したかを示し、民間の決算や税務との違いを残します。部署の名称が近いことや、数字を扱ったことだけで同じ実務と考えないことが基本です。

## 実務条件と資格の条件を一つずつ読む

SREの当該求人は、事業会社または税理士法人等での経理実務4年以上と、上場企業水準の決算・開示またはそれに準ずる専門性の高いコーポレート業務の経験を必須にしています。前者には月次・年次決算、税務申告等の説明があります。両方の欄を照合し、どちらか一つだけあればよいとは読みません。

同求人の簿記2級以上や税理士科目合格等は歓迎です。簿記を学んでいること、合格したことから、必須の経理実務を経験済みとすることはできません。また、連結、税務、会計システムの導入等の歓迎経験も、本人が担当した範囲に限って説明します。

フジの当該求人は、三つの経路のうち一つ以上に当てはまることを必須としています。監査法人・税理士法人等での実務、事業会社の経理財務または金融機関での実務、事業会社の管理部門で丁寧な作業を集中して行うような実務と簿記2級程度以上の知識です。第三の経路は実務と知識の両方を確認し、知識だけでよいとは読みません。

| 求人の条件 | 本人側で照合すること | 避けたい読み替え |
| --- | --- | --- |
| 対象となる実務 | 対象制度、業務、本人工程、時期 | 公務の支出照合を民間決算とする |
| 実務年数 | 対象業務を実際に担った期間 | 在職期間のすべてを足す |
| 資格・知識 | 保有、合格、学習中の区分 | 学習を実務の代わりにする |
| 複数条件 | 必須の組合せと選択経路 | ANDをORに弱める |

公務の実務が応募条件に該当するかは、本人の担当を示して確認します。明示されていない対象を自分で加えず、要確認として残してください。[公務員経験を整理しながら求人を比較する](../?gov=1)際も、必須を満たすかと、仕事への関心は別に整理できます。

## 本人の確認、システム処理、他者の判断を分ける

公務で支出関係の書類を扱った場合、項目や添付の確認、入力、照会、承認依頼、記録などを説明できます。システムが自動で行った計算と、本人が確認した部分を区分してください。決裁者の判断や、会計担当が行った処理を本人の実務に加えません。

財政や予算の仕事なら、要求の集計、ヒアリング、資料作成、差異の確認など、本人工程を示します。部局全体の予算決定を本人一人の実績とせず、提案、調整、最終判断を分けます。予実の確認という言葉が近くても、企業の管理会計と同じ対象や責任だと決めないようにします。

専門職歴や過去の民間経験がある人は、それを省略する必要はありません。本人が実際に担当した決算や仕訳等の工程、期間、使用したシステム、確認者を具体化します。公務員という現在の勤務先だけで、以前の実務を小さく扱わないことも大切です。

一方、資格試験や独学で問題を解いた経験は学習として記載します。架空データで作った仕訳や表も、実務の成果物とは分けてください。実際の取引や締切、確認と承認の体制を経験していないなら、その範囲は未経験として残します。

:::insight
経理への接点を探すときは、数字を扱った経験を大きくまとめるより、本人工程を確かめることを勧めます。予算要求の集計、支出書類の確認、会計上の判断はそれぞれ別です。民間の決算や税務と同じ実務に置き換えなくても、本人がした照合や照会は具体的に説明できます。そのうえで求人の実務と資格の条件を一つずつ読み、該当が不明なら窓口へ尋ねてください。簿記を学ぶことは知識を整理する機会ですが、実務年数を満たすことにはなりません。現在の経験と今後の学習を分けると、応募できる職務を確認しやすくなります。条件が合わない場合も、現職を続けながら別の募集を調べる選択を残せます。
:::

## 独立した架空例：応募条件との対応表

以下は説明用に作成した架空例です。実在する相談、職員の経歴、採用結果ではありません。本人の応募準備に使う場合は事実に置き換え、実施していない工程や保有していない資格を削除してください。

| 項目 | 架空の記入例 |
| --- | --- |
| 本人の担当 | 自治体の庶務として支出関係書類を確認 |
| 実施したこと | 記載項目と添付を照合し、不足を担当者へ確認 |
| 他者の仕事 | 会計上の判断は会計担当、承認は決裁者 |
| 学習 | 簿記を学習中。架空の仕訳例で練習 |
| 未経験 | 企業の月次・年次決算、税務申告、連結、開示 |
| 条件の照合 | 今回の専門職求人の実務条件を満たすとは判断できない |
| 次の確認 | 本人の経験が対象となるか窓口へ確認し、合う職務を再調査 |

この例なら「支出関係の書類の項目と添付を照合し、不足事項を確認しました」と説明できます。「民間企業の経理を一通り担当しました」と書くと事実が変わります。また、簿記の学習を実務経験や資格保有に置き換えません。

応募対象ではないと分かっても、本人の能力全体を否定する必要はありません。当該募集の条件と現在の経験の関係として整理し、別の役割や学習の必要を調べ直せます。未経験の補助事務などを探す場合も、その募集が実際に存在するか、どの条件かを個別に確認してください。専門職の募集から未掲載の入口を推測しません。

表に実績を足す場合も、本人が実際に記録し、外部へ説明できる範囲に限ります。未計測の効率化率、存在しない処理件数、他者が行った改善を作りません。数値がなくても、確認の順序と誰へ引き継いだかは具体的に示せます。

[担当工程と希望する仕事を相談用にまとめる](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担）。経験や希望条件によって、面談や求人紹介を案内できない場合があります。

## 学習の目的と、応募の確認を分ける

簿記や会計を学ぶ場合は、求人の用語を理解する目的、現在不足している知識、操作を習得する目的を分けます。学習の進み具合を、すぐに採用される見込みへ置き換えないことが大切です。資格の取得と応募の可否、担当できる仕事は、それぞれ確認する事項です。

学習用の表や資料を作るなら、独立した架空データを使います。現職の帳票、職員情報、取引先情報、未公開の予算・契約資料を持ち出さないでください。匿名化だけで外部利用が認められるとは限りません。個人端末や外部の生成AIに内部情報を入力することも避けます。

求人にシステムの導入や改善があっても、ソフトを使っただけで導入を主導した経験にしません。本人が要求を整理したのか、設定したのか、確認したのか、委託先が構築したのかを区分します。学習作例や他者の成果を実務実績として提出しないようにしましょう。

## 応募、選考、入職の段階を分ける

フジの当該募集は、情報登録後に適宜ポジションがある場合に連絡する仕組みで、登録は1年間有効、すべての人に選考機会を約束するものではないと明記しています。登録できることと、応募条件を満たすこと、選考へ進むこと、入職が決まることは別です。退職や入職の日程を先に固定しないでください。

SREの当該求人は正社員、試用期間6か月、条件変更なしとしています。業務と勤務地の変更範囲も掲載されています。本人の担当や配属がずっと固定されると考えず、契約、入職直後の担当、確認者、決算期の分担、勤務を照合しましょう。

勤務制度や給与も、仕事内容と別に確認します。フレックスがあるからすべての時間を自由に選べる、表示された給与範囲が本人の額になるといった判断はしません。給与の内訳、時間外、休日、勤務地の変更を聞き、生活上引き受けられる条件かを検討します。

公務で経験した行政上の手続きや連絡先を、応募先へ便宜を提供できる材料として使わないことも基本です。説明するのは適切に外部へ伝えられる担当工程です。仕事に関心があっても条件が合わない場合は、現職を続けることや別の職務を比較することを選べます。

:::insight
学習を進めることと、いまの専門職募集へ応募できることを分けて考えるよう勧めます。実務の年数や対象が指定されている求人では、関心や資格の知識だけで条件を満たしたことにはできません。一方、公務で本人が行った確認や資料整理の経験は、事実として説明できます。条件に合わない場合は、その経験を無理に決算へ言い換えるより、対象となる職務を調べ直してください。研修や将来の配置の案内も、本人の役割や習得を保証するものではありません。現職を続けながら学習し、応募条件と勤務を確認することもできます。進路を急いで固定せず、現在の経験、未経験の工程、希望する仕事を別々に残す進め方を勧めます。
:::

## 確認の返答を受けて候補を見直す

採用窓口へは、部署名だけではなく、本人が実施した作業と対象の制度、担当時期を短く伝えます。確認したい条件を特定し、「この書類照合の担当が、募集に記載された実務の対象に含まれるか」のように尋ねることができます。実際の書類や秘密を送らず、外部へ説明できる工程に限ってください。

返答があっても、対象となる職種や募集時点が異なる場合はそのまま別の応募へ流用しません。同じ会社でも、専門職と補助の仕事、担当者とリーダーでは条件が異なります。質問した求人、確認日、返答と残った疑問を分けて記録しましょう。

応募条件に該当しない場合は、学習中の内容を実務へ言い換えるのではなく、別の募集を調べるか、現職を続けながら必要な準備を検討します。該当が確認できた場合も、未経験の工程がなくなったわけではありません。入職後の担当と習得する範囲を改めて聞き、引き受けたい仕事かを判断する段階へ進みます。

## まとめ：実務と知識を別々に照合する

未経験から経理・財務部門を目指すときは、主計、税務、資金、管理会計等の仕事を分け、必須条件を確認します。公務の予算や支出の経験を民間決算へ自動換算せず、資格や学習も実務の代わりにしないことが基本です。本人の担当を示して窓口へ確認し、勤務と契約も照合しましょう。

[LINEで相談の進め方を確認する](https://line.me/R/ti/p/@697nxhbt)際は、担当工程、未経験の実務、学習歴、希望を分けて伝えてください。現職を続けながら比較する選択も残せます。

## よくある質問

### 簿記を学べば、実務経験が必要な求人にも応募できますか？

知識と実務は別です。今回の専門職募集にも実務の条件があります。資格が必須か歓迎か、複数の条件をどう組み合わせるかを確認してください。

### 公務の支出事務は、企業の経理経験になりますか？

対象制度と本人の作業が異なるため、そのまま同じ実務とはしません。確認、入力、照会、判断の分担を示し、応募先の条件への該当を確かめます。

### 登録できたら、選考や入社が決まりますか？

別の段階です。今回のフジの案内はポジションがある場合の連絡とし、選考機会を保証していません。本人への案内を確認し、退職日等を先に決めないようにします。
