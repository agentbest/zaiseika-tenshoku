**公立の保育所で働いてきた方からのご相談**です。

**保育士は、他の職種と決定的に違う点**があります。

この記事では、**その違い**と、**経験の示し方**を扱います。

## 資格が、法律で定義されています

**児童福祉法第18条の4**です。

> **この法律で、保育士とは、**第十八条の十八第三項に規定する**保育士登録**（略）**を受け、保育士の名称を用いて、専門的知識及び技術をもつて、児童の保育及び児童の保護者に対する保育に関する指導を行うことを業とする者をいう。**

**2つの点に注目してください。**

**1つ目。登録に基づく資格**であるという点です。

**公立か私立かを問わず、同じ資格**です。

**つまり、資格がそのまま持ち運べます。**

**多くの公務員の職種では、経験を民間の言葉に言い換える作業が必要**になります。

**保育士は、その作業が小さい**という特徴があります。

**2つ目。定義に「児童の保育」と「児童の保護者に対する保育に関する指導」の2つが入っている**という点です。

**保護者への支援も、職務の内容として定義されています。**

**この点は、書類に書いてよい**ということです。

## 経験を分ける

| 要素 | 実際にやっていること |
|---|---|
| ① 保育の実施 | 日々の保育、個別の対応 |
| ② 指導の計画 | 年間・月間の計画、記録 |
| ③ 保護者への支援 | **面談、相談、連絡** |
| ④ 園の運営 | 行事、分掌、シフト |
| ⑤ 後輩の育成 | 指導、手順の共有 |
| ⑥ 関係機関との連携 | 保健、福祉、学校、医療 |
| ⑦ 制度の事務 | **入所の事務、給付、監査への対応** |

**③と⑦が、公立ならではの材料**です。

**⑦について。**

**公立では、制度の運用に関わる場面**があります。

**入所の調整、保育料の仕組み、監査への対応、計画の策定。**

**これらは、保育の運営を行う会社で必要とされます。**

## 書き方の例

**悪い例**

> ◯◯保育所で、保育士として勤務しました。

**良い例**

> ◯◯において、**◯歳児クラス（児童◯名、職員◯名）の担任**を担当。年間・月間の指導の計画を作成し、**個別の記録を作成。****保護者◯世帯との面談を年◯回実施し、相談への対応を担当。**行事の企画・運営を担い、**新規に採用された職員◯名への指導**を実施。**監査への対応として、書類の整備を担当。**

**「人数」「計画」「保護者」「指導」「制度の事務」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 言い換えの対応

| 保育の言葉 | 民間での読まれ方 |
|---|---|
| 指導の計画の作成 | **計画の立案、進行の管理** |
| 記録の作成 | 記録の管理、経過の記録 |
| 保護者への対応 | **顧客対応、相談の対応** |
| 行事の企画・運営 | 企画、運営、進行 |
| 後輩の指導 | 育成、手順の整備 |
| 関係機関との連携 | 部門間・社外との調整 |
| 監査への対応 | 内部統制、書類の整備 |
| シフトの調整 | 人員の配置、勤務の管理 |

**3行目です。**

**保護者への対応は、「相手を選べない状況での対応」**にあたります。

**苦情や相談を含む対応の経験**は、顧客の対応を担う部署で評価されます。

## 見る領域

| 領域 | 内容 |
|---|---|
| ① 私立の保育所・認定こども園 | **資格がそのまま使えます** |
| ② 保育の運営の会社 | 指定管理、受託、複数園の運営 |
| ③ 企業内の保育 | 事業所内の施設 |
| ④ 学童・児童発達支援 | 近接する分野 |
| ⑤ 保育に関するサービス | 教材、システム、人材 |
| ⑥ 自治体が相手の事業 | **制度の実務が分かる** |

**②と⑥が、公立の経験と重なります。**

**②について。**

**指定管理や受託で保育所を運営する会社**があります。

**公立の運営を知っている人**は、そこで必要とされます。

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 何を担当したか | **年齢、人数、期間** |
| 保護者への対応 | 難しい場面での進め方 |
| 記録・計画の作成 | 作成したものの種類 |
| 制度の事務の経験 | **入所、給付、監査** |
| 勤務の条件 | 時間、シフト、行事 |

**4行目です。**

**制度の事務に関わった経験は、聞かれたときに答えられるよう整理**しておいてください。

**保育の実務だけでなく、運営の側面も担えると伝わります。**

**なお、特定の児童や保護者が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

:::insight
公立の保育士の方のご相談で、**面談でお伝えしているのが「保育以外の部分を書いてください」**という点です。保育の実務は、**資格を持つ方であれば共通の前提**として読まれます。差がつくのは、**それ以外の部分**です。公立では、**制度の運用に近い場面**を経験します。入所の調整の仕組みを知っている、保育料の考え方が分かる、監査で何を見られるかを知っている、計画の策定に関わったことがある。**これらは、私立で保育だけを担当してきた方にはない経験**です。そして、**保育所を運営する会社**——とくに指定管理や受託を行う会社——では、**この理解が業務の前提**になります。行政に報告し、監査を受け、制度に沿って運営する。**ここでつまずく会社が少なくありません。**書類には、**「監査への対応として書類の整備を担当」「入所に関する事務を担当」**と書いてください。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 準備の順序

| 順 | やること |
|---|---|
| 1 | 担当したクラス・年齢・人数を書き出す |
| 2 | 作成した計画・記録の種類を書き出す |
| 3 | **保護者への対応と、制度の事務を書き出す** |
| 4 | 後輩の指導、行事の運営を書き出す |
| 5 | 民間の言葉に置き換える |
| 6 | 求人を読む |

**3が要**です。

**この2つが、公立ならではの材料**です。

[経験の言い換えから相談する](../apply.html)こともできます。

## 在職中の進め方

| 項目 | 内容 |
|---|---|
| 記録 | 担当した人数、作成した資料 |
| 制度の確認 | 退職の手続き、時期 |
| 求人を読む | 週に30分 |
| 日程の確保 | **年度の変わり目と行事の時期を避ける** |

**4行目です。**

**保育の現場は、年度の変わり目と行事の時期に時間が取れません。**

**選考の開始を、この時期と重ならないように選んでください。**

**扱いは**[選考スケジュールの組み方](senko-sagasu-schedule.html)**に整理しています。**

## よくある失敗

**1. 保育の実務だけを書く**

**それ以外の部分**で差がつきます。

**2. 人数を書かない**

**規模が伝わりません。**

**3. 保護者への対応を書かない**

**顧客対応**として読まれます。

**4. 制度の事務を書かない**

**公立ならではの材料**です。

**5. 後輩の指導を書かない**

**育成**として書けます。

**6. 運営の会社を見ない**

**公立の運営を知っている人**が必要とされます。

**7. 年度の変わり目に選考を始める**

**時間が取れません。**

**8. 特定の児童が分かる説明をする**

**守秘の義務は退職後も続きます。**

:::insight
ここまで書き方の話をしておいて逆のことを言いますが、**保育士の資格を持つ方は、保育の現場以外にも選択肢があります。**面談で拝見していると、**「保育士だから保育所しかない」と考えている方**がいらっしゃいます。ところが、**保育に関わる事業は、現場だけではありません。**保育に関するシステムを作る会社では、**現場でどう使われるかを知っている人**が必要です。教材や備品を扱う会社では、**何が使いやすいかを判断できる人**が求められます。人材の紹介や研修を行う会社では、**現場の実情を説明できる人**が要ります。そして、**自治体が相手の事業では、公立の運営を知っていること自体が要件**になります。**資格と現場の経験は、現場の外でも使えます。**選ぶ軸は、**「保育に関わり続けたいか」「働き方を変えたいか」**の2つです。**この2つを分けて考えてください。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **児童福祉法第18条の4**は、**保育士を、登録を受け、専門的知識及び技術をもつて、児童の保育及び児童の保護者に対する保育に関する指導を行うことを業とする者**と定義しています
- **登録に基づく資格**であるため、**公立・私立を問わず持ち運べます**
- 定義に**保護者に対する指導**が含まれています。**保護者への支援も職務**です
- 差がつくのは、**保育以外の部分**です。**制度の事務、監査への対応、計画の策定**を書いてください
- **保育所を運営する会社**では、公立の運営を知っている人が必要とされます
- **保育の現場以外にも選択肢**があります
- **年度の変わり目と行事の時期**を避けて選考を始めてください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 私立の保育所に移ると、進め方が違いますか

**運営の主体が変わるため、違いはあります。**行事の規模、保育の方針、職員の体制、保護者との関わり方。**園によって異なります。**確認の仕方は、**見学と面接**です。「一日の流れを教えてください」「職員の体制を伺えますか」と聞けば、具体が分かります。なお、**公立での経験が評価される場面**もあります。制度に沿った運営、記録の作法、監査への対応。**これらは、園の運営で必要とされます。**判断の目安は、**保育の方針が自分の考えと合うか**です。**求人票だけでは分からないため、見学を申し込んで**ください。

### ブランクがありますが、戻れますか

**資格は登録に基づくものです。**期間が空いても、**登録が有効であれば資格は続きます。**ただし、**制度や運用は変わっている**ことがあります。復帰の前に、**最近の動向を確認**しておくと安心です。なお、**復帰を支援する仕組みが置かれている団体**もあります。**居住する市区町村の担当に確認**してください。**求人の側でも、ブランクのある方を前提とした募集**があります。求人票に「ブランク可」「復帰の支援あり」と記載があるものを見てください。**短時間の勤務から始める**という選択もあります。

### 保育以外の職種に移ることはできますか

**できます。**保育で身につけた**計画の立案、記録の作成、保護者への対応、後輩の指導、行事の運営**は、**業種を問わず使えます。**とくに、**顧客の対応を担う職種**では、**相手を選べない状況での対応の経験**が評価されます。また、**公立での制度の事務の経験**は、**自治体が相手の事業**で直接使えます。なお、**職種を変える場合、説明の組み立てが必要**になります。なぜ変えるのか、何を持ち込めるのか。扱いは[職種を変える転職と、変えない転職](senko-tachiba-shokushutenkan.html)に整理しています。**求人票の応募条件を読んで、該当するかを確認**してください。
