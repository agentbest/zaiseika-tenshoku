まちづくり・都市開発の選考について、**公務員の方が最初につまずく点**があります。

**「求人票に資格が並んでいて、応募できる気がしません」**

**この業界の求人票には、たしかに資格の名前が並びます。**

**ただし、すべての職種で必須とは限りません。**そして、**資格が何を意味しているかを知ると、読み方が変わります。**

この記事では、**選考の流れ**と、**資格の扱い**、**面接で見られている観点**を扱います。業界の構造は[未経験からまちづくり・都市開発に入るには](industry-machizukuri-mikeiken.html)、志望動機の組み立ては[まちづくり・都市開発の志望動機](industry-machizukuri-shiboudoki.html)にあります。

## 技術士とは、何を指す資格か

**求人票でいちばんよく見る資格**から説明します。

**技術士法第2条第1項**です。

> **この法律において「技術士」とは、第三十二条第一項の登録を受け、技術士の名称を用いて、科学技術**（人文科学のみに係るものを除く。以下同じ。）**に関する高等の専門的応用能力を必要とする事項についての計画、研究、設計、分析、試験、評価又はこれらに関する指導の業務**（他の法律において（中略））**を行う者をいう。**

**「第三十二条第一項の登録を受け」**——**登録を受けることが、技術士の定義に含まれています。**

**そして、業務の内容として「計画」が最初に挙げられています。**

**まちづくり・都市開発の仕事の多くは、この「計画」に当たります。**だから、**この資格が求人票に出てきます。**

**⚠ 試験の区分、受験の要件、登録の手続きについては、所管する文部科学省や試験を実施する機関の公表を確認してください。**当社が確認していない内容は、この記事には載せていません。

## 資格が「必須」か「歓迎」かを見分ける

**求人票の書き方で、扱いが違います。**

| 書かれ方 | 意味 |
|---|---|
| **必須要件**の欄にある | **無いと応募できない** |
| **歓迎要件**の欄にある | **無くても応募できる** |
| 「取得支援あり」とある | **入ってから取る前提** |
| 「◯◯または同等の経験」 | **経験で代替できる** |

**4つ目の書き方が、この業界には多い**です。

**「技術士、またはこれと同等の実務経験を有する方」**という形で書かれていることがあります。**行政での計画の策定や事業の実施の経験**が、ここに当たる場合があります。

**⚠ 該当するかどうかは、会社の判断によります。**迷ったら、**応募の前に問い合わせて構いません。**「◯◯の実務経験がありますが、応募の対象になりますか」。**この問い合わせ自体が、失礼にはなりません。**

**そして、調整・手続きを担う職種や、まちづくり会社の職種では、資格が要件になっていない募集もあります。**

## 選考の流れは、職種で分かれます

| 職種 | 流れの型 | 回数の目安 |
|---|---|---|
| 再開発コンサルタント | 書類 → 部門長 → 役員 | **2〜3回** |
| 都市計画コンサルタント | 書類 → 部門長 → **課題の提出** → 役員 | 3回前後 |
| デベロッパー | 書類 → 人事 → 部門長 → 役員 | **3〜4回** |
| 建設コンサルタント | 書類 → 技術部門 → 役員 | 2〜3回 |
| まちづくり会社 | 書類 → 代表・責任者 | **1〜2回。速い** |

**都市計画コンサルタントでは、課題の提出を求められる**ことがあります。

**「この地区について、あなたならどう進めますか」**という形で、**簡単な提案を作らせる**というものです。

**⚠ ここで、役所の目線で書かないでください。**「まず現況の調査を行い、課題を整理し」という書き方は、**行政の計画の策定の手順**です。**求められているのは、「誰に、何から話しに行くか」**です。

**まちづくり会社は、選考が速い**です。**組織が小さく、代表が直接判断する**ためです。

**役所の採用試験と違う点は、筆記試験が無いか軽いこと**です。**書類と面接で判断されます。**

## 面接で見られている観点は、5つです

| 観点 | 具体的に確かめられること |
|---|---|
| ① 合意形成の経験 | **年単位で向き合った経験があるか** |
| ② 止まった状態への耐性 | **まとまらない案件に居続けられるか** |
| ③ 行政との協議の段取り | **どの課と、どの順で話すかが分かるか** |
| ④ 立場の切り替え | **事業者の側に立てるか** |
| ⑤ 受注への構え | 提案の場面にどう関わるか |

**①と②が、この業界の核心**です。

**[まちづくり・都市開発の志望動機](industry-machizukuri-shiboudoki.html)でも触れましたが、「まとまらなかった案件は、どう扱いましたか」という質問には、まとまらなかった話をそのまま答えてください。**

**③は、公務員の強い持ち札**です。

**答え方は、具体的に。**「この種の協議では、先に道路の部署と話して幅員の考え方を確認しておかないと、建築の部署との協議が空転します。順番を間違えると、戻ることになります」。**この種の説明ができる人は、この業界では即戦力です。**

**⑤は、職位によります。**担当として入るなら、**「提案書の作成を支援する形から入りたい」**で足ります。

:::insight
選考に同席させていただいていて、**この業界で公務員の方が損をしている場面**があります。**「行政のどの部署と、どういうやり取りをしていましたか」**という質問への答え方です。多くの方が、**自分の所属と所掌事務**を説明されます。「都市計画課で、地区計画の担当をしていました」。**これは経歴の説明であって、質問の答えではありません。**この質問で聞かれているのは、**「あなたを雇うと、行政との協議がどれだけ楽になるか」**です。ですから、答えるべきは**関係の地図**です。「地区計画の案件では、建築の部署、道路の部署、公園の部署、それから消防と協議が要ります。このうち、消防は建物の計画がある程度固まらないと実質的な話ができないので、後ろに回します。逆に、道路の部署は早い段階で押さえないと、あとで計画を組み直すことになります」。**この説明は、外から入った人には作れません。**役所に何年もいて、**協議で戻された経験がある人だけが持っている知識**です。そして、会社にとっては**時間が金銭に直結する**ので、**この知識には値段が付きます。**職務経歴書にも、**所掌事務ではなく「協議の相手と順番」**を書いてください。
:::

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 場面 | 効く理由 |
|---|---|
| 制度・手続きについての質問 | **条文と運用の両方を知っている** |
| 行政との協議の段取り | **関係の地図を持っている** |
| 権利者対応についての質問 | 用地・住民説明の経験 |
| 書類の作り込み | 記録を残す習慣 |
| 補助の制度についての質問 | **交付する側にいた** |

**効きにくい場所**

| 場面 | 効きにくい理由 |
|---|---|
| 成果を数字で語る | **役所では個人の成果として記録されない** |
| 自己紹介を短く話す | 説明が経緯から始まりがち |
| 課題の提出で、実行の手順を書く | **計画の手順で書いてしまう** |
| 採算についての質問 | 予算の執行とは見る方向が違う |

**3つ目について、もう一度**。**課題を出されたら、「誰に、何から話しに行くか」から書いてください。**

**現況の調査から始める答えは、行政の側の手順**です。**民間は、権利者の顔が見えている前提で動きます。**

## 準備の手順

| 順 | やること | 目安 |
|---|---|---|
| 1 | **年単位で向き合った経験**を3つ書き出す | 1時間 |
| 2 | **まとまらなかった案件**を1つ用意する | 30分 |
| 3 | **協議の相手と順番**を、担当した案件ごとに書き出す | 1時間 |
| 4 | 応募先の**実績のページ**を読む | 1時間 |
| 5 | 求人票の**資格の扱い**（必須か歓迎か）を確認する | 20分 |
| 6 | **確認する項目を3つ**決める（勤務地・転勤・案件の数） | 20分 |

**3つ目が、この業界で最も効く準備**です。**面接でそのまま使えます。**

[経験の言い換えから相談する](../apply.html)こともできます。ご利用は無料です（紹介手数料は採用企業の負担です）。

## 逆質問で使えるもの

| 質問 | 何が分かるか |
|---|---|
| いま動いている案件は何件ありますか | **仕事の密度** |
| そのうち、着手から5年以上のものはありますか | **案件の構成** |
| 転勤や長期の出張の範囲を教えてください | **勤務地の前提** |
| 入って最初に任せたいことは何ですか | 期待されている役割 |
| 権利者対応で、夜間や休日の対応はありますか | **生活の組み立て方** |

**5つ目を忘れないでください。**[まちづくり・都市開発の年収と働き方](industry-machizukuri-nenshu.html)で触れたとおり、**権利者の方にお勤めの方がいれば、協議が平日の夜や休日になる**ことがあります。

## 内定から入社まで

**労働基準法第15条第1項**により、**労働契約の締結に際して、賃金・労働時間その他の労働条件の明示**が求められます。**書面で条件を確認してください。**

**とくに確認していただきたいのは、次の3つ**です。

| 確認すること | 理由 |
|---|---|
| 就業の場所と、**転勤の範囲** | 会社によって幅が大きい |
| **評価の仕組み** | 案件が長期のため、単年度で測りにくい |
| 資格手当の有無 | 取る順番の判断に関わる |

:::insight
ここまで対策の話をしてきましたが、**この業界を受ける前に、必ず済ませておいていただきたいこと**があります。**再就職に関する規程の確認**です。まちづくりの事業では、**自治体と民間の会社が委託や協議の関係にある**ことが多く、**自分が担当していた事業の相手方に応募する**という形になりやすい。⚠ **規制は、国家公務員と地方公務員で異なり、地方公務員については自治体ごとに定めがあります。**離職前の職務との関係で、**一定期間、特定の行為が制限される**場合があります。**⚠ この記事では、個別の事情について判断できません。必ず、所属の人事担当部署と、適用される条例・規程を確認してください。**⚠ そして、**選考が進んでから確認するのでは遅い**です。最終面接まで行って、そこで問題が分かると、**ご本人にも、会社にも負担がかかります。**応募先を選ぶ前に済ませておけば、**候補の絞り方が最初から定まります。**確認した結果、候補から外れる会社が出ることもありますが、**この業界には会社が複数あります。**確認を理由に、業界ごと諦める必要はありません。当社が、いまの職を辞めることをお勧めすることはありません。**確認した結果、残るという結論も正しい結論です。**
:::

## まとめ

- **求人票に資格が並んでいても、すべての職種で必須とは限りません**
- **技術士法第2条第1項**は、技術士を**「第三十二条第一項の登録を受け、技術士の名称を用いて、科学技術に関する高等の専門的応用能力を必要とする事項についての計画、研究、設計、分析、試験、評価又はこれらに関する指導の業務を行う者」**と定義しています
- ⚠ **試験や登録の要件は、所管と実施機関の公表を確認してください**
- 求人票では、**必須要件か歓迎要件か**を見分けてください。**「◯◯または同等の経験」**という書き方が多く、**行政での実務が当たる場合があります**
- **都市計画コンサルタントでは、課題の提出**を求められることがあります。⚠ **「現況の調査から」ではなく「誰に、何から話しに行くか」**で書いてください
- 見られている観点は、**①合意形成の経験 ②止まった状態への耐性 ③行政との協議の段取り ④立場の切り替え ⑤受注への構え**の5つです
- ⚠ **③では、所掌事務ではなく「協議の相手と順番」**を答えてください。**外から入った人には作れない知識**です
- ⚠ **応募先を選ぶ前に、再就職に関する規程の確認を済ませてください。**選考が進んでからでは遅いです

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 在職中です。面接や課題の提出に対応できますか

**対応できます。**この業界は**中途採用が中心**なので、在職中の応募が前提になっています。一次面接をオンラインで行う、平日の夜に設定するといった対応も一般的です。**課題の提出がある場合、期限は相談できます。**「現職の状況から、◯日いただけますか」と伝えて構いません。⚠ **むしろ、短い期限で急がせる会社は、入ったあとの進め方も同じ**である可能性があります。なお、**課題に時間をかけすぎないでください。**求められているのは完成度ではなく、**考え方の筋道**です。半日で書ける分量に収めて、**「誰に、何から話しに行くか」が明確**であれば足ります。

### 資格を取ってから応募すべきですか

**必須要件でなければ、先に応募して構いません。**この業界の中途採用では、**実務の経験が先に見られます。**行政での計画の策定、事業の実施、権利者との折衝。**これらの経験があるなら、資格の有無で足切りされない募集があります。**⚠ ただし、**必須要件に挙げられている募集**には応募できません。求人票で確認してください。また、**「取得支援あり」と書かれている会社**は、**入ってから取る前提**で採用しています。この場合、**学習を始めていることを伝える**と、意欲が伝わります。⚠ **試験の要件については、実施する機関の公表を確認してください。**当社が確認していない内容はお伝えできません。

### 複数の会社を並行して受けても問題ありませんか

**問題ありません。**中途採用では一般的です。ただし、**この業界では会社の数が限られる**ため、**同じ地域で複数社を受けると、業界内で話が伝わる**ことがあります。**隠す必要はありません**が、**それぞれの会社に対して志望動機を書き分けておく**ことは、より重要になります。⚠ また、**応募先を決める前に、再就職に関する規程の確認を済ませておいてください。**複数社に応募してから確認して、**その大半が候補から外れる**という事態を避けられます。進め方のこつは、**日程を少しずらすこと**です。条件を比べる時間を確保できます。
