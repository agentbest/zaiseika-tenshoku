**商工や産業の担当をしてきた方から、「取る意味はあるか」**というご相談を伺います。

**登録の制度が、法律に置かれています。**

この記事では、**その位置づけ**と、**現実的な進め方**を扱います。

**⚠ 登録の要件・手続・更新は、所管するところの公表を確認してください。****この記事では、個別の要件には触れません。**

## 登録の制度が、法律に置かれています

**中小企業支援法第11条**です。

> **経済産業大臣は、中小企業者がその経営資源に関し適切な経営の診断及び経営に関する助言**（以下単に「経営診断」という。）**を受ける機会を確保するため、登録簿を備え、中小企業の経営診断の業務に従事する者であつて次の各号のいずれかに**（略）**該当するものの登録を行う。**

**「経営の診断及び経営に関する助言」**が、制度の目的として書かれています。

**つまり、事業者の相談に応じる立場**です。

**行政の商工や産業の担当は、この相談を受けてきた側**でもあります。

**補助金の相談、融資の相談、事業の計画の確認。**

**立場は違いますが、扱う内容は重なります。**

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 支援の機関・団体 | **事業者の相談** |
| ② 金融・保証 | 事業の内容の評価 |
| ③ 調査・コンサルティング | 調査、計画の支援 |
| ④ 自治体が相手の事業 | **補助金・制度の理解** |
| ⑤ 事業会社の企画 | 計画の立案 |

**④が、行政の経験と最も重なります。**

**補助金の制度を運用してきた経験**は、**申請を支援する側でそのまま使えます。**

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 商工・産業の実務で身についていること

| 経験 | 民間での読まれ方 |
|---|---|
| ① 補助金の審査 | **事業の計画の確認** |
| ② 事業者からの相談 | 顧客の相談への対応 |
| ③ 制度の設計・運用 | 仕組みの設計 |
| ④ 関係機関との連携 | 支援機関、金融機関 |
| ⑤ 統計・調査 | 地域の状況の把握 |
| ⑥ 説明会の運営 | 周知、研修 |

**①が中心**です。

**事業の計画を読み、実現の見込みを確認してきた経験**です。

**この動作は、支援する側でも、評価する側でも使えます。**

## 書き方の例

**悪い例**

> 商工課で、補助金の担当をしていました。

**良い例**

> ◯◯課において、**中小企業向けの補助の制度◯件を担当。**年間約◯件の申請について、**事業の計画の内容と実現の見込みを確認し、審査の資料を作成。**事業者からの相談に**年約◯件対応し、制度の要件と申請の手順を説明。**制度の設計にあたり、**対象と要件を整理し、要綱と様式を作成。**支援の機関や金融機関と**連携し、説明会を年◯回運営。**

**「制度の数」「件数」「審査」「相談」「設計」「連携」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

:::insight
この資格について、**面談でお伝えしているのが「相談を受けた経験を書いてください」**という点です。**「補助金の担当」と書かれると、審査の事務として読まれます。**ところが、**実際には、事業者から相談を受けてきた**はずです。何をしたいのか、どの制度が使えるのか、要件を満たすには何が必要か。**この相談の対応が、支援の業務そのもの**です。そして、**行政の窓口には、相手を選ばずに相談が来ます。**準備が整った事業者も、これから考える事業者も来る。**この幅のある相談に対応してきた経験は、支援の機関や金融機関で使えます。**書類には、**「事業者からの相談に年約◯件対応し、制度の要件と申請の手順を説明」**と書いてください。**件数があると、経験の厚みが伝わります。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 現実的な進め方

| 順 | やること |
|---|---|
| 1 | **応募したい求人の条件を確認する** |
| 2 | 実務で書ける材料を並べる |
| 3 | 資格が必要かを判断する |
| 4 | 必要なら、学習の期間を見積もる |
| 5 | **見直しの時期を決めて始める** |

**5が要**です。

**「半年後に進み方を確認する」と決めておく**と、**続けるか切り替えるかを判断できます。**

**期限を決めずに始めると、判断の機会が来ません。**

**扱いは**[公認会計士を目指す場合の現実](skill-kaikeishi.html)**に整理した考え方と同じです。**

## 資格の位置づけ

| 状況 | 扱い |
|---|---|
| ① 応募条件に記載がある | **満たす材料になる** |
| ② 支援の業務を担う | 評価される場面があります |
| ③ 実務の経験がある | **経験のほうが具体な場合も** |
| ④ 体系的に学びたい | 範囲が決まっています |
| ⑤ 目的が曖昧 | 優先順位を下げてください |

**④について。**

**企業の経営に関する内容を、体系的に学べます。**

**行政の側からは見えにくい部分**を知る手段になります。

**なお、取れば転職できる、という関係にはありません。**

**何を審査し、どう相談に応じたか**が、評価の対象です。

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 実績の整理 | **制度の数、件数、相談の件数** |
| 相談の整理 | 難しかった事例の進め方 |
| 要件の確認 | 所管の公表を確認 |
| 求人を読む | 週に30分 |

**1行目です。**

**年度の報告や統計の資料から、件数を確認**してください。

**根拠のない数は書かないでください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 担当した制度 | **制度の内容、件数** |
| 審査の観点 | 何を見たか |
| 相談への対応 | 難しかった場面 |
| 関係機関との連携 | 相手と、進め方 |
| 学習の状況 | 続けているか |

**2行目です。**

**事業の計画のどこを見たか**を説明できると、実務の水準が伝わります。

**なお、特定の事業者が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

## 審査の観点という材料

**補助金の審査で見てきた項目は、そのまま書ける材料になります。**

| 観点 | 内容 |
|---|---|
| ① 要件への適合 | **対象、業種、規模** |
| ② 事業の内容 | 何を、いつまでに、どうするか |
| ③ 経費の妥当性 | 見積り、対象となる範囲 |
| ④ 実現の見込み | 体制、資金、工程 |
| ⑤ 効果の見通し | 何がどう変わるか |

**④と⑤が、判断の分かれ目**です。

**計画として整っていても、実現の見込みが立たない案件があります。**

**体制が足りない、資金の手当てがない、時期が合わない。**

**この見極めをしてきた経験は、支援する側でも、評価する側でも使えます。**

**書類には、「事業の計画の内容と実現の見込みを確認」**と書いてください。

## よくある失敗

**1. 「補助金の担当」で止める**

**相談を受けた経験**を書いてください。

**2. 件数を書かない**

**経験の厚み**が伝わりません。

**3. 審査の観点を書かない**

**計画を読む動作**として読まれます。

**4. 制度の設計を書かない**

**仕組みの設計**にあたります。

**5. 連携の経験を書かない**

**支援機関、金融機関**との関係です。

**6. 見直しの時期を決めずに学習を始める**

**判断の機会が来ません。**

**7. 要件を人づてで判断する**

**所管の公表**を確認してください。

**8. 取れば転職できると考える**

**何を審査し相談に応じたか**が評価の対象です。

:::insight
ここまで資格の話をしておいて逆のことを言いますが、**この分野は、資格がなくても入口が広い領域です。**面談で拝見していると、**「資格がないと支援の仕事はできない」と考える方**がいらっしゃいます。ところが、**補助金の申請を支援する会社、地域の支援に関わる事業、金融機関の事業性の評価**では、**制度を知っていることが要件**になる場面があります。とくに、**自治体が関わる補助の制度**は、**要綱の読み方、申請の時期、報告の様式**まで理解している人が少ない。**運用してきた側の知識が、そのまま価値**になります。ですから、**まず求人票を5件読んで、資格が必須かどうかを確認してください。**必須でなければ、**いま応募できます。**そのうえで、**学びたいなら、働きながら進める**という順序で差し支えありません。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **中小企業支援法第11条**は、**経営の診断及び経営に関する助言を受ける機会を確保するため、登録簿を備え、登録を行う**としています
- **行政の商工や産業の担当は、事業者の相談を受けてきた側**です。扱う内容は重なります
- 効くのは、**支援の機関・団体、金融・保証、調査・コンサルティング、自治体が相手の事業、事業会社の企画**です
- **補助金の制度を運用してきた経験**は、申請を支援する側でそのまま使えます
- **相談を受けた経験**を書いてください。件数があると厚みが伝わります
- **見直しの時期を決めてから**学習を始めてください
- **資格がなくても入口が広い領域**です。先に求人票を読んでください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 商工の担当ではありませんでした

**書ける経験があるか確認してください。**事業者を相手にした業務——許認可、指導、契約、相談——があれば、**事業者への対応の経験**として書けます。また、**補助金や交付金の事務**は、商工に限らず多くの分野にあります。「◯◯に関する補助の制度について、要件の確認と交付の決定を年約◯件担当」という形です。**制度を運用した経験**として読まれます。なお、**経営に関する知識は、学習で補える部分**です。扱いは[財務諸表の読み方｜公会計との違いから入る](skill-zaimu.html)にも整理しています。

### 独立を前提に考えるべきですか

**両方の道があります。**支援の機関や会社に入る道と、独立する道です。**独立には、営業と運営という別の要素**が加わります。誰から依頼を受けるか、どう知ってもらうか、収支をどう回すか。一方、**会社に入る場合は、まず実務を覚えることになります。**判断の目安は、**収入の見通しと生活の条件**です。なお、**会社で経験を積んでから独立する**という順序もあります。扱いは[行政書士｜行政経験との相性と、転職での使い方](skill-gyoseishoshi.html)に整理した考え方と同じです。**先に選択肢を並べてください。**

### 学習を続けられるか不安です

**見直しの時期を決めてから始めてください。**「半年後に進み方を確認する」と決めておくと、**続けるか切り替えるかを判断できます。**なお、**在職中の学習は、繁忙期に止まりがち**です。年間でどれだけ時間が取れるかを、**繁忙期を含めて見積もって**ください。また、**団体によっては、研修や自己啓発に関する制度**が置かれていることがあります。**人事担当に確認**してください。扱いは[選考スケジュールの組み方](senko-sagasu-schedule.html)に整理しています。
