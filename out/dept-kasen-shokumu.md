河川・砂防課の職務経歴書で、いちばん多い失敗はこれです。

**「河川及び砂防に関する業務」**

**この1行で終わってしまいます。**

読む側は、ここから**「川の工事をしていた人」**という像しか作れません。実際には、**降った雨がいつどこに出てくるかを読み、区域の中に住んでいる人にそれを伝え、出水のときに人を動かす順番を決めていた**わけですが、それが書かれていません。

この記事では、**職務要約・担当業務・実績**の3つに分けて、悪い例と良い例を並べます。

言い換えは[河川・砂防課の経験は民間で何と呼ばれるか](dept-kasen-honyaku.html)、行き先は[河川・砂防課から転職しやすい業界と職種](dept-kasen-tenshokusaki.html)に書いています。

## 区域を決めるのは県、備えるのは市町村です

書き方に入る前に、この仕事の立ち位置を条文で押さえます。**書類の芯になる部分**です。

土砂災害防止法第7条は、**土砂災害警戒区域の指定について、こう定めています。**

> 都道府県知事は、基本指針に基づき、急傾斜地の崩壊等が発生した場合には住民等の生命又は身体に危害が生ずるおそれがあると認められる土地の区域で、当該区域における土砂災害を防止するために警戒避難体制を特に整備すべき土地の区域として政令で定める基準に該当するものを、土砂災害警戒区域として指定することができる。

そして同条第3項に、**「あらかじめ、関係のある市町村の長の意見を聴かなければならない」**、第5項に、**公示した事項を記載した図書を関係のある市町村の長に送付する**と続きます。

**ここが、書類の芯です。**

**区域を指定するのは、都道府県です。**市町村の担当が持っているのは、**指定の前に意見を出す役割**と、**指定された後に警戒避難体制を組み立てる役割**の2つです。つまり、**決定そのものは自分の手元にはないのに、決定の後に現場を動かす責任は自分の側にある**——**この形の仕事を、何年もやってきたことになります。**

民間で人を採る側から見ると、これは**「他社が決めた基準を、自社の現場で運用できる形に落とす仕事」**です。**法令でも、本社の方針でも、親会社の規程でも、構図は同じ**です。

職務経歴書には、**この構図が見えるように書いてください。**

## 職務要約

### 悪い例

> 河川及び砂防に関する業務に従事。河川の維持管理、砂防事業の関連業務、災害時の対応を担当。

**これでは、範囲が読めません。**

### 良い例（現場の運用が長い方）

> 市が管理する準用河川および普通河川、延長約◯キロメートルの維持管理を担当。護岸、水門、樋門など施設約◯か所の点検と修繕の発注を実施。土砂災害警戒区域◯か所について、県の指定を受けた後の周知、避難場所の確認、自主防災組織への説明を担当。出水期には水防の当番体制に入り、水位の観測と避難情報の発令の補助を実施。

### 良い例（計画と調整が長い方）

> 河川および砂防に関する事業について、県の事業との調整、地元との協議、予算の要求と執行を担当。土砂災害警戒区域の指定に係る市としての意見の取りまとめ、指定後の住民説明会◯回の運営を実施。ハザードマップの改定を担当し、配布と自主防災組織への説明までを実施。災害時には被害の調査と復旧の要望の取りまとめを担当。

**太字にしなくても、数字が入っているだけで読み方が変わります。**延長、施設の数、区域の数、説明会の回数。**この4つのうち、分かるものから埋めてください。**

:::insight
この経歴の職務経歴書で、**書けるのに書かれていないことの筆頭が「説明会の回数」**です。区域の指定の前後、ハザードマップの改定、事業の着手前。**この仕事は、住民に説明する場面が繰り返し来ます。**ところが、**「説明するのは当たり前」だと思われている**ので、実績欄に出てきません。面談で伺うと、**「毎年、何回かはやっていました」とおっしゃいます。****その回数を数えてください。**しかも、**この説明会は、歓迎される説明ではないことがあります。**区域に入れば、土地の扱いに影響が出るからです。**反対の意見が出る場を、資料を作って、進行して、持ち帰って、次の回に返す。****これは、民間でいえば、合意が取れていない相手への説明の設計そのもの**です。建設コンサルタントでも、再生可能エネルギーの用地の交渉でも、工場の周辺の対応でも、同じ場面があります。書くなら、**「土砂災害警戒区域の指定に伴う住民説明会を年間約◯回運営。資料の作成、進行、質疑の記録、次回への回答までを担当」**という形です。**この一行があると、扱える相手の幅が一段広く読まれます。**
:::

## 担当業務

**「河川及び砂防」で丸めず、6つに分けてください。**

| 機能 | 書き方の例 |
|---|---|
| 施設の維持管理 | 準用河川・普通河川の延長約◯キロメートル、護岸・水門・樋門など約◯か所の点検、修繕の計画と発注 |
| 許可と占用 | 河川区域内の工作物の新築・改築に関する事務、占用の許可の審査、県が管理する河川に係る進達 |
| 砂防・急傾斜地 | 県が実施する砂防事業・急傾斜地の事業との調整、地元の同意の取りまとめ、市の負担金の予算執行 |
| 区域と周知 | 土砂災害警戒区域の指定に係る意見の提出、指定後の周知、ハザードマップの作成と配布 |
| 水防と避難 | 水位の観測、水防の当番体制、避難情報の発令に係る資料の作成と助言、自主防災組織との連携 |
| 災害と復旧 | 出水後の被害の調査、公共土木施設の災害復旧の申請、応急の措置の手配 |

**この6つのうち、自分がやっていないものは書かなくて構いません。**むしろ、**やっていない機能を空欄にしたほうが、やった機能の密度が読まれます。**

**注意したいのは、2番目の「許可と占用」**です。河川法第26条は、**河川区域内の土地で工作物を新築し、改築し、又は除却しようとする者は、河川管理者の許可を受けなければならない**と定めています。**つまり、川に手を入れる人は、全員が許可を通る**ということです。**その窓口にいた経験は、「他人の工事を審査していた経験」**として書けます。**自分が発注した工事ではないので、実績だと思われていないことが多い部分**です。

## 実績

**ここが、いちばん書きにくい部分です。**成果が、**何も起きなかったこと**として現れるからです。

### 悪い例

> 令和◯年の豪雨の際、災害対応に従事した。

**これは、出来事の記録であって、実績ではありません。**

### 良い例——3つの型

**型1：体制を作った**

> 土砂災害警戒区域◯か所について、指定後の避難場所と避難経路を点検し、うち◯か所で避難場所の変更を市の防災担当と調整。区域ごとの連絡先の一覧を整備し、自主防災組織◯団体へ説明を実施。

**型2：判断の材料を整えた**

> 水位の観測の値と、過去の出水の記録を突き合わせ、避難情報の検討を始める水位の目安を河川ごとに整理。夜間の出水に備え、当番が単独で判断しないための連絡の手順を文書化。

**型3：事業を回した**

> 護岸の修繕について、点検の結果を4段階に区分し、優先順位の基準を作成。年間◯件、約◯万円の工事を発注し、着手から完了までの工程を管理。県が実施する砂防事業◯か所について、地元の同意の取りまとめと市の負担金の執行を担当。

**3つとも、「何が起きたか」ではなく、「自分が何を設計したか」で書かれています。**

### 数字の出し方

| 数えるもの | 書き方の例 | 注意 |
|---|---|---|
| 管理の延長 | 準用河川・普通河川あわせて約◯キロメートル | 台帳の数字を使う。県の管理の分は分けて書く |
| 施設の数 | 護岸・水門・樋門など約◯か所 | 点検の対象の数で構わない |
| 区域の数 | 土砂災害警戒区域◯か所、うち特別警戒区域◯か所 | 公表されている数字を使う |
| 工事の件数と額 | 年間約◯件、約◯万円 | 発注の実績。個別の案件は書かない |
| 説明会の回数 | 年間約◯回 | 数えていないことが多い部分 |
| 出水の対応 | 出水期の当番◯回、警戒体制◯回 | 回数で書く。被害の規模は書かない |

**「約」を付けて構いません。**正確な数字が出せないことよりも、**桁が分かることのほうが大事**です。

### 応募先で並べ替える

| 応募先の方向 | 上に置く機能 |
|---|---|
| 建設コンサルタント | 区域と周知／砂防・急傾斜地／許可と占用 |
| 建設会社 | 施設の維持管理／災害と復旧／工事の発注 |
| 企業の防災・事業継続 | 水防と避難／区域と周知／体制を作った実績 |
| 損害保険・リスクの調査 | 災害と復旧／被害の調査／区域の読み方 |
| 自治体を顧客とする企業 | 許可と占用／点検の委託／台帳と図面 |

**同じ経歴でも、順番を変えるだけで読まれ方が変わります。**中身を作り直す必要はありません。

:::insight
書き方の話をしておいて逆のことを言いますが、**書類を完成させてから動く必要はありません。**この経歴の方に多いのは、**「災害が来なければ何もしていない」**と考えて、実績欄を薄く書いてしまうことです。ところが、**この仕事の中心は、起きる前に決めておくことです。**どの水位で誰に連絡するか。どの区域から先に伝えるか。夜に降り始めたら、誰が起きているか。**それを、起きていないうちに決めて、文書にして、毎年確かめてきた。****これは、民間の事業継続の計画で、そのまま求められる技術**です。しかも、**「空振りになる体制に、毎年お金と人を付ける説明」**まで経験しています。**先に、4つの数字だけ確かめてください。**管理の延長、施設の数、区域の数、説明会の回数。**このうち4つ目は、数えていないことが多い**ので、**過去3年分だけでも数えてみてください。**この4つが揃った時点で、**書類の読まれ方が変わります。**在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 書いてはいけないこと

| ✕ 書かない | ○ こう書く |
|---|---|
| 被災した地区の名前と、そこで起きたことの詳細 | 区域の類型と、そこで実施した手順 |
| 住民や事業者の名前、個別の協議の経緯 | 協議の型と、合意に至るまでの工程 |
| 公表されていない資料の中身 | 公表されている区域の数や計画の名称 |
| 「うちの市は体制が遅れていた」 | 「点検の結果を4段階に区分し、優先順位の基準を作成した」 |
| 災害の規模を、自分の成果のように書く | 対応した回数と、そこで運用した手順を書く |

**最後の行が、いちばん見落とされます。**大きな災害を経験したこと自体は、**経歴ではありますが、実績ではありません。**読む側が知りたいのは、**そのときに何を運用していたか**です。

## つまずきやすい点

**1. 「河川及び砂防に関する業務」で丸める**

**維持管理／許可と占用／砂防・急傾斜地／区域と周知／水防と避難／災害と復旧**の6つに分けてください。

**2. 説明会の回数を書かない**

**合意が取れていない相手に説明した量**です。**書かれていない部分なので、差が付きます。**

**3. 「決めたのは県だから」と引いてしまう**

**決定は県、運用は市町村。**この分担は、**民間で「他社が決めた基準を自社で運用する」構図とそのまま重なります。**引く必要はありません。

**4. 災害対応を、苦労話にする**

**起きる前に決めて、文書にして、毎年確かめていた**と書いてください。

**5. 技術職でないことを、弱点として書く**

**許可の審査、区域の周知、予算の執行、地元との協議。**技術以外の部分が広くあります。**自分の範囲を明示すれば、それで足ります。**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## まとめ

- 土砂災害防止法第7条は、**区域を指定するのは都道府県で、市町村の長の意見を聴き、指定後は図書を市町村に送付する**と定めています
- つまり、**河川・砂防課は「他が決めた区域を、現場で回る形に落とす」仕事**をしています
- 職務要約には、**延長・施設の数・区域の数・説明会の回数**を入れてください
- 実績は、**①体制を作った ②判断の材料を整えた ③事業を回した**の3つの型で書けます
- 書いてはいけないのは、**地区の名前、個人の名前、公表されていない資料、災害の規模を成果にすること**です
- **説明会の回数**は、**数えていないことが多い**ので、**過去3年分だけでも数えてください**

## よくある質問

### 事務職で、設計や積算はしていません

**それでも書けます。**河川・砂防課の事務は、**占用の許可の受付、県との負担金の事務、区域の周知、ハザードマップの作成の発注、水防の体制の名簿の管理、災害復旧の申請の事務**など、**技術以外の部分が広くあります。**とくに、**区域の周知とハザードマップ**は、**防災を扱う企業や、自治体を顧客とする企業でそのまま効く経験**です。書くなら、**「土砂災害警戒区域◯か所の周知とハザードマップの改定を担当。印刷と配布の発注、自主防災組織◯団体への説明までを実施。設計と積算は技術職が担当」**と、**自分の範囲を明示してください。**線を引いた応募は、読まれます。

### 大きな災害を経験していないのですが

**それは、書き方で埋まります。**読む側が見ているのは、**災害の大きさではなく、備えの中身**です。書くべきは、**①どの水位・どの雨量で何を始めると決めていたか ②その手順を誰と共有していたか ③毎年どこを見直していたか**の3つです。**災害が起きなかった年に、体制を維持し続けたこと**は、**民間の事業継続の部門でいちばん難しいとされている部分**です。むしろ、**「起きない期間の運用」を語れる人は多くありません。**大きな災害の経験がないことを、断り書きとして書く必要はありません。

### 県ではなく市町村なので、砂防の事業そのものはしていません

**市町村の側の役割を書けば足ります。**砂防の事業の多くは県が実施しますが、**地元の同意の取りまとめ、用地の相談、市の負担金の予算の要求と執行、工事の期間中の住民からの問い合わせの対応**は、市町村の側に来ます。書くなら、**「県が実施する砂防事業◯か所について、地元の同意の取りまとめと市の負担金の執行を担当。工事期間中の住民からの問い合わせの窓口を担当」**という形です。**「事業の主体ではないが、地元を動かす部分を持っていた」**——**この書き方は、受託の側に回る会社にとって、いちばん知りたい部分です。**面接で聞かれることは[河川・砂防課出身者が面接で必ず聞かれること](dept-kasen-mensetsu.html)に整理しています。
