**用地の事務を担当してきた方から、「この経験はどこへつながるか」**というご相談を伺います。

**評価の仕事と、取得の仕事は、隣接しています。**

この記事では、**接続の仕方**と、**資格の位置づけ**を扱います。

**⚠ 受験・登録の要件と手続は、所管するところの公表を確認してください。****この記事では、個別の要件には触れません。**

## 鑑定評価は、資格の業務として定められています

**不動産の鑑定評価に関する法律第3条第1項**です。

> **不動産鑑定士は、不動産の鑑定評価を行う。**

**同条第2項**です。

> **不動産鑑定士は、不動産鑑定士の名称を用いて、不動産の客観的価値に作用する諸要因に関して調査若しくは分析を行い、又は不動産の利用、取引若しくは投資に関する相談に応じることを業とすることができる。**ただし、他の法律においてその業務を行うことが制限されている事項については、この限りでない。

**鑑定評価そのもの**と、**価値に作用する要因の調査・分析、利用や取引の相談**が、業務として書かれています。

**用地の事務では、この評価を依頼し、内容を確認してきた**はずです。

**依頼する側にいた経験が、そのまま接続の材料**になります。

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 用地の取得の支援 | **発注者支援、補償の業務** |
| ② 不動産の管理・活用 | 権利関係の調査 |
| ③ 鑑定・調査の事業 | 評価の補助、資料の収集 |
| ④ 金融・保証 | 担保の評価に関する業務 |
| ⑤ 自治体が相手の事業 | 手続と基準の理解 |

**①が、最も直接に重なります。**

**公共の事業に伴う用地の取得では、調査、交渉、補償、登記の一連があります。**

**この工程を経験している人**が、支援する側で必要とされます。

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 用地の実務で身についていること

| 経験 | 民間での読まれ方 |
|---|---|
| ① 権利関係の調査 | **登記、相続、共有の整理** |
| ② 評価の依頼と確認 | 鑑定の内容の読み取り |
| ③ 補償の算定 | 基準に沿った積算 |
| ④ 権利者との折衝 | 利害の対立する相手との合意形成 |
| ⑤ 契約と登記 | 手続の管理 |
| ⑥ 記録の作成 | 経緯を残す |

**①と④が、民間から見て希少**です。

**①について。**

**相続が複数代にわたる土地の権利者の調査**は、**年数がないとできません。**

**④について。**

**強制力のない関係で、期限までに合意を作った経験**です。

**扱いは**[同じ部署が長い場合の職務経歴書](senko-shokumu-onajibusho.html)**にも整理しています。**

## 書き方の例

**悪い例**

> 用地買収を担当しました。

**良い例**

> 公共事業に係る用地の取得を担当。**年間約◯件の物件の調査、補償の算定、権利者との折衝**を実施。**相続が複数代にわたる土地について、権利者◯名の調査と同意の取得**を担当。**鑑定評価を◯件依頼し、内容を確認のうえ、算定の根拠を決裁の文書に整理。**契約から登記までの手続を管理。

**「件数」「権利関係」「評価の確認」「手続」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

:::insight
用地の経験について、**面談でお伝えしているのが「評価を読んだ側にいた経験を書いてください」**という点です。**鑑定評価を自分で行っていなくても、依頼し、内容を確認し、算定の根拠として使ってきた**はずです。**どの条件で評価が変わるのか、どの資料が必要になるのか、何を確認すれば説明できるのか。****これは、依頼する側にいないと身につきません。**そして、**用地の取得を支援する会社では、この理解が業務の前提**になります。発注者がどの基準で判断するか、どの資料を求めるか。**書類には、「鑑定評価を◯件依頼し、内容を確認のうえ、算定の根拠を整理」と書いてください。**「用地買収を担当」では、この立場が伝わりません。**資格の取得を考える前に、この経験を整理してください。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 資格の位置づけ

| 状況 | 扱い |
|---|---|
| ① 応募条件に記載がある | **満たす材料になる** |
| ② 評価そのものを業とする | 資格が前提になります |
| ③ 用地の実務がある | **経験のほうが具体** |
| ④ 長く続ける前提がある | 学習に時間がかかります |
| ⑤ 目的が曖昧 | 優先順位を下げてください |

**④が要**です。

**準備に相応の時間がかかる資格**です。

**応募の時期が決まっているなら、間に合うかを先に確認**してください。

**なお、取れば転職できる、という関係にはありません。**

**何を調査し、どう合意を作ったか**が、評価の対象です。

## 取る前に考えること

| 確認すること | 内容 |
|---|---|
| ① 受験・登録の要件 | **所管の公表を確認** |
| ② 実務で書ける材料 | 調査、算定、折衝 |
| ③ 目的 | 評価を業とするのか、支援に回るのか |
| ④ 期限 | 応募の時期に間に合うか |
| ⑤ 在職中の学習 | 続けられるか |

**③で大きく分かれます。**

**評価そのものを業とする**のか、**用地の取得を支援する側に回る**のか。

**後者であれば、資格がなくても応募できる求人があります。**

**⑤について。**

**在職中の学習は、繁忙期に止まりがちです。**

**年間の見通しを立ててから始めてください。**

**途中で止めると、費やした時間が戻りません。**

**転職の時期と重ねない判断もあります。**

**どちらを先にするかを決めてください。****同時に進めると、どちらも遅れることがあります。**

**先に応募し、入社後に学ぶという順序もあります。**

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 実績の整理 | **件数、権利者の数、事業の種類** |
| 評価の確認の整理 | 依頼した件数、確認した観点 |
| 折衝の整理 | 難しかった案件の経緯 |
| 求人を読む | 週に30分 |

**1行目です。**

**年度の報告や決裁の資料から確認**してください。

**根拠のない数は書かないでください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 担当した件数と種類 | **事業の種類、年間の件数** |
| 権利関係の調査 | 難しかった事例の進め方 |
| 評価の確認 | 何を見たか |
| 折衝の進め方 | 合意までの手順 |
| 手続の管理 | 契約から登記まで |

**4行目です。**

**なお、特定の権利者や物件が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

## よくある失敗

**1. 「用地買収を担当」で止める**

**工程と件数**を書いてください。

**2. 評価を読んだ側にいた経験を書かない**

**依頼する側の理解**が価値です。

**3. 権利関係の調査を書かない**

**年数がないとできない**経験です。

**4. 折衝を「交渉しました」で済ませる**

**手順と期間**を書いてください。

**5. 資格がないと応募できないと考える**

**支援する側の求人**があります。

**6. 学習の期間を見積もらない**

**時間がかかります。**

**7. 要件を人づてで判断する**

**所管の公表**を確認してください。

**8. 特定の物件が分かる説明をする**

**守秘の義務は退職後も続きます。**

:::insight
ここまで「経験が先」という話をしておいて逆のことを言いますが、**長く続ける前提があるなら、学ぶ意味は大きい分野です。**面談で拝見していると、**用地の実務を長く担当し、評価の考え方を体で覚えている方**がいらっしゃいます。**この方が体系的に学ぶと、実務と知識がつながります。**どの手法でなぜその結論になるのか、なぜその資料が必要なのか。**理解の形が変わります。**そして、**転職の有無にかかわらず、在職中の業務でも効きます。**評価の内容を確認するとき、根拠を追えるようになるからです。ですから、**「転職のために取る」ではなく、「実務の理解を深めるために学び、結果として選択肢が増える」**という位置づけで考えてください。**この順序であれば、途中で止めても損になりません。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **不動産の鑑定評価に関する法律第3条**は、**鑑定評価**と、**価値に作用する要因の調査・分析、利用や取引の相談**を業務としています
- **用地の事務では、評価を依頼し、内容を確認してきた**はずです。**依頼する側の経験**が材料になります
- 効くのは、**用地の取得の支援、不動産の管理・活用、鑑定・調査の事業、金融・保証、自治体が相手の事業**です
- **権利関係の調査と、権利者との折衝**が、民間から見て希少です
- **「用地買収を担当」ではなく、工程と件数**を書いてください
- **評価そのものを業とするか、支援に回るか**で、資格の要否が変わります
- **準備に時間がかかります。**期限を先に確認してください

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 資格がなくても、用地の支援の仕事に就けますか

**求人によります。**発注者支援や補償の業務では、**用地の実務経験が要件**とされることがあります。**資格が必須でない求人**もあります。判断の目安は、**求人票の「必須」の欄**です。なお、**行政での用地の経験は、この領域で直接評価される**ことがあります。調査、算定、折衝、契約、登記。**工程を一貫して担った経験**は、外から入った人には得にくいものです。読み方は[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。

### 折衝の経験は、どう書けば伝わりますか

**相手、争点、手順、期間で書いてください。**「権利者◯名との折衝を担当。補償の算定の根拠と、代替地の条件について、資料を示しながら協議。◯か月で合意に至り、経緯を記録に整理」という形です。**強制力のない関係で、期限までに合意を作った**という点が伝わります。なお、**特定の権利者が分かる記述は避けてください。**「相続が複数代にわたる案件」のように、**類型で書く**ほうが安全です。扱いは[交渉と調整｜庁内調整の経験を民間で言語化する](skill-koushou.html)にも整理しています。

### 在職中に学習を続けられるか不安です

**期間を見積もってから始めてください。**準備に相応の時間がかかる資格です。**繁忙期を含めた年間の見通し**を立て、**続けられる形かを確認**してください。なお、**転職の準備と並行する場合、優先順位を決めて**ください。応募の時期が近いなら、**職務経歴書の作成と求人を読む作業が先**です。扱いは[選考スケジュールの組み方](senko-sagasu-schedule.html)に整理しています。**学習は、転職の後でも続けられます。**急いで同時に進める必要はありません。
