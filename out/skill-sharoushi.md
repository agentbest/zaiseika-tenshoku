**人事や給与を担当してきた方から、「この資格は噛み合うか」**というご相談を伺います。

**業務の範囲が、法律に定められています。**

この記事では、**その中身**と、**実務との噛み合い方**を扱います。

**⚠ 受験・登録の要件と手続は、所管するところの公表を確認してください。****この記事では、個別の要件には触れません。**

## 業務が、法律に定められています

**社会保険労務士法第2条第1項**です。

> **社会保険労務士は、次の各号に掲げる事務を行うことを業とする。**
>
> 一 **別表第一に掲げる労働及び社会保険に関する法令**（以下「労働社会保険諸法令」という。）**に基づいて申請書等**（行政機関等に提出する申請書、届出書、報告書、審査請求書、再審査請求書その他の書類（略））**を作成すること。**（略）

**労働及び社会保険に関する法令に基づく書類の作成**が、業務として挙げられています。

**行政の人事や給与の事務では、これらの法令に沿った手続を扱ってきた**はずです。

**ただし、公務員の制度は、民間の制度と異なる部分があります。**

**この違いを先に押さえてください。**

## 制度の違いを押さえる

| 項目 | 公務員 | 民間 |
|---|---|---|
| 根拠 | **法律・条例・規則** | 法律・就業規則 |
| 保険 | 共済の制度 | 健康保険・厚生年金 |
| 雇用の保険 | 適用の扱いが異なります | 適用 |
| 勤務の条件 | 条例で定める | 就業規則・労働契約 |
| 争いの解決 | 人事委員会等の制度 | 労働基準監督署等 |

**この違いがあるため、「同じ」とは言えません。**

**一方、動作は共通**しています。

**根拠に沿って処理し、記録を残し、対象者に説明する。**

**この部分が、噛み合う**ところです。

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 人事・労務の部門 | **制度の運用、手続** |
| ② 給与の計算の事業 | 手続、確認 |
| ③ 事務の受託 | 手順の整備 |
| ④ 自治体が相手の事業 | 公務員の制度の理解 |
| ⑤ 相談・窓口の業務 | 制度の説明 |

**①と④が中心**です。

**④について。**

**自治体を顧客とする会社では、公務員の制度を理解している人**が必要とされます。

**共済、条例、人事の制度。**

**外から入った人には見えにくい**部分です。

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 人事・給与の実務で身についていること

| 経験 | 民間での読まれ方 |
|---|---|
| ① 給与の計算と支給 | **支給の事務、確認** |
| ② 勤怠の管理 | 労働時間の管理 |
| ③ 保険・年金の手続 | 資格の取得・喪失の届出 |
| ④ 採用・人事の記録 | 人事の情報の管理 |
| ⑤ 規程の整備 | 条例・規則の改正 |
| ⑥ 相談への対応 | 制度の説明 |

**⑤が、行政ならでは**です。

**条例や規則の改正に関わった経験**は、**規程の整備の業務と重なります。**

**扱いは**[衛生管理者｜総務・人事からの転職で使える場面](skill-eisei.html)**にも整理しています。**

## 書き方の例

**悪い例**

> 人事課で、給与と福利厚生を担当しました。

**良い例**

> ◯◯課において、**職員約◯名の給与の計算と支給の事務**を担当。**勤怠の管理と、時間外の手当の確認**を月次で実施。**共済の資格の取得・喪失の手続を年約◯件処理。**制度改正に伴い、**条例と規則の改正の起案と、職員への周知の資料の作成**を担当。**職員からの照会に年約◯件対応し、制度の内容を説明。**

**「対象の人数」「工程」「件数」「規程の改正」「説明」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

:::insight
人事・給与の経験について、**面談でお伝えしているのが「制度が違うことを、先に自分から言ってください」**という点です。**公務員の人事や給与は、条例と規則に基づきます。**民間は、**法律と就業規則**です。**この違いを踏まえずに「同じことをしていました」と説明すると、話が噛み合いません。**一方、**違いを認識したうえで、共通する動作を述べれば、伝わります。**「根拠が条例か就業規則かは異なりますが、根拠に沿って処理し、記録を残し、対象者に説明するという流れは同じだと理解しています」。**この一言があると、適応の見通しが伝わります。**そして、**条例や規則の改正に関わった経験**は、**規程を作る側の経験**として評価されます。**民間でも、就業規則の改定は同じ作業**です。**違いを隠さず、共通点を示してください。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 資格の位置づけ

| 状況 | 扱い |
|---|---|
| ① 社会保険労務士の業務を行う | **登録が前提になります** |
| ② 応募条件に記載がある | 満たす材料になる |
| ③ 人事・労務の実務 | **経験のほうが具体な場合も** |
| ④ 民間の制度を学びたい | 体系的に学べます |
| ⑤ 目的が曖昧 | 優先順位を下げてください |

**④が、この資格では効きます。**

**公務員の制度しか知らない状態から、民間の制度を体系的に学べる**ためです。

**面接でも、「制度の違いを学んでいる」と説明できます。**

**なお、取れば転職できる、という関係にはありません。**

**何を処理し、どう説明したか**が、評価の対象です。

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 実績の整理 | **対象の人数、件数、担当した制度** |
| 規程の整理 | 改正に関わったもの |
| 要件の確認 | 所管の公表を確認 |
| 求人を読む | 週に30分 |

**1行目です。**

**人事の記録や統計から、対象の人数を確認**してください。

**根拠のない数は書かないでください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 担当した規模 | **職員数、件数** |
| 制度の違いの理解 | **公務員と民間の差** |
| 規程の改正 | 関わった内容 |
| 照会への対応 | 難しかった場面 |
| 正確さの担保 | 確認の手順 |

**2行目です。**

**違いを説明できると、適応の見通しが伝わります。**

**なお、特定の職員が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

## 確認の手順という材料

**人事や給与の事務では、確認の工程が成果物になります。**

| 工程 | 内容 |
|---|---|
| ① 根拠の確認 | **条例・規則のどこによるか** |
| ② 入力の確認 | 勤怠、手当の要件 |
| ③ 計算の確認 | 前月との差、異常値 |
| ④ 相互の点検 | 複数名での確認 |
| ⑤ 記録 | 確認した事実を残す |

**③と④が、誤りを防ぐ中心**です。

**③について。**

**前月と比べて差が大きい項目を抽出し、理由を確認する**という手順です。

**この方法は、制度が変わっても使えます。**

**書類には、「支給の前に前月との差を確認する手順を整備」**と書いてください。

**④について。**

**複数名での点検の運用を作った**という事実があれば、併せて書いてください。

## よくある失敗

**1. 「同じことをしていた」と言う**

**制度の違い**を先に述べてください。

**2. 対象の人数を書かない**

**規模**が伝わりません。

**3. 規程の改正を書かない**

**規程を作る側**の経験です。

**4. 照会への対応を書かない**

**制度の説明**は材料です。

**5. 確認の手順を書かない**

**正確さの担保**として読まれます。

**6. 自治体が相手の事業を見ない**

**公務員の制度の理解**が求められます。

**7. 要件を人づてで判断する**

**所管の公表**を確認してください。

**8. 取れば転職できると考える**

**何を処理し説明したか**が評価の対象です。

:::insight
ここまで違いの話をしておいて逆のことを言いますが、**違いがあることは、不利ではありません。**面談で拝見していると、**「民間の制度を知らないので、通らないのでは」と考える方**がいらっしゃいます。ところが、**人事や給与の実務で最も重視されるのは、正確さ**です。支給の誤り、届出の漏れ、期限の遅れ。**これらは、金額と信用に直結します。**そして、**行政では、条例と規則に沿って処理し、監査を受けることが前提**になっています。**確認の工程が習慣として身についている。****この習慣は、制度が変わっても持ち込めます。**書類には、**「支給の前に◯重の確認を行う手順を整備」「届出の期限を一覧で管理」**と書いてください。**制度の知識は入社後に覚えられますが、確認の習慣はすぐには身につきません。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **社会保険労務士法第2条第1項**は、**労働及び社会保険に関する法令に基づく申請書等の作成**などを業務としています
- **公務員の制度は、民間の制度と異なる部分があります。**違いを先に押さえてください
- **根拠に沿って処理し、記録を残し、対象者に説明する**という動作は共通します
- 効くのは、**人事・労務の部門、給与の計算の事業、事務の受託、自治体が相手の事業、相談・窓口**です
- **条例や規則の改正に関わった経験**は、規程の整備の業務と重なります
- **違いを隠さず、共通点を示して**ください
- **確認の習慣は、制度が変わっても持ち込めます**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 民間の保険や年金の制度を知りません

**入社後に覚える部分です。**ただし、**面接では「違いを理解している」ことを示してください。**「共済の制度を扱ってきたため、健康保険や厚生年金の制度は改めて学ぶ必要があると考えています」という形です。**知らないことを認めたうえで、学ぶ姿勢を示す**ほうが、**「同じです」と言うより信用されます。**なお、**体系的に学ぶ手段として、資格の学習を使う**こともできます。扱いは本文の「資格の位置づけ」④に整理しています。**応募の時期が近い場合は、書類の作成を優先**してください。

### 給与の計算は委託していました

**確認する側の経験で書いてください。**「給与の計算を委託し、支給の前に内容を確認する手順を担当」という形です。**何を確認したか**を書くと、実務の水準が伝わります。支給の額、控除、手当の要件、勤怠との突き合わせ。**確認の観点は、計算を自分で行わなくても身についています。**また、**制度改正に伴う仕様の変更の確認**に関わっていた場合、それも材料です。扱いは[契約書の読み方｜自治体の契約実務との差](skill-keiyakusho.html)にも整理しています。

### 人事課の経験は、どの職種につながりますか

**人事、労務、給与、総務の部門**です。また、**事務の受託を行う会社**では、**自治体の人事や給与の事務を受託する**場合があり、**公務員の制度を知っている人**が必要とされます。さらに、**採用の支援**の分野では、**募集や選考の運営の経験**が使えます。判断の目安は、**求人票の仕事内容の欄**です。「制度の運用」「手続」「規程の整備」「相談の対応」といった言葉があれば、**経験が接続します。**読み方は[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。
