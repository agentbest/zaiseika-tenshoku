**課長、部長、次長。**

**組織を預かる立場からの転職**です。

**担ってきた範囲が広いぶん、書類にまとめにくい**という相談を伺います。

この記事では、**所管の範囲の示し方**と、**求人の選び方**を扱います。

## 所管した範囲は、条例で確認できます

**地方自治法第158条第1項**です。

> **普通地方公共団体の長は、その権限に属する事務を分掌させるため、必要な内部組織を設けることができる。**この場合において、当該普通地方公共団体の長の**直近下位の内部組織の設置及びその分掌する事務については、条例で定める**ものとする。

**組織と、その組織が分掌する事務が、条例で定められている**という仕組みです。

**部の分掌は条例、課や係の分掌は規則で定められている**のが一般的です。

**つまり、自分が所管していた事務の範囲は、文書で確認できる**ということです。

**分掌の規定を読み返して、所管した事務を書き出してください。**

**「課長でした」ではなく、「◯◯に関する事務を所管していた」**という形になります。

## 管理職が担っていること

| 項目 | 内容 |
|---|---|
| ① 組織の運営 | **人数、係の数、業務の範囲** |
| ② 予算 | 編成、執行の管理、決算 |
| ③ 人事 | 配置、評価、育成 |
| ④ 議会 | 説明、答弁、資料 |
| ⑤ 対外 | 住民、事業者、他団体、報道 |
| ⑥ 危機の対応 | 事故、災害、苦情、不祥事 |
| ⑦ 制度の設計 | 条例・規則・要綱の立案 |

**⑥と⑦が、民間で読まれにくい**項目です。

**書いておいてください。**

**危機の対応は、どの業界でも必要とされます。**

## 書き方の例

**悪い例**

> ◯◯課長として、課の運営に当たりました。

**良い例**

> ◯◯課長として、**係◯つ・職員◯人の組織を所管。**◯◯に関する事務を分掌し、**年間約◯億円の予算の編成と執行の管理**を担当。**議会における説明と答弁の調整**、**◯◯に係る条例の改正の立案**を担った。**苦情の申出が集中した事案について、対応の方針を整理し、記録の様式と対応の手順を整備。**

**「人数」「予算」「分掌」「作ったもの」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 言い換えの対応

| 役所の言葉 | 民間での読まれ方 |
|---|---|
| 課の所管 | **部門の統括** |
| 予算の編成 | 予算の策定、資源の配分 |
| 執行の管理 | 予算の管理、原価の管理 |
| 議会への答弁 | 経営層・社外への説明 |
| 条例の立案 | 制度の設計、規程の整備 |
| 不祥事への対応 | 危機の対応、再発の防止 |
| 監査への対応 | 内部統制、是正の対応 |

**4行目です。**

**議会での説明は、事前の想定と、その場での応答の両方を含みます。**

**この経験は、民間の経営層への報告や、社外への説明に対応します。**

## 求人の選び方

| 種類 | 内容 |
|---|---|
| ① 管理部門 | 総務、人事、経営の企画 |
| ② 事業の責任者 | 部門の運営を担う |
| ③ 行政が相手の事業の責任者 | **受託・指定の事業の統括** |
| ④ 専門の職種 | 経験のある分野での実務 |
| ⑤ 制度・渉外 | 公共政策、渉外、渉外の窓口 |

**③が、経験と最も重なります。**

**指定管理や業務の受託では、発注した側の考え方を理解している人が求められます。**

**予算の年度、議会の時期、報告の様式。**

**これらを知っていること自体が、業務の前提になります。**

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 何人を、どう動かしたか | **人数、配分の方法、育成** |
| どこまで自分で決めたか | 所管の範囲、決裁の区分 |
| 難しい局面の対応 | 3件、経緯と結論 |
| 数字の管理 | 予算の規模と管理の方法 |
| 役割が変わることへの受け止め | **入社時の役割の考え方** |

**5行目が確認される**ことがあります。

**前職より狭い範囲での採用になる場合**があるためです。

**担いたい範囲があるなら、条件として伝えて差し支えありません。**

**なお、特定の事案が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**扱いは[口コミサイトとの付き合い方](senko-sagasu-kuchikomi.html)に整理しています。

:::insight
管理職のご相談で、**面談でお伝えしているのが「所管の広さより、決めた場面を書いてください」**という点です。管理職の職務経歴書は、**所管した事務を並べると、それだけで紙面が埋まります。**ところが、**読む側が知りたいのは、その範囲の中で何を決めたか**です。予算の配分をどう決めたか。人の配置をどう決めたか。前例のない事案で、どの根拠を用いて結論を出したか。**この3つは、どの業界の管理の仕事にも共通します。**そして、**役所の管理職は、決めた記録が残っている**という利点があります。決裁の文書、議会の答弁、要綱の改正。**これらは、自分が何をどう判断したかの記録**です。書類に書くときは、**所管の一覧を先に置き、その後に「決めた場面」を3つ置いてください。**一覧だけでは、範囲は伝わっても判断は伝わりません。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 準備の順序

| 順 | やること |
|---|---|
| 1 | **分掌の規定を確認する**（条例・規則） |
| 2 | 人数、係の数、予算の規模を確認する |
| 3 | 決裁の区分を確認する |
| 4 | 決めた場面を3つ書き出す |
| 5 | 民間の言葉に置き換える |
| 6 | 求人を読む |

**1と4が、この立場ならではの作業**です。

**4について。**

**「難しかった」と感じた案件を3つ思い出してください。**

**何が難しく、どう整理し、どう結論づけたか。**

**これが、面接で話す材料になります。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 在職中の進め方

| 項目 | 内容 |
|---|---|
| 資料の確認 | 分掌の規定、決裁の区分、予算の資料 |
| 記録 | 決めた場面を書き留める |
| 求人を読む | 週に30分 |
| 日程の確保 | **議会・予算・決算の時期を避ける** |

**4行目です。**

**管理職は、議会と予算の時期に時間が取れません。**

**選考の開始を、繁忙期と重ならないように選んでください。**

**扱いは**[選考スケジュールの組み方](senko-sagasu-schedule.html)**に整理しています。**

## 処遇と役割の考え方

| 項目 | 確認すること |
|---|---|
| 入社時の役割 | **求人票の仕事内容** |
| 処遇の構成 | 基本給と手当の内訳 |
| 決裁の範囲 | どこまで任されるか |
| 中長期の展開 | 面接で確認できます |

**1行目です。**

**入社時の役割は、求人票に書かれた内容で決まります。**

**面接での印象で変わるものではありません。**

**求人票の仕事内容を、先に確認**してください。読み方は[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。

## よくある失敗

**1. 所管の一覧だけを書く**

**決めた場面**を3つ置いてください。

**2. 分掌の規定を確認しない**

**範囲が文書で確認できます。**

**3. 危機の対応を書かない**

**どの業界でも必要**とされます。

**4. 条例・要綱の立案を書かない**

**制度の設計**として読まれます。

**5. 議会対応を書かない**

**経営層への説明**に対応します。

**6. 管理の職種だけを探す**

**専門の職種**も候補です。

**7. 議会・予算の時期に選考を始める**

**途中で止まります。**

**8. 入社時の役割を求人票で確認しない**

**書かれた内容で決まります。**

:::insight
ここまで書き方の話をしておいて逆のことを言いますが、**管理職からの転職では、「何を手放せるか」を先に決めてください。**面談で拝見していると、**所管の広さ、決裁の権限、組織の規模を、そのまま持ち越そうとする方**がいらっしゃいます。ところが、**役所の課長と、民間の同じ名称の職位では、範囲が違います。**そして、**入社した直後から同じ範囲を任されることは、多くありません。**業務を覚える期間が必要だからです。ですから、**優先順位を決めてください。**決裁の範囲なのか、扱う分野なのか、人を育てる役割なのか、勤務の条件なのか。**すべてを満たす求人はまれ**です。**1つを軸にすると、候補が残ります。**そして、**手放してもよいものが決まっていると、面接での答え方も変わります。**「役割については、必要とされる範囲で担います。ただし、◯◯の分野に関わることは希望しています」。**この形なら、条件が伝わります。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **地方自治法第158条第1項**は、**内部組織の設置と、直近下位の内部組織の分掌する事務を条例で定める**としています。**所管した範囲は文書で確認できます**
- 書くのは、**人数・予算・分掌・作ったもの**です
- **危機の対応と、条例・要綱の立案**を書いてください
- **所管の一覧の後に、「決めた場面」を3つ**置いてください
- **議会での説明**は、経営層・社外への説明に対応します
- **行政が相手の事業の責任者**が、経験と最も重なります
- **何を手放せるかを先に決めて**ください。1つを軸にすると候補が残ります

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 管理職の求人は、どこにありますか

**掲載されていない募集が多い領域**です。組織の体制に関わるため、**公開を控える**ことがあります。このため、**紹介を通じて示される**形が中心になります。扱いは[非公開求人とは何か](senko-sagasu-hikoukai.html)に整理しています。一方、**掲載されている求人もあります。**探すときは、**「管理」「マネージャー」で絞るのではなく、仕事内容の欄**を見てください。「部門の統括」「事業の責任者」「立ち上げ」といった記載があれば該当します。なお、**行政が相手の事業では、受託や指定が決まった後に責任者の募集が出る**ことがあります。時期は事業の周期によります。

### 部下を持たない役割でも、応募してよいですか

**差し支えありません。**管理職の経験を持つ方が、**専門の職種で採用される**ことは珍しくありません。制度の理解、判断の経験、対外の説明。**これらは、人を持たない役割でも使えます。**とくに、**行政が相手の事業では、実務の中核を担う人が求められる**ことがあります。判断の目安は、**求人票の応募条件**です。「マネジメントの経験」が必須でなければ、**専門の経験で応募できます。**なお、**役割が変わることへの受け止めを聞かれる**ことがあります。**担いたい範囲を条件として伝えて**差し支えありません。

### 在職中に、選考の時間が取れません

**時期を選んでください。**管理職は、議会・予算・決算の時期に時間が取りにくくなります。**空いている期間が2か月以上あるところから始める**と、途中で止まりません。また、**オンラインでの実施**が可能な会社もあります。**面接の時間帯についても、相談の対象**になります。なお、**紹介を通す場合、日程の調整を任せられます。**在職中の事情を伝えておけば、**調整が可能な先を優先して示す**こともできます。扱いは[転職エージェントの使い方](senko-sagasu-agent.html)に整理しています。**準備（分掌の確認、記録の整理）は、繁忙期でも進められます。**
