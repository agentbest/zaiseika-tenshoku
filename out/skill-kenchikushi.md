**建築の指導や営繕を担当してきた方から、「資格をどう組み合わせるか」**というご相談を伺います。

**確認する側と、発注する側では、書く内容が変わります。**

この記事では、**その違い**を扱います。

**⚠ 免許の要件と手続は、所管するところの公表を確認してください。****この記事では、個別の要件には触れません。**

## 確認を受けることが、建築主の義務です

**建築基準法第6条第1項**です。

> **建築主は、第一号若しくは第二号に掲げる建築物を建築しようとする場合**（略）、**これらの建築物の大規模の修繕**（略）**をしようとする場合においては、当該工事に着手する前に、その計画が建築基準関係規定**（略）**に適合するものであることについて、確認の申請書を提出して建築主事等の確認を受け、確認済証の交付を受けなければならない。**

**着手の前に、計画が規定に適合することの確認を受ける**という仕組みです。

**建築の指導の担当は、この確認を行う側**にあります。

**そして、営繕の担当は、確認を受ける側（建築主の側）**にあります。

**同じ分野でも、立場が逆**です。

**書類では、この立場を明記**してください。

## 立場による違い

| 項目 | 建築指導 | 営繕 |
|---|---|---|
| 立場 | **確認・審査する側** | **発注・建築主の側** |
| 中心の動作 | 規定への適合の確認 | 設計・工事の発注と管理 |
| 相手 | 申請者、設計者 | 設計者、施工者 |
| 成果 | 確認、是正の指導 | 完成した建物 |
| 民間での近い職 | 審査、法令の確認 | 発注者支援、施設の管理 |

**この違いを踏まえて、応募先を選んでください。**

**どちらの経験も使えますが、**求人が求めているのは**どちらか一方**であることがあります。

## どの転職先で効くか

| 領域 | 使いどころ |
|---|---|
| ① 審査・確認の事業 | **建築指導の経験** |
| ② 設計事務所 | 設計、監理 |
| ③ 発注者支援 | 営繕の経験 |
| ④ 施設の管理・保全 | 改修、点検の計画 |
| ⑤ 不動産・開発 | 法令の確認、調査 |

**①と⑤について。**

**規定への適合を確認してきた経験**は、**法令の確認が必要な場面で使えます。**

**開発や取得の際に、建物が規定に適合しているかを確認する業務**があります。

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 行政での経験との接続

| 経験 | 民間での読まれ方 |
|---|---|
| ① 確認・審査 | **基準に照らした判断** |
| ② 是正の指導 | 改善の要求、是正の管理 |
| ③ 相談への対応 | 計画の初期の相談 |
| ④ 設計の発注と確認 | 仕様、成果の確認 |
| ⑤ 工事の監督と検査 | 工程、品質、出来形 |
| ⑥ 保全の計画 | 中長期の計画、予算 |

**③が見落とされやすい**です。

**計画の初期の段階で、規定との関係を整理して助言した経験**です。

**この動作は、設計や開発の側でも必要とされます。**

## 書き方の例

**悪い例**

> 建築指導課で、確認申請の審査をしていました。

**良い例**

> ◯◯課において、**建築の確認に関する事務を担当。**年間約◯件の申請について、**建築基準関係規定への適合を確認し、是正が必要な事案について指導を実施。**計画の初期の段階での**相談に年約◯件対応し、規定との関係を整理して助言。**違反の事案について、**経緯を整理し、是正の状況を記録。**

**「件数」「確認の動作」「相談」「記録」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

:::insight
建築の分野について、**面談でお伝えしているのが「立場を最初の1行に書いてください」**という点です。同じ「建築」でも、**確認する側と、発注する側では、求人の種類が違います。**建築指導の経験は、**審査、法令の確認、調査**の業務につながります。営繕の経験は、**発注者支援、施設の管理、保全の計画**につながります。**ところが、書類に「建築課」とだけ書かれていると、どちらか分かりません。**読む側は、**求人に合うかどうかを判断できません。**ですから、冒頭に、**「建築の確認に関する事務を担当」または「営繕の担当として、設計と工事の発注を担当」**と書いてください。**その1行で、読む側が照らし合わせられます。**そして、**両方を経験している場合は、両方を分けて書く。**期間と件数を添えれば、厚みが伝わります。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 資格の位置づけ

| 状況 | 扱い |
|---|---|
| ① 設計又は工事監理を業とする | **免許が前提になります** |
| ② 応募条件に記載がある | 満たす材料になる |
| ③ 審査・確認の業務 | **経験と併せて評価されます** |
| ④ 発注者支援・管理 | 経験のほうが具体な場合も |
| ⑤ 目的が曖昧 | 優先順位を下げてください |

**①について。**

**⚠ 設計や工事監理を業として行うことができる範囲は、法令で定められています。**

**要件と範囲は、所管の公表を確認**してください。

**なお、取れば転職できる、という関係にはありません。**

**何を確認し、どう判断したか**が、評価の対象です。

## 在職中にできること

| 項目 | 内容 |
|---|---|
| 実績の整理 | **件数、用途、規模** |
| 立場の整理 | 確認する側か、発注する側か |
| 要件の確認 | 所管の公表を確認 |
| 証明の書類の準備 | 所属での手続 |

**4行目を早めに**してください。

**在職中のほうが、手続が簡単**です。

**根拠のない数は書かないでください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 担当した業務 | **立場、件数、用途** |
| 判断が難しかった事案 | 3件、経緯と結論 |
| 相談への対応 | 助言の進め方 |
| 是正の指導 | 手順と結果 |
| 立場 | **確認側か、発注側か** |

**2行目です。**

**規定の解釈が分かれる事案を、どう整理したか**を用意しておいてください。

**なお、特定の物件や申請者が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

## 確認の観点という材料

**審査や検査で見てきた項目は、そのまま書ける材料になります。**

| 観点 | 内容 |
|---|---|
| ① 用途・規模 | **規定の適用の区分** |
| ② 敷地の条件 | 接道、区域、制限 |
| ③ 構造 | 安全に関する基準 |
| ④ 設備 | 避難、消防に関する事項 |
| ⑤ 添付の書類 | 揃い、整合 |

**⑤が、事務の比重が高い部分**です。

**書類の揃いと整合を確認してきた経験**は、**申請する側で「何を出せばよいか」を知っていることになります。**

**設計や開発の会社では、この理解が手戻りを減らします。**

**なお、⚠ 具体の基準や適用の判断は、法令と所管の公表を確認**してください。

**この記事では、構造の説明にとどめます。**

## よくある失敗

**1. 立場を書かない**

**確認する側か発注する側か**を最初に書いてください。

**2. 件数と用途を書かない**

**規模**が伝わりません。

**3. 相談への対応を書かない**

**設計や開発の側でも必要**とされます。

**4. 是正の指導を書かない**

**改善の要求・是正の管理**として読まれます。

**5. 両方の経験を混ぜる**

**分けて書いて**ください。

**6. 免許の範囲を確認しない**

**業として行える範囲**が定められています。

**7. 要件を人づてで判断する**

**所管の公表**を確認してください。

**8. 取れば転職できると考える**

**何を確認しどう判断したか**が評価の対象です。

:::insight
ここまで立場の話をしておいて逆のことを言いますが、**両方を経験していることは、強みになります。**面談で拝見していると、**指導と営繕の両方を経験している方**がいらっしゃいます。**確認する側と、確認を受ける側の両方を知っている。**この組み合わせは、民間では得にくいものです。設計や開発の会社では、**「どこで止まるか」を先に読める人**が求められます。確認の段階で何を聞かれるか、どの資料が必要になるか、どの解釈が分かれるか。**これは、審査した経験がないと分かりません。**一方、**発注の実務を知っていると、工程と費用の見通しが立ちます。**ですから、**両方を経験している場合は、分けて書いたうえで、「両方の立場を経験」と一言添えてください。**読む側が、**その価値に気づきます。**在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **建築基準法第6条**は、**工事に着手する前に、計画が建築基準関係規定に適合することについて確認を受け、確認済証の交付を受けなければならない**としています
- **建築指導は確認する側、営繕は確認を受ける側**です。**立場を最初の1行に書いて**ください
- 効くのは、**審査・確認の事業、設計事務所、発注者支援、施設の管理・保全、不動産・開発**です
- **計画の初期の相談に応じた経験**は、設計や開発の側でも必要とされます
- **設計又は工事監理を業とする範囲は、法令で定められています。**所管の公表を確認してください
- **証明の書類の準備は、在職中に**済ませてください
- **両方の立場を経験していることは、強みになります**

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 事務職として建築の部署にいました

**書けます。**技術職でなくても、**申請の受付、手数料の収納、台帳の管理、統計の作成、工事の契約の手続**に関わっていれば、材料になります。書き方は、**「建築の確認に関する事務のうち、申請の受付から確認済証の交付までの手続と、台帳の管理を担当」**という形です。**技術的な審査を担っていない場合は、そう書いてください。**「技術的な審査は担当職員が実施し、手続と記録の管理を担当」。**できる範囲を正確に書く**ほうが、入社後に困りません。

### 違反の事案への対応は、どう書けばよいですか

**手順で書いてください。**「違反の疑いのある事案について、現地の確認、関係者からの聴取、法令との照合を行い、是正の方針を整理。是正の状況を確認し、経緯を記録」という形です。**事案の詳細は書かないでください。**物件、所在、関係者が分かる記述は避けてください。**類型で書く**ほうが安全です。なお、**面接でも「守秘の義務があるため、個別の事案には触れられませんが」と前置きすれば、手順の説明はできます。**扱いは[警察官から民間へ](senko-tachiba-keisatsu.html)に整理した考え方と同じです。

### 免許を持っていませんが、応募できますか

**求人によります。**設計や工事監理を業とする職では、**免許が前提**になります。一方、**発注者支援、施設の管理、法令の確認、調査**の業務では、**免許が必須でない求人**があります。判断の目安は、**求人票の「必須」の欄**です。なお、**行政での確認や営繕の経験が要件として挙げられる**ことがあります。この場合、**経験が直接評価されます。**読み方は[求人票の読み方｜どこを見れば実態が分かるか](senko-sagasu-kyujinhyo.html)に整理しています。**免許の有無で、候補を狭めないでください。**
