人事課から転職しようとすると、少し妙なことが起きます。

**人事の仕事をしてきたのに、人事の求人票を読んで戸惑う。**

書かれている言葉が違うからです。等級、報酬設計、タレントマネジメント、要員計画。庁内では使わない言い方ばかりが並びます。

ただし、**やっていることはかなりの部分が重なっています。**言葉が違うだけです。

この記事では、人事課の仕事を分解して、それぞれが求人票でどう書かれているかを並べます。訳語が分かれば、検索する言葉も応募先の選び方も変わります。

## 「能力の実証」と「職務と責任」――2つの原則

先に、この部署の立ち位置を条文で押さえます。ここが、民間に説明するときのいちばんの材料になります。

**1つ目は、人を動かすときの原則です。**

地方公務員法第15条は、**職員の任用は、この法律の定めるところにより、受験成績、人事評価その他の能力の実証に基づいて行わなければならない**と定めています。

任用というのは、採用も昇任も配置も含みます。**そのすべてに「能力の実証」が要る**ということです。

好き嫌いでも、年功でも、人手が足りないからでもありません。**根拠を示せなければ、人を動かせない。**

**2つ目は、給与の原則です。**

第24条第1項は、**職員の給与は、その職務と責任に応ずるものでなければならない**としています。第2項では、生計費、国や他の地方公共団体の職員、民間事業の従事者の給与その他の事情を考慮して定められなければならない、と続きます。

**人に対してではなく、職務と責任に対して払う。**

民間でいえば、**職務給の考え方**です。そして第2項は、水準を決めるときに外部と比べることを求めています。

この2つの原則は、民間の人事制度の中心にある考え方と同じです。**等級をどう定義し、何を根拠に上げ、いくら払うか。**人事課は、これを法律に基づいて運用してきたことになります。

## 人事課が実際にやっていること

自治体によって所管の範囲は違いますが、おおむね次の仕事が入ります。

- 採用試験の設計と実施（募集、試験、面接、合格発表、採用）
- 任用（昇任、配置、異動、人事異動の内示）
- 給与（給料表の管理、諸手当の認定、期末・勤勉手当の計算）
- 人事評価（制度の設計、評価者の研修、結果の活用）
- 勤務条件（勤務時間、休暇、時間外の管理と縮減）
- 育児休業、介護休暇、両立支援の制度運用
- 分限・懲戒の手続
- 研修（階層別、専門分野、派遣）
- 定数管理、組織機構の見直し
- 職員団体との交渉
- 健康管理、ハラスメントの相談窓口
- 会計年度任用職員の任用と処遇

**採用から評価、給与、労務、研修までが1つの課に入っている**のが特徴です。民間では、これらが別々のチームに分かれていることが普通です。

範囲が広いぶん、**どの領域も一通り分かる**という強みがあります。一方で、**1つの領域だけを深く掘った経験にはなりにくい**という面もあります。書類を作るときは、この両方を意識してください。

## 庁内の言葉と、求人票の言葉の対応

| 庁内での言い方 | 求人票での言い方 |
|---|---|
| 採用試験の設計と実施 | 採用計画、選考設計、新卒採用、中途採用 |
| 募集、説明会、広報 | 採用広報、リクルーティング |
| 昇任・配置・異動 | 要員配置、人材配置、人事異動の企画 |
| 定数管理 | 要員計画、人員計画 |
| 給料表の管理 | 給与制度の運用、報酬設計、等級制度 |
| 諸手当の認定 | 手当の審査、給与計算の管理 |
| 人事評価制度の設計 | 評価制度の設計、目標管理 |
| 評価者研修 | 管理職研修、評価者トレーニング |
| 勤務時間・休暇の管理 | 労務管理、勤怠管理 |
| 時間外の縮減 | 働き方改革、労務管理 |
| 育児休業・介護休暇の運用 | 両立支援、福利厚生 |
| 分限・懲戒の手続 | 労務対応、就業規則の運用 |
| 研修の企画・運営 | 人材開発、教育研修、育成企画 |
| 職員団体との交渉 | 労使交渉、労務 |
| ハラスメントの相談窓口 | 相談窓口の運営、内部通報 |
| 会計年度任用職員の任用 | 有期雇用の管理、契約社員の人事 |
| 組織機構の見直し | 組織設計、組織開発 |

並べると、**人事の主要な領域をほぼ網羅している**ことが分かります。民間の人事担当者でも、採用から評価、給与、労務までを通しで見ている人は多くありません。

:::insight
人事課の方の書類で、いちばんもったいないのが**「人事全般を担当」と書いてしまうこと**です。範囲の広さは強みなのですが、この書き方だと**何ができる人か分かりません。**求人票は領域ごとに分かれていて、採用の求人と労務の求人では読まれる経験が違います。**先に応募先の領域を決めて、その領域の経験を先頭に置いてください。**そのうえで「加えて、採用から給与、労務まで通しで担当していた」と添えると、範囲の広さが効いてきます。順番が逆だと、広く浅い人に見えます。検索する語も「人事」だけでなく、**「採用」「労務」「人事制度」「人材開発」**に分けて探してください。
:::

## 民間の人事と、どこが同じでどこが違うか

訳語の対応だけでは伝わりにくいので、**同じところと違うところ**を並べておきます。面接でそのまま使えます。

**同じところ**

- 採用の枠を決め、選考し、配属する
- 等級や号給の体系を持ち、上げる基準を定めている
- 評価の制度を作り、評価者を訓練し、結果を処遇に反映する
- 勤務時間と休暇を管理し、時間外を抑える
- 問題行動への手続を持ち、相談の窓口を置く
- 研修を階層別に組み、受講の記録を残す

**違うところ**

- **制度を変えるのに条例や規則の改正が要る**（要綱だけでは動かせない範囲がある）
- **給与の水準に、外部との比較が制度として組み込まれている**（第24条第2項）
- **解雇に相当する手続の要件が厳格**（分限は法定の事由に限られる）
- **労働基準法の適用範囲に差がある**（争議行為や労働協約の扱いが違う）
- **採用が試験によることを原則とする**（能力の実証が法律で求められている）

この5つのうち、面接でいちばん効くのは**1つ目**です。民間でも制度変更には合意や周知が要りますが、**議会の議決という外部の手続まで通した経験**は多くありません。

**「制度を変えるのに、外部の手続まで通してきた」**という説明は、人事制度の改定を控えている企業には強く響きます。

## この経験がとくに高く評価される場所

### 1. 事業会社の人事部門

いちばん自然な接続先です。ただし、**領域によって求められるものが違います。**

**制度設計**の求人では、給料表の管理と人事評価制度の設計が効きます。**「等級をどう定義し、何を根拠に上げ、いくら払うか」を制度として運用してきた経験**は、そのまま使えます。地方公務員法第24条が「職務と責任に応ずる」と定めているので、職務給の考え方には最初から馴染んでいます。

**労務**の求人では、勤務時間の管理、時間外の縮減、分限・懲戒の手続、職員団体との交渉が効きます。**とくに、労使の交渉を経験している人は民間でも多くありません。**

**採用**の求人では、試験の設計と実施が効きます。**大量の応募者を、決まった基準で公正に選考してきた経験**は、新卒採用の領域で直接使えます。

### 2. 人材サービス

人材紹介、採用支援、研修を扱う会社です。

採用の設計や研修の企画をしてきた経験が使えます。とくに、**自治体の採用を支援する事業**を持つ企業では、試験の仕組みや日程を知っていること自体が値になります。

[行政が相手の求人を見てみる](../?gov=1)

### 3. 自治体を顧客にする企業

人事給与システム、研修サービス、採用支援の会社です。

**給与計算の複雑さ、手当の種類、評価制度の運用の実態**を知っていることが効きます。人事給与システムは制度の細部に左右されるため、外から見ただけでは分からない部分が多くあります。

とくに、**手当の認定をしてきた経験**は希少です。住居、通勤、扶養、単身赴任。それぞれに要件があり、証明書類があり、変更のたびに認定し直します。**この細かさを知らずに作られたシステムは、現場で使われません。**

### 4. 組織開発・人材開発

研修の企画と運営、評価者研修、階層別の育成を担当していた方の接続先です。

企業側では、人材開発、組織開発、育成企画といった職種になります。

ここで効くのは、**受講を「させる」側の設計をしてきたこと**です。企業の研修は希望者を募る形が多いのに対し、自治体は階層別に対象者を決めて全員に受けさせます。**対象者の選び方、日程の組み方、受講できない人への手当て**まで設計してきた経験は、全社研修を組む場面で直接使えます。

ただし、この方向は**求人の数が限られます。**方向1（人事部門）と並行して見ておくのが現実的です。

## 職務経歴書でつまずきやすい点

**1. 「人事全般」で止める**

上の見解に書いたとおりです。**領域を選んで先頭に置いてください。**

**2. 規模を書かない**

**職員数、採用した人数、応募者数、評価の対象人数、研修の受講者数。**規模が伝わる数字を必ず入れてください。

**3. 制度を作った話を書かない**

運用した話は書かれていても、**制度そのものを変えた話が書かれていない**ことが多くあります。評価制度の改定、手当の見直し、勤務時間の制度の導入。**設計した経験は、運用した経験より強く読まれます。**

**4. 交渉の話を落とす**

職員団体との交渉は、民間でいう労使交渉です。**経験がある人は多くないので、必ず書いてください。**ただし、**個別の交渉の中身は書かないでください。**「何について、どういう手順で協議し、どう決着させたか」の形で書きます。

**5. 個人が特定できる書き方をする**

分限・懲戒や相談対応は、扱いに注意が要ります。**事案の詳細ではなく、手続と判断の構造で書いてください。**

自分の経歴がどう言い換えられるかは、一度話しながら整理したほうが早いことが多いです。[どの経験に値が付くのかから相談できます](../apply.html)。

:::insight
ここまで書いておいて逆のことを言いますが、**人事課にいるうちに動かないほうがよい場合もあります。**とくに、**制度の改定に関わる機会が近い段階**です。人事評価制度の改定、給与制度の見直し、会計年度任用職員の処遇の変更。**この種の仕事は数年に一度しか来ませんが、通すと書けることが大きく変わります。**運用だけを担当していた人と、制度を設計した人では、民間での読まれ方が違います。もう一つ、**人事課は庁内の全部署を見る部署**です。ここで得た全体像は、庁内に残る場合でも外に出る場合でも効きます。異動の希望が出せる時期なら、そちらを先に確かめるのも十分に理のある判断です。
:::

## まとめ

- 地方公務員法第15条は、**任用を「受験成績、人事評価その他の能力の実証に基づいて」行うこと**を定めています。**根拠を示せなければ人を動かせない**という構造です
- 第24条第1項は、**給与は職務と責任に応ずるもの**としています。民間でいう**職務給**の考え方です
- この2つは、民間の人事制度の中心にある考え方と同じです
- 庁内の「人事」は、求人票では**「採用」「労務」「人事制度」「人材開発」**に分かれています。**検索する言葉を分けるところから始めてください**
- 評価が高くなるのは、**事業会社の人事部門／人材サービス／自治体を顧客にする企業／組織開発・人材開発**の4方向です
- 書類では**「人事全般」と書かない**でください。領域を選んで先頭に置き、範囲の広さは後から添えます

在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。

## よくある質問

### 社会保険労務士の資格は必要ですか

**必須ではありません。**労務の求人で有利に働く場面はありますが、**実務経験のほうが先に読まれます。**とくに、労使の交渉や分限・懲戒の手続を経験しているなら、資格より直接的な材料です。一方、社会保険や労働保険の実務は、**公務員の身分では扱いが違う部分がある**ので、そこは入ってから学ぶ前提になります。**先に方向を決めてから、必要かどうかを判断してください。**

### 公務員の人事は民間と制度が違いすぎませんか

違う部分はありますが、**考え方の骨格は近いです。**地方公務員法第15条の「能力の実証」は民間の評価と昇格の関係に、第24条の「職務と責任に応ずる」は職務給に対応します。**違うのは、制度を変えるときに条例や規則の改正が要ることと、労働基準法の適用範囲に差があること**です。面接では、この違いを自分から正確に説明できると、準備してきた人として読まれます。

### 採用と労務では、どちらが転職しやすいですか

**求人の数でいえば労務のほうが多くなります。**採用は景気や企業の採用計画に左右されやすく、募集の増減が大きい領域です。一方、労務は法改正への対応が常にあるため、需要が安定しています。ただし、**自分が長くやってきた領域を選ぶほうが、書類も面接も組みやすい**のは確かです。方向の選び方は[人事課からの転職先](dept-jinji-tenshokusaki.html)に整理しています。
