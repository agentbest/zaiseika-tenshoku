製造業への転職と聞くと、**現場での仕事を思い浮かべる方が多い**です。

**「ものづくりの経験がないので、無理だと思っていました」**

**その前提が、機会を狭めています。**

**製造業の会社には、工場と同じだけ管理部門があります。**そして、**その管理部門の仕事のかなりの部分が、法令上の義務として発生しています。**

**義務として発生する仕事は、なくなりません。**そして、**その義務の中身は、行政の側から見てきたものと同じ**です。

この記事では、**製造業の管理部門にどんな職種があるか**と、**未経験から入る道筋**を扱います。

## 製造業には、法令上の管理体制が求められています

**製造業の管理部門が、他の業種と違う理由**から説明します。

**労働安全衛生法第10条第1項**です。

> **事業者は、政令で定める規模の事業場ごとに、厚生労働省令で定めるところにより、総括安全衛生管理者を選任し、**その者に安全管理者、衛生管理者又は第二十五条の二第二項の規定により技術的事項を管理する者の指揮をさせるとともに、次の業務を統括管理させなければならない。
>
> 一　**労働者の危険又は健康障害を防止するための措置に関すること。**
>
> 二　**労働者の安全又は衛生のための教育の実施に関すること。**

そして、**同法第11条第1項**です。

> **事業者は、政令で定める業種及び規模の事業場ごとに、厚生労働省令で定める資格を有する者のうちから、厚生労働省令で定めるところにより、安全管理者を選任し、**（中略）**その者に前条第一項各号の業務**（中略）**のうち安全に係る技術的事項を管理させなければならない。**

**第11条に注目してください。****「政令で定める業種」**という限定が付いています。

**衛生管理者の選任が業種を問わず求められるのに対し、安全管理者は業種が限定されています。****製造業は、その対象に含まれます。**

**つまり、製造業の事業場には、安全の管理を担う体制が法令上求められている**ということです。

**この体制を回すのが、管理部門の仕事**です。

## 環境の届出も、管理部門の仕事です

**もう一つ、製造業に固有の義務があります。**

**大気汚染防止法第6条第1項**です。

> **ばい煙を大気中に排出する者は、ばい煙発生施設を設置しようとするときは、環境省令で定めるところにより、次の事項を都道府県知事に届け出なければならない。**
>
> 一　氏名又は名称及び住所並びに法人にあつては、その代表者の氏名
>
> 二　**工場又は事業場の名称及び所在地**
>
> 三　**ばい煙発生施設の種類**
>
> 四　ばい煙発生施設の構造
>
> 五　ばい煙発生施設の使用の方法
>
> 六　**ばい煙の処理の方法**

**「都道府県知事に届け出なければならない」**です。

**この届出を受け取っていた側にいた方**なら、**何が起きているかがすぐ分かるはずです。**

**環境部局で、ばい煙・排水・騒音・振動・廃棄物の届出を扱っていた方**は、**その届出を出す側の実務**を、**すでに半分知っています。**

**水質、廃棄物、化学物質、省エネルギー。**製造業の工場は、**複数の法令の届出と報告の対象**です。**これを担うのが、環境や安全の管理を担当する部署**です。

## 製造業の管理部門には、こんな職種があります

| 職種 | 何をするか | 未経験からの入りやすさ |
|---|---|---|
| 総務 | 施設の管理、社内の規程、株主総会の事務 | **入りやすい** |
| 人事・労務 | 採用、賃金、勤怠、就業規則、安全衛生委員会 | **入りやすい** |
| 経理・財務 | 決算、原価の管理、資金の管理 | **入りやすい** |
| 法務・コンプライアンス | 契約の確認、社内の規程、法令の改正への対応 | **入りやすい** |
| 環境・安全 | **届出、報告、監査への対応、教育** | **経験が直結する** |
| 品質保証 | 規格への適合、監査、苦情への対応 | 分野による |
| 購買・調達 | 仕入れ先の選定、契約、価格の交渉 | 契約の経験が効く |
| 生産管理 | 計画、在庫、納期の管理 | 経験が要る |

**下の3つ以外は、行政の経験から入れます。**

**とくに、環境・安全の担当は、公務員の経験がそのまま需要と重なります。**

## 届出を受ける側から、出す側へ

**この移り方は、実務として自然です。**

| 役所の側 | 工場の側 |
|---|---|
| 届出を受け取り、内容を確認する | **届出の書類を作り、提出する** |
| 基準に適合しているかを見る | 基準に適合させる仕組みを回す |
| 立入検査を行う | **検査を受け、指摘に対応する** |
| 報告を求める | 報告を作成する |
| 改善を指導する | **改善の計画を作り、実行する** |

**左の列をやってきた方は、右の列で何が求められるかが分かります。**

**「どう書けば通るか」を知っている**からです。**様式のどこでつまずくか、添付が足りないと何を言われるか、変更のときにどのタイミングで出すか。**

**これは、外から学ぶのが難しい知識**です。**行政の側にいた期間の長さが、そのまま価値になります。**

## 公務員の経験が効く場所・効きにくい場所

**効く場所**

| 場面 | 効く理由 |
|---|---|
| 環境・安全の届出と報告 | **受け取る側の観点を知っている** |
| 立入検査・監査への対応 | 検査する側にいた |
| 社内の規程・手順の整備 | **要綱を条文の形で書いてきた** |
| 安全衛生委員会の運営 | 審議会・委員会の事務と同じ構造 |
| 契約・購買の事務 | 契約事務と入札の経験 |
| 補助金を使う設備の投資 | **交付する側にいた** |
| 記録を残して説明する | 監査を受ける前提の書類の作り方 |

**効きにくい場所**

| 場面 | 効きにくい理由 |
|---|---|
| 原価の管理 | **予算の執行とは見る方向が違う** |
| 生産の計画と納期の調整 | 現場の感覚が要る |
| 仕入れ先との価格の交渉 | 値決めの判断を自分でする |
| 製品や技術の知識 | 入ってから覚える領域 |
| 現場の作業者との距離の取り方 | **相手の職種が違う** |

**最後の1つは、意外に大きい**です。

**工場では、管理部門と現場の距離の取り方**が、仕事の進み方を決めます。**「本社が言ってきた」と受け取られると、決めたことが回りません。**

**この点は、役所で出先機関や現場の部署と調整してきた方には、掴みやすい**はずです。**本庁と出先の関係に、構造が似ています。**

:::insight
面談で拝見していて、**環境部局や保健所の経験をお持ちの方が、いちばん自分を安く見積もっておられます。**「許認可の事務しかやっていません」とおっしゃる。ところが、**製造業の側から見ると、この経験は探しても見つかりません。**理由は、**工場の環境・安全の担当が、たいてい社内で育てられているから**です。技術系の社員が異動で配属され、**法令を一から読んで覚える**という形が多い。**行政の側の運用を知っている人は、中にいません。**ですから、**「この届出は、どの時点で出す必要があるか」「変更の届出が要るのはどの範囲か」「立入で何を見られるか」を実務として知っている人**が入ってくると、**部署の動き方が変わります。**しかも、この知識は**分野を問わず使えます。**大気の届出を扱っていた方が、水質や廃棄物の届出に当たることになっても、**行政の手続きの構造は同じ**なので、立ち上がりが速い。職務経歴書では、**「許認可の事務」ではなく「◯◯法にもとづく届出の受理と審査、立入検査の実施」**と、**法令名を入れて**書いてください。それだけで、読む側の受け取り方が変わります。
:::

## 入り方の手順

| 順 | やること | 目安 |
|---|---|---|
| 1 | 自分が扱った**法令の名前を書き出す** | 30分 |
| 2 | その法令が**どの業種の工場に関わるか**を確認する | 1時間 |
| 3 | **職種名で求人を検索する**（環境、安全、総務、法務など） | 1時間 |
| 4 | 出てきた会社の**業種と事業所の場所**を確認する | 1時間 |
| 5 | 求人票の**応募条件を5件読み比べる** | 1時間 |
| 6 | 自分の法令の経験と**重なるものを前へ** | 30分 |

**1つ目が、この業界では効きます。**

**扱った法令の名前が、そのまま検索の手がかり**になります。大気汚染防止法、水質汚濁防止法、廃棄物処理法、消防法、毒物及び劇物取締法、高圧ガス保安法。**どれも、工場側に担当者がいます。**

**⚠ 業種を先に決めないでください。**同じ法令でも、**食品、化学、金属、機械と、いろいろな業種の工場が対象**です。**法令から入ると、候補の幅が広がります。**

## 面接で聞かれやすいこと

| 聞かれること | 何を見られているか |
|---|---|
| どの法令を、どの立場で扱っていましたか | **経験の具体性** |
| 立入検査では、何を見ていましたか | **受け入れる側に回れるか** |
| 現場の人と話をした経験はありますか | **工場での立ち位置** |
| 勤務地は、工場でも構いませんか | 前提の確認 |
| 製品や技術の知識がないが、大丈夫ですか | 学ぶ構え |

**2つ目は、この業界での強い持ち札**です。

**答え方は、指摘した話ではなく、見ていた観点**にしてください。「記録が残っているか、実際の運用が届出の内容と一致しているか、変更があったときに手続きが取られているか」。**これは、そのまま工場側の自主点検の観点になります。**

**4つ目は、正直に答えてください。**製造業の管理部門は、**本社にある職種と、工場にある職種**があります。**環境・安全は、工場に置かれることが多い**です。**通勤の前提が変わるので、早い段階で確認してください。**

:::insight
ここまで入り方の話をしてきましたが、**この業界を検討するときに、見ておいていただきたい点**があります。**事業所の場所と、その会社の生産の拠点がどこにあるか**です。製造業は、**工場のある場所でしか成り立たない仕事**があります。ですから、**転居を伴う異動の可能性が、業種によっては高くなります。**一方で、**これは利点にもなります。**役所の勤務地が1つの自治体の中に限られるのに対し、**製造業では、地方の工場に管理部門の職がある**からです。**都市部を離れたい方、出身地の近くで働きたい方**にとっては、**選択肢が広がる業界**です。実際、**工場のある地域では、その工場が地域最大の事業所**ということも珍しくありません。**役所からの転職で、通勤の距離が短くなった**という例も伺います。ですから、**求人を探すときに勤務地を都市部に限定しないでください。**そして、**いま動くかどうかを決めきらないまま、どの地域にどんな工場があるかを見ておく**だけでも意味があります。**この情報は、いま動かなくても消えません。**在職のまま、情報収集だけのご相談も承っています。
:::

## まとめ

- **製造業の会社には、工場と同じだけ管理部門があります。**現場の経験は、必ずしも要りません
- **労働安全衛生法第10条**は**総括安全衛生管理者**、**第11条**は**安全管理者**の選任を義務づけています。**第11条は「政令で定める業種」に限定され、製造業はその対象**です
- **大気汚染防止法第6条第1項**は、**ばい煙発生施設を設置しようとするときの都道府県知事への届出**を義務づけています。**工場は複数の法令の届出の対象**です
- **この届出を受け取っていた側の経験は、出す側でそのまま使えます。**「どう書けば通るか」を知っているからです
- 未経験から入りやすいのは、**総務・人事・経理・法務・環境安全**です。**環境・安全は経験が直結**します
- ⚠ **業種ではなく、自分が扱った法令から探してください。**同じ法令が、食品・化学・金属・機械の工場に関わります
- 効きにくいのは、**原価の管理、生産の計画、価格の交渉、製品の知識、現場との距離の取り方**です
- **勤務地が工場になることがあります。**早い段階で確認してください。**都市部以外に選択肢が広がる**という面もあります

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 事務職です。環境や安全の法令を扱ったことがありません

**総務・人事・経理・法務から探してください。**製造業の管理部門は、**他の業種の管理部門と、仕事の中身が大きく違うわけではありません。**人事であれば採用と労務、経理であれば決算と支払い。**行政での対応する経験が、そのまま材料になります。**そのうえで、**製造業ならではの部分**を押さえておくと話が通じます。**交替制の勤務がある、安全衛生委員会がある、工場ごとに就業の条件が違うことがある。**面接で「製造業の人事は、交替制の勤務の管理があると伺っています」と言えるだけで、**調べてきた人**として受け取られます。**法令の経験が無いことを、応募しない理由にしないでください。**

### 技術職です。土木や建築の経験は使えますか

**使えます。**工場は**建物と設備の集合体**なので、**施設の管理、修繕の計画、設備の更新の発注**を担う職種があります。役所で**工事の発注と監督**をしていた方なら、**仕様書の作成、業者との協議、検査**の経験がそのまま重なります。**消防法や建築基準法にもとづく点検・届出**を扱っていた方は、**工場側の対応する業務に直接つながります。**探し方は、**「設備管理」「施設管理」「工務」**といった職種名です。**製造業の求人は、職種名が会社ごとに違う**ので、**仕事内容の欄を読んで判断してください。**なお、**製品の技術の知識は、入ってから覚える前提**で構いません。

### 年齢が高めです。未経験の業界に移れますか

**職種によります。****環境・安全、法務、経理**のような機能の職種では、**行政での実務の年数が、そのまま経験として読まれます。**とくに、**許認可や検査を長く担当してきた方**は、**年数が不利になりにくい**です。理由は、この分野の担当者が**社内で育てられていて、外から来る人が少ないから**です。ただし、**役職の名称は、そのままでは評価に結びつきません。**「課長補佐を◯年」ではなく、**「◯◯法にもとづく届出の審査を年間◯件、立入検査を◯件実施」**という形で、**担った範囲と件数**で書いてください。**扱った法令の名前を必ず入れる**ことが、この業界では特に効きます。
