応募の書類は、**2通で1組**です。

**履歴書と、職務経歴書。**ところが、**同じことを2回書いている書類**をよく拝見します。履歴書の職歴欄に部署と期間が並び、職務経歴書の冒頭にも同じ部署と期間が並ぶ。**読む側から見ると、1通目で得た情報が2通目で増えません。**

**2通には、役割の違いがあります。**

この記事では、**その分担**を決めます。職務経歴書そのものの型は[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)にあります。

## 結論：履歴書は台帳、職務経歴書は読ませる書類

| 書類 | 役割 | 読み手の使い方 |
|---|---|---|
| 履歴書 | **事実の台帳**。学歴、職歴、資格、連絡先 | 確認する。採否の判断材料ではない |
| 職務経歴書 | **読ませる書類**。何ができる人かを示す | 判断する。ここで選考が決まる |

**履歴書で差は付きません。**正確であれば足ります。**時間をかけるのは、職務経歴書のほう**です。

ただし、**履歴書の不備は減点になります。**期間の食い違い、空欄、資格の級の記載漏れ。**確認のやり取りが増えるぶん、印象に影響します。**

## 個人情報は、「目的の達成に必要な範囲内」

書く内容の範囲については、**採用する側に課されている義務**が参考になります。

**職業安定法第5条の5第1項**です。

> （中略）求職者等の個人情報（中略）を収集し、保管し、又は使用するに当たつては、その業務の目的の達成に必要な範囲内で、厚生労働省令で定めるところにより、当該目的を明らかにして求職者等の個人情報を収集し、並びに当該収集の目的の範囲内でこれを保管し、及び使用しなければならない。

**「業務の目的の達成に必要な範囲内で」**、**目的を明らかにして**収集する。

つまり、**採用の選考に必要な範囲を超えた個人情報は、そもそも集めてはならない**という建て付けです。

**応募する側も、この範囲で書けば足ります。**求められていない情報を、自分から書き足す必要はありません。

**書かなくてよい代表**は、次のとおりです。

| 項目 | 扱い |
|---|---|
| 家族の職業・続柄 | **書かない**。選考に関係しない |
| 本籍・出生地 | **書かない** |
| 住宅の状況、資産 | **書かない** |
| 思想・信条、支持政党、宗教 | **書かない** |
| 健康の状態 | 業務の遂行に関わる範囲で、必要なら面接で |

**様式にこれらの欄がある場合**は、古い様式である可能性があります。**別の様式を使って差し支えありません。**

## どちらに何を書くか

| 項目 | 履歴書 | 職務経歴書 |
|---|---|---|
| 学歴 | ◯（最終学歴から） | ✕ |
| 在籍の期間・所属 | ◯（正式名称で） | ◯（機能の説明とセットで） |
| 役職 | ◯（任用の年月） | ◯（人数・権限とセットで） |
| 担当した業務の中身 | ✕（1行の概要まで） | ◯ |
| 実績 | ✕ | ◯ |
| 資格 | ◯（正式名称・取得年月） | ◯（実務の量を添える） |
| 志望動機 | ◯（欄があれば） | 原則✕ |
| 自己PR | 欄があれば簡潔に | ◯（本体） |
| 通勤時間・扶養 | ◯（欄があれば） | ✕ |

**履歴書の職歴欄は、「◯年◯月　◯◯市役所　入庁」から始めて、異動を年月で並べれば足ります。**中身は職務経歴書に書きます。

**異動が多い場合、履歴書の職歴欄に全部の異動を書くと、それだけで欄が埋まります。**その場合は、**入庁・主な異動・現職の3点**に絞り、**「詳細は職務経歴書に記載」**と書いて構いません。

## 整合を取る3点

**2通の間で食い違いやすいのは、この3つ**です。

| 確認する点 | よくある食い違い |
|---|---|
| 在籍の期間 | 異動の年月が、職務経歴書と1か月ずれている |
| 役職に就いた時期 | 履歴書に書いていない役職が、職務経歴書に出てくる |
| 資格の名称と取得年 | 履歴書は正式名称、職務経歴書は略称で書いている |

**提出の前に、この3点だけは突き合わせてください。**面接で食い違いを指摘されると、**中身と関係のないところで時間を使います。**

**役所の名称の書き方も揃えてください。**「◯◯市」「◯◯市役所」「◯◯市役所 ◯◯部 ◯◯課」。**履歴書は正式名称、職務経歴書は部署名まで**という使い分けが自然です。

:::insight
履歴書でいちばん相談が多いのが、**異動の扱い**です。「3年ごとに9回異動しているが、全部書くべきか」という質問を受けます。**結論としては、全部書かなくて構いません。**履歴書の職歴欄は、**採用と退職の事実を示す欄**です。同じ団体の中での異動は、**厳密には職歴の変更ではありません。**そのうえで、**主な異動を数件だけ書く**のは、経歴の幅を示すうえで有効です。選ぶ基準は、**応募先に関係する部署**です。一方、**職務経歴書のほうには、すべての異動を反映させてください。**ただし、書き方は在籍ごとではなく、**機能ごとにまとめる形**です。**履歴書は時系列で薄く、職務経歴書は機能で厚く。**この分担にすると、2通の役割が重なりません。異動の整理の仕方は[異動が多い公務員の職務経歴書の並べ方](senko-shokumu-ido.html)にまとめています。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 送付状を付けるかどうか

**郵送する場合は、送付状を1枚付けてください。**内容は、**宛先、日付、氏名と連絡先、応募する職種、同封した書類の一覧、簡単な挨拶**で足ります。**A4で1枚、10行程度**です。

**データで送る場合は、本文がその代わり**になります。応募する職種と、添付した書類の内容を書いてください。**本文が1行だけのまま送るのは避けたほうが確実**です。

**送付状で選考の結果が変わることはありません。**ただし、**同封した書類の一覧があると、受け取る側の確認が早くなります。**役所で文書を送るときに添える鑑と、考え方は同じです。

## 履歴書の実務

| 項目 | 実務 |
|---|---|
| 様式 | 指定がなければ、職歴欄が広いものを選ぶ |
| 写真 | 指定があれば貼る。スーツ、3か月以内が目安 |
| 日付 | **提出する日**（作成日ではない） |
| 学歴 | 最終学歴の1つ前から書けば足りる |
| 賞罰 | **欄があり、該当がなければ「なし」** |
| 本人希望欄 | 「貴社の規定に従います」で足りる |

**「賞罰」の欄は、庁内の表彰を書く欄ではありません。**該当がなければ「なし」と書いてください。

**本人希望欄に、勤務地や職種の希望を細かく書く必要はありません。**制約がある場合（通勤の範囲、勤務の時間帯など）は、**具体的に1行で書いてください。**書かずに入社後に判明するほうが、双方にとって困ります。

[経験の言い換えから相談する](../apply.html)こともできます。

## よくある失敗

**1. 2通に同じことを書く**

**履歴書は台帳、職務経歴書は読ませる書類。**役割を分けてください。

**2. 履歴書に力を入れすぎる**

**差が付くのは職務経歴書**です。時間の配分を間違えないでください。

**3. 期間と役職が食い違う**

**提出の前に3点を突き合わせ**てください。

**4. 求められていない個人情報を書く**

**選考に関係しない情報**は、書かなくて構いません。

**5. 賞罰欄に庁内の表彰を書く**

**「なし」で足ります。**

**6. 本人希望欄を空欄にする**

**「貴社の規定に従います」**と書いてください。制約があれば1行で。

:::insight
ここまで書き分けの話をしておいて逆のことを言いますが、**履歴書の準備に時間をかけすぎないでください。**この2通のうち、**選考の結果を動かすのは職務経歴書**です。履歴書は、**1度作れば応募先が変わっても使い回せます。**日付と、志望動機の欄だけを差し替えれば足ります。面談で拝見していて、**履歴書を手書きで何通も書き直している方**がいます。**その時間は、職務経歴書の要約欄を作り直すほうに使ったほうが、結果が変わります。**加えて、**在職中の方は、書類を作る時間そのものが限られています。**優先順位を間違えると、応募できる件数が減ります。**履歴書は正確に、短時間で。職務経歴書に時間をかける。**この配分を守ってください。応募先が決まっていない段階のほうが、整理する意味があります。
:::

## まとめ

- **履歴書は事実の台帳、職務経歴書は読ませる書類**です。**差が付くのは後者**です
- **職業安定法第5条の5第1項**は、求職者等の個人情報を**業務の目的の達成に必要な範囲内で、目的を明らかにして収集**することを求めています
- **家族の職業、本籍、資産、思想・信条**は、書く必要がありません
- 履歴書の職歴欄は、**入庁・主な異動・現職**に絞って構いません。中身は職務経歴書に書きます
- **在籍の期間・役職の時期・資格の名称**の3点は、提出の前に突き合わせてください
- **本人希望欄は「貴社の規定に従います」。**制約があれば1行で具体的に書きます

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 履歴書の職歴欄に、異動を全部書かないと経歴を隠していると思われませんか

**思われません。**同じ団体に継続して在籍している事実は、**入庁の年月と現職が書かれていれば示せます。**むしろ、**異動を9行並べると、職歴欄が埋まって現職が見えにくくなります。**選び方としては、**応募先に関係する部署と、役職が変わった時期**を優先してください。そのうえで、**「詳細は職務経歴書に記載」**と一言添えれば、確認の手間も生じません。職務経歴書のほうには、**すべての在籍を一覧の表で載せておく**と、突き合わせができます。

### 在職中です。履歴書の職歴の最後はどう書きますか

**「現在に至る」**と書きます。退職の予定が決まっている場合は、**「◯年◯月　◯◯市役所　退職予定」**と書いても構いませんが、**退職の手続きが確定していない段階では書かないでください。**面接の場で、**「内定をいただいた場合、退職の手続きに◯か月程度を見込んでいます」**と伝えれば足ります。なお、**年度の途中で退職する場合の実務**は、所属の規程で手続きの時期が決まっていることがあります。**先に確認しておくと、入社の時期の相談がしやすくなります。**

### 職務経歴書に自己PRを書くと、履歴書の自己PR欄と重複します

**履歴書の欄は短く、職務経歴書のほうを本体にしてください。**履歴書の自己PR欄が小さい場合は、**3〜4行で要点だけ**を書き、**「詳細は職務経歴書に記載」**と添えれば足ります。内容を変える必要はありません。**同じ主張を、長さを変えて2か所に置く**という考え方です。職務経歴書の自己PRは、**能力の主張・業績の裏づけ・応募先での再現の3ブロック**で書きます。作り方は[自己PRの作り方｜公務員の実績を民間の言葉にする](senko-shokumu-jikopr.html)に整理しています。
