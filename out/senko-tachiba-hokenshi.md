**行政で働く保健師・看護師からのご相談**です。

**資格があるため、選べる範囲は広い**という特徴があります。

この記事では、**行政ならではの経験**と、**見る領域**を扱います。

## 資格が、法律で定義されています

**保健師助産師看護師法第2条**です。

> **この法律において「保健師」とは、厚生労働大臣の免許を受けて、保健師の名称を用いて、保健指導に従事することを業とする者をいう。**

**同法第5条**です。

> **この法律において「看護師」とは、厚生労働大臣の免許を受けて、傷病者若しくはじよく婦に対する療養上の世話又は診療の補助を行うことを業とする者をいう。**

**免許に基づく資格**であるため、**勤務先が変わっても持ち運べます。**

**多くの公務員の職種では、経験を民間の言葉に言い換える作業が必要**です。

**資格職は、その作業が小さい**という特徴があります。

**一方、「行政でしかできない経験」**もあります。

**そこを書けるかどうかで、読まれ方が変わります。**

## 行政ならではの経験

| 要素 | 内容 |
|---|---|
| ① 地区を単位とした把握 | **個人ではなく、集団を見る** |
| ② 計画の策定 | 健康増進、母子保健、介護予防などの計画 |
| ③ 法に基づく事務 | 感染症、精神保健、難病、母子保健 |
| ④ 関係機関との連携 | 医療、福祉、学校、警察、保健所 |
| ⑤ 統計・データの扱い | 健診の結果、罹患の状況、事業の評価 |
| ⑥ 事業の企画・運営 | 健診、教室、相談の窓口 |
| ⑦ 予算・委託の管理 | 事業の予算、委託先の管理 |

**①と⑤が、民間で希少**です。

**個人の支援だけでなく、集団の傾向を把握して事業に反映する**という動作は、**病院での勤務では得にくい**ものです。

**⑦について。**

**事業の予算を組み、委託先を管理した経験**は、**運営の側の仕事につながります。**

## 書き方の例

**悪い例**

> ◯◯市で、保健師として勤務しました。

**良い例**

> ◯◯において、**母子保健の事業を担当。**年間約◯件の乳幼児健診の企画・運営と、**健診の結果に基づく個別の相談◯件**を実施。**地区の状況を分析し、◯か年の計画の策定に参画。****医療機関・福祉の窓口・学校と連携し、支援が必要な世帯◯件について、関係機関の会議を運営。****委託事業◯件の仕様の作成と履行の確認**を担当。

**「件数」「分析」「連携」「委託の管理」**が入っています。

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 言い換えの対応

| 行政の言葉 | 民間での読まれ方 |
|---|---|
| 保健指導 | **面談、行動の変容の支援** |
| 地区診断 | 集団の分析、課題の抽出 |
| 計画の策定 | 中期の計画、施策の設計 |
| 事業の企画・運営 | 企画、運営、進行の管理 |
| 健診の実施 | 検査の運営、結果の管理 |
| 関係機関との連携 | 部門間・社外との調整 |
| 委託の管理 | 外部の委託先の管理 |
| 統計の作成 | データの集計、効果の測定 |

**1行目と2行目です。**

**「相手の行動が変わるように働きかける」**という動作は、**産業の保健や、健康に関するサービスでそのまま業務**になります。

## 見る領域

| 領域 | 内容 |
|---|---|
| ① 企業の健康の管理 | **産業の保健、健康の経営** |
| ② 健診の機関 | 健診の運営、結果の説明 |
| ③ 保険・共済 | 給付の審査、健康の支援 |
| ④ 医療機関・介護 | 看護、相談、連携の窓口 |
| ⑤ 健康に関するサービス | 保健の指導、教材、システム |
| ⑥ 自治体が相手の事業 | **保健の事業の受託、システム** |

**①と⑥が、行政の経験と重なります。**

**①について。**

**企業の中で、従業員の健康の管理を担う役割**があります。

**個別の相談と、集団の傾向の把握**の両方を行うため、**行政での動作に近い**ものです。

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 何を担当したか | **事業、件数、対象** |
| 難しい対応の経験 | 3件、経緯と結論 |
| データの扱い | 分析と、事業への反映 |
| 連携の経験 | 相手と、進め方 |
| 保有する資格 | **免許と、その他の資格** |

**3行目です。**

**数字を扱った経験は、聞かれたときに答えられるよう整理**しておいてください。

**「健診の結果から◯◯の傾向を把握し、翌年度の事業に反映」**という形です。

**なお、特定の対象者が分かる説明は避けてください。**

**守秘の義務は、退職した後も続きます。**

:::insight
行政の保健師・看護師の方のご相談で、**面談でお伝えしているのが「集団を見てきた経験を書いてください」**という点です。多くの方が、**個別の相談や支援の経験を中心に書かれます。**それも大切ですが、**病院や施設で働いてきた方も、同じことを書きます。**差がつくのは、**集団の傾向を把握し、事業として組み立てた経験**のほうです。地区の状況を分析し、課題を絞り、事業を企画し、予算を組み、実施し、評価して翌年に反映する。**この一巡は、行政でしか回せません。**そして、**企業の健康の管理や、健康に関するサービスでは、この動作がそのまま必要**とされます。従業員全体の健診の結果を見て、どこに課題があるかを判断し、施策を設計する。**やっていることは同じ**です。書類には、**「◯◯の傾向を分析し、事業を企画・実施のうえ、評価を翌年度に反映」**と書いてください。ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 準備の順序

| 順 | やること |
|---|---|
| 1 | 担当した事業と対象を書き出す |
| 2 | 件数、対象の数を確認する |
| 3 | **分析・計画・評価に関わった場面を書き出す** |
| 4 | 委託・予算に関わった経験を書き出す |
| 5 | 民間の言葉に置き換える |
| 6 | 求人を読む |

**3と4が要**です。

**この2つが、資格を持つ他の方と差がつく部分**です。

[経験の言い換えから相談する](../apply.html)こともできます。

## 在職中の進め方

| 項目 | 内容 |
|---|---|
| 記録 | 担当した事業、件数、対象 |
| 資格の確認 | 保有するもの、取得できるもの |
| 求人を読む | 週に30分 |
| 日程の確保 | **健診・事業の集中する時期を避ける** |

**4行目です。**

**健診や事業の時期は、分野ごとに異なります。**

**自分の繁忙期を書き出してから、選考の時期を決めてください。**

**扱いは**[選考スケジュールの組み方](senko-sagasu-schedule.html)**に整理しています。**

## よくある失敗

**1. 個別の支援だけを書く**

**集団を見た経験**で差がつきます。

**2. 件数・対象の数を書かない**

**規模が伝わりません。**

**3. 計画の策定への関与を書かない**

**施策の設計**として読まれます。

**4. データの扱いを書かない**

**効果の測定**として読まれます。

**5. 委託・予算の経験を書かない**

**運営の側**の仕事につながります。

**6. 医療機関だけを見る**

**企業の健康の管理**も領域です。

**7. 繁忙期に選考を始める**

**健診の時期を確認**してください。

**8. 特定の対象者が分かる説明をする**

**守秘の義務は退職後も続きます。**

:::insight
ここまで集団の話をしておいて逆のことを言いますが、**「相手が拒否できる関係で支援してきた」という点も、書ける材料です。**面談で拝見していると、この点を当たり前だと思っている方がいらっしゃいます。ところが、**行政の保健の事業は、原則として相手の同意のうえで進みます。**訪問を断られることもある、助言が受け入れられないこともある。**その中で、関係を作り、必要な支援につなげてきた。**この経験は、**顧客との関係を長く保つ仕事**——健康に関するサービス、保険、介護の相談、企業の健康の管理——で必要とされます。**指示ではなく、納得を作る。**書類には、**「継続的な関わりが必要な◯件について、訪問と電話により関係を維持し、必要な支援につないだ」**という形で書いてください。**強制力のない関係で成果を出してきた**という点は、伝われば強い材料です。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **保健師助産師看護師法第2条・第5条**は、**保健師を「保健指導に従事することを業とする者」**、**看護師を「療養上の世話又は診療の補助を行うことを業とする者」**と定義しています
- **免許に基づく資格**であるため、**勤務先が変わっても持ち運べます**
- 差がつくのは、**行政でしかできない経験**です
- **集団の傾向を把握し、事業として組み立てた経験**を書いてください
- **計画の策定、データの扱い、委託・予算の管理**を書いてください
- **企業の健康の管理**は、行政での動作に近い領域です
- **強制力のない関係で成果を出してきた**点も、材料になります

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 臨床の経験が少ないと、医療機関には移りにくいですか

**求人の条件によります。**病棟での勤務を前提とする求人では、**臨床の経験が要件**とされることがあります。一方、**相談の窓口、連携の担当、健診の運営、訪問の部門**では、**行政での経験が評価される**ことがあります。判断の目安は、**求人票の応募条件**です。なお、**医療機関以外にも領域があります。**企業の健康の管理、健診の機関、保険、健康に関するサービス。**これらでは、臨床より、面談と分析の経験が見られる**ことがあります。**臨床の経験の有無で、範囲を狭めないでください。**

### 企業の健康の管理の仕事は、どう探せばよいですか

**職種名が分かれます。**「産業保健師」「健康管理室」「健康経営の推進」「人事（健康の管理）」など、**会社によって呼び方が違います。**このため、**職種名ではなく、仕事内容の欄**で探してください。「従業員の健康の管理」「健診の結果の管理」「面談」「ストレスに関する対応」といった記載があれば該当します。また、**健診の機関や健康に関するサービスの会社**が、企業向けに保健の指導を提供している場合もあります。**そこでの勤務という形**もあります。扱いは[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)に整理しています。

### 行政の経験を、どう数字で書けばよいですか

**3種類の数を使ってください。**1つ目は、**対象の数**。「対象者約◯名の地区を担当」「◯世帯を継続して支援」。2つ目は、**実施の件数**。「年間約◯件の健診を運営」「個別の相談を年◯件実施」。3つ目は、**関わった機関・事業の数**。「関係機関◯者との会議を運営」「委託事業◯件を管理」。**この3つがあれば、規模と範囲が伝わります。**なお、**正確な数が分からない場合、「約」で構いません。**ただし、**根拠のない数は書かないでください。**在職中に、**年度の報告や統計の資料から確認**しておくと確実です。
