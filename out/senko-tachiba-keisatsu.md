**警察官からの転職では、経験の言い換えが要になります。**

**職務の性質が、民間に対応するものを見つけにくい**ためです。

この記事では、**分け方**と、**示し方**を扱います。

## 責務が、法律で定められています

**警察法第2条第1項**です。

> **警察は、個人の生命、身体及び財産の保護に任じ、犯罪の予防、鎮圧及び捜査、被疑者の逮捕、交通の取締その他公共の安全と秩序の維持に当ることをもつてその責務とする。**

**同条第2項**です。

> **警察の活動は、厳格に前項の責務の範囲に限られるべきものであつて、その責務の遂行に当つては、不偏不党且つ公平中正を旨とし、いやしくも日本国憲法の保障する個人の権利及び自由の干渉にわたる等その権限を濫用することがあつてはならない。**

**責務の範囲が限定され、権限の濫用が禁じられている**という構造です。

**つまり、定められた範囲の中で、規律に従って職務を遂行してきた**ということです。

**この「規律に従って判断する」という動作**が、**民間で評価される部分**です。

## 経験を分ける

| 要素 | 実際にやっていること |
|---|---|
| ① 現場での判断 | 限られた情報で、その場で決める |
| ② 事実の確認 | 聴取、記録、裏づけ |
| ③ 記録の作成 | **定型に沿った、正確な文書** |
| ④ 対人の対応 | 相手が選べない状況での対応 |
| ⑤ 関係機関との連携 | 他部署、他機関、自治体 |
| ⑥ 24時間の体制 | 交替、引継ぎ |
| ⑦ 後進の指導 | 実務の指導、手順の伝達 |

**①〜③が、民間で最も使えます。**

**②と③は、調査や監査の業務にそのまま対応**します。

**④について。**

**相手を選べない状況での対応**は、顧客の対応や苦情の処理と構造が同じです。

## 書き方の例

**悪い例**

> ◯◯警察署で、地域課に勤務しました。

**良い例**

> **管内◯◯地区（世帯数約◯）を担当し、**巡回の連絡、相談の受理、各種の届出の受付を実施。**年間約◯件の相談に対応し、内容に応じて関係機関へ引き継ぎ。****事案の経過について、定められた様式に基づく記録を作成。**新規に配置された職員◯名に対する実務の指導を担当。

**「担当の範囲」「件数」「記録」「指導」**が入っています。

**⚠ 具体の事件・事故が特定される記述は避けてください。****守秘の義務は、退職した後も続きます。**

**基本の型は**[公務員の職務経歴書｜民間で読まれる形にする基本](senko-shokumu-kihon.html)**に整理しています。**

## 言い換えの対応

| 警察の言葉 | 民間での読まれ方 |
|---|---|
| 事実の確認・聴取 | **調査、ヒアリング、事実の認定** |
| 記録・書類の作成 | 報告書の作成、証跡の管理 |
| 現場での判断 | 初動の対応、リスクの判断 |
| 相談の受理 | 一次の受付、顧客の対応 |
| 関係機関との連携 | 部門間・社外との調整 |
| 交通の取締 | 基準に照らした確認と指導 |
| 警備・雑踏の管理 | 安全の管理、動線の設計 |
| 防犯の指導 | 啓発、研修、リスクの周知 |

**1行目と2行目です。**

**「調べて、裏づけて、記録に残す」**という動作は、**内部監査、保険の調査、与信の審査、コンプライアンス**の業務と重なります。

## 民間での使いどころ

| 領域 | 使える経験 |
|---|---|
| ① 安全・警備の管理 | 現場の判断、動線、体制 |
| ② 内部監査・コンプライアンス | 事実の確認、記録 |
| ③ 調査（保険・債権・与信） | 聴取、裏づけ、報告 |
| ④ 施設・イベントの運営 | 雑踏の管理、安全の計画 |
| ⑤ 顧客の対応・苦情 | 相手を選べない対応 |
| ⑥ 行政が相手の事業 | **制度と手続きの理解** |

**⑥について。**

**行政が相手の事業では、手続きの流れと文書の作法を理解している人**が求められます。

**照会、報告、協議。**

**これらの進め方を知っている点は、業務の前提になります。**

**探し方は**[公務員経験が活きる求人の探し方](senko-sagasu-kyujin.html)**に整理しています。**

## 面接で聞かれやすいこと

| 質問の趣旨 | 用意しておくこと |
|---|---|
| 何を担当したか | **範囲、件数、役割** |
| どう判断したか | 判断の手順（事案の詳細ではなく） |
| 対人の対応 | 難しい場面での進め方 |
| 交替の勤務への考え | 勤務の条件 |
| 話せる範囲 | **守秘の線引き** |

**5行目です。**

**具体の事案を話せないことは、あらかじめ伝えて差し支えありません。**

**「守秘の義務があるため、個別の事案には触れられませんが、進め方としては」**と前置きすれば、**手順の説明はできます。**

**採用する側も、この点は理解しています。**

:::insight
警察官の方のご相談で、**面談でお伝えしているのが「事案ではなく、手順を話してください」**という点です。**守秘の義務があるため、具体の事件・事故は話せません。**このため、**「話せることがない」と感じて、説明が薄くなる方**がいらっしゃいます。ところが、**採用する側が知りたいのは、事案の中身ではなく、どう進めたか**です。情報が限られる中で、何を優先したか。関係者から話を聞くとき、何を確認し、どう裏づけたか。記録に何を残し、何を残さなかったか。**これらは、事案を特定せずに説明できます。**そして、**この手順の説明こそが、調査や監査の業務での適性を示します。**書き方も同じで、**「◯◯の事案を担当」ではなく、「◯件の相談について、内容を確認のうえ、関係機関へ引き継ぎ」**という形にしてください。**守秘を守りながら、経験は伝えられます。**ご利用は無料です（紹介手数料は採用企業の負担です）。
:::

## 準備の順序

| 順 | やること |
|---|---|
| 1 | 配置された部門と期間を書き出す |
| 2 | 担当した範囲（区域、対象、件数）を確認する |
| 3 | **手順として説明できる形に整理する** |
| 4 | 民間の言葉に置き換える |
| 5 | 求人を読む |
| 6 | 職務経歴書を作る |

**3が要**です。

**「何を確認し、どう裏づけ、何を記録したか」**を、**事案を特定せずに書けるかを確かめてください。**

[経験の言い換えから相談する](../apply.html)こともできます。

## 在職中の進め方

| 項目 | 内容 |
|---|---|
| 記録 | 担当した範囲と件数（事案の詳細は書かない） |
| 制度の確認 | 退職の手続き、退職手当の扱い |
| 求人を読む | 週に30分 |
| 日程の確保 | **交替の勤務との調整** |

**4行目です。**

**交替の勤務では、日程の確保が難しい場合があります。**

**オンラインでの実施が可能かを、応募の段階で確認**してください。

**扱いは**[選考スケジュールの組み方](senko-sagasu-schedule.html)**に整理しています。**

## よくある失敗

**1. 事案の詳細を話そうとする**

**手順で説明**してください。

**2. 「話せることがない」と考える**

**事案を特定せずに説明できます。**

**3. 担当の範囲を書かない**

**区域、対象、件数**を書いてください。

**4. 記録の作成を書かない**

**報告書・証跡の管理**として読まれます。

**5. 対人の対応を書かない**

**相手を選べない対応**は希少です。

**6. 指導の経験を書かない**

**実務の伝達**として書けます。

**7. 交替の勤務との調整を後回しにする**

**面接の日程に影響**します。

**8. 守秘の線引きを伝えない**

**先に前置きすれば進みます。**

:::insight
ここまで言い換えの話をしておいて逆のことを言いますが、**警察官の経験で最も評価されるのは、「その場で決めて、後から説明できること」です。**面談で拝見していると、**判断の速さを当たり前だと思っている方**がいらっしゃいます。ところが、**民間では、判断を先送りにできる場面が多い**です。確認してから決める、上司に相談してから決める、次回までに持ち帰る。**一方、現場では、その場で決めなければならない。**しかも、**後から説明を求められる**ことを前提に、**根拠を意識しながら決めている。**この組み合わせを持つ人は、多くありません。**初動の対応が必要な業務**——設備の事故、情報の漏えい、苦情の拡大、災害時の対応——では、**この経験がそのまま使えます。**書類には、**「限られた情報のもとで対応の優先順位を判断し、事後に経過を記録」**と書いてください。在職中でも、情報収集だけでも構いません。
:::

## まとめ

- **警察法第2条**は、**責務の範囲**を定め、**権限の濫用を禁じています**。**定められた範囲で、規律に従って判断してきた**ことになります
- 経験は、**①現場での判断 ②事実の確認 ③記録 ④対人 ⑤連携 ⑥交替 ⑦指導**に分けられます
- **②と③は、調査・監査の業務にそのまま対応**します
- **事案ではなく、手順を話して**ください。事案を特定せずに説明できます
- **守秘の線引きは、先に前置き**して差し支えありません
- **相手を選べない状況での対応**は、希少な経験です
- **その場で決めて、後から説明できる**点が、最も評価されます

行政が相手の求人もまとまっています。[行政が相手の求人を見てみる](../?gov=1)。

## よくある質問

### 職務経歴書に、どこまで書いてよいですか

**担当した部門、期間、範囲、件数、役割**までは書けます。**書かないのは、個別の事案が特定される記述**です。事件名、発生の日時と場所、関係者が分かる記述。**これらは避けてください。**書き方は、**「◯◯地区を担当し、年間約◯件の相談に対応」「定められた様式に基づく記録を作成」**という形です。**動作と範囲で書く**と、守秘を守りながら経験が伝わります。**判断に迷う記述は、書かないでください。**なお、**在職中の確認は、所属の担当に照会**できます。**記載の範囲について、一般的な説明を求めて差し支えありません。**

### 交替の勤務で、面接の時間が取れません

**先に伝えてください。**「交替の勤務のため、日程の調整に制約がある」という事情は、**伝えれば調整の対象**になります。**オンラインでの実施、平日の日中以外の時間帯**など、対応できる範囲は会社によって異なります。なお、**紹介を通す場合、日程の調整を任せられます。**勤務の形を伝えておけば、**調整が可能な先を優先して示す**こともできます。扱いは[転職エージェントの使い方](senko-sagasu-agent.html)に整理しています。**準備（範囲の整理、手順の言語化）は、勤務の合間に進められます。**

### 体力や年齢を理由に、選考で不利になりますか

**求人の条件によります。**警備や現場の管理の業務では、**勤務の形（夜間、立ち仕事、交替）が条件として示される**ことがあります。一方、**調査、監査、コンプライアンス、顧客の対応**などでは、**体力よりも、事実の確認と記録の正確さ**が見られます。**応募条件の欄を読んで判断**してください。**労働施策総合推進法第9条**は、**募集及び採用について、年齢にかかわりなく均等な機会を与えなければならない**と定めています。年齢の記載がある求人では、**その理由が示されている**ことがあります。**年代より、経験の中身で判断**してください。
