部署別 / 税務課

税務課の働き方と評価｜納期が一年の形を決めている

2026年9月時点の公開情報にもとづきます。制度や募集要項は変わることがあるため、手続きの前に各機関の公式情報をご確認ください。

税務課の働き方について、先に言えることがあります。

一年の形が、納期で決まっています。

しかも、税目ごとに納期が違います。だから一年中どこかで納期が来るという状態になります。この構造を知っておくと、転職活動の時期を決めるときに迷いが減ります。

この記事では、その構造を条文から確認したうえで、評価のされ方と、民間に移ったあとに何が変わるかを扱います。

言い換えは税務課の経験は民間で何と呼ばれるか、行き先は税務課からの転職先、書類と面接は職務経歴書と面接に分けています。

納期は、法律が月を決めて、条例が日を決めます

地方税法第320条は、普通徴収の方法によって徴収する個人の市町村民税の納期は、6月、8月、10月及び1月中（税額が均等割額に相当する金額以下である場合は6月中）において、当該市町村の条例で定めるとしています。ただし特別の事情がある場合は異なる納期を定めることができる、と続きます。

第362条第1項は、固定資産税の納期は、4月、7月、12月及び2月中において、当該市町村の条例で定めるとしています。こちらも特別の事情がある場合の例外が置かれています。

法律が月を枠づけ、条例が日を確定する。そして、2つの税で納期の月が重なっていません。

個人住民税は6月・8月・10月・1月。固定資産税は4月・7月・12月・2月。

合わせると、3月と5月と9月と11月以外は、毎月どこかの納期が来ます。

納期が来れば、その後に督促があり、催告があり、納付相談があります。税務課に「何も来ない月」がないのは、この構造から来ています。

税務課の一年

自治体によって時期の細部は違いますが、おおむね次の流れになります。

時期主な仕事
1月給与支払報告書の受付と処理、個人住民税の第4期納期
2月固定資産税の第4期納期、確定申告の受付応援
3月確定申告データの受領、当初課税に向けた資料の突合
4月固定資産税の当初課税と納税通知書の発送、第1期納期
5〜6月個人住民税の当初課税と通知書の発送（最大の山）、特別徴収税額通知、第1期納期
7月固定資産税の第2期納期、当初課税後の問い合わせ対応
8月個人住民税の第2期納期
9〜11月滞納整理が本格化。催告、財産調査、差押え
10月個人住民税の第3期納期
12月固定資産税の第3期納期、年末の催告
通年更正・決定、減免の判断、審査請求への対応

山は2つあります。当初課税の時期（4〜6月）と、滞納整理が集中する時期（9〜11月）です。

前者は発送期限が動かない仕事で、後者は時効までに手をつけなければならない仕事です。性質が違います。

そして3年に一度、固定資産の評価替えが入ります。この年度は、評価の作業が通年で上に乗ります。

転職活動の時期を、この波から逆算する

面接は平日日中に入ることが多く、1社で複数回あります。4月から6月の当初課税の時期は避けたほうが無難です。発送の期限が動かないためです。

比較的まとまった時間を作りやすいのは、当初課税が終わって問い合わせが落ち着いた7月から8月、または年明けの2月から3月です。滞納整理は通年ですが、期間の調整が効きやすい仕事でもあります。

現実的な組み立てはこうなります。

  1. 当初課税が片付いた7月に書類を作る
  2. 7月から8月に2社ほど受けて、説明の詰まる場所を直す
  3. 9月から11月の滞納整理の時期は、進んでいる1社だけに絞る
  4. 年明けに再開する

評価替えの年度に当たっている場合は、それを通してから動く判断にも十分な理があります。3年に一度しか来ない機会で、扱う件数が桁違いになるためです。

税務課の評価は、なぜ扱いが難しいのか

税務課には、収納率という分かりやすい指標があります。ほかの部署には、ここまではっきりした数字がありません。

ただし、この指標には特徴があります。

1つ目は、自分の力だけでは動かないことです。収納率は、地域の経済環境、雇用の状況、自治体の人口構成に左右されます。同じ働き方をしても、年によって上下します。

2つ目は、上げ方に幅がないことです。税率も課税対象も条例で決まっているので、値引きや条件の変更で数字を作ることはできません。できるのは、手をかける順序を変えることと、手続を速くすることだけです。

3つ目は、下がったときだけ問われることです。上がって当然、下がると原因を説明しなければならない。

この構造は、不満として語らないでください。転職の面接でこれを不満の形で出すと、次の職場でも同じことを言うと思われます。

構造として説明してください。「自分の裁量で動かせる部分が限られた指標を、順序の設計と手続の速さで動かしてきた」と言えれば、それはそのまま管理指標を扱える人として読まれます。

庁内の言葉と、求人票の言葉

働き方に関わる部分を置き換えると、次のようになります。

庁内での言い方求人票での言い方
当初課税の発送スケジュール管理大量処理の進行管理、締切管理
納期ごとの収納状況の把握入金消込、売掛金の期日管理
滞納案件の区分と順序の設計業務設計、優先順位の設計
催告・財産調査の計画回収計画、アクションプランの設計
収納率の管理指標の管理、モニタリング
評価替えの作業管理一斉更新の進行管理、プロジェクト推進
確定申告の受付応援繁忙期の要員配置、業務平準化

このうち、働き方として直接伝わるのは「大量処理の進行管理」と「優先順位の設計」です。民間でも請求や回収は件数が多く、期日が動かない仕事なので、そこを回してきた経験として説明すると通りやすくなります。

財政・会計の経験が効く求人を見てみる

エージェントベストの見解

税務課の方が民間に移って最初に戸惑うのは、「相手を選べるようになること」です。税務課は課税対象を選べません。払える人も払えない人も、全部引き受けたうえで回収します。民間の債権管理では、そもそも与信の段階で取引しない選択ができます。そして、回収が難しい相手は最初から絞られている前提で仕事が組まれています。この違いは、慣れれば有利に働きます。「相手を選べない前提で件数をさばいてきた人」は、選べる環境に入ると手数が余ります。一方で、与信の判断そのものは経験していない領域なので、そこは入ってから学ぶ部分になります。面接では「与信の工程に関わるかどうか」を確認しておいてください。

民間に移ると、何が変わるか

1. 相手を選べるようになる

上に書いたとおりです。与信の判断は経験していない領域なので、そこは学ぶ前提になります。

2. 期日の性質が変わる

法律と条例で決まった納期から、契約で決まった支払期日に変わります。動かせないという点は同じですが、交渉で変わる場合があります。

3. 指標が増える

収納率という1つの指標から、回収率、滞留日数、貸倒率、1件あたりのコストといった複数の指標に変わります。見る数字が増えるぶん、どこを動かすかを自分で選べるようになります。

4. 自力執行ができなくなる

これがいちばん大きい違いです。地方税法では、督促から一定期間を経て徴税吏員が財産を差し押えなければならないとされていますが、民間では裁判所の手続が必要です。手を出せる範囲が狭くなるので、その前の段階での交渉が重くなります。

在職中から残しておくとよい記録

評価の構造は変えられませんが、記録の残し方は自分で決められます。在職中からやっておくと、書類を作るときに困りません。

1. 工程ごとの件数

賦課の処理件数、財産調査、差押え、分割協議、滞納処分の停止。年ごとに控えておいてください。あとから数えるのは難しくなります。

2. 区分の基準

滞納案件をどういう軸で分けたか。自分で作った基準があるなら、1枚にまとめた形で控えておいてください。

3. やめた判断

滞納処分の停止をした件数と、どの要件に当たると判断したか。取った話より差が付く材料です。

4. 評価替えで扱った物件数

3年に一度の機会なので、通したなら必ず控えておいてください。

5. 手続を速くした話

発送のスケジュールを組み替えた、調査の照会先の順序を変えた、催告の文面を変えた。収納率という指標は自分の裁量で動かしにくいぶん、「何を変えたら何が速くなったか」を残しておくと、そこが実績になります。日数で書けるとより読まれます。「調査から差押えまでが平均◯日短くなった」という形です。

つまずきやすい点

1. 当初課税の時期に活動を始めて中断する

いちばん多い形です。7月以降から始めてください。

2. 収納率だけを実績にする

自分の関与が見えません。工程ごとの件数と、順序の設計を先に置いてください。

3. 忙しさを転職理由にする

回収の仕事は民間でも繁忙期があります。理由は、やってきたことの延長で組んでください。

4. 評価の構造を不満の形で出す

構造として説明すれば強みになり、不満として出すと弱みになります。同じ事実でも、置き方で逆になります。

5. 退職時期の制度面を確認しないまま決める

退職手当や共済の扱いは在職期間で変わる部分があります。手続きの前に、必ず所属の人事担当課と共済組合で確認してください。公務員には雇用保険が適用されないため、辞めてから探すと収入のない期間がそのまま持ち出しになります（公務員に雇用保険がない理由）。

自分の場合にどの時期が動きやすいかは、一度話しながら整理したほうが早いことが多いです。どの経験に値が付くのかから相談できます。

エージェントベストの見解

ここまで時期の話をしておいて逆のことを言いますが、「落ち着いたら動く」と考えていると、動かないまま数年たちます。納期が年に8回ある以上、完全に手が空く時期は来ません。実際に動いた方に共通しているのは、当初課税が終わった直後に「書類を作る」「2社受ける」といった小さい単位で区切って進めたことです。全部を一気にやろうとすると、次の山に飲まれて止まります。逆に、いま当初課税の真ん中にいるなら、無理に始める必要はありません。書類の下書きだけ作って、発送が終わってから出すという進め方で十分間に合います。在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。

よくある質問

税務課は残業が多いと聞きますが、実際どうですか

自治体ごとの実態は公表されていないので、個別の水準をここで断定することはできません。制度から言えるのは、納期が年に8回あり、当初課税の発送期限が動かない構造になっているということです。応募先に自分の状況を説明するときは、時間数ではなく「納期が年8回あって、当初課税と滞納整理で年に2回山が来る部署でした」と構造で伝えるほうが正確に伝わります。

収納率が上がった年を実績として書いてよいですか

書いても構いませんが、それだけを実績にしないでください。収納率は地域の経済環境にも左右される数字で、読み手もそれを知っています。書くなら、自分が何を変えたのかを添えてください。「案件の区分を3軸に組み替えたうえで、収納率が◯ポイント動いた」という形なら、関与が見えます。

賦課と徴収では、忙しい時期が違いますか

違います。賦課は当初課税（4〜6月）と申告期（1〜3月）に集中し、徴収は納期の後と年度末に集中します。とくに賦課は発送期限が動かないので、この時期の面接はかなり難しくなります。徴収は時効までの猶予があるぶん、期間の調整が効きやすい面があります。自分がどちら側にいるかで、動きやすい時期が変わります。
