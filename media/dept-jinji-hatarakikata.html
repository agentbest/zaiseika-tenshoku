部署別 / 人事課

人事課の働き方と評価｜決めたことに異議を申し立てられる仕組みがある

2026年9月時点の公開情報にもとづきます。制度や募集要項は変わることがあるため、手続きの前に各機関の公式情報をご確認ください。

人事課の働き方には、他の管理部門にはない特徴があります。

決めたことに対して、正面から異議を申し立てる仕組みが制度として用意されています。

不満が出る、という話ではありません。法律に基づいた手続として、当局が応じなければならない場面があるということです。

この構造を知っておくと、自分の仕事をどう説明すればよいかが決まりますし、民間に移ったときに何が変わるかも見通せます。

言い換えは人事課の経験は民間で何と呼ばれるか、行き先は人事課からの転職先、書類と面接は職務経歴書と面接に分けています。

異議の申立ては、2つのルートがあります

地方公務員法第46条は、職員は、給与、勤務時間その他の勤務条件に関し、人事委員会又は公平委員会に対して、地方公共団体の当局により適当な措置が執られるべきことを要求することができると定めています。

これが措置要求です。職員は、当局の外にある委員会に対して、直接申し立てることができます。

もう1つが交渉です。

第55条第1項は、地方公共団体の当局は、登録を受けた職員団体から、職員の給与、勤務時間その他の勤務条件に関し、及びこれに附帯して、社交的又は厚生的活動を含む適法な活動に係る事項に関し、適法な交渉の申入れがあった場合においては、その申入れに応ずべき地位に立つとしています。

申入れがあれば、応じなければならない立場に立つ。

ただし第2項で、交渉は団体協約を締結する権利を含まないとされています。第3項では、地方公共団体の事務の管理及び運営に関する事項が交渉の対象外とされています。

つまり、話し合いには応じるが、協約は結ばない。この独特の形のなかで、人事課は勤務条件を決めています。

決めて終わりではありません。必ず、反対側からの手続が控えています。

人事課の一年

自治体によって時期の細部は違いますが、おおむね次の流れになります。

時期主な仕事
4月新採用職員の受入れ、人事異動の後処理（第1の山）
5〜7月採用試験の募集と第1次試験、人事評価の前年度分の取りまとめ
7〜9月採用試験の第2次・面接、人事委員会勧告への対応準備
10〜11月給与改定（第2の山）。勧告を受けた条例改正、職員団体との協議
12月期末・勤勉手当の支給事務、条例改正の議会対応
1〜3月人事異動の検討と内示（最大の山）、定数と組織機構の調整、条例改正
通年分限・懲戒の手続、相談対応、研修の実施、措置要求への対応

山が3回あります。新年度（4月）、給与改定（10〜11月）、人事異動（1〜3月）です。

このうち、人事異動がいちばん重くなります。全部署の要員配置を組み替える作業で、定数と組織機構の見直しが同時に走り、条例改正が絡むこともあります。

そして、措置要求や相談は、時期を選んで来ません。計画の外で時間が消える仕事が、常に一定量あります。

転職活動の時期を、この波から逆算する

面接は平日日中に入ることが多く、1社で複数回あります。1月から4月は避けたほうが無難です。人事異動の検討と内示、新年度の受入れが重なります。

比較的まとまった時間を作りやすいのは、5月から7月です。新年度が落ち着き、給与改定の時期に入る前にあたります。

現実的な組み立てはこうなります。

  1. 新年度の受入れが片付いた5月に書類を作る
  2. 5月から7月に2社ほど受けて、説明の詰まる場所を直す
  3. 10月から11月の給与改定と、1月から3月の異動の時期は止める
  4. 翌年度の5月に再開する

制度の改定に関わっている場合は、通してから動く判断にも十分な理があります。評価制度の改定や給与制度の見直しは数年に一度しか来ず、通すと書けることが大きく変わります。

人事課の評価は、なぜ扱いが難しいのか

1. 良い決定ほど、静かに終わる

人事異動が円滑に済めば、誰も何も言いません。問題が起きたときだけ、人事課の判断が問われます。

2. 公正であることが前提で、成果として数えられない

公正な選考も、正しい手続も、できていて当たり前として扱われます。

3. 異議の手続が制度として用意されている

第46条の措置要求と第55条の交渉です。決めたことに対して、必ず反対側からの手続が来る前提で仕事をします。

この3つは、不満として語らないでください。転職の面接でこれを不満の形で出すと、次の職場でも同じことを言うと思われます。

構造として説明してください。「決定に対して異議の手続が制度として用意されている環境で、決め方の説明がつく形を作ってきた」と言えれば、それはそのまま人事の適性として読まれます。

「何を決めたか」より「どう決めたか」が問われる仕事だった、という言い方が、いちばん正確です。

働き方として直接伝わるのは「人事異動の企画」と「労使協議」です。民間でも、期の切替えに合わせた配置の見直しと、労働者側との協議は避けて通れません。

財政・会計の経験が効く求人を見てみる

エージェントベストの見解

人事課の方が民間に移って最初に戸惑うのは、「決定の速さ」です。自治体では、給与も勤務条件も条例で定めるので、変えるには規則や条例の改正が要ります。職員団体との協議もあり、議会の議決まで通します。だから、決めるまでに時間がかかる代わりに、決まったことは動きません。民間では、就業規則の変更で済む範囲が広く、決めるのは速いが、あとから変わることもあります。ここで「せっかく決めたのに」と感じる方が多いのですが、制度の重さが違うだけです。むしろ、外部の手続まで通してきた人は、変更の影響範囲を見積もる目を持っています。面接では「制度を変えるとき、どこまで手続を踏んでいますか」と聞いてみてください。その会社が変更をどう扱っているかが分かります。

民間に移ると、何が変わるか

1. 決定が速くなる

上に書いたとおりです。決めるのは速いが、あとから変わることもあるという前提に慣れが要ります。

2. 異議の手続が変わる

措置要求のような、当局の外にある委員会への申立ての仕組みは民間にありません。代わりに、労働基準監督署への申告、あっせん、訴訟といったルートがあります。性質が違うので、扱い方を学び直す部分があります。

3. 数字で測られる領域が増える

採用の単価と歩留まり、離職率、研修の受講率。公務の人事では中心になりにくかった指標が、評価の軸になります。

4. 人を減らす場面が出てくる

分限は法定の事由に限られ、そもそも人を減らすための制度として作られていません。事業の再編に伴う人員の整理は、経験していない領域になります。隠さず、経験していないと言えるようにしておいてください。

在職中から残しておくとよい記録

1. 対象の規模

職員数、部署数、採用の申込者数と採用者数、評価の対象人数。あとから調べるのは難しくなります。

2. 手続の年間件数

分限・懲戒、休業の承認、手当の認定、措置要求への対応。件数は実務の量を示します。

3. 制度を変えた記録

何を、なぜ、どの手続を通して変えたか。規則改正か条例改正か、協議は何回だったか。この経歴でいちばん差が付く材料です。

4. やめた判断

廃止した手当、取りやめた通知や研修。増やした話より差が付きます。

5. 説明の記録

人事課の仕事は、決め方を説明できるかどうかで評価が変わります。議題ごとに、どういう材料を出して、どう説明したかを控えておいてください。協議の場で使った資料の構成、措置要求に対する当局の説明の組み立て方、異動の方針をどう庁内に伝えたか。「決めたこと」ではなく「決め方」の記録が、そのまま職務経歴書の材料になります。とくに、反対があった議題で最終的にどう収めたかは、あとから思い出しにくいので、その場で1行残しておくと役に立ちます。

つまずきやすい点

1. 異動の時期に活動を始めて中断する

いちばん多い形です。5月以降から始めてください。

2. 忙しさを転職理由にする

人事は民間でも繁忙期があります。理由は、やってきたことの延長で組んでください。

3. 評価されにくさを不満の形で出す

構造として説明すれば強みになり、不満として出すと弱みになります。同じ事実でも、置き方で逆になります。

4. 制度の改定の途中で動く

通すと書けることが大きく変わります。「関わった」と「通した」では読まれ方が違います。

5. 異動の可能性を検討しないまま動く

人事課は、企画課、財政課、総務課、事業課のいずれとも接続します。庁内で移る選択肢を一度も検討していないなら、先にそちらを確かめたほうが選択肢は減りません。

6. 退職時期の制度面を確認しないまま決める

退職手当や共済の扱いは在職期間で変わる部分があります。人事課にいると制度は分かりますが、自分のこととして計算していない方が多いです。手続きの前に、必ず所属の人事担当課と共済組合で確認してください。

自分の場合にどの時期が動きやすいかは、一度話しながら整理したほうが早いことが多いです。どの経験に値が付くのかから相談できます。

エージェントベストの見解

ここまで時期の話をしておいて逆のことを言いますが、「異動が落ち着いたら動く」と考えていると、動かないまま数年たちます。人事課の一年は、異動が終われば採用が始まり、採用が終われば給与改定が来ます。完全に区切りがつく瞬間は来ません。実際に動いた方に共通しているのは、新年度が落ち着いた5月に「書類を作る」「2社受ける」といった小さい単位で区切って進めたことです。全部を一気にやろうとすると、次の山に飲まれて止まります。逆に、いま制度の改定の真ん中にいるなら、無理に始める必要はありません。通してから動くほうが、書ける材料は確実に厚くなります。在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。

よくある質問

人事課は残業が多いと聞きますが、実際どうですか

自治体ごとの実態は公表されていないので、個別の水準をここで断定することはできません。制度から言えるのは、人事異動・給与改定・新年度の受入れという3つの山が制度の日程で決まっていて、加えて措置要求や相談が計画の外で発生する構造だということです。応募先に説明するときは、時間数ではなく「山が年3回あって、そのうえ時期を選ばない対応が一定量ある部署でした」と構造で伝えるほうが正確に伝わります。

措置要求に対応した経験は、面接で話せますか

話せます。ただし、個別の事案ではなく、手続の形で話してください。「勤務条件に関する要求について、事実関係を確認し、当局としての説明を整理して委員会に提出した」という形なら、個人に触れずに済みます。民間でいえば苦情対応や係争対応にあたり、経験者は多くありません。

人事の経験が長いほど、転職しやすいですか

必ずしもそうではありません。年数より、どの領域をどこまで通したかが問われます。とくに、制度を変えた経験があるかどうかで、応募できる求人が変わります。運用だけが長い場合は、労務の方向のほうが説明しやすくなります。領域ごとの違いは人事課からの転職先に整理しています。
