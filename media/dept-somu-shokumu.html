部署別 / 総務課

総務課の職務経歴書｜書き方と、そのまま使える記述例

2026年9月時点の公開情報にもとづきます。制度や募集要項は変わることがあるため、手続きの前に各機関の公式情報をご確認ください。

総務課の職務経歴書で、いちばん多い1行目はこれです。

「総務課にて庶務、文書、例規等を担当。」

事実です。ただ、読んだ側には何も残りません。しかも「庶務」という言葉は、民間では指示された作業をこなす役割として読まれます。

実際にやっていたのは、規程を作り、条文を書き、外部からの請求に期限内に応え、争いになったときに手続を通す仕事です。まったく別の職種として書けます。

この記事では、総務課の仕事を職務経歴書にどう落とすかを、悪い例と良い例を並べて整理します。

言い換えの一覧は総務課の経験は民間で何と呼ばれるかに、行き先の選び方は総務課からの転職先に分けて書いています。

「公正の確保と透明性の向上」が、仕事の基準です

書き方の前に、一つ押さえます。

行政手続法第1条第1項は、この法律が、処分、行政指導及び届出に関する手続並びに命令等を定める手続に関し、共通する事項を定めることによって、行政運営における公正の確保と透明性（行政上の意思決定について、その内容及び過程が国民にとって明らかであることをいう）の向上を図り、もって国民の権利利益の保護に資することを目的とすると定めています。

透明性の意味が、条文の括弧の中で定義されています。

「意思決定について、その内容及び過程が明らかであること」。

内容だけではありません。過程もです。何を決めたかに加えて、どうやって決めたかが分かる状態にしておく。これが行政手続の基準です。

なお、条例に基づく処分などは第3条第3項で適用除外とされていますが、第46条が地方公共団体は、この法律の規定の趣旨にのっとり、行政運営における公正の確保と透明性の向上を図るため必要な措置を講ずるよう努めなければならないとしています。多くの自治体が行政手続条例を持っているのは、このためです。

だから職務経歴書に書くべきなのは、担当した事務の名前ではありません。どういう手続を設計し、決め方をどう見える形にしたかです。

書類全体の形を決める

総務課の場合、応募先の領域を先に決めてから書くのが鉄則です。範囲が広いので、全部並べると何の人か分からなくなります。

  1. 職務要約（5〜8行。応募する領域を先頭に）
  2. 担当業務（箇条書き。領域ごとに分ける）
  3. 実績（3〜4件。応募する領域のものを2件以上）
  4. 活かせる経験・スキル（応募先に合わせて並べ替える）

読まれるのは職務要約と実績です。時間は実績に使ってください。

職務要約の書き方

悪い例

> ◯◯市役所に入庁後、市民課、福祉課を経て総務課に配属。文書管理、例規、情報公開、選挙等の事務を担当。現在は総務課主査として庶務全般に従事している。

事務の名前が並んでいるだけです。

良い例（法務の求人に出す場合）

> 市役所に入庁後、市民課と福祉課で計8年、総務課で6年。総務課では例規を中心に担当し、条例◯件・規則◯件の改正を、条文の作成から議会の議決まで通しで担当した。改正にあたっては、上位法との整合、庁内の他の例規との整合、施行日と経過措置の設計、関係する例規の同時改正までを整理している。施行後は、各課からの解釈の照会に年間◯件対応した。あわせて、文書管理規程の改定（保存年限の見直しと廃棄の手続の整備）、情報公開請求への対応（年間◯件）、審査請求の手続（年間◯件）も担当した。

違いは4つです。

1. 応募する領域（例規）が先頭に来ている2. どこからどこまで通したかが書いてある（条文の作成から議会の議決まで）3. 工程が分解されている（整合の確認、施行日、経過措置、同時改正）4. 施行後まで見ている（解釈の照会に対応）

4つ目が効きます。書いて終わりではなく、運用まで見た人として読まれます。

担当業務の書き方

領域ごとに分けてください。

悪い例

> ・文書、例規、情報公開、審査請求、選挙、儀式、表彰等に関する事務

これでは何も伝わりません。

良い例

> 【例規（6年）】> ・条例の改正（年間◯件、条文の作成から議会の議決まで）> ・規則・要綱の審査（年間◯件、上位法および庁内例規との整合の確認）> ・施行日と経過措置の設計、関係例規の同時改正> ・施行後の解釈の照会への対応（年間◯件）>> 【文書・記録管理（6年）】> ・文書管理規程の改定（保存年限の見直し、廃棄の手続の整備）> ・文書の収受・発送、公印の管理（年間◯件規模）>> 【開示・争訟（4年）】> ・情報公開請求への対応（年間◯件、部分開示の判断と理由の記載を含む）> ・個人情報の開示請求への対応（年間◯件）> ・審査請求の手続（年間◯件、審理員・審査会との調整）>> 【選挙（3回）】> ・投票所◯か所、従事者◯人規模の管理執行、期日前投票の運営、開票の管理

領域ごとに分けて、それぞれに年数と規模を添えます。これで、どの領域が中心だったかが一目で分かります。

実績の書き方――ここに時間を使う

実績は3〜4件に絞り、応募する領域のものを2件以上入れます。書く形は状況 → 論点 → 自分の判断 → 結果です。

悪い例

> 文書管理規程を改定し、文書管理の適正化を図った。

「適正化」しかありません。何をしたのかが分かりません。

良い例

> 【保存年限を見直し、捨てられる状態を作った】> 文書の保存年限が長い年限に寄っており、書庫が満杯で新しい文書を入れる場所がない状態が続いていた。個別に確認すると、判断に迷ったものが一律で長期の年限になっており、廃棄の手続も「担当課の判断」とだけ定められていて、実際には誰も廃棄していなかった。> そこで、文書の類型ごとに年限を定め直す作業を行い、残す理由が説明できるものだけを長期に置く形に整理した。あわせて、廃棄の手続を「保存年限が満了したものを年1回一覧にし、担当課の確認を経て決裁する」と規程に明記している。迷う類型については、判断の例を一覧にして各課に配布した。> 結果として、初年度に◯件を廃棄し、書庫の使用率が◯%に下がった。翌年度以降も同じ手続で廃棄が行われている。

長く見えますが、10行です。ここに書かれているのは「適正化」ではありません。捨てられない理由の発見、年限の定め直し、手続の明文化、そして実際に捨てられたという結果です。

「捨てる仕組みを作った」という実績は、企業でもほとんど見ません。多くの組織が「とりあえず全部残す」になっています。

実績に使える題材

総務課なら、次のような題材が使えます。

  • 保存年限を見直し、廃棄の手続を作った話（上の例）
  • 条例の改正を通した話（何が問題で、どこを変えたか）
  • 他の例規との整合の問題を見つけた話
  • 開示請求で、部分開示の判断をした話（何を根拠に分けたか）
  • 審査請求の手続を整理した話
  • 処分の通知の書き方を変えた話（理由の記載を厚くした、など）
  • 選挙で、当日の体制を組み直した話
  • 全庁の照会の様式を統一した話

方向ごとの詳細は総務課からの転職先に整理しています。

書いてはいけないこと

1. 個別の開示請求や審査請求の内容

請求者や相手方が特定できる書き方はしないでください。「部分開示とした案件で、どの条項を根拠に分けたか」という判断の構造で書きます。

2. 訴訟の具体的な争点と結果

係争中・係争後を問わず、事件の中身は書かないでください。「訴訟の対応を担当し、資料の整理と弁護士との連絡にあたった」で足ります。

3. 未公表の例規改正の内容

まだ議会に提出していない改正案の中身は書けません。通ったものだけを書いてください。

4. 公印や決裁の手順の細部

内部の統制に関わります。「公印の管理を担当」までにしてください。

この4点を外せば、書ける材料は十分に残ります。

エージェントベストの見解

書類を見ていて、総務課出身の方に共通して足りないのが「やめた・減らした」記述です。作った規程、整備した様式、増やした手続は書かれていますが、廃止した規程、統合した様式、省いた手続が書かれていません。総務課の仕事は積み上がりやすく、増えるほど全庁の負担が増えます。企業の管理部門でも、いちばん求められているのは「増やせる人」ではなく「やめられる人」です。上の良い例で廃棄の手続を作った話を選んだのは、そのためです。1件でいいので、何を、どういう理由でやめたかを書いてください。書類の通過率が変わります。

つまずきやすい点

1. 「庶務」と書く

領域の名前に置き換えてください。法務、規程整備、記録管理、事務局。

2. 領域を全部並べる

範囲が広いので、全部並べると何の人か分からなくなります。応募する領域を先頭に、他は後ろにまとめてください。

3. 例規の工程を分解しない

「例規を担当」では伝わりません。上位法との整合、条文の作成、改正の手続、施行後の解釈。どこを担当したかを書いてください。

4. 主語が消える

「規程を改定した」では、課としてなのか自分なのかが分かりません。課の成果と自分の関与を分けてください。

5. 数字に期間が付いていない

「◯件を担当」だけでは、年間なのか合計なのか分かりません。必ず期間を添えてください。

自分の経歴がどう言い換えられるかは、一度話しながら整理したほうが早いことが多いです。どの経験に値が付くのかから相談できます。

エージェントベストの見解

書き直しを勧めておいて逆のことを言いますが、書類が完成していなくても動き出して構いません。総務課の方は、文書の体裁を整える仕事をしてきているぶん、自分の書類も完璧に整えてから出そうとして、議会や選挙の時期に入って中断する例が多いです。体裁は、通る書類の条件ではありません。中身が伝わるかどうかが条件です。むしろ、1社目の書類選考の結果がいちばん精度の高い添削になります。通ればその方向で合っていますし、通らなければ何が足りないかが分かります。完成を待つより、1通出してから直すほうが早く終わります。在職中でも、情報収集だけでも構いません。ご利用は無料です（紹介手数料は採用企業の負担です）。

まとめ

  • 行政手続法第1条は、透明性を「意思決定について、その内容及び過程が明らかであること」と定義しています。内容だけでなく、過程もです
  • 地方公共団体については第46条が、この趣旨にのっとった措置を講ずるよう努めることを定めています
  • だから書類に書くのは事務の名前ではなく、どういう手続を設計し、決め方をどう見える形にしたかです
  • 「庶務」と書かないでください。民間では指示された作業をこなす役割として読まれます
  • 例規は工程を分解して書きます。上位法との整合、条文の作成、改正の手続、施行後の解釈
  • 「やめた・減らした」記述を1件入れてください。総務課の仕事は積み上がりやすく、求められているのは「やめられる人」です

よくある質問

選挙の経験は、どの領域の書類に入れますか

事務局機能やオペレーション管理を狙うなら先頭に、法務を狙うなら後ろに置いてください。選挙は期日が動かず、従事者が数百人規模で、やり直しが利かない事務です。規模と時間の数字（投票所の数、従事者の人数、期日前投票の期間、開票の所要時間）を必ず添えて書けば、大規模なオペレーションを回せる人として読まれます。

条例の改正を担当していない場合、法務の求人は難しいですか

難しくはなりますが、外す必要はありません。規則や要綱の審査を担当していたなら、それを書いてください。上位の決まりとの整合を確認する作業は同じです。ただし、「条文の作成から議決まで通した」経験があるほうが強いのは確かなので、通す機会が近いなら、それを待つ判断にも理があります。

情報公開請求の対応は、実績として書けますか

書けます。ただし、請求の内容ではなく、判断の構造で書いてください。「年間◯件に対応し、うち部分開示とした◯件について、どの条項を根拠に分けたかを理由に記載した」という形なら、個別の案件に触れずに済みます。「出す前提で判断してきた」という経験は、開示や監査が重い企業で強く読まれます。
